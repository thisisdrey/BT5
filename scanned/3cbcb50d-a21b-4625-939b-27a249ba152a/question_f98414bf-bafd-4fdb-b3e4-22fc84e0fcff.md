Preconditions: attacker account exists, has signed a valid nonce, `attached_deposit` is zero so `do_auth_call` skips the `promise_result_checked_void(0)` check for wNEAR unwrap. Binding: the set of balance changes an `execute_intents` receipt commits == the set the signed intents authorise; here two intents execute concurrently against the same `token_balances` entry. Impact: Critical, double-authorised spend against the signer's own balance or a counterparty's credited balance.
