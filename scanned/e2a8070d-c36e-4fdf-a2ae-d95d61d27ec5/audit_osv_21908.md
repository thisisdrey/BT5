# [M] NULL Pointer Dereference in r_bin_ne_get_entrypoints function in radareorg/radare2

## Summary
Severity: Medium
Advisory: CVE-2022-1283
CVSS: 6.6 (CVSS:3.0/AV:L/AC:L/PR:N/UI:R/S:U/C:L/I:L/A:H)
Published: 2022-04-08
Source: https://osv.dev/vulnerability/CVE-2022-1283
Type: osv

## Details
NULL Pointer Dereference in r_bin_ne_get_entrypoints function in GitHub repository radareorg/radare2 prior to 5.6.8. This vulnerability allows attackers to cause a denial of service (application crash).
