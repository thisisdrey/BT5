# [H] Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal') in Crafty Controller

## Summary
Severity: High
Advisory: CVE-2026-0805
CVSS: 8.2 (CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:H/I:H/A:N)
Published: 2026-01-30
Source: https://osv.dev/vulnerability/CVE-2026-0805
Type: osv

## Details
An input neutralization vulnerability in the Backup Configuration component of Crafty Controller allows a remote, authenticated attacker to perform file tampering and remote code execution via path traversal.
