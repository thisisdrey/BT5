Call sequence: attacker sends a direct tx as `predecessor_account_id = victim_account_id` (i.e., attacker IS that NEAR account) -> `ensure_auth_predecessor_id` returns `predecessor_account_id` -> `internal_ft_withdraw(owner_id=predecessor, ...)`. Scoped impact: Critical for cross-chain/foreign key holders whose Verifier account name coincides with a predecessor id they don't control the NEAR keys for.
