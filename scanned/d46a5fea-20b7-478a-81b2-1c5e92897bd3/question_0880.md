# Q0880: ubalance via collateral-remove-redeem: satisfy a bound with a value the bound was never designed 

## Question
Does `collateral-remove-redeem` (mainnet/contracts/market/v0-4-market.clar:1211) let an unprivileged attacker who controls remaining zToken collateral whose price moves with the redeem reach `ubalance` (mainnet/contracts/vault/v0-vault-stx.clar:303) in a state where it satisfy a bound with a value the bound was never designed to admit?
