# [M] CVE-2019-5794

## Summary
Severity: Medium
Advisory: CVE-2019-5794
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:N)
Published: 2019-05-23
Source: https://osv.dev/vulnerability/CVE-2019-5794
Type: osv

## Details
Incorrect handling of cancelled requests in Navigation in Google Chrome prior to 73.0.3683.75 allowed a remote attacker to perform domain spoofing via a crafted HTML page.
