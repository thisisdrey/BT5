# [M] CVE-2015-8688

## Summary
Severity: Medium
Advisory: CVE-2015-8688
CVSS: 5.4 (CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:L/I:L/A:N)
Published: 2016-01-15
Source: https://osv.dev/vulnerability/CVE-2015-8688
Type: osv

## Details
Gajim before 0.16.5 allows remote attackers to modify the roster and intercept messages via a crafted roster-push IQ stanza.
