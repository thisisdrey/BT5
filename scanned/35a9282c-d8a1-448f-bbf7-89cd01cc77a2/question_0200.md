# Q0200: normalize via collateral-remove-redeem: satisfy a bound with a value the bound was never designed 

## Question
Does `collateral-remove-redeem` (mainnet/contracts/market/v0-4-market.clar:1211) let an unprivileged attacker who controls remaining zToken collateral whose price moves with the redeem reach `normalize` (mainnet/contracts/market/v0-4-market.clar:576) in a state where it satisfy a bound with a value the bound was never designed to admit? Given that it divides by `(pow u10 decimals)` only AFTER multiplying amount by price, making the protocol's USD unit a whole dollar, the invariant that no position row exists that the position mask does not represent breaks and the result is protocol insolvency.

- Expected Immunefi impact: Critical - protocol insolvency
