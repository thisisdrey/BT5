# [H] PowerShell Direct Elevation of Privilege Vulnerability

## Summary
Severity: High
Advisory: BIT-powershell-2025-49734
Aliases: CVE-2025-49734
Ecosystem: Bitnami
Published: 2025-10-03
Source: https://osv.dev/vulnerability/BIT-powershell-2025-49734
Type: osv

## Affected
- Bitnami: `powershell` — affected >=7.5.0 <7.5.3

## Details
Improper restriction of communication channel to intended endpoints in Windows PowerShell allows an authorized attacker to elevate privileges locally.
