# [H] Onyx incident: Onyx protocol suffered a security breach, resulting in a loss of over $3.8 million. The attacker exploited a known precision issue

## Summary
Severity: High
Target: Onyx
Loss: $ 3,800,000
Attack method: Contract Vulnerability
Published: 2024-09-26
Source: https://x.com/OnyxDAO/status/1839444120060023167
Type: slowmist-incident

## Details
Onyx protocol suffered a security breach, resulting in a loss of over $3.8 million. The attacker exploited a known precision issue in the Compound V2 code. Additionally, the NFTLiquidation contract failed to properly validate untrusted user input, allowing the attacker to inflate the self-liquidation reward amount, which further worsened the losses.
