# [H] Yii PHP Framework arbitrary PHP scripts execution

## Summary
Severity: High
Advisory: GHSA-74qv-rv53-5wcx
CVE: CVE-2014-4672
CWE: CWE-94
Ecosystem: Packagist
Published: 2022-05-17
Source: https://github.com/advisories/GHSA-74qv-rv53-5wcx
Type: github-advisory

## Affected
- Packagist: `yiisoft/yii` — affected >=1.1.14 <1.1.15

## Details
The CDetailView widget in Yii PHP Framework 1.1.14 allows remote attackers to execute arbitrary PHP scripts via vectors related to the value property.
