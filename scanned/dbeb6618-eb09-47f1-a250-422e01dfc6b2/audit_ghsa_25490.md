# [H] ZCatalog plug-in for Zope allows anonymous users to bypass access restrictions

## Summary
Severity: High
Advisory: GHSA-7944-h5rw-qmjx
CVE: CVE-2002-0688
Ecosystem: PyPI
Published: 2022-04-30
Source: https://github.com/advisories/GHSA-7944-h5rw-qmjx
Type: github-advisory

## Affected
- PyPI: `zope` — affected >=2.4.0 <2.6.0

## Details
ZCatalog plug-in index support capability for Zope 2.4.0 through 2.5.1 allows anonymous users and untrusted code to bypass access restrictions and call arbitrary methods of catalog indexes.
