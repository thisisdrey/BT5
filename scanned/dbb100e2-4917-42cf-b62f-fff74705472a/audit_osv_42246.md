# [M] Apache Ranger: Logs contain replayable JWT bearer tokens

## Summary
Severity: Medium
Advisory: CVE-2026-65945
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N)
Published: 2026-08-10
Source: https://osv.dev/vulnerability/CVE-2026-65945
Type: osv

## Details
Logs contain replayable JWT tokens in Apache Ranger versions <= 2.8.0
Users are recommended to upgrade to version 2.9.0, which fixes this issue.
