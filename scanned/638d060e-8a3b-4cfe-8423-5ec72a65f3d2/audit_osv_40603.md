# [M] Frappe CRM: Authentication Bypass via Logged Invitation Keys in crm/api

## Summary
Severity: Medium
Advisory: CVE-2026-53761
Aliases: GHSA-wqrv-q8m5-qr77
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:N/VC:N/VI:H/VA:N/SC:N/SI:N/SA:N)
Published: 2026-09-04
Source: https://osv.dev/vulnerability/CVE-2026-53761
Type: osv

## Details
Frappe CRM is an open-source customer relationship management tool. Prior to version 1.73.0, there is an authentication bypass vulnerability via logged invitation keys in crm/api. This issue has been patched in version 1.73.0.
