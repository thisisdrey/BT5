# [M] Jenkins Git client Plugin has an OS command injection vulnerability on agents in Git client Plugin

## Summary
Severity: Medium
Advisory: GHSA-v8hg-m323-jvjq
CVE: CVE-2025-67640
CWE: CWE-78
Ecosystem: Maven
CVSS: CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:U/C:L/I:L/A:L (CVSS_V3)
Published: 2025-12-10
Source: https://github.com/advisories/GHSA-v8hg-m323-jvjq
Type: github-advisory

## Affected
- Maven: `org.jenkins-ci.plugins:git-client` — affected >=0 <6.4.1

## Details
Jenkins Git client Plugin 6.4.0 and earlier does not not correctly escape the path to the workspace directory as part of an argument in a temporary shell script generated by the plugin, allowing attackers able to control the workspace directory name to inject arbitrary OS commands.
