# [C] Apache Ranger: Privilege Escalation via URL Parameter

## Summary
Severity: Critical
Advisory: CVE-2026-40920
CVSS: 9.8 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
Published: 2026-08-10
Source: https://osv.dev/vulnerability/CVE-2026-40920
Type: osv

## Details
Privilege Escalation via URL Parameter is reported in Apache Ranger versions <= 2.8.0.

Users are recommended to upgrade to version 2.9.0, which fixes this issue.
