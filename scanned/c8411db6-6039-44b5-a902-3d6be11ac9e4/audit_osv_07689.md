# [H] Apache Thrift: Swift Compact Protocol integer overflow

## Summary
Severity: High
Advisory: BIT-thrift-2026-41605
Aliases: CVE-2026-41605
Ecosystem: Bitnami
Published: 2026-04-29
Source: https://osv.dev/vulnerability/BIT-thrift-2026-41605
Type: osv

## Affected
- Bitnami: `thrift` — affected >=0 <0.23.0

## Details
Integer Overflow or Wraparound vulnerability in Apache Thrift.

This issue affects Apache Thrift: before 0.23.0.

Users are recommended to upgrade to version 0.23.0, which fixes the issue.
