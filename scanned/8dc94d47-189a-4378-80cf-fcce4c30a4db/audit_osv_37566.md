# [H] Combodo iTop: Unauthorized access to object information via search operation

## Summary
Severity: High
Advisory: CVE-2026-31936
Aliases: GHSA-3r3r-j29m-3v43
CVSS: 8.8 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H)
Published: 2026-08-21
Source: https://osv.dev/vulnerability/CVE-2026-31936
Type: osv

## Details
Combodo iTop is a web based IT service management tool. Prior to 3.2.3, users can access to unauthorized object information through the search operation. This issue has been fixed in version 3.2.3.
