`Deltas` (`contracts/defuse/core/src/engine/state/deltas.rs`) tracks `internal_add_balance`/`internal_sub_balance` calls per `(owner_id, token_id)` and `Engine::finalize` calls `self.state.finalize()` which is asserted (per `DefuseError::InvariantViolated`) to check the deltas net out. Does `finalize()` verify that EVERY token's summed delta across ALL accounts touched in the batch equals exactly zero (true conservation), or only that individual per-account subtractions didn't underflow? Construct a `MultiPayload` batch with two independent signers whose `TokenDiff`s each individually pass `internal_apply_deltas` (no underflow) but whose combined deltas for a shared `TokenId` sum to a positive residual (net credit with no matching debit anywhere in the batch or existing balance) — does `execute_intents` commit this batch, and if so does ANY subsequent call ever detect that the Verifier now owes more `token_balances` for that `TokenId` than it custodies? Binding: sum of all `Deltas` entries for a given `TokenId` across one `execute_intents` call == 0. Impact: Critical, batch-level conservation break inflates total owed balance with no reconciling debit. Proof idea: `cargo test` submitting a two-signer batch whose `TokenDiff`s sum to a net-positive delta on one `TokenId` (e.g. both signers include `+1` on the same token with no offsetting `-1` from either), asserting whether `execute_intents` panics via `InvariantViolated` or silently commits.
