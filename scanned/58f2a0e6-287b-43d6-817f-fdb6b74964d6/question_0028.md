# Q0028: find-collateral-amount via liquidate-redeem: satisfy a bound with a value the bound was never designed 

## Question
Does `liquidate-redeem` (mainnet/contracts/market/v0-4-market.clar:1604) let an unprivileged attacker who controls the borrower targeted reach `find-collateral-amount` (mainnet/contracts/market/v0-4-market.clar:609) in a state where it satisfy a bound with a value the bound was never designed to admit?
