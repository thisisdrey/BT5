# [M] CVE-2011-1136

## Summary
Severity: Medium
Advisory: CVE-2011-1136
CVSS: 4.7 (CVSS:3.1/AV:L/AC:H/PR:L/UI:N/S:U/C:N/I:H/A:N)
Published: 2019-11-14
Source: https://osv.dev/vulnerability/CVE-2011-1136
Type: osv

## Details
In tesseract 2.03 and 2.04, an attacker can rewrite an arbitrary user file by guessing the PID and creating a link to the user's file.
