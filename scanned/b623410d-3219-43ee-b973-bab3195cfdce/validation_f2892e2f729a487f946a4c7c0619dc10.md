### Title
`set_full_admin` in `pallet-psm` accepts an unvalidated arbitrary origin, allowing permanent, unrecoverable loss of all Full-privilege administration - (File: `substrate/frame/psm/src/lib.rs`)

### Summary
The external report's core broken invariant is: a privileged role that gates safety-critical administrative functions (pause/unpause, fee/ceiling recovery) can be irrevocably discarded through a normal, unguarded call, with no protocol-level safeguard preventing the loss. `pallet-psm` has a direct structural analog: `set_full_admin` lets the current `full_admin` reassign itself to an arbitrary `T::PalletsOrigin` value with zero validation that the new value is a reachable, dispatchable origin. Once set to an unreachable origin, every Full-gated operation on that PSM instance — including the ability to ever fix the mistake — becomes permanently inaccessible.

### Finding Description
`PsmManagerLevel::can_manage_admins()` restricts reassignment of both `full_admin` and `emergency_admin` to the `Full` level only: [1](#0-0) 

`set_full_admin` performs this reassignment after checking only that the caller matches the current `full_admin`; it does not validate the `new_admin` value in any way — any encoded `T::PalletsOrigin` is accepted and swapped in via `core::mem::replace`: [2](#0-1) 

Authorization for every Full-only extrinsic (`set_minting_fee`, `set_redemption_fee`, `set_max_debt`, `set_asset_ceiling_weight`, `add_external_asset`, `remove_external_asset`, `set_full_admin`, `set_emergency_admin`, and PSM removal) is resolved by literally comparing the incoming caller against the stored `full_admin`/`emergency_admin` values with no fallback path: [3](#0-2) 

Because `set_full_admin` will accept any `PalletsOrigin` (e.g. an origin variant that can never again be produced as an incoming `OriginFor<T>` by any account, or a `Signed` origin whose key is deliberately burned/unknown), the current `full_admin` can transition the PSM into a state where `ensure_psm_admin` can never again resolve `PsmManagerLevel::Full` for any future call. Since `can_manage_admins()` is Full-only, this also means `emergency_admin` can never be reassigned afterward either — even the `Emergency` role becomes permanently frozen if it ever needs replacing (e.g. its key is compromised or lost), because only `Full` could have fixed that, and `Full` is gone.

This is the exact same broken invariant as the external report: privileged administrative control that is required to keep the vault/PSM safely operable (adjusting debt ceilings, disabling a compromised external asset, fee correction) can be permanently and irrecoverably severed via a normal, intended call path, with no override, no two-step confirmation, and no "sealing" flag required from governance.

### Impact Explanation
If a PSM's `full_admin` is set to an unreachable origin (by operator error, a buggy governance proposal, or intentional "finalization" mirroring the exact renounce-ownership pattern in the report), the instance permanently loses the ability to:
- Add/remove approved external assets (`add_external_asset`/`remove_external_asset`),
- Adjust debt ceilings and per-asset ceiling weights (`set_max_debt`, `set_asset_ceiling_weight`),
- Adjust minting/redemption fees,
- Replace a compromised or lost `emergency_admin`,
- Remove the PSM instance to recover the creation deposit.

Since `emergency_admin` retains only `can_set_circuit_breaker`, if the emergency key is ever lost/compromised after `full_admin` is bricked, there is no longer any way to halt or resume the PSM's minting/redemption paths at all, which can lead to a permanent lock of the debt ceiling in a stuck state and, combined with `AllDisabled` circuit breaker status, permanent lock of user funds queued for redemption within that PSM instance — matching the "permanent user-fund lock" impact class.

### Likelihood Explanation
This requires only a single call by the current `full_admin` (who is already trusted to manage the instance) with a malformed/unreachable `new_admin` argument — no external attacker, relayer, or validator collusion is needed, and the call itself is part of ordinary intended functionality (`set_full_admin` is designed to be freely callable to reassign admin control). The lack of any validation on the target origin's reachability makes this a straightforward operational/config mistake as well as a plausible deliberate "finalization" action, exactly mirroring how `renounceOwnership()` was used pre-fix in the referenced report.

### Recommendation
- Restrict `new_admin` in `set_full_admin`/`set_emergency_admin` to a known-reachable class of origins (e.g. only `Signed` accounts or a small enumerated allow-list of pallet origins), rejecting origin variants that can never be produced by a dispatch.
- Alternatively, add an explicit two-step admin-transfer flow (propose + accept) so a bad target cannot silently brick the instance, analogous to `Auth2Step`'s two-step ownership transfer pattern referenced in the report.
- Consider a protocol-level safeguard requiring governance to explicitly disable further reassignment (a `sealed` flag) rather than allowing an implicit, irreversible loss of control through an ordinary call.

### Proof of Concept
1. PSM instance created with `full_admin = Signed(Alice)`, `emergency_admin = Signed(Bob)`.
2. Alice calls `set_full_admin(origin=Alice, internal_asset, new_admin=Box::new(some_origin_variant_that_can_never_be_dispatched_again))`. This succeeds because `set_full_admin` performs no validation on `new_admin` beyond type-decoding, see: [4](#0-3) 
3. Any subsequent call to `set_full_admin`, `set_emergency_admin`, `set_max_debt`, `add_external_asset`, `remove_external_asset`, etc. now fails with `DispatchError::BadOrigin` for every possible caller, because `ensure_psm_admin` can never match the stored `full_admin` again: [5](#0-4) 
4. If Bob's `emergency_admin` key is later lost or compromised, there is no remaining path to replace it (Full-only), and if the circuit breaker was left at `AllDisabled` for any external asset, minting and redemption for that pair are frozen permanently with no administrative recovery path.

		pub fn set_full_admin(
			origin: OriginFor<T>,
			internal_asset: T::AssetId,
			new_admin: Box<T::PalletsOrigin>,
		) -> DispatchResult {
			Self::ensure_psm_admin(origin, &internal_asset, |l| l.can_manage_admins())?;
			let new_admin = *new_admin;
			let old_admin = PsmAdmin::<T>::try_mutate(
				&internal_asset,
				|maybe| -> Result<T::PalletsOrigin, DispatchError> {
					let admin = maybe.as_mut().ok_or(Error::<T>::PsmNotFound)?;
					let old = core::mem::replace(&mut admin.full_admin, new_admin.clone());
					Ok(old)
				},
			)?;
			Self::deposit_event(Event::FullAdminChanged {
				internal_asset,
				old_admin: Box::new(old_admin),
				new_admin: Box::new(new_admin),
			});
			Ok(())
		}

		pub(crate) fn ensure_psm_admin(
			origin: OriginFor<T>,
			internal_asset: &T::AssetId,
			required: impl Fn(PsmManagerLevel) -> bool,
		) -> DispatchResult {
			let admin = PsmAdmin::<T>::get(internal_asset).ok_or(Error::<T>::PsmNotFound)?;
			let caller = <T as Config>::RuntimeOrigin::from(origin).into_caller();
			let level = if caller == admin.full_admin {
				PsmManagerLevel::Full
			} else if caller == admin.emergency_admin {
				PsmManagerLevel::Emergency
			} else {
				return Err(DispatchError::BadOrigin);
			};
			ensure!(required(level), Error::<T>::InsufficientPrivilege);
			Ok(())
		}
