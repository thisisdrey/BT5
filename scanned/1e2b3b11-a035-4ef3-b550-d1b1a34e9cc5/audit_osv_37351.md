# [M] Apache OFBiz: Cross-Tenant Data Exposure via Program Export Feature

## Summary
Severity: Medium
Advisory: CVE-2026-31388
CVSS: 5.3 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-31388
Type: osv

## Details
Improper Access Control vulnerability in Apache OFBiz in multi-tenant deployments.

This issue affects Apache OFBiz: before 24.09.06.

Users are recommended to upgrade to version 24.09.06, which fixes the issue.
