# [M] Moderate severity vulnerability that affects apache axis

## Summary
Severity: Medium
Advisory: GHSA-96jq-75wh-2658
CVE: CVE-2018-8032
CWE: CWE-79
Ecosystem: Maven
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N (CVSS_V3)
Published: 2018-10-16
Source: https://github.com/advisories/GHSA-96jq-75wh-2658
Type: github-advisory

## Affected
- Maven: `org.apache.axis:axis` — affected >=0
- Maven: `axis:axis` — affected >=0

## Details
Apache Axis 1.x up to and including 1.4 is vulnerable to a cross-site scripting (XSS) attack in the default servlet/services.
