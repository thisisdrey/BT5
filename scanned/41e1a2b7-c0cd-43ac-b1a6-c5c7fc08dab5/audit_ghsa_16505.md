# [H] Thelia authentication bypass vulnerability

## Summary
Severity: High
Advisory: GHSA-g8pg-33v4-9r96
CWE: CWE-287
Ecosystem: Packagist
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N (CVSS_V3)
Published: 2024-05-30
Source: https://github.com/advisories/GHSA-g8pg-33v4-9r96
Type: github-advisory

## Affected
- Packagist: `thelia/thelia` — affected >=2.0.0-beta1 <2.1.3

## Details
An authentication bypass was identifed in thelia/thelia project for customer and admin. This vulnerability is present from version 2.0.0-beta1 and is fixed in 2.1.3 and 2.2.0-alpha1.
