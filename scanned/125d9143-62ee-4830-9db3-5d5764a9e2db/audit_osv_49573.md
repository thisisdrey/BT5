# [M] CVE-2019-13743

## Summary
Severity: Medium
Advisory: CVE-2019-13743
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:N)
Published: 2019-12-10
Source: https://osv.dev/vulnerability/CVE-2019-13743
Type: osv

## Details
Incorrect security UI in external protocol handling in Google Chrome prior to 79.0.3945.79 allowed a remote attacker to spoof security UI via a crafted HTML page.
