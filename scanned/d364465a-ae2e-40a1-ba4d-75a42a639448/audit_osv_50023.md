# [H] CVE-2019-5841

## Summary
Severity: High
Advisory: CVE-2019-5841

## Details
Out of bounds memory access in JavaScript in Google Chrome prior to 75.0.3770.80 allowed a remote attacker to potentially exploit heap corruption via a crafted HTML page.
