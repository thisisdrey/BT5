# [C] Apache Cocoon Improper Restriction of XML External Entity Reference vulnerability

## Summary
Severity: Critical
Advisory: GHSA-77jg-cpw9-73vg
CVE: CVE-2023-49733
CWE: CWE-611
Ecosystem: Maven
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H (CVSS_V3)
Published: 2023-11-30
Source: https://github.com/advisories/GHSA-77jg-cpw9-73vg
Type: github-advisory

## Affected
- Maven: `org.apache.cocoon:cocoon` — affected >=2.2.0 <2.3.0

## Details
Improper Restriction of XML External Entity Reference vulnerability in Apache Cocoon. This issue affects Apache Cocoon: from 2.2.0 before 2.3.0.

Users are recommended to upgrade to version 2.3.0, which fixes the issue.
