# [M] CVE-2014-9915

## Summary
Severity: Medium
Advisory: CVE-2014-9915

## Details
Off-by-one error in ImageMagick before 6.6.0-4 allows remote attackers to cause a denial of service (application crash) via a crafted 8BIM profile.
