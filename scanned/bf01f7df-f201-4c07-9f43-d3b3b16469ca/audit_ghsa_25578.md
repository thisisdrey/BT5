# [H] MoinMoin Improper Privilege Management

## Summary
Severity: High
Advisory: GHSA-9xh4-wpx8-rg2w

Published: 2022-04-29
Source: https://github.com/advisories/GHSA-9xh4-wpx8-rg2w

## Affected
- PyPI: `Moin` — affected >=0 <1.2.3

## Details
MoinMoin 1.2.2 and earlier could allow a remote attacker to gain elevated privileges, caused by an undisclosed Access Control List (ACL) vulnerability in the PageEditor.
