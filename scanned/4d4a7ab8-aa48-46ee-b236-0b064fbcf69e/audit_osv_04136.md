# [H] Apache HTTP Server: mod_http2 denial of service

## Summary
Severity: High
Advisory: BIT-apache-2026-49975
Aliases: CVE-2026-49975
Ecosystem: Bitnami
Published: 2026-06-10
Source: https://osv.dev/vulnerability/BIT-apache-2026-49975
Type: osv

## Affected
- Bitnami: `apache` — affected >=2.4.17 <2.4.68

## Details
Memory Allocation with Excessive Size Value vulnerability in Apache HTTP Server's mod_http leads to denial of service via malicious HTTP requests.

This issue affects Apache HTTP Server: from 2.4.17 through 2.4.67.
