# [H] Unknown vulnerability in Coinbase Wallet SDK

## Summary
Severity: High
Advisory: GHSA-8rgj-285w-qcq4
Ecosystem: npm
Published: 2025-02-10
Source: https://github.com/advisories/GHSA-8rgj-285w-qcq4
Type: github-advisory

## Affected
- npm: `@coinbase/wallet-sdk` — affected >=4.0.0-beta.0 <4.3.0

## Details
### Impact
There is a security vulnerability in outdated versions of Coinbase Wallet SDK. This does not directly affect users' keys, smart contracts, or funds.

### Patches
Please update to version >= 4.3.0.
