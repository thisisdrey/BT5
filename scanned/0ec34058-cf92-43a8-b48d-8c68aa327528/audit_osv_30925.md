# [M] Apache HertzBeat: Server-Side Request Forgery (SSRF) in Api Config Oss

## Summary
Severity: Medium
Advisory: CVE-2024-56736
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N)
Published: 2025-04-16
Source: https://osv.dev/vulnerability/CVE-2024-56736
Type: osv

## Details
Server-Side Request Forgery (SSRF) vulnerability in Apache HertzBeat.

This issue affects Apache HertzBeat (incubating): before 1.7.0.

Users are recommended to upgrade to version 1.7.0, which fixes the issue.
