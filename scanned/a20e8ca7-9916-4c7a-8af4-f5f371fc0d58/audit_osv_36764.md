# [H] DataHub's LDAP Ingestion Source vulnerable to MITM attack through TLS downgrade

## Summary
Severity: High
Advisory: CVE-2026-25644
Aliases: GHSA-j34h-x7qg-4qw5
CVSS: 7.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N)
Published: 2026-02-06
Source: https://osv.dev/vulnerability/CVE-2026-25644
Type: osv

## Details
DataHub is an open-source metadata platform. Prior to version 1.3.1.8, the LDAP ingestion source is vulnerable to MITM attack through TLS downgrade. This issue has been patched in version 1.3.1.8.
