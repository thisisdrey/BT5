# [H] BIT-gitlab-2020-13321

## Summary
Severity: High
Advisory: BIT-gitlab-2020-13321
Aliases: CVE-2020-13321
Ecosystem: Bitnami
Published: 2024-03-06
Source: https://osv.dev/vulnerability/BIT-gitlab-2020-13321
Type: osv

## Affected
- Bitnami: `gitlab` — affected >=13.1.0 <13.1.2

## Details
A vulnerability was discovered in GitLab versions prior to 13.1. Username format restrictions could be bypassed allowing for html tags to be added.
