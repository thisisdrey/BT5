## Summary
Severity: Medium
Advisory: CVE-2018-19578

## Details
GitLab EE, version 11.5 before 11.5.1, is vulnerable to an insecure object reference issue that permits a user with Reporter privileges to view the Jaeger Tracing Operations page.
