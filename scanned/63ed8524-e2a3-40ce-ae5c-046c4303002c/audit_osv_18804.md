# [M] CVE-2020-36252

## Summary
Severity: Medium
Advisory: CVE-2020-36252
CVSS: 5.7 (CVSS:3.1/AV:A/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N)
Published: 2021-02-19
Source: https://osv.dev/vulnerability/CVE-2020-36252
Type: osv

## Details
ownCloud Server 10.x before 10.3.1 allows an attacker, who has one outgoing share from a victim, to access any version of any file by sending a request for a predictable ID number.
