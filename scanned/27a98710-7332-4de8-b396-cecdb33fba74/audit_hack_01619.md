# [M] ETC incident: Bitfly tweeted that today, the ETC blockchain has undergone a chain reorganization of 3693 blocks at a block height of 10904146. T

## Summary
Severity: Medium
Target: ETC
Loss: -
Attack method: The miner using the old software
Published: 2020-08-01
Source: https://www.btcfans.com/en-us/flash/id-7810
Type: slowmist-incident

## Details
Bitfly tweeted that today, the ETC blockchain has undergone a chain reorganization of 3693 blocks at a block height of 10904146. This causes all state construction nodes to stop synchronizing. The ETC blockchain did not produce blocks for nearly 6 hours, and then the block production returned to normal.
