# [M] Hyland Alfresco Transformation Service Absolute Path Traversal Arbitrary File Read and SSRF

Advisory: CVE-2026-26337
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:L/VA:N/SC:N/SI:N/SA:N)
