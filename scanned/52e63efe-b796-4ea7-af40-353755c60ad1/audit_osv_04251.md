# [H] Azure Command Line Integration (CLI) Elevation of Privilege Vulnerability

## Summary
Severity: High
Advisory: BIT-azure-cli-2025-24049
Aliases: CVE-2025-24049
Ecosystem: Bitnami
Published: 2025-07-03
Source: https://osv.dev/vulnerability/BIT-azure-cli-2025-24049
Type: osv

## Affected
- Bitnami: `azure-cli` — affected >=0 <2.69.0

## Details
Improper neutralization of special elements used in a command ('command injection') in Azure Command Line Integration (CLI) allows an unauthorized attacker to elevate privileges locally.
