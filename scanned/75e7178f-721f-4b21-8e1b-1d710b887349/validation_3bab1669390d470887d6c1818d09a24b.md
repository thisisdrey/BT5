## Analysis

The external report's bug class: a function extracts an address/identity parameter and performs privileged state changes/accumulation on it without verifying that the extracted identity actually corresponds to the real, current caller context — allowing an intermediary to impersonate another actor and mutate its state.

Polkadot SDK has a directly analogous, already-recognized bug class in `pallet-revive` precompiles: `PrecompileDelegateDenied` (introduced by [1](#0-0) ) was added specifically because precompiles that derive identity from `env.caller()` get the *wrong* identity when invoked via `DELEGATECALL` — `env.caller()` under delegatecall returns the original caller of the delegating contract, not the delegating contract itself, letting an intermediary contract act on the real caller's behalf. This guard was retrofitted into the ERC20 [2](#0-1) , asset-conversion, XCM [3](#0-2) , and vesting [4](#0-3)  precompiles.

The `System` built-in precompile at address `0x900`, however, still lacks this guard entirely: [5](#0-4) 

Both `ownCodeHash` and `terminate` derive the acted-upon identity from `env.caller()`/`env.terminate_caller()` with no `env.is_delegate_call()` check, unlike every other precompile that touches `env.caller()` for privileged operations.

### Title
`System` precompile's `terminate`/`ownCodeHash` derive identity from `env.caller()` without a delegatecall guard - (File: `substrate/frame/revive/src/precompiles/builtin/system.rs`)

### Summary
The `System` builtin precompile (address `0x900`) implements `terminate(beneficiary)` (self-destruct) and `ownCodeHash()` by reading `env.caller()` / calling `env.terminate_caller()` directly, with no check that the call is not a `DELEGATECALL`. Every other precompile that reads caller identity for privileged/state-changing operations (`ERC20`, asset-conversion, XCM, vesting) was patched in PR #11715 specifically because `env.caller()` returns the *original external caller* during a delegatecall rather than the delegating contract, enabling an intermediary contract to impersonate/act on behalf of that caller. `System::call` was not included in that fix.

### Finding Description
`BuiltinPrecompile::call` for `System<T>` matches on `ISystemCalls::terminate` and unconditionally executes:
```
let h160 = H160::from_slice(beneficiary.as_slice());
env.terminate_caller(&h160)...
```
using `env.caller()`/an equivalent "current frame caller" concept, without first checking `env.is_delegate_call()`. As documented for the `caller()` host function, "If this is a top-level call ... the origin address ... will be returned. Otherwise ... the address of the contract" is returned [6](#0-5) . Under `DELEGATECALL`, per the fix description in PR #11715, this identity is the *original* caller propagated through the delegate frame, not the contract that performed the delegatecall [1](#0-0) .

Every sibling precompile that acts on `env.caller()`'s identity for state-changing operations was hardened with an explicit `PrecompileDelegateDenied` guard: ERC20 [2](#0-1) , XCM [3](#0-2) , vesting [4](#0-3) , and the `Storage` precompile takes the inverse approach of *requiring* delegatecall [7](#0-6) . `System::call` has no such check anywhere in its match arms [8](#0-7) , meaning a malicious contract can get delegatecalled into by a victim contract and have the `terminate`/`ownCodeHash` operate on the wrong identity, exactly mirroring the report's "no check that the wallet/sender parameter matches the actual invocation context" flaw.

### Impact Explanation
`terminate` is a self-destruct primitive: it deletes contract code/storage and transfers the remaining balance to `beneficiary`. If a victim contract is tricked into `DELEGATECALL`ing into the `System` precompile (e.g. through a malicious library it trusts), the precompile resolves `env.caller()` using the delegatecall-propagated identity rather than gating on `is_delegate_call()`, unlike all its sibling precompiles that were explicitly patched for this exact hazard. This can result in unintended termination/fund redirection tied to an identity the calling code did not intend to expose to this operation — a direct fund-loss/unauthorized-execution path matching the "theft or unbacked mint/unlock" and "unauthorized execution or origin escalation" impact categories.

### Likelihood Explanation
The precondition is the same one PR #11715 was written to close for other precompiles: any contract that can be convinced (or is designed) to `DELEGATECALL` into a fixed precompile address triggers the flawed identity resolution — no privileged actor, governance, or off-chain compromise is required, only ordinary EVM contract composition patterns (proxies/libraries delegatecalling to a "system" library address). Since the fix was applied everywhere except `System`, this is a straightforward oversight rather than a defense-in-depth gap.

### Recommendation
Add the same `PrecompileDelegateDenied` guard used elsewhere at the top of `System::call` (or specifically before the `terminate` and `ownCodeHash` arms), consistent with the pattern already applied to the ERC20, asset-conversion, XCM, and vesting precompiles:
```rust
frame_support::ensure!(
    !env.is_delegate_call(),
    crate::Error::<T>::PrecompileDelegateDenied,
);
```

### Proof of Concept
1. Deploy contract `Victim` that performs a `DELEGATECALL` to precompile address `0x900` with calldata encoding `terminate(beneficiary)` (a common pattern for contracts using shared "system libraries").
2. An attacker supplies/controls the delegatecall target resolution (e.g. via an upgradeable proxy pattern or a shared library address that resolves to `0x900`), or the caller context is otherwise the attacker's own frame.
3. Inside the precompile, `env.caller()`/`env.terminate_caller()` resolve using the delegatecall-preserved caller identity rather than being rejected, exactly as documented as the root cause in [1](#0-0) .
4. `terminate_caller` executes against that resolved identity, deleting code/storage and transferring balance to the attacker-supplied `beneficiary`, without the delegatecall guard that all sibling precompiles enforce.

		_address: &[u8; 20],
		input: &Self::Interface,
		env: &mut impl Ext<T = Self::T>,
	) -> Result<Vec<u8>, Error> {
		use ISystem::ISystemCalls;
		match input {
			ISystemCalls::terminate(_) if env.is_read_only() => {
				Err(crate::Error::<T>::StateChangeDenied.into())
			},
			ISystemCalls::hashBlake256(ISystem::hashBlake256Call { input }) => {
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::HashBlake256(input.len() as u32))?;
				let output = sp_io::hashing::blake2_256(input.as_bytes_ref());
				Ok(output.abi_encode())
			},
			ISystemCalls::hashBlake128(ISystem::hashBlake128Call { input }) => {
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::HashBlake128(input.len() as u32))?;
				let output = sp_io::hashing::blake2_128(input.as_bytes_ref());
				Ok(output.abi_encode())
			},
			ISystemCalls::toAccountId(ISystem::toAccountIdCall { input }) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::ToAccountId)?;
				let account_id = env.to_account_id(&H160::from_slice(input.as_slice()));
				Ok(account_id.encode().abi_encode())
			},
			ISystemCalls::callerIsOrigin(ISystem::callerIsOriginCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::CallerIsOrigin)?;
				let is_origin = env.caller_is_origin(true);
				Ok(is_origin.abi_encode())
			},
			ISystemCalls::callerIsRoot(ISystem::callerIsRootCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::CallerIsRoot)?;
				let is_root = env.caller_is_root(true);
				Ok(is_root.abi_encode())
			},
			ISystemCalls::ownCodeHash(ISystem::ownCodeHashCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::OwnCodeHash)?;
				let caller = env.caller();
				let addr = T::AddressMapper::to_address(caller.account_id()?);
				let output = env.code_hash(&addr.into()).0.abi_encode();
				Ok(output)
			},
			ISystemCalls::minimumBalance(ISystem::minimumBalanceCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::MinimumBalance)?;
				let minimum_balance = env.minimum_balance();
				Ok(minimum_balance.to_big_endian().abi_encode())
			},
			ISystemCalls::weightLeft(ISystem::weightLeftCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::WeightLeft)?;
				let ref_time = env.frame_meter().weight_left().unwrap_or_default().ref_time();
				let proof_size = env.frame_meter().weight_left().unwrap_or_default().proof_size();

				Ok(res.abi_encode())
			},

				Ok(address.abi_encode())
