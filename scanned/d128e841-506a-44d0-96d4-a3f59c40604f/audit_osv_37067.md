# [C] FreePBX: Authenticated SQL Injection in CDR (Call Data Record) Reports

## Summary
Severity: Critical
Advisory: CVE-2026-28210
Aliases: GHSA-59gp-632h-c54v
CVSS: 9.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N)
Published: 2026-03-05
Source: https://osv.dev/vulnerability/CVE-2026-28210
Type: osv

## Details
FreePBX is an open source IP PBX. Prior to versions 16.0.49 and 17.0.7, FreePBX module cdr (Call Data Record) is vulnerable to SQL query injection. This issue has been patched in versions 16.0.49 and 17.0.7.
