# [H] MoinMoin allows administrative access

## Summary
Severity: High
Advisory: GHSA-7jrp-r6jx-32cw
CVE: CVE-2004-0708
Ecosystem: PyPI
Published: 2022-04-29
Source: https://github.com/advisories/GHSA-7jrp-r6jx-32cw
Type: github-advisory

## Affected
- PyPI: `Moin` — affected >=0 <1.2.2

## Details
MoinMoin 1.2.1 and earlier allows remote attackers to gain privileges by creating a user with the same name as an existing group that has higher privileges.
