# [M] Combodo iTop: Object can be locked by a user without write permissions

## Summary
Severity: Medium
Advisory: CVE-2026-33047
Aliases: GHSA-3qpj-3fcg-f5jc
CVSS: 4.3 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:L)
Published: 2026-08-21
Source: https://osv.dev/vulnerability/CVE-2026-33047
Type: osv

## Details
Combodo iTop is a web based IT service management tool. Prior to 3.2.3, an object can be locked by a user who is not assigned write permissions. This issue has been fixed in version 3.2.3.
