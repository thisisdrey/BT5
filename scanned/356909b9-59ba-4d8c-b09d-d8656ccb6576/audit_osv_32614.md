# [C] Dataease H2 JDBC Connection Remote Code Execution

## Summary
Severity: Critical
Advisory: CVE-2025-32966
Aliases: GHSA-h7hj-4j78-cvc7
CVSS: 9.0 (CVSS:4.0/AV:N/AC:H/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N/E:P)
Published: 2025-04-23
Source: https://osv.dev/vulnerability/CVE-2025-32966
Type: osv

## Details
DataEase is an open-source BI tool alternative to Tableau. Prior to version 2.10.8, authenticated users can complete RCE through the backend JDBC link. This issue has been patched in version 2.10.8.
