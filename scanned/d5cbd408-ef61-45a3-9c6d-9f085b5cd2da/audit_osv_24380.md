# [C] [minikube] Network Port exposure in minikube running on macOS using Docker driver

## Summary
Severity: Critical
Advisory: CVE-2023-1174
CVSS: 9.8 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
Published: 2023-05-24
Source: https://osv.dev/vulnerability/CVE-2023-1174
Type: osv

## Details
This vulnerability exposes a network port in minikube running on macOS with Docker driver that could enable unexpected remote access to the minikube container.
