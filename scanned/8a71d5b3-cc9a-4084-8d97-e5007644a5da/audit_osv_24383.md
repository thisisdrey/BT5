# [H] Missing MAC layer security in Wi-SUN Linux Border Router

## Summary
Severity: High
Advisory: CVE-2023-1262
CVSS: 8.2 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:H)
Published: 2023-03-21
Source: https://osv.dev/vulnerability/CVE-2023-1262
Type: osv

## Details
Missing MAC layer security in Silicon Labs Wi-SUN Linux Border Router v1.5.2 and earlier allows malicious node to route malicious messages through network.
