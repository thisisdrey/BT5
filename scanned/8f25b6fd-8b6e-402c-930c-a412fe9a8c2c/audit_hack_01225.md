# [M] Nereus incident: The project Nereus Finance on AVAX was attacked. The attacker made a profit of about 371,000 USDC by using the classic flash loan

## Summary
Severity: Medium
Target: Nereus
Loss: 371,000 USDC
Attack method: Flash Loan Attack
Published: 2022-09-06
Source: https://medium.com/nereus-protocol/post-mortem-flash-loan-exploit-in-single-nxusd-market-343fa32f0c6
Type: slowmist-incident

## Details
The project Nereus Finance on AVAX was attacked. The attacker made a profit of about 371,000 USDC by using the classic flash loan attack mode, namely "flash loan -> skew reserve -> fake LP token pricing -> repay the flash loan".
