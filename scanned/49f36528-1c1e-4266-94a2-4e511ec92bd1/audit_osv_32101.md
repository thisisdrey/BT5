# [H] iTop server vulnerable to portal code injection

## Summary
Severity: High
Advisory: CVE-2025-24022
Aliases: GHSA-rhv2-wfrr-4j2j
CVSS: 8.5 (CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:H/I:H/A:H)
Published: 2025-05-14
Source: https://osv.dev/vulnerability/CVE-2025-24022
Type: osv

## Details
iTop is an web based IT Service Management tool. Prior to versions 2.7.12, 3.1.3, and 3.2.1, server code execution is possible through the frontend of iTop's portal. This is fixed in versions 2.7.12, 3.1.3 and 3.2.1.
