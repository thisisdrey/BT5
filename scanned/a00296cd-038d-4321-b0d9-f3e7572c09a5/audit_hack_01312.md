# [M] Metaconz incident: The developer of Klaytn-based NFT project Metaconz tweeted that a malicious bot was installed on the administrator account of Meta

## Summary
Severity: Medium
Target: Metaconz
Loss: 11.9 ETH
Attack method: Account Compromise
Published: 2022-04-16
Source: https://twitter.com/iamdoo2/status/1515278116268421120
Type: slowmist-incident

## Details
The developer of Klaytn-based NFT project Metaconz tweeted that a malicious bot was installed on the administrator account of Metaconz’s Discord overseas team on Saturday, causing 79 users to lose 11.9 ETH (about $36,000), the team said. It promised to compensate all losses, and 53 users have so far been compensated. In addition, the developer reminded that if the user executes the setApprovalForAll function in Etherscan, please transfer the wallet unconditionally. Therefore, in this attack, the hacker used this function to deprive the victim of the wallet permission.
