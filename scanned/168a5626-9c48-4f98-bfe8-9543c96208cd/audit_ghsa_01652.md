# [H] Improper Restriction of XML External Entity Reference in jackson-mapper-asl

## Summary
Severity: High
Advisory: GHSA-r6j9-8759-g62w
CVE: CVE-2019-10172
CWE: CWE-611
Ecosystem: Maven
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:H/A:N (CVSS_V3)
Published: 2020-02-04
Source: https://github.com/advisories/GHSA-r6j9-8759-g62w

## Affected
- Maven: `org.codehaus.jackson:jackson-mapper-asl` — affected >=0

## Details
A flaw was found in org.codehaus.jackson:jackson-mapper-asl:1.9.x libraries. XML external entity vulnerabilities similar to CVE-2016-3720 also affects codehaus jackson-mapper-asl libraries but in different classes.
