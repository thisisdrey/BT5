# [M] Cross-Site Scripting in TYPO3 CMS Link Handling

## Summary
Severity: Medium
Advisory: GHSA-4j77-gg36-9864
CVE: CVE-2020-11065
CWE: CWE-79
Ecosystem: Packagist
CVSS: CVSS:3.1/AV:N/AC:L/PR:L/UI:R/S:C/C:L/I:L/A:N (CVSS_V3)
Published: 2020-05-13
Source: https://github.com/advisories/GHSA-4j77-gg36-9864
Type: github-advisory

## Affected
- Packagist: `typo3/cms-core` — affected >=10.0.0 <10.4.2
- Packagist: `typo3/cms-core` — affected >=9.0.0 <9.5.17
- Packagist: `typo3/cms` — affected >=10.0.0 <10.4.2
- Packagist: `typo3/cms` — affected >=9.0.0 <9.5.17

## Details
It has been discovered that link tags generated by `typolink` functionality are vulnerable to cross-site scripting - properties being assigned as HTML attributes have not been parsed correctly.

Update to TYPO3 versions 9.5.17 or 10.4.2 that fix the problem described.
