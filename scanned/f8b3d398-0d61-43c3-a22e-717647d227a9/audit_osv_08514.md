# [H] CVE-2016-4040

## Summary
Severity: High
Advisory: CVE-2016-4040
CVSS: 7.2 (CVSS:3.0/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:H/A:H)
Published: 2016-04-19
Source: https://osv.dev/vulnerability/CVE-2016-4040
Type: osv

## Details
SQL injection vulnerability in the Workflow Screen in dotCMS before 3.3.2 allows remote administrators to execute arbitrary SQL commands via the orderby parameter.
