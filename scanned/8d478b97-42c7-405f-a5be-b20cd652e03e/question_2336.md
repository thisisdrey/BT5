# Q2336: get-asset-value via borrow: make two code sites that must agree disagree by an attacke

## Question
Does `borrow` (mainnet/contracts/market/v0-4-market.clar:1238) let an unprivileged attacker who controls the `price-feeds` buffers reach `get-asset-value` (mainnet/contracts/market/v0-4-market.clar:679) in a state where it make two code sites that must agree disagree by an attacker-chosen amount? ## Target

- Exploit idea: `get-asset-value` resolves a fresh price for a single asset and normalizes with a caller-supplied rounding direction. Reach it through `borrow` and make two code sites that must agree disagree by an attacker-chosen amount.

- Expected Immunefi impact: Critical - protocol insolvency through uncollateralised debt
- Fast validation: Write a Clarinet simnet test calling `borrow` twice with the `price-feeds` buffers varied, and assert that the value `get-asset-value` returns is identical in both runs; a divergence confirms the finding.
