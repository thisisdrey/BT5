# Q1312: calc-liq-debt-repay via liquidate-redeem: make an aggregate and its per-item breakdown disagree

## Question
Does `liquidate-redeem` (mainnet/contracts/market/v0-4-market.clar:1604) let an unprivileged attacker who controls the seized zToken amount that is immediately redeemed reach `calc-liq-debt-repay` (mainnet/contracts/market/v0-4-market.clar:723) in a state where it make an aggregate and its per-item breakdown disagree? Given that it takes the liquidation factor times the debt with `mul-bps-down`, the invariant that a value cached within a block still describes the state it was derived from breaks and the result is direct theft of another user's collateral.
