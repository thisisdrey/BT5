# [C] Apache Ranger: Remote Code Execution Vulnerability in GraalScriptEngineCreator

## Summary
Severity: Critical
Advisory: CVE-2026-55799
CVSS: 9.8 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
Published: 2026-08-10
Source: https://osv.dev/vulnerability/CVE-2026-55799
Type: osv

## Details
Remote Code Execution Vulnerability in GraalScriptEngineCreator in Apache Ranger <= 2.8.0
Users are recommended to upgrade to version 2.9.0, which fixes this issue.
