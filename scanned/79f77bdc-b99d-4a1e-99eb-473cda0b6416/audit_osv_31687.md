# [M] GLPI allows SQL injection through the rules configuration

## Summary
Severity: Medium
Advisory: CVE-2025-21619
Aliases: GHSA-pcmc-xv3g-hjxv
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:N/VA:N/SC:H/SI:N/SA:N)

## Details
GLPI is a free asset and IT management software package. An administrator user can perfom a SQL injection through the rules configuration forms. This vulnerability is fixed in 10.0.18.
