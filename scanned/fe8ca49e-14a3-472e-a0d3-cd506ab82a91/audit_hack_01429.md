# [M] Secret Network incident: The private public chain Secret Network stated on Twitter that the main network has undergone an unplanned upgrade, from secret-2

## Summary
Severity: Medium
Target: Secret Network
Loss: -
Attack method: Contract Vulnerability
Published: 2021-09-15
Source: https://twitter.com/SecretNetwork/status/1437856678830133258
Type: slowmist-incident

## Details
The private public chain Secret Network stated on Twitter that the main network has undergone an unplanned upgrade, from secret-2 to secret-3, to prevent major network security issues from causing financial losses. The team stated that neither the native token SCRT nor the cross-chain bridge contract were affected. Only a single smart contract was affected. The contract came from SecretSwap. A vulnerability was exploited, allowing the attacker to take away the pledged SEFI contract. funds. At present, the cross-chain bridge is still closed, and the deposit function of the exchange is also closed.
