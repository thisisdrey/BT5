# [H] Apache DolphinScheduler: General user can mint admin access tokens via /access-tokens

## Summary
Severity: High
Advisory: CVE-2026-49050
CVSS: 8.8 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H)
Published: 2026-08-25
Source: https://osv.dev/vulnerability/CVE-2026-49050
Type: osv

## Details
General user can mint admin access tokens via /access-tokens



This issue affects Apache DolphinScheduler: before 3.4.2.



Users are recommended to upgrade to version 3.4.2, which fixes the issue.
