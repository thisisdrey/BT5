# [M] CVE-2018-18346

## Summary
Severity: Medium
Advisory: CVE-2018-18346
CVSS: 6.5 (CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:N)
Published: 2018-12-11
Source: https://osv.dev/vulnerability/CVE-2018-18346
Type: osv

## Details
Incorrect handling of alert box display in Blink in Google Chrome prior to 71.0.3578.80 allowed a remote attacker to present confusing browser UI via a crafted HTML page.
