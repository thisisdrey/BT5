# [M] CVE-2017-8355

## Summary
Severity: Medium
Advisory: CVE-2017-8355

## Details
In ImageMagick 7.0.5-5, the ReadMTVImage function in mtv.c allows attackers to cause a denial of service (memory leak) via a crafted file.
