# [C] Spring Security Authorization Server Dynamic Client Registration endpoints perform insufficient validation of client metadata

## Summary
Severity: Critical
Advisory: CVE-2026-22752
CVSS: 9.6 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:N)
Published: 2026-07-16
Source: https://osv.dev/vulnerability/CVE-2026-22752
Type: osv

## Details
Authentication bypass by primary weakness vulnerability in Spring Security Spring Authorization Server.

This issue affects Spring Authorization Server: from 7.0.0 through 7.0.4, from 1.5.0 through 1.5.6, from 1.4.0 through 1.4.9, from 1.3.0 through 1.3.10.
