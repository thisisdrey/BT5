# [H] Path Traversal in express-cart

## Summary
Severity: High
Advisory: GHSA-8h8v-6qqm-fwpq
CWE: CWE-22
Ecosystem: npm
Published: 2020-09-01
Source: https://github.com/advisories/GHSA-8h8v-6qqm-fwpq
Type: github-advisory

## Affected
- npm: `express-cart` — affected >=0 <1.1.7

## Details
Versions of `express-cart` before 1.1.7 are vulnerable to Path Traversal.


## Recommendation

Update to version 1.1.7 or later.
