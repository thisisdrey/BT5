# [M] Remote site authentication secrets written to web log

## Summary
Severity: Medium
Advisory: CVE-2025-2092
CVSS: 6.0 (CVSS:4.0/AV:L/AC:L/AT:P/PR:L/UI:N/VC:H/VI:N/VA:N/SC:H/SI:H/SA:H)
Published: 2025-04-22
Source: https://osv.dev/vulnerability/CVE-2025-2092
Type: osv

## Details
Insertion of Sensitive Information into Log File in Checkmk GmbH's Checkmk versions <2.3.0p29, <2.2.0p41 and <=2.1.0p49 (EOL) causes remote site authentication secrets to be written to log files accessible to administrators.
