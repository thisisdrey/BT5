Target: TonConnectPayload::try_prehash domain-separation prefixes b"txt", b"bin", and the Cell arm's distinct return path via cell::TonConnectCellMessage::hash (all in lib.rs, with the Cell hashing delegated to cell.rs). Attacker action: attacker searches for a byte string `s` and a `Cell c` such that Sha256(0xFFFF ++ 'ton-connect/sign-data/' ++ address ++ domain_len ++ domain ++ timestamp ++ b'txt' ++ len(s) ++ s) == TonConnectCellMessage{schema_crc,timestamp,user_address:&address,app_domain:&domain,payload:&c}.hash(), i.e. a Text-schema hash colliding with a Cell-schema hash for the same address/domain/timestamp. Preconditions: attacker has one legitimately-obtained user signature over a Text payload s that decodes via extract_defuse_payload into a benign DefusePayload (e.g. a zero-value intent) that the user actually reviewed and signed. Call sequence: if such a collision existed, an attacker could NOT swap the accepted content since extract_defuse_payload deserializes the literal `self.payload` field, not the hash, so this is a probe rather than a live path; the binding under test is that the hash function used for verify() is never used to look up which content gets executed. Binding: hash used by Ed25519::verify(prehash) == hash used to select which literal payload bytes extract_defuse_payload deserializes; the code must never let one signature stand in for two different literal payloads. Impact: Critical only if find_collision succeeds and the engine only checked the hash rather than storing/replaying literal bytes it received. Proof idea: cargo test asserting that for a fixed (address, domain, timestamp), TonConnectPayload{payload: TonConnectPayloadSchema::text(s)}.try_prehash() != TonConnectPayload{payload: TonConnectPayloadSchema::cell(crc,c)}.try_prehash() for a representative sample of (s, crc, c) pairs, confirming the domain-separation prefixes (b'txt' vs MESSAGE_TAG=0x75569022) keep the two hash spaces disjoint as designed, and documenting that execute_signed_intent's actual security relies on this disjointness holding for ALL inputs, not just the sampled ones.
