# [M] Apache OFBiz: Authenticated Remote Code Execution via Unsafe Template Expansion in email services

## Summary
Severity: Medium
Advisory: CVE-2026-35086
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-35086
Type: osv

## Details
Improper Control of Generation of Code ('Code Injection') vulnerability in email services of Apache OFBiz.

This issue affects Apache OFBiz: before 24.09.06.

Users are recommended to upgrade to version 24.09.06, which fixes the issue.
