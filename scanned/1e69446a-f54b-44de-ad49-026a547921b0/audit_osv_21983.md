# [H] OFFIS DCMTK NULL Pointer Dereference

## Summary
Severity: High
Advisory: CVE-2022-2121
CVSS: 7.5 (CVSS:3.1/AV:A/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H)
Published: 2022-06-24
Source: https://osv.dev/vulnerability/CVE-2022-2121
Type: osv

## Details
OFFIS DCMTK's (All versions prior to 3.6.7) has a NULL pointer dereference vulnerability while processing DICOM files, which may result in a denial-of-service condition.
