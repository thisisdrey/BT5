`Contract::simulate_intents` (contracts/defuse/src/contract/intents/mod.rs) builds `Engine::new(self.cached(), &mut inspector)` and calls `execute_signed_intents`, which internally calls `self.state.commit_nonce(...)` on the `CachedState` wrapper (contracts/defuse/core/src/engine/state/cached.rs). Craft a `MultiPayload` with a fresh, unused nonce and call `simulate_intents` only (never `execute_intents`). Binding: nonce usage state persisted in real contract storage must equal nonce usage state BEFORE the simulate call — `is_nonce_used` in real storage must be unchanged by simulation. Impact: High/Critical if simulate can mark a nonce as used in real storage, permanently burning a valid signature the owner never authorized to execute (funds later frozen, since resubmission via real `execute_intents` would falsely return `NonceUsed`). Proof: near-workspaces sandbox test calling `simulate_intents` with a signed payload, then calling `execute_intents` with the identical payload and asserting it succeeds (nonce was not consumed by simulation).
