`Timestamp::now()` is read independently inside `Engine::verify_intent_nonce` (for `NonceExpired`) and inside `Contract::is_nonce_cleanable` (for GC eligibility) — both within the SAME block could, in principle, read the same value, but they are invoked in DIFFERENT contract calls (`execute_intents` vs `cleanup_nonces`), so no single-call race exists. Binding: confirm no code path calls both within one call such that a nonce could be simultaneously accepted by `verify_intent_nonce` (not yet expired) and eligible for cleanup by `is_nonce_cleanable` (`deadline < Timestamp::now()`) — i.e. the predicates `deadline >= now` and `deadline < now` must be mutually exclusive at every instant. Impact: Critical if ever both true (opens the prefix-collision replay window mid-signature-validity). Proof: cargo test pinning a mocked `Timestamp::now()` to `deadline` exactly and asserting `verify_intent_nonce` accepts while `is_nonce_cleanable` simultaneously rejects (deadline < now is false at equality, confirming exclusivity), then one nanosecond later confirming the flip is atomic and total (no third state).
