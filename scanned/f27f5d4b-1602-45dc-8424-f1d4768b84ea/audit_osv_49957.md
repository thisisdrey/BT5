# [M] CVE-2019-5766

## Summary
Severity: Medium
Advisory: CVE-2019-5766
CVSS: 6.5 (CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:N/A:N)
Published: 2019-02-19
Source: https://osv.dev/vulnerability/CVE-2019-5766
Type: osv

## Details
Incorrect handling of origin taint checking in Canvas in Google Chrome prior to 72.0.3626.81 allowed a remote attacker to leak cross-origin data via a crafted HTML page.
