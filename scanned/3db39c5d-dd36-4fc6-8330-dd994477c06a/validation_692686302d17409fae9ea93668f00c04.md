**Rationale:**

`payout_stakers` is weighted at `T::WeightInfo::payout_stakers_alive_staked(T::MaxExposurePageSize::get())`, i.e., the *maximum possible* per-page nominator count is charged **up front**, before execution [1](#0-0) . The actual work in `do_payout_stakers_by_page` is strictly bounded by that same `MaxExposurePageSize`, since it iterates only over `exposure.others()` for a single page of the validator's exposure, and the post-dispatch weight is corrected down to `T::WeightInfo::payout_stakers_alive_staked(nominator_payout_count)` where `nominator_payout_count <= T::MaxExposurePageSize::get()` (enforced by a `debug_assert!`) [2](#0-1) .

The only "cleanup" work performed is `ledger.legacy_claimed_rewards.retain(...)`, which trims entries older than `current_era - history_depth` — this is bounded by `HistoryDepth` and does not grow with attacker-supplied input or repeated calls [3](#0-2) . `do_payout_stakers` itself does not loop over `Ledger` or `Nominators` collections; it resolves a single next claimable page via `EraInfo::<T>::get_next_claimable_page` and delegates to the single-page payout path, which cannot be repeated for the same page (`AlreadyClaimed` guard) [4](#0-3) [5](#0-4) .

Benchmarks (`payout_stakers_alive_staked` in both `substrate/frame/staking/src/benchmarking.rs` and the `staking-async` variant) linearly scale weight with `n` up to `MaxExposurePageSize`, and tests explicitly assert that charged weight scales with actual nominator count (`half_max_nom_rewarded_weight`, `max_nom_rewarded_weight`) [6](#0-5) . Since the pre-dispatch charge already assumes the worst case (`MaxExposurePageSize`) and the real per-call cost cannot exceed that bound regardless of call repetition, batching order, or state shape, there is no route to underpriced work, unbounded iteration over `Ledger`/`Nominators`, or persistent block-production degradation.

	pub(super) fn do_payout_stakers(
		validator_stash: T::AccountId,
		era: EraIndex,

		let page = EraInfo::<T>::get_next_claimable_page(era, &validator_stash, &ledger)
			.ok_or_else(|| {
				Error::<T>::AlreadyClaimed
					.with_weight(T::WeightInfo::payout_stakers_alive_staked(0))
			})?;

		Self::do_payout_stakers_by_page(validator_stash, era, page)
	}
