# [C] Apache OFBiz: Unauthenticated RCE via Default JWT Signing Key and Widget Template Injection

## Summary
Severity: Critical
Advisory: CVE-2026-31986
CVSS: 9.1 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-31986
Type: osv

## Details
Use of Hard-coded Cryptographic Key vulnerability in Apache OFBiz.

This issue affects Apache OFBiz: before 24.09.06.

Users are recommended to upgrade to version 24.09.06, which fixes the issue.
