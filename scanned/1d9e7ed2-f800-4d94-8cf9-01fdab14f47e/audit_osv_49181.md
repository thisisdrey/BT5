# [M] CVE-2018-5161

## Summary
Severity: Medium
Advisory: CVE-2018-5161
CVSS: 4.3 (CVSS:3.0/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:N/A:L)
Published: 2018-06-11
Source: https://osv.dev/vulnerability/CVE-2018-5161
Type: osv

## Details
Crafted message headers can cause a Thunderbird process to hang on receiving the message. This vulnerability affects Thunderbird ESR < 52.8 and Thunderbird < 52.8.
