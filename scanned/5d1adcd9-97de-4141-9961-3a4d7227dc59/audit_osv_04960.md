## Affected
- Bitnami: `gitlab` — affected >=13.1.0 <13.1.2

## Details
An issue has been discovered in GitLab affecting versions prior to 13.1.2, 13.0.8 and 12.10.13. Missing permission check for adding time spent on an issue.
