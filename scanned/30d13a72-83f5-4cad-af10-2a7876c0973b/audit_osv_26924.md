# [H] Livestatus injection in ajax_search

## Summary
Severity: High
Advisory: CVE-2023-6157
CVSS: 7.6 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:L/A:H)
Published: 2023-11-22
Source: https://osv.dev/vulnerability/CVE-2023-6157
Type: osv

## Details
Improper neutralization of livestatus command delimiters in ajax_search in Checkmk <= 2.0.0p39, < 2.1.0p37, and < 2.2.0p15 allows arbitrary livestatus command execution for authorized users.
