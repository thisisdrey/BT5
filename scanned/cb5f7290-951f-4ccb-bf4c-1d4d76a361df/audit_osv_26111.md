# [M] Glitch detection not active by default in Silicon Labs Secure Vault High devices

## Summary
Severity: Medium
Advisory: CVE-2023-5138
CVSS: 6.8 (CVSS:3.1/AV:P/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
Published: 2024-01-03
Source: https://osv.dev/vulnerability/CVE-2023-5138
Type: osv

## Details
Glitch detection is not enabled by default for the CortexM33 core in Silicon Labs secure vault high parts EFx32xG2xB, except EFR32xG21B.
