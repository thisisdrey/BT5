# [H] A BOLA vulnerability in POST /secretaries in EasyAppointments < 1.5.0

## Summary
Severity: High
Advisory: CVE-2023-3286
CVSS: 7.7 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:N/I:H/A:N)
Published: 2024-07-09
Source: https://osv.dev/vulnerability/CVE-2023-3286
Type: osv

## Details
A BOLA vulnerability in POST /secretaries allows a low privileged user to create a low privileged user (secretary) in the system. This results in unauthorized data manipulation.
