# [H] Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal') in Wireshark

## Summary
Severity: High
Advisory: CVE-2026-5656
CVSS: 7.0 (CVSS:3.1/AV:L/AC:H/PR:N/UI:R/S:U/C:H/I:H/A:H)
Published: 2026-04-30
Source: https://osv.dev/vulnerability/CVE-2026-5656
Type: osv

## Details
Profile import path traversal in Wireshark 4.6.0 to 4.6.4 and 4.4.0 to 4.4.14 allows denial of service and possible code execution
