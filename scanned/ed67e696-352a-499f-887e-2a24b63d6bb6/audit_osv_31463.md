# [C] MongoDB BI Connector ODBC driver installation via MSI may leave ACLs unset on custom installation directories

## Summary
Severity: Critical
Advisory: CVE-2025-12100
CVSS: 9.0 (CVSS:4.0/AV:L/AC:L/AT:P/PR:L/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H)
Published: 2025-10-23
Source: https://osv.dev/vulnerability/CVE-2025-12100
Type: osv

## Details
Incorrect Default Permissions vulnerability in MongoDB BI Connector ODBC driver allows Privilege Escalation.This issue affects BI Connector ODBC driver: from 1.0.0 through 1.4.6.
