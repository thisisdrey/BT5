# [M] Meteraphsere vulnerable to unauthorized viewing by workspace members

## Summary
Severity: Medium
Advisory: CVE-2024-32467
Aliases: GHSA-7499-q88f-mxqp
CVSS: 5.7 (CVSS:3.1/AV:N/AC:L/PR:H/UI:R/S:U/C:H/I:L/A:L)
Published: 2024-04-25
Source: https://osv.dev/vulnerability/CVE-2024-32467
Type: osv

## Details
MeterSphere is an open source continuous testing platform. Prior to version 2.10.14-lts, members without space permissions can view member information from other workspaces beyond their authority. Version 2.10.14-lts fixes this issue.
