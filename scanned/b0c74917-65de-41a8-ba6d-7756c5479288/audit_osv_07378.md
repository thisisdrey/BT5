# [H] BIT-processmaker-2022-38577

## Summary
Severity: High
Advisory: BIT-processmaker-2022-38577
Aliases: CVE-2022-38577
Ecosystem: Bitnami
Published: 2023-11-06
Source: https://osv.dev/vulnerability/BIT-processmaker-2022-38577
Type: osv

## Affected
- Bitnami: `processmaker` — affected >=0 <3.5.4

## Details
ProcessMaker before v3.5.4 was discovered to contain insecure permissions in the user profile page. This vulnerability allows attackers to escalate normal users to Administrators.
