Target: `ImtTokenId::from_str` (crates/primitives/token-id/src/imt.rs) and `State::imt_mint` (contracts/defuse/core/src/engine/state/mod.rs). Attacker signs a `MultiPayload` containing an `ImtMint` intent naming `minter_id = attacker.near` and a `token_id` string equal to `victim.near:realft` (embedding a colon to impersonate `ImtTokenId{minter_id:'victim.near', token_id:'realft'}`). Precondition: `imt` feature enabled, attacker has a valid signature over their own account, no privileged role needed since `imt_mint` is only gated by `minter_id == signer_id` inside `ImtTokens::into_generic_tokens`. Call sequence: `execute_intents` -> `State::imt_mint(minter_id=attacker.near, ...)` -> `tokens.into_generic_tokens(minter_id)` constructs `TokenId::Imt(ImtTokenId{minter_id:'attacker.near', token_id:'victim.near:realft'})` -> `self.mint(receiver_id, tokens, memo)` credits `receiver_id.token_balances`. Binding: `ImtTokenId{minter_id:'attacker.near', token_id:'victim.near:realft'}.to_string()` (`imt:attacker.near:victim.near:realft`) must not equal `to_string()` of any `TokenId::Imt(ImtTokenId{minter_id:'victim.near', token_id:'realft'})` (`imt:victim.near:realft`) or any other constructible IMT token. Scoped impact: Critical - a colliding string would let an unprivileged minter mint tokens indistinguishable from `victim.near`'s legitimately-minted IMT balance, letting the attacker's worthless mint claim a valuable existing balance. Proof idea: `cargo test` computing both `to_string()` outputs and asserting inequality, then asserting `balance_of(receiver, imt_token_for_attacker) != balance_of(receiver, imt_token_for_victim)` after only the attacker's mint runs.
