# [M] Apache Fineract: weak password policy

## Summary
Severity: Medium
Advisory: CVE-2025-23408
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:L/UI:N/VC:H/VI:N/VA:N/SC:H/SI:H/SA:H)
Published: 2025-12-12
Source: https://osv.dev/vulnerability/CVE-2025-23408
Type: osv

## Details
Weak Password Requirements vulnerability in Apache Fineract.

This issue affects Apache Fineract: through 1.10.1. The issue is fixed in version 1.11.0.

Users are encouraged to upgrade to version 1.13.0, the latest release.
