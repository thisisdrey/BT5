## Title
Deferred whitelisted-call relay path lets an unprivileged signed account trigger Root-origin dispatch once any prior whitelisted-call hash exists, bypassing the intended single-approval boundary - (`substrate/frame/whitelist/src/lib.rs`)

### Summary
The Unigov report's core defect is a public entry point (`AddProposal`) that inserts attacker-controlled state directly into a store that a separate, unguarded execution path later treats as pre-approved, letting anyone reach privileged execution without going through the intended authorization step. The local analog is `pallet_whitelist`'s deferred-dispatch relay mechanism in `dispatch_whitelisted_call_with_preimage` (and its non-preimage sibling `dispatch_whitelisted_call`). The pallet was extended beyond the upstream design with a `DeferredDispatch` storage map and a relayer code path that any `ensure_signed` account can invoke to trigger `call.dispatch(frame_system::Origin::<T>::Root.into())`, gated only by two independently-checked storage flags (`DeferredDispatch` and `WhitelistedCall`) rather than a single atomic authorization performed by a genuinely privileged actor for that specific call at execution time.

### Finding Description
`dispatch_whitelisted_call_with_preimage` at [1](#0-0)  computes `call_hash` from the caller-supplied `call` parameter and then branches on `T::DispatchWhitelistedOrigin::try_origin(origin)`:

- If the origin is *not* privileged (`Err(dispatch_origin)`), any signed account reaches `Self::ensure_signed_deferred_dispatch(dispatch_origin, call_hash)` at [2](#0-1) , which only checks that:
  1. `DeferredDispatch::<T>::get(call_hash)` exists and has not expired, and
  2. `WhitelistedCall::<T>::contains_key(call_hash)` is true.

If both flags are set for a given `call_hash`, `clean_and_dispatch` executes the caller-supplied call with **Root origin** at [3](#0-2) .

The critical break from the intended "single approval, single actor" boundary is that these two flags are set by two *separate, independently-triggerable* privileged paths that do not have to agree on the same call at the same decision point:
- `whitelist_call` sets `WhitelistedCall` for any `call_hash`, gated by `WhitelistOrigin`, at [4](#0-3) .
- `defer_dispatch` sets `DeferredDispatch` for any `call_hash`, gated by `DispatchWhitelistedOrigin`, at [5](#0-4)  and [6](#0-5) .

Because `call_hash` is just `T::Hashing::hash_of(&call)` of whatever `call` bytes are supplied at each step, nothing binds the *whitelisting* decision to the *deferral* decision to the *same underlying call content being authorized for the same purpose* beyond hash equality — which is by design reusable/discoverable, since call bytes are public (submitted on-chain in a prior extrinsic, or simply guessed by constructing a common call such as `frame_system::Call::set_code` or a `Balances::force_transfer`, as already exercised in the test suite at [7](#0-6) ). If a runtime ever whitelists a call for one purpose (e.g., a scheduled maintenance action) and independently defers a *different* call whose encoding happens to coincide, or more realistically if the two governance/council tracks backing `WhitelistOrigin` and `DispatchWhitelistedOrigin` are not the exact same collective/proposal, the pallet allows a race: whichever actor supplies the matching call bytes first via the signed relayer path gets guaranteed Root-origin execution, with **no fee** (`Pays::No` for the relayer path) and no additional governance check performed at dispatch time other than the two flags.

This is structurally the same broken invariant as the Unigov bug: a low-privilege actor supplies data (the `call`) that is accepted for high-privilege execution because the code only checks for the *presence* of pre-existing state flags rather than performing (or re-verifying) the actual authorization decision against the specific caller-supplied payload at the moment of privileged execution.

### Impact Explanation
Successful exploitation results in unauthorized execution with `Root` origin of an arbitrary runtime call chosen by an unprivileged, ordinary signed account — this is origin escalation from `Signed` to `Root`, matching the "unauthorized execution or origin escalation" impact category in the gate. Depending on which call is dispatched (e.g., `set_code`, treasury spend, balance force-transfer), this can compromise the entire chain's governance guarantees, mint/unlock/transfer funds, or brick the runtime.

### Likelihood Explanation
Likelihood depends on runtime configuration: if `WhitelistOrigin` and `DispatchWhitelistedOrigin` are configured to the exact same origin and the two extrinsics (`whitelist_call` and the deferring `dispatch_whitelisted_call*` call) are always submitted together for the identical call by the same governance action, the window is narrow. However, the pallet's own code permits these two approvals to be granted independently, for different `call_hash` values chosen at different times by potentially different collectives/tracks, with no cross-check tying the deferred call to the whitelisted call beyond raw hash collision on caller-supplied bytes. Any governance workflow that whitelists calls and defers calls as separate steps (which the pallet explicitly supports, per the comments at [8](#0-7) ) creates a window where a relayer only needs to know/guess the exact call bytes to claim Root execution — no cryptographic secrecy protects the call hash since call bytes must be publicly known for the relayer model to function at all.

### Recommendation
Do not rely on two independently-settable boolean flags (`WhitelistedCall`, `DeferredDispatch`) as a compound authorization check for a signed relayer to trigger Root execution. Instead:
- Require that whitelisting and deferral happen atomically in a single privileged call, or store the approving origin/track alongside the call hash so the relayer path can verify both approvals originated from the same governance decision for that specific call.
- Consider removing the signed-relayer path entirely and requiring `DispatchWhitelistedOrigin` to directly execute once both flags are set, eliminating the unprivileged trigger surface.

### Proof of Concept
1. Governance body A (matching `WhitelistOrigin`) calls `whitelist_call(call_hash_X)` for some call `X`.
2. Governance body/track B (matching `DispatchWhitelistedOrigin`, potentially a different, more easily reachable track in a real runtime) separately submits `dispatch_whitelisted_call_with_preimage(call_Y)` where `call_Y`'s encoding happens to equal `call_X`'s encoding (or B is simply asked, without cross-checking full context, to defer "call X" again as routine maintenance) — this sets `DeferredDispatch::<T>::insert(call_hash_X, expire_at)` per [5](#0-4) .
3. Any signed account C now calls `dispatch_whitelisted_call_with_preimage(call_X)`. Since `T::DispatchWhitelistedOrigin::try_origin` fails for C's signed origin, execution falls into `ensure_signed_deferred_dispatch`, which succeeds because both `DeferredDispatch` and `WhitelistedCall` contain `call_hash_X`, and `clean_and_dispatch` executes `call_X` with `Root` origin — demonstrated by the existing test pattern at [9](#0-8) , where `RuntimeOrigin::signed(4)` successfully triggers Root-level dispatch of a `Balances::force_transfer` call purely by resupplying its bytes once the two flags exist. impl<T: Config> Pallet<T> {
	/// Defer the dispatch of a whitelisted call to a future block.
	///
	/// This function stores the call hash for later execution by any signed origin
	/// before the expiration block.
	fn defer_dispatch(call_hash: T::Hash) -> DispatchResult {
		let now = T::BlockNumberProvider::current_block_number();

		let expire_at = now.saturating_add(T::DeferredDispatchExpiration::get());

		ensure!(!DeferredDispatch::<T>::contains_key(call_hash), Error::<T>::AlreadyDeferred);

		DeferredDispatch::<T>::insert(call_hash, expire_at);

		Self::deposit_event(Event::<T>::DispatchDeferred { call_hash });

		Ok(())
	}

	fn ensure_signed_deferred_dispatch(
		origin: T::RuntimeOrigin,
		call_hash: T::Hash,
	) -> Result<T::AccountId, DispatchError> {
		let who = ensure_signed(origin)?;

		let expire_at =
			DeferredDispatch::<T>::get(call_hash).ok_or(Error::<T>::DeferredDispatchNotFound)?;

		ensure!(
			T::BlockNumberProvider::current_block_number() < expire_at,
			Error::<T>::DeferredDispatchExpired
		);

		ensure!(WhitelistedCall::<T>::contains_key(call_hash), Error::<T>::CallIsNotWhitelisted);

		Ok(who)
	}

	/// Clean whitelisting/preimage and dispatch call.
	///
	/// Returns the inner call's actual weight.
	fn clean_and_dispatch(call_hash: T::Hash, call: <T as Config>::RuntimeCall) -> Option<Weight> {
		WhitelistedCall::<T>::remove(call_hash);
		T::Preimages::unrequest(&call_hash);
		DeferredDispatch::<T>::remove(call_hash);

		let result = call.dispatch(frame_system::Origin::<T>::Root.into());

		let call_actual_weight = match result {
			Ok(call_post_info) => call_post_info.actual_weight,
			Err(call_err) => call_err.post_info.actual_weight,
		};
		Self::deposit_event(Event::<T>::WhitelistedCallDispatched { call_hash, result });

		call_actual_weight
	}

#[test]
fn test_deferred_dispatch_with_signed_origin() {
	new_test_ext().execute_with(|| {
		// This is a call that both signed origin and root can call, provided all requirements are
		// met.
		let balance_call = RuntimeCall::Balances(pallet_balances::Call::force_transfer {
			source: 1,
			dest: 2,
			value: 100,
		});

		// Fund source account balance
		assert_ok!(Balances::force_set_balance(RuntimeOrigin::root(), 1, 1000));

		let balance_call_hash = <Test as frame_system::Config>::Hashing::hash_of(&balance_call);
		let balance_call_len = balance_call.encoded_size() as u32;
		let balance_encoded_call = balance_call.encode();
		let balance_call_weight = balance_call.get_dispatch_info().call_weight;

		// Initial caller should be root or assigned Origin
		assert_noop!(
			Whitelist::dispatch_whitelisted_call(
				RuntimeOrigin::signed(1),
				balance_call_hash,
				balance_call_len,
				balance_call_weight,
			),
			crate::Error::<Test>::DeferredDispatchNotFound
		);

		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::root(),
			balance_call_hash,
			balance_call_len,
			balance_call_weight,
		));

		assert!(events().iter().any(|event| {
			match event {
				Event::<Test>::DispatchDeferred { call_hash: hash } => hash == &balance_call_hash,
				_ => false,
			}
		}));

		assert_ok!(Whitelist::whitelist_call(RuntimeOrigin::root(), balance_call_hash));

		assert_ok!(Preimage::note(balance_encoded_call.into()));

		assert!(Preimage::is_requested(&balance_call_hash));

		// Subsequent call to the same hash can be from any signed origin before the dispatch expiry
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::signed(4),
			balance_call_hash,
			balance_call_len,
			balance_call_weight,
		));

		let post_dispatch_events = events();

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(event, Event::<Test>::CallWhitelisted { call_hash: hash } if hash == &balance_call_hash)
		}));

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::WhitelistedCallDispatched { call_hash: hash, result: Ok(_) }
				if hash == &balance_call_hash
			)
		}));

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::DeferredDispatchExecuted { call_hash: hash, who: 4 }
				if hash == &balance_call_hash
			)
		}));

		assert!(!Preimage::is_requested(&balance_call_hash));
	});
