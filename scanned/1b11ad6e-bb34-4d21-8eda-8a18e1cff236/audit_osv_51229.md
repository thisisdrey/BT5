# [M] CVE-2021-21229

## Summary
Severity: Medium
Advisory: CVE-2021-21229
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:H/A:N)
Published: 2021-04-30
Source: https://osv.dev/vulnerability/CVE-2021-21229

## Details
Incorrect security UI in downloads in Google Chrome on Android prior to 90.0.4430.93 allowed a remote attacker to perform domain spoofing via a crafted HTML page.
