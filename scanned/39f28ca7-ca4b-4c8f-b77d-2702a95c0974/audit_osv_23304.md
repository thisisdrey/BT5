# [H] Apache Traffic Server: Invalid Range header causes a crash

Severity: High
Advisory: CVE-2022-47185
CVSS: 7.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H)
