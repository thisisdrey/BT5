# Q2812: calc-index-next via repay: make two code sites that must agree disagree by an attacke

## Question
Does `repay` (mainnet/contracts/market/v0-4-market.clar:1316) let an unprivileged attacker who controls `on-behalf-of`, naming any third-party principal reach `calc-index-next` (mainnet/contracts/vault/v0-vault-stx.clar:183) in a state where it make two code sites that must agree disagree by an attacker-chosen amount?
