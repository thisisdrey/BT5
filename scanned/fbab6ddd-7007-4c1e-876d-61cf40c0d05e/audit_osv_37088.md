# [C] FreePBX: Authenticated SQL Injection Vulnerabilities in FreePBX Logfiles Module

## Summary
Severity: Critical
Advisory: CVE-2026-28284
Aliases: GHSA-4887-4jwp-327g
CVSS: 9.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N)
Published: 2026-03-05
Source: https://osv.dev/vulnerability/CVE-2026-28284
Type: osv

## Details
FreePBX is an open source IP PBX. Prior to versions 16.0.10 and 17.0.5, the FreePBX logfiles module contains several authenticated SQL injection vulnerabilities. This issue has been patched in versions 16.0.10 and 17.0.5.
