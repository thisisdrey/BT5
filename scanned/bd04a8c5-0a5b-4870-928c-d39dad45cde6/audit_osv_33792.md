# [H] Chamilo: Error-based SQL Injection via POST userFile with the /main/exercise/hotpotatoes.php script

## Summary
Severity: High
Advisory: CVE-2025-50191
Aliases: GHSA-82qx-25j7-5639
CVSS: 7.5 (CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:N/VA:H/SC:N/SI:N/SA:N)
Published: 2026-03-02

Type: osv

## Details
Chamilo is a learning management system. Prior to version 1.11.30, there is an error-based SQL Injection via POST userFile with the /main/exercise/hotpotatoes.php script. This issue has been patched in version 1.11.30.
