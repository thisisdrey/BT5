# [M] CVE-2016-6234

## Summary
Severity: Medium
Advisory: CVE-2016-6234

## Details
The process_file function in lepton/jpgcoder.cc in Dropbox lepton 1.0 allows remote attackers to cause a denial of service (crash) via a crafted jpeg file.
