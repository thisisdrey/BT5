Target: `SignerStopSignaler::send` in libsigner/src/events.rs, which POSTs to `/shutdown` on `self.local_addr`. Attacker action: any remote party who can reach the signer's bound event-receiver TCP port sends `POST /shutdown HTTP/1.1` with arbitrary body. Preconditions: the event receiver socket is reachable at all (typically same-host, but the check is purely URL-based, not source-based). Call sequence: `next_event` matches `request.url() == "/shutdown"` -> `event_receiver.stop_signal.store(true, ...)` -> returns `Err(EventError::Terminated)` -> `main_loop` breaks. Equality/fault: only the legitimate stop-signaler (the process itself) should be able to set `stop_signal`; there is no authentication distinguishing the internal self-signal connection from an arbitrary remote POST to `/shutdown`. Impact: Critical - unauthenticated remote DoS: a single crafted HTTP request permanently terminates the signer's event-receiver main loop, stopping it from ever processing further StackerDB/event traffic, a single-message denial of service.
