# [H] MANTRA Chain incident: An attacker exploited an unsigned integer underflow vulnerability in the upstream Cosmos EVM module to unauthorizedly transfer app

## Summary
Severity: High
Target: MANTRA Chain
Loss: $ 3,600,000
Attack method: Smart Contract Vulnerability
Published: 2026-08-20
Source: https://x.com/MANTRA_Chain/status/2093311678205374867
Type: slowmist-incident

## Details
An attacker exploited an unsigned integer underflow vulnerability in the upstream Cosmos EVM module to unauthorizedly transfer approximately 720.9 million MANTRA from two MANTRA-managed addresses (the burn address and a dormant genesis-era multisig). The chain was halted to contain the threat and later resumed after a v8.4.0 patch. No validator keys, admin privileges, or user funds were compromised.
