# [C] Synthetix incident: Synthetix, a synthetic asset issuance platform built on Ethereum, experienced an oracle attack which netted the attacker over 37 m

## Summary
Severity: Critical
Target: Synthetix
Loss: 35,759,524 sETH
Attack method: Database attack
Published: 2019-06-25
Source: https://www.theblockcrypto.com/tiny/synthetix-suffers-oracle-attack-potentially-looting-37-million-synthetic-ether/
Type: slowmist-incident

## Details
Synthetix, a synthetic asset issuance platform built on Ethereum, experienced an oracle attack which netted the attacker over 37 million sETH, according to Etherscan. However, the true dollar value is difficult to calculate at this time given the relative illiquidity of sETH on secondary markets.
