# [H] Possibility of SQL Injection in Spring Cloud Data Flow Task Execution Sorting Query

## Summary
Severity: High
Advisory: BIT-spring-cloud-dataflow-2020-5427
Aliases: CVE-2020-5427
Ecosystem: Bitnami
Published: 2024-03-06
Source: https://osv.dev/vulnerability/BIT-spring-cloud-dataflow-2020-5427
Type: osv

## Affected
- Bitnami: `spring-cloud-dataflow` — affected >=2.6.0 <2.6.5

## Details
In Spring Cloud Data Flow, versions 2.6.x prior to 2.6.5, versions 2.5.x prior 2.5.4, an application is vulnerable to SQL injection when requesting task execution.
