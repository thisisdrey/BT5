# Q1732: mask-update via liquidate: make an aggregate and its per-item breakdown disagree

## Question
Does `liquidate` (mainnet/contracts/market/v0-4-market.clar:1382) let an unprivileged attacker who controls which collateral and debt asset pair is targeted reach `mask-update` (mainnet/contracts/market/v0-market-vault.clar:94) in a state where it make an aggregate and its per-item breakdown disagree?
