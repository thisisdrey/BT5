# [C] Apache OFBiz: Path traversal allowing authentication bypass.

## Summary
Severity: Critical
Advisory: CVE-2024-25065
CVSS: 9.1 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N)
Published: 2024-02-28
Source: https://osv.dev/vulnerability/CVE-2024-25065
Type: osv

## Details
Possible path traversal in Apache OFBiz allowing authentication bypass.
Users are recommended to upgrade to version 18.12.12, that fixes the issue.
