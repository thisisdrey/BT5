# [M] openCart Server-Side Template Injection (SSTI) vulnerability

Severity: Medium
Advisory: GHSA-xrh7-2gfq-4rcq
CVE: CVE-2024-36694
CWE: CWE-1336, CWE-94
Ecosystem: Packagist

## Affected
- Packagist: `opencart/opencart` — affected >=0

## Details
A Server-Side Template Injection (SSTI) vulnerability in the Theme Editor Function of openCart project v4.0.2.3 allows attackers to execute arbitrary code via injecting a crafted payload.
