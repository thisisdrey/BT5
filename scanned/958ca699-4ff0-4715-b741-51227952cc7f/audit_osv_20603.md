# [C] CVE-2021-35474

## Summary
Severity: Critical
Advisory: CVE-2021-35474

## Details
Stack-based Buffer Overflow vulnerability in cachekey plugin of Apache Traffic Server. This issue affects Apache Traffic Server 7.0.0 to 7.1.12, 8.0.0 to 8.1.1, 9.0.0 to 9.0.1.
