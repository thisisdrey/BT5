# [M] XSS in Django

## Summary
Severity: Medium
Advisory: GHSA-2m34-jcjv-45xf
CVE: CVE-2020-13596
CWE: CWE-79
Ecosystem: PyPI
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N (CVSS_V3)
Published: 2020-06-05
Source: https://github.com/advisories/GHSA-2m34-jcjv-45xf
Type: github-advisory

## Affected
- PyPI: `Django` — affected >=2.2a1 <2.2.13
- PyPI: `Django` — affected >=3.0a1 <3.0.7

## Details
An issue was discovered in Django version 2.2 before 2.2.13 and 3.0 before 3.0.7. Query parameters generated by the Django admin ForeignKeyRawIdWidget were not properly URL encoded, leading to a possibility of an XSS attack.
