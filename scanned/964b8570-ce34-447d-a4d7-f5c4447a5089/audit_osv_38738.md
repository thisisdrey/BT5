# [C] Apache OFBiz: Authentication Bypass due to Improper Neutralization of LDAP Special Elements in DN Construction

## Summary
Severity: Critical
Advisory: CVE-2026-41919
CVSS: 9.1 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-41919
Type: osv

## Details
Improper Neutralization of Special Elements used in an LDAP Query ('LDAP Injection') vulnerability in Apache OFBiz.

This issue affects Apache OFBiz: before 24.09.06.

Users are recommended to upgrade to version 24.09.06, which fixes the issue.
