# [H] The Direct Mail (direct_mail) TYPO3 extension improperly discloses sensitive information

## Summary
Severity: High
Advisory: GHSA-4mh5-jj5w-3f9q
CVE: CVE-2013-7400
CWE: CWE-200
Ecosystem: Packagist
CVSS: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N (CVSS_V3)
Published: 2022-05-13
Source: https://github.com/advisories/GHSA-4mh5-jj5w-3f9q
Type: github-advisory

## Affected
- Packagist: `directmailteam/direct-mail` — affected >=0 <3.1.2

## Details
The Direct Mail (direct_mail) extension before 3.1.2 for TYPO3 allows remote attackers to obtain sensitive information by leveraging improper checking of authentication codes.
