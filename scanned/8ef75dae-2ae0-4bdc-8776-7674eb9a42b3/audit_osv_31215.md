# [H] pgAdmin 4 Installation Directory permission issue

## Summary
Severity: High
Advisory: CVE-2024-6238
CVSS: 7.4 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:L/I:L/A:L)
Published: 2024-06-25
Source: https://osv.dev/vulnerability/CVE-2024-6238
Type: osv

## Details
pgAdmin <= 8.8 has an installation Directory permission issue. Because of this issue, attackers can gain unauthorised access to the installation directory on the Debian or RHEL 8 platforms.
