Target: `Contract::nft_resolve_withdraw` (contracts/defuse/src/contract/tokens/nep171/withdraw.rs). Attacker deploys an NFT receiver whose `nft_transfer_call`'s underlying `nft_on_transfer` returns `false` (meaning 'do not keep, return the token') even though the receiver contract does NOT actually return the token on-chain (attacker's own NFT contract implementation simply keeps the token but reports the on-chain nft_transfer as successful while the app-level callback returns false, or vice versa exploits the boundary where the actual NFT ownership already transferred to receiver_id in the token contract's own state before nft_on_transfer runs). Preconditions: A owns NFT (T, token_id) inside the Verifier ledger, signs NftWithdraw{token=T, receiver_id=attacker_receiver, token_id=tid, msg=Some(x)}. Call sequence: internal_nft_withdraw debits the 1-unit NFT balance from A -> do_nft_withdraw -> nft_transfer_call moves the actual NFT to attacker_receiver in T's own contract state (this happens regardless of nft_on_transfer's return) -> attacker's nft_on_transfer returns Ok(Ok(false)) meaning used=false (not used, refund requested) -> nft_resolve_withdraw sees used=false, credits 1 unit of (T, token_id) back to sender_id A. Binding: (1 unit debited) == (1 asset that left the contract, i.e. NFT now owned by attacker_receiver in T=1) + (1 refunded to A). RHS=2 but only 1 unit ever existed — A now has an internal-ledger claim on an NFT actually owned by attacker_receiver in the real NFT contract, a phantom double-claim. Scoped impact: Critical — the Verifier now believes A owns the NFT (refunded) while the real NFT contract shows attacker_receiver as owner; a subsequent withdraw by A would attempt to move an NFT the Verifier no longer custodies (or double-move if attacker_receiver never actually returns it per NEP-171 nft_transfer_call semantics which SHOULD auto-return on false, but only if attacker's own contract honors that, which a malicious NFT contract does not have to). Proof idea: sandbox test deploying a malicious NFT contract that transfers ownership unconditionally in nft_transfer_call regardless of nft_on_transfer's boolean, then assert Verifier's internal ledger shows A's balance restored to 1 while the NFT contract's owner_of(token_id) == attacker_receiver, proving settled-transfer-refunded-anyway.
