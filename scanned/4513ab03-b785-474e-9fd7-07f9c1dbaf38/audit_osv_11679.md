# [C] CVE-2017-9270

## Summary
Severity: Critical
Advisory: CVE-2017-9270
CVSS: 9.1 (CVSS:3.0/AV:N/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:H)
Published: 2018-03-01
Source: https://osv.dev/vulnerability/CVE-2017-9270
Type: osv

## Details
In cryptctl before version 2.0 a malicious server could send RPC requests that could overwrite files outside of the cryptctl key database.
