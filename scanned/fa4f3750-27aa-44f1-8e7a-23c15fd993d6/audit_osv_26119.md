# [H] Micrium OS Network uC-HTTP server header parsing invalid pointer dereference vulnerability

## Summary
Severity: High
Advisory: CVE-2023-51391
CVSS: 7.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H)
Published: 2024-04-16
Source: https://osv.dev/vulnerability/CVE-2023-51391
Type: osv

## Details
A bug in Micrium OS Network HTTP Server permits an invalid pointer dereference during header processing - potentially allowing a device crash and Denial of Service.
