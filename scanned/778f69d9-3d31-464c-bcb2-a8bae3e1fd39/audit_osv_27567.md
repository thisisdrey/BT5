# [M] Apache OFBiz: Path traversal or file inclusion

## Summary
Severity: Medium
Advisory: CVE-2024-23946
CVSS: 5.3 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:N/A:N)
Published: 2024-02-28
Source: https://osv.dev/vulnerability/CVE-2024-23946
Type: osv

## Details
Possible path traversal in Apache OFBiz allowing file inclusion.
Users are recommended to upgrade to version 18.12.12, that fixes the issue.
