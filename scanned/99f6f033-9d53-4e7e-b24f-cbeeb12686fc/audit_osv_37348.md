# [M] Apache OFBiz: FreeMarker SSTI via Duplicate Parameter Sanitization Bypass

## Summary
Severity: Medium
Advisory: CVE-2026-31380
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:L/A:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-31380
Type: osv

## Details
Improper Neutralization of Special Elements used in an Expression Language Statement ('Expression Language Injection') vulnerability in Apache OFBiz.

This issue affects Apache OFBiz: before 24.09.06.

Users are recommended to upgrade to version 24.09.06, which fixes the issue.
