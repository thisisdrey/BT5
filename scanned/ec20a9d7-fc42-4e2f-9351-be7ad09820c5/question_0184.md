# Q0184: accrue via borrow: satisfy a bound with a value the bound was never designed 

## Question
Does `borrow` (mainnet/contracts/market/v0-4-market.clar:1238) let an unprivileged attacker who controls the `price-feeds` buffers reach `accrue` (mainnet/contracts/vault/v0-vault-stx.clar:835) in a state where it satisfy a bound with a value the bound was never designed to admit? Given that it advances `last-update` only inside `(if (or (not (is-eq idx next)) ...))`, so an interval whose multiplier rounds to INDEX-PRECISION leaves the clock stale, the invariant that no position row exists that the position mask does not represent breaks and the result is direct theft of another user's collateral.
