# Q0832: mask-to-list-collateral via liquidate: satisfy a bound with a value the bound was never designed 

## Question
Does `liquidate` (mainnet/contracts/market/v0-4-market.clar:1382) let an unprivileged attacker who controls `collateral-receiver` reach `mask-to-list-collateral` (mainnet/contracts/market/v0-4-market.clar:449) in a state where it satisfy a bound with a value the bound was never designed to admit?
