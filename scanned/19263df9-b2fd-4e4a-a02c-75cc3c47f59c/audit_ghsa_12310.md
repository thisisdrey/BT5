# [H] Remote code execution in rwiki

## Summary
Severity: High
Advisory: GHSA-wwmf-6p58-6vj2
CVE: CVE-2006-2582
Ecosystem: RubyGems
Published: 2017-10-24
Source: https://github.com/advisories/GHSA-wwmf-6p58-6vj2
Type: github-advisory

## Affected
- RubyGems: `rwiki` — affected >=2.1.0pre1 <2.1.1

## Details
The editing form in RWiki 2.1.0pre1 through 2.1.0 allows remote attackers to execute arbitrary Ruby code via unknown attack vectors.
