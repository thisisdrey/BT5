# [M] CVE-2019-20015

## Summary
Severity: Medium
Advisory: CVE-2019-20015

## Details
An issue was discovered in GNU LibreDWG 0.92. Crafted input will lead to an attempted excessive memory allocation in dwg_decode_LWPOLYLINE_private in dwg.spec.
