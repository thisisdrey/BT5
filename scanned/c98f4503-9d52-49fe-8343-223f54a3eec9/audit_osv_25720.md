# [H] InSpec Archive Command Vulnerable to Maliciously Crafted Profile

## Summary
Severity: High
Advisory: CVE-2023-42658
CVSS: 8.8 (CVSS:3.1/AV:L/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H)
Published: 2023-10-31
Source: https://osv.dev/vulnerability/CVE-2023-42658
Type: osv

## Details
Archive command in Chef InSpec prior to 4.56.58 and 5.22.29 allow local command execution via maliciously crafted profile.
