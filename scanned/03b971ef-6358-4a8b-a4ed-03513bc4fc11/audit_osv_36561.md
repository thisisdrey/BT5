# [H] Apache HertzBeat: Uncontrolled Resource Consumption via Crafted XPath Expressions

## Summary
Severity: High
Advisory: CVE-2026-24343
CVSS: 8.8 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H)
Published: 2026-02-10
Source: https://osv.dev/vulnerability/CVE-2026-24343
Type: osv

## Details
Improper Neutralization of Data within XPath Expressions ('XPath Injection') vulnerability in Apache HertzBeat.

This issue affects Apache HertzBeat: from 1.7.1 before 1.8.0.

Users are recommended to upgrade to version 1.8.0, which fixes the issue.
