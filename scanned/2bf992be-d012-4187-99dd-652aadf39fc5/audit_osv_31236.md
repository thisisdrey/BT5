# [M] Livestatus injection in mknotifyd

## Summary
Severity: Medium
Advisory: CVE-2024-6542
CVSS: 6.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:L)
Published: 2024-07-22
Source: https://osv.dev/vulnerability/CVE-2024-6542
Type: osv

## Details
Improper neutralization of livestatus command delimiters in mknotifyd in Checkmk <= 2.0.0p39, < 2.1.0p47, < 2.2.0p32 and < 2.3.0p11 allows arbitrary livestatus command execution.
