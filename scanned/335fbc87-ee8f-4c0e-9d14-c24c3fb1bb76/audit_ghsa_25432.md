# [M] Plone allows a user to masquerade as a group

## Summary
Severity: Medium
Advisory: GHSA-r7j4-82xw-8m9p
CVE: CVE-2006-4249
Ecosystem: PyPI
CVSS: CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:U/C:N/I:H/A:N (CVSS_V3)
Published: 2022-05-01
Source: https://github.com/advisories/GHSA-r7j4-82xw-8m9p
Type: github-advisory

## Affected
- PyPI: `Plone` — affected >=2.5 <2.5.2

## Details
Unspecified vulnerability in PlonePAS in Plone 2.5 and 2.5.1, when anonymous member registration is enabled, allows an attacker to "masquerade as a group."
