# [M] Open WebUI vulnerable to server-side request forgery in utils.py

## Summary
Severity: Medium
Advisory: CVE-2024-30256
Aliases: GHSA-39wr-r5vm-3jxj
CVSS: 6.4 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:L/I:L/A:N)
Published: 2024-04-16

## Details
Open WebUI is a user-friendly WebUI for LLMs. Open-webui is vulnerable to authenticated blind server-side request forgery. This vulnerability is fixed in 0.1.117.
