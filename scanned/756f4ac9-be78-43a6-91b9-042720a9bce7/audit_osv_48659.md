# [M] CVE-2018-10877

## Summary
Severity: Medium
Advisory: CVE-2018-10877
CVSS: 6.5 (CVSS:3.0/AV:L/AC:L/PR:H/UI:R/S:U/C:H/I:H/A:H)
Published: 2018-07-18
Source: https://osv.dev/vulnerability/CVE-2018-10877
Type: osv

## Details
Linux kernel ext4 filesystem is vulnerable to an out-of-bound access in the ext4_ext_drop_refs() function when operating on a crafted ext4 filesystem image.
