# [M] Local DoS in OpenSMTPD via UNIX domain socket smtpd.sock

## Summary
Severity: Medium
Advisory: CVE-2025-62875
CVSS: 6.0 (CVSS:4.0/AV:L/AC:L/AT:N/PR:N/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:N)
Published: 2025-11-20
Source: https://osv.dev/vulnerability/CVE-2025-62875
Type: osv

## Details
An Improper Check for Unusual or Exceptional Conditions vulnerability in OpenSMTPD allows local users to crash OpenSMTPD.




This issue affects openSUSE Tumbleweed: from ? before 7.8.0p0-1.1.
