# [M] baserCMS Code Injection Vulnerability in Mail Form Feature

## Summary
Severity: Medium
Advisory: CVE-2023-43792
Aliases: GHSA-vrm6-c878-fpq6
CVSS: 5.3 (CVSS:3.0/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:L/A:N)
Published: 2023-10-30
Source: https://osv.dev/vulnerability/CVE-2023-43792
Type: osv

## Details
baserCMS is a website development framework. In versions 4.6.0 through 4.7.6, there is a Code Injection vulnerability in the mail form of baserCMS. As of time of publication, no known patched versions are available.
