# [H] Microsoft PowerShell Remote Code Execution Vulnerability

## Summary
Severity: High
Advisory: BIT-powershell-2026-50523
Aliases: CVE-2026-50523
Ecosystem: Bitnami
Published: 2026-08-19
Source: https://osv.dev/vulnerability/BIT-powershell-2026-50523
Type: osv

## Affected
- Bitnami: `powershell` — affected >=7.6.0 <7.6.5

## Details
Improper neutralization of special elements used in a command ('command injection') in Microsoft PowerShell allows an authorized attacker to execute code locally.
