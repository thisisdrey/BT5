# [M] MCP Server Exposure via Insecure Default Binding on alibabacloud-rds-openapi-mcp-server

## Summary
Severity: Medium
Advisory: CVE-2026-9680
CVSS: 5.8 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:L/I:N/A:N)
Published: 2026-07-28
Source: https://osv.dev/vulnerability/CVE-2026-9680
Type: osv

## Details
Improper exposure of the MCP server in alibabacloud-rds-openapi-mcp-server allows remote attackers to invoke exposed MCP tools via network access to an MCP endpoint listening on all network interfaces by default.
