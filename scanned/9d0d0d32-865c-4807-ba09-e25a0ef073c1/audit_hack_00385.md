# [C] Ostium incident: Ostium, an RWA-focused perpetuals DEX on Arbitrum, suffered an oracle manipulation exploit. The attacker used a compromised oracle

## Summary
Severity: Critical
Target: Ostium
Loss: $ 18,000,000
Attack method: Private Key Leakage
Published: 2026-07-15
Source: https://x.com/kaledora/status/2077525044733837736
Type: slowmist-incident

## Details
Ostium, an RWA-focused perpetuals DEX on Arbitrum, suffered an oracle manipulation exploit. The attacker used a compromised oracle signer key to submit fraudulent future-dated price reports, generating artificial trading profits and draining approximately $18 million USDC from the liquidity vault. The protocol has halted trading and is investigating.
