# [M] CVE-2016-0731

## Summary
Severity: Medium
Advisory: CVE-2016-0731
CVSS: 4.9 (CVSS:3.0/AV:N/AC:L/PR:H/UI:N/S:U/C:H/I:N/A:N)
Published: 2016-05-18
Source: https://osv.dev/vulnerability/CVE-2016-0731
Type: osv

## Details
The File Browser View in Apache Ambari before 2.2.1 allows remote authenticated administrators to read arbitrary files via a file: URL in the WebHDFS URL configuration.
