# [H] Joomla! Framework Remote Code Injection Vulnerability

## Summary
Severity: High
Advisory: GHSA-wwfh-28hx-w2r2
CVE: CVE-2015-8566
CWE: CWE-74
Ecosystem: Packagist
Published: 2022-05-17
Source: https://github.com/advisories/GHSA-wwfh-28hx-w2r2
Type: github-advisory

## Affected
- Packagist: `joomla/session` — affected >=0 <1.3.1

## Details
The Session package 1.x before 1.3.1 for Joomla! Framework allows remote attackers to execute arbitrary code via unspecified session values.
