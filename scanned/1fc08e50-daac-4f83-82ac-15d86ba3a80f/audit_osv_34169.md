# [M] The Scratch Channel Allows Username Modification

## Summary
Severity: Medium
Advisory: CVE-2025-55301
Aliases: GHSA-9q4f-4vjm-7gp2
CVSS: 6.7 (CVSS:3.1/AV:L/AC:H/PR:N/UI:N/S:U/C:H/I:N/A:H)
Published: 2025-08-25
Source: https://osv.dev/vulnerability/CVE-2025-55301
Type: osv

## Details
The Scratch Channel is a news website. In version 1, it is possible to go to application in devtools and click local storage to edit the account's username locally. This issue has been patched in version 1.1.
