# [M] Mailman Sensitive Information Disclosure

## Summary
Severity: Medium
Advisory: GHSA-hj4h-vqpq-95wg
CVE: CVE-2004-0412
CWE: CWE-200
Ecosystem: PyPI
Published: 2022-04-29
Source: https://github.com/advisories/GHSA-hj4h-vqpq-95wg
Type: github-advisory

## Affected
- PyPI: `mailman` — affected >=0 <2.1.5

## Details
Mailman before 2.1.5 allows remote attackers to obtain user passwords via a crafted email request to the Mailman server.
