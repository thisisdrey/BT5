# [H] CVE-2019-5858

## Summary
Severity: High
Advisory: CVE-2019-5858

## Details
Incorrect security UI in MacOS services integration in Google Chrome on OS X prior to 76.0.3809.87 allowed a local attacker to execute arbitrary code via a crafted HTML page.
