# [H] A BOLA vulnerability in POST /providers in EasyAppointments < 1.5.0

## Summary
Severity: High
Advisory: CVE-2023-3288
CVSS: 8.5 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:L/I:H/A:N)
Published: 2024-07-09
Source: https://osv.dev/vulnerability/CVE-2023-3288
Type: osv

## Details
A BOLA vulnerability in POST /providers allows a low privileged user to create a privileged user (provider) in the system. This results in privilege escalation.
