# [M] The Heart Project incident: The official Discord server of the NFT project The Heart Project was hacked. Scammers deleted most of The Heart Project's Discord

## Summary
Severity: Medium
Target: The Heart Project
Loss: -
Attack method: Account Compromise
Published: 2022-02-02
Source: https://twitter.com/HeartNFTs/status/1488743536195301377
Type: slowmist-incident

## Details
The official Discord server of the NFT project The Heart Project was hacked. Scammers deleted most of The Heart Project's Discord channels and posted scam links. According to The Heart Project, some users clicked on fraudulent links and said they lost assets. The Heart Project says it will reimburse users for lost ether.
