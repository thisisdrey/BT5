# [M] Apache Traffic Server: HostDB SRV handling leaks memory

## Summary
Severity: Medium
Advisory: CVE-2026-58175
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:N/VC:N/VI:N/VA:H/SC:N/SI:N/SA:L)
Published: 2026-07-29
Source: https://osv.dev/vulnerability/CVE-2026-58175
Type: osv

## Details
Apache Traffic Server leaks memory when handling HostDB SRV records.

This issue affects Apache Traffic Server: from 8.0.0 through 8.1.9, from 9.0.0 through 9.2.14, from 10.0.0 through 10.1.3.

Users are recommended to upgrade to version 9.2.15 or 10.1.4, which fix the issue.
