Preconditions: a victim previously deposited a real MT balance under `Nep245TokenId{contract_id: victim_mt_contract, mt_token_id: victim_token_id}`. Call sequence: attacker's evil.near calls mt_on_transfer with the crafted `token_id` -> deposit -> `token_balances.add`. Scoped impact: Critical, worthless deposit credits a valuable existing balance held by another account, if collision exists (violating CONSERVATION: sum of `token_balances` changes for that token key across attacker's deposit call != the token actually received).
