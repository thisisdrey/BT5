# [H] GLPI allows authenticated remote code execution

## Summary
Severity: High
Advisory: CVE-2025-24801
Aliases: GHSA-g2p3-33ff-r555
CVSS: 8.5 (CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:C/C:H/I:H/A:H)
Published: 2025-03-18
Source: https://osv.dev/vulnerability/CVE-2025-24801
Type: osv

## Details
GLPI is a free asset and IT management software package. An authenticated user can upload and force the execution of *.php files located on the GLPI server. This vulnerability is fixed in 10.0.18.
