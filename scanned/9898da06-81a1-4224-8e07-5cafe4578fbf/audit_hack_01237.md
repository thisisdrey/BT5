# [M] Curve Finance incident: The Curve Finance frontend was attacked, prompting users to grant token approvals to malicious smart contracts. The attackers move

## Summary
Severity: Medium
Target: Curve Finance
Loss: $ 428,000
Attack method: Malicious Code Injection Attack
Published: 2022-08-09
Source: https://twitter.com/CurveFinance/status/1557107088962224132
Type: slowmist-incident

## Details
The Curve Finance frontend was attacked, prompting users to grant token approvals to malicious smart contracts. The attackers moved the stolen funds to FixedFloat and Tornado Cash, with at least 362 ETH (~$620,000) stolen. FixedFloat tweeted that they had frozen 112 stolen ETH (~$192,000).
