# [H] CVE-2017-5518

## Summary
Severity: High
Advisory: CVE-2017-5518

## Details
The media-file upload feature in GeniXCMS through 0.0.8 allows remote attackers to conduct SSRF attacks via a URL, as demonstrated by a URL with an intranet IP address.
