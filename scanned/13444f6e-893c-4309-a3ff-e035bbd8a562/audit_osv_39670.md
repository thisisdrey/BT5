# [C] Flowise: Evaluation create+update mass-assignment allows cross-workspace evaluation takeover

## Summary
Severity: Critical
Advisory: CVE-2026-46479
Aliases: GHSA-mq53-pc65-wjc4
CVSS: 9.0 (CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:H/VI:H/VA:H/SC:N/SI:N/SA:N)
Published: 2026-06-08
Source: https://osv.dev/vulnerability/CVE-2026-46479
Type: osv

## Details
Flowise is a drag & drop user interface to build a customized large language model flow. Prior to version 3.1.2, evaluation create and update mass-assignment allows cross-workspace evaluation takeover. This issue has been patched in version 3.1.2.
