# [M] A BOLA vulnerability in POST /customers in EasyAppointments < 1.5.0

## Summary
Severity: Medium
Advisory: CVE-2023-3290
CVSS: 5.0 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:N/I:L/A:N)
Published: 2024-07-09
Source: https://osv.dev/vulnerability/CVE-2023-3290
Type: osv

## Details
A BOLA vulnerability in POST /customers allows a low privileged user to create a low privileged user (customer) in the system. This results in unauthorized data manipulation.
