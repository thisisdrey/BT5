# [C] scratch-coding-hut.github.io Login Links Generation vulnerability

## Summary
Severity: Critical
Advisory: CVE-2025-31122
Aliases: GHSA-mmg3-567w-v9j2
CVSS: 9.0 (CVSS:4.0/AV:N/AC:H/AT:P/PR:N/UI:P/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H)
Published: 2025-03-31
Source: https://osv.dev/vulnerability/CVE-2025-31122
Type: osv

## Details
scratch-coding-hut.github.io is the website for Coding Hut. In 1.0-beta3 and earlier, the login link can be used to login to any account by changing the username in the username field.
