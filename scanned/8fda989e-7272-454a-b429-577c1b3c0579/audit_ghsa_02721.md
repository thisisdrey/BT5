# [H] Arbitrary Code Execution in feehi/cms

## Summary
Severity: High
Advisory: GHSA-rf3w-29h3-r636
CVE: CVE-2020-21322
CWE: CWE-434
Ecosystem: Packagist
Published: 2021-09-20
Source: https://github.com/advisories/GHSA-rf3w-29h3-r636
Type: github-advisory

## Affected
- Packagist: `feehi/cms` — affected >=0 <2.0.8.1

## Details
An arbitrary file upload vulnerability in Feehi CMS v2.0.8 and below allows attackers to execute arbitrary code via a crafted PHP file.
