# [H] Missing authentication for critical function in ScadaBR

## Summary
Severity: High
Advisory: CVE-2026-8602
CVSS: 7.5 (CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:N/VI:H/VA:H/SC:N/SI:N/SA:N)
Published: 2026-05-19
Source: https://osv.dev/vulnerability/CVE-2026-8602
Type: osv

## Details
In ScadaBR version 1.2.0, a Missing Authentication for Critical Function vulnerability could allow an unauthenticated attacker to send a HTTP GET requests to the SCADA system and inject arbitrary sensor readings.
