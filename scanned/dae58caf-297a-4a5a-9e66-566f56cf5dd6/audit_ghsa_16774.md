# [C] Magento remote code execution (RCE), Cross-Site Scripting (XSS) and other vulnerabilities

## Summary
Severity: Critical
Advisory: GHSA-5gmh-85x8-5cx7
Ecosystem: Packagist
Published: 2024-05-15
Source: https://github.com/advisories/GHSA-5gmh-85x8-5cx7
Type: github-advisory

## Affected
- Packagist: `magento/community-edition` — affected >=2.1 <2.1.14
- Packagist: `magento/community-edition` — affected >=2.2 <2.2.5

## Details
Magento Commerce and Open Source 2.2.5 and 2.1.14 contain multiple security enhancements that help close authenticated Admin user remote code execution (RCE), Cross-Site Scripting (XSS) and other vulnerabilities.
