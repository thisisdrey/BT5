# [M] Nexus Repository Manager - Improper Restriction of Excessive Authentication Attempts

## Summary
Severity: Medium
Advisory: CVE-2026-3329
CVSS: 6.0 (CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:N/VA:N/SC:N/SI:N/SA:N)
Published: 2026-06-11
