Preconditions: attacker holds a legitimate signer slot on signers-N-M, contract message_id fixed. Call sequence: process_event -> TryFrom<StackerDBChunksEvent> -> type_byte check via signer_message_payload_matches_lane -> read_next::<T,_>(&mut &chunk.data[..]). Impact: Critical, forged-lane message accepted into SignerMessages despite the type-prefix gate.
