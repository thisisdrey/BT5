### Title
Unauthenticated remote `/shutdown` HTTP POST halts the signer's event receiver - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` treats any HTTP POST to `/shutdown` as a valid stop command and unconditionally sets `stop_signal` to `true`, with no check that the request originated from the local `SignerStopSignaler`. Any TCP client that can reach the signer's bound event-receiver port can send this request and halt the signer's `main_loop`.

### Finding Description
The intended invariant is: "the stop signal is only set when the trusted local `SignerStopSignaler::send` issues it." The code breaks this equality by authenticating the stop command purely by URL path, not by origin. In `next_event`: [1](#0-0) 
the handler matches `request.url() == "/shutdown"` and calls `event_receiver.stop_signal.store(true, Ordering::SeqCst)` unconditionally, returning `EventError::Terminated`. This is reached from `http_server.recv()` on the bound socket at line 420, which accepts any inbound TCP HTTP connection — there is no peer-address check, no shared secret, no signature, nothing that ties the request to the legitimate `SignerStopSignaler::send` implementation at lines 376-396, which itself just connects via plain `TcpStream::connect` and writes a raw HTTP POST with a fixed, guessable body/path.

The bound address is passed in by the caller as `bind_addr` in `Signer::spawn` (`libsigner/src/runloop.rs` lines 209-224), and whatever interface/port this binds to, once reachable, accepts unauthenticated shutdown POSTs. Since `main_loop` (`libsigner/src/events.rs` lines 284-312) checks `is_stopped()` on every iteration and exits when true, this halts the signer's event ingestion permanently until process/thread restart.

### Impact Explanation
An attacker who can open a TCP connection to the signer's event-receiver port can send a single crafted `POST /shutdown HTTP/1.1` request and cause the event receiver's `main_loop` to terminate, cutting off the signer's ingestion of StackerDB chunks, burn blocks, and block-validation responses from the node. This matches the Critical category "remote crash/unauthenticated DoS from few messages" — one message suffices, and it is repeatable against a restarted receiver.

### Likelihood Explanation
No credentials, secrets, or privileged roles are needed — this exploits a missing-authentication logic bug in message handling, not volumetric flooding (a single crafted request suffices). The only precondition is that the attacker can open a TCP connection to the event-receiver's bound address/port, which is the same reachability assumption used by the legitimate `SignerStopSignaler`. Whether this is remotely exploitable depends on operational binding (e.g., loopback-only vs. externally reachable), which is a deployment/config detail outside this file, but nothing in the code itself restricts the accepted TCP source.

### Recommendation
Authenticate the shutdown request instead of relying solely on the URL path — e.g., require a shared secret/token known only to `SignerStopSignaler` and validated in `next_event`, or replace the TCP-based wakeup with a mechanism that isn't reachable over the network (e.g., an internal channel/self-pipe, or binding the shutdown listener strictly to loopback and validating `request.remote_addr()` is loopback).

### Proof of Concept
```rust
// libsigner/src/events.rs (or a new test module)
use std::io::Write;
use std::net::TcpStream;
use crate::events::{EventReceiver, SignerEventReceiver};
use crate::v0::messages::SignerMessage;

#[test]
fn test_unauthenticated_shutdown() {
    let mut receiver: SignerEventReceiver<SignerMessage> = SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Simulate an unprivileged remote client, NOT the SignerStopSignaler
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {addr}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Drive one iteration of next_event, as main_loop would
    let err = receiver.next_event().unwrap_err();
    assert!(matches!(err, crate::EventError::Terminated));
    assert!(receiver.is_stopped()); // stop_signal flipped by an unauthenticated remote peer
}
```
This demonstrates that `is_stopped()` becomes `true` after a raw, unauthenticated `/shutdown` POST from a connection that never went through `SignerStopSignaler::send`, confirming the broken authentication invariant at [1](#0-0) .
