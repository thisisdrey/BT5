## Title
Unrestricted client-controlled `GitObjectDirectory`/`GitAlternateObjectDirectories` fields allow cross-repository object access via path traversal - (File: `internal/git/gitcmd/command_factory.go`, `internal/git/alternates/alternates.go`)

### Summary
The `Repository` protobuf message carries `git_object_directory` and `git_alternate_object_directories` fields that are meant to be set only by Gitaly itself (during quarantine) or looped back by Rails after an access check. However, these fields are ordinary, client-settable protobuf fields present on every `Repository` message accepted by Gitaly RPCs. When Gitaly builds git commands, it resolves these fields into `GIT_OBJECT_DIRECTORY`/`GIT_ALTERNATE_OBJECT_DIRECTORIES` environment variables via a raw, unvalidated `filepath.Join`, unlike the dedicated `ObjectDirectoryPath()` helper which does validate that the resulting path stays inside the storage/repo or an expected quarantine prefix. This mirrors the external report's pattern: a state-influencing entry point that is supposed to be reachable only by a trusted caller (there: only `GigaNameNFT`; here: only Gitaly's own quarantine machinery/Rails callback) is in practice reachable and controllable by an ordinary client.

### Finding Description
The `Repository` message defines client-visible fields: [1](#0-0) 

These fields are resolved into git subprocess environment variables directly via `filepath.Join(repoPath, dir)`, with no bound-checking against the storage root or the repository directory: [2](#0-1) 

This helper is invoked by the command factory for essentially every git command Gitaly executes on behalf of an RPC: [3](#0-2) 

This is in stark contrast to `localrepo.Repo.ObjectDirectoryPath()`, the function meant to safely resolve this same field, which explicitly validates the path stays within the storage root and either matches the repo's own object directory or a legitimate transaction/quarantine-directory prefix: [4](#0-3) 

The transaction middleware is aware that these fields can be attacker-supplied on non-mutator (accessor) RPCs, and only rejects them for mutators — for accessor RPCs it deliberately skips `locator.ValidateRepository` and forwards the request untouched, with an explicit comment acknowledging the gap is left unaddressed: [5](#0-4) 

Because any accessor RPC (e.g. `FindCommits`, `TreeEntry`, `ListBranchNames`, etc.) accepts a full `Repository` message, an ordinary authenticated client can set `git_object_directory`/`git_alternate_object_directories` to a `../`-traversal path. `filepath.Join`+`Clean` will resolve the traversal, escaping the intended repository directory and pointing git's object search path at another repository's (or any accessible directory's) object database on the same storage — all without going through the validation logic in `ObjectDirectoryPath()`/`ValidateRepository`.

### Impact Explanation
A crafted, ordinary (non-privileged) RPC request lets a client point Gitaly's git subprocess at an arbitrary object directory on the storage, enabling cross-repository object disclosure: the client can read blobs/commits/trees that exist in another repository's object store (e.g. a private repository) as long as the attacker can guess or brute-force object IDs, by directing lookups via the alternate object directory mechanism. This is a concrete storage/isolation escape consistent with the "cross-repository object access" acceptance criterion.

### Likelihood Explanation
Reachability requires only an ordinary, authenticated gRPC client capable of sending any request containing a `Repository` message with the two fields populated to point outside the intended path — no privileged role, leaked token, or malicious peer is required. This matches an ordinary user's crafted RPC field, and the middleware code comment confirms the maintainers are aware this circumvents intended access-check flow.

### Recommendation
Route `GitObjectDirectory`/`GitAlternateObjectDirectories` resolution through the same validation used in `localrepo.Repo.ObjectDirectoryPath()` (bounding the path to the storage root and to either the repo's own objects directory or a recognized quarantine-directory prefix) before constructing `alternates.Env()`/git subprocess environment variables, for both mutator and accessor RPCs, rather than only rejecting mutators in the transaction middleware.

### Proof of Concept
1. As an authenticated client with access to `RepoA`, send an accessor RPC (e.g. `FindCommitsRequest`) with `Repository{storage_name: "default", relative_path: "RepoA.git", git_object_directory: "../RepoB.git/objects"}`.
2. Because the request is a non-mutator, `beginTransactionForRepository` skips `locator.ValidateRepository` and forwards the request as-is (`internal/gitaly/storage/storagemgr/middleware.go:271-296`).
3. `ExecCommandFactory.newCommand` calls `alternates.Env(repoPath, "../RepoB.git/objects", nil)`, producing `GIT_OBJECT_DIRECTORY=<storage>/RepoB.git/objects`.
4. The subsequent `git` invocation for the RPC now searches `RepoB`'s objects, letting the client read objects belonging to `RepoB` for which they may have no independent authorization.

// Env returns the alternate object directory environment variables.
func Env(repoPath, objectDirectory string, alternateObjectDirectories []string) []string {
	var env []string
	if objectDirectory != "" {
		env = append(env, fmt.Sprintf("GIT_OBJECT_DIRECTORY=%s", filepath.Join(repoPath, objectDirectory)))
	}

	if len(alternateObjectDirectories) > 0 {
		var dirsList []string

		for _, dir := range alternateObjectDirectories {
			dirsList = append(dirsList, filepath.Join(repoPath, dir))
		}

		env = append(env, fmt.Sprintf("GIT_ALTERNATE_OBJECT_DIRECTORIES=%s", strings.Join(dirsList, ":")))
	}

	return env
}

// ObjectDirectoryPath returns the full path of the object directory. The errors returned are gRPC
// errors with relevant error codes and should be passed back to gRPC without further decoration.
func (repo *Repo) ObjectDirectoryPath(ctx context.Context) (string, error) {
	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", err
	}

	objectDirectoryPath := repo.GetGitObjectDirectory()
	if objectDirectoryPath == "" {
		return "", structerr.NewInvalidArgument("object directory path is not set")
	}

	storagePath, err := repo.locator.GetStorageByName(ctx, repo.GetStorageName())
	if err != nil {
		return "", fmt.Errorf("get storage by name: %w", err)
	}

	// Ensure the path points somewhere in the storage.
	relativeObjectDirectoryPath, err := storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))
	if err != nil {
		return "", structerr.NewInvalidArgument("validate relative path: %w", err)
	}

	parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
	baseDir := filepath.Base(relativeObjectDirectoryPath)
	isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

	// Transactions quarantine a repository by pointing the object directory to a 'quarantine' named
	// directory in the transaction's temporary directory. If the base directory is `quarantine`,
	// Git push may apply an additional layer of quarantine such as `/quarantine/tmp_objdir-incoming-Gbc29N`
	// so we don't assert the `/quarantine` being the last element of the path. We thus also check for
	// whether the parent directory is in `quarantine` and whether the base directory has the expected
	// `tmp_objdir` suffix.
	if !isTransactionQuarantineDir {
		// We need to check whether the relative object directory as given by the repository is
		// a valid path. This may either be a path in the Git repository itself, where it may either
		// point to the main object directory storage or to an object quarantine directory as
		// created by git-receive-pack(1). Alternatively, if that is not the case, then it may be a
		// manual object quarantine directory located in the storage's temporary directory. These
		// have a repository-specific prefix which we must check in order to determine whether the
		// quarantine directory does in fact belong to the repo at hand.
		if _, origError := storage.ValidateRelativePath(repoPath, objectDirectoryPath); origError != nil {
			tempDir, err := repo.locator.TempDir(repo.GetStorageName())
			if err != nil {
				return "", structerr.NewInvalidArgument("getting storage's temporary directory: %w", err)
			}

			expectedQuarantinePrefix := filepath.Join(tempDir, storage.QuarantineDirectoryPrefix(repo))
			absoluteObjectDirectoryPath := filepath.Join(repoPath, objectDirectoryPath)

			// The relative path is outside of the repository
			if !strings.HasPrefix(absoluteObjectDirectoryPath, expectedQuarantinePrefix) {
				return "", structerr.NewInvalidArgument("not a valid relative path: %w", origError)
			}
		}
	}

	fullPath := filepath.Join(repoPath, objectDirectoryPath)
	if _, err := os.Stat(fullPath); os.IsNotExist(err) {
		return "", structerr.NewNotFound("object directory does not exist: %q", fullPath)
	}

	return fullPath, nil
}
