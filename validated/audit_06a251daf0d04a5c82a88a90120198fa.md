Confirmed: `DefuseIntents { intents: Vec<Intent> }` allows a single signed payload (one nonce) to contain an arbitrary number of `TokenDiff` intents, each executed sequentially via `Intent::execute_intent` [1](#0-0) , with `TokenDiff::execute_intent` computing and crediting its fee independently for each intent in the loop [2](#0-1) .

### Title
Protocol fees on Nep245/Imt token diffs can be bypassed by splitting a single delta into many unit-sized `TokenDiff` intents - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::execute_intent` computes and collects the protocol fee independently, per intent, per token, using `Self::token_fee(token_id, amount, protocol_fee)` [3](#0-2) . For `Nep245`/`Imt` tokens, this function returns `Pips::ZERO` whenever the per-intent `amount <= 1` [4](#0-3) . Because fees are never aggregated across intents in the same `MultiPayload`/batch, a signer can split what would otherwise be one large-value `Nep245`/`Imt` negative delta (e.g. `-1_000_000`, which would incur `fee_ceil(1_000_000)`) into `1_000_000` separate `TokenDiff` intents each with `delta == -1`, each of which is fee-exempt, netting the same total `-1_000_000` transfer with zero aggregate fee collected.

### Finding Description
The binding the fee mechanism is meant to satisfy is: for every negative delta `d` on token `T` in the batch, `fee_collector_credit(T) == Σ Pips::fee_ceil(|d|)` (with the documented exception that any single Nep245/Imt intent moving `amount <= 1` is legitimately fee-free, since a single unit move is treated like an NFT/atomic transfer, not a fractional trade).

`TokenDiff::execute_intent` enforces this only *within a single intent's own diff*, not across the whole batch:
```
for (token_id, delta) in &self.diff {
    ...
    if *delta < 0 {
        let amount = delta.unsigned_abs();
        let fee = Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount);
        fees_collected.add(token_id.clone(), fee)...
    }
}
``` [5](#0-4) 

and `token_fee` explicitly zeroes the fee for Nep245/Imt when `amount <= 1`:
```
TokenIdType::Nep245 | TokenIdType::Imt if amount > 1 => {}
TokenIdType::Nep171 | TokenIdType::Nep245 | TokenIdType::Imt => return Pips::ZERO,
``` [6](#0-5) 

`DefuseIntents` allows an unbounded `Vec<Intent>` to be signed under one nonce/payload, and each `Intent::TokenDiff` is executed and its fee credited independently in the loop:
```
for intent in self.intents {
    intent.execute_intent(signer_id, engine, intent_hash)?;
}
``` [1](#0-0) 

Exploit flow: instead of signing one `TokenDiff{ diff: {Nep245(T): -1_000_000, ...} }` (fee = `fee_ceil(1_000_000)` on `T`), the attacker signs one `MultiPayload` whose `DefuseIntents.intents` contains `1_000_000` separate `TokenDiff` intents, each `{ diff: {Nep245(T): -1, other_token: matching_amount} }`. Each of the `1_000_000` sub-intents independently computes `token_fee(Nep245, amount=1, fee) == Pips::ZERO`, so `fees_collected` is empty for every sub-intent, and the aggregate fee credited to `fee_collector` over the whole batch is `0` instead of `fee_ceil(1_000_000)`. The counterparty leg(s) matching these deltas to net the batch to zero (enforced by `TransferMatcher::finalize`) can likewise be split, or can simply be a normal counter-trade that nets out - the `TransferMatcher` only checks that aggregate deltas per token net to zero across the whole batch [7](#0-6) ; it does not re-derive or enforce fee correctness, so it cannot detect or prevent this bypass.

None of the existing guards address this: `MultiPayload::verify`/nonce/salt checks only authenticate the signer and prevent replay [8](#0-7) ; they say nothing about fee aggregation across intents in a payload. `TransferMatcher::finalize` only guarantees balance conservation (net-zero deltas), not fee correctness.

### Impact Explanation
Protocol fees intended to be collected on `Nep245`/`Imt` token diffs can be reduced to zero regardless of total moved value, simply by expressing the same net trade as many unit-sized legs in one signed payload. This directly matches the listed Critical category "protocol fees bypassed" - value that should have been credited to `fee_collector` never is, and the bypass scales linearly with the number of unit legs used (i.e. arbitrarily large trades can be fully fee-free). It is repeatable by any account, on any Nep245/Imt token pair, in every batch, at no cost beyond message size/gas for constructing the larger intents list.

### Likelihood Explanation
Preconditions are minimal and fully within an unprivileged attacker's control: they need a Verifier balance on the `Nep245`/`Imt` token(s) being traded (or a colluding counterparty/self-controlled second account providing the matching leg), and no special roles are required - just constructing and signing one `MultiPayload` with a large `intents: Vec<Intent>` list under a single nonce. The main practical constraint is gas/message size for very large numbers of sub-legs, but even partial splitting (e.g. splitting only part of the delta into unit legs and keeping the remainder as one larger, fee-liable leg) yields partial, proportional fee under-collection, so the vulnerability is exploitable at any granularity, not just the full 1,000,000-leg extreme.

### Recommendation
Aggregate the total absolute value moved per `(signer_id, token_id)` across all `TokenDiff` intents in the same execution/batch (or use the *total* signed delta for a token as the fee basis, not the per-intent delta) before applying the Nep245/Imt "amount <= 1 is free" exemption, so a signer cannot circumvent the threshold by fragmenting one large trade into many unit-size intents within a single payload or batch.

async fn nep245_fee_bypass_via_leg_splitting() {
    // setup env with fee = Pips::ONE_PERCENT, create Nep245-backed MT token, fund signer + counterparty

    // Variant A: single TokenDiff with delta = -1_000_000 on Nep245 token
    let single_leg = TokenDiff {
        diff: TokenDeltas::default()
            .with_apply_deltas([(nep245_token.clone(), -1_000_000), (other_token.clone(), 1_000_000)])
            .unwrap(),
        memo: None,
        referral: None,
    };
    // counterparty leg nets deltas to zero
    // execute -> check TokenDiffEvent.fees_collected for nep245_token == fee.fee_ceil(1_000_000) (> 0)

    // Variant B: same signer, same total net effect, but split into 1_000_000
    // TokenDiff intents each { nep245_token: -1, other_token: 1 } inside ONE DefuseIntents/payload
    let intents: Vec<Intent> = (0..1_000_000)
        .map(|_| TokenDiff {
            diff: TokenDeltas::default()
                .with_apply_deltas([(nep245_token.clone(), -1), (other_token.clone(), 1)])
                .unwrap(),
            memo: None,
            referral: None,
        }.into())
        .collect();
    // sign as single MultiPayload with one nonce containing `intents`
    // execute against matching counterparty legs

    // Assert: total fee_collector credit on nep245_token for Variant A > 0,
    // total fee_collector credit on nep245_token for Variant B == 0,
    // despite identical net token movement -1_000_000 / +1_000_000.
    assert_ne!(fee_collected_variant_a, fee_collected_variant_b);
    assert_eq!(fee_collected_variant_b, 0);
}

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }
