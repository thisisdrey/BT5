## Analog Found

### Title
QUIC connection stake classification (`ConnectionPeerType`) is cached for the lifetime of a connection and is never re-validated or revoked if the peer's stake later drops to zero — enabling persistent QoS evasion - ([File: streamer/src/nonblocking/quic.rs, streamer/src/nonblocking/swqos.rs])

### Summary
The Visor bug is fundamentally about a one-time-granted permission (`nftApprovals[nft] = true`) that is never cleared or revocable, so it keeps conferring privileges to a party after the condition that justified the grant (trust in the delegate) no longer holds. The closest reachable analog in Agave's unprivileged-facing QUIC streamer is the caching of a connection's stake-derived `ConnectionPeerType` (staked vs. unstaked, and the specific stake amount) at connection-establishment time. This value is stored inside the connection context/`ConnectionEntry` and reused for the entire lifetime of that QUIC connection to gate stream throttling limits and connection-table admission — with no mechanism to re-check or revoke it if the peer's stake is subsequently reduced or removed.

### Finding Description
When a QUIC connection is accepted, `get_connection_stake()` looks up the peer's pubkey against the current `StakedNodes` snapshot once, and the resulting `ConnectionPeerType::Staked(stake)`/`Unstaked` classification is baked into the `SwQosConnectionContext`/`SimpleQosConnectionContext` returned by `build_connection_context()`: [1](#0-0) 

This classification is then stored per-connection in the `ConnectionEntry` (`peer_type` field) used by the `ConnectionTable`, and is what determines the maximum concurrent uni-streams and throttling budget for that connection for its entire lifetime: [2](#0-1) [3](#0-2) 

The `StakedNodes` table backing this lookup is refreshed only periodically by a background service (every `STAKE_REFRESH_CYCLE` = 5 seconds), and even then, only *new* connections consult the refreshed table via `build_connection_context()`: [4](#0-3) 

There is no code path that re-evaluates an already-established connection's `peer_type`/stake against the live `StakedNodes` table, nor any mechanism to revoke/downgrade an in-flight connection's stake-derived QoS classification once granted. The only way a stale "staked" classification is removed is if the connection itself is pruned/closed (e.g., via `prune_random`, `remove_connection`, or natural close) — the same structural gap as the Visor report, where an approval, once set, persists until an unrelated event (a transfer) happens to clear it, rather than through an explicit, timely revocation check.

### Impact Explanation
An unprivileged QUIC client that held meaningful stake at connection time — and is later slashed, deactivated, or has its stake fully withdrawn — continues to receive staked-tier QoS treatment (higher `max_concurrent_uni_streams`, priority admission into the staked `ConnectionTable`, exemption from unstaked connection limits) for as long as the underlying QUIC connection stays open, since QUIC connections can be kept alive by the client indefinitely (subject to idle timeouts). This is a QoS evasion vector explicitly recognized as in-scope: a formerly staked (now effectively unstaked) peer retains disproportionate transaction-submission throughput/priority relative to genuinely unstaked peers, degrading fairness of the packet-ingestion path for other unstaked/low-stake clients.

### Likelihood Explanation
Reachable by any unprivileged network peer without validator/operator privileges: an attacker only needs to acquire stake briefly (e.g., via a delegate/temporary stake position, or coordination with a soon-to-be-deactivated stake account), open and maintain a long-lived QUIC connection to a validator's TPU/QUIC endpoint during that window, and then let the stake be removed while keeping the connection alive. No malicious snapshot, RPC abuse, or multiple-client coordination is required, and the exploit window is bounded only by QUIC idle-timeout/connection-pruning behavior, not by a single fixed check.

### Recommendation
Periodically re-validate each open connection's stake against the current `StakedNodes` table (e.g., on the same cadence as `StakedNodesUpdaterService`, or lazily on stream admission) and downgrade/evict connections whose backing stake has dropped below the staked threshold, mirroring the recommended NFT fix of re-checking/clearing a previously granted privilege rather than trusting a value cached at grant time indefinitely.

### Proof of Concept
1. Peer P holds stake S at time T0 and opens a QUIC connection to the validator; `build_connection_context()` classifies P as `ConnectionPeerType::Staked(S)`, and this is cached in the connection's `ConnectionEntry`/`SwQosConnectionContext`.
2. At T1 (< 5s or more), P's stake is fully deactivated/withdrawn on-chain, so a fresh lookup via `get_connection_stake()` would now return `Unstaked`.
3. P keeps the original QUIC connection alive (does not reconnect) and continues opening new streams on it.
4. Because `conn_context.peer_type()` was fixed at T0 and is never re-derived, `compute_max_allowed_uni_streams_with_rtt()` and connection-table membership continue to treat P as staked, granting it staked-tier throughput/admission indefinitely — exactly analogous to Eve retaining transfer rights after Alice's approval should have been revoked in the Visor report. impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }
