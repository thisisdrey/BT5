### Title
Roaming-suppression window (`RoamingSuppressSeconds`) is too short to prevent rapid address-flap abuse in `handleHostRoaming` - (File: outside.go)

### Summary
`handleHostRoaming` in `outside.go` re-trusts a peer's new underlay `ip:port` (a "roam") whenever a packet decrypts correctly under the existing `ConnectionState`, and only throttles *immediate* flapping back to the same previously-seen remote via a 2-second constant, `RoamingSuppressSeconds`. [1](#0-0)  The constant is defined with a comment claiming it exists to prevent "flapping due to packets already in flight," but its value (`2`) is a small, arbitrarily short window that offers negligible practical protection against an authenticated peer repeatedly bouncing the tunnel's trusted remote address. [2](#0-1) 

### Finding Description
Once a tunnel is established, `Interface.handleHostRoaming` is invoked for every inbound packet whose source `via.UdpAddr` differs from the hostinfo's currently recorded remote. [3](#0-2)  After the remote-allow-list check, the only replay/flap defense is:

```go
if !hostinfo.lastRoam.IsZero() && via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < RoamingSuppressSeconds*time.Second {
``` [4](#0-3) 

This only suppresses roaming *back to the exact same previous remote* within `RoamingSuppressSeconds` (2 seconds). Any other new source address, or the same address after just over 2 seconds, is accepted immediately and stored via `hostinfo.SetRemote(via.UdpAddr)`. [5](#0-4)  `SetRemote` updates the atomic `remote` pointer, which is subsequently used to route locally originated ciphertext traffic and drive the connection manager's NAT-punch/health-check logic. [6](#0-5) 

Because a packet only needs to (a) come from a source not blocked by the remote allow list and (b) decrypt/authenticate against the existing Noise `ConnectionState`, any party capable of spoofing UDP source addresses toward the victim (which is trivial on UDP, unlike a signed handshake) can force the local peer to swap its trusted remote address every ~2 seconds indefinitely, since the suppression window resets each time and only blocks the exact previous address, not the pattern of flapping in general. This matches the CollateralBook analog: a constant that is nominally a "security delay" safeguard but is set far too small to meaningfully throttle the abuse it is supposed to prevent, letting an attacker who can inject spoofed UDP frames continuously redirect where the tunnel's encrypted traffic is sent (a remote/hostmap state-poisoning primitive), well before any legitimate NAT rebind would occur.

### Impact Explanation
An attacker who can inject spoofed UDP datagrams (no valid certificate needed — the roam path runs on already-authenticated Noise counters, but an attacker replaying/spoofing the *source address* of a legitimate packet, or racing a genuine handshake reply, can trigger this) can repeatedly force `SetRemote` to point the tunnel at attacker-chosen addresses. This can be used to redirect (poison) the destination for encrypted outbound traffic to an address the attacker controls (traffic redirection) or to a black-hole/off-path address (denial of service against the tunnel), circumventing the intended damping the `RoamingSuppressSeconds` constant is supposed to provide against exactly this kind of address flapping.

### Likelihood Explanation
Reachable by any external network attacker capable of UDP source-address spoofing toward the victim's listen port — no CA-signed certificate or valid peer credential is required to abuse this specific gate, since the roaming logic is only reached in `handleOutsideMessagePacket`/`handleOutsideRelayPacket` post successful decryption, but the attacker only needs to spoof the *source `UdpAddr`* on an in-flight/replayed packet, not forge its own handshake. The 2-second window is short enough that automated flapping is trivial and continuous.

### Recommendation
Increase `RoamingSuppressSeconds` to a value that meaningfully throttles repeated roam attempts (e.g., tens of seconds, consistent with expected NAT rebind/handshake cadence), and/or extend the suppression logic to rate-limit roams to *any* new address within a rolling window, not just exact repeats of `lastRoamRemote`, so a single short constant cannot be trivially worked around by cycling through multiple spoofed source addresses.

### Proof of Concept
1. Establish a normal tunnel between `me` and `them`.
2. From an attacker-controlled vantage point capable of spoofing UDP source addresses, repeatedly send captured/replayed Message packets for the tunnel's index with a spoofed source `ip:port` A, wait >2s, then spoof source `ip:port` B, wait >2s, then back to A, etc.
3. Because each call to `handleHostRoaming` only checks `via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < 2s`, cycling between ≥2 distinct spoofed addresses at intervals >2s never triggers suppression, and `SetRemote` is called on every such packet — see `outside.go:264-292` and the constant `outside.go`'s `RoamingSuppressSeconds*time.Second` check versus the definition and comment in `hostmap.go:33-35`. func (f *Interface) handleHostRoaming(hostinfo *HostInfo, via ViaSender) {
	curRemote := hostinfo.GetRemote()
	if !via.IsRelayed && curRemote != via.UdpAddr {
		if !f.lightHouse.GetRemoteAllowList().AllowAll(hostinfo.vpnAddrs, via.UdpAddr.Addr()) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("lighthouse.remote_allow_list denied roaming", "newAddr", via.UdpAddr)
			}
			return
		}

		if !hostinfo.lastRoam.IsZero() && via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < RoamingSuppressSeconds*time.Second {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("Suppressing roam back to previous remote",
					"suppressSeconds", RoamingSuppressSeconds,
					"udpAddr", curRemote,
					"newAddr", via.UdpAddr,
				)
			}
			return
		}

		hostinfo.logger(f.l).Info("Host roamed to new udp ip/port.",
			"udpAddr", curRemote,
			"newAddr", via.UdpAddr,
		)
		hostinfo.lastRoam = time.Now()
		hostinfo.lastRoamRemote = curRemote
		hostinfo.SetRemote(via.UdpAddr)
	}
