### Title
Signer event listener (`SignerEventReceiver`) accepts unauthenticated `/stackerdb_chunks`, `/proposal_response`, `/new_block`, `/new_burn_block` POSTs with no Host/Origin or token check - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` (`libsigner/src/events.rs`) implements the HTTP listener that a `stacks-signer` binds to receive event pushes from its configured Stacks node. It dispatches on `request.url()` alone and never inspects the `Host` or `Origin` header, nor any shared secret/authentication header, before parsing the POST body and forwarding it as a trusted `SignerEvent` to the signer's decision runloop.

### Finding Description
`SignerEventReceiver::bind` opens a plain `tiny_http`-style `HttpServer` on the configured `endpoint` address [1](#0-0) . The sample signer configuration binds this listener to `0.0.0.0:30000` — i.e., all interfaces, not loopback-only — while `node_host` is separately configured to point the signer's outbound RPC client at the node [2](#0-1) .

`next_event` reads a raw HTTP request and dispatches purely by `request.url()`, with no check of the `Host`/`Origin`/any authentication header: [3](#0-2) 

`process_event` reads the body and deserializes it directly into a `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent`, then converts it into a `SignerEvent` that is forwarded, unauthenticated, into the signer's run loop: [4](#0-3) 

Compare this to the low-level HTTP request decoder used for this same listener (`libsigner/src/http.rs`), which parses headers but never surfaces or validates `Host`/`Origin`: it only checks header well-formedness (UTF-8, ASCII, length, duplicates) [5](#0-4) . There is no `AllowedHosts`/`AllowedOrigins` allowlist anywhere in `libsigner`, and no shared-secret/auth-token check comparable to the node's `[connection_options] auth_token` mechanism used for the *node's own* RPC surface (`stackslib/src/net/httpcore.rs` `auth_token` field) [6](#0-5) . This mirrors exactly the reported bug class: a Rack/HTTP transport that dispatches JSON-RPC-like payloads from any Host/Origin without a rebinding guard.

### Impact Explanation
Because the equality "request came from the configured stacks-node" vs. "request came from any reachable peer" is never checked (no Host, Origin, or auth-token verification), any host that can reach the signer's bound port — which per the shipped sample config is `0.0.0.0` (all interfaces), not `127.0.0.1` — can POST forged `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` payloads that are accepted, parsed, and forwarded as trusted `SignerEvent`s into the signer's decision runloop, exactly as if they had come from the legitimate node. This is an auth-gate-fails-open condition on a network-facing transport that services a security-critical component (the block-signing agent), matching the "unauthenticated write to state" / "auth bypass" impact class at the transport layer described in the rules. (Whatever the downstream signer runloop actually *does* with such injected events is signer decision logic and out of scope for this analog — the finding here is strictly that the transport accepts and forwards such data without any Host/Origin/token check.)

### Likelihood Explanation
Any actor capable of reaching the bound TCP port (which, per the shipped sample config, is on `0.0.0.0`, i.e. potentially reachable over the network, not restricted to loopback) can trivially craft a raw HTTP POST to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` with an arbitrary JSON body; there is no header, token, or TLS gate to bypass. No secrets, node keys, or privileged roles are required.

### Recommendation
Add mandatory authentication to `SignerEventReceiver`/`process_event` in `libsigner/src/events.rs` and `libsigner/src/http.rs`: require and verify a shared secret/HMAC or bearer token on inbound event POSTs (mirroring the node-side `auth_token` mechanism), and/or validate the `Host`/source address against an allowlist (default to loopback-only) before dispatching to `process_event`. Document that operators should bind the signer's event endpoint to `127.0.0.1` unless a network-level authentication proxy is in front of it.

### Proof of Concept
```
POST /stackerdb_chunks HTTP/1.1
Host: attacker-controlled-or-irrelevant
Content-Type: application/json
Content-Length: <n>

{ ...forged StackerDBChunksEvent JSON... }
```
Sent directly to the signer's bound `endpoint` (e.g. `0.0.0.0:30000` per `sample/conf/signer/mainnet-signer-conf.toml`) from any reachable host: `SignerEventReceiver::next_event` matches on `request.url() == "/stackerdb_chunks"` with no prior Host/Origin/token check [7](#0-6) , calls `process_event::<T, StackerDBChunksEvent>(request)`, which deserializes the body straight into the event type and forwards it into the signer's run loop as a trusted `SignerEvent` [4](#0-3) , with no verification that the request originated from the configured Stacks node.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

/// Returns (verb, path, table of headers, body_offset) on success
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };
