### Title
Unauthenticated event injection into `SignerEventReceiver` via `/new_block`, `/new_burn_block`, `/stackerdb_chunks` - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` accepts any TCP connection via `tiny_http::HttpServer::recv()` and dispatches POST requests to `process_event` purely by URL path, with no signature, shared-secret, or peer-identity check anywhere in the receive path. Any remote party who can reach the bound `endpoint` socket can POST a crafted JSON body and have it converted into a `SignerEvent::NewBlock`/`NewBurnBlock`/`SignerMessages` and pushed into the signer's runloop channel, exactly as if a legitimate configured node had emitted it.

### Finding Description
The claimed equality is "event forwarded to runloop == event emitted by the configured node's event dispatcher." This equality is broken because `next_event` (libsigner/src/events.rs:413-459) only branches on `request.url()` and `request.method()`:

```
if request.url() == "/new_block" {
    process_event::<T, StacksBlockEvent>(request)
}
```

`process_event` (libsigner/src/events.rs:519-542) reads the raw body, deserializes it with `serde_json::from_slice::<E>`, and converts it with `E: TryInto<SignerEvent<T>>` — no header, token, or IP check is performed anywhere in this function or in `next_event`/`bind`. `TryFrom<StacksBlockEvent> for SignerEvent<T>` (libsigner/src/events.rs:708-720) and `TryFrom<BurnBlockEvent> for SignerEvent<T>` (libsigner/src/events.rs:637-649) unconditionally build a `SignerEvent` from whatever fields were present in attacker-controlled JSON. `forward_event` then sends this event straight into the runloop's channel (libsigner/src/events.rs:469-490) with no further validation.

`auth_password`/`auth_token` exist in the configuration (`sample/conf/signer/mainnet-signer-conf.toml`, `sample/conf/mainnet-signer.toml`) but are only used for the **outbound** direction — the node authenticating the signer's calls to the node's RPC API — not for the **inbound** direction of the node POSTing events to the signer's `endpoint`. There is no `Authorization` header check, HMAC, or source-address allowlist in `libsigner/src/events.rs`. The default sample configs bind the signer's event listener to `0.0.0.0:30000`, i.e., all interfaces, and the code itself acknowledges the trust assumption in `stacks-signer/src/lib.rs`, warning that "the signer is primarily designed for use with a local or subnet network stacks node" and to "exercise caution ... if additional proper security checks are not integrated."

### Impact Explanation
An attacker who can reach the signer's bound event-receiver socket can inject fabricated `SignerEvent::NewBlock`, `SignerEvent::NewBurnBlock`, or (for StackerDB, subject to chunk signature checks inside `TryFrom<StackerDBChunksEvent>`) forged runloop state with no proof any real Stacks node emitted it. This is a repeatable, unauthenticated write into the signer's internal event stream/state — matching the Critical category "unauthenticated/unauthorized write to state."

### Likelihood Explanation
Preconditions: the attacker must be able to open a TCP connection to the signer's configured `endpoint` address/port. Per the sample and reference configs, this endpoint commonly binds to `0.0.0.0:<port>`, and there is no authentication layer for the inbound direction, so if the port is not separately firewalled, it is remotely reachable by any unprivileged party at trivial cost (a single crafted HTTP POST), and is fully repeatable per request. The code and docs explicitly flag this as a deployment-level trust assumption rather than a code-enforced protection, meaning the vulnerability is real whenever operators don't additionally firewall the port — which the tooling itself does not enforce or verify.

### Recommendation
Add inbound authentication to `SignerEventReceiver`/`process_event`: require and verify a shared secret/HMAC header (or mTLS) on every POST before deserializing/dispatching, matching the same `auth_password`/`auth_token` value already present in configuration, and reject/ignore requests that fail the check instead of relying solely on network-level firewalling.

### Proof of Concept

```rust
// libsigner/src/events.rs (test module) or an integration test crate
use std::io::Write;
use std::net::{TcpStream, SocketAddr};
use std::sync::mpsc::channel;

#[test]
fn unauthenticated_new_block_injection() {
    let mut receiver: SignerEventReceiver<SomeSignerMessageType> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();
    let (tx, rx) = channel();
    receiver.add_consumer(tx);

    std::thread::spawn(move || receiver.main_loop());

    // Attacker: raw TCP connection, no secret, no node involved
    let body = r#"{"index_block_hash":"0x00..","consensus_hash":"0x00..","block_hash":"0x00..","block_height":999999,"transactions":[]}"#;
    let mut stream = TcpStream::connect(bound).unwrap();
    let req = format!(
        "POST /new_block HTTP/1.1\r\nHost: x\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let ev = rx.recv_timeout(std::time::Duration::from_secs(2)).unwrap();
    // Assertion: attacker-forged NewBlock event reaches the runloop with no node involved
    assert!(matches!(ev, SignerEvent::NewBlock { block_height: 999999, .. }));
}
```

```rust
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
```

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```
