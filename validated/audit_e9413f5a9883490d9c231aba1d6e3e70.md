### Title
Unchecked slice indexing while parsing reftable `.ref` files causes a DoS panic - ([File: internal/git/reftable/reftable.go])

### Summary
The reftable binary parser in `internal/git/reftable/reftable.go` repeatedly slices attacker-influenced byte buffers using offsets and lengths decoded directly from the file contents, without validating that the resulting indices stay within the buffer bounds. A malformed or truncated `.ref` table file processed by Gitaly's reftable code path triggers an out-of-range slice panic, matching the reported bug class (unvalidated length-derived slicing causing a crash before any content-level error is returned).

### Finding Description
`getVarInt` reads a variable-length integer from `src` starting at `start` and only bounds-checks the continuation byte against `blockEnd`, not the very first read `src[start]`: [1](#0-0) 

`getRefsFromBlock` then uses lengths returned by `getVarInt` (`prefixLength`, `suffixLength`, hash sizes, symref `size`) to slice `src` and `prefix` without checking they fit within the buffer: [2](#0-1) 

For example, `refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])` and `reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()` will panic with "slice bounds out of range" if `prefixLength`, `suffixLength`, or the computed `idx` exceed the actual buffer/string length — there is no `if` guard analogous to the length check pattern used elsewhere in the codebase (e.g. `getBlockRange`).

`extractBlockLen` and `parseRefBlock` likewise index `src` at attacker-controlled offsets without bounds checks: [3](#0-2) [4](#0-3) 

`GetReferences` also indexes `src[blockStart+headerOffset]` directly: [5](#0-4) 

While `parseHeader`/`parseFooter` validate the magic bytes, version, hash ID, and CRC32 checksum of the file, none of these checks constrain the internal block/record length fields used later during `getRefsFromBlock`, so a file that passes header/footer/CRC validation can still contain corrupted internal block structure that causes an out-of-bounds panic during ref-block parsing.

This parser is reachable via `reftable.ParseTable`, which is invoked from `reftableRecorder.stageTables` during transaction WAL staging when resequencing newly written reftable files: [6](#0-5) 

More importantly for cross-node/cross-repository reachability, `ReplicateRepository`/`createFromSnapshot` extracts a tar snapshot of a **source** repository (potentially served by a different Gitaly node) directly onto disk via `extractTarToDirectory`/`extractFile`, writing arbitrary file contents (including any reftable `.ref` files) into the target repository's `reftable/` directory without validating their internal structure: [7](#0-6) [8](#0-7) 

If the source repository (which may be reachable by an ordinary user through fork/replication workflows, or compromised/malicious in a multi-node topology) contains a reftable file whose header/footer/CRC are valid but whose internal block encoding is corrupted, any subsequent write transaction against that repository that triggers `reftableRecorder.stageTables` → `reftable.ParseTable` → (indirectly parsing) will panic in `getRefsFromBlock`/`getVarInt`.

### Impact Explanation
A panic during RPC handling in `internal/gitaly/storage/storagemgr/partition/reftable.go` crashes the goroutine handling the request; `panichandler.UnaryPanicHandler`/`StreamPanicHandler` recovers gRPC-level panics for the *current* RPC, but during transaction staging deep in the storage manager, an unrecovered panic can still destabilize the partition's transaction manager or the whole process depending on the call context. At minimum, this results in denial of service for the affected repository's partition, and repeated corrupted reftable propagation via replication could cause repeated crashes across nodes.

### Likelihood Explanation
Reaching this requires a reftable-backend repository containing a corrupted-but-checksum-valid `.ref` file to exist in storage and be replicated or written to via a normal Gitaly write transaction — no privileged access or forged proof/token is required, only a repository whose stored reftable bytes are malformed at the block/record level, similar to the original report's "valid serialization with a short vector" scenario.

### Recommendation
Add explicit bounds checks before every slice operation in `getVarInt`, `getRefsFromBlock`, `extractBlockLen`, `parseRefBlock`, and `GetReferences` — verify decoded offsets/lengths (`prefixLength`, `suffixLength`, `idx+hashSize`, symref `size`, `blockStart+currentBS`, etc.) against the buffer length and block boundaries, returning a structured error instead of allowing Go's runtime bounds check to panic. Consider wrapping the parsing path with recovery at the point reftable files are opened from storage/replication, in addition to fixing root-cause validation.

### Proof of Concept
1. Create a reftable-backend repository and obtain a valid `.ref` file (passes header/footer/CRC checks).
2. Corrupt an internal record's length-prefixed field (e.g., set `suffixLength` in a ref block's varint encoding to a value larger than the remaining block bytes) while keeping the footer CRC32 consistent (recompute CRC over the modified footer bytes; block/ref-block bytes are not covered by footer CRC per the reftable format, only header/footer verified in `parseFooter`).
3. Store this corrupted `.ref` file (and matching `tables.list`) as part of a repository's `reftable/` directory, e.g. via `ReplicateRepository`'s snapshot-extraction path (`extractTarToDirectory`) which writes files without content validation.
4. Trigger a write transaction on the repository that adds/updates references, causing `reftableRecorder.stageTables` to call `reftable.ParseTable(...)` on the corrupted file.
5. Observe the process panics inside `getRefsFromBlock`/`getVarInt` due to out-of-range slicing, crashing the request path (and potentially the partition's transaction manager).

func (t *Table) getVarInt(src []byte, start uint, blockEnd uint) (uint, uint, error) {
	var val uint

	val = uint(src[start]) & 0x7f

	for (uint(src[start]) & 0x80) > 0 {
		start++
		if start > blockEnd {
			return 0, 0, fmt.Errorf("exceeded block length")
		}

		val = ((val + 1) << 7) | (uint(src[start]) & 0x7f)
	}

	return start + 1, val, nil
}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}

func (s *server) extractSnapshot(ctx context.Context, source, target *gitalypb.Repository) error {
	repoClient, err := s.newRepoClient(ctx, source.GetStorageName())
	if err != nil {
		return fmt.Errorf("new client: %w", err)
	}

	stream, err := repoClient.GetSnapshot(ctx, &gitalypb.GetSnapshotRequest{Repository: source})
	if err != nil {
		return fmt.Errorf("get snapshot: %w", err)
	}

	// We need to catch a possible 'invalid repository' error from GetSnapshot. On an empty read,
	// we read the first message from the stream here to get access to the possible 'invalid repository' error.
	firstBytes, err := stream.Recv()
	if err != nil {
		switch {
		case structerr.GRPCCode(err) == codes.NotFound && strings.Contains(err.Error(), "GetRepoPath: not a git repository:"):
			// The error condition exists for backwards compatibility purposes, only,
			// and can be removed in the next release.
			return ErrInvalidSourceRepository
		case structerr.GRPCCode(err) == codes.NotFound && strings.Contains(err.Error(), storage.ErrRepositoryNotFound.Error()):
			return ErrInvalidSourceRepository
		case structerr.GRPCCode(err) == codes.FailedPrecondition && strings.Contains(err.Error(), storage.ErrRepositoryNotValid.Error()):
			return ErrInvalidSourceRepository
		default:
			return fmt.Errorf("first snapshot read: %w", err)
		}
	}

	snapshotReader := io.MultiReader(
		bytes.NewReader(firstBytes.GetData()),
		streamio.NewReader(func() ([]byte, error) {
			resp, err := stream.Recv()
			return resp.GetData(), err
		}),
	)

	targetPath, err := s.locator.GetRepoPath(ctx, target, storage.WithRepositoryVerificationSkipped())
	if err != nil {
		return fmt.Errorf("target path: %w", err)
	}

	// Extract tar using Go's tar package
	if err := s.extractTarToDirectory(ctx, snapshotReader, targetPath); err != nil {
		return fmt.Errorf("extract tar: %w", err)
	}

	return nil
}

func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

		default:
			// Skip unsupported file types (devices, FIFOs, etc.)
			s.logger.WithField("file", header.Name).WithField("type", header.Typeflag).
				WarnContext(ctx, "skipping unsupported file type in tar archive")
		}

		if header.Typeflag == tar.TypeReg || header.Typeflag == tar.TypeDir {
			if err := os.Chmod(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("setting permissions for %s: %w", targetPath, err)
			}
		}
	}

	return nil
}
