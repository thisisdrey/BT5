### Title
CA-Pool Blocklist Bypass for Certificates Issued by a Revoked CA - ([File: cert/ca_pool.go])

### Summary
`CAPool.verify()` only checks the *leaf certificate's own* fingerprint against the blocklist. It never checks the fingerprint of the **signing CA** (the entity returned by `GetCAForCert`) against that same blocklist. This is the same bug class as the H-01 finding: an authorization/restriction check is bound to the wrong identity — the code validates the wrong actor (leaf cert fingerprint) instead of the actor whose trust actually needs to be revoked (the issuing CA fingerprint) — allowing the restriction to be silently bypassed.

### Finding Description
`CAPool` maintains a single fingerprint blocklist (`certBlocklist`) that is used both for revoking individual host certificates and, per the `pki.blocklist` config option, for revoking arbitrary fingerprints — including CA certificates that remain present in the `pki.ca` trust bundle (e.g. while an operator rotates away from a compromised CA without editing the CA bundle file). The verification path is: [1](#0-0) 

`verify()` checks `ncp.IsBlocklisted(certFp)` for the leaf certificate's fingerprint only. It then calls `GetCAForCert`, which simply performs a map lookup by `Issuer()` fingerprint with no blocklist check on the returned signer: [2](#0-1) 

Nowhere in `verify()`, `VerifyCertificate()`, or `VerifyCachedCertificate()` is `signer.Fingerprint` (the CA's own fingerprint) tested against `certBlocklist`: [3](#0-2) 

Operators can add arbitrary fingerprints to the blocklist via `pki.blocklist`, which is the documented mechanism for revoking compromised certificates, including CAs: [4](#0-3) 

Because `AddCA()` also performs no blocklist check when the CA is loaded into the pool, a CA that has been explicitly blocklisted (revoked) remains fully functional as a trust anchor — every host certificate it ever signed (or newly signs, if its key is compromised) continues to pass `VerifyCertificate`/`VerifyCachedCertificate`. [5](#0-4) 

This is directly analogous to the H-01 root cause: `_update` checks `hasRole(FULL_RESTRICTED_STAKER_ROLE, from)` where `from` is forced to `address(0)` by `_mint`, so the restriction is checked against the wrong (always-innocent) identity instead of the actual restricted actor. Here, the blocklist is checked against the leaf cert's fingerprint (always distinct/innocent) instead of also checking the actual revoked identity — the signing CA's fingerprint.

### Impact Explanation
This is a certificate-verification/authentication-bypass bug. An operator's attempt to revoke a compromised or no-longer-trusted CA via `pki.blocklist` (without also physically removing the CA from the `pki.ca` bundle, which is a supported and realistic operational pattern for staged CA rotation) silently fails: any peer holding a certificate signed by that revoked CA — including newly minted certificates signed with a leaked CA private key — will still pass handshake verification (`VerifyCertificate`) and periodic re-validation during the tunnel's life (`connection_manager.isInvalidCertificate` → `VerifyCachedCertificate`): [6](#0-5) 

The result is that a host the operator believed was cut off from the mesh (because its issuing CA was revoked) can still complete handshakes, decrypt/forge traffic, and pass firewall rule matching, since firewall CA-based rules also rely on the same trusted CA relationship (`FirewallCA.match` via `caPool.GetCAForCert`), which is unaffected by the blocklist: [7](#0-6) 

### Likelihood Explanation
Any node that already possesses a certificate signed by a CA the network operator has blocklisted can exploit this without any additional capability — it does not require forging a signature or obtaining a certificate from a still-trusted CA. This is a realistic and expected admin workflow (mark a CA's fingerprint on the blocklist while phasing it out), so the bypass condition is easily triggered unintentionally, and trivially reachable by an attacker who already holds (or can mint, if the CA key leaked) a certificate under the revoked CA.

### Recommendation
In `CAPool.verify()`, also check `ncp.IsBlocklisted(signer.Fingerprint)` (and the P256 alternate fingerprint of the signer, mirroring the existing high-s/low-s handling) immediately after `GetCAForCert` resolves the signer, and return `ErrBlockListed` if the CA itself is blocklisted. Optionally also reject/skip CAs in `AddCA()` that are already present in `certBlocklist` at load time, and cache this signer-blocklist result in `CachedCertificate` for cheap re-validation in `VerifyCachedCertificate`.

### Proof of Concept
1. Configure a CA pool with CA `A` (trusted, in `pki.ca`) and issue host cert `H` signed by `A`.
2. Operator suspects `A`'s key is compromised and adds `A`'s fingerprint to `pki.blocklist`, but leaves `A` in the `pki.ca` bundle (e.g., during a rolling migration to a new CA, or because removing it would also invalidate other still-desired certs signed by `A`).
3. Node presenting `H` connects: `CAPool.VerifyCertificate` computes `H`'s own fingerprint, checks it against `certBlocklist` (not present, since only `A`'s fingerprint was blocklisted), resolves `A` via `GetCAForCert`, verifies the signature/constraints, and returns success — despite `A` being explicitly revoked.
4. The handshake proceeds and periodic checks in `connection_manager.isInvalidCertificate` also pass, since `VerifyCachedCertificate` has the same gap — the tunnel is never torn down for being signed by a blocklisted CA.

// AddCA verifies a Nebula CA certificate and adds it to the pool.
func (ncp *CAPool) AddCA(c Certificate) error {
	if !c.IsCA() {
		return fmt.Errorf("%s: %w", c.Name(), ErrNotCA)
	}

	if !c.CheckSignature(c.PublicKey()) {
		return fmt.Errorf("%s: %w", c.Name(), ErrNotSelfSigned)
	}

	sum, err := c.Fingerprint()
	if err != nil {
		return fmt.Errorf("could not calculate fingerprint for provided CA; error: %w; %s", err, c.Name())
	}

	cc := &CachedCertificate{
		Certificate:    c,
		Fingerprint:    sum,
		InvertedGroups: make(map[string]struct{}),
	}

	for _, g := range c.Groups() {
		cc.InvertedGroups[g] = struct{}{}
	}

	ncp.CAs[sum] = cc

	if c.Expired(time.Now()) {
		return fmt.Errorf("%s: %w", c.Name(), ErrExpired)
	}

	return nil
}

func (ncp *CAPool) VerifyCachedCertificate(now time.Time, c *CachedCertificate) error {
	// Check any available alternate fingerprint forms for this certificate, re P256 high-s/low-s
	if c.fingerprint2 != "" && ncp.IsBlocklisted(c.fingerprint2) {
		return ErrBlockListed
	}

	_, err := ncp.verify(c.Certificate, now, c.Fingerprint, c.signerFingerprint)
	return err
}

func (ncp *CAPool) verify(c Certificate, now time.Time, certFp string, signerFp string) (*CachedCertificate, error) {
	if ncp.IsBlocklisted(certFp) {
		return nil, ErrBlockListed
	}

	signer, err := ncp.GetCAForCert(c)
	if err != nil {
		return nil, err
	}

	if signer.Certificate.Curve() != c.Curve() {
		return nil, ErrCurveMismatch
	}

	if signer.Certificate.Expired(now) {
		return nil, ErrRootExpired
	}

	if c.Expired(now) {
		return nil, ErrExpired
	}

	// If we are checking a cached certificate then we can bail early here
	// Either the root is no longer trusted or everything is fine
	if len(signerFp) > 0 {
		if signerFp != signer.Fingerprint {
			return nil, ErrFingerprintMismatch
		}
		return signer, nil
	}
	if !c.CheckSignature(signer.Certificate.PublicKey()) {
		return nil, ErrSignatureMismatch
	}

	err = CheckCAConstraints(signer.Certificate, c)
	if err != nil {
		return nil, err
	}

	return signer, nil
}

// GetCAForCert attempts to return the signing certificate for the provided certificate.
// No signature validation is performed
func (ncp *CAPool) GetCAForCert(c Certificate) (*CachedCertificate, error) {
	issuer := c.Issuer()
	if issuer == "" {
		return nil, fmt.Errorf("no issuer in certificate")
	}

	signer, ok := ncp.CAs[issuer]
	if ok {
		return signer, nil
	}

	return nil, ErrCaNotFound
}

func (cm *connectionManager) isInvalidCertificate(now time.Time, hostinfo *HostInfo) bool {
	remoteCert := hostinfo.GetCert()
	if remoteCert == nil {
		return false //don't tear down tunnels for handshakes in progress
	}

	caPool := cm.intf.pki.GetCAPool()
	err := caPool.VerifyCachedCertificate(now, remoteCert)
	if err == nil {
		return false //cert is still valid! yay!
	} else if err == cert.ErrBlockListed { //avoiding errors.Is for speed
		// Block listed certificates should always be disconnected
		hostinfo.logger(cm.l).Info("Remote certificate is blocked, tearing down the tunnel",
			"error", err,
			"fingerprint", remoteCert.Fingerprint,
		)
		return true

func (fc *FirewallCA) match(p firewall.Packet, c *cert.CachedCertificate, caPool *cert.CAPool) bool {
	if fc == nil {
		return false
	}

	if fc.Any.match(p, c) {
		return true
	}

	if t, ok := fc.CAShas[c.Certificate.Issuer()]; ok {
		if t.match(p, c) {
			return true
		}
	}

	s, err := caPool.GetCAForCert(c.Certificate)
	if err != nil {
		return false
	}

	return fc.CANames[s.Certificate.Name()].match(p, c)
}
