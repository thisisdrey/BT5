### Title
Unauthenticated `/proposal_response`, `/new_burn_block`, `/new_block` endpoints allow forged consensus-adjacent events to be forwarded to the signer runloop - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` routes any POST to `/proposal_response`, `/new_burn_block`, or `/new_block` straight into `process_event::<T, BlockValidateResponse>`, `process_event::<T, BurnBlockEvent>`, or `process_event::<T, StacksBlockEvent>` with no signature, token, or peer-identity check on the request. `try_from` then wraps the deserialized JSON directly into `SignerEvent::BlockValidationResponse`, `SignerEvent::NewBurnBlock`, or `SignerEvent::NewBlock` and `forward_event` sends it unchanged to the runloop channel, so the transport layer treats any TCP client that can reach the listening port as if it were the configured stacks-node. [2](#0-1) [3](#0-2) [4](#0-3) 

### Finding Description
The claimed equality — "the party asserting a block was validated/processed == the actual configured stacks-node" — is broken at the transport layer. `next_event` matches on `request.url()` and, for `POST` requests, dispatches directly to `process_event::<T, E>` for all four event types (`StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, `StacksBlockEvent`) without ever inspecting the request's origin, an auth header, or a shared secret. [5](#0-4) 
The `GlobalConfig::endpoint` that this `SignerEventReceiver` binds to is documented and sample-configured as `0.0.0.0:30000`, i.e., listening on all interfaces rather than restricted to loopback, and the `auth_password`/`auth_token` pair documented alongside it is only used for the signer's outbound RPC calls to the node, not for validating inbound POSTs to this event listener. [6](#0-5) 
Consequently, any TCP client that can reach that port can POST a crafted `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` JSON body; `TryFrom` conversions perform no cross-checks against real chain state (e.g., no verification that a `NewBlock`'s `consensus_hash`/`block_id` correspond to anything the node actually processed), and `forward_event` relays the resulting `SignerEvent` to the runloop unchanged. [7](#0-6) 

### Impact Explanation
This lets an unauthenticated party inject fabricated `SignerEvent::BlockValidationResponse`, `SignerEvent::NewBurnBlock`, or `SignerEvent::NewBlock` events into the signer's internal event stream, which the runloop then treats as authentic node output (e.g., `handle_block_validate_response`, `stacks_block_arrival`/`mark_globally_accepted`, `insert_burn_block`). [8](#0-7) 
Scoped strictly to the transport surfacing (not the runloop's downstream decision logic, which is out of scope), this is an unauthenticated forged consensus-adjacent event accepted and forwarded by the transport with no verification, matching the "unauthenticated write to state" class of impact since it is stored into `signer_db`/local state machine driven purely from an unauthenticated network write. It is repeatable per message with no rate limiting visible in this dispatch path.

### Likelihood Explanation
No preconditions beyond network reachability to the signer's bound event-receiver port are required — no secret, no valid peer key, no StackerDB slot ownership. The sample/documented configuration binds this listener to `0.0.0.0`, so it is remotely reachable by design unless operators separately firewall it; attacker cost is a single crafted HTTP POST, and the action is trivially repeatable. [9](#0-8) 

### Recommendation
Require the `SignerEventReceiver` HTTP server to validate an authentication token/secret (e.g., reuse `auth_password`/`auth_token` for inbound requests, not just outbound RPC calls) on every POST before dispatching to `process_event`, and/or bind the listener to loopback only by default and document the risk of exposing it externally.

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }
