### Title
Unbounded memory allocation from StackerDB replica HTTP response body (no `MAX_MESSAGE_LEN` cap on non-chunked bodies) - (File: libsigner/src/http.rs)

### Summary
`run_http_request` in `libsigner/src/http.rs` reads an entire HTTP response into memory via `sock.read_to_end(&mut buf)` with no size limit, and for non-chunked bodies `decode_http_body` simply does `buf.to_vec()` with no cap tied to `MAX_MESSAGE_LEN`. A malicious StackerDB replica that a `StackerDBSession` dials (via `list_chunks`/`get_chunks`/`put_chunk`) can respond with an arbitrarily large non-chunked HTTP/1.1 body and force the client node to allocate memory proportional to whatever the attacker chooses to send.

### Finding Description
`StackerDBSession::rpc_request` (`libsigner/src/session.rs:162-172`) calls `run_http_request(sock, &session.host, ...)`, which is defined in `libsigner/src/http.rs:221-262`. That function issues the request and then does:

```rust
let mut buf = vec![];
sock.read_to_end(&mut buf)?;
let (headers, body_offset) = decode_http_response(&buf)?;
...
decode_http_body(&headers, &buf[body_offset..]).map_err(|e| e.into())
```

`sock.read_to_end` has no size bound — it keeps allocating and reading until the peer closes the connection or the socket read times out (the socket has only a read *timeout*, `socket_timeout`, not a byte-count cap, set in `StackerDBSession::connect_or_reconnect`). Then in `decode_http_body` (`libsigner/src/http.rs:197-217`), only the chunked-encoding branch is capped via `HttpChunkedTransferReader::from_reader(ptr, MAX_MESSAGE_LEN.into())`; the non-chunked branch is just `buf.to_vec()`, applying no size check at all.

Critically, the unbounded read already happens at `sock.read_to_end` *before* `decode_http_body` is even invoked, so even the chunked-path cap only limits how much of the already-fully-buffered response gets copied into the decoded output — it doesn't prevent the initial unbounded materialization of the raw response into `buf`. For a non-chunked response this is compounded: nothing in the entire request path enforces `MAX_MESSAGE_LEN` on body size.

An attacker operating as a StackerDB replica peer that a signer's `StackerDBSession` connects to (its `host` is a configured peer, e.g. via `list_chunks`/`get_chunks` calls) can respond to any such request with a non-chunked `Content-Length`-less or arbitrarily large `Content-Length` body and stream as many bytes as it likes within the read timeout window (each individual `read()` syscall just needs to complete within `socket_timeout`; the attacker can keep sending data indefinitely as long as bytes keep arriving before the timeout elapses), causing the signer client to allocate memory proportional to attacker-chosen size with no upper bound.

### Impact Explanation
The affected node (a signer or any consumer of `StackerDBSession`) can be driven to unbounded memory allocation from a single malicious StackerDB replica response, leading to memory exhaustion and process crash/OOM — an unauthenticated DoS achievable from few (a single) HTTP responses from an attacker-controlled StackerDB peer. This matches the Critical category "remote crash/unauthenticated DoS from few messages."

### Likelihood Explanation
Preconditions: the attacker must be a StackerDB replica that the victim's `StackerDBSession` is configured to dial (a peer whose `host` the client legitimately connects to for `list_chunks`/`get_chunks`/`put_chunk`), which matches the in-scope attacker profile of "attacker runs their own peer" and holds a legitimate StackerDB slot/replica role. No secret or privileged role is needed beyond being a reachable replica endpoint. The attack is trivially repeatable on every RPC call the client makes to that replica, and costs the attacker only the bytes/time it is willing to send.

### Recommendation
Bound `sock.read_to_end` itself (e.g., wrap the socket read in a `Read::take(MAX_MESSAGE_LEN)` limiter, or read incrementally while enforcing a running byte-count limit and aborting/erroring once `MAX_MESSAGE_LEN` is exceeded) before any parsing occurs. Additionally, enforce the same `MAX_MESSAGE_LEN` cap in the non-chunked branch of `decode_http_body`, rejecting bodies whose length (or `Content-Length` header) exceeds the limit, so the guard is consistent between chunked and non-chunked responses.

### Proof of Concept
```rust
// libsigner/src/session.rs (test module) or a new integration test
use std::io::{Read, Write};
use std::net::TcpListener;
use std::thread;
use std::time::Duration;

#[test]
fn oversized_non_chunked_body_is_not_capped() {
    let listener = TcpListener::bind("127.0.0.1:0").expect("bind failed");
    let addr = listener.local_addr().unwrap();

    thread::spawn(move || {
        if let Ok((mut stream, _)) = listener.accept() {
            // drain the request
            let mut tmp = [0u8; 4096];
            let _ = stream.read(&mut tmp);
            // Respond with a huge non-chunked body, no Transfer-Encoding: chunked
            let big_len = stacks_common::codec::MAX_MESSAGE_LEN as usize * 4; // 4x over the cap
            stream
                .write_all(format!("HTTP/1.1 200 OK\r\nContent-Length: {big_len}\r\n\r\n").as_bytes())
                .unwrap();
            let chunk = vec![0u8; 1024 * 1024];
            let mut sent = 0;
            while sent < big_len {
                stream.write_all(&chunk).unwrap();
                sent += chunk.len();
            }
        }
    });

    let contract_id = clarity::vm::types::QualifiedContractIdentifier::transient();
    let mut session = StackerDBSession::new(&addr.to_string(), contract_id, Duration::from_secs(30));
    session.connect_or_reconnect().expect("connect failed");

    let result = session.rpc_request("GET", "/", None, &[]).expect("request failed");
    // Demonstrates no MAX_MESSAGE_LEN enforcement: body exceeds the cap that the
    // chunked path would have enforced via HttpChunkedTransferReader.
    assert!(result.len() > stacks_common::codec::MAX_MESSAGE_LEN as usize);
}
```

/// Decode an HTTP body, given the headers.
pub fn decode_http_body(headers: &HashMap<String, String>, mut buf: &[u8]) -> io::Result<Vec<u8>> {
    let chunked = if let Some(val) = headers.get("transfer-encoding") {
        val == "chunked"
    } else {
        false
    };

    let body = if chunked {
        // chunked encoding
        let ptr = &mut buf;
        let mut fd = HttpChunkedTransferReader::from_reader(ptr, MAX_MESSAGE_LEN.into());
        let mut decoded_body = vec![];
        fd.read_to_end(&mut decoded_body)?;
        decoded_body
    } else {
        // body is just as-is
        buf.to_vec()
    };

    Ok(body)
}

pub fn run_http_request<S: Read + Write>(
    sock: &mut S,
    host: &str,
    verb: &str,
    path: &str,
    content_type: Option<&str>,
    payload: &[u8],
) -> Result<Vec<u8>, RPCError> {
    let content_length_hdr = if !payload.is_empty() {
        format!("Content-Length: {}\r\n", payload.len())
    } else {
        "".to_string()
    };

    let req_txt = if let Some(content_type) = content_type {
        format!(
            "{verb} {path} HTTP/1.1\r\nHost: {host}\r\nConnection: close\r\nContent-Type: {content_type}\r\n{content_length_hdr}User-Agent: libsigner/0.1\r\nAccept: */*\r\n\r\n"
        )
    } else {
        format!(
            "{verb} {path} HTTP/1.1\r\nHost: {host}\r\nConnection: close\r\n{content_length_hdr}User-Agent: libsigner/0.1\r\nAccept: */*\r\n\r\n"
        )
    };
    debug!("HTTP request\n{}", &req_txt);

    sock.write_all(req_txt.as_bytes())?;
    sock.write_all(payload)?;

    let mut buf = vec![];

    sock.read_to_end(&mut buf)?;

    let (headers, body_offset) = decode_http_response(&buf)?;
    if body_offset >= buf.len() {
        // no body
        debug!("No HTTP body");
        debug!("Headers: {:?}", &headers);
        return Ok(vec![]);
    }

    decode_http_body(&headers, &buf[body_offset..]).map_err(|e| e.into())
}

        let mut payloads = vec![];
        for (slot_id, slot_version) in slots_and_versions.iter() {

                self.stackerdb_contract_id.clone(),
                *slot_id,
                Some(*slot_version),
            );
            let chunk = match self.rpc_request("GET", &path, None, &[]) {
                Ok(body_bytes) => Some(body_bytes),
                Err(RPCError::HttpError(code)) => {
                    if code != 404 {
                        return Err(RPCError::HttpError(code));
                    }
                    None
                }
                Err(e) => {
                    return Err(e);
                }
            };
            payloads.push(chunk);
