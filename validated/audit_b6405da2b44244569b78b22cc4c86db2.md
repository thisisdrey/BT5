### Title
Unliquidatable bad debt when remaining debt is forced below `debtFloorInUsd` - (`contracts/Pool.sol`)

### Summary
`Pool.liquidate()` can permanently strand an underwater position when the account’s debt is greater than the debt floor but less than `debtFloorInUsd / (1 - maxLiquidable)`, because every non-zero repayment that satisfies `maxLiquidable` leaves a positive remainder below the floor. [1](#0-0) 

### Finding Description
An unprivileged borrower can open a normal healthy position with debt just above `debtFloorInUsd`. After the collateral value falls enough for the position to become unhealthy, liquidation becomes unavailable: any `amountToRepay_` up to `maxLiquidable * debt` leaves `debt - amountToRepay_` positive and below `debtFloorInUsd`, while any larger repayment reverts as exceeding `maxLiquidable`. [2](#0-1) [3](#0-2) 

The default configuration initializes `maxLiquidable` to `50%`, so a debt-floor amount between the floor and twice the floor can enter this state. [4](#0-3) 

For example, with `debtFloorInUsd = $3,000` and a debt worth `$3,100`, a `50%` liquidation cap permits at most `$1,550`; repaying more than `$100` therefore leaves less than `$3,000` and reverts, while repaying more than `$1,550` also reverts. [1](#0-0) 

`DebtToken.repay()` repeats the same floor check, but it does not transfer collateral, so it cannot substitute for liquidation; `repayAll()` is only a voluntary debt repayment path and likewise does not seize collateral. [5](#0-4) [6](#0-5) 

### Impact Explanation
The liquidation-liveness invariant breaks: an unhealthy position cannot be liquidated through `Pool.liquidate()` once the allowed repayment range is incompatible with the floor. [7](#0-6) 

If the collateral value subsequently falls below the outstanding debt, the protocol is left with bad debt because the borrower can abandon the position and external liquidators cannot clear it. [8](#0-7) 

This does not require privileged access: the attacker only calls `DepositToken.deposit()` and `DebtToken.issue()` for their own account before ordinary market movement makes the position unhealthy. [9](#0-8) [10](#0-9) 

### Likelihood Explanation
Likelihood depends on `debtFloorInUsd` being nonzero and `maxLiquidable` being below `100%`; the deployed implementation initializes the cap to `50%`. [4](#0-3) [11](#0-10) 

The attacker’s setup cost is bounded by the required collateral for a debt in the affected range, and ordinary collateral depreciation can move the position into the unliquidatable state. [12](#0-11) 

### Recommendation
Change `Pool.liquidate()` so a liquidation may clear the entire remaining debt when a partial repayment would otherwise violate `debtFloorInUsd`, or exempt exact-full liquidation from the floor check before applying the `maxLiquidable` cap. [1](#0-0) 

A safe ordering is to normalize `amountToRepay_` to `min(amountToRepay_, debtBalance)`, explicitly permit `amountToRepay_ == debtBalance`, and only enforce `maxLiquidable` for strictly partial liquidations. [13](#0-12) 

### Proof of Concept
This Foundry-style test demonstrates the revert pair on the existing Hardhat fixture/model: a `$3,100` debt with a `$3,000` floor and `50%` liquidation cap cannot be cleared. [14](#0-13) 

```solidity
// test/foundry/poc/LiquidationDebtFloorDoS.t.sol
function test_debtFloorBlocksFullAndPartialLiquidation() public {
    // Assumes:
    //   borrower deposited collateral and issued debt = $3,100
    //   debtFloorInUsd = $3,000
    //   maxLiquidable = 0.5e18
    //   collateral price then fell, making debtPositionOf(borrower).isHealthy false

    pool.updateDebtFloor(3_000e18);
    pool.updateMaxLiquidable(0.5e18);

    uint256 debt = msDebt.balanceOf(borrower); // quoteTokenToUsd(msSynth, debt) == $3,100

    // Full repayment exceeds the 50% cap.
    vm.expectRevert(Pool.AmountGreaterThanMaxLiquidable.selector);
    pool.liquidate(msSynth, borrower, debt, depositToken);

    // Maximum allowed partial repayment leaves $1,550, below the $3,000 floor.
    uint256 maxRepay = debt / 2;
    vm.expectRevert(Pool.RemainingDebtIsLowerThanTheFloor.selector);
    pool.liquidate(msSynth, borrower, maxRepay, depositToken);

    // The largest repayment compatible with the floor is only $100;
    // after that liquidation, exactly $3,000 remains and every positive
    // liquidation attempt still reverts with RemainingDebtIsLowerThanTheFloor.
    uint256 floorCompatibleRepay =
        debt - masterOracle.quoteUsdToToken(address(msSynth), 3_000e18);

    pool.liquidate(msSynth, borrower, floorCompatibleRepay, depositToken);

    vm.expectRevert(Pool.RemainingDebtIsLowerThanTheFloor.selector);
    pool.liquidate(msSynth, borrower, 1, depositToken);
}
```

On a fork, configure the test from the live `pool`, `debtToken`, `depositToken`, and `masterOracle` addresses, create the borrower position through `deposit()` and `issue()`, move to a block/state where the position is unhealthy, and call `liquidate()` using the boundaries shown above. [15](#0-14)

        ISyntheticToken syntheticToken_,
        address account_,
        uint256 amountToRepay_,
        IDepositToken depositToken_
    )
        external
        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticToken_)
        onlyIfDepositTokenExists(depositToken_)
        returns (uint256 _totalSeized, uint256 _toLiquidator, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (amountToRepay_ == 0) revert AmountIsZero();
        if (_msgSender == account_) revert CanNotLiquidateOwnPosition();

        IDebtToken _debtToken = debtTokenOf[syntheticToken_];
        _debtToken.accrueInterest();

        (bool _isHealthy, , , , ) = debtPositionOf(account_);

        if (_isHealthy) {
            revert PositionIsHealthy();
        }

        uint256 _debtTokenBalance = _debtToken.balanceOf(account_);

        if (amountToRepay_.wadDiv(_debtTokenBalance) > maxLiquidable) {
            revert AmountGreaterThanMaxLiquidable();
        }

        if (debtFloorInUsd > 0) {
            uint256 _newDebtInUsd = masterOracle().quoteTokenToUsd(
                address(syntheticToken_),
                _debtTokenBalance - amountToRepay_
            );
            if (_newDebtInUsd > 0 && _newDebtInUsd < debtFloorInUsd) {
                revert RemainingDebtIsLowerThanTheFloor();
            }
        }

        (_totalSeized, _toLiquidator, _fee) = quoteLiquidateOut(syntheticToken_, amountToRepay_, depositToken_);

        if (_totalSeized > depositToken_.balanceOf(account_)) {
            revert AmountIsTooHigh();
        }

        syntheticToken_.burn(_msgSender, amountToRepay_);
        _debtToken.burn(account_, amountToRepay_);
        depositToken_.seize(account_, _msgSender, _toLiquidator);

        if (_fee > 0) {
            depositToken_.seize(account_, _poolRegistry.feeCollector(), _fee);
        }

        emit PositionLiquidated(_msgSender, account_, syntheticToken_, amountToRepay_, _totalSeized, _fee);
