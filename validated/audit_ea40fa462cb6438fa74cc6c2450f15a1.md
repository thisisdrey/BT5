## Finding: No vulnerability

**Premise 1 — boundary check.** `Preamble::consensus_deserialize` rejects `burn_block_height <= burn_stable_block_height` (note it's `<=`, not `<`), so a preamble with `burn_block_height == burn_stable_block_height` is explicitly **rejected**, not accepted at a boundary. [1](#0-0) 

**Premise 2 — memory allocation.** `payload_len` must be `< MAX_MESSAGE_LEN` (checked at line 179), but crucially the buffer is *not* pre-allocated to `payload_len` upon preamble parse. `buffer_message_bytes` only ever extends `self.buf` by `bytes.len().min(message_remaining)` — i.e., by the number of bytes *actually delivered* on the socket in that read, capped by however much is still needed for the declared payload length. [2](#0-1) 

Consequently, if the attacker declares `payload_len = MAX_MESSAGE_LEN - 6` but only ever sends 5 bytes after the preamble, `self.buf` only grows by those 5 bytes — not by the declared payload length. `consume_payload_known_length` then simply observes `buf_bytes.len() < payload_len` and returns `Ok(None)` ("not enough data yet"), leaving the connection waiting for more bytes rather than allocating anything close to 16MB.

    fn buffer_message_bytes(
        &mut self,
        bytes: &[u8],
        message_len_opt: Option<usize>,
    ) -> Result<usize, net_error> {
        let message_len = message_len_opt.unwrap_or(MAX_MESSAGE_LEN as usize);
        let buffered_so_far = self
            .buf
            .len()
            .checked_sub(self.message_ptr)
            .ok_or_else(|| {
                net_error::RecvError(format!("Message ptr {} overran buffer", self.message_ptr))
            })?;

        let Some(message_remaining) = message_len.checked_sub(buffered_so_far) else {
            // can happen if we receive so much data when parsing the preamble that we've
            // also already received the message, and part of the next preamble (or more).
            return Ok(0);
        };

        let to_consume = bytes.len().min(message_remaining);

        trace!("Consume {} bytes from input buffer", to_consume);
        self.buf.extend_from_slice(
            bytes
                .get(..to_consume)
                .expect("FATAL: bad length check in buffer handling"),
        );
        Ok(to_consume)
    }
