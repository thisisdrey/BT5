### Title
Signer event-receiver HTTP endpoint accepts unauthenticated data, allowing any remote peer to impersonate the trusted Stacks node - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver` (`libsigner/src/events.rs`) binds a plaintext HTTP listener that the stacks-signer process uses to receive `stackerdb_chunks`, `proposal_response`, `new_burn_block`, and `new_block` events from its paired Stacks node. Node and signer configuration documentation (`docs/signing.md`, `sample/conf/testnet-miner-conf.toml`) instructs operators to set a shared `auth_token`/`auth_password` "for authentication," but the event-receiver code that actually accepts and parses incoming HTTP POSTs never checks any credential. Any request reaching the listening socket — regardless of source — is treated as if it originated from the trusted, paired node.

### Finding Description
`SignerEventReceiver::next_event` dispatches incoming HTTP requests purely by URL/method match: [1](#0-0) 

It never inspects the `Authorization` header or compares any bearer/password value before calling `process_event`, which just deserializes the JSON body directly into a `SignerEvent`: [2](#0-1) 

`decode_http_request` in `libsigner/src/http.rs` does parse and store HTTP headers into a table, but nothing in `events.rs` reads that table to compare against a configured secret: [3](#0-2) 

This is analogous to the OAuth report's root cause: an endpoint that is documented/expected to authenticate its caller, but instead trusts whatever payload is presented, because there is no code path that actually validates identity of the request's sender. Just as the Open WebUI `token_exchange` endpoint validated only "is this a valid token" rather than "was this token issued to a trusted client," the signer's event listener validates only "does this look like well-formed JSON for a known route" rather than "did this come from my paired node."

The operator-facing documentation reinforces that this check is expected but not enforced in code: [4](#0-3) [5](#0-4) 

### Impact Explanation
Any party who can reach the signer's configured `endpoint` (which the sample configs show bound to `0.0.0.0:<port>`, not restricted to loopback) can submit forged `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` payloads. These are forwarded verbatim into the signer's runloop and processed as though they were emitted by the operator's own trusted Stacks node: [6](#0-5) 

This breaks the intended trust boundary between "data from my paired node" and "data from an arbitrary network peer," letting an attacker inject fabricated events into the signer's event pipeline without possessing any secret, node key, or admin role.

### Likelihood Explanation
Exploitation requires only network reachability to the signer's listening port and a well-formed HTTP POST — no authentication material, cryptographic key, or privileged access is needed. This mirrors the "unauthenticated remote write to state" pattern called out as in-scope impact.

### Recommendation
Enforce the documented `auth_token`/`auth_password` check inside `SignerEventReceiver::next_event` (or `decode_http_request`) before dispatching to `process_event`: extract the `Authorization` header from the parsed request, compare it in constant time against the configured secret, and reject (401/403) any request that fails the check, mirroring the intent already documented in `docs/signing.md`.

### Proof of Concept
1. Configure a signer per `sample/conf/signer/mainnet-signer-conf.toml` with `endpoint = "0.0.0.0:30000"` and any `auth_password`.
2. From a separate host with network access to port 30000, send:
```
POST /stackerdb_chunks HTTP/1.1
Host: <signer-ip>:30000
Content-Type: application/json
Content-Length: <n>

{"contract_id": "...", "modified_slots": [...]}
```
with no `Authorization` header (or any arbitrary value).
3. Observe the request is accepted, parsed via `process_event::<T, StackerDBChunksEvent>`, and forwarded to the signer's runloop exactly as if it had come from the paired node — confirming the absence of any authentication enforcement in `libsigner/src/events.rs`.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

/// Returns (verb, path, table of headers, body_offset) on success
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}

### 2. Configure the Signer

Use [`mainnet-signer-conf.toml`](../sample/conf/signer/mainnet-signer-conf.toml) as a starting point.
Key settings:

```toml
stacks_private_key = "<YOUR_SIGNER_PRIVATE_KEY_HEX>"
node_host = "127.0.0.1:20443"
endpoint = "0.0.0.0:30000"
network = "mainnet"
auth_password = "your-secret-token"
db_path = "/var/lib/stacks-signer/signerdb.sqlite"
```

### 3. Verify Coordination

These settings **must** match between the node and signer configs:

| Signer Config   | Node Config                       | Must Match                    |
| --------------- | --------------------------------- | ----------------------------- |
| `auth_password` | `[connection_options] auth_token` | Exact string match            |
| `endpoint`      | `[[events_observer]] endpoint`    | Same host:port                |
| `node_host`     | `[node] rpc_bind`                 | Signer connects to node's RPC |
```
