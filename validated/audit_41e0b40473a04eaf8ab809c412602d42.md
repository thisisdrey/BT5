### Title
`/v2/neighbors` HTTP RPC endpoint discloses private/internal IP addresses of peers regardless of `private_neighbors` config - (File: stackslib/src/net/api/getneighbors.rs)

### Summary
The `RPCNeighborsInfo::from_p2p` handler backing the unauthenticated `GET /v2/neighbors` RPC endpoint serves the raw `addrbytes` (IP) of every bootstrap, sampled, inbound, and outbound peer without applying the private-IP filtering that every other neighbor-disclosure code path in the same codebase applies.

### Finding Description
Every other place in this codebase that surfaces neighbor/peer addresses filters out private-range and any-net addresses unless the operator has explicitly opted in via `connection_opts.private_neighbors`:
- P2P `handle_getneighbors` uses `get_fresh_random_neighbors(..., public_only=...)` [1](#0-0) .
- The neighbor walker filters with `filter_sensible_neighbors`, dropping `is_anynet()` and (if `!private_neighbors`) `is_in_private_range()` addresses [2](#0-1) .
- `find_qualified_replicas` (StackerDB sync) applies the identical `is_anynet`/`is_in_private_range` gate keyed on `private_neighbors` [3](#0-2) .
- The `RPCListStackerDBReplicasRequestHandler` (the sibling HTTP RPC endpoint for StackerDB peers) explicitly filters `is_anynet()` and `is_in_private_range()` unless `allow_private` (`private_neighbors`) is set [4](#0-3) .

In contrast, `RPCNeighborsInfo::from_p2p`, which serves the `/v2/neighbors` HTTP RPC endpoint, builds `bootstrap`, `sample`, `inbound`, and `outbound` peer lists directly from `PeerDB::get_bootstrap_peers`, `PeerDB::get_fresh_random_neighbors`, and live P2P conversations with **no** `is_anynet()` or `is_in_private_range()` filtering step at all [5](#0-4) . The handler itself performs no additional filtering before serializing the response [6](#0-5) . This endpoint requires no authentication (`try_parse_request` only validates body length) [7](#0-6) , and the existing test suite for it never asserts private-range filtering (only that `stackerdbs` is populated) [8](#0-7) .

The equality broken here is: "internal-topology-safe view (as intended by `private_neighbors=false`, the default)" vs. "actually served view over the unauthenticated public RPC surface." Every sibling code path (P2P protocol handler, neighbor walker, StackerDB replica sync, StackerDB replica RPC) enforces this equality; the `/v2/neighbors` HTTP endpoint alone fails to, exactly analogous to the SkyWalking `/debugging/config/dump` bug where an operational/introspection endpoint leaked internal configuration data that should have been redacted for non-privileged/unauthenticated callers.

### Impact Explanation
Any unauthenticated remote caller of a stacks-node's public HTTP RPC interface can enumerate the private IP addresses (RFC1918 ranges, `127.0.0.0/8`, `fc00::/7`, `::1`) and loopback/internal addresses of the node's inbound/outbound peers and any peers it has sampled or bootstrapped, even though the node operator relies on `private_neighbors=false` (the default) to keep this information hidden. This is a network topology / internal infrastructure disclosure that can aid targeted attacks against internal-only nodes (e.g., signer or validator nodes deliberately kept off public IP space), directly analogous in class to the referenced CVE (config-disclosure over a debug/info endpoint that should redact sensitive fields).

### Likelihood Explanation
Trivial and remotely reachable: `GET /v2/neighbors` requires no authentication token, no special client state, and returns whatever is currently stored in `PeerDB` / live conversations. Any node that has ever connected inbound or outbound to a peer behind a private/internal address (e.g., during local testing, VPN-connected peers, or misconfigured deployments) will leak that address to any anonymous querier.

### Recommendation
In `RPCNeighborsInfo::from_p2p` (stackslib/src/net/api/getneighbors.rs), apply the same filtering used elsewhere: drop entries where `addrbytes.is_anynet()` is true, and drop entries where `addrbytes.is_in_private_range()` is true unless `network.get_connection_opts().private_neighbors` is set, mirroring `RPCListStackerDBReplicasRequestHandler::try_handle_request` and `NeighborWalk::filter_sensible_neighbors`.

### Proof of Concept
1. Configure a stacks-node with default settings (`private_neighbors` unset / `false`).
2. Ensure the node has at least one peer connection or bootstrap/sample entry whose IP falls in a private range (e.g., connect a peer over `10.x.x.x`, `192.168.x.x`, or via `127.0.0.1` in a test/lab topology).
3. As an unauthenticated remote client, issue `GET /v2/neighbors` against the node's public RPC port.
4. Observe that the JSON response's `bootstrap`/`sample`/`inbound`/`outbound` arrays include the private IP address in the `ip` field, unlike the equivalent `GET /v2/stackerdb_replicas/:contract_id` endpoint which correctly omits such entries under the same configuration.

impl RPCNeighborsInfo {
    /// Load neighbor address information from the peer network
    pub fn from_p2p(network: &PeerNetwork) -> Result<RPCNeighborsInfo, NetError> {
        let network_epoch = network.get_current_epoch().network_epoch;
        let network_id = network.get_local_peer().network_id;
        let max_neighbor_age = network.get_connection_opts().max_neighbor_age;
        let burnchain_view = network.get_chain_view();
        let peerdb_conn = network.peerdb_conn();

        let bootstrap_nodes =
            PeerDB::get_bootstrap_peers(peerdb_conn, network_id).map_err(NetError::DBError)?;
        let bootstrap = bootstrap_nodes
            .into_iter()
            .map(|n| {
                let stackerdb_contract_ids =
                    PeerDB::static_get_peer_stacker_dbs(peerdb_conn, &n).unwrap_or_default();
                RPCNeighbor::from_neighbor_key_and_pubkh(
                    n.addr.clone(),
                    Hash160::from_node_public_key(&n.public_key),
                    true,
                    stackerdb_contract_ids,
                    None,
                )
            })
            .collect();

        let neighbor_sample = PeerDB::get_fresh_random_neighbors(
            peerdb_conn,
            network_id,
            network_epoch,
            network.peer_version,
            get_epoch_time_secs().saturating_sub(max_neighbor_age),
            MAX_NEIGHBORS_DATA_LEN,
            burnchain_view.burn_block_height,
            false,
            true,
        )
        .map_err(NetError::DBError)?;

        let sample: Vec<RPCNeighbor> = neighbor_sample
            .into_iter()
            .map(|n| {
                let stackerdb_contract_ids =
                    PeerDB::static_get_peer_stacker_dbs(peerdb_conn, &n).unwrap_or_default();
                RPCNeighbor::from_neighbor_key_and_pubkh(
                    n.addr.clone(),
                    Hash160::from_node_public_key(&n.public_key),
                    true,
                    stackerdb_contract_ids,
                    None,
                )
            })
            .collect();

        let mut inbound = vec![];
        let mut outbound = vec![];
        for event_id in network.iter_peer_event_ids() {
            let convo = if let Some(convo) = network.get_p2p_convo(*event_id) {
                convo
            } else {
                continue;
            };

            let nk = convo.to_neighbor_key();
            let naddr = convo.to_neighbor_address();
            if convo.is_outbound() {
                outbound.push(RPCNeighbor::from_neighbor_key_and_pubkh(
                    nk,
                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            } else {
                inbound.push(RPCNeighbor::from_neighbor_key_and_pubkh(
                    nk,
                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            }
        }

        Ok(RPCNeighborsInfo {
            bootstrap,
            sample,
            inbound,
            outbound,
        })
    }
}

fn test_try_make_response() {
    let addr = SocketAddr::new(IpAddr::V4(Ipv4Addr::new(127, 0, 0, 1)), 33333);

    let mut requests = vec![];

    let request = StacksHttpRequest::new_getneighbors(addr.into());
    requests.push(request);

    let mut responses = test_rpc(function_name!(), requests);

    let response = responses.remove(0);
    debug!(
        "Response:\n{}\n",
        std::str::from_utf8(&response.try_serialize().unwrap()).unwrap()
    );

    let resp = response.decode_rpc_neighbors().unwrap();

    // as configured there's one boostrap neighbor
    assert_eq!(resp.bootstrap.len(), 1);

    // all neighboring peers (there's one) report stackerdbs
    for n in resp.sample.iter() {
        assert!(n.stackerdbs.is_some());
    }

    for n in resp.bootstrap.iter() {
        assert!(n.stackerdbs.is_some());
    }

    for n in resp.inbound.iter() {
        assert!(n.stackerdbs.is_some());
    }

    for n in resp.outbound.iter() {
        assert!(n.stackerdbs.is_some());
    }
}
