### No vulnerability found for this question.

The claimed fault does not exist. The handler's rejection path is fully separate from the commit path.

`RPCPostStackerDBChunkRequestHandler::try_handle_request` calls `tx.try_replace_chunk` and, on `Err`, immediately returns the `accepted: false` ack via `return Ok(ack)` inside the `if let Err(e) = ...` block, which happens well before `tx.commit()` is ever reached — `tx.commit()` only executes in the success branch, after the `if let Err(e) = tx.try_replace_chunk(...)` block has already returned early. [1](#0-0) [2](#0-1) 

Inside `StackerDBTx::try_replace_chunk`, the signer check (`slot_desc.verify(&slot_validation.signer)?`) runs before the version check and before `self.insert_chunk(...)` is called, so a bad-signer chunk never reaches `insert_chunk` (the only mutating call in this function) at all. [3](#0-2) 

Because `insert_chunk` is never invoked for a `BadSlotSigner` rejection, there is nothing uncommitted to roll back — the SQLite transaction `tx` simply never had a pending write for this request; it's dropped (implicitly rolled back per rusqlite's `Drop` semantics) or never touched, and the ack correctly reports `accepted: false` with `code: BadSigner`. This exact scenario — signing slot 1 (owned by `privk1`) with `privk2` — is already covered by `test_request_fail_bad_signer_slot`, which asserts `!chunk_ack.accepted` and `chunk_ack.code == Some(StackerDBErrorCodes::BadSigner.code())`. [4](#0-3) 

The DB-level test suite additionally confirms `BadSlotSigner` is returned without any state mutation for the rejected write (the stored slot metadata after a `BadSlotSigner` error remains at its prior version/hash, only advancing on subsequent successful calls with a correct signer). [5](#0-4) 

The equality "committed transaction == signer verification succeeded" holds: `tx.commit()` at line 284 is only reachable after `try_replace_chunk` returns `Ok(())`, which requires `slot_desc.verify(&slot_validation.signer)` to succeed. There is no code path where a `BadSlotSigner`/`BadSigner`-classified request reaches `tx.commit()`, so no partial or unauthenticated write is observable.

    pub fn try_replace_chunk(
        &self,
        smart_contract: &QualifiedContractIdentifier,
        slot_desc: &SlotMetadata,
        chunk: &[u8],
    ) -> Result<(), net_error> {
        // Check per-replica chunk-size cap.
        if (chunk.len() as u64) > self.config.chunk_size {
            return Err(net_error::StackerDBChunkTooBig(chunk.len()));
        }

        let slot_validation = self
            .get_slot_validation(smart_contract, slot_desc.slot_id)?
            .ok_or(net_error::NoSuchSlot(
                smart_contract.clone(),
                slot_desc.slot_id,
            ))?;

        if !slot_desc.verify(&slot_validation.signer)? {
            return Err(net_error::BadSlotSigner(
                slot_validation.signer,
                slot_desc.slot_id,
            ));
        }
        if slot_desc.slot_version <= slot_validation.version {
            return Err(net_error::StaleChunk {
                supplied_version: slot_desc.slot_version,
                latest_version: slot_validation.version,
            });
        }
        if slot_desc.slot_version > self.config.max_writes {
            return Err(net_error::TooManySlotWrites {
                supplied_version: slot_desc.slot_version,
                latest_version: slot_validation.version,
                max_writes: self.config.max_writes,
            });
        }
        self.insert_chunk(smart_contract, slot_desc, chunk)
    }

#[test]
fn test_request_fail_bad_signer_slot() {
    let addr = SocketAddr::new(IpAddr::V4(Ipv4Addr::new(127, 0, 0, 1)), 33333);

    let rpc_test = TestRPC::setup(function_name!());

    // Slot 1 is owned by `privk1`; signing with `privk2` yields a well-formed signature that
    // recovers to the wrong signer (distinct from the unverifiable-signature case).
    let data = "bad signer".as_bytes();
    let data_hash = Sha512Trunc256Sum::from_data(data);
    let mut slot_metadata = SlotMetadata::new_unsigned(1, 1, data_hash);
    slot_metadata.sign(&rpc_test.privk2).unwrap();

    let request = StacksHttpRequest::new_post_stackerdb_chunk(
        addr.into(),
        TEST_CONTRACT_ID.clone(),
        slot_metadata.slot_id,
        slot_metadata.slot_version,
        slot_metadata.signature.clone(),
        data.to_vec(),
    );

    let chunk_ack = rpc_test
        .run_one(request)
        .decode_stackerdb_chunk_ack()
        .unwrap();
    assert!(!chunk_ack.accepted);
    assert_eq!(chunk_ack.code, Some(StackerDBErrorCodes::BadSigner.code()));
    assert!(chunk_ack.reason.is_some());
}
