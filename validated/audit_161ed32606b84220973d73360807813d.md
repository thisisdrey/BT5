### Title
`create_psm` accepts an unvalidated, permanently-fixed `fee_destination` account with no zero-address check and no update path - ([File: substrate/frame/psm/src/lib.rs])

### Summary
`pallet-psm`'s permissionless `create_psm` extrinsic takes a caller-supplied `fee_destination: T::AccountId` and stores it verbatim in `PsmInfo` with no validation that it is non-default/non-zero, and unlike `full_admin`/`emergency_admin` (which have `set_full_admin`/`set_emergency_admin`), there is no `set_fee_destination` extrinsic to correct it afterward. This is the same defect class as the Aave `BridgeExecutorBase` report: a security-critical address accepted at construction time without a zero-address guard, with no mechanism ever provided to change it.

### Finding Description
`create_psm` is dispatched under `Config::CreateOrigin`, which per the pallet docs resolves to "a signed origin that owns `internal_asset`" via the recommended `EnsureAssetOwner` — i.e. any account that owns/creates an asset can permissionlessly instantiate a PSM for it [1](#0-0) .

The extrinsic stores the caller-supplied `fee_destination` directly into `PsmInfo` with no `ensure!` check against `T::AccountId::default()` or any other sentinel, and increments a provider reference on it: [2](#0-1) .

Compare this to the admin fields in the same struct: `full_admin`/`emergency_admin` are explicitly documented as reassignable via `set_full_admin`/`set_emergency_admin` [3](#0-2) , and those setters do exist [4](#0-3) . The governance-operations table in the README confirms no analogous `set_fee_destination` extrinsic exists for the PSM instance [5](#0-4) .

Every `mint`/`redeem` call for that PSM instance routes accrued fees to `info.fee_destination` unconditionally, e.g. in `redeem`: [6](#0-5) . If `fee_destination` is left as (or supplied as) the default all-zero `AccountId`, every fee payment for the lifetime of that PSM instance is unrecoverably routed to that address, and — unlike `full_admin`/`emergency_admin` — there is no code path to ever redirect it, matching exactly the "no tool to change guardian" defect described in the external report.

### Impact Explanation
Because `fee_destination` cannot be changed once a PSM is created, an unvalidated/zero value permanently and unrecoverably diverts all minting/redemption fee revenue for that instance's entire lifetime. This is a permanent-fund-lock class bug: value that should be recoverable by the protocol/instance owner becomes permanently stuck, with no admin-level (`full_admin`/`emergency_admin`) or governance recourse short of removing and recreating the whole PSM instance (which itself requires draining all debt to zero first, per `remove_psm`'s `PsmHasDebt`/`PsmHasApprovedExternals` checks).

### Likelihood Explanation
`create_psm` is reachable by any account satisfying `CreateOrigin` (asset ownership under the recommended `EnsureAssetOwner`), which is a low/permissionless privilege bar compared to root or governance. No existing `ensure!` in `create_psm` rejects a default/zero `fee_destination`, so the corrupted state is trivially reachable — either accidentally (a caller passing an uninitialized/default value) or deliberately.

### Recommendation
Add an explicit validation in `create_psm` rejecting `fee_destination == T::AccountId::default()` (and any other clearly invalid sentinel value used by the runtime), returning a new `Error::<T>::InvalidFeeDestination`. Additionally, add a `set_fee_destination` extrinsic gated by `full_admin`, mirroring `set_full_admin`/`set_emergency_admin`, so a misconfigured or compromised fee destination can be corrected without tearing down the PSM instance.

### Proof of Concept
1. Account `ALICE` creates/owns asset `X` via `pallet-assets`, satisfying `CreateOrigin` for `internal_asset = X`.
2. `ALICE` calls `Psm::create_psm(origin, X, full_admin, emergency_admin, fee_destination = T::AccountId::default(), max_debt, min_swap_amount)` — this succeeds because no check rejects the default account, as shown by the call path in [7](#0-6) .
3. Any user performs `mint`/`redeem` against this PSM; the fee component of each swap is transferred to `T::AccountId::default()` per [6](#0-5) .
4. There is no extrinsic in the pallet (confirmed absent from the extrinsic list `set_minting_fee`, `set_redemption_fee`, `set_max_debt`, `set_asset_ceiling_weight`, `set_asset_status`, `add_external_asset`, `remove_external_asset`, `set_full_admin`, `set_emergency_admin`) that can update `fee_destination`, so all accumulated fees remain permanently stuck at the default account for the life of the PSM instance.

```rust
		pub fn create_psm(
			origin: OriginFor<T>,
			internal_asset: T::AssetId,
			full_admin: Box<T::PalletsOrigin>,
			emergency_admin: Box<T::PalletsOrigin>,
			fee_destination: T::AccountId,
			max_debt: BalanceOf<T>,
			min_swap_amount: BalanceOf<T>,
		) -> DispatchResult {
			let maybe_depositor = T::CreateOrigin::ensure_origin(origin, &internal_asset)?;
			ensure!(!Psm::<T>::contains_key(&internal_asset), Error::<T>::PsmAlreadyExists);
			ensure!(!min_swap_amount.is_zero(), Error::<T>::ZeroMinSwapAmount);
			ensure!(
				T::Fungibles::asset_exists(internal_asset.clone()),
				Error::<T>::AssetDoesNotExist
			);

			let deposit = maybe_depositor
				.map(|depositor| {
					T::Consideration::new(&depositor, Footprint::from_parts(1, 0))
						.map(|ticket| (depositor, ticket))
				})
				.transpose()?;

			let full_admin = *full_admin;
			let emergency_admin = *emergency_admin;
			let internal_decimals = T::Fungibles::decimals(internal_asset.clone());
			Psm::<T>::insert(
				&internal_asset,
				PsmInfo::<T> {
					fee_destination: fee_destination.clone(),
					max_debt,
					min_swap_amount,
					internal_decimals,
					external_count: 0,
				},
			);
			PsmAdmin::<T>::insert(
				&internal_asset,
				PsmAdminInfo::<T> {
					full_admin: full_admin.clone(),
					emergency_admin: emergency_admin.clone(),
					deposit,
				},
			);
			// Acquire a provider reference on the reserve account and the fee destination for the
			// lifetime of this PSM, so they can hold non-sufficient assets (external collateral /
			// minted fees). Released in `remove_psm`. Unconditional (rather than
			// `ensure_account_exists`) so the inc/dec is symmetric even when an account already
			// exists or is shared across PSMs.
			frame_system::Pallet::<T>::inc_providers(&Self::psm_account(&internal_asset));
			frame_system::Pallet::<T>::inc_providers(&fee_destination);
```

```rust
		pub fn set_full_admin(
			origin: OriginFor<T>,
			internal_asset: T::AssetId,
			new_admin: Box<T::PalletsOrigin>,
		) -> DispatchResult {
			Self::ensure_psm_admin(origin, &internal_asset, |l| l.can_manage_admins())?;
			let new_admin = *new_admin;
			let old_admin = PsmAdmin::<T>::try_mutate(
				&internal_asset,
				|maybe| -> Result<T::PalletsOrigin, DispatchError> {
					let admin = maybe.as_mut().ok_or(Error::<T>::PsmNotFound)?;
					let old = core::mem::replace(&mut admin.full_admin, new_admin.clone());
					Ok(old)
				},
			)?;
			Self::deposit_event(Event::FullAdminChanged {
				internal_asset,
				old_admin: Box::new(old_admin),
				new_admin: Box::new(new_admin),
			});
			Ok(())
		}
```
