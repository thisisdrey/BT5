## Valid Analog Found

### Title
Unauthenticated Disclosure of Internal Node System, Network, and Configuration Information via `/wallet/getnodeinfo` and `GetNodeInfo` RPC - (`framework/src/main/java/org/tron/core/services/http/GetNodeInfoServlet.java`)

### Summary
The `getnodeinfo` HTTP endpoint and its gRPC/JSON-RPC-adjacent equivalent expose detailed internal machine, network, and configuration telemetry to any anonymous, unauthenticated caller who can reach the node's HTTP/gRPC listener — matching the bug class in CVE-2024-52367 (unauthorized disclosure of sensitive system information usable for further attacks).

### Finding Description
`GetNodeInfoServlet.doGet` calls `NodeInfoService.getNodeInfo()` and writes the full result to the HTTP response with no authentication, authorization, or caller-identity check beyond generic QPS rate limiting inherited from `RateLimiterServlet`. [1](#0-0) 

`RateLimiterServlet.service()` only enforces per-endpoint/global QPS quotas; it performs no authentication or IP allow-listing before dispatching to the servlet's `doGet`/`doPost`. [2](#0-1) 

`NodeInfoService.getNodeInfo()` aggregates and returns: JVM/OS internals (Java version, OS name/version, CPU count/load, total/free physical and heap memory, per-pool memory usage, thread counts, and full stack traces for deadlocked threads), per-peer network details (remote peer IP address/host, listening port, node ID, connection timing, sync state, disconnect reasons), and node configuration (listen port, discovery enablement, max connection counts, backup member count/priority, participation-rate thresholds, adaptive-energy/contract-creation flags). [3](#0-2) [4](#0-3) 

This servlet is registered on the full node's main wallet path `/wallet/getnodeinfo`, which sits outside the scope of the `httpApiAccessFilter` (that filter is applied to `/walletsolidity/*` paths, and `/wallet/getnodeinfo` is only explicitly added to its path specs on the solidity-node service variant, not the primary full-node `Wallet` HTTP API). [5](#0-4) 

The equivalent unauthenticated gRPC RPC `GetNodeInfo` returns the identical protobuf-serialized `NodeInfo` structure to any gRPC client with network access, with no signature or permission check, unlike transaction-broadcasting RPCs. [6](#0-5) 

The `NodeInfo` protobuf message itself documents the breadth of exposed data (peer IPs, node IDs, config, machine stats). [7](#0-6) 

A closely related endpoint, `ListNodesServlet` (`/wallet/listnodes`), similarly discloses the list of connectable peer IP addresses and ports to any anonymous caller with the same lack of access control. [8](#0-7) [9](#0-8) 

### Impact Explanation
An anonymous network client can fingerprint the node's OS, JVM version, memory/CPU headroom, deadlock/thread state (including internal stack traces), P2P listening port, discovery configuration, backup/HA member count and priority, and the IP addresses/node IDs of connected peers. This information materially aids reconnaissance for follow-on attacks: targeting specific JVM/OS CVEs, timing resource-exhaustion (DoS) attacks against a node under memory/CPU pressure, or mapping the peer topology (including backup/HA nodes) to select high-value targets for eclipse or DoS attacks against SR/witness infrastructure.

### Likelihood Explanation
Trivial to exploit: a single unauthenticated HTTP GET to `/wallet/getnodeinfo` (or `/wallet/listnodes`), or a single unauthenticated gRPC `GetNodeInfo` call, against any publicly reachable full node returns the full disclosure. No signed transaction, special privilege, or prior state is required — only network reachability, which is the default posture for public API nodes.

### Recommendation
Require the same access-control gating for `/wallet/getnodeinfo`, `/wallet/listnodes`, and their gRPC equivalents as is applied elsewhere (e.g., extend `httpApiAccessFilter`/an equivalent gRPC interceptor to cover these paths on the primary full-node service, not only the solidity-node variant), or strip peer IP/node-ID and deep machine/thread-dump details from the response by default and gate the full payload behind an authenticated/admin-only interface (e.g., local-only binding, API key, or the JSON-RPC admin namespace convention).

### Proof of Concept
```
# Against an unauthenticated public full node HTTP JSON-RPC port (default 8090):
curl http://<victim-node-ip>:8090/wallet/getnodeinfo

# Response includes (abridged):
{
  "machineInfo": {"javaVersion": "...", "osName": "...", "cpuRate": ..., "totalMemory": ..., "deadLockThreadInfoList": [...stack traces...]},
  "peerList": [{"host": "<peer-ip>", "port": <peer-port>, "nodeId": "<hex-id>", ...}],
  "configNodeInfo": {"listenPort": ..., "discoverEnable": ..., "backupMemberSize": ..., "backupPriority": ...}
}

# Peer/topology enumeration:
curl http://<victim-node-ip>:8090/wallet/listnodes
```
No signature, API key, or prior authorization is required for either request.

  private void setMachineInfo(NodeInfo nodeInfo) {
    MachineInfo machineInfo = new MachineInfo();
    machineInfo.setThreadCount(threadMXBean.getThreadCount());
    machineInfo.setCpuCount(Runtime.getRuntime().availableProcessors());
    machineInfo.setTotalMemory(operatingSystemMXBean.getTotalPhysicalMemorySize());
    machineInfo.setFreeMemory(operatingSystemMXBean.getFreePhysicalMemorySize());
    machineInfo.setCpuRate(operatingSystemMXBean.getSystemCpuLoad());
    machineInfo.setJavaVersion(runtimeMXBean.getSystemProperties().get("java.version"));
    machineInfo
        .setOsName(operatingSystemMXBean.getName() + " " + operatingSystemMXBean.getVersion());
    machineInfo.setJvmTotalMemory(memoryMXBean.getHeapMemoryUsage().getMax());
    machineInfo.setJvmFreeMemory(
        memoryMXBean.getHeapMemoryUsage().getMax() - memoryMXBean.getHeapMemoryUsage().getUsed());
    machineInfo.setProcessCpuRate(operatingSystemMXBean.getProcessCpuLoad());
    List<MemoryDescInfo> memoryDescInfoList = new ArrayList<>();
    List<MemoryPoolMXBean> pools = ManagementFactory.getMemoryPoolMXBeans();
    if (CollectionUtils.isNotEmpty(pools)) {
      for (MemoryPoolMXBean pool : pools) {
        MemoryDescInfo memoryDescInfo = new MemoryDescInfo();
        memoryDescInfo.setName(pool.getName());
        memoryDescInfo.setInitSize(pool.getUsage().getInit());
        memoryDescInfo.setUseSize(pool.getUsage().getUsed());
        memoryDescInfo.setMaxSize(pool.getUsage().getMax());
        if (pool.getUsage().getMax() > 0) {
          memoryDescInfo.setUseRate((double) pool.getUsage().getUsed() / pool.getUsage().getMax());
        } else {
          memoryDescInfo
              .setUseRate((double) pool.getUsage().getUsed() / pool.getUsage().getCommitted());
        }
        memoryDescInfoList.add(memoryDescInfo);
      }
    }
    machineInfo.setMemoryDescInfoList(memoryDescInfoList);
    //dead lock thread
    long[] deadlockedIds = threadMXBean.findDeadlockedThreads();
    if (ArrayUtils.isNotEmpty(deadlockedIds)) {
      machineInfo.setDeadLockThreadCount(deadlockedIds.length);
      ThreadInfo[] deadlockInfos = threadMXBean.getThreadInfo(deadlockedIds);
      List<DeadLockThreadInfo> deadLockThreadInfoList = new ArrayList<>();
      for (ThreadInfo deadlockInfo : deadlockInfos) {
        DeadLockThreadInfo deadLockThreadInfo = new DeadLockThreadInfo();
        deadLockThreadInfo.setName(deadlockInfo.getThreadName());
        deadLockThreadInfo.setLockName(deadlockInfo.getLockName());
        deadLockThreadInfo.setLockOwner(deadlockInfo.getLockOwnerName());
        deadLockThreadInfo.setBlockTime(deadlockInfo.getBlockedTime());
        deadLockThreadInfo.setWaitTime(deadlockInfo.getWaitedTime());
        deadLockThreadInfo.setState(deadlockInfo.getThreadState().name());
        deadLockThreadInfo.setStackTrace(Arrays.toString(deadlockInfo.getStackTrace()));
        deadLockThreadInfoList.add(deadLockThreadInfo);
      }
      machineInfo.setDeadLockThreadInfoList(deadLockThreadInfoList);
    }
    nodeInfo.setMachineInfo(machineInfo);
  }

  public NodeList listNodes() {

    if (!Args.getInstance().p2pDisable) {
