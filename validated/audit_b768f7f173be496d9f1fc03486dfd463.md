Searching the in-scope areas (`stackslib/src/net/**` excluding epoch2x/neon, `libstackerdb/**`, and `libsigner` transport files) found no analogous remote, unprivileged code path:

The only archive/zip-adjacent code in the repo lives in out-of-scope areas: `contrib/tools/block-validation.sh` (local operator tooling extracting `tar.zst`), `contrib/marf-squash` (offline CLI tool), and `stx-genesis/build.rs` (build-time only, not reachable by any network peer).

- The HTTP `POST /stackerdb/chunk` handler in `stackslib/src/net/api/poststackerdbchunk.rs` similarly only commits and stores a chunk after the DB-transaction's signature check passes [3](#0-2) .
