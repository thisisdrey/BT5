### Title
Revoked/reduced validator stake continues to grant staked-tier QUIC QoS privileges for the lifetime of an already-established connection - (File: streamer/src/nonblocking/swqos.rs, streamer/src/nonblocking/simple_qos.rs)

### Summary
The bug class in the report is: an actor's authorization decision is computed from a back-dated/stale snapshot of permission (stake), and once granted, that authorization keeps controlling downstream behavior even after the authority revokes the permission at the source of truth. In Agave's QUIC transaction-ingest path, the analogous defect is that a connection's `ConnectionPeerType`/stake classification (`Staked(stake)`), which determines QoS treatment such as prune-priority and per-connection stream allowances, is computed **once** at connection-establishment time from the shared `StakedNodes` snapshot and then baked into the long-lived `ConnectionEntry`/`SwQosConnectionContext`/`SimpleQosConnectionContext`. It is never re-derived from the (periodically refreshed) `StakedNodes` map while the connection remains open.

### Finding Description
`get_connection_stake` reads the peer's current stake from the shared `StakedNodes` map only when a connection context is built (`build_connection_context`), which happens once per new QUIC connection: [1](#0-0) 

That single stake reading is captured into `ConnectionPeerType::Staked(stake)` and stored in the long-lived `ConnectionEntry` for the entire lifetime of the connection: [2](#0-1) 

Both QoS controllers (`SwQos` and `SimpleQos`) build this context exactly once, at `try_add_connection` time, and never revisit it: [3](#0-2) [4](#0-3) 

The backing `StakedNodes` map itself is refreshed only periodically (every 5 seconds) from the root bank by `StakedNodesUpdaterService`: [5](#0-4) 

The cached `stake()` value on `ConnectionEntry` is used to decide pruning priority when the staked connection table is full — the entry with the lowest recorded stake is the one considered for eviction: [6](#0-5) 

Because the peer's stake classification is fixed at connection-open time and there is no mechanism found in `swqos.rs`/`simple_qos.rs`/`quic.rs` that re-queries `staked_nodes` for existing connections (only `try_add_connection` for *new* connections consults it), a peer whose stake is later reduced to zero via a stake-account deactivation/withdrawal (the on-chain analog of the DAO "expel validator" action) is not demoted. Its already-open connection keeps its `Staked(stake)`-derived privileges — higher per-connection stream allowance (`max_streams_per_second`/`compute_max_allowed_uni_streams_with_rtt`), inclusion in the staked connection table with pruning protection over genuinely-unstaked/low-stake peers, and immunity from the aggressive unstaked-table eviction path — for as long as the QUIC connection is kept alive (which the client fully controls via keep-alives, well beyond the 5-second `StakedNodesUpdaterService` refresh cycle).

### Impact Explanation
This is a QoS-evasion class issue: an entity whose real-time, chain-verified stake/permission has been revoked continues to receive elevated priority in the transaction-ingest gate long after revocation, at the expense of genuinely staked/legitimate peers competing for the same limited connection/stream capacity. Since prune decisions and stream-rate allowances are driven purely by the frozen `stake()` value captured at connect time, a validator (or delegator) that is slashed/deactivated can retain outsized influence over which packets get admitted to the TPU pipeline, directly analogous to the reported bug where a validator whose voting power was zeroed still influenced outcomes based on stale snapshot data.

### Likelihood Explanation
Reaching this path requires only establishing an ordinary QUIC connection while staked (or being a previously-staked identity) and then keeping the connection open — no special privileges beyond having once held stake are needed, and connection keep-alive is entirely client-controlled, so the staleness window is unbounded in practice, not limited to the 5-second cache TTL.

### Recommendation
Periodically re-validate the stake classification of already-open staked connections against the current `StakedNodes` snapshot (e.g., during the existing prune/eviction sweep or a lightweight background task), demoting/evicting entries whose stake has dropped to zero or below the staked threshold, rather than relying solely on the stake value captured at connection-open time.

### Proof of Concept
1. Establish a QUIC connection to the TPU/TPU-vote QUIC endpoint from an identity that currently has nonzero stake in `StakedNodes` — `build_connection_context`/`get_connection_stake` classify it `ConnectionPeerType::Staked(stake)` and it is admitted to the staked connection table with the elevated stream allowance.
2. Deactivate/withdraw the stake for that identity on-chain; after up to `STAKE_REFRESH_CYCLE` (5s), `StakedNodesUpdaterService` updates the shared `StakedNodes` map to reflect stake `0`.
3. Keep the original QUIC connection alive (standard QUIC keep-alive/idle-timeout mechanics); no code path re-reads `staked_nodes` for this existing `ConnectionEntry`.
4. Continue sending streams on the still-open connection — it keeps the original `max_concurrent_uni_streams`/stream-rate limit and pruning priority computed from the now-stale stake value, instead of being reclassified/evicted as unstaked, as would occur for a brand-new connection from the same (now-zero-stake) identity per `test_quic_server_zero_staked_connection_removal`: [7](#0-6)

pub fn get_connection_stake(
    connection: &Connection,
    staked_nodes: &RwLock<StakedNodes>,

    let pubkey = get_remote_pubkey(connection)?;

    let staked_nodes = staked_nodes.read().unwrap();
    Some((
        pubkey,
        staked_nodes.get_node_stake(&pubkey)?,
        staked_nodes.total_stake(),
    ))
}

            connection,
            stream_counter,
        }

        self.last_update.load(Ordering::Relaxed)
    }

            ConnectionPeerType::Staked(stake) => stake,

    // Randomly selects sample_size many connections, evicts the one with the
    // lowest stake, and returns the number of pruned connections.
    // If the stakes of all the sampled connections are higher than the
    // threshold_stake, rejects the pruning attempt, and returns 0.
    pub(crate) fn prune_random(&mut self, sample_size: usize, threshold_stake: u64) -> usize {
        let num_pruned = std::iter::once(self.table.len())
            .filter(|&size| size > 0)
            .flat_map(|size| {
                let mut rng = rng();
                repeat_with(move || rng.random_range(0..size))
            })
            .map(|index| {
                let connection = self.table[index].first();
                let stake = connection.map(|connection: &ConnectionEntry<S>| connection.stake());
                (index, stake)
            })
            .take(sample_size)
            .min_by_key(|&(_, stake)| stake)
            .filter(|&(_, stake)| stake < Some(threshold_stake))
            .and_then(|(index, _)| self.table.swap_remove_index(index))
            .map(|(_, connections)| connections.len())
            .unwrap_or_default();
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

const STAKE_REFRESH_CYCLE: Duration = Duration::from_secs(5);

pub struct StakedNodesUpdaterService {
    thread_hdl: JoinHandle<()>,
}

impl StakedNodesUpdaterService {
    pub fn new(
        exit: Arc<AtomicBool>,
        bank_forks: Arc<RwLock<BankForks>>,
        staked_nodes: Arc<RwLock<StakedNodes>>,
        staked_nodes_overrides: Arc<RwLock<HashMap<Pubkey, u64>>>,
    ) -> Self {
        let thread_hdl = Builder::new()
            .name("solStakedNodeUd".to_string())
            .spawn(move || {
                while !exit.load(Ordering::Relaxed) {
                    let stakes = {
                        let root_bank = bank_forks.read().unwrap().root_bank();
                        root_bank.current_epoch_staked_nodes()
                    };
                    let overrides = staked_nodes_overrides.read().unwrap().clone();
                    *staked_nodes.write().unwrap() = StakedNodes::new(stakes, overrides);
                    std::thread::sleep(STAKE_REFRESH_CYCLE);
                }
            })
            .unwrap();

        Self { thread_hdl }
    }
