### Title
Unprivileged clients can fake backend health "violations" via cheap application-level errors, triggering false node-unhealthy circuit breaks - ([File: internal/praefect/middleware/errorhandler.go])

### Summary
Praefect's per-node error tracker treats *any* gRPC error returned by an accessor/mutator RPC to a backend Gitaly node as a "violation" toward a read/write error threshold, without distinguishing cheap, attacker-controllable application errors (e.g. `NotFound`, `InvalidArgument`) from genuine node-health failures. Once the threshold is reached, the health-check circuit breaker refuses to check that node and it is marked unhealthy, which can remove it from the pool of eligible primaries/secondaries — the same "fake a violation report at near-zero cost to disable the system" pattern described in the DutchTrade finding.

### Finding Description
`StreamErrorHandler` wraps every client stream Praefect opens to a backend Gitaly node and unconditionally counts any non-EOF error on `SendMsg`/`RecvMsg` as a read or write error, based only on whether the RPC is classified as an accessor or mutator — it does not inspect the gRPC status code: [1](#0-0) 

These counts feed `errorTracker.IncrReadErr`/`IncrWriteErr`, which append a timestamp per error and expose `ReadThresholdReached`/`WriteThresholdReached` once the configured threshold is hit within the configured time window: [2](#0-1) [3](#0-2) 

`HealthClient.Check` (the "circuit breaker") short-circuits the actual health check and fails outright whenever either threshold is reached for that node's storage: [4](#0-3) 

`nodeStatus.CheckHealth` records this as a failed health check, and after `healthcheckThreshold` (3) consecutive failures the node is marked unhealthy: [5](#0-4) [6](#0-5) 

An ordinary, unprivileged client that can issue accessor RPCs (e.g. `RepositoryExists`, ref/object lookups) or mutator RPCs against repositories it has read/write access to can trivially cause the backend to return legitimate application-level errors — nonexistent repository/ref/object, invalid argument, precondition failure — at essentially zero cost per request. The middleware makes no distinction between these and real infrastructure failures (timeouts, `Unavailable`, `Internal`), so a burst of cheap, deliberately-invalid requests can reach the read/write threshold and falsely trip the "node is failing" signal, exactly mirroring the DutchTrade pattern of faking a violation report cheaply to defeat a protection mechanism.

### Impact Explanation
Once a node is marked unhealthy via this false-positive path, it is excluded from `GetHealthySecondaries` and `GetSyncedNode`, and the election strategies (`sql_elector.go`/`local_elector.go`) may fail over the primary or refuse to route to that storage: [7](#0-6) [8](#0-7) 

This can cause an unwarranted failover of the primary or removal of a healthy secondary from rotation for a whole virtual storage, degrading availability/writes for all tenants on that storage — a low-cost, unprivileged DoS against the cluster's failover subsystem, analogous to disabling "trading" (in this case, disabling normal repository read/write routing) by faking a cheap violation report.

### Likelihood Explanation
Likelihood is bounded by two factors I could not fully verify from the available index: the configured `ReadErrorThresholdCount`/`WriteErrorThresholdCount` and `ErrorThresholdWindow` values in `internal/praefect/config/config.go` (which determine how many cheap errors and what time window are required), and whether `Failover.Enabled` is set (the tracker is disabled entirely when failover is off, per `NewManager`). Given the code inspects only "error present or not" with no severity/cost filtering, likelihood is otherwise high whenever failover/error-tracking is enabled with reasonably low thresholds — a realistic production configuration.

### Recommendation
Filter or weight error counting by gRPC status code and/or error cost: only count errors indicative of real backend/node health degradation (`Unavailable`, `DeadlineExceeded`, `Internal`, `ResourceExhausted` from timeouts) toward the read/write threshold, and exclude client-attributable application errors (`NotFound`, `InvalidArgument`, `FailedPrecondition`, `PermissionDenied`) that any caller can trigger cheaply and repeatedly. Consider also scoping the error window/threshold per calling identity or repository rather than purely per-node-storage, to prevent a single client from unilaterally influencing cluster-wide failover decisions.

### Proof of Concept
1. Deploy Praefect with `Failover.Enabled = true` and default/typical `ReadErrorThresholdCount`/`WriteErrorThresholdCount` values.
2. As an unprivileged client with access to at least one repository routed through a given virtual storage, repeatedly issue cheap accessor RPCs against nonexistent repositories or invalid refs (e.g. `RepositoryExists` on a bogus path) until the read-error threshold is reached, as demonstrated by the existing test pattern: [9](#0-8) 
3. Observe `ReadThresholdReached`/`WriteThresholdReached` become true for the targeted node storage, causing `HealthClient.Check` to fail and the node to be marked unhealthy after subsequent health-check cycles, potentially triggering failover or exclusion from the healthy-node pool — all without the attacker performing any operation that reflects an actual backend health problem.

func (e *errorTracker) IncrReadErr(node string) {
	e.incrReadErrTime(node, time.Now())

func (e *errorTracker) incrReadErrTime(node string, t time.Time) {
	select {
	case <-e.ctx.Done():
		return
	default:
		e.m.Lock()
		defer e.m.Unlock()

		e.readErrors[node] = append(e.readErrors[node], t)

		if len(e.readErrors[node]) > e.readThreshold {
			e.readErrors[node] = e.readErrors[node][1:]
		}
	}
}

// ReadThresholdReached indicates whether or not the read threshold has been reached within the time window
func (e *errorTracker) ReadThresholdReached(node string) bool {
	select {
	case <-e.ctx.Done():
		break
	default:
		e.m.RLock()
		defer e.m.RUnlock()

		now := time.Now()

		for i, errTime := range e.readErrors[node] {
			if e.isInErrorWindow(now, errTime) {
				if i == 0 {
					return len(e.readErrors[node]) >= e.readThreshold
				}
				return len(e.readErrors[node][i-1:]) >= e.readThreshold
			}
		}
	}

	return false
}

// WriteThresholdReached indicates whether or not the write threshold has been reached within the time window

// Check circuit breaks the health check if write or read error thresholds have been reached. If not, it performs
// the health check.
func (hc HealthClient) Check(ctx context.Context, req *grpc_health_v1.HealthCheckRequest, opts ...grpc.CallOption) (*grpc_health_v1.HealthCheckResponse, error) {
	if hc.tracker.ReadThresholdReached(hc.storage) {
		return nil, fmt.Errorf("read error threshold reached for storage %q", hc.storage)
	}

	if hc.tracker.WriteThresholdReached(hc.storage) {
		return nil, fmt.Errorf("write error threshold reached for storage %q", hc.storage)
	}

	return hc.HealthClient.Check(ctx, req, opts...)

func (n *Mgr) GetSyncedNode(ctx context.Context, virtualStorageName, repoPath string) (Node, error) {
	_, upToDateStorages, err := n.csg.GetConsistentStorages(ctx, virtualStorageName, repoPath)
	if err != nil && !errors.Is(err, datastore.ErrRepositoryNotFound) {
		return nil, err
	}

	if upToDateStorages == nil || upToDateStorages.IsEmpty() {
		// this possible when there is no data yet in the database for the repository
		shard, err := n.GetShard(ctx, virtualStorageName)
		if err != nil {
			return nil, fmt.Errorf("get shard for %q: %w", virtualStorageName, err)
		}

		upToDateStorages = datastructure.SetFromValues(shard.Primary.GetStorage())
	}

	healthyStorages := make([]Node, 0, upToDateStorages.Len())
	for _, node := range n.Nodes()[virtualStorageName] {
		if !node.IsHealthy() {
			continue
		}

		if !upToDateStorages.HasValue(node.GetStorage()) {
			continue
		}

		healthyStorages = append(healthyStorages, node)
	}

	if len(healthyStorages) == 0 {
		return nil, fmt.Errorf("no healthy nodes: %w", ErrPrimaryNotHealthy)
	}

	return healthyStorages[rand.Intn(len(healthyStorages))], nil
}

func (n *nodeStatus) IsHealthy() bool {
	n.mtx.RLock()
	healthy := n.isHealthy()
	n.mtx.RUnlock()
	return healthy
}

func (n *nodeStatus) isHealthy() bool {
	if len(n.statuses) < healthcheckThreshold {
		return false
	}

	for _, ok := range n.statuses[len(n.statuses)-healthcheckThreshold:] {
		if !ok {
			return false
		}
	}

	return true
}

func (n *nodeStatus) CheckHealth(ctx context.Context) (bool, error) {
	health := healthpb.NewHealthClient(n.clientConn)
	if n.errTracker != nil {
		health = tracker.NewHealthClient(health, n.GetStorage(), n.errTracker)
	}

	ctx, cancel := context.WithTimeout(ctx, healthcheckTimeout)
	defer cancel()

	start := time.Now()
	resp, err := health.Check(ctx, &healthpb.HealthCheckRequest{})
	n.latencyHist.WithLabelValues(n.node.Storage).Observe(time.Since(start).Seconds())
	if err != nil {
		n.log.WithError(err).WithFields(log.Fields{
			"storage": n.node.Storage,
			"address": n.node.Address,
		}).Warn("error when pinging healthcheck")
	}

	status := resp.GetStatus() == healthpb.HealthCheckResponse_SERVING

	metrics.NodeLastHealthcheckGauge.WithLabelValues(n.GetStorage()).Set(metrics.BoolAsFloat(status))

	n.updateStatus(status)

	return status, err
