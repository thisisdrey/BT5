This is important architectural context that invalidates the premise of the question.

`TransactionRecorder::record_transactions` does not call into `PohRecorder::record` directly on a shared, lockable `PohRecorder` from multiple banking threads. Instead, `TransactionRecorder::record` sends a `Record` message through a `RecordSender` channel via `try_send` [1](#0-0) . The actual `PohRecorder::record` function, with the `poh_lock`/`drop(poh_lock)`/`working_bank_sender.send` sequence described in the question, runs single-threaded inside the PoH service loop that consumes these `Record` messages one at a time [2](#0-1) . Multiple banking-stage threads calling `record_transactions` concurrently only race to enqueue `Record` entries on the channel via `try_send`; they never concurrently execute `PohRecorder::record` itself, because `record` takes `&mut self` and is invoked from a single owning task/thread (the PoH recording service), not directly by banking threads.

Given this, the scenario in the question — "two banking-stage threads racing `record()` on the same `working_bank`" causing `PohRecorder::record`'s internal loop to interleave across threads via the `drop(poh_lock)` at line 379 — is not reachable in this codebase's actual call structure. `PohRecorder::record` requires exclusive `&mut self` access and is not shared/called concurrently by two threads; the `poh_lock` (a `Mutex` guarding just the underlying `Poh` hash-chain state) is not what serializes calls to `record`, but there is no concurrent entry into `PohRecorder::record` in the first place given the `RecordSender`/single-consumer design. The premise requiring "thread A `poh_lock.record(mixinA)` -> drop -> thread B `poh_lock.record(mixinB)`" racing inside the same `PohRecorder::record` call is not supported by the actual architecture, since only one thread ever executes the `PohRecorder::record` method body at a time.

    pub fn record(
        &mut self,
        bank_id: BankId,
        mixin: Hash,
        transactions: Vec<VersionedTransaction>,
    ) -> Result<RecordSummary> {
        // Entries without transactions are used to track real-time passing in the ledger and
        // cannot be generated by `record()`
        assert!(!transactions.is_empty(), "No transactions provided");

        if let Some(working_bank) = self.working_bank.as_ref() {
            let ((), report_metrics_us) =
                measure_us!(self.metrics.report(working_bank.bank.slot()));
            self.metrics.report_metrics_us += report_metrics_us;
        }

        loop {
            let (flush_cache_res, flush_cache_us) = measure_us!(self.flush_cache(false, None));
            self.metrics.flush_cache_no_tick_us += flush_cache_us;
            flush_cache_res?;

            let tick_height = self.tick_height(); // cannot change until next loop iteration.
            let working_bank = self
                .working_bank
                .as_mut()
                .ok_or(PohRecorderError::MaxHeightReached)?;
            if bank_id != working_bank.bank.bank_id() {
                return Err(PohRecorderError::MaxHeightReached);
            }

            let (mut poh_lock, poh_lock_us) = measure_us!(self.poh.lock().unwrap());
            self.metrics.record_lock_contention_us += poh_lock_us;

            let (entry, record_mixin_us) = measure_us!(poh_lock.record(mixin));
            self.metrics.record_us += record_mixin_us;
            let remaining_hashes_in_slot =
                poh_lock.remaining_hashes_in_slot(working_bank.bank.ticks_per_slot());

            drop(poh_lock);

            if let Some(entry) = entry {
                let (send_entry_res, send_entry_us) = measure_us!(
                    self.working_bank_sender.send((
                        working_bank.bank.clone(),
                        (
                            Entry {
                                num_hashes: entry.num_hashes,
                                hash: entry.hash,
                                transactions,
                            }
                            .into(),
                            tick_height,
                        ),
                    ))
                );
                self.metrics.send_entry_us += send_entry_us;
                send_entry_res.map_err(Box::new)?;

                return Ok(RecordSummary {
                    remaining_hashes_in_slot,
                });
            }

            // record() might fail if the next PoH hash needs to be a tick.  But that's ok, tick()
            // and re-record()
            self.metrics.ticks_from_record += 1;
            self.tick();
        }
    }
