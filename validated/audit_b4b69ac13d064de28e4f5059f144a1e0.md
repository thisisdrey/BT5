### Title
Frozen CoinStore of Any Single Shareholder/Beneficiary Permanently Blocks `distribute()` for All Vesting Shareholders — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`vesting.move`'s `distribute()` and `staking_contract.move`'s `distribute_internal()` iterate over all shareholders and call `aptos_account::deposit_coins()` for each one inside a single atomic transaction. If any single recipient's `CoinStore` is frozen, the entire transaction aborts, permanently blocking every other shareholder from receiving their vested APT. This is the direct Aptos analog of the external H-01 finding: a transfer to a "blacklisted" (frozen) recipient reverts the entire settlement, locking funds that belong to innocent third parties.

---

### Finding Description

`vesting.move`'s `distribute()` iterates over all shareholders and calls `aptos_account::deposit_coins` for each:

```move
shareholders.for_each_ref(|shareholder| {
    let shareholder = *shareholder;
    let shares = pool_u64::shares(grant_pool, shareholder);
    let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
    let share_of_coins = coin::extract(&mut coins, amount);
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);  // <-- aborts if frozen
});
``` [1](#0-0) 

`aptos_account::deposit_coins` ultimately calls `coin::deposit<CoinType>(to, coins)`:

```move
pub fun deposit_coins<CoinType>(to: address, coins: Coin<CoinType>) acquires DirectTransferConfig {
    ...
    coin::deposit<CoinType>(to, coins)   // aborts with EFROZEN if CoinStore is frozen
}
``` [2](#0-1) 

`coin::deposit` aborts unconditionally when the target `CoinStore` is frozen (`EFROZEN = 10`): [3](#0-2) 

The formal spec confirms this abort condition:

```
spec schema DepositAbortsIf<CoinType> {
    aborts_if !exists<CoinStore<CoinType>>(account_addr);
    aborts_if coin_store.frozen;
}
``` [4](#0-3) 

The same pattern exists in `staking_contract.move`'s `distribute_internal()`: [5](#0-4) 

The `set_beneficiary` function in `vesting.move` attempts a partial mitigation — it checks that the beneficiary is registered for APT — but the code comment itself acknowledges this is insufficient:

```move
// Verify that the beneficiary account is set up to receive APT. This is a requirement so distribute() wouldn't
// fail and block all other accounts from receiving APT if one beneficiary is not registered.
assert_account_is_registered_for_apt(new_beneficiary);
``` [6](#0-5) 

The check only validates registration at the time `set_beneficiary` is called. It does **not** check whether the `CoinStore` is frozen, and it does not apply to the original shareholder addresses when no beneficiary is set.

---

### Impact Explanation

If any single shareholder's (or their beneficiary's) `CoinStore` is frozen at the time `distribute()` is called:

- The entire `distribute()` transaction aborts atomically.
- All other shareholders are blocked from receiving their vested APT.
- The vested APT remains locked inside the vesting contract with no alternative withdrawal path.
- `terminate_vesting_contract` also calls `distribute()` internally, so even contract termination is blocked. [7](#0-6) 

This constitutes permanent freezing of vesting balances for innocent third-party shareholders — an impact category explicitly listed in the Aptos bounty scope.

---

### Likelihood Explanation

For `AptosCoin` specifically, freezing a `CoinStore` requires the `FreezeCapability<AptosCoin>`, which is held by the Aptos framework (governance). This makes the trigger privileged, which the bounty scope excludes. However:

1. The code comment at line 921–922 explicitly acknowledges the risk, confirming the developers are aware of the pattern but only partially mitigated it.
2. The mitigation gap (frozen vs. unregistered) is real and documented.
3. For any future vesting/staking module extended to support non-APT fungible assets with third-party freeze capabilities, this becomes an unprivileged attack: any token issuer (e.g., a stablecoin with a freeze/blacklist feature) holding a `TransferRef` or `FreezeCapability` can freeze one shareholder's store and permanently block all others.

---

### Recommendation

Replace the sequential `for_each_ref` deposit loop with a pattern that isolates per-recipient failures:

1. **Pull-based claims**: Instead of pushing coins to each recipient in `distribute()`, record each recipient's claimable amount in a `Table<address, u64>` and let each shareholder call a separate `claim()` entry function. This is the exact "claims[token]" pattern recommended in the external report.

2. **Skip-and-record**: Wrap each `deposit_coins` call in a check for frozen status before attempting the deposit; if frozen, record the amount in a pending-claims table rather than aborting.

3. **Strengthen `set_beneficiary`**: Add a check that the beneficiary's `CoinStore` is not currently frozen, in addition to the existing registration check.

---

### Proof of Concept

1. Create a vesting contract with shareholders A, B, and C.
2. Wait for vesting to begin; call `vest()` to unlock coins.
3. Freeze shareholder B's `CoinStore<AptosCoin>` (requires `FreezeCapability<AptosCoin>`).
4. Call `distribute(contract_address)`.
5. Observe: the transaction aborts with `EFROZEN` when processing shareholder B.
6. Shareholders A and C receive nothing; their vested APT is permanently locked in the contract.
7. Calling `terminate_vesting_contract` also fails because it internally calls `distribute()`. [8](#0-7) [9](#0-8)

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
