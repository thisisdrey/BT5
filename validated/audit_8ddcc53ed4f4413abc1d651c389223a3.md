The reported issue is specific to zkSync Era's custom precompile-dispatch implementation (its `EfficientCall.sol` library and Yul-based `Ecrecover.yul`), where `delegatecall` to the ECRECOVER address incorrectly falls through to executing the precompile's own bytecode in the caller's context instead of performing the actual EC-recovery computation.

In go-ethereum, precompile dispatch does not have this class of bug. All call variants (`Call`, `CallCode`, `DelegateCall`, `StaticCall`) explicitly check `evm.precompile(addr)` first and, if true, invoke `RunPrecompiledContract` directly — bypassing any bytecode-execution path entirely. This is explicitly commented in the code: "It is allowed to call precompiles, even via delegatecall" [1](#0-0) . The same holds for `CallCode` [2](#0-1)  and `StaticCall` [3](#0-2) .

The `ecrecover` precompile's `Run` method is a pure function of its `input` bytes only — it has no dependency on call type, caller address, or `msg.sender`/context, so there is no way for `delegatecall` vs `call`/`staticcall` to produce different outputs for the same input [4](#0-3) . This holds uniformly across all call types in go-ethereum, so the analog described in the report does not exist here.

func (c *ecrecover) Run(input []byte) ([]byte, error) {
	input = common.RightPadBytes(input, ecRecoverInputLength)
	// "input" is (hash, v, r, s), each 32 bytes
	// but for ecrecover we want (r, s, v)

	r := new(big.Int).SetBytes(input[64:96])
	s := new(big.Int).SetBytes(input[96:128])
	v := input[63] - 27

	// tighter sig s values input homestead only apply to tx sigs
	if bitutil.TestBytes(input[32:63]) || !crypto.ValidateSignatureValues(v, r, s, false) {
		return nil, nil
	}
	// We must make sure not to modify the 'input', so placing the 'v' along with
	// the signature needs to be done on a new allocation
	var sig [65]byte
	copy(sig[:], input[64:128])
	sig[64] = v
	// v needs to be at the end for libsecp256k1
	pubKey, err := crypto.Ecrecover(input[:32], sig[:])
	// make sure the public key is a valid one
	if err != nil {
		return nil, nil
	}

	// the first byte of pubkey is bitcoin heritage
	return common.LeftPadBytes(crypto.Keccak256(pubKey[1:])[12:], 32), nil
