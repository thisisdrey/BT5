### Title
Recipient-Controlled DoS in `distribute_internal` / `distribute` via `deposit_coins` Abort — (`File: aptos-move/framework/aptos-framework/sources/staking_contract.move`, `aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`staking_contract::distribute_internal` and `vesting::distribute` iterate over all recipients and call `aptos_account::deposit_coins` for each one inside a single transaction. If any recipient's account is configured to reject coin deposits — achievable by any account holder calling `set_allow_direct_coin_transfers(false)` on a new account that lacks the legacy `CoinStore<AptosCoin>` resource — the entire transaction aborts. This permanently blocks all other recipients (stakers, shareholders, operators) from receiving their funds until the blocking account relents.

---

**The abort path in `aptos_account::deposit_coins`** (lines 111–131):

```move
public fun deposit_coins<CoinType>(to: address, coins: Coin<CoinType>) acquires DirectTransferConfig {
    if (!account::exists_at(to)) { create_account(to); };
    if (!coin::is_account_registered<CoinType>(to)) {
        assert!(
            can_receive_direct_coin_transfers(to),          // returns false → ABORT
            error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
        );
        coin::register<CoinType>(&create_signer(to));
    };
    coin::deposit<CoinType>(to, coins)
}
``` [3](#0-2) 

`coin::is_account_registered<CoinType>` checks only for the legacy `CoinStore<CoinType>` resource:

```move
pub fn is_account_registered<CoinType>(account_addr: address): bool {
    exists<CoinStore<CoinType>>(account_addr)
}
```

Accounts created after the FA migration via `aptos_account::create_account` call `register_apt` → `ensure_primary_fungible_store_exists`, which creates only the FA-based primary store — **not** the legacy `CoinStore<AptosCoin>`. Therefore `coin::is_account_registered<AptosCoin>` returns `false` for such accounts. [4](#0-3) 

`can_receive_direct_coin_transfers` returns `false` when the account has explicitly called `set_allow_direct_coin_transfers(false)`: [5](#0-4) 

**Cascade of blocked callers.** `distribute_internal` is called by every mutating entry point in `staking_contract`:

- `distribute` (line 848)
- `unlock_stake` (line 691)
- `request_commission` (line 625)
- `update_commision` (line 582)
- `switch_operator` (implicitly via `distribute_internal`) [6](#0-5) 

If the distribution is blocked, the staker cannot unlock stake, switch operators, or claim rewards. In `vesting.move`, `distribute` is also called inside `terminate_vesting_contract` (line 775), so termination is also blocked. [7](#0-6) 

---

### Impact Explanation

A single shareholder whose account is a post-FA-migration account with `allow_arbitrary_coin_transfers = false` can:

1. Block `vesting::distribute` for **all** shareholders indefinitely — no other shareholder receives vested APT or rewards.
2. Block `staking_contract::distribute_internal`, preventing the staker from ever calling `unlock_stake` or `switch_operator`, effectively freezing their staking balance.

The coins are not permanently destroyed (they remain in the stake pool), but access to them is denied for as long as the blocking account maintains its configuration. The blocking account can sustain this DoS at zero cost.

---

### Likelihood Explanation

- Any account created after the FA migration lacks `CoinStore<AptosCoin>` by default.
- `set_allow_direct_coin_transfers(false)` is a public entry function callable by any account holder.
- A shareholder in a vesting contract (or an operator's beneficiary in a staking contract) who performs both steps can trigger the DoS with a single subsequent `distribute` call.
- No privileged capability is required beyond being a participant in the contract.

---

### Recommendation

Replace the hard-abort `deposit_coins` call inside distribution loops with a pattern that skips or defers failed transfers and emits an event, analogous to the external report's recommendation:

```move
// Instead of:
aptos_account::deposit_coins(recipient, coin::extract(&mut coins, amount));

// Use a guarded path:
if (can_receive_coins(recipient)) {
    aptos_account::deposit_coins(recipient, coin::extract(&mut coins, amount));
} else {
    // hold in escrow or emit DistributionFailed event; do not abort
    emit(DistributionFailed { recipient, amount });
    // re-merge coins back or store in a claimable map
};
```

Alternatively, require all distribution recipients to pre-register for `AptosCoin` (ensuring `coin::is_account_registered<AptosCoin>` returns `true`) before they can be added to a staking or vesting pool.

---

### Proof of Concept

```
1. Create account `blocker` via aptos_account::create_account(@blocker).
   → blocker has FA primary store but NO CoinStore<AptosCoin>.
   → coin::is_account_registered<AptosCoin>(@blocker) == false.

2. blocker calls set_allow_direct_coin_transfers(blocker_signer, false).
   → can_receive_direct_coin_transfers(@blocker) == false.

3. Admin creates a vesting contract with shareholders = [@alice, @blocker].

4. Time passes; stake earns rewards; coins become withdrawable.

5. Anyone calls vesting::distribute(contract_address).
   → Loop reaches blocker's entry.
   → aptos_account::deposit_coins(@blocker, share) aborts with
      EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS (error code 0x50003).
   → Entire transaction reverts.
   → @alice receives nothing.

6. blocker maintains this state indefinitely; alice's vested APT is inaccessible.
```

The same sequence applies to `staking_contract::distribute_internal` when the operator's beneficiary is `@blocker`, blocking the staker from calling `unlock_stake` or `switch_operator`.

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
