### Title
Unauthenticated signer event listener accepts forged node events on an unrestricted bind address - (File: libsigner/src/events.rs)

### Summary
The `SignerEventReceiver` HTTP listener that the `stacks-signer` binds to receive events from the Stacks node (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`) performs **no authentication or source-address restriction** on incoming POST requests. Any TCP peer that can reach the listening port can POST arbitrary JSON payloads that are deserialized and forwarded directly into the signer's runloop as if they came from the trusted local `stacks-node`.

### Finding Description
`SignerEventReceiver::bind` simply starts a `tiny_http::Server` on the configured socket with no credential check: [1](#0-0) 

`next_event` then dispatches purely on the URL path — there is no header, token, or peer-address check anywhere in the request-handling path before the body is parsed and converted into a `SignerEvent`: [2](#0-1) 

`process_event` reads the body, deserializes it as JSON into `StackerDBChunksEvent`, `BlockValidateResponse`, or `BurnBlockEvent`, and converts it into a `SignerEvent<T>` that is pushed straight into the signer's processing channel via `forward_event`: [3](#0-2) [4](#0-3) 

By contrast, the node's own RPC surface is explicitly gated by an `auth_token`/`auth_password` shared secret configured in `[connection_options]` and the signer config, as documented in the sample configs: [5](#0-4) [6](#0-5) 

No equivalent secret or peer-identity check exists on the signer's *inbound* event-receiver endpoint. Worse, the shipped sample configuration explicitly binds this listener to all interfaces: [7](#0-6) 

This is a direct structural analog of the reported bug class: an internal, trust-sensitive protocol relay (here, the node→signer event channel, standing in for the CDP relay) that is bound broadly (`0.0.0.0`) without restricting the source of incoming connections, and additionally lacks any authentication gate at all — so the "equality" that should hold (only the paired local `stacks-node` may feed events into this signer) fails open for any network peer that can reach the port.

### Impact Explanation
Any unprivileged remote peer able to reach the signer's event-receiver port (which, per the shipped sample config, listens on `0.0.0.0`) can inject forged `StackerDBChunksEvent`, `BlockValidateResponse`, or `BurnBlockEvent` messages directly into the signer's event channel, impersonating the local trusted node without needing the node's `auth_token` or any private key. This is an unauthenticated write into the signer's internal event/state pipeline — the exact "auth-gate that fails open" pattern called out in scope, reachable purely over the network with no privileges.

### Likelihood Explanation
Exploitation only requires network reachability to the bound port; the sample/reference configuration itself binds to `0.0.0.0`, and there is no code-level restriction preventing this regardless of configured bind address (unlike the node's RPC layer, which enforces `auth_token`). No secret material, private key, or elevated role is required — a bare `POST /stackerdb_chunks` (or the other endpoints) with a well-formed JSON body from any reachable IP is sufficient to have the payload accepted and forwarded.

### Recommendation
Add authentication to the `SignerEventReceiver` HTTP endpoint (e.g., require the same shared `auth_token`/`auth_password` used on the node side, verified via a header before body deserialization) and/or default-restrict acceptable source addresses to loopback/configured trusted peers, analogous to the fix applied for the CDP relay (enforce a source-range restriction by default rather than broad `0.0.0.0` exposure).

### Proof of Concept
1. Configure a `stacks-signer` per the shipped sample (`endpoint = "0.0.0.0:30000"`), as in `sample/conf/signer/mainnet-signer-conf.toml`.
2. From any host that can route to that IP:port, send a raw HTTP POST as done in the existing test harness (no auth headers needed):
```
POST /stackerdb_chunks HTTP/1.1
Host: <signer-ip>:30000
Connection: close
Content-Type: application/json
Content-Length: <n>

{"contract_id": "...", "modified_slots": [...]}
```
(mirrors the test client construction in `libsigner/src/tests/mod.rs`, lines 121-146, but from an arbitrary remote source rather than the local node)
3. The listener (`libsigner/src/events.rs`, `next_event`/`process_event`) accepts and forwards the payload with no verification that it originated from the paired node, demonstrating the missing auth gate. [8](#0-7)

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
