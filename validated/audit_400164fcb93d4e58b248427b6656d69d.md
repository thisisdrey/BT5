### Title
Name-pattern–based quarantine ownership check in `Repo.ObjectDirectoryPath` allows cross-repository object-directory access via crafted `GitObjectDirectory` field - (File: internal/git/localrepo/paths.go)

### Summary
`Repo.ObjectDirectoryPath` decides whether a client-supplied `GitObjectDirectory` value is a legitimate transaction quarantine directory purely by inspecting the *names* of its path components (`baseDir == "quarantine"` or `parentDir == "quarantine" && strings.HasPrefix(baseDir, "tmp_objdir")`), instead of verifying that the path actually belongs to this repository's quarantine (as the parallel branch does via `QuarantineDirectoryPrefix`). Any storage-internal path that merely matches this naming shape bypasses the ownership check, mirroring the Lambo.win flaw where a value was validated by a superficial bit-pattern condition (`directionMask == _BUY_MASK`) instead of true origin/identity, letting an attacker substitute an arbitrary trusted-looking value.

### Finding Description
`Repo.ObjectDirectoryPath` in [1](#0-0)  first calls `storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))`, which only guarantees the resulting path stays inside the *storage* root — not inside the repository or inside a quarantine directory that actually belongs to this repository.

It then computes:
```go
parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
baseDir := filepath.Base(relativeObjectDirectoryPath)
isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))
``` [2](#0-1) 

If `isTransactionQuarantineDir` is `true`, the function **skips** the stricter ownership check that otherwise validates the path against `storage.QuarantineDirectoryPrefix(repo)` (a SHA1-derived, repository-specific prefix) [3](#0-2) [4](#0-3) . That stricter check is the only mechanism that ties a manually-specified quarantine directory back to the requesting repository.

Because the "is this a transaction quarantine dir" test is a pure name/shape match rather than an identity check, any path within the storage whose last (or last-two) path component(s) are literally named `quarantine` — or `quarantine/tmp_objdir-*` — satisfies it, regardless of which repository, transaction, or tenant it actually belongs to.

`GitObjectDirectory` is a field on the `gitalypb.Repository` message that ordinary accessor RPCs are permitted to set (only mutators are rejected when it's set) [5](#0-4) , and it is nominally intended only to carry back quarantine information that GitLab Rails received from a prior push's `pre-receive` hook, as documented in [6](#0-5) . Nothing at the RPC boundary cryptographically ties this field's value to the actual quarantine directory created for that request; the only defense inside Gitaly is the (bypassable) ownership check in `ObjectDirectoryPath`.

### Impact Explanation
An attacker who can issue an accessor RPC (e.g. `GetObjectDirectorySize`, which calls `repo.ObjectDirectoryPath` directly [7](#0-6) ) can set `Repository.GitObjectDirectory` to any storage-relative path ending in a `quarantine`-named component that exists on disk (e.g., another repository's own `quarantine` staging directory left over from an in-flight transaction, or any attacker-creatable directory under the storage that happens to be named `quarantine`). Because the naming check short-circuits the real ownership validation, Gitaly will treat that arbitrary directory as this repository's legitimate object directory and operate on it (e.g., report its size, or in other consumers of `ObjectDirectoryPath`, potentially read its contents). This is a cross-repository/cross-tenant object-directory access, matching the accepted "cross-repository object access" impact class — the storage-boundary check exists, but the intra-storage, per-repository boundary that quarantine directories are supposed to enforce is defeated by relying on directory-name shape instead of actual provenance.

### Likelihood Explanation
Reaching this code path only requires an ordinary Gitaly client to send a Repository message with a crafted `GitObjectDirectory` value on an accessor RPC — no special privilege beyond what any Gitaly gRPC caller (e.g., GitLab Rails, or any actor that can invoke Gitaly RPCs) already has. The attacker needs to (a) know or predict a `quarantine`-named path elsewhere in the same storage (transaction staging quarantine directories under a storage's temp dir are somewhat predictable and multiple such directories exist concurrently under load) and (b) that directory must exist for `os.Stat` to succeed. This is a moderate-effort but concretely reachable condition, analogous in structure (though not in exact exploitation mechanics) to the reported bug class of "shape-matching bypasses identity validation."

### Recommendation
Remove the purely name-based `isTransactionQuarantineDir` shortcut, or strengthen it to also validate that the directory is rooted under the *current* transaction's own staging/temp directory for *this* repository (e.g., always require the `expectedQuarantinePrefix` / `QuarantineDirectoryPrefix(repo)` check, rather than skipping it whenever the base/parent directory name merely matches `"quarantine"` or `"tmp_objdir*"`). Ownership of a quarantine directory should be established by verifiable provenance (e.g., a value derived from the transaction/repository identity, as `QuarantineDirectoryPrefix` already does) — never by string pattern-matching on the directory's name alone.

### Proof of Concept
Not runnable without live access to a Gitaly storage layout; conceptually:
1. Attacker sends `GetObjectDirectorySizeRequest` (or any accessor RPC that uses `ObjectDirectoryPath`) for `Repository{StorageName: S, RelativePath: attackerRepo}` and sets `GitObjectDirectory` to a relative path such as `../../<storage-tmp>/<other-tx-staging-dir>/quarantine` (or any `.../quarantine` directory that exists within storage `S`).
2. `storage.ValidateRelativePath(storagePath, …)` succeeds because the resulting absolute path is still inside `storagePath`.
3. `filepath.Base(relativeObjectDirectoryPath) == "quarantine"` makes `isTransactionQuarantineDir == true`, so the `expectedQuarantinePrefix` ownership check tying the directory to `attackerRepo`'s own `QuarantineDirectoryPrefix` hash is skipped entirely.
4. `os.Stat(fullPath)` succeeds (the directory exists, created by another repository's transaction), and Gitaly returns size/data for that foreign directory as if it belonged to `attackerRepo`.

Whether other quarantine-set-eligible RPCs beyond `GetObjectDirectorySize` amplify this into a bigger read primitive (e.g., feeding the mis-attributed object directory into `git` subprocess execution) could not be fully confirmed within available index coverage; this would need direct inspection of how `GIT_OBJECT_DIRECTORY`/`GIT_ALTERNATE_OBJECT_DIRECTORIES` environment variables are populated from `Repository.GitObjectDirectory` in `internal/git/gitcmd` command construction, which the indexed code did not fully surface.

// ObjectDirectoryPath returns the full path of the object directory. The errors returned are gRPC
// errors with relevant error codes and should be passed back to gRPC without further decoration.
func (repo *Repo) ObjectDirectoryPath(ctx context.Context) (string, error) {
	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", err
	}

	objectDirectoryPath := repo.GetGitObjectDirectory()
	if objectDirectoryPath == "" {
		return "", structerr.NewInvalidArgument("object directory path is not set")
	}

	storagePath, err := repo.locator.GetStorageByName(ctx, repo.GetStorageName())
	if err != nil {
		return "", fmt.Errorf("get storage by name: %w", err)
	}

	// Ensure the path points somewhere in the storage.
	relativeObjectDirectoryPath, err := storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))
	if err != nil {
		return "", structerr.NewInvalidArgument("validate relative path: %w", err)
	}

	parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
	baseDir := filepath.Base(relativeObjectDirectoryPath)
	isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

// QuarantineDirectoryPrefix returns a prefix for use in the temporary directory. The prefix is
// based on the relative repository path and will stay stable for any given repository. This allows
// us to verify that a given quarantine object directory indeed belongs to the repository at hand.
// Ideally, this function would directly be located in the quarantine module, but this is not
// possible due to cyclic dependencies.
func QuarantineDirectoryPrefix(repo Repository) string {
	hash := [20]byte{}
	if repo != nil {
		hash = sha1.Sum([]byte(repo.GetRelativePath()))
	}
	return fmt.Sprintf("quarantine-%x-", hash[:8])
}

### Relative paths

During the Gitaly migration we had to handle a complication with the
object quarantine information: Git uses absolute paths for this. These
paths get generated wherever `git receive-pack` runs, i.e., on the
Gitaly server. During the migration, the repositories were also
accessible via NFS at the Rails side, but at a different path. That
meant that the absolute paths supplied by Git would be invalid part of
the time.

To work around this, the GitLab `pre-receive` hook
[converts the absolute paths from Git into relative paths](https://gitlab.com/gitlab-org/gitaly/-/blob/969bac80e2f246867c1a976864bd1f5b34ee43dd/ruby/gitlab-shell/lib/object_dirs_helper.rb#L16),
relative to the repository directory. These relative paths then get
passed around inside GitLab. At the time Gitaly recreates the object
directory variables, it
[converts the paths back from relative to absolute](https://gitlab.com/gitlab-org/gitaly/-/blob/969bac80e2f246867c1a976864bd1f5b34ee43dd/internal/git/alternates/alternates.go#L23).

func (s *server) GetObjectDirectorySize(ctx context.Context, in *gitalypb.GetObjectDirectorySizeRequest) (*gitalypb.GetObjectDirectorySizeResponse, error) {
	repository := in.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}
	repo := s.localRepoFactory.Build(repository)

	path, err := repo.ObjectDirectoryPath(ctx)
	if err != nil {
		return nil, err
	}
	// path is the objects directory path, not repo's path
	sizeInBytes, err := dirSizeInBytes(path, snapshot.NewDefaultFilter(ctx))
	if err != nil {
		return nil, fmt.Errorf("calculating directory size: %w", err)
	}

	return &gitalypb.GetObjectDirectorySizeResponse{Size: sizeInBytes / 1024}, nil
}
