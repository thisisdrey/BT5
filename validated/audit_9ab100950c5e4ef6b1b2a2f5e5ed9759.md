### Title
Protocol fee bypass on Nep245/Imt token-in legs via unit-amount fragmentation - (File: contracts/defuse/core/src/intents/token_diff.rs)

### Summary
`TokenDiff::token_fee` waives the fee for `Nep245`/`Imt` legs whenever the transferred `amount <= 1`, and this check is evaluated independently for every `TokenDiff` intent in a batch rather than on the signer's aggregate transfer of that token. Because one signed `MultiPayload` can carry an arbitrary `Vec<Intent>` under a single signature/nonce, an attacker can split a large Nep245/Imt outflow into many unit-amount `TokenDiff` intents and have every one of them hit the `amount<=1` fee-exempt branch, reducing the total collected fee on that token to zero.

### Finding Description
The broken binding: for a signer transferring an aggregate quantity `N` of a Nep245/Imt `token_id` as `token_in` in one `execute_intents` call, the protocol should collect `fee_collected(token_id) == Pips::fee_ceil(protocol_fee, N)` (as it would for one `TokenDiff` intent with `delta = -N`). Instead, the code computes and collects fee per intent: [1](#0-0) [2](#0-1) 

`token_fee` exempts `Nep245`/`Imt` whenever `amount <= 1`, and this predicate is evaluated per `TokenDiff` intent, using only that intent's own `delta`, never an aggregate over the batch or over the signer's account.

`DefusePayload<DefuseIntents>` allows the signer to bundle an arbitrary list of intents under one signature and one committed `Nonce`: [3](#0-2) [4](#0-3) 

so the attacker signs one `MultiPayload` containing `N` separate `TokenDiff` intents, each `diff = {nep245_or_imt_token_id: -1, other_token_id: +k}`, instead of one intent with `delta = -N`. Every one of the `N` calls to `TokenDiff::execute_intent` independently computes `amount = 1`, hits the `amount<=1` branch of `token_fee`, and adds `Pips::ZERO` to `fees_collected`, so the fee for that token across the whole batch sums to `0`.

The invariant enforced by `TransferMatcher::finalize` only checks that raw balance deltas (including whatever was actually credited to `fee_collector`) net to zero across the entire batch — it does not check that a minimum fee was charged: [5](#0-4) 

so nothing downstream re-derives or enforces the fee that should have applied to the aggregate transfer; the counterparty side (e.g., a Nep141 leg) is charged normally since `Nep141` has no amount exemption, but the Nep245/Imt leg's fee is fully bypassed regardless of how large `N` is.

None of the existing guards (`MultiPayload::verify`, `has_public_key`, `verify_intent_nonce`, nonce commit, salt validity, `TransferMatcher::finalize`) address this because they validate authenticity/replay/zero-sum invariants, not fee minimality per token per batch.

### Impact Explanation
The `fee_collector` account under-receives protocol fee revenue on every Nep245/Imt-denominated swap that the signer chooses to fragment into unit-amount `TokenDiff` intents within a single `MultiPayload`, while the actual token balances still move the full intended (large) amount between the signer and counterparty. This is a direct instance of "protocol fees bypassed," which the rules classify as Critical, since it is `fee_collector` funds that are under-collected on legitimate value transfers, repeatable for any account and any Nep245/Imt token, in every batch containing such legs, with no cap on the fragmentation count `N` other than gas/message-size limits.

### Likelihood Explanation
Preconditions are trivial for an unprivileged attacker: they only need to hold a Nep245/Imt balance in the Verifier and a willing (or self-controlled, via a second account) counterparty to net the batch to zero, plus a nonzero `protocol_fee`. The attacker pays no extra cost beyond constructing `N` `TokenDiff` entries in one already-required signed payload (one signature, one nonce, no additional key or role needed). This is repeatable on every swap and scales fee avoidance linearly with `N`.

### Recommendation
Compute/track the Nep245/Imt fee exemption on the signer's aggregate negative delta for that `token_id` across the whole `execute_intents` call (e.g., accumulate per-signer, per-token `amount` before applying `token_fee`, or simply remove the `amount<=1` exemption and rely on `fee_ceil` rounding for genuinely unit NFT/MT transfers) rather than per individual `TokenDiff` intent.

3. Batch A: signer signs ONE `MultiPayload` containing `N` `TokenDiff` intents, each `{token_id: -1, ft_out: +k}`, matched by counterparty legs; assert `fees_collected` for `token_id` after `execute_intents` equals `0`.

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
