### Title
Nep245/Imt protocol fee bypass by splitting a single-token trade into multiple `TokenDiff` intents of amount ≤ 1 - (File: contracts/defuse/core/src/intents/token_diff.rs)

### Summary
`TokenDiff::execute_intent` computes the fee for each negative delta using `Self::token_fee(token_id, amount, protocol_fee)`, where `amount` is only the magnitude of that single intent's delta on that token, not the aggregate amount of that token debited across the whole `execute_intents` batch. For `Nep245`/`Imt` token types, `token_fee` returns `Pips::ZERO` whenever `amount <= 1` [1](#0-0) . An unprivileged signer can therefore split what would otherwise be a fee-bearing multi-unit MT/NFT debit into several separate `TokenDiff` intents of exactly `-1` each, so every intent independently sees `amount == 1` and computes zero fee, while the `TransferMatcher::finalize` step still nets and settles the full multi-unit transfer across the batch [2](#0-1) .

### Finding Description
Broken binding: `fee_collector_credit(T, batch) == Pips::fee_ceil(sum_of_|negative_deltas_of_T|_across_batch, protocol_fee)`. The code instead computes, per `TokenDiff` intent, a local `fees_collected` that is reset to `Amounts::default()` on every call to `execute_intent` [3](#0-2) , so the fee-exemption check `TokenIdType::Nep245 | TokenIdType::Imt if amount > 1` in `token_fee` only ever sees the delta of the single intent being executed [4](#0-3) .

Exploit flow: the attacker (an ordinary signer with a Nep245/Imt balance in the Verifier) constructs a `DefuseIntents` message (or two separate signed `MultiPayload`s) containing two `TokenDiff` intents, each with `diff = { token_id: -1 }`, instead of a single `TokenDiff` with `diff = { token_id: -2 }`. `DefuseIntents::execute_intent` simply iterates and executes each contained intent in sequence [5](#0-4) . Each `TokenDiff::execute_intent` call independently computes `amount.unsigned_abs() == 1`, so `token_fee` returns `Pips::ZERO`, `fee = 0`, and `fees_collected` stays empty for that intent, skipping the `internal_add_balance` call to `fee_collector` entirely [6](#0-5) . Meanwhile `internal_apply_deltas` records both `-1` debits into the batch-wide `TransferMatcher`, which nets them against a `+2` credit elsewhere in the batch and settles the full 2-unit transfer via `finalize` [7](#0-6) . Had the same 2-unit debit been expressed as one `TokenDiff` intent with `amount == 2`, `token_fee` would have applied `protocol_fee` and `fee_ceil(2)` would have been credited to `fee_collector`.

No existing guard catches this: `MultiPayload::verify`, nonce/salt checks, and `Deltas::finalize`'s invariant check only ensure debits and credits net to zero across the batch (solvency), not that the fee-exemption threshold is evaluated on the aggregate per-token amount [8](#0-7) .

### Impact Explanation
The Verifier's `fee_collector` under-collects protocol fees on every Nep245/Imt trade that a signer chooses to structure as multiple unit-sized `TokenDiff` intents instead of one aggregated intent. This is repeatable without limit: any Nep245/Imt balance of size `N` can be moved as `N` separate `-1` intents, reducing the fee from `fee_ceil(N)` to `0` for arbitrary `N`, on every batch, for every account holding such tokens. This matches the "protocol fees bypassed" Critical impact category since it is systematic value (fee revenue) never collected that the protocol design otherwise entitles the fee collector to.

### Likelihood Explanation
No special privilege is required — any signer who can call `execute_intents`/`simulate_intents` with a `MultiPayload` can trivially restructure their own `TokenDiff` diff map into multiple single-unit intents instead of one multi-unit intent. The only cost is marginally larger payload/signature size and slightly higher gas, which is negligible compared to the fee saved for any token with a non-negligible balance. This is fully feasible and repeatable across accounts, tokens, and batches with no counterparty cooperation needed beyond whatever counterparty already exists to net the trade (which is required for any trade regardless of fee-splitting).

### Recommendation
Compute the Nep245/Imt fee-exemption threshold and the fee itself on the aggregate `|delta|` of each `TokenId` across the whole `DefuseIntents`/batch (e.g., by pre-aggregating deltas per signer/token before iterating `TokenDiff` intents, or by tracking cumulative per-token debited amounts in `Engine`/`Deltas` state across all intents in the batch and finalizing fee computation only once), rather than resetting `fees_collected`'s basis for the `amount > 1` check on every individual intent call.

### Proof of Concept
`cargo test` plan (near-workspaces sandbox), extending `tests/src/tests/defuse/intents/token_diff.rs`:
1. Set up a `Nep245` token contract and deposit balance of 2 units of `token_id` to `user1` and matching counterparty balance to `user2` in the Verifier, with `protocol_fee = Pips::ONE_PERCENT` (or any nonzero fee).
2. Baseline case: sign one `TokenDiff` intent for `user1` with `diff = { token_id: -2, other_token: +X }` and matching `user2` intent, execute via `execute_intents`, and assert `fee_collector`'s balance increases by exactly `Pips::fee_ceil(2, protocol_fee)` (nonzero).
3. Exploit case: sign two separate `TokenDiff` intents for `user1`, each `diff = { token_id: -1, other_token: +X/2 }` (or equivalent split), plus matching `user2` intent(s) summing to `+2`/`-X`, execute via `execute_intents` in one call, and assert `fee_collector`'s balance increase is `0` instead of `Pips::fee_ceil(2, protocol_fee)`.
4. Assert both `user1`'s and `user2`'s net token balances after execution are identical in both cases (proving the same economic trade occurred), while the fee collected differs (`0` vs `fee_ceil(2)`), demonstrating the bypass.

/// Accumulates internal deposits and withdrawals on different tokens
/// to match transfers using `.finalize()`
///
/// Transfers in `TokenDiff` intents are represented as deltas without receivers.
/// This struct accumulates tokens all transfers, and converts them from deltas, to
/// a set of transfers from one account to another.
/// Note that this doesn't touch account balances. The balances were already changed
/// in an earlier stage while executing the intent.
#[derive(Debug, Default)]
pub struct TransferMatcher(HashMap<TokenId, TokenTransferMatcher>);

impl TransferMatcher {
    #[inline]
    pub fn new() -> Self {
        Self(HashMap::new())
    }

    #[inline]
    pub fn deposit(&mut self, owner_id: AccountId, token_id: TokenId, amount: u128) -> bool {
        self.0.entry_or_default(token_id).deposit(owner_id, amount)
    }

    #[inline]
    pub fn withdraw(&mut self, owner_id: AccountId, token_id: TokenId, amount: u128) -> bool {
        self.0.entry_or_default(token_id).withdraw(owner_id, amount)
    }

    #[inline]
    pub fn add_delta(&mut self, owner_id: AccountId, token_id: TokenId, delta: i128) -> bool {
        self.0.entry_or_default(token_id).add_delta(owner_id, delta)
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }

    pub fn execute_signed_intents(
        mut self,
        signed: impl IntoIterator<Item = MultiPayload>,
    ) -> Result<Transfers> {
        for signed in signed {
            self.execute_signed_intent(signed)?;
        }
        self.finalize()
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    #[inline]
    fn verify_intent_nonce(&self, nonce: Nonce, intent_deadline: Timestamp) -> Result<()> {
        let Some(nonce) = VersionedNonce::maybe_from(nonce) else {
            return Ok(());
        };

        match nonce {
            VersionedNonce::V1(SaltedNonce {
                salt,
                nonce: ExpirableNonce { deadline, .. },
            }) => {
                if !self.state.is_valid_salt(salt) {
                    return Err(DefuseError::InvalidSalt);
                }

                if intent_deadline > deadline {
                    return Err(DefuseError::DeadlineGreaterThanNonce);
                }

                if deadline < Timestamp::now() {
                    return Err(DefuseError::NonceExpired);
                }
            }
        }

        Ok(())
    }

    #[inline]
    fn finalize(self) -> Result<Transfers> {
        self.state
            .finalize()
            .map_err(DefuseError::InvariantViolated)
    }
