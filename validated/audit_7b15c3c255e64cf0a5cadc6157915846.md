### Title
Unauthenticated event injection into signer's event-listener HTTP server - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` in `libsigner/src/events.rs` dispatches every incoming HTTP request purely by matching `request.url()` and `request.method()`, with no check of the request's source, no shared-secret/token header validation, and no TLS/mTLS. Any TCP client that can reach the signer's bound listener address can POST to `/new_burn_block`, `/new_block`, `/proposal_response`, or `/stackerdb_chunks` and have the signer treat the body as if it were emitted by the locally configured, trusted `stacks-node`.

### Finding Description
The claimed equality is: every `SignerEvent` forwarded to the runloop must equal an event actually emitted by the trusted node's event-dispatcher. Tracing `next_event()`: [1](#0-0) 

The function reads a raw request from `http_server.recv()` and branches solely on `request.url()`/`request.method()`:
- `/stackerdb_chunks` → `process_event::<T, StackerDBChunksEvent>`
- `/proposal_response` → `process_event::<T, BlockValidateResponse>`
- `/new_burn_block` → `process_event::<T, BurnBlockEvent>`
- `/new_block` → `process_event::<T, StacksBlockEvent>`
- `/shutdown` → sets the stop signal directly, no auth check at all

`process_event` simply reads the body, JSON-deserializes it, and converts it via `TryFrom` into a `SignerEvent`: [2](#0-1) 

There is no IP allowlist, no peer-certificate check, and no shared-secret header comparison anywhere in this path. The `auth_password`/`auth_token` mechanism documented in the sample configs is unidirectional and used only for the **signer → node** RPC channel (block-proposal endpoint), not for authenticating **node → signer** POSTs into this listener: [3](#0-2) [4](#0-3) 

The reference deployment config even sets the signer's own listener to `0.0.0.0:30000` (all interfaces), which is LAN/remotely reachable depending on operator network placement: [5](#0-4) 

`Signer::spawn` binds this address and starts `event_receiver.main_loop()` in its own thread, which calls `next_event()` in a loop and unconditionally forwards whatever `SignerEvent` it produces to the signer runloop channel: [6](#0-5) [7](#0-6) [8](#0-7) 

Nothing in this call chain verifies the sender is the configured node. The equality "forwarded event == node-originated event" is broken: any TCP peer that can connect to the bound address can forge `SignerEvent::NewBurnBlock`, `SignerEvent::NewBlock`, or `SignerEvent::BlockValidationResponse` with attacker-chosen fields (burn height, consensus hash, block transactions, validation verdicts) and have it delivered to the runloop indistinguishably from a genuine node event.

### Impact Explanation
An attacker who can reach the signer's event-listener TCP port can unauthenticated-ly inject consensus-adjacent data into the signer's decision-input stream: fake burn-block heights/consensus hashes via `/new_burn_block`, fake new-block transaction sets via `/new_block`, or forged block-validation verdicts via `/proposal_response`. This is a repeatable, per-message forgery (each POST produces one forwarded event) and matches the "unauthenticated write to state" / "network-wide propagation of forged data" severity category, since the runloop's subsequent decision-making consumes these forged inputs as if node-originated (decision-logic consequences are out of scope for this specific finding, but the injection point itself is in-scope and unauthenticated).

### Likelihood Explanation
Preconditions: the attacker only needs TCP reachability to the signer's bound event-listener address/port — no node secret, no signer key, no StackerDB slot, and no privileged role is required by this code path. The reference/sample configuration binds this listener to `0.0.0.0:30000`, i.e., all interfaces, which is remotely reachable unless an operator adds external firewalling that is not enforced by the code itself. The attack requires only a single crafted HTTP POST per forged event and is trivially repeatable.

### Recommendation
Add authentication to the signer's inbound event listener that mirrors the existing outbound `auth_password`/`auth_token` mechanism: require a shared-secret header (e.g., `Authorization`) on every POST to `/new_burn_block`, `/new_block`, `/proposal_response`, and `/stackerdb_chunks` in `next_event()`, rejecting requests that don't present the correct token before any body is read or deserialized. Additionally, document/enforce that the event-listener bind address should default to `127.0.0.1` rather than `0.0.0.0` unless explicitly overridden with an authenticated reverse proxy.

### Proof of Concept
```rust
// libsigner/src/events.rs (test module) — demonstrates unauthenticated forgery
#[test]
fn test_unauthenticated_forged_new_burn_block() {
    let mut receiver: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let bound_addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    let handle = std::thread::spawn(move || receiver.next_event());

    // Simulate an arbitrary remote peer -- NOT the configured node -- with no secret.
    let mut stream = TcpStream::connect(bound_addr).unwrap();
    let body = serde_json::json!({
        "burn_block_hash": "0x00".repeat(32),
        "burn_block_height": 999999999u64,          // attacker-chosen
        "consensus_hash": "0x11".repeat(20),         // attacker-chosen
        "parent_burn_block_hash": "0x22".repeat(32),
        // ... remaining BurnBlockEvent fields
    }).to_string();
    let req = format!(
        "POST /new_burn_block HTTP/1.1\r\nContent-Length: {}\r\nContent-Type: application/json\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let event = handle.join().unwrap().unwrap();
    // Assertion: the forged, attacker-supplied burn_height/consensus_hash is accepted
    // verbatim with no rejection, no auth check, no origin check.
    match event {
        SignerEvent::NewBurnBlock { burn_height, .. } => assert_eq!(burn_height, 999999999u64),
        _ => panic!("expected forged NewBurnBlock to be accepted"),
    }
}
```
This test binds the receiver exactly as `Signer::spawn` does [9](#0-8) , connects as an arbitrary unrelated TCP peer, and confirms `next_event()` at [10](#0-9)  accepts and returns the attacker-forged `SignerEvent::NewBurnBlock` with no rejection.

```rust
    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {

            }

                    continue;
                }

                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };

                info!("Failed to forward event");
                break;
            }
        }
```

```rust
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
```

```rust
    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }
```

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```
