The premise doesn't match the actual code. `RPCNakamotoBlockSimulateRequestHandler::try_parse_request` in `stackslib/src/net/api/blocksimulate.rs` enforces the `Authorization` header check unconditionally, before any query-string parsing occurs at all [1](#0-0) . The only query parameter this endpoint recognizes is `profiler`, and it uses strict equality (`value == "1"`), not a loose "non-empty string is truthy" check, so values like `"0"` or `"false"` do not set `self.profiler = true` [2](#0-1) . There is no `simulate`/`commit` boolean anywhere in this handler that selects between a "simulate-only" and "persist/relay" code path — `block_simulate` only calls `remine_nakamoto_block`, which mines a hypothetical block for inspection and never persists or relays it [3](#0-2) . Since auth is checked first and unconditionally, and no such flag exists to be flipped, the described auth-bypass/mis-parsing scenario is not present in this file.

    pub fn block_simulate(
        &self,
        sortdb: &SortitionDB,
        chainstate: &mut StacksChainState,
    ) -> Result<RPCReplayedBlock, ChainError> {
        let Some(block_id) = &self.block_id else {
            return Err(ChainError::InvalidStacksBlock("block_id is None".into()));
        };

        let rpc_simulated_block = remine_nakamoto_block(
            block_id,
            sortdb,
            chainstate,
            self.profiler,
            |_| self.transactions.clone(),
            |tenure_tx| {
                if !self.mint.is_empty() {
                    tenure_tx.connection().as_transaction(|tx| {
                        tx.with_clarity_db(|ref mut db| {
                            for mint in &self.mint {
                                let mut balance = db.get_stx_balance_snapshot(&mint.principal)?;
                                balance.credit(mint.amount)?;
                                balance.save()?;
                            }
                            Ok(())
                        })
                    })?;
                }
                Ok(())
            },
        )?;

        Ok(rpc_simulated_block)
    }
