After thorough investigation of the Aptos codebase, I found a direct structural analog to the external bug in `vesting.move`.

---

### Title
Immutable `withdrawal_address` in Vesting Contract Causes Permanent Fund Lock When Recipient's CoinStore Is Frozen — (`File: aptos-move/framework/aptos-framework/sources/vesting.move`)

### Summary

The `VestingContract` struct stores a `withdrawal_address` that is set once at creation and has no update mechanism. Both `distribute()` and `admin_withdraw()` unconditionally send APT to this fixed address via `aptos_account::deposit_coins`. If the `withdrawal_address`'s `CoinStore<AptosCoin>` is frozen, every call to `distribute()` reverts (due to the dust transfer path), permanently blocking all fund distributions and contract termination. All vesting balances become permanently stuck.

### Finding Description

**Root cause — immutable `withdrawal_address`:**

The `VestingContract` struct stores `withdrawal_address` as a plain field with no setter: [1](#0-0) 

At creation, only a basic liveness check is performed — the address must exist and be registered for APT. No freeze-resistance is guaranteed for the lifetime of the contract: [2](#0-1) 

**Failure path 1 — `distribute()` dust transfer:**

After distributing shares to all shareholders, any remaining dust is unconditionally sent to `withdrawal_address`: [3](#0-2) 

`aptos_account::deposit_coins` calls `coin::deposit`, which aborts if the recipient's `CoinStore` is frozen (`aborts_if coin_store.frozen`): [4](#0-3) [5](#0-4) 

Because rounding almost always produces dust, `distribute()` reverts on every call when `withdrawal_address` is frozen.

**Failure path 2 — `terminate_vesting_contract()` calls `distribute()` internally:** [6](#0-5) 

If `distribute()` reverts, the admin cannot terminate the contract. The contract stays in `VESTING_POOL_ACTIVE` state indefinitely.

**Failure path 3 — `admin_withdraw()` also sends to the same fixed address:** [7](#0-6) 

Even if termination somehow succeeded, `admin_withdraw()` also unconditionally deposits to `withdrawal_address`, so all terminated-contract funds are equally blocked.

**No update path exists.** Unlike `locked_coins.move` which provides `update_withdrawal_address`, `vesting.move` has no equivalent function. The `withdrawal_address` field is written once and never changed.

### Impact Explanation

If `withdrawal_address`'s `CoinStore<AptosCoin>` is frozen after contract creation:

1. `distribute()` reverts on every call — no shareholder receives vested tokens or rewards.
2. `terminate_vesting_contract()` reverts — the admin cannot terminate the contract.
3. `admin_withdraw()` reverts — terminated-contract funds cannot be recovered.
4. All APT staked in the underlying stake pool is permanently inaccessible.

This matches the bounty's in-scope impact: **permanent freezing of vesting balances**.

### Likelihood Explanation

Freezing a `CoinStore<AptosCoin>` requires the `FreezeCapability<AptosCoin>`, which is held by the Aptos framework and exercisable only via governance. This makes the trigger a privileged action, which limits practical likelihood. However, the structural defect — a fixed recipient with no update mechanism in a long-lived financial contract — is a real design flaw. Any future mechanism that can freeze an APT coin store (e.g., regulatory compliance tooling, a future framework upgrade) would immediately weaponize this path.

### Recommendation

Add an admin-only `update_withdrawal_address` function to `vesting.move`, analogous to the one already present in `locked_coins.move`: [8](#0-7) 

Additionally, consider splitting the dust transfer from the main shareholder distribution loop so that a frozen `withdrawal_address` does not block shareholder payouts.

### Proof of Concept

1. Admin calls `create_vesting_contract(admin, shareholders, buy_ins, schedule, withdrawal_addr, ...)` — `withdrawal_addr` is stored immutably.
2. Staking rewards accumulate; shareholders call `vest()` and `unlock_rewards()`.
3. The APT freeze-capability holder freezes `withdrawal_addr`'s `CoinStore<AptosCoin>`.
4. Any caller invokes `distribute(contract_address)`:
   - Shareholder shares are extracted from `coins`.
   - Dust remains; `aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins)` is called.
   - `coin::deposit` aborts with `EFROZEN` (error code 10).
   - Entire transaction reverts; no shareholder receives funds.
5. Admin calls `terminate_vesting_contract(admin, contract_address)`:
   - Internally calls `distribute(contract_address)` → same revert.
   - Contract remains `VESTING_POOL_ACTIVE`; admin cannot terminate.
6. All staked APT is permanently inaccessible. [9](#0-8) [10](#0-9)

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

        emit(
            Terminate {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
            },
        );
    }

    public entry fun admin_withdraw(admin: &signer, contract_address: address) acquires VestingContract {
        let vesting_contract = borrow_global<VestingContract>(contract_address);
        assert!(
            vesting_contract.state == VESTING_POOL_TERMINATED,
            error::invalid_state(EVESTING_CONTRACT_STILL_ACTIVE)
        );

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let amount = coin::value(&coins);
        if (amount == 0) {
            coin::destroy_zero(coins);
            return
        };
        aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);

        emit(
            AdminWithdraw {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount,
            },
        );
    }

    /// Update the withdrawal address. This is only allowed if there are currently no active locks.
    public entry fun update_withdrawal_address<CoinType>(
        sponsor: &signer, new_withdrawal_address: address) acquires Locks {
        let sponsor_address = signer::address_of(sponsor);
        assert!(exists<Locks<CoinType>>(sponsor_address), error::not_found(ESPONSOR_ACCOUNT_NOT_INITIALIZED));

        let locks = borrow_global_mut<Locks<CoinType>>(sponsor_address);
        assert!(locks.total_locks == 0, error::invalid_state(EACTIVE_LOCKS_EXIST));
        let old_withdrawal_address = locks.withdrawal_address;
        locks.withdrawal_address = new_withdrawal_address;

        event::emit(UpdateWithdrawalAddress {
            sponsor: sponsor_address,
            old_withdrawal_address,
            new_withdrawal_address,
        });
    }
