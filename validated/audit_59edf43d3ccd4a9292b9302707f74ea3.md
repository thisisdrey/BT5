### Title
Credential leak via unsanitized `req.GetRemote()` URL in `FindRemoteRepository`'s `git ls-remote` argv logged by `logProcessComplete` - ([File: internal/gitaly/service/remote/find_remote_repository.go])

### Summary
`FindRemoteRepository` passes the caller-controlled `Remote` field directly as a positional argument to `git ls-remote <remote> HEAD` via `gitcmd.Command{Args: []string{req.GetRemote(), "HEAD"}}` [1](#0-0) . If that `git ls-remote` invocation fails or writes to stderr, `logProcessComplete` in `internal/command/command.go` logs `cmd.Args` (only count-truncated, not content-sanitized) at Warn/Error level [2](#0-1) . The `URLSanitizerHook` that redacts embedded basic-auth credentials in URLs only fires for `grpc.method` values in its static allowlist, which does not include `FindRemoteRepository` [3](#0-2) [4](#0-3) .

### Finding Description
`URLSanitizerHook.Fire` only sanitizes `args`/`error` log fields when `entry.Data["grpc.method"]` matches one of the strings registered via `AddPossibleGrpcMethod` [5](#0-4) . In `serve.go`, only `"CreateRepositoryFromURL"`, `"FetchRemote"`, and `"UpdateRemoteMirror"` are registered [3](#0-2) .

`FindRemoteRepository` is a `RemoteService` RPC that takes an attacker-controlled `Remote` string (can embed `https://user:pass@host/...`) and forwards it unmodified into `git ls-remote`'s argv via `gitcmd.NewWithoutRepo` [6](#0-5) . This RPC method name is not in the sanitizer's allowlist, so any log line involving this spawned command's argv is not redacted.

When the spawned `git ls-remote` process exits non-zero (e.g., attacker points `Remote` at an unreachable/invalid host to force a failure) or writes anything to stderr, `Command.wait()` calls `c.logProcessComplete()`, which builds a `log.Fields` map including `"args": truncateArgsForLogging(cmd.Args, maxLoggedArgsElements)` — this is only truncated by element count, never by content — and logs it via `entry.WarnContext`/`entry.ErrorContext` when stderr is non-empty [7](#0-6) . Because `URLSanitizerHook.Fire` does not match `grpc.method == "FindRemoteRepository"`, the hook returns early without redacting the `args` field, and the credentialed URL is written verbatim into Gitaly's log stream.

This bypasses the intended defense: the sanitizer is designed as an allowlist keyed on RPC name rather than detecting URL-shaped arguments generically, so any RPC that accepts a URL and forwards it into a git subprocess argv, but isn't explicitly registered, leaks credentials on any command failure/stderr output.

### Impact Explanation
This matches a credential-disclosure impact class: an attacker who controls the `Remote` field of an unauthenticated-adjacent but authenticated `FindRemoteRepository` call can force git-ls-remote to fail (e.g., wrong host, DNS failure, TLS failure, auth failure) and thereby cause Gitaly to log the full URL including embedded username/password at Warn/Error level. Anywhere these Gitaly logs are surfaced (e.g., to support/CI/log-aggregation pipelines, or GitLab's own log tooling with sufficient read access), the credentials embedded by the attacker's request are exposed. Note that in the typical GitLab-Rails-mediated flow, the credentials embedded here are usually supplied by the calling user (their own mirror/import token, e.g. testing whether a repo they specify exists) — so the primary risk is where these credentials belong to another identity forwarded through Rails without the attacker being the credential owner (e.g., mirror-existence checks using project-scoped access tokens), causing Gitaly to log secrets the requesting user should not otherwise see even though they triggered the log line.

### Likelihood Explanation
Fully reachable by an unprivileged authenticated gRPC caller: `FindRemoteRepository` requires only a `Remote` string and no repository-specific privilege checks are shown beyond it being non-empty [8](#0-7) . Triggering a git-ls-remote failure (e.g., a malformed or unreachable host in the URL) is trivial and deterministic, satisfying the "stderr non-empty or non-zero exit" condition in `logProcessComplete`. No special configuration, admin role, or race condition is required.

### Recommendation
Sanitize command argv/error content unconditionally (independent of `grpc.method` allowlisting) using the existing `hostPattern`-based `sanitizeString`, e.g., always run `sanitizeSpawnLog`/`sanitizeErrorLog` over `args`/`error` fields in `URLSanitizerHook.Fire` regardless of gRPC method, or apply the same sanitization at the point `logProcessComplete` builds the `args` field in `internal/command/command.go`. Additionally, register `FindRemoteRepository` (and audit all other RPCs, e.g., `FindRemoteRootRef`, that pass URLs into git argv) with `AddPossibleGrpcMethod`, and add a regression test enumerating all `.proto`-declared RPC fields resembling URLs against the sanitizer's `possibleGrpcMethods` set so future additions fail closed.

// truncateArgsForLogging truncates the provided args list to at most limit
// elements. A final entry is added to the returned list indicating how many
// elements have been removed, if this occurs.
func truncateArgsForLogging(args []string, limit int) []string {
	if len(args) <= limit {
		return args
	}

	truncated := make([]string, 0, limit+1)
	truncated = append(truncated, args[:limit]...)
	truncated = append(truncated, fmt.Sprintf("[%d more args truncated]", len(args)-limit))
	return truncated
}

func (c *Command) logProcessComplete() {
	exitCode := 0
	if c.waitError != nil {
		if exitStatus, ok := ExitStatus(c.waitError); ok {
			exitCode = exitStatus
		}
	}

	ctx := c.context
	cmd := c.cmd

	systemTime := cmd.ProcessState.SystemTime()
	userTime := cmd.ProcessState.UserTime()
	realTime := time.Since(c.startTime)

		"path":                   cmd.Path,
		"args":                   truncateArgsForLogging(cmd.Args, maxLoggedArgsElements),

func (hook *URLSanitizerHook) AddPossibleGrpcMethod(methods ...string) {
	for _, method := range methods {
		hook.possibleGrpcMethods[method] = true
	}
}

// Fire is called by logrus.
func (hook *URLSanitizerHook) Fire(entry *logrus.Entry) error {
	mth, ok := entry.Data["grpc.method"]
	if !ok {
		return nil
	}

	mthStr, ok := mth.(string)
	if !ok || !hook.possibleGrpcMethods[mthStr] {
		return nil
	}

	if _, ok := entry.Data["args"]; ok {
		sanitizeSpawnLog(entry)
	} else if _, ok := entry.Data["error"]; ok {
		sanitizeErrorLog(entry)
	} else {
		entry.Message = sanitizeString(entry.Message)
	}

	return nil
