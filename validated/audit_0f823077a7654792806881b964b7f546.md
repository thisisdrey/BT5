Based on the investigation, Go's standard library `net/http` package already implements robust protections against exactly the directory-traversal primitive described in CVE-2017-16806.

Key defenses found:
- `http.Dir.Open` cleans the path via `path.Clean("/" + name)[1:]` and then validates it through `filepath.Localize`, rejecting any path that can't be safely represented, returning `errInvalidUnsafePath` [1](#0-0) .
- `fileHandler.ServeHTTP` (the `http.FileServer` entry point) applies `path.Clean(upath)` to the incoming `r.URL.Path` before ever calling into the filesystem [2](#0-1) .
- `ServeFile`/`ServeFileFS` additionally reject any request whose `r.URL.Path` contains a `..` path element via `containsDotDot`, specifically to guard callers that unsafely build paths with `filepath.Join` [3](#0-2) [4](#0-3) .
- Test coverage explicitly exercises traversal, null-byte, and encoded-slash attack payloads and confirms they are rejected or normalized rather than escaping the served root [5](#0-4) [6](#0-5) [7](#0-6) .

The single production caller located in this repo, `vcweb`'s `dirHandler`, simply delegates to `http.FileServer(http.Dir(dir))` without introducing its own path handling, so it inherits these protections rather than bypassing them [8](#0-7) .

The CVE's root cause (Ulterius's `HttpServer.cs` `Process` function) is the complete absence of path sanitization/canonicalization before file access. Go's `net/http` file-serving stack does the opposite: it actively cleans, localizes, and rejects unsafe/`..`-containing paths at every entry point identified, so the same bug class does not reproduce here.

func ServeFile(w ResponseWriter, r *Request, name string) {
	if containsDotDot(r.URL.Path) {
		// Too many programs use r.URL.Path to construct the argument to
		// serveFile. Reject the request under the assumption that happened
		// here and ".." may not be wanted.
		// Note that name might not contain "..", for example if code (still
		// incorrectly) used filepath.Join(myDir, r.URL.Path).
		serveError(w, "invalid URL path", StatusBadRequest)
		return
	}
	dir, file := filepath.Split(name)
	serveFile(w, r, Dir(dir), file, false)
}

func containsDotDot(v string) bool {
	if !strings.Contains(v, "..") {
		return false
	}
	for ent := range strings.FieldsFuncSeq(v, isSlashRune) {
		if ent == ".." {
			return true
		}
	}
	return false
}
