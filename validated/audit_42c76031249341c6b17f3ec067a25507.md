### Title
Vesting and Staking Distribution Permanently Frozen by Recipient's `allow_arbitrary_coin_transfers = false` Flag — (`aptos-move/framework/aptos-framework/sources/vesting.move`, `staking_contract.move`)

---

### Summary

`vesting::distribute()` and `staking_contract::distribute_internal()` iterate over all shareholders/recipients and call `aptos_account::deposit_coins()` for each one. If any single recipient has explicitly set `allow_arbitrary_coin_transfers = false` and has not registered a `CoinStore<AptosCoin>`, the call aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`. Because Move transactions are atomic, the entire distribution reverts — permanently freezing all shareholders' APT in the contract until the blocking recipient changes their setting.

---

### Finding Description

`vesting::distribute()` withdraws unlocked APT from the underlying stake pool and distributes it to every shareholder (or their beneficiary) in a single atomic transaction: [1](#0-0) 

Each iteration calls `aptos_account::deposit_coins(recipient_address, share_of_coins)`. Inside that function: [2](#0-1) 

If the recipient account exists but has no `CoinStore<AptosCoin>` registered, the code checks `can_receive_direct_coin_transfers(to)`: [3](#0-2) 

Any account owner can call `set_allow_direct_coin_transfers(account, false)` to set `allow_arbitrary_coin_transfers = false`: [4](#0-3) 

When this flag is `false` and the account has no registered `CoinStore<AptosCoin>`, `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`. Because `vesting::distribute()` processes all shareholders in a single loop with no error isolation, one aborting recipient reverts the entire transaction — including the already-extracted coins, which are returned to the stake pool. The function will abort on every subsequent call as long as the blocking condition persists.

The identical pattern exists in `staking_contract::distribute_internal()`: [5](#0-4) 

The dust-remainder path at line 744 of `vesting.move` and line 914–915 of `staking_contract.move` also call `deposit_coins` on the `withdrawal_address`, creating a second blocking point controlled by whoever owns that address. [6](#0-5) 

---

### Impact Explanation

- **Permanent freeze of all shareholders' APT**: A single shareholder (or their admin-assigned beneficiary, or the `withdrawal_address` owner) can block `distribute()` for every other participant indefinitely.
- **Affected entry points**: `vesting::distribute`, `vesting::distribute_many`, `vesting::terminate_vesting_contract` (which calls `distribute` internally), `vesting::admin_withdraw` (calls `withdraw_stake` → `staking_contract::distribute`), `staking_contract::distribute`, and `staking_contract::unlock_stake`.
- **No privileged assumption required**: Any shareholder can call `set_allow_direct_coin_transfers(self, false)` unprivileged, then simply not register for `AptosCoin`. This is a fully unprivileged, on-chain, mainnet-reachable trigger.
- **Funds are not lost but are inaccessible**: The APT remains in the stake pool but cannot be withdrawn by any party as long as the blocking condition holds.

---

### Likelihood Explanation

- The `set_allow_direct_coin_transfers` entry function is publicly callable by any account owner with no restrictions.
- A shareholder who wants to grief other shareholders (e.g., a competitor or a disgruntled participant) can trivially trigger this.
- The condition can also arise accidentally: a beneficiary address set by the admin may belong to an account that has opted out of direct transfers or has never registered for `AptosCoin` (e.g., a multisig or resource account with custom configuration).
- Because `vesting::distribute` is also called inside `terminate_vesting_contract`, even the admin's ability to terminate and recover funds is blocked.

---

### Recommendation

Replace the all-or-nothing loop with a pattern that isolates per-recipient failures:

1. **Skip-and-accumulate**: Catch the abort condition before calling `deposit_coins` by checking `can_receive_direct_coin_transfers` and `coin::is_account_registered<AptosCoin>` upfront. If a recipient would fail, leave their share in a claimable escrow keyed by their address rather than aborting the whole distribution.

2. **Use `aptos_account::deposit_coins` only for APT via the FA path**: The `fungible_transfer_only` / `unchecked_deposit` path used for APT in `aptos_account::transfer` bypasses the `DirectTransferConfig` check entirely. Vesting and staking distributions of APT should use the FA-native path (`primary_fungible_store::deposit`) rather than the legacy `Coin<AptosCoin>` path, since APT's primary fungible store cannot be opted out of in the same way.

3. **Separate dust distribution**: The `withdrawal_address` dust send (lines 743–744 of `vesting.move`) should be guarded independently so a bad `withdrawal_address` does not block shareholder payouts.

---

### Proof of Concept

1. Alice and Bob are shareholders in a vesting contract. Carol is the `withdrawal_address`.
2. Bob calls `aptos_account::set_allow_direct_coin_transfers(bob_signer, false)` and ensures he has no `CoinStore<AptosCoin>` (e.g., he only has the FA-based APT store, not the legacy coin store).
3. The lockup period expires. Alice calls `vesting::distribute(contract_address)`.
4. The loop reaches Bob's entry: `aptos_account::deposit_coins(bob_address, bob_share)` → `can_receive_direct_coin_transfers(bob_address)` returns `false` → abort with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`.
5. The entire transaction reverts. Alice receives nothing. The coins return to the stake pool.
6. Every subsequent call to `distribute()` aborts identically. Alice's APT is permanently inaccessible until Bob re-enables direct transfers — which Bob has no incentive to do. [7](#0-6) [8](#0-7) [9](#0-8)

    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
