### Title
Interest-fee shares minted to treasury before bad-debt is known are never clawed back when debt is socialized - (File: `mainnet/contracts/vault/v0-vault-ststxbtc.clar` and sibling vault contracts)

### Summary
Every vault's `accrue` function mints `fee-reserve`-based treasury LP shares against the *entire* pool-wide interest delta (`debt-delta`) immediately, before any borrower's individual position health is evaluated. When a borrower's debt later becomes unrecoverable and is written off via `socialize-debt`, only `principal-scaled`, `total-borrowed`, and `lindex` are adjusted — the `treasury-lp` shares that were already minted for the (now-uncollectible) interest portion of that debt are never reversed. This is the same root cause as the referenced Overlay report: a fee/reward is recorded against notional/interest before the corresponding debt is confirmed collectible, and is not corrected once the shortfall becomes known.

### Finding Description
In `accrue()`, the vault computes the global interest accrued since the last update and immediately mints treasury shares for the reserve cut: [1](#0-0) 

`debt-delta` is derived purely from the growth of the global scaled-principal index — it has no visibility into whether any individual borrower behind that debt is still solvent. `reserve-inc` (the fee-reserve cut of that interest) is converted into `treasury-lp` shares and minted to `.dao-treasury` unconditionally on essentially every vault interaction (`deposit`, `redeem`, `system-borrow`, `system-repay` all call `accrue` first).

Later, when a borrower's position is liquidated and found to have no remaining collateral, the market contract writes off the residual debt through `socialize-debt-asset`, which calls into the vault's `socialize-debt`: [2](#0-1) 

`socialize-debt` reduces `principal-scaled`, `total-borrowed`, and writes down `lindex` proportionally to the loss, but it does not — and cannot, since it has no reference to which prior `accrue()` calls minted fees against this now-bad debt — claw back the `treasury-lp` shares minted earlier: [3](#0-2) 

This mirrors the Overlay finding precisely: `_feeAmount` (there) / `treasury-lp` (here) is computed and disbursed against the full notional/interest *before* checking whether that value is actually going to be realized (position health / debt collectibility), and no correction is applied once the position is confirmed underwater and its debt is socialized away.

### Impact Explanation
The treasury receives permanent, non-reversible LP share dilution credit for interest that regular depositors never actually receive (the debt was written off). Depositors' shares are diluted by shares minted against yield that was never collected, while their principal loss from the bad debt is charged via the `lindex` markdown. This constitutes theft/permanent freezing of unclaimed yield from ordinary depositors, redirected as an unearned windfall to the treasury — an in-scope High-severity impact (theft of unclaimed yield / permanent loss of value to depositors of the vault).

### Likelihood Explanation
This requires no privileged action and no DAO compromise. It occurs naturally any time a borrower's position accrues interest for some period before becoming undercollateralized and is subsequently liquidated with insufficient collateral to cover accrued interest (a normal, expected liquidation outcome caused by price movement or accrual over time), triggering `bad-debt-socialized` in `liquidate()`: [4](#0-3) 
Given interest continuously accrues and liquidations of undercollateralized positions are a routine part of protocol operation, this is a high-likelihood, systemically recurring issue rather than an edge case.

### Recommendation
Do not mint `treasury-lp` fee shares against interest that has not yet been confirmed collectible, or defer/clawback the fee-reserve mint for debt that is later socialized. Concretely: track the fee-reserve portion of interest per position (or defer realization of `reserve-inc` until repayment actually occurs), and when `socialize-debt` writes off debt, proportionally burn/void the previously minted `treasury-lp` shares that correspond to the uncollectible interest portion, analogous to adjusting `_feeAmount` only against the recoverable value as recommended in the referenced report.

### Proof of Concept
1. Borrower opens a position and borrows from a vault (e.g., `v0-vault-ststxbtc`).
2. Time passes; each block/tx that touches the vault calls `accrue`, which mints `treasury-lp` against accrued interest on the borrower's growing debt, even as the position drifts underwater due to price movement.
3. A liquidator calls `market.liquidate(...)`, and the position's collateral is fully exhausted before covering accrued interest; `no-collateral-left` is true and `socialize-debt-asset`/vault `socialize-debt` is invoked to write off the remaining scaled debt.
4. Inspect vault state: `treasury-lp` shares minted to `.dao-treasury` throughout step 2 for the interest that has now been socialized are still held by treasury and were never reduced, while `lindex` was written down to spread the loss across all depositor shares — depositors bear the full loss while treasury retains fee shares for interest that was never actually paid.

(define-public (socialize-debt (scaled-amount uint))
  (let ((scaled-principal (var-get principal-scaled))
        (borrowed (var-get total-borrowed))
        (idx (var-get index))
        (current-assets (var-get assets))
        (current-lindex (var-get lindex))
        (old-total-assets (total-assets))
        (debt-reduction (mul-div-down scaled-amount idx INDEX-PRECISION))
        (principal-reduction (if (> scaled-principal u0)
                                (mul-div-down scaled-amount borrowed scaled-principal)
                                u0))
        ;; Write down lindex proportionally to loss in total-assets
        (new-lindex (if (and (> old-total-assets u0) (> old-total-assets debt-reduction))
                       (mul-div-down current-lindex (- old-total-assets debt-reduction) old-total-assets)
                       u0)))

    (try! (check-caller-auth))
    (asserts! (> scaled-amount u0) ERR-AMOUNT-ZERO)

    (var-set lindex new-lindex)
    (var-set principal-scaled (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0))
    (var-set total-borrowed (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0))
    (var-set assets (if (> current-assets principal-reduction) (- current-assets principal-reduction) u0))

    (print {
      action: "socialize-debt",
      caller: contract-caller,
      data: {
        scaled-amount: scaled-amount,
        debt-reduction: debt-reduction,
        principal-reduction: principal-reduction,
        old-lindex: current-lindex,
        new-lindex: new-lindex,
        old-total-assets: old-total-assets,
        principal-scaled: (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0),
        total-borrowed: (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0),
        index: idx
      }
    })

    (ok true)))

(define-private (socialize-debt-asset
                (debt-entry { aid: uint, scaled: uint })
                (acc { borrower: principal, success: bool }))
  ;; Early return if previous socialization failed
  (if (not (get success acc))
      acc
      (let ((borrower (get borrower acc))
            (failed-status { borrower: borrower, success: false })
            (asset-id (get aid debt-entry))
            (scaled-debt (get scaled debt-entry)))

            ;; Socialize in vault - pass scaled directly to avoid rounding
            (unwrap! (vault-socialize-debt asset-id scaled-debt) failed-status)
            ;; Refresh cache with new indexes post-write-down (lindex decreased)
            (map-set index-cache
                     { timestamp: stacks-block-time, aid: asset-id }
                     (unwrap! (vault-accrue asset-id) failed-status))
            ;; Remove from obligation
            (unwrap! (contract-call? .v0-market-vault
                                      debt-remove-scaled
                                      borrower
                                      scaled-debt
                                      asset-id) failed-status)
          acc)
        ))
