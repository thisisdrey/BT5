### Title
Missing size/length bounds in V1 certificate unmarshalling allows unauthenticated remote CPU/memory amplification during handshake processing - (File: cert/cert_v1.go)

### Summary
`unmarshalCertificateV1` (used by `cert.Recombine` for `VersionPre1`/`Version1` certs) performs a bare `proto.Unmarshal` of attacker-controlled bytes with **no size limit on the overall certificate, no limit on the `Name` string length, and no limit on the number of `Groups`/`Ips`/`Subnets` entries**, unlike the `Version2` path (`unmarshalCertificateV2`/`unmarshalDetails`) which explicitly enforces `MaxCertificateSize`, `MaxNameLength`, and `MaxNetworkLength` on every field. This mirrors the reported bug class: unbounded attacker-controlled data length accepted during a pre-verification parsing step, which is then processed multiple times downstream, causing disproportionate resource consumption relative to the attacker's cost.

### Finding Description
The handshake payload carries a raw certificate blob in the protobuf `Cert` field, decoded by `UnmarshalPayload`/`unmarshalPayloadDetails` without any length cap on that field [1](#0-0) . That blob is handed to `cert.Recombine`, which for V1 certs calls `unmarshalCertificateV1(b, publicKey)` [2](#0-1) .

`unmarshalCertificateV1` unconditionally `proto.Unmarshal`s the bytes into `RawNebulaCertificate` and then builds `groups`, `networks`, and `unsafeNetworks` slices sized to whatever counts the attacker supplied, with no cap on the number of entries or on `rc.Details.Name` length, before calling `validate()`: [3](#0-2) . `validate()` itself then iterates over every network/unsafe-network entry [4](#0-3) , so the CPU cost of a single handshake packet scales linearly (or worse, given repeated iteration and copying in `Copy()` [5](#0-4) ) with attacker-controlled counts.

By contrast, the V2 path explicitly bounds every one of these dimensions before doing any further work: [6](#0-5) [7](#0-6) [8](#0-7) [9](#0-8) , confirming the V1 path is the outlier missing these guards.

This is reachable pre-authentication: `beginHandshake` builds a fresh responder `Machine` for any inbound handshake packet and calls `machine.ProcessPacket`, which in turn calls `validateCert` → `cert.Recombine` **before** the certificate is checked against the CA pool or the verifier callback is invoked [10](#0-9) [11](#0-10) . No CA-signed certificate is required from the attacker to reach this parsing code — the attacker is the one supplying the (unverified, self-crafted) certificate bytes.

### Impact Explanation
Each inbound UDP handshake packet is bounded by UDP's practical packet-size ceiling (~64 KB), which limits the achievable amplification compared to the original report's ~1.3 MB payload scenario used to approach the block-gas-limit. Within that ~64 KB budget, an attacker can still pack many thousands of small `Groups`/`Ips`/`Subnets` protobuf entries (or a large `Name`) with zero validation, forcing the responder to allocate multiple slices, copy data, and iterate over every entry in `validate()` for every spoofed handshake packet it sends — with no per-field cost to the attacker beyond crafting the bytes once and replaying it. This is a resource-asymmetry / CPU-amplification issue on the unauthenticated handshake-processing path, not a full crash or memory-exhaustion primitive given the UDP size cap, so the severity is bounded relative to the original finding's more severe (block-gas-limit-reaching) scenario.

### Likelihood Explanation
High reachability: any unauthenticated peer can send a single handshake packet (stage 0) to trigger `beginHandshake` → `ProcessPacket` → `validateCert` → `cert.Recombine` → `unmarshalCertificateV1`, with no prior trust relationship or valid CA-signed certificate required. The attack can be repeated/amplified with a flood of crafted packets at negligible attacker cost, since crafting the oversized-but-valid-shaped protobuf blob is cheap (no cryptographic operation required to reach the parsing/validation loop).

### Recommendation
Add the same defensive bounds to the V1 certificate path that already exist for V2: enforce an overall `MaxCertificateSize` check on the raw bytes before `proto.Unmarshal`, and cap `len(rc.Details.Name)`, `len(rc.Details.Groups)`, `len(rc.Details.Ips)`, and `len(rc.Details.Subnets)` in `unmarshalCertificateV1` prior to allocating and iterating over the corresponding slices in `validate()`.

### Proof of Concept
1. Craft a `NebulaHandshakeDetails`-wrapped payload whose `Cert` field is a `RawNebulaCertificate` protobuf message containing a valid-looking `PublicKey`/`Signature` placeholder but with `Details.Groups` (or `Ips`/`Subnets`) populated with tens of thousands of short repeated entries, filling the packet up to the UDP size limit (~64 KB).
2. Send this as the stage-0 handshake packet to a nebula node that has never seen this index before.
3. Observe `beginHandshake` → `machine.ProcessPacket` → `validateCert` → `cert.Recombine` → `unmarshalCertificateV1` allocate and iterate `len(Groups)+len(Networks)+len(UnsafeNetworks)` entries in `validate()` before the certificate signature/CA check ever fails, at negligible cost to the sender relative to the CPU/allocation work performed by the responder.
4. Repeat with a flood of packets from spoofed/varying indices to amplify total CPU consumed by the target node, since no proof-of-work or size limit gates the parsing step.

	// Empty names are allowed

	if len(c.details.publicKey) == 0 {
		return ErrInvalidPublicKey
	}

	// Original v1 rules allowed multiple networks to be present but ignored all but the first one.
	// Continue to allow this behavior
	if !c.details.isCA && len(c.details.networks) == 0 {
		return NewErrInvalidCertificateProperties("non-CA certificates must contain exactly one network")
	}

	for _, network := range c.details.networks {
		if !network.IsValid() || !network.Addr().IsValid() {
			return NewErrInvalidCertificateProperties("invalid network: %s", network)
		}

		if network.Addr().Is6() {
			return NewErrInvalidCertificateProperties("certificate may not contain IPv6 networks: %v", network)
		}

		if network.Addr().IsUnspecified() {
			return NewErrInvalidCertificateProperties("non-CA certificates must not use the zero address as a network: %s", network)
		}

		if network.Addr().Zone() != "" {
			return NewErrInvalidCertificateProperties("networks may not contain zones: %s", network)
		}
	}

			return NewErrInvalidCertificateProperties("invalid unsafe network: %s", network)

		}

			return NewErrInvalidCertificateProperties("unsafe networks may not contain zones: %s", network)

// unmarshalCertificateV1 will unmarshal a protobuf byte representation of a nebula cert
// if the publicKey is provided here then it is not required to be present in `b`
func unmarshalCertificateV1(b []byte, publicKey []byte) (*certificateV1, error) {
	if len(b) == 0 {
		return nil, fmt.Errorf("nil byte array")
	}
	var rc RawNebulaCertificate
	err := proto.Unmarshal(b, &rc)
	if err != nil {
		return nil, err
	}

	if rc.Details == nil {
		return nil, fmt.Errorf("encoded Details was nil")
	}

	if len(rc.Details.Ips)%2 != 0 {
		return nil, fmt.Errorf("encoded IPs should be in pairs, an odd number was found")
	}

	if len(rc.Details.Subnets)%2 != 0 {
		return nil, fmt.Errorf("encoded Subnets should be in pairs, an odd number was found")
	}

	nc := certificateV1{
		details: detailsV1{
			name:           rc.Details.Name,
			groups:         make([]string, len(rc.Details.Groups)),
			networks:       make([]netip.Prefix, len(rc.Details.Ips)/2),
			unsafeNetworks: make([]netip.Prefix, len(rc.Details.Subnets)/2),
			notBefore:      time.Unix(rc.Details.NotBefore, 0),
			notAfter:       time.Unix(rc.Details.NotAfter, 0),
			publicKey:      nil,
			isCA:           rc.Details.IsCA,
			curve:          rc.Details.Curve,
		},
		signature: make([]byte, len(rc.Signature)),
	}

	copy(nc.signature, rc.Signature)
	copy(nc.details.groups, rc.Details.Groups)
	nc.details.issuer = hex.EncodeToString(rc.Details.Issuer)

	// If a public key is passed in as an argument, the certificate pubkey must be empty
	// and the passed-in pubkey copied into the cert.
	if len(publicKey) > 0 {
		if len(rc.Details.PublicKey) != 0 {
			return nil, ErrCertPubkeyPresent
		}
		nc.details.publicKey = make([]byte, len(publicKey))
		copy(nc.details.publicKey, publicKey)
	} else {
		nc.details.publicKey = make([]byte, len(rc.Details.PublicKey))
		copy(nc.details.publicKey, rc.Details.PublicKey)
	}

func (m *Machine) validateCert(payload Payload) error {
	cred := m.getCred(m.myVersion)
	if cred == nil {
		m.failed = true
		return fmt.Errorf("%w: %v", ErrNoCredential, m.myVersion)
	}
	rc, err := cert.Recombine(
		cert.Version(payload.CertVersion),
		payload.Cert,
		m.hs.PeerStatic(),
		cred.Cert.Curve(),
	)
	if err != nil {
		m.failed = true
		return fmt.Errorf("recombine cert: %w", err)
	}

	if !bytes.Equal(rc.PublicKey(), m.hs.PeerStatic()) {
		m.failed = true
		return ErrPublicKeyMismatch
	}

	// Version negotiation, if the peer sent a different version and we have it, switch
	if rc.Version() != m.myVersion {
		if m.getCred(rc.Version()) != nil {
			m.myVersion = rc.Version()
		}
	}

	verified, err := m.verifier(rc)
	if err != nil {
		m.failed = true
		return fmt.Errorf("verify cert: %w", err)
	}

	m.result.RemoteCert = verified
	m.remoteCertSet = true
	return nil
