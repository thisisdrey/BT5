### Title
Unauthenticated event-observer HTTP endpoint allows forged `BlockValidateResponse`/`SignerEvent` injection - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver` binds a plain `tiny_http::HttpServer` and dispatches any POST to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block` straight into `process_event`, which only reads the body and JSON-deserializes it — there is no shared secret, signature, or peer-address check anywhere in `next_event`/`process_event`. Any TCP client that can reach the bound port can therefore forge a `BlockValidateResponse` and have it forwarded as `SignerEvent::BlockValidationResponse` to the signer runloop as if the locally configured node had validated it.

### Finding Description
The broken equality is: the runloop treats `SignerEvent::BlockValidationResponse` as "what my locally configured stacks-node validated," but the actual guarantee provided by the code is only "whatever bytes arrived on this TCP port." Tracing the path:

- `SignerEventReceiver::bind` (`libsigner/src/events.rs:404-408`) just calls `HttpServer::http(listener)` — no TLS, no auth token, no allow-list of source IPs.
- `next_event` (`libsigner/src/events.rs:413-459`) accepts any connection, checks only the URL path and HTTP method, then routes to `process_event::<T, BlockValidateResponse>(request)` for `/proposal_response` (`libsigner/src/events.rs:439-440`), with equivalent handling for `/stackerdb_chunks`, `/new_burn_block`, `/new_block`.
- `process_event` (`libsigner/src/events.rs:519-542`) reads the raw body, `serde_json::from_slice` into `E` (e.g. `BlockValidateResponse`), then calls `.try_into()` to build a `SignerEvent<T>`. There is no signature check, no HMAC/shared-secret header check, and no check of `request.remote_addr()` anywhere in this function or its callers.
- `TryFrom<BlockValidateResponse> for SignerEvent<T>` (`libsigner/src/events.rs:627-635`) unconditionally wraps the deserialized JSON into `SignerEvent::BlockValidationResponse(block_validate_response)`.
- `forward_event` (`libsigner/src/events.rs:469-490`) sends this event, unmodified, over an `mpsc::Sender` to the signer runloop, where (per `docs/signer-flows.md` section 4, `handle_block_validate_response` in `stacks-signer/src/v0/signer.rs`) an `Ok` verdict causes the signer to mark the block pre-committed and broadcast a pre-commit/signature vote.

No guard in this file (or in `SignerEventReceiver`) restricts who may connect to this HTTP server or verifies that the JSON body actually originated from the node process the signer is configured to trust. The only mitigation the code performs is deserialization-shape validation (JSON parsing correctness), not origin authentication.

### Impact Explanation
A remote, unprivileged attacker able to reach the signer's event-receiver port can inject arbitrary `BlockValidateResponse` payloads that the signer runloop treats identically to a genuine validation result from its own configured stacks-node. Depending on the content forged, this can push the signer toward pre-committing/signing (via `handle_block_validate_ok`) or force spurious rejections (via `handle_block_validate_reject`), both of which are downstream, consensus-adjacent decisions folded into the signer's global state machine. Similarly, forged `/stackerdb_chunks`, `/new_burn_block`, `/new_block` POSTs are accepted unauthenticated and forwarded as trusted events. This is repeatable per TCP connection and matches "unauthenticated/unauthorized write to state" — here, forged writes into the signer's internal decision-driving event stream.

### Likelihood Explanation
Preconditions: the attacker needs only network reachability to the port the operator configured for the event observer (`bind`) — no secret, no valid StackerDB slot key, no P2P handshake. The attack requires no privileged role and is trivially repeatable (each POST is an independent forgery attempt). This makes the likelihood high wherever the event-observer endpoint is exposed beyond localhost/a private network — which is an operator/deployment choice, not something enforced or checked in this code path.

### Recommendation
Add authentication to the event-observer HTTP server: require a shared secret/bearer token (checked in `next_event`/`process_event` before deserializing), and/or bind by default to a loopback-only address with an explicit opt-in and warning for exposing it more broadly. Reject requests lacking a valid token before performing any deserialization work.

### Proof of Concept
Rust test plan (net-level):
1. Start a `SignerEventReceiver` bound to `127.0.0.1:0` via `bind()`, call `add_consumer` to attach an `mpsc::channel` receiver, and start `main_loop` in a thread.
2. From a plain `std::net::TcpStream` (or `reqwest`) acting as an unprivileged remote client, craft a valid JSON body for `BlockValidateResponse::Ok(..)` (or `::Reject(..)`) and POST it to `http://<bound_addr>/proposal_response` with no auth headers.
3. Assert that the consumer channel receives `SignerEvent::BlockValidationResponse(..)` matching the forged content — demonstrating the event receiver accepted and forwarded it with no origin check.
4. Assertion/crash site: the lack of any early-return/auth-check inside `process_event` at `libsigner/src/events.rs:519-542` before `serde_json::from_slice` and `.try_into()`. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3)

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {

                debug!(

                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
