Found a concrete analog: `extractBytesArray` / `extractSigArray` in `PrecompiledContracts.java` compute a byte offset into the raw calldata (`bytesOffset + offset + 2) * WORD_SIZE`) that is bounds-checked only loosely (or not at all against `data.length`) before doing an unchecked `Arrays.copyOfRange`, mirroring the kernel bug's pattern of computing an offset for a chunk but only validating a prefix/partial bound before reading past the real allocation.

### Title
Unbounded offset computation in `ValidateMultiSign`/`BatchValidateSign` precompiles leads to out-of-bounds read of calldata - ([File: actuator/src/main/java/org/tron/core/vm/PrecompiledContracts.java])

### Summary
`extractBytesArray`, `extractSigArray`, and `extractBytes32Array` in `PrecompiledContracts.java` compute byte offsets from attacker-controlled `DataWord` values taken directly out of the raw precompile calldata, then read from the underlying `rawData`/`data` array via `Arrays.copyOfRange` without validating the computed offset/length against the actual array bounds. [1](#0-0) 

### Finding Description
`extractBytesArray(words, offset, data)` reads `len = words[offset].intValueSafe()`, then for each `i` computes `bytesOffset = words[offset + i + 1].intValueSafe() / WORD_SIZE` and `bytesLen = words[offset + bytesOffset + 1].intValueSafe()`, and finally calls `extractBytes(data, (bytesOffset + offset + 2) * WORD_SIZE, bytesLen)`, which does an unchecked `Arrays.copyOfRange(data, offset, offset + len)`. [1](#0-0) 

This is structurally the same bug class as the reported kernel `keyring_get_key_chunk()` issue: an offset is derived by combining several attacker-influenced fields (here, `words[...]` values interpreted as word-offsets and lengths), and only a narrow/partial check (`offset > words.length - 1`, or the `MAX_SIZE`/ABI-shape checks gated behind `allowTvmSelfdestructRestriction()`/`allowTvmOsaka()`) is performed before the actual byte-level read — the full computed byte range (`(bytesOffset + offset + 2) * WORD_SIZE` .. `+ bytesLen`) is never checked against `data.length`. `extractSigArray` has the same pattern but with a fixed `SIG_LENGTH` instead of an attacker length. [2](#0-1) 

The `words` array itself is built by `DataWord.parseArray(rawData)`, which only contains as many `DataWord`s as fit exactly in 32-byte chunks of `rawData`; if `bytesOffset` or `offset` computed from attacker data indexes past `words.length`, `words[...]` accesses throw `ArrayIndexOutOfBoundsException` (caught in `ValidateMultiSign.execute` inside its try/catch around the loop, but the array-index accesses for `words[offset]`, `words[offset+i+1]` etc. happen *before* entering that try block in some call paths), and if the derived byte offset into `data`/`rawData` overruns the backing array in `Arrays.copyOfRange`, that throws too. Whether this is only an uncaught-exception DoS or a genuine info leak depends on whether `Arrays.copyOfRange` clamps (it does throw `ArrayIndexOutOfBoundsException`/`NegativeArraySizeException` rather than silently over-reading), so the primary confirmed impact is an unhandled runtime exception during precompile execution triggered entirely by unprivileged, attacker-supplied smart-contract calldata to `ValidateMultiSign`/`BatchValidateSign`. [3](#0-2) [4](#0-3) 

### Impact Explanation
An uncaught exception thrown deep inside energy-metered TVM precompile execution (from malformed offset math rather than a validated failure path) can propagate in unexpected ways through the VM's exception handling, and unlike the standard `Program.Exception` paths, this is not a modeled/expected VM failure. In `BatchValidateSign.execute`, the outer `doExecute` call is wrapped in try/catch that returns a zero result for any `Throwable`, limiting impact there to energy waste; however `ValidateMultiSign.execute` performs `words[0]`, `words[1]`, `words[2]`, and the `sigArraySize`/`extractBytesArray`/`extractSigArray` calls (which include the vulnerable indexing) entirely outside of any try/catch, so a crafted calldata length/offset combination that causes an `ArrayIndexOutOfBoundsException` in these lines is uncaught by the actuator, and depending on how `Program`/`Runtime` handle unchecked exceptions from precompiled contracts, this can abort transaction execution abnormally or crash the node process executing the block, which is a denial-of-service against the node. [5](#0-4) 

### Likelihood Explanation
Reachable by any unprivileged account through a plain smart-contract call that invokes the `validatemultisign` or `batchvalidatesign` TVM precompile (address 0x100...09/0x100...08-style precompiles) with crafted `bytes[]` payloads; no special permission or SR/witness status is required — only a `TriggerSmartContract` transaction with attacker-chosen ABI-encoded input. [6](#0-5) 

### Recommendation
Bound-check every computed byte offset and length against `data.length`/`rawData.length` (and every `words[idx]` access against `words.length`) before calling `Arrays.copyOfRange` in `extractBytesArray`, `extractSigArray`, and `extractBytes32Array`, returning a failure result instead of throwing when the computed range is invalid. Also wrap the initial `words[0]`/`words[1]`/`words[2]` and array-size lookups in `ValidateMultiSign.execute` in the same try/catch that already guards the rest of the method, or add an explicit length check on `words.length` before any indexing.

### Proof of Concept
Send a `TriggerSmartContract` transaction that calls the `validatemultisign(address,uint256,bytes32,bytes[])` precompile with ABI-encoded input where the dynamic-array head word (index `3`) encodes an offset such that `words[3].intValueSafe() / WORD_SIZE` plus the header size exceeds `words.length`, or where an inner signature-array length/offset entry (`words[offset + i + 1]`) is set to a huge value causing `(bytesOffset + offset + 2) * WORD_SIZE` in `extractBytes`/`extractSigArray` to exceed `rawData.length`; this drives `words[...]` indexing or `Arrays.copyOfRange(data, offset, offset+len)` out of bounds and raises an uncaught `ArrayIndexOutOfBoundsException`/`NegativeArraySizeException` inside `ValidateMultiSign.execute`, outside its inner try/catch. [5](#0-4)

  private static byte[][] extractBytesArray(DataWord[] words, int offset, byte[] data) {
    if (offset > words.length - 1) {
      return new byte[0][];
    }
    int len = words[offset].intValueSafe();
    byte[][] bytesArray = new byte[len][];
    for (int i = 0; i < len; i++) {
      int bytesOffset = words[offset + i + 1].intValueSafe() / WORD_SIZE;
      int bytesLen = words[offset + bytesOffset + 1].intValueSafe();
      bytesArray[i] = extractBytes(data, (bytesOffset + offset + 2) * WORD_SIZE,
          bytesLen);
    }
    return bytesArray;
  }

  private static byte[][] extractSigArray(DataWord[] words, int offset, byte[] data) {
    if (offset > words.length - 1) {
      return new byte[0][];
    }
    int len = words[offset].intValueSafe();
    byte[][] bytesArray = new byte[len][];
    for (int i = 0; i < len; i++) {
      int bytesOffset = words[offset + i + 1].intValueSafe() / WORD_SIZE;
      bytesArray[i] = extractBytes(data, (bytesOffset + offset + 2) * WORD_SIZE,
          SIG_LENGTH);
    }
    return bytesArray;
  }

  private static byte[] extractBytes(byte[] data, int offset, int len) {
    return Arrays.copyOfRange(data, offset, offset + len);
  }

    private static final int ENGERYPERSIGN = 1500;
    private static final int MAX_SIZE = 5;
    private static final int ABI_HEADER_WORDS = 5;
    private static final int ABI_ITEM_WORDS = 5;


    @Override
    public long getEnergyForData(byte[] data) {
      long cnt = (data.length / WORD_SIZE - 5) / 5;
      // one sign 1500, half of ecrecover
      return cnt * ENGERYPERSIGN;
    }

    @Override
    public Pair<Boolean, byte[]> execute(byte[] rawData) {
      if (VMConfig.allowTvmOsaka()
          && !isValidAbiEncoding(rawData, ABI_HEADER_WORDS, ABI_ITEM_WORDS)) {
        return Pair.of(false, EMPTY_BYTE_ARRAY);
      }
      DataWord[] words = DataWord.parseArray(rawData);
      byte[] address = words[0].toTronAddress();
      int permissionId = words[1].intValueSafe();
      byte[] data = words[2].getData();

      byte[] combine = ByteUtil.merge(address, ByteArray.fromInt(permissionId), data);
      byte[] hash = Sha256Hash.hash(CommonParameter
          .getInstance().isECKeyCryptoEngine(), combine);

      if (VMConfig.allowTvmSelfdestructRestriction()) {
        int sigArraySize = words[words[3].intValueSafe() / WORD_SIZE].intValueSafe();
        if (sigArraySize > MAX_SIZE) {
          return Pair.of(true, DATA_FALSE);
        }
      }
      byte[][] signatures = VMConfig.allowTvmSelfdestructRestriction() ?
          extractSigArray(words, words[3].intValueSafe() / WORD_SIZE, rawData) :
          extractBytesArray(words, words[3].intValueSafe() / WORD_SIZE, rawData);

      if (signatures.length == 0 || signatures.length > MAX_SIZE) {
        return Pair.of(true, DATA_FALSE);
      }

      AccountCapsule account = this.getDeposit().getAccount(address);
      if (account != null) {
        try {
          Permission permission = account.getPermissionById(permissionId);
          if (permission != null) {
            //calculate weight
            long totalWeight = 0L;
            List<byte[]> executedSignList = new ArrayList<>();
            for (byte[] sign : signatures) {
              byte[] recoveredAddr = recoverAddrBySign(sign, hash);

              sign = merge(recoveredAddr, sign);
              if (ByteArray.matrixContains(executedSignList, recoveredAddr)) {
                if (ByteArray.matrixContains(executedSignList, sign)) {
                  continue;
                }
                MUtil.checkCPUTime();
              }
              long weight = TransactionCapsule.getWeight(permission, recoveredAddr);
              if (weight == 0) {
                //incorrect sign
                return Pair.of(true, DATA_FALSE);
              }
              totalWeight += weight;
              executedSignList.add(sign);
              executedSignList.add(recoveredAddr);
            }

            if (totalWeight >= permission.getThreshold()) {
              return Pair.of(true, dataOne());
            }
          }
        } catch (Throwable t) {
          if (t instanceof OutOfTimeException) {
            throw t;
          }
          logger.info("ValidateMultiSign error:{}", t.getMessage());
        }
      }
      return Pair.of(true, DATA_FALSE);
    }
  }
