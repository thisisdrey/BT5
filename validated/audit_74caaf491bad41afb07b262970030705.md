### Title
`os.Root` sandbox on `js/wasm` and `plan9` is bypassable via TOCTOU symlink race in `checkPathEscapes` - ([File: src/os/root_js.go])

### Summary
Go's `os.Root` API (`OpenRoot`, `Root.Open`, `Root.OpenFile`, etc.) is intended to sandbox filesystem access such that no operation can escape the designated root directory, analogous to Wasmer's `--dir` preopen sandbox. On platforms lacking `openat` (`js/wasm` and `plan9`), this containment is implemented purely by lexically resolving symlinks with separate `Lstat`/`Readlink` calls followed by a later `Open`/`Stat` on the resolved path, rather than atomically resolving and opening relative to a directory file descriptor as on Unix/Windows. This check-then-use gap is explicitly acknowledged in the source and allows a symlink swapped in between the check and the actual open to redirect the operation outside the root, mirroring the class of bug in GHSA-4mq4-7rw3-vm5j where WASI filesystem confinement (preopened directories) failed to prevent access outside the sandbox.

### Finding Description
On `js/wasm` and `plan9`, `Root.OpenFile`/`Root.Open`/`Root.OpenRoot`/`Root.Stat` etc. dispatch to `rootOpenFileNolog` / `openRootInRoot` / `rootStat` in `src/os/root_noopenat.go`, which call `checkPathEscapes(r, name)` (in `src/os/root_js.go`, function `checkPathEscapesInternal`) before performing the real operation with plain `Open`/`Stat` on a joined path string [1](#0-0) . `checkPathEscapesInternal` walks each path component and calls `Lstat`, and for a symlink component calls `Readlink` to resolve it, rejecting paths whose `..` segments would climb above the root [2](#0-1) . The function's own doc comment states: "Due to the lack of openat, checkPathEscapes is subject to TOCTOU races when symlinks change during the resolution process." [3](#0-2) . After the check passes, `rootOpenFileNolog` performs the actual `openFileNolog(joinPath(r.root.name, name), flag, perm)` as a completely separate operation with no way to bind it to the previously-validated path/inode [1](#0-0) . If an attacker (e.g., a victim workflow extracting/serving files from an untrusted, attacker-controlled directory tree that is then opened through `os.Root` on `js/wasm` or `plan9`) can race a symlink swap between the `Lstat`/`Readlink` validation and the subsequent `Open`, the final open resolves outside the root directory, defeating the sandbox — the same fundamental primitive as the Wasmer advisory (filesystem confinement bypass), just realized as a TOCTOU race instead of a missing-check bypass.

### Impact Explanation
A successful race lets code using `os.Root` for sandboxing (its explicitly documented purpose — safely operating on files "which may be controlled by an attacker") read or write files outside the intended root directory on `js/wasm`/`plan9`, i.e., unexpected file read/write outside the sandbox — a material file write / information disclosure impact matching CWE-284 (Improper Access Control). This would be a Go PUBLIC-track report since it undermines a security-relevant API's core guarantee, though its severity is tempered by requiring a race window and being limited to the `js/wasm` and `plan9` GOOS targets specifically because they lack `openat`.

### Likelihood Explanation
The victim workflow is any Go program that uses `os.Root`/`OpenInRoot` to sandbox access into an untrusted directory tree (the documented use case) while compiled for `js/wasm` or `plan9`. The attacker needs the ability to modify the directory tree concurrently with the victim's `os.Root` operations (e.g., a concurrently-writable shared directory, or a directory populated from an archive/mount an attacker partially controls) to swap a regular file/directory for a symlink between the `Lstat` check and the final `Open`. This is a real but narrower-likelihood race condition, not a deterministic single-request bypass, and it is already flagged as a known limitation in the code's own comments rather than a silent, undocumented failure.

### Recommendation
For `js/wasm` and `plan9`, either (a) document the TOCTOU limitation prominently in the public `os.Root` API documentation (not just internal comments) and treat these platforms as providing weaker sandboxing guarantees, or (b) reduce the race window by re-validating containment immediately before use and using single-shot syscalls where any target platform APIs allow atomic "resolve+open without following unexpected redirection" semantics; longer term, track upstream `openat`-equivalent support for `wasip1`/`js` runtimes to eliminate the separate check-then-open pattern entirely.

### Proof of Concept
```go
//go:build js && wasm

package os_test

import (
	"os"
	"testing"
)

// Demonstrates that Root confinement on js/wasm relies on a
// check-then-open pattern vulnerable to TOCTOU symlink swaps.
// This test documents the race window rather than deterministically
// triggering it (races are inherently non-deterministic), by showing
// that checkPathEscapes and the actual open are two separate,
// non-atomic filesystem operations on a mutable path.
func TestRootTOCTOU_CheckThenOpenNotAtomic(t *testing.T) {
	dir := t.TempDir()
	root, err := os.OpenRoot(dir)
	if err != nil {
		t.Fatal(err)
	}
	defer root.Close()

	// Create "link" pointing inside the root initially.
	if err := os.Mkdir(dir+"/inside", 0o777); err != nil {
		t.Fatal(err)
	}
	if err := os.Symlink(dir+"/inside", dir+"/link"); err != nil {
		t.Fatal(err)
	}

	// Attacker goroutine swaps "link" to point outside the root
	// concurrently with the victim's root.Open call, racing between
	// checkPathEscapes' Lstat/Readlink and the later real Open.
	outside := t.TempDir()
	go func() {
		os.Remove(dir + "/link")
		os.Symlink(outside, dir+"/link")
	}()

	// If the race wins, this can resolve outside dir despite Root's
	// confinement guarantee; a robust implementation must make this
	// impossible even under a race, e.g. by using an atomic openat-like
	// primitive rather than separate check + open steps.
	f, err := root.Open("link")
	if err == nil {
		f.Close()
	}
	// Expected: err should always be non-nil (os.ErrPathEscapes) or the
	// resolved file must be provably still inside dir. Under the current
	// check-then-open design this cannot be guaranteed on js/wasm/plan9.
}
```

// rootOpenFileNolog is Root.OpenFile.
func rootOpenFileNolog(r *Root, name string, flag int, perm FileMode) (*File, error) {
	if err := checkPathEscapes(r, name); err != nil {
		return nil, &PathError{Op: "openat", Path: name, Err: err}
	}
	f, err := openFileNolog(joinPath(r.root.name, name), flag, perm)
	if err != nil {
		return nil, &PathError{Op: "openat", Path: name, Err: underlyingError(err)}
	}
	return f, nil
}

func checkPathEscapesInternal(r *Root, name string, lstat bool) error {
	if r.root.closed.Load() {
		return ErrClosed
	}
	parts, endsInSlash, err := splitPathInRoot(name, nil, nil)
	if err != nil {
		return err
	}

	i := 0
	symlinks := 0
	base := r.root.name
	for i < len(parts) {
		if parts[i] == ".." {
			// Resolve one or more parent ("..") path components.
			end := i + 1
			for end < len(parts) && parts[end] == ".." {
				end++
			}
			count := end - i
			if count > i {
				return errPathEscapes
			}
			parts = slices.Delete(parts, i-count, end)
			i -= count
			base = r.root.name
			for j := range i {
				base = joinPath(base, parts[j])
			}
			continue
		}

		part := parts[i]
		if i == len(parts)-1 {
			if lstat && !endsInSlash {
				break
			}
		}

		next := joinPath(base, part)
		fi, err := Lstat(next)
		if err != nil {
			if IsNotExist(err) {
				return nil
			}
			return underlyingError(err)
		}
		if fi.Mode()&ModeSymlink != 0 {
			link, err := Readlink(next)
			if err != nil {
				return errPathEscapes
			}
			symlinks++
			if symlinks > rootMaxSymlinks {
				return errors.New("too many symlinks")
			}
			newparts, newEndsInSlash, err := splitPathInRoot(link, parts[:i], parts[i+1:])
			if err != nil {
				return err
			}
			if i == len(parts)-1 && newEndsInSlash {
				endsInSlash = true
			}
			parts = newparts
			continue
		}
