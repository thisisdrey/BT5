### Title
Unauthenticated `/shutdown` POST terminates the signer's event receiver, causing remote DoS - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` treats any HTTP POST to `/shutdown` as an authoritative termination signal, regardless of the sender's identity. Because the signer's event-listener port can be bound on all interfaces (e.g., the reference config uses `endpoint = "0.0.0.0:30000"`), any remote party who can reach that port can permanently halt the signer's event-processing loop with a single unauthenticated request.

### Finding Description
In `next_event`, the URL dispatch logic is: [1](#0-0) 

There is no check of any secret, token, source IP, or peer identity before setting `stop_signal` to `true` and returning `EventError::Terminated`. The legitimate stop path (`SignerStopSignaler::send`) simply issues a plain, unauthenticated `POST /shutdown` over TCP to the bound `local_addr`: [2](#0-1) 

The `main_loop` treats `EventError::Terminated` as a clean exit condition and breaks out of the loop entirely: [3](#0-2) 

Once `main_loop` exits, the event-receiver thread is gone permanently; there is no retry/restart logic in `Signer::spawn`, so the signer stops receiving `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` events from the node from that point forward: [4](#0-3) 

Any attacker with raw TCP access to the bound event port can forge the identical request (`POST /shutdown HTTP/1.1` with any body) and achieve the same effect as the legitimate stop-signaler, since the handler performs no validation of the caller.

The reference/sample node-side and signer-side configs default the event endpoint to `0.0.0.0:30000` and `endpoint = "0.0.0.0:30000"` respectively (all-interfaces bind), and the code even warns operators about exposing the signer to "external node[s]" and associated security risks — confirming this port is intended to be reachable beyond localhost in some deployments: [5](#0-4) [6](#0-5) 

### Impact Explanation
A single forged POST to `/shutdown` permanently disables the signer's event-receiver thread, which is the sole ingestion path for miner block proposals, StackerDB chunk events, burn-block events, and new-block events. Once shut down, the signer stops participating in block validation/signing until manually restarted, degrading availability of signing services and potentially reducing the number of signers reachable for consensus at a critical moment — this is an unauthenticated, one-message remote DoS against a component in the node-to-signer trust boundary, matching the "Critical - remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
The only precondition is TCP reachability to the signer's bound event port — the same trust boundary as node-to-signer traffic, which the transport itself does not authenticate at the connection level. No secret, key, or role is required; the attacker only needs to know or guess the host:port (which per sample configs can default to `0.0.0.0`), and send one crafted HTTP request. This is trivially repeatable and requires no special timing beyond a single connection.

### Recommendation
Require the `/shutdown` endpoint to be authenticated (e.g., matching an `auth_token`/shared secret analogous to `[connection_options] auth_token`, or a signed/local-only IPC token) before setting `stop_signal`. Alternatively, if this is a local health/control endpoint, bind the event server to `127.0.0.1` only and reject non-loopback shutdown requests. At minimum, validate the request body/source before treating a `/shutdown` POST as authoritative.

### Proof of Concept
```rust
// libsigner/src/events.rs test (or a new integration test)
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use std::sync::mpsc::channel;
use libsigner::{SignerEventReceiver, EventReceiver, EventStopSignaler};

#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut ev: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let endpoint: SocketAddr = "127.0.0.1:31999".parse().unwrap();
    ev.bind(endpoint).unwrap();

    // Attacker with no credentials forges a shutdown request identical to
    // what SignerStopSignaler::send would produce.
    let mut sock = TcpStream::connect(endpoint).unwrap();
    let body = "attacker forged shutdown";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        endpoint, body.len(), body
    );
    sock.write_all(req.as_bytes()).unwrap();

    // next_event() now returns Terminated for an unauthenticated attacker request.
    let res = ev.next_event();
    assert!(matches!(res, Err(libsigner::EventError::Terminated)));
    assert!(ev.is_stopped());
}
```

                    info!("Caught termination signal");

                }
            };

                info!("Failed to forward event");
                break;
            }
        }
