### Title
`socialize-debt` lacks any pause gate, bypassing vault-level pause controls during liquidation-driven bad-debt write-down - (File: `mainnet/contracts/vault/v0-vault-usdc.clar` and sibling vault files)

### Summary
Every vault contract (`v0-vault-usdc.clar`, `v0-vault-stx.clar`, `v0-vault-sbtc.clar`, `v0-vault-ststx.clar`, `v0-vault-ststxbtc.clar`, `v0-vault-usdh.clar`) exposes a `pause-states` record gating `deposit`, `redeem`, `borrow`, `repay`, `accrue`, and `flashloan` independently. `system-repay` explicitly checks `(asserts! (not (get repay states)) ERR-PAUSED)` before mutating `principal-scaled`, `total-borrowed`, and `assets` [1](#0-0) . However, `socialize-debt`, which performs the same class of state mutation (writing down `principal-scaled`, `total-borrowed`, `assets`, and — critically — `lindex`, the liquidity index that determines share value for every depositor) has no pause check whatsoever [2](#0-1) . It is guarded only by `check-caller-auth`, meaning any registered caller (the market contract, reachable from an ordinary user's permissionless liquidation call) can still trigger this debt/index write-down while the vault is supposed to be frozen.

### Finding Description
This is a direct analog of the GoGoPool `whenNotPaused` bypass: the admin/DAO pauses vault operations (e.g. `repay`, `borrow`, or `accrue`) to halt debt and index mutations during an incident, but `socialize-debt` — which mutates the exact same state (`principal-scaled`, `total-borrowed`, `assets`, `lindex`) — has no corresponding pause flag or check. Compare:
- `system-repay`: gated by `(get repay states)` [3](#0-2) 
- `socialize-debt`: only `check-caller-auth`, no pause check at all [4](#0-3) 

`socialize-debt` directly rewrites `lindex` proportionally to the loss recognized (`new-lindex`), which is the value used by `redeem`/`convert-to-assets-preview` to compute how much every depositor receives for their shares [5](#0-4) . Since it is exempt from any pause gate, it remains reachable through the market's liquidation flow (an ordinary, unprivileged principal action) regardless of whether the DAO has paused `repay`/`borrow`/`accrue` on the vault in response to an oracle issue, exploit, or other emergency that this pause mechanism exists to contain.

### Impact Explanation
Because `socialize-debt` mutates `lindex` (the global share-price index) with no pause guard, an emergency pause of the vault does not prevent bad-debt socialization from altering the accounting that all depositors' share redemptions depend on. If the DAO pauses the vault expecting all index/debt state to be frozen (e.g. during active oracle manipulation or an ongoing exploit being investigated), a liquidation that reaches `socialize-debt` can still write down `lindex`/`assets`, locking in a debt-writeoff that is inconsistent with the "frozen" invariant the pause is meant to enforce. This directly affects vault share math and interest accrual — an explicitly in-scope area — and can result in inconsistent or premature socialization of bad debt while the protocol believes state to be frozen, contributing to protocol insolvency risk if used during a period the pause was meant to prevent state changes for.

### Likelihood Explanation
Moderate. `socialize-debt` requires `check-caller-auth`, so it is only reachable through the market contract's liquidation logic rather than a direct unprivileged call, mirroring the GGP report's `restakeGGP`/`claimAndRestake` pattern where the bypass function is one hop removed from the paused entry point. Since liquidation itself is a permissionless action available to any principal, this bypass path is reachable whenever a liquidatable position with recognized bad debt exists during a paused window.

### Recommendation
Add an explicit `socialize-debt` (or reuse `repay`/`accrue`) flag to `pause-states` and assert it is not paused inside `socialize-debt`, consistent with `system-borrow`/`system-repay`/`flashloan`, so DAO-initiated pauses cannot be bypassed via the liquidation-triggered bad-debt write-down path.

### Proof of Concept
1. DAO pauses the vault's `repay` (or `accrue`) state via `set-pause-states` to halt debt-state mutation during an incident.
2. An ordinary user calls the market's permissionless liquidation entry point on an undercollateralized position with recognized bad debt.
3. The market contract (an authorized caller per `check-caller-auth`) invokes `socialize-debt` on the vault.
4. `socialize-debt` executes without any pause check [6](#0-5) , mutating `principal-scaled`, `total-borrowed`, `assets`, and `lindex` — despite the DAO's explicit intent to freeze vault state via the pause mechanism.

(define-public (socialize-debt (scaled-amount uint))
  (let ((scaled-principal (var-get principal-scaled))
        (borrowed (var-get total-borrowed))
        (idx (var-get index))
        (current-assets (var-get assets))
        (current-lindex (var-get lindex))
        (old-total-assets (total-assets))
        (debt-reduction (mul-div-down scaled-amount idx INDEX-PRECISION))
        (principal-reduction (if (> scaled-principal u0)
                                (mul-div-down scaled-amount borrowed scaled-principal)
                                u0))
        ;; Write down lindex proportionally to loss in total-assets
        (new-lindex (if (and (> old-total-assets u0) (> old-total-assets debt-reduction))
                       (mul-div-down current-lindex (- old-total-assets debt-reduction) old-total-assets)
                       u0)))

    (try! (check-caller-auth))
    (asserts! (> scaled-amount u0) ERR-AMOUNT-ZERO)

    (var-set lindex new-lindex)
    (var-set principal-scaled (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0))
    (var-set total-borrowed (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0))
    (var-set assets (if (> current-assets principal-reduction) (- current-assets principal-reduction) u0))

    (print {
      action: "socialize-debt",
      caller: contract-caller,
      data: {
        scaled-amount: scaled-amount,
        debt-reduction: debt-reduction,
        principal-reduction: principal-reduction,
        old-lindex: current-lindex,
        new-lindex: new-lindex,
        old-total-assets: old-total-assets,
        principal-scaled: (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0),
        total-borrowed: (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0),
        index: idx
      }
    })

    (ok true)))
