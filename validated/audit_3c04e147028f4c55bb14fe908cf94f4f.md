### Title
Escaping tar entries survive `CreateRepositoryFromSnapshot` failure cleanup, leaving orphaned files outside the repository - (File: internal/gitaly/service/repository/create_repository_from_snapshot.go)

### Summary
`CreateRepositoryFromSnapshot` extracts an attacker-supplied tar directly into a temporary repository directory via `tar -C path -xvf -`, and on any extraction failure the only cleanup performed is `os.RemoveAll` of that exact temporary directory. Any tar entries that escaped the target directory with a `../` path component before the fatal error occurred are never touched by the rollback path, leaving residue outside the intended repository location even though the RPC reports failure.

### Finding Description
`s.untar` (`internal/gitaly/service/repository/create_repository_from_snapshot.go:87-121`) spawns `tar -C <path> -xvf -` and streams the HTTP response body from `in.GetHttpUrl()` directly as stdin, with no entry-name validation of the tar stream contents before or during extraction: [1](#0-0) . `path` is the location of the temporary repository created by `tempdir.NewRepository`, i.e. `os.MkdirTemp(root, prefix)` under the storage's temp directory [2](#0-1) .

If the tar stream contains a path-escaping entry (e.g. `../evil`) followed later by a malformed/corrupted header, GNU `tar` will process entries sequentially: any writes that occur before the fatal parse error are already committed to disk, and only then does `tar` abort with a non-zero exit code. `cmd.Wait()` returns that error, causing `s.untar` to return an error, which `repoutil.Create`'s seed callback propagates [3](#0-2) .

On this failure, `repoutil.Create`'s only rollback mechanism is the deferred `cleanup()` returned by `tempdir.NewRepository`, which calls `os.RemoveAll(dir.path)` — strictly the temporary directory that was passed as `-C path` to tar [4](#0-3)  and [5](#0-4) . Nothing in `repoutil.Create` or `CreateRepositoryFromSnapshot` inspects or removes files written to `filepath.Join(path, "..", ...)` or deeper ancestor directories. The existing test `TestCreateRepositoryFromSnapshot_malformedArchive` only asserts the destination repo path itself does not exist afterward, not that no residue exists elsewhere [6](#0-5) . The code's own comment acknowledges the archive is "trusted *a lot*" and needs hardening before being pointed at untrusted endpoints [7](#0-6) , confirming no entry-name sanitization exists anywhere in this path.

### Impact Explanation
An attacker who controls the tar stream served at `HttpUrl` (i.e., the source of the snapshot) can plant files outside of the intended repository directory — inside the storage's shared temp root (`+gitaly/tmp/...`) or, depending on traversal depth, elsewhere under the storage path — and have them persist even though the RPC returns an internal error to the caller. Because the failure is reported as an ordinary internal error, there is no operator-facing signal that files were left behind, enabling stealthy planting of arbitrary content on the Gitaly node's filesystem (matches "storage-path escape / archive extraction escape" impact class in scope).

### Likelihood Explanation
Exploitation requires the attacker to control the tar bytes returned by `HttpUrl` for a `CreateRepositoryFromSnapshotRequest`, and to interleave an escaping entry (e.g. `../evil`) before an entry that causes `tar` to abort (e.g. a corrupted header, as already exercised by `TestCreateRepositoryFromSnapshot_malformedArchive`). No special privileges, secrets, or non-default configuration are needed beyond triggering this RPC with attacker-influenced snapshot content; the flaw is deterministic and repeatable given a crafted tar.

### Recommendation
Do not trust `tar`'s own path handling for untrusted input. Before or during extraction, validate every tar header's name via `storage.ValidateRelativePath` (or equivalent) and reject/abort on any entry containing `..` components or absolute paths, rather than relying solely on `os.RemoveAll` of the target directory as a rollback. Consider extracting into an isolated per-request scratch directory that is provably unreachable from any `../` escape (e.g., by rejecting entries client-side via a streaming tar reader in Go rather than shelling out to `tar`), so a partial failure can be fully rolled back by removing that single directory.

```go
func TestCreateRepositoryFromSnapshot_malformedArchiveWithEscape(t *testing.T) {
	t.Parallel()

	ctx := testhelper.Context(t)
	cfg, client := setupRepositoryService(t)

	_, sourceRepoPath := gittest.CreateRepository(t, ctx, cfg)
	gittest.WriteCommit(t, cfg, sourceRepoPath, gittest.WithBranch(git.DefaultBranch))

	data, _ := generateTarFile(t, sourceRepoPath)

	// Prepend an escaping entry, then corrupt a later header so tar aborts
	// after the escape has already been written.
	escapingEntry := buildTarEntry(t, "../evil-poc", []byte("pwned"))
	malformedData := append(escapingEntry, corruptTarHeader(data)...)

	srv := httptest.NewServer(&tarTesthandler{tarData: bytes.NewReader(malformedData), secret: secret})
	defer srv.Close()

	repo := &gitalypb.Repository{
		StorageName:  cfg.Storages[0].Name,
		RelativePath: gittest.NewRepositoryName(t),
	}

	response, err := client.CreateRepositoryFromSnapshot(ctx, &gitalypb.CreateRepositoryFromSnapshotRequest{
		Repository: repo,
		HttpUrl:    srv.URL + tarPath,
		HttpAuth:   secret,
	})
	require.Error(t, err)
	require.Nil(t, response)

	// Expected (vulnerable) result: the escaped file still exists in the
	// storage's temp root even though the RPC failed.
	escapedPath := filepath.Join(cfg.Storages[0].Path, "+gitaly/tmp", "evil-poc")
	require.NoFileExists(t, escapedPath, "escaped tar entry should not survive rollback, but it does")
}
```

```go
func newDirectory(ctx context.Context, storageName string, prefix string, logger log.Logger, loc storage.Locator) (Dir, error) {
	root, err := loc.TempDir(storageName)
	if err != nil {
		return Dir{}, fmt.Errorf("temp directory: %w", err)
	}

	if err := os.MkdirAll(root, mode.Directory); err != nil {
		return Dir{}, err
	}

	tempDir, err := os.MkdirTemp(root, prefix)
	if err != nil {
		return Dir{}, err
	}

	return Dir{
		logger: logger,
		path:   tempDir,
	}, err
```
