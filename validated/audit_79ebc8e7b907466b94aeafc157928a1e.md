### Title
Unauthenticated forged frontier write via self-declared HandshakeAccept address in neighbor-of-neighbor crawl - ([File: stackslib/src/net/neighbors/walk.rs] / [File: stackslib/src/net/neighbors/db.rs])

### Summary
When the neighbor-walk crawler asks an attacker-controlled peer (`naddr`) to handshake as part of resolving a `GetNeighbors` list, `NeighborWalk::handle_neighbor_handshake_accept` passes the reply's self-declared `HandshakeData` straight into `PeerDBNeighborWalk::add_or_schedule_replace_neighbor` with no check that the declared `addrbytes`/`port` actually correspond to the socket/`naddr` that was contacted. Because the `NeighborKey` used to key the PeerDB row is built purely from the attacker-chosen `HandshakeData` fields, an attacker can make the node insert (or, if already present, upgrade the key of) a frontier row for a third-party IP:port under the attacker's own public key.

### Finding Description
The identity equality that should hold is: *the `NeighborKey{addrbytes,port}` written into `PeerDB` == the peer that the TCP/handshake exchange actually authenticated*. This equality is broken because `NeighborKey::from_handshake` [1](#0-0)  builds the key exclusively from attacker-controlled `HandshakeData.addrbytes/port`, and `Neighbor::load_and_update` [2](#0-1)  uses that key to look up/construct the `Neighbor` that gets persisted.

`PeerDBNeighborWalk::add_or_schedule_replace_neighbor` [3](#0-2)  then either updates an existing row's public key (`save_update` → `PeerDB::update_peer`, which updates purely on `network_id/addrbytes/port` match, no ownership proof [4](#0-3) ) or inserts a brand-new row via `save` → `PeerDB::try_insert_peer`, which allocates a free frontier slot for that address without any prior contact [5](#0-4) .

Crucially, `handle_neighbor_handshake_accept` — the handler invoked after handshaking with each address discovered via `GetNeighbors` — calls `add_or_schedule_replace_neighbor` with the raw `data.handshake` and performs **no** validation that `data.handshake.addrbytes/port` equals the `naddr` that was actually dialed: [6](#0-5) . Contrast this with `handle_handshake_accept` (used only for `cur_neighbor`, the primary outbound target), which explicitly rejects a mismatch between the declared address and the address actually walked to [7](#0-6) , and `pingback_handshakes_try_finish`, which at least checks the declared pubkey hash against the pre-registered `NeighborAddress` (though still not the address) [8](#0-7) . No equivalent guard exists on the neighbor-of-neighbor path.

Exploit flow: the attacker runs a peer at some IP the crawler will contact (e.g. is gossiped as a `NeighborAddress` by any node, or is itself a `cur_neighbor`). When the victim node performs `GetHandshakesBegin/Finish` against the attacker's address, the attacker replies with a validly-signed `HandshakeAccept`/`StackerDBHandshakeAccept` whose `HandshakeData.addrbytes/port` is set to an arbitrary third-party (victim) IP:port instead of its own. `handle_neighbor_handshake_accept` then calls `add_or_schedule_replace_neighbor`, which writes/updates a `PeerDB` frontier row keyed at the third-party IP:port with the attacker's real public key.

### Impact Explanation
This is an unauthenticated write of a forged frontier record into `PeerDB`: an entry keyed by a third-party's socket identity ends up holding the attacker's public key, either by overwriting a previously legitimate peer entry's key (breaking future authentication toward that IP) or by fabricating a brand-new entry for an address the node never actually validated. This corrupts the local frontier used for peer selection, allow/deny decisions, and future handshake trust, and is repeatable on every crawl cycle against the attacker's advertised address. This matches the Critical "unauthenticated write to state" category.

### Likelihood Explanation
No special privileges are required: the attacker only needs to run an ordinary P2P peer that a victim node's neighbor-walk crawler will eventually contact (trivial — nodes routinely walk to any gossiped or self-announced address), and reply with a normal, correctly-signed Handshake/HandshakeAccept message containing a spoofed `addrbytes/port`. No secret keys, RPC auth, or admin state are needed, and the attack is cheap and repeatable each walk cycle.

### Recommendation
In `NeighborWalk::handle_neighbor_handshake_accept` (and any other caller of `add_or_schedule_replace_neighbor` that doesn't already do so), verify that `HandshakeData.addrbytes/port` in the reply matches the `naddr`/socket actually contacted before accepting the handshake data for frontier storage; reject or fall back to the dialed address otherwise (mirroring the check already done in `handle_handshake_accept` for `cur_neighbor`).

### Proof of Concept
Rust test in `stackslib::net::neighbors::walk` tests module:
1. Set up a `NeighborWalk` with a mock `NeighborComms`/`NeighborWalkDB` (or use existing test harness for `neighbor_handshakes_try_finish`).
2. Register `naddr` = attacker's real test IP/port with a pending handshake request.
3. Craft a `StacksMessage` containing `StacksMessageType::HandshakeAccept(HandshakeAcceptData { handshake: HandshakeData { addrbytes: victim_ip, port: victim_port, node_public_key: attacker_pubkey, .. }, .. })`, signed with the attacker's private key, and deliver it as the "reply" for `naddr`.
4. Call `neighbor_handshakes_try_finish` → `handle_neighbor_handshake_accept`.
5. Assert `PeerDB::get_peer(conn, network_id, &victim_ip, victim_port).unwrap().public_key == attacker_pubkey`, even though the TCP/handshake exchange was only ever conducted with the attacker's address `naddr`.

    fn add_or_schedule_replace_neighbor(
        &self,
        network: &mut PeerNetwork,
        preamble: &Preamble,
        handshake: &HandshakeData,
        db_data: Option<&StackerDBHandshakeData>,
        replacements: &mut NeighborReplacements,
    ) -> Result<(bool, Neighbor), net_error> {
        let local_peer_str = format!("{:?}", network.get_local_peer());
        let tx = network.peerdb_tx_begin()?;
        let (mut neighbor_from_handshake, was_present) =
            Neighbor::load_and_update(&tx, preamble.peer_version, preamble.network_id, handshake)?;

        if was_present {
            test_debug!(
                "{}: already know about neighbor {:?}",
                &local_peer_str,
                &neighbor_from_handshake.addr
            );
            neighbor_from_handshake
                .save_update(&tx, db_data.map(|x| x.smart_contracts.as_slice()))?;
            tx.commit()?;

            // seen this neighbor before
            return Ok((false, neighbor_from_handshake));
        }

        debug!(
            "{}: new neighbor {:?}",
            &local_peer_str, &neighbor_from_handshake.addr
        );

        // didn't know about this neighbor yet. Try to add it.
        let added =
            neighbor_from_handshake.save(&tx, db_data.map(|x| x.smart_contracts.as_slice()))?;

        if added {
            // neighbor was new, and we had space to add it.
            tx.commit()?;
            return Ok((true, neighbor_from_handshake));
        }

        // neighbor was new, but we don't have space to insert it.
        // find and record a neighbor it would replace.
        let replaced_neighbor_slot_opt =
            Self::find_replaced_neighbor_slot(&tx, &neighbor_from_handshake.addr)?;
        if let Some(slot) = replaced_neighbor_slot_opt {
            replacements.add_neighbor(
                NeighborAddress::from_neighbor(&neighbor_from_handshake),
                neighbor_from_handshake.clone(),
                slot,
            );
        }

        tx.commit()?;

        // neighbor was new
        Ok((true, neighbor_from_handshake))
    }

    pub fn try_insert_peer(
        tx: &Transaction,
        neighbor: &Neighbor,
        stacker_dbs: &[QualifiedContractIdentifier],
    ) -> Result<bool, db_error> {
        let present = PeerDB::has_peer(
            tx,
            neighbor.addr.network_id,
            &neighbor.addr.addrbytes,
            neighbor.addr.port,
        )?;
        if present {
            // already here
            PeerDB::update_peer(tx, neighbor)?;
            PeerDB::update_peer_stacker_dbs(tx, neighbor, stacker_dbs)?;
            return Ok(true);
        }

        let slots = PeerDB::peer_slots(
            tx,
            neighbor.addr.network_id,
            &neighbor.addr.addrbytes,
            neighbor.addr.port,
        )?;
        for slot in slots.iter() {
            let used_slot = PeerDB::has_peer_at(tx, neighbor.addr.network_id, *slot)?;
            if !used_slot {
                // have a spare slot!
                PeerDB::insert_or_replace_peer(tx, neighbor, *slot)?;
                PeerDB::insert_or_replace_stacker_dbs(tx, *slot, stacker_dbs)?;
                return Ok(true);
            }
        }

        // no slots free
        return Ok(false);
    }

    /// Handle a handshake accept from a neighbor as part of our neighbor-handshake step
    fn handle_neighbor_handshake_accept(
        &mut self,
        network: &mut PeerNetwork,
        naddr: NeighborAddress,
        preamble: &Preamble,
        data: &HandshakeAcceptData,
        db_data: Option<&StackerDBHandshakeData>,
    ) -> Result<(), net_error> {
        // NOTE: even if cur_neighbor is an inbound neighbor, the neighbors
        // of cur_neighbor that we could handshake with are necessarily
        // outbound connections.  So, save them all.
        // Do we know about this peer already?
        let (new, neighbor) = self.neighbor_db.add_or_schedule_replace_neighbor(
            network,
            preamble,
            &data.handshake,
            db_data,
            &mut self.neighbor_replacements,
        )?;

        if new {
            // neighbor was new
            self.new_frontier
                .insert(neighbor.addr.clone(), neighbor.clone());
        } else {
            // frontier maintenance
            self.frontier
                .insert(neighbor.addr.clone(), neighbor.clone());
        }

        self.resolved_handshake_neighbors.insert(naddr, neighbor);
        Ok(())
    }

    /// Does a given handshakedata represent an expected public key hash?
    fn check_handshake_pubkey_hash(
        nk: &NeighborKey,
        data: &HandshakeAcceptData,
        naddr: &NeighborAddress,
    ) -> bool {
        let neighbor_pubkey_hash =
            Hash160::from_node_public_key_buffer(&data.handshake.node_public_key);
        if neighbor_pubkey_hash != naddr.public_key_hash {
            debug!(
                "Neighbor {:?} had an unexpected pubkey hash: expected {:?} != {:?}",
                nk, &naddr.public_key_hash, &neighbor_pubkey_hash
            );
            return false;
        }

        true
    }

    /// Finish up connecting to newly-discovered inbound peers
    pub fn pingback_handshakes_try_finish(
        &mut self,
        network: &mut PeerNetwork,
    ) -> Result<bool, net_error> {
        assert!(self.state == NeighborWalkState::PingbackHandshakesFinish);

        // see if we got any replies
        for (naddr, message) in self.comms.collect_replies(network).into_iter() {
            // if we got back a HandshakeAccept, and it's on the same chain as us, we're good!
            let (data, db_data) = match message.payload {
                StacksMessageType::HandshakeAccept(ref data) => {
                    debug!("{:?}: received HandshakeAccept from peer {:?}; now known to be routable from us", network.get_local_peer(), &message.to_neighbor_key(&data.handshake.addrbytes, data.handshake.port));
                    (data, None)
                }
                StacksMessageType::StackerDBHandshakeAccept(ref data, ref db_data) => {
                    debug!("{:?}: received StackerDBHandshakeAccept from peer {:?}; now known to be routable from us", network.get_local_peer(), &message.to_neighbor_key(&data.handshake.addrbytes, data.handshake.port));
                    (data, Some(db_data))
                }
                _ => {
                    let nkey = naddr.to_neighbor_key(network);
                    debug!(
                        "{:?}: Neighbor {:?} replied {:?} instead of pingback handshake",
                        network.get_local_peer(),
                        &nkey,
                        &message.get_message_name()
                    );
                    continue;
                }
            };

            let peer_nk = message.to_neighbor_key(&data.handshake.addrbytes, data.handshake.port);
            if !Self::check_handshake_pubkey_hash(&peer_nk, data, &naddr) {
                continue;
            }

            self.neighbor_db.add_or_schedule_replace_neighbor(
                network,
                &message.preamble,
                &data.handshake,
                db_data,
                &mut self.neighbor_replacements,
            )?;
