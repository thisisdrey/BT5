### Title
StakeV2 feature-flag bypass via TVM native contract opcodes - (File: `actuator/src/main/java/org/tron/core/vm/nativecontract/FreezeBalanceV2Processor.java`, `actuator/src/main/java/org/tron/core/vm/nativecontract/UnfreezeBalanceV2Processor.java`)

### Summary
The committee-controlled feature switch `supportUnfreezeDelay()` (which gates whether the StakeV2 unfreeze-delay mechanism is enabled at all) is enforced by `FreezeBalanceV2Actuator.validate()` and `UnfreezeBalanceV2Actuator.validate()` for ordinary broadcast transactions, but is never checked by the corresponding TVM native-contract processors `FreezeBalanceV2Processor.validate()` and `UnfreezeBalanceV2Processor.validate()`, which are reachable by any smart contract calling the `freezeBalanceV2`/`unfreezeBalanceV2` TVM opcodes. This mirrors the reported bug class: a state-changing entry point that bypasses the pausing/feature-gate check enforced elsewhere.

### Finding Description
`FreezeBalanceV2Actuator.validate()` explicitly rejects the transaction unless the committee has enabled StakeV2: [1](#0-0) 

Similarly, `UnfreezeBalanceV2Actuator.validate()` performs the same check: [2](#0-1) 

However, the TVM-reachable equivalents of these operations, `FreezeBalanceV2Processor.validate()` and `UnfreezeBalanceV2Processor.validate()`, never call `supportUnfreezeDelay()` anywhere in their validation logic: [3](#0-2) [4](#0-3) 

These processors are invoked directly from `Program.freezeBalanceV2` and `Program.unfreezeBalanceV2`, which back the TVM opcodes any deployed smart contract can execute: [5](#0-4) 

The only gate on these opcodes is the separate `VMConfig.allowTvmFreezeV2()` flag (opcode-enablement / hard fork flag), which is distinct from `supportUnfreezeDelay()`. `allowTvmFreezeV2` controls whether the opcode itself is enabled in `OperationRegistry`, but does not track whether the StakeV2/unfreeze-delay feature has actually been turned on by committee proposal. If these two flags can be in different states (e.g., the TVM freeze-v2 opcode is enabled on a hard fork boundary while `supportUnfreezeDelay` has not yet been separately enabled by committee proposal, or is later disabled while the opcode fork remains active), a smart contract could still freeze/unfreeze StakeV2 balances via TVM even though ordinary `FreezeBalanceV2Contract`/`UnfreezeBalanceV2Contract` transactions from EOAs are being rejected by the actuators for the same reason.

### Impact Explanation
This allows unauthorized state changes to StakeV2 stake accounting (frozen/unfrozen balances, resource weights, and vote states) through a contract-call code path that is supposed to be disabled when the committee has not enabled StakeV2 delayed-unfreeze semantics. Because `execute()` in these processors mutates account balances, total resource weights, and vote records, an inconsistent state between the actuator-based and TVM-based paths could allow stake/resource accounting or unfreeze-delay timing to be manipulated in a way the network operators did not intend to permit yet, which affects resource/energy accounting integrity network-wide.

### Likelihood Explanation
Reachable by any account that deploys a smart contract and invokes it — no privileged role required. The precondition (a divergence between the opcode fork flag `allowTvmFreezeV2` and the `supportUnfreezeDelay` proposal flag) depends on the deployment/rollout sequence of these two independent flags, so likelihood is moderate rather than certain, but the code itself provides no defense-in-depth once the opcode is enabled.

### Recommendation
Add an explicit `dynamicStore.supportUnfreezeDelay()` check (mirroring the actuator behavior) at the start of `FreezeBalanceV2Processor.validate()` and `UnfreezeBalanceV2Processor.validate()`, throwing `ContractValidateException` if the feature is not enabled, so the TVM-reachable path cannot diverge from the actuator-enforced path.

### Proof of Concept
1. Deploy a smart contract that calls the `freezeBalanceV2`/`unfreezeBalanceV2` TVM opcodes (as exercised in `Program.freezeBalanceV2`/`Program.unfreezeBalanceV2`).
2. Configure/observe a chain state where `VMConfig.allowTvmFreezeV2()` is true (opcode enabled) but `DynamicPropertiesStore.supportUnfreezeDelay()` is false (StakeV2 not yet enabled by committee).
3. Submit a normal `FreezeBalanceV2Contract`/`UnfreezeBalanceV2Contract` transaction — it is rejected by `FreezeBalanceV2Actuator.validate()`/`UnfreezeBalanceV2Actuator.validate()` with "Not support FreezeV2 transaction...".
4. Call the contract that invokes the `freezeBalanceV2`/`unfreezeBalanceV2` opcode — `FreezeBalanceV2Processor.validate()`/`UnfreezeBalanceV2Processor.validate()` contain no such check and the operation succeeds, demonstrating the bypass.

  public void validate(FreezeBalanceV2Param param, Repository repo) throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule ownerCapsule = repo.getAccount(ownerAddress);
    if (ownerCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ACCOUNT_EXCEPTION_STR + readableOwnerAddress + "] does not exist");
    }
    long frozenBalance = param.getFrozenBalance();
    if (frozenBalance <= 0) {
      throw new ContractValidateException("FrozenBalance must be positive");
    } else if (frozenBalance < TRX_PRECISION) {
      throw new ContractValidateException("FrozenBalance must be greater than or equal to 1 TRX");
    } else if (frozenBalance > ownerCapsule.getBalance()) {
      throw new ContractValidateException(
          "FrozenBalance must be less than or equal to accountBalance");
    }

    // validate arg @resourceType
    switch (param.getResourceType()) {
      case BANDWIDTH:
      case ENERGY:
        break;
      case TRON_POWER:
        if (!repo.getDynamicPropertiesStore().supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException(
              "Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    if (repo.isSelfDestructed(ownerAddress)) {
      MUtil.checkCPUTimeForFreezeV2AfterSelfDestruct();
    }
  }

  public void validate(UnfreezeBalanceV2Param param, Repository repo)
      throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (accountCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ACCOUNT_EXCEPTION_STR + readableOwnerAddress + "] does not exist");
    }
    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    int unfreezingCount = accountCapsule.getUnfreezingV2Count(now);
    if (UnfreezeBalanceV2Actuator.getUNFREEZE_MAX_TIMES() <= unfreezingCount) {
      throw new ContractValidateException("Invalid unfreeze operation, unfreezing times is over limit");
    }
    switch (param.getResourceType()) {
      case BANDWIDTH:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.BANDWIDTH)) {
          throw new ContractValidateException("no frozenBalance(BANDWIDTH)");
        }
        break;
      case ENERGY:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.ENERGY)) {
          throw new ContractValidateException("no frozenBalance(ENERGY)");
        }
        break;
      case TRON_POWER:
        if (dynamicStore.supportAllowNewResourceModel()) {
          if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.TRON_POWER)) {
            throw new ContractValidateException("no frozenBalance(TRON_POWER)");
          }
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    if (!checkUnfreezeBalance(accountCapsule, param.getUnfreezeBalance(), param.getResourceType())) {
      throw new ContractValidateException(
          "Invalid unfreeze_balance, [" + param.getUnfreezeBalance() + "] is invalid");
    }

    if (accountCapsule.hasInvalidDelegatedV2()) {
      MUtil.checkCPUTimeForInvalidDelegatedV2Balance();
    }
  }

  public boolean freezeBalanceV2(DataWord frozenBalance, DataWord resourceType) {
    Repository repository = getContractState().newRepositoryChild();
    byte[] owner = getContextAddress();

    increaseNonce();
    InternalTransaction internalTx = addInternalTx(null, owner, owner,
        frozenBalance.longValue(), null,
        "freezeBalanceV2For" + convertResourceToString(resourceType), nonce, null);

    try {
      FreezeBalanceV2Param param = new FreezeBalanceV2Param();
      param.setOwnerAddress(owner);
      param.setResourceType(parseResourceCodeV2(resourceType));
      param.setFrozenBalance(frozenBalance.sValue().longValueExact());

      FreezeBalanceV2Processor processor = new FreezeBalanceV2Processor();
      processor.validate(param, repository);
      processor.execute(param, repository);
      repository.commit();
      return true;
    } catch (ContractValidateException e) {
      logger.warn("TVM FreezeBalanceV2: validate failure. Reason: {}", e.getMessage());
    } catch (ArithmeticException e) {
      logger.warn("TVM FreezeBalanceV2: frozenBalance out of long range.");
    }
    if (internalTx != null) {
      internalTx.reject();
    }
    return false;
  }

  public boolean unfreezeBalanceV2(DataWord unfreezeBalance, DataWord resourceType) {
    Repository repository = getContractState().newRepositoryChild();
    byte[] owner = getContextAddress();

    increaseNonce();
    InternalTransaction internalTx = addInternalTx(null, owner, owner,
        unfreezeBalance.longValue(), null,
        "unfreezeBalanceV2For" + convertResourceToString(resourceType), nonce, null);

    try {
      UnfreezeBalanceV2Param param = new UnfreezeBalanceV2Param();
      param.setOwnerAddress(owner);
      param.setUnfreezeBalance(unfreezeBalance.sValue().longValueExact());
      param.setResourceType(parseResourceCodeV2(resourceType));

      UnfreezeBalanceV2Processor processor = new UnfreezeBalanceV2Processor();
      processor.validate(param, repository);
      long unfreezeExpireBalance = processor.execute(param, repository);
      repository.commit();
      if (unfreezeExpireBalance > 0) {
        increaseNonce();
        addInternalTx(null, owner, owner, unfreezeExpireBalance, null,
            "withdrawExpireUnfreezeWhileUnfreezing", nonce, null);
      }
      return true;
    } catch (ContractValidateException e) {
      logger.warn("TVM UnfreezeBalanceV2: validate failure. Reason: {}", e.getMessage());
    } catch (ArithmeticException e) {
      logger.warn("TVM UnfreezeBalanceV2: balance out of long range.");
    }
    if (internalTx != null) {
      internalTx.reject();
    }
    return false;
  }
