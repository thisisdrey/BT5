## Finding: Blind SSRF via peer-supplied `data_url` in Stacks P2P handshake/download subsystem

### Title
Unauthenticated node causes victim to issue outbound HTTP requests to attacker-chosen internal/loopback addresses via unsanitized `data_url` - (File: `stackslib/src/net/dns.rs`, `stackslib/src/net/p2p.rs`, `stackslib/src/util_lib/strings.rs`)

### Summary
Every Stacks peer self-reports a `data_url` in its `HandshakeData` [1](#0-0) , and remote peers use this attacker-controlled string to build outbound HTTP requests for block/microblock download, mempool sync, and StackerDB replication. Nowhere in the URL-validation path is the resolved destination checked against loopback/private/link-local ranges, and `try_get_url_ip` even hard-codes `"localhost"` to `127.0.0.1` [2](#0-1) . This is the same bug class as CVE-2022-36663 (SSRF via a crafted URL parameter): a peer supplies a URL, and the victim node blindly fetches it.

### Finding Description
`UrlString::parse_to_block_url` only validates scheme (http/https), absence of credentials, presence of a host, and absence of query/fragment — it does not reject private, loopback, or link-local hosts [3](#0-2) . `UrlString::has_routable_host` only excludes the any-net addresses `0.0.0.0`/`::`, again not private ranges [4](#0-3) .

The `data_url` field is taken directly from the remote peer's self-reported `HandshakeData` [5](#0-4)  and is stored per-conversation (`convo.data_url`). It is later resolved to a socket address either directly (bare IP/`localhost`) via `try_get_url_ip` [2](#0-1)  or through DNS resolution in `DNSResolver::resolve`, which performs a plain `to_socket_addrs()` lookup with no address-range filtering [6](#0-5) .

Once resolved, the address is used to open an outbound HTTP connection and send a crafted, attacker-influenced-format HTTP request (`GetBlocksInv`, mempool sync `GET`, StackerDB chunk fetch, etc.) via `connect_or_send_http_request` / `NeighborRPC::send_request` [7](#0-6)  and `stackslib/src/net/httpcore.rs` `connect_or_send_http_request` [8](#0-7) . The same unsanitized-URL pattern recurs independently in the epoch2x block downloader's `dns_lookups_begin` [9](#0-8) , the mempool-sync DNS resolver [10](#0-9) , and the Atlas attachment downloader [11](#0-10) .

### Impact Explanation
A malicious or compromised remote node (any peer that can complete or attempt a handshake) can advertise a `data_url` pointing at `127.0.0.1`, an RFC1918 address, or a cloud instance-metadata endpoint (e.g. `169.254.169.254`). The victim node will then send crafted HTTP requests (with attacker-influenced path/body shape, since the requester constructs `StacksHttpRequest`s toward this host) to that internal target from the victim's own network position. This can be used to probe or interact with services that are normally unreachable from the internet (local RPC/admin endpoints, internal management interfaces, cloud metadata services that can leak credentials), i.e. a blind SSRF pivot — matching the reported CWE-918 class.

### Likelihood Explanation
No authentication is strictly required to have a `data_url` considered: an inbound peer's self-reported handshake data is accepted and stored as long as the handshake itself parses (signature checks in `validate_handshake` verify the handshake payload signature, not the URL's target) [12](#0-11) . Any peer capable of completing a handshake or being queried for blocks/mempool/StackerDB data can trigger the outbound fetch, making this reachable by any remote, unprivileged actor.

### Recommendation
Add a hostname/IP allow-list check (reject loopback, RFC1918/link-local/multicast ranges, and `localhost`) both at URL-parse time (`UrlString::parse_to_block_url`/`has_routable_host`) and after DNS resolution (in `DNSResolver::resolve` and `try_get_url_ip`), so that resolved destinations pointing to internal/loopback ranges are rejected before an outbound HTTP request is issued.

### Proof of Concept
1. Stand up a malicious Stacks peer that completes a handshake with the victim node, setting `HandshakeData.data_url = "http://169.254.169.254/latest/meta-data/iam/security-credentials/"` (or `http://127.0.0.1:<internal-port>/`).
2. Wait for the victim to attempt block/microblock download, mempool sync, or StackerDB chunk fetch against this peer (this happens automatically once neighbor walk/download logic selects the peer).
3. Observe that the victim resolves the URL via `DNSResolver::resolve`/`try_get_url_ip` without range filtering and issues an outbound HTTP GET/POST to the attacker-chosen internal address, confirmable via a listener bound to that address in a lab environment (e.g. loopback on the victim host) capturing the crafted request.

```rust
impl UrlString {
    /// Determine that the UrlString parses to something that can be used to fetch blocks via HTTP(S).
    /// A block URL must be an HTTP(S) URL without a query or fragment, and without a login.
    pub fn parse_to_block_url(&self) -> Result<url::Url, codec_error> {
        // even though this code uses from_utf8_unchecked() internally, we've already verified that
        // the bytes in this string are all ASCII.
        let url = url::Url::parse(&self.to_string())
            .map_err(|e| codec_error::DeserializeError(format!("Invalid URL: {:?}", &e)))?;

        if url.scheme() != "http" && url.scheme() != "https" {
            return Err(codec_error::DeserializeError(format!(
                "Invalid URL: invalid scheme '{}'",
                url.scheme()
            )));
        }

        if !url.username().is_empty() || url.password().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: must not contain a username/password".to_string(),
            ));
        }

        if url.host_str().is_none() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: no host string".to_string(),
            ));
        }

        if url.query().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: query strings not supported for block URLs".to_string(),
            ));
        }

        if url.fragment().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: fragments are not supported for block URLs".to_string(),
            ));
        }

        Ok(url)
    }
```

```rust
    pub fn dns_lookups_begin(

                    continue;
                }

                    match dns_client.queue_lookup(
                        domain,
                        port,
                        get_epoch_time_ms() + self.dns_timeout,

                        Ok(_) => {}
                        Err(_) => continue,
                    }

                    self.parsed_urls
```

```rust
    fn validate_handshake(
        &mut self,
        local_peer: &LocalPeer,
        chain_view: &BurnchainView,
        message: &mut StacksMessage,
    ) -> Result<(), net_error> {
        let handshake_data = match message.payload {
            StacksMessageType::Handshake(ref mut data) => data.clone(),
            _ => panic!("Message is not a handshake"),
        };

        match self.connection.get_public_key() {
            None => {
                // if we don't yet have a public key for this node, verify the message.
                // if it's improperly signed, it's probably a poorly-timed re-key request (but either way the message should be rejected)
                message
                    .verify_secp256k1(&handshake_data.node_public_key)
                    .map_err(|_e| {
                        debug!(
                            "{:?}: invalid handshake: not signed with given public key",
                            &self
                        );
                        net_error::InvalidMessage
                    })?;
            }
            Some(_) => {
                // for outbound connections, the self-reported address must match socket address if we already have a public key.
                // (not the case for inbound connections, since the peer socket address we see may
                // not be the same as the address the remote peer thinks it has).
                // The only exception to this is if the remote peer does not yet know its own
                // public IP address, in which case, its handshake addrbytes will be the
                // any-network bind address (0.0.0.0 or ::)
                if self.stats.outbound
                    && (!handshake_data.addrbytes.is_anynet()
                        && (self.peer_addrbytes != handshake_data.addrbytes
                            || self.peer_port != handshake_data.port))
                {
                    // wrong peer address
                    debug!(
                        "{:?}: invalid handshake -- wrong addr/port ({:?}:{:?})",
                        &self, &handshake_data.addrbytes, handshake_data.port
                    );
                    return Err(net_error::InvalidHandshake);
                }
            }
        };

        let their_public_key_res = handshake_data.node_public_key.to_public_key();
        match their_public_key_res {
            Ok(_) => {}
            Err(_e) => {
                // bad public key
                debug!("{:?}: invalid handshake -- invalid public key", &self);
                return Err(net_error::InvalidMessage);
            }
        };

        if handshake_data.expire_block_height <= chain_view.burn_block_height {
            // already stale
            debug!(
                "{:?}: invalid handshake -- stale public key (expired at {})",
                &self, handshake_data.expire_block_height
            );
            return Err(net_error::InvalidHandshake);
        }

        // the handshake cannot come from us
        if handshake_data.node_public_key
            == StacksPublicKeyBuffer::from_public_key(&Secp256k1PublicKey::from_private(
                &local_peer.private_key,
            ))
        {
            debug!(
                "{:?}: invalid handshake -- got a handshake from myself",
                &self
            );
            return Err(net_error::InvalidHandshake);
        }

        Ok(())
    }
```
