### Title
`Repo.ObjectDirectoryPath` skips per-repository quarantine ownership verification when directory is literally named `quarantine` - (File: internal/git/localrepo/paths.go)

### Summary
`internal/git/localrepo/paths.go`'s `ObjectDirectoryPath` computes an `isTransactionQuarantineDir` flag with an OR-condition that, similar to the referenced `TridentNFT.permit` bug, allows one disjunct to short-circuit and skip a security-critical ownership check that the other disjunct is supposed to enforce.

### Finding Description
`ObjectDirectoryPath` resolves the client-supplied `GitObjectDirectory` field of a `Repository` message (set on requests such as `GetObjectDirectorySizeRequest`) into an absolute path: [1](#0-0) 

After confirming the path stays inside the storage root (`storage.ValidateRelativePath(storagePath, ...)`), the code computes:

```go
isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))
``` [2](#0-1) 

If this flag is true, the subsequent block that ties the object/quarantine directory to *this specific repository* via `QuarantineDirectoryPrefix(repo)` (a SHA1 hash of the repository's relative path) is skipped entirely: [3](#0-2) [4](#0-3) 

The only requirement to satisfy `isTransactionQuarantineDir` is that the *last path component* of the resolved (attacker-supplied) `GitObjectDirectory` is literally `quarantine` (or its parent is `quarantine` with a `tmp_objdir` prefix child) — this says nothing about whether that particular `quarantine` directory belongs to the requesting repository or to the requesting transaction. This mirrors the external report's flaw: a check meant to gate a privileged/trusted condition (`recoveredAddress == owner`) is bypassed because an unrelated OR-branch (`isApprovedForAll`) is satisfiable by an attacker-controlled value (the zero address), skipping the mandatory `recoveredAddress != 0` guard. Here, the mandatory "does this quarantine dir actually belong to me" guard (the `QuarantineDirectoryPrefix` check) is skipped whenever the attacker names their directory `quarantine`, which is trivially satisfiable since the transaction manager itself creates directories named exactly `quarantine` under a shared per-storage temporary state directory (`tx-state/quarantine`) for every write transaction: [5](#0-4) 

### Impact Explanation
`ObjectDirectoryPath` is reachable from unprivileged client-controlled RPC input: `GetObjectDirectorySizeRequest.Repository` is passed straight to `repo.ObjectDirectoryPath` with no restriction that `GitObjectDirectory` must be a directory the caller's own transaction created: [6](#0-5) 

By supplying a `GitObjectDirectory` value that resolves (after `filepath.Join`) to another concurrently-running transaction's staging quarantine directory (e.g. `../../<other-storage-relative-path>/tx-state/quarantine`) whose base directory name is `quarantine`, an attacker skips the per-repository ownership check and can have Gitaly walk/size an object directory belonging to a different repository/transaction. Because the same helper underlies quarantine/object-directory resolution used elsewhere in the object-access path (`GIT_OBJECT_DIRECTORY`/`GIT_ALTERNATE_OBJECT_DIRECTORIES` used for git commands), this class of check bypass is a cross-repository/cross-transaction object isolation weakness rather than a mere theoretical concern — it directly maps to the "cross-repository object access" category called out in the validation rules.

### Likelihood Explanation
The trigger condition (a directory literally named `quarantine`) is not attacker-chosen arbitrarily — it is the exact name Gitaly's own `TransactionManager` uses for legitimate quarantine directories during every write transaction, meaning the bypass condition is guaranteed to be satisfiable in normal operation, not just a contrived edge case. Exploitation requires only crafting the `GitObjectDirectory` field of a `Repository` proto in a routine RPC (`GetObjectDirectorySize` and any other path relying on `ObjectDirectoryPath`), which is achievable by any client capable of issuing Gitaly RPCs (e.g., a compromised or malicious internal caller, or any request path where `GitObjectDirectory` is not independently generated and locked down by Gitaly itself before being echoed back, as documented in the surrounding test suite around Rails round-tripping this field).

### Recommendation
Do not let the `isTransactionQuarantineDir` shortcut fully bypass ownership verification. Require that the ownership/prefix check documented for the "not `isTransactionQuarantineDir`" branch also be applied (or an equivalent verification that the resolved path was actually allocated for this repository's current transaction) whenever the directory is claimed to be a "transaction quarantine directory," instead of trusting the bare directory name `quarantine`. Concretely, change the logic from an OR that grants an exemption to an AND that additionally confirms the path was issued to the current transaction/repository (e.g., compare against the transaction's own recorded `quarantineDirectory`, not just a name pattern).

### Proof of Concept
1. Attacker (or malicious/compromised client) starts a `GetObjectDirectorySize` RPC against `repoA`.
2. In the request's `Repository`, sets `GitObjectDirectory` to a relative path that, once joined with `repoA`'s path, resolves within the storage root and ends in a directory literally named `quarantine` — for example a path traversal string pointing at the shared `tx-state/quarantine` staging directory used by another concurrently-committing transaction (as created in `transaction_manager.go`'s `Begin`).
3. `ObjectDirectoryPath` computes `isTransactionQuarantineDir = true` purely because `baseDir == "quarantine"`, and skips the `QuarantineDirectoryPrefix(repo)` ownership check that would otherwise reject a quarantine directory not belonging to `repoA`.
4. Gitaly proceeds to `os.Stat`/walk the foreign quarantine directory and returns its size in the RPC response, disclosing information about another transaction's/repository's staged object directory that the caller has no authorization to access.

func (repo *Repo) ObjectDirectoryPath(ctx context.Context) (string, error) {
	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", err
	}

	objectDirectoryPath := repo.GetGitObjectDirectory()
	if objectDirectoryPath == "" {
		return "", structerr.NewInvalidArgument("object directory path is not set")
	}

	storagePath, err := repo.locator.GetStorageByName(ctx, repo.GetStorageName())
	if err != nil {
		return "", fmt.Errorf("get storage by name: %w", err)
	}

	// Ensure the path points somewhere in the storage.
	relativeObjectDirectoryPath, err := storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))
	if err != nil {
		return "", structerr.NewInvalidArgument("validate relative path: %w", err)
	}

	parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
	baseDir := filepath.Base(relativeObjectDirectoryPath)
	isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

// QuarantineDirectoryPrefix returns a prefix for use in the temporary directory. The prefix is
// based on the relative repository path and will stay stable for any given repository. This allows
// us to verify that a given quarantine object directory indeed belongs to the repository at hand.
// Ideally, this function would directly be located in the quarantine module, but this is not
// possible due to cyclic dependencies.
func QuarantineDirectoryPrefix(repo Repository) string {
	hash := [20]byte{}
	if repo != nil {
		hash = sha1.Sum([]byte(repo.GetRelativePath()))
	}
	return fmt.Sprintf("quarantine-%x-", hash[:8])
}

func (s *server) GetObjectDirectorySize(ctx context.Context, in *gitalypb.GetObjectDirectorySizeRequest) (*gitalypb.GetObjectDirectorySizeResponse, error) {
	repository := in.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}
	repo := s.localRepoFactory.Build(repository)

	path, err := repo.ObjectDirectoryPath(ctx)
	if err != nil {
		return nil, err
	}
	// path is the objects directory path, not repo's path
	sizeInBytes, err := dirSizeInBytes(path, snapshot.NewDefaultFilter(ctx))
	if err != nil {
		return nil, fmt.Errorf("calculating directory size: %w", err)
	}

	return &gitalypb.GetObjectDirectorySizeResponse{Size: sizeInBytes / 1024}, nil
}
