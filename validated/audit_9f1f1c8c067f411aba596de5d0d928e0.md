## Analog Vulnerability Found

Nebula's certificate blocklist verification exhibits the same class of bug as the BLS banned-key issue: the check verifies one piece of authorization criteria but omits the "not banned" check for the signing authority.

### Title
CA blocklist entries do not prevent certificates issued by a blocklisted CA from being accepted - (File: `cert/ca_pool.go`)

### Summary
`CAPool.verify()` (used by both `VerifyCertificate` and `VerifyCachedCertificate`, which gate every Nebula handshake and hostinfo revalidation) only checks the leaf certificate's own fingerprint against the blocklist. It never checks whether the fingerprint of the *signing CA* (`signer.Fingerprint`) is blocklisted, so blocklisting a compromised/revoked CA fingerprint via `pki.blocklist` does not revoke any host certificates that CA has already issued.

### Finding Description
`(ncp *CAPool) verify` performs the following sequence: [1](#0-0) 

It calls `ncp.IsBlocklisted(certFp)` for the presented (leaf) certificate's fingerprint only, then resolves the issuing CA via `GetCAForCert`, checks curve match, expiry, and signature/CA constraints — but at no point does it call `ncp.IsBlocklisted(signer.Fingerprint)`.

Both public entry points inherit this gap: [2](#0-1) 

`BlocklistFingerprint`/`IsBlocklisted` operate on a flat map keyed by fingerprint with no distinction between "CA fingerprint" and "leaf cert fingerprint": [3](#0-2) 

Operationally, `pki.blocklist` is the mechanism operators use to revoke certificates (documented, and populated at load/reload time): [4](#0-3) 

Both the initial handshake authentication path and the ongoing hostinfo/tunnel-teardown recheck rely on this same `verify()` logic: [5](#0-4) [6](#0-5) 

This mirrors the BLS finding's root cause exactly: the code checks "is this thing part of the trusted set" (`isBLSPublicKeyPartOfLSDNetwork` / `GetCAForCert` succeeding) but omits "and is it/its issuer not banned" (`isBLSPublicKeyBanned` / checking `signer.Fingerprint` against the blocklist).

### Impact Explanation
If an operator discovers that an intermediate/subordinate CA's private key is compromised (or otherwise wants to revoke trust in a CA without removing it from the pool, e.g. to still validate its still-valid non-revoked certs is not the use case — but blocklisting is the only mechanism nebula exposes for revocation) and blocklists that CA's fingerprint via `pki.blocklist`, **every host certificate that CA has ever signed remains fully trusted** for both new handshakes and existing tunnels. This is a concrete authentication-bypass / revocation-bypass: an attacker holding a leaf certificate+key issued by the "banned" CA can still complete a Noise IX handshake and establish/keep an authenticated, encrypted overlay tunnel, since `certVerifier()` → `VerifyCertificate()` → `verify()` never rejects it.

### Likelihood Explanation
High likelihood of being triggered whenever an operator relies on `pki.blocklist` to revoke a compromised signing certificate rather than only ever blocklisting individual leaf-cert fingerprints. Since Nebula ships no separate "CRL" concept and documents `pki.blocklist` as the fingerprint revocation mechanism, this is a realistic operational scenario, not a contrived edge case, and any attacker with access to a key/cert previously signed by the now-blocklisted CA can exploit it with no additional prerequisites (no valid, non-revoked cert needed).

### Recommendation
In `(ncp *CAPool) verify`, after resolving `signer` via `GetCAForCert`, add a check equivalent to the leaf check:
```go
if ncp.IsBlocklisted(signer.Fingerprint) {
    return nil, ErrBlockListed
}
```
placed before (or alongside) the existing `ncp.IsBlocklisted(certFp)` check, so both `VerifyCertificate` and `VerifyCachedCertificate` reject certificates transitively signed by a blocklisted CA.

### Proof of Concept
1. Create CA `ca1` and issue host certificate `hostA` signed by `ca1`, add `ca1` to the `CAPool` via `AddCA`.
2. Successfully verify `hostA` with `caPool.VerifyCertificate(now, hostA)` — succeeds as expected.
3. Simulate CA compromise/revocation: `caPool.BlocklistFingerprint(ca1Fingerprint)` (the CA's own fingerprint, as an operator would do via `pki.blocklist`).
4. Call `caPool.VerifyCertificate(now, hostA)` again — it still returns `nil` error (no `ErrBlockListed`), because `verify()` only checks `IsBlocklisted(certFp)` for `hostA`'s own fingerprint, never `ca1Fingerprint`. `hostA` remains fully trusted and can complete a handshake via `HandshakeManager.certVerifier()` and keep its tunnel alive across `connectionManager.isInvalidCertificate` rechecks.

// VerifyCertificate verifies the certificate is valid and is signed by a trusted CA in the pool.
// If the certificate is valid then the returned CachedCertificate can be used in subsequent verification attempts
// to increase performance.
func (ncp *CAPool) VerifyCertificate(now time.Time, c Certificate) (*CachedCertificate, error) {
	if c == nil {
		return nil, fmt.Errorf("no certificate")
	}
	fp, err := c.Fingerprint()
	if err != nil {
		return nil, fmt.Errorf("could not calculate fingerprint to verify: %w", err)
	}

	signer, err := ncp.verify(c, now, fp, "")
	if err != nil {
		return nil, err
	}

	// Pre nebula v1.10.3 could generate signatures in either high or low s form and validation
	// of signatures allowed for either. Nebula v1.10.3 and beyond clamps signature generation to low-s form
	// but validation still allows for either. Since a change in the signature bytes affects the fingerprint, we
	// need to test both forms until such a time comes that we enforce low-s form on signature validation.
	fp2, err := CalculateAlternateFingerprint(c)
	if err != nil {
		return nil, fmt.Errorf("could not calculate alternate fingerprint to verify: %w", err)
	}
	if fp2 != "" && ncp.IsBlocklisted(fp2) {
		return nil, ErrBlockListed
	}

	cc := CachedCertificate{
		Certificate:       c,
		InvertedGroups:    make(map[string]struct{}),
		Fingerprint:       fp,
		fingerprint2:      fp2,
		signerFingerprint: signer.Fingerprint,
	}

	for _, g := range c.Groups() {
		cc.InvertedGroups[g] = struct{}{}
	}

	return &cc, nil
}

// VerifyCachedCertificate is the same as VerifyCertificate other than it operates on a pre-verified structure and
// is a cheaper operation to perform as a result.
func (ncp *CAPool) VerifyCachedCertificate(now time.Time, c *CachedCertificate) error {
	// Check any available alternate fingerprint forms for this certificate, re P256 high-s/low-s
	if c.fingerprint2 != "" && ncp.IsBlocklisted(c.fingerprint2) {
		return ErrBlockListed
	}

	_, err := ncp.verify(c.Certificate, now, c.Fingerprint, c.signerFingerprint)
	return err
}

func (ncp *CAPool) verify(c Certificate, now time.Time, certFp string, signerFp string) (*CachedCertificate, error) {
	if ncp.IsBlocklisted(certFp) {
		return nil, ErrBlockListed
	}

	signer, err := ncp.GetCAForCert(c)
	if err != nil {
		return nil, err
	}

	if signer.Certificate.Curve() != c.Curve() {
		return nil, ErrCurveMismatch
	}

	if signer.Certificate.Expired(now) {
		return nil, ErrRootExpired
	}

	if c.Expired(now) {
		return nil, ErrExpired
	}

	// If we are checking a cached certificate then we can bail early here
	// Either the root is no longer trusted or everything is fine
	if len(signerFp) > 0 {
		if signerFp != signer.Fingerprint {
			return nil, ErrFingerprintMismatch
		}
		return signer, nil
	}
	if !c.CheckSignature(signer.Certificate.PublicKey()) {
		return nil, ErrSignatureMismatch
	}

	err = CheckCAConstraints(signer.Certificate, c)
	if err != nil {
		return nil, err
	}

	return signer, nil
}

func (cm *connectionManager) isInvalidCertificate(now time.Time, hostinfo *HostInfo) bool {
	remoteCert := hostinfo.GetCert()
	if remoteCert == nil {
		return false //don't tear down tunnels for handshakes in progress
	}

	caPool := cm.intf.pki.GetCAPool()
	err := caPool.VerifyCachedCertificate(now, remoteCert)
	if err == nil {
		return false //cert is still valid! yay!
	} else if err == cert.ErrBlockListed { //avoiding errors.Is for speed
		// Block listed certificates should always be disconnected
		hostinfo.logger(cm.l).Info("Remote certificate is blocked, tearing down the tunnel",
			"error", err,
			"fingerprint", remoteCert.Fingerprint,
		)
		return true
	} else if cm.intf.disconnectInvalid.Load() {
		hostinfo.logger(cm.l).Info("Remote certificate is no longer valid, tearing down the tunnel",
			"error", err,
			"fingerprint", remoteCert.Fingerprint,
		)
		return true
	} else {
		//if we reach here, the cert is no longer valid, but we're configured to keep tunnels from now-invalid certs open
		return false
	}
}
