### Title
Unauthenticated `/shutdown` HTTP endpoint permanently terminates the signer event receiver - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` treats any HTTP POST to `/shutdown` on the signer's event-ingestion port as a legitimate operator stop signal, with no authentication, token, or origin check. Any remote party able to reach that port can send a single crafted POST to permanently halt the signer's event loop.

### Finding Description
The broken equality: "termination of the event loop" is supposed to equal "an operator-issued stop signal via `SignerStopSignaler::send()`", but the code instead equates it with "any HTTP request whose URL path is `/shutdown`." In `next_event`, the branch: [1](#0-0) 
unconditionally executes `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `EventError::Terminated` as soon as the URL matches `/shutdown`, regardless of the request's origin, body, headers, or any secret. There is no comparison against a shared secret, no check of the peer address against `127.0.0.1`/loopback, and no validation tying the request to the same-process `SignerStopSignaler` defined at [2](#0-1) , which itself just opens a plain TCP connection and sends the same unauthenticated `POST /shutdown` bytes. This means the "trusted" stop path and an attacker's forged path are byte-for-byte indistinguishable at the receiver.

Once `stop_signal` is set, `is_stopped()` returns true and `main_loop` breaks out of its loop at [3](#0-2) , permanently ending all further event ingestion (StackerDB chunk events, burn block events, new block events, block-validation responses) for the life of the process — the signer must be manually restarted.

### Impact Explanation
A single crafted HTTP POST from any party able to open a TCP connection to the signer's event port causes complete, permanent denial of the signer's event stream: no further miner/signer StackerDB messages, burn blocks, new blocks, or block-validation responses are delivered to the signer's runloop until the process is restarted. This matches the Critical category ("remote crash/unauthenticated DoS from few messages") since it is a one-message, unauthenticated denial-of-service against the signer's control-plane ingestion.

### Likelihood Explanation
No privileged role, secret, or prior state is required — only network reachability to the bound event-receiver socket. The event receiver binds a plain `tiny_http::HttpServer` on a configured address/port with no authentication mechanism (`bind`, at [4](#0-3) ). If that address is not strictly restricted to loopback by deployment/firewall configuration, remote unprivileged attackers can trivially reach it since the code itself performs no access control. The attack requires exactly one TCP connection and one HTTP request, making it trivial and fully repeatable against any restart.

### Recommendation
Require the `/shutdown` request to be authenticated as coming from the trusted local stop-signaler — e.g., have `SignerStopSignaler` include a random per-process secret (generated at `bind()` time and known only to `get_stop_signaler()`), and have `next_event` compare that secret from the request body/header before setting `stop_signal`. Alternatively/additionally, enforce that the event server only accepts connections from loopback (verify peer address) and/or bind it only to `127.0.0.1` by default, rejecting non-local shutdown requests outright.

### Proof of Concept
```rust
// libsigner/src/events.rs (test) or an external integration test
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use std::thread;

use libsigner::{SignerEventReceiver, EventReceiver};

#[test]
fn unauthenticated_remote_shutdown_dos() {
    let mut receiver: SignerEventReceiver<SomeMessageType> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    let handle = thread::spawn(move || {
        receiver.main_loop(); // runs until stop_signal set or channel error
    });

    // Attacker: unrelated socket, no secret, no trusted role
    let mut stream = TcpStream::connect(bound).unwrap();
    let body = "attacker controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        bound, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // main_loop should exit due to EventError::Terminated from the unauthenticated request
    handle.join().unwrap();
    // Assert: no further forwarded events are ever received after this point,
    // proving permanent DoS from a single unauthenticated POST.
}
```
