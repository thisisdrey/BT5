### Title
Unauthenticated remote `/shutdown` request permanently halts the signer's event receiver - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` dispatches solely on `request.url()` string equality with no check on the caller's identity, so any TCP client that can reach the bound event-receiver socket can POST to `/shutdown` and permanently stop the signer's event loop. This turns what is intended as a local-node-only control channel into a remotely triggerable, single-request denial of service.

### Finding Description
In `SignerEventReceiver::next_event` [1](#0-0) , after accepting a connection via `http_server.recv()`, the code branches purely on the URL path string and HTTP method — there is no shared secret, token, or peer-identity check anywhere in this function or in `bind()` [2](#0-1) . When `request.url() == "/shutdown"`, the handler unconditionally does `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `Err(EventError::Terminated)` [3](#0-2) . The intended caller of this control-plane endpoint is the signer's own paired stacks-node process — the "legitimate" shutdown path is `SignerStopSignaler::send`, which itself just opens a plain `TcpStream` to `self.local_addr` and writes a raw `POST /shutdown` HTTP request with no credential attached [4](#0-3) . Since the wire protocol accepted by the server is identical for the legitimate caller and any other TCP peer, the equality "party permitted to shut down the event loop == local node" is broken; the real permitted set is "any TCP peer that can complete an HTTP request to this socket." In `main_loop`, receiving `EventError::Terminated` causes an immediate `break`, ending event processing for the process's lifetime [5](#0-4) . No other guard (auth header, source-IP allowlist, secret token) exists in this file to intercept this before the `stop_signal` store.

### Impact Explanation
A single unauthenticated POST to `/shutdown` sets `stop_signal` to `true`, after which `is_stopped()` returns `true` on every subsequent iteration of `main_loop`, so the receiver stops calling `next_event()` and the signer stops receiving StackerDB chunks, block proposals, burn-block events, and new-block events from the node it's paired with [5](#0-4) [6](#0-5) . This is a one-shot, low-cost, remotely triggerable denial of service against a signer's event pipeline, matching the "Critical – remote crash/unauthenticated DoS from few messages" category, provided the event-receiver socket is reachable by the attacker.

### Likelihood Explanation
The only precondition is that the configured `endpoint` for the signer's event receiver is bound to an address reachable by the attacker (i.e., not restricted to loopback/firewalled). If so, exploitation requires a single crafted HTTP POST with no secret, credential, or prior state — attacker cost is trivial and the action is repeatable (each connection attempt after the stop can also be sent, though one is sufficient). Whether this is remotely reachable in practice depends entirely on the signer operator's network/firewall configuration of the event-observer endpoint, which is outside this file's control.

### Recommendation
Add authentication/authorization to `next_event` before honoring `/shutdown` (and ideally all POST endpoints): e.g., require a pre-shared secret/token in a header that only the paired node and the in-process `SignerStopSignaler` know, or bind the event-receiver socket to loopback only and document that binding it non-locally is unsupported/unsafe. At minimum, gate `/shutdown` on a check that isn't satisfiable by an arbitrary remote TCP client.

### Proof of Concept
Rust test plan in `libsigner::events` tests module:
1. Construct a `SignerEventReceiver::<T>` and call `bind()` on `127.0.0.1:0` (or a non-loopback test address to simulate remote exposure), as done for `local_addr` in `bind()` [2](#0-1) .
2. Spawn `main_loop()` (or directly call `next_event()`) in a thread.
3. From a plain `std::net::TcpStream::connect(bound_addr)`, write the raw HTTP request `"POST /shutdown HTTP/1.1\r\nHost: ...\r\nConnection: close\r\nContent-Length: 0\r\n\r\n"` with no credential/header (mirroring the format in `SignerStopSignaler::send` [7](#0-6)  but from an unrelated `TcpStream`, not the signaler).
4. Assert that `event_receiver.is_stopped()` becomes `true` (checking `stop_signal.load(Ordering::SeqCst)` via `is_stopped()` [8](#0-7) ) and that `next_event()` subsequently returns `Err(EventError::Terminated)`, confirming any TCP peer — not just the paired node — can halt the receiver.

    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {
                info!("Event receiver stopped");
                break;
            }
            let next_event = match self.next_event() {
                Ok(event) => event,
                Err(EventError::UnrecognizedEvent(..)) => {
                    // got an event that we don't care about (not a problem)
                    continue;
                }
                Err(EventError::Terminated) => {
                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };
            if !self.forward_event(next_event) {
                info!("Failed to forward event");
                break;
            }
        }
        info!("Event receiver main loop exit");
    }

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
