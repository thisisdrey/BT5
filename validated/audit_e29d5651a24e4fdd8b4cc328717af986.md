Based on my research, this advisory (CVE-2024-7631 / GHSA-69x5-hjg4-m267) concerns `github.com/openshift/console`'s `pkg/plugins/handlers/unsafely.go`, a package that does not exist anywhere in the `Kohvert/go--005` repository, which is the Go language/toolchain/stdlib source tree itself. This is not a case where a downstream Go module vendors or reimplements that vulnerable code.

I searched the repository for the actual bug-class analog — unsanitized request parameters used to construct a filesystem path via `filepath.Join`/`os.Open` in an HTTP handler — and found only code that actively defends against exactly this pattern:

- `net/http.Dir.Open` cleans the path with `path.Clean("/" + name)[1:]` and calls `filepath.Localize` before joining, returning `errInvalidUnsafePath` if the path can't be safely localized [1](#0-0) .
- `net/http.ServeFile` and `ServeFileFS` explicitly reject any request whose `r.URL.Path` contains a `..` element via `containsDotDot`, specifically to protect callers who "might unsafely use filepath.Join on r.URL.Path without sanitizing it" [2](#0-1) , with a dedicated regression test `TestServeFile_DotDot` [3](#0-2) .
- The `fileHandler.ServeHTTP` used by `FileServer` cleans `r.URL.Path` with `path.Clean` before it ever reaches `serveFile` [4](#0-3) .
- `path/filepath.IsLocal` and `Localize` are the general-purpose primitives Go's stdlib uses to guarantee a request-controlled path element can't escape a base directory [5](#0-4) .
- Even the internal `cmd/go/internal/vcweb` test HTTP server cleans the URL path with `path.Clean` before joining it against a script directory [6](#0-5) .

I found no production, unauthenticated/attacker-reachable Go entry point in this repository that mirrors the OpenShift Console flaw (raw query-parameter values fed directly into `filepath.Join`/file-open without cleaning or `..`-rejection). The closest candidates (`net/http/fs.go`) are precisely the code that was hardened to prevent this bug class, not an instance of it.

// As a precaution, ServeFile will reject requests where r.URL.Path
// contains a ".." path element; this protects against callers who
// might unsafely use [filepath.Join] on r.URL.Path without sanitizing
// it and then use that filepath.Join result as the name argument.
//
// As another special case, ServeFile redirects any request where r.URL.Path
// ends in "/index.html" to the same path, without the final
// "index.html". To avoid such redirects either modify the path or
// use [ServeContent].
//
// Outside of those two special cases, ServeFile does not use
// r.URL.Path for selecting the file or directory to serve; only the
// file or directory provided in the name argument is used.
func ServeFile(w ResponseWriter, r *Request, name string) {
	if containsDotDot(r.URL.Path) {
		// Too many programs use r.URL.Path to construct the argument to
		// serveFile. Reject the request under the assumption that happened
		// here and ".." may not be wanted.
		// Note that name might not contain "..", for example if code (still
		// incorrectly) used filepath.Join(myDir, r.URL.Path).
		serveError(w, "invalid URL path", StatusBadRequest)
		return
	}
	dir, file := filepath.Split(name)
	serveFile(w, r, Dir(dir), file, false)
}

// IsLocal reports whether path, using lexical analysis only, has all of these properties:
//
//   - is within the subtree rooted at the directory in which path is evaluated
//   - is not an absolute path
//   - is not empty
//   - on Windows, is not a reserved name such as "NUL"
//
// If IsLocal(path) returns true, then
// Join(base, path) will always produce a path contained within base and
// Clean(path) will always produce an unrooted path with no ".." path elements.
//
// IsLocal is a purely lexical operation.
// In particular, it does not account for the effect of any symbolic links
// that may exist in the filesystem.
func IsLocal(path string) bool {
	return filepathlite.IsLocal(path)
}

// Localize converts a slash-separated path into an operating system path.
// The input path must be a valid path as reported by [io/fs.ValidPath].
//
// Localize returns an error if the path cannot be represented by the operating system.
// For example, the path a\b is rejected on Windows, on which \ is a separator
// character and cannot be part of a filename.
//
// The path returned by Localize will always be local, as reported by IsLocal.
func Localize(path string) (string, error) {
	return filepathlite.Localize(path)
