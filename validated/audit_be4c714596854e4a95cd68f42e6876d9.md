### Title
Credential disclosure via unredacted `GOPROXY`/`GOAUTH` values in `go env` and `go bug` output - ([File: src/cmd/go/internal/envcmd/env.go])

### Summary
`cmd/go`'s `MkEnv` function collects the raw, unredacted values of `GOPROXY` and `GOAUTH` into the environment variable list printed by `go env` and included in `go bug` reports. Because `GOPROXY` may legitimately contain HTTP Basic Auth credentials embedded in its URL (`https://user:pass@proxy.example.com`) and `GOAUTH` custom commands can embed tokens/secrets in their argument strings, any user who runs `go env`, `go env -json`, or (most dangerously) `go bug`—which is explicitly designed to be pasted into a public GitHub issue—will disclose those credentials verbatim.

### Finding Description
A user configures `GOPROXY=https://user:secret@corp-proxy.example.com` (a documented, supported way to authenticate to a private module proxy) or a custom `GOAUTH` command string containing a secret argument. `cmd/go/internal/envcmd.MkEnv` (`src/cmd/go/internal/envcmd/env.go:79-127`) reads `cfg.GOPROXY` and `cfg.GOAUTH` directly and stores them as plain `cfg.EnvVar{Value: ...}` entries — no call to `net/url.URL.Redacted()` or any other credential-scrubbing step, unlike the rest of `cmd/go` which consistently redacts URLs before logging or erroring (e.g. `proxyRepo.redactedBase` in `src/cmd/go/internal/modfetch/proxy.go:184-227`, and the pervasive use of `Redacted()` in `src/cmd/go/internal/web/http.go`). `envcmd.PrintEnv` (`src/cmd/go/internal/envcmd/env.go:513-551`) then writes `fmt.Fprintf(w, "%s=%s\n", e.Name, shellQuote(e.Value))` for every entry, emitting the raw credential-bearing string. This same `MkEnv`/`PrintEnv` pipeline is invoked both by `go env` and by `printGoEnv` in `src/cmd/go/internal/bug/bug.go:107-112`, which is called from `printEnvDetails`, part of the `go bug` command whose entire purpose is to produce a report that the user submits to the public golang/go GitHub issue tracker.

### Impact Explanation
Any secret embedded in `GOPROXY` (basic-auth proxy credentials) or `GOAUTH` (custom auth command arguments) is disclosed in cleartext to:
- The terminal/log output of `go env` (visible to anyone with shell/log access, similar to syft's `-vv`/`-vvv` log leakage), and
- A `go bug`-generated bug report, which is explicitly meant to be pasted into a public GitHub issue — a direct, active disclosure vector with no attacker action required beyond convincing/observing the victim running a standard, documented troubleshooting command.

This is a genuine secret-disclosure issue (CWE-200/CWE-532 analog) but the "attacker" role here is essentially the victim's own reporting workflow rather than an external attacker, so this would likely be evaluated on Go's PUBLIC track as a low-severity hardening/privacy issue rather than an urgent security vulnerability, since it requires the user to (a) put credentials in the URL/command form (an already-known-risky pattern) and (b) run a diagnostic/reporting command and paste its output publicly.

### Likelihood Explanation
Using `GOPROXY=https://user:pass@host` is a documented, common way to authenticate to private proxies, and `go bug` is a normal part of the victim's troubleshooting/reporting workflow. No special privileges are needed; the disclosure happens purely as a side effect of standard tool usage by the credential owner themselves.

### Recommendation
Redact credentials before including `GOPROXY` (and any `GOAUTH` command with embedded secrets) in `MkEnv`'s output, e.g. by parsing the value as a comma-separated list of URLs and applying `url.URL.Redacted()` to each entry (mirroring the existing pattern in `modfetch/proxy.go` and `web/http.go`) before storing it in `cfg.EnvVar.Value`, or by masking anything matching `user:pass@` syntax prior to printing in both `go env` and `go bug`.

import (
	"bytes"
	"strings"
	"testing"

	"cmd/go/internal/cfg"

func TestPrintEnvLeaksProxyCredentials(t *testing.T) {
	env := []cfg.EnvVar{
		{Name: "GOPROXY", Value: "https://user:supersecret@corp-proxy.example.com"},
	}
	var buf bytes.Buffer
	PrintEnv(&buf, env, false)

	if strings.Contains(buf.String(), "supersecret") {
		t.Fatalf("credential leaked in go env output: %s", buf.String())
	}
}

// PrintEnv prints the environment variables to w.
func PrintEnv(w io.Writer, env []cfg.EnvVar, onlyChanged bool) {
	env = slices.Clone(env)
	slices.SortFunc(env, func(x, y cfg.EnvVar) int { return strings.Compare(x.Name, y.Name) })

	for _, e := range env {
		if e.Name != "TERM" {
			if runtime.GOOS != "plan9" && bytes.Contains([]byte(e.Value), []byte{0}) {
				base.Fatalf("go: internal error: encountered null byte in environment variable %s on non-plan9 platform", e.Name)
			}
			if onlyChanged && !e.Changed {
				continue
			}
			switch runtime.GOOS {
			default:
				fmt.Fprintf(w, "%s=%s\n", e.Name, shellQuote(e.Value))
			case "plan9":
				if strings.IndexByte(e.Value, '\x00') < 0 {
					fmt.Fprintf(w, "%s='%s'\n", e.Name, strings.ReplaceAll(e.Value, "'", "''"))
				} else {
					v := strings.Split(e.Value, "\x00")
					fmt.Fprintf(w, "%s=(", e.Name)
					for x, s := range v {
						if x > 0 {
							fmt.Fprintf(w, " ")
						}
						fmt.Fprintf(w, "'%s'", strings.ReplaceAll(s, "'", "''"))
					}
					fmt.Fprintf(w, ")\n")
				}
			case "windows":
				if hasNonGraphic(e.Value) {
					base.Errorf("go: stripping unprintable or unescapable characters from %%%q%%", e.Name)
				}
				fmt.Fprintf(w, "set %s=%s\n", e.Name, batchEscape(e.Value))
			}
		}
	}
}

type proxyRepo struct {
	url          *url.URL // The combined module proxy URL joined with the module path.
	path         string   // The module path (unescaped).
	redactedBase string   // The base module proxy URL in [url.URL.Redacted] form.

	listLatestOnce sync.Once
	listLatest     *RevInfo
	listLatestErr  error
}

func newProxyRepo(baseURL, path string) (Repo, error) {
	// Parse the base proxy URL.
	base, err := url.Parse(baseURL)
	if err != nil {
		return nil, err
	}
	redactedBase := base.Redacted()
	switch base.Scheme {
	case "http", "https":
		// ok
	case "file":
		if *base != (url.URL{Scheme: base.Scheme, Path: base.Path, RawPath: base.RawPath}) {
			return nil, fmt.Errorf("invalid file:// proxy URL with non-path elements: %s", redactedBase)
		}
	case "":
		return nil, fmt.Errorf("invalid proxy URL missing scheme: %s", redactedBase)
	default:
		return nil, fmt.Errorf("invalid proxy URL scheme (must be https, http, file): %s", redactedBase)
	}

	// Append the module path to the URL.
	url := base
	enc, err := module.EscapePath(path)
	if err != nil {
		return nil, err
	}
	url.Path = strings.TrimSuffix(base.Path, "/") + "/" + enc
	url.RawPath = strings.TrimSuffix(base.RawPath, "/") + "/" + pathEscape(enc)

	return &proxyRepo{url, path, redactedBase, sync.Once{}, nil, nil}, nil
}

// Redacted is like [URL.String] but replaces any password with "xxxxx".
// Only the password in u.User is redacted.
func (u *URL) Redacted() string {
	if u == nil {
		return ""
	}

	ru := *u
	if _, has := ru.User.Password(); has {
		ru.User = UserPassword(ru.User.Username(), "xxxxx")
	}
	return ru.String()
}
