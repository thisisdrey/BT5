### Title
`DelegateResourceActuator`/`UnDelegateResourceActuator` reduce owner's TRON Power without updating votes, allowing unbacked (over-subscribed) SR votes and stale vote rewards - (File: actuator/src/main/java/org/tron/core/actuator/DelegateResourceActuator.java)

### Summary
This is analogous to the DYAD `liquidate()` bug where a required post-state-change accounting step (`updateXP`) can be skipped, leaving a stale/incorrect balance snapshot. In java-tron, `DelegateResourceActuator.execute()` reduces the owner account's `FrozenV2Balance` (i.e., its TRON Power backing bandwidth/energy) via `addFrozenBalanceForBandwidthV2(-delegateBalance)` / `addFrozenBalanceForEnergyV2(-delegateBalance)` [1](#0-0) , but never calls `mortgageService.withdrawReward()` nor an equivalent "vote reconciliation" step, unlike the sibling actuator `UnfreezeBalanceV2Actuator`, which explicitly withdraws pending vote reward and then proportionally shrinks the account's votes to fit within the new (reduced) TRON Power via `updateVote()` [2](#0-1) .

### Finding Description
`UnfreezeBalanceV2Actuator.updateVote()` explicitly re-validates the invariant that `ownedTronPower >= totalVote * TRX_PRECISION` and, if not, proportionally trims the account's votes to fit the new lower TRON Power [3](#0-2) . The TVM-reachable `UnfreezeBalanceProcessor.execute()` does the same check for old-style freeze via `VoteRewardUtil.withdrawReward` and vote clearing when `accountCapsule.getTronPower() < usedTronPower * TRX_PRECISION` [4](#0-3) .

`DelegateResourceActuator`, however, also decreases the owner's TRON Power (by moving frozen balance into `DelegatedFrozenV2Balance`) but performs none of this reconciliation: it does not call `mortgageService.withdrawReward()`/`VoteRewardUtil.withdrawReward()`, and it does not check or shrink `accountCapsule.getVotesList()` against the new, lower TRON Power [5](#0-4) . This means an account can freeze balance, vote for witnesses with the full TRON Power, then delegate that same frozen balance away to another account (which is a completely separate, allowed operation not requiring unfreezing first), retaining full voting weight in `VotesStore`/`AccountCapsule.votesList` that is no longer backed by any TRON Power the account actually still owns.

This is directly analogous to the reported bug class: a state-changing operation (`vault.move`/`delegateResource`) alters the underlying backing asset/resource, but the dependent accounting structure (`dyadXP`/vote weight & reward snapshot) is not updated in lockstep, leaving a stale, unbacked balance (XP balance / vote weight) that downstream logic (balance computation / SR election & `VoteRewardUtil.computeReward`) continues to trust.

### Impact Explanation
Unbacked votes let an account inflate its influence on the Super Representative (witness) election process and continue to accrue/claim vote-based rewards computed from `computeReward(beginCycle, endCycle, accountCapsule)` in `VoteRewardUtil`/`MortgageService`, using a votes snapshot that is no longer economically backed by frozen TRX [6](#0-5) . This can be used to (a) win witness elections or manipulate the SR list without maintaining the required stake, and (b) receive/claim voting rewards disproportionate to actual locked TRX, which constitutes an unauthorized/unbacked economic advantage.

### Likelihood Explanation
`DelegateResource` is a normal, permissionless transaction any account holder can broadcast, requiring no special privilege beyond having frozen balance for bandwidth/energy (`supportDR`/`supportUnfreezeDelay` feature flags must be enabled, which they are on current mainnet). No malicious validator, witness, or peer collusion is required — a single account performing freeze → vote → delegate is sufficient to reach this state, making likelihood high.

### Recommendation
Mirror the reconciliation logic already present in `UnfreezeBalanceV2Actuator.updateVote()` inside `DelegateResourceActuator.execute()` (and its `UnDelegateResourceActuator` counterpart): after adjusting `FrozenV2Balance`/`DelegatedFrozenV2Balance`, call `mortgageService.withdrawReward(ownerAddress)` and re-check that `ownerCapsule`'s total vote count does not exceed its updated TRON Power, proportionally shrinking `votesList`/`VotesStore` entries when necessary, exactly as done for the unfreeze path.

### Proof of Concept
1. Account `A` freezes X TRX for bandwidth, obtaining TRON Power = X.
2. `A` calls `VoteWitnessContract` to vote the full X TRON Power for witness `W` (`VoteWitnessActuator.countVoteAccount` records `X` TRON Power worth of votes) [7](#0-6) .
3. `A` calls `DelegateResourceContract` to delegate the same X frozen balance (for bandwidth or energy) to account `B`. `DelegateResourceActuator.execute()` reduces `A`'s `FrozenV2BalanceForBandwidth` by X and increases `DelegatedFrozenV2BalanceForBandwidth` by X, but never touches `A`'s `votesList` or triggers reward/vote reconciliation [8](#0-7) .
4. `A` now has TRON Power ≈ 0 (all delegated away) but still holds X worth of active votes for `W` in `VotesStore`, which continue to count toward `W`'s election weight and toward `A`'s reward computation in `VoteRewardUtil.computeReward`/`MortgageService.computeReward`, unbacked by any TRON Power `A` still controls.

  public void withdrawReward(byte[] address) {
    if (!dynamicPropertiesStore.allowChangeDelegation()) {
      return;
    }
    AccountCapsule accountCapsule = accountStore.get(address);
    long beginCycle = delegationStore.getBeginCycle(address);
    long endCycle = delegationStore.getEndCycle(address);
    long currentCycle = dynamicPropertiesStore.getCurrentCycleNumber();
    long reward = 0;
    if (beginCycle > currentCycle || accountCapsule == null) {
      return;
    }
    if (beginCycle == currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        return;
      }
    }
    //withdraw the latest cycle reward
    if (beginCycle + 1 == endCycle && beginCycle < currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        reward = computeReward(beginCycle, endCycle, account);
        adjustAllowance(address, reward);
        reward = 0;
        logger.info("Latest cycle reward {}, {}.", beginCycle, account.getVotesList());
      }
      beginCycle += 1;
    }
    //
    endCycle = currentCycle;
    if (CollectionUtils.isEmpty(accountCapsule.getVotesList())) {
      delegationStore.setBeginCycle(address, endCycle + 1);
      return;
    }
    if (beginCycle < endCycle) {
      reward += computeReward(beginCycle, endCycle, accountCapsule);
      adjustAllowance(address, reward);
    }
    delegationStore.setBeginCycle(address, endCycle);
    delegationStore.setEndCycle(address, endCycle + 1);
    delegationStore.setAccountVote(endCycle, address, accountCapsule);
    logger.info("Adjust {} allowance {}, now currentCycle {}, beginCycle {}, endCycle {}, "
            + "account vote {}.", Hex.toHexString(address), reward, currentCycle,
        beginCycle, endCycle, accountCapsule.getVotesList());
  }

  private void countVoteAccount(VoteWitnessContract voteContract) {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    VotesStore votesStore = chainBaseManager.getVotesStore();
    MortgageService mortgageService = chainBaseManager.getMortgageService();
    byte[] ownerAddress = voteContract.getOwnerAddress().toByteArray();

    VotesCapsule votesCapsule;

    //
    mortgageService.withdrawReward(ownerAddress);

    AccountCapsule accountCapsule = accountStore.get(ownerAddress);

    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    if (dynamicStore.supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    if (!votesStore.has(ownerAddress)) {
      votesCapsule = new VotesCapsule(voteContract.getOwnerAddress(),
          accountCapsule.getVotesList());
    } else {
      votesCapsule = votesStore.get(ownerAddress);
    }

    accountCapsule.clearVotes();
    votesCapsule.clearNewVotes();

    voteContract.getVotesList().forEach(vote -> {
      logger.debug("countVoteAccount, address[{}]",
          ByteArray.toHexString(vote.getVoteAddress().toByteArray()));

      votesCapsule.addNewVotes(vote.getVoteAddress(), vote.getVoteCount());
      accountCapsule.addVotes(vote.getVoteAddress(), vote.getVoteCount());
    });

    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    votesStore.put(ownerAddress, votesCapsule);
  }
