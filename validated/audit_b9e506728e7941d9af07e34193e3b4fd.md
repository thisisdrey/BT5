Based on my investigation, I found a genuine analog: an unbounded tar-extraction path-join used to unpack a WAL log entry's archive during Gitaly's recovery tooling, which lacks the containment ("does the resulting path stay inside the target dir") check that a sibling extraction routine in the same codebase does perform.

### Title
Tar extraction path traversal (Zip-Slip) in WAL log-entry recovery replay - ([File: internal/cli/gitaly/subcmd_recovery_replay.go])

### Summary
`extractArchive` in `internal/cli/gitaly/subcmd_recovery_replay.go` extracts a tar archive representing a WAL log entry into a staging directory but never validates that each entry's resolved path stays inside that directory before writing it, unlike the equivalent extraction routine `extractTarToDirectory` in `internal/gitaly/service/repository/replicate.go`, which explicitly checks `strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator))` for every entry type (regular file, symlink, hardlink) before acting on it.

### Finding Description
`extractArchive` reads each tar header and computes the target path with a bare `filepath.Join(path, header.Name)` [1](#0-0) , then unconditionally calls `os.MkdirAll` for directories or `os.OpenFile`+`io.Copy` for regular files at that path. There is no check that the joined path remains within `path` (the staging directory) — an entry with a name like `../../../etc/cron.d/evil` would escape the intended `stagingDir` created in `processLogEntry` [2](#0-1) .

By contrast, the codebase already recognizes this exact class of bug and fixes it elsewhere: `extractTarToDirectory` in `replicate.go` cleans the target directory and, for every header type (`TypeDir`, `TypeReg`, `TypeSymlink`, `TypeLink`), verifies the resolved path/target is contained within `targetDir` before creating it [3](#0-2) . The near-identical `extractBackup` helper in `internal/cli/gitaly/subcmd_recovery_restore.go` also performs the join without any containment check [4](#0-3) , showing the same missing-check pattern was copy/pasted into a second recovery code path.

This matches the reported bug class ("missing existence/validity check before performing a subsequent trusted operation") mapped onto Gitaly's archive-extraction surface, which is explicitly an in-scope analog category.

### Impact Explanation
If an attacker can influence the content of a WAL log-entry archive (or a backup archive consumed by `gitaly recovery restore`) — for example via a compromised/tampered backup sink, a malicious replica, or corruption/injection into the log-entry store that `rc.logEntryStore.GetReader` reads from — a crafted tar entry with `../` path segments (or an absolute path via `filepath.Join` normalization quirks) could write or overwrite arbitrary files outside the intended staging/target directory, up to and including files elsewhere on the Gitaly host's filesystem, when the administrator runs `gitaly recovery replay`/`restore`. This is a directory-escape / arbitrary file write primitive on a privileged host tool.

### Likelihood Explanation
Exploitation requires an attacker to control the content ingested by these recovery archives (log-entry store or backup sink) rather than being reachable directly from ordinary git push/fetch traffic, so the practical likelihood depends on the trust model of the WAL archive/backup storage. Within the stated scope (storage-path resolution / archive extraction escape), this is a concrete, code-verifiable missing containment check with a proven working fix pattern already present elsewhere in the same repository, which increases confidence that this is a real gap rather than a false positive — but it is lower likelihood than an RPC directly reachable by an unprivileged git client, since it fires only when the recovery/replay CLI tooling processes an attacker-influenced archive.

### Recommendation
Apply the same containment validation used in `extractTarToDirectory` (`replicate.go`) to `extractArchive` (`subcmd_recovery_replay.go`) and `extractBackup` (`subcmd_recovery_restore.go`): after computing `target := filepath.Join(path, header.Name)`, verify `strings.HasPrefix(target, filepath.Clean(path)+string(os.PathSeparator))` (or equivalent) before performing `MkdirAll`/`OpenFile`, and reject the archive/log entry with an error otherwise. Also validate symlink/hardlink targets if such entry types are ever expected in these archives.

### Proof of Concept
1. Craft a tar stream containing a header with `Name: "../../../tmp/evil"` and `Typeflag: tar.TypeReg`.
2. Have this stream be returned by `rc.logEntryStore.GetReader(ctx, partitionInfo, nextLSN)` (e.g., by tampering with the on-disk/replicated log-entry store or backup sink content).
3. Run `gitaly recovery replay --storage <name> --partition <id>`; `processLogEntry` → `extractArchive` will call `os.OpenFile` on the resolved path outside `stagingDir`, writing attacker-controlled content to `/tmp/evil` (or any path reachable via `../` traversal) instead of confining it to the temporary staging directory. [5](#0-4) 

**Uncertainty note:** I could not fully verify how attacker-controlled the log-entry store / backup sink contents can realistically become in a production deployment (i.e., whether an ordinary, unprivileged git client action can ever inject content into these archives, versus this requiring admin/storage-level access). This affects the "reachable from ordinary user" strength of the finding, so treat the likelihood assessment above as conservative pending that confirmation.

func processLogEntry(reader io.Reader, tempDir string, logWriter storage.LogWriter, lsn storage.LSN) (returnErr error) {
	stagingDir, err := os.MkdirTemp(tempDir, "staging-*")
	if err != nil {
		return fmt.Errorf("create staging dir: %w", err)
	}
	defer func() {
		if err := os.RemoveAll(stagingDir); err != nil {
			returnErr = errors.Join(returnErr, fmt.Errorf("removing temp staging dir: %w", err))
		}
	}()

	if err := extractArchive(reader, stagingDir); err != nil {
		return fmt.Errorf("extract archive: %w", err)
	}

	// Validate that WAL entry was extracted correctly to its own directory
	entryPath := filepath.Join(stagingDir, lsn.String())
	info, err := os.Stat(entryPath)
	if err != nil {
		return fmt.Errorf("WAL entry not found after archive extraction: %w", err)
	}
	if !info.IsDir() {
		return fmt.Errorf("expected WAL entry path %s to be a directory", entryPath)
	}

	if _, err := logWriter.CompareAndAppendLogEntry(lsn, entryPath); err != nil {
		return fmt.Errorf("append log entry: %w", err)
	}
	logWriter.NotifyNewEntries()

	return nil
}

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

func extractBackup(reader io.Reader, destDir string) (string, error) {
	var repoRelPath string
	tarReader := tar.NewReader(reader)
	for {
		header, err := tarReader.Next()
		if err != nil {
			if errors.Is(err, io.EOF) {
				break
			}

			return repoRelPath, fmt.Errorf("read tar header: %w", err)
		}

		targetPath := filepath.Join(destDir, header.Name)

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return repoRelPath, fmt.Errorf("create directory %s: %w", header.Name, err)
			}

			if strings.HasSuffix(targetPath, ".git") {
				repoRelPath, err = filepath.Rel(filepath.Join(destDir, "fs"), targetPath)
				if err != nil {
					return repoRelPath, fmt.Errorf("find rel path: %w", err)
				}
			}
		case tar.TypeReg:
			if err := os.MkdirAll(filepath.Dir(targetPath), mode.Directory); err != nil {
				return repoRelPath, fmt.Errorf("create parent directory for %s: %w", header.Name, err)
			}

			file, err := os.OpenFile(targetPath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, os.FileMode(header.Mode))
			if err != nil {
				return repoRelPath, fmt.Errorf("create file %s: %w", header.Name, err)
			}

			if _, err := io.Copy(file, tarReader); err != nil {
				return repoRelPath, fmt.Errorf("write file %s: %w", header.Name, errors.Join(err, file.Close()))
			}

			if err := file.Close(); err != nil {
				return repoRelPath, fmt.Errorf("close file %s: %w", header.Name, err)
			}
		default:
			return repoRelPath, fmt.Errorf("unsupported file type %d for %s", header.Typeflag, header.Name)
		}
	}
