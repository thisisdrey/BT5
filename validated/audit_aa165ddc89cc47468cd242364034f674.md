Audit Report

## Title
Division-by-zero in `Perbill::from_rational` causes `ranked-collective::Tally::support()` to vacuously return 100% support with zero voters - (File: `substrate/frame/ranked-collective/src/lib.rs`)

## Summary
`pallet-ranked-collective`'s `Tally::support()` computes `Perbill::from_rational(self.bare_ayes, M::get_max_voters(class))` without guarding against a zero `get_max_voters` denominator, unlike `pallet-conviction-voting`'s `Tally::approval()`, which was explicitly patched (PR #11567) to return `Perbill::zero()` on a zero-vote total. Because `Perbill::from_rational`'s default implementation converts a `0/0` division error into `Self::one()` rather than `Self::zero()`, any poll/track whose minimum-rank voter tier (`MemberCount` at `T::MinRankOfClass::convert(class)`) is empty causes `support()` to report 100% support even with zero actual votes.

## Finding Description
`Tally::support()` is implemented exactly as cited: [1](#0-0)  and its denominator comes from `GetMaxVoters::get_max_voters`, implemented as a direct `MemberCount` lookup with no zero-check: [2](#0-1) .

`Perbill::from_rational`'s default trait method swallows the `Err(())` that `from_rational_with_rounding` returns when the denominator is zero and substitutes `Self::one()`: [3](#0-2) . This "0/0 → 100%" fallback is a general property of the default `from_rational` method, not specific to `ranked-collective`.

By contrast, `pallet-conviction-voting`'s `Tally::approval()` was hardened to explicitly special-case a zero total and return `Perbill::zero()`: [4](#0-3) . `ranked-collective::Tally::support()` has no analogous guard, and this is confirmed as intentional design in the pallet's own test, `tally_support_correct`, which demonstrates `support()`'s dependence on `MinRankOfClass` without ever exercising or guarding the zero-member-count case: [5](#0-4) .

`pallet-referenda::is_passing` consumes `tally.support(id)` directly against the track's support curve with no additional sanity check: [6](#0-5) . If `support()` returns `Perbill::one()` due to the zero-denominator fallback, `support_needed.passing(x, Perbill::one())` is satisfied trivially for essentially any curve/track, regardless of real voter turnout.

## Impact Explanation
This corrupts the `support` value used by `pallet-referenda` to gate `Confirmed`/`Approved` transitions, allowing a referendum on a rank-gated track whose minimum-rank tier is currently empty (e.g., a newly configured or fully-vacated rank tier) to pass with fabricated 100% support despite zero real votes cast. This falls under "runtime bugs that compromise intended behavior" in the accepted impact gate, since it can result in privileged-origin dispatch (e.g., fellowship-controlled treasury or referenda actions) being authorized without genuine consensus.

## Likelihood Explanation
No malicious peer, validator, or compromised relayer is needed. Any track whose `MinRankOfClass`-derived rank tier is (even transiently) empty of members — through normal demotions/removals of the last member at a rank, or a rank tier that has not yet been populated — creates the zero-denominator condition automatically, and an ordinary account can submit a referendum on such a track and simply wait out the normal decision/confirmation periods to trigger it.

## Recommendation
Guard `Tally::support()` in `substrate/frame/ranked-collective/src/lib.rs` the same way `conviction-voting::Tally::approval()` was fixed: check `M::get_max_voters(class).is_zero()` and return `Perbill::zero()` explicitly instead of delegating to `Perbill::from_rational`, which defaults a zero denominator to 100% rather than 0%.

## Proof of Concept
1. Configure or reach a state where a `pallet-referenda` track's `T::MinRankOfClass::convert(class)` maps to a rank with `MemberCount == 0` (e.g., via `do_add_member_to_rank`/`remove_member` sequences as exercised in `substrate/frame/ranked-collective/src/tests.rs`).
2. Submit a referendum on that track with `bare_ayes = 0`.
3. Call `Tally::support(class)`, which evaluates `Perbill::from_rational(0, 0)` via [1](#0-0) , returning `Perbill::one()` per the default fallback in [3](#0-2) .
4. Observe that `is_passing` in `pallet-referenda` treats the track as fully supported and progresses the referendum toward approval despite zero real votes.

```rust
#[test]
fn tally_support_correct() {
	ExtBuilder::default().build_and_execute(|| {
		// add members,
		// rank 1: accounts 1, 2, 3
		// rank 2: accounts 2, 3
		// rank 3: accounts 3.
		assert_ok!(Club::add_member(RuntimeOrigin::root(), 1));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 1));
		assert_ok!(Club::add_member(RuntimeOrigin::root(), 2));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 2));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 2));
		assert_ok!(Club::add_member(RuntimeOrigin::root(), 3));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 3));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 3));
		assert_ok!(Club::promote_member(RuntimeOrigin::root(), 3));

		// init tally with 1 aye vote.
		let tally: TallyOf<Test> = Tally::from_parts(1, 1, 0);

		// with minRank(Class) = Class
		// for class 3, 100% support.
		MinRankOfClassDelta::set(0);
		assert_eq!(tally.support(3), Perbill::from_rational(1u32, 1));

		// with minRank(Class) = (Class - 1)
		// for class 3, ~50% support.
		MinRankOfClassDelta::set(1);
		assert_eq!(tally.support(3), Perbill::from_rational(1u32, 2));

		// with minRank(Class) = (Class - 2)
		// for class 3, ~33% support.
		MinRankOfClassDelta::set(2);
		assert_eq!(tally.support(3), Perbill::from_rational(1u32, 3));

		// reset back.
		MinRankOfClassDelta::set(0);
	});
}
```

**File:** substrate/frame/referenda/src/lib.rs (L1315-1329)
```rust
	/// Determine whether the given `tally` would result in a referendum passing at `elapsed` blocks
	/// into a total decision `period`, given the two curves for `support_needed` and
	/// `approval_needed`.
	fn is_passing(
		tally: &T::Tally,
		elapsed: BlockNumberFor<T, I>,
		period: BlockNumberFor<T, I>,
		support_needed: &Curve,
		approval_needed: &Curve,
		id: TrackIdOf<T, I>,
	) -> bool {
		let x = Perbill::from_rational(elapsed.min(period), period);
		support_needed.passing(x, tally.support(id)) &&
			approval_needed.passing(x, tally.approval(id))
	}
```
