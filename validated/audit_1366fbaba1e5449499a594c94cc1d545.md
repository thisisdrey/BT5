### Title
Unauthenticated QUIC connection slots keyed by IP allow a single unstaked attacker to exhaust `max_connections_per_unstaked_peer` and deny co-tenant clients on the same NAT/IP - (File: streamer/src/nonblocking/quic.rs)

### Summary
`ConnectionTableKey::new` falls back to `ConnectionTableKey::IP(ip)` whenever a connecting peer presents no pubkey, which is the normal, unauthenticated path for any unstaked client. [1](#0-0)  Because `ConnectionTable::try_add_connection` enforces `max_connections_per_peer` (here, `max_connections_per_unstaked_peer`) per `ConnectionTableKey` entry rather than per distinct client identity, one unstaked attacker sharing a NAT/IP with legitimate unstaked clients can fill that IP-keyed slot bucket and cause subsequent legitimate connection attempts from the same IP to be rejected. [2](#0-1) 

### Finding Description
When an incoming unstaked QUIC connection is admitted, the connection table key is computed from the remote IP and an optional pubkey via `ConnectionTableKey::new(ip, maybe_pubkey)`:
```
pub(crate) fn new(ip: IpAddr, maybe_pubkey: Option<Pubkey>) -> Self {
    maybe_pubkey.map_or(ConnectionTableKey::IP(ip), |pubkey| {
        ConnectionTableKey::Pubkey(pubkey)
    })
}
``` [1](#0-0) 

For unstaked connections there is no cryptographic identity requirement enforced before this keying decision — an unstaked TLS/QUIC handshake can proceed without presenting a verifiable pubkey, so `maybe_pubkey` is `None` and the key degenerates to `ConnectionTableKey::IP(ip)`.

`ConnectionTable::try_add_connection` then looks up (or creates) the `Vec<ConnectionEntry>` for that single key and only allows a new entry if the existing count is below `max_connections_per_peer`:
```
let connection_entry = self.table.entry(key).or_default();
let has_connection_capacity = connection_entry
    .len()
    .checked_add(1)
    .map(|c| c <= max_connections_per_peer)
    .unwrap_or(false);
if has_connection_capacity {
    ...
} else {
    if let Some(connection) = connection {
        connection.close(CONNECTION_CLOSE_CODE_TOO_MANY.into(), CONNECTION_CLOSE_REASON_TOO_MANY);
    }
    None
}
``` [2](#0-1) 

This bucket is shared by IP, not by client identity. Any device behind carrier-grade NAT, a corporate proxy, VPN egress, or cloud NAT gateway sharing that public IP with the attacker is subject to the same key. An attacker who opens `max_connections_per_unstaked_peer` connections from that shared IP (without ever presenting a pubkey) fills the `Vec<ConnectionEntry>` for `ConnectionTableKey::IP(ip)` to capacity. Any subsequent legitimate, unstaked, co-tenant client attempting to connect from the same shared IP will fail the capacity check and have its connection closed with `CONNECTION_CLOSE_REASON_TOO_MANY`, i.e., permanently starved as long as the attacker keeps its connections alive (or keeps refilling the bucket).

No existing mitigation distinguishes tenants sharing one IP: there is no secondary per-source-port, per-TLS-session, or per-connection-attempt fairness check inside `try_add_connection`; the only granularity available is the `ConnectionTableKey` itself, which collapses to a bare IP for any client that doesn't present a pubkey.

### Impact Explanation
This is a targeted denial-of-service against legitimate unstaked traffic reaching the leader's TPU/TPU-forwards QUIC endpoint. Any legitimate wallet/RPC-relay/unstaked sender sharing a NAT IP with an attacker can be starved of TPU access indefinitely, without the attacker needing any stake or privileged network position — only co-location behind the same NAT/proxy IP, which is common for consumer ISPs (CGNAT), corporate networks, and cloud egress IPs. This matches a network/QoS DoS category rather than a consensus-safety bug: it does not corrupt state, panic the validator, or bypass sigverify, but it does defeat the intended purpose of per-peer connection limits (fair access), causing scoped availability loss for co-tenant legitimate clients.

### Likelihood Explanation
Highly feasible and repeatable with no privileged preconditions beyond IP co-location, which is common in real-world NAT/proxy deployments (mobile carriers, offices, VPNs, cloud providers). The attacker only needs to be unstaked and to open ordinary QUIC connections without providing a pubkey — the default for unauthenticated/unstaked clients. The attack requires no packet crafting beyond standard QUIC handshakes and can be sustained indefinitely by keeping connections alive or quickly reopening them as they are pruned, since `prune_oldest`/`prune_random` operate at whole-key granularity and do not restore per-client fairness within a shared IP bucket. [3](#0-2) 

### Recommendation
Do not collapse all unstaked, pubkey-less connections that share a NAT IP into a single fairness bucket. Options: (1) enforce `max_connections_per_unstaked_peer` per `(IP, source port)` or per distinct QUIC connection ID/TLS session rather than raw IP alone so co-tenant clients get independent slots up to a total-per-IP ceiling that is meaningfully larger than one attacker's allotment; (2) add a secondary, larger aggregate cap per IP alongside a smaller per-flow cap, so a single attacker cannot claim the entire per-IP budget; (3) prioritize pruning of the oldest/least-recently-active connections within an IP bucket when a new legitimate connection arrives instead of unconditionally rejecting, giving fresh legitimate clients a chance to displace stale attacker connections.

### Proof of Concept
Integration test plan in `streamer/src/nonblocking/quic.rs` test module (or a new test file exercising `ConnectionTable` directly, which is `pub(crate)` and testable in-crate):

```rust
#[test]
fn test_shared_ip_unstaked_dos() {
    let cancel = CancellationToken::new();
    let mut table = ConnectionTable::<StreamerStatsCounter>::new(ConnectionTableType::Unstaked, cancel);
    let shared_ip: IpAddr = "203.0.113.5".parse().unwrap();
    let max_connections_per_unstaked_peer = 8usize; // matches production default

    // Attacker opens max_connections_per_unstaked_peer connections, all keyed by IP only.
    for _ in 0..max_connections_per_unstaked_peer {
        let key = ConnectionTableKey::new(shared_ip, None);
        let result = table.try_add_connection(
            key,
            /* port */ 0,
            fake_client_connection_tracker(),
            None,
            ConnectionPeerType::Unstaked,
            Arc::new(AtomicU64::new(0)),
            max_connections_per_unstaked_peer,
            || Arc::new(StreamerStatsCounter::default()),
        );
        assert!(result.is_some(), "attacker connection should be admitted");
    }

    // A distinct legitimate client, sharing the same NAT IP, also presents no pubkey.
    let victim_key = ConnectionTableKey::new(shared_ip, None);
    let victim_result = table.try_add_connection(
        victim_key,
        /* port */ 0,
        fake_client_connection_tracker(),
        None,
        ConnectionPeerType::Unstaked,
        Arc::new(AtomicU64::new(0)),
        max_connections_per_unstaked_peer,
        || Arc::new(StreamerStatsCounter::default()),
    );

    // Documents the co-tenancy DoS: legitimate victim is unconditionally rejected
    // solely because it shares an IP with the attacker, despite being a wholly
    // distinct client.
    assert!(
        victim_result.is_none(),
        "legitimate co-tenant client sharing the attacker's IP is denied TPU access"
    );
}
```
Expected result: the assertion at the end passes, demonstrating that once an attacker fills the `ConnectionTableKey::IP(shared_ip)` bucket, a totally distinct legitimate unstaked client from the same shared IP is unconditionally denied — confirming the co-tenancy DoS.

    pub(crate) fn prune_oldest(&mut self, max_size: usize) -> usize {
        let mut num_pruned = 0;
        let key = |(_, connections): &(_, &Vec<_>)| {
            connections.iter().map(ConnectionEntry::last_update).min()
        };
        while self.total_size.saturating_sub(num_pruned) > max_size {
            match self.table.values().enumerate().min_by_key(key) {
                None => break,
                Some((index, connections)) => {
                    num_pruned += connections.len();
                    self.table.swap_remove_index(index);
                }
            }
        }
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

    // Randomly selects sample_size many connections, evicts the one with the
    // lowest stake, and returns the number of pruned connections.
    // If the stakes of all the sampled connections are higher than the
    // threshold_stake, rejects the pruning attempt, and returns 0.
    pub(crate) fn prune_random(&mut self, sample_size: usize, threshold_stake: u64) -> usize {
        let num_pruned = std::iter::once(self.table.len())
            .filter(|&size| size > 0)
            .flat_map(|size| {
                let mut rng = rng();
                repeat_with(move || rng.random_range(0..size))
            })
            .map(|index| {
                let connection = self.table[index].first();
                let stake = connection.map(|connection: &ConnectionEntry<S>| connection.stake());
                (index, stake)
            })
            .take(sample_size)
            .min_by_key(|&(_, stake)| stake)
            .filter(|&(_, stake)| stake < Some(threshold_stake))
            .and_then(|(index, _)| self.table.swap_remove_index(index))
            .map(|(_, connections)| connections.len())
            .unwrap_or_default();
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

    pub(crate) fn try_add_connection<F: FnOnce() -> Arc<S>>(
        &mut self,
        key: ConnectionTableKey,
        port: u16,
        client_connection_tracker: ClientConnectionTracker,
        connection: Option<Connection>,
        peer_type: ConnectionPeerType,
        last_update: Arc<AtomicU64>,
        max_connections_per_peer: usize,
        stream_counter_factory: F,
    ) -> Option<(Arc<AtomicU64>, CancellationToken, Arc<S>)> {
        let connection_entry = self.table.entry(key).or_default();
        let has_connection_capacity = connection_entry
            .len()
            .checked_add(1)
            .map(|c| c <= max_connections_per_peer)
            .unwrap_or(false);
        if has_connection_capacity {
            let cancel = self.cancel.child_token();
            let stream_counter = connection_entry
                .first()
                .map(|entry| entry.stream_counter.clone())
                .unwrap_or_else(stream_counter_factory);
            connection_entry.push(ConnectionEntry::new(
                cancel.clone(),
                peer_type,
                last_update.clone(),
                port,
                client_connection_tracker,
                connection,
                stream_counter.clone(),
            ));
            self.total_size += 1;
            Some((last_update, cancel, stream_counter))
        } else {
            if let Some(connection) = connection {
                connection.close(
                    CONNECTION_CLOSE_CODE_TOO_MANY.into(),
                    CONNECTION_CLOSE_REASON_TOO_MANY,
                );
            }
            None
        }
