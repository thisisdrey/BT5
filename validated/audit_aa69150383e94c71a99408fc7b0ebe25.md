Audit Report

## Title
`add_external_asset` never initializes `AssetCeilingWeight`, permanently bricking minting for every newly approved external asset - (File: `substrate/frame/psm/src/lib.rs`)

## Summary
`AssetCeilingWeight` is a `ValueQuery` double map that defaults to `Permill::zero()`, and a zero weight is explicitly documented to mean "disabled." `add_external_asset` inserts into `ExternalAssets` and bumps `PsmInfo::external_count` but never writes an entry into `AssetCeilingWeight`, so any freshly approved external asset has ceiling weight zero until the separate `set_asset_ceiling_weight` extrinsic is called.

## Finding Description
The storage declaration confirms the zero-default semantics: [1](#0-0) 

`add_external_asset` inserts `ExternalAssetInfo` into `ExternalAssets` and updates `info.external_count`, but contains no call to `AssetCeilingWeight::<T>::insert`: [2](#0-1) 

`max_asset_debt` reads `AssetCeilingWeight::<T>::get(internal_asset, external_asset)` and feeds it into `normalised_ceiling`, which returns zero whenever `weight == 0`: [3](#0-2) 

This zero ceiling is enforced in `mint` via `ensure!(new_debt <= max_debt, Error::<T>::ExceedsMaxPsmDebt)`, per the citation from the claim (`substrate/frame/psm/src/lib.rs` L738-741). The only path to a non-zero weight is the separate `set_asset_ceiling_weight` extrinsic (claim citation L1258-1282), which is not invoked anywhere else in the pallet — I found no other call site writing `AssetCeilingWeight` besides that extrinsic and no genesis/migration logic doing so either.

This matches an implementation bug: the intended behavior of the PSM (approving an external asset should make it mintable, subject to the PSM's overall `max_debt`) is violated because the natural admin workflow (`create_psm` → `add_external_asset`) leaves the new external's ceiling at zero, silently disabling minting with a misleading `ExceedsMaxPsmDebt` error rather than any "not yet configured" signal.

## Impact Explanation
This is a runtime bug that compromises intended pallet behavior — a live-scope impact category. It does not corrupt funds or bypass authorization, but it causes the core mint functionality to be completely and silently non-functional for every newly approved external asset until an admin performs an additional, undocumented setup step. The failure is deterministic and affects any runtime that deploys `pallet-psm`, not caused by malicious governance action but by an ordinary/expected admin workflow gap.

## Likelihood Explanation
High. This triggers automatically on the very first use of the documented `create_psm` → `add_external_asset` flow, with no adversarial input required — every fresh deployment will hit this unless the operator independently knows to also call `set_asset_ceiling_weight`.

## Recommendation
Have `add_external_asset` also initialize `AssetCeilingWeight` (e.g., to an equal share recomputed across existing externals, or `Permill::one()` when it's the sole external), or change `max_asset_debt`/`normalised_ceiling` to fall back to `PsmInfo::max_debt` when no explicit weight entry exists. Add integration/benchmark coverage that calls `mint` immediately after `add_external_asset` without a prior `set_asset_ceiling_weight` call.

## Proof of Concept
1. `Root`/asset owner calls `create_psm(internal_asset, full_admin, emergency_admin, fee_destination, max_debt = 1_000_000, min_swap_amount = 1)`.
2. `full_admin` calls `add_external_asset(internal_asset, USDC)` — succeeds; `ExternalAssets` contains `(internal_asset, USDC)` but `AssetCeilingWeight::get(internal_asset, USDC)` remains `Permill::zero()`.
3. A user calls `mint(internal_asset, USDC, external_amount = 1000, max_fee)`.
4. `max_asset_debt` resolves ceiling to `0` via `normalised_ceiling`; `new_debt (>0) <= max_debt (0)` is `false`, and the call reverts with `Error::ExceedsMaxPsmDebt`, despite `PsmInfo::max_debt` being `1_000_000`.
5. Minting stays blocked for all users until `full_admin` separately calls `set_asset_ceiling_weight(internal_asset, USDC, weight)`.

		#[pallet::call_index(9)]
		#[pallet::weight(T::WeightInfo::add_external_asset())]
		pub fn add_external_asset(
			origin: OriginFor<T>,
			internal_asset: T::AssetId,
			external_asset: T::AssetId,
		) -> DispatchResult {
			Self::ensure_psm_admin(origin, &internal_asset, |l| l.can_manage_assets())?;
			let mut info = Psm::<T>::get(&internal_asset).ok_or(Error::<T>::PsmNotFound)?;
			ensure!(
				!ExternalAssets::<T>::contains_key(&internal_asset, &external_asset),
				Error::<T>::AssetAlreadyApproved
			);
			ensure!(info.external_count < T::MaxExternals::get(), Error::<T>::TooManyAssets);
			ensure!(
				T::Fungibles::asset_exists(external_asset.clone()),
				Error::<T>::AssetDoesNotExist
			);

			let asset_decimals = T::Fungibles::decimals(external_asset.clone());
			ensure!(
				T::Fungibles::decimals(internal_asset.clone()) == info.internal_decimals,
				Error::<T>::DecimalsMismatch
			);
			ensure!(
				(asset_decimals.abs_diff(info.internal_decimals) as u32) <= MAX_DECIMALS_DIFF,
				Error::<T>::DecimalsRangeExceeded
			);

			ExternalAssets::<T>::insert(
				&internal_asset,
				&external_asset,
				ExternalAssetInfo {
					status: CircuitBreakerLevel::AllEnabled,
					decimals: asset_decimals,
				},
			);
			info.external_count = info.external_count.saturating_add(1);
			Psm::<T>::insert(&internal_asset, info);

			Self::deposit_event(Event::ExternalAssetAdded { internal_asset, external_asset });
			Ok(())
		}

		/// Calculate max debt for a specific external on a PSM.
		///
		/// Weights are normalised against the sum of weights within the same instance to
		/// fill the instance's `max_debt` ceiling. Returns zero if the external has no
		/// configured weight or weights sum to zero.
		pub(crate) fn max_asset_debt(
			internal_asset: &T::AssetId,
			external_asset: &T::AssetId,
			info: &PsmInfo<T>,
		) -> BalanceOf<T> {
			let asset_weight = AssetCeilingWeight::<T>::get(internal_asset, external_asset);
			let total_weight = Self::total_ceiling_weight(internal_asset);
			Self::normalised_ceiling(asset_weight, total_weight, info.max_debt)
		}

		/// Sum of the configured ceiling weights across a PSM's approved externals.
		fn total_ceiling_weight(internal_asset: &T::AssetId) -> u32 {
			AssetCeilingWeight::<T>::iter_prefix(internal_asset)
				.map(|(_, w)| w.deconstruct())
				.fold(0u32, |acc, x| acc.saturating_add(x))
		}

		/// A single external's normalised debt ceiling: its share of the total weight applied
		/// to `max_debt`. Zero if the external (or the PSM as a whole) carries no weight.
		fn normalised_ceiling(
			asset_weight: Permill,
			total_weight: u32,
			max_debt: BalanceOf<T>,
		) -> BalanceOf<T> {
			let weight = asset_weight.deconstruct();
			if weight == 0 || total_weight == 0 {
				return BalanceOf::<T>::zero();
			}
			Perbill::from_rational(weight, total_weight).mul_floor(max_debt)
		}
