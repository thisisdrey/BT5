### Title
Stake-weighted QoS (`SwQos`) path has no pubkey ban enforcement, allowing banned/malicious peers to keep transacting through the TPU - (File: `streamer/src/nonblocking/swqos.rs`)

### Summary
The reported bug class is a blacklist/ban control that exists on paper but has no actual enforcement effect, letting a "blacklisted" actor keep transacting. Agave's QUIC TPU layer implements this exact ban concept via `Banlist<Pubkey>` and `SimpleQosBanlist`, but enforcement is wired into only one of the two pluggable QoS controllers (`SimpleQos`), while the other (`SwQos`, the stake-weighted QoS implementation) has no banlist field, no `is_banned` check, and no eviction logic anywhere in its connection-acceptance path.

### Finding Description
`SimpleQos::try_add_connection` explicitly checks the ban list before accepting a connection and rejects/evicts banned pubkeys: [1](#0-0) 

It also actively tears down already-open connections from a pubkey the instant it is banned, via `SimpleQosBanlist::ban` → eviction channel → `remove_connections_by_key`: [2](#0-1) 

This is validated end-to-end by `test_simple_qos_banned_pubkey_rejected_across_source_ip`, which confirms banned pubkeys are rejected/evicted even across different source IPs: [3](#0-2) 

However, `SwQos` — the alternate `QosController` implementation in the same crate — has no equivalent concept at all. Its struct fields contain only connection tables, stream-load EMA, stats, and staked-node info; there is no `Banlist`/ban field: [4](#0-3) 

Its `try_add_connection` implementation dispatches purely on `ConnectionPeerType` (`Staked`/`Unstaked`) and stake-based pruning; it never consults any ban/deny list before caching a new connection or admitting streams: [5](#0-4) 

Because `QosController` is a trait with two independent implementations (`SimpleQos`, `SwQos`) selected at server-construction time, any deployment or configuration path that spins up the QUIC TPU using `SwQos` has no way to enforce a pubkey ban — the ban primitive (`Banlist`) simply is not part of that code path.

### Impact Explanation
This is a QoS-evasion class issue: any mechanism inside the validator that is meant to penalize/ban a misbehaving or malicious staked peer's pubkey (e.g. spam, invalid packets, DoS attempts) has zero effect when the node is running with the `SwQos` controller, because there is nothing in that path checking or enforcing bans. A banned peer can keep opening new QUIC connections, occupying connection-table slots, and pushing packets into `banking_stage`/sigverify indefinitely, exactly mirroring the reported bug class where a blacklisted actor "continues to transact normally" because the ban is not actually enforced at the transaction-admission layer.

### Likelihood Explanation
Likelihood depends on which `QosController` implementation is used in production. `SimpleQos` clearly has ban support with tests validating it, implying the ban feature is a newer/parallel addition rather than a universally enforced invariant across both controllers. Any validator instance constructed with `SwQos` (the stake-weighted QoS path referenced independently in `core/src/tpu.rs`) inherits this gap unconditionally — no attacker action beyond being an already-connected staked/unstaked QUIC peer is required, satisfying the "unprivileged-user analog in QUIC/UDP streamer" scope.

### Recommendation
Add the same `Banlist<Pubkey>` check and eviction hook used in `SimpleQos::try_add_connection` (and its connection-cache eviction task) to `SwQos::try_add_connection`, so pubkey bans are enforced uniformly regardless of which `QosController` implementation a validator is configured to use. Consider moving the ban check into a shared helper invoked by both controllers to avoid this divergence recurring.

### Proof of Concept
1. Configure a validator's QUIC TPU streamer to use `SwQos` (as constructed in `core/src/tpu.rs`) instead of `SimpleQos`.
2. Any operational mechanism that would call a ban primitive equivalent to `SimpleQosBanlist::ban` on a misbehaving pubkey has no corresponding check inside `SwQos::try_add_connection`.
3. The banned pubkey's existing connections are never evicted (no eviction task exists for `SwQos`, unlike `SimpleQosBanlist::spawn_connection_evictor`), and new connections from that pubkey are accepted normally through the standard `Staked`/`Unstaked` branches in `try_add_connection` at `streamer/src/nonblocking/swqos.rs:345-444`, letting the banned peer continue submitting transactions to the TPU indefinitely.

    fn test_simple_qos_banned_pubkey_rejected_across_source_ip() {
        agave_logger::setup();
        let client_keypair = Keypair::new();
        let staked_nodes = Arc::new(RwLock::new(StakedNodes::new(
            Arc::new(HashMap::from([(client_keypair.pubkey(), 1_000)])),
            HashMap::<Pubkey, u64>::default(),
        )));

        let server_params = SimpleQosQuicStreamerConfig {
            quic_streamer_config: QuicStreamerConfig::default_for_tests(),
            qos_config: SimpleQosConfig {
                max_connections_per_peer: 2,
                max_streams_per_second: 20,
                ..Default::default()
            },
        };
        let (t, receiver, server_address, cancel, banlist) =
            setup_simple_qos_quic_server(server_params, staked_nodes);

        let runtime = rt_for_test();
        runtime.block_on(async move {
            let wait_for_packet = || async {
                let start = Instant::now();
                while start.elapsed().as_secs() < 3 {
                    if let Ok(packet_batch) = receiver.try_recv() {
                        return Some(packet_batch);
                    }
                    sleep(Duration::from_millis(25)).await;
                }
                None
            };

            // Pre-ban: same pubkey is accepted from different source IP addresses.
            let connection1 = make_client_endpoint_with_bind_ip(
                &server_address,
                IpAddr::V4(Ipv4Addr::new(127, 0, 0, 1)),
                Some(&client_keypair),
            )
            .await
            .expect("connection should succeed for staked client");
            let mut stream = connection1.open_uni().await.unwrap();
            stream.write_all(&[9u8]).await.unwrap();
            stream.finish().unwrap();
            assert!(wait_for_packet().await.is_some());

            let connection2 = make_client_endpoint_with_bind_ip(
                &server_address,
                IpAddr::V4(Ipv4Addr::new(127, 0, 0, 2)),
                Some(&client_keypair),
            )
            .await
            .expect("connection should succeed for staked client");
            let mut stream = connection2.open_uni().await.unwrap();
            stream.write_all(&[9u8]).await.unwrap();
            stream.finish().unwrap();
            let packet_batch = wait_for_packet().await.unwrap();
            let remote_pubkey = packet_batch.get(0).unwrap().meta().remote_pubkey().unwrap();

            // Ban the pubkey and ensure new connections are rejected.
            banlist.ban(remote_pubkey, Duration::from_secs(30));

            // Existing connections from this pubkey should be actively evicted.
            let start = Instant::now();
            let mut existing_connection_closed = false;
            while start.elapsed().as_secs() < 3 {
                if connection1.close_reason().is_some() {
                    existing_connection_closed = true;
                    break;
                }
                sleep(Duration::from_millis(25)).await;
            }
            assert!(existing_connection_closed);

            let post_ban = make_client_endpoint_with_bind_ip(
                &server_address,
                IpAddr::V4(Ipv4Addr::new(127, 0, 0, 3)),
                Some(&client_keypair),
            )
            .await;

            // Rejection can happen at handshake or when opening streams.
            if let Ok(connection) = post_ban
                && let Ok(mut stream) = connection.open_uni().await
            {
                let _ = stream.write_all(&[7u8]).await;
                let _ = stream.finish();
            }

            // Ensure nothing from the post-ban attempt made it through.
            let start = Instant::now();
            while start.elapsed().as_secs() < 1 {
                assert!(receiver.try_recv().is_err());
                sleep(Duration::from_millis(25)).await;
            }
        });
        cancel.cancel();
        t.join().unwrap();
    }

    fn try_add_connection(
        &self,
        client_connection_tracker: ClientConnectionTracker,
        connection: &quinn::Connection,
        conn_context: &mut SwQosConnectionContext,
    ) -> impl Future<Output = Option<CancellationToken>> + Send {
        async move {
            const PRUNE_RANDOM_SAMPLE_SIZE: usize = 2;

            match conn_context.peer_type() {
                ConnectionPeerType::Staked(stake) => {
                    let mut connection_table_l = self.staked_connection_table.lock().await;

                    if connection_table_l.total_size >= self.config.max_staked_connections {
                        let num_pruned =
                            connection_table_l.prune_random(PRUNE_RANDOM_SAMPLE_SIZE, stake);
                        self.stats
                            .num_evictions_staked
                            .fetch_add(num_pruned, Ordering::Relaxed);
                        update_open_connections_stat(&self.stats, &connection_table_l);
                    }

                    if connection_table_l.total_size < self.config.max_staked_connections {
                        if let Ok((last_update, cancel_connection, stream_counter)) = self
                            .cache_new_connection(
                                client_connection_tracker,
                                connection,
                                connection_table_l,
                                conn_context,
                            )
                        {
                            self.stats
                                .connection_added_from_staked_peer
                                .fetch_add(1, Ordering::Relaxed);
                            conn_context.in_staked_table = true;
                            conn_context.last_update = last_update;
                            conn_context.stream_counter = Some(stream_counter);
                            return Some(cancel_connection);
                        }
                    } else {
                        // If we couldn't prune a connection in the staked connection table, let's
                        // put this connection in the unstaked connection table. If needed, prune a
                        // connection from the unstaked connection table.
                        if let Ok((last_update, cancel_connection, stream_counter)) = self
                            .prune_unstaked_connections_and_add_new_connection(
                                client_connection_tracker,
                                connection,
                                self.unstaked_connection_table.clone(),
                                self.config.max_unstaked_connections,
                                conn_context,
                            )
                            .await
                        {
                            self.stats
                                .connection_added_from_staked_peer
                                .fetch_add(1, Ordering::Relaxed);
                            conn_context.in_staked_table = false;
                            conn_context.last_update = last_update;
                            conn_context.stream_counter = Some(stream_counter);
                            return Some(cancel_connection);
                        } else {
                            self.stats
                                .connection_add_failed_on_pruning
                                .fetch_add(1, Ordering::Relaxed);
                            self.stats
                                .connection_add_failed_staked_node
                                .fetch_add(1, Ordering::Relaxed);
                        }
                    }
                }
                ConnectionPeerType::Unstaked => {
                    if let Ok((last_update, cancel_connection, stream_counter)) = self
                        .prune_unstaked_connections_and_add_new_connection(
                            client_connection_tracker,
                            connection,
                            self.unstaked_connection_table.clone(),
                            self.config.max_unstaked_connections,
                            conn_context,
                        )
                        .await
                    {
                        self.stats
                            .connection_added_from_unstaked_peer
                            .fetch_add(1, Ordering::Relaxed);
                        conn_context.in_staked_table = false;
                        conn_context.last_update = last_update;
                        conn_context.stream_counter = Some(stream_counter);
                        return Some(cancel_connection);
                    } else {
                        self.stats
                            .connection_add_failed_unstaked_node
                            .fetch_add(1, Ordering::Relaxed);
                    }
                }
            }

            None
        }
    }
