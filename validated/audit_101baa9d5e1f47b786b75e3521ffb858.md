### Title
Unauthenticated `/shutdown` POST permanently terminates the signer's event-receiving thread - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` dispatches on `request.url() == "/shutdown"` and unconditionally sets `stop_signal` to `true` before returning `EventError::Terminated`, with no check of the request body, source address, or any secret/credential. Any TCP client that can reach the signer's HTTP event-listener socket can send a bare `POST /shutdown HTTP/1.1` request and permanently halt the signer's `main_loop`, since `EventReceiver::main_loop` treats `EventError::Terminated` as a clean break condition.

### Finding Description
The broken equality claimed by the question holds: the code intends "only the co-located node process may halt the event loop" but enforces "any TCP peer that can complete an HTTP request to this URL may halt the event loop." In `next_event` [1](#0-0) , the `/shutdown` branch performs `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` with no signature check, no shared secret, no comparison against a known peer address — nothing that distinguishes the legitimate `SignerStopSignaler::send` call (used only by the signer's own shutdown path, matching the exact request format built in `SignerStopSignaler::send` at lines 382-394) from an attacker crafting the same bytes over their own TCP connection to the bound socket.

`main_loop` treats this as intended termination, not an error to retry: `Err(EventError::Terminated) => { info!("Caught termination signal"); break; }` [2](#0-1) . Once this loop exits, the signer's event-receiving thread stops permanently — `is_stopped()` is already true (`stop_signal` was set), so re-invoking `next_event()` will always short-circuit with `Err(EventError::Terminated)` at line 416-418, and the thread has already exited its loop in any case.

The HTTP request is parsed by `tiny_http`'s `HttpServer::recv()` at line 420, which returns a `Request` object exposing only method and URL for routing; no header/body validation ties the request to the trusted node. Any bytes forming a syntactically valid HTTP POST to `/shutdown` are sufficient — the exact content of the body ("Yo. Shut this shit down!" in the legitimate signaler) is never checked, only the URL and method.

### Impact Explanation
An attacker who can open a TCP connection to the signer's bound event-receiver address can, with a single crafted HTTP POST request, permanently stop the signer from processing any further miner/stackerdb/burn-block/proposal events (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`). This is a full, permanent denial-of-service against the signer's event ingestion path from one request, matching the "Critical - remote crash/unauthenticated DoS from few messages" category. It affects the individual signer node reachable at that address, and is trivially repeatable against any signer whose event port is reachable.

### Likelihood Explanation
No privileged role, secret, or prior state is required — only network reachability to the signer's event HTTP listener socket, which is documented/expected to be reachable by the co-located Stacks node's event dispatcher (i.e., it is a listening TCP/HTTP server accepting arbitrary inbound connections, not restricted to loopback by any code shown here). The attacker cost is one TCP connection and one crafted HTTP request; the exploit is deterministic and repeatable.

### Recommendation
Authenticate `/shutdown` requests (and ideally all requests) before honoring them — e.g., require a shared secret/token known only to the co-located node process (similar to RPC secrets elsewhere in the codebase), or bind the event receiver strictly to a loopback/localhost address and/or an authenticated Unix socket, and reject `/shutdown` requests not originating from `127.0.0.1`/the trusted local node. At minimum, verify the request originates from the same host as the configured node RPC endpoint and add a per-request authentication token check in the `next_event` dispatch before acting on `/shutdown`.

```rust
use std::net::TcpStream;
use std::io::Write;
use std::thread;

#[test]
fn test_unauthenticated_shutdown() {
    let mut receiver: SignerEventReceiver<SomeEventType> = SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Attacker: no credentials, no secret, arbitrary TCP client
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = "POST /shutdown HTTP/1.1\r\nHost: x\r\nConnection: close\r\nContent-Length: 0\r\n\r\n";
    stream.write_all(req.as_bytes()).unwrap();

    // Give the server a moment to process, then assert termination
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());
}
```

```rust
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
```
