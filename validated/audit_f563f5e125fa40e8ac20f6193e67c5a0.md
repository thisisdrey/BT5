### No vulnerability found for this question.

The premise doesn't hold. `Nonces::commit` at [1](#0-0)  is a low-level bitmap operation whose only job is to enforce uniqueness (replay protection), not temporal validity — that binding is enforced elsewhere, before `commit_nonce` is ever called.

In `Engine::execute_signed_intent`, the payload-level `deadline` (independent of the nonce's format) is checked against `Timestamp::now()` for **every** payload, legacy or versioned: [2](#0-1) . Only after this deadline check does the code call `verify_intent_nonce` and then `commit_nonce`: [3](#0-2) .

`verify_intent_nonce` itself only imposes the salt/expiry binding on `VersionedNonce`-wrapped nonces; for a legacy (non-versioned) nonce it deliberately short-circuits with `Ok(())`: [4](#0-3) . This is explicitly documented as an intentional, temporary compatibility state, not an oversight: [5](#0-4) .

So the equality the question wants broken — "temporal validity is bound only via `Salt`/`ExpirableNonce`" — is false; temporal validity for *all* payloads (legacy-nonce or not) is bound by the signer-chosen `DefusePayload::deadline` field, checked unconditionally. A signer who signs a message with a far-future `deadline` and a bare legacy nonce is knowingly authorizing that message to remain executable until that deadline — this is the signer's own choice at signing time, not something an attacker can inject or extend, since the attacker has no victim private key and cannot alter a payload the victim already signed. `Salt` rotation via `SaltRotationEvent` only affects `SaltedNonce`/`VersionedNonce` payloads via `is_valid_salt`, per [6](#0-5) ; legacy nonces were never bound to a salt to begin with, so rotation cannot "break" a binding that never existed for them.

Additionally, `MaybeLegacyNonces::commit` still enforces one-time use across both legacy and new maps, preventing double execution: [7](#0-6) . There is no path here to funds moving without the signer's valid, deadline-bounded authorization, so this does not meet any Critical/High impact category in scope.
