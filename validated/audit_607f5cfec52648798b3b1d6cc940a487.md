### Title
Committee feature-gate `supportUnfreezeDelay()` bypassed for resource delegation via TVM `delegateresource` native contract - ([File: actuator/src/main/java/org/tron/core/vm/nativecontract/DelegateResourceProcessor.java])

### Summary
`DelegateResourceActuator` (the transaction-level path for `DelegateResourceContract`) enforces two independent committee-controlled feature switches before allowing resource delegation: `supportDR()` and `supportUnfreezeDelay()`. The TVM native-contract path that implements the same operation for smart contracts, `DelegateResourceProcessor`, only checks `supportDR()` and omits the `supportUnfreezeDelay()` check entirely, allowing the delegate-resource feature to be invoked from a contract even when the committee has not yet enabled it via the `supportUnfreezeDelay` proposal.

### Finding Description
`DelegateResourceActuator.validate()` requires both flags before performing a delegation: [1](#0-0) 

However, the TVM opcode/precompiled-contract implementation `program.delegateResource(...)` (exposed through `OperationActions.delegateResourceAction`) routes into `DelegateResourceProcessor.validate()`, which only checks `supportDR()`: [2](#0-1) 

The precompiled/native-contract call path is: `OperationActions.delegateResourceAction` (VM opcode) → `Program.delegateResource` → `DelegateResourceProcessor.validate/execute`. [3](#0-2) 

This mirrors the reported GoGoPool bug class exactly: an administrative/committee gate (`whenNotPaused` there, `supportUnfreezeDelay` here) is enforced on the primary user-facing entry point (`stakeGGP`/`DelegateResourceActuator`) but is missing on an alternate reachable entry point that performs the same state-changing action (`restakeGGP`/`DelegateResourceProcessor` via TVM).

### Impact Explanation
If the committee has enabled `AllowDelegateResource` (`supportDR`) but not yet enabled `supportUnfreezeDelay` (i.e., the new Freeze V2/delegation model has not been fully activated on-chain, e.g., during a phased rollout), a smart contract can still call the `delegateresource` TVM opcode to delegate FreezeV2 bandwidth/energy balances to another account, bypassing the intended sequencing/feature gate that the committee controls. This breaks the intended committee-controlled activation ordering for the resource-delegation feature and could allow delegation operations to execute in a chain state/version where they are not supposed to be supported yet, potentially causing inconsistent resource accounting between the actuator and TVM paths.

### Likelihood Explanation
Reachable by any account deploying/calling a smart contract that invokes the `delegateresource` opcode; no special privilege is required beyond `supportDR` being enabled, which is a lesser gate than the one enforced on the ordinary transaction path. This is trivially triggerable whenever the two flags are toggled independently by governance, a state that occurs deterministically during any phased feature rollout.

### Recommendation
Add the missing `dynamicStore.supportUnfreezeDelay()` check to `DelegateResourceProcessor.validate()` (and audit sibling native-contract processors such as `UnDelegateResourceProcessor`, `FreezeBalanceV2Processor`, `UnfreezeBalanceV2Processor`, `WithdrawExpireUnfreezeProcessor`, `CancelAllUnfreezeV2Processor`) to ensure every committee-controlled feature flag checked in the corresponding `*Actuator.validate()` is also checked in the TVM native-contract counterpart, keeping both entry points consistent.

### Proof of Concept
1. Committee enables `AllowDelegateResource` (`supportDR()` returns true) but has not yet enabled the `UnfreezeDelayDays`/`supportUnfreezeDelay()` proposal.
2. A regular `DelegateResourceContract` transaction sent via `DelegateResourceActuator` is rejected with "Not support Delegate resource transaction, need to be opened by the committee". [4](#0-3) 
3. A deployed smart contract instead invokes the `delegateresource(receiver, amount, resourceType)` TVM opcode, which reaches `DelegateResourceProcessor.validate()` — this succeeds because only `supportDR()` is checked, and the delegation executes via `DelegateResourceProcessor.execute()`. [5](#0-4)

  public void validate(DelegateResourceParam param, Repository repo) throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!dynamicStore.supportDR()) {
      throw new ContractValidateException("No support for resource delegate");
    }
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }

  public void execute(DelegateResourceParam param, Repository repo) {
    byte[] ownerAddress = param.getOwnerAddress();
    AccountCapsule ownerCapsule = repo.getAccount(param.getOwnerAddress());
    long delegateBalance = param.getDelegateBalance();
    byte[] receiverAddress = param.getReceiverAddress();

    // delegate resource to receiver
    switch (param.getResourceType()) {
      case BANDWIDTH:
        delegateResource(ownerAddress, receiverAddress, true,
            delegateBalance, repo);

        ownerCapsule.addDelegatedFrozenV2BalanceForBandwidth(delegateBalance);
        ownerCapsule.addFrozenBalanceForBandwidthV2(-delegateBalance);
        break;
      case ENERGY:
        delegateResource(ownerAddress, receiverAddress, false,
            delegateBalance, repo);

        ownerCapsule.addDelegatedFrozenV2BalanceForEnergy(delegateBalance);
        ownerCapsule.addFrozenBalanceForEnergyV2(-delegateBalance);
        break;
      default:
        logger.debug("Resource Code Error.");
    }

    repo.updateAccount(ownerCapsule.createDbKey(), ownerCapsule);
  }

  public static void delegateResourceAction(Program program) {
    if (program.isStaticCall()) {
      throw new Program.StaticCallModificationException();
    }
    DataWord resourceType = program.stackPop();
    DataWord delegateBalance = program.stackPop();
    DataWord receiverAddress = program.stackPop();

    boolean result = program.delegateResource(receiverAddress, delegateBalance, resourceType);
    program.stackPush(result ? DataWord.ONE() : DataWord.ZERO());
    program.step();
  }
