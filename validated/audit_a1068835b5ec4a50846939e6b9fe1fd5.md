### Title
Permissionless `pallet-psm::mint`/`redeem` swap external stablecoins 1:1 with no price or peg check at all - ([File: substrate/frame/psm/src/lib.rs])

### Summary
The external report flags `Engine.sol`'s ±5% price-deviation ceiling as too wide, letting an off-peg stablecoin still be minted against. The local analog in this repository is worse in kind: `pallet-psm`'s `mint`/`redeem` extrinsics contain **no price or oracle check whatsoever**. Conversion between the internal stablecoin and an approved external asset (e.g. USDC/USDT) is done purely through a fixed decimals-based scaling factor, treating the external asset as permanently worth exactly 1:1 with the internal asset, with zero tolerance/deviation logic and zero external price feed integration.

### Finding Description
`Pallet::mint` [1](#0-0)  takes a signed, unprivileged caller, transfers `external_amount` of an approved external asset into the PSM reserve, and computes the internal amount to mint solely via `Self::external_to_internal(external_amount, ext_decimals, internal_decimals)`, i.e. a decimals-only rescale. There is no call to any oracle, no `PriceDeviation`-style bound, and no per-asset tolerance parameter anywhere in the pallet (confirmed by search: no `price`, `oracle`, or deviation-related identifiers exist in `substrate/frame/psm/src/lib.rs`). The only guards present are decimals-snapshot consistency (`ensure_decimals_match`), min swap amount, fee-vs-`max_fee`, and the aggregate/per-asset debt ceiling [2](#0-1) . `redeem` mirrors this with the same unconditional 1:1 decimals conversion [3](#0-2) .

The pallet's own documentation explicitly frames this design as relying on external arbitrageurs to hold the peg: "When the internal asset trades above $1... below $1..." [4](#0-3)  — i.e., it assumes the *internal* asset can depeg and be arbitraged, but it never protects against the *external* asset (USDC/USDT) itself depegging. If USDC or USDT depegs (e.g., to $0.90 or lower during a real-world stablecoin crisis), the PSM will still mint the internal stablecoin 1:1 against that impaired collateral for any signed caller, up to the per-asset/aggregate debt ceiling, since none of the existing checks (`min_swap_amount`, `max_fee`, `max_debt`, decimals match) reference market price at all.

### Impact Explanation
This is the unbacked-mint / conserve-value violation category called out in the task's Pivots: "Balances, assets... must conserve value." An unprivileged, permissionless `mint` call can convert a depegged/impaired external asset into full-value internal stablecoin, directly diluting the PSM's backing ratio and socializing the loss across all internal-asset holders once redemptions later drain the reserve of the remaining good collateral. Unlike `Engine.sol`, which at least bounds this to a ±5% window controlled by an oracle, `pallet-psm` bounds it by nothing — the effective "deviation tolerance" is infinite. This directly parallels and exceeds the referenced bug class ("continues minting while the stable trades off-peg... adverse P&L").

### Likelihood Explanation
High. `mint`/`redeem` are public, `ensure_signed` dispatchables requiring no special permission beyond an approved `external_asset` for that PSM instance [5](#0-4) . No governance action or malicious admin is needed to trigger the loss — it manifests automatically the moment any approved external stablecoin depegs in the open market, which is a foreseeable, non-privileged, non-adversarial event (the exact scenario the external report itself analyzes).

### Recommendation
Integrate an oracle-based price check (analogous to `pallet-oracle`, already present in this repo at `substrate/frame/honzon/oracle`) into `mint`/`redeem`, enforcing a bounded, per-asset acceptable deviation from 1 external-asset-unit = 1 internal-asset-unit (e.g. ≤ 25–50 bps for USDC/USDT), and automatically pausing minting (via the existing `CircuitBreakerLevel::MintingDisabled`) when the observed price falls outside that band, rather than relying purely on manual admin intervention through `set_asset_status`.

### Proof of Concept
1. Governance/creator sets up a PSM instance with internal asset `pUSD` and approves `USDC` as an external asset via `add_external_asset` + `set_asset_ceiling_weight` (normal setup, no misconfiguration needed).
2. USDC depegs on secondary markets to $0.90 due to a real-world event (banking/reserve issue) — no admin or governance action on this chain is required.
3. Any signed account calls `Psm::mint(origin, pUSD, USDC, external_amount, max_fee)`. The pallet transfers the (impaired) USDC into the reserve and mints `pUSD` 1:1 by decimals, per `external_to_internal` [6](#0-5) , with no check that USDC is actually worth $1.
4. Repeat up to `max_debt`/per-asset ceiling; the PSM reserve is now backed by depegged USDC while `pUSD` in circulation reflects full $1 backing, and later redeemers under `redeem` [3](#0-2)  drain the remaining sound collateral first, leaving later holders unbacked.

		pub fn mint(
			origin: OriginFor<T>,
			internal_asset: T::AssetId,
			external_asset: T::AssetId,
			external_amount: BalanceOf<T>,
			max_fee: Permill,
		) -> DispatchResult {
			let who = ensure_signed(origin)?;
			let info = Psm::<T>::get(&internal_asset).ok_or(Error::<T>::PsmNotFound)?;

			let external = ExternalAssets::<T>::get(&internal_asset, &external_asset)
				.ok_or(Error::<T>::UnsupportedAsset)?;
			ensure!(external.status.allows_minting(), Error::<T>::MintingStopped);

			let (ext_decimals, internal_decimals) =
				Self::ensure_decimals_match(&info, &internal_asset, &external_asset, &external)?;

			let internal_equivalent =
				Self::external_to_internal(external_amount, ext_decimals, internal_decimals)?;
			ensure!(!internal_equivalent.is_zero(), Error::<T>::AmountTooSmallAfterConversion);
			ensure!(internal_equivalent >= info.min_swap_amount, Error::<T>::BelowMinimumSwap);

			let effective_external =
				Self::internal_to_external(internal_equivalent, ext_decimals, internal_decimals)?;

			let fee_rate = MintingFee::<T>::get(&internal_asset, &external_asset);
			ensure!(fee_rate <= max_fee, Error::<T>::FeeTooHigh);
			let fee = fee_rate.mul_ceil(internal_equivalent);
			let internal_to_user = internal_equivalent.saturating_sub(fee);

			let current_total_psm_debt = Self::total_psm_debt(&internal_asset);
			ensure!(
				current_total_psm_debt.saturating_add(internal_equivalent) <= info.max_debt,
				Error::<T>::ExceedsMaxPsmDebt
			);

			let current_debt = PsmDebt::<T>::get(&internal_asset, &external_asset);
			let max_debt = Self::max_asset_debt(&internal_asset, &external_asset, &info);
			let new_debt = current_debt.saturating_add(internal_equivalent);

				.ok_or(Error::<T>::UnsupportedAsset)?;
			ensure!(external.status.allows_redemption(), Error::<T>::AllSwapsStopped);

			let ext_decimals = external.decimals;
			let internal_decimals = info.internal_decimals;

			ensure!(internal_amount >= info.min_swap_amount, Error::<T>::BelowMinimumSwap);

			let fee_rate = RedemptionFee::<T>::get(&internal_asset, &external_asset);
			ensure!(fee_rate <= max_fee, Error::<T>::FeeTooHigh);
			let fee = fee_rate.mul_ceil(internal_amount);
			let internal_net = internal_amount.saturating_sub(fee);

			let external_out =
				Self::internal_to_external(internal_net, ext_decimals, internal_decimals)?;
			ensure!(
				internal_net.is_zero() || !external_out.is_zero(),
				Error::<T>::AmountTooSmallAfterConversion
