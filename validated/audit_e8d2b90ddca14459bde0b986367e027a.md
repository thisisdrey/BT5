### Title
Unauthenticated HTTP listener in `SignerEventReceiver` accepts forged node events from any network-reachable client - (File: `libsigner/src/events.rs`)

### Summary
The signer-side event transport (`SignerEventReceiver`) opens an HTTP server that is meant to receive event-observer callbacks exclusively from the paired `stacks-node`. Unlike the node's own RPC surface — which gates sensitive POST endpoints behind `connection_options.auth_token` (checked in `stackslib/src/net/httpcore.rs` and `stackslib/src/net/api/postblock_proposal.rs`) — the signer's listener performs **no authentication check whatsoever** on incoming requests before deserializing and forwarding them into the signer runloop.

### Finding Description
`SignerEventReceiver::next_event` in `libsigner/src/events.rs` accepts any POST to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, or `/shutdown` and unconditionally routes the body to `process_event::<T, E>()`: [1](#0-0) 

`process_event` reads the raw body, deserializes it as JSON into the target event type, and converts it into a `SignerEvent<T>` with no sender verification of any kind — no shared-secret header, no IP allow-list, no signature check on the transport itself: [2](#0-1) 

Documentation and sample configs describe an `auth_token`/`auth_password` pair that is supposed to be "matched" between the node and the signer: [3](#0-2) [4](#0-3) 

However, a repo-wide search of `libsigner/**` for any reference to `auth_token` or `Authorization` returns no matches — the value is never read, sent, or validated on this transport path. By contrast, the node's own HTTP RPC surface enforces this check explicitly (`stackslib/src/net/httpcore.rs`, `stackslib/src/net/api/postblock_proposal.rs`, both matched multiple times for `auth_token`). This is the exact equality the bug class targets: a documented/expected "authenticated sender" gate exists on one side of the channel (node RPC) but is silently absent on the other (signer's own listener), and the sample configuration binds this listener to `0.0.0.0` by default, i.e. all interfaces, not loopback-only: [5](#0-4) 

Because there is no verification of the caller's identity, any network-reachable client (not just the paired node) can POST attacker-crafted `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` JSON directly to the signer's bound port, and it will be accepted and forwarded into the signer's runloop exactly as if it had come from the legitimate node: [6](#0-5) 

### Impact Explanation
This breaks the implicit trust boundary that the signer's control-plane feed is authenticated node output. An unauthenticated attacker who can reach the configured `endpoint` can inject forged events (fabricated burn-block notices, fabricated block-validation responses, fabricated StackerDB chunk-arrival notices) into the signer process without needing the node's private key, the signer's private key, or any admin role. Depending on deployment (the sample config defaults to binding all interfaces), this is a remotely reachable unauthenticated write into a component that feeds signing decisions — matching the "unauthenticated/unauthorized write to state" class called out in scope.

### Likelihood Explanation
High for any deployment that does not manually firewall the signer's listen port to loopback/node-only, since: (1) the shipped sample configuration binds `0.0.0.0`, (2) there is no code path in `libsigner` that reads or checks an auth token, and (3) the only gate present is a `respond 200 OK`/ack for unrecognized URLs — not a rejection based on sender identity.

### Recommendation
Add an authentication check to `SignerEventReceiver::next_event` (or `process_event`) that validates a shared secret/HMAC or bearer token supplied by the node on every POST (mirroring the `auth_token` check already implemented for the node's own RPC surface in `stackslib/src/net/httpcore.rs`), and reject/ack-and-drop any request that fails the check before it is deserialized or forwarded to the runloop. Additionally, default the sample/signer bind address to loopback rather than `0.0.0.0`.

### Proof of Concept
1. Start a `stacks-signer` using the sample config (`endpoint = "0.0.0.0:30000"`, no auth check implemented).
2. From any host that can reach the signer's port (not the paired node), issue:
```
POST /stackerdb_chunks HTTP/1.1
Host: <signer-ip>:30000
Content-Type: application/json
Content-Length: <n>

{"contract_id": "...", "modified_slots": [ ... attacker-crafted StackerDBChunkData ... ]}
```
3. Because `next_event` (`libsigner/src/events.rs:413-458`) performs no sender authentication before calling `process_event` (`libsigner/src/events.rs:518-542`), the forged JSON is deserialized and forwarded via `forward_event` into the signer's runloop channel exactly as legitimate node-originated data.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

#[cfg_attr(test, mutants::skip)]
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
