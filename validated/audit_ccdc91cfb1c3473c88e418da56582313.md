### Title
Unauthenticated remote `/shutdown` request permanently halts signer event processing - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` dispatches purely on `request.url()` string equality with no authentication, source-IP allowlist, or shared secret check. Any TCP client that can reach the event-receiver's bind address can POST to `/shutdown` and permanently set `stop_signal`, causing the signer to stop processing all further events.

### Finding Description
`next_event` matches `request.url()` against `/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/shutdown`, and `/new_block` with no verification of caller identity: [1](#0-0) 

When the URL is `/shutdown`, the handler unconditionally executes `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `EventError::Terminated`, with no distinction between a request that originated from the local node process (as `SignerStopSignaler::send` does) and a request from an arbitrary remote peer: [2](#0-1) 

The legitimate stop path (`SignerStopSignaler::send`) simply opens a plain `TcpStream` to the bound address and sends a raw, unauthenticated `POST /shutdown` HTTP request — there is no secret or token in this request that could be checked, confirming the endpoint was never designed with any authentication: [3](#0-2) 

Once `stop_signal` is set, `is_stopped()` returns `true` on every subsequent call, so `next_event` immediately returns `Err(EventError::Terminated)` forever: [4](#0-3) [5](#0-4) 

The event-receiver thread's main loop (spawned via `Signer::spawn`) runs `event_receiver.main_loop()` in its own thread and forwards events over an mpsc channel to the signer runloop thread; once the receiver thread exits/stops due to `Terminated`, `event_send` is dropped, causing `event_recv.recv_timeout` in `SignerRunLoop::main_loop` to return `RecvTimeoutError::Disconnected`, which makes the runloop `return None` and exit as well: [6](#0-5) [7](#0-6) 

Thus a single crafted HTTP POST to `/shutdown`, sent by anyone able to open a TCP connection to the bind address, halts both the event receiver and the signer runloop threads — a permanent denial of service requiring no credentials, secret, or prior state.

### Impact Explanation
A remote unauthenticated attacker who can reach the signer's event-receiver listening socket can send one crafted `POST /shutdown` request to permanently stop the signer's event processing and runloop threads, effectively taking that signer offline until manually restarted. This matches the Critical category: remote crash/unauthenticated DoS from a single message.

### Likelihood Explanation
The only precondition is TCP reachability to the address `SignerEventReceiver::bind` is bound to; no secret, peer identity, StackerDB slot ownership, or privileged role is required. The attack is a single, trivially reproducible HTTP request and is fully repeatable against any exposed signer event-receiver endpoint. The actual network exposure (whether this port is bound to a public interface vs. localhost/firewalled in typical deployments) depends on operator configuration, which is out of scope of the code itself, but the code provides zero authentication regardless of exposure.

### Recommendation
Add authentication to state-changing/administrative event-receiver endpoints (at minimum `/shutdown`), e.g., a shared secret/token known only to the local node process, or bind restriction plus a random per-process token embedded by `SignerStopSignaler`, and reject requests without a valid token before acting on `/shutdown`.

### Proof of Concept

```rust
use std::net::{TcpStream, SocketAddr};
use std::io::Write;

#[test]
fn unauthenticated_remote_shutdown_dos() {
    let mut receiver = SignerEventReceiver::new(/* ... */ false);
    let bind_addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let addr = receiver.bind(bind_addr).unwrap();

    // Attacker: plain TCP connection, no auth token, no shared secret
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker payload";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // First call processes the forged shutdown request
    let first = receiver.next_event();
    assert!(matches!(first, Err(EventError::Terminated)));

    // Every subsequent call is permanently Terminated -- event loop is dead
    let second = receiver.next_event();
    assert!(matches!(second, Err(EventError::Terminated)));
}
```
