### Title
Unauthenticated remote DoS via `POST /shutdown` on signer event-receiver port - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` matches any incoming request whose URL is `/shutdown` and unconditionally sets `stop_signal` to `true`, with no check that the request actually originated from the local node process holding the corresponding `SignerStopSignaler`. Any remote party who can open a TCP connection to the signer's bound event port (the same port the Stacks node POSTs events to) can send a single crafted HTTP POST to permanently terminate the signer's event-processing pipeline.

### Finding Description
In `libsigner/src/events.rs`, `next_event` dispatches based solely on `request.url()`: [1](#0-0) 

There is no authentication, shared secret, source-address check, or session token distinguishing a legitimate shutdown request (normally sent only by `SignerStopSignaler::send`, which connects to `self.local_addr` and POSTs `/shutdown`) from a request forged by any other TCP client: [2](#0-1) 

The equality the question poses — "sender-of-shutdown == the node process holding stop_signaler" — is never checked. The handler only checks the HTTP method and URL path (`request.method() == Post` and `request.url() == "/shutdown"`), both of which any TCP peer can trivially satisfy with a raw HTTP request. Once `stop_signal` is set, `is_stopped()` returns true and `next_event` returns `Err(EventError::Terminated)`, causing `EventReceiver::main_loop` to break: [3](#0-2) 

Because the event-receiver thread exits and drops its `Sender<SignerEvent<T>>` (`out_channels`), the paired `SignerRunLoop::main_loop`'s `event_recv.recv_timeout` subsequently returns `RecvTimeoutError::Disconnected`, which also terminates the signer's business-logic thread: [4](#0-3) 

So a single unauthenticated POST kills both the event-receiver thread and (via channel disconnection) the signer runloop thread — the entire signer process's event pipeline stops functioning, and no legitimate node event will ever be processed again.

### Impact Explanation
An unauthenticated remote attacker who can reach the signer's bound listener port (the same port configured for the node to POST events to) can send one `POST /shutdown` request and permanently stop the signer from receiving/processing any further block-validation responses, burn-block events, or StackerDB chunk events from the node. This is a Critical, single-message, remotely triggerable DoS against the signer's event pipeline. The project's own code and documentation acknowledge the exposure risk of this endpoint being reachable from outside the local/trusted network: [5](#0-4) 

### Likelihood Explanation
No privileged role, secret, or peer/slot ownership is required — only the ability to open a TCP connection to the signer's bound event port and send raw bytes, which is explicitly within the defined unprivileged-attacker capability. The attack is a single crafted HTTP request, trivially repeatable, and reliably reproducible as shown by the existing `SignerStopSignaler::send` implementation which performs exactly this action from an arbitrary `TcpStream::connect`.

### Recommendation
Require some form of authentication or origin verification for the `/shutdown` endpoint (e.g., a shared secret/token known only to the node and signer process, or binding the event receiver strictly to loopback/trusted interfaces and rejecting non-local connections), rather than trusting the HTTP path alone to authorize termination of the event loop.

### Proof of Concept
Rust test (analogous to existing `test_status_endpoint` in `libsigner/src/tests/mod.rs`):
1. Spawn a `SignerEventReceiver`/`Signer` bound to `127.0.0.1:<port>` via `signer.spawn(endpoint)`.
2. From an unrelated `TcpStream::connect(endpoint)` (not via `SignerStopSignaler`), send:
   `POST /shutdown HTTP/1.1\r\nHost: 127.0.0.1:<port>\r\nConnection: close\r\nContent-Length: 4\r\n\r\ntest`
3. Sleep briefly, then assert `event_receiver.is_stopped() == true` and that `running_signer.join()` / the runloop thread terminates, without ever having sent it a legitimate `SignerStopSignaler::send()` call — demonstrating the loop is killed by an arbitrary, unauthenticated remote peer. [6](#0-5)

    fn main_loop<EVST: EventStopSignaler>(
        &mut self,
        event_recv: Receiver<SignerEvent<T>>,
        result_send: Sender<R>,
        mut event_stop_signaler: EVST,
    ) -> Option<R> {
        info!("Signer runloop begin");
        loop {
            let poll_timeout = self.get_event_timeout();
            let next_event_opt = match event_recv.recv_timeout(poll_timeout) {
                Ok(event) => Some(event),
                Err(RecvTimeoutError::Timeout) => None,
                Err(RecvTimeoutError::Disconnected) => {
                    info!("Event receiver disconnected");
                    return None;
                }
            };

                info!("Runloop exit; signaling event-receiver to stop");
                event_stop_signaler.send();
                return Some(final_state);
            }
        }
    }

#[test]
fn test_status_endpoint() {
    let ev = SignerEventReceiver::new(false);
    let (res_send, _res_recv) = channel();
    let max_events = 1;
    let mut signer = Signer::new(SimpleRunLoop::new(max_events), ev, res_send);
    let endpoint: SocketAddr = "127.0.0.1:31000".parse().unwrap();

    // Spawn the signer first so the HTTP server is listening before the mock client connects
    let running_signer = signer.spawn(endpoint).unwrap();

    // simulate a node that's trying to push data
    let mock_stacks_node = thread::spawn(move || {
        let mut sock = TcpStream::connect(endpoint).unwrap();
        let req = format!("GET /status HTTP/1.1\r\nHost: {endpoint}\r\nConnection: close\r\n\r\n");

        sock.write_all(req.as_bytes()).unwrap();
        let mut buf = [0; 128];
        let _ = sock.read(&mut buf).unwrap();
        let res_str = std::str::from_utf8(&buf).unwrap();
        let expected_status_res = "HTTP/1.1 200 OK\r\n";
        assert_eq!(expected_status_res, &res_str[..expected_status_res.len()]);
        sock.flush().unwrap();
    });
    sleep_ms(3000);
    let accepted_events = running_signer.stop().unwrap();

    let sent_events: Vec<SignerEvent<SignerMessage>> = vec![SignerEvent::StatusCheck];

    assert_eq!(sent_events, accepted_events);
    mock_stacks_node.join().unwrap();
}
