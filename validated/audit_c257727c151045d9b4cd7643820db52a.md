### Title
Unauthenticated `/wallet/getnodeinfo` (and Solidity/PBFT equivalents) leak internal node topology, peer IPs, and system internals to any anonymous API client - (File: `framework/src/main/java/org/tron/core/services/http/GetNodeInfoServlet.java`)

### Summary
The `GetNodeInfoServlet` HTTP endpoint (mounted at `/wallet/getnodeinfo`, `/walletsolidity/getnodeinfo`, and via `GetNodeInfoOnPBFTServlet`/`GetNodeInfoOnSolidityServlet`) requires no authentication or authorization and returns a full dump of node internals — connected peer IP addresses and node IDs, listen ports, backup cluster membership/priority, JVM/OS details, memory usage, and thread/deadlock stack traces — to any anonymous caller who issues a single unauthenticated GET/POST request. This mirrors the Apache Pinot `/appconfigs` disclosure (GHSA-8gj9-r4hv-3jjw / CVE-2024-39676), where an unauthenticated controller endpoint disclosed system/environment/config information because access control was optional rather than default.

### Finding Description
`GetNodeInfoServlet.doGet` simply calls `NodeInfoService.getNodeInfo()` and serializes the result with no permission check whatsoever: [1](#0-0) 

`NodeInfoService.getNodeInfo()` aggregates several sensitive internal data structures:
- `setConnectInfo` enumerates every connected peer, including host/IP, node ID, sync state, disconnect reasons and counts: [2](#0-1) 
- `setConfigNodeInfo` exposes listen port, backup cluster member size/priority, connection limits, min/max time ratio, and contract-creation/adaptive-energy flags: [3](#0-2) 
- `setMachineInfo` exposes OS name, Java version, CPU/memory usage, and — if a JVM deadlock is detected — full thread stack traces: [4](#0-3) 

The only gate on this endpoint is the optional `HttpApiAccessFilter`, which merely checks whether the operator has manually added the endpoint's top-level path segment to a `disabledApiList` config; by default this list is empty, so the endpoint is served to any caller with no authentication: [5](#0-4) 

The servlet is wired into the FullNode HTTP service at `/wallet/getnodeinfo` and inherited by the Solidity/PBFT node HTTP services at `/walletsolidity/getnodeinfo` and `/getnodeinfo`, all without any auth requirement beyond the same disable-list check: [6](#0-5) [7](#0-6) 

This is directly analogous to Apache Pinot's `/appconfigs`: an operational/diagnostic endpoint that discloses system information, configuration, and topology, reachable without credentials unless an operator opts into restricting it.

### Impact Explanation
An unauthenticated remote attacker can enumerate all currently connected peers' IP addresses and node IDs, the node's listen port, backup-cluster membership size and priority, and JVM/OS fingerprinting data (Java version, OS name/version, memory sizing). This information materially aids network reconnaissance for targeted DoS/eclipse attacks against specific peers, fingerprinting for exploitation of version-specific bugs, and mapping of backup/HA cluster topology. If a deadlock is present, full thread stack traces (potentially including internal class/package paths) are also disclosed. This matches the CWE-200 classification and High-severity rating used by the analogous Pinot advisory, since it degrades the confidentiality of node topology and internals for any anonymous API client on the network.

### Likelihood Explanation
The endpoint is enabled by default on any FullNode/SolidityNode/PBFT node that exposes its HTTP API, requires a single unauthenticated GET request, and needs no wallet, signature, or special network position. No configuration change is required to reach it — an operator must instead take an opt-out action (adding the API to `disabledApiList`) to prevent disclosure, exactly mirroring the "affected until RBAC is configured" state described in the Pinot advisory.

### Recommendation
Treat `/wallet/getnodeinfo`, `/walletsolidity/getnodeinfo`, and the PBFT/Solidity equivalents as sensitive operational endpoints by default: require authentication (e.g., local-only binding, API key, or RBAC) unless explicitly enabled, or at minimum strip peer IP/node ID, backup cluster fields, and thread stack traces from the response payload returned to external callers. Consider defaulting these diagnostic endpoints to loopback-only access, consistent with the direction Pinot took by adding RBAC and (in later versions) a default-deny admin role for such endpoints.

### Proof of Concept
Against any FullNode exposing its HTTP API on the default port, send an unauthenticated request:
```
GET /wallet/getnodeinfo HTTP/1.1
Host: <target-node>:8090
```
The response contains a JSON body with `peerList` (each peer's `host`, `nodeId`, sync status), `configNodeInfo` (`listenPort`, `backupMemberSize`, `backupPriority`, etc.), and `machineInfo` (`osName`, `javaVersion`, memory stats, and any `deadLockThreadInfoList` with stack traces) — all served with no authentication header or session required, matching the servlet logic in [1](#0-0) .

  private void setMachineInfo(NodeInfo nodeInfo) {
    MachineInfo machineInfo = new MachineInfo();
    machineInfo.setThreadCount(threadMXBean.getThreadCount());
    machineInfo.setCpuCount(Runtime.getRuntime().availableProcessors());
    machineInfo.setTotalMemory(operatingSystemMXBean.getTotalPhysicalMemorySize());
    machineInfo.setFreeMemory(operatingSystemMXBean.getFreePhysicalMemorySize());
    machineInfo.setCpuRate(operatingSystemMXBean.getSystemCpuLoad());
    machineInfo.setJavaVersion(runtimeMXBean.getSystemProperties().get("java.version"));
    machineInfo
        .setOsName(operatingSystemMXBean.getName() + " " + operatingSystemMXBean.getVersion());
    machineInfo.setJvmTotalMemory(memoryMXBean.getHeapMemoryUsage().getMax());
    machineInfo.setJvmFreeMemory(
        memoryMXBean.getHeapMemoryUsage().getMax() - memoryMXBean.getHeapMemoryUsage().getUsed());
    machineInfo.setProcessCpuRate(operatingSystemMXBean.getProcessCpuLoad());
    List<MemoryDescInfo> memoryDescInfoList = new ArrayList<>();
    List<MemoryPoolMXBean> pools = ManagementFactory.getMemoryPoolMXBeans();
    if (CollectionUtils.isNotEmpty(pools)) {
      for (MemoryPoolMXBean pool : pools) {
        MemoryDescInfo memoryDescInfo = new MemoryDescInfo();
        memoryDescInfo.setName(pool.getName());
        memoryDescInfo.setInitSize(pool.getUsage().getInit());
        memoryDescInfo.setUseSize(pool.getUsage().getUsed());
        memoryDescInfo.setMaxSize(pool.getUsage().getMax());
        if (pool.getUsage().getMax() > 0) {
          memoryDescInfo.setUseRate((double) pool.getUsage().getUsed() / pool.getUsage().getMax());
        } else {
          memoryDescInfo

        }
        memoryDescInfoList.add(memoryDescInfo);
      }
    }
    machineInfo.setMemoryDescInfoList(memoryDescInfoList);
    //dead lock thread
    long[] deadlockedIds = threadMXBean.findDeadlockedThreads();
    if (ArrayUtils.isNotEmpty(deadlockedIds)) {
      machineInfo.setDeadLockThreadCount(deadlockedIds.length);
      ThreadInfo[] deadlockInfos = threadMXBean.getThreadInfo(deadlockedIds);
      List<DeadLockThreadInfo> deadLockThreadInfoList = new ArrayList<>();
      for (ThreadInfo deadlockInfo : deadlockInfos) {
        DeadLockThreadInfo deadLockThreadInfo = new DeadLockThreadInfo();
        deadLockThreadInfo.setName(deadlockInfo.getThreadName());
        deadLockThreadInfo.setLockName(deadlockInfo.getLockName());
        deadLockThreadInfo.setLockOwner(deadlockInfo.getLockOwnerName());
        deadLockThreadInfo.setBlockTime(deadlockInfo.getBlockedTime());
        deadLockThreadInfo.setWaitTime(deadlockInfo.getWaitedTime());
        deadLockThreadInfo.setState(deadlockInfo.getThreadState().name());
        deadLockThreadInfo.setStackTrace(Arrays.toString(deadlockInfo.getStackTrace()));
        deadLockThreadInfoList.add(deadLockThreadInfo);
      }
      machineInfo.setDeadLockThreadInfoList(deadLockThreadInfoList);
    }
    nodeInfo.setMachineInfo(machineInfo);

  private boolean isDisabled(String endpoint) {
    boolean disabled = false;

    try {
      endpoint = URI.create(endpoint).normalize().toString();
      List<String> disabledApiList = CommonParameter.getInstance().getDisabledApiList();
      if (!disabledApiList.isEmpty()) {
        disabled = disabledApiList.contains(endpoint.split("/")[2].toLowerCase(Locale.ROOT));
      }
    } catch (Exception e) {
      logger.warn("check isDisabled except, endpoint={}, {}", endpoint, e.getMessage());
    }

    return disabled;
  }
