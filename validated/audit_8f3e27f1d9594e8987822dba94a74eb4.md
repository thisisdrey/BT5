### Title
Local TOCTOU race in `codehost.WorkDir` allows symlink substitution of the module VCS cache directory - ([File: src/cmd/go/internal/modfetch/codehost/codehost.go])

### Summary
`codehost.WorkDir` computes a deterministic, world-derivable directory path (`sha256(type+name)` under `GOMODCACHE/cache/vcs`), then does `os.RemoveAll(dir)` followed by `os.MkdirAll(dir, 0777)` and `os.WriteFile(dir+".info", ...)` [1](#0-0) . Between the `RemoveAll` and `MkdirAll` calls there is a window where a local unprivileged user (or process) sharing the same `GOMODCACHE` can recreate `dir` as a symlink to an attacker-chosen location, and `go`'s subsequent `git clone`/checkout into `r.dir` (which is set to this `WorkDir` result, see `newGitRepo` in `git.go`) will then write repository contents through that symlink [2](#0-1) . This is the same bug class as CVE-2021-3702: a deterministic/predictable directory is deleted and recreated, and an attacker races the gap to substitute the directory before the victim process writes into it.

### Finding Description
`WorkDir(ctx, typ, name)` builds `dir = filepath.Join(GOMODCACHE, "cache/vcs", sha256hex(typ+":"+name))` — fully deterministic from public inputs (VCS type + repo URL) [3](#0-2) . It acquires a lock file (`dir+".lock"`) to serialize concurrent `go` command invocations, but this lock only protects cooperating `go` processes, not an attacker with independent filesystem write access to the same cache tree [4](#0-3) . When the on-disk state doesn't match expectations, the function does:
```go
os.RemoveAll(dir)
if err := os.MkdirAll(dir, 0777); err != nil { ... }
if err := os.WriteFile(dir+".info", []byte(key), 0666); err != nil { ... }
``` [5](#0-4) 
Between `RemoveAll(dir)` and `MkdirAll(dir, ...)`, an attacker who can predict `dir` (trivial, since it's a hash of public module/VCS data) and has write access to the parent `cache/vcs` directory can create a symlink at that exact path pointing anywhere the attacker has write permission. `os.MkdirAll` on a path that is already a symlink to an existing directory returns success without error, so the substitution is not detected. The returned `dir` is then used as `r.dir` by `newGitRepo`, and `go` performs `git clone`/fetch operations that write objects and refs into `r.dir` [2](#0-1) , i.e., through the attacker-controlled symlink.

### Impact Explanation
If exploited, an unprivileged local attacker sharing a `GOMODCACHE` (e.g., a multi-tenant build server, shared `/tmp`-based cache, or CI runner with a shared cache volume) could redirect the `go` command's git-checkout writes to a directory the attacker controls but the victim (running `go build`/`go get`) has write access to — a material file write outside the intended cache sandbox, potentially clobbering files or planting content the attacker can later read/tamper with. This matches the GHSA-772j-xvf9-qpf5 primitive (predictable temp/work dir race → private-data disclosure/integrity loss) applied to Go's module VCS cache. This would be assessed on Go's **PUBLIC** track as a lower-severity, environment-dependent local race requiring an unusual shared-cache configuration and precise timing.

### Likelihood Explanation
Exploitation requires: (1) attacker and victim share the same `GOMODCACHE/cache/vcs` directory with attacker write access to the parent directory, (2) attacker can predict or observe when the victim's `go` command will call `WorkDir` for a specific module/repo (feasible since the path is a deterministic hash of public inputs), and (3) attacker wins a narrow race between `RemoveAll` and `MkdirAll`. This is a plausible but narrow local multi-user/shared-cache scenario, not remotely triggerable — likelihood is low-to-moderate and highly environment-dependent.

### Recommendation
Avoid recreate-by-name races: create the replacement directory under a securely-generated random temporary name (e.g., via `os.MkdirTemp` in the same parent) and atomically `os.Rename` it into place at `dir`, rather than `RemoveAll` + `MkdirAll` on the fixed, predictable path. Additionally, consider using `os.Lstat`/`O_NOFOLLOW`-equivalent checks before writing into `dir` to detect symlink substitution.

package codehost_test

import (
	"context"
	"os"
	"path/filepath"
	"testing"

	"cmd/go/internal/modfetch/codehost"

// Simulates the race window in WorkDir: between RemoveAll(dir) and
// MkdirAll(dir), an attacker with write access to the parent directory
// substitutes dir with a symlink to an attacker-controlled location.
func TestWorkDirSymlinkRace(t *testing.T) {
	root := t.TempDir()
	os.Setenv("GOMODCACHE", root) // simplified for illustration; real cfg.GOMODCACHE wiring differs

	attackerTarget := filepath.Join(root, "attacker-owned")
	if err := os.MkdirAll(attackerTarget, 0777); err != nil {
		t.Fatal(err)
	}

	// First call establishes dir and its deterministic path.
	dir, _, err := codehost.WorkDir(context.Background(), "git3", "https://example.com/repo.git")
	if err != nil {
		t.Fatal(err)
	}

	// Attacker races: as soon as dir is removed (simulated here directly),
	// substitute a symlink pointing at attackerTarget before MkdirAll runs.
	os.RemoveAll(dir)
	if err := os.Symlink(attackerTarget, dir); err != nil {
		t.Fatal(err)
	}

	// Re-invoke WorkDir (simulating the victim's next call, e.g. re-fetch
	// after cache invalidation) - MkdirAll succeeds silently on the symlink.
	dir2, _, err := codehost.WorkDir(context.Background(), "git3", "https://example.com/repo.git")
	if err != nil {
		t.Fatal(err)
	}

	fi, err := os.Lstat(dir2)
	if err != nil {
		t.Fatal(err)
	}
	if fi.Mode()&os.ModeSymlink != 0 {
		t.Fatalf("WorkDir returned a path that is a symlink (substituted by attacker): %s -> attackerTarget", dir2)
	}
}
```
Expected assertion if vulnerable: `dir2` resolves through the attacker's symlink (test fails at the `Lstat` mode check), demonstrating that `WorkDir`/`MkdirAll` does not detect or reject the symlink substitution, so subsequent VCS writes would land in `attackerTarget` instead of the intended cache directory.

**Note on confidence:** I could not fully trace every downstream write path (e.g., exact `git` subprocess invocation code that writes objects into `r.dir`) within the tool budget available, and I was not able to execute this PoC against the actual repository to confirm `os.MkdirAll`'s exact behavior on pre-existing symlinks in this Go version, nor confirm whether any additional `Lstat`/symlink check was added elsewhere in the call chain that I did not locate. This should be treated as a strong analog requiring runtime confirmation, not a fully proven exploit.

func WorkDir(ctx context.Context, typ, name string) (dir, lockfile string, err error) {
	if cfg.GOMODCACHE == "" {
		return "", "", fmt.Errorf("neither GOPATH nor GOMODCACHE are set")
	}

	// We name the work directory for the SHA256 hash of the type and name.
	// We intentionally avoid the actual name both because of possible
	// conflicts with valid file system paths and because we want to ensure
	// that one checkout is never nested inside another. That nesting has
	// led to security problems in the past.
	if strings.Contains(typ, ":") {
		return "", "", fmt.Errorf("codehost.WorkDir: type cannot contain colon")
	}
	key := typ + ":" + name
	dir = filepath.Join(cfg.GOMODCACHE, "cache/vcs", fmt.Sprintf("%x", sha256.Sum256([]byte(key))))

	xLog, buildX := cfg.BuildXWriter(ctx)
	if buildX {
		fmt.Fprintf(xLog, "mkdir -p %s # %s %s\n", filepath.Dir(dir), typ, name)
	}
	if err := os.MkdirAll(filepath.Dir(dir), 0777); err != nil {
		return "", "", err
	}

	lockfile = dir + ".lock"
	if buildX {
		fmt.Fprintf(xLog, "# lock %s\n", lockfile)
	}

	unlock, err := lockedfile.MutexAt(lockfile).Lock()
	if err != nil {
		return "", "", fmt.Errorf("codehost.WorkDir: can't find or create lock file: %v", err)
	}
	defer unlock()

	data, err := os.ReadFile(dir + ".info")
	info, err2 := os.Stat(dir)
	if err == nil && err2 == nil && info.IsDir() {
		// Info file and directory both already exist: reuse.
		have := strings.TrimSuffix(string(data), "\n")
		if have != key {
			return "", "", fmt.Errorf("%s exists with wrong content (have %q want %q)", dir+".info", have, key)
		}
		if buildX {
			fmt.Fprintf(xLog, "# %s for %s %s\n", dir, typ, name)
		}
		return dir, lockfile, nil
	}

	// Info file or directory missing. Start from scratch.
	if xLog != nil {
		fmt.Fprintf(xLog, "mkdir -p %s # %s %s\n", dir, typ, name)
	}
	os.RemoveAll(dir)
	if err := os.MkdirAll(dir, 0777); err != nil {
		return "", "", err
	}
	if err := os.WriteFile(dir+".info", []byte(key), 0666); err != nil {
		os.RemoveAll(dir)
		return "", "", err
	}
	return dir, lockfile, nil
