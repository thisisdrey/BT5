### Title
Unauthenticated remote shutdown of signer event receiver via `/shutdown` HTTP path - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` treats any HTTP `POST /shutdown` reaching the bound listener socket identically, regardless of whether it originated from the process's own `SignerStopSignaler` or from an arbitrary remote TCP client. There is no session token, secret, or peer-identity check tying the shutdown action to the legitimate signaler.

### Finding Description
`SignerStopSignaler::send` wakes the receiver by opening a fresh `TcpStream::connect(self.local_addr)` and writing a hardcoded `POST /shutdown HTTP/1.1` request [1](#0-0) . On the receiver side, `next_event`'s dispatch match on `request.url()` handles `"/shutdown"` by unconditionally calling `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returning `EventError::Terminated`, with no check on the request's origin, no secret/token in the body, and no comparison of the connecting peer to any expected identity [2](#0-1) . `is_stopped()` simply loads the same `AtomicBool` and is checked at the top of `main_loop`, so once the flag is set the receiver thread exits [3](#0-2) [4](#0-3) . Since the HTTP server here is `tiny_http::Server` bound via `HttpServer::http(listener)` on the configured event-receiver socket address [5](#0-4) , any TCP peer that can reach that listener and send the literal bytes `POST /shutdown HTTP/1.1\r\n...` gets exactly the same effect as the legitimate in-process `SignerStopSignaler`: there is no equality check distinguishing "self" from "any remote client" — raw reachability is sufficient.

### Impact Explanation
An attacker who can reach the signer's event-receiver endpoint can permanently halt the `main_loop` of `SignerEventReceiver` with a single crafted HTTP request, stopping the signer from processing further miner/signer StackerDB events, burn block events, and block-validation responses until the operator manually restarts the process. This is an unauthenticated, repeatable, single-message remote DoS against a signer node, matching the "Critical: remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
The only precondition is TCP reachability to the event-receiver's bound address/port; no secret, key, StackerDB slot, or any privileged role is required, and the request is a fixed, publicly-derivable string (`POST /shutdown HTTP/1.1 ... `). The action is idempotent/repeatable across restarts if the listener is reachable each time.

### Recommendation
Do not treat network reachability as authorization to trigger shutdown. Options: (a) use a local-only mechanism to wake the blocking `http_server.recv()` call (e.g., bind an internal loopback-only control channel, or use a self-pipe/channel-based wakeup instead of an HTTP endpoint reachable from the network), (b) require a per-process random secret token generated at startup and included by `SignerStopSignaler`, checked by the handler before honoring `/shutdown`, or (c) restrict the `/shutdown` route to connections originating from `127.0.0.1` when the bind address is not already loopback-only, rejecting all others.

### Proof of Concept
```rust
// libsigner/src/events.rs (or an integration test crate)
use std::net::{TcpListener, TcpStream};
use std::io::Write;
use std::sync::atomic::Ordering;

#[test]
fn external_client_can_trigger_shutdown() {
    let mut receiver: SignerEventReceiver<SomeSignerMessageType> = SignerEventReceiver::new(false);
    let addr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Spawn main_loop in a thread (omitted: add_consumer with a dummy channel)
    let stop_signal = receiver_stop_signal_handle(&mut receiver); // Arc<AtomicBool> clone

    // Attacker: independent TcpStream, NOT derived from SignerStopSignaler
    let mut attacker_stream = TcpStream::connect(bound).unwrap();
    let body = "attacker payload";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        bound, body.len(), body
    );
    attacker_stream.write_all(req.as_bytes()).unwrap();

    // drive one iteration of next_event() to process the request
    let _ = receiver.next_event(); // returns Err(EventError::Terminated)

    assert!(receiver.is_stopped(), "shutdown flag was set by an unrelated external TCP client");
}
```
This demonstrates that `is_stopped()` flips to `true` from a `TcpStream` never created by `SignerStopSignaler`, confirming the lack of any sender-identity check in `next_event`'s `"/shutdown"` branch [2](#0-1) .
