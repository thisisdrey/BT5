### Title
Unsigned integer underflow/overflow in reftable parser causes out-of-bounds panic and handler crash - (File: internal/git/reftable/reftable.go)

### Summary
The Umee report describes an arithmetic operation on attacker-influenced values (`StandardDeviation`) that lacks overflow checks, causing a Go panic that crashes a node when the panicking goroutine is not recovered. The equivalent unprivileged pattern in gitaly is the reftable binary-format parser: block-length and restart-count fields read directly from an on-disk `.ref` file are combined in unsigned (`uint`) arithmetic without validating that the subtraction cannot underflow, which then drives subsequent slice indexing far outside the buffer, producing an unrecovered/likely-unrecovered runtime panic.

### Finding Description
`internal/git/reftable/reftable.go` parses the reftable ref-storage binary format used by Gitaly repositories. Several fields are extracted from raw file bytes with no bounds/overflow validation before being used as slice indices:

- `extractBlockLen` reads a 3-byte block length directly from the buffer: [1](#0-0) 
- `getVarInt` accumulates an unbounded `uint` from a variable-length encoding with only a "past block end" check, no overflow check: [2](#0-1) 
- `parseRefBlock` computes `b.RestartStart` using unsigned subtraction of attacker-controlled `currentBS` and `RestartCount`: [3](#0-2) 

Because `blockStart`, `currentBS`, and `RestartStart` are all declared as `uint` (line 144-150, `block` struct), the expression `blockStart + currentBS - 2 - 3*uint(b.RestartCount)` underflows to a huge value (near `math.MaxUint64`) whenever `currentBS` is smaller than `2 + 3*RestartCount`. This corrupted `RestartStart` is then used as the loop bound in `getRefsFromBlock`: [4](#0-3)  where `idx < b.RestartStart` remains true far beyond the actual buffer, and indices such as `src[idx:idx+suffixLength]` or `src[idx : idx+uint(hashSize)]` (lines 247, 268, 274, 290) go out of range, causing an unrecovered Go slice-bounds panic — the same "unchecked arithmetic causes overflow/underflow that later triggers a runtime panic" bug class as the Umee report, just manifesting via unsigned wraparound and OOB indexing instead of `big.Int` overflow.

`ParseTable`/`GetReferences` operate on whatever raw bytes exist in a repository's `reftable/*.ref` files: [5](#0-4) [6](#0-5) . These files are populated wholesale, with no structural/content validation, by tar extraction in unprivileged/ordinary repository-creation and replication RPC handlers:
- `CreateRepositoryFromSnapshot` extracts an externally-fetched tar archive directly into the new repository directory, and its own comment acknowledges the trust gap: [7](#0-6) 
- `ReplicateRepository`'s `extractTarToDirectory` only checks for path traversal/absolute symlinks — it performs no validation of git-format file contents such as `reftable/*.ref`: [8](#0-7) 

Once such a repository exists, any subsequent write transaction against it invokes `reftable.ParseTable` on the on-disk `.ref` files as part of normal WAL bookkeeping: [9](#0-8) , and reference listing calls `GetReferences`, both of which reach the vulnerable arithmetic.

### Impact Explanation
A crafted `.ref` file with an inconsistent block-length/restart-count combination drives the parser's unsigned arithmetic into underflow, producing an out-of-bounds slice access and a Go runtime panic. Depending on whether the RPC-handling goroutine is wrapped by panic-recovery middleware, this results at minimum in failure of the specific RPC (DoS of that repository's read/write handlers) and, if any codepath that dereferences the corrupted `Table`/`Bitmap`-style state lacks recovery, in a crash of the entire `gitaly` process — directly analogous to the Umee finding where an unchecked arithmetic overflow escalates from a single validator's vote processing to a full node crash.

### Likelihood Explanation
Requires only invoking a routine, low-privilege repository-import RPC (`CreateRepositoryFromSnapshot` or `ReplicateRepository`) with a snapshot/tar payload whose `reftable/` directory contains a byte-for-byte crafted `.ref` file — the tar extraction logic performs no git-format-specific validation of file contents, so the attacker fully controls block-length and restart-count bytes. No knowledge of internal git object encoding beyond the (publicly documented) reftable spec is needed.

### Recommendation
- In `getVarInt`, `extractBlockLen`, and `parseRefBlock`, validate that all derived offsets/lengths are non-negative and within the bounds of the source buffer *before* performing subtraction, e.g. check `currentBS >= 2 + 3*uint(b.RestartCount)` prior to computing `RestartStart`, and check every computed `idx`/`idx+len` against `len(src)` before slicing.
- Prefer signed arithmetic with explicit bounds checks (or Go's checked-arithmetic idioms) over unsigned subtraction for values derived from untrusted file content, mirroring the report's recommendation to add explicit overflow checks to all arithmetic on externally supplied values.
- Add structural validation (or a maximum trusted-source allowlist) for archive contents ingested by `CreateRepositoryFromSnapshot`/`ReplicateRepository` before they are treated as valid git repository state.
- Add fuzz tests for `internal/git/reftable` parsing functions, per the report's long-term recommendation to fuzz all arithmetic-heavy untrusted-input parsers.

### Proof of Concept
1. Build a minimal reftable file: a valid header/footer (per `git-scm.com/docs/reftable`) so `ParseTable` succeeds, but with a ref block whose 3-byte `currentBS` (block length) value is set smaller than `2 + 3*RestartCount` (e.g., set `RestartCount` to a nonzero value while making the trailing block length claim a tiny size).
2. Package this `.ref` file plus a matching `tables.list` inside a tar archive representing a `reftable`-backend repository, and serve it from an HTTP endpoint.
3. Call `CreateRepositoryFromSnapshot` with `http_url` pointing at that archive (or replicate from a controlled source via `ReplicateRepository`).
4. Trigger any operation that reads references from the resulting repository (`ListRefs`, or any write transaction that calls `stageTables`/`reftable.ParseTable`); `parseRefBlock`'s `RestartStart` underflows, and `getRefsFromBlock` subsequently indexes `src` out of bounds, panicking the handling goroutine.

func (t *Table) getVarInt(src []byte, start uint, blockEnd uint) (uint, uint, error) {
	var val uint

	val = uint(src[start]) & 0x7f

	for (uint(src[start]) & 0x80) > 0 {
		start++
		if start > blockEnd {
			return 0, 0, fmt.Errorf("exceeded block length")
		}

		val = ((val + 1) << 7) | (uint(src[start]) & 0x7f)
	}

	return start + 1, val, nil
}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}

// GetReferences returns all references from the table.
func (t *Table) GetReferences() ([]git.Reference, error) {
	headerOffset := uint(t.footer.Version.HeaderSize())
	offset := uint(0)
	var allRefs []git.Reference

	if _, err := t.src.Seek(0, io.SeekStart); err != nil {
		return nil, fmt.Errorf("seek start: %w", err)
	}

	src, err := io.ReadAll(t.src)
	if err != nil {
		return nil, fmt.Errorf("read all: %w", err)
	}

	for offset < t.footerOffset {
		blockStart, blockEnd := t.getBlockRange(offset, t.blockSize)
		if blockStart == 0 && blockEnd == 0 {
			break
		}

		// If we run out of ref blocks, we can stop the iteration.
		if src[blockStart+headerOffset] != 'r' {
			return allRefs, nil
		}

		references, err := t.parseRefBlock(src, headerOffset, blockStart, blockEnd)
		if err != nil {
			return nil, fmt.Errorf("parsing block: %w", err)
		}

		if len(references) == 0 {
			break
		}

		allRefs = append(allRefs, references...)

		offset = blockEnd
	}

	return allRefs, nil
}

// ParseTable opens the table at the given path and parses it. Close must be called
// once the table is no longer used to close the associated file.
func ParseTable(absolutePath string) (_ *Table, returnedErr error) {
	src, err := os.Open(absolutePath)
	if err != nil {
		return nil, fmt.Errorf("open: %w", err)
	}

	defer func() {
		if returnedErr != nil {
			if err := src.Close(); err != nil {
				returnedErr = errors.Join(returnedErr, fmt.Errorf("close: %w", err))
			}
		}
	}()

	t := &Table{src: src, absolutePath: absolutePath}

	var h header
	if err := parseHeader(src, &h); err != nil {
		return nil, fmt.Errorf("parse header: %w", err)
	}

	footerOffset, err := src.Seek(int64(-h.Version.FooterSize()), io.SeekEnd)
	if err != nil {
		return nil, fmt.Errorf("seek footer: %w", err)
	}

	t.footerOffset = uint(footerOffset)

	if err := parseFooter(src, &t.footer); err != nil {
		return nil, fmt.Errorf("parse footer: %w", err)
	}

	if h != t.footer.header {
		return nil, fmt.Errorf("footer doesn't match header")
	}

	t.blockSize = parseUint24(t.footer.BlockSize)

	return t, nil
}

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

		default:
			// Skip unsupported file types (devices, FIFOs, etc.)
			s.logger.WithField("file", header.Name).WithField("type", header.Typeflag).
				WarnContext(ctx, "skipping unsupported file type in tar archive")
		}

		if header.Typeflag == tar.TypeReg || header.Typeflag == tar.TypeDir {
			if err := os.Chmod(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("setting permissions for %s: %w", targetPath, err)
			}
		}
	}
