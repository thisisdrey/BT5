The premise doesn't hold — `Deduper` is a fixed-size Bloom filter, not a growing structure, so no packet volume or crafted duplicate-content burst can make its memory grow.

`Deduper::new` allocates a `Vec<AtomicU64>` bitset sized once from a constant `num_bits` argument (e.g. `DEDUPER_NUM_BITS: u64 = 63_999_979` in `core/src/sigverify_stage.rs`), and that allocation never changes size afterward. [1](#0-0) 

The `dedup()` hot path only ever flips bits within this pre-allocated fixed-size array via `fetch_or` — it never inserts new entries, allocates per-packet state, or grows any collection, regardless of how many distinct or duplicate-looking packets are hashed into it. [2](#0-1) 

Saturation (i.e., too many bits set, meaning the false-positive rate crept up because many distinct packets were seen) is handled by `maybe_reset`, which zeroes the fixed bitset and reseeds the hash state — again with no memory growth, just in-place clearing. [3](#0-2) 

This is exercised directly by `test_dedup_saturated`, which floods the deduper with 1,000,000 distinct transactions and confirms the bitset saturates and resets in place without growing. [4](#0-3) 

In `SigVerifyStage`, this same fixed-capacity `Deduper` is constructed once with the constant `DEDUPER_NUM_BITS` and reused across all incoming packet batches via `dedup_packets_and_count_discards`. [5](#0-4) [6](#0-5) 

An attacker sending a burst of QUIC streams with distinct-looking but duplicate-payload packets cannot cause unbounded memory growth here: worst case they saturate the fixed bitset (increasing false-positive rate, i.e., some non-duplicate packets get incorrectly treated as duplicates), which is bounded by `maybe_reset`'s saturation check and periodic `MAX_DEDUPER_AGE` reset — not an unbounded-memory condition. The same fixed-size design applies to the shred-path deduper in `turbine/src/retransmit_stage.rs` and `turbine/src/sigverify_shreds.rs` (`DEDUPER_NUM_BITS: u64 = 637_534_199`). [7](#0-6)

    // Returns true if the data is duplicate.
    #[must_use]
    #[allow(clippy::arithmetic_side_effects)]
    pub fn dedup(&self, data: &T) -> bool {
        let mut out = true;
        let state = self.state.load();
        for random_state in state.random_states.iter() {
            let hash: u64 = random_state.hash_one(data) % self.num_bits;
            let index = (hash >> 6) as usize;
            let mask: u64 = 1u64 << (hash & 63);
            let old = self.bits[index].fetch_or(mask, Ordering::Relaxed);
            if old & mask == 0u64 {
                self.popcount.fetch_add(1, Ordering::Relaxed);
                out = false;
            }
        }
        out
    }

pub fn dedup_packets_and_count_discards<const K: usize>(
    deduper: &Deduper<K, [u8]>,
    batches: &mut [PacketBatch],
) -> u64 {
    batches
        .iter_mut()
        .flat_map(|batch| batch.iter_mut())
        .map(|mut packet| {
            if !packet.meta().discard()
                && packet
                    .data(..)
                    .map(|data| deduper.dedup(data))
                    .unwrap_or(true)
            {
                packet.meta_mut().set_discard(true);
            }
            u64::from(packet.meta().discard())
        })
        .sum()
}
