### Title
Frozen CoinStore or Disabled Direct Transfers Permanently Bricks `vesting::distribute()` and `terminate_vesting_contract()` — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`vesting::distribute()` atomically iterates over every shareholder and calls `aptos_account::deposit_coins()` for each one. If any single recipient's `CoinStore` is frozen or that account has disabled direct coin transfers, the entire transaction aborts. Because `terminate_vesting_contract()` unconditionally calls `distribute()` first, a single hostile or frozen shareholder can permanently prevent all other shareholders from receiving their vested APT and block the admin from ever terminating the contract.

---

### Finding Description

`vesting::distribute()` withdraws all unlocked stake from the pool and then distributes it to every shareholder in a single atomic transaction: [1](#0-0) 

For each shareholder it calls:

```move
aptos_account::deposit_coins(recipient_address, share_of_coins);
```

`aptos_account::deposit_coins()` will abort under two conditions that any shareholder can arrange:

1. **Disabled direct transfers**: If the recipient has called `set_allow_direct_coin_transfers(false)` and has not yet registered a `CoinStore<AptosCoin>`, the function aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`. [2](#0-1) 

2. **Frozen CoinStore**: `coin::deposit<CoinType>()` checks the `frozen` flag on the recipient's `CoinStore`. If the coin issuer has frozen the account, the call aborts with `EFROZEN`. [3](#0-2) 

Because Move transactions are atomic, a single abort in the shareholder loop reverts the entire `distribute()` call. The withdrawn coins are never deposited anywhere — the whole transaction rolls back, leaving the funds still locked in the staking pool.

`terminate_vesting_contract()` calls `distribute()` as its very first step before setting `state = VESTING_POOL_TERMINATED`: [4](#0-3) 

If `distribute()` reverts, `terminate_vesting_contract()` also reverts, so the contract state is never updated to `VESTING_POOL_TERMINATED`, and `admin_withdraw()` (which requires that state) can never be called either.

The same pattern exists in `staking_contract::distribute_internal()`, which also loops over all distribution recipients and calls `aptos_account::deposit_coins()` for each one atomically: [5](#0-4) 

---

### Impact Explanation

A single shareholder in a vesting contract can permanently freeze the entire contract by calling `aptos_account::set_allow_direct_coin_transfers(account, false)` before their `CoinStore<AptosCoin>` is registered. This causes every subsequent call to `vesting::distribute()` to abort, which in turn:

- Prevents all other shareholders from ever receiving their vested APT.
- Prevents the admin from terminating the contract via `terminate_vesting_contract()`.
- Prevents `admin_withdraw()` from ever being reachable (requires `VESTING_POOL_TERMINATED` state).

All APT locked in the vesting contract's staking pool is permanently inaccessible. The impact is **permanent freezing of user-controlled staking balances** — a direct match to the allowed impact gate.

---

### Likelihood Explanation

The trigger is a single unprivileged entry function call (`set_allow_direct_coin_transfers`) by any one of the vesting contract's shareholders. No special permissions are required. A malicious or simply uncooperative shareholder (e.g., one who has been removed from a team but retains their shareholder slot) can execute this at any time before or after the vesting contract is created. The `set_allow_direct_coin_transfers` function is a standard, publicly callable entry function: [6](#0-5) 

---

### Recommendation

Separate the distribution loop from the atomic transaction. Two approaches:

1. **Pull-based distribution**: Instead of pushing coins to each shareholder in `distribute()`, record each shareholder's claimable balance in a table and let each shareholder call a separate `claim()` entry function to withdraw their own share. This is the Aptos analog of the "split stopping and claiming" mitigation suggested in the original report.

2. **Skip-on-failure**: Wrap each `deposit_coins` call in a way that records failed distributions (e.g., into a fallback escrow table) rather than aborting the entire transaction, so one bad recipient does not block all others.

---

### Proof of Concept

1. Alice (admin) creates a vesting contract with shareholders Bob and Carol.
2. Carol calls `aptos_account::set_allow_direct_coin_transfers(carol_signer, false)` and has no `CoinStore<AptosCoin>` registered.
3. After the lockup period, anyone calls `vesting::distribute(contract_address)`.
4. The loop reaches Carol; `aptos_account::deposit_coins(carol_addr, coins)` hits the `assert!(can_receive_direct_coin_transfers(to), ...)` check and aborts.
5. The entire transaction reverts. Bob receives nothing. The coins remain in the staking pool.
6. Admin calls `terminate_vesting_contract(admin, contract_address)` — it calls `distribute()` internally and also aborts.
7. `admin_withdraw()` requires `VESTING_POOL_TERMINATED` state, which is never set. All APT is permanently frozen. [7](#0-6) [8](#0-7)

    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }
