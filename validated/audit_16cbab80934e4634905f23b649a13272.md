### Title
Unauthenticated event ingestion on the signer's `SignerEventReceiver` HTTP endpoint - (File: `libsigner/src/events.rs`)

### Summary
The `SignerEventReceiver` in `libsigner/src/events.rs` binds a plain HTTP server (`tiny_http`) that accepts `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, and `/shutdown` POST requests and forwards their bodies directly into the signer's decision-making runloop, with no authentication of the sender.

### Finding Description
`SignerEventReceiver::next_event` dispatches based solely on the URL path and deserializes whatever JSON body is posted, with no check of caller identity, secret, or signature: [1](#0-0) 

`process_event` reads the raw body and attempts `serde_json` deserialization into the expected event type, then converts it into a `SignerEvent`, again without validating the origin of the request: [2](#0-1) 

The accepted event is unconditionally forwarded to every registered consumer channel (i.e., the signer's runloop) via `forward_event`: [3](#0-2) 

There is no `Authorization` header, shared secret, or source-address allowlist check anywhere in `libsigner/src/events.rs` — a grep for `Authorization|auth_token|bearer|shared_secret` in `libsigner/**` returned no matches. This is the same bug class as the reported `notifyFeeReceived` issue: an event-ingestion entry point that any caller can invoke to inject an "event" whose authenticity is never verified by the receiver itself, `/shutdown` even allows an unauthenticated terminate of the receiver loop.

This differs from the StackerDB chunk-write path (`stackslib/src/net/stackerdb/mod.rs::validate_received_chunk`, `stackslib/src/net/api/poststackerdbchunk.rs`), which does cryptographically verify a `MessageSignature` against the slot's registered owner before accepting a chunk — that path is correctly access-controlled and out of scope for this finding. The unauthenticated surface is specifically the local event receiver that the Stacks node's `EventDispatcher` (`stacks-node/src/event_dispatcher.rs`) is configured to POST to, and which `stacks-signer` listens on.

### Impact Explanation
Whoever can reach the bound TCP port of `SignerEventReceiver` can forge `BurnBlockEvent`, `StacksBlockEvent`, `BlockValidateResponse` (proposal_response), or `StackerDBChunksEvent` payloads and inject them straight into the signer's decision runloop, or send `/shutdown` to unauthenticatedly terminate the receiver. Since consensus-critical signer decision logic consumes these forwarded events, this could steer the signer's internal state with attacker-supplied, unauthenticated data if the port is reachable from outside the intended trust boundary (e.g., misconfiguration, container network exposure, or a compromised co-located process). This matches the "unauthenticated/unauthorized write to state" and "unauthenticated DoS" impact classes (the `/shutdown` path is a trivial one-request DoS).

### Likelihood Explanation
Exploitability is contingent on network exposure of the bind address (typically intended to be localhost/private, per the node's `events_observers` configuration), but the receiver code itself performs zero authentication regardless of binding — the vulnerability is a code-level absence of access control, not merely a config issue. Any process capable of reaching the listener (misconfigured bind interface, container/network misconfiguration, or an attacker who reaches an exposed management interface) can exploit it with a single crafted POST request, no keys or privileges required.

### Recommendation
Add authentication to `SignerEventReceiver`/`process_event` in `libsigner/src/events.rs`, e.g., a shared-secret/bearer token configured between the node's `EventDispatcher` and the signer's event listener, verified before processing `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, and especially before honoring `/shutdown`. At minimum, restrict the listener to loopback and document/enforce that it must never be exposed beyond the local trust boundary, and reject requests lacking the expected credential rather than silently `ack`-ing and processing them.

### Proof of Concept
1. Start a `stacks-signer` instance; note the bind address/port from its event-receiver config (`SignerEventReceiver::bind`).
2. From any host that can reach that address, send:
   ```
   POST /new_burn_block HTTP/1.1
   Content-Type: application/json

   { ...forged BurnBlockEvent JSON... }
   ```
3. Observe via `process_event` (`libsigner/src/events.rs:519-542`) that the forged JSON is deserialized and forwarded via `forward_event` into the signer runloop, with no check that the request came from the legitimate node.
4. Separately, send `POST /shutdown` with no body/credentials and observe the event receiver's stop signal is set, terminating the receiver loop (`libsigner/src/events.rs:443-445`).

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
