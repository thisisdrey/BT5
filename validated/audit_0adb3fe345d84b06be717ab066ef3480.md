The closest structurally analogous Go code is in modular exponentiation / RSA exponent handling (`math/big.Int.Exp`, `src/crypto/internal/fips140/bigmod/nat.go`'s `Exp`/`ExpShortVarTime`, and RSA public/large-exponent validation in `src/crypto/internal/fips140/rsa/largeexponent.go`), which is exactly where "unbounded exponent size → unbounded computation" would occur.
