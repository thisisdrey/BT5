### Title
Unhandled exception during smart-contract event/log parsing crashes the node via `Manager.blockTrigger` → `TronError` (`System.exit`) - (File: `framework/src/main/java/org/tron/core/db/Manager.java`)

### Summary
`Manager.blockTrigger()` wraps `postBlockFilter`, `postLogsFilter`, `postSolidityFilter`, `postBlockTrigger`, and `postSolidityTrigger` in a single `try { ... } catch (Exception e) { ...; throw new TronError(e, TronError.ErrCode.EVENT_SUBSCRIBE_ERROR); }` block [1](#0-0) . `TronError` is documented as fatal-by-design: throwing it triggers `System.exit()` via the default uncaught exception handler and callers are told never to catch it [2](#0-1) . `blockTrigger` is invoked from `pushBlock` right after a block (containing attacker-supplied smart-contract event/log data) is committed [3](#0-2) .

### Finding Description
The log/event-parsing pipeline that runs inside this window (`postLogsFilter` → `LogMatch`/`ContractEventParserAbi`/`ContractEventParserJson`, and `postBlockTrigger`/`postSolidityTrigger` → `BlockEventGet.processTrigger`/`LogInfoTriggerParser`) processes attacker-controlled contract ABI entries, event topics, and log data taken directly from a deployed contract's emitted events [4](#0-3) . While many of the individual parsing helpers (`ContractEventParser.parseDataBytes`, `subBytes`, `ContractEventParserJson.parseEventData`) have been hardened with explicit bounds checks and `try/catch(UnsupportedOperationException | ArithmeticException)` guards [5](#0-4) [6](#0-5) , `ContractEventParserAbi.parseTopics`/`parseEventData` and `LogMatch.matchBlock`/`processTrigger` in `BlockEventGet` call into the same `parseTopic`/`Hash.sha3` machinery without an equivalent broad catch, and the overall `blockTrigger` wrapper only catches `Exception` (not `Error`/`Throwable`). Any unexpected `RuntimeException`, `OutOfMemoryError`, or other `Throwable` escaping deep in this call chain (e.g. via malformed/mismatched ABI vs. actual log topics/data crafted by an unprivileged contract deployer, or a `NullPointerException` similar to the one already reproduced in `ManagerMockTest.testPostContractTriggerSwallowsThrowable`) that is *not* caught locally is converted by `blockTrigger`'s `catch (Exception e)` into a `TronError`, and `TronError` unconditionally exits the process. Unlike `postContractTrigger`, which explicitly `catch (Throwable throwable)` and only logs a warning (proven safe by `ManagerMockTest.testPostContractTriggerSwallowsThrowable`) [7](#0-6) , the JSON-RPC filter/log path (`postLogsFilter`→`LogMatch`) and the event-subscribe trigger path invoked from `blockTrigger` do not have that same defensive `Throwable` boundary at every layer, so a crafted contract event can propagate an exception all the way to the fatal `TronError` handler.

### Impact Explanation
If reachable, this converts a benign parsing bug into a full node crash/halt: `TronError`'s contract is to call `System.exit`, taking down the java-tron process entirely (or, for a witness/SR node, halting block production), rather than merely degrading a filter or trigger feature. This matches the "node crash or halt" acceptance criterion — a much more severe outcome than the original GitLab job-log DoS.

### Likelihood Explanation
Reaching this path requires: (1) deploying a smart contract with a crafted ABI (`CreateSmartContract`, unprivileged), and (2) triggering it to emit a log/event whose topics/data are deliberately inconsistent with the ABI in a way not already covered by the hardened `UnsupportedOperationException`/`ArithmeticException`/`OutputLengthException` catches added in `ContractEventParser`. This is plausible but not proven with a concrete exception-triggering input in this codebase — most of the obvious edge cases (oversized length, negative offset, negative length) have already been patched and covered by regression tests (`EventParserTest`, `EventParserJsonTest`), and `postContractTrigger` itself is hardened. The likelihood therefore depends on finding a remaining unguarded code path (e.g., in `ContractEventParserAbi` used by `BlockEventGet.processTrigger`/`LogInfoTriggerParser`, which lacks the same `try/catch` wrapping present in `ContractEventParserJson.parseEventData`), which I could not fully confirm is exploitable without executing the code.

### Recommendation
Broaden the catch in `Manager.blockTrigger` (and any similarly fatal-on-exception wrapper around log/event/trigger processing) from `catch (Exception e)` to `catch (Throwable t)`, and avoid escalating recoverable parsing failures to `TronError`/`System.exit`; instead log and skip the malformed trigger, mirroring the pattern already used in `postContractTrigger`. Additionally, audit `ContractEventParserAbi.parseTopics`/`parseEventData` and `BlockEventGet.processTrigger`/`LogInfoTriggerParser` to ensure they have the same defensive bounds/format checks and local exception handling as `ContractEventParserJson`, so malformed on-chain log data can never surface as an uncaught exception in the block-application/trigger-emission path.

### Proof of Concept
Not independently reproduced. A concrete PoC would deploy a contract whose ABI event signature matches a log's first topic but whose declared parameter types are crafted to make `ContractEventParserAbi.parseTopics`/`parseEventData` (invoked via `BlockEventGet.processTrigger` or `TransactionLogTriggerCapsule`) throw an uncaught `RuntimeException`/`Error` during `postBlockTrigger`/`postSolidityTrigger`/`postLogsFilter`, which `blockTrigger`'s `catch (Exception e)` would convert into a fatal `TronError`. I was not able to construct and verify such an input against the current hardened parsing code within the scope of this review, so this should be treated as a plausible but unverified analog pending dynamic testing.

  void blockTrigger(final BlockCapsule block, long oldSolid, long newSolid) {
    // post block and logs for jsonrpc
    try {
      if (CommonParameter.getInstance().isJsonRpcHttpFullNodeEnable()) {
        postBlockFilter(block, false);
        postLogsFilter(block, false, false);
      }

      if (CommonParameter.getInstance().isJsonRpcHttpSolidityNodeEnable()) {
        postSolidityFilter(oldSolid, newSolid);
      }

      if (EventPluginLoader.getInstance().getVersion() != 0) {
        lastUsedSolidityNum = newSolid;
        return;
      }

      // if event subscribe is enabled, post block trigger to queue (real-time, not removed)
      postBlockTrigger(block, false);
      // if event subscribe is enabled, post solidity trigger to queue
      // (also emits solidified-mode block/transaction triggers)
      postSolidityTrigger(newSolid);
    } catch (Exception e) {
      logger.error("Block trigger failed. head: {}, oldSolid: {}, newSolid: {}",
          block.getNum(), oldSolid, newSolid, e);
      throw new TronError(e, TronError.ErrCode.EVENT_SUBSCRIBE_ERROR);
    }
  }

  private ContractTrigger processTrigger(ContractTrigger contractTrigger) {
    ContractTrigger event;
    boolean isEvent = false;
    LogInfo logInfo = contractTrigger.getLogInfo();
    SmartContractOuterClass.SmartContract.ABI abi = contractTrigger.getAbi();
    List<DataWord> topics = logInfo.getTopics();

    String eventSignature = "";
    String eventSignatureFull = "fallback()";
    String entryName = "";
    SmartContractOuterClass.SmartContract.ABI.Entry eventEntry = null;

    if (abi != null && abi.getEntrysCount() > 0 && topics != null && !topics.isEmpty()
        && !ArrayUtils.isEmpty(topics.get(0).getData())
        && Args.getInstance().getStorage().isContractParseSwitch()) {
      String logHash = topics.get(0).toString();

      for (SmartContractOuterClass.SmartContract.ABI.Entry entry : abi.getEntrysList()) {
        if (entry.getType() != SmartContractOuterClass.SmartContract.ABI.Entry.EntryType.Event
            || entry.getAnonymous()) {
          continue;
        }

        String signature = entry.getName() + "(";
        String signatureFull = entry.getName() + "(";
        StringBuilder signBuilder = new StringBuilder();
        StringBuilder signFullBuilder = new StringBuilder();
        for (SmartContractOuterClass.SmartContract.ABI.Entry.Param param : entry.getInputsList()) {
          if (signBuilder.length() > 0) {
            signBuilder.append(",");
            signFullBuilder.append(",");
          }
          String type = param.getType();
          String name = param.getName();
          signBuilder.append(type);
          signFullBuilder.append(type);
          if (org.pf4j.util.StringUtils.isNotNullOrEmpty(name)) {
            signFullBuilder.append(" ").append(name);
          }
        }
        signature += signBuilder + ")";
        signatureFull += signFullBuilder + ")";
        String sha3 = Hex.toHexString(Hash.sha3(signature.getBytes()));
        if (sha3.equals(logHash)) {
          eventSignature = signature;
          eventSignatureFull = signatureFull;
          entryName = entry.getName();
          eventEntry = entry;
          isEvent = true;
          break;
        }
      }
    }

    if (isEvent) {
      event = new ContractEventTrigger();
      ((ContractEventTrigger) event).setEventSignature(eventSignature);
      ((ContractEventTrigger) event).setEventSignatureFull(eventSignatureFull);
      ((ContractEventTrigger) event).setEventName(entryName);

      List<byte[]> topicList = logInfo.getClonedTopics();
      byte[] data = logInfo.getClonedData();

      ((ContractEventTrigger) event)
          .setTopicMap(ContractEventParserAbi.parseTopics(topicList, eventEntry));
      ((ContractEventTrigger) event)
          .setDataMap(ContractEventParserAbi.parseEventData(data, topicList, eventEntry));
    } else {
      event = new ContractLogTrigger();
      ((ContractLogTrigger) event).setTopicList(logInfo.getHexTopics());
      ((ContractLogTrigger) event).setData(logInfo.getHexData());
    }

  public static String parseDataBytes(byte[] data, String typeStr, int index) {
    try {
      byte[] startBytes = subBytes(data, index * DATAWORD_UNIT_SIZE, DATAWORD_UNIT_SIZE);
      Type type = basicType(typeStr);

      if (type == Type.INT_NUMBER) {
        return new BigInteger(startBytes).toString();
      } else if (type == Type.BOOL) {
        return String.valueOf(!DataWord.isZero(startBytes));
      } else if (type == Type.FIXED_BYTES) {
        return Hex.toHexString(startBytes);
      } else if (type == Type.ADDRESS) {
        byte[] last20Bytes = Arrays.copyOfRange(startBytes, 12, startBytes.length);
        return StringUtil.encode58Check(TransactionTrace.convertToTronAddress(last20Bytes));
      } else if (type == Type.STRING || type == Type.BYTES) {
        int start = intValueExact(startBytes);
        byte[] lengthBytes = subBytes(data, start, DATAWORD_UNIT_SIZE);
        // this length is byte count. no need X 32
        int length = intValueExact(lengthBytes);
        if (length < 0) {
          throw new OutputLengthException("data length:" + length);
        }
        byte[] realBytes =
            length > 0 ? subBytes(data, start + DATAWORD_UNIT_SIZE, length) : new byte[0];
        return type == Type.STRING
            ? new String(realBytes, StandardCharsets.UTF_8)
            : Hex.toHexString(realBytes);
      }
    } catch (OutputLengthException | ArithmeticException e) {
      logger.debug("parseDataBytes ", e);
    }
    throw new UnsupportedOperationException("unsupported type:" + typeStr);
  }
