### Title
Stale-price arbitrage via `Pool.swap` front-running a permissionless pull-oracle price update — ([File: contracts/Pool.sol](contracts/Pool.sol))

### Summary
`Pool.swap` prices synthetic-token swaps exclusively through `MasterOracle.quote` and has no slippage/`amountOutMin` parameter [1](#0-0) . In the mainnet pull-oracle configuration, the Pyth feed is permissionlessly updatable by anyone who calls `updatePriceFeeds` with publicly available Hermes update data [2](#0-1) . An unprivileged attacker can atomically swap into a synth at the stale (old) price, push the new price on-chain, and swap back — extracting the price delta from the pool in a single transaction. This is the Metronome analog of front-running `updateCollectionPrice()` to buy cheap before a price increase.

### Finding Description
`swap` burns `syntheticTokenIn_` and mints `syntheticTokenOut_` using `quoteSwapOut`, which delegates to `masterOracle().quote(assetIn → assetOut)` [3](#0-2) . The only guards are `isSwapActive`, non-zero amount, and sender balance [4](#0-3) . There is no minimum-out check, no price-deviation bound, and no freshness check inside `swap` beyond the oracle's own staleness window (`price-too-behind`), which only rejects prices older than the configured staleness threshold — within that window the old price remains fully valid.

Because Pyth's `updatePriceFeeds` is permissionless and the signed update payload is publicly fetchable from Hermes before it lands on-chain, the attacker does not even need mempool front-running: they can bundle `swap` → `updatePriceFeeds` → `swap` into one transaction through `Operator.execute`, which supports arbitrary batched calls and preserves `msg.sender` via the transient `MSG_SENDER` slot [5](#0-4) .

### Impact Explanation
A `swap` is zero-sum mint/burn accounting: minting synth `X` cheap and re-swapping it after the price update mints back more `Y` than burned. The surplus synth is backed by the same collateral/debt pool, so the profit is extracted from all other synth holders and debtors — i.e., the effective collateralization of the synth supply is reduced (protocol insolvency / value extraction from users). Reproducible scenario:

- Stored ETH price = $2,000, still within the staleness window; Hermes publishes $2,200.
- Attacker swaps `msUSD → msETH` at the stale quote, receiving `amountIn * 1/2000` msETH.
- Attacker calls `pyth.updatePriceFeeds` (permissionless, cost = Pyth fee).
- Attacker swaps `msETH → msUSD` at $2,200, receiving ~10% more msUSD.
- Repeatable every update with a directional move exceeding `swapFees` (which can be 0 per pair) [6](#0-5) .

### Likelihood Explanation
Requires only an unprivileged EOA/contract. Preconditions: `isSwapActive` (it is on the live mainnet pool [7](#0-6) ), a pull oracle as the `MasterOracle` source (deployed configuration), and an off-chain price move between the stored update and the latest Hermes price — which is the normal state of crypto markets. Profit is capped by the price delta minus swap fee and by `SyntheticToken` supply caps, but requires no privileged role, no fake contracts, and no oracle corruption.

### Recommendation
- Add `amountOutMin_` to `Pool.swap` so callers can bound oracle-price slippage (breaks the atomic round-trip).
- Atomically refresh the pull-oracle price inside `swap` (or require a max-price-age tighter than the oracle provider's update cadence) so quotes never use a price older than the latest available update.
- Alternatively, treat swap quotes with the same "update-then-act" workflow the tests already demonstrate for deposits: force `updatePriceFeeds` (or staleness-bound enforcement) before executing the swap in `Operator.execute` flows.

### Proof of Concept
Foundry fork test outline (mainnet fork, `Pool`, `msUSD`, `msETH`, Pyth `0x4305fb66699c3b2702d4d05cf36551390a4c69c6`):

```solidity
function test_swapStalePriceArb() external {
    // wait until stored ETH price is stale-but-accepted and Hermes has a higher price
    uint256 usdIn = 1_000_000e18;
    deal(msUSD, attacker, usdIn);

    vm.startPrank(attacker);
    // 1. buy msETH at stale price
    pool.swap(msUSD, msETH, usdIn);
    uint256 msEthBal = IERC20(msETH).balanceOf(attacker);

    // 2. permissionlessly push new (higher) price
    pyth.updatePriceFeeds{value: fee}(updateData); // updateData from Hermes

    // 3. sell back at new price
    pool.swap(msETH, msUSD, msEthBal);
    vm.stopPrank();

    assertGt(IERC20(msUSD).balanceOf(attacker), usdIn); // profit = delta - fees
}
```

Equivalent single-transaction version via `Operator.execute([swap, updatePriceFeeds, swap])`, mirroring the existing E2E bundle pattern [8](#0-7) .

```text
    function quoteSwapOut(
        ISyntheticToken syntheticTokenIn_,
        ISyntheticToken syntheticTokenOut_,
        uint256 amountIn_
    ) public view override returns (uint256 _amountOut, uint256 _fee) {
        _amountOut = _poolRegistry.masterOracle().quote(
            address(syntheticTokenIn_),
            address(syntheticTokenOut_),
            amountIn_
        );

        uint256 _swapFee = feeProvider.swapFees(address(syntheticTokenIn_), address(syntheticTokenOut_));

        if (_swapFee > 0) {
            _fee = _amountOut.wadMul(_swapFee);
            _amountOut -= _fee;
        }
    }
```

```text
    function swap(
        ISyntheticToken syntheticTokenIn_,
        ISyntheticToken syntheticTokenOut_,
        uint256 amountIn_
    )
        external
        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticTokenIn_)
        onlyIfSyntheticTokenExists(syntheticTokenOut_)
        returns (uint256 _amountOut, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (!isSwapActive) revert SwapFeatureIsInactive();
        if (amountIn_ == 0 || amountIn_ > syntheticTokenIn_.balanceOf(_msgSender)) revert AmountInIsInvalid();

        syntheticTokenIn_.burn(_msgSender, amountIn_);

        (_amountOut, _fee) = quoteSwapOut(syntheticTokenIn_, syntheticTokenOut_, amountIn_);

        if (_fee > 0) {
            syntheticTokenOut_.mint(_poolRegistry.feeCollector(), _fee);
        }

        syntheticTokenOut_.mint(_msgSender, _amountOut);

        emit SyntheticTokenSwapped(_msgSender, syntheticTokenIn_, syntheticTokenOut_, amountIn_, _amountOut, _fee);
    }
```
