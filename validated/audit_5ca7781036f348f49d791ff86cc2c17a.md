### Title
Unstaked QoS per-peer connection cap is bypassed via free ephemeral pubkeys, allowing single-IP Sybil capture of the shared unstaked connection pool - ([File: streamer/src/nonblocking/swqos.rs])

### Summary
`SwQos::cache_new_connection` keys the unstaked connection table by `ConnectionTableKey::new(remote_addr.ip(), conn_context.remote_pubkey)`, which resolves to `ConnectionTableKey::Pubkey` whenever a pubkey is present. Because any QUIC client can present a fresh, self-signed certificate with an arbitrary freshly-generated `Keypair` at zero cost, an unstaked attacker from a single source IP can mint unlimited distinct `ConnectionTableKey::Pubkey` entries, each independently allowed up to `max_connections_per_unstaked_peer`, consuming the shared `max_unstaked_connections` budget while the per-peer cap intended to bound abuse per source is never engaged.

### Finding Description
`ConnectionTableKey::new` maps `(ip, Some(pubkey)) -> ConnectionTableKey::Pubkey(pubkey)` and only falls back to `ConnectionTableKey::IP(ip)` when no pubkey is available [1](#0-0) . `SwQos::cache_new_connection` always constructs the key from `conn_context.remote_pubkey`, which is populated from `solana_tls_utils::get_remote_pubkey(connection)` [2](#0-1) .

`get_remote_pubkey` simply decodes whatever self-signed certificate the peer presented during the TLS handshake and extracts the embedded public key — there is no binding to a known/staked identity [3](#0-2) . Client certificates are generated from an arbitrary `Keypair` (a fresh one is created if none supplied) via `new_dummy_x509_certificate` [4](#0-3) , and the server's `SkipClientVerification::verify_client_cert` unconditionally accepts any client certificate regardless of the embedded pubkey [5](#0-4) .

Consequently, `try_add_connection` sees each new ephemeral-pubkey connection as belonging to a brand-new table entry rather than an existing one, so the `max_connections_per_peer` check (`connection_entry.len() + 1 <= max_connections_per_peer`) is evaluated per-key, never accumulating across the attacker's actual IP [6](#0-5) . This is explicitly demonstrated (and treated as intended per-pubkey behavior) by the existing test `test_prune_table_with_unique_pubkeys`, which asserts that using distinct pubkeys allows exceeding `max_connections_per_peer` [7](#0-6) . However, all such connections still land in the same `unstaked_connection_table` and count against the single shared `max_unstaked_connections` ceiling enforced/pruned only by LRU recency in `prune_unstaked_connection_table`, not by IP [8](#0-7) .

### Impact Explanation
A single unstaked attacker IP can occupy a disproportionate share (up to the entire `max_unstaked_connections` pool, subject only to any independent connection-rate limiter) of slots that are supposed to be fairly shared among unstaked peers, by rotating a new ephemeral Ed25519 keypair per QUIC connection. This is a QoS/admission-control evasion: legitimate unstaked peers keyed by their own single identity are starved out or preferentially pruned while the attacker's many single-connection, distinct-pubkey entries persist, degrading TPU availability for genuine unstaked traffic. This falls under the Agave QoS-evasion / DoS-adjacent bounty category, scoped to the streamer's QUIC connection admission path.

### Likelihood Explanation
Highly feasible: generating an Ed25519 keypair and a self-signed certificate is computationally trivial and requires no stake, no gossip participation, and no privileged access — just repeated TCP/UDP QUIC handshakes from one IP with distinct client certs, fully within the "unstaked remote client opening QUIC connections to leader TPU" threat model. The only friction is any external per-IP connection-rate limiter (`ConnectionRateLimiter`), which bounds the *rate* of new connections but not the *total distinct identities* admitted over time, so sustained attack traffic can still gradually saturate the unstaked pool.

### Recommendation
Enforce an additional IP-scoped ceiling for unstaked connections independent of the presented pubkey (e.g., track and cap concurrent/admitted connections per source IP in addition to per-pubkey, or ignore/de-prioritize self-signed-cert pubkeys for unstaked (non-staked-verified) peers and key them by IP only, as already done when no pubkey is present).

### Proof of Concept
```rust
// streamer/src/nonblocking/quic.rs (added test)
#[test]
fn test_unstaked_pubkey_rotation_bypasses_ip_ceiling() {
    agave_logger::setup();
    let cancel = CancellationToken::new();
    let mut table = ConnectionTable::new(ConnectionTableType::Unstaked, cancel);
    let stats = Arc::new(StreamerStats::default());
    let fixed_ip = IpAddr::V4(std::net::Ipv4Addr::new(10, 0, 0, 1));
    let max_connections_per_peer = 2; // e.g. max_connections_per_unstaked_peer

    // Attacker rotates N distinct ephemeral pubkeys from ONE ip.
    let n = 50;
    let mut admitted = 0;
    for i in 0..n {
        let pubkey = Pubkey::new_unique();
        let key = ConnectionTableKey::new(fixed_ip, Some(pubkey));
        if table
            .try_add_connection(
                key,
                0,
                ClientConnectionTracker::new(stats.clone(), 1000).unwrap(),
                None,
                ConnectionPeerType::Unstaked,
                Arc::new(AtomicU64::new(i as u64)),
                max_connections_per_peer,
                || Arc::new(NullStreamerCounter {}),
            )
            .is_some()
        {
            admitted += 1;
        }
    }

    // Expected (invariant): total admitted connections from a single IP
    // should be bounded (e.g. <= some IP-level ceiling), not grow linearly
    // with the number of distinct spoofed pubkeys.
    assert!(
        admitted <= max_connections_per_peer,
        "attacker admitted {admitted} connections from one IP by rotating pubkeys, \
         exceeding intended per-source cap of {max_connections_per_peer}"
    );
}
```
Running this against current code shows `admitted == n` (all 50 admitted), demonstrating the per-IP ceiling is not enforced, only the trivially-evadable per-pubkey ceiling.

    fn test_prune_table_with_unique_pubkeys() {
        agave_logger::setup();
        let cancel = CancellationToken::new();
        let mut table = ConnectionTable::new(ConnectionTableType::Unstaked, cancel);

        // We should be able to add more entries than max_connections_per_peer, since each entry is
        // from a different peer pubkey.
        let num_entries = 15;
        let max_connections_per_peer = 10;
        let stats = Arc::new(StreamerStats::default());

        let pubkeys: Vec<_> = (0..num_entries).map(|_| Pubkey::new_unique()).collect();
        for (i, pubkey) in pubkeys.iter().enumerate() {
            table
                .try_add_connection(
                    ConnectionTableKey::Pubkey(*pubkey),
                    0,
                    ClientConnectionTracker::new(stats.clone(), 1000).unwrap(),
                    None,
                    ConnectionPeerType::Unstaked,
                    Arc::new(AtomicU64::new(i as u64)),
                    max_connections_per_peer,
                    || Arc::new(NullStreamerCounter {}),
                )
                .unwrap();
        }

        let new_size = 3;
        let pruned = table.prune_oldest(new_size);
        assert_eq!(pruned, num_entries as usize - new_size);
        assert_eq!(table.table.len(), new_size);
        assert_eq!(table.total_size, new_size);
        for pubkey in pubkeys.iter().take(num_entries as usize).skip(new_size - 1) {
            table.remove_connection(ConnectionTableKey::Pubkey(*pubkey), 0, 0);
        }
        assert_eq!(table.total_size, 0);
        assert_eq!(stats.open_connections.load(Ordering::Relaxed), 0);
    }

    fn prune_unstaked_connection_table(
        &self,
        unstaked_connection_table: &mut ConnectionTable<ConnectionStreamCounter>,
        max_unstaked_connections: usize,
        stats: Arc<StreamerStats>,
    ) {
        if unstaked_connection_table.total_size >= max_unstaked_connections {
            // Prune the connection table down to 90% capacity
            const PRUNE_TABLE_RATIO: f64 = 0.90;
            let max_connections = (PRUNE_TABLE_RATIO * (max_unstaked_connections as f64)) as usize;
            let num_pruned = unstaked_connection_table.prune_oldest(max_connections);
            stats
                .num_evictions_unstaked
                .fetch_add(num_pruned, Ordering::Relaxed);
        }
    }

    async fn prune_unstaked_connections_and_add_new_connection(
        &self,
        client_connection_tracker: ClientConnectionTracker,
        connection: &Connection,
        connection_table: Arc<Mutex<ConnectionTable<ConnectionStreamCounter>>>,
        max_connections: usize,
        conn_context: &SwQosConnectionContext,
    ) -> Result<
        (
            Arc<AtomicU64>,
            CancellationToken,
            Arc<ConnectionStreamCounter>,
        ),
        ConnectionHandlerError,
    > {
        let stats = self.stats.clone();
        if max_connections > 0 {
            let mut connection_table = connection_table.lock().await;
            self.prune_unstaked_connection_table(&mut connection_table, max_connections, stats);
            self.cache_new_connection(
                client_connection_tracker,
                connection,
                connection_table,
                conn_context,
            )

                CONNECTION_CLOSE_CODE_DISALLOWED.into(),
                CONNECTION_CLOSE_REASON_DISALLOWED,
            );
            Err(ConnectionHandlerError::ConnectionAddError)
        }

/// Recover the peer's Solana pubkey from a `quinn::Connection`. Accepts
/// only a self-signed cert chain of length 1 (matches the cert shape
/// produced by [`new_dummy_x509_certificate`]).
///
/// Single source of truth for anything doing QUIC and using
/// Solana validator identities for auth.
pub fn get_remote_pubkey(connection: &quinn::Connection) -> Option<Pubkey> {
    connection
        .peer_identity()?
        .downcast::<Vec<rustls::pki_types::CertificateDer>>()
        .ok()
        .filter(|certs| certs.len() == 1)?
        .first()
        .and_then(get_pubkey_from_tls_certificate)
}
