### Title
Debt-floor and liquidation-cap checks can permanently block liquidation of small unhealthy positions - ([File: contracts/Pool.sol](contracts/Pool.sol))

### Summary
`Pool.liquidate()` can enter an unrecoverable state for positions whose remaining synthetic debt value is at or near `debtFloorInUsd`, because a full repayment exceeds `maxLiquidable` while every permitted partial repayment leaves a nonzero debt below the floor. [1](#0-0) 

### Finding Description
`Pool.initialize()` sets `maxLiquidable` to 50%, so a liquidator cannot ordinarily repay the full debt of a position. [2](#0-1) 

During liquidation, `amountToRepay_.wadDiv(_debtTokenBalance) > maxLiquidable` causes a full repayment to revert. [3](#0-2) 

Immediately afterward, the function prices the post-liquidation debt and reverts whenever the remaining debt is both nonzero and below `debtFloorInUsd`. [4](#0-3) 

`DebtToken._mint()` allows a borrower to open a position whose debt is exactly equal to the floor because it only rejects values strictly below `debtFloorInUsd`. [5](#0-4) 

Once such a minimally sized position becomes unhealthy, any positive liquidation amount leaves a nonzero remaining debt below the floor, while repaying the whole balance violates `maxLiquidable`. [6](#0-5) 

The same trap is reached after legitimate partial liquidations reduce an unhealthy account's debt to the floor boundary. [4](#0-3) 

### Impact Explanation
An unhealthy position can retain bad debt and collateral indefinitely because every public `liquidate()` repayment size either exceeds `maxLiquidable` or produces `RemainingDebtIsLowerThanTheFloor`. [7](#0-6) 

The liquidation liveness invariant therefore breaks for exactly the small, risky positions most likely to become bad debt after collateral declines. [8](#0-7) 

If the collateral later falls below the outstanding debt value, the protocol is left with an unliquidatable insolvent account rather than merely a temporarily unavailable feature. [8](#0-7) 

The borrower could voluntarily call `repayAll()`, but that cannot be relied on to protect the protocol because an attacker controlling the account has no incentive to repay. [9](#0-8) 

### Likelihood Explanation
An unprivileged borrower can intentionally create this state by depositing collateral and issuing debt with an oracle value at or just above `debtFloorInUsd`; equality is expressly permitted by the debt-mint floor check. [5](#0-4) 

Only an ordinary adverse collateral-price movement is then required to make the minimally sized debt unhealthy; no privileged call, malicious oracle response, flash loan, or external-contract failure is needed. [8](#0-7) 

The issue requires a deployed pool configured with `debtFloorInUsd > 0` and `maxLiquidable < 1e18`; the initialized production code path sets `maxLiquidable` to 50%. [2](#0-1) 

### Recommendation
Allow liquidation to fully close an unhealthy position when the remaining debt would otherwise be below `debtFloorInUsd`, rather than applying `maxLiquidable` before the terminal-debt exception. [1](#0-0) 

For example, compute the allowed repayment as `debtBalance` when `debtBalance` is at or below the floor, or when the desired capped amount would leave a nonzero amount below the floor. [10](#0-9) 

Alternatively, prevent issuance and repayment flows from ever leaving debt below the floor and add an explicit full-close liquidation path for floor-sized unhealthy accounts. [5](#0-4) 

### Proof of Concept
The following Foundry fork test demonstrates the reachable terminal state against a configured pool; replace `POOL_ADDRESS` with a deployed pool where `debtFloorInUsd() > 0`. [1](#0-0) 

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.24;

import {Test} from "forge-std/Test.sol";
import {IERC20} from "../contracts/dependencies/openzeppelin/token/ERC20/IERC20.sol";
import {IPool} from "../contracts/interfaces/IPool.sol";
import {IDepositToken} from "../contracts/interfaces/IDepositToken.sol";
import {IDebtToken} from "../contracts/interfaces/IDebtToken.sol";
import {ISyntheticToken} from "../contracts/interfaces/ISyntheticToken.sol";
import {IMasterOracle} from "../contracts/interfaces/external/IMasterOracle.sol";

error AmountGreaterThanMaxLiquidable();
error RemainingDebtIsLowerThanTheFloor();

contract FloorLiquidationLockTest is Test {
    function test_floorSizedDebtCannotBeLiquidated() public {
        IPool pool = IPool(vm.envAddress("POOL_ADDRESS"));
        IMasterOracle oracle = pool.masterOracle();
        uint256 floor = pool.debtFloorInUsd();

        require(floor > 0, "pool must use a nonzero debt floor");
        require(pool.maxLiquidable() < 1e18, "pool must cap liquidation");

        IDepositToken collateral = IDepositToken(pool.getDepositTokens()[0]);
        IDebtToken debtToken = IDebtToken(pool.getDebtTokens()[0]);
        ISyntheticToken synth = debtToken.syntheticToken();
        IERC20 underlying = collateral.underlying();

        address borrower = address(0xB0B);
        address liquidator = address(0xCAFE);

        uint256 debtAmount = oracle.quoteUsdToToken(address(synth), floor);
        uint256 collateralAmount =
            oracle.quoteUsdToToken(address(underlying), floor * 2e18 / collateral.collateralFactor());

        deal(address(underlying), borrower, collateralAmount);
        deal(address(underlying), liquidator, collateralAmount * 2);

        vm.startPrank(borrower);
        underlying.approve(address(collateral), collateralAmount);
        collateral.deposit(collateralAmount, borrower);
        debtToken.issue(debtAmount, borrower);
        vm.stopPrank();

        // Give the liquidator synth through normal protocol issuance.
        vm.startPrank(liquidator);
        underlying.approve(address(collateral), collateralAmount * 2);
        collateral.deposit(collateralAmount * 2, liquidator);
        debtToken.issue(debtAmount, liquidator);
        vm.stopPrank();

        uint256 borrowerDepositBalance = collateral.balanceOf(borrower);
        uint256 collateralFactor = collateral.collateralFactor();
        uint256 unhealthyCollateralUsd = (floor * 1e18 / collateralFactor) - 1;

        // Model a legitimate post-deposit market quote in which the collateral
        // has fallen enough to make the floor-sized debt unhealthy.
        vm.mockCall(
            address(oracle),
            abi.encodeCall(
                IMasterOracle.quoteTokenToUsd,
                (address(underlying), borrowerDepositBalance)
            ),
            abi.encode(unhealthyCollateralUsd)
        );

        (bool healthy,,,,) = pool.debtPositionOf(borrower);
        assertFalse(healthy);

        vm.startPrank(liquidator);

        // A full close is prohibited by maxLiquidable.
        vm.expectRevert(AmountGreaterThanMaxLiquidable.selector);
        pool.liquidate(synth, borrower, debtAmount, collateral);

        // The maximum capped repayment leaves nonzero debt below the floor.
        vm.expectRevert(RemainingDebtIsLowerThanTheFloor.selector);
        pool.liquidate(synth, borrower, debtAmount.wadMul(pool.maxLiquidable()), collateral);

        vm.stopPrank();
    }
}
```
