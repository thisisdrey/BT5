### Title
Peer ban/deny enforcement keyed on ephemeral IP:port instead of the authenticated node public key allows a banned peer to trivially bypass `denied` restrictions - ([File: stackslib/src/net/db.rs], [File: stackslib/src/net/p2p.rs])

### Summary
The external report describes an attacker whose *identity* (a contract address) is checked with a proxy (`extcodesize`) that is not bound to a persistent, authenticated identity — so the attacker can destroy and recreate that identity at will to slip past a blocklist. In `stacks-core`, peer banning/denial (`PeerDB::set_deny_peer` / `PeerDB::is_peer_denied`) is similarly keyed on a mutable, attacker-controlled proxy for identity — the `(network_id, addrbytes, port)` tuple — rather than on the node's authenticated public key, which is the value actually used elsewhere (`can_register_peer_with_pubkey`, `get_pubkey_events`) to recognize "the same peer."

### Finding Description
`PeerDB::is_peer_denied` and `PeerDB::set_deny_peer` operate strictly on `(network_id, addrbytes, port)`: [1](#0-0) [2](#0-1) 

`process_bans()` in `p2p.rs`, which is triggered when a neighbor misbehaves, also writes the deny record keyed on `neighbor_key.addrbytes`/`port` (the socket-level `NeighborKey`), not on the neighbor's authenticated public key: [3](#0-2) 

And the actual connection-admission gate, `can_register_peer`, checks denial purely via IP/port: [4](#0-3) 

Meanwhile, the codebase clearly treats the **public key** — not the IP:port — as the durable identity of a peer for other purposes: `can_register_peer_with_pubkey` explicitly de-duplicates/tracks peers by public-key hash (`get_pubkey_events`), and `Neighbor`'s own `PartialEq` impl states "Neighbor equality is based on having the same address **and** public key": [5](#0-4) [6](#0-5) 

The handshake path (`validate_handshake` / `update_from_handshake_data`) accepts any public key at all — the only pubkey the code explicitly excludes is the local node's own key — with no check against the deny list by public key: [7](#0-6) [8](#0-7) 

This mirrors the report's fault pattern precisely: the enforcement point checks a *transient, attacker-controllable* attribute (an ephemeral socket address, analogous to `extcodesize`), while the system's true notion of node identity (the private/public keypair, analogous to a persistent contract address concept the report says should be used) is left completely unchecked by the deny/ban mechanism. A malicious node banned for misbehavior (protocol violations, StackerDB chunk spam, relay abuse, etc.) can simply reconnect from a different local port or a different source IP using the **same authenticated keypair**, and `is_peer_denied`/`can_register_peer` will treat it as an entirely new, un-denied peer, exactly as the self-destruct/`CREATE2`-recreate attacker in the report evades `Blocklist.sol`'s `_isContract` check by recreating a "new" identity at will.

### Impact Explanation
This breaks the intended equality "banned public key == blocked from reconnecting" and instead only enforces "banned IP:port == blocked." A remote, unauthenticated party can restore full P2P privileges (handshake, StackerDB chunk push/relay, gossip participation) after being banned, by reconnecting from a new ephemeral port/address while keeping the same keypair — no privileged access or victim cooperation is required. This is a bypass of a protocol-level access restriction (an "auth-gate" for continued participation) that other nodes rely on to keep misbehaving/malicious peers out of the gossip and StackerDB replication network, enabling continued propagation of abusive traffic, forged/invalid StackerDB pushes, or repeated protocol violations from an already-identified bad actor. It falls under "unauthenticated/unauthorized write to state (StackerDB continues to accept from banned key) / network-wide propagation of forged data by a peer that should be excluded" — i.e., a High-severity access-control equality break, since it only steers around a restriction rather than causing memory disclosure or crash.

### Likelihood Explanation
Likelihood is high: rotating the source port (or IP, which is cheap for many attackers, e.g., cloud/VPS/NAT scenarios) requires no privileged access, no cryptographic break, and no cooperation from any other party — the attacker only needs to reuse the same private key when reconnecting. The deny mechanism is exclusively keyed on network address fields throughout `db.rs` and `p2p.rs`, with no corresponding pubkey-based deny check found anywhere in the handshake/registration path.

### Recommendation
Extend the deny/ban mechanism to also track and check the misbehaving peer's public key hash (already computed and used elsewhere via `Hash160::from_node_public_key`), not just `(network_id, addrbytes, port)`. `can_register_peer`/`can_register_peer_with_pubkey` and `is_peer_denied` should reject/deny a connecting node if either its socket address or its authenticated public key matches an active deny record, and `process_bans` should persist deny records keyed by public key (in addition to address) so that a banned node cannot regain standing merely by changing its ephemeral network coordinates.

### Proof of Concept
1. Node `B` misbehaves against local node `A` (e.g., sends unsolicited/invalid StackerDB push chunks or violates gossip protocol). `A`'s `process_bans()` inserts a deny record for `(network_id, B_ip, B_port)` via `PeerDB::set_deny_peer` [9](#0-8) .
2. `B`, still holding the same private key, reconnects to `A` from a different local port (or a different IP it controls).
3. `PeerDB::is_peer_denied(conn, network_id, new_addr, new_port)` returns `false` because the query is keyed on `(network_id, addrbytes, port)` [1](#0-0) , and `can_register_peer` passes [4](#0-3) .
4. `A` performs the handshake with `B`'s same public key; `validate_handshake` never checks the deny list by public key, so `B` is accepted as a "new" peer [7](#0-6) , fully bypassing the earlier ban.

    /// Process ban requests.  Update the deny in the peer database.  Return the vec of event IDs to disconnect from.
    fn process_bans(&mut self) -> Result<Vec<DropPeer>, net_error> {
        if cfg!(test) && self.connection_opts.disable_network_bans {
            return Ok(vec![]);
        }

        let tx = self.peerdb.tx_begin()?;
        let mut disconnect = vec![];
        for event_id in self.bans.drain() {
            let (neighbor_key, neighbor_info_opt) = match self.peers.get(&event_id) {
                Some(convo) => match Neighbor::from_conversation(&tx, convo)? {
                    Some(neighbor) => {
                        if neighbor.is_allowed() {
                            debug!(
                                "Misbehaving neighbor {:?} is allowed; will not punish",
                                &neighbor.addr
                            );
                            continue;
                        }
                        (convo.to_neighbor_key(), Some(neighbor))
                    }
                    None => {
                        debug!(
                            "No such neighbor in peer DB, but will ban nevertheless: {:?}",
                            convo.to_neighbor_key()
                        );
                        (convo.to_neighbor_key(), None)
                    }
                },
                None => {
                    continue;
                }
            };

            disconnect.push(DropPeer {
                address: neighbor_key.addrbytes.clone(),
                port: neighbor_key.port,
                reason: DropReason::BannedConnection,
                source: DropSource::PeerNetwork,
            });

            let now = get_epoch_time_secs();
            let penalty = if let Some(neighbor_info) = neighbor_info_opt {
                if neighbor_info.denied < 0
                    || (neighbor_info.denied as u64) < now + DENY_MIN_BAN_DURATION
                {
                    now + DENY_MIN_BAN_DURATION
                } else {
                    // already recently penalized; make ban length grow exponentially
                    if ((neighbor_info.denied as u64) - now) * 2 < DENY_BAN_DURATION {
                        now + ((neighbor_info.denied as u64) - now) * 2
                    } else {
                        now + DENY_BAN_DURATION
                    }
                }
            } else {
                now + DENY_BAN_DURATION
            };

            debug!(
                "Ban peer {:?} for {}s until {}",
                &neighbor_key,
                penalty - now,
                penalty
            );

            PeerDB::set_deny_peer(
                &tx,
                neighbor_key.network_id,
                &neighbor_key.addrbytes,
                neighbor_key.port,
                penalty,
            )?;
        }

        tx.commit()?;
        Ok(disconnect)

    pub fn can_register_peer(
        &mut self,
        neighbor_key: &NeighborKey,
        outbound: bool,
    ) -> Result<(), net_error> {
        // don't talk to our bind address
        if self.is_bound(neighbor_key) {
            debug!(
                "{:?}: do not register myself at {:?}",
                &self.local_peer, neighbor_key
            );
            return Err(net_error::Denied);
        }

        // denied?
        if PeerDB::is_peer_denied(
            self.peerdb.conn(),
            neighbor_key.network_id,
            &neighbor_key.addrbytes,
            neighbor_key.port,
        )? {
            info!(
                "{:?}: Peer {:?} is denied; dropping",
                &self.local_peer, neighbor_key
            );
            return Err(net_error::Denied);
        }

        // already connected?
        if let Some(event_id) = self.get_event_id(neighbor_key) {
            debug!(
                "{:?}: already connected to {:?} on event {}",
                &self.local_peer, neighbor_key, event_id
            );
            return Err(net_error::AlreadyConnected(event_id, neighbor_key.clone()));
        }

        // unroutable?
        if !self.connection_opts.private_neighbors && neighbor_key.addrbytes.is_in_private_range() {
            debug!("{:?}: Peer {:?} is in private range and we are configured to drop private neighbors",
                  &self.local_peer,
                  neighbor_key
            );
            return Err(net_error::Denied);
        }

        // consider rate-limits on in-bound peers
        let num_outbound = PeerNetwork::count_outbound_conversations(&self.peers);
        if !outbound && (self.peers.len() as u64) - num_outbound >= self.connection_opts.num_clients
        {
            // too many inbounds
            info!("{:?}: Too many inbound connections", &self.local_peer);
            return Err(net_error::TooManyPeers);
        }

        Ok(())
    }

    /// Check to see if we can register a peer with a given public key in a given direction
    pub fn can_register_peer_with_pubkey(
        &mut self,
        nk: &NeighborKey,
        outbound: bool,
        pubkh: &Hash160,
    ) -> Result<(), net_error> {
        // can't talk to myself
        let my_pubkey_hash = Hash160::from_node_public_key(&Secp256k1PublicKey::from_private(
            &self.local_peer.private_key,
        ));
        if pubkh == &my_pubkey_hash {
            return Err(net_error::ConnectionCycle);
        }

        self.can_register_peer(nk, outbound).and_then(|_| {
            let other_events = self.get_pubkey_events(pubkh);
            if !other_events.is_empty() {
                for event_id in other_events.into_iter() {
                    if let Some(convo) = self.peers.get(&event_id) {
                        // only care if we're trying to connect in the same direction
                        if outbound == convo.is_outbound() {
                            let nk = self.get_event_neighbor_key(event_id).ok_or(
                                net_error::PeerNotConnected(format!(
                                    "No neighbor for event {event_id}",
                                )),
                            )?;
                            return Err(net_error::AlreadyConnected(event_id, nk));
                        }
                    }
                }
            }
            return Ok(());
        })
    }

    pub fn update_from_handshake_data(
        &mut self,
        preamble: &Preamble,
        handshake_data: &HandshakeData,
    ) -> Result<bool, net_error> {
        let pubk = handshake_data
            .node_public_key
            .to_public_key()
            .map_err(|e| net_error::DeserializeError(e.into()))?;

        self.peer_version = preamble.peer_version;
        self.peer_network_id = preamble.network_id;
        self.peer_services = handshake_data.services;
        self.peer_expire_block_height = handshake_data.expire_block_height;
        self.handshake_addrbytes = handshake_data.addrbytes.clone();
        self.handshake_port = handshake_data.port;
        self.data_url = handshake_data.data_url.clone();

        let mut updated = false;
        let cur_pubk_opt = self.connection.get_public_key();
        if let Some(cur_pubk) = cur_pubk_opt {
            if pubk != cur_pubk {
                debug!(
                    "{:?}: Upgrade key {:?} to {:?} expires {:?}",
                    &self,
                    &to_hex(&cur_pubk.to_bytes_compressed()),
                    &to_hex(&pubk.to_bytes_compressed()),
                    self.peer_expire_block_height
                );
                updated = true;
            }
        }

        self.connection.set_public_key(Some(pubk.clone()));

        Ok(updated)
    }
