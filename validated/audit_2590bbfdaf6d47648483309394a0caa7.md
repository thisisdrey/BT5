### Title
Unauthenticated HTTP event injection into signer runloop via `SignerEventReceiver::next_event` - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` (libsigner/src/events.rs:413-458) accepts any TCP connection to the signer's bound HTTP listener and dispatches purely on `request.url()` and `request.method()`, with no check on the peer's identity, no shared secret, and no validation that the request actually originated from the local stacks-node's event-dispatcher. Any client that can open a socket to that port can POST a forged JSON body to `/new_burn_block`, `/new_block`, `/proposal_response`, or `/stackerdb_chunks` and have it deserialized and forwarded verbatim to the signer runloop.

### Finding Description
The intended equality is: every `SignerEvent` reaching the runloop via `forward_event` should have originated from the local, trusted stacks-node's event-observer subsystem. This equality is broken because `next_event` performs zero authentication of the request source:
- `http_server.recv()` accepts the request from any connected `TcpStream` [1](#0-0) .
- Dispatch is purely by URL string match, with no header/secret/peer check before calling `process_event` [2](#0-1) .
- `process_event::<T,E>` reads the raw HTTP body, ACKs the request, and blindly `serde_json::from_slice`s it into `E`, then `TryInto<SignerEvent<T>>` [3](#0-2) .
- The `TryFrom<BurnBlockEvent>`/`TryFrom<StacksBlockEvent>`/`TryFrom<BlockValidateResponse>` impls copy attacker-supplied fields (`burn_height`, `consensus_hash`, `burn_header_hash`, block IDs, transactions, validation results) directly into `SignerEvent` variants with no cross-check against any node-held state [4](#0-3) [5](#0-4) .
- `forward_event` then sends this attacker-controlled `SignerEvent` straight to the runloop channel with no further gating [6](#0-5) .

`stacks-common/src/util/macros.rs` contains only generic byte/enum-definition macros unrelated to any authentication mechanism [7](#0-6) , confirming there is no shared-secret or auth macro backing this endpoint.

### Impact Explanation
An unprivileged remote party that can reach the signer's bound event-receiver port can inject forged `NewBurnBlock`, `NewBlock`, `BlockValidationResponse`, or (via forged `StackerDBChunksEvent`) `SignerMessages`/`MinerMessages` events straight into the signer's runloop, indistinguishable from genuine node-originated events. This is repeatable per TCP connection and requires no signature, secret, or state to forge, matching the "unauthenticated/unauthorized write to state" Critical category, since it can corrupt the signer's internal view of burn/chain tip and validation state, which feeds signing decisions.

### Likelihood Explanation
Preconditions are minimal: the attacker only needs network reachability to the port the signer binds via `bind()` [8](#0-7) . While operational guidance typically recommends binding to localhost or a private network, the code itself enforces no restriction, and the question's framing (reachable if bound non-locally or via port-forward) is accurate to the code path. No peer state, config secret, or privileged role is needed — a single crafted HTTP POST suffices, and it is trivially repeatable.

### Recommendation
Add source authentication to the signer's event HTTP listener: require a shared bearer token/secret configured between the node's `event_dispatcher` and the signer (checked in `next_event` before any URL dispatch), and/or bind the listener strictly to loopback with an explicit opt-in warning for any other bind address, and validate a `Host`/token header on every request in `next_event` before calling `process_event`.

### Proof of Concept
Rust test plan: 
1. Instantiate `SignerEventReceiver::<T>::new(false)` and call `bind("127.0.0.1:0")`, capturing the returned address.
2. In a separate thread, call `next_event()` in a loop and forward to an `mpsc::channel` via `add_consumer`.
3. From the test (acting as an unauthenticated attacker, not the real node), open a plain `TcpStream::connect` to the bound address and send a raw HTTP request:
```
POST /new_burn_block HTTP/1.1\r\nHost: 127.0.0.1\r\nContent-Length: <len>\r\nContent-Type: application/json\r\nConnection: close\r\n\r\n{"burn_block_hash":"...","burn_block_height":999999,"reward_recipients":[],"reward_slot_holders":[],"burn_amount":0,"consensus_hash":"...","parent_burn_block_hash":"..."}
```
4. Assert `next_event()` returns `Ok(SignerEvent::NewBurnBlock { burn_height: 999999, .. })` with the attacker-chosen `consensus_hash`, proving injection succeeded at libsigner/src/events.rs:441-442 without any authentication of the socket's origin.

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
