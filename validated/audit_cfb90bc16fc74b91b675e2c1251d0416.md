### Title
Firewall bypass via stale per-routine conntrack cache not invalidated on ruleset reload - (File: firewall.go)

### Summary
The bug class from the Sherlock report is "a cached value derived from prior state is reused for a security-relevant calculation instead of being revalidated against the current state, because the cache invalidation trigger is tied to the wrong event." In the Balancer case, the cached amplification factor from the last invariant calculation was used instead of the live parameter, producing a stale price. The reachable analog in nebula is the per-routine `ConntrackCache` (`firewall.ConntrackCache`) used in `Firewall.Drop` / `Firewall.inConns`, which is invalidated only by a fixed timer tick, not by a firewall ruleset change (`rulesVersion` bump).

### Finding Description
`Firewall.inConns` first checks a caller-supplied `localCache` (a `firewall.ConntrackCache`, i.e. `map[Packet]struct{}`) and returns `true` (packet allowed, no further rule check) immediately on a hit, entirely bypassing the `rulesVersion` revalidation logic that the authoritative `Firewall.Conntrack` map performs: [1](#0-0) 

Compare this to the authoritative conntrack path a few lines below, which explicitly re-validates an entry against the *current* ruleset whenever `c.rulesVersion != f.rulesVersion` (i.e., whenever the firewall config has been reloaded via SIGHUP): [2](#0-1) 

The `localCache` itself is populated unconditionally whenever a flow passes (`localCache[fp] = struct{}{}`) with no `rulesVersion` tag attached to the cache key/value at all: [3](#0-2) 

The cache's only invalidation mechanism is `ConntrackCacheTicker`, which resets the map purely based on a wall-clock ticker (`firewall.conntrack.routine_cache_timeout`, default 1s when routines>1) — it has no awareness of firewall rule reloads: [4](#0-3) [5](#0-4) 

Meanwhile, `reloadFirewall` (triggered on SIGHUP or config change) swaps in a brand-new `*Firewall` with an incremented `rulesVersion`, but the old `Conntrack` table (and therefore the entries backing any concurrently-held `localCache`) is carried forward and only the authoritative table performs re-validation — the per-routine cache is a separate object entirely unaffected by this reload event: [6](#0-5) 

So the invalidation event for `Conntrack` (rule change) and the invalidation event for `localCache` (fixed timer tick) are decoupled — exactly the same root-cause shape as the Balancer bug, where the cached invariant/amp-factor invalidation event (join/exit) is decoupled from the actual amp-factor update event (admin-triggered ramp).

### Impact Explanation
If an operator tightens firewall rules (e.g., via SIGHUP to remove a previously allowed rule or narrow ports/groups) while traffic for an already-permitted flow is in flight, any goroutine holding a `localCache` entry for that 4/5-tuple will continue to allow packets for that flow until the local cache's own timer tick fires — independent of, and in addition to, however long the authoritative `Conntrack` table would have allowed it under the correct re-check logic. This is a remote state poisoning / firewall bypass condition: traffic that should be dropped under the new, more restrictive ruleset is passed for an interval solely because of stale local cache state, not because of legitimate conntrack semantics.

This most directly affects deployments running with `routines > 1` (multi-queue mode), where `firewall.conntrack.routine_cache_timeout` defaults to 1 second and `localCache` is explicitly used to avoid lock contention on the shared `Conntrack` table.

### Likelihood Explanation
This requires an admin-driven ruleset change (SIGHUP reload) to occur while an attacker-controlled flow is already established and cached in a hot routine's local map — a believable but narrow operational window (bounded by the cache-reset ticker interval, default ~1s, but configurable/longer under other settings). It does not require attacker access to any host's certificate or private key; it only requires an already-permitted flow to exist at reload time, matching the "reachable by an attacker without a CA-signed certificate" criterion since the attacker side just needs its previously-allowed flow to still be replayed/continued during the reload race window.

### Recommendation
Tag `localCache` entries with the `rulesVersion` that was active when they were inserted (mirroring the `conn.rulesVersion` field used by the authoritative `Conntrack` map), and treat a `localCache` hit whose `rulesVersion` differs from the current `f.rulesVersion` as a cache miss requiring full re-validation against `table.match`, rather than an unconditional allow. Alternatively, invalidate/clear all routine-local caches synchronously as part of `reloadFirewall`'s swap-in of the new `Firewall` object.

### Proof of Concept
Not directly executable from static review alone; the following describes the reproducible race:
1. Start nebula with `routines > 1` (so `conntrackCacheTimeout` defaults to `1s`) and a firewall rule set `R1` permitting flow `F` (4/5-tuple).
2. Establish flow `F`; a receive routine's `localCache` records `F` as seen (`firewall.go` line 573-575) and the authoritative `Conntrack` records it with `rulesVersion = v1`.
3. Trigger SIGHUP with a new config `R2` that no longer permits `F`. `reloadFirewall` installs a new `Firewall` with `rulesVersion = v1+1` (interface.go lines 386-434); the authoritative `Conntrack.Conns[F]` entry would be correctly re-validated and dropped on next lookup via `inConns`'s rulesVersion check.
4. Within the same tick window (up to the configured `routine_cache_timeout`), continue sending packets for `F` to the same receiving goroutine. `inConns` hits `localCache[F]` first (firewall.go line 505-510) and returns `true` immediately, bypassing the `rulesVersion` check and the new `table.match` re-validation entirely — packets for `F` are allowed even though `R2` forbids them.
5. Only after the routine's `ConntrackCacheTicker` fires and clears `localCache` does the flow fall back to the authoritative, correctly-revalidated `Conntrack` path and get dropped.

I was not able to fully trace every call site that supplies `localCache` into `Drop`/`inConns` at runtime (e.g., the exact packet-read loop in `outside.go`) within the available context, so the precise duration/window of exposure per platform/config combination is not fully confirmed from the index alone; a Devin session with full repo access would be needed to trace `readOutsidePackets`/`listenOut` call sites and confirm the exact per-routine cache lifetime in production configurations.

func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}

	if c.rulesVersion != f.rulesVersion {
		// This conntrack entry was for an older rule set, validate
		// it still passes with the current rule set
		table := f.OutRules
		if c.incoming {
			table = f.InRules
		}

		// We now know which firewall table to check against
		if !table.match(fp, c.incoming, h.ConnectionState.peerCert, caPool) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				h.logger(f.l).Debug("dropping old conntrack entry, does not match new ruleset",
					"fwPacket", fp,
					"incoming", c.incoming,
					"rulesVersion", f.rulesVersion,
					"oldRulesVersion", c.rulesVersion,
				)
			}
			delete(conntrack.Conns, fp)
			conntrack.Unlock()
			return false
		}

		if f.l.Enabled(context.Background(), slog.LevelDebug) {
			h.logger(f.l).Debug("keeping old conntrack entry, does match new ruleset",
				"fwPacket", fp,
				"incoming", c.incoming,
				"rulesVersion", f.rulesVersion,
				"oldRulesVersion", c.rulesVersion,
			)
		}

		c.rulesVersion = f.rulesVersion
	}

	switch fp.Protocol {
	case firewall.ProtoTCP:
		c.Expires = time.Now().Add(f.TCPTimeout)
	case firewall.ProtoUDP:
		c.Expires = time.Now().Add(f.UDPTimeout)
	default:
		c.Expires = time.Now().Add(f.DefaultTimeout)
	}

	conntrack.Unlock()

	if localCache != nil {
		localCache[fp] = struct{}{}
	}

	return true
}

func (c *ConntrackCacheTicker) tick(ctx context.Context, d time.Duration) {
	t := time.NewTicker(d)
	defer t.Stop()
	for {
		select {
		case <-ctx.Done():
			return
		case <-t.C:
			c.cacheTick.Add(1)
		}
	}
}

// Get checks if the cache ticker has moved to the next version before returning
// the map. If it has moved, we reset the map.
func (c *ConntrackCacheTicker) Get() ConntrackCache {
	if c == nil {
		return nil
	}
	if tick := c.cacheTick.Load(); tick != c.cacheV {
		c.cacheV = tick
		if ll := len(c.cache); ll > 0 {
			if c.l.Enabled(context.Background(), slog.LevelDebug) {
				c.l.Debug("resetting conntrack cache", "len", ll)
			}
			c.cache = make(ConntrackCache, ll)
		}
	}

	return c.cache
}

func (f *Interface) reloadFirewall(c *config.C) {
	cs := f.pki.getCertState()
	curCert := cs.getCertificate(cert.Version2)
	if curCert == nil {
		curCert = cs.getCertificate(cert.Version1)
	}

	// The firewall builds its routableNetworks set from the certificate's UnsafeNetworks at construction.
	// Check to see if that set has changed, and if so, rebuild the firewall.
	certUnsafeChanged := curCert != nil && !slices.Equal(curCert.UnsafeNetworks(), f.firewall.unsafeNetworks)

	if !c.HasChanged("firewall") && !certUnsafeChanged {
		f.l.Debug("No firewall config change detected")
		return
	}

	fw, err := NewFirewallFromConfig(f.l, cs, c)
	if err != nil {
		f.l.Error("Error while creating firewall during reload", "error", err)
		return
	}

	oldFw := f.firewall
	conntrack := oldFw.Conntrack
	conntrack.Lock()
	defer conntrack.Unlock()

	fw.rulesVersion = oldFw.rulesVersion + 1
	// If rulesVersion is back to zero, we have wrapped all the way around. Be
	// safe and just reset conntrack in this case.
	if fw.rulesVersion == 0 {
		f.l.Warn("firewall rulesVersion has overflowed, resetting conntrack",
			"firewallHashes", fw.GetRuleHashes(),
			"oldFirewallHashes", oldFw.GetRuleHashes(),
			"rulesVersion", fw.rulesVersion,
		)
	} else {
		fw.Conntrack = conntrack
	}

	f.firewall = fw

	oldFw.Destroy()
	f.l.Info("New firewall has been installed",
		"firewallHashes", fw.GetRuleHashes(),
		"oldFirewallHashes", oldFw.GetRuleHashes(),
		"rulesVersion", fw.rulesVersion,
	)
}
