### Title
Missing self-reference validation in `LinkRepositoryToObjectPool` allows a caller-supplied `repository` field equal to the object pool itself to create a self-referential `alternates` file - ([File: internal/git/objectpool/link.go])

### Summary
The external report describes a bug where an operation meant to relate two distinct entities (an NFT `_from` and `_to`) is not guarded against being invoked with the same entity for both roles, corrupting state that a second party later depends on. The structural analog in Gitaly is `LinkRepositoryToObjectPool`, which links a caller-supplied `repository` to a caller-supplied `pool.Repository` by writing the pool's path into the repository's `objects/info/alternates` file. Neither the gRPC handler nor `objectpool.Link` verifies that `repository` and `pool.Repository` are different, so a caller can link the pool repository to itself.

### Finding Description
`LinkRepositoryToObjectPool` builds the member repo directly from the request field and passes it to `pool.Link` without any equality check against the pool's own repository: [1](#0-0) 

`Link` then computes the relative object path between `pool` and `repo` and, if not already "linked", writes that relative path into `repo`'s alternates file: [2](#0-1) 

Nothing here rejects `pool.Repository == repo` (the self-transfer analog). Notably, elsewhere in the codebase Gitaly explicitly recognizes that a repository referencing itself as an alternate is a hazardous state and guards against it: [3](#0-2) 
The comment there states self-pointing alternates would "cause a dead lock as the repository is locked during this call already." That protection, however, is only enforced along the WAL partition-assignment path at repository creation time, not inside `objectpool.Link`/`LinkRepositoryToObjectPool`, which can introduce a self-pointing alternates file into an already-partitioned repository after the fact.

### Impact Explanation
If `LinkRepositoryToObjectPool` is invoked with the pool repository as its own member, `objects/info/alternates` becomes self-referential. This produces an inconsistent repository/pool state analogous to the reported issue: state that later logic in the codebase (`getAlternatePartitionID` in `internal/gitaly/storage/storagemgr/partition_assigner.go`) treats as an invalid/dangerous condition (`storage.ErrAlternatePointsToSelf`, with the documented deadlock risk). This can manifest as request failures/deadlocks for the affected repository/pool, or a repository stuck with a broken alternates configuration that requires manual (administrator) intervention to fix, comparable in kind to the "griefing" impact in the original report — a legitimate later consumer of the repository/pool is denied normal function due to unchecked self-reference.

### Likelihood Explanation
`ObjectPoolService` RPCs are meant for internal (Rails/administrative) callers rather than direct end-user access, and `poolForRequest` still requires request fields naming both a pool and a repository — i.e., this is a "crafted RPC field" scenario, not an ordinary push/fetch path. This lowers the likelihood compared to the original NFT bug (which any NFT owner could trigger), because it depends on whichever caller composes the `LinkRepositoryToObjectPoolRequest` message allowing pool and repository to coincide. There is no evidence in the code that gRPC-level input validation prevents equal `repository`/`pool.Repository` fields, and no test coverage was found confirming this case is rejected.

### Recommendation
Add an explicit check in `objectpool.Link` (or in `LinkRepositoryToObjectPoolRequest` handling) rejecting the request when the target repository resolves to the same path as the pool repository, mirroring the existing `storage.ErrAlternatePointsToSelf` guard used in `partition_assigner.go`, so the self-reference is detected uniformly regardless of entry point (partition assignment or object pool linking).

### Proof of Concept
Not independently executed against a live Gitaly instance (index-based review only). Conceptually: call `ObjectPoolService.CreateObjectPool` to create pool `P` from an origin repo, then call `LinkRepositoryToObjectPool` with `ObjectPool.Repository == P` and `Repository == P` (the same repository message). Trace through `internal/gitaly/service/objectpool/link.go` → `internal/git/objectpool/link.go Link()`: no equality check exists before `getRelativeObjectPath`/writing the alternates file, so the alternates file for `P` would end up referencing `P` itself.

func (s *server) LinkRepositoryToObjectPool(ctx context.Context, req *gitalypb.LinkRepositoryToObjectPoolRequest) (*gitalypb.LinkRepositoryToObjectPoolResponse, error) {
	repository := req.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}

	pool, err := s.poolForRequest(ctx, req)
	if err != nil {
		return nil, err
	}

	repo := s.localRepoFactory.Build(repository)

	if err := pool.Link(ctx, repo); err != nil {
		return nil, structerr.NewInternal("%w", err)
	}

	return &gitalypb.LinkRepositoryToObjectPoolResponse{}, nil

func Link(ctx context.Context, pool, repo *localrepo.Repo, txManager transaction.Manager) (returnedErr error) {
	altPath, err := repo.InfoAlternatesPath(ctx)
	if err != nil {
		return err
	}

	expectedRelPath, err := getRelativeObjectPath(ctx, pool, repo)
	if err != nil {
		return err
	}

	linked, err := linkedToRepository(ctx, pool, repo)
	if err != nil {
		return err
	}

	if linked {
		// When the repository is already linked to the repository, cast a vote to ensure the
		// repository is consistent with the other replicas.
		if err := transaction.VoteOnContext(ctx, txManager, voting.VoteFromData([]byte("repository linked")), voting.Synchronized); err != nil {
			return fmt.Errorf("vote on linked repository: %w", err)
		}

		return nil
	}

	alternatesWriter, err := safe.NewLockingFileWriter(altPath)
	if err != nil {
		return fmt.Errorf("creating alternates writer: %w", err)
	}
	defer func() {
		if err := alternatesWriter.Close(); err != nil && returnedErr == nil {
			returnedErr = fmt.Errorf("closing alternates writer: %w", err)
		}
	}()

	if _, err := io.WriteString(alternatesWriter, expectedRelPath); err != nil {
		return fmt.Errorf("writing alternates: %w", err)
	}

	if err := transaction.CommitLockedFile(ctx, txManager, alternatesWriter); err != nil {
		return fmt.Errorf("committing alternates: %w", err)
	}

	if tx := storage.ExtractTransaction(ctx); tx != nil {
		alternatesRelativePath, err := filepath.Rel(tx.FS().Root(), altPath)
		if err != nil {
			return fmt.Errorf("rel alternates file: %w", err)
		}

		if err := tx.FS().RecordFile(alternatesRelativePath); err != nil {
			return fmt.Errorf("record alternates file")
		}
	}

	return removeMemberBitmaps(ctx, pool, repo)
}
