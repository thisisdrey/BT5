2. `msg.pay_for_gas` panic check [1](#0-0) 
3. `chain_id` check
4. `signer_id` check
5. `self.0.nonces.commit(...)` [2](#0-1) 
6. signature verification
7. `execute_request(...)`

The `env::panic_str("\`pay_for_gas\` is not currently supported")` call for `msg.pay_for_gas == true` occurs at line 178-180, strictly **before** the nonce commit at line 193-195. There is no code path where `nonces.commit()` runs prior to the `pay_for_gas` panic check. [3](#0-2) 

Additionally, even setting aside code ordering, the premise about "partial state persisting after a mid-execution panic" misunderstands NEAR runtime semantics: `env::panic_str` aborts the entire function-call execution and the NEAR runtime discards **all** state changes (register writes / trie writes) made during that call — nothing is committed to the contract's persistent state when a call panics. This is standard, well-documented NEAR VM behavior, not something this contract needs to defend against. So even a hypothetical reordering where `commit()` ran before the panic would not leave the nonce marked as used, because the whole receipt fails atomically.

Given:
- The panic already occurs before any nonce-state mutation in the current code, and
- NEAR's panic semantics guarantee full state rollback for the failed call regardless of ordering,

there is no way for an attacker to consume a nonce, bypass a nonce check, or move any funds via this `pay_for_gas` panic path. The commented-out future-only `if !msg.pay_for_gas && env::is_external()` line is dead code (compiled out) and has no effect on current behavior.

    fn execute_signed(&mut self, msg: RequestMessage, proof: &str) -> Result<()> {
        if !self.0.is_signature_allowed() {
            return Err(Error::SignatureDisabled);
        }

        // TODO: change to the following when External Contract Calls land:

            env::panic_str("`pay_for_gas` is not currently supported");
        }

        // check chain_id
        if msg.chain_id != env::chain_id() {
            return Err(Error::InvalidChainId);
        }

        // check signer_id
        if msg.signer_id != env::current_account_id() {
            return Err(Error::InvalidSignerId(msg.signer_id));
        }

        // commit the nonce
        self.0
            .nonces
            .commit(msg.nonce, msg.created_at, msg.timeout)?;

        // verify signature
        if !S::verify_request_msg(&self.0.public_key, &msg, proof) {
            return Err(Error::InvalidSignature);
        }

        let hash = msg.hash();
        WalletEvent::SignedRequest { hash }.emit();

        self.execute_request(msg.request, &Actor::SignedRequest(hash))
    }
