### Title
Unauthenticated `/shutdown` endpoint allows any remote peer to terminate the signer's event receiver - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` matches on the literal request path `/shutdown` and unconditionally flips `stop_signal` to `true` before returning `EventError::Terminated`, with no check of origin, secret, or session state. Any TCP client that can reach the signer's bound event port can send a single `POST /shutdown` and permanently halt the signer's event-receiver main loop.

### Finding Description
In `next_event`, the dispatch logic is: [1](#0-0) 
This branch is reached for any HTTP POST whose URL is exactly `/shutdown` — there is no comparison of the request against the specific message body/format generated by `SignerStopSignaler::send` (a hardcoded body string), no shared secret, no check that the request originates from `127.0.0.1`/the same process, and no token verification. The legitimate stop mechanism, `SignerStopSignaler::send`, simply opens a fresh `TcpStream::connect` to the same address and POSTs `/shutdown` with a fixed body: [2](#0-1) 
Because the handler only inspects `request.url()` and `request.method()` (see the full dispatch block) before matching `/shutdown`, any external client capable of opening a raw TCP connection to the bound listener and issuing `POST /shutdown HTTP/1.1` (with any or no body) triggers the identical code path as the legitimate internal stop signal: [3](#0-2) 
Once `stop_signal` is set, `is_stopped()` returns true, and the very next iteration of `EventReceiver::main_loop` breaks out, permanently disabling event delivery for that signer instance: [4](#0-3) 
There is no re-arm — the receiver never resumes without a full process restart. The existing test suite only exercises the legitimate stop path (`SignerStopSignaler::send` via `RunningSigner::stop`) and never validates that an unaffiliated socket triggers the same effect, so this gap is untested. Notably, `SpawnedSigner::new` itself documents the exposure risk of running against a non-local node/network, implying the endpoint's binding is not always guaranteed to be strictly localhost-only in every deployment: [5](#0-4) 

### Impact Explanation
Any party that can reach the signer's bound event HTTP port (which listens for POSTs from the Stacks node) can send one crafted `POST /shutdown` request and terminate the signer's event-receiving thread. This stops the signer from observing further block proposals, burn blocks, or StackerDB chunk events, effectively taking the signer offline for its "listen to node events" duty with a single unauthenticated message — matching the Critical "remote crash/unauthenticated DoS from few messages" category. This is repeatable against any restarted signer instance as long as the attacker retains reachability.

### Likelihood Explanation
The only precondition is TCP reachability to the bound port — no secret, key, StackerDB slot ownership, or privileged role is required, and the request format is a simple hardcoded string that's trivial to replicate outside the library. The attacker cost is a single raw HTTP POST with no signature/auth material.

### Recommendation
Bind the shutdown control channel separately from the public node-event listener (e.g., a local Unix socket or a random token embedded in the shutdown request and verified server-side), or require a shared secret/HMAC over the `/shutdown` request that only the in-process `SignerStopSignaler` knows, rejecting any `/shutdown` POST that doesn't include/validate it.

### Proof of Concept
1. Spawn a `SignerEventReceiver`/`Signer` bound to `127.0.0.1:PORT` as in `test_status_endpoint` (`libsigner/src/tests/mod.rs:199-230`).
2. From a separate, unaffiliated `TcpStream::connect` (not via `SignerStopSignaler`), send:
   `POST /shutdown HTTP/1.1\r\nHost: 127.0.0.1:PORT\r\nConnection: close\r\nContent-Length: 0\r\n\r\n`
3. Assert that shortly after, `event_receiver.is_stopped()` (or observing that `main_loop` exits / no further events are forwarded) becomes true, proving termination was achieved without going through `SignerStopSignaler::send`.

    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {
                info!("Event receiver stopped");
                break;
            }
            let next_event = match self.next_event() {
                Ok(event) => event,
                Err(EventError::UnrecognizedEvent(..)) => {
                    // got an event that we don't care about (not a problem)
                    continue;
                }
                Err(EventError::Terminated) => {
                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };
            if !self.forward_event(next_event) {
                info!("Failed to forward event");
                break;
            }
        }
        info!("Event receiver main loop exit");
    }

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
