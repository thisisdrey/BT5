### Title
Unauthenticated event-injection into `stacks-signer`'s HTTP event endpoint allows forged block/StackerDB/burn events - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` in `libsigner/src/events.rs` binds a plaintext HTTP server that is meant to receive event pushes only from the paired `stacks-node`. The only gate on incoming requests is the HTTP method (`POST`, with `/status` allowing `GET`) - there is no check of any shared secret, `Authorization` header, or peer identity before an incoming JSON body is deserialized and forwarded into the signer's run loop as a trusted `SignerEvent`.

### Finding Description
The event receiver dispatch loop only inspects the URL and verb before processing: [1](#0-0) 

For every recognized path (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, `/shutdown`), any `POST` request is accepted and passed to `process_event`, which simply reads the body and deserializes it into the corresponding event type — no signature, token, or peer check is performed at any point in this path: [2](#0-1) 

The `SignerHttpRequest`/`decode_http_request` helper in `libsigner/src/http.rs`, used for a different (SIP-003 length-delimited) parsing path, likewise contains no authentication logic — it only parses verb/path/headers: [3](#0-2) 

Grepping the whole `libsigner` crate for `auth_token`/`Authorization` returns no matches, confirming the signer's inbound event listener never consults the `auth_token`/`auth_password` shared secret that is otherwise documented as securing "the communication channel between this node and a connected `stacks-signer` instance": [4](#0-3) 

That `auth_token` is only consulted on the *node* side, e.g. to gate `/v3/block_proposal` and `/v2/blocks?broadcast=1` (`RPCBlockProposalRequestHandler::try_parse_request`), which is the *opposite* direction of traffic: [5](#0-4) 

Sample configs advise binding the signer's event endpoint to `0.0.0.0`, i.e. network-reachable, and rely purely on the shared secret for mutual authentication — but the signer side never checks it: [6](#0-5) [7](#0-6) 

This breaks the intended equality "event received == event legitimately sent by the paired node." Any remote, unprivileged party who can reach the signer's bound TCP port can `POST` a forged `BlockValidateResponse`, `StackerDBChunksEvent`, `BurnBlockEvent`, or `StacksBlockEvent` JSON body and have it accepted and forwarded to the signer's decision run loop exactly as if it originated from the trusted node — no possession of the node's private key, StackerDB slot signer key, or `auth_token` is required. This is analogous to the Jenkins advisory's core defect: an endpoint intended to be reachable only from a trusted, authenticated party (there: an admin browser session; here: the paired node) accepts unauthenticated requests and performs a state-affecting action (there: delete/restore config history; here: inject events consumed by signer logic) because the transport layer performs no authentication check regardless of verb.

### Impact Explanation
This is a Critical-class transport authentication gap: an unauthenticated remote party can write forged data (block-validation responses, StackerDB chunk-modification notices, burn-block/new-block events) directly into a signer's inbound event pipeline. Depending on how the run loop consumes `SignerEvent::BlockValidateResponse`/`SignerEvent::NewBlock`/`SignerEvent::NewBurnBlock`, this can desynchronize the signer's local view of chain/validation state from reality (feeding it fabricated proposal-validation results or fabricated StackerDB chunk-modification notifications), i.e., serving non-canonical/forged data into signer state as if canonical/trusted. This maps to the Critical bucket: "unauthenticated/unauthorized write to state" and "network-wide propagation of forged data" (the signer's outgoing actions are gated on this ingested state).

### Likelihood Explanation
The event server binds to `0.0.0.0:<port>` per the sample configs (network reachable by default guidance), requires nothing more than crafting a small HTTP POST with a JSON body matching one of the four event schemas, and requires no cryptographic material, node secret, or admin role. This is directly and trivially reachable by any remote unprivileged network participant who can route to the signer's event port.

### Recommendation
Require the signer's event HTTP server to authenticate the sender before dispatching to `process_event`/`forward_event` — e.g., verify the `Authorization` header against the configured `auth_password`/shared secret (mirroring what the node side already does for `/v3/block_proposal`), and reject unauthenticated requests with 401 prior to reading/deserializing the body in `next_event`.

### Proof of Concept
1. Configure a `stacks-signer` per `sample/conf/signer/mainnet-signer-conf.toml`, with `endpoint = "0.0.0.0:30000"`.
2. From any remote host with network access to port 30000, send:
```
POST /new_burn_block HTTP/1.1
Host: <signer-ip>:30000
Content-Type: application/json
Content-Length: <n>

{...forged BurnBlockEvent JSON...}
```
No `Authorization` header or `auth_password` is required.
3. Observe in `SignerEventReceiver::next_event` (`libsigner/src/events.rs:413-458`) that the request is accepted solely because it is a `POST` to a recognized path; `process_event` (lines 519-542) deserializes the body and forwards a `SignerEvent` to the run loop via `forward_event`, indistinguishable from a genuine event pushed by the paired `stacks-node`.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

/// Returns (verb, path, table of headers, body_offset) on success
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}
