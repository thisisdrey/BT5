### Title
Unauthenticated `RecvError` packet allows unrestricted, unilateral remote tunnel teardown - (File: outside.go)

### Summary
Nebula's `RecvError` control message is processed entirely in the clear, before any AEAD authentication or handshake validation is performed on the packet. Any entity that knows (or spoofs) the legitimate remote's currently-recorded UDP source address, and knows the target's `RemoteIndex` (a plaintext 32-bit value sent unencrypted in every single packet header), can send a single unauthenticated `RecvError` packet and cause the receiving Nebula node to immediately and unconditionally tear down that tunnel — mirroring the "unrestricted vetoer" pattern where a single unchecked actor can veto/cancel already-established state without further authorization or rate limiting.

### Finding Description
`header.RecvError` packets are handled at the very top of `readOutsidePackets`, before decryption or any signature/MAC check: [1](#0-0) 

The handler `handleRecvError` looks up the hostinfo purely by the plaintext `RemoteIndex` field and performs only a source-address equality check (a UDP source address, which is trivially spoofable by an off-path attacker) before tearing the tunnel down: [2](#0-1) 

The `RemoteIndex` field used for this lookup is transmitted unencrypted in the header of every single packet on the wire: [3](#0-2) [4](#0-3) 

Because this field is visible in cleartext on every outbound/inbound packet, any attacker capable of observing traffic between two Nebula nodes (or simply guessing a 32-bit index, since it is not a cryptographic nonce/MAC-bound value at this stage) can learn a valid `RemoteIndex`. Once known, that attacker can forge a single-packet `header.RecvError` message with a spoofed UDP source IP:port matching the current `hostinfo.GetRemote()` value, and the check `hr.IsValid() && hr != addr` in `handleRecvError` will pass, at which point `f.closeTunnel(hostinfo)` unconditionally executes: [5](#0-4) 

This is directly analogous to the reported "vetoer" bug class: a single, unauthenticated signal is granted unrestricted power to immediately cancel/terminate an already-established, authenticated session state, with no additional confirmation, quorum, or cryptographic binding to the session's actual encryption keys.

### Impact Explanation
An attacker can repeatedly and unilaterally force teardown of any Nebula tunnel they can observe or guess indexes for, causing persistent denial of service between mesh peers. Because the check relies solely on UDP source address matching (spoofable) rather than any AEAD/MAC verification tied to the session's negotiated keys, this bypasses the entire certificate/handshake trust model for the specific purpose of terminating sessions — the "vetoer" here (an unauthenticated off-path attacker) has power disproportionate to its lack of any cryptographic standing in the mesh.

### Likelihood Explanation
The `listen.accept_recv_error` config defaults to `always` per [6](#0-5) , meaning this path is enabled out-of-the-box. UDP source-address spoofing is a well-known, low-cost attack technique, and the `RemoteIndex` value is passively observable on any packet exchanged between the two peers (e.g., via network vantage point, or in some deployments via NAT traversal / relay infrastructure), making exploitation practical wherever an attacker has any visibility into the traffic path or can predict indexes.

### Recommendation
Do not act on `RecvError` (or any control-plane teardown signal) unless it can be cryptographically bound to the session's negotiated key material, e.g., require `RecvError` to be authenticated using the session's AEAD/MAC key (similar to `Message` and `CloseTunnel` on the encrypted path) rather than trusting a bare source-IP comparison. At minimum, rate-limit and require multiple independent unauthenticated corroborations before closing an active tunnel, and avoid deleting pending handshake state in response to any single unauthenticated packet.

### Proof of Concept
1. Node A and Node B establish a tunnel; A's `hostinfo` for B records `RemoteIndex = X` and `hostinfo.GetRemote() = B_addr`.
2. Attacker observes any packet flowing between A and B (or otherwise learns `X`) and learns `B_addr`.
3. Attacker crafts a raw UDP packet: source = `B_addr` (spoofed), destination = A, payload = a 16-byte Nebula header with `Type = header.RecvError`, `RemoteIndex = X`.
4. A receives the packet in `readOutsidePackets`, dispatches to `f.handleRecvError(via.UdpAddr, h)` before any decryption/authentication.
5. `handleRecvError` finds `hostinfo` via `QueryReverseIndex(X)`, sees `hr == addr` (spoofed source matches recorded remote), and calls `f.closeTunnel(hostinfo)` plus `f.handshakeManager.DeleteHostInfo(hostinfo)`, unilaterally tearing down the tunnel with a single unauthenticated packet.

func (f *Interface) handleRecvError(addr netip.AddrPort, h *header.H) {
	if !f.acceptRecvErrorConfig.ShouldRecvError(addr) {
		f.l.Debug("Recv error received, ignoring",
			"index", h.RemoteIndex,
			"udpAddr", addr,
		)
		return
	}

	if f.l.Enabled(context.Background(), slog.LevelDebug) {
		f.l.Debug("Recv error received",
			"index", h.RemoteIndex,
			"udpAddr", addr,
		)
	}

	hostinfo := f.hostMap.QueryReverseIndex(h.RemoteIndex)
	if hostinfo == nil {
		f.l.Debug("Did not find remote index in main hostmap", "remoteIndex", h.RemoteIndex)
		return
	}

	hr := hostinfo.GetRemote()
	if hr.IsValid() && hr != addr {
		f.l.Info("Someone spoofing recv_errors?",
			"addr", addr,
			"hostinfoRemote", hr,
		)
		return
	}

	f.closeTunnel(hostinfo)
	// We also delete it from pending hostmap to allow for fast reconnect.
	f.handshakeManager.DeleteHostInfo(hostinfo)
}

func (h *H) Parse(b []byte) error {
	if len(b) < Len {
		return ErrHeaderTooShort
	}
	// get upper 4 bytes
	h.Version = uint8((b[0] >> 4) & 0x0f)
	// get lower 4 bytes
	h.Type = MessageType(b[0] & 0x0f)
	h.Subtype = MessageSubType(b[1])
	h.Reserved = binary.BigEndian.Uint16(b[2:4])
	h.RemoteIndex = binary.BigEndian.Uint32(b[4:8])
	h.MessageCounter = binary.BigEndian.Uint64(b[8:16])
	return nil
}

func (f *Interface) reloadAcceptRecvError(c *config.C) {
	if c.InitialLoad() || c.HasChanged("listen.accept_recv_error") {

		switch stringValue {

			f.acceptRecvErrorConfig = recvErrorAlways
		case "never":
			f.acceptRecvErrorConfig = recvErrorNever
		case "private":
			f.acceptRecvErrorConfig = recvErrorPrivate
		default:
			if c.GetBool("listen.accept_recv_error", true) {
				f.acceptRecvErrorConfig = recvErrorAlways
			} else {
				f.acceptRecvErrorConfig = recvErrorNever
			}
		}

		f.l.Info("Loaded accept_recv_error config", "acceptRecvError", f.acceptRecvErrorConfig.String())
	}
}
