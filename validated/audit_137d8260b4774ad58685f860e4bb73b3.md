### Title
`LinkRepositoryToObjectPool` Permits Linking a Repository to Itself, Writing a Self-Referential `objects/info/alternates` and Permanently Breaking WAL Partition Assignment for that Repository - (File: `internal/git/objectpool/link.go`)

### Summary
Analogous to the Illuminate `Lender.mint()` bug — where a caller-controlled parameter (`p`) is not checked against a "self" value and lets a resource be pointed at itself, causing runaway self-referential state — `LinkRepositoryToObjectPool` in Gitaly never validates that the `ObjectPool.Repository` differs from the `Repository` being linked. `objectpool.Link()` will happily compute a relative alternates path and write `objects/info/alternates` pointing the repository at itself.

### Finding Description
`LinkRepositoryToObjectPool` (`internal/gitaly/service/objectpool/link.go`) validates only that `repository` is a valid repository and that the pool exists/is valid; it never compares `repository` against `req.ObjectPool.Repository`: [1](#0-0) 

`objectpool.Link()` itself has no equality guard between `pool` and `repo` either — it simply computes the relative object path and writes it into the target's alternates file: [2](#0-1) [3](#0-2) 

If a caller supplies `LinkRepositoryToObjectPoolRequest{Repository: R, ObjectPool: {Repository: R}}` (or an `ObjectPool` repository whose relative path canonicalizes to the same repository, e.g. via a pool created directly at `R`'s path), `getRelativeObjectPath` computes the relative path from `R/objects` back to `R/objects`, and `Link()` writes this self-referencing path into `R`'s own `objects/info/alternates`. The `linkedToRepository` idempotency check does not reject this state either since it only compares the written path to the expected (self-referential) path.

That gitaly engineers consider self-pointing alternates a serious hazard is confirmed by the explicit guard added in the WAL partition assigner, which special-cases this exact condition and refuses to proceed, citing dead-lock risk: [4](#0-3) 

Because `objectpool.Link()` (used for pool linking) has no equivalent check, a caller can create a repository whose `objects/info/alternates` file is self-referential *before* the partition assigner ever inspects it. Any subsequent WAL transaction against that repository (essentially every mutating/transactional RPC once WAL is enabled) will call `assignPartitionID` → `getAlternatePartitionID`, which will now detect `alternateRelativePath == relativePath` and return `storage.ErrAlternatePointsToSelf`, permanently failing partition assignment for that repository: [5](#0-4) 

Separately, non-WAL code paths that walk alternates recursively (`internal/git/dirs.go`) only bound recursion by a fixed depth counter rather than detecting cycles, so a self-referential alternates chain is processed up to `maxAlternatesDepth` times, needlessly duplicating the same object directory in `GIT_ALTERNATE_OBJECT_DIRECTORIES`/`altObjectDirs` output on every git invocation against that repository: [6](#0-5) 

### Impact Explanation
An ordinary, otherwise-authorized RPC caller (anyone permitted to call `ObjectPoolService.LinkRepositoryToObjectPool`, the same trust level as any other repository-mutating RPC) can corrupt a repository's alternates configuration into a self-reference. On WAL-enabled Gitaly, this permanently bricks the repository for all future transactional RPCs (`ErrAlternatePointsToSelf` is returned for every attempt to assign/re-derive its partition), constituting a targeted denial of service against that repository/project. On non-WAL paths it causes wasted/duplicated alternate object-directory resolution on every git invocation against the repo, which is a resource-waste analog of the "infinite mint" loop, bounded only by the depth constant. There is no direct data loss, matching the medium-severity characterization of the original finding ("no direct fund loss" analog / no data loss, functionality impact).

### Likelihood Explanation
Reaching this requires only a normal `LinkRepositoryToObjectPoolRequest` where the `object_pool` field is crafted (or coincidentally configured) to reference the same repository/relative path as `repository`. No privilege escalation, leaked token, or malicious peer is needed — it is directly reachable from a standard client RPC call with attacker-controlled request fields, which matches the required "ordinary user's ... crafted RPC field" analog class.

### Recommendation
In `LinkRepositoryToObjectPool` (`internal/gitaly/service/objectpool/link.go`) and/or `objectpool.Link()` (`internal/git/objectpool/link.go`), explicitly reject requests where the resolved pool repository's storage+relative path equals the target repository's storage+relative path, returning an `InvalidArgument`/`FailedPrecondition` error analogous to `storage.ErrAlternatePointsToSelf` used in the partition assigner, before any write to `objects/info/alternates` occurs. Consider unifying this check into a shared helper so both the WAL partition assigner and the object-pool linking path enforce the same self-reference protection.

### Proof of Concept
1. Create (or identify) a repository `R` and create an object pool proto whose `Repository.StorageName`/`Repository.RelativePath` resolve to the same on-disk repository as `R` (e.g., call `CreateObjectPool` with `object_pool.repository` pointed at `R` itself, or otherwise obtain a pool proto equal to `R`).
2. Call `LinkRepositoryToObjectPool(ctx, &gitalypb.LinkRepositoryToObjectPoolRequest{Repository: R, ObjectPool: &gitalypb.ObjectPool{Repository: R}})`.
3. `objectpool.Link()` computes `expectedRelPath` via `getRelativeObjectPath(pool=R, repo=R)` and, finding `linkedToRepository` false, writes this self-referential relative path into `R/objects/info/alternates`, per [2](#0-1) .
4. On a WAL-enabled Gitaly node, trigger any transactional RPC on `R` (e.g. a new commit/push). `partitionAssigner.assignPartitionID` → `getAlternatePartitionID` reads the alternates file, computes `alternateRelativePath == relativePath`, and returns `storage.ErrAlternatePointsToSelf`, per [5](#0-4) , causing the RPC to fail — repeatable indefinitely, denying service on `R`.

func (s *server) LinkRepositoryToObjectPool(ctx context.Context, req *gitalypb.LinkRepositoryToObjectPoolRequest) (*gitalypb.LinkRepositoryToObjectPoolResponse, error) {
	repository := req.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}

	pool, err := s.poolForRequest(ctx, req)
	if err != nil {
		return nil, err
	}

	repo := s.localRepoFactory.Build(repository)

	if err := pool.Link(ctx, repo); err != nil {
		return nil, structerr.NewInternal("%w", err)
	}

	return &gitalypb.LinkRepositoryToObjectPoolResponse{}, nil

func Link(ctx context.Context, pool, repo *localrepo.Repo, txManager transaction.Manager) (returnedErr error) {
	altPath, err := repo.InfoAlternatesPath(ctx)
	if err != nil {
		return err
	}

	expectedRelPath, err := getRelativeObjectPath(ctx, pool, repo)
	if err != nil {
		return err
	}

	linked, err := linkedToRepository(ctx, pool, repo)
	if err != nil {
		return err
	}

	if linked {
		// When the repository is already linked to the repository, cast a vote to ensure the
		// repository is consistent with the other replicas.
		if err := transaction.VoteOnContext(ctx, txManager, voting.VoteFromData([]byte("repository linked")), voting.Synchronized); err != nil {
			return fmt.Errorf("vote on linked repository: %w", err)
		}

		return nil
	}

func getRelativeObjectPath(ctx context.Context, pool, repo *localrepo.Repo) (string, error) {
	poolPath, err := pool.Path(ctx)
	if err != nil {
		return "", fmt.Errorf("getting object pool path: %w", err)
	}

	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", fmt.Errorf("getting repository path: %w", err)
	}

	relPath, err := filepath.Rel(filepath.Join(repoPath, "objects"), poolPath)
	if err != nil {
		return "", err
	}

	return filepath.Join(relPath, "objects"), nil
}

func (pa *partitionAssigner) getAlternatePartitionID(ctx context.Context, relativePath string, recursiveCall bool, partitionHint storage.PartitionID) (storage.PartitionID, error) {
	alternate, err := gitstorage.ReadAlternatesFile(filepath.Join(pa.storagePath, relativePath))
	if err != nil {
		return 0, fmt.Errorf("read alternates file: %w", err)
	}

	if recursiveCall {
		// recursive being true indicates we've arrived here through another repository's alternate.
		// Repositories in Gitaly should only have a single alternate that points to the repository's
		// pool. Chains of alternates are unexpected and could go arbitrarily long, so fail the operation.
		return 0, storage.ErrAlternateHasAlternate
	}

	// The relative path should point somewhere within the same storage.
	alternateRelativePath, err := storage.ValidateRelativePath(
		pa.storagePath,
		// Take the relative path to the repository, not 'repository/objects'.
		filepath.Dir(
			// The path in alternates file points to the object directory of the alternate
			// repository. The path is relative to the repository's own object directory.
			filepath.Join(relativePath, "objects", alternate),
		),
	)
	if err != nil {
		return 0, fmt.Errorf("validate relative path: %w", err)
	}

	if alternateRelativePath == relativePath {
		// The alternate must not point to the repository itself. Not only is it non-sensical
		// but it would also cause a dead lock as the repository is locked during this call
		// already.
		return 0, storage.ErrAlternatePointsToSelf
	}

	// Recursively get the alternate's partition ID or assign it one. This time
	// we set recursive to true to fail the operation if the alternate itself has an
	// alternate configured.
	ptnID, err := pa.getPartitionIDRecursive(ctx, alternateRelativePath, true, partitionHint, false)
	if err != nil {
		return 0, fmt.Errorf("get partition ID: %w", err)
	}

	return ptnID, nil
}

func altObjectDirs(ctx context.Context, logger log.Logger, storagePrefix, objDir string, depth int) ([]string, error) {
	const maxAlternatesDepth = 5 // Taken from https://github.com/git/git/blob/v2.23.0/sha1-file.c#L575
	if depth > maxAlternatesDepth {
		logger.WithField("objdir", objDir).WarnContext(ctx, "ignoring deeply nested alternate object directory")
		return nil, nil
	}

	fi, err := os.Stat(objDir)
	if os.IsNotExist(err) {
		logger.WithField("objdir", objDir).WarnContext(ctx, "object directory not found")
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	if !fi.IsDir() {
		return nil, nil
	}

	dirs := []string{objDir}

	alternates, err := os.ReadFile(filepath.Join(objDir, "info", "alternates"))
	if os.IsNotExist(err) {
		return dirs, nil
	}
	if err != nil {
		return nil, err
	}

	for _, newDir := range strings.Split(string(alternates), "\n") {
		if len(newDir) == 0 || newDir[0] == '#' {
			continue
		}

		if !filepath.IsAbs(newDir) {
			newDir = filepath.Join(objDir, newDir)
		}

		if !strings.HasPrefix(newDir, storagePrefix) {
			return nil, alternateOutsideStorageError(newDir)
		}

		nestedDirs, err := altObjectDirs(ctx, logger, storagePrefix, newDir, depth+1)
		if err != nil {
			return nil, err
		}

		dirs = append(dirs, nestedDirs...)
	}

	return dirs, nil
}
