### Title
Protocol fee bypass on Nep245/Imt volume via unit-delta `TokenDiff` decomposition - (File: contracts/defuse/core/src/intents/token_diff.rs)

### Summary
`TokenDiff::token_fee` waives the protocol fee whenever a single `TokenDiff` intent's per-token delta has `amount <= 1` for `Nep245`/`Imt` token types. Since fee is computed independently per `TokenDiff` intent (not on the net delta across a batch), an unprivileged signer can decompose one `N`-unit `TokenDiff` into `N` one-unit `TokenDiff` intents inside a single signed `MultiPayload`, paying zero protocol fee instead of `fee_ceil(N)`.

### Finding Description
The broken binding: for any account and `Nep245`/`Imt` `token_id`, the invariant intended by the protocol is
`fee_collector_credit(token_id) == Pips::fee_ceil(sum_of_negative_deltas_on(token_id))` for a batch that nets a total outflow of `N` units on that token.

In `TokenDiff::execute_intent` [2](#0-1)  the fee is computed **per intent, per token_id, using only that intent's own `delta`**:
```
let amount = delta.unsigned_abs();
let fee = Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount);
```
and `token_fee` explicitly zeroes the fee for `Nep245`/`Imt` when `amount <= 1`:
```rust
TokenIdType::Nep245 | TokenIdType::Imt if amount > 1 => {}
TokenIdType::Nep171 | TokenIdType::Nep245 | TokenIdType::Imt => return Pips::ZERO,
``` [1](#0-0) 

Because a single `MultiPayload`/`DefusePayload` can carry a `DefuseIntents` with an arbitrary `Vec<Intent>`, all committed under one nonce/signature [3](#0-2) , and `DefuseIntents::execute_intent` simply loops each `Intent` through its own independent `execute_intent` call [4](#0-3) , the signer can submit:
- One `TokenDiff` per unit: `{diff: {token_id: -1, <counterparty_token>: +k}}`, repeated `N` times, instead of one `{diff: {token_id: -N, <counterparty_token>: +N*k}}`.

Each of the `N` legs computes `token_fee(token_id, 1, protocol_fee)` → `Pips::ZERO` → `fee_ceil(1) == 0`. The single-leg equivalent would compute `token_fee(token_id, N, protocol_fee)` → `protocol_fee` → `fee_ceil(N) > 0`. `Nep245TokenId` is not restricted to NFT-like uses; it is used for arbitrary fungible amounts, e.g. wrapped FT balances moved between two Defuse deployments via `mt_transfer_call`, confirmed in `tests/src/tests/defuse/intents/simulate.rs:368-397`. No guard aggregates deltas per `token_id` across multiple `TokenDiff` intents in the batch before fee computation, and `Engine::execute_signed_intent`/`finalize` only checks that total deltas balance to zero (including whatever `fees_collected` happens to be), not that the fee matches the true netted volume [5](#0-4) .

### Impact Explanation
The fee collector under-collects protocol fee on `Nep245`/`Imt` swap volume: `fee_collector_credit == 0` instead of `fee_ceil(N) > 0` for the same net economic transfer. This matches the "protocol fees bypassed" Critical category — the shortfall is the difference between what the fee-paying party would otherwise transfer to a counterparty (since `TokenDiff::closure_delta` computes counterparty amounts net of fee) and what they now retain, at the fee collector's expense. The attack is fully repeatable: any signer trading `Nep245`/`Imt` balances repeats this on every trade and every token, scaling losses with volume of Nep245-denominated trading across the whole protocol.

### Likelihood Explanation
Preconditions are minimal and attacker-controlled: any signer with a `Nep245`/`Imt` balance and a non-zero `protocol_fee` configured. No privileged role, relayer key, or special deposit `msg` is needed — the attacker simply structures their own signed `MultiPayload`/`DefuseIntents` as `N` singleton-delta `TokenDiff` intents instead of one `N`-delta `TokenDiff`, matched against a counterparty (or their own second signed payload in the same batch) supplying the offsetting positive deltas. Cost is only marginally higher payload/gas size for `N` legs versus 1; this is trivially automatable by any solver/relayer-like actor building payloads today.

### Recommendation
Compute the Nep245/Imt fee waiver on the netted delta per `token_id` across the whole batch (i.e., aggregate all `TokenDiff` intents' deltas per signer/token before applying `token_fee`'s `amount > 1` threshold), or remove the per-intent `amount <= 1` fee waiver for `Nep245`/`Imt` entirely and instead special-case true non-fungible mint/burn amounts (e.g., via a token metadata/decimals flag) so that fungible-amount Nep245 balances always pay `fee_ceil` on their true netted volume regardless of how many `TokenDiff` intents the volume is split across.

### Proof of Concept
```rust
// cargo test in contracts/defuse/core (or tests/ sandbox crate)
// Setup: protocol_fee = Pips::ONE_PERCENT (or any non-zero fee), signer holds
// N units of a Nep245 token_id (e.g. via mt_transfer_call from another Defuse instance).

// Case A: single TokenDiff with delta = -N
let fee_single = TokenDiff::token_fee(&nep245_token_id, N, protocol_fee).fee_ceil(N);
assert!(fee_single > 0);

// Case B: N separate TokenDiff intents in one MultiPayload, each delta = -1
// (signed together with a counterparty payload providing N matching +1 legs
// for the counterparty token, so the batch balances to zero per `finalize`)
let mut fees_collected_total: u128 = 0;
for _ in 0..N {
    // execute_intent computes:
    let fee_leg = TokenDiff::token_fee(&nep245_token_id, 1, protocol_fee).fee_ceil(1);
    fees_collected_total += fee_leg;
}
assert_eq!(fees_collected_total, 0);

// Binding violated:
assert_ne!(fees_collected_total, fee_single); // 0 != fee_ceil(N)
```
A full `near-workspaces`/sandbox integration test would: deploy two Defuse instances, bridge `N` fungible units into a `Nep245` balance on the target contract, sign one `MultiPayload` containing `N` unit-delta `TokenDiff` intents (matched by a counterparty's offsetting intents in the same `execute_intents` call), execute it, and assert the `fee_collector`'s resulting balance is `0`, then repeat with a single `N`-delta `TokenDiff` and assert the fee collector receives `fee_ceil(N) > 0` for the same net token movement.

    pub fn execute_signed_intents(
        mut self,
        signed: impl IntoIterator<Item = MultiPayload>,
    ) -> Result<Transfers> {
        for signed in signed {
            self.execute_signed_intent(signed)?;
        }
        self.finalize()
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    #[inline]
    fn verify_intent_nonce(&self, nonce: Nonce, intent_deadline: Timestamp) -> Result<()> {
        let Some(nonce) = VersionedNonce::maybe_from(nonce) else {
            return Ok(());
        };

        match nonce {
            VersionedNonce::V1(SaltedNonce {
                salt,
                nonce: ExpirableNonce { deadline, .. },
            }) => {
                if !self.state.is_valid_salt(salt) {
                    return Err(DefuseError::InvalidSalt);
                }

                if intent_deadline > deadline {
                    return Err(DefuseError::DeadlineGreaterThanNonce);
                }

                if deadline < Timestamp::now() {
                    return Err(DefuseError::NonceExpired);
                }
            }
        }

        Ok(())
    }

    #[inline]
    fn finalize(self) -> Result<Transfers> {
        self.state
            .finalize()
            .map_err(DefuseError::InvariantViolated)
    }
