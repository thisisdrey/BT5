### Title
Unvalidated length fields in reftable binary parser cause out-of-bounds slice panics - ([File: internal/git/reftable/reftable.go])

### Summary
`internal/git/reftable/reftable.go` parses the binary `.ref` reftable format (block headers, restart tables, and individual ref records) using raw slice indexing driven by length values that are read directly from the file (`getVarInt`, `extractBlockLen`, `getRefsFromBlock`, `parseRefBlock`). None of these length values are validated against the size of the in-memory buffer before being used to index or slice it, so a malformed or truncated reftable file drives Go into an out-of-bounds slice access, which panics.

### Finding Description
`getVarInt` reads `src[start]` in a loop and only checks `start > blockEnd`, not `start >= len(src)`: [1](#0-0) 

`getRefsFromBlock` computes `prefixLength`/`suffixLength` via `getVarInt` and then directly does `prefix[:prefixLength]` and `src[idx:idx+suffixLength]`, and similarly slices `src[idx:idx+uint(hashSize)]` for the object ID and `src[idx:idx+size]` for symref targets — none of these bounds are checked against `len(src)` or `len(prefix)` before slicing: [2](#0-1) 

`extractBlockLen` also slices `src[blockStart+1 : blockStart+4]` without checking that `blockStart+4 <= len(src)`: [3](#0-2) 

`parseRefBlock` computes `b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)`, which can underflow (since these are unsigned `uint` values) if `currentBS` or `RestartCount` are attacker-influenced/corrupted, producing a huge `RestartStart` that is later used as a loop bound and slice index in `getRefsFromBlock`: [4](#0-3) 

This is the same bug class as the referenced report: conversion/parsing code trusts length fields embedded in the input and performs unchecked operations (here, slice indexing instead of `unwrap()`) that panic on malformed data instead of returning a structured error.

`Table.GetReferences()` is the entry point that reads the whole table file into memory and calls `parseRefBlock`/`getRefsFromBlock` in a loop over blocks: [5](#0-4) 

This parsing path is exercised whenever Gitaly needs to enumerate references in a repository that uses the reftable backend (referenced from `internal/gitaly/service/ref/list_refs_test.go`, `internal/gitaly/service/repository/replicate.go`, `internal/backup/repository.go`, and the storage manager's `transaction_manager.go`/`transaction_manager_housekeeping.go`). A reftable file can end up containing attacker-influenced or corrupted bytes through repository replication/fork/import flows that copy raw on-disk repository data (including `.git/reftable/*.ref` files) without re-validating their internal structure, or through any path where the file is later read from a partially-written/corrupted/truncated state (e.g., concurrent compaction, disk truncation, or a crafted import).

### Impact Explanation
An out-of-bounds slice access on attacker-influenced or corrupted `.ref` table content causes a `panic: runtime error: index out of range` (or `slice bounds out of range`). In Gitaly, unary/stream RPC panics are recovered by `panichandler.UnaryPanicHandler`/`StreamPanicHandler`, so this generally degrades to a single failed RPC (`Internal` error) rather than a full process crash: [6](#0-5) 
However, if the same malformed table is parsed outside of a request goroutine wrapped by this interceptor (e.g., in a background housekeeping/compaction goroutine not wrapped by `dontpanic.Go`/`dontpanic.Try`), the panic is unrecovered and crashes the entire `gitaly` process, taking down all in-flight requests for that node — a genuine denial of service as described in `STYLE.md`'s own warning about unrecovered goroutine panics: [7](#0-6) 
Even when caught by the panic handler, repeated triggering (e.g., via repeated `ListRefs` calls against the affected repository) causes persistent RPC failures for that repository until the corrupted table is removed/repaired, which is a functional DoS for that repository's ref-reading operations.

### Likelihood Explanation
Reaching this code requires a repository using the (currently newer/optional) reftable ref backend, and a `.ref` table file whose length-prefixed fields don't match the buffer contents — either through direct corruption/truncation or via replication/fork/import flows that copy raw reftable bytes across trust boundaries without re-validating format invariants. This is a moderately narrow but realistic trigger surface: it doesn't require privileged access, only the ability to make Gitaly read a table file that is corrupt (partial write, truncated backup restore, or crafted copy).

### Recommendation
Add explicit bounds checks in `getVarInt`, `extractBlockLen`, `getRefsFromBlock`, and `parseRefBlock` before every slice operation, returning a structured error (e.g., `fmt.Errorf("corrupt reftable: ...")`) instead of relying on Go's runtime panic for out-of-range access. Specifically:
- Validate `start+1 <= len(src)` in `getVarInt` before each `src[start]` read.
- Validate `idx+suffixLength <= len(src)`, `prefixLength <= len(prefix)`, and `idx+hashSize/size <= len(src)` in `getRefsFromBlock` before slicing.
- Validate `blockStart+4 <= len(src)` in `extractBlockLen`.
- Guard against unsigned underflow when computing `b.RestartStart` in `parseRefBlock` (e.g. check `currentBS >= 2+3*uint(b.RestartCount)` first).
Additionally, ensure any background/non-RPC goroutine that parses reftables is wrapped with `dontpanic.Go`/`dontpanic.Try` so a malformed table cannot crash the whole process even if a bounds check is missed.

### Proof of Concept
Not independently executed; based on static analysis of `internal/git/reftable/reftable.go`. A minimal reproduction would:
1. Create a repository configured to use the reftable ref backend.
2. Overwrite one of its `.git/reftable/*.ref` block files with a crafted ref-block record where the varint-encoded `suffixLength` (or `prefixLength`) is larger than the remaining bytes in the block (e.g., set `suffixLength` to a large value while truncating the actual data), or a `RestartCount` value engineered to underflow `RestartStart`.
3. Call `Table.GetReferences()` (exercised via the `ListRefs` RPC or replication/backup code paths) against that repository — this is expected to trigger an out-of-bounds slice panic in `getRefsFromBlock`/`getVarInt`, confirming the missing validation.

func (t *Table) getVarInt(src []byte, start uint, blockEnd uint) (uint, uint, error) {
	var val uint

	val = uint(src[start]) & 0x7f

	for (uint(src[start]) & 0x80) > 0 {
		start++
		if start > blockEnd {
			return 0, 0, fmt.Errorf("exceeded block length")
		}

		val = ((val + 1) << 7) | (uint(src[start]) & 0x7f)
	}

	return start + 1, val, nil
}

// getRefsFromBlock provides the ref udpates from a reference block.
func (t *Table) getRefsFromBlock(src []byte, b *block) ([]git.Reference, error) {
	var references []git.Reference

	prefix := ""

	// Skip the block_type and block_len
	idx := b.BlockStart + 4

	for idx < b.RestartStart {
		var prefixLength, suffixLength, updateIndexDelta uint
		var err error

		idx, prefixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting prefix length: %w", err)
		}

		idx, suffixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting suffix length: %w", err)
		}

		extra := (suffixLength & 0x7)
		suffixLength >>= 3

		refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])
		idx = idx + suffixLength

		idx, updateIndexDelta, err = t.getVarInt(src, idx, b.FullBlockSize)
		if err != nil {
			return nil, fmt.Errorf("getting update index delta: %w", err)
		}
		// we don't use this for now
		_ = updateIndexDelta

		reference := git.Reference{
			Name: git.ReferenceName(refname),
		}

		switch extra {
		case 0:
			// Deletion, no value
			reference.Target = t.shaFormat().ZeroOID.String()
		case 1:
			// Regular reference
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)
		case 2:
			// Peeled Tag
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)

			// For now we don't need the peeledOID, but we still need
			// to skip the index.
			// peeledOID := ObjectID(bytesToHex(t.src[idx : idx+uint(hashSize)]))
			idx += uint(hashSize)
		case 3:
			// Symref
			var size uint
			idx, size, err = t.getVarInt(src, idx, b.FullBlockSize)
			if err != nil {
				return nil, fmt.Errorf("getting symref size: %w", err)
			}

			reference.Target = git.ReferenceName(src[idx : idx+size]).String()
			reference.IsSymbolic = true
			idx = idx + size
		}

		prefix = refname

		references = append(references, reference)
	}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}

// GetReferences returns all references from the table.
func (t *Table) GetReferences() ([]git.Reference, error) {
	headerOffset := uint(t.footer.Version.HeaderSize())
	offset := uint(0)
	var allRefs []git.Reference

	if _, err := t.src.Seek(0, io.SeekStart); err != nil {
		return nil, fmt.Errorf("seek start: %w", err)
	}

	src, err := io.ReadAll(t.src)
	if err != nil {
		return nil, fmt.Errorf("read all: %w", err)
	}

	for offset < t.footerOffset {
		blockStart, blockEnd := t.getBlockRange(offset, t.blockSize)
		if blockStart == 0 && blockEnd == 0 {
			break
		}

		// If we run out of ref blocks, we can stop the iteration.
		if src[blockStart+headerOffset] != 'r' {
			return allRefs, nil
		}

		references, err := t.parseRefBlock(src, headerOffset, blockStart, blockEnd)
		if err != nil {
			return nil, fmt.Errorf("parsing block: %w", err)
		}

		if len(references) == 0 {
			break
		}

		allRefs = append(allRefs, references...)

		offset = blockEnd
	}

	return allRefs, nil
}
