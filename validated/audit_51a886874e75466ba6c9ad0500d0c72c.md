### Title
No mechanism to selectively discard a fraudulent/malicious message from `pallet-message-queue` without executing it - ([File: substrate/frame/message-queue/src/lib.rs])

### Summary
The external report identifies a class of bug where a detection mechanism (the Watcher) can flag bad state (fraudulent roots) that has already entered a public queue, but the contract provides no privileged, pause-time path to excise that specific bad entry — leaving operators with either "do nothing and let it propagate" or "halt everything." The same broken invariant — *detect-but-cannot-remove* — exists in `pallet-message-queue`, the generic pallet used by DMP/UMP/HRMP/XCMP to hold inbound messages (including XCM) before dispatch.

### Finding Description
`pallet-message-queue` exposes exactly two governance/relayer-facing remediation primitives for a queued message:

1. `execute_overweight` (`substrate/frame/message-queue/src/lib.rs:746-757`, implementation at `substrate/frame/message-queue/src/lib.rs:1066-1140`) — this can only ever **execute** a permanently-overweight message; it does not provide a way to discard a message without running its payload through `T::MessageProcessor`.
2. `reap_page` (`substrate/frame/message-queue/src/lib.rs:716-726`) — this only removes a whole page, and only once it is empty or "stale" (i.e., far enough behind the current processing watermark, gated by `MaxStale`/`do_reap_page`, see `substrate/frame/message-queue/src/tests.rs:311-349` `reap_page_permanent_overweight_works`, which shows `NotReapable` errors returned until the staleness watermark condition is met).

The only "stop propagation" primitives available are queue-wide pause switches: `QueuePausedQuery` (checked in `do_execute_overweight_inner`, `substrate/frame/message-queue/src/lib.rs:1088`) and, for XCMP specifically, `suspend_xcm_execution`/`resume_xcm_execution` in `cumulus/pallets/xcmp-queue/src/lib.rs:177-213`, which are Root/`ControllerOrigin`-gated and only flip a global `QueueSuspended` boolean.

There is no call analogous to "owner may, while paused, remove the specific offending queued item" (as recommended for `RootManager.sol`). Once a message is enqueued (via DMP, UMP, XCMP, or `paras_sudo_wrapper::sudo_queue_downward_xcm` at `polkadot/runtime/common/src/paras_sudo_wrapper.rs:150-170`, itself Root-gated but capable of queuing an arbitrary downward XCM), an operator who determines post-hoc that a specific enqueued message is malformed, malicious, or the product of a bug has exactly two options:
- Pause the entire queue/channel (`suspend_xcm_execution` or a `QueuePausedQuery` implementation) — this blocks *all* messages, including legitimate ones behind or ahead of the bad one, causing a chain-wide processing stall (an availability/DoS side effect), or
- Leave the queue running and let the bad message dispatch when its turn comes, because `service_page_item`/`process_message_payload` (`substrate/frame/message-queue/src/lib.rs:1557-1630`) will process it exactly like any other message unless the processor itself rejects it with `BadFormat`/`Corrupt`/`Unsupported` (automatic, not owner-invoked).

Existing guards do not stop this path because:
- `reap_page` explicitly requires the page to be fully processed or beyond the stale-page watermark (`Error::<T>::NotReapable`), so a targeted single bad message inside an otherwise-active page cannot be reaped.
- `execute_overweight` only applies to messages already marked `OverweightEnqueued`, and even then it forces execution rather than removal.
- Pausing (`QueuePausedQuery`, `suspend_xcm_execution`) halts the whole origin/channel rather than the single message, and does not remove the bad entry from storage — once resumed, it will still be serviced.

### Impact Explanation
This maps directly to the "Message queues, bridge markers, receipts, and payout state must only advance after decode, dispatch, execution, and settlement succeed atomically" pivot, and to the report's core defect class ("fraudulent state accepted into a queue cannot be surgically removed before it propagates"). If a malformed/malicious message enters the DMP/UMP/XCMP → `message-queue` pipeline (e.g., via a misused `sudo_queue_downward_xcm`, a relay bug, or any upstream acceptance error), the runtime has no root-only "delete this specific message" call. Operators are forced to choose between full-queue/channel downtime (degrading or stalling message/bridge processing for all senders sharing that origin) or allowing the bad message to execute with whatever runtime side effects it carries.

### Likelihood Explanation
This is a structural gap rather than an attacker-triggerable exploit by itself — it requires that some other bug, misconfiguration, or unintentional Root action first place a bad message into the queue. Once that precondition holds, the lack of a surgical removal mechanism is deterministic and always reproducible: exhaustively demonstrated by `reap_page_permanent_overweight_works` and `execute_overweight_works`/`execute_overweight_keeps_stack_ov_message` in `substrate/frame/message-queue/src/tests.rs`, none of which offer a discard-without-execute path.

### Recommendation
Add a Root/Owner-only extrinsic (analogous to `reap_page`/`execute_overweight`) that can, while the target queue/channel is paused (`QueuePausedQuery::is_paused` true, or `QueueSuspended` true for XCMP), permanently discard a specific `(message_origin, page, index)` message without invoking `T::MessageProcessor::process_message`, decrementing `BookStateFor` and calling `T::QueueChangeHandler::on_queue_changed` exactly as `do_execute_overweight_inner` does on the `Processed`/`Unprocessable{permanent:true}` branch (`substrate/frame/message-queue/src/lib.rs:1116-1138`), but skipping execution entirely and emitting a distinct `Discarded` event for auditability.

### Proof of Concept
Not applicable as an on-chain exploit — this is a missing-mitigation gap, not a state-transition bug that a permissionless actor can trigger. Reproduction of the gap itself:
1. Enqueue a message via `MessageQueue::enqueue_message(msg, origin)` (or via DMP/UMP/XCMP ingestion).
2. Observe that no call exists to remove that message before it is (a) executed by `service_queues`/`execute_overweight`, or (b) both stale enough and fully-processed-before it, per `do_reap_page`'s `NotReapable` gate — see `substrate/frame/message-queue/src/tests.rs:311-349`.
3. The only available remediation, `suspend_xcm_execution`/`QueuePausedQuery`, halts the entire origin's queue rather than removing the specific message, as shown in `substrate/frame/message-queue/src/tests.rs:1499-1611` (`service_queues_suspend_works`, `execute_overweight_respects_suspension`). 	/// Same as `do_execute_overweight` but must be called while holding the `service_mutex`.
	fn do_execute_overweight_inner(
		origin: MessageOriginOf<T>,
		page_index: PageIndex,
		index: T::Size,
		weight_limit: Weight,
	) -> Result<Weight, Error<T>> {
		let mut book_state = BookStateFor::<T>::get(&origin);
		ensure!(!T::QueuePausedQuery::is_paused(&origin), Error::<T>::QueuePaused);

		let mut page = Pages::<T>::get(&origin, page_index).ok_or(Error::<T>::NoPage)?;
		let (pos, is_processed, payload) =
			page.peek_index(index.into() as usize).ok_or(Error::<T>::NoMessage)?;
		let payload_len = payload.len() as u64;
		ensure!(
			page_index < book_state.begin ||
				(page_index == book_state.begin && pos < page.first.into() as usize),
			Error::<T>::Queued
		);
		ensure!(!is_processed, Error::<T>::AlreadyProcessed);
		use MessageExecutionStatus::*;
		let mut weight_counter = WeightMeter::with_limit(weight_limit);
		match Self::process_message_payload(
			origin.clone(),
			page_index,
			index,
			payload,
			&mut weight_counter,
			Weight::MAX,
			// ^^^ We never recognise it as permanently overweight, since that would result in an
			// additional overweight event being deposited.
		) {
			Overweight | InsufficientWeight => Err(Error::<T>::InsufficientWeight),
			StackLimitReached | Unprocessable { permanent: false } => {
				Err(Error::<T>::TemporarilyUnprocessable)
			},
			Unprocessable { permanent: true } | Processed => {
				page.note_processed_at_pos(pos);
				book_state.message_count.saturating_dec();
				book_state.size.saturating_reduce(payload_len);
				let page_weight = if page.remaining.is_zero() {
					debug_assert!(
						page.remaining_size.is_zero(),
						"no messages remaining; no space taken; qed"
					);
					Pages::<T>::remove(&origin, page_index);
					debug_assert!(book_state.count >= 1, "page exists, so book must have pages");
					book_state.count.saturating_dec();
					T::WeightInfo::execute_overweight_page_removed()
				// no need to consider .first or ready ring since processing an overweight page
				// would not alter that state.
				} else {
					Pages::<T>::insert(&origin, page_index, page);
					T::WeightInfo::execute_overweight_page_updated()
				};
				BookStateFor::<T>::insert(&origin, &book_state);
				T::QueueChangeHandler::on_queue_changed(origin, book_state.into());
				Ok(weight_counter.consumed().saturating_add(page_weight))
			},
		}
	}

#[test]
fn reap_page_permanent_overweight_works() {
	use MessageOrigin::*;
	build_and_execute::<Test>(|| {
		// Create 10 pages more than the stale limit.
		let n = (MaxStale::get() + 10) as usize;
		for _ in 0..n {
			MessageQueue::enqueue_message(msg("weight=200 datadatadata"), Here);
		}
		assert_eq!(Pages::<Test>::iter().count(), n);
		assert_eq!(MessageQueue::footprint(Here).pages, n as u32);
		assert_eq!(QueueChanges::take().len(), n);
		// Mark all pages as stale since their message is permanently overweight.
		MessageQueue::service_queues(1.into_weight());

		// Check that we can reap everything below the watermark.
		let max_stale = MaxStale::get();
		for i in 0..n as u32 {
			let b = BookStateFor::<Test>::get(Here);
			let stale_pages = n as u32 - i;
			let overflow = stale_pages.saturating_sub(max_stale + 1) + 1;
			let backlog = (max_stale * max_stale / overflow).max(max_stale);
			let watermark = b.begin.saturating_sub(backlog);

			if i >= watermark {
				break;
			}
			assert_ok!(MessageQueue::do_reap_page(&Here, i));
			assert_eq!(QueueChanges::take(), vec![(Here, b.message_count - 1, b.size - 23)]);
		}

		// Cannot reap any more pages.
		for (o, i, _) in Pages::<Test>::iter() {
			assert_noop!(MessageQueue::do_reap_page(&o, i), Error::<Test>::NotReapable);
			assert!(QueueChanges::take().is_empty());
		}
		assert_eq!(MessageQueue::footprint(Here).pages, 3);
	});
}

/// Tests that manual overweight execution on a suspended queue errors with `QueueSuspended`.
#[test]
fn execute_overweight_respects_suspension() {
	build_and_execute::<Test>(|| {
		let origin = MessageOrigin::Here;
		MessageQueue::enqueue_message(msg("weight=200"), origin);
		// Mark the message as permanently overweight.
		MessageQueue::service_queues(4.into_weight());
		assert_last_event::<Test>(
			Event::OverweightEnqueued {
				id: blake2_256(b"weight=200"),
				origin,
				message_index: 0,
				page_index: 0,
			}
			.into(),
		);
		PausedQueues::set(vec![origin]);
		assert!(<Test as Config>::QueuePausedQuery::is_paused(&origin));

		// Execution should fail.
		assert_eq!(
			<MessageQueue as ServiceQueues>::execute_overweight(Weight::MAX, (origin, 0, 0)),
			Err(ExecuteOverweightError::QueuePaused)
		);

		PausedQueues::take();
		assert!(!<Test as Config>::QueuePausedQuery::is_paused(&origin));

		// Execution should work again with same args.
		assert_ok!(<MessageQueue as ServiceQueues>::execute_overweight(
			Weight::MAX,
			(origin, 0, 0)
		));

		assert_last_event::<Test>(
			Event::Processed {
				id: blake2_256(b"weight=200").into(),
				origin,
				weight_used: 200.into_weight(),
				success: true,
			}
			.into(),
		);
	});
}

	#[pallet::call]
	impl<T: Config> Pallet<T> {
		/// Suspends all XCM executions for the XCMP queue, regardless of the sender's origin.
		///
		/// - `origin`: Must pass `ControllerOrigin`.
		#[pallet::call_index(1)]
		#[pallet::weight((T::DbWeight::get().writes(1), DispatchClass::Operational,))]
		pub fn suspend_xcm_execution(origin: OriginFor<T>) -> DispatchResult {
			T::ControllerOrigin::ensure_origin(origin)?;

			QueueSuspended::<T>::try_mutate(|suspended| {
				if *suspended {
					Err(Error::<T>::AlreadySuspended.into())
				} else {
					*suspended = true;
					Ok(())
				}
			})
		}

		/// Resumes all XCM executions for the XCMP queue.
		///
		/// Note that this function doesn't change the status of the in/out bound channels.
		///
		/// - `origin`: Must pass `ControllerOrigin`.
		#[pallet::call_index(2)]
		#[pallet::weight((T::DbWeight::get().writes(1), DispatchClass::Operational,))]
		pub fn resume_xcm_execution(origin: OriginFor<T>) -> DispatchResult {
			T::ControllerOrigin::ensure_origin(origin)?;

			QueueSuspended::<T>::try_mutate(|suspended| {
				if !*suspended {
					Err(Error::<T>::AlreadyResumed.into())
				} else {
					*suspended = false;
					Ok(())
				}
			})
		}
