### Title
Fee-splitting on `TokenIdType::Nep245`/`Imt` legs bypasses protocol fee via unit-sized `TokenDiff` chunking - (File: contracts/defuse/core/src/intents/token_diff.rs)

### Summary
`TokenDiff::token_fee` waives the fee whenever the per-intent `|delta|` on a `Nep245`/`Imt` token is `1`, and the engine computes the fee independently for every `TokenDiff` intent it processes rather than on the aggregate amount moved in the batch. An attacker can therefore split a single negative delta of size `N` on a `Nep245`/`Imt` token into `N` separate signed `TokenDiff` intents of `-1` each (matched against one counterparty diff providing the offsetting `+N`/`-V`), collecting the same net trade while `fee_collector` receives `0` instead of `Pips::fee_ceil(protocol_fee, N)`.

### Finding Description
The binding: for a `Nep245`/`Imt` `token_id` with total negative exposure `N`, the fee credited to `fee_collector` should equal `Pips::fee_ceil(protocol_fee, N)` regardless of how the exposure is partitioned across intents in the batch. Instead, `TokenDiff::execute_intent` computes the fee per intent using only that intent's own `delta`: [1](#0-0) 

and `TokenDiff::token_fee` returns `Pips::ZERO` for `Nep245`/`Imt` whenever `amount <= 1`: [2](#0-1) 

`Intent::TokenDiff` intents are executed one at a time by `DefuseIntents::execute_intent`/`Intent::execute_intent`, with no aggregation across intents in the same `DefuseIntents` message or across the whole `execute_intents` batch: [3](#0-2) 

The only cross-intent invariant enforced by the engine is that all deltas for a token, across every signed payload in the call, net to zero via `TransferMatcher::finalize` (this only checks balance conservation, not fee correctness): [4](#0-3) 

Exploit flow: attacker signs `N` `TokenDiff` intents (or `N` `MultiPayload`s, each independently signed with the attacker's own key), each with `diff = {nep245_token_id: -1, ft_token_id: +(V/N)}`. A counterparty (a real solver, or a second account the attacker also controls) supplies one offsetting `TokenDiff` `{nep245_token_id: +N, ft_token_id: -V}` so the batch balances per `TransferMatcher`. All are submitted together to `execute_intents` (or deposited via `nep245/deposit.rs` `mt_on_transfer` with an `execute_intents` `msg`, then routed through `Engine::execute_signed_intents`): [5](#0-4) 

On the attacker's side, each of the `N` legs has `delta.unsigned_abs() == 1`, so `Self::token_fee(nep245_token_id, 1, protocol_fee)` hits the `Nep245 | Imt` catch-all and returns `Pips::ZERO` every time, so `fees_collected` for that token stays `0` across the whole batch. Had the attacker submitted one `TokenDiff` with `delta = -N`, `token_fee` would return `protocol_fee` (since `N > 1`), and `fee_ceil(protocol_fee, N) > 0` would be added to `fees_collected` and credited to `fee_collector` via `internal_add_balance`. No existing guard (`verify`, nonce/salt checks, `TransferMatcher::finalize`, `checked_*` arithmetic) recomputes or aggregates the fee base across intents/payloads — each is independent and none inspects "total exposure per token per batch."

### Impact Explanation
`fee_collector` under-collects protocol fees on every `Nep245`/`Imt`-denominated leg of a trade whenever an attacker (whether acting alone across two of their own accounts, or as a party in a trade with any counterparty willing to sign a normal offsetting diff) chunks their negative delta into unit-sized `TokenDiff` intents. This is repeatable per token, per batch, and scales with `N` (the more units, the larger the absolute fee avoided, since `fee_ceil(protocol_fee, N)` grows with `N` while the split cost stays `0`). This matches the explicitly listed Critical category "protocol fees bypassed or over-collected." No signature, nonce, or lock invariant is broken — value never leaves the Verifier improperly — but the protocol's revenue collection is systematically evaded.

### Likelihood Explanation
Preconditions are trivial for any unprivileged user: hold a `Nep245`/`Imt` balance inside the Verifier, and construct/sign `N` `TokenDiff` intents instead of one. No special role, relayer key, or victim key is needed; a normal counterparty (solver) providing the matching offsetting diff is sufficient and does not need to be complicit — they only see a net trade that matches their own diff, unaware the other side split its legs. Cost to the attacker is just extra intents/payloads and gas for `execute_intents`, which is straightforward and fully attacker-controlled.

### Recommendation
Compute the `Nep245`/`Imt` fee based on the total negative exposure per token aggregated over the entire batch (e.g., sum negative deltas per `token_id` across all intents in the call before deciding whether `amount > 1`), or remove the per-leg amount-based fee waiver entirely and instead handle the "1 unit → 100% fee" rounding problem with a fixed minimum-fee floor/no-fee threshold defined independently of how many intents the exposure is split across.

### Proof of Concept
`cargo test` in `contracts/defuse` (or `tests/src/tests/defuse/intents/token_diff.rs` using the sandbox harness):
1. Set `protocol_fee = Pips::ONE_PERCENT` (or any `> 0`), deposit attacker with `N` units of a `Nep245` token and a solver with `V` units of an FT.
2. Case A (single diff): attacker signs one `TokenDiff{diff: {nep245: -N, ft: +V}}`, solver signs `{nep245: +N, ft: -V}`. Execute via `execute_intents`; assert `fee_collector`'s `nep245_token_id` balance == `Pips::fee_ceil(protocol_fee, N)` and is `> 0`.
3. Case B (split diff): attacker signs `N` separate `TokenDiff{diff: {nep245: -1, ft: +(V/N)}}` intents (same signer, same or separate payloads), solver signs the single offsetting `{nep245: +N, ft: -V}`. Execute via `execute_intents`; assert `fee_collector`'s `nep245_token_id` balance == `0`.
4. Assert the two `fee_collector` balances differ (Case A `> 0`, Case B `== 0`) for identical net token movement, proving the fee is bypassed by splitting.

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
}

    pub fn execute_signed_intents(
        mut self,
        signed: impl IntoIterator<Item = MultiPayload>,
    ) -> Result<Transfers> {
        for signed in signed {
            self.execute_signed_intent(signed)?;
        }
        self.finalize()
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }
