### Title
Protocol fee bypass on NEP-245/NEP-171/Imt tokens via unit-size `TokenDiff` splitting - (File: `contracts/defuse/core/src/intents/token_diff.rs`)

### Summary
`TokenDiff::token_fee` returns `Pips::ZERO` whenever the per-intent `amount <= 1` for `TokenIdType::Nep171`, `Nep245`, or `Imt`. Because the fee is computed independently for each `TokenDiff` intent (not on the aggregate volume moved across a batch), a signer can move an arbitrary total volume of a NEP-245 (or Imt) token between two accounts by encoding it as many size‑1 `TokenDiff` intents inside one `MultiPayload`, entirely avoiding `fee_ceil` regardless of the total value transacted.

### Finding Description
The binding that should hold is: for a signer's total negative delta `N` on a given `token_id` executed within a session/batch, the protocol should collect `fee_collector_credit == Pips::fee_ceil(N)` (for a fee-bearing token type) or a deterministic, size-invariant fee schedule. Instead, `execute_intent` computes the fee strictly per-intent: [1](#0-0) 

and `token_fee` special-cases `amount <= 1` for `Nep171`/`Nep245`/`Imt` to `Pips::ZERO`: [2](#0-1) 

`DefuseIntents::execute_intent` iterates a `Vec<Intent>` from a *single* signed `DefusePayload`, so an attacker can pack arbitrarily many `TokenDiff` intents — each with `diff: {tok:-1, tok2:1}` — into one `MultiPayload`, consuming a single nonce/signature: [3](#0-2) [4](#0-3) 

Each of the N intents independently satisfies `self.diff.is_empty()` (false) and `*delta==0` (false) checks, so none is rejected. Each is executed with `amount = delta.unsigned_abs() = 1`, so `Self::token_fee(token_id, 1, protocol_fee)` returns `Pips::ZERO` on every single intent, and `fees_collected` for that token stays empty across the whole batch even though the aggregate volume moved is `N` units of a high-value NEP-245 token. No existing guard (`MultiPayload::verify`, nonce commit, `Lock`, `TransferMatcher::finalize`, invariant checks) inspects per-token aggregate volume across intents in a batch — they only validate signature/nonce validity and that total deltas net to zero, which unit-splitting still satisfies.

### Impact Explanation
The `fee_collector` under-collects protocol fees on NEP-245 (and Imt) token volume: instead of `Pips::fee_ceil(N)` on N units transferred, it collects `0`. This is repeatable indefinitely by any unprivileged signer pair for any NEP-245/Imt token they control or trade, and scales with batch size (bounded only by gas/tx limits, which is out of scope but does not block the fee-evasion mechanism itself for realistic batch sizes). This matches the "protocol fees bypassed" Critical category since it lets value that should go to `fee_collector` never leave the trading counterparties.

### Likelihood Explanation
No special role or privilege is required — only the ability to sign a `MultiPayload` (any account) and hold/trade a NEP-245 balance in Defuse, which any user can deposit via `mt_transfer_call`. The only cost is constructing N intents instead of 1 in the same signed payload, which is essentially free compared to the fee saved on high-value assets. This is fully repeatable across any NEP-245/Imt token_id and any account pair.

### Recommendation
Compute the fee based on the aggregate signer's net delta per `token_id` across the whole `DefuseIntents` execution (or per signed payload), not on each individual `TokenDiff` intent's local `amount`. Alternatively, gate the zero-fee exemption to token_ids that are provably non-fungible (e.g., total supply == 1) rather than solely on the per-intent transferred amount.

### Proof of Concept
`cargo test` plan (contracts/defuse/core, unit test in `token_diff.rs` or an engine-level test):
1. Configure `protocol_fee = Pips::ONE_PERCENT` (or any `Pips > 0`).
2. Construct a NEP-245 `TokenId` and give signer A a balance of 100 units of `tok`, signer B a balance of 100 units of `tok2`.
3. Case A (baseline/no evasion): submit ONE `TokenDiff{diff:{tok:-100, tok2:100}}` intent for A (and matching intent for B). Assert `fees_collected` for `tok` equals `Pips::ONE_PERCENT.fee_ceil(100)` (nonzero) via the `TokenDiffEvent` / `Amounts` returned in `fees_collected`.
4. Case B (evasion): submit 100 separate `TokenDiff{diff:{tok:-1, tok2:1}}` intents for A within a single `DefuseIntents.intents` vector (one signed `MultiPayload`), and matching 100 intents for B. Execute via `Engine::execute_signed_intents`.
5. Assert: total `fees_collected` for `tok` across all 100 intents in Case B equals `0`, while the total net delta moved (`100` units, same as Case A) is identical. This demonstrates `sum(fees_collected_case_B) (=0) != sum(fees_collected_case_A) (=Pips::ONE_PERCENT.fee_ceil(100))` for equal aggregate volume, proving the binding `fee_collected == Pips::fee_ceil(total_volume)` is broken by unit-splitting.

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }
