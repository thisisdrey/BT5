### Title
Unvalidated `new_beneficiary` in `set_beneficiary_for_operator` Permanently Locks Staker Funds via `distribute_internal` Abort - (File: `aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

`staking_contract::set_beneficiary_for_operator` stores an arbitrary `new_beneficiary` address with no validation that the address can receive APT. When commission is later distributed via `distribute_internal`, `aptos_account::deposit_coins` is called on that address. If the address has an account but has disabled direct coin transfers and is not registered for APT, the call aborts — permanently blocking all fund withdrawals for every staker using that operator, including the staker's own principal and rewards.

---

### Finding Description

`set_beneficiary_for_operator` accepts any `new_beneficiary: address` and stores it directly: [1](#0-0) 

No existence check, no APT registration check, and no `can_receive_direct_coin_transfers` check is performed.

Compare this to `vesting::set_beneficiary`, which explicitly guards against this exact failure mode with the comment *"This is a requirement so distribute() wouldn't fail and block all other accounts from receiving APT if one beneficiary is not registered"*: [2](#0-1) 

In `distribute_internal`, when the operator is a recipient, the stored beneficiary address is substituted and `aptos_account::deposit_coins` is called on it: [3](#0-2) 

`aptos_account::deposit_coins` aborts if the target account exists, is not registered for the coin type, and has disabled direct coin transfers: [4](#0-3) 

Because `distribute_internal` is called atomically inside a single Move transaction, one abort rolls back the entire distribution — including the staker's share. All callers of `distribute_internal` are affected: `distribute`, `switch_operator`, `update_commision`, and `unlock_stake` (via `request_commission_internal`). [5](#0-4) 

---

### Impact Explanation

A staker's APT principal and accumulated rewards become permanently unwithdrawable. The staker cannot:
- Call `distribute` (calls `distribute_internal` → aborts)
- Call `switch_operator` (calls `distribute_internal` on the old operator first → aborts)
- Call `update_commision` (calls `distribute_internal` → aborts)

The staker's funds are locked in the stake pool with no recovery path available through the staking contract's public API. This constitutes permanent freezing of user-controlled staking balances.

---

### Likelihood Explanation

The feature flag `operator_beneficiary_change_enabled` must be active (it is on mainnet). Any operator who has a staking relationship with a staker can call `set_beneficiary_for_operator` at any time. The operator needs to control or know of one address that has an account, is not registered for APT coin, and has called `set_allow_direct_coin_transfers(false)` — a trivially constructible condition. The operator does not need any special privilege beyond being an operator in a staking contract.

---

### Recommendation

Add the same guard used in `vesting::set_beneficiary` before storing the new beneficiary:

```move
public entry fun set_beneficiary_for_operator(
    operator: &signer, new_beneficiary: address
) acquires BeneficiaryForOperator {
    assert!(
        features::operator_beneficiary_change_enabled(),
        std::error::invalid_state(EOPERATOR_BENEFICIARY_CHANGE_NOT_SUPPORTED)
    );
+   // Verify the beneficiary can receive APT so distribute_internal cannot be wedged.
+   aptos_account::assert_account_is_registered_for_apt(new_beneficiary);
    ...
}
```

This mirrors the explicit protection in `vesting::set_beneficiary` at line 923. [6](#0-5) 

---

### Proof of Concept

1. Operator creates address `X`, creates an account at `X`, calls `aptos_account::set_allow_direct_coin_transfers(false)` from `X` (so `X` has an account but has disabled direct transfers and is not registered for APT).
2. Operator calls `staking_contract::set_beneficiary_for_operator(operator_signer, X)`. This succeeds with no validation.
3. Staker's stake earns rewards; operator calls `request_commission` to move commission to pending_inactive.
4. After the lockup period, anyone calls `staking_contract::distribute(staker, operator)`.
5. Inside `distribute_internal`, `recipient` is set to `X` (the invalid beneficiary) for the operator's commission share.
6. `aptos_account::deposit_coins(X, commission_coins)` aborts at the `can_receive_direct_coin_transfers` assert.
7. The entire transaction reverts. The staker's withdrawable funds remain locked in the pool.
8. The staker attempts `switch_operator` to escape — it also calls `distribute_internal` on the old operator first and aborts identically.
9. Staker's APT is permanently frozen. [1](#0-0) [7](#0-6) [8](#0-7)

    public entry fun set_beneficiary_for_operator(
        operator: &signer, new_beneficiary: address
    ) acquires BeneficiaryForOperator {
        assert!(
            features::operator_beneficiary_change_enabled(),
            std::error::invalid_state(EOPERATOR_BENEFICIARY_CHANGE_NOT_SUPPORTED)
        );
        // The beneficiay address of an operator is stored under the operator's address.
        // So, the operator does not need to be validated with respect to a staking pool.
        let operator_addr = signer::address_of(operator);
        let old_beneficiary = beneficiary_for_operator(operator_addr);
        if (exists<BeneficiaryForOperator>(operator_addr)) {
            borrow_global_mut<BeneficiaryForOperator>(operator_addr).beneficiary_for_operator =
                new_beneficiary;
        } else {
            move_to(
                operator,
                BeneficiaryForOperator { beneficiary_for_operator: new_beneficiary }
            );
        };

        emit(
            SetBeneficiaryForOperator {
                operator: operator_addr,
                old_beneficiary,
                new_beneficiary
            }
        );
    }

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
