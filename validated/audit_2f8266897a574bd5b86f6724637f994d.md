## Title
Unvalidated tar extraction from attacker-controlled HTTP URL in `CreateRepositoryFromSnapshot` allows path/symlink escape outside repository storage - (File: `internal/gitaly/service/repository/create_repository_from_snapshot.go`)

## Summary
`CreateRepositoryFromSnapshot`'s `untar()` handler streams an HTTP response body — fetched from a fully caller-controlled `http_url` — directly into the system `tar` binary invoked as `tar -C <path> -xvf -`, with no inspection of the tar member names, symlink targets, or hard-link targets before extraction. This mirrors the WatchPug root cause: Gitaly's privileged process ("the contract") performs an operation (writing arbitrary files as the Gitaly process) whose target is fully determined by attacker-supplied data (the "calldata"), and the codebase's own sibling extractor (`extractTarToDirectory` in `replicate.go`) proves that this exact bug class is otherwise recognized and defended against elsewhere.

## Finding Description
`untar()` fetches the archive from `in.GetHttpUrl()` and pipes the raw HTTP response body into a shelled-out `tar` process: [1](#0-0) 

Specifically:
```
cmd, err := command.New(ctx, s.logger, []string{"tar", "-C", path, "-xvf", "-"}, command.WithStdin(rsp.Body))
```
No validation is performed on the tar stream's contents before or during extraction — no check that member names stay within `path`, no rejection of absolute or `..`-containing member names, and no restriction on symlink/hard-link targets.

This is in stark contrast to the Go-native tar extractor used for the sibling internal replication path (`ReplicateRepository` → `extractSnapshot` → `extractTarToDirectory`), which explicitly guards against every one of these cases: [2](#0-1) 

That hardened function validates that every regular/dir entry's resolved path has `targetDir` as a strict prefix, rejects absolute symlinks, resolves and validates relative symlink targets against the extraction root, and validates hard-link targets the same way — protections that are entirely absent from `untar()`.

Because `CreateRepositoryFromSnapshot` is a caller-facing mutator RPC that accepts a repository-caller-supplied `http_url` (and even a `resolved_address` for DNS-rebinding mitigation, showing the code is aware the URL is untrusted/external), an attacker who controls (or can redirect) the content served at that URL fully controls the tar stream that Gitaly's own `tar` process extracts with Gitaly's file permissions into the target repository's storage directory: [3](#0-2) 

## Impact Explanation
A malicious or compromised HTTP endpoint referenced by `http_url` can supply a tar archive containing:
- Members with `../../` path components, or
- Symlink entries pointing outside the target directory, followed by regular-file entries written through that symlink, or
- Hard-link entries targeting arbitrary existing paths on the Gitaly host.

Depending on the underlying `tar` implementation/version and its default safety behavior, this can result in files being written or overwritten outside the intended repository directory on the Gitaly node — a storage/path escape performed with the Gitaly service's own filesystem privileges, i.e., exactly the "confused deputy" pattern in the reference report where privileged execution is redirected by attacker-supplied data to act outside its intended scope. In the git-server context this can corrupt other repositories, tamper with configuration/hooks in reachable directories, or use the crafted archive as an initial-access primitive.

## Likelihood Explanation
Reaching this code path only requires the ability to invoke the `CreateRepositoryFromSnapshot` RPC (an ordinary mutator RPC gated by Gitaly's normal RPC auth, not special/administrative privileges) with a `repository` target and an `http_url` under the caller's control — no other repository access or write approvals are required, unlike the finer-grained requirements of many other RPCs. The bar is low: any client capable of calling this RPC, and controlling (or man-in-the-middling within the resolved-address flow) the HTTP response, can attempt this.

## Recommendation
Replace the shelled-out `tar -xvf -` invocation in `untar()` with the same hardened, Go-native extraction routine already implemented as `extractTarToDirectory`/`extractFile` in `replicate.go` (path-prefix validation for regular files/directories, rejection of absolute symlinks, resolved-target validation for relative symlinks and hard links). Consolidating both extraction call sites onto a single audited implementation removes the discrepancy and closes the escape.

## Proof of Concept
1. Host an HTTP server serving a crafted tar archive containing an entry such as:
   - `../../../etc/cron.d/evil` (regular file), or
   - a symlink entry `link -> ../../../tmp` followed by a regular file `link/payload`.
2. Call `CreateRepositoryFromSnapshot` with `http_url` pointing at that server and a `repository` to be created.
3. Gitaly's `untar()` pipes the response body straight into `tar -C <target> -xvf -` with no member-name or symlink validation (contrast with the checks present in `extractTarToDirectory`), so a `tar` implementation/version that does not itself refuse the crafted entries will write outside `<target>`.

func (s *server) untar(ctx context.Context, path string, in *gitalypb.CreateRepositoryFromSnapshotRequest) error {
	req, err := http.NewRequestWithContext(ctx, "GET", in.GetHttpUrl(), nil)
	if err != nil {
		return structerr.NewInvalidArgument("Bad HTTP URL: %w", err)
	}

	client := httpClient
	if resolvedAddress := in.GetResolvedAddress(); resolvedAddress != "" {
		client, err = newResolvedHTTPClient(in.GetHttpUrl(), resolvedAddress)
		if err != nil {
			return structerr.NewInvalidArgument("creating resolved HTTP client: %w", err)
		}
	}

	if in.GetHttpAuth() != "" {
		req.Header.Set("Authorization", in.GetHttpAuth())
	}

	rsp, err := client.Do(req)
	if err != nil {
		return structerr.NewInternal("HTTP request failed: %w", err)
	}
	defer rsp.Body.Close()

	if rsp.StatusCode < http.StatusOK || rsp.StatusCode >= http.StatusMultipleChoices {
		return structerr.NewInternal("HTTP server: %s", rsp.Status)
	}

	cmd, err := command.New(ctx, s.logger, []string{"tar", "-C", path, "-xvf", "-"}, command.WithStdin(rsp.Body))
	if err != nil {
		return err
	}

	return cmd.Wait()
}

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

		default:
			// Skip unsupported file types (devices, FIFOs, etc.)
			s.logger.WithField("file", header.Name).WithField("type", header.Typeflag).
				WarnContext(ctx, "skipping unsupported file type in tar archive")
		}

		if header.Typeflag == tar.TypeReg || header.Typeflag == tar.TypeDir {
			if err := os.Chmod(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("setting permissions for %s: %w", targetPath, err)
			}
		}
	}

	return nil
}

// CreateRepositoryFromSnapshotRequest is a request for the CreateRepositoryFromSnapshot RPC.
message CreateRepositoryFromSnapshotRequest {
  // repository indicates where the new repo should be created. The storage_name and
  // relative_path attributes must be provided.
  Repository repository = 1 [(target_repository)=true];
  // http_url is the full URL of the location of the snapshot TAR.
  string http_url = 2;
  // http_auth is the value of the Authorization header to send to http_url.
  string http_auth = 3;
  // resolved_address holds the resolved IP address of the remote_url. This is
  // used to avoid DNS rebinding by mapping the url to the resolved address.
  // Only IPv4 dotted decimal ("192.0.2.1"), IPv6 ("2001:db8::68"), or IPv4-mapped
  // IPv6 ("::ffff:192.0.2.1") forms are supported.
  // Works with HTTP/HTTPS protocols.
  // Optional.
  string resolved_address = 5;

  // http_host has been removed in favor of ResolvedAddress.
  reserved 4;
  reserved "http_host";
}
