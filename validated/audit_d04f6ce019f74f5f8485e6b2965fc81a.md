### Title
Unauthenticated `/shutdown` endpoint on signer event-receiver allows any remote host reaching the port to permanently kill the signer's event and run loops - ([File: libsigner/src/events.rs])

### Summary
The `SignerEventReceiver::next_event` HTTP dispatcher in `libsigner/src/events.rs` handles `POST /shutdown` by unconditionally setting the stop flag and terminating, with no authentication, secret, or peer check of any kind. Any TCP client that can reach the signer's bound event-receiver socket — which the shipped reference config `sample/conf/signer/mainnet-signer-conf.toml` sets to `endpoint = "0.0.0.0:30000"` — can send a single raw `POST /shutdown` and disable the signer.

### Finding Description
`SignerStopSignaler::send()` is meant to be an internal-only mechanism used by the runloop or the OS signal handler to make the (blocking) `next_event()` HTTP server wake up and check the stop flag: it opens a `TcpStream` to `self.local_addr` and issues `POST /shutdown` [1](#0-0) .

The receiving side, `SignerEventReceiver::next_event`, treats `/shutdown` as just another unauthenticated route dispatched purely on `request.url()`: [2](#0-1) 
There is no comparison of a shared secret/token, no source-address check, and no correlation to the internal `SignerStopSignaler` instance — any HTTP client that completes a TCP connection to the listener and sends `POST /shutdown HTTP/1.1` with a `Content-Length` header (the tiny_http server used by `HttpServer::http(listener)` requires a well-formed HTTP/1.1 request but nothing else) reaches this branch.

Once triggered, `event_receiver.stop_signal.store(true, ...)` is set and `Err(EventError::Terminated)` is returned, causing the event-receiver's `main_loop` to break and exit its thread [3](#0-2) . This drops `event_receiver` (and its `out_channels` senders held inside), so the paired `SignerRunLoop::main_loop` thread's `event_recv.recv_timeout(..)` subsequently returns `RecvTimeoutError::Disconnected`, causing that thread to also return `None` and exit [4](#0-3) . Both signer threads spawned by `Signer::spawn` are thereby terminated [5](#0-4) , silently disabling the signer's participation in block signing until an operator manually restarts the process.

None of the other routes on this listener (`/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`) perform any authentication either [6](#0-5) ; the `auth_password`/`auth_token` mechanism described in the signer/node configs only gates the *node's* block-proposal RPC endpoint, not this signer-side event listener, so it provides no protection here.

### Impact Explanation
A single, unauthenticated `POST /shutdown` request permanently terminates both the event-receiver thread and the signer runloop thread for the targeted signer process, silently taking that signer offline (it will stop validating/signing block proposals and stop responding to the node) until manually restarted. This is a one-message, unauthenticated denial-of-service against a signer, matching the "Critical — remote crash/unauthenticated DoS from few messages" category. It is trivially repeatable against any signer whose event port is reachable.

### Likelihood Explanation
The only precondition is TCP reachability to the signer's event-receiver port. The reference configuration shipped in this repo, `sample/conf/signer/mainnet-signer-conf.toml`, sets `endpoint = "0.0.0.0:30000"` [7](#0-6) , i.e. bound to all interfaces rather than loopback, and `stacks-signer/src/lib.rs` even prints a runtime warning acknowledging the risk of exposing the signer externally without additional controls [8](#0-7) . No secret, peer key, or admin role is required — the attacker only needs a TCP connection and a 5-line crafted HTTP request. Cost is negligible and the exploit is a single request.

### Recommendation
Require a shared secret/HMAC (e.g., reuse `auth_password`, or a dedicated random token minted at `bind()` and known only to the in-process `SignerStopSignaler`) checked on `/shutdown` (and ideally on all other routes) before honoring it. Alternatively, restrict the stop signal to a loopback-only side channel (e.g., a Unix domain socket or in-process channel) instead of an unauthenticated HTTP route, and document/default `endpoint` to bind to `127.0.0.1` rather than `0.0.0.0`.

### Proof of Concept
```rust
// libsigner/src/tests/mod.rs (new test)
#[test]
fn test_unauthenticated_remote_shutdown() {
    let ev = SignerEventReceiver::new(false);
    let (res_send, _res_recv) = channel();
    let mut signer = Signer::new(SimpleRunLoop::new(usize::MAX), ev, res_send);
    let endpoint: SocketAddr = "0.0.0.0:31999".parse().unwrap();
    let running_signer = signer.spawn(endpoint).unwrap();

    // Attacker with no credentials sends a raw shutdown POST.
    let mut sock = TcpStream::connect(("127.0.0.1", 31999)).unwrap();
    let body = "attacker-controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: 127.0.0.1:31999\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    sock.write_all(req.as_bytes()).unwrap();

    // Give threads time to exit; both threads should have terminated
    // even though `.stop()` (the legitimate internal signaler) was never called.
    std::thread::sleep(std::time::Duration::from_secs(1));
    // running_signer.join() should return promptly (threads already exited)
    // instead of hanging, proving the unauthenticated request killed the signer.
    let _ = running_signer.join();
}
```

                }

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    pub fn spawn(&mut self, bind_addr: SocketAddr) -> Result<RunningSigner<EV, R, T>, EventError> {
        let mut event_receiver = self
            .event_receiver
            .take()
            .ok_or(EventError::AlreadyRunning)?;
        let result_sender = self
            .result_sender
            .take()
            .ok_or(EventError::AlreadyRunning)?;
        let mut signer_loop = self.signer_loop.take().ok_or(EventError::AlreadyRunning)?;

        let (event_send, event_recv) = channel();
        event_receiver.add_consumer(event_send);

        let bind_port = bind_addr.port();
        event_receiver.bind(bind_addr)?;
        let stop_signaler = event_receiver.get_stop_signaler()?;
        let mut ret_stop_signaler = event_receiver.get_stop_signaler()?;

        // start a thread for the event receiver
        let event_thread = thread::Builder::new()
            .name(format!("event_receiver:{bind_port}"))
            .stack_size(THREAD_STACK_SIZE)
            .spawn(move || event_receiver.main_loop())
            .map_err(|e| {
                error!("EventReceiver failed to start: {:?}", &e);
                EventError::FailedToStart
            })?;

        // start receiving events and doing stuff with them
        let runloop_thread = thread::Builder::new()
            .name(format!("signer_runloop:{bind_port}"))
            .stack_size(THREAD_STACK_SIZE)
            .spawn(move || signer_loop.main_loop(event_recv, result_sender, stop_signaler))
            .map_err(|e| {
                error!("SignerRunLoop failed to start: {:?}", &e);
                ret_stop_signaler.send();
                EventError::FailedToStart
            })?;

        let running_signer = RunningSigner {
            signer_join: runloop_thread,
            event_join: event_thread,
            stop_signal: ret_stop_signaler,
        };

        Ok(running_signer)
    }
