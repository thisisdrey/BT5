### Title
Unauthenticated `/shutdown` endpoint in `SignerEventReceiver` allows any TCP peer to terminate the signer's event-receiver main loop - (File: libsigner/src/events.rs)

### Summary
The `SignerEventReceiver::next_event` handler dispatches on `request.url()` and, for `/shutdown`, unconditionally sets `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `Err(EventError::Terminated)` with no check of the request's source, credentials, or body content. Since the receiver's `main_loop` treats `EventError::Terminated` as a clean exit condition, any TCP client that can reach the bound event port can send a single unauthenticated `POST /shutdown` and permanently halt signer event processing.

### Finding Description
`SignerEventReceiver` binds an HTTP server via `tiny_http::HttpServer` in `bind()` [1](#0-0) . In `next_event()`, requests are routed purely by URL/method with no peer-identity, secret, or header check anywhere in the branch chain [2](#0-1) . The `/shutdown` branch specifically does:
```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
}
``` [3](#0-2) 

The intended caller is the local stacks-node's own `SignerStopSignaler::send()`, which connects to `self.local_addr` and issues the same literal `POST /shutdown` request with a fixed, non-secret body ("Yo. Shut this shit down!") [4](#0-3) . Nothing in that flow — nor in the handler — verifies the request actually originated from that trusted local caller; the equality "shutdown_authorized_by == the_local_stacks_node_only" that the code implicitly assumes is never enforced. `main_loop()` treats `EventError::Terminated` as a normal termination signal and breaks out of the loop [5](#0-4) . A grep across `libsigner` confirms there is no `Authorization`/auth-token header check anywhere in this module or crate that could gate this endpoint.

### Impact Explanation
Any remote party able to open a TCP connection to the signer's bound event-receiver port can send one crafted `POST /shutdown` HTTP request and cause the signer's event-receiver thread to stop processing all further `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` events pushed by the node. This is a single-message, unauthenticated, repeatable DoS against the signer process (an attacker can re-issue it after any restart), matching the "Critical - remote crash/unauthenticated DoS from few messages" category, since it silently stops the signer from participating in block validation/signing without crashing the process outright but rendering it functionally dead.

### Likelihood Explanation
No preconditions beyond network reachability to the bound port are required — no secret, no StackerDB slot ownership, no signature, and no peer registration. The only "mitigation" is operational: deployments are expected to bind this port to loopback or a private/LAN interface, but the code itself performs no defense-in-depth check, so any node that binds the event port to a non-loopback-restricted interface, or any peer within reach of that LAN, can trigger it trivially and repeatedly at near-zero cost.

### Recommendation
Add authentication to the `/shutdown` (and ideally all) endpoints of `SignerEventReceiver` — e.g., require a shared secret/token known only to the local node (passed via header or as part of the body) and verify it in `next_event()` before honoring `/shutdown`, or restrict acceptance to connections whose peer address matches the expected loopback/local address recorded at bind time. Reject all other `/shutdown` requests with `EventError::MalformedRequest` instead of storing the stop signal.

use std::net::{TcpStream, SocketAddr};

#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let bind_addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let addr = receiver.bind(bind_addr).unwrap();
    let (tx, _rx) = channel();
    receiver.add_consumer(tx);

    // Attacker: no credentials, no prior relationship with the node.
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker-controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Assert the receiver is terminated by a single unauthenticated message.
    let err = receiver.next_event().unwrap_err();
    assert!(matches!(err, EventError::Terminated));
    assert!(receiver.is_stopped());
}
