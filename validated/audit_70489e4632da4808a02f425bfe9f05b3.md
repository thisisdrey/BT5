### Title
Missing zero-address validation for `new_authority` in `transfer_to_new_account`/`transfer_to_new_account_pda` permanently locks migrated account funds - (File: programs/marginfi/src/instructions/marginfi_account/transfer_account.rs)

### Summary
The Fantium report's bug class is "insufficient constraint checks" (missing zero-address / bounds validation) in state-mutating functions. The strongest reachable, unprivileged-user analog in marginfi-v2 is the `new_authority` parameter accepted by `transfer_to_new_account` and `transfer_to_new_account_pda`, which is explicitly documented as unchecked and is never validated against `Pubkey::default()` (the zero address) before being written as the sole authority of the new account.

### Finding Description
Both `transfer_to_new_account` and `transfer_to_new_account_pda` accept `new_authority` as a completely unchecked account: [1](#0-0) 

This value is passed directly into `initialize_migrated_account`, which sets it as the sole `authority` field of the newly created `MarginfiAccount`: [2](#0-1) 

At the same time, the old account is disabled and stripped of its `lending_account` (all balances/positions are moved to the new account): [3](#0-2) 

Neither `transfer_to_new_account` nor `transfer_to_new_account_pda` contain any `check!`/`check_eq!` validating that `new_authority` is non-default: [4](#0-3) [5](#0-4) 

If the current authority (the account owner, an unprivileged, non-admin user — this instruction is signed only by `authority`/`fee_payer`, not by any group admin) sets `new_authority = Pubkey::default()`, the new `MarginfiAccount`'s `authority` field becomes the zero address. Since `is_signer_authorized` (used to gate all account operations) checks the signer against `account.authority`, no real keypair can ever sign as `Pubkey::default()`, permanently freezing all of the account's deposited/borrowed positions that were just migrated into it.

### Impact Explanation
This satisfies the "permanent lock/freeze" impact category in the rules: all assets represented by the migrated account's `lending_account` balances (deposits, which back real token custody in bank vaults) become permanently inaccessible because no key can control the new account. This is a concrete, unprivileged-user-reachable state corruption/fund-freeze bug, not theoretical — it is directly caused by the missing zero-address check on a state-mutating instruction argument, matching the exact bug class described in the external report (`updateFantiumMinterAddress`/`updateFantiumNFTAddress` etc. lacking zero-address checks).

### Likelihood Explanation
Likelihood is low-to-moderate: this requires the account owner to supply `Pubkey::default()` as `new_authority`, which would typically be a user error (fat-fingered/uninitialized pubkey in client code) rather than a third-party attack, since only the account's own authorized signer can invoke this transfer. However, it is a genuine missing input-validation gap on a fully unprivileged, user-facing instruction with a permanent, unrecoverable consequence — exactly the "increases human error probability" class of issue the source report describes.

### Recommendation
Add an explicit check in both `transfer_to_new_account` and `transfer_to_new_account_pda` rejecting `new_authority == Pubkey::default()` (and any other reserved/unusable sentinel value) before calling `initialize_migrated_account`, e.g.:
```rust
check!(
    ctx.accounts.new_authority.key() != Pubkey::default(),
    MarginfiError::InvalidAuthority // or similar
);
```
placed before the migration/finalization steps in both instruction handlers.

### Proof of Concept
1. Account owner `A` holds a `MarginfiAccount` with deposits/borrows.
2. `A` calls `transfer_to_new_account` (or the PDA variant), signing as `authority`, and supplies `new_authority = Pubkey::default()`.
3. The instruction succeeds: `initialize_migrated_account` sets the new account's `authority` to `Pubkey::default()`; the old account is disabled and its `lending_account` zeroed out per `finalize_migrated_old_account`.
4. No signer can ever satisfy `is_signer_authorized` for the new account (since no keypair corresponds to the all-zero pubkey), so all migrated balances are permanently locked with no recovery path (the old account is disabled and `migrated_to` is set, and `AccountAlreadyMigrated` blocks retrying from the old account).

pub fn transfer_to_new_account(ctx: Context<TransferToNewAccount>) -> MarginfiResult {
    // Validate the global fee wallet and claim a nominal fee
    let group = ctx.accounts.group.load()?;
    check_eq!(
        ctx.accounts.global_fee_wallet.key(),
        group.fee_state_cache.global_fee_wallet,
        MarginfiError::InvalidFeeAta
    );
    anchor_lang::system_program::transfer(ctx.accounts.transfer_fee(), ACCOUNT_TRANSFER_FEE)?;

    let mut old_account = ctx.accounts.old_marginfi_account.load_mut()?;

    check!(
        !old_account.get_flag(ACCOUNT_IN_FLASHLOAN),
        MarginfiError::AccountInFlashloan
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_RECEIVERSHIP),
        MarginfiError::ForbiddenIx
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_ORDER_EXECUTION),
        MarginfiError::ForbiddenIx
    );

    check!(
        old_account.active_orders == 0,
        MarginfiError::IllegalAction,
        "Close all active orders before transfer"
    );

    // Prevent multiple migrations from the same account
    check_eq!(
        old_account.migrated_to,
        Pubkey::default(),
        MarginfiError::AccountAlreadyMigrated
    );

    let mut new_account = ctx.accounts.new_marginfi_account.load_init()?;
    let current_timestamp = Clock::get()?.unix_timestamp as u64;
    initialize_migrated_account(
        &mut new_account,
        &old_account,
        ctx.accounts.new_authority.key(),
        current_timestamp,
        ctx.accounts.old_marginfi_account.key(),
    );

    finalize_migrated_old_account(
        &mut old_account,
        ctx.accounts.new_marginfi_account.key(),
        current_timestamp,
    );

    emit!(MarginfiAccountTransferToNewAccount {
        header: AccountEventHeader {
            signer: Some(ctx.accounts.authority.key()),
            marginfi_account: ctx.accounts.new_marginfi_account.key(),
            marginfi_account_authority: ctx.accounts.new_authority.key(),
            marginfi_group: ctx.accounts.group.key(),
        },
        old_account: ctx.accounts.old_marginfi_account.key(),
        old_account_authority: ctx.accounts.authority.key(),
        new_account_authority: ctx.accounts.new_authority.key(),
    });

    Ok(())
}

pub fn transfer_to_new_account_pda(
    ctx: Context<TransferToNewAccountPda>,
    account_index: u16,
    third_party_id: Option<u16>,
) -> MarginfiResult {
    // Validate the global fee wallet and claim a nominal fee
    let group = ctx.accounts.group.load()?;
    check_eq!(
        ctx.accounts.global_fee_wallet.key(),
        group.fee_state_cache.global_fee_wallet,
        MarginfiError::InvalidFeeAta
    );
    anchor_lang::system_program::transfer(ctx.accounts.transfer_fee(), ACCOUNT_TRANSFER_FEE)?;

    let mut old_account = ctx.accounts.old_marginfi_account.load_mut()?;

    check!(
        !old_account.get_flag(ACCOUNT_IN_FLASHLOAN),
        MarginfiError::AccountInFlashloan
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_RECEIVERSHIP),
        MarginfiError::ForbiddenIx
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_ORDER_EXECUTION),
        MarginfiError::ForbiddenIx
    );

    check!(
        old_account.active_orders == 0,
        MarginfiError::IllegalAction,
        "Close all active orders before transfer"
    );

    // Prevent multiple migrations from the same account
    check_eq!(
        old_account.migrated_to,
        Pubkey::default(),
        MarginfiError::AccountAlreadyMigrated
    );

    // Validate third-party id restriction if provided
    if let Some(id) = third_party_id {
        if !is_allowed_cpi_for_third_party_id(&ctx.accounts.instructions_sysvar, id)? {
            return err!(MarginfiError::Unauthorized);
        }
    }

    let mut new_account = ctx.accounts.new_marginfi_account.load_init()?;
    let current_timestamp = Clock::get()?.unix_timestamp as u64;
    initialize_migrated_account(
        &mut new_account,
        &old_account,
        ctx.accounts.new_authority.key(),
        current_timestamp,
        ctx.accounts.old_marginfi_account.key(),
    );
    new_account.account_index = account_index;
    new_account.third_party_index = third_party_id.unwrap_or(0);
    new_account.bump = ctx.bumps.new_marginfi_account;

    finalize_migrated_old_account(
        &mut old_account,
        ctx.accounts.new_marginfi_account.key(),
        current_timestamp,
    );

    emit!(MarginfiAccountTransferToNewAccount {
        header: AccountEventHeader {
            signer: Some(ctx.accounts.authority.key()),
            marginfi_account: ctx.accounts.new_marginfi_account.key(),
            marginfi_account_authority: ctx.accounts.new_authority.key(),
            marginfi_group: ctx.accounts.group.key(),
        },
        old_account: ctx.accounts.old_marginfi_account.key(),
        old_account_authority: ctx.accounts.authority.key(),
        new_account_authority: ctx.accounts.new_authority.key(),
    });

    Ok(())
}
