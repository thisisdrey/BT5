### Title
Self-matching orders in MarketSellAssetActuator cause account balance updates to be silently overwritten, resulting in permanent loss of funds - (File: actuator/src/main/java/org/tron/core/actuator/MarketSellAssetActuator.java)

### Summary
The reported H-6 bug is a classic "in-memory ledger update lost because a stale copy is written back to storage" accounting bug. `D3Vault.withdrawReserves()` moved funds out without updating the internal balance counter used for later accounting. The equivalent analog in java-tron is in `MarketSellAssetActuator`, TRON's on-chain order-book matching engine (`MarketSellAssetContract`, reachable by any account placing an order). When an account's own resting order is matched against its own new order (self-trade), the maker-side balance credit is persisted to `AccountStore` from a stale, freshly-fetched copy of the account, and is then immediately overwritten by the taker-side in-memory account object that is persisted at the end of `execute()` — silently erasing the maker credit.

### Finding Description
In `MarketSellAssetActuator.execute()` [1](#0-0) , the taker's `AccountCapsule` is loaded once at the top of `execute()` and mutated in-memory throughout the whole matching process (fee, sell-token deduction, and any buy-token credit obtained as a taker), and is finally persisted at the very end with a single `accountStore.put(accountCapsule.createDbKey(), accountCapsule)` call.

During matching, `matchSingleOrder` credits the **maker** side of a fill through a separate helper, `addTrxOrToken(MarketOrderCapsule orderCapsule, long num)` [2](#0-1) , which independently re-fetches the maker's account from `accountStore`, applies the credit, and immediately calls `accountStore.put(...)` to persist it right away — separate from the taker's in-memory object and separate from the final write at the end of `execute()`.

Nothing in `validate()` prevents an account from matching against its own resting order [3](#0-2) : the checks only cover token validity, quantity limits, and balance sufficiency — there is no restriction that the taker and the maker order owner must differ.

When the maker and taker are the same address (self-trade):
1. The taker's initial account snapshot is loaded and mutated in-memory (fee + sell-token deducted, and any taker-side buy-token credit added via the `addTrxOrToken(..., accountCapsule)` overload, which does not write to the store) — see `execute()` and `matchSingleOrder()` [4](#0-3) .
2. Immediately afterward, the maker-side credit `addTrxOrToken(makerOrderCapsule, makerBuyTokenQuantityReceive)` re-reads the SAME account from `accountStore` (still holding the pre-transaction balance, since the taker's in-memory changes have not been flushed yet), applies the maker credit, and writes it straight to the store.
3. At the end of `execute()`, `accountStore.put(accountCapsule.createDbKey(), accountCapsule)` persists the taker's in-memory object, which has no knowledge of the maker credit just written in step 2 — overwriting and permanently erasing it.

### Impact Explanation
The maker-side proceeds of the trade (the token the account should have received for the matched resting order) are deducted from the account when the order was originally created (in `transferBalanceOrToken`/`createAndSaveOrder`), but the corresponding credit is subsequently lost due to the overwrite. This breaks the token conservation invariant of the exchange: tokens are locked/removed from a user's account but never actually delivered to any account, and the amount is permanently and unrecoverably lost — a direct "unbacked balance / permanent freezing of funds" outcome, reachable by any unprivileged account through two ordinary `MarketSellAssetContract` transactions (place order, then submit a second order that matches it).

### Likelihood Explanation
This requires no special privileges, only that a single account submits a sell/buy order pair whose prices cross (self-match), a completely permissionless action available to every order placer. It can happen unintentionally (a user accidentally crossing their own order) or be triggered deliberately, and the market-matching loop (`matchOrder`) can process multiple maker fills per transaction, so the bug is deterministically triggerable.

### Recommendation
Persist the maker-side account update through the same in-memory object graph as the taker (e.g., cache modified `AccountCapsule` objects per address in a map for the duration of `execute()` and write each one exactly once at the end), or explicitly detect and merge updates when the maker and taker addresses are identical before writing to `AccountStore`, mirroring the fix recommended for `D3Vault.withdrawReserves()`: always keep the persisted state consistent with every balance-affecting operation performed during the transaction.

### Proof of Concept
1. Account `A` places order `O1` via `MarketSellAssetContract`: sell 100 `TokenX` for 200 `TokenY` (processed by `MarketSellAssetActuator.execute()`; `TokenX` is deducted from `A` and `O1` is stored as a resting maker order).
2. Account `A` (same address) places a second order `O2` via `MarketSellAssetContract`: sell 200 `TokenY` for 100 `TokenX`, at a price that matches `O1`.
3. In `execute()` for `O2`, `A`'s account is loaded once as `accountCapsule` (taker) and `TokenY` + fee are deducted in-memory.
4. `matchOrder`/`matchSingleOrder` fully fills `O1` against `O2`; the maker credit for `O1` (100 `TokenX`) is applied via `addTrxOrToken(makerOrderCapsule, ...)`, which reloads `A`'s account fresh from `AccountStore` (pre-`O2` state) and writes it back immediately with the `TokenX` credit.
5. `execute()` finishes by writing the taker's `accountCapsule` (which reflects `O2`'s fee/`TokenY` deduction and any taker-side `TokenX` receive, but not step 4's maker credit) back to `AccountStore`, overwriting step 4.
6. Final state: Account `A` has 100 `TokenX` deducted for `O1` in step 1, but no corresponding maker credit survives in the account store — the 100 `TokenX` is permanently lost.

  public boolean execute(Object object) throws ContractExeException {
    initStores();

    TransactionResultCapsule ret = (TransactionResultCapsule) object;
    if (Objects.isNull(ret)) {
      throw new RuntimeException(TX_RESULT_NULL);
    }

    long fee = calcFee();

    try {
      final MarketSellAssetContract contract = this.any
          .unpack(MarketSellAssetContract.class);

      AccountCapsule accountCapsule = accountStore
          .get(contract.getOwnerAddress().toByteArray());

      sellTokenID = contract.getSellTokenId().toByteArray();
      buyTokenID = contract.getBuyTokenId().toByteArray();
      sellTokenQuantity = contract.getSellTokenQuantity();
      buyTokenQuantity = contract.getBuyTokenQuantity();
      MarketPrice takerPrice = MarketPrice.newBuilder()
          .setSellTokenQuantity(sellTokenQuantity)
          .setBuyTokenQuantity(buyTokenQuantity).build();

      // fee
      accountCapsule.setBalance(accountCapsule.getBalance() - fee);
      // add to blackhole address
      if (dynamicStore.supportBlackHoleOptimization()) {
        dynamicStore.burnTrx(fee);
      } else {
        adjustBalance(accountStore, accountStore.getBlackhole(), fee);
      }
      // 1. transfer of balance
      transferBalanceOrToken(accountCapsule);

      // 2. create and save order
      MarketOrderCapsule orderCapsule = createAndSaveOrder(accountCapsule, contract);

      // 3. match order
      matchOrder(orderCapsule, takerPrice, ret, accountCapsule);

      // 4. save remain order into order book
      if (orderCapsule.getSellTokenQuantityRemain() != 0) {
        saveRemainOrder(orderCapsule);
      }

      orderStore.put(orderCapsule.getID().toByteArray(), orderCapsule);
      accountStore.put(accountCapsule.createDbKey(), accountCapsule);

      ret.setOrderId(orderCapsule.getID());
      ret.setStatus(fee, code.SUCESS);

  @Override
  public boolean validate() throws ContractValidateException {
    if (this.any == null) {
      throw new ContractValidateException(CONTRACT_NOT_EXIST);
    }
    if (chainBaseManager == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    initStores();

    if (!this.any.is(MarketSellAssetContract.class)) {
      throw new ContractValidateException(
          "contract type error,expected type [MarketSellAssetContract],real type[" + any
              .getClass() + "]");
    }

    if (!dynamicStore.supportAllowMarketTransaction()) {
      throw new ContractValidateException("Not support Market Transaction, need to be opened by"
          + " the committee");
    }

    final MarketSellAssetContract contract;
    try {
      contract =
          this.any.unpack(MarketSellAssetContract.class);
    } catch (InvalidProtocolBufferException e) {
      logger.debug(e.getMessage(), e);
      throw new ContractValidateException(e.getMessage());
    }

    // Parameters check
    byte[] ownerAddress = contract.getOwnerAddress().toByteArray();
    sellTokenID = contract.getSellTokenId().toByteArray();
    buyTokenID = contract.getBuyTokenId().toByteArray();
    sellTokenQuantity = contract.getSellTokenQuantity();
    buyTokenQuantity = contract.getBuyTokenQuantity();

    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }

    // Whether the accountStore exist
    AccountCapsule ownerAccount = accountStore.get(ownerAddress);
    if (ownerAccount == null) {
      throw new ContractValidateException("Account does not exist!");
    }

    if (!Arrays.equals(sellTokenID, "_".getBytes()) && !isNumber(sellTokenID)) {
      throw new ContractValidateException("sellTokenId is not a valid number");
    }
    if (!Arrays.equals(buyTokenID, "_".getBytes()) && !isNumber(buyTokenID)) {
      throw new ContractValidateException("buyTokenId is not a valid number");
    }

    if (Arrays.equals(sellTokenID, buyTokenID)) {
      throw new ContractValidateException("cannot exchange same tokens");
    }

    if (sellTokenQuantity <= 0 || buyTokenQuantity <= 0) {
      throw new ContractValidateException("token quantity must greater than zero");
    }

    long quantityLimit = dynamicStore.getMarketQuantityLimit();
    if (sellTokenQuantity > quantityLimit || buyTokenQuantity > quantityLimit) {
      throw new ContractValidateException("token quantity must less than " + quantityLimit);
    }

    // check order num
    MarketAccountOrderCapsule marketAccountOrderCapsule = marketAccountStore
        .getUnchecked(ownerAddress);
    if (marketAccountOrderCapsule != null
        && marketAccountOrderCapsule.getCount() >= MAX_ACTIVE_ORDER_NUM) {
      throw new ContractValidateException(
          "Maximum number of orders exceeded，" + MAX_ACTIVE_ORDER_NUM);
    }

    try {
      // Whether the balance is enough
      long fee = calcFee();

      if (Arrays.equals(sellTokenID, "_".getBytes())) {
        if (ownerAccount.getBalance() < addExact(sellTokenQuantity, fee)) {
          throw new ContractValidateException("No enough balance !");
        }
      } else {
        if (ownerAccount.getBalance() < fee) {
          throw new ContractValidateException("No enough balance !");
        }

        AssetIssueCapsule assetIssueCapsule = Commons
            .getAssetIssueStoreFinal(dynamicStore, assetIssueStore, assetIssueV2Store)
            .get(sellTokenID);
        if (assetIssueCapsule == null) {
          throw new ContractValidateException("No sellTokenId !");
        }
        if (!ownerAccount.assetBalanceEnoughV2(sellTokenID, sellTokenQuantity,
            dynamicStore)) {
          throw new ContractValidateException("SellToken balance is not enough !");
        }
      }

      if (!Arrays.equals(buyTokenID, "_".getBytes())) {
        // Whether have the token
        AssetIssueCapsule assetIssueCapsule = Commons
            .getAssetIssueStoreFinal(dynamicStore, assetIssueStore, assetIssueV2Store)
            .get(buyTokenID);
        if (assetIssueCapsule == null) {
          throw new ContractValidateException("No buyTokenId !");
        }
      }
    } catch (ArithmeticException e) {
      logger.debug(e.getMessage(), e);
      throw new ContractValidateException(e.getMessage());
    }

  private void addTrxOrToken(MarketOrderCapsule orderCapsule, long num) {
    AccountCapsule accountCapsule = accountStore
        .get(orderCapsule.getOwnerAddress().toByteArray());

    byte[] buyTokenId = orderCapsule.getBuyTokenId();
    if (Arrays.equals(buyTokenId, "_".getBytes())) {
      accountCapsule.setBalance(addExact(accountCapsule.getBalance(), num));
    } else {
      accountCapsule
          .addAssetAmountV2(buyTokenId, num, dynamicStore, assetIssueStore);
    }
    accountStore.put(orderCapsule.getOwnerAddress().toByteArray(), accountCapsule);
