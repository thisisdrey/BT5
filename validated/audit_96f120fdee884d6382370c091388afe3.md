### Title
Protocol fee bypass on `Imt`/`Nep245` tokens via delta-splitting across multiple `TokenDiff` intents in one batch - (`contracts/defuse/core/src/intents/token_diff.rs`)

### Summary
`TokenDiff::token_fee` waives fees for `Nep245`/`Imt` tokens whenever the **per-intent** `|delta|` is `<= 1`, but `TokenDiff::execute_intent` computes and charges this fee independently for each `TokenDiff` intent rather than on the total netted delta for a token across the whole `MultiPayload` batch. A signer can split a single `delta = -2` `TokenDiff` on an `Imt` token into two `delta = -1` `TokenDiff` intents in the same batch, each of which independently evaluates `amount > 1` as false and returns `Pips::ZERO`, so the total protocol fee collected drops from `fee_ceil(2, fee)` to `0`.

### Finding Description
The broken binding: `fee_collected_for_token_T == Pips::fee_ceil(protocol_fee, |sum_of_negative_deltas_for_T_in_batch|)`. In this codebase, the actual computation is `fee_collected_for_token_T == Σ_over_intents( token_fee(T, |delta_in_that_intent|, protocol_fee).fee_ceil(|delta_in_that_intent|) )`, evaluated intent-by-intent, not on the aggregate.

`TokenDiff::execute_intent` iterates its own `self.diff` map and, for each negative delta, computes `Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount)` using only that single intent's `amount = delta.unsigned_abs()`: [1](#0-0) 

`token_fee` special-cases `Nep245`/`Imt` tokens so that any single call with `amount <= 1` returns `Pips::ZERO`, while `amount > 1` charges the real `fee`: [2](#0-1) 

Because a `TokenDeltas` map (`BTreeMap<TokenId, i128>`) can only hold one entry per `TokenId`, an attacker cannot merge two `-1` deltas for the same `Imt` `token_id` inside one `TokenDiff`; but nothing stops them submitting **two separate `TokenDiff` intents** (in the same `MultiPayload`, or two `MultiPayload`s in the same batch) each with `delta = -1` on the same `Imt` token. `Engine::execute_signed_intent` calls `intents.execute_intent(...)` per signed payload and applies balance deltas immediately via `internal_apply_deltas`, and the whole-batch conservation check happens later in `TransferMatcher::finalize`, which only checks that deltas net to zero — it performs no fee logic and is agnostic to how many intents produced the aggregate delta: [3](#0-2) [4](#0-3) 

Thus the `TransferMatcher` sees `-1` and `-1` on the same token as equivalent to a single `-2` for balance-netting purposes, but the fee code computes `token_fee` per intent execution, before the netting/finalize stage, and never re-aggregates. Exploit: attacker crafts a `MultiPayload` (or a `DefusePayload` with two `TokenDiff` intents) where their own signed intents contain two `TokenDiff`s, each `{Imt_token: -1, other_token: +X/2}` (or any counterparty structure providing the offsetting `+2` on the `Imt` token from another leg of the same batch), instead of one `TokenDiff` `{Imt_token: -2, other_token: +X}`. Existing guards (`MultiPayload::verify`, nonce/salt checks, `TransferMatcher::finalize`) validate signatures, replay-protection and balance conservation, but none of them re-derive or enforce the fee based on the aggregate delta of a token across the batch, so they do not prevent this divergence.

### Impact Explanation
The fee collector (`fee_collector`) receives strictly less than the protocol entitles it to for `Imt`/`Nep245` token trades whenever the signer structures the trade as multiple unit-sized `TokenDiff` legs instead of one bulk leg. This is a protocol-fee-bypass matching the Critical category ("protocol fees bypassed or over-collected"). The attacker gains the difference between the honest fee (`fee_ceil(2, fee)`, scaling with amount for larger splits) and zero, at no cost beyond an extra intent/signature. It is repeatable per token, per batch, and scales linearly with the number of unit legs an attacker is willing to split a trade into (an `Imt` amount `N` can be split into `N` legs of `delta=-1`, reducing total collected fees for that trade to `0` regardless of `N`).

### Likelihood Explanation
Preconditions are minimal and fully attacker-controlled: the signer only needs an `Imt` token balance of at least the amount they wish to trade (`>=2`), a nonzero `protocol_fee`, and the ability to construct a `MultiPayload`/`DefusePayload` with more than one `TokenDiff` intent — capabilities explicitly available to any unprivileged signer (`execute_intents`/`simulate_intents` callers). No special role, relayer key, or victim key is required. The attack is trivially repeatable across accounts, tokens, and batches, and costs only the extra signature/intent overhead.

### Recommendation
Compute the `Imt`/`Nep245` fee waiver threshold (`amount > 1`) against the total netted negative delta for that `token_id` across the whole batch (e.g., using the same aggregation `TransferMatcher` performs) rather than the per-intent delta, or alternatively track a running total in `Engine`/`Deltas` per `(signer, token_id)` across all `TokenDiff` intents processed in a batch before evaluating the fee-waiver condition.

### Proof of Concept
Add a `cargo test` (e.g. `tests/src/tests/defuse/intents/token_diff.rs`) with fee > 0 (`Env::builder().fee(Pips::ONE_PERCENT)`):
1. Deposit an `Imt` token balance of `>=2` to a test signer (via `ImtMint` or equivalent minting intent already exercised in the test suite).
2. Case A (baseline): sign one `TokenDiff` with `diff = {imt_token: -2, other_token: +closure}` in a `MultiPayload`, execute via `env.defuse_execute_intents`, and assert `mt_balance_of(fee_collector, imt_token) > 0` (nonzero fee credited).
3. Case B (exploit): sign two `TokenDiff` intents, each `diff = {imt_token: -1, other_token: +closure_half}` (or one `TokenDiff` with `-1` matched by a second party leg providing the offsetting `+2`), bundled in the same batch, execute, and assert `mt_balance_of(fee_collector, imt_token) == 0` despite an identical net `-2` transferred.
4. Compare the two `fee_collector` balances to demonstrate the fee-ceil(2) vs. 0 discrepancy for economically identical trades.

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
