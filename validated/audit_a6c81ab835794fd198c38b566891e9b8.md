Audit Report

## Title
Documented replay-safety invariant ("era shorter than `LockPeriod`") is never enforced on-chain in `pallet-scarcity`'s `AsScarcity` extension - (File: `substrate/frame/scarcity/src/extension.rs`)

## Summary
`pallet-scarcity`'s module docs assert that signers of `AsScarcity`-authorized transactions must use a mortal era shorter than `Config::LockPeriod`, guaranteeing "every retry after a failure is a fresh signing decision rather than a third-party replay of the old transaction." [1](#0-0) [2](#0-1)  No code path — `validate`, `prepare`, or `post_dispatch_details` — checks the extrinsic's era against `T::LockPeriod`, so this guarantee rests entirely on unenforced caller discipline.

## Finding Description
`AsScarcity::validate` only checks whether `Locked::<T>::get(&owner)` is currently active and whether `instance`/`state_nonce` match; it never inspects `DispatchInfoOf` or any mortality/era information relative to `T::LockPeriod::get()`. [3](#0-2)  The backoff lock computed in `failed_dispatch_lock` is derived purely from `T::UnixTime::now()` and `T::LockPeriod::get()`, with no linkage to the actual era length of the failed transaction. [4](#0-3)  `prepare` and `post_dispatch_details` likewise perform no era-related checks. [5](#0-4) 

Critically, the module docs state that `AsScarcity` is placed before `frame_system::CheckNonce` in the extension pipeline and that "account checks deliberately see a non-system origin and skip it," meaning `CheckNonce` provides no dedup/replay protection for NFT-purse-authorized calls. [6](#0-5)  This is confirmed by the actual runtime wiring, which places `(AsScarcity, AuthorizeCall)` before `CheckNonce` and `CheckEra` in the extension tuple. [7](#0-6)  `CheckEra` only validates that the era is still within its window relative to the current block — it has no knowledge of, or interaction with, `pallet-scarcity`'s `LockPeriod`. Consequently, replay protection for NFT-purse transactions depends solely on (a) `state_nonce` matching and (b) the era not yet expiring, and nothing binds the era's length to `LockPeriod` as the documentation promises.

## Impact Explanation
This breaks the documented "fresh signing decision" guarantee for the feeless, unprivileged `transfer`/`burn` dispatch path authorized via `AsScarcity`. If a signer chooses (or a bystander retains) a mortal era longer than `LockPeriod`, a transaction that failed once and set the backoff lock remains a valid, signed extrinsic after the lock naturally expires. Any third party who retained a copy can resubmit it, and because `state_nonce` still matches (the NFT was restored on failure), `validate` will accept it — executing a transfer/burn against the signer's current intent without checking whether they still consent. This matches the "unauthorized execution" impact category for the affected purse's NFT.

## Likelihood Explanation
No privileged actor is required — only an ordinary signed account choosing an era not shorter than `LockPeriod` (fully within a normal user's control and never rejected by any check), combined with a bystander retaining a broadcast/failed transaction. Since `validate`, `prepare`, and `post_dispatch_details` never inspect era vs. `LockPeriod`, the guard the documentation promises does not exist in code, making the scenario reachable whenever `LockPeriod` is short relative to the chosen era or an immortal transaction is used.

## Recommendation
Enforce the documented invariant in code: in `AsScarcity::validate`, inspect the transaction's era/mortality (via `DispatchInfoOf` or explicit `CheckMortality` binding) and reject any `AsScarcity`-authorized call whose era is not strictly shorter than `T::LockPeriod::get()`. Alternatively, bind the failed-dispatch lock's replay protection to the specific extrinsic (e.g., via an explicit replay nonce independent of `state_nonce`) so lock expiry cannot resurrect a stale signed payload.

## Proof of Concept
1. Configure `LockPeriod = 60` seconds for `pallet-scarcity`.
2. Owner `A` holds NFT `N` at `state_nonce = 5` and signs a mortal `transfer(to: B)` with an era spanning far more than 60 seconds' worth of blocks, authorized via `AsScarcity::AsNft { instance: N, state_nonce: 5 }`.
3. The transaction is included and dispatch fails once (e.g., `B`'s purse becomes occupied between validate and dispatch); `post_dispatch_details` restores the NFT to `A` and sets `Locked::<T>::insert(A, LockInfo { retries: 1, until: now + 60 })`. [8](#0-7) 
4. `A` no longer wants to send to `B` and does not move the NFT again, so `state_nonce` stays `5`.
5. After 60 seconds, `Locked::<T>::get(A)` no longer blocks validation. [9](#0-8) 
6. A third party who retained the original signed transaction (still within its long era) rebroadcasts it; `validate` passes because `instance`/`state_nonce` still match and the lock has expired, executing the transfer to `B` without `A`'s current consent.

	fn failed_dispatch_lock(previous: Option<LockInfo>) -> LockInfo {
		let retries = previous.map(|lock| lock.retries.saturating_add(1)).unwrap_or(1);
		let exponent = retries.saturating_sub(1);
		let multiplier = 2u64.saturating_pow(u32::from(exponent).min(63));
		LockInfo {
			retries,
			until: T::UnixTime::now()
				.as_secs()
				.saturating_add(multiplier.saturating_mul(T::LockPeriod::get())),
		}
	}

	fn validate(
		&self,
		mut origin: <T as frame_system::Config>::RuntimeOrigin,
		call: &<T as frame_system::Config>::RuntimeCall,
		_info: &DispatchInfoOf<<T as frame_system::Config>::RuntimeCall>,
		_len: usize,
		_self_implicit: Self::Implicit,
		_inherited_implication: &impl Implication,
		_source: TransactionSource,
	) -> ValidateResult<Self::Val, <T as frame_system::Config>::RuntimeCall> {
		let transfer_to = match call.is_sub_type() {
			Some(Call::<T>::transfer { to }) => Some(to),
			Some(Call::<T>::burn {}) => None,
			_ => return Ok((ValidTransaction::default(), Val::NotUsing, origin)),
		};
		let Some(AsScarcityInfo::AsNft { instance, state_nonce }) = self.0.as_ref() else {
			return Ok((ValidTransaction::default(), Val::NotUsing, origin));
		};

		let Some(frame_system::Origin::<T>::Signed(owner)) = origin.as_system_ref() else {
			return Err(CustomInvalidity::OriginToAsNftMustBeSigned.into());
		};
		let owner = owner.clone();
		let now = T::UnixTime::now().as_secs();
		if let Some(lock) = Locked::<T>::get(&owner) {
			if lock.until > now {
				return Err(CustomInvalidity::NftTemporarilyLocked.into());
			}
		}
		let nft = NftsByOwner::<T>::get(&owner).ok_or(CustomInvalidity::NoNft)?;
		if nft.instance != *instance || nft.state_nonce != *state_nonce {
			return Err(CustomInvalidity::NftStateMismatch.into());
		}

	fn prepare(
		self,
		val: Self::Val,
		_origin: &<T as frame_system::Config>::RuntimeOrigin,
		_call: &<T as frame_system::Config>::RuntimeCall,
		_info: &DispatchInfoOf<<T as frame_system::Config>::RuntimeCall>,
		_len: usize,
	) -> Result<Self::Pre, TransactionValidityError> {
		match val {
			Val::NotUsing => Ok(Pre::NotUsing),
			Val::UsingNft { owner, instance, state_nonce } => {
				let nft = NftsByOwner::<T>::try_mutate_exists(
					&owner,
					|maybe_nft| -> Result<Nft, TransactionValidityError> {
						let nft = maybe_nft.as_ref().ok_or(CustomInvalidity::NoNft)?;
						if nft.instance != instance || nft.state_nonce != state_nonce {
							return Err(CustomInvalidity::NftStateMismatch.into());
						}
						// Dispatch assumes the source purse is empty. Taking the NFT here
						// prevents same-block double use and lets post-dispatch restore the exact
						// pre-state if dispatch fails.
						Ok(maybe_nft.take().expect("NFT existence checked above; qed"))
					},
				)?;
				Ok(Pre::UsingNft { owner, nft })
			},
		}
	}

	fn post_dispatch_details(
		pre: Self::Pre,
		_info: &DispatchInfoOf<<T as frame_system::Config>::RuntimeCall>,
		_post_info: &PostDispatchInfoOf<<T as frame_system::Config>::RuntimeCall>,
		_len: usize,
		result: &DispatchResult,
	) -> Result<Weight, TransactionValidityError> {
		if let Pre::UsingNft { owner, nft } = pre {
			if result.is_err() {
				NftsByOwner::<T>::insert(&owner, nft);
				Locked::<T>::insert(&owner, Self::failed_dispatch_lock(Locked::<T>::get(&owner)));
			} else {
				Locked::<T>::remove(&owner);
			}
		}
		Ok(Weight::zero())
	}
