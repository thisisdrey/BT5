### Title
Unauthenticated `/shutdown` POST to signer event-receiver permanently terminates signer event loop - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` treats any HTTP POST to `/shutdown` as a valid termination signal, setting `stop_signal` and returning `Err(EventError::Terminated)`, without checking the request body, an auth token, or the origin of the connection [1](#0-0) . This differs from the pattern used elsewhere for legitimate protection (e.g. `node_host`/`auth_password` matching between node and signer for block proposals) but the shutdown path has no equivalent check.

### Finding Description
The intended equality — that only the signer's own in-process `SignerStopSignaler::send()` should be able to trigger shutdown — is never enforced. `SignerStopSignaler::send()` connects to the receiver's own `local_addr` and POSTs a hardcoded body `"Yo. Shut this shit down!"` to `/shutdown` [2](#0-1) , but the receiver-side handler for `/shutdown` never reads or validates the body, any header, or any shared secret — it unconditionally does `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` for any POST to that path [1](#0-0) . `EventReceiver::main_loop` treats `Err(EventError::Terminated)` as a clean break out of the loop [3](#0-2) , and once `stop_signal` is set, `next_event` will keep immediately returning `Err(EventError::Terminated)` on every subsequent call via the `is_stopped()` check at the top of `next_event` [4](#0-3) , so the event receiver thread permanently exits and the signer stops processing StackerDB chunks, block-proposal responses, and burn-block events entirely.

The signer's event-receiver endpoint (default `0.0.0.0:30000` or `127.0.0.1:30000` per sample configs) is a plain HTTP listener with no authentication comparable to the node's `auth_token`/`auth_password` pairing used for block-proposal RPC [5](#0-4) . Any TCP client that can reach that port can send `POST /shutdown HTTP/1.1\r\nContent-Length: 0\r\n\r\n` and the handler code path is identical to the legitimate one, since no body length or content check occurs before storing `stop_signal = true`.

### Impact Explanation
A single unauthenticated HTTP POST permanently halts the `SignerEventReceiver`'s `main_loop`, meaning `forward_event` will never fire again [6](#0-5) . This starves the signer's runloop of new `SignerEvent`s (StackerDB chunks, block-validation responses, burn blocks), so the signer stops participating in signing decisions — a critical, single-message, unauthenticated denial-of-service against the signer process, matching the "Critical - remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
The only precondition is TCP reachability to the signer's configured `endpoint` (e.g., `0.0.0.0:30000` in the sample signer config) [7](#0-6) . No secret, key, StackerDB slot ownership, or any privileged role is required — the attacker only needs to open a socket and write a fixed-format HTTP request. This is trivially repeatable and requires only one crafted request per shutdown.

### Recommendation
Require verification before honoring `/shutdown`: e.g., check the request body against a shared secret known only to the `SignerStopSignaler` and the receiver (analogous to `auth_password`/`auth_token`), or restrict the listener to loopback-only and rely on OS-level access control, or use a local IPC mechanism (Unix socket, in-process channel) instead of an HTTP endpoint reachable over TCP for the stop signal.

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }
