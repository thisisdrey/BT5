### Title
Unauthenticated event-ingestion endpoint on the `stacks-signer` HTTP listener allows forged StackerDB/block-validation events to be injected — (File: libsigner/src/events.rs)

### Summary
The node-facing RPC endpoints in `stackslib/src/net/api/**` (`postblock_proposal.rs`, `postblock_v3.rs`, `blockreplay.rs`, `blocksimulate.rs`, `fastcallreadonly.rs`, `txsimulate.rs`) all gate sensitive requests behind an `authorization` header compared against a configured `auth_token`/password. [1](#0-0) [2](#0-1)  By contrast, the corresponding listener on the *signer* side — `SignerEventReceiver::next_event()` in `libsigner/src/events.rs` — accepts `POST /stackerdb_chunks`, `POST /proposal_response`, `POST /new_burn_block`, and `POST /new_block` with no authentication check whatsoever. [3](#0-2)  The HTTP decoding helper in `libsigner/src/http.rs` (`decode_http_request`) likewise parses headers but never inspects an `authorization`/`auth_token` value. [4](#0-3) 

### Finding Description
`SignerEventReceiver` binds an HTTP server socket (`bind()`) and, in its main receive loop, dispatches any well-formed POST body straight into `process_event::<T, E>` for deserialization into a `SignerEvent`, with zero credential check gating the dispatch. [5](#0-4)  `process_event` reads the raw body, ACKs the request, and deserializes it as JSON into the target event type (`StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, `StacksBlockEvent`) before converting it `TryInto<SignerEvent<T>>` and handing it to the signer's out-channel. [6](#0-5) 

This breaks the "authenticated vs. stored/served" equality that the rest of the node-facing surface enforces: every comparable node RPC endpoint (block proposal submission, block broadcast, replay, simulate, fast-call-read-only, tx-simulate) requires the caller to present a bearer token equal to `connection_options.auth_token` before the request body is even parsed. [7](#0-6) [8](#0-7)  The signer's event-ingestion socket — which is the mechanism by which the node pushes `StackerDBChunksEvent`/`BlockValidateResponse`/block/burn-block events to the `stacks-signer` process (`sample/conf/testnet-miner-conf.toml` shows this is configured as a network-reachable `events_observer` endpoint, not a Unix socket) [9](#0-8)  — has no equivalent gate. Any client that can reach the configured `endpoint` (e.g. `127.0.0.1:30000`, but operators can and do bind these more broadly, and the `auth_token` config comment states it "secures the communication channel between this node and a connected stacks-signer instance", implying it was intended to protect exactly this channel) can POST directly to `/stackerdb_chunks` or `/proposal_response` and have the payload accepted and forwarded into the signer runloop as if it came from the trusted node.

I was unable to fully verify, within the available index, whether the downstream `TryInto<SignerEvent<T>>` conversion for `StackerDBChunksEvent`/`BlockValidateResponse` re-validates chunk signatures or block-validation-response provenance before use — the `stacks-signer/src/v0/messages.rs` file that likely contains this conversion was not present in the indexed content, so I cannot state with certainty whether a forged event is caught by a secondary check inside the (out-of-scope) signer decision logic. What is certain and in-scope is that the transport-layer gate itself — the piece analogous to Kylin's authentication bypass — is absent on this endpoint while present on every structurally similar node RPC endpoint.

### Impact Explanation
This matches the "auth-gate that fails open" analog class explicitly called out as in-scope: unauthenticated network input is accepted and forwarded into the signer's internal event stream, which drives block-validation-response and StackerDB-chunk-event processing. Even bounded to the transport layer, this is an unauthenticated write to signer-process state (its inbound event channel) from an untrusted network peer, satisfying the "unauthenticated/unauthorized write to state" criterion.

### Likelihood Explanation
Exploitation only requires network reachability to the signer's bound listener address and the ability to send a well-formed HTTP POST with a JSON body matching one of the four recognized event schemas — no cryptographic material, node secret, or `auth_token` is needed, since none is checked in `next_event()`. The `main_loop()`/`is_stopped()` design further shows this is a long-running listener meant to keep processing arbitrary incoming POSTs at these paths. [10](#0-9) 

### Recommendation
Add the same bearer-token check used by `stackslib/src/net/api/*` handlers (compare the `authorization` header against the configured `auth_token`) inside `SignerEventReceiver::next_event()` / `process_event()` before accepting `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` payloads, returning `401 Unauthorized` on mismatch or missing header, mirroring `blockreplay.rs`/`fastcallreadonly.rs`.

### Proof of Concept
Given a running signer with `SignerEventReceiver` bound to `HOST:PORT` (per `sample/conf/testnet-miner-conf.toml`, e.g. `127.0.0.1:30000`), an attacker with network access sends, with no credentials:
```
POST /stackerdb_chunks HTTP/1.1
Host: HOST:PORT
Content-Type: application/json
Content-Length: <n>

{"contract_id": "...", "modified_slots": [ ... attacker-forged chunk ... ]}
```
This matches the mock "node" traffic pattern already exercised in `libsigner/src/tests/mod.rs::test_simple_signer`, which shows the exact request the receiver accepts and forwards without any authentication header being sent or checked. [11](#0-10)

```rust
    /// Main loop for the receiver.
    /// Typically, this is started in a separate thread.
    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {
                info!("Event receiver stopped");
                break;
            }
            let next_event = match self.next_event() {
                Ok(event) => event,
                Err(EventError::UnrecognizedEvent(..)) => {
                    // got an event that we don't care about (not a problem)
                    continue;
                }
                Err(EventError::Terminated) => {
                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };
            if !self.forward_event(next_event) {
                info!("Failed to forward event");
                break;
            }
        }
        info!("Event receiver main loop exit");
    }
}
```

```rust
    /// Errors are recoverable -- the caller should call this method again even if it returns an
    /// error.
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
```

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```

```rust
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}
```
