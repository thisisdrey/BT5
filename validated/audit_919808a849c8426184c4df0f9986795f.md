The reported issue concerns `shrine`'s `derivation_endpoint` plugin comparing URL signatures with a non-constant-time `==` instead of a timing-safe compare. Searching the analogous Go standard library code for similar signature/MAC verification logic shows the opposite: every relevant comparison path already uses constant-time primitives correctly.

- `crypto/hmac.Equal` explicitly documents the timing-attack risk and delegates to `subtle.ConstantTimeCompare` [1](#0-0) .
- `crypto/subtle.ConstantTimeCompare` and the FIPS-internal implementation perform length/content comparison without early-exit content branching [2](#0-1) .
- TLS record MAC verification in `halfConn.decrypt` combines MAC and padding checks via `subtle.ConstantTimeCompare` and `ConstantTimeSelect` specifically to avoid timing side channels between bad-MAC and bad-padding cases [3](#0-2) .
- RSA PKCS#1v1.5/PSS verification paths use `bytes.Equal` only on values that are not attacker-adjustable secrets in a way that creates an exploitable timing side channel for guessing a secret (they compare computed digests/encoded messages, not a secret token derived independently of the input) [4](#0-3) .

There is no equivalent to Shrine's custom, application-level "generate a keyed signature and compare with a naive `==`" pattern anywhere reachable via an unauthenticated Go stdlib HTTP/TLS entry point in this repository — the stdlib's own signature/MAC verification call sites already use `crypto/subtle` or `crypto/hmac.Equal`. Since no unpatched, reachable constant-time-comparison flaw analogous to CVE-2020-15237 exists in this codebase, this report does not translate into a valid finding here.

```go
// ConstantTimeCompare returns 1 if the two slices, x and y, have equal contents
// and 0 otherwise. The time taken is a function of the length of the slices and
// is independent of the contents. If the lengths of x and y do not match it
// returns 0 immediately.
func ConstantTimeCompare(x, y []byte) int {
	if len(x) != len(y) {
		return 0
	}

	var v byte

	for i := 0; i < len(x); i++ {
		v |= x[i] ^ y[i]
	}

	return constanttime.ByteEq(v, 0)
}
```
