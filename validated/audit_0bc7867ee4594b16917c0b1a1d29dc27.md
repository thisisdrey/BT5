Audit Report

## Title
On-demand spot-traffic decay formula omits the base term, letting an attacker crash blockspace pricing to near-floor with a single call - (File: `polkadot/runtime/parachains/src/on_demand/mod.rs`)

## Summary
`Pallet::calculate_spot_traffic` computes the multiplicative update applied to `traffic`, which directly scales `spot_price` in `do_place_order`. The increasing branch correctly implements `traffic * (1 + diff + diff²/2)`, but the decreasing branch omits the `1 +`/`1 -` base term and instead computes `traffic * (diff − diff²/2)`, directly multiplying by the raw deviation rather than a near-unity multiplier centered at 1. [1](#0-0) 

## Finding Description
The negative (below-target) branch reads:
```rust
let new_traffic = queue_util_diff.saturating_sub(div_by_two).saturating_mul(traffic);
```
with no `One::one()` term, while the positive branch correctly adds `One::one()` before multiplying by `traffic`. [2](#0-1)  This mirrors `pallet_transaction_payment`'s `TargetedFeeAdjustment` design intent of `previous * (1 ± t1 + t2)`, but the on-demand pallet's negative branch instead multiplies `traffic` by the bare deviation magnitude `diff − diff²/2`, which for typical small `diff` values (e.g. 0.1) collapses `traffic` to roughly `traffic * diff` — a large single-step drop instead of a mild reduction. The existing tests (`spot_traffic_can_decrease`, `spot_traffic_decreases_over_time`) only exercise `diff = 1.0` with `variability = 100%`, where `diff − diff²/2 = 1 − diff + diff²/2 = 0.5` numerically coincide, masking the asymmetry for any partial `diff`. [3](#0-2) 

`traffic` is used unconditionally to scale `spot_price` in `do_place_order`, which gates pricing for the public, unprivileged extrinsics `place_order_allow_death`/`place_order_with_credits`, so this defect is directly reachable and exploitable without any privileged role.

## Impact Explanation
The bug causes the decay path of the on-demand congestion-pricing mechanism to crash `traffic` toward the configured floor (`TrafficDefaultValue`) far faster than intended whenever the queue is even mildly under-utilized. This degrades the anti-congestion economics of on-demand blockspace pricing, allowing underpriced consumption of blockspace shortly after congestion — matching the "public underpriced work that degrades block production" impact category permitted by the program scope.

## Likelihood Explanation
No privileged, validator, governance, or off-chain/relayer capability is needed. Any account can observe queue state and simply avoid placing orders for a block (or wait for existing orders to drain) to push utilization below target, triggering the negative branch and its outsized traffic decay, then place cheap orders. This is trivially and repeatably reproducible using only public dispatchables.

## Recommendation
Fix the decreasing branch to mirror the increasing branch, centering the multiplier at `1`:
```rust
let new_traffic = One::one()
    .saturating_sub(queue_util_diff)
    .saturating_add(div_by_two)
    .saturating_mul(traffic);
```
Add regression tests with `diff < 1` and `variability < 100%` (partial under-utilization) to catch this asymmetry, and audit whether `var_times_qud` (variability-scaled diff) should be used instead of raw `queue_util_diff` in both branches for consistency with the documented `p/(k*(1-s))` semantics.

## Proof of Concept
Using `calculate_spot_traffic(traffic=100, queue_capacity=100, queue_size=40, target_queue_utilisation=50%, variability=100%)`:
- `queue_util_diff = 0.1`, `var_times_qud = 0.1`, `div_by_two ≈ 0.005`.
- Buggy result: `new_traffic = (0.1 − 0.005) * 100 ≈ 9.5` (≈90% instantaneous collapse).
- Intended result: `new_traffic = (1 − 0.1 + 0.005) * 100 ≈ 90.5` (mild ~10% reduction).

This can be verified directly against the current implementation: [4](#0-3) , and contrasted with the existing test cases that only cover `diff=1.0`: [5](#0-4)

	fn calculate_spot_traffic(
		traffic: FixedU128,
		queue_capacity: u32,
		queue_size: u32,
		target_queue_utilisation: Perbill,
		variability: Perbill,
	) -> Result<FixedU128, SpotTrafficCalculationErr> {
		// Return early if queue has no capacity.
		if queue_capacity == 0 {
			return Err(SpotTrafficCalculationErr::QueueCapacityIsZero);
		}

		// Return early if queue size is greater than capacity.
		if queue_size > queue_capacity {
			return Err(SpotTrafficCalculationErr::QueueSizeLargerThanCapacity);
		}

		// (queue_size / queue_capacity) - target_queue_utilisation
		let queue_util_ratio = FixedU128::from_rational(queue_size.into(), queue_capacity.into());
		let positive = queue_util_ratio >= target_queue_utilisation.into();
		let queue_util_diff = queue_util_ratio.max(target_queue_utilisation.into()) -
			queue_util_ratio.min(target_queue_utilisation.into());

		// variability * queue_util_diff
		let var_times_qud = queue_util_diff.saturating_mul(variability.into());

		// variability^2 * queue_util_diff^2
		let var_times_qud_pow = var_times_qud.saturating_mul(var_times_qud);

		// (variability^2 * queue_util_diff^2)/2
		let div_by_two: FixedU128;
		match var_times_qud_pow.const_checked_div(2.into()) {
			Some(dbt) => div_by_two = dbt,
			None => return Err(SpotTrafficCalculationErr::Division),
		}

		// traffic * (1 + queue_util_diff) + div_by_two
		if positive {
			let new_traffic = queue_util_diff
				.saturating_add(div_by_two)
				.saturating_add(One::one())
				.saturating_mul(traffic);
			Ok(new_traffic.max(<T as Config>::TrafficDefaultValue::get()))
		} else {
			let new_traffic = queue_util_diff.saturating_sub(div_by_two).saturating_mul(traffic);
			Ok(new_traffic.max(<T as Config>::TrafficDefaultValue::get()))
		}
	}

#[test]
fn spot_traffic_can_decrease() {
	let traffic = FixedU128::from_u32(100u32);
	match OnDemand::calculate_spot_traffic(
		traffic,
		100u32,
		0u32,
		Perbill::from_percent(100),
		Perbill::from_percent(100),
	) {
		Ok(new_traffic) => {
			assert_eq!(new_traffic, FixedU128::from_inner(50_000_000_000_000_000_000u128))
		},
		_ => panic!("Error"),
	}
}

#[test]
fn spot_traffic_decreases_over_time() {
	let mut traffic = FixedU128::from_u32(100u32);
	for _ in 0..5 {
		traffic = OnDemand::calculate_spot_traffic(
			traffic,
			100u32,
			0u32,
			Perbill::from_percent(100),
			Perbill::from_percent(100),
		)
		.unwrap();
		println!("{traffic}");
	}
	assert_eq!(traffic, FixedU128::from_inner(3_125_000_000_000_000_000u128))
}
