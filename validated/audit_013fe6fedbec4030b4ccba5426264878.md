### Title
Unbounded pending-handshake resource exhaustion via unauthenticated stage-1 handshake packets - (File: handshake_manager.go)

### Summary
`HandshakeManager.beginHandshake` runs the full Noise responder handshake processing (`machine.ProcessPacket`) for *any* incoming stage-1 (`h.MessageCounter == 1`) packet before any certificate/authentication check succeeds, and if the multi-message/certificate paths are incomplete it still consumes CPU and, on success paths, allocates a new `HostInfo`/index. There is no minimum-cost, no per-source rate limit, and no cap on the number of concurrent pending handshakes tracked in `hm.vpnIps` / `hm.indexes`. This mirrors the `StakePet::create` bug class: an operation reachable by an unauthenticated party with no real cost limit lets an attacker inflate an internal collection that other code later has to fully iterate, risking resource exhaustion / DoS instead of an out-of-gas revert.

### Finding Description
`HandshakeManager.HandleIncoming` routes any packet with `h.MessageCounter == 1` and `h.RemoteIndex == 0` directly into `beginHandshake`, gated only by `AllowUnknownVpnAddr` (an IP allow-list check, not authentication) and subtype validation. [1](#0-0) 

`beginHandshake` then builds a responder `handshake.Machine` and calls `machine.ProcessPacket`, and — for the successful IX single-message case — allocates a brand-new `HostInfo`, calls `generateIndex`, and eventually calls `hm.CheckAndComplete`, which inserts the new pending/host entry. [2](#0-1) [3](#0-2) 

Because any unauthenticated peer can send a stage-1 packet with a spoofed source address and an arbitrary claimed VPN identity, an attacker can drive the creation of many entries in the pending handshake maps `hm.vpnIps` and `hm.indexes` maintained by `HandshakeManager`. [4](#0-3) 

There is no minimum cost, proof-of-work, or bound on how many pending handshakes can exist simultaneously — the only cleanup is the retry/timeout path in `handleOutbound`/`NextOutboundHandshakeTimerTick`, which runs on a fixed ticker and only reaps entries after `hm.config.retries` attempts have elapsed, not immediately. [5](#0-4) 

These unbounded maps are then fully iterated by `ForEachVpnAddr`/`ForEachIndex`, which are used for control-plane and SSH debug operations such as `list-pending-hostmap` (`ListHostmapHosts(true)` / `ListHostmapIndexes(true)`), each of which walks every entry under a lock. [6](#0-5) [7](#0-6) [8](#0-7) 

This is structurally the same bug class as `StakePet::create`: a state-mutating entry point has no minimum cost to the caller, so an attacker can grow an internal collection to a size that later strains an all-elements iteration function (`buryAllDeadPets`/`getDeadNonBuriedPets` there; `listHostMapHosts`/`listHostMapIndexes`, `EmitStats`, and any future all-pending-handshake sweep here).

### Impact Explanation
An attacker with no valid certificate can repeatedly spam forged/garbage stage-1 handshake packets (spoofed source UDP addresses, arbitrary claimed VPN IPs) to cause the node to run Noise `ProcessPacket` work and, when a message parses far enough, insert entries into `hm.vpnIps`/`hm.indexes` under the `HandshakeManager` mutex. Sustained abuse grows memory usage of these maps and increases the lock-held duration of `ForEachVpnAddr`/`ForEachIndex`/`EmitStats`, which are on the hot path for SSH debugging and control operations, potentially degrading availability of the handshake manager (lock contention affects `HandleIncoming`, `handleOutbound`, `StartHandshake`, all of which take `hm.Lock()`/`hm.RLock()`). This is a remote resource-exhaustion / degraded-availability finding rather than a full crash guarantee, since Go maps growing large do not directly OOM-crash the process the way an EVM out-of-gas revert would, but the underlying root cause (unbounded, low-cost state creation reachable pre-authentication, later fully iterated) is the same as the reported bug class.

### Likelihood Explanation
High: reaching `beginHandshake` requires no certificate, no successful handshake, and no valid VPN membership — only passing the coarse `AllowUnknownVpnAddr` allow-list check (which is unset/open by default in most configurations) and a well-formed stage-1 header. An attacker can trivially script mass stage-1 packet generation from spoofed UDP sources.

### Recommendation
Introduce a cost/rate bound on pending-handshake creation analogous to the `StakePet` fix (minimum deposit): e.g., cap the number of concurrent pending entries in `hm.vpnIps`/`hm.indexes` per source or globally, add a lightweight per-source rate limiter before invoking `machine.ProcessPacket` in `beginHandshake`, and/or require a cheap proof-of-work or cookie exchange before allocating a `HostInfo` and index for unauthenticated stage-1 packets.

### Proof of Concept
Not independently reproduced against a running node in this analysis (no execution environment available). Conceptually: repeatedly call `myControl.InjectUDPPacket` (as used in `e2e/handshakes_test.go`, e.g. `TestHandshakeUnknownSubtype`) with well-formed stage-1 packets (`h.MessageCounter == 1`, `h.RemoteIndex == 0`) from many distinct spoofed source addresses/claimed VPN IPs, then observe `ListHostmapHosts(true)`/`ListHostmapIndexes(true)` growth via `EmitStats`/`hostmap.pending.hosts` metrics as in the existing test harness pattern. func (hm *HandshakeManager) NextOutboundHandshakeTimerTick(now time.Time) {
	hm.OutboundHandshakeTimer.Advance(now)
	for {
		vpnIp, has := hm.OutboundHandshakeTimer.Purge()
		if !has {
			break
		}
		hm.handleOutbound(vpnIp, false)
	}
}

func (hm *HandshakeManager) handleOutbound(vpnIp netip.Addr, lighthouseTriggered bool) {
	hh := hm.queryVpnIp(vpnIp)
	if hh == nil {
		return
	}
	hh.Lock()
	defer hh.Unlock()

	hostinfo := hh.hostinfo
	// If we are out of time, clean up
	if hh.counter >= hm.config.retries {
		fields := []any{
			"udpAddrs", hh.hostinfo.remotes.CopyAddrs(hm.mainHostMap.GetPreferredRanges()),
			"initiatorIndex", hh.hostinfo.localIndexId,
			"durationNs", time.Since(hh.startTime).Nanoseconds(),
		}
		// hh.machine can be nil here if buildStage0Packet never succeeded
		// (e.g., no certificate available). In that case there's no useful
		// handshake metadata to log.
		if hh.machine != nil {
			fields = append(fields, "handshake", m{
				"stage": uint64(hh.machine.MessageIndex()),
				"style": header.SubTypeName(header.Handshake, hh.machine.Subtype()),
			})
		}
		hh.hostinfo.logger(hm.l).Info("Handshake timed out", fields...)
		hm.metricTimedOut.Inc(1)
		hm.DeleteHostInfo(hostinfo)
		return
	}

func (hm *HandshakeManager) beginHandshake(via ViaSender, packet []byte, h *header.H) {
	f := hm.f
	cs := f.pki.getCertState()

	v := cs.DefaultVersion()
	if cs.GetCredential(v) == nil {
		f.l.Error("Unable to handshake with host because no certificate is available",
			"from", via, "certVersion", v)
		return
	}

	machine, err := handshake.NewMachine(
		v, cs.GetCredential,
		hm.certVerifier(), func() (uint32, error) { return generateIndex(f.l) },
		false, header.HandshakeIXPSK0,
	)
	if err != nil {
		f.l.Error("Failed to create handshake machine", "from", via, "error", err)
		return
	}

	response, result, err := machine.ProcessPacket(nil, packet)
	if err != nil {
		f.l.Error("Failed to process handshake packet", "from", via, "error", err)
		return
	}

func TestHandshakeUnknownSubtype(t *testing.T) {
	t.Parallel()
	// A handshake packet with an unknown subtype should be silently dropped.

	ca, _, caKey, _ := cert_test.NewTestCaCert(cert.Version1, cert.Curve_CURVE25519, time.Now(), time.Now().Add(10*time.Minute), nil, nil, []string{})
	myControl, _, myUdpAddr, _ := newSimpleServer(cert.Version1, ca, caKey, "me", "10.128.0.1/24", nil)
	theirControl, _, theirUdpAddr, _ := newSimpleServer(cert.Version1, ca, caKey, "them", "10.128.0.2/24", nil)

	myControl.Start()
	theirControl.Start()

	t.Log("Inject handshake with unknown subtype 99")
	myControl.InjectUDPPacket(makeHandshakePacket(theirUdpAddr, myUdpAddr, header.MessageSubType(99), 0, 1))

	t.Log("Verify no tunnels or pending handshakes")
	assert.Empty(t, myControl.ListHostmapHosts(false))
	assert.Empty(t, myControl.ListHostmapHosts(true))

	t.Log("Verify no UDP response was sent")
	time.Sleep(100 * time.Millisecond)
	assert.Nil(t, myControl.GetFromUDP(false))

	myControl.Stop()
	theirControl.Stop()
}
