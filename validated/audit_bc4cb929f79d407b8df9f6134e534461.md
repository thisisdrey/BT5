**Analysis:**

`force_batch` charges weight identically to `batch`/`batch_all`: the `#[pallet::weight]` annotation calls `Pallet::<T>::weight_and_dispatch_class(&calls)`, which sums each nested call's declared `call_weight` from `get_dispatch_info()` for every call in the batch, then adds `T::WeightInfo::force_batch(calls.len())` for the per-item overhead [1](#0-0) . This weight is charged pre-dispatch by the transaction extension before any of the nested calls execute, so the block producer already accounts for the worst-case cost of every nested call before doing the work [2](#0-1) .

The number of calls is also bounded by `batched_calls_limit`, which is derived from the allocator limit and the call enum size, preventing unbounded memory/loop blow-up regardless of duplicate or adversarial ordering [3](#0-2) [4](#0-3) .

Inside the loop, `force_batch` also tracks and refunds the *actual* weight used per call via `extract_actual_weight`, and the final `Ok(Some(base_weight.saturating_add(weight)).into())` reflects the true cost so the extrinsic's post-dispatch weight correction is accurate rather than underpriced [5](#0-4) .

Any "underpriced public auth work" (e.g., proxy announcements, multisig approvals, preimage note/unnote, recovery friends) would have to originate from an incorrect weight annotation in the *target* pallet's own dispatchable, not from `force_batch` itself — `force_batch` simply sums whatever weight those pallets declare for their own calls. It applies the caller's origin filters just like `batch`/`batch_all` (bypassing filters only for Root, which is intended and matches root's existing unrestricted authority) [6](#0-5) , so it does not widen origin or bypass auth checks beyond what root/signed dispatch already permits. No duplicate-guard bypass, storage-growth amplification, or origin-widening specific to `force_batch` was found; the weight-accounting pattern is identical to `batch` and `batch_all`, which are already exposed to unprivileged origins in the same way.

		fn weight_and_dispatch_class(
			calls: &[<T as Config>::RuntimeCall],
		) -> (Weight, DispatchClass) {
			if calls.is_empty() {
				return (Weight::zero(), DispatchClass::Normal);
			}

			let dispatch_infos = calls.iter().map(|call| call.get_dispatch_info());
			let (dispatch_weight, dispatch_class) = dispatch_infos.fold(
				(Weight::zero(), DispatchClass::Operational),
				|(total_weight, dispatch_class): (Weight, DispatchClass), di| {
					(
						total_weight.saturating_add(di.call_weight),
						// If not all are `Operational`, we want to use `DispatchClass::Normal`.
						if di.class == DispatchClass::Normal { di.class } else { dispatch_class },
					)
				},
			);

			(dispatch_weight, dispatch_class)
		}
