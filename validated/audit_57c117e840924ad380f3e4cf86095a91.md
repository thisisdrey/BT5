### Title
Full-cycle SR vote rewards can be claimed for votes cast only in the last block of a cycle - ([File: chainbase/src/main/java/org/tron/core/service/MortgageService.java])

### Summary
The vote-reward accounting in `MortgageService`/`VoteRewardUtil` (used by `WithdrawBalanceContract`, `WithdrawRewardProcessor`, `UnfreezeBalanceActuator`, `UnfreezeBalanceV2Actuator`, and TVM `withdrawReward`) pays a user `deltaVi(beginCycle-1, endCycle-1) * userVoteCount`, where `userVoteCount` is the *final* vote weight recorded for the account, with no time-weighting for how long that vote weight was actually held during the cycle. `VoteWitnessActuator` lets any account instantly change its vote allocation at any block, with no minimum holding period. This mirrors the NovaBox root cause: a reward/dividend value is computed against a share size that was only briefly true, instead of the share actually held for the period being rewarded.

### Finding Description
`VoteWitnessActuator.countVoteAccount()` settles any pending reward for the account's *old* votes via `mortgageService.withdrawReward(ownerAddress)` and then immediately overwrites `accountCapsule`'s votes with the new allocation, with no delay or partial-cycle proration. [1](#0-0) 

At the end of a cycle, `MaintenanceManager.doMaintenance()` aggregates `votesStore` into per-witness vote totals (`countWitness`) that reflect whatever votes are on record *at that instant*, and this total is what `delegationStore.setWitnessVote(nextCycle, ...)` and the Vi/reward accumulation use for the cycle. [2](#0-1) 

The reward itself is then computed strictly as a delta-Vi times the account's recorded vote count for the whole `[beginCycle, endCycle)` span — there is no mechanism that reduces the reward for votes that were only in place for a fraction of the cycle: [3](#0-2) [4](#0-3) 

Because `VoteWitnessContract` execution is instantaneous (no freeze/lock delay is required to change *votes*, only to change frozen principal), an account can wait until immediately before a maintenance/cycle boundary, cast a large vote (using `getAllTronPower()`/`getTronPower()` from TRX it already has frozen for bandwidth/energy or TRON_POWER — no new freeze needed), let `doMaintenance()` snapshot that vote into the closing cycle's totals, then call `withdrawReward`/`WithdrawBalanceContract` in the very next block to collect the *entire* cycle's SR block+fee reward proportional to that vote weight, and finally revert the vote in the following transaction. This is functionally identical to the NovaBox bug class: a large "deposit" (vote) is registered just before a dividend snapshot is taken and calculated using a full-period reward rate, producing reward disproportionate to the actual time the stake was committed, draining the SR/vote reward pool.

### Impact Explanation
This allows continuous, repeatable extraction of block and transaction-fee rewards from the shared SR reward pool by unprivileged accounts that never genuinely participate in governance for a full cycle, at the expense of legitimate long-term voters whose effective share of rewards is diluted every cycle by this last-block vote stuffing. Because this can be repeated every maintenance cycle, it constitutes ongoing unauthorized diversion of reward funds (theft of funds / unbacked reward payout), reachable purely through signed `VoteWitnessContract` and `WithdrawBalanceContract`/`WithdrawRewardContract` transactions.

### Likelihood Explanation
Any account with existing frozen TRX (for bandwidth/energy or TRON_POWER) already possesses the tron power needed; no flash loan primitive is required on TRON since resource-frozen balance already grants voting power via `getAllTronPower()`. The only requirement is timing a `VoteWitnessContract` transaction to land in the last block(s) before `nextMaintenanceTime`, which is public/predictable, and then withdrawing/re-voting in subsequent blocks. This is straightforward to script and repeat every cycle.

### Recommendation
Time-weight (or otherwise prorate) reward accrual within `MortgageService`/`VoteRewardUtil` so that a vote's weight for a given cycle's Vi calculation reflects the fraction of the cycle it was actually held (e.g., using a checkpoint of vote weight at the *start* of the cycle rather than allowing changes right before `doMaintenance` to count for the full closing cycle), or enforce a minimum holding period before a newly cast/increased vote counts toward the current cycle's reward distribution.

### Proof of Concept
1. Account A already has frozen TRX (bandwidth/energy or TRON_POWER) worth `X` tron power, currently voting 0 or a small amount.
2. Immediately before `nextMaintenanceTime` (visible on-chain via `DynamicPropertiesStore`), A submits `VoteWitnessContract` allocating all `X` tron power to witness `W` — processed by `VoteWitnessActuator.countVoteAccount()`. [5](#0-4) 
3. The block containing this vote crosses `nextMaintenanceTime`, triggering `MaintenanceManager.applyBlock() -> doMaintenance()`, which folds A's full `X` vote into witness `W`'s vote total for the closing cycle. [6](#0-5) 
4. In the following block, A submits `WithdrawBalanceContract` (or TVM `withdrawReward`), and `MortgageService.withdrawReward`/`computeReward` pays A `deltaVi * X` for the entire cycle just closed, even though A's vote was registered for only the final block(s) of that cycle. [7](#0-6) 
5. A then reallocates votes away from `W` and repeats the sequence at the next cycle boundary, continually extracting full-cycle rewards for near-zero holding time.

  private void countVoteAccount(VoteWitnessContract voteContract) {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    VotesStore votesStore = chainBaseManager.getVotesStore();
    MortgageService mortgageService = chainBaseManager.getMortgageService();
    byte[] ownerAddress = voteContract.getOwnerAddress().toByteArray();

    VotesCapsule votesCapsule;

    //
    mortgageService.withdrawReward(ownerAddress);

    AccountCapsule accountCapsule = accountStore.get(ownerAddress);

    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    if (dynamicStore.supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    if (!votesStore.has(ownerAddress)) {
      votesCapsule = new VotesCapsule(voteContract.getOwnerAddress(),
          accountCapsule.getVotesList());
    } else {
      votesCapsule = votesStore.get(ownerAddress);
    }

    accountCapsule.clearVotes();
    votesCapsule.clearNewVotes();

    voteContract.getVotesList().forEach(vote -> {
      logger.debug("countVoteAccount, address[{}]",
          ByteArray.toHexString(vote.getVoteAddress().toByteArray()));

      votesCapsule.addNewVotes(vote.getVoteAddress(), vote.getVoteCount());
      accountCapsule.addVotes(vote.getVoteAddress(), vote.getVoteCount());
    });

    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    votesStore.put(ownerAddress, votesCapsule);
  }

  public void withdrawReward(byte[] address) {
    if (!dynamicPropertiesStore.allowChangeDelegation()) {
      return;
    }
    AccountCapsule accountCapsule = accountStore.get(address);
    long beginCycle = delegationStore.getBeginCycle(address);
    long endCycle = delegationStore.getEndCycle(address);
    long currentCycle = dynamicPropertiesStore.getCurrentCycleNumber();
    long reward = 0;
    if (beginCycle > currentCycle || accountCapsule == null) {
      return;
    }
    if (beginCycle == currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        return;
      }
    }
    //withdraw the latest cycle reward
    if (beginCycle + 1 == endCycle && beginCycle < currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        reward = computeReward(beginCycle, endCycle, account);
        adjustAllowance(address, reward);
        reward = 0;
        logger.info("Latest cycle reward {}, {}.", beginCycle, account.getVotesList());
      }
      beginCycle += 1;
    }
    //
    endCycle = currentCycle;
    if (CollectionUtils.isEmpty(accountCapsule.getVotesList())) {
      delegationStore.setBeginCycle(address, endCycle + 1);
      return;
    }
    if (beginCycle < endCycle) {
      reward += computeReward(beginCycle, endCycle, accountCapsule);
      adjustAllowance(address, reward);
    }
    delegationStore.setBeginCycle(address, endCycle);
    delegationStore.setEndCycle(address, endCycle + 1);
    delegationStore.setAccountVote(endCycle, address, accountCapsule);
    logger.info("Adjust {} allowance {}, now currentCycle {}, beginCycle {}, endCycle {}, "
            + "account vote {}.", Hex.toHexString(address), reward, currentCycle,
        beginCycle, endCycle, accountCapsule.getVotesList());
  }

  private long computeReward(long beginCycle, long endCycle, AccountCapsule accountCapsule) {
    if (beginCycle >= endCycle) {
      return 0;
    }

    long reward = 0;
    long newAlgorithmCycle = dynamicPropertiesStore.getNewRewardAlgorithmEffectiveCycle();
    List<Pair<byte[], Long>> srAddresses = accountCapsule.getVotesList().stream()
        .map(vote -> new Pair<>(vote.getVoteAddress().toByteArray(), vote.getVoteCount()))
        .collect(Collectors.toList());
    if (beginCycle < newAlgorithmCycle) {
      long oldEndCycle = min(endCycle, newAlgorithmCycle,
          dynamicPropertiesStore.disableJavaLangMath());
      reward = getOldReward(beginCycle, oldEndCycle, srAddresses);
      beginCycle = oldEndCycle;
    }
    if (beginCycle < endCycle) {
      for (Pair<byte[], Long>  vote : srAddresses) {
        byte[] srAddress = vote.getKey();
        BigInteger beginVi = delegationStore.getWitnessVi(beginCycle - 1, srAddress);
        BigInteger endVi = delegationStore.getWitnessVi(endCycle - 1, srAddress);
        BigInteger deltaVi = endVi.subtract(beginVi);
        if (deltaVi.signum() <= 0) {
          continue;
        }
        long userVote = vote.getValue();
        reward += deltaVi.multiply(BigInteger.valueOf(userVote))
            .divide(DelegationStore.DECIMAL_OF_VI_REWARD).longValue();
      }
    }
    return reward;

  private static long computeReward(long beginCycle, long endCycle,
                                    AccountCapsule accountCapsule, Repository repository) {
    if (beginCycle >= endCycle) {
      return 0;
    }

    long reward = 0;
    for (Protocol.Vote vote : accountCapsule.getVotesList()) {
      byte[] srAddress = vote.getVoteAddress().toByteArray();
      BigInteger beginVi = repository.getDelegationStore().getWitnessVi(beginCycle - 1, srAddress);
      BigInteger endVi = repository.getDelegationStore().getWitnessVi(endCycle - 1, srAddress);
      BigInteger deltaVi = endVi.subtract(beginVi);
      if (deltaVi.signum() <= 0) {
        continue;
      }
      long userVote = vote.getVoteCount();
      reward += deltaVi.multiply(BigInteger.valueOf(userVote))
          .divide(DelegationStore.DECIMAL_OF_VI_REWARD).longValue();
    }
    return reward;
  }
