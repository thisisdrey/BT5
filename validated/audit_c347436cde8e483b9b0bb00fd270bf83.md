The libcontainer/runc CVE concerns Linux capability inheritance (`inheritable`/`ambient` capability sets) being incorrectly propagated to a new "tenant" process (`exec`-created process joining an existing container) without properly filtering against the original container's capability set — a container-runtime `exec` mechanism. Bazel has no analogous concept: it does not create tenant processes inside a shared container with inheritable/ambient Linux capabilities, and its `linux-sandbox` (`src/main/tools/linux-sandbox-pid1.cc`, `src/main/tools/linux-sandbox.cc`) uses namespace isolation and uid/gid mapping rather than POSIX capability-set inheritance for privilege management [1](#0-0) .

Per the scan rules, this class also reduces to a sandbox-as-security-boundary/local-execution-privilege scenario rather than a fetch/cache/lockfile/credential integrity bypass reachable from unprivileged, attacker-published content (archives, registry data, URLs, etc.), so it is out of scope for the required Bazel surfaces (fetch/integrity, caches, extraction, repository rules, bzlmod/lockfile, credentials, cache keying, output materialization, input staging) [2](#0-1) . No reachable, attacker-published-content path exists in Bazel that mirrors the runc/libcontainer capability-elevation bug class.

  // Disable needs for CAP_SETGID.
  struct stat sb;
  if (stat("/proc/self/setgroups", &sb) == 0) {
    WriteFile("/proc/self/setgroups", "deny");
  } else {
    // Ignore ENOENT, because older Linux versions do not have this file (but
    // also do not require writing to it).
    if (errno != ENOENT) {
      DIE("stat(/proc/self/setgroups");
    }
  }

  uid_t inner_uid;
  gid_t inner_gid;
  if (opt.fake_root) {
    // Change our username to 'root'.
    inner_uid = 0;
    inner_gid = 0;
  } else if (opt.fake_username) {
    // Change our username to 'nobody'.
    struct passwd pwd;
    char buf[1024];
    size_t buflen = sizeof(buf);
    struct passwd* result;
    if (getpwnam_r("nobody", &pwd, buf, buflen, &result) != 0 ||
        result == nullptr) {
      DIE("getpwnam_r for nobody failed");
    }

    inner_uid = pwd.pw_uid;
    inner_gid = pwd.pw_gid;
  } else {
    // Do not change the username inside the sandbox.
    inner_uid = global_outer_uid;
    inner_gid = global_outer_gid;
  }
  if (opt.enable_pty) {
    // Change the group to "tty" regardless of what was previously set
    struct group grp;
    char buf[256];
    size_t buflen = sizeof(buf);
    struct group* result;
    getgrnam_r("tty", &grp, buf, buflen, &result);
    if (result == nullptr) {
      DIE("getgrnam_r");
    }
    inner_gid = grp.gr_gid;
  }

  WriteFile("/proc/self/uid_map", "%u %u 1\n", inner_uid, global_outer_uid);
  WriteFile("/proc/self/gid_map", "%u %u 1\n", inner_gid, global_outer_gid);
}
