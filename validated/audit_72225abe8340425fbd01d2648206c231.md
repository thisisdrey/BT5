### Title
Unauthenticated `POST /shutdown` on signer event-receiver permanently halts `main_loop` - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` checks only that a request is a `POST` before dispatching to the URL switch, so any TCP client that can reach the event-receiver's bound HTTP port can send `POST /shutdown` and permanently set `stop_signal`, terminating the signer's event-processing loop with no credential check of any kind.

### Finding Description
In `next_event`, the only per-request check applied before path dispatch is `request.method() != &HttpMethod::Post` [1](#0-0) . There is no shared-secret, token, or peer-identity check anywhere in this function — the `/status` branch is unauthenticated by design, and the remaining branches (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, `/shutdown`) are reached solely by matching `request.url()` as a plain string after the generic POST check [2](#0-1) . Reaching `/shutdown` requires nothing beyond `POST /shutdown` over HTTP/1.1: `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` [3](#0-2) . This exactly mirrors the internal `SignerStopSignaler::send` implementation, which itself issues a raw `POST /shutdown` with no authentication token to trigger the same code path [4](#0-3) , confirming the protocol has no secret gating this endpoint by design — it relies entirely on network-level access control (the assumption that only the local node's event dispatcher can reach this bound address).

Once `stop_signal` is `true`, `is_stopped()` returns `true` [5](#0-4) , and `main_loop` checks this flag at the top of every iteration and breaks out permanently [6](#0-5) . There is no reset path for `stop_signal`, so this is a one-shot, irreversible shutdown of the event receiver thread.

### Impact Explanation
A single unauthenticated `POST /shutdown` from any TCP peer that can reach the bound address permanently halts the signer's `main_loop`, which is the mechanism through which the signer learns about new StackerDB chunks, burn blocks, Stacks blocks, and block-proposal validation responses. This is a one-message, irrecoverable denial of service against the signer's event pipeline, matching the "Critical - remote crash/unauthenticated DoS from few messages" category, provided the port is remotely reachable.

### Likelihood Explanation
The exploit requires only a raw TCP connection and a syntactically valid `POST /shutdown HTTP/1.1` request — no secret, key, StackerDB slot, or privileged role is needed. The sole precondition is that the event-receiver socket is reachable from the attacker's network position. This component is intended to be bound to a loopback/local address reachable only by the local node's event dispatcher; I was unable to fully confirm the default bind address/interface configuration in this repo snapshot (the `stacks-signer` config search for the event-server bind address did not return conclusive results within the available context), so whether this is remotely reachable in a standard deployment is uncertain and depends on operator configuration.

### Recommendation
Add an authentication check (e.g., a shared secret/token compared in constant time, or restrict to loopback-only binding enforced in code) that gates all state-mutating endpoints, especially `/shutdown`, independent of the network binding configuration. Do not rely solely on the assumption that the socket is only reachable locally.

### Proof of Concept
```rust
// libsigner/src/events.rs (test module) - conceptual PoC
#[test]
fn test_unauthenticated_shutdown() {
    let mut receiver: SignerEventReceiver<SomeSignerMessage> = SignerEventReceiver::new(false);
    let bound_addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Simulate a remote attacker with no credentials
    std::thread::spawn(move || {
        let mut stream = TcpStream::connect(bound_addr).unwrap();
        let body = "x";
        let req = format!(
            "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
            bound_addr, body.len(), body
        );
        stream.write_all(req.as_bytes()).unwrap();
    });

    let result = receiver.next_event();
    // Assert: attacker with zero credentials caused Terminated error
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped()); // main_loop will now exit permanently
}
```
