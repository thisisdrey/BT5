The CVE-2020-14295 describes an application-level SQL injection in Cacti's PHP code, where user-supplied `filter` parameter is concatenated into a SQL string. The `ThankGodontt/go--020` repository is the Go standard library source distribution itself, not a web application. Its `database/sql` package is a driver-agnostic API that never itself constructs SQL from untrusted input — all query text is supplied verbatim by the calling application, and the package's job is limited to argument conversion/binding via placeholders (see `driverArgsConnLocked` in [1](#0-0) ) and executing prepared statements (see `DB.QueryContext`/`DB.ExecContext` in [2](#0-1)  and [3](#0-2) ). There is no analogous code path in this repository where an unauthenticated or low-privileged HTTP request is parsed and concatenated into a SQL string that then reaches a query execution sink — the pattern described in the report (string concatenation into a stacked-query-capable SQL statement, e.g. `color.php`'s filter handling) simply does not exist in the Go standard library's `database/sql` package or elsewhere in this source tree. All example/test usages consistently use parameterized placeholders (`?`, named args) rather than string concatenation, e.g. [4](#0-3)  and [5](#0-4) .

Since the report's bug class (application-controlled SQL string construction reachable from an unauthenticated/low-privileged web request) has no matching production code path in this repository, there is no valid analog to report.

// ExecContext executes a query without returning any rows.
// The args are for any placeholder parameters in the query.
func (db *DB) ExecContext(ctx context.Context, query string, args ...any) (Result, error) {
	var res Result
	var err error

	err = db.retry(func(strategy connReuseStrategy) error {
		res, err = db.exec(ctx, query, args, strategy)
		return err
	})

	return res, err
}

// The args are for any placeholder parameters in the query.
func (db *DB) QueryContext(ctx context.Context, query string, args ...any) (*Rows, error) {
	var rows *Rows
	var err error

	err = db.retry(func(strategy connReuseStrategy) error {
		rows, err = db.query(ctx, query, args, strategy)
		return err
	})

	return rows, err
}
