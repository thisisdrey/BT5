### Title
NEP-245 fee bypass via splitting a single `TokenDiff` transfer into N unit-magnitude `TokenDiff` intents - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::token_fee` decides whether to charge a fee purely on the magnitude of the delta within a *single* `TokenDiff` intent, exempting `Nep245`/`Imt`/`Nep171` deltas whose absolute value is `<= 1`. Because a signed `DefuseIntents` payload can bundle an arbitrary `Vec<Intent>` under one signature/nonce, an attacker can split a NEP-245 transfer of magnitude `N` into `N` separate `TokenDiff` intents each with `|delta| == 1`, making every per-intent fee computation hit the zero-fee branch and collecting `0` total fee instead of the fee owed on a single `TokenDiff{delta: -N}`.

### Finding Description
The broken binding: fee owed on one `TokenDiff{diff: {token_id: -N}}` should equal fee collected by `fee_collector` for moving `N` units of that `Nep245` token. In `TokenDiff::execute_intent` [1](#0-0) , the fee is computed per `(token_id, delta)` pair inside a single intent's `diff` map:
```
let amount = delta.unsigned_abs();
let fee = Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount);
```
and `Self::token_fee` [2](#0-1)  returns `Pips::ZERO` whenever `token_id` is `Nep171`/`Nep245`/`Imt` and `amount <= 1`, otherwise returns the full `protocol_fee`.

`DefuseIntents` allows an arbitrary `Vec<Intent>` to be executed under one signature/nonce [3](#0-2) , and `Intent::execute_intent` dispatches each `TokenDiff` intent independently [4](#0-3) , with no state carried between intents to accumulate the total `Nep245` amount moved per token per signer per batch.

Attack payload: instead of one `TokenDiff{diff: {nep245_token: -N}}`, the signer submits one `DefuseIntents` with `N` `TokenDiff` intents, each `{diff: {nep245_token: -1}}`, matched by counterparty `+1` legs elsewhere in the batch so the overall balance invariant nets to zero. Each of the `N` calls to `token_fee(Nep245, 1, protocol_fee)` returns `Pips::ZERO`, so `fees_collected` accumulates nothing across all `N` intents, and no fee is ever credited to `fee_collector` via `internal_add_balance` [5](#0-4) , whereas one `TokenDiff{delta:-N}` would have charged `protocol_fee.fee_ceil(N)`.

No existing guard prevents this: there is no cross-intent accumulation of moved amount per `token_id`/signer within `execute_intent`/`DefuseIntents::execute_intent`, and the exemption in `token_fee` was designed for genuinely unit-sized NFT/MT transfers, not for splitting fungible NEP-245 balances.

### Impact Explanation
This under-collects protocol fees for the `fee_collector` on any NEP-245 (multi-token) asset with a fungible (non-unit) balance, at zero cost beyond the extra intents in the same signed batch. It is fully repeatable across any NEP-245 token, any account, and any batch size `N`, letting any unprivileged signer move an arbitrary NEP-245 balance while paying zero protocol fee, which falls under "protocol fees bypassed" in the Critical impact category.

### Likelihood Explanation
Preconditions are minimal and fully within an unprivileged attacker's control: they need an NEP-245 balance `N>1` in their Verifier account and one or more counterparties (which can be the attacker's own second controlled account or a cooperating market maker) supplying the matching `+1` legs so the batch's aggregate deltas net to zero. Constructing `N` `TokenDiff` intents inside one `DefuseIntents`/`MultiPayload` costs nothing extra beyond payload size/gas, and is trivially repeatable for any NEP-245 asset and any signer.

### Recommendation
Compute `token_fee` based on the aggregate `Nep245`/`Imt` amount moved per `token_id` (and ideally per signer) across the whole `DefuseIntents`/batch, not per individual `TokenDiff` intent — e.g., accumulate `|delta|` per `token_id` across all `TokenDiff` intents executed within the same `DefuseIntents::execute_intent` call before deciding whether the `amount <= 1` exemption applies, so that splitting a transfer into multiple intents cannot reduce total moved amount used for fee computation below the true amount moved.

### Proof of Concept
`cargo test` in `defuse-core` (or `tests/src/tests/defuse/intents/token_diff.rs`):
1. Construct a `Nep245TokenId` with `protocol_fee = Pips::ONE_PERCENT` (or any nonzero fee).
2. Case A: build `DefuseIntents{intents: vec![TokenDiff{diff:{token:-N}}, TokenDiff{diff:{token:+N}} /* counterparty leg from a second signer or fixture */]}` and execute via the engine; assert `fees_collected` for `token` equals `protocol_fee.fee_ceil(N)`.
3. Case B: build `DefuseIntents{intents: (0..N).flat_map(|_| [TokenDiff{diff:{token:-1}}, TokenDiff{diff:{token:+1}}]).collect()}` (or split across multiple signers/counterparties as needed for balance) and execute the same total moved amount `N`; assert the summed `fees_collected` for `token` across all intents is `0`.
4. Assert Case A's collected fee `!=` Case B's collected fee (`> 0` vs `== 0`), despite both moving the same total notional `N` of the same `Nep245` token.

impl ExecutableIntent for Intent {
    fn execute_intent<S, I>(
        self,
        signer_id: &AccountIdRef,
        engine: &mut Engine<S, I>,
        intent_hash: [u8; 32],
    ) -> Result<()>
    where
        S: State,
        I: Inspector,
    {
        match self {
            Self::AddPublicKey(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::RemovePublicKey(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::Transfer(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::FtWithdraw(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::NftWithdraw(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::MtWithdraw(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::NativeWithdraw(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::StorageDeposit(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::TokenDiff(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            Self::SetAuthByPredecessorId(intent) => {
                intent.execute_intent(signer_id, engine, intent_hash)
            }
            Self::AuthCall(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            #[cfg(feature = "imt")]
            Self::ImtMint(intent) => intent.execute_intent(signer_id, engine, intent_hash),
            #[cfg(feature = "imt")]
            Self::ImtBurn(intent) => intent.execute_intent(signer_id, engine, intent_hash),
        }
    }
}
