Audit Report

## Title
Slashed pool member can self-report and pocket the reporter's slash-reward cut via `apply_slash` - (File: `substrate/frame/nomination-pools/src/lib.rs`)

## Summary
`pallet-nomination-pools::apply_slash` is a permissionless dispatchable that lets any signed account apply a pending slash on a `member_account` and receive a `SlashRewardFraction` cut of the slashed amount as a reporter reward. There is no check anywhere in `apply_slash`, `do_apply_slash`, or the downstream `delegated-staking::do_slash` that `who != member_account`, so a member with a pending slash can name themselves as the reporter and reclaim part of their own penalty.

## Finding Description
`apply_slash` only checks the configured `StakeAdapter` strategy, resolves `who` via `ensure_signed`, and forwards `who` unconditionally as the reporter into `do_apply_slash`: [1](#0-0) 

`do_apply_slash` computes the member's pending slash and calls `T::StakeAdapter::member_slash(..., reporter)`, again with no identity check against `member_account`: [2](#0-1) 

For the `Delegate` stake strategy (the only strategy for which `apply_slash` is enabled — `Transfer` strategy's `member_slash` unconditionally errors with `DelegationUnsupported`), `member_slash` routes into `delegated-staking::do_slash`, which pays the reporter directly out of the slashed credit before forwarding the remainder to `T::OnSlash`: [3](#0-2) 

None of these functions verify that the reporter (`who`) differs from the slashed `delegator`/`member_account`. The existing test suite even demonstrates the reporter-reward mechanic with a distinct reporter account, but never exercises or guards against `reporter == delegator`: [4](#0-3) 

Exploit flow: a member `M` with a pending slash (reachable through ordinary validator slashing while delegated to a pool) calls `apply_slash(origin: signed(M), member_account: M)`. `do_apply_slash` passes `Some(M)` as reporter into `delegated_staking::do_slash(agent, M, amount, Some(M))`, which slashes `M`'s held balance by `amount`, then immediately resolves `SlashRewardFraction * actual_slash` back to `M`. Net effect: `M`'s effective slash is reduced from `amount` to `amount * (1 - SlashRewardFraction)`, and the call is `Pays::No`, so `M` incurs no fee either.

## Impact Explanation
This violates the intended "correct beneficiary" invariant for the reporter reward: the reward is meant to compensate an independent, honest party for triggering slash application, not to be reclaimed by the offender being slashed. The result is a value-conservation deviation in the slashing/staking accounting path — the amount forwarded to `T::OnSlash` (burn/treasury) is smaller than the full intended slash, and the offending account retains `SlashRewardFraction * actual_slash` that should have been lost or gone to a distinct reporter. This falls within the staking/asset-accounting and reward-payout impact scope (theft/unbacked retention of value that should have been burned or paid to a legitimate third party), though the magnitude is bounded by the (typically small) `SlashRewardFraction`.

## Likelihood Explanation
High feasibility from an unprivileged attacker's perspective: `apply_slash` is a public extrinsic requiring only a pending slash on the caller's own delegated stake (attainable through normal, expected validator misbehavior/offence flows) and no special permission, `Pays::No` further removes the fee deterrent, and the call can be repeated by any slashed member every time they have a pending slash.

## Recommendation
In `do_apply_slash` (or `delegated-staking::do_slash`), refuse to pay the reporter reward — or reject the call outright — when the reporter equals the account being slashed, e.g. `ensure!(maybe_reporter.as_ref() != Some(&delegator), Error::<T>::...)` or simply drop the reward silently by treating `who == member_account` as `maybe_reporter = None`.

## Proof of Concept
1. Bond/delegate member `M` into a pool using the `Delegate` stake strategy.
2. Trigger a validator slash against the pool's agent so that `M` accrues `PendingSlash > 0` (analogous to the existing test setup in `substrate/frame/nomination-pools/test-delegate-stake/src/lib.rs` lines 701-753 which slashes pool member `21`).
3. Instead of a third party calling `apply_slash`, have `M` call `NominationPools::apply_slash(RuntimeOrigin::signed(M), M)`.
4. Assert `Balances::free_balance(M)` increases by `SlashRewardFraction * actual_slash` immediately after the call, confirming `M`'s effective slash is reduced below the full pending amount and `M` received a reward as its own reporter.

```rust
	/// Slash member against the pending slash for the pool.
	fn do_apply_slash(
		member_account: &T::AccountId,
		reporter: Option<T::AccountId>,
		enforce_min_slash: bool,
	) -> DispatchResult {
		let member = PoolMembers::<T>::get(member_account).ok_or(Error::<T>::PoolMemberNotFound)?;

		let pending_slash =
			Self::member_pending_slash(Member::from(member_account.clone()), member.clone())?;

		// ensure there is something to slash.
		ensure!(!pending_slash.is_zero(), Error::<T>::NothingToSlash);

		if enforce_min_slash {
			// ensure slashed amount is at least the minimum balance.
			ensure!(pending_slash >= T::Currency::minimum_balance(), Error::<T>::SlashTooLow);
		}

		T::StakeAdapter::member_slash(
			Member::from(member_account.clone()),
			Pool::from(Pallet::<T>::generate_bonded_account(member.pool_id)),
			pending_slash,
			reporter,
		)
	}
```

```rust
	/// Take slash `amount` from agent's `pending_slash`counter and apply it to `delegator` account.
	pub fn do_slash(
		agent: Agent<T::AccountId>,
		delegator: Delegator<T::AccountId>,
		amount: BalanceOf<T>,
		maybe_reporter: Option<T::AccountId>,
	) -> DispatchResult {
		// get inner type
		let agent = agent.get();
		let delegator = delegator.get();

		let agent_ledger = AgentLedgerOuter::<T>::get(&agent)?;
		// ensure there is something to slash
		ensure!(agent_ledger.ledger.pending_slash > Zero::zero(), Error::<T>::NothingToSlash);

		let mut delegation = <Delegators<T>>::get(&delegator).ok_or(Error::<T>::NotDelegator)?;
		ensure!(delegation.agent == agent.clone(), Error::<T>::NotAgent);
		ensure!(delegation.amount >= amount, Error::<T>::NotEnoughFunds);

		// slash delegator
		let (mut credit, missing) =
			T::Currency::slash(&HoldReason::StakingDelegation.into(), &delegator, amount);

		defensive_assert!(missing.is_zero(), "slash should have been fully applied");

		let actual_slash = credit.peek();

		// remove the applied slashed amount from agent.
		agent_ledger.remove_slash(actual_slash).save();
		delegation.amount =
			delegation.amount.checked_sub(&actual_slash).ok_or(ArithmeticError::Overflow)?;
		delegation.update(&delegator);

		if let Some(reporter) = maybe_reporter {
			let reward_payout: BalanceOf<T> = T::SlashRewardFraction::get() * actual_slash;
			let (reporter_reward, rest) = credit.split(reward_payout);

			// credit is the amount that we provide to `T::OnSlash`.
			credit = rest;

			// reward reporter or drop it.
			let _ = T::Currency::resolve(&reporter, reporter_reward);
		}

		T::OnSlash::on_unbalanced(credit);

		Self::deposit_event(Event::<T>::Slashed { agent, delegator, amount });

		Ok(())
	}
```
