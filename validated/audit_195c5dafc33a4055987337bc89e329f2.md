### Title
Voting power not reconciled when delegating resources reduces owner TronPower - ([File: actuator/src/main/java/org/tron/core/actuator/DelegateResourceActuator.java])

### Summary
The bug reported for `VotingEscrowTruf.sol` is a class of issue where an operation that mutates a user's underlying balance/power (mint/burn during migration) fails to invoke the corresponding "recompute voting power" step that a sibling operation (`_stake`) performs. The closest reachable analog in java-tron is `DelegateResourceActuator`/`DelegateResourceProcessor`, which reduce an owner's frozen (TronPower-backing) balance when delegating resources to a receiver, but never call the vote-reconciliation routine (`updateVote`) that sibling operations `UnfreezeBalanceActuator`, `UnfreezeBalanceV2Actuator`, and `UnfreezeBalanceV2Processor` explicitly call after they reduce TronPower.

### Finding Description
`DelegateResourceActuator.execute()` reduces the owner's `FrozenBalanceForBandwidthV2`/`FrozenBalanceForEnergyV2` and increases `DelegatedFrozenV2Balance...` when a user delegates out frozen resources: [1](#0-0) . The identical pattern exists in the TVM-native path `DelegateResourceProcessor.execute()`: [2](#0-1) .

By contrast, when TronPower-backing balance is reduced via unfreeze, the code explicitly recomputes/caps the account's outstanding votes so they never exceed the account's remaining TronPower, in `UnfreezeBalanceActuator`: [3](#0-2) , in `UnfreezeBalanceV2Actuator.updateVote`: [4](#0-3) , and in the native `UnfreezeBalanceV2Processor.updateVote`/`UnfreezeBalanceProcessor`: [5](#0-4) [6](#0-5) .

`DelegateResourceActuator`/`DelegateResourceProcessor` never touch `VotesStore` or the account's `votesList` at all — no `updateVote`-equivalent call exists in either class. This means an account that has cast votes based on its TronPower, and then delegates out enough frozen balance to reduce its TronPower below its already-cast vote total, keeps its full (now unbacked) vote total recorded in `AccountStore`/`VotesStore` until the account happens to touch votes again via `VoteWitnessActuator` or an unfreeze operation.

### Impact Explanation
This produces vote counts in `VotesStore`/`AccountCapsule.votesList` that are not backed by the account's real TronPower, mirroring the reported bug class (voting power desynchronized from the underlying stake after a balance-moving operation). Because witness vote tallying (`Wallet.countVote`, used to compute `TotalNetWeight`-adjacent witness election results) sums `oldVotes`/`newVotes` directly from `VotesStore` without re-validating against current TronPower at tally time [7](#0-6) , an account can delegate away its backing stake immediately after voting and still have its full unbacked vote count counted toward witness election, inflating a witness's vote share beyond what any circulating TronPower actually supports.

### Likelihood Explanation
Reachable by any unprivileged owner via a normal `DelegateResourceContract` transaction (broadcastable, no special permission) or via the TVM `delegateResource` native contract call, requiring only that the caller already has cast votes and available frozen V2 balance to delegate — a straightforward two-step sequence (vote, then delegate) fully within a single account's control.

### Recommendation
Call the same `updateVote` reconciliation logic used in `UnfreezeBalanceV2Actuator`/`UnfreezeBalanceV2Processor` from `DelegateResourceActuator.execute()` and `DelegateResourceProcessor.execute()` after reducing the owner's frozen balance, so that votes are proportionally capped/cleared whenever an operation reduces TronPower below the total already-cast vote count — regardless of whether that reduction comes from unfreezing or from delegating resources away.

### Proof of Concept
1. Account A freezes balance for bandwidth (`FreezeBalanceV2Contract`), obtaining TronPower.
2. Account A votes for witness W using its full TronPower via `VoteWitnessContract` (`VoteWitnessActuator.countVoteAccount`) [8](#0-7) .
3. Account A submits `DelegateResourceContract` delegating its entire frozen bandwidth balance to Account B. `DelegateResourceActuator.execute()` reduces A's `FrozenBalanceForBandwidthV2` (and hence TronPower) to zero but never touches `VotesStore`/`votesList` [1](#0-0) .
4. `VotesStore` for Account A still records the full pre-delegation vote count for witness W, which is now completely unbacked by any TronPower, and will still be counted in the next maintenance-period tally via `Wallet.countVote`.

  private void updateVote(AccountCapsule accountCapsule,
                          final UnfreezeBalanceV2Contract unfreezeBalanceV2Contract,
                          byte[] ownerAddress) {
    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    VotesStore votesStore = chainBaseManager.getVotesStore();

    if (accountCapsule.getVotesList().isEmpty()) {
      return;
    }
    if (dynamicStore.supportAllowNewResourceModel()) {
      if (accountCapsule.oldTronPowerIsInvalid()) {
        switch (unfreezeBalanceV2Contract.getResource()) {
          case BANDWIDTH:
          case ENERGY:
            // there is no need to change votes
            return;
          default:
            break;
        }
      } else {
        // clear all votes at once when new resource model start
        VotesCapsule votesCapsule;
        if (!votesStore.has(ownerAddress)) {
          votesCapsule = new VotesCapsule(
              unfreezeBalanceV2Contract.getOwnerAddress(),
              accountCapsule.getVotesList()
          );
        } else {
          votesCapsule = votesStore.get(ownerAddress);
        }
        accountCapsule.clearVotes();
        votesCapsule.clearNewVotes();
        votesStore.put(ownerAddress, votesCapsule);
        return;
      }
    }

    long totalVote = 0;
    for (Protocol.Vote vote : accountCapsule.getVotesList()) {
      totalVote += vote.getVoteCount();
    }
    long ownedTronPower;
    if (dynamicStore.supportAllowNewResourceModel()) {
      ownedTronPower = accountCapsule.getAllTronPower();
    } else {
      ownedTronPower = accountCapsule.getTronPower();
    }

    // tron power is enough to total votes
    if (ownedTronPower >= totalVote * TRX_PRECISION) {
      return;
    }
    if (totalVote == 0) {
      return;
    }

    VotesCapsule votesCapsule;
    if (!votesStore.has(ownerAddress)) {
      votesCapsule = new VotesCapsule(
          unfreezeBalanceV2Contract.getOwnerAddress(),
          accountCapsule.getVotesList()
      );
    } else {
      votesCapsule = votesStore.get(ownerAddress);
    }

    // Update Owner Voting
    List<Vote> addVotes = new ArrayList<>();
    for (Vote vote : accountCapsule.getVotesList()) {
      long newVoteCount = (long)
          ((double) vote.getVoteCount() / totalVote * ownedTronPower / TRX_PRECISION);
      if (newVoteCount > 0) {
        Vote newVote = Vote.newBuilder()
            .setVoteAddress(vote.getVoteAddress())
            .setVoteCount(newVoteCount)
            .build();
        addVotes.add(newVote);
      }
    }
    votesCapsule.clearNewVotes();
    votesCapsule.addAllNewVotes(addVotes);
    votesStore.put(ownerAddress, votesCapsule);

    accountCapsule.clearVotes();
    accountCapsule.addAllVotes(addVotes);
  }

  private void updateVote(
      AccountCapsule accountCapsule,
      Common.ResourceCode freezeType,
      byte[] ownerAddress,
      Repository repo) {
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();

    if (!VMConfig.allowTvmVote() || accountCapsule.getVotesList().isEmpty()) {
      return;
    }
    if (dynamicStore.supportAllowNewResourceModel()) {
      if (accountCapsule.oldTronPowerIsInvalid()) {
        switch (freezeType) {
          case BANDWIDTH:
          case ENERGY:
            // there is no need to change votes
            return;
          default:
            break;
        }
      } else {
        // clear all votes at once when new resource model start
        VotesCapsule votesCapsule = repo.getVotes(ownerAddress);
        if (votesCapsule == null) {
          votesCapsule =
              new VotesCapsule(ByteString.copyFrom(ownerAddress), accountCapsule.getVotesList());
        }
        accountCapsule.clearVotes();
        votesCapsule.clearNewVotes();
        repo.updateVotes(ownerAddress, votesCapsule);
        return;
      }
    }

    long totalVote = 0;
    for (Protocol.Vote vote : accountCapsule.getVotesList()) {
      totalVote += vote.getVoteCount();
    }
    if (totalVote == 0) {
      return;
    }

    long ownedTronPower;
    if (dynamicStore.supportAllowNewResourceModel()) {
      ownedTronPower = accountCapsule.getAllTronPower();
    } else {
      ownedTronPower = accountCapsule.getTronPower();
    }
    // tron power is enough to total votes
    if (ownedTronPower >= totalVote * TRX_PRECISION) {
      return;
    }

    VotesCapsule votesCapsule = repo.getVotes(ownerAddress);
    if (votesCapsule == null) {
      votesCapsule =
          new VotesCapsule(ByteString.copyFrom(ownerAddress), accountCapsule.getVotesList());
    }

    // Update Owner Voting
    List<Protocol.Vote> votesToAdd = new ArrayList<>();
    for (Protocol.Vote vote : accountCapsule.getVotesList()) {
      long newVoteCount =
          (long) ((double) vote.getVoteCount() / totalVote * ownedTronPower / TRX_PRECISION);
      if (newVoteCount > 0) {
        votesToAdd.add(
            Protocol.Vote.newBuilder()
                .setVoteAddress(vote.getVoteAddress())
                .setVoteCount(newVoteCount)
                .build());
      }
    }
    votesCapsule.clearNewVotes();
    votesCapsule.addAllNewVotes(votesToAdd);
    repo.updateVotes(ownerAddress, votesCapsule);

    accountCapsule.clearVotes();
    accountCapsule.addAllVotes(votesToAdd);
  }

  private Map<ByteString, Long> countVote(VotesStore votesStore) {
    // Initialize a result map to store vote changes for each witness
    Map<ByteString, Long> countWitness = Maps.newHashMap();

    // VotesStore is a key-value store, where the key is the address of the voter
    Iterator<Entry<byte[], VotesCapsule>> dbIterator = votesStore.iterator();

    while (dbIterator.hasNext()) {
      Entry<byte[], VotesCapsule> next = dbIterator.next();
      VotesCapsule votes = next.getValue();

      /**
       * VotesCapsule contains two lists:
       * - Old votes: Last votes from the previous epoch, updated in maintenance period
       * - New votes: Latest votes in current epoch, updated after each vote transaction
       */
      votes.getOldVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        countWitness.put(voteAddress,
            countWitness.getOrDefault(voteAddress, 0L) - voteCount);
      });
      votes.getNewVotes().forEach(vote -> {
        ByteString voteAddress = vote.getVoteAddress();
        long voteCount = vote.getVoteCount();
        countWitness.put(voteAddress,
            countWitness.getOrDefault(voteAddress, 0L) + voteCount);
      });
    }
    return countWitness;
  }
