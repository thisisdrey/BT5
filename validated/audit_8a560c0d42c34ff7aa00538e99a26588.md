### Title
Unauthenticated `/shutdown` endpoint on Signer's `SignerEventReceiver` allows any TCP client to terminate the signer's event loop - (File: `libsigner/src/events.rs`)

### Summary
The `SignerEventReceiver::next_event` HTTP dispatch handles the `/shutdown` route by unconditionally setting the stop flag and returning `EventError::Terminated`, with no verification of the caller's identity, secret, or origin. Any TCP client capable of reaching the signer's bound event-listener port can send a single POST to `/shutdown` and permanently kill the signer's event ingestion loop.

### Finding Description
The equality that should hold — "the sender invoking `/shutdown` must be the node's configured event observer" — is never checked. In `next_event()`: [1](#0-0) 
the branch for `request.url() == "/shutdown"` immediately calls `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `Err(EventError::Terminated)`, with no signature check, no shared-secret comparison, and no source-address allowlist — unlike the legitimate stop path in `SignerStopSignaler::send`, which is only reachable from in-process code holding the `Arc<AtomicBool>` handle: [2](#0-1) 
Because the HTTP server (`tiny_http`) accepts any connection to the bound socket, and the dispatch logic performs no authentication on any route (contrast with `/status`, `/stackerdb_chunks`, etc., which also lack a caller-identity check but at worst just get ignored/erred; `/shutdown` has permanent, unrecoverable state-mutating effect), a single crafted `POST /shutdown` request from an arbitrary socket reaches this branch. Once `stop_signal` is `true`, `EventReceiver::main_loop` observes `is_stopped()` (backed by the same `AtomicBool`, see `is_stopped` at line 462-464) and breaks out on the next iteration, or immediately receives `EventError::Terminated` from `next_event` and exits at the `main_loop` match arm: [3](#0-2) 
This permanently halts the signer's event pipeline (stackerdb chunks, burn blocks, new blocks, block-validation responses all stop being ingested), until the signer process is manually restarted.

### Impact Explanation
A remote, unprivileged party who can open a TCP connection to the signer's event-receiver bind address can send one crafted HTTP POST to `/shutdown` and permanently disable that signer's event stream — no further events (block proposals, burn blocks, StackerDB chunks) will be processed until manual restart. This is a Critical, unauthenticated single-message DoS against the signer's runloop, matching the "remote crash/unauthenticated DoS from few messages" category. It is trivially repeatable against any signer whose event port is reachable.

### Likelihood Explanation
No secret, credential, or privileged role is required — only network reachability to the port the signer bound via `EventReceiver::bind` (configured via the signer's `endpoint` setting). Attacker cost is a single raw HTTP POST. If the operator has bound the listener to a non-loopback interface (common in multi-host/dockerized deployments where the stacks-node pushes events to a separate signer host), this is directly exploitable from the network.

### Recommendation
Add an authentication check to `/shutdown` (and ideally all event dispatch routes) in `SignerEventReceiver::next_event`, e.g. requiring a shared secret/HMAC header configured out-of-band between the node and the signer, or restricting the shutdown mechanism to a local-only Unix socket / loopback-bound control channel instead of the same HTTP listener that accepts node-pushed events.

### Proof of Concept
```rust
// libsigner/src/tests/mod.rs style test
#[test]
fn test_unauthenticated_shutdown() {
    let ev = SignerEventReceiver::new(false);
    let (res_send, _res_recv) = channel();
    let mut signer = Signer::new(SimpleRunLoop::new(1), ev, res_send);
    let endpoint: SocketAddr = "127.0.0.1:32000".parse().unwrap();
    let running_signer = signer.spawn(endpoint).unwrap();

    // Attacker: arbitrary local socket, no credentials
    let mut sock = TcpStream::connect(endpoint).unwrap();
    let body = "attack";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {endpoint}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{body}",
        body.len()
    );
    sock.write_all(req.as_bytes()).unwrap();

    // main_loop should exit due to unauthenticated stop_signal write
    let result = running_signer.stop(); // returns once event_join/signer_join complete
    // Assert event receiver terminated without any legitimate stop_signal.send() call
    assert!(result.is_some()); // reached termination via forged /shutdown, not SignerStopSignaler
}
```
The assertion point is `event_receiver.stop_signal.store(true, Ordering::SeqCst)` at [1](#0-0)  being reached from an unauthenticated raw socket, causing `main_loop` to exit at [3](#0-2) .
