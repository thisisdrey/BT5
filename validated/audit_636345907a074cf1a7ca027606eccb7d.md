Audit Report

## Title
Unbounded relayer-supplied `call_weight_witness` combined with silently-dropped `actual_weight` in `pallet-whitelist::clean_and_dispatch` allows free, near-max-block-weight griefing - (File: `substrate/frame/whitelist/src/lib.rs`)

## Summary
`pallet-whitelist::dispatch_whitelisted_call` accepts a relayer-supplied `call_weight_witness` that is only lower-bounded against the inner call's declared weight, and this witness directly inflates the extrinsic's pre-dispatch declared weight annotation. The dispatchable's `actual_weight` is computed by `.map()`-ing over the inner call's `actual_weight`, which propagates `None` for the whole outer extrinsic whenever the inner call reports `actual_weight: None` (the common default for calls with no custom weight refund), causing the block's weight-accounting to fall back to the inflated pre-dispatch weight while the relayer pays no fee (`Pays::No`).

## Finding Description
In `dispatch_whitelisted_call`, the only check on the relayer-supplied `call_weight_witness` is: [1](#0-0) 
which is a pure lower bound (`all_lte`) with no upper bound, while the same witness is fed directly into the `#[pallet::weight(...)]` pre-dispatch annotation: [2](#0-1) 
The relayer path unconditionally grants `Pays::No`: [3](#0-2) 
The outer extrinsic's post-dispatch `actual_weight` is derived purely by mapping over the inner call's `actual_weight` from `clean_and_dispatch`: [4](#0-3) 
and `clean_and_dispatch` returns exactly the inner call's own `actual_weight` field, unmodified, with no fallback to the inner call's declared weight when it is `None`: [5](#0-4) 
Because `Option::map` on `None` yields `None`, if the inner call reports `actual_weight: None` (default for many simple calls that don't implement custom weight refunding), the outer extrinsic's `PostDispatchInfo.actual_weight` is `None`. `frame_system`'s block-weight accounting (`CheckWeight::post_dispatch_details` → `Pallet::reclaim_weight`) treats a `None` `actual_weight` as "no more-precise information available," which is the standard frame convention for falling back to the pre-dispatch declared weight — the same declared weight that was inflated by the attacker-controlled `call_weight_witness`. Other pallets that execute inner calls and refund weight (e.g. `pallet-utility`) explicitly use `frame_support::dispatch::extract_actual_weight` to correctly fall back to the inner call's own declared (small) weight rather than to the outer wrapper's inflated pre-dispatch weight; `pallet-whitelist` does not use this helper. The `ensure_signed_deferred_dispatch` check only validates signed origin, deferral existence/non-expiry, and whitelist status, never re-validating that `call_weight_witness` is tight to the call's real weight.

## Impact Explanation
This matches "public underpriced work that degrades block production" from the impact gate: an unprivileged signed account, with no governance/validator/admin privilege, can consume a large, attacker-chosen fraction of the chain's "Normal" per-block weight budget in a single fee-free transaction (`Pays::No`), by naming a small already-deferred-and-whitelisted call hash together with a near-max `call_weight_witness`. Repeating this against any deferred/whitelisted call whose inner dispatch reports `actual_weight: None` degrades block production for legitimate transactions, a direct availability impact.

## Likelihood Explanation
The precondition — a governance-deferred call currently sitting in `WhitelistedCall`/`DeferredDispatch` storage — is a normal, expected state reached through the intended, permissionless "any signed account may relay" workflow of this feature, not privileged misuse. `DeferredDispatch` and `WhitelistedCall` are public on-chain storage, so an attacker can observe eligible call hashes and race to submit the inflated-witness dispatch before anyone else. No collusion with governance or validators is required.

## Recommendation
- Upper-bound `call_weight_witness` (require it to equal, or be tightly capped to, `call.get_dispatch_info().call_weight`) instead of only lower-bounding it via `all_lte`.
- In `clean_and_dispatch`/the calling dispatchables, use `frame_support::dispatch::extract_actual_weight` (as `pallet-utility` does) so that a `None` inner `actual_weight` falls back to the inner call's own declared weight, not the outer wrapper's witness-inflated declared weight.
- Reconsider unconditional `Pays::No` for the relayer path independent of how large `call_weight_witness` was.

## Proof of Concept
1. Governance defers and later whitelists a small call, e.g. `System::remark { remark: vec![] }`, whose dispatch reports `actual_weight: None`.
2. Attacker (any `Signed` account, no privilege) calls:
```rust
Whitelist::dispatch_whitelisted_call(
    RuntimeOrigin::signed(attacker),
    call_hash,
    call_encoded_len,
    Weight::from_parts(RuntimeBlockWeights::get().max_block.ref_time() * 9 / 10, u64::MAX),
)
```
3. `ensure!(call_weight.all_lte(call_weight_witness), ...)` passes trivially since the witness vastly exceeds the real call weight; `pays_fee = Pays::No`; `clean_and_dispatch` returns `None` (inner `System::remark` reports no `actual_weight`); `actual_weight = None.map(...) = None`.
4. Block weight accounting falls back to the pre-dispatch declared weight, which includes the attacker's inflated `call_weight_witness`, consuming most of the block's Normal weight budget at zero fee.
A concrete `#[test]` in `substrate/frame/whitelist/src/tests.rs`, asserting the post-dispatch `System::block_weight()` after such a call reflects the inflated witness rather than the small real call weight, would confirm this on a live test harness.

	fn clean_and_dispatch(call_hash: T::Hash, call: <T as Config>::RuntimeCall) -> Option<Weight> {
		WhitelistedCall::<T>::remove(call_hash);
		T::Preimages::unrequest(&call_hash);
		DeferredDispatch::<T>::remove(call_hash);

		let result = call.dispatch(frame_system::Origin::<T>::Root.into());

		let call_actual_weight = match result {
			Ok(call_post_info) => call_post_info.actual_weight,
			Err(call_err) => call_err.post_info.actual_weight,
		};
		Self::deposit_event(Event::<T>::WhitelistedCallDispatched { call_hash, result });

		call_actual_weight
	}
