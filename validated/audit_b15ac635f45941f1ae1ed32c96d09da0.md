Confirmed: `PKI.reloadCAPool` swaps `p.caPool` on every config reload but never touches `Firewall.rulesVersion` [1](#0-0) , and `firewall.go`'s `rulesVersion` is only bumped by the firewall-rule reload path, not by CA pool/blocklist reloads [2](#0-1) .

### Title
Stale conntrack fast-path skips CA-pool re-validation after CA/blocklist reload, allowing revoked-CA-signed peers to keep passing `ca_name`/`ca_sha` firewall rules - (File: firewall.go)

### Summary
`Firewall.Drop` allows an established flow to bypass full rule evaluation via `inConns`, which only re-checks a conntrack entry against the ruleset if `c.rulesVersion != f.rulesVersion` [3](#0-2) . `rulesVersion` is only incremented when firewall rules are reloaded; reloading the CA pool (`pki.ca`) or the CA blocklist (`pki.blocklist`) replaces `PKI.caPool` via `p.caPool.Store(caPool)` without touching the firewall's `rulesVersion` [1](#0-0) . As a result, a tunnel that was allowed into conntrack under a `ca_name`/`ca_sha` rule while its signing CA was still trusted continues to be allowed indefinitely after that CA is removed or blocklisted, because the fast conntrack path never re-runs `FirewallCA.match`, which is the only place that consults the live `caPool.GetCAForCert` lookup [4](#0-3) , [5](#0-4) .

### Finding Description
This is the analog of the Suzaku bug: rewards were computed against a *live* vault list (`getVaults(epoch)`), so once a vault was removed from that live list, historically-earned entitlements tied to it became permanently stuck because nothing retroactively reprocessed them. Here, the roles are inverted but the root cause is identical: a security decision (packet-forwarding permission) is made once, cached as a conntrack `conn{rulesVersion}` entry, and only re-validated when a *specific counter* changes. That counter (`Firewall.rulesVersion`) is coupled only to firewall-rule reloads, not to the CA pool that the very rule-matching logic (`FirewallCA.match` → `caPool.GetCAForCert`) depends on. Removing/blocklisting a CA is exactly the kind of "removal from the live list" event that should invalidate previously-granted state, but the invalidation trigger (`rulesVersion`) never fires for it.

Concretely:
1. Operator has a firewall rule keyed on `ca_name`/`ca_sha` allowing traffic from peers signed by CA `X`.
2. A peer whose cert is signed by CA `X` completes a handshake and its first packet passes `Firewall.Drop`, calling `table.match` → `FirewallCA.match`, which resolves `caPool.GetCAForCert` and matches the rule, then calls `f.addConn`, stamping the conntrack entry with the current `f.rulesVersion` [6](#0-5) , [7](#0-6) .
3. Operator later reloads `pki.ca` (rotates CAs) or adds CA `X`'s fingerprint to `pki.blocklist`. `PKI.reloadCAPool` swaps in a new `*cert.CAPool` with CA `X` removed/blocklisted, but this path never calls anything that bumps `Firewall.rulesVersion`.
4. On every subsequent packet from that peer, `inConns` sees `c.rulesVersion == f.rulesVersion` and returns `true` immediately without ever calling `table.match` again [8](#0-7) .
5. The peer's traffic keeps flowing through the `ca_name`/`ca_sha`-scoped rule indefinitely (until natural conntrack expiry, which for TCP defaults to up to 5 days), even though its trust anchor has been explicitly revoked by the operator.

### Impact Explanation
This is a firewall-enforcement bypass: CA revocation/blocklisting is a security control meant to immediately cut off traffic that was only permitted because of a trust relationship to a CA. Because the conntrack fast path doesn't re-derive from the new CA pool, already-established flows silently continue to be treated as trusted for the remaining conntrack timeout, undermining the operator's revocation action. This is distinct from (and does not fully overlap with) the general certificate-invalidity teardown handled separately by `connection_manager.isInvalidCertificate`, which only tears down the tunnel object itself and is not what feeds `rulesVersion`/conntrack revalidation in `firewall.go`.

### Likelihood Explanation
Any operator workflow that revokes a CA via `pki.ca` rotation or `pki.blocklist` while relying on `ca_name`/`ca_sha`-scoped firewall rules (a documented, supported feature — see `firewall.AddRule`'s `caName`/`caSha` parameters [9](#0-8) ) will trigger this. No attacker action beyond already having an established, previously-allowed tunnel is required; the bypass persists automatically due to normal config-reload operational behavior.

### Recommendation
Increment `Firewall.rulesVersion` (or otherwise force conntrack re-validation) whenever the CA pool changes — i.e., have `PKI.reloadCAPool` (or its caller) notify the active `Firewall` to bump `rulesVersion`, mirroring how `reloadFirewall`/rule changes already do, so that `inConns` is forced to re-run `table.match` against the new `caPool` for every existing conntrack entry.

### Proof of Concept
Not independently reproduced against a running binary; the trace above is derived directly from reading `firewall.go`'s `inConns`/`addConn`/`FirewallCA.match` and `pki.go`'s `reloadCAPool`, which show the missing coupling between CA pool reloads and `rulesVersion`. Confirming exploitability end-to-end (e.g., via an e2e test analogous to `TestFirewall_DropConntrackReload`) would require running the test suite, which is outside the scope of this read-only analysis.

func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}

	if c.rulesVersion != f.rulesVersion {
		// This conntrack entry was for an older rule set, validate
		// it still passes with the current rule set
		table := f.OutRules
		if c.incoming {
			table = f.InRules
		}

		// We now know which firewall table to check against
		if !table.match(fp, c.incoming, h.ConnectionState.peerCert, caPool) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				h.logger(f.l).Debug("dropping old conntrack entry, does not match new ruleset",
					"fwPacket", fp,
					"incoming", c.incoming,
					"rulesVersion", f.rulesVersion,
					"oldRulesVersion", c.rulesVersion,
				)
			}
			delete(conntrack.Conns, fp)
			conntrack.Unlock()
			return false
		}

		if f.l.Enabled(context.Background(), slog.LevelDebug) {
			h.logger(f.l).Debug("keeping old conntrack entry, does match new ruleset",
				"fwPacket", fp,
				"incoming", c.incoming,
				"rulesVersion", f.rulesVersion,
				"oldRulesVersion", c.rulesVersion,
			)
		}

		c.rulesVersion = f.rulesVersion
	}

func (f *Firewall) addConn(fp firewall.Packet, incoming bool) {
	var timeout time.Duration
	c := &conn{}

	switch fp.Protocol {
	case firewall.ProtoTCP:
		timeout = f.TCPTimeout
	case firewall.ProtoUDP:
		timeout = f.UDPTimeout
	default:
		timeout = f.DefaultTimeout
	}

	conntrack := f.Conntrack
	conntrack.Lock()
	if _, ok := conntrack.Conns[fp]; !ok {
		conntrack.TimerWheel.Advance(time.Now())
		conntrack.TimerWheel.Add(fp, timeout)
	}

	// Record which rulesVersion allowed this connection, so we can retest after
	// firewall reload
	c.incoming = incoming
	c.rulesVersion = f.rulesVersion
	c.Expires = time.Now().Add(timeout)
	conntrack.Conns[fp] = c
	conntrack.Unlock()
}

func (fc *FirewallCA) match(p firewall.Packet, c *cert.CachedCertificate, caPool *cert.CAPool) bool {
	if fc == nil {
		return false
	}

	if fc.Any.match(p, c) {
		return true
	}

	if t, ok := fc.CAShas[c.Certificate.Issuer()]; ok {
		if t.match(p, c) {
			return true
		}
	}

	s, err := caPool.GetCAForCert(c.Certificate)
	if err != nil {
		return false
	}

	return fc.CANames[s.Certificate.Name()].match(p, c)
}

// GetCAForCert attempts to return the signing certificate for the provided certificate.
// No signature validation is performed
func (ncp *CAPool) GetCAForCert(c Certificate) (*CachedCertificate, error) {
	issuer := c.Issuer()
	if issuer == "" {
		return nil, fmt.Errorf("no issuer in certificate")
	}

	signer, ok := ncp.CAs[issuer]
	if ok {
		return signer, nil
	}

	return nil, ErrCaNotFound
}
