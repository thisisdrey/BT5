### Title
Unauthenticated UDP packets to plain-UDP `tpu_vote` socket are unconditionally marked as staked-origin, bypassing unstaked throttling/prioritization - ([File: core/src/fetch_stage.rs])

### Summary
The plain-UDP `tpu_vote` socket is bound and publicly advertised via `ContactInfo::set_tpu_vote(UDP, ...)`, yet `FetchStage::new_multi_socket` wires it into `streamer::receiver` with `is_staked_service` hardcoded to `true`, based only on the assumption "only staked connections should be voting." `streamer::recv_loop` then unconditionally calls `p.meta_mut().set_from_staked_node(is_staked_service)` for every packet pulled off that socket, with zero identity, signature, or stake verification performed at the UDP layer. Any unstaked remote attacker can therefore send raw UDP datagrams to this socket and have them permanently marked `FROM_STAKED_NODE` before any authentication occurs.

### Finding Description
The vulnerable call chain is:
1. `gossip/src/node.rs` binds a plain UDP `tpu_vote` socket and publicly advertises it via `info.set_tpu_vote(UDP, (advertised_ip, tpu_vote_port))` [1](#0-0) , meaning any unstaked internet client can address it directly.
2. `Tpu::new_with_client` passes these sockets (`tpu_vote_sockets`) into `FetchStage::new_with_sender` / `new_multi_socket` [2](#0-1) .
3. `FetchStage::new_multi_socket` spawns one `streamer::receiver` thread per tpu_vote socket, hardcoding the final boolean argument (`is_staked_service`) to `true` with the comment "only staked connections should be voting": [3](#0-2) .
4. `streamer::receiver` forwards this flag straight into `recv_loop` [4](#0-3) .
5. `recv_loop` reads raw datagrams via `recv_from`/`recv_mmsg` with **no identity, signature, or stake check whatsoever**, and unconditionally stamps every packet in the batch with `p.meta_mut().set_from_staked_node(is_staked_service)` [5](#0-4) .

Because `is_staked_service` is a compile-time constant `true` for this socket, and the socket accepts arbitrary UDP traffic from any source IP, an unstaked/unprivileged attacker's packets are marked as staked-origin (`PacketFlags::FROM_STAKED_NODE`) purely by virtue of which local port they hit — there is no cryptographic or stake-based gate between the attacker and this flag being set. This directly violates the invariant (used elsewhere, e.g. `forwarding_stage.rs`'s `initial_packet_meta_filter`, which treats `FROM_STAKED_NODE` as a trust signal for forwarding eligibility [6](#0-5) , and `tpu_to_pack.rs`'s `flags_from_meta`, which propagates `PacketFlags::FROM_STAKED_NODE` into the banking-stage `tpu_message_flags::FROM_STAKED_NODE` used for downstream scheduling decisions [7](#0-6) ).

### Impact Explanation
Packets from an unstaked attacker sent to the public plain-UDP tpu_vote port are unconditionally labeled `is_from_staked_node() == true` at the fetch-stage boundary, with no actual relationship to any staked validator identity or signature verification having occurred. This flag flows into `PacketFlags::FROM_STAKED_NODE` and later `tpu_message_flags::FROM_STAKED_NODE`, which are consumed by `forwarding_stage.rs` (forwarding eligibility gating) and the banking-stage vote packet pipeline as a trust/priority signal for vote traffic — effectively letting arbitrary unstaked UDP senders masquerade as staked, unfairly capturing vote-processing/forwarding capacity meant to be reserved for staked validators. This is a QoS/prioritization evasion issue (unstaked traffic bypassing staked/unstaked classification), matching the Agave "QoS evasion" bounty category.

### Likelihood Explanation
Fully reachable by an unprivileged remote attacker with no preconditions: the tpu_vote UDP address/port is public gossip-advertised information (`ContactInfo`), the socket is plain UDP (no handshake, no QUIC/TLS identity), and `recv_loop` performs the staked-flag stamping unconditionally on every packet received. No stake, key, or validator control is required — only knowledge of the leader's public `tpu_vote` UDP address, which is broadcast in gossip. This is trivially and repeatably reproducible.

### Recommendation
Do not hardcode `is_staked_service=true` for the plain-UDP tpu_vote receiver in `FetchStage::new_multi_socket`. Either (a) remove the plain-UDP tpu_vote ingestion path entirely in favor of the QUIC/stake-weighted-QoS vote path (`spawn_simple_qos_server` for `quic_streamer_tpu_vote`, which does perform stake-aware admission), or (b) if the plain-UDP path must remain, derive `is_from_staked_node` from real verified identity/stake information (e.g., via a QUIC-authenticated per-connection lookup against `StakedNodes`) rather than a compile-time constant applied to every packet from an unauthenticated socket.

### Proof of Concept
```rust
// streamer/src/streamer.rs (integration-style test)
#[test]
fn test_unauthenticated_udp_flagged_as_staked() {
    let exit = Arc::new(AtomicBool::new(false));
    let socket = Arc::new(UdpSocket::bind("127.0.0.1:0").unwrap());
    let addr = socket.local_addr().unwrap();
    let (sender, receiver) = crossbeam_channel::unbounded();
    let stats = Arc::new(StreamerReceiveStats::new("test_tpu_vote"));

    // Mirrors FetchStage::new_multi_socket's hardcoded is_staked_service=true
    let handle = receiver_thread_from(
        socket, exit.clone(), sender, PacketBatchRecycler::default(), stats,
        None, true, /* use_pinned_memory */
        true, /* is_staked_service - hardcoded, per fetch_stage.rs */
    );

    // Attacker: unstaked client, arbitrary garbage bytes, no signature, no identity
    let attacker_socket = UdpSocket::bind("127.0.0.1:0").unwrap();
    attacker_socket.send_to(b"garbage-not-a-vote", addr).unwrap();

    let batch = receiver.recv_timeout(Duration::from_secs(2)).unwrap();
    let packet = batch.first().unwrap();

    // Bug: attacker packet is classified as staked despite no stake relation
    assert!(packet.meta().is_from_staked_node());

    exit.store(true, Ordering::Relaxed);
    handle.join().unwrap();
}
```
Expected (buggy) result: assertion passes, confirming an arbitrary unstaked UDP sender's packet is marked `is_from_staked_node() == true` purely because of the destination socket, with no signature/stake check performed.

#[allow(clippy::too_many_arguments)]
pub fn receiver(
    thread_name: String,
    socket: Arc<UdpSocket>,
    exit: Arc<AtomicBool>,
    packet_batch_sender: impl ChannelSend<PacketBatch>,
    recycler: PacketBatchRecycler,
    stats: Arc<StreamerReceiveStats>,
    coalesce: Option<Duration>,
    use_pinned_memory: bool,
    is_staked_service: bool,
) -> JoinHandle<()> {
    Builder::new()
        .name(thread_name)
        .spawn(move || {
            let mut provider = FixedSocketProvider::new(socket);
            let _ = recv_loop(
                &mut provider,
                &exit,
                &packet_batch_sender,
                &recycler,
                &stats,
                coalesce,
                use_pinned_memory,
                is_staked_service,
            );
        })
        .unwrap()
