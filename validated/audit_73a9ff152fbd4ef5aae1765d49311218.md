### Title
No vulnerability - StackerDB chunk reads are intentionally public by design - ([File: stackslib/src/net/chat.rs])

### Summary
`handle_stacker_db_getchunk` and its underlying `make_stacker_db_getchunk_response` only validate the `rc_consensus_hash` (freshness of view) and the chunk's existence/version at the requested slot; they perform no check on the identity or authorization of the requester. This is confirmed as intentional: the equivalent HTTP RPC endpoint `RPCGetStackerDBChunkRequestHandler` in `getstackerdbchunk.rs` declares `security: []` in `docs/rpc/openapi.yaml`, and StackerDB chunk data is documented and designed to be a public replication mechanism, not a confidentiality boundary.

### Finding Description
`handle_stacker_db_getchunk` at [1](#0-0)  calls `make_stacker_db_getchunk_response`, which checks only the reward-cycle consensus hash for freshness and then fetches the chunk by `contract_id`/`slot_id`/`slot_version` with no requester identity check at all: [2](#0-1) . The write path (`PutChunk`) is the one that enforces per-slot signature/ownership checks against the slot's designated public key — reads are not gated the same way, because StackerDB is explicitly a public replication protocol: "Any reachable Stacks node can fulfill requests for chunks," as documented at [3](#0-2) . The equivalent HTTP endpoint explicitly marks `security: []` for `getStackerDbChunk`/`getStackerDbChunkVersioned`, confirming the public, unauthenticated-read design intent: [4](#0-3) . The RPC handler `RPCGetStackerDBChunkRequestHandler::try_handle_request` likewise performs no ownership/session check before returning chunk bytes: [5](#0-4) .

### Impact Explanation
None. There is no broken equality here — StackerDB is a public, gossip-based replication system where "read" is intentionally open to any peer (and even to unauthenticated HTTP clients), while "write" (`PutChunk`) is the operation gated by per-slot public-key signature verification. Application data placed in a StackerDB slot is not treated as confidential by the protocol; any application requiring confidentiality must encrypt its payload before writing it to a chunk. This does not meet the Critical "unauthenticated memory disclosure" bar because there is no disclosure of data beyond what the protocol's design already exposes to any participant on the network.

### Likelihood Explanation
N/A — this is a documented, intentional design characteristic, not an exploitable flaw.

### Recommendation
No fix needed. If confidentiality of specific StackerDB application data is desired, that must be implemented at the application layer (client-side encryption of chunk payloads) rather than in the transport/replication layer, since StackerDB's design goal is public replication of slot-owner-authenticated (not requester-authenticated) data.

### Proof of Concept
Not applicable — no vulnerability to demonstrate; behavior matches documented design (`security: []` in the OpenAPI spec and public replication semantics in `stackerdb/mod.rs`).

    fn make_stacker_db_getchunk_response(
        network: &PeerNetwork,
        getchunk: &StackerDBGetChunkData,
    ) -> StacksMessageType {
        let local_peer = network.get_local_peer();
        let burnchain_view = network.get_chain_view();
        let stacker_dbs = network.get_stackerdbs();

        if burnchain_view.rc_consensus_hash != getchunk.rc_consensus_hash {
            debug!(
                "{local_peer:?}: NACK StackerDBGetChunk; {} != {}",
                &burnchain_view.rc_consensus_hash, &getchunk.rc_consensus_hash
            );
            return StacksMessageType::Nack(NackData::new(NackErrorCodes::StaleView));
        }

        let chunk = match stacker_dbs.get_chunk(
            &getchunk.contract_id,
            getchunk.slot_id,
            getchunk.slot_version,
        ) {
            Ok(Some(chunk)) => chunk,
            Ok(None) => {
                // TODO: this is racey
                if let Ok(Some(actual_version)) =
                    stacker_dbs.get_slot_version(&getchunk.contract_id, getchunk.slot_id)
                {
                    // request for a stale chunk
                    debug!("{local_peer:?}: NACK StackerDBGetChunk; version mismatch for requested slot {}.{} for {}. Expected {actual_version}", getchunk.slot_id, getchunk.slot_version, &getchunk.contract_id);
                    if actual_version > getchunk.slot_version {
                        return StacksMessageType::Nack(NackData::new(
                            NackErrorCodes::StaleVersion,
                        ));
                    } else {
                        return StacksMessageType::Nack(NackData::new(
                            NackErrorCodes::FutureVersion,
                        ));
                    }
                }
                // if we hit a DB error, just treat it as if the DB doesn't exist
                debug!(
                    "{local_peer:?}: NACK StackerDBGetChunk; unloadable slot {}.{} for {}",
                    getchunk.slot_id, getchunk.slot_version, &getchunk.contract_id
                );
                return StacksMessageType::Nack(NackData::new(NackErrorCodes::NoSuchDB));
            }
            Err(e) => {
                debug!(
                    "{local_peer:?}: failed to get chunk for slot {}.{} for {}: {e:?}",
                    getchunk.slot_id, getchunk.slot_version, &getchunk.contract_id
                );

                // most likely indicates that this DB doesn't exist
                return StacksMessageType::Nack(NackData::new(NackErrorCodes::NoSuchDB));
            }
        };

        StacksMessageType::StackerDBChunk(chunk)
    }

    fn try_handle_request(
        &mut self,
        preamble: HttpRequestPreamble,
        _contents: HttpRequestContents,
        node: &mut StacksNodeState,
    ) -> Result<(HttpResponsePreamble, HttpResponseContents), NetError> {
        let contract_identifier = self
            .contract_identifier
            .take()
            .ok_or(NetError::SendError("`contract_identifier` not set".into()))?;
        let slot_id = self
            .slot_id
            .take()
            .ok_or(NetError::SendError("`slot_id` not set".into()))?;
        let slot_version = self.slot_version.take();

        let chunk_resp =
            node.with_node_state(|network, _sortdb, _chainstate, _mempool, _rpc_args| {
                let chunk_res = if let Some(version) = slot_version.as_ref() {
                    network
                        .get_stackerdbs()
                        .get_chunk(&contract_identifier, slot_id, *version)
                        .map(|chunk_data| chunk_data.map(|chunk_data| chunk_data.data))
                } else {
                    network
                        .get_stackerdbs()
                        .get_latest_chunk(&contract_identifier, slot_id)
                };

                match chunk_res {
                    Ok(Some(chunk)) => {
                        debug!(
                            "Loaded {}-byte chunk for {} slot {} version {:?}",
                            chunk.len(),
                            &contract_identifier,
                            slot_id,
                            &slot_version
                        );
                        Ok(chunk)
                    }
                    Ok(None) | Err(NetError::NoSuchStackerDB(..)) => {
                        // not found
                        Err(StacksHttpResponse::new_error(
                            &preamble,
                            &HttpNotFound::new("StackerDB contract or chunk not found".to_string()),
                        ))
                    }
                    Err(e) => {
                        // some other error
                        error!("Failed to load StackerDB chunk";
                               "smart_contract_id" => contract_identifier.to_string(),
                               "slot_id" => slot_id,
                               "slot_version" => slot_version,
                               "error" => format!("{:?}", &e)
                        );
                        Err(StacksHttpResponse::new_error(
                            &preamble,
                            &HttpServerError::new("Failed to load StackerDB chunk".to_string()),
                        ))
                    }
                }
            });

        let chunk_resp = match chunk_resp {
            Ok(chunk) => chunk,
            Err(response) => {
                return response.try_into_contents().map_err(NetError::from);
            }
        };

        let preamble = HttpResponsePreamble::from_http_request_preamble(
            &preamble,
            200,
            "OK",
            None,
            HttpContentType::Bytes,
        );
        let body = HttpResponseContents::from_ram(chunk_resp);
        Ok((preamble, body))
