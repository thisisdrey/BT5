### Title
Zero-point silent fund donation on `join`/`bond_extra` when balance:points ratio rounds a valid deposit down to `0` points - (File: `substrate/frame/nomination-pools/src/lib.rs`)

### Summary
`pallet-nomination-pools` converts a member's deposited balance into "points" using integer division (`balance_to_point`), and unlike the Aave `supplyTokenTo()` report — which explicitly guards with `require(_shares > 0)` — the pools pallet has no equivalent check that the points issued to a joining/bonding member are non-zero before the deposit is transferred and staked.

### Finding Description
`BondedPool::try_bond_funds` issues points via `self.issue(amount)` and then unconditionally calls `T::StakeAdapter::pledge_bond(..., amount, ty)`, which transfers/delegates the *full* `amount` into the pool's bonded stake, regardless of how many points were actually issued: [1](#0-0) 

Point issuance is computed with truncating integer division: [2](#0-1) 

In `join`, the only pre-condition on the deposited amount is `amount >= MinJoinBond::<T>::get()`; there is no check that the resulting `points_issued` is greater than zero before the member record is stored and funds bonded: [3](#0-2) 

The same pattern repeats in `do_bond_extra` for `bond_extra`: `points_issued` from `try_bond_funds` is added directly to `member.points` with no zero check, and the corresponding `bonded` amount is unconditionally transferred/staked: [4](#0-3) 

Because `balance_to_point` computes `current_points * new_funds / current_balance` (truncating), whenever `current_points < current_balance` (which happens whenever the bonded pool's balance has grown relative to points — e.g. after staking rewards accrue to the pool's bonded stake, or after multiple prior slashes/rebalances shifted the ratio below 1), a `new_funds` amount at or slightly above `MinJoinBond`/`MinCreateBond` can produce `points_issued == 0` while the full deposited `amount` is still transferred into the bonded account and staked. The member is inserted into `PoolMembers` with `points: 0`. Their `active_balance()`/`total_balance()` (both computed via `points_to_balance`, which returns `0` when `points` is `0` — see the `current_balance.is_zero() || current_points.is_zero() || points.is_zero()` early return) will forever read `0`. The deposited value becomes an unrecoverable, silent transfer of value to the other existing point-holders of the pool: it inflates the pool's bonded balance (and thus the value of everyone else's points) without minting any corresponding claim for the depositor. [5](#0-4) 

This is the structural analog of the Aave `supplyTokenTo()` finding: a public, unprivileged, un-front-run-dependent entry point (`join`/`bond_extra`) computes shares via rounding division but transfers/stakes the full nominal amount regardless of whether any shares were actually minted for the caller — except here there is no `require(shares > 0)` guard at all, so the loss is not merely "a few wei of imprecision" but can be a complete, permanent loss of the member's entire deposit with zero recourse (the member cannot even `unbond` since `unbond` operates on `points`, and they hold `0`).

### Impact Explanation
This falls squarely within "permanent user-fund lock" / value not conserved / not settled to the rightful beneficiary from the Impact Gate: an ordinary user calling the public `join` extrinsic can have their entire deposit permanently and silently transferred to the bonded pool's other members with zero compensating points, with no admin/governance/relayer/attacker collusion required — only a pool state where `current_points/current_balance` ratio has drifted low enough (achievable after normal reward accrual over time via `bond_extra` compounding, or slashing history) combined with a deposit near the minimum bond threshold.

### Likelihood Explanation
Likelihood depends on the bonded pool's points:balance ratio drifting to the point where `MinJoinBond`/`MinCreateBond` sized deposits round to `0` points. `MinJoinBond` is a configurable, potentially small value, and ratios do legitimately drift over the life of a pool (rewards accumulate onto the bonded stake through `bond_extra(Rewards)`/compounding while points issued for that reward are proportionally smaller due to prior truncation, and slashes reduce balance relative to points inversely). Given the pallet already contains dedicated tests validating `balance_to_point`/`points_to_balance` rounding behavior (e.g. `points_to_balance_works`, `balance_to_point_works`) but none asserting `points_issued > 0` is enforced on `join`, this looks like an overlooked invariant rather than a deliberately accepted risk. [6](#0-5) 

### Recommendation
Add an explicit check analogous to the Aave fix's `require(_shares > 0)`: after computing `points_issued` in `try_bond_funds` (or immediately after calling it in `join`/`do_create`/`do_bond_extra`), `ensure!(!points_issued.is_zero(), Error::<T>::...)` before transferring/staking the member's funds, so that a deposit that would round down to zero points is rejected rather than silently donated to the rest of the pool.

### Proof of Concept
1. Create/observe a pool where `bonded_pool.points` is small relative to the bonded account's `active_stake` (e.g., after extended reward compounding via `bond_extra(Rewards)` pushes `current_balance` well above `current_points`, or after a targeted sequence of slashes/rebalances).
2. An account calls `Pools::join(origin, amount, pool_id)` with `amount == MinJoinBond` (a value that satisfies `ensure!(amount >= MinJoinBond::<T>::get())`).
3. Inside `try_bond_funds`, `self.issue(amount)` calls `balance_to_point(bonded_balance, points, amount)`, which computes `points * amount / bonded_balance` using truncating u256 division; with the ratio described above this yields `0`.
4. `pledge_bond` is still called with the full `amount`, transferring/staking it into the pool's bonded account.
5. `PoolMembers` inserts the new member with `points: 0`; `member.active_balance()`/`total_balance()` return `0` (per `point_to_balance`'s zero-points early return), and the member has no way to reclaim the deposited `amount` — it has become part of the bonded stake benefiting all other point-holders.

	fn try_bond_funds(
		&mut self,
		who: &T::AccountId,
		amount: BalanceOf<T>,
		ty: BondType,
	) -> Result<BalanceOf<T>, DispatchError> {
		// We must calculate the points issued *before* we bond who's funds, else points:balance
		// ratio will be wrong.
		let points_issued = self.issue(amount);

		T::StakeAdapter::pledge_bond(
			Member::from(who.clone()),
			Pool::from(self.bonded_account()),
			&self.reward_account(),
			amount,
			ty,
		)?;
		TotalValueLocked::<T>::mutate(|tvl| {
			tvl.saturating_accrue(amount);
		});

		Ok(points_issued)
	}

		pub fn join(
			origin: OriginFor<T>,
			#[pallet::compact] amount: BalanceOf<T>,
			pool_id: PoolId,
		) -> DispatchResult {
			let who = ensure_signed(origin)?;
			// ensure pool is not in an un-migrated state.
			ensure!(!Self::api_pool_needs_delegate_migration(pool_id), Error::<T>::NotMigrated);

			// ensure account is not restricted from joining the pool.
			ensure!(!T::Filter::contains(&who), Error::<T>::Restricted);

			ensure!(amount >= MinJoinBond::<T>::get(), Error::<T>::MinimumBondNotMet);
			// If a member already exists that means they already belong to a pool
			ensure!(!PoolMembers::<T>::contains_key(&who), Error::<T>::AccountBelongsToOtherPool);

			let mut bonded_pool = BondedPool::<T>::get(pool_id).ok_or(Error::<T>::PoolNotFound)?;
			bonded_pool.ok_to_join()?;

			let mut reward_pool = RewardPools::<T>::get(pool_id)
				.defensive_ok_or::<Error<T>>(DefensiveError::RewardPoolNotFound.into())?;
			// IMPORTANT: reward pool records must be updated with the old points.
			reward_pool.update_records(
				pool_id,
				bonded_pool.points,
				bonded_pool.commission.current(),
			)?;

			bonded_pool.try_inc_members()?;
			let points_issued = bonded_pool.try_bond_funds(&who, amount, BondType::Extra)?;

			PoolMembers::insert(
				who.clone(),
				PoolMember::<T> {
					pool_id,
					points: points_issued,
					// we just updated `last_known_reward_counter` to the current one in
					// `update_recorded`.
					last_recorded_reward_counter: reward_pool.last_recorded_reward_counter(),
					unbonding_eras: Default::default(),
				},
			);

			Self::deposit_event(Event::<T>::Bonded {
				member: who,
				pool_id,
				bonded: amount,
				joined: true,
			});

			bonded_pool.put();
			RewardPools::<T>::insert(pool_id, reward_pool);

			Ok(())
		}

	fn balance_to_point(
		current_balance: BalanceOf<T>,
		current_points: BalanceOf<T>,
		new_funds: BalanceOf<T>,
	) -> BalanceOf<T> {
		let u256 = T::BalanceToU256::convert;
		let balance = T::U256ToBalance::convert;
		match (current_balance.is_zero(), current_points.is_zero()) {
			(_, true) => new_funds.saturating_mul(POINTS_TO_BALANCE_INIT_RATIO.into()),
			(true, false) => {
				// The pool was totally slashed.
				// This is the equivalent of `(current_points / 1) * new_funds`.
				new_funds.saturating_mul(current_points)
			},
			(false, false) => {
				// Equivalent to (current_points / current_balance) * new_funds
				balance(
					u256(current_points)
						.saturating_mul(u256(new_funds))
						// We check for zero above
						.div(u256(current_balance)),
				)
			},
		}

	/// Calculate the equivalent balance of `points` in a pool with `current_balance` and
	/// `current_points`.
	fn point_to_balance(
		current_balance: BalanceOf<T>,
		current_points: BalanceOf<T>,
		points: BalanceOf<T>,
	) -> BalanceOf<T> {
		let u256 = T::BalanceToU256::convert;
		let balance = T::U256ToBalance::convert;
		if current_balance.is_zero() || current_points.is_zero() || points.is_zero() {
			// There is nothing to unbond
			return Zero::zero();
		}

		// Equivalent of (current_balance / current_points) * points
		balance(
			u256(current_balance)
				.saturating_mul(u256(points))
				// We check for zero above
				.div(u256(current_points)),
		)
	}

	fn do_bond_extra(
		signer: T::AccountId,
		member_account: T::AccountId,
		extra: BondExtra<BalanceOf<T>>,
	) -> DispatchResult {
		// ensure account is not restricted from joining the pool.
		ensure!(!T::Filter::contains(&member_account), Error::<T>::Restricted);

		if signer != member_account {
			ensure!(
				ClaimPermissions::<T>::get(&member_account).can_bond_extra(),
				Error::<T>::DoesNotHavePermission
			);
			ensure!(extra == BondExtra::Rewards, Error::<T>::BondExtraRestricted);
		}

		let (mut member, mut bonded_pool, mut reward_pool) =
			Self::get_member_with_pools(&member_account)?;

		// payout related stuff: we must claim the payouts, and updated recorded payout data
		// before updating the bonded pool points, similar to that of `join` transaction.
		reward_pool.update_records(
			bonded_pool.id,
			bonded_pool.points,
			bonded_pool.commission.current(),
		)?;
		let claimed = Self::do_reward_payout(
			&member_account,
			&mut member,
			&mut bonded_pool,
			&mut reward_pool,
		)?;

		let (points_issued, bonded) = match extra {
			BondExtra::FreeBalance(amount) => {
				(bonded_pool.try_bond_funds(&member_account, amount, BondType::Extra)?, amount)
			},
			BondExtra::Rewards => {
				(bonded_pool.try_bond_funds(&member_account, claimed, BondType::Extra)?, claimed)
			},
		};

		bonded_pool.ok_to_be_open()?;
		member.points =
			member.points.checked_add(&points_issued).ok_or(Error::<T>::OverflowRisk)?;

		Self::deposit_event(Event::<T>::Bonded {
			member: member_account.clone(),
			pool_id: member.pool_id,
			bonded,
			joined: false,
		});
		Self::put_member_with_pools(&member_account, member, bonded_pool, reward_pool);

		Ok(())
	}

	#[test]
	fn points_to_balance_works() {
		ExtBuilder::default().build_and_execute(|| {
			// 1 balance : 1 points ratio
			let mut bonded_pool = BondedPool::<Runtime> {
				id: 123123,
				inner: BondedPoolInner {
					commission: Commission::default(),
					member_counter: 1,
					points: 100,
					roles: DEFAULT_ROLES,
					state: PoolState::Open,
				},
			};

			set_pool_balance(bonded_pool.bonded_account(), 100);
			assert_eq!(bonded_pool.points_to_balance(10), 10);
			assert_eq!(bonded_pool.points_to_balance(0), 0);

			// 2 balance : 1 points ratio
			bonded_pool.points = 50;
			assert_eq!(bonded_pool.points_to_balance(10), 20);

			// 100 balance : 0 points ratio
			set_pool_balance(bonded_pool.bonded_account(), 100);
			bonded_pool.points = 0;
			assert_eq!(bonded_pool.points_to_balance(10), 0);

			// 0 balance : 100 points ratio
			set_pool_balance(bonded_pool.bonded_account(), 0);
			bonded_pool.points = 100;
			assert_eq!(bonded_pool.points_to_balance(10), 0);

			// 10 balance : 3 points ratio
			set_pool_balance(bonded_pool.bonded_account(), 100);
			bonded_pool.points = 30;
			assert_eq!(bonded_pool.points_to_balance(10), 33);

			// 2 balance : 3 points ratio
			set_pool_balance(bonded_pool.bonded_account(), 200);
			bonded_pool.points = 300;
			assert_eq!(bonded_pool.points_to_balance(10), 6);

			// 4 balance : 9 points ratio
			set_pool_balance(bonded_pool.bonded_account(), 400);
			bonded_pool.points = 900;
			assert_eq!(bonded_pool.points_to_balance(90), 40);
		})
	}
