### Title
`reap_stash` permissionlessly kills a nomination pool's bonded stash without notifying `on_withdraw`, permanently desyncing `TotalValueLocked` - (File: `substrate/frame/staking/src/pallet/mod.rs`, `substrate/frame/staking/src/pallet/impls.rs`)

### Summary
This is a direct analog of the FeiPool bug: an aggregate accounting variable (`totalStaked` in FeiPool ≈ `TotalValueLocked` in `pallet-nomination-pools`) is supposed to be decremented every time value leaves a pool's staked balance, but one of the paths that removes staked value from a pool's bonded stash skips the update hook entirely, permanently desyncing the aggregate.

### Finding Description
`pallet-nomination-pools` maintains a global `TotalValueLocked` storage item that must be decremented whenever a bonded pool's stash withdraws staked funds. This is implemented through the `OnStakingUpdate::on_withdraw` hook [1](#0-0) , which `pallet-staking`'s `do_withdraw_unbonded` correctly calls after consolidating unlocked chunks [2](#0-1) . This mechanism (PR#3052) was specifically built to fix a previous TVL-desync bug caused by staking's *implicit* withdrawal [3](#0-2) .

However, `kill_stash` — the function that fully removes a stash's ledger, unbonded lock, and staking metadata — is also called directly from two other code paths that **never** invoke `T::EventListeners::on_withdraw`:

- `force_unstake` (root-only, excluded by the gate) [4](#0-3) 
- `reap_stash`, which is **permissionless** (`ensure_signed`, callable by any account against any stash whose balance or ledger total has fallen below the existential deposit) [5](#0-4) 

Both call `Self::kill_stash(&stash, num_slashing_spans)` directly [6](#0-5) , which removes the entire `StakingLedger` (freeing the whole remaining `ledger.total` from being locked) but does not call `Self::deposit_event(Event::Withdrawn)` nor `T::EventListeners::on_withdraw`. Consequently, if the reaped stash is a nomination pool's bonded account, `pallet-nomination-pools::TotalValueLocked` is never reduced by the amount released through this path — exactly mirroring the FeiPool bug where `totalStaked` was left stale after `_withdraw`.

### Impact Explanation
Because `TotalValueLocked` is a chain-wide aggregate over all pools, once it is inflated by an un-notified `reap_stash` withdrawal of a bonded pool's dust balance, it stays permanently too high relative to the funds genuinely staked. Any logic gating pool operations on `TotalValueLocked` (issuance-relative caps, monitoring, or future governance-configured global staking limits) will operate on stale, inflated state — the same class of "public underpriced work / incorrect accounting leads to false state acceptance" identified in the FeiPool report, where a stale aggregate broke downstream invariant checks (there, a hard revert; here, a silent accounting desync of a security-relevant global counter that other subsystems trust as ground truth).

### Likelihood Explanation
`reap_stash` is a fully public, unprivileged extrinsic (`ensure_signed(origin)?`, no filter beyond stash eligibility) [7](#0-6) . Any account can trigger it against a pool's bonded stash once that stash's `ledger.total` or free balance drops below the existential deposit (a state reachable through normal pool unbonding activity, e.g. dissolving pools or heavily-slashed pools nearing dust). No malicious peer, validator, relayer, or governance actor is required — a bystander can call this extrinsic directly.

### Recommendation
In `kill_stash` (`substrate/frame/staking/src/pallet/impls.rs`), emit `Event::Withdrawn` and invoke `T::EventListeners::on_withdraw(stash, ledger.total)` for the full remaining `ledger.total` before removing the `StakingLedger`, so that `force_unstake` and `reap_stash` notify listeners identically to `do_withdraw_unbonded`'s kill branch. This mirrors the FeiPool fix of always decrementing the aggregate on every code path that reduces individual stake.

### Proof of Concept
1. Create a nomination pool; let it bond a stash account `P` via `pallet-nomination-pools`.
2. Fully unbond `P`'s active stake and let the bonding duration elapse so `ledger.active` and `ledger.total` fall to (or near) 0 / below existential deposit, but do not call `withdraw_unbonded` (so the ledger is not yet killed through the standard path that fires `on_withdraw`).
3. Any unprivileged account calls `Staking::reap_stash(origin, P, _)`. Since `ledger_total < ed` is satisfied, `reapable` is `true` and `kill_stash(&P, ..)` executes, wiping the ledger and releasing any remaining locked balance — with no call to `on_withdraw`.
4. Observe `pallet_nomination_pools::TotalValueLocked::<T>::get()` is unchanged (or higher than the real sum of pool member balances), diverging permanently from the true amount now staked, replicating the FeiPool `totalStaked`-not-decremented desync.

	/// Remove all associated data of a stash account from the staking system.
	///
	/// Assumes storage is upgraded before calling.
	///
	/// This is called:
	/// - after a `withdraw_unbonded()` call that frees all of a stash's bonded balance.
	/// - through `reap_stash()` if the balance has fallen to zero (through slashing).
	pub(crate) fn kill_stash(stash: &T::AccountId, num_slashing_spans: u32) -> DispatchResult {
		slashing::clear_stash_metadata::<T>(&stash, num_slashing_spans)?;

		// removes controller from `Bonded` and staking ledger from `Ledger`, as well as reward
		// setting of the stash in `Payee`.
		StakingLedger::<T>::kill(&stash)?;

		Self::do_remove_validator(&stash);
		Self::do_remove_nominator(&stash);

		Ok(())
	}

		#[pallet::call_index(20)]
		#[pallet::weight(T::WeightInfo::reap_stash(*num_slashing_spans))]
		pub fn reap_stash(
			origin: OriginFor<T>,
			stash: T::AccountId,
			num_slashing_spans: u32,
		) -> DispatchResultWithPostInfo {
			ensure_signed(origin)?;

			// virtual stakers should not be allowed to be reaped.
			ensure!(!Self::is_virtual_staker(&stash), Error::<T>::VirtualStakerNotAllowed);

			let ed = asset::existential_deposit::<T>();
			let origin_balance = asset::total_balance::<T>(&stash);
			let ledger_total =
				Self::ledger(Stash(stash.clone())).map(|l| l.total).unwrap_or_default();
			let reapable = origin_balance < ed ||
				origin_balance.is_zero() ||
				ledger_total < ed ||
				ledger_total.is_zero();
			ensure!(reapable, Error::<T>::FundedTarget);

			// Remove all staking-related information and lock.
			Self::kill_stash(&stash, num_slashing_spans)?;

			Ok(Pays::No.into())
		}
