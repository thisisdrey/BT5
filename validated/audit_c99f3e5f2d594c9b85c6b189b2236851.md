### Title
Operator Can Permanently Lock Staker Funds by Poisoning Beneficiary Address in `staking_contract::distribute_internal` - (File: `aptos-move/framework/aptos-framework/sources/staking_contract.move`)

### Summary

`staking_contract::distribute_internal` calls `aptos_account::deposit_coins` for each distribution recipient. An operator can set their beneficiary (via `set_beneficiary_for_operator`) to an address that has migrated away its legacy `CoinStore<AptosCoin>` and has `allow_direct_coin_transfers = false`. This causes `deposit_coins` to abort unconditionally, permanently blocking every staking-contract operation that calls `distribute_internal`: `switch_operator`, `unlock_stake`, `request_commission`, and `distribute`. The staker's APT is locked in the pool until the operator voluntarily reverses the configuration.

### Finding Description

`distribute_internal` iterates over all distribution-pool shareholders and deposits their share:

```move
if (recipient == operator) {
    recipient = beneficiary_for_operator(operator);
};
aptos_account::deposit_coins(
    recipient, coin::extract(&mut coins, amount_to_distribute)
);
``` [1](#0-0) 

`aptos_account::deposit_coins` contains the following guard:

```move
if (!coin::is_account_registered<CoinType>(to)) {
    assert!(
        can_receive_direct_coin_transfers(to),
        error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
    );
    coin::register<CoinType>(&create_signer(to));
};
coin::deposit<CoinType>(to, coins)
``` [2](#0-1) 

`coin::is_account_registered<AptosCoin>` checks for the existence of the legacy `CoinStore<AptosCoin>` resource. After an account calls `coin::migrate_to_fungible_store<AptosCoin>`, `maybe_convert_to_fungible_store` removes the `CoinStore` via `move_from`:

```move
let CoinStore<CoinType> { coin, frozen, deposit_events, withdraw_events } =
    move_from<CoinStore<CoinType>>(account);
``` [3](#0-2) 

After migration, `is_account_registered<AptosCoin>` returns `false` for that account. If the account has also called `set_allow_direct_coin_transfers(false)`:

```move
direct_transfer_config.allow_arbitrary_coin_transfers = allow;
``` [4](#0-3) 

then `can_receive_direct_coin_transfers` returns `false`, and `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`.

The operator controls their beneficiary address via `set_beneficiary_for_operator`:

```move
borrow_global_mut<BeneficiaryForOperator>(operator_addr).beneficiary_for_operator =
    new_beneficiary;
``` [5](#0-4) 

**Attack steps (all unprivileged, operator-controlled):**
1. Operator calls `coin::migrate_to_fungible_store<AptosCoin>` on their own account, removing `CoinStore<AptosCoin>`.
2. Operator calls `aptos_account::set_allow_direct_coin_transfers(false)` on their own account.
3. Operator calls `staking_contract::set_beneficiary_for_operator` pointing to their own account.
4. Any subsequent call to `distribute_internal` that has a non-zero commission to pay to the operator aborts at `deposit_coins`.

Every public entry point that calls `distribute_internal` is now blocked:

- `switch_operator` (line 785): staker cannot replace the operator.
- `unlock_stake` (line 691): staker cannot begin unlocking their APT.
- `request_commission` (line 700): commission cannot be processed.
- `distribute` (line 848): funds cannot be distributed. [6](#0-5) 

### Impact Explanation

The staker's entire APT balance held in the `StakingContract` pool is permanently frozen. They cannot unlock stake, switch to a different operator, or receive any distributions. This constitutes permanent freezing of staking balances, which is within the Aptos bounty scope. The operator suffers no loss; they simply keep their beneficiary in the poisoned state.

### Likelihood Explanation

The attack requires only three unprivileged transactions by the operator (migrate, disable-direct-transfer, set-beneficiary). No governance approval, no privileged capability, and no external dependency is needed. A malicious operator who anticipates being replaced has a clear incentive to execute this before the staker acts. The FA migration path (`migrate_to_fungible_store`) is a live, callable entry function on mainnet.

### Recommendation

Decouple the commission deposit from the critical state-change operations. Options:

1. **Lazy distribution**: In `switch_operator` and `unlock_stake`, record the pending commission as an on-chain debt rather than immediately calling `deposit_coins`. Let the operator (or anyone) claim it separately.
2. **Graceful skip**: If `deposit_coins` would fail for the operator's beneficiary, keep the commission in the pool and continue the state transition (analogous to the RocketPool fix: proceed without returning the bond if the vault is short).
3. **Validate beneficiary at set-time**: In `set_beneficiary_for_operator`, assert that the new beneficiary can receive APT (`coin::is_account_registered<AptosCoin>` or `can_receive_direct_coin_transfers`).

### Proof of Concept

```move
// Step 1: operator migrates their CoinStore away
coin::migrate_to_fungible_store<AptosCoin>(operator_signer);
// After this: coin::is_account_registered<AptosCoin>(operator_addr) == false

// Step 2: operator disables direct coin transfers
aptos_account::set_allow_direct_coin_transfers(operator_signer, false);
// After this: can_receive_direct_coin_transfers(operator_addr) == false

// Step 3: operator points beneficiary at their own (now-poisoned) address
staking_contract::set_beneficiary_for_operator(operator_signer, operator_addr);

// Step 4: staker tries to switch operators — ABORTS
// distribute_internal -> deposit_coins(operator_addr, commission)
//   -> is_account_registered == false
//   -> can_receive_direct_coin_transfers == false
//   -> abort EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS
staking_contract::switch_operator(staker_signer, operator_addr, new_operator_addr, 10);
// RESULT: staker is permanently stuck; their APT cannot be unlocked or redistributed
```

The abort path is confirmed by the formal spec:
```
aborts_if if_exist_coin && global<coin::CoinStore<CoinType>>(to).frozen;
// and implicitly: aborts if !is_account_registered && !can_receive_direct_coin_transfers

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
