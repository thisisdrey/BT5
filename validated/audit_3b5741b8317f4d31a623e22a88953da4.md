### Title
Arbitrary File Overwrite / Path Traversal via Unvalidated `tar` Extraction in `CreateRepositoryFromSnapshot` - (File: internal/gitaly/service/repository/create_repository_from_snapshot.go)

### Summary
The external report describes a SQL injection where an unsanitized user-supplied string (`invite_code`) is concatenated into a backend operation without validation. The closest analog in Gitaly is `CreateRepositoryFromSnapshot`, which takes a fully attacker/caller-controlled HTTP response body and feeds it *unvalidated* into the system `tar` binary for extraction into a live repository path — a structurally similar "trust the input verbatim" flaw, but manifesting as extraction/path-traversal rather than SQL injection.

### Finding Description
`CreateRepositoryFromSnapshot` calls `s.untar`, which fetches an archive from an attacker/caller-supplied `HttpUrl` (optionally with `HttpAuth` header and a `ResolvedAddress` override) and pipes the raw HTTP response body directly into the real `tar` executable: [1](#0-0) 

Critically, unlike every other tar-extraction code path in the same codebase, this implementation performs **no validation whatsoever** of the entries being extracted — no check for `..` path traversal, no check for absolute/relative symlink escape, no check for hardlink targets. This is explicitly acknowledged in the code's own comment: [2](#0-1) 

Contrast this with the hardened, purpose-built Go `tar` extraction used elsewhere in Gitaly for functionally the same task (extracting a repository snapshot from another node), which explicitly validates every path against directory-escape and rejects unsafe symlinks/hardlinks: [3](#0-2) 

and a similar hardened implementation exists for backup/WAL restoration and hook extraction: [4](#0-3) [5](#0-4) 

`CreateRepositoryFromSnapshot.untar` bypasses all of that hardening by delegating straight to the OS `tar` binary with no `--strip-components`, no entry filtering, and no post-extraction validation — meaning any tar entry with `../../` traversal or a malicious symlink in its `Name`/`Linkname` will be honored by GNU/BSD tar and can write or overwrite files anywhere the Gitaly process has filesystem permission for, including outside the target repository directory (e.g., other repositories' data, hook scripts, or Gitaly's own config/binaries).

### Impact Explanation
An entity able to invoke `CreateRepositoryFromSnapshot` (or supply/influence the `HttpUrl` it fetches) can serve a crafted tar stream that:
- Escapes the target repository path via `../` traversal entries, corrupting or overwriting files in sibling repositories or arbitrary storage locations.
- Plants malicious server-side hook scripts (`custom_hooks/pre-receive`, etc.) in another repository's directory, achieving command execution on subsequent pushes to that repository.
- Overwrites Gitaly configuration or other sensitive files reachable by the Gitaly process user.

This is a legitimate concrete storage-escape / arbitrary file write vulnerability class, matching the "Validate" criteria (concrete storage escape via extraction).

### Likelihood Explanation
The RPC is a mutator that only requires a valid target repository reference and a URL it is told to fetch from; the archive origin (`HttpUrl`) is treated as fully trusted despite being attacker-reachable input, and the code comment itself flags this as unhardened. Whether this RPC is currently reachable directly from an ordinary/unprivileged actor's request path (vs. only from trusted internal callers like Rails/Praefect during fork operations) could not be fully confirmed from the available proto/service registration index — the ACL/`op_type` scoping annotations on this RPC were not retrievable within the current investigation. This should be verified by inspecting `proto/repository.proto`'s `CreateRepositoryFromSnapshot` RPC option block and Praefect's route/ACL configuration for this RPC.

### Recommendation
- Replace the raw shell-out to `tar -C path -xvf -` in `untar` (create_repository_from_snapshot.go) with the same hardened, validated extraction logic already implemented in `extractTarToDirectory`/`extractFile` (replicate.go), including: rejecting entries whose resolved path escapes `path`, rejecting absolute symlinks, and validating relative symlink/hardlink targets stay within the extraction root.
- Alternatively, invoke `tar` with `--no-same-owner`, restrict entries strictly to the repository's own relative namespace, and post-validate the resulting directory tree against `storage.ValidateRelativePath`.
- Confirm and, if necessary, restrict which callers/ACL scopes can invoke `CreateRepositoryFromSnapshot`, since this RPC's docstring already flags it as untrusted-input-sensitive.

### Proof of Concept
1. Stand up an HTTP server that returns a tar stream containing an entry named `../../../victim-repo/custom_hooks/pre-receive` (or a symlink entry `evil -> /path/outside/target`).
2. Call `CreateRepositoryFromSnapshot` with `HttpUrl` pointing at that server and a target `Repository`.
3. `s.untar` pipes the response directly into `tar -C <target-repo-path> -xvf -`; because there is no path/symlink validation, the malicious entry is extracted outside of `<target-repo-path>`, demonstrating the storage escape (compare against `TestExtractTarToDirectory_SymlinkValidation`, which shows the exact escape patterns that the *sibling* function `extractTarToDirectory` explicitly blocks but `untar` does not): [6](#0-5)

func (s *server) untar(ctx context.Context, path string, in *gitalypb.CreateRepositoryFromSnapshotRequest) error {
	req, err := http.NewRequestWithContext(ctx, "GET", in.GetHttpUrl(), nil)
	if err != nil {
		return structerr.NewInvalidArgument("Bad HTTP URL: %w", err)
	}

	client := httpClient
	if resolvedAddress := in.GetResolvedAddress(); resolvedAddress != "" {
		client, err = newResolvedHTTPClient(in.GetHttpUrl(), resolvedAddress)
		if err != nil {
			return structerr.NewInvalidArgument("creating resolved HTTP client: %w", err)
		}
	}

	if in.GetHttpAuth() != "" {
		req.Header.Set("Authorization", in.GetHttpAuth())
	}

	rsp, err := client.Do(req)
	if err != nil {
		return structerr.NewInternal("HTTP request failed: %w", err)
	}
	defer rsp.Body.Close()

	if rsp.StatusCode < http.StatusOK || rsp.StatusCode >= http.StatusMultipleChoices {
		return structerr.NewInternal("HTTP server: %s", rsp.Status)
	}

	cmd, err := command.New(ctx, s.logger, []string{"tar", "-C", path, "-xvf", "-"}, command.WithStdin(rsp.Body))
	if err != nil {
		return err
	}

	return cmd.Wait()
}

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

		default:
			// Skip unsupported file types (devices, FIFOs, etc.)
			s.logger.WithField("file", header.Name).WithField("type", header.Typeflag).
				WarnContext(ctx, "skipping unsupported file type in tar archive")
		}

		if header.Typeflag == tar.TypeReg || header.Typeflag == tar.TypeDir {
			if err := os.Chmod(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("setting permissions for %s: %w", targetPath, err)
			}
		}
	}

	return nil
}

// extractBackup extracts the contents of a backup tar file to the specified directory.
// It returns any error encountered during extraction.
func extractBackup(reader io.Reader, destDir string) (string, error) {
	var repoRelPath string
	tarReader := tar.NewReader(reader)
	for {
		header, err := tarReader.Next()
		if err != nil {
			if errors.Is(err, io.EOF) {
				break
			}

			return repoRelPath, fmt.Errorf("read tar header: %w", err)
		}

		targetPath := filepath.Join(destDir, header.Name)

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return repoRelPath, fmt.Errorf("create directory %s: %w", header.Name, err)
			}

			if strings.HasSuffix(targetPath, ".git") {
				repoRelPath, err = filepath.Rel(filepath.Join(destDir, "fs"), targetPath)
				if err != nil {
					return repoRelPath, fmt.Errorf("find rel path: %w", err)
				}
			}
		case tar.TypeReg:
			if err := os.MkdirAll(filepath.Dir(targetPath), mode.Directory); err != nil {
				return repoRelPath, fmt.Errorf("create parent directory for %s: %w", header.Name, err)
			}

			file, err := os.OpenFile(targetPath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, os.FileMode(header.Mode))
			if err != nil {
				return repoRelPath, fmt.Errorf("create file %s: %w", header.Name, err)
			}

			if _, err := io.Copy(file, tarReader); err != nil {
				return repoRelPath, fmt.Errorf("write file %s: %w", header.Name, errors.Join(err, file.Close()))
			}

			if err := file.Close(); err != nil {
				return repoRelPath, fmt.Errorf("close file %s: %w", header.Name, err)
			}
		default:
			return repoRelPath, fmt.Errorf("unsupported file type %d for %s", header.Typeflag, header.Name)
		}
	}

	return repoRelPath, nil
}

// ExtractHooks unpacks a tar file containing custom hooks into a `custom_hooks`
// directory at the specified path. If stripPrefix is set, the hooks are extracted directly
// to the target directory instead of in a `custom_hooks` directory in the target directory.
func ExtractHooks(ctx context.Context, logger log.Logger, reader io.Reader, path string, stripPrefix bool) error {
	// GNU tar does not accept an empty file as a valid tar archive and produces
	// an error. Since an empty hooks tar is symbolic of a repository having no
	// hooks, the reader is peeked to check if there is any data present.
	buf := bufio.NewReader(reader)
	if _, err := buf.Peek(1); errors.Is(err, io.EOF) {
		return nil
	}

	stripComponents := "0"
	if stripPrefix {
		stripComponents = "1"
	}

	cmdArgs := []string{"-xf", "-", "-C", path, "--strip-components", stripComponents, CustomHooksDir}

	var stderrBuilder strings.Builder
	cmd, err := command.New(ctx, logger, append([]string{"tar"}, cmdArgs...),
		command.WithStdin(buf),
		command.WithStderr(&stderrBuilder))
	if err != nil {
		return fmt.Errorf("executing tar command: %w", err)
	}

	if err := cmd.Wait(); err != nil {
		stderr := stderrBuilder.String()

		// GNU and BSD tar versions have differing errors when attempting to
		// extract specified members from a valid tar archive. If the tar
		// archive is valid the errors for GNU and BSD tar should have the
		// same prefix, which can be checked to validate whether the expected
		// content is present in the archive for extraction.
		if strings.HasPrefix(stderr, "tar: custom_hooks: Not found in archive") {
			return nil
		}

		return structerr.New("waiting for tar command completion: %w", err).WithMetadata("stderr", stderr)
	}

	return nil
}
