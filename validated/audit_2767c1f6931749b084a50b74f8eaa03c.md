No vulnerability found for this question.

**Rationale:** Go's `crypto/x509` never uses the Common Name for hostname/name-constraint verification, which is the precise root cause of the Botan CVE. `VerifyHostname` explicitly ignores CN: "Note that the legacy Common Name field is ignored" [1](#0-0) , and only iterates over `c.DNSNames` for matching [2](#0-1) . Similarly, `checkChainConstraints` only checks SAN-derived DNS names/URIs/emails/IPs (`c.DNSNames`, `uris`, `emails`, `c.IPAddresses`) against name constraints — CN is never fed into this path [3](#0-2) . This is confirmed by explicit test cases asserting CN is not subject to name constraints, e.g. "CN is ignored in constrained chain" and "constraints don't apply to CN" [4](#0-3) [5](#0-4) .

Additionally, unlike Botan's buggy case-sensitive CN comparison, Go's DNS name-constraint matching itself (`dnsCompare`, `dnsHasSuffix`) is explicitly case-insensitive by design, with dedicated test coverage for mixed-case exclusion scenarios (e.g. "subdomain exclusion blocks uppercase wildcard", "uppercase subdomain exclusion blocks lowercase wildcard") [6](#0-5) [7](#0-6) [8](#0-7) .

Since Go's design intentionally excludes CN from both hostname verification and name-constraint checking (avoiding the entire class of bug described in the Botan advisory), and the DNS comparison primitives it does use are already case-insensitive, there is no analogous reachable vulnerability in this codebase.

func dnsHasSuffix(a, b string) bool {
	lenA := len(a)
	lenB := len(b)
	if lenA > lenB {
		return false
	}
	i := lenA - 1
	offset := lenA - lenB
	for ; i >= 0; i-- {
		ar, br := a[i], b[i-(offset)]
		if ar == br {
			continue
		}
		if br < ar {
			ar, br = br, ar
		}
		if 'A' <= ar && ar <= 'Z' && br == ar+'a'-'A' {
			continue
		}
		return false
	}

	if a[0] != '.' && lenB > lenA && b[lenB-lenA-1] != '.' {
		return false
	}

	return true
}

func dnsCompare(a, b string) int {
	idxA := len(a) - 1
	idxB := len(b) - 1

	for idxA >= 0 && idxB >= 0 {
		byteA := dnsCompareTable[a[idxA]]
		byteB := dnsCompareTable[b[idxB]]
		if byteA == byteB {
			idxA--
			idxB--
			continue
		}
		ret := 1
		if byteA < byteB {
			ret = -1
		}
		return ret
	}

	ret := 0
	if idxA < idxB {
		ret = -1
	} else if idxB < idxA {
		ret = 1
	}
	return ret
}
