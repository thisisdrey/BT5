### Title
Unauthenticated `/shutdown` HTTP endpoint allows any remote peer to terminate the signer event pipeline - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` treats any POST to `/shutdown` on the event-listener socket as an authoritative stop signal, with no check of sender identity, secret, or origin. Anyone with TCP reachability to the bound `bind_addr` can send the exact same raw HTTP request that `SignerStopSignaler::send` sends and permanently halt the signer's event processing loop.

### Finding Description
The comparison the code relies on is `request.url() == "/shutdown"`, which is intended to represent "the node (via `SignerStopSignaler`) told us to stop," but the branch has no way to distinguish a legitimate stop request from an attacker-forged one — `is_stopped()` becoming true is not actually equivalent to "the configured node asked to stop." The relevant code: [1](#0-0) 
This is reached inside `next_event()`, which is called in a loop from `main_loop()`: on `Err(EventError::Terminated)` the loop `break`s permanently. [2](#0-1) 
`SignerStopSignaler::send` (the legitimate caller) does nothing more than open a `TcpStream` to `local_addr` and write a plain, unauthenticated HTTP request: [3](#0-2) 
An attacker who can reach the bound event-listener address (`bind_addr` passed to `Signer::spawn` / `SignerEventReceiver::bind`) can open their own `TcpStream` and send byte-for-byte the same `POST /shutdown HTTP/1.1 ...` request. There is no shared secret, no source-IP allowlist, and no distinguishing header checked anywhere in `next_event`, `bind`, or `HttpServer` setup. The `bind` call simply opens a plain `tiny_http`-style listener: [4](#0-3) 
Once the attacker's request is processed, `stop_signal` is flipped and `EventError::Terminated` propagates up through `next_event()` -> `main_loop()`, which permanently exits the loop and logs "Caught termination signal." Since `main_loop` runs in its own dedicated thread and `Signer::spawn` never restarts it, this is a one-shot, permanent kill of the signer's HTTP event receiver — no more StackerDB chunk events, block validation responses, burn block events, or new block events are ever received again for the life of the process.

### Impact Explanation
A single unauthenticated TCP message permanently disables the event ingestion pipeline of a running stacks-signer, causing it to stop observing StackerDB messages, block proposals, burn blocks, and new blocks. Since the signer's core participation in block signing depends on this event flow, a remote unauthenticated attacker can silently disable an individual signer's participation with one packet, repeatable at will against any signer whose event endpoint is reachable. This matches "Critical - remote crash/unauthenticated DoS from few messages."

### Likelihood Explanation
The only precondition is TCP reachability to the signer's configured event-listener endpoint (`config.endpoint`, bound via `Signer::spawn`/`SignerEventReceiver::bind`). No secret, peer identity, StackerDB slot ownership, or privileged role is required — this matches the allowed unprivileged-attacker model exactly (a remote party who can connect and send arbitrary bytes to a reachable port). The attack requires exactly one crafted HTTP request and is trivially repeatable against any restart. Note the code does carry an operator-facing warning about exposing the signer's endpoint to untrusted networks, but no protocol-level authentication was ever added to the `/shutdown` path itself: [5](#0-4) 

### Recommendation
Require the `/shutdown` request to prove it originates from the trusted local stop-signaler (e.g., bind the listener to loopback-only for the shutdown path, require a per-process random shared secret/token generated at `bind()` time and included by `SignerStopSignaler::send`, or use a local-only IPC/unix-socket/pipe mechanism instead of an unauthenticated HTTP endpoint reachable on the network-bound socket).

### Proof of Concept
```rust
// libsigner/src/events.rs or a new integration test module
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use std::time::Duration;

#[test]
fn attacker_can_forge_shutdown() {
    let mut receiver: SignerEventReceiver<StacksBlockEventData> = SignerEventReceiver::new(false);
    let bound_addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    let handle = std::thread::spawn(move || receiver.main_loop());

    // Attacker: no relationship to the node, just TCP reachability
    let mut stream = TcpStream::connect(bound_addr).unwrap();
    let body = "forged shutdown";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
        bound_addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // main_loop should exit promptly, proving the pipeline was killed by an
    // unauthenticated actor mimicking SignerStopSignaler::send
    handle.join().unwrap();

    // Any subsequent legitimate node POST to this address will now fail to be processed,
    // since the receiver thread has terminated permanently.
    assert!(TcpStream::connect_timeout(&bound_addr, Duration::from_millis(200)).is_err());
}
```
