### Title
Operator-controlled beneficiary with disabled direct coin transfers permanently blocks `terminate_vesting_contract`, `update_operator`, and all `distribute_internal` callers — (`aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

`staking_contract::distribute_internal` atomically bundles commission distribution with every principal-withdrawal path. It calls `aptos_account::deposit_coins(operator_beneficiary, commission_coins)`. If the operator's beneficiary address exists on-chain, is not registered for `AptosCoin`, and has called `set_allow_direct_coin_transfers(false)`, then `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`. Because `distribute_internal` is called unconditionally at the start of `unlock_stake` and `switch_operator`, this single abort propagates upward and permanently blocks `vesting::terminate_vesting_contract`, `vesting::update_operator`, `vesting::vest`, and every other path that must flush pending distributions before proceeding.

---

### Finding Description

**Step 1 — Unprivileged setup.**
Any operator can call `set_beneficiary_for_operator` to point their commission to an arbitrary address:

```move
public entry fun set_beneficiary_for_operator(
    operator: &signer, new_beneficiary: address
) acquires BeneficiaryForOperator {
``` [1](#0-0) 

The operator sets `new_beneficiary` to an address that (a) exists on-chain, (b) is **not** registered for `AptosCoin`, and (c) has previously called `set_allow_direct_coin_transfers(false)`. All three conditions are achievable without any privileged capability.

**Step 2 — The abort in `deposit_coins`.**
`aptos_account::deposit_coins` checks, for an unregistered recipient, whether direct transfers are allowed:

```move
if (!coin::is_account_registered<CoinType>(to)) {
    assert!(
        can_receive_direct_coin_transfers(to),
        error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
    );
``` [2](#0-1) 

If `allow_arbitrary_coin_transfers == false` for the beneficiary, this assertion aborts.

**Step 3 — `distribute_internal` is the chokepoint.**
Every distribution path routes through `distribute_internal`, which sends commission to the operator's beneficiary:

```move
if (recipient == operator) {
    recipient = beneficiary_for_operator(operator);
};
aptos_account::deposit_coins(
    recipient, coin::extract(&mut coins, amount_to_distribute)
);
``` [3](#0-2) 

**Step 4 — `distribute_internal` is called unconditionally before every critical operation.**

`staking_contract::unlock_stake` calls it first: [4](#0-3) 

`staking_contract::switch_operator` calls it first: [5](#0-4) 

**Step 5 — Propagation to vesting.**

`vesting::withdraw_stake` calls `staking_contract::distribute`: [6](#0-5) 

`vesting::terminate_vesting_contract` calls `distribute` (which calls `withdraw_stake`) before it can unlock remaining stake: [7](#0-6) 

`vesting::update_operator` calls `staking_contract::switch_operator`, which calls `distribute_internal`: [8](#0-7) 

Because every escape route (`terminate_vesting_contract`, `update_operator`) also calls `distribute_internal`, there is no recovery path once the operator sets a blocking beneficiary.

---

### Impact Explanation

The vesting contract's entire APT staking balance is permanently frozen. The admin cannot:
- Terminate the vesting contract (blocked at `distribute`)
- Change the operator to a cooperative one (blocked at `switch_operator` → `distribute_internal`)
- Vest or distribute rewards (blocked at `unlock_stake` → `distribute_internal`)
- Call `admin_withdraw` (requires prior termination)

This constitutes **permanent freezing of vesting balances**, which are user-controlled on-chain APT assets.

---

### Likelihood Explanation

The operator is a semi-trusted party. A malicious or compromised operator can execute this grief with two cheap, unprivileged transactions:
1. Create/control an account and call `set_allow_direct_coin_transfers(false)` on it.
2. Call `set_beneficiary_for_operator` pointing to that address.

No special capability, governance vote, or privileged key is required. The attack is irreversible once any commission has accrued (so `distribute_internal` has non-zero coins to distribute).

---

### Recommendation

Decouple commission distribution from the principal-withdrawal path. Specifically:

1. In `distribute_internal`, wrap each `aptos_account::deposit_coins` call in a try/skip pattern (or use a pull-payment model where recipients claim their own commission rather than having it pushed atomically).
2. Alternatively, validate in `set_beneficiary_for_operator` that the new beneficiary is registered for `AptosCoin` and has direct transfers enabled, rejecting addresses that would cause future distributions to abort.
3. At minimum, `terminate_vesting_contract` and `update_operator` should not be gated behind a distribution step that can be made to fail by the operator.

---

### Proof of Concept

```
// Off-chain setup (attacker = operator)
1. Create account at address BAD_ADDR.
2. BAD_ADDR calls: set_allow_direct_coin_transfers(false)
   // BAD_ADDR now has DirectTransferConfig { allow_arbitrary_coin_transfers: false }
   // BAD_ADDR is NOT registered for AptosCoin

3. Operator calls: set_beneficiary_for_operator(operator_signer, BAD_ADDR)
   // BeneficiaryForOperator { beneficiary_for_operator: BAD_ADDR } stored under operator

// Now any call that reaches distribute_internal will abort:

4. Admin calls: terminate_vesting_contract(admin, contract_address)
   → vesting::distribute(contract_address)
   → vesting::withdraw_stake(...)
   → staking_contract::distribute(contract_address, operator)
   → staking_contract::distribute_internal(...)
   → aptos_account::deposit_coins(BAD_ADDR, commission_coins)
   → can_receive_direct_coin_transfers(BAD_ADDR) == false
   → ABORT: EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS

5. Admin calls: update_operator(admin, contract_address, new_operator, ...)
   → staking_contract::switch_operator(...)
   → distribute_internal(...)  ← same abort

// Admin is permanently locked out. Vesting balance is frozen.
```

    public entry fun set_beneficiary_for_operator(
        operator: &signer, new_beneficiary: address
    ) acquires BeneficiaryForOperator {
        assert!(
            features::operator_beneficiary_change_enabled(),
            std::error::invalid_state(EOPERATOR_BENEFICIARY_CHANGE_NOT_SUPPORTED)
        );
        // The beneficiay address of an operator is stored under the operator's address.
        // So, the operator does not need to be validated with respect to a staking pool.
        let operator_addr = signer::address_of(operator);
        let old_beneficiary = beneficiary_for_operator(operator_addr);
        if (exists<BeneficiaryForOperator>(operator_addr)) {
            borrow_global_mut<BeneficiaryForOperator>(operator_addr).beneficiary_for_operator =
                new_beneficiary;
        } else {
            move_to(
                operator,
                BeneficiaryForOperator { beneficiary_for_operator: new_beneficiary }
            );
        };

        emit(
            SetBeneficiaryForOperator {
                operator: operator_addr,
                old_beneficiary,
                new_beneficiary
            }
        );
    }

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

        emit(
            Terminate {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
            },
        );
    }
