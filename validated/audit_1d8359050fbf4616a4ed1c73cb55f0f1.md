### Title
Unauthenticated HTTP event listener lets any remote peer inject forged StackerDB/block/burn events into a signer's runloop - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver`, the `libsigner` transport component that the `stacks-signer` binary uses to receive event pushes from its paired `stacks-node`, exposes a plain HTTP server with **no authentication check whatsoever** on the endpoints that feed data into the signer's decision pipeline (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`). Any host that can reach the bound port can POST forged JSON payloads that are deserialized and forwarded verbatim as trusted `SignerEvent`s.

### Finding Description
`SignerEventReceiver::next_event` dispatches inbound HTTP requests purely by URL path, with zero credential verification: [1](#0-0) 

Contrast this with the node side of the same channel: the Stacks node explicitly documents and enforces an `auth_token`/`Authorization` header to protect the *node's* signer-facing endpoints (`/v3/block_proposal`, `/v2/blocks?broadcast=1`): [2](#0-1) 

But the reverse direction — the node pushing events *into* the signer via `SignerEventReceiver` — has no analogous check anywhere in `libsigner`. A grep across the entire `libsigner` crate for `auth_token`, `Authorization`, `password`, or `secret` returns no matches; the HTTP decoding layer (`libsigner/src/http.rs`) parses headers generically but never validates them: [3](#0-2) 

`process_event` simply reads the body, deserializes it into the expected type, and converts it into a `SignerEvent` — accepting it unconditionally regardless of who sent the request: [4](#0-3) 

Each of the four data-bearing conversions is reachable this way:
- `StackerDBChunksEvent -> SignerEvent` (does internally recover a signer key per-chunk via `chunk.recover_pk()`, so *miner/signer StackerDB message* content is at least keyed by an on-chain-verifiable pubkey, but the event *envelope itself* — which contract, which slots were "modified" — is fully attacker-controlled since there's no proof it came from the real node's StackerDB replica): [5](#0-4) 
- `BlockValidateResponse -> SignerEvent::BlockValidationResponse` has **no verification at all**: [6](#0-5) 
- `BurnBlockEvent -> SignerEvent::NewBurnBlock` has **no verification at all**: [7](#0-6) 

Deployment guidance in this very repo makes the exposure concrete: the shipped sample signer config binds the event-receiver socket to all interfaces, not just loopback: [8](#0-7) 
`grep` confirms `endpoint = "0.0.0.0:...` appears in `sample/conf/signer/mainnet-signer-conf.toml` and `stacks-signer/src/tests/conf/signer-0.toml`, i.e. this is a documented/sample deployment pattern, not a theoretical misconfiguration.

This is the direct analog of the reported bug class: the report's `withdrawAdminFees()` broke the equality "amount actually owed vs. amount recorded as owed" because a required state-invariant check (`resetting adminFees`) was missing. Here, the broken equality is "message actually sent by the trusted node vs. message accepted as if sent by the trusted node" — the required check (verifying the caller's identity/credential) is entirely absent on this transport endpoint, even though the symmetric node-side endpoint enforces exactly this kind of check.

### Impact Explanation
Any network-reachable, unprivileged attacker who can connect to the signer's bound event-receiver port can:
- Inject a forged `BlockValidateResponse` (`/proposal_response`) that the signer's runloop will treat as if the local node validated (or rejected) a block — a raw unauthenticated write into signer state feeding block-signing decisions.
- Inject forged `BurnBlockEvent` / `StacksBlockEvent` data (`/new_burn_block`, `/new_block`), corrupting the signer's view of chain progress.
- Inject a forged `StackerDBChunksEvent` envelope claiming arbitrary "modified slots" for a chosen contract, at will and repeatedly, without needing to actually win a StackerDB write (the object-level per-chunk signature only proves who authored the chunk *payload* if present — it does not gate whether the *event notification itself* is genuine).

This is exactly the kind of "unauthenticated/unauthorized write to state" that the rules classify as Critical severity, achieved with a handful of unauthenticated HTTP requests (no volumetric flooding needed).

### Likelihood Explanation
High. No secret, key, or privileged role is required — only network reachability to the bound TCP port. The shipped sample configuration in this repository explicitly binds this endpoint on `0.0.0.0`, and the design provides no compensating control (no token, no mTLS, no source-IP allowlist enforced by `libsigner` itself) to prevent exploitation once reachable.

### Recommendation
Add a shared-secret/token authentication check (mirroring the node's `auth_token`/`Authorization` mechanism already used for the node-side signer endpoints) to `SignerEventReceiver::next_event` in `libsigner/src/events.rs`, rejecting any `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` request that lacks a valid credential, before deserializing or forwarding the body. Additionally, default the sample/documented `endpoint` configuration to bind on loopback only, and require an explicit, deliberate opt-in (with an auth token mandatorily configured) to bind on a non-loopback interface.

### Proof of Concept
1. Start a `stacks-signer` per `sample/conf/signer/mainnet-signer-conf.toml`, which binds `endpoint = "0.0.0.0:30000"` (confirmed present in that sample file and in `stacks-signer/src/tests/conf/signer-0.toml`).
2. From any host that can reach port 30000 (no credentials, no key), send:
```
POST /proposal_response HTTP/1.1
Host: <signer-ip>:30000
Content-Type: application/json
Content-Length: <n>

{ ... forged BlockValidateResponse JSON ... }
```
3. `SignerEventReceiver::next_event` (libsigner/src/events.rs:437-447) routes this to `process_event::<T, BlockValidateResponse>`, which deserializes the JSON and, via the unconditional `TryFrom<BlockValidateResponse> for SignerEvent<T>` (libsigner/src/events.rs:627-635), forwards it straight into the signer's runloop channel as if the paired stacks-node had sent it — with no signature, token, or source check anywhere in the path.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

impl<T: SignerEventTrait> TryFrom<StackerDBChunksEvent> for SignerEvent<T> {
    type Error = EventError;

    fn try_from(event: StackerDBChunksEvent) -> Result<Self, Self::Error> {
        let received_time = SystemTime::now();
        let signer_event = if event.contract_id.name.as_str() == MINERS_NAME
            && event.contract_id.is_boot()
        {
            let mut messages = vec![];
            for chunk in event.modified_slots {
                match T::consensus_deserialize(&mut chunk.data.as_slice()) {
                    Ok(msg) => messages.push(msg),
                    Err(e) => {
                        debug!(
                            "Signer failed to deserialize miner chunk";
                            "slot_id" => chunk.slot_id,
                            "slot_version" => chunk.slot_version,
                            "data_len" => chunk.data.len(),
                            "error" => %e,
                        );
                    }
                }
            }
            SignerEvent::MinerMessages(messages)
        } else if event.contract_id.name.starts_with(SIGNERS_NAME) && event.contract_id.is_boot() {
            let Some((signer_set, message_id)) =
                get_signers_db_signer_set_message_id(event.contract_id.name.as_str())
            else {
                return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
            };
            // signer-XXX-YYY boot contract
            //
            // NOTE: the payload-type check below uses v0 `SignerMessageTypePrefix` semantics
            // (the mapping in `signer_message_payload_matches_lane` is fixed to v0). Future
            // signer-message versions must extend that mapping, or their chunks will not be
            // recognized here regardless of which `T` is in scope.
            let messages: Vec<_> = event
                .modified_slots
                .iter()
                .filter_map(|chunk| {
                    // Accept only payloads whose type is valid for this contract's message id.
                    let &type_byte = chunk.data.first()?;
                    let payload_kind = SignerMessageTypePrefix::from_u8(type_byte)?;
                    if !signer_message_payload_matches_lane(payload_kind, message_id) {
                        warn!(
                            "Skipping signer chunk with unexpected payload type for contract";
                            "contract" => %event.contract_id,
                            "lane_message_id" => message_id,
                            "payload_type_prefix" => type_byte,
                        );
                        return None;
                    }
                    let Ok(pk) = chunk.recover_pk() else {
                        warn!(
                            "Skipping signer chunk: signature recovery failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    let Ok(message) = read_next::<T, _>(&mut &chunk.data[..]) else {
                        warn!(
                            "Skipping signer chunk: payload deserialization failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    Some((chunk.slot_id, pk, message))
                })
                .collect();
            SignerEvent::SignerMessages {
                signer_set,
                messages,
                received_time,
            }
        } else {
            return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
        };
        Ok(signer_event)
    }
}

/// Returns (verb, path, table of headers, body_offset) on success
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}
