### Title
Any exception during block/transaction trigger or filter construction in `Manager.blockTrigger()` is converted into a `TronError` that crashes the node - (File: framework/src/main/java/org/tron/core/db/Manager.java)

### Summary
`Manager.blockTrigger()`, invoked for every applied block, wraps the calls that build and post block/transaction event-subscribe triggers and JSON-RPC filters (`postBlockFilter`, `postLogsFilter`, `postSolidityFilter`, `postBlockTrigger`, `postSolidityTrigger`) in a single `try { ... } catch (Exception e) { throw new TronError(e, EVENT_SUBSCRIBE_ERROR); }` block. [1](#0-0) 
`TronError` is documented and tested to trigger `System.exit()` via the JVM's default uncaught-exception handler, i.e. it kills the node process. [2](#0-1) 
A unit test confirms this exact behavior — any `RuntimeException` surfacing from the trigger-posting calls inside `blockTrigger` is rethrown as `TronError`: [3](#0-2) 

This is structurally identical to the SurrealDB bug class: a data-dependent evaluation/formatting error inside the “notify subscribers” side path is not isolated from the main write/consensus path, so a malformed input can turn a benign write (here: block application) into a hard failure of the whole system.

### Finding Description
Notably, the project has already recognized and fixed this exact failure mode for **contract-level** triggers: `postContractTrigger()` wraps each `contractTriggerCapsule.processTrigger()` call in its own `try { ... } catch (Throwable throwable) { logger.warn(...); }`, explicitly to prevent a bad trigger from aborting anything else, as confirmed by `ManagerMockTest.testPostContractTriggerSwallowsThrowable`. [4](#0-3) [5](#0-4) 

However, the sibling **block-level** trigger/filter path called from `blockTrigger()` — `postBlockFilter`/`postLogsFilter` (JSON-RPC full-node filters), `postSolidityFilter`, `postBlockTrigger` → `processTransactionTrigger` → `postTransactionTrigger` (which constructs `TransactionLogTriggerCapsule` from raw transaction/internal-transaction/log data), and `postSolidityTrigger` — has **no per-item exception isolation**. [6](#0-5) [7](#0-6) 
Any exception raised while these objects are built or serialized from attacker-influenced transaction/log content (contract logs, internal-transaction lists, ABI-based event decoding used by `BlockEventGet`) is not caught locally; it propagates up to `blockTrigger()`'s outer catch, which is deliberately designed to convert it into a fatal `TronError`. [8](#0-7) 

Because `blockTrigger()` runs during ordinary block application (`pushBlock`) on every node that has JSON-RPC full/solidity-node filters or the event-subscribe plugin enabled, a single crafted transaction that reaches this unprotected sub-path deterministically crashes every such node that applies the block containing it — a much stronger outcome than the original SurrealDB report (which only blocked writes on one node/session).

### Impact Explanation
If reachable, this is a full node crash/halt (`System.exit`) triggered by ordinary transaction content, not requiring any special privilege — any account that can broadcast a transaction (deploy/call a contract producing a particular log/event or internal transaction) could potentially crash all full nodes and JSON-RPC nodes on the network that process the resulting block, since block content and its trigger/filter derivation are identical everywhere. This falls squarely under the accepted "node crash or halt" impact category.

### Likelihood Explanation
The asymmetry between the hardened `postContractTrigger` (catches `Throwable` per item) and the unhardened `postBlockTrigger`/`processTransactionTrigger`/`postSolidityTrigger`/filter path strongly suggests the latter is an overlooked instance of the same bug class that was already fixed once in this codebase. I was not able to fully verify, within the available tool budget, a concrete data-crafted throw site (e.g., in `ContractEventParserAbi.parseTopics/parseEventData` or `TransactionLogTriggerCapsule`'s internal-transaction/log serialization) that an unprivileged transaction can trigger; this needs confirmation via code/fuzz review of those constructors before treating this as fully proven. The escalation path (any Exception → TronError → System.exit) is, however, directly demonstrated by the code and its own test.

### Recommendation
Apply the same isolation pattern used in `postContractTrigger` to the rest of the trigger/filter pipeline invoked from `blockTrigger()`: wrap `postBlockFilter`, `postLogsFilter`, `postSolidityFilter`, `postBlockTrigger`/`processTransactionTrigger`/`postTransactionTrigger`, and `postSolidityTrigger` (or their per-item inner loops) in local `try/catch(Throwable)` blocks that log and skip the offending trigger/filter instead of letting the exception escape to `blockTrigger()`'s fatal `TronError` handler. Reserve `TronError`/`System.exit` for genuinely unrecoverable infrastructure failures, not for data-dependent event-subscription formatting errors.

### Proof of Concept
Not independently reproduced. The reasoning is based on the confirmed code paths and the project's own regression test:
1. `ManagerTest.blockTrigger()` proves that any exception from `postBlockTrigger` (or, by the same code path, `postSolidityTrigger`/`postBlockFilter`/`postLogsFilter`) becomes a fatal `TronError`. [3](#0-2) 
2. Unlike `postContractTrigger`, none of `postBlockTrigger`, `processTransactionTrigger`, `postTransactionTrigger`, or `postSolidityTrigger` catch per-item exceptions. [9](#0-8) 
A concrete exploit would require identifying a transaction/log/internal-transaction shape that throws inside `TransactionLogTriggerCapsule` construction or the ABI/event-decoding logic in `BlockEventGet`; confirming that requires deeper code/dynamic analysis than was possible here.

  void blockTrigger(final BlockCapsule block, long oldSolid, long newSolid) {
    // post block and logs for jsonrpc
    try {
      if (CommonParameter.getInstance().isJsonRpcHttpFullNodeEnable()) {
        postBlockFilter(block, false);
        postLogsFilter(block, false, false);
      }

      if (CommonParameter.getInstance().isJsonRpcHttpSolidityNodeEnable()) {
        postSolidityFilter(oldSolid, newSolid);
      }

      if (EventPluginLoader.getInstance().getVersion() != 0) {
        lastUsedSolidityNum = newSolid;
        return;
      }

      // if event subscribe is enabled, post block trigger to queue (real-time, not removed)
      postBlockTrigger(block, false);
      // if event subscribe is enabled, post solidity trigger to queue
      // (also emits solidified-mode block/transaction triggers)
      postSolidityTrigger(newSolid);
    } catch (Exception e) {
      logger.error("Block trigger failed. head: {}, oldSolid: {}, newSolid: {}",
          block.getNum(), oldSolid, newSolid, e);
      throw new TronError(e, TronError.ErrCode.EVENT_SUBSCRIBE_ERROR);
    }
  }

  // Real-time block/transaction triggers for a single block. The solidified-mode batch is
  // handled in postSolidityTrigger (driven by solidification advancement), so here we only
  // emit for triggers configured as non-solidified. {@code removed=true} re-emits the same
  // trigger when the block is rolled back by a chain reorg (see reOrgBlockTrigger).
  void postBlockTrigger(final BlockCapsule blockCapsule, boolean removed) {
    long solidityBlkNum = getDynamicPropertiesStore().getLatestSolidifiedBlockNum();

    if (eventPluginLoaded && EventPluginLoader.getInstance().isBlockLogTriggerEnable()
        && !EventPluginLoader.getInstance().isBlockLogTriggerSolidified()) {
      BlockLogTriggerCapsule blockLogTriggerCapsule = new BlockLogTriggerCapsule(blockCapsule);
      blockLogTriggerCapsule.setLatestSolidifiedBlockNumber(solidityBlkNum);
      blockLogTriggerCapsule.setRemoved(removed);
      if (!triggerCapsuleQueue.offer(blockLogTriggerCapsule)) {
        logger.info("Too many triggers, block trigger lost: {}.", blockCapsule.getBlockId());
      }
    }

    if (eventPluginLoaded && EventPluginLoader.getInstance().isTransactionLogTriggerEnable()
        && !EventPluginLoader.getInstance().isTransactionLogTriggerSolidified()) {
      processTransactionTrigger(blockCapsule, removed);
    }
  }

  public SmartContractTrigger getContractTrigger(BlockCapsule block, long solidNum) {

    GrpcAPI.TransactionInfoList list = manager.getTransactionInfoByBlockNum(block.getNum());

    SmartContractTrigger contractTrigger = new SmartContractTrigger();
    for (int i = 0; i < block.getTransactions().size(); i++) {
      Protocol.Transaction tx = block.getInstance().getTransactions(i);
      Protocol.TransactionInfo txInfo = list.getTransactionInfo(i);

      List<ContractTrigger> triggers = parseLogs(tx, txInfo);
      for (ContractTrigger trigger : triggers) {
        if (!EventPluginLoader.matchFilter(trigger)) {
          continue;
        }
        ContractTrigger eventOrLog = processTrigger(trigger);
        eventOrLog.setBlockHash(Hex.toHexString(block.getBlockId().getBytes()));
        eventOrLog.setLatestSolidifiedBlockNumber(solidNum);
        if (eventOrLog instanceof ContractEventTrigger) {
          ContractEventTrigger event = (ContractEventTrigger) eventOrLog;
          if (instance.isContractEventTriggerEnable() || instance.isSolidityEventTriggerEnable()) {
            contractTrigger.getContractEventTriggers().add(event);
          }
          if ((instance.isContractLogTriggerEnable()
              && instance.isContractLogTriggerRedundancy())
              || (instance.isSolidityLogTriggerEnable()
              && instance.isSolidityLogTriggerRedundancy())) {
            ContractLogTrigger logTrigger = new ContractLogTrigger(event);
            logTrigger.setTopicList(trigger.getLogInfo().getHexTopics());
            logTrigger.setData(trigger.getLogInfo().getHexData());
            contractTrigger.getRedundancies().add(logTrigger);
          }
        } else if (eventOrLog instanceof ContractLogTrigger) {
          ContractLogTrigger log = (ContractLogTrigger) eventOrLog;
          if (instance.isContractLogTriggerEnable() || instance.isSolidityLogTriggerEnable()) {
            contractTrigger.getContractLogTriggers().add(log);
          }
        }
      }
    }

    return contractTrigger;
  }
