### Title
Pingback handshake accept stores self-reported (unverified) `addrbytes`/`port` in `PeerDB`, decoupling the authenticated socket from the stored `NeighborKey` - (File: stackslib/src/net/neighbors/walk.rs)

### Summary
In `NeighborWalk::pingback_handshakes_try_finish`, the code verifies only that the responder's `node_public_key` hashes to the expected `naddr.public_key_hash` via `check_handshake_pubkey_hash`, but then persists the neighbor using the *self-reported* `data.handshake.addrbytes`/`data.handshake.port` field rather than the address (`naddr`) that was actually dialed and that the TCP/session-level handshake proved reachable. This lets a peer that legitimately owns a keypair (and legitimately received a pingback at its real address) get an arbitrary, attacker-chosen IP:port written into `PeerDB` as its `Neighbor` record.

### Finding Description
The pingback flow is:
1. `pingback_handshakes_begin` (stackslib/src/net/neighbors/walk.rs:1589) dials out to `naddr` (the address the node actually decided to verify, derived from the original inbound connection).
2. `pingback_handshakes_try_finish` (stackslib/src/net/neighbors/walk.rs:1683) collects the reply. For `HandshakeAccept`/`StackerDBHandshakeAccept`, it builds `peer_nk` from the payload's self-reported fields:
```rust
let peer_nk = message.to_neighbor_key(&data.handshake.addrbytes, data.handshake.port);
if !Self::check_handshake_pubkey_hash(&peer_nk, data, &naddr) {
    continue;
}
self.neighbor_db.add_or_schedule_replace_neighbor(
    network, &message.preamble, &data.handshake, db_data, &mut self.neighbor_replacements,
)?;
```
3. `check_handshake_pubkey_hash` (stackslib/src/net/neighbors/walk.rs:1664-1680) only compares `Hash160::from_node_public_key_buffer(&data.handshake.node_public_key)` against `naddr.public_key_hash`. It never compares `data.handshake.addrbytes`/`port` to `naddr.addrbytes`/`naddr.port` (the address that was actually dialed and over which the session was authenticated).
4. `add_or_schedule_replace_neighbor` (stackslib/src/net/neighbors/db.rs:368-426) calls `Neighbor::load_and_update(&tx, preamble.peer_version, preamble.network_id, handshake)` where `handshake` is `&data.handshake` — i.e., the self-reported address fields, not `naddr`. The resulting `Neighbor` (keyed by this self-reported address) is then `save()`d into `PeerDB`, and can also be scheduled into `NeighborReplacements`/`replace_neighbors` (stackslib/src/net/neighbors/db.rs:463-505), which calls `PeerDB::insert_or_replace_peer`.

The broken invariant is: the session that cryptographically authenticated the handshake (TCP connect to `naddr.addrbytes:naddr.port`, receipt of a validly-signed `HandshakeAccept`) proves the peer controls that specific socket, but the code stores a *different*, attacker-supplied `addrbytes`/`port` pulled from the payload body as the peer's `NeighborKey`. Nothing ties the stored address back to the socket that was actually used for the authenticated exchange.

### Impact Explanation
An attacker who legitimately connects inbound once (with their own real keypair) and is scheduled for a pingback can, upon replying to the pingback handshake, claim an arbitrary third-party IP:port in the `HandshakeAccept.handshake.addrbytes/port` fields. This forged `(pubkey_hash, victim_addrbytes, victim_port)` tuple is written into the node's `PeerDB` as a legitimate neighbor. Because `PeerDB` entries are the source of gossiped `Neighbors`/peer-list responses (used elsewhere in the walk and RPC neighbor-listing code), this forged record can propagate network-wide, causing other nodes to attempt outbound connections to the attacker-chosen (victim) address — an unauthenticated write of forged peer state that the network subsequently relays and acts on. This matches the Critical category "unauthenticated/unauthorized write to state ... network-wide propagation of forged data."

### Likelihood Explanation
- The attacker needs only to be an ordinary, unprivileged remote peer: open one inbound TCP connection to the target node's P2P port, complete a normal `Handshake`, and be selected for a pingback (a normal occurrence for "newly discovered inbound peers").
- No secrets, admin roles, or privileged access are needed; the attacker uses their own valid keypair, satisfying `check_handshake_pubkey_hash`.
- The attack is repeatable per pingback round and cheap (a single crafted `HandshakeAcceptData`/`StackerDBHandshakeAcceptData` message).

### Recommendation
In `pingback_handshakes_try_finish` (and anywhere `add_or_schedule_replace_neighbor`/`Neighbor::load_and_update` is fed handshake data), do not trust `data.handshake.addrbytes`/`port` for identity/storage purposes when they were obtained via a self-reported field in a message payload. Instead, bind and persist the neighbor using the address that was actually dialed/authenticated (`naddr.addrbytes`/`naddr.port`, or the underlying socket's peer address), and additionally verify (or explicitly reject on mismatch) that `data.handshake.addrbytes/port == naddr.addrbytes/port` before calling `check_handshake_pubkey_hash`/`add_or_schedule_replace_neighbor`.

### Proof of Concept

3. Drive A through `pingback_handshakes_begin`, which dials out to `naddr` and sends a `Handshake`.

    /// Does a given handshakedata represent an expected public key hash?
    fn check_handshake_pubkey_hash(
        nk: &NeighborKey,
        data: &HandshakeAcceptData,
        naddr: &NeighborAddress,
    ) -> bool {
        let neighbor_pubkey_hash =
            Hash160::from_node_public_key_buffer(&data.handshake.node_public_key);
        if neighbor_pubkey_hash != naddr.public_key_hash {
            debug!(
                "Neighbor {:?} had an unexpected pubkey hash: expected {:?} != {:?}",
                nk, &naddr.public_key_hash, &neighbor_pubkey_hash
            );
            return false;
        }

        true
    }

    fn add_or_schedule_replace_neighbor(
        &self,
        network: &mut PeerNetwork,
        preamble: &Preamble,
        handshake: &HandshakeData,
        db_data: Option<&StackerDBHandshakeData>,
        replacements: &mut NeighborReplacements,
    ) -> Result<(bool, Neighbor), net_error> {
        let local_peer_str = format!("{:?}", network.get_local_peer());
        let tx = network.peerdb_tx_begin()?;
        let (mut neighbor_from_handshake, was_present) =
            Neighbor::load_and_update(&tx, preamble.peer_version, preamble.network_id, handshake)?;

        if was_present {
            test_debug!(
                "{}: already know about neighbor {:?}",
                &local_peer_str,
                &neighbor_from_handshake.addr
            );
            neighbor_from_handshake
                .save_update(&tx, db_data.map(|x| x.smart_contracts.as_slice()))?;
            tx.commit()?;

            // seen this neighbor before
            return Ok((false, neighbor_from_handshake));
        }

        debug!(
            "{}: new neighbor {:?}",
            &local_peer_str, &neighbor_from_handshake.addr
        );

        // didn't know about this neighbor yet. Try to add it.
        let added =
            neighbor_from_handshake.save(&tx, db_data.map(|x| x.smart_contracts.as_slice()))?;

        if added {
            // neighbor was new, and we had space to add it.
            tx.commit()?;
            return Ok((true, neighbor_from_handshake));
        }

        // neighbor was new, but we don't have space to insert it.
        // find and record a neighbor it would replace.
        let replaced_neighbor_slot_opt =
            Self::find_replaced_neighbor_slot(&tx, &neighbor_from_handshake.addr)?;
        if let Some(slot) = replaced_neighbor_slot_opt {
            replacements.add_neighbor(
                NeighborAddress::from_neighbor(&neighbor_from_handshake),
                neighbor_from_handshake.clone(),
                slot,
            );
        }

        tx.commit()?;

        // neighbor was new
        Ok((true, neighbor_from_handshake))
    }

    fn replace_neighbors(
        &self,
        network: &mut PeerNetwork,
        replacements: &NeighborReplacements,
        result: &mut NeighborWalkResult,
    ) -> Result<(), net_error> {
        let network_id = network.bound_neighbor_key().network_id;
        let local_peer_str = format!("{:?}", network.get_local_peer());

        let tx = network.peerdb_tx_begin()?;
        for (replaceable_naddr, slot) in replacements.iter_slots() {
            let replacement = match replacements.get_neighbor(replaceable_naddr) {
                Some(n) => n,
                None => {
                    continue;
                }
            };

            let replaced_opt = PeerDB::get_peer_at(&tx, network_id, *slot)?;
            if let Some(replaced) = replaced_opt {
                if PeerDB::is_address_denied(&tx, &replacement.addr.addrbytes)? {
                    debug!(
                        "{:?}: Will not replace {:?} with {:?} -- is denied",
                        local_peer_str, &replaced.addr, &replacement.addr
                    );
                    continue;
                }
                debug!(
                    "{:?}: Replace {:?} with {:?}",
                    local_peer_str, &replaced.addr, &replacement.addr
                );

                PeerDB::insert_or_replace_peer(&tx, replacement, *slot)?;
                result.add_replaced(DropNeighbor {
                    key: replaced.addr.clone(),
                    reason: DropReason::ReplacedConnection,
                    source: DropSource::NeighborWalkPeerDB,
                });
            }
        }
        tx.commit()?;
        Ok(())
    }
