### Title
Unbounded slice indexing while parsing reftable ref blocks causes a panic/DoS on malformed `.ref` table files - (File: `internal/git/reftable/reftable.go`)

### Summary
`Table.getRefsFromBlock` and its helpers (`extractBlockLen`, `getVarInt`, `parseRefBlock`) decode Git reftable binary data by slicing `src` at offsets and lengths that are read directly from the file content, without validating that those offsets/lengths remain within the bounds of the actual byte slice before the slice expression is evaluated. This mirrors the reported `_formatProof` bug class: length-derived values taken from untrusted input are used to index into a buffer before any bounds check is performed, which in Go causes an unrecoverable index-out-of-range panic rather than Solidity's revert.

### Finding Description
`Table.GetReferences()` reads the whole reftable file into memory and walks its ref blocks: [1](#0-0) 

For each block it calls `parseRefBlock`, which first derives the block length from the file itself via `extractBlockLen`: [2](#0-1) 

`currentBS` and `b.RestartCount` (read a few lines later from `src[blockStart+currentBS-2:]`) are attacker-controlled values taken straight from file bytes; only a soft comparison against `t.blockSize`/`blockEnd-blockStart` is made — there is no check that `blockStart+currentBS <= len(src)` or `blockStart+currentBS-2 >= 0`, so a corrupt/undersized block header can under- or over-shoot the buffer: [3](#0-2) 

`b.RestartStart` is then computed as `blockStart + currentBS - 2 - 3*uint(b.RestartCount)`, an unsigned subtraction that can wrap around to a huge value if `RestartCount` is crafted to be large, immediately producing an out-of-range slice index in the following `getRefsFromBlock` loop: [4](#0-3) 

Inside `getRefsFromBlock`, `suffixLength`, `hashSize`, and symref `size` are used to slice `src[idx:idx+suffixLength]`, `src[idx:idx+hashSize]`, `src[idx:idx+size]` etc., again with no check that `idx+length <= len(src)` — only `getVarInt` checks its own cursor against `blockEnd`, not the derived lengths used for the subsequent slice: [5](#0-4) 

This is functionally identical to the `_formatProof` flaw: a length/offset value pulled from raw, non-length-validated input is used directly to slice a buffer, and the only protection is an implicit assumption that the input is well-formed.

### Impact Explanation
`ParseTable`/`GetReferences` on reftable-backend repositories is invoked in mainline RPC and transaction-management code paths — e.g. `internal/gitaly/storage/storagemgr/partition/reftable.go`'s `stageTables`/`getLatestReftableName` flow, and reference-serving RPCs when `ReferenceBackendReftables` is enabled: [6](#0-5) 

A reftable file is Git-repository storage state; it can originate from repository creation via bundle/mirror import, replication, or any code path that writes/reads reftables sourced from a fetched/pushed/imported repository. If such a file is corrupted or adversarially crafted (e.g., via a malicious mirror source or crafted push payload materializing bad reftable bytes on disk before being parsed), parsing it triggers a Go slice-bounds-out-of-range panic. Because this occurs deep in a helper function with no `recover`, it will unwind up through the calling RPC handler / transaction goroutine, crashing that goroutine and, depending on gRPC panic-recovery middleware, potentially the whole `gitaly` process — a denial-of-service condition for a shared multi-tenant server.

### Likelihood Explanation
Reftable is an increasingly used reference backend in Gitaly (`git.ReferenceBackendReftables`), and reftable files are read whenever references are listed/looked up or during WAL/transaction table resequencing. Any pathway that lets an ordinary user's untrusted repository content (fetch/mirror/import) end up materialized as reftable bytes on disk, or a bug/race that leaves a partially written/corrupted `.ref` file, is sufficient to trigger the panic on the next `ParseTable`/`GetReferences` call. No privileged access is required — the trigger is a malformed on-disk reftable file consumed through ordinary reference-reading operations.

### Recommendation
Before using any length/count/offset value extracted from `src` to build a slice (`currentBS`, `b.RestartCount`, `b.RestartStart`, `suffixLength`, `hashSize`+`idx`, symref `size`), validate:
- that the value is non-negative and does not cause unsigned underflow/overflow,
- that `offset + length <= len(src)` (or `<= blockEnd`, as appropriate) before performing the slice,
and return a descriptive parse error instead of allowing the slice expression to panic, mirroring the recommended fix of validating `_rawProof[0]` length before extracting `nextFreeNode` in the original report.

### Proof of Concept
1. Create a repository using the reftable backend (`git init --ref-format=reftable` or via Gitaly's MVCC/reftable creation path).
2. Locate the generated `.ref` table file under `reftable/`.
3. Patch the on-disk block's length/restart-count fields (the bytes read by `extractBlockLen`/`RestartCount` in `parseRefBlock`) to an out-of-range value, e.g. set `RestartCount` large enough that `currentBS - 2 - 3*RestartCount` underflows, or shrink the file so `blockStart+currentBS` exceeds `len(src)`.
4. Call `reftable.ParseTable(path)` followed by `table.GetReferences()` (as done by `internal/gitaly/storage/storagemgr/partition/reftable.go`'s table-reading code paths, or any reference-listing RPC on a reftable-backend repository).
5. Observe a Go runtime panic (`slice bounds out of range`) originating in `getRefsFromBlock`/`parseRefBlock`/`extractBlockLen`, propagating out of the parsing call instead of returning a handled error.

// getRefsFromBlock provides the ref udpates from a reference block.
func (t *Table) getRefsFromBlock(src []byte, b *block) ([]git.Reference, error) {
	var references []git.Reference

	prefix := ""

	// Skip the block_type and block_len
	idx := b.BlockStart + 4

	for idx < b.RestartStart {
		var prefixLength, suffixLength, updateIndexDelta uint
		var err error

		idx, prefixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting prefix length: %w", err)
		}

		idx, suffixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting suffix length: %w", err)
		}

		extra := (suffixLength & 0x7)
		suffixLength >>= 3

		refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])
		idx = idx + suffixLength

		idx, updateIndexDelta, err = t.getVarInt(src, idx, b.FullBlockSize)
		if err != nil {
			return nil, fmt.Errorf("getting update index delta: %w", err)
		}
		// we don't use this for now
		_ = updateIndexDelta

		reference := git.Reference{
			Name: git.ReferenceName(refname),
		}

		switch extra {
		case 0:
			// Deletion, no value
			reference.Target = t.shaFormat().ZeroOID.String()
		case 1:
			// Regular reference
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)
		case 2:
			// Peeled Tag
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)

			// For now we don't need the peeledOID, but we still need
			// to skip the index.
			// peeledOID := ObjectID(bytesToHex(t.src[idx : idx+uint(hashSize)]))
			idx += uint(hashSize)
		case 3:
			// Symref
			var size uint
			idx, size, err = t.getVarInt(src, idx, b.FullBlockSize)
			if err != nil {
				return nil, fmt.Errorf("getting symref size: %w", err)
			}

			reference.Target = git.ReferenceName(src[idx : idx+size]).String()
			reference.IsSymbolic = true
			idx = idx + size

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)

// GetReferences returns all references from the table.
func (t *Table) GetReferences() ([]git.Reference, error) {
	headerOffset := uint(t.footer.Version.HeaderSize())
	offset := uint(0)
	var allRefs []git.Reference

	if _, err := t.src.Seek(0, io.SeekStart); err != nil {
		return nil, fmt.Errorf("seek start: %w", err)
	}

	src, err := io.ReadAll(t.src)
	if err != nil {
		return nil, fmt.Errorf("read all: %w", err)
	}

	for offset < t.footerOffset {
		blockStart, blockEnd := t.getBlockRange(offset, t.blockSize)
		if blockStart == 0 && blockEnd == 0 {
			break
		}

		// If we run out of ref blocks, we can stop the iteration.
		if src[blockStart+headerOffset] != 'r' {
			return allRefs, nil
		}

		references, err := t.parseRefBlock(src, headerOffset, blockStart, blockEnd)
		if err != nil {
			return nil, fmt.Errorf("parsing block: %w", err)
		}
