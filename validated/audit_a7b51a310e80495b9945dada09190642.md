### Title
Zero-fee oracle-priced `Pool.swap` lets arbitrageurs convert depegged synths into fairly-valued synths at stale oracle rates - (File: contracts/Pool.sol)

### Summary
Metronome's `Pool.swap` converts one synthetic asset into another purely at the `MasterOracle` exchange rate, burning `syntheticTokenIn_` and minting `syntheticTokenOut_` to the caller. The fee charged is `feeProvider.swapFees(in, out)`, which is configured per direction and defaults to **0** for any pair the governor has not explicitly configured (the test suite explicitly asserts `swapFees(msETH, msDOGE) == 0`). This is the same bug class as USSD M-9: a permissionless, oracle-priced mint path whose spread to the real market is bounded only by the oracle's deviation threshold, not by any fee or slippage.

### Finding Description
`swap` is a public, `nonReentrant`, `whenNotShutdown` entry point gated only by `isSwapActive`, `onlyIfSyntheticTokenExists`, and the synth's own `isActive` flag (contracts/Pool.sol ~L640-L671). `quoteSwapOut` prices the trade solely via `masterOracle().quote(tokenIn, tokenOut, amountIn)` and subtracts `_amountOut.wadMul(_swapFee)` only if a fee is configured (L508-L525). If the fee is zero, the swap executes at exactly the oracle rate.

Attack flow (all public entry points, unprivileged EOA):
1. Wait until a listed synth (e.g., msETH) trades below its oracle price on external AMMs — this happens naturally within the oracle's deviation threshold (e.g., 0.5% on Chainlink ETH/USD) whenever the market moves but the feed hasn't updated.
2. Buy the cheap synth on the market (or hold an inventory acquired earlier).
3. Call `pool.swap(msETH, msUSD, amountIn)` on a zero-fee direction. The oracle still reports the old, higher price, so the attacker receives more msUSD than the market value of the msETH burned.
4. Sell the received msUSD for underlying stable value and repeat until the market price re-converges or the oracle updates.

Unlike USSD, collateral is not pulled into the protocol here; instead the leak manifests as **supply dilution**: burning 1 "cheap" msETH mints oracle-valued msUSD, so outstanding claims in USD terms grow while the debt positions that originally backed the burned synth remain denominated in the burned asset. Each iteration transfers value to the arbitrageur at the expense of synthOut holders' backing ratio — the same "value leaked to arbitrageurs" impact as M-9.

### Impact Explanation
Each swap extracts up to the oracle deviation (minus any configured fee) per unit of volume, repeatable until convergence or oracle update. The protocol mints more USD-value of `syntheticTokenOut_` than the market value of `syntheticTokenIn_` burned, degrading the aggregate collateralization backing of `syntheticTokenOut_` — a direct value leak/dilution of user-held synths.

### Likelihood Explanation
- Requires only public calls: buy synth on AMM → `Pool.swap` → sell. No privileged role involved.
- Trigger conditions are realistic: oracle deviation thresholds guarantee windows where oracle ≠ market price after any price move.
- Constraint: profit exists only on pairs where `swapFees` is below the deviation. The code permits zero-fee directions (default when unconfigured, confirmed in `test/Integration.test.ts:334` and `test/Pool.test.ts:1067`), so the viability depends on the deployed `FeeProvider` configuration — on any unconfigured/zero-fee listed pair the attack is fully open.

### Recommendation
Enforce a protocol-wide minimum swap fee (e.g., ≥1%) in `quoteSwapIn`/`quoteSwapOut` or in `FeeProvider`, above the maximum oracle deviation threshold of any listed asset, rather than allowing zero-fee pairs. Optionally add per-swap slippage protection (minAmountOut) so callers bound oracle-vs-market drift.

### Proof of Concept
Foundry fork sketch (mainnet fork, using deployed Pool/FeeProvider/MasterOracle):

```solidity
// setup: fork mainnet; pool = deployed Pool; msETH, msUSD listed; isSwapActive
// assume swapFees(msETH, msUSD) == 0 on the target direction

function test_oracleDeviationSwapArb() public {
    // 1) ETH market drops 0.4% but Chainlink feed (0.5% deviation) not updated
    //    => market msETH price < masterOracle price

    // 2) attacker buys msETH cheap on Uniswap/Swapper
    uint256 ethIn = 100e18;
    dealOrSwapForMsETH(attacker, ethIn); // acquired at ~oracle*0.996

    vm.startPrank(attacker);
    (uint256 quotedOut, uint256 fee) = pool.quoteSwapOut(msETH, msUSD, ethIn);
    assertEq(fee, 0); // zero-fee direction

    uint256 balBefore = msUSD.balanceOf(attacker);
    pool.swap(msETH, msUSD, ethIn);        // burns msETH, mints msUSD at stale rate
    uint256 minted = msUSD.balanceOf(attacker) - balBefore;

    // minted corresponds to oracle $2000/ETH while market paid ~$1992/ETH
    assertGt(minted * 1e18 / ethIn, marketEthPrice()); // profit = oracle-market spread
    vm.stopPrank();

    // 3) dump msUSD for USDC/DAI on Curve; repeat each block until convergence
}
```

Expected invariant break: `sum over synths of (supply × oraclePrice)` increases after the swap without any collateral or debt adjustment compensating it — value is minted against nothing and absorbed by the arbitrageur.
