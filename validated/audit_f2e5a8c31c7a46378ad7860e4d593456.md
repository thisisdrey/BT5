### Title
Unstaked connection table pruning executes before capacity/eligibility check, letting a cheap unprivileged client repeatedly churn-evict legitimate unstaked connections - (File: streamer/src/nonblocking/swqos.rs)

### Summary
`SwQos::prune_unstaked_connections_and_add_new_connection` unconditionally prunes ~10% of the `unstaked_connection_table` whenever the table is at/above `max_unstaked_connections`, *before* checking whether the incoming connection can even be admitted (per-peer connection cap is checked afterward in `cache_new_connection`). An unstaked or misclassified low-stake attacker whose own connection attempt is doomed to be rejected (e.g. already at `max_connections_per_unstaked_peer` for their own key) can still trigger eviction of other legitimate unstaked peers' connections on every attempt, at a rate bounded only by the per-IP `ConnectionRateLimiter`.

### Finding Description
In `streamer/src/nonblocking/swqos.rs`, `SwQos::try_add_connection` routes any connection classified `ConnectionPeerType::Unstaked` (either genuinely unstaked, or a staked peer whose `stake_ratio < min_stake_ratio` and is reclassified to `Unstaked` in `build_connection_context`, `streamer/src/nonblocking/swqos.rs:318-329`) into `prune_unstaked_connections_and_add_new_connection` (`streamer/src/nonblocking/swqos.rs:258-290`).

That function does, in order:
```
self.prune_unstaked_connection_table(&mut connection_table, max_connections, stats);
self.cache_new_connection(client_connection_tracker, connection, connection_table, conn_context)
```
`prune_unstaked_connection_table` (`streamer/src/nonblocking/swqos.rs:241-256`) prunes the table down to 90% capacity via `ConnectionTable::prune_oldest` (`streamer/src/nonblocking/quic.rs:964-980`) whenever `total_size >= max_unstaked_connections`, **regardless of who is connecting or whether their connection will ultimately be admitted**. `prune_oldest` evicts entries by globally-oldest `last_update`, i.e., other peers' entries, potentially removing multiple different keys' connections in one call.

Only *after* this eviction does `cache_new_connection` call `ConnectionTable::try_add_connection` (`streamer/src/nonblocking/quic.rs:1008-1051`), which enforces `max_connections_per_unstaked_peer` per key and can reject the attacker's own connection outright if they already hold the maximum allowed connections under their key. Because the prune happened first and unconditionally, the attacker's rejected/no-op connection attempt still caused real, permanent eviction of other unstaked peers' connections.

This bypasses the intended invariant that per-IP/per-peer QoS limits are what bound a single client's impact: here, a client's *own* connection count contributes nothing to the churn it inflicts on others once the table is saturated. The only throttle on how often this can be repeated is the per-IP `ConnectionRateLimiter::register_connection` in `streamer/src/nonblocking/connection_rate_limiter.rs:42-50`, a fixed token-bucket per source IP unrelated to how much churn is caused per request.

### Impact Explanation
This is a QoS evasion / unfair capture of unstaked TPU connection capacity (Agave bounty category: DoS / QoS limits bypass). A cheap, unprivileged, unstaked (or low-stake-but-classified-unstaked) client can force continuous eviction of other unstaked senders' active QUIC connections from `unstaked_connection_table`, degrading legitimate unstaked transaction ingress on the leader's TPU without needing to itself hold any of the contested capacity, at a rate limited only by per-source-IP connection attempts.

### Likelihood Explanation
Fully reachable by an unprivileged remote client: open enough connections under one identity to hit `max_connections_per_unstaked_peer` (default config), then keep opening additional handshakes from the same IP at whatever rate the per-IP `ConnectionRateLimiter` allows. Each such attempt, while `unstaked_connection_table.total_size >= max_unstaked_connections`, causes eviction of ~10% of the table's other entries even though the attacker's own connection is subsequently rejected. No staked identity, gossip, or validator control is required.

### Recommendation
Reorder the logic so pruning is only performed if the incoming connection can actually be admitted for the requesting key (e.g., first check the peer's own per-peer connection headroom, or make eviction proportional/tied 1:1 to the space actually needed for the new connection rather than bulk-pruning to a fixed 90% target on every over-capacity attempt regardless of outcome). Alternatively, track and cap eviction attempts per source key/IP separately from the general connection rate limiter so that failed admission attempts cannot trigger destructive pruning of others' entries.

// streamer/src/nonblocking/swqos.rs (test module)
#[tokio::test]
async fn test_failed_admission_still_evicts_other_unstaked_peers() {
    let cancel = CancellationToken::new();
    let stats = Arc::new(StreamerStats::default());
    let staked_nodes = Arc::new(RwLock::new(StakedNodes::default()));

    let swqos = SwQos::new(
        SwQosConfig {
            max_unstaked_connections: 10,
            max_connections_per_unstaked_peer: 1,
            ..Default::default()
        },
        stats.clone(),
        staked_nodes,
        cancel.clone(),
    );

    // Fill unstaked table to capacity with distinct legitimate peers.
    for _ in 0..10 {
        let (conn, _c, _s) = create_server_side_connection().await;
        let mut ctx = swqos.build_connection_context(&conn);
        let tracker = ClientConnectionTracker::new(stats.clone(), 1000).unwrap();
        assert!(swqos.try_add_connection(tracker, &conn, &mut ctx).await.is_some());
    }
    assert_eq!(stats.num_evictions_unstaked.load(Ordering::Relaxed), 0);

    // Attacker already at its own per-peer cap: first connection from attacker identity.
    let (attacker_conn1, _c1, _s1) = create_server_side_connection().await; // simulate fixed attacker IP/key
    let mut attacker_ctx1 = swqos.build_connection_context(&attacker_conn1);
    let tracker1 = ClientConnectionTracker::new(stats.clone(), 1000).unwrap();
    assert!(swqos.try_add_connection(tracker1, &attacker_conn1, &mut attacker_ctx1).await.is_some());

    // Attacker retries from same key/IP (would exceed max_connections_per_unstaked_peer=1,
    // so admission should fail) but table is at capacity, so pruning still executes.
    let (attacker_conn2, _c2, _s2) = create_server_side_connection().await; // same identity/IP
    let mut attacker_ctx2 = swqos.build_connection_context(&attacker_conn2);
    let tracker2 = ClientConnectionTracker::new(stats.clone(), 1000).unwrap();
    let result2 = swqos.try_add_connection(tracker2, &attacker_conn2, &mut attacker_ctx2).await;

    // Expected (bug): eviction of other legitimate peers occurred even though
    // attacker's own connection was not admitted.
    assert!(stats.num_evictions_unstaked.load(Ordering::Relaxed) > 0);
    // Assert this violates fairness: attacker gained 0 net new admitted connections
    // relative to evictions caused.
}

    fn prune_unstaked_connection_table(
        &self,
        unstaked_connection_table: &mut ConnectionTable<ConnectionStreamCounter>,
        max_unstaked_connections: usize,
        stats: Arc<StreamerStats>,
    ) {
        if unstaked_connection_table.total_size >= max_unstaked_connections {
            // Prune the connection table down to 90% capacity
            const PRUNE_TABLE_RATIO: f64 = 0.90;
            let max_connections = (PRUNE_TABLE_RATIO * (max_unstaked_connections as f64)) as usize;
            let num_pruned = unstaked_connection_table.prune_oldest(max_connections);
            stats
                .num_evictions_unstaked
                .fetch_add(num_pruned, Ordering::Relaxed);
        }
    }

    async fn prune_unstaked_connections_and_add_new_connection(
        &self,
        client_connection_tracker: ClientConnectionTracker,
        connection: &Connection,
        connection_table: Arc<Mutex<ConnectionTable<ConnectionStreamCounter>>>,
        max_connections: usize,
        conn_context: &SwQosConnectionContext,
    ) -> Result<
        (
            Arc<AtomicU64>,
            CancellationToken,
            Arc<ConnectionStreamCounter>,
        ),
        ConnectionHandlerError,
    > {
        let stats = self.stats.clone();
        if max_connections > 0 {
            let mut connection_table = connection_table.lock().await;
            self.prune_unstaked_connection_table(&mut connection_table, max_connections, stats);
            self.cache_new_connection(
                client_connection_tracker,
                connection,
                connection_table,
                conn_context,
            )
        } else {
            connection.close(
                CONNECTION_CLOSE_CODE_DISALLOWED.into(),
                CONNECTION_CLOSE_REASON_DISALLOWED,
            );
            Err(ConnectionHandlerError::ConnectionAddError)
        }
    }

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )
    }

    pub(crate) fn prune_oldest(&mut self, max_size: usize) -> usize {
        let mut num_pruned = 0;
        let key = |(_, connections): &(_, &Vec<_>)| {
            connections.iter().map(ConnectionEntry::last_update).min()
        };
        while self.total_size.saturating_sub(num_pruned) > max_size {
            match self.table.values().enumerate().min_by_key(key) {
                None => break,
                Some((index, connections)) => {
                    num_pruned += connections.len();
                    self.table.swap_remove_index(index);
                }
            }
        }
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

    pub(crate) fn try_add_connection<F: FnOnce() -> Arc<S>>(
        &mut self,
        key: ConnectionTableKey,
        port: u16,
        client_connection_tracker: ClientConnectionTracker,
        connection: Option<Connection>,
        peer_type: ConnectionPeerType,
        last_update: Arc<AtomicU64>,
        max_connections_per_peer: usize,
        stream_counter_factory: F,
    ) -> Option<(Arc<AtomicU64>, CancellationToken, Arc<S>)> {
        let connection_entry = self.table.entry(key).or_default();
        let has_connection_capacity = connection_entry
            .len()
            .checked_add(1)
            .map(|c| c <= max_connections_per_peer)
            .unwrap_or(false);
        if has_connection_capacity {
            let cancel = self.cancel.child_token();
            let stream_counter = connection_entry
                .first()
                .map(|entry| entry.stream_counter.clone())
                .unwrap_or_else(stream_counter_factory);
            connection_entry.push(ConnectionEntry::new(
                cancel.clone(),
                peer_type,
                last_update.clone(),
                port,
                client_connection_tracker,
                connection,
                stream_counter.clone(),
            ));
            self.total_size += 1;
            Some((last_update, cancel, stream_counter))
        } else {
            if let Some(connection) = connection {
                connection.close(
                    CONNECTION_CLOSE_CODE_TOO_MANY.into(),
                    CONNECTION_CLOSE_REASON_TOO_MANY,
                );
            }
            None
        }
    }
