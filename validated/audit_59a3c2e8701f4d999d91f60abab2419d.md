### Title
Missing size/count bounds on Version1 certificate unmarshaling allows pre-authentication resource-exhaustion during handshake - (File: cert/cert_v1.go)

### Summary
`unmarshalCertificateV1` builds `networks`, `unsafeNetworks`, and `groups` slices directly from attacker-controlled protobuf-decoded counts with no cap, unlike its Version2 counterpart which enforces `MaxCertificateSize`, `MaxNetworkLength`, and `MaxNameLength`. This parsing happens during handshake certificate reconstruction (`validateCert` → `cert.Recombine`) **before** the certificate's signature or CA trust is checked, so it is reachable by any remote peer sending a handshake packet, without possessing a valid CA-signed certificate.

### Finding Description
The reported bug class is: an unauthenticated/untrusted actor supplies a data structure whose size is unchecked, and that size directly drives the amount of work a victim must perform in a subsequent expensive operation, with no cap enforced by the code that accepts the data.

In this repository, `handshake.Machine.validateCert` (`handshake/machine.go:342-380`) calls `cert.Recombine` on the raw bytes taken straight from the incoming handshake payload, *before* `m.verifier(rc)` (the CA/signature check) is invoked: [1](#0-0) [2](#0-1) 

For Version1 certificates, `Recombine` dispatches to `unmarshalCertificateV1`, which unmarshals the payload with `proto.Unmarshal` and then allocates and fills slices whose lengths are taken directly from the attacker-supplied counts of `Groups`, `Ips`, and `Subnets`, with **no upper bound check** on the number of entries (contrast with V2's explicit `MaxCertificateSize`/`MaxNetworkLength`/`MaxNameLength` checks): [3](#0-2) [4](#0-3) 

The subsequent `validate()` call then iterates over every network and unsafe network entry: [5](#0-4) 

By comparison, Version2 parsing explicitly checks `l > MaxCertificateSize` and per-entry length limits (`MaxNetworkLength`, `MaxNameLength`) before building the equivalent lists: [6](#0-5) [7](#0-6) 

This asymmetry means the V1 code path has no analog of the "max entries" guard that the external report says was missing for `enterMarkets`: the number of loop iterations performed on unauthenticated input (allocation of the `groups`/`networks`/`unsafeNetworks` slices, plus the `validate()` scan over them) is controlled entirely by the peer, and is not capped independently of the incoming packet's byte length.

### Impact Explanation
An attacker with no CA-signed certificate can send a handshake message (stage 0 or stage 1, both `expectsCert: true` per `handshake/patterns.go`) carrying a crafted Version1 certificate payload with a very large number of `Groups`/`Ips`/`Subnets` entries. Nebula will unmarshal it, allocate the corresponding slices, and iterate over them in `validate()` — all before any cryptographic trust decision is made and before the packet can be rejected for being sent by an untrusted peer. Because this work happens on the hot path of `beginHandshake`/`handleOutbound`, an attacker can repeatedly trigger this parsing/validation cost per handshake attempt, which is a remote CPU/allocation amplification vector reachable pre-authentication — the same root cause class as the report's "no bound on attacker-controlled list processed by an unauthenticated/lower-trust party" issue.

### Likelihood Explanation
The handshake responder path (`beginHandshake` in `handshake_manager.go`) processes the very first inbound packet from any source without prior authentication, and calls into `cert.Recombine`/`unmarshalCertificateV1` unconditionally when a V1-cert-carrying handshake message is expected. Any host that can reach the UDP listener can trigger this path repeatedly and cheaply (each attempt costs the attacker only one packet), while the defender performs proto-unmarshal, slice allocation, and O(n) validation work scaled to the attacker's chosen entry counts.

### Recommendation
Add explicit upper bounds to `unmarshalCertificateV1` (or to `cert.Recombine`) analogous to the V2 path: cap total raw certificate size (`MaxCertificateSize`-equivalent) and/or cap the number of `Groups`/`Ips`/`Subnets` entries before allocating slices sized from attacker-supplied counts, rejecting oversized payloads early — mirroring the fix pattern recommended in the source report (bound the attacker-controlled count before it drives victim-side work).

### Proof of Concept
Not independently reproduced in this session (no execution environment available); the finding is derived from static code comparison between `cert/cert_v1.go`'s `unmarshalCertificateV1` (no size/count caps) and `cert/cert_v2.go`'s `unmarshalCertificateV2`/`unmarshalDetails` (explicit `MaxCertificateSize`, `MaxNetworkLength`, `MaxNameLength` checks), combined with tracing the call path `handshake.Machine.ProcessPacket` → `processPayload` → `validateCert` → `cert.Recombine` → `unmarshalCertificateV1` → `validate()`, confirmed to execute prior to `m.verifier(rc)` (the CA-signature check) in `handshake/machine.go:371-379`. A full exploit would require constructing a V1-format handshake packet with a maximal-size UDP payload containing a large `Groups`/`Ips` array and measuring responder-side CPU/allocation cost, which was not executed here due to lack of a runtime/test harness in this session.

func (c *certificateV1) validate() error {
	// Empty names are allowed

	if len(c.details.publicKey) == 0 {
		return ErrInvalidPublicKey
	}

	// Original v1 rules allowed multiple networks to be present but ignored all but the first one.
	// Continue to allow this behavior
	if !c.details.isCA && len(c.details.networks) == 0 {
		return NewErrInvalidCertificateProperties("non-CA certificates must contain exactly one network")
	}

	for _, network := range c.details.networks {
		if !network.IsValid() || !network.Addr().IsValid() {
			return NewErrInvalidCertificateProperties("invalid network: %s", network)
		}

		if network.Addr().Is6() {
			return NewErrInvalidCertificateProperties("certificate may not contain IPv6 networks: %v", network)
		}

		if network.Addr().IsUnspecified() {
			return NewErrInvalidCertificateProperties("non-CA certificates must not use the zero address as a network: %s", network)
		}

		if network.Addr().Zone() != "" {
			return NewErrInvalidCertificateProperties("networks may not contain zones: %s", network)
		}
	}

	for _, network := range c.details.unsafeNetworks {
		if !network.IsValid() || !network.Addr().IsValid() {
			return NewErrInvalidCertificateProperties("invalid unsafe network: %s", network)
		}

			return NewErrInvalidCertificateProperties("certificate may not contain IPv6 unsafe networks: %v", network)
		}

		if network.Addr().Zone() != "" {
			return NewErrInvalidCertificateProperties("unsafe networks may not contain zones: %s", network)
		}
	}

func unmarshalCertificateV1(b []byte, publicKey []byte) (*certificateV1, error) {
	if len(b) == 0 {
		return nil, fmt.Errorf("nil byte array")
	}
	var rc RawNebulaCertificate
	err := proto.Unmarshal(b, &rc)
	if err != nil {
		return nil, err
	}

	if rc.Details == nil {
		return nil, fmt.Errorf("encoded Details was nil")
	}

	if len(rc.Details.Ips)%2 != 0 {
		return nil, fmt.Errorf("encoded IPs should be in pairs, an odd number was found")
	}

	if len(rc.Details.Subnets)%2 != 0 {
		return nil, fmt.Errorf("encoded Subnets should be in pairs, an odd number was found")
	}

	nc := certificateV1{
		details: detailsV1{
			name:           rc.Details.Name,
			groups:         make([]string, len(rc.Details.Groups)),
			networks:       make([]netip.Prefix, len(rc.Details.Ips)/2),
			unsafeNetworks: make([]netip.Prefix, len(rc.Details.Subnets)/2),
			notBefore:      time.Unix(rc.Details.NotBefore, 0),
			notAfter:       time.Unix(rc.Details.NotAfter, 0),
			publicKey:      nil,
			isCA:           rc.Details.IsCA,
			curve:          rc.Details.Curve,
		},
		signature: make([]byte, len(rc.Signature)),
	}

	copy(nc.signature, rc.Signature)
	copy(nc.details.groups, rc.Details.Groups)
	nc.details.issuer = hex.EncodeToString(rc.Details.Issuer)

	// If a public key is passed in as an argument, the certificate pubkey must be empty
	// and the passed-in pubkey copied into the cert.
	if len(publicKey) > 0 {
		if len(rc.Details.PublicKey) != 0 {
			return nil, ErrCertPubkeyPresent
		}
		nc.details.publicKey = make([]byte, len(publicKey))
		copy(nc.details.publicKey, publicKey)
	} else {
		nc.details.publicKey = make([]byte, len(rc.Details.PublicKey))
		copy(nc.details.publicKey, rc.Details.PublicKey)
	}
