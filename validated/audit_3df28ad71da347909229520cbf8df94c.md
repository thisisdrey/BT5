### Title
`ProxyOFT.retryMessage()` permanently locks unneeded native coin - (File: `contracts/dependencies/@layerzerolabs/solidity-examples/contracts-upgradeable/lzApp/NonblockingLzAppUpgradeable.sol`)

### Summary
`ProxyOFT` inherits a public `payable` `retryMessage()` function from `NonblockingLzAppUpgradeable`. [1](#0-0)  The function accepts `msg.value`, but never forwards, refunds, or otherwise uses it before successfully replaying the stored LayerZero message. [2](#0-1)  Any native coin attached to a successful retry therefore remains in the `ProxyOFT` contract with no user-accessible withdrawal path. [2](#0-1) 

### Finding Description
`retryMessage()` verifies that a failed message exists and that the supplied payload matches the stored payload hash, then clears the failed-message entry and invokes `_nonblockingLzReceive()`. [2](#0-1)  For `ProxyOFT`, a normal `PT_SEND` payload reaches `_creditTo()`, which mints the synthetic token to the encoded recipient. [3](#0-2)  The function does not use `msg.value` to pay the endpoint because message retries are local replays rather than new endpoint sends. [2](#0-1) 

A caller can consequently supply any nonzero `msg.value` while retrying a valid failed message, and the transaction succeeds without returning the excess. [2](#0-1)  Unlike outbound sends, which pass the entire supplied value to the LayerZero endpoint, the retry path performs no value transfer or refund accounting. [4](#0-3)  `ProxyOFT` also exposes no general native-token recovery function, so the balance remains locked. [5](#0-4) 

### Impact Explanation
This permanently freezes native coin supplied to a public entry point where no native payment is required. [2](#0-1)  The issue directly matches the bug class in which payable code accepts unrelated native value and leaves it stranded after successful execution. [2](#0-1)  The funds are not credited as collateral, fees, bridge payment, or retry payment, and no privileged or unprivileged user can recover them through the exposed `ProxyOFT` API. [5](#0-4) 

### Likelihood Explanation
The function is externally callable and only requires an existing failed message whose payload can be successfully replayed. [2](#0-1)  A failed receive can occur when synthetic-token minting exceeds the configured bridged-in supply or total supply, and the message can later succeed after bridged-out supply reduces the net bridged-in amount or capacity changes. [6](#0-5)  The issue does not rely on governance misconduct, oracle manipulation, a malicious endpoint, or privileged behavior; it only requires a caller to attach unnecessary native coin to a valid retry. [2](#0-1)  The likelihood is limited by the need for a retryable failed message and the fact that `msg.value` is not required, but accidental integrations and multicall-style interactions can still send it. [7](#0-6) 

### Recommendation
Make `retryMessage()` non-payable, or explicitly refund `msg.value` before or after the replay. [2](#0-1)  If the `payable` signature must remain compatible with the inherited LayerZero interface, add `if (msg.value != 0) revert`; alternatively, return the unused amount as the configured wrapped native token if reverting would be incompatible with a caller that cannot receive native coin. [8](#0-7) 

### Proof of Concept
The following Foundry fork-style test demonstrates the issue by creating a failed inbound bridge message at the bridged-in cap, reducing net bridged-in supply through a normal outbound bridge, and then retrying with unrelated native value. [6](#0-5) 

```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.24;

import "forge-std/Test.sol";

interface IProxyOFT {
    function lzReceive(
        uint16 srcChainId,
        bytes calldata srcAddress,
        uint64 nonce,
        bytes calldata payload
    ) external;

    function retryMessage(
        uint16 srcChainId,
        bytes calldata srcAddress,
        uint64 nonce,
        bytes calldata payload
    ) external payable;

    function sendFrom(
        address from,
        uint16 dstChainId,
        address to,
        uint256 amount
    ) external payable;

    function trustedRemoteLookup(uint16 chainId) external view returns (bytes memory);
    function lzEndpoint() external view returns (address);
    function token() external view returns (address);
    function estimateSendFee(uint16 dstChainId, address to, uint256 amount)
        external
        view
        returns (uint256);
}

interface ISynth {
    function bridgedInSupply() external view returns (uint256);
    function maxBridgedInSupply() external view returns (uint256);
    function balanceOf(address account) external view returns (uint256);
}

contract ProxyOFTRetryValuePoC is Test {
    function test_retryMessage_locks_native_value() public {
        // Fork at a deployed ProxyOFT whose remote path is configured.
        IProxyOFT proxy = IProxyOFT(PROXY_OFT);
        ISynth synth = ISynth(proxy.token());
        uint16 srcChain = SOURCE_CHAIN_ID;
        address attacker = address(this);

        bytes memory remotePath = proxy.trustedRemoteLookup(srcChain);
        require(remotePath.length != 0, "missing remote");

        // An inbound amount one unit above remaining bridged-in capacity fails.
        uint256 remaining =
            synth.maxBridgedInSupply() - synth.bridgedInSupply();
        uint256 amount = remaining + 1;
        uint64 nonce = 1;
        bytes memory payload =
            abi.encode(uint16(0), abi.encodePacked(attacker), amount);

        vm.prank(proxy.lzEndpoint());
        proxy.lzReceive(srcChain, remotePath, nonce, payload);

        // Bridging out one unit increases totalBridgedOut and frees the unit
        // needed for the failed inbound message to succeed on retry.
        uint256 fee = proxy.estimateSendFee(srcChain, attacker, 1);
        vm.deal(attacker, fee + 1 ether);
        proxy.sendFrom{value: fee}(attacker, srcChain, attacker, 1);

        uint256 proxyBalanceBefore = address(proxy).balance;

        // The retry succeeds, but the unrelated 1 ether is neither used nor
        // refunded.
        proxy.retryMessage{value: 1 ether}(
            srcChain,
            remotePath,
            nonce,
            payload
        );

        assertEq(address(proxy).balance, proxyBalanceBefore + 1 ether);
    }
}
```

    function retryMessage(uint16 _srcChainId, bytes calldata _srcAddress, uint64 _nonce, bytes calldata _payload) public payable virtual {
        // assert there is message to retry
        bytes32 payloadHash = failedMessages[_srcChainId][_srcAddress][_nonce];
        require(payloadHash != bytes32(0), "NonblockingLzApp: no stored message");
        require(keccak256(_payload) == payloadHash, "NonblockingLzApp: invalid payload");
        // clear the stored message
        failedMessages[_srcChainId][_srcAddress][_nonce] = bytes32(0);
        // execute the message. revert if it fails again
        _nonblockingLzReceive(_srcChainId, _srcAddress, _nonce, _payload);
        emit RetryMessageSuccess(_srcChainId, _srcAddress, _nonce, payloadHash);
