### Title
Vote reward is granted for an entire DPoS cycle regardless of when within the cycle the vote was cast, allowing last‑moment voters to earn a full cycle's proportional reward - (File: chainbase/src/main/java/org/tron/core/service/MortgageService.java, actuator/src/main/java/org/tron/core/vm/utils/VoteRewardUtil.java)

### Summary
Like the am-AMM report where rent for an entire epoch is distributed to whoever holds `BunniToken` at the epoch boundary (even if they deposited seconds before the epoch ended), java-tron's DPoS vote-reward mechanism grants a voter the witness's *entire* cycle reward (computed from the cycle-level `Vi` delta) as long as a vote to that witness exists at cycle-boundary snapshot time — with no accounting for how long the vote was actually outstanding during that cycle.

### Finding Description
Reward accounting for SR (super representative) votes is done per maintenance cycle. `MortgageService.payReward()` accumulates the block/fee reward for a witness into a per-cycle bucket keyed only by cycle number: [1](#0-0) . At each maintenance boundary, `MaintenanceManager.doMaintenance()` converts that bucket into a cumulative "value index" (`Vi`) per witness using the witness's *current* total vote count at that instant: [2](#0-1)  and [3](#0-2) .

A voter's reward for a range of cycles `[beginCycle, endCycle)` is computed as `deltaVi * userVoteCount`, using the account's *current* `votesList` at the time reward is withdrawn/queried — not a time-weighted amount: [4](#0-3) . `VoteRewardUtil.withdrawReward` (the TVM-facing native contract path) implements the identical bucket logic: [5](#0-4) .

Critically, `beginCycle` for an address is only advanced when `withdrawReward`/`VoteRewardUtil.withdrawReward` is invoked, which happens inside `VoteWitnessActuator.countVoteAccount` *before* the new vote is registered: [6](#0-5) . This sets `beginCycle = currentCycle` for the voter at whatever moment within the current (not-yet-closed) cycle the vote transaction lands — even if that is the very last block before the next maintenance event. When the reward is later withdrawn (or the account votes again), `computeReward(beginCycle, endCycle, accountCapsule)` applies the *entire* `deltaVi` accumulated for cycle `beginCycle` to the voter's *current* vote amount, granting a full cycle's proportional reward for a vote that may have only existed for a single block of that cycle.

This directly mirrors the reported bug class: reward for a discrete accounting period is disbursed in bulk based on a point-in-time balance/position snapshot at the period boundary, rather than being pro-rated by the duration the position was actually held during that period.

### Impact Explanation
An account can call `FreezeBalanceActuator`/`FreezeBalanceV2` (broadcastable by any address) to obtain TRON Power and then call `VoteWitnessActuator` (or the TVM `vote` precompile path guarded by `VoteRewardUtil`) at the last block of a maintenance cycle. The reward computation credits that vote with the full cycle's proportional share of the witness's block/standby/fee reward, computed from the total vote weight recorded at the maintenance boundary (which already includes the newly cast, last-second vote), diluting the share that should accrue to voters who backed the witness for the whole cycle. This is a value-extraction/unfair-distribution issue rather than a fund-freezing/theft bug, and its practical severity is bounded by the mandatory minimum freeze duration required by `FreezeBalanceActuator`/`FreezeBalanceV2Actuator` before capital can be unfrozen, unlike the AMM report's 1–2 minute withdrawal delay.

### Likelihood Explanation
Both `FreezeBalanceActuator`/`FreezeBalanceV2Actuator` and `VoteWitnessActuator` are unprivileged, fully public transaction types reachable by any signed transaction, and the timing of a transaction relative to the maintenance boundary is fully observable/controllable by watching `getNextMaintenanceTime()`. No special permissions, races with other validators, or non-deterministic conditions are required beyond submitting a transaction in the final block(s) before the maintenance switch.

### Recommendation
Track voting/holding duration within a cycle (e.g., snapshot vote weight at cycle start rather than allowing `beginCycle` to be set to the in-progress cycle on a fresh vote), or otherwise pro-rate rewards by the fraction of the cycle during which the vote was actually registered, so that late entrants cannot claim a full cycle's reward for a partial-cycle position.

### Proof of Concept
1. Monitor `DynamicPropertiesStore.getNextMaintenanceTime()` to determine the last block of the current cycle `N`.
2. In that last block, broadcast `FreezeBalanceContract` (or `FreezeBalanceV2Contract`) to acquire TRON Power, then broadcast `VoteWitnessContract` voting for a high-reward witness. `VoteWitnessActuator.countVoteAccount` calls `mortgageService.withdrawReward(ownerAddress)` first (settling any prior, empty history) then records the new vote, implicitly setting `beginCycle = N` for the account: [7](#0-6) .
3. `MaintenanceManager.doMaintenance()` fires, closing cycle `N`, computing `Vi` for cycle `N` using the witness's vote total which already includes the attacker's last-second vote: [2](#0-1) .
4. In a subsequent cycle, call `mortgageService.withdrawReward(address)` (e.g. via `WithdrawBalanceActuator` or by voting again). `computeReward` charges the full `deltaVi` for cycle `N` against the attacker's current vote count, paying out as if the vote had been active the entire cycle `N`: [8](#0-7) .

  private long computeReward(long beginCycle, long endCycle, AccountCapsule accountCapsule) {
    if (beginCycle >= endCycle) {
      return 0;
    }

    long reward = 0;
    long newAlgorithmCycle = dynamicPropertiesStore.getNewRewardAlgorithmEffectiveCycle();
    List<Pair<byte[], Long>> srAddresses = accountCapsule.getVotesList().stream()
        .map(vote -> new Pair<>(vote.getVoteAddress().toByteArray(), vote.getVoteCount()))
        .collect(Collectors.toList());
    if (beginCycle < newAlgorithmCycle) {
      long oldEndCycle = min(endCycle, newAlgorithmCycle,
          dynamicPropertiesStore.disableJavaLangMath());
      reward = getOldReward(beginCycle, oldEndCycle, srAddresses);
      beginCycle = oldEndCycle;
    }
    if (beginCycle < endCycle) {
      for (Pair<byte[], Long>  vote : srAddresses) {
        byte[] srAddress = vote.getKey();
        BigInteger beginVi = delegationStore.getWitnessVi(beginCycle - 1, srAddress);
        BigInteger endVi = delegationStore.getWitnessVi(endCycle - 1, srAddress);
        BigInteger deltaVi = endVi.subtract(beginVi);
        if (deltaVi.signum() <= 0) {
          continue;
        }
        long userVote = vote.getValue();
        reward += deltaVi.multiply(BigInteger.valueOf(userVote))
            .divide(DelegationStore.DECIMAL_OF_VI_REWARD).longValue();
      }
    }
    return reward;
  }

  private void accumulateWitnessVi(long cycle, byte[] address) {
    BigInteger preVi = getWitnessVi(cycle - 1, address);
    long voteCount = getWitnessVote(cycle, address);
    long reward = getReward(cycle, address);
    if (reward == 0 || voteCount == 0) { // Just forward pre vi
      if (!BigInteger.ZERO.equals(preVi)) { // Zero vi will not be record
        setWitnessVi(cycle, address, preVi);
      }
    } else { // Accumulate delta vi
      BigInteger deltaVi = BigInteger.valueOf(reward)
          .multiply(DECIMAL_OF_VI_REWARD)
          .divide(BigInteger.valueOf(voteCount));
      setWitnessVi(cycle, address, preVi.add(deltaVi));
    }
  }

  public static void withdrawReward(byte[] address, Repository repository) {
    if (!VMConfig.allowTvmVote()) {
      return;
    }
    AccountCapsule accountCapsule = repository.getAccount(address);
    long beginCycle = repository.getBeginCycle(address);
    long endCycle = repository.getEndCycle(address);
    long currentCycle = repository.getDynamicPropertiesStore().getCurrentCycleNumber();
    long reward = 0;
    if (beginCycle > currentCycle || accountCapsule == null) {
      return;
    }
    if (beginCycle == currentCycle) {
      AccountCapsule account = repository.getAccountVote(beginCycle, address);
      if (account != null) {
        return;
      }
    }
    if (beginCycle + 1 == endCycle && beginCycle < currentCycle) {
      AccountCapsule account = repository.getAccountVote(beginCycle, address);
      if (account != null) {
        reward = computeReward(beginCycle, endCycle, account, repository);
        adjustAllowance(address, reward, repository);
        reward = 0;
      }
      beginCycle += 1;
    }
    endCycle = currentCycle;
    if (CollectionUtils.isEmpty(accountCapsule.getVotesList())) {
      repository.updateBeginCycle(address, endCycle + 1);
      return;
    }
    if (beginCycle < endCycle) {
      reward += computeReward(beginCycle, endCycle, accountCapsule, repository);
      adjustAllowance(address, reward, repository);
    }
    repository.updateBeginCycle(address, endCycle);
    repository.updateEndCycle(address, endCycle + 1);
    repository.updateAccountVote(address, endCycle, accountCapsule);
  }

  private void countVoteAccount(VoteWitnessContract voteContract) {
    AccountStore accountStore = chainBaseManager.getAccountStore();
    VotesStore votesStore = chainBaseManager.getVotesStore();
    MortgageService mortgageService = chainBaseManager.getMortgageService();
    byte[] ownerAddress = voteContract.getOwnerAddress().toByteArray();

    VotesCapsule votesCapsule;

    //
    mortgageService.withdrawReward(ownerAddress);

    AccountCapsule accountCapsule = accountStore.get(ownerAddress);

    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    if (dynamicStore.supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    if (!votesStore.has(ownerAddress)) {
      votesCapsule = new VotesCapsule(voteContract.getOwnerAddress(),
          accountCapsule.getVotesList());
    } else {
      votesCapsule = votesStore.get(ownerAddress);
    }

    accountCapsule.clearVotes();
    votesCapsule.clearNewVotes();

    voteContract.getVotesList().forEach(vote -> {
      logger.debug("countVoteAccount, address[{}]",
          ByteArray.toHexString(vote.getVoteAddress().toByteArray()));

      votesCapsule.addNewVotes(vote.getVoteAddress(), vote.getVoteCount());
      accountCapsule.addVotes(vote.getVoteAddress(), vote.getVoteCount());
    });

    accountStore.put(accountCapsule.createDbKey(), accountCapsule);
    votesStore.put(ownerAddress, votesCapsule);
  }
