### Title
SSRF via attacker-controlled `HttpUrl` in `CreateRepositoryFromSnapshot` - ([File: internal/gitaly/service/repository/create_repository_from_snapshot.go])

### Summary
`CreateRepositoryFromSnapshot` issues an outbound HTTP GET to the caller-supplied `HttpUrl` (with caller-supplied `HttpAuth` as the `Authorization` header) with no validation that the destination is not an internal-only or link-local address. The optional `ResolvedAddress` mechanism only pins the DNS resolution to prevent rebinding attacks; it does not restrict the target to a public/allow-listed IP range, so the RPC can be used as a server-side request forgery primitive against internal hosts (e.g. cloud metadata endpoints, internal services) reachable from the Gitaly node.

### Finding Description
`untar` builds an HTTP request directly from `in.GetHttpUrl()` and sets `Authorization: in.GetHttpAuth()` verbatim [1](#0-0) . If `ResolvedAddress` is supplied, `newResolvedHTTPClient` only checks that it parses as a valid IP address and pins the TCP dial to that IP:port — it never checks that the IP/host is not private, loopback, or link-local (e.g. `169.254.169.254`, `127.0.0.1`, RFC1918 ranges) [2](#0-1) . If `ResolvedAddress` is omitted, the plain `httpClient` performs ordinary DNS resolution and connects to whatever `HttpUrl` resolves to, again with no destination allow-list [3](#0-2) . The code comment itself acknowledges the archive/endpoint is "trusted a lot" and needs hardening before being pointed at untrusted endpoints [4](#0-3) . On failure, the HTTP status line is echoed back to the caller via `structerr.NewInternal("HTTP server: %s", rsp.Status)` and connection errors via `structerr.NewInternal("HTTP request failed: %w", err)` [5](#0-4) , giving the caller a signal about reachability/response of the internal target (status code/text), though not the full response body.

### Impact Explanation
An attacker who can invoke this RPC (per the stated precondition) can force the Gitaly node to make arbitrary outbound HTTP GET requests to internal-only network addresses, using Gitaly as an SSRF proxy. This enables internal network/port reconnaissance and potential interaction with internal-only services (status/error text is reflected back), matching the SSRF impact class. Note the `HttpAuth` value is attacker-supplied, not a Gitaly secret, so this does not itself leak Gitaly credentials — the concrete impact is SSRF/internal reachability disclosure, not credential leak.

### Likelihood Explanation
Given the stated precondition that an unprivileged, repository-owning user can directly invoke `CreateRepositoryFromSnapshot` with arbitrary `HttpUrl`/`HttpAuth`/`ResolvedAddress` values, exploitation is straightforward and fully repeatable: no allow-list or private-IP filtering exists in `untar`/`newResolvedHTTPClient` to block it.

### Recommendation
Validate the resolved destination IP (and the parsed host of `HttpUrl` when `ResolvedAddress` is not set) against private/loopback/link-local/reserved IP ranges before dialing, and reject such requests. Consider requiring `ResolvedAddress` always be set by a trusted caller (e.g. GitLab Rails/Workhorse) with server-side validation performed outside of Gitaly's trust boundary, and avoid reflecting raw upstream HTTP status/error text back through structured errors.

func newResolvedHTTPClient(httpAddress, resolvedAddress string) (*http.Client, error) {
	url, err := url.ParseRequestURI(httpAddress)
	if err != nil {
		return nil, structerr.NewInvalidArgument("parsing HTTP URL: %w", err)
	}

	port := url.Port()
	if port == "" {
		switch url.Scheme {
		case "http":
			port = "80"
		case "https":
			port = "443"
		default:
			return nil, structerr.NewInvalidArgument("unsupported schema %q", url.Scheme)
		}
	}

	// Sanity-check whether the resolved address is a valid IP address.
	if net.ParseIP(resolvedAddress) == nil {
		return nil, structerr.NewInvalidArgument("invalid resolved address %q", resolvedAddress)
	}

	transport := httpTransport.Clone()
	transport.DialContext = func(ctx context.Context, network, _ string) (net.Conn, error) {
		return httpTransport.DialContext(ctx, network, fmt.Sprintf("%s:%s", resolvedAddress, port))
	}

func (s *server) untar(ctx context.Context, path string, in *gitalypb.CreateRepositoryFromSnapshotRequest) error {
	req, err := http.NewRequestWithContext(ctx, "GET", in.GetHttpUrl(), nil)
	if err != nil {
		return structerr.NewInvalidArgument("Bad HTTP URL: %w", err)
	}

	client := httpClient
	if resolvedAddress := in.GetResolvedAddress(); resolvedAddress != "" {
		client, err = newResolvedHTTPClient(in.GetHttpUrl(), resolvedAddress)
		if err != nil {
			return structerr.NewInvalidArgument("creating resolved HTTP client: %w", err)
		}
	}

	if in.GetHttpAuth() != "" {
		req.Header.Set("Authorization", in.GetHttpAuth())
	}
