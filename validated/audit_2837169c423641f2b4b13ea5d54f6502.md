### Title
Unauthenticated remote `POST /shutdown` permanently terminates the signer's event receiver - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` handles the `/shutdown` URL by unconditionally setting `stop_signal` and terminating, with no check of source address, secret, or any credential. Any TCP peer that can reach the bound event-receiver socket can POST to `/shutdown` and permanently stop the signer's event processing loop.

### Finding Description
In `next_event`, the request-routing logic dispatches purely on `request.url()` and `request.method()`: [1](#0-0) 

When `request.url() == "/shutdown"`, the code immediately does `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `Err(EventError::Terminated)` — there is no verification of a shared secret, no check that the request came from the local Stacks node process (e.g., no loopback-only enforcement at the HTTP layer, no token/header comparison), unlike the RPC-secret gating used elsewhere in the codebase for privileged node endpoints. The intended caller is `SignerStopSignaler::send`, which is only invoked by the signer's own process via a local `TcpStream::connect(self.local_addr)`, but nothing in `next_event` restricts the `/shutdown` path to that caller — it accepts the request from any TCP client that can complete an HTTP POST to that socket: [2](#0-1) 

Once `stop_signal` is set, `main_loop`'s subsequent call to `next_event` short-circuits with `Err(EventError::Terminated)`, causing the loop to `break` and exit permanently: [3](#0-2) 

The attacker's exact message is a single crafted HTTP request:
```
POST /shutdown HTTP/1.1
Host: <event-receiver-addr>
Content-Length: 0

```
No body content, JSON payload, or signature is checked before the stop flag is stored — the equality/guard the code should have (verifying the caller is the trusted local Stacks node) does not exist at all.

### Impact Explanation
Any remote party who can open a TCP connection to the signer's event-receiver bind address can permanently disable the signer's ability to receive block proposals, StackerDB chunk events, burn-block events, and block-validation responses from the node, since `main_loop` exits and is not automatically restarted. This is a single-message, unauthenticated, repeatable remote DoS against the signer's core event pipeline, matching the "Critical - remote crash/unauthenticated DoS from few messages" category. It does not corrupt on-chain state directly, but it silences a signer, which can affect the signer's participation in block signing.

### Likelihood Explanation
No privileged role, secret, or session state is required — only network reachability to the bound event-receiver socket, and this is explicitly allowed under the threat model as "any remote party who can connect to a node's P2P or RPC port." The event-receiver socket address is configured (`endpoint` in `stacks-signer/src/config.rs`) and depending on operator configuration may be bound to a non-loopback interface; the attack is a single crafted HTTP request costing effectively nothing and is fully repeatable across any signer instance whose event-receiver port is reachable.

### Recommendation
Restrict `/shutdown` handling to trusted local callers only: verify the request originates from `127.0.0.1`/loopback (reject `/shutdown` if the peer address is not local), and/or require a shared-secret token (e.g., compare against a value only known to the local node process) before storing `stop_signal`. Do not rely solely on URL string matching for a control-plane operation.

use std::io::Write;
use std::thread;
use std::time::Duration;

#[test]
fn remote_shutdown_without_auth() {
    let mut receiver = SignerEventReceiver::<SomeSignerMessageType>::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();
    let (tx, _rx) = std::sync::mpsc::channel();
    receiver.add_consumer(tx);

    let handle = thread::spawn(move || {
        receiver.main_loop(); // should run until it receives /shutdown
    });

    // Attacker: no secret, no local privilege -- just a raw POST
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = "POST /shutdown HTTP/1.1\r\nHost: x\r\nContent-Length: 0\r\n\r\n";
    stream.write_all(req.as_bytes()).unwrap();

    // Assert the main loop exits (i.e., is_stopped() becomes true / thread joins)
    // within a short deadline, proving unauthenticated remote shutdown succeeded.
    handle.join().unwrap();
}
