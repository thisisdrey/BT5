### Title
Unauthenticated `/shutdown` endpoint permanently halts `SignerEventReceiver::main_loop` - (File: libsigner/src/events.rs)

### Summary
The `next_event` handler in `SignerEventReceiver` treats any HTTP POST to `/shutdown` as an authoritative termination command, setting `stop_signal` to `true` with no signature, secret, or origin check whatsoever. Since `main_loop` checks `is_stopped()` on every iteration and exits when true, a single unauthenticated POST permanently stops the signer's event-processing loop.

### Finding Description
In `next_event`, the URL dispatch branches check `request.url()` against fixed strings, and for `/shutdown` the code does: [1](#0-0) 
This branch performs no validation of the request body, headers, or sender identity — it is reached purely by matching the URL string, unlike `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block`, which at least attempt to deserialize a JSON/event payload via `process_event`. The `stop_signal` is an `Arc<AtomicBool>` shared with `is_stopped()`: [2](#0-1) 
and `main_loop` unconditionally breaks out of the receive loop once `is_stopped()` returns true: [3](#0-2) 
The legitimate caller of this mechanism is `SignerStopSignaler::send`, which is only ever invoked internally by the signer process itself to gracefully shut down its own receiver by connecting to `self.local_addr` and sending exactly this `POST /shutdown` request: [4](#0-3) 
However, nothing in `next_event`'s `/shutdown` branch restricts the trigger to this internal caller — any TCP client that can open a connection to the bound `HttpServer` address and send `POST /shutdown HTTP/1.1` with any (or even empty) body reaches the same code path and flips the same flag.

### Impact Explanation
Once `stop_signal` is set, `is_stopped()` returns `true` on every subsequent poll, so `main_loop` exits permanently — the signer stops receiving miner block proposals, StackerDB chunk events, burn-block events, and new-block events from the node indefinitely (until the signer process is manually restarted). This is a full, permanent unauthenticated denial of service against the signer's event pipeline from a single crafted HTTP request, matching the "Critical - remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
The only precondition is TCP reachability to the address `SignerEventReceiver::bind` is called with. This endpoint is intended to receive callbacks only from the local stacks-node event-observer, but the code contains no binding restriction to loopback and no authentication layer at the application level — reachability depends entirely on operator network configuration/firewalling, not on any code-level defense. If the port is reachable (e.g., bound to a non-loopback interface, or reachable via any lateral network path), the attack requires exactly one TCP connection and one HTTP request, with no secret, key, or privileged role needed, and is trivially repeatable.

### Recommendation
Require the `/shutdown` request (and ideally all POST endpoints) to be authenticated — e.g., include a shared secret/token known only to the local node and signer process (similar to RPC bearer-token patterns elsewhere in the codebase), and/or restrict `HttpServer::http` binding to loopback only and reject connections from non-loopback peer addresses at accept time. At minimum, validate a secret header/body value in the `/shutdown` branch before storing `true` into `stop_signal`.

```rust
// libsigner/src/events.rs (test module)
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use std::thread;

#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<SomeMessageType> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound_addr = receiver.bind(addr).unwrap();

    // Attacker: connect directly, no secret/auth header, no relation to the node
    let mut stream = TcpStream::connect(bound_addr).unwrap();
    let body = "arbitrary attacker body";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        bound_addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Trigger recv() inside next_event to process the pending request
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());

    // Any subsequent call also terminates immediately
    let result2 = receiver.next_event();
    assert!(matches!(result2, Err(EventError::Terminated)));
}
```
