**Analysis**: The claimed binding — that `commit_nonce` keying on `(signer_id, nonce)` rather than nonce alone constitutes a flaw — inverts the actual security requirement. Nonce replay protection is *intentionally* scoped per-account: each `Account` struct stores its own `nonces: MaybeLegacyAccountNonces` field [1](#0-0) , backed by a `LookupMap` nested under an account-specific storage prefix [2](#0-1) .

`Engine::execute_signed_intent` calls `self.state.commit_nonce(signer_id.clone(), nonce)` [3](#0-2) , which routes through `Contract::commit_nonce` to `self.accounts.get_or_create(account_id).get_mut()...commit_nonce(nonce)` [4](#0-3) . Since each account is a distinct storage-keyed entry with its own independent nonce map, committing the same raw nonce bytes under two different `signer_id`s writes to two entirely separate `LookupMap` instances with different storage prefixes — there is no shared state, key collision, or cross-account interference possible. This is confirmed by `MaybeLegacyNonces::commit`/`is_used`, which operate purely on the instance's own `nonces`/`legacy` fields with no cross-account references [5](#0-4) .

A batch with `MultiPayload::Nep413` (signer A) and `MultiPayload::Erc191` (signer B) both using identical nonce bytes settles both independently: each commits into its own account's nonce map, no balance or replay state is shared, and neither transaction affects the other's nonce namespace. This does not violate any of the listed Critical/High impact categories — no unauthorized fund movement, no double-settlement of a single signature, and no `simulate_intents`/`execute_intents` divergence.

    pub fn commit(&mut self, nonce: Nonce) -> Result<()> {
        // Check legacy maps for used nonce
        if self
            .legacy
            .as_ref()
            .is_some_and(|legacy| legacy.is_used(nonce))
        {
            return Err(DefuseError::NonceUsed);
        }

        // New nonces can be committed only to the new map
        self.nonces.commit(nonce)
    }

    #[inline]
    pub fn is_used(&self, nonce: Nonce) -> bool {
        self.nonces.is_used(nonce)
            || self
                .legacy
                .as_ref()
                .is_some_and(|legacy| legacy.is_used(nonce))
    }
