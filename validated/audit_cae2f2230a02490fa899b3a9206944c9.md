### Title
Stake 2.0 "unfreeze delay" feature gate is enforced in the transaction-level actuator but missing in the TVM native-contract path, letting a smart contract call `unfreezeBalanceV2`/`withdrawExpireUnfreeze` before the committee has enabled the feature - (File: `actuator/src/main/java/org/tron/core/vm/nativecontract/UnfreezeBalanceV2Processor.java`)

### Summary
Just like the LooksRare `rolloverEth()` bug where the `outflowAllowed` gate was checked in every withdrawal-capable function except one, java-tron enforces the `dynamicStore.supportUnfreezeDelay()` committee gate in the ordinary `UnfreezeBalanceV2Contract` actuator, but the equivalent TVM native-contract processor invoked by a smart contract via the `unfreezeBalanceV2`/`withdrawExpireUnfreeze` opcodes omits this check entirely.

### Finding Description
`UnfreezeBalanceV2Actuator.validate()` explicitly rejects the transaction unless the committee has turned on the Stake 2.0 delayed-unfreeze feature: [1](#0-0) 

The TVM-reachable counterpart, `UnfreezeBalanceV2Processor.validate()` (invoked from `Program.unfreezeBalanceV2()`, which any deployed contract can call), performs address/frozen-balance/unfreeze-count checks but never calls `dynamicStore.supportUnfreezeDelay()`: [2](#0-1) [3](#0-2) 

The same asymmetry exists for the companion withdraw function: `WithdrawExpireUnfreezeActuator.validate()` gates on `supportUnfreezeDelay()`: [4](#0-3) 

while `WithdrawExpireUnfreezeProcessor.validate()`, called from `Program.withdrawExpireUnfreeze()` and reachable by any contract, does not: [5](#0-4) [6](#0-5) 

`CancelAllUnfreezeV2Processor` (also TVM-reachable) likewise has no `supportUnfreezeDelay()` check: [7](#0-6) 

`supportUnfreezeDelay()` is the accessor for the `ALLOW_UNFREEZE_DELAY` committee-controlled chain parameter, meant to be a single network-wide switch gating the entire delayed-unfreeze/withdraw code path across all entry points: [8](#0-7) 

Because this switch is checked only in the transaction actuators and not in the TVM native-contract processors, any contract (deployed and invoked by an unprivileged caller via a normal `TriggerSmartContract`) can call the `unfreezeBalanceV2`/`withdrawExpireUnfreeze`/`cancelAllUnfreezeV2` opcodes and populate/consume `unfrozenV2` state even on a chain where the committee has not yet activated `ALLOW_UNFREEZE_DELAY`.

### Impact Explanation
This is the same bug class as the reported issue: a governance/feature gate that is supposed to block an entire class of state-mutating/fund-releasing operations is bypassed through one alternate call path. Here, the alternate path is reachable by any account through ordinary smart-contract execution (no privileged role required). Exploiting it allows an account to force the network into the Stake 2.0 unfreeze/withdraw model (mutating `frozenV2`/`unfrozenV2` lists, total resource weights, and vote power) before the network has been upgraded to support that data model consistently across `BandwidthProcessor`, `EnergyProcessor`, and `ResourceProcessor`, which all branch on `supportUnfreezeDelay()`. This can desynchronize resource accounting and vote/TRON-power bookkeeping between nodes/paths that assume the feature is off, a state-consistency and potential fund-accounting integrity issue.

### Likelihood Explanation
Reachable by any unprivileged account that deploys a trivial contract calling the corresponding precompiled/native opcode — no special privileges, no malicious-SR/witness role, and no reliance on rare edge-case dust amounts (unlike the original LooksRare bug), making this straightforward to trigger the moment the code paths diverge (i.e., on any network/testnet where `ALLOW_UNFREEZE_DELAY` isn't yet enabled but the TVM opcodes are already live).

### Recommendation
Add the same `dynamicStore.supportUnfreezeDelay()` check (mirroring `UnfreezeBalanceV2Actuator.validate()`/`WithdrawExpireUnfreezeActuator.validate()`) to `UnfreezeBalanceV2Processor.validate()`, `WithdrawExpireUnfreezeProcessor.validate()`, and `CancelAllUnfreezeV2Processor.validate()` so that the feature gate is enforced uniformly across both the transaction-actuator and TVM native-contract entry points.

### Proof of Concept
1. Deploy any contract on a network/config where `ALLOW_UNFREEZE_DELAY` has not been enabled by the committee (`dynamicStore.supportUnfreezeDelay()` returns `false`).
2. From the contract, invoke the `unfreezeBalanceV2` TVM opcode (via `Program.unfreezeBalanceV2`) after freezing balance normally through `freezeBalanceV2`.
3. Observe that `UnfreezeBalanceV2Processor.validate()` at [9](#0-8)  succeeds and mutates `unfrozenV2` state, whereas issuing the equivalent `UnfreezeBalanceV2Contract` transaction through the normal actuator path fails with "Not support UnfreezeV2 transaction, need to be opened by the committee" per [1](#0-0) , confirming the gate bypass through the TVM path.

  public void validate(UnfreezeBalanceV2Param param, Repository repo)
      throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (accountCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ACCOUNT_EXCEPTION_STR + readableOwnerAddress + "] does not exist");
    }
    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    int unfreezingCount = accountCapsule.getUnfreezingV2Count(now);
    if (UnfreezeBalanceV2Actuator.getUNFREEZE_MAX_TIMES() <= unfreezingCount) {
      throw new ContractValidateException("Invalid unfreeze operation, unfreezing times is over limit");
    }
    switch (param.getResourceType()) {
      case BANDWIDTH:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.BANDWIDTH)) {
          throw new ContractValidateException("no frozenBalance(BANDWIDTH)");
        }
        break;
      case ENERGY:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.ENERGY)) {
          throw new ContractValidateException("no frozenBalance(ENERGY)");
        }
        break;
      case TRON_POWER:
        if (dynamicStore.supportAllowNewResourceModel()) {
          if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.TRON_POWER)) {
            throw new ContractValidateException("no frozenBalance(TRON_POWER)");
          }
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    if (!checkUnfreezeBalance(accountCapsule, param.getUnfreezeBalance(), param.getResourceType())) {
      throw new ContractValidateException(
          "Invalid unfreeze_balance, [" + param.getUnfreezeBalance() + "] is invalid");
    }

    if (accountCapsule.hasInvalidDelegatedV2()) {
      MUtil.checkCPUTimeForInvalidDelegatedV2Balance();
    }
  }

  public boolean unfreezeBalanceV2(DataWord unfreezeBalance, DataWord resourceType) {
    Repository repository = getContractState().newRepositoryChild();
    byte[] owner = getContextAddress();

    increaseNonce();
    InternalTransaction internalTx = addInternalTx(null, owner, owner,
        unfreezeBalance.longValue(), null,
        "unfreezeBalanceV2For" + convertResourceToString(resourceType), nonce, null);

    try {
      UnfreezeBalanceV2Param param = new UnfreezeBalanceV2Param();
      param.setOwnerAddress(owner);
      param.setUnfreezeBalance(unfreezeBalance.sValue().longValueExact());
      param.setResourceType(parseResourceCodeV2(resourceType));

      UnfreezeBalanceV2Processor processor = new UnfreezeBalanceV2Processor();
      processor.validate(param, repository);
      long unfreezeExpireBalance = processor.execute(param, repository);
      repository.commit();
      if (unfreezeExpireBalance > 0) {
        increaseNonce();
        addInternalTx(null, owner, owner, unfreezeExpireBalance, null,
            "withdrawExpireUnfreezeWhileUnfreezing", nonce, null);
      }
      return true;
    } catch (ContractValidateException e) {
      logger.warn("TVM UnfreezeBalanceV2: validate failure. Reason: {}", e.getMessage());
    } catch (ArithmeticException e) {
      logger.warn("TVM UnfreezeBalanceV2: balance out of long range.");
    }
    if (internalTx != null) {
      internalTx.reject();
    }
    return false;
  }

  public void validate(WithdrawExpireUnfreezeParam param, Repository repo) throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (Objects.isNull(accountCapsule)) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(ACCOUNT_EXCEPTION_STR
          + readableOwnerAddress + NOT_EXIST_STR);
    }

    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    List<Protocol.Account.UnFreezeV2> unfrozenV2List = accountCapsule.getInstance()
        .getUnfrozenV2List();
    long totalWithdrawUnfreeze = getTotalWithdrawUnfreeze(unfrozenV2List, now);
    if (totalWithdrawUnfreeze < 0) {
      throw new ContractValidateException("no unFreeze balance to withdraw ");
    }
    try {
      LongMath.checkedAdd(accountCapsule.getBalance(), totalWithdrawUnfreeze);
    } catch (ArithmeticException e) {
      logger.debug(e.getMessage(), e);
      throw new ContractValidateException(e.getMessage());
    }

    if (accountCapsule.hasInvalidDelegatedV2()) {
      MUtil.checkCPUTimeForInvalidDelegatedV2Balance();
    }
  }
