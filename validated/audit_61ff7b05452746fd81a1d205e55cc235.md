Audit Report

## Title
Missing decimals-drift validation on `pallet-psm::redeem` allows stale conversion scale to break PSM reserve/debt accounting - (File: `substrate/frame/psm/src/lib.rs`)

## Summary
`pallet-psm::mint` re-validates live `pallet-assets` decimals against the registration-time snapshot and halts with `Error::DecimalsMismatch` on drift, but `pallet-psm::redeem` does not perform the equivalent check before calling `internal_to_external`/`external_to_internal`, and instead silently uses the stale snapshot decimals to compute the payout scale.

## Finding Description
The conversion helpers `external_to_internal` and `internal_to_external` compute the conversion purely by scaling with `10^diff` derived from whatever `ext_decimals`/`internal_decimals` values are passed in — they perform no independent validation of those values against live on-chain state [1](#0-0) . The pallet's documented invariant is that decimals are snapshotted at registration and any operation halts if live `pallet-assets` metadata drifts from that snapshot [2](#0-1) . This is enforced for `mint`, as shown by the test `mint_halts_when_asset_decimals_drift`, which changes an approved external asset's decimals post-registration and asserts the subsequent `mint` call fails with `Error::DecimalsMismatch` [3](#0-2) , and similarly `mint_halts_when_internal_decimals_drift` for the internal asset's decimals [4](#0-3) .

The corresponding `redeem` tests demonstrate the opposite behavior under the identical drift setup: `redeem_uses_snapshot_when_asset_decimals_drift` performs the same `Assets::set_metadata` decimals change after minting, then calls `Psm::redeem` and asserts `assert_ok!`, with resulting balances computed from the stale registration-time snapshot rather than being rejected [5](#0-4) . The analogous `redeem_uses_snapshot_when_internal_decimals_drift` confirms the same asymmetry for internal-asset decimal drift, again succeeding and using stale decimals to derive the external payout and debt reduction [6](#0-5) .

I was unable to directly view the `redeem` dispatchable's function body in this session (only located it exists via `grep_search` matches in `substrate/frame/psm/src/lib.rs`), so the exact missing guard call site is inferred from the test-suite behavior rather than confirmed by reading the dispatchable's source line-by-line.

## Impact Explanation
Decimals are `pallet-assets` metadata mutable by the external asset's owner (an entity separate from and not privileged over the PSM instance's governance). If decimals drift after registration, `redeem` computes the external payout and internal-debt reduction using the outdated snapshot's scale factor instead of rejecting the operation the way `mint` does. This breaks the 1:1 backing invariant between `PsmDebt` and the reserve balance held under the PSM account, resulting in over- or under-payment of the external reserve relative to the internal debt burned — an asset-accounting value-conservation failure reachable through a fully public, unprivileged extrinsic.

## Likelihood Explanation
The precondition (an asset owner calling the standard, unprivileged `pallet-assets::set_metadata` to change decimals on an already-PSM-approved asset) requires no PSM governance/admin capability, no validator or node compromise, and no relayer trust assumption — only ordinary control over the external asset's own metadata, which the asset owner naturally has. Once decimals drift, any user can call the public `redeem` extrinsic to realize the miscalculated exchange, making this directly and repeatably reachable via normal public dispatch.

## Recommendation
Apply the same live-vs-snapshot decimals validation in `redeem` that `mint` performs before calling `external_to_internal`/`internal_to_external`: re-fetch each involved asset's live decimals from `pallet-assets` metadata, compare against `AssetDecimals`/`InternalDecimals`, and return `Error::DecimalsMismatch` on divergence, exactly mirroring `mint`'s check, before performing the conversion and updating `PsmDebt`/reserve balances.

## Proof of Concept
1. Register an external asset (e.g., `USDX`) on a PSM instance and call `Psm::mint` to establish `PsmDebt` and reserve balance under the original decimals snapshot.
2. As the external asset's owner, call `Assets::set_metadata` to change its `decimals` field, simulating post-registration drift, exactly as done in `redeem_uses_snapshot_when_asset_decimals_drift` [7](#0-6) .
3. Call the public `Psm::redeem` extrinsic — per the existing test assertions it succeeds (`assert_ok!`) rather than returning `DecimalsMismatch`, computing the external payout using the stale decimals snapshot instead of the asset's live/current unit scale [8](#0-7) .

		///
		/// Scales by `10^(ext_decimals - internal_decimals)` — multiplies up when internal has more
		/// decimals, floor-divides when it has fewer. Returns [`Error::ConversionOverflow`] if
		/// the scaling factor or the product does not fit in the balance type.
		pub(crate) fn external_to_internal(
			amount: BalanceOf<T>,
			ext_decimals: u8,
			internal_decimals: u8,
		) -> Result<BalanceOf<T>, Error<T>> {
			use core::cmp::Ordering::*;
			match ext_decimals.cmp(&internal_decimals) {
				Equal => Ok(amount),
				Less => {
					let diff = (internal_decimals - ext_decimals) as u32;
					let factor = Self::pow10(diff)?;
					amount.checked_mul(&factor).ok_or(Error::<T>::ConversionOverflow)
				},
				Greater => {
					let diff = (ext_decimals - internal_decimals) as u32;
					let factor = Self::pow10(diff)?;
					Ok(amount.checked_div(&factor).unwrap_or_else(BalanceOf::<T>::zero))
				},
			}
		}

	#[test]
	fn redeem_uses_snapshot_when_asset_decimals_drift() {
		new_test_ext().execute_with(|| {
			register_external_asset_with_weight(USDX_ASSET_ID, Permill::from_percent(100));
			set_zero_fees(USDX_ASSET_ID);

			// Mint first, then change decimals.
			assert_ok!(Psm::mint(
				RuntimeOrigin::signed(ALICE),
				INTERNAL_ASSET_ID,
				USDX_ASSET_ID,
				10_000 * USDX_UNIT,
				Permill::zero()
			));
			assert_ok!(Assets::set_metadata(
				RuntimeOrigin::signed(ALICE),
				USDX_ASSET_ID,
				b"USDX".to_vec(),
				b"USDX".to_vec(),
				4
			));

			let alice_usdx_before = get_asset_balance(USDX_ASSET_ID, ALICE);
			let alice_internal_before = get_asset_balance(INTERNAL_ASSET_ID, ALICE);
			let debt_before = PsmDebt::<Test>::get(INTERNAL_ASSET_ID, USDX_ASSET_ID);

			assert_ok!(Psm::redeem(
				RuntimeOrigin::signed(ALICE),
				INTERNAL_ASSET_ID,
				USDX_ASSET_ID,
				100 * INTERNAL_UNIT,
				Permill::zero()
			));

			assert_eq!(
				get_asset_balance(USDX_ASSET_ID, ALICE),
				alice_usdx_before + 100 * USDX_UNIT
			);
			assert_eq!(
				get_asset_balance(INTERNAL_ASSET_ID, ALICE),
				alice_internal_before - 100 * INTERNAL_UNIT
			);
			assert_eq!(
				PsmDebt::<Test>::get(INTERNAL_ASSET_ID, USDX_ASSET_ID),
				debt_before - 100 * INTERNAL_UNIT
			);
		});
	}

	#[test]
	fn redeem_uses_snapshot_when_internal_decimals_drift() {
		new_test_ext().execute_with(|| {
			// Seed ALICE's internal balance and PSM reserve with a prior mint, then
			// drift the internal asset's decimals.
			assert_ok!(Psm::mint(
				RuntimeOrigin::signed(ALICE),
				INTERNAL_ASSET_ID,
				USDC_ASSET_ID,
				1000 * INTERNAL_UNIT,
				Permill::from_percent(1)
			));
			assert_ok!(Assets::set_metadata(
				RuntimeOrigin::signed(ALICE),
				INTERNAL_ASSET_ID,
				b"INTERNAL".to_vec(),
				b"INTERNAL".to_vec(),
				8
			));

			let alice_usdc_before = get_asset_balance(USDC_ASSET_ID, ALICE);
			let alice_internal_before = get_asset_balance(INTERNAL_ASSET_ID, ALICE);
			let insurance_internal_before = get_asset_balance(INTERNAL_ASSET_ID, INSURANCE_FUND);
			let debt_before = PsmDebt::<Test>::get(INTERNAL_ASSET_ID, USDC_ASSET_ID);
			let redeem = 100 * INTERNAL_UNIT;
			let fee = Permill::from_percent(1).mul_ceil(redeem);
			let external_out = redeem - fee;

			assert_ok!(Psm::redeem(
				RuntimeOrigin::signed(ALICE),
				INTERNAL_ASSET_ID,
				USDC_ASSET_ID,
				redeem,
				Permill::from_percent(1)
			));

			assert_eq!(get_asset_balance(USDC_ASSET_ID, ALICE), alice_usdc_before + external_out);
			assert_eq!(get_asset_balance(INTERNAL_ASSET_ID, ALICE), alice_internal_before - redeem);
			assert_eq!(
				get_asset_balance(INTERNAL_ASSET_ID, INSURANCE_FUND),
				insurance_internal_before + fee
			);
			assert_eq!(
				PsmDebt::<Test>::get(INTERNAL_ASSET_ID, USDC_ASSET_ID),
				debt_before - external_out
			);
		});
	}
