No vulnerability found for this question.

**Reasoning:**

The premise misidentifies the code path. `bootstrap_congestion_info` (`runtime/runtime/src/congestion_control.rs:743`) is only invoked as an IO-heavy fallback from `ApplyState::own_congestion_info` (`runtime/runtime/src/lib.rs:2894-2907`) when no prior `CongestionInfo` exists for a shard in `apply_state.congestion_info` — this happens at genesis or similar bootstrap scenarios, not as part of the resharding split pipeline. [1](#0-0) 

Resharding's child `CongestionInfo` is computed by a completely different, deterministic mechanism: `ReshardingManager::get_child_congestion_info_not_finalized` (`chain/chain/src/resharding/manager.rs:327-365`). The left child inherits the parent's `CongestionInfo` verbatim (it retains all delayed/buffered receipts), and the right child's info is derived by *subtracting* the exact gas/size totals recorded in each shard's `ReceiptGroupsQueue` metadata — precomputed running totals, not a re-iteration/re-summation of receipts — via `remove_buffered_receipt_gas`/`remove_receipt_bytes`. [2](#0-1) 

This split is invariant-checked with an explicit assertion (`assert_eq!(congestion_info.buffered_receipts_gas(), 0)`) and executed identically by every node validating the chunk witness (`chain/chain/src/stateless_validation/chunk_validation.rs:711-746`), not by a single privileged actor an attacker could bias — it's deterministic given the same parent state, so there's no double-count/miss window an unprivileged attacker's receipt placement could introduce distinct from any other user's receipts. [3](#0-2) 

Additionally, the overflow concern is unfounded: `CongestionInfo::add_buffered_receipt_gas`/`remove_buffered_receipt_gas` use `checked_add`/`checked_sub` and return `RuntimeError::UnexpectedIntegerOverflow` rather than silently wrapping. [4](#0-3) 

Reaching anywhere near `u128::MAX` gas via legitimate or malicious transaction submission is not feasible — gas amounts are bounded per-receipt by protocol fee schedules and per-chunk by `gas_limit` (order of `10^14`–`10^17`), many orders of magnitude below `2^128 ≈ 3.4×10^38`. An attacker cannot submit enough receipts across any realistic timeframe to approach this bound, and even if it were approached, the checked-arithmetic returns an error (aborting chunk application) rather than corrupting state or double-counting.

There is no reachable path from an unprivileged attacker's transaction into `bootstrap_congestion_info` during a resharding boundary, no overflow is achievable given `checked_add`, and the actual resharding congestion-split logic uses precise metadata subtraction rather than re-iteration prone to double counting.

    fn get_child_congestion_info_not_finalized(
        parent_trie: &dyn TrieAccess,
        parent_shard_layout: &ShardLayout,
        parent_congestion_info: CongestionInfo,
        retain_mode: RetainMode,
    ) -> Result<CongestionInfo, Error> {
        // The left child contains all the delayed and buffered receipts from the
        // parent so it should have identical congestion info.
        if retain_mode == RetainMode::Left {
            return Ok(parent_congestion_info);
        }

        // The right child contains all the delayed receipts from the parent but it
        // has no buffered receipts. It's info needs to be computed by subtracting
        // the parent's buffered receipts from the parent's congestion info.
        let mut congestion_info = parent_congestion_info;
        for shard_id in parent_shard_layout.shard_ids() {
            let receipt_groups = ReceiptGroupsQueue::load(parent_trie, shard_id)?;
            let Some(receipt_groups) = receipt_groups else {
                continue;
            };

            let bytes = receipt_groups.total_size();
            let gas = receipt_groups.total_gas();

            congestion_info
                .remove_buffered_receipt_gas(gas)
                .expect("Buffered gas must not exceed congestion info buffered gas");
            congestion_info
                .remove_receipt_bytes(bytes)
                .expect("Buffered size must not exceed congestion info buffered size");
        }

        // The right child does not inherit any buffered receipts. The
        // congestion info must match this invariant.
        assert_eq!(congestion_info.buffered_receipts_gas(), 0);

        Ok(congestion_info)
    }

    pub fn add_buffered_receipt_gas(&mut self, gas: Gas) -> Result<(), RuntimeError> {
        match self {
            CongestionInfo::V1(inner) => {
                inner.buffered_receipts_gas = inner
                    .buffered_receipts_gas
                    .checked_add(gas.as_gas().into())
                    .ok_or_else(|| {
                        RuntimeError::UnexpectedIntegerOverflow("add_buffered_receipt_gas".into())
                    })?;
            }
        }
        Ok(())
    }

    pub fn remove_buffered_receipt_gas(&mut self, gas: u128) -> Result<(), RuntimeError> {
        match self {
            CongestionInfo::V1(inner) => {
                inner.buffered_receipts_gas =
                    inner.buffered_receipts_gas.checked_sub(gas).ok_or_else(|| {
                        RuntimeError::UnexpectedIntegerOverflow(
                            "remove_buffered_receipt_gas".into(),
                        )
                    })?;
            }
        }
        Ok(())
    }
