### Title
Nep245/Imt protocol fees bypassed by splitting a single TokenDiff transfer into many unit-delta intents - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::token_fee` charges zero fee whenever `amount <= 1` for `Nep245`/`Imt` token types, and fees are computed independently per executed `TokenDiff` intent rather than on the aggregated transfer size. An unprivileged signer can split one intended transfer of `N>1` units of a Nep245/Imt token into `N` separate `TokenDiff` intents (each with `|delta| == 1`) inside the same `MultiPayload` batch, causing every leg's fee to be `0` instead of the `fee_ceil(protocol_fee, N)` that a single `N`-unit `TokenDiff` would owe.

### Finding Description
The claimed invariant is:
`sum(fee_ceil(protocol_fee, 1) for i in 1..=N) == fee_ceil(protocol_fee, N)` for a Nep245/Imt token transfer of total magnitude `N`.

In `TokenDiff::token_fee` [1](#0-0) , the fee applied is `Pips::ZERO` for `Nep245`/`Imt` whenever `amount <= 1`, and the full `protocol_fee` only when `amount > 1`. This function is invoked per-intent, per-token, inside `TokenDiff::execute_intent`, which loops over `self.diff` (a single intent's own delta map) and computes `fee_ceil` using only that intent's own `amount = delta.unsigned_abs()` [2](#0-1) .

Because `DefuseIntents::execute_intent` simply iterates the `Vec<Intent>` and executes each one independently [3](#0-2) , and `Engine::execute_signed_intents` processes each signed payload (and each intent inside it) independently before calling `finalize()` only to check that the *sum of all deltas nets to zero* across the whole batch [4](#0-3) , there is no point in the pipeline where fee computation aggregates deltas for the same token/signer across multiple intents in a batch.

Exploit: instead of signing one `TokenDiff{diff: {token: -N, ...}}` intent (which would evaluate `token_fee(token, N, protocol_fee)` = `protocol_fee` since `N>1`, yielding a non-zero `fee_ceil(protocol_fee, N)`), the attacker signs `N` separate `TokenDiff` intents (in the same or across `MultiPayload`s), each with `diff: {token: -1, ...}`. For each, `amount == 1`, so `TokenIdType::Nep245 | TokenIdType::Imt if amount > 1 => {}` does not match, falling through to `return Pips::ZERO`, making every leg's `fee_ceil(1) == 0`. Provided the attacker (optionally using a second, self-controlled counterparty account) supplies matching offsetting `+1` legs so the batch balances to zero at `finalize()`, the whole transfer of `N` units settles with `fees_collected == 0` for the `fee_collector`, whereas the equivalent single intent would have paid `fee_ceil(protocol_fee, N) > 0`. No existing guard (`MultiPayload::verify`, nonce checks, `TransferMatcher::finalize`, `assert_one_yocto`, role checks) inspects cross-intent amount aggregation for fee purposes.

### Impact Explanation
This under-collects protocol fees that should accrue to `engine.state.fee_collector()` [5](#0-4) . It matches the explicitly listed Critical category "protocol fees bypassed or over-collected." The bypass is repeatable indefinitely, for any Nep245/Imt token, any account, and any batch size — an attacker (or colluding pair of self-owned accounts) can always decompose an arbitrarily large multi-token transfer into unit legs to owe zero fee, at the cost of larger payload/gas size only.

### Likelihood Explanation
No special privileges are required — any signer can construct and sign an arbitrary number of `TokenDiff` intents with `|delta| = 1` for a Nep245/Imt token id, provided they (or an accomplice account they control) have matching offsetting legs to satisfy the global zero-sum invariant in `finalize()`. Cost is only extra transaction/payload size and gas, which is fully within an ordinary NEAR transaction budget for realistic `N`. This is directly, deterministically reproducible.

### Recommendation
Base the Nep245/Imt fee exemption threshold on the actual per-token per-signer aggregate delta observed across the whole batch (i.e., accumulate deltas by `(signer_id, token_id)` before evaluating `token_fee`'s `amount > 1` condition), rather than evaluating it intent-by-intent. Alternatively, remove/restrict the `amount <= 1` fee exemption for `Nep245`/`Imt` so it only applies to genuinely non-fungible semantics (e.g., token ids with a fixed max supply of 1), not to fungible-like multi-token balances that can be freely split into unit-sized intents.

    pub fn execute_signed_intents(
        mut self,
        signed: impl IntoIterator<Item = MultiPayload>,
    ) -> Result<Transfers> {
        for signed in signed {
            self.execute_signed_intent(signed)?;
        }
        self.finalize()
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    #[inline]
    fn verify_intent_nonce(&self, nonce: Nonce, intent_deadline: Timestamp) -> Result<()> {
        let Some(nonce) = VersionedNonce::maybe_from(nonce) else {
            return Ok(());
        };

        match nonce {
            VersionedNonce::V1(SaltedNonce {
                salt,
                nonce: ExpirableNonce { deadline, .. },
            }) => {
                if !self.state.is_valid_salt(salt) {
                    return Err(DefuseError::InvalidSalt);
                }

                if intent_deadline > deadline {
                    return Err(DefuseError::DeadlineGreaterThanNonce);
                }

                if deadline < Timestamp::now() {
                    return Err(DefuseError::NonceExpired);
                }
            }
        }

        Ok(())
    }

    #[inline]
    fn finalize(self) -> Result<Transfers> {
        self.state
            .finalize()
            .map_err(DefuseError::InvariantViolated)
    }
