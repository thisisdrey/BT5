## Finding: Signer event-receiver HTTP endpoint accepts unauthenticated pushes, allowing forged node events to be injected into the signer

The `stacks-signer`'s `SignerEventReceiver` (in `libsigner`) opens an HTTP listener that is meant to receive `stackerdb_chunks`, `proposal_response`, `new_burn_block`, and `new_block` events pushed only by the trusted, co-located `stacks-node`. However, the transport layer performs no authentication of the sender at all.

### Finding Description

`SignerEventReceiver::next_event` dispatches incoming HTTP POST requests purely by URL path, with no credential check: [1](#0-0) 

The low-level HTTP decoder, `decode_http_request`, parses the verb, path, and headers but never inspects any `Authorization` header or shared secret: [2](#0-1) 

A grep across `libsigner/**` for `auth_token`/`Authorization` returns zero matches — the event receiver has no notion of the `auth_token`/`auth_password` pairing that the project's own documentation describes as a security-relevant setting: [3](#0-2) 

That documented `auth_token`/`auth_password` pairing is only enforced in the opposite direction — it gates the **node's** RPC endpoints (e.g. `postblock_proposal`) when the *signer* calls *into* the node: [4](#0-3) 

There is no analogous check protecting the signer's own listener when the node (or anyone else) pushes data *into* it. The sample config binds this listener to all interfaces by default: [5](#0-4) 

Once a request is accepted, its body is deserialized directly into a `SignerEvent` and handed to the signer runloop as if it had come from the trusted node: [6](#0-5) 

This breaks the equality "message received on the signer's event port == message actually sent by the paired stacks-node." Any remote, unprivileged party that can reach the bound address/port can POST arbitrary `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` payloads and have them treated as authentic node-originated events feeding the signer's state machine.

### Impact Explanation

This is an unauthenticated write into signer-local processing state via a transport-layer auth gate that simply does not exist. Depending on operator network topology (the sample config explicitly binds `0.0.0.0`), a remote attacker can inject forged `new_burn_block`/`new_block`/`stackerdb_chunks` events that desynchronize the signer's view of chain/burnchain state or feed it spoofed StackerDB chunk contents, without needing any node secret or admin role — purely by reaching the configured `endpoint`.

### Likelihood Explanation

Exploitability depends entirely on network exposure of the signer's `endpoint`. Any deployment that binds this listener to a non-loopback address (as the shipped sample config does — `0.0.0.0:30000`), or that has it reachable across a shared/segmented network, is directly exploitable by any unauthenticated peer with network access, requiring only a well-formed HTTP POST.

### Recommendation

Require a shared secret (e.g., reuse of `auth_password`/`auth_token`) or mTLS on the signer's event-receiver HTTP endpoint, verified in `decode_http_request`/`next_event` before any event is forwarded to the signer runloop. At minimum, default the listener to loopback-only binding and document/enforce that non-loopback deployments must be firewalled.

### Proof of Concept

1. Start a `stacks-signer` per `sample/conf/signer/mainnet-signer-conf.toml`, with `endpoint = "0.0.0.0:30000"`.
2. From a separate, unauthenticated host with network access to port 30000, send:
   ```
   POST /new_burn_block HTTP/1.1
   Host: <signer-ip>:30000
   Content-Type: application/json
   Content-Length: <n>

   { ...forged BurnBlockEvent JSON... }
   ```
3. Observe that `SignerEventReceiver::next_event` accepts and forwards this as `SignerEvent::NewBurnBlock` with no authentication check, exactly as it would for a genuine push from the paired node — confirmed by the dispatch logic in `libsigner/src/events.rs` lines 436-457 and the absence of any credential validation in `decode_http_request`.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);

                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}
