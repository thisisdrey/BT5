Audit Report

## Title
Removed/demoted ranked-collective member's vote weight stays counted in ongoing poll tallies - ([File: substrate/frame/ranked-collective/src/lib.rs])

## Summary
`pallet-ranked-collective`'s `vote()` extrinsic writes a member's rank-derived weight into a poll's `Tally` and the `Voting<T, I>` double map [1](#0-0) , but `remove_member`/`do_remove_member_from_rank` and `demote_member`/`do_demote_member` only manipulate `Members`, `IdToIndex`, `IndexToId`, and `MemberCount` via `remove_from_rank` [2](#0-1) [3](#0-2) [4](#0-3) , never touching `Voting<T, I>` or decrementing the ongoing poll's `Tally`. This leaves a removed/demoted member's vote weight baked into any poll's outcome-determining tally after they lose standing.

## Finding Description
Casting a vote via `vote()` writes `Voting::<T, I>::insert(&poll, &who, &vote)` and mutates `tally.ayes`/`tally.nays`/`tally.bare_ayes` in place through `T::Polls::try_access_poll` [5](#0-4) . `remove_member` calls `T::RemoveOrigin::ensure_origin`, validates rank witnesses, then calls `do_remove_member_from_rank`, which loops `remove_from_rank` for ranks `0..=rank` and removes the `Members` entry — no reference to `Voting` or any poll's `Tally` [6](#0-5) [4](#0-3) . `do_demote_member` behaves identically, only adjusting `Members`/rank bookkeeping [3](#0-2) . The only code path that ever clears `Voting` entries is `cleanup_poll`, which is explicitly gated to polls that have already concluded (`ensure!(T::Polls::as_ongoing(poll_index).is_none(), Error::<T, I>::Ongoing)`), so it cannot correct an ongoing poll's tally [7](#0-6) . By contrast, `pallet-collective::change_members_sorted` explicitly filters outgoing accounts' `ayes`/`nays` out of every open proposal's `Votes`, showing this cleanup is a recognized necessary pattern that ranked-collective omits entirely. The existing regression test `remove_member_cleanup_works` only asserts `IdToIndex`/`IndexToId` correctness and never exercises a scenario where a removed member has an active vote on an ongoing poll.

## Impact Explanation
This is a runtime bug that compromises intended governance behavior in a live-scope pallet used to back privileged OpenGov origins (Fellowship/Ambassador collectives). A poll's pass/fail outcome can be determined by the tallied weight of an account that `Members::<T, I>::get` no longer recognizes as a member, since that weight was never subtracted from `Tally.ayes`/`Tally.nays`. This falls under the accepted impact category "runtime bugs that compromise intended behavior," as the exact corrupted value is the poll's `Tally` (`ayes`/`nays`/`bare_ayes`) which retains a stale, no-longer-authorized voter's weight.

## Likelihood Explanation
No attacker or malicious governance action is required — this is a normal-course-of-operation timing bug. Any member casts a vote via the public `vote()` extrinsic, and subsequently `RemoveOrigin`/`DemoteOrigin` performs an ordinary administrative removal/demotion while that poll remains ongoing; the missing cleanup step guarantees the stale weight persists regardless of intent. The bug is deterministic and 100% reproducible whenever removal/demotion occurs before a voted-on poll concludes.

## Recommendation
In `do_remove_member_from_rank` and `do_demote_member`, before or during the rank/member bookkeeping removal, iterate the member's `Voting<T, I>` entries for ongoing polls (or accept bounded iteration cost similar to `pallet-collective::change_members_sorted`), decrement the corresponding poll's `Tally.ayes`/`Tally.nays`/`Tally.bare_ayes` by the recorded vote weight via `T::Polls::try_access_poll`, and remove the stale `Voting` entry.

## Proof of Concept
1. Add member A at rank ≥1 in a ranked-collective instance; open a poll via `T::Polls`.
2. A calls `Club::vote(poll, true)` — `Voting::<T, I>::insert(&poll, &A, ...)` and `tally.ayes` increases by A's rank-derived weight (per `vote()` at lines 632-676).
3. `RemoveOrigin` calls `Club::remove_member(A, min_rank)` while the poll is still ongoing.
4. Assert `Members::<T, I>::get(A)` is `None` while `Voting::<T, I>::get(poll, A)` still returns A's vote record and the poll's `Tally.ayes` still includes A's weight — no code path corrects it before poll conclusion.

		pub fn vote(
			origin: OriginFor<T>,
			poll: PollIndexOf<T, I>,
			aye: bool,
		) -> DispatchResultWithPostInfo {
			let who = ensure_signed(origin)?;
			let record = Self::ensure_member(&who)?;
			use VoteRecord::*;
			let mut pays = Pays::Yes;

			let (tally, vote) = T::Polls::try_access_poll(
				poll,
				|mut status| -> Result<(TallyOf<T, I>, VoteRecord), DispatchError> {
					match status {
						PollStatus::None | PollStatus::Completed(..) => {
							Err(Error::<T, I>::NotPolling)?
						},
						PollStatus::Ongoing(ref mut tally, class) => {
							match Voting::<T, I>::get(&poll, &who) {
								Some(Aye(votes)) => {
									tally.bare_ayes.saturating_dec();
									tally.ayes.saturating_reduce(votes);
								},
								Some(Nay(votes)) => tally.nays.saturating_reduce(votes),
								None => pays = Pays::No,
							}
							let min_rank = T::MinRankOfClass::convert(class);
							let votes = Self::rank_to_votes(record.rank, min_rank)?;
							let vote = VoteRecord::from((aye, votes));
							match aye {
								true => {
									tally.bare_ayes.saturating_inc();
									tally.ayes.saturating_accrue(votes);
								},
								false => tally.nays.saturating_accrue(votes),
							}
							Voting::<T, I>::insert(&poll, &who, &vote);
							Ok((tally.clone(), vote))
						},
					}
				},
			)?;
			Self::deposit_event(Event::Voted { who, poll, vote, tally });
			Ok(pays.into())
		}

		fn remove_from_rank(who: &T::AccountId, rank: Rank) -> DispatchResult {
			MemberCount::<T, I>::try_mutate(rank, |last_index| {
				last_index.saturating_dec();
				let index = IdToIndex::<T, I>::get(rank, &who).ok_or(Error::<T, I>::Corruption)?;
				if index != *last_index {
					let last = IndexToId::<T, I>::get(rank, *last_index)
						.ok_or(Error::<T, I>::Corruption)?;
					IdToIndex::<T, I>::insert(rank, &last, index);
					IndexToId::<T, I>::insert(rank, index, &last);
				}

				IdToIndex::<T, I>::remove(rank, who);
				IndexToId::<T, I>::remove(rank, last_index);

				Ok(())
			})
		}

		fn do_demote_member(who: T::AccountId, maybe_max_rank: Option<Rank>) -> DispatchResult {
			let mut record = Self::ensure_member(&who)?;
			let rank = record.rank;
			if let Some(max_rank) = maybe_max_rank {
				ensure!(max_rank >= rank, Error::<T, I>::NoPermission);
			}

			Self::remove_from_rank(&who, rank)?;
			let maybe_rank = rank.checked_sub(1);
			match maybe_rank {
				None => {
					Members::<T, I>::remove(&who);
					Self::deposit_event(Event::MemberRemoved { who, rank: 0 });
				},
				Some(rank) => {
					record.rank = rank;
					Members::<T, I>::insert(&who, &record);
					Self::deposit_event(Event::RankChanged { who, rank });
				},
			}
			Ok(())
		}
