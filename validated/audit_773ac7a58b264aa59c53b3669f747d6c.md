The Ibexa RichText issue was a **blocklist** bypass (checking for `javascript:`/`vbscript:` case-sensitively, missing an allowlist). The closest analog in the Go standard library, `isSafeURL` in `html/template/url.go`, already implements the exact fix pattern that the advisory recommends: it uses an **allowlist** (`http`, `https`, `mailto`) rather than a blocklist, and the protocol comparison uses `strings.EqualFold`, making it case-insensitive by design. [1](#0-0) 

This is exercised by `urlFilter` for `href`/`src`-like URL attribute contexts and by `filterSrcsetElement` for `srcset` parsing, both of which reject any URL whose scheme isn't on the allowlist regardless of case. [2](#0-1) [3](#0-2) 

The package's own test suite explicitly covers case-variant and encoded bypass attempts (`javascript:`, `vbscript:`, mixed-case `URL(...)`, CSS-escaped colons) and asserts they are all defanged to `#ZgotmplZ`. [4](#0-3) [5](#0-4) 

Since `html/template`'s design already matches the *patched* Ibexa behavior (allowlist + case-insensitive match) rather than the vulnerable blocklist pattern, there is no reachable analog of CVE-2024-43369 in this codebase to report.

```go
// isSafeURL is true if s is a relative URL or if URL has a protocol in
// (http, https, mailto).
func isSafeURL(s string) bool {
	if protocol, _, ok := strings.Cut(s, ":"); ok && !strings.Contains(protocol, "/") {
		if !strings.EqualFold(protocol, "http") && !strings.EqualFold(protocol, "https") && !strings.EqualFold(protocol, "mailto") {
			return false
		}
	}
	return true
}
```

```go
func filterSrcsetElement(s string, left int, right int, b *strings.Builder) {
	start := left
	for start < right && isHTMLSpace(s[start]) {
		start++
	}
	end := right
	for i := start; i < right; i++ {
		if isHTMLSpace(s[i]) {
			end = i
			break
		}
	}
	if url := s[start:end]; isSafeURL(url) {
		// If image metadata is only spaces or alnums then
		// we don't need to URL normalize it.
		metadataOk := true
		for i := end; i < right; i++ {
			if !isHTMLSpaceOrASCIIAlnum(s[i]) {
				metadataOk = false
				break
			}
		}
		if metadataOk {
			b.WriteString(s[left:start])
			processURLOnto(url, true, b)
			b.WriteString(s[end:right])
			return
		}
	}
	b.WriteString("#")
	b.WriteString(filterFailsafe)
}
```
