### Title
Certificate `Details` fields are unmarshaled into unbounded slices before signature verification, enabling handshake-stage resource-exhaustion DoS - (File: cert/cert_v2.go)

### Summary
`unmarshalDetails` in `cert/cert_v2.go` parses the `networks`, `unsafeNetworks`, and `groups` ASN.1 SEQUENCE fields of a peer certificate into `[]netip.Prefix` / `[]string` slices with unbounded `append` loops, and this parsing runs on the **initiator/responder handshake payload before the certificate's signature is checked against the CA pool**. An attacker who has never obtained a CA-signed certificate can submit a self-crafted certificate blob (up to the only enforced limit, `MaxCertificateSize` = 65536 bytes) packed with tens of thousands of tiny `groups`/network entries, forcing the responder to allocate and iterate over these unbounded slices on every handshake attempt, mirroring the reported `predictions` unbounded-array DoS pattern.

### Finding Description
`unmarshalDetails` reads three repeated ASN.1 fields with no cap on element *count* (only a per-element byte-length cap for networks, and none at all for `groups`): [1](#0-0) 

This function is invoked from `unmarshalCertificateV2`, called by `cert.Recombine`, which reconstructs the peer's raw certificate bytes carried in the handshake payload: [2](#0-1) 

Crucially, in the handshake `Machine`, `cert.Recombine` (which performs the full unbounded unmarshal) executes **before** `m.verifier(rc)`, which is the call that actually checks the certificate's signature against the trusted CA pool: [3](#0-2) 

On the responder side, this path is reachable for *any* first-stage handshake packet, with no certificate authentication having taken place yet — `beginHandshake` builds a fresh `Machine` and calls `machine.ProcessPacket`, which internally calls `validateCert`/`Recombine` on the attacker-supplied payload: [4](#0-3) 

Only after the (already unbounded) parsing has occurred does `certVerifier` invoke `CAPool.VerifyCertificate`, which itself iterates the parsed `Groups()` to build `InvertedGroups`: [5](#0-4) [6](#0-5) 

Because `groups` entries have no minimum-size or count restriction (unlike `name`, which is capped by `MaxNameLength`, and networks, capped by `MaxNetworkLength`), an attacker can pack a 65536-byte certificate with a very large number of near-zero-length group strings, all of which get appended to a slice and later iterated to populate a map — work performed for every spoofed handshake attempt regardless of whether the certificate is ultimately rejected for lacking a valid CA signature.

### Impact Explanation
This allows an unauthenticated remote attacker to force the responder to perform repeated, attacker-amplified allocation and iteration work per handshake attempt at near-zero cost to the attacker (a single UDP packet), before any proof of CA trust is established. Repeated at volume (multiple spoofed source addresses/handshakes), this degrades CPU and memory on the responder, a denial-of-service class impact analogous to the reported unbounded-array iteration DoS.

### Likelihood Explanation
Likelihood is Medium: the attack requires only the ability to send UDP packets to the Nebula listener and craft a valid ASN.1 `Certificate`/`Details` structure (no valid CA signature is needed since verification happens after parsing); the per-packet size is capped at 65536 bytes, and the responder still discards the certificate after failing CA verification, but the parsing/allocation cost is paid before that check on every attempt.

### Recommendation
Enforce upper bounds on the *count* of `networks`, `unsafeNetworks`, and `groups` entries (and a minimum-plausible length or the existing `MaxNetworkLength`-style cap on `groups`) in `unmarshalDetails`, independent of the total `MaxCertificateSize` byte cap, so a maximal-size certificate cannot be crafted purely from a huge number of degenerate small entries. Consider also cheaply checking structural bounds before doing the more expensive per-entry `netip.Prefix`/string appends.

### Proof of Concept
1. Craft a `Details` ASN.1 blob within `MaxCertificateSize` (65536 bytes) containing a `groups` `SEQUENCE` with as many minimal-length UTF8String entries as fit (each entry only needs the ASN.1 tag/length overhead, no minimum content length is enforced).
2. Wrap it as a `Certificate` structure with a bogus signature/public key matching the handshake's ephemeral static key, and send it as the payload of a stage-1 (`msg1`) Nebula handshake packet to a responder that has no prior session with the attacker's index.
3. Observe that `HandshakeManager.beginHandshake` → `machine.ProcessPacket` → `validateCert` → `cert.Recombine` → `unmarshalCertificateV2` → `unmarshalDetails` fully parses and appends every group entry into a slice before `m.verifier(rc)` (CA-pool signature check) is ever invoked, and that `CAPool.VerifyCertificate` further iterates all groups into `InvertedGroups` even though the signature will ultimately fail.
4. Repeat the packet send from many source ports/spoofed addresses to multiply the CPU/memory cost imposed on the responder per handshake attempt.

func unmarshalCertificateV2(b []byte, publicKey []byte, curve Curve) (*certificateV2, error) {
	l := len(b)
	if l == 0 || l > MaxCertificateSize {
		return nil, ErrBadFormat
	}

	input := cryptobyte.String(b)
	// Open the envelope
	if !input.ReadASN1(&input, asn1.SEQUENCE) || input.Empty() {
		return nil, ErrBadFormat
	}

	// Grab the cert details, we need to preserve the tag and length
	var rawDetails cryptobyte.String
	if !input.ReadASN1Element(&rawDetails, TagCertDetails) || rawDetails.Empty() {
		return nil, ErrBadFormat
	}

	//Maybe grab the curve
	var rawCurve byte
	if !readOptionalASN1Byte(&input, &rawCurve, TagCertCurve, byte(curve)) {
		return nil, ErrBadFormat
	}
	curve = Curve(rawCurve)

	// Maybe grab the public key
	var rawPublicKey cryptobyte.String
	if len(publicKey) > 0 {
		// If a public key is passed in, then the handshake certificate must
		// not have a public key present
		if input.PeekASN1Tag(TagCertPublicKey) {
			return nil, ErrCertPubkeyPresent
		}
		rawPublicKey = make(cryptobyte.String, len(publicKey))
		copy(rawPublicKey, publicKey)
	} else if !input.ReadOptionalASN1(&rawPublicKey, nil, TagCertPublicKey) {
		return nil, ErrBadFormat
	}

	if len(rawPublicKey) == 0 {
		return nil, ErrBadFormat
	}

	// Grab the signature
	var rawSignature cryptobyte.String
	if !input.ReadASN1(&rawSignature, TagCertSignature) || rawSignature.Empty() {
		return nil, ErrBadFormat
	}

	// Finally unmarshal the details
	details, err := unmarshalDetails(rawDetails)
	if err != nil {
		return nil, err
	}

	c := &certificateV2{
		details:    details,
		rawDetails: rawDetails,
		curve:      curve,
		publicKey:  rawPublicKey,
		signature:  rawSignature,
	}

	err = c.validate()
	if err != nil {
		return nil, err
	}

	return c, nil
}

func (m *Machine) validateCert(payload Payload) error {
	cred := m.getCred(m.myVersion)
	if cred == nil {
		m.failed = true
		return fmt.Errorf("%w: %v", ErrNoCredential, m.myVersion)
	}
	rc, err := cert.Recombine(
		cert.Version(payload.CertVersion),
		payload.Cert,
		m.hs.PeerStatic(),
		cred.Cert.Curve(),
	)
	if err != nil {
		m.failed = true
		return fmt.Errorf("recombine cert: %w", err)
	}

	if !bytes.Equal(rc.PublicKey(), m.hs.PeerStatic()) {
		m.failed = true
		return ErrPublicKeyMismatch
	}

	// Version negotiation, if the peer sent a different version and we have it, switch
	if rc.Version() != m.myVersion {
		if m.getCred(rc.Version()) != nil {
			m.myVersion = rc.Version()
		}
	}

	verified, err := m.verifier(rc)
	if err != nil {
		m.failed = true
		return fmt.Errorf("verify cert: %w", err)
	}

	m.result.RemoteCert = verified
	m.remoteCertSet = true
	return nil

func (hm *HandshakeManager) beginHandshake(via ViaSender, packet []byte, h *header.H) {
	f := hm.f
	cs := f.pki.getCertState()

	v := cs.DefaultVersion()
	if cs.GetCredential(v) == nil {
		f.l.Error("Unable to handshake with host because no certificate is available",
			"from", via, "certVersion", v)
		return
	}

	machine, err := handshake.NewMachine(
		v, cs.GetCredential,
		hm.certVerifier(), func() (uint32, error) { return generateIndex(f.l) },
		false, header.HandshakeIXPSK0,
	)
	if err != nil {
		f.l.Error("Failed to create handshake machine", "from", via, "error", err)
		return
	}

	response, result, err := machine.ProcessPacket(nil, packet)
	if err != nil {
		f.l.Error("Failed to process handshake packet", "from", via, "error", err)
		return
	}

func (hm *HandshakeManager) certVerifier() handshake.CertVerifier {
	return func(c cert.Certificate) (*cert.CachedCertificate, error) {
		return hm.f.pki.GetCAPool().VerifyCertificate(time.Now(), c)
	}
