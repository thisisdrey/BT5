### Title
`Pool.liquidate` lacks slippage and deadline protection, allowing oracle price movement to make liquidations unprofitable for the caller - (File: contracts/Pool.sol)

### Summary
`Pool.liquidate` lets any caller repay `amountToRepay_` of a synthetic-token debt and seize `depositToken_` collateral priced entirely at execution time via `masterOracle().quote`. The function accepts no `minAmountToSeize`/`maxAmountToRepay` bound and no deadline, so mempool delay or same-block price movement between quote and execution can make the liquidator burn more synth value than the collateral received.

### Finding Description
`liquidate` is a public, unprivileged entry point callable by any EOA (or through `Operator.execute`, since it uses `SynthContext._msgSender`). Its only bounds checks are: the position must be unhealthy (`debtPositionOf`), `amountToRepay_` must be ≤ `maxLiquidable` fraction of the victim's debt balance, the remaining debt must clear `debtFloorInUsd`, and `_totalSeized` must not exceed the victim's deposit balance. The amount seized is computed inside the transaction by `quoteLiquidateOut`, which calls `masterOracle().quote(syntheticToken_, depositToken_.underlying(), amountToRepay_)` and then adds `liquidatorIncentive` and `protocolFee` from `feeProvider.liquidationFees()`. [1](#0-0) [2](#0-1) 

Because the caller supplies a fixed `amountToRepay_` that is burned unconditionally (`syntheticToken_.burn(_msgSender, amountToRepay_)`) while the seized collateral is whatever the oracle returns at execution, an adverse price move — synth appreciating, collateral depreciating, or incentive parameters differing from the caller's off-chain quote — shrinks `_toLiquidator` with no way for the caller to bound it. If collateral price falls or synth price rises such that `quote(incentive-adjusted) < amountToRepay_` value, the liquidator executes at a loss. A liquidator operating through a public mempool has no recourse: there is no deadline to expire a stale transaction and no minimum-received parameter to revert on slippage. Note `CanNotLiquidateOwnPosition` prevents self-liquidation, and `nonReentrant`/`whenNotShutdown` do not address pricing staleness, so nothing in the deployed configuration mitigates this.

### Impact Explanation
Liquidators are economically incentivized actors; a liquidation that executes at a negative margin is a direct loss of the liquidator's funds (the synth burned exceeds collateral value seized, while the protocol still collects `_fee` and the victim's debt is still reduced). In volatile conditions or congested mempools — precisely when liquidations are most needed — callers either lose funds or are forced to over-price gas to race inclusion. This mirrors the DODO finding: identical missing-control bug class on an equivalent liquidation function.

### Likelihood Explanation
Requires no attacker privilege: any liquidator (unprivileged caller) is exposed whenever oracle prices move between simulation/submission and execution, or when a keeper/guardian updates `liquidationFees` or `maxLiquidable`-adjacent state in the same block. Same-transaction oracle movement via AMM trades is permitted per scope. Likelihood is moderate — it needs adverse price drift within the inclusion window, which is common during the volatility that creates liquidation opportunities.

### Recommendation
Add caller-controlled protection to `liquidate`, e.g. a `minAmountToSeize_` (or `minToLiquidator_`) parameter enforced after `quoteLiquidateOut` with `revert` if `_totalSeized`/ `_toLiquidator` falls below it, plus an optional `deadline_` check against `block.timestamp`. The same bounds should apply to any liquidation wrapper (e.g. via `Operator.execute`).

    function quoteLiquidateOut(
        ISyntheticToken syntheticToken_,
        uint256 amountToRepay_,
        IDepositToken depositToken_
    ) public view override returns (uint256 _totalToSeize, uint256 _toLiquidator, uint256 _fee) {
        _toLiquidator = masterOracle().quote(
            address(syntheticToken_),
            address(depositToken_.underlying()),
            amountToRepay_
        );

        (uint128 _liquidatorIncentive, uint128 _protocolFee) = feeProvider.liquidationFees();

        if (_protocolFee > 0) {
            _fee = _toLiquidator.wadMul(_protocolFee);
        }
        if (_liquidatorIncentive > 0) {
            _toLiquidator += _toLiquidator.wadMul(_liquidatorIncentive);
        }

        _totalToSeize = _fee + _toLiquidator;
    }

```text
    function liquidate(
        ISyntheticToken syntheticToken_,
        address account_,
        uint256 amountToRepay_,
        IDepositToken depositToken_
    )
        external
        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticToken_)
        onlyIfDepositTokenExists(depositToken_)
        returns (uint256 _totalSeized, uint256 _toLiquidator, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (amountToRepay_ == 0) revert AmountIsZero();
        if (_msgSender == account_) revert CanNotLiquidateOwnPosition();

        IDebtToken _debtToken = debtTokenOf[syntheticToken_];
        _debtToken.accrueInterest();

        (bool _isHealthy, , , , ) = debtPositionOf(account_);

        if (_isHealthy) {
            revert PositionIsHealthy();
        }

        uint256 _debtTokenBalance = _debtToken.balanceOf(account_);

        if (amountToRepay_.wadDiv(_debtTokenBalance) > maxLiquidable) {
            revert AmountGreaterThanMaxLiquidable();
        }

        if (debtFloorInUsd > 0) {
            uint256 _newDebtInUsd = masterOracle().quoteTokenToUsd(
                address(syntheticToken_),
                _debtTokenBalance - amountToRepay_
            );
            if (_newDebtInUsd > 0 && _newDebtInUsd < debtFloorInUsd) {
                revert RemainingDebtIsLowerThanTheFloor();
            }
        }

        (_totalSeized, _toLiquidator, _fee) = quoteLiquidateOut(syntheticToken_, amountToRepay_, depositToken_);

        if (_totalSeized > depositToken_.balanceOf(account_)) {
            revert AmountIsTooHigh();
        }

        syntheticToken_.burn(_msgSender, amountToRepay_);
        _debtToken.burn(account_, amountToRepay_);
        depositToken_.seize(account_, _msgSender, _toLiquidator);

        if (_fee > 0) {
            depositToken_.seize(account_, _poolRegistry.feeCollector(), _fee);
        }

        emit PositionLiquidated(_msgSender, account_, syntheticToken_, amountToRepay_, _totalSeized, _fee);
    }
```
