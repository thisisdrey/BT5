### Title
Vested-but-Locked APT Swept to Admin Withdrawal Address on `terminate_vesting_contract` + `admin_withdraw` — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

When `vest()` is called, vested tokens are moved from the stake pool's `active` bucket into `pending_inactive` (staking lockup not yet expired). If the admin then calls `terminate_vesting_contract()` before the lockup expires, the function only reads and unlocks the `active` stake — it does not account for the already-vested `pending_inactive` tokens that belong to shareholders. After the lockup expires, `admin_withdraw()` sweeps the entire inactive balance (which now includes both the remaining grant **and** the previously vested shareholder tokens) to the admin's `withdrawal_address`, permanently depriving shareholders of APT they had already earned.

---

### Finding Description

**Step 1 — `vest()` moves vested tokens to `pending_inactive`**

`vest()` calls `unlock_stake()` → `staking_contract::unlock_stake()` → `stake::unlock_with_cap()`, which extracts `vested_amount` from `active` and merges it into `pending_inactive`: [1](#0-0) [2](#0-1) 

These tokens are now in `pending_inactive` and belong to shareholders, but they cannot be distributed until the staking lockup expires.

**Step 2 — `terminate_vesting_contract()` ignores `pending_inactive`**

`terminate_vesting_contract()` first calls `distribute()`, which calls `withdraw_stake()` → `staking_contract::distribute_internal()`. `distribute_internal` attempts to withdraw `inactive + pending_inactive`, but `stake::withdraw_with_cap` only withdraws from `inactive` when the lockup has not yet expired: [3](#0-2) [4](#0-3) 

So if the lockup has not expired, the vested `pending_inactive` tokens are **not** distributed to shareholders. Then `terminate_vesting_contract` reads only `active_stake` from `stake::get_stake()`, ignoring the 4th return value (`pending_inactive`): [5](#0-4) 

It then calls `unlock_stake(vesting_contract, active_stake)`, moving the remaining active grant into `pending_inactive`. At this point `pending_inactive` contains **both** the previously vested shareholder tokens **and** the remaining unvested grant.

**Step 3 — `admin_withdraw()` sweeps everything**

After the lockup expires, `admin_withdraw()` calls `withdraw_stake()` → `staking_contract::distribute_internal()`. Now the lockup has expired, so `stake::withdraw_with_cap` moves all `pending_inactive` into `inactive` and withdraws it all. The entire balance — including the previously vested shareholder tokens — is deposited into `vesting_contract.withdrawal_address`: [6](#0-5) 

---

### Impact Explanation

Shareholders permanently lose APT that was already vested (i.e., already earned and deducted from `remaining_grant`). The admin's `withdrawal_address` receives tokens it is not entitled to. This is a direct theft of vesting balances — an in-scope impact category. The magnitude equals the sum of all `vest()` calls whose `pending_inactive` tokens had not yet cleared the staking lockup at the time of termination.

---

### Likelihood Explanation

This is triggered by the ordinary, designed admin flow: `vest()` is called (by anyone, it is a public entry), then the admin terminates before the current staking lockup cycle expires. Staking lockup periods are typically 30 days or more, so there is a large window during which termination causes this loss. No malicious intent is required — a well-intentioned admin following the documented termination procedure triggers the bug.

---

### Recommendation

Before unlocking the remaining active stake in `terminate_vesting_contract`, the function should also distribute the current `pending_inactive` balance to shareholders (or at minimum track it so `admin_withdraw` excludes it). Concretely, after the `distribute()` call, read the `pending_inactive` value from `stake::get_stake()` and record it as shareholder-owned funds that must not be swept by `admin_withdraw`:

```move
let (active_stake, _, pending_active_stake, pending_inactive_stake) =
    stake::get_stake(vesting_contract.staking.pool_address);
// pending_inactive_stake belongs to shareholders; do not include in admin recovery
```

Alternatively, `admin_withdraw` should only withdraw `remaining_grant`-proportional funds, not the entire inactive balance.

---

### Proof of Concept

```
State before termination (lockup NOT expired):
  stake pool: active = 900 APT (remaining grant), pending_inactive = 100 APT (vested, belongs to shareholders)

1. Anyone calls vest(contract_address)
   → 100 APT moves: active(1000) → pending_inactive(100), remaining_grant = 900

2. Admin calls terminate_vesting_contract(admin, contract_address)
   → distribute() called: lockup not expired → 0 APT distributed to shareholders
   → active_stake = 900 (pending_inactive ignored)
   → unlock_stake(900): active(0) → pending_inactive(1000)  [900 + 100]
   → remaining_grant = 0

3. Lockup expires (epoch transition)
   → pending_inactive(1000) → inactive(1000)

4. Admin calls admin_withdraw(admin, contract_address)
   → withdraw_stake() withdraws all 1000 APT
   → 1000 APT sent to withdrawal_address

Result: shareholders receive 0 APT; withdrawal_address receives 1000 APT (including the 100 APT vested tokens)
Expected: shareholders receive 100 APT; withdrawal_address receives 900 APT
``` [7](#0-6) [8](#0-7) [9](#0-8)

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

        emit(
            Terminate {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
            },
        );
    }

    public entry fun admin_withdraw(admin: &signer, contract_address: address) acquires VestingContract {
        let vesting_contract = borrow_global<VestingContract>(contract_address);
        assert!(
            vesting_contract.state == VESTING_POOL_TERMINATED,
            error::invalid_state(EVESTING_CONTRACT_STILL_ACTIVE)
        );

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let amount = coin::value(&coins);
        if (amount == 0) {
            coin::destroy_zero(coins);
            return
        };
        aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);

        emit(
            AdminWithdraw {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount,
            },
        );
    }
