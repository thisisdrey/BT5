The reported CVE (ALPINE-CVE-2022-3204) concerns `unbound`'s iterative/recursive DNS resolution architecture, where a malicious delegation with many non-responsive nameservers causes the resolver to repeatedly attempt resolving records under that delegation point, consuming resources through iterative delegation-chasing logic.

Go's standard library `net` package DNS client is a **stub resolver**, not an iterative/recursive resolver — it does not walk delegation chains or discover/query nameservers on its own. It only sends queries to the small, statically configured set of servers from `/etc/resolv.conf` (parsed by `dnsReadConfig` in [1](#0-0) ) and relies on those configured servers being "recursive resolvers" that return complete answers, as documented in [2](#0-1) .

The retry loop in `Resolver.tryOneName` is bounded strictly by `cfg.attempts * len(cfg.servers)`, both of which come from trusted local configuration, not from attacker-supplied DNS response content: [3](#0-2) . There is no code path where a malicious DNS response (e.g., NS referral records) causes the Go resolver to recursively chase additional delegated nameservers or retry indefinitely — unlike unbound, which performs actual delegation/referral processing that the NRDelegation attack exploits.

The closest related logic, `TestIgnoreLameReferrals`, shows Go's resolver behavior on lame referrals: it simply moves to the next configured server rather than following/chasing NS delegation chains, confirming the stub-resolver model: [4](#0-3) .

Since the vulnerable primitive (iterative delegation resolution with attacker-controlled NS record fan-out causing unbounded resolver work) does not exist in Go's stub DNS client, there is no valid analog in this repository.

func (r *Resolver) tryOneName(ctx context.Context, cfg *dnsConfig, name string, qtype dnsmessage.Type) (dnsmessage.Parser, string, error) {
	var lastErr error
	serverOffset := cfg.serverOffset()
	sLen := uint32(len(cfg.servers))

	n, err := dnsmessage.NewName(name)
	if err != nil {
		return dnsmessage.Parser{}, "", &DNSError{Err: errCannotMarshalDNSMessage.Error(), Name: name}
	}
	q := dnsmessage.Question{
		Name:  n,
		Type:  qtype,
		Class: dnsmessage.ClassINET,
	}

	for i := 0; i < cfg.attempts; i++ {
		for j := uint32(0); j < sLen; j++ {
			server := cfg.servers[(serverOffset+j)%sLen]

			p, h, err := r.exchange(ctx, server, q, cfg.timeout, cfg.useTCP, cfg.trustAD)
			if err != nil {
				dnsErr := newDNSError(err, name, server)
				// Set IsTemporary for socket-level errors. Note that this flag
				// may also be used to indicate a SERVFAIL response.
				if _, ok := err.(*OpError); ok {
					dnsErr.IsTemporary = true
				}
				lastErr = dnsErr
				continue
			}

			if err := checkHeader(&p, h); err != nil {
				if err == errNoSuchHost {
					// The name does not exist, so trying
					// another server won't help.
					return p, server, newDNSError(errNoSuchHost, name, server)
				}
				lastErr = newDNSError(err, name, server)
				continue
			}

			if err := skipToAnswer(&p, qtype); err != nil {
				if err == errNoSuchHost {
					// The name does not exist, so trying
					// another server won't help.
					return p, server, newDNSError(errNoSuchHost, name, server)
				}
				lastErr = newDNSError(err, name, server)
				continue
			}

			return p, server, nil
		}
	}
	return dnsmessage.Parser{}, "", lastErr
}
