### Title
Attacker who spoofs a replayed ciphertext's UDP source can hijack `HostInfo` roaming state via `handleHostRoaming` - ([File: outside.go])

### Summary
`Interface.handleHostRoaming` trusts the outer, unauthenticated UDP source address (`via.UdpAddr`) of *any* packet that passes AEAD decryption as the basis for updating `HostInfo.remote`. Because AEAD authentication only binds to the header bytes used as AAD (`packet[:header.Len]`) and the per-message counter — not to the UDP source IP/port — a captured, still-valid ciphertext from a legitimate peer can be replayed by an attacker from a spoofed source and, if it wins the race against the real packet for the same message counter, will cause `SetRemote` to point the tunnel at the attacker-chosen address.

### Finding Description
In `readOutsidePackets` (outside.go:126-136), a packet is decrypted with `hostinfo.ConnectionState.Decrypt(f.l, h.MessageCounter, out, packet, nb)` [1](#0-0)  and, on success, `f.handleHostRoaming(hostinfo, via)` is called using the `via` value derived purely from the UDP packet's source address as read off the socket, with no cryptographic binding to that address [2](#0-1) .

`handleHostRoaming` then compares `via.UdpAddr` to the current remote and, if different (and allow-listed / not roam-suppressed), calls `hostinfo.SetRemote(via.UdpAddr)` [3](#0-2) .

`ConnectionState.Decrypt` only verifies the AEAD tag and enforces the anti-replay window (`Bits.Check`/`Bits.Update`) keyed on the message counter; it never touches or authenticates the UDP source address [4](#0-3) . The replay window (`bits.go`) is a first-come-first-served consumer of a given counter value: whichever copy of a given counter arrives first and passes `Check`/`Update` "wins", and any subsequent delivery of the same counter is rejected as a duplicate [5](#0-4) [6](#0-5) .

Exploit flow:
1. Attacker passively observes one ciphertext UDP datagram sent by a legitimate peer to the victim (e.g., on a shared/untrusted network segment) before it's consumed.
2. Attacker immediately retransmits the identical ciphertext to the victim with a spoofed UDP source address, racing the real packet.
3. If the spoofed copy arrives first, `Decrypt` succeeds (valid AEAD tag, counter unconsumed) exactly as it would for the genuine copy, because the AEAD/AAD binds only to header bytes and counter, not the transport source.
4. `handleHostRoaming` sees `curRemote != via.UdpAddr` and, absent an allow-list block or suppression window hit, calls `SetRemote(attackerAddr)`.
5. The genuine, later-arriving copy of the same counter is now rejected by the replay window as a duplicate (`ErrAlreadySeen`), so it produces no compensating roam.
6. Worse, once the spoofed roam occurs, `hostinfo.lastRoamRemote` is set to the *real* previous address; if the legitimate peer's next genuine packet arrives from that same real address within `RoamingSuppressSeconds`, the roam-suppression check (`via.UdpAddr == hostinfo.lastRoamRemote && time.Since(...) < RoamingSuppressSeconds`) actively suppresses reverting to the legitimate address, prolonging the hijack [7](#0-6) .

None of the existing checks (subtype validation, hostinfo/index lookup, AEAD decrypt, replay window, remote allow-list) authenticate that the UDP source address matches the entity that actually possesses the session keys — they only prove the ciphertext content is authentic, not its transport origin.

### Impact Explanation
This allows an unprivileged network observer/spoofer to poison `HostInfo.remote` and steer subsequent outbound traffic for that tunnel toward an attacker-controlled address (traffic hijacking / interception opportunity), and to potentially wedge legitimate roaming for the `RoamingSuppressSeconds` window, degrading availability of the real path. This matches the reported "remote state poisoning / traffic hijack" impact category — it does not break AEAD confidentiality/integrity or CA/cert verification, but it does violate the intended invariant that only traffic verifiably originating from the peer's real network path can move the tunnel's remote endpoint.

### Likelihood Explanation
Exploitability requires the attacker to (a) capture one legitimate ciphertext (passive observation on a shared medium, or by being positioned on-path/off-path with visibility into the flow) and (b) win a race to deliver a spoofed-source duplicate before the genuine packet arrives — a timing-dependent, probabilistic condition, not a deterministic bypass. It does not require breaking any cryptography, only IP spoofing (trivial on UDP) and a favorable network race. This is a real, but conditional/opportunistic, weakness rather than a reliably reproducible one; success rate depends on network conditions and attacker positioning relative to victim and legitimate peer.

### Recommendation
Do not treat a bare successful AEAD decrypt as sufficient authorization to update `HostInfo.remote`. Options: require multiple consecutive/consistent packets from a new address before roaming (debounce), rate-limit/require confirmation (e.g., a round-trip test/handshake confirmation from the new address) before committing `SetRemote`, or bind roaming decisions to strictly monotonic counters only (reject roaming triggered by a counter that is not the new "highest ever seen", since an attacker replaying an already-in-flight packet is likely to be racing rather than genuinely relocated), and shorten/reconsider the `RoamingSuppressSeconds` suppression logic so a spoofed roam cannot block legitimate reversion.

### Proof of Concept
Integration test using `router.R` (as hinted in the question):
1. Establish two real Nebula hosts A and B with an active tunnel; capture one valid `header.Message`/`header.Test` ciphertext datagram sent from A to B off the wire (same bytes, same `MessageCounter`).
2. Before delivering the real packet to B's `readOutsidePackets`, inject a duplicate of the captured bytes into B's UDP receive path with a spoofed source `netip.AddrPort` (attacker-chosen), racing it ahead of the real one.
3. Assert that after the spoofed packet is processed, `hostinfo.GetRemote()` on B equals the attacker-chosen address (violating the invariant) and that the subsequent legitimate packet from A is dropped as `ErrAlreadySeen` by `ConnectionState.Decrypt`.
4. A companion invariant/property test: for `handleHostRoaming`, assert that `SetRemote` is only invoked with a `via.UdpAddr` that corresponds to the address that actually delivered the message counter that flipped `Bits` from unconsumed to consumed (currently unenforced, since `via.UdpAddr` is trusted independent of any binding to the AEAD-verified counter's true origin).

func (f *Interface) handleHostRoaming(hostinfo *HostInfo, via ViaSender) {
	curRemote := hostinfo.GetRemote()
	if !via.IsRelayed && curRemote != via.UdpAddr {
		if !f.lightHouse.GetRemoteAllowList().AllowAll(hostinfo.vpnAddrs, via.UdpAddr.Addr()) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("lighthouse.remote_allow_list denied roaming", "newAddr", via.UdpAddr)
			}
			return
		}

		if !hostinfo.lastRoam.IsZero() && via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < RoamingSuppressSeconds*time.Second {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("Suppressing roam back to previous remote",
					"suppressSeconds", RoamingSuppressSeconds,
					"udpAddr", curRemote,
					"newAddr", via.UdpAddr,
				)
			}
			return
		}

		hostinfo.logger(f.l).Info("Host roamed to new udp ip/port.",
			"udpAddr", curRemote,
			"newAddr", via.UdpAddr,
		)
		hostinfo.lastRoam = time.Now()
		hostinfo.lastRoamRemote = curRemote
		hostinfo.SetRemote(via.UdpAddr)
	}

func (cs *ConnectionState) Decrypt(l *slog.Logger, messageCounter uint64, out []byte, packet []byte, nb []byte) ([]byte, error) {
	var err error
	cs.decryptLock.Lock()
	result := cs.window.Check(l, messageCounter)
	cs.decryptLock.Unlock()
	if !result {
		return nil, ErrAlreadySeen
	}

	out, err = cs.dKey.DecryptDanger(out, packet[:header.Len], packet[header.Len:], messageCounter, nb)
	if err != nil {
		return nil, err
	}

	cs.decryptLock.Lock()
	result = cs.window.Update(l, messageCounter)
	cs.decryptLock.Unlock()
	if !result {
		return nil, ErrAlreadySeen
	}
	return out, nil
}

func (b *Bits) Check(l *slog.Logger, i uint64) bool {
	// If i is the next number, return true.
	if i > b.current {
		return true
	}

	if b.strictlyWithinWindow(i) {
		return !b.get(i)
	}

	// Not within the window
	if l.Enabled(context.Background(), slog.LevelDebug) {
		l.Debug("rejected a packet (top)", "current", b.current, "incoming", i)
	}
	return false
}
