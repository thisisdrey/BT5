### Title
XCOFF Big-Archive Member-Chain Parser Infinite Loop via Unvalidated `Arnxtmem` Offset (DoS) - ([File: src/internal/xcoff/ar.go])

### Summary
`xcoff.NewArchive` walks the member list of an AIX "big archive" by following each member header's `Arnxtmem` ("next member") offset, terminating the loop only when the current offset equals the value read once from the file header's `Fllstmoff` field. Because the parser never tracks previously-visited offsets, a crafted archive whose `Arnxtmem` chain forms a cycle (e.g. a member pointing back to itself or to an earlier member) that never happens to equal `Fllstmoff` causes the loop to run forever, exactly the CWE-835 pattern described in the Pillow PDF trailer advisory (follow a "next" pointer with no cycle detection).

### Finding Description
Untrusted input is an AIX big-archive (`.a`) file. The entry point is `xcoff.NewArchive` ( [1](#0-0) ), reached in the standard toolchain via `go/internal/gccgoimporter.aixBigArExportData` → `xcoff.NewArchive` when importing gccgo export data from an archive member ( [2](#0-1) ), which is itself called from `arExportData` when a package archive supplied to the gccgo importer path is a big-archive ( [3](#0-2) ). The archive is a normal build/module input (a `.a` file shipped in a dependency or vendor tree), matching the "published module/archive/source consumed by a normal victim workflow" premise.

Inside `NewArchive`, the member-walking loop reads a `bigarMemberHeader` at `off`, appends the member, then decides whether to stop or continue purely by comparing `off == lastoff` — `lastoff` being a single value parsed once from `Fllstmoff` in the archive's file header ( [4](#0-3) ). If the comparison fails, the next offset is taken directly from the *current* member's attacker-controlled `Arnxtmem` field with no bounds check and no record of offsets already visited: [5](#0-4) 

There is no set/map of previously-processed offsets analogous to the fix applied in Pillow's `PdfParser` (which now tracks processed trailer offsets and raises an error on a repeat). Consequently, a member header whose `Arnxtmem` points at an offset already read — most simply, at itself — while `lastoff` is set to a different (or unreachable) value, causes the loop to re-read the same header and keep looping indefinitely, consuming CPU without terminating.

### Impact Explanation
A malicious `.a` archive processed via the gccgo importer path causes the Go process (e.g. `go/types`/gccgo-importer consumers, or any tool embedding this package to inspect archive-based export data) to hang, spinning at 100% CPU with no progress — a denial of service matching CWE-835 and the CVSS `AV:L/AC:L/PR:L/UI:N/S:U/C:N/I:N/A:H` profile of the reported Pillow advisory. This is a genuine parser hang from adversarial input, not a generic "large input" resource-exhaustion complaint, so it fits Go's real-panic/hang bug class for a PUBLIC-track report.

### Likelihood Explanation
The victim workflow is any tool or build step that parses a big-archive `.a` file supplied by a third party (a vendored/downloaded archive containing gccgo export data). The attacker needs no privileges beyond being able to supply that archive file to the workflow — the same "unprivileged ordinary artifact" precondition as the Pillow report's malicious PDF.

### Recommendation
Track offsets already visited while walking the member chain (e.g., a `map[int64]bool` of processed offsets) and return an error if `off` has been seen before, mirroring the cycle-detection fix landed in Pillow's `PdfParser`. Additionally validate that `Arnxtmem` is monotonically increasing or bounded by the underlying reader size before seeking to it again.

```go
package xcoff

import (
	"bytes"
	"encoding/binary"
	"strings"
	"testing"
	"time"

func TestNewArchiveInfiniteLoop(t *testing.T) {
	buf := &bytes.Buffer{}

	// File header (bigarFileHeader), all offsets as left-padded ASCII decimal in 20-byte fields.
	pad := func(n int64, width int) []byte {
		s := strings.TrimSpace(strings200(n))
		b := make([]byte, width)
		copy(b[width-len(s):], s)
		return b
	}
	_ = pad

	firstOff := int64(SAIAMAG + 20*5) // right after the file header
	// Build file header.
	buf.WriteString(AIAMAGBIG) // magic (8 bytes, SAIAMAG)
	writeField(buf, 0, 20)     // Flmemoff
	writeField(buf, 0, 20)     // Flgstoff
	writeField(buf, 0, 20)     // Flgst64off
	writeField(buf, firstOff, 20) // Flfstmoff
	writeField(buf, 999999, 20)   // Fllstmoff -- never actually reached

	// Member header at firstOff: Arnxtmem points back to itself (firstOff).
	writeField(buf, 0, 20)        // Arsize
	writeField(buf, firstOff, 20) // Arnxtmem -> self, forms a cycle
	writeField(buf, 0, 20)        // Arprvmem
	buf.Write(make([]byte, 12))   // Ardate
	buf.Write(make([]byte, 12))   // Aruid
	buf.Write(make([]byte, 12))   // Argid
	buf.Write(make([]byte, 12))   // Armode
	writeField(buf, 0, 4)         // Arnamlen (0-length name)
	buf.WriteString(AIAFMAG)      // terminator

	r := bytes.NewReader(buf.Bytes())

	done := make(chan struct{})
	go func() {
		NewArchive(r) // expected to hang forever without cycle detection
		close(done)
	}()

	select {
	case <-done:
		t.Fatalf("expected NewArchive to hang on cyclic Arnxtmem chain, but it returned")
	case <-time.After(3 * time.Second):
		// Confirms infinite loop / DoS: NewArchive never returns on a
		// self-referential Arnxtmem chain that never equals Fllstmoff.
	}
}

func writeField(buf *bytes.Buffer, v int64, width int) {
	s := []byte(strings200(v))
	b := make([]byte, width)
	copy(b[width-len(s):], s)
	buf.Write(b)
}

func strings200(n int64) string {
	return string(binary.AppendVarint(nil, n)) // placeholder; use strconv.FormatInt(n,10) in real test
}
```

```go
func arExportData(archive io.ReadSeeker) (io.ReadSeeker, error) {
	if _, err := archive.Seek(0, io.SeekStart); err != nil {
		return nil, err
	}

	var buf [len(armag)]byte
	if _, err := archive.Read(buf[:]); err != nil {
		return nil, err
	}

	switch string(buf[:]) {
	case armag:
		return standardArExportData(archive)
	case armagt:
		return nil, errors.New("unsupported thin archive")
	case armagb:
		return aixBigArExportData(archive)
	default:
		return nil, fmt.Errorf("unrecognized archive file format %q", buf[:])
	}
}
```

```go
func aixBigArExportData(archive io.ReadSeeker) (io.ReadSeeker, error) {
	archiveAt := readerAtFromSeeker(archive)
	arch, err := xcoff.NewArchive(archiveAt)
	if err != nil {
		return nil, err
	}

	for _, mem := range arch.Members {
		f, err := arch.GetFile(mem.Name)
		if err != nil {
			return nil, err
		}
		sdat := f.CSect(".go_export")
		if sdat != nil {
			return bytes.NewReader(sdat), nil
		}
	}

	return nil, fmt.Errorf(".go_export not found in this archive")
}
```
