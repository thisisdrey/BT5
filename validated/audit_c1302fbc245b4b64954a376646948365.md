### Title
Unauthenticated remote DoS via `POST /shutdown` in `SignerEventReceiver::next_event` - (File: libsigner/src/events.rs)

### Summary
The signer's HTTP event-receiver treats any inbound `POST /shutdown` request as an authoritative termination signal, with no authentication, shared secret, or loopback restriction. Any TCP client that can reach the bound event-receiver address can permanently stop the signer's event ingestion loop with a single crafted HTTP request.

### Finding Description
`SignerEventReceiver::next_event` dispatches on `request.url()` inside `with_server`, and for `"/shutdown"` it unconditionally does `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` [1](#0-0) . This is the exact same mechanism `SignerStopSignaler::send` uses to make the signer self-terminate: it stores `true` into the shared `Arc<AtomicBool>` and wakes the blocked `http_server.recv()` by connecting and sending a literal `POST /shutdown HTTP/1.1 ...` request [2](#0-1) . Critically, the HTTP handler path has no way to distinguish a self-issued shutdown from a shutdown sent by an arbitrary remote peer — there is no signature, token, or source-address check anywhere in `next_event`, only a URL string match. Once `stop_signal` is set, `is_stopped()` returns `true` [3](#0-2) , and `EventReceiver::main_loop` breaks out of its loop on `Err(EventError::Terminated)` [4](#0-3) , permanently ending the signer's event ingestion (block proposals, StackerDB chunks, burn/new-block notifications) until the process is restarted. `SignerEventReceiver::bind` opens the `tiny_http::Server` on whatever `SocketAddr` is configured, with no loopback enforcement in this code [5](#0-4) , so if that address is reachable by the attacker (e.g., not firewalled to localhost), the request will be accepted directly from the network.

### Impact Explanation
An unauthenticated attacker who can open a TCP connection to the signer's event-receiver `SocketAddr` can permanently kill the signer's event loop with a single `POST /shutdown` message, halting the signer's participation (block validation responses, StackerDB message ingestion) until manual restart. This matches "Critical - remote crash/unauthenticated DoS from few messages."

### Likelihood Explanation
The only precondition is TCP reachability to the bound event-receiver socket; no secret, peer identity, or StackerDB slot is required. The attack is a single, deterministic, repeatable HTTP request with no retries or timing needed.

### Recommendation
Restrict the `/shutdown` endpoint so it can only be triggered by the local process (e.g., bind the event-receiver listener to loopback only and reject non-loopback source addresses for `/shutdown`, or require a locally-generated shared secret/token known only to `SignerStopSignaler` that is validated on the `/shutdown` request body/headers before setting `stop_signal`).

### Proof of Concept
```rust
// libsigner/src/events.rs (test module) or a new integration test
#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Attacker (no auth) opens a plain TCP connection and sends /shutdown
    let mut stream = TcpStream::connect(bound).unwrap();
    let body = "attacker payload";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
        bound, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());
}
```
This demonstrates that a raw, unauthenticated TCP client can terminate the signer's event ingestion loop, confirming the missing authorization check on the `/shutdown` path in `next_event`.

                    info!("Caught termination signal");

                }
            };

            }
