### Title
Push-Payment DoS via `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS` Abort in `staking_contract::distribute_internal` and `vesting::distribute` — (File: `aptos-move/framework/aptos-framework/sources/staking_contract.move`, `aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

Both `staking_contract::distribute_internal` and `vesting::distribute` use a push-payment loop that calls `aptos_account::deposit_coins` for every recipient. If any recipient address has not registered for `AptosCoin` **and** has set `allow_arbitrary_coin_transfers = false`, `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS`, reverting the entire transaction atomically. In the staking contract, the operator can unilaterally set their commission beneficiary to such an address via `set_beneficiary_for_operator`, permanently blocking the staker from ever withdrawing their stake — including through `switch_operator`, which also calls `distribute_internal` internally.

---

### Finding Description

**Root cause — `aptos_account::deposit_coins` can abort on push:** [1](#0-0) 

```move
public fun deposit_coins<CoinType>(to: address, coins: Coin<CoinType>) acquires DirectTransferConfig {
    if (!account::exists_at(to)) { create_account(to); };
    if (!coin::is_account_registered<CoinType>(to)) {
        assert!(
            can_receive_direct_coin_transfers(to),
            error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
        );
        coin::register<CoinType>(&create_signer(to));
    };
    coin::deposit<CoinType>(to, coins)
}
```

If `to` has an account but has **not** registered a `CoinStore<AptosCoin>`, and has called `set_allow_direct_coin_transfers(false)`, the `assert!` fires and aborts the entire transaction.

---

### Impact Explanation

**Staking contract path (highest severity):**

1. Operator calls `set_beneficiary_for_operator(operator_signer, malicious_addr)`.
2. `malicious_addr` calls `set_allow_direct_coin_transfers(false)` and never registers for `AptosCoin`.
3. Every call to `distribute(staker, operator)` aborts at the operator's `deposit_coins`, reverting atomically — the staker's share is also reverted.
4. `switch_operator` internally calls `distribute_internal` first, so it also aborts — the staker cannot escape to a new operator.
5. The staker's entire stake is frozen in the staking contract for as long as the operator maintains the malicious beneficiary.

**Vesting contract path:**

The same abort occurs in `vesting::distribute` if any shareholder's beneficiary (set by the admin via `update_beneficiary`) is a non-APT-registered address with direct transfers disabled. All other shareholders are blocked from receiving their vested APT.

The corrupted value is the staker's/shareholders' APT balance: funds are withdrawn from the stake pool into `coins` inside `distribute_internal`, but the transaction reverts, leaving the funds inaccessible until the attacker relents.

---

### Likelihood Explanation

**Low.** The operator must deliberately set a malicious beneficiary. However, no staker consent or on-chain permission is required for `set_beneficiary_for_operator` — it is a unilateral operator action. A disgruntled or adversarial operator can execute this at zero cost. The `malicious_addr` setup (create account, call `set_allow_direct_coin_transfers(false)`, skip APT registration) requires only two cheap transactions.

---

### Recommendation

Replace the push-payment loop with a pull (claim) pattern:

- In `distribute_internal` and `vesting::distribute`, record each recipient's claimable amount in a per-address map instead of immediately calling `deposit_coins`.
- Add a separate `claim(recipient: &signer)` entry function that lets each recipient withdraw their own share.
- This eliminates the ability of any single recipient to abort the distribution for all others.

Alternatively, wrap each `deposit_coins` call in a try-catch equivalent (if the VM supports it) and skip failed recipients, crediting their share to a claimable escrow.

---

### Proof of Concept

```
// Setup (attacker = operator)
1. staker creates staking contract with operator.
2. operator calls: set_beneficiary_for_operator(operator_signer, @malicious)
3. @malicious calls: set_allow_direct_coin_transfers(false)
   (and never calls coin::register<AptosCoin>)

// Attack
4. Anyone calls: distribute(staker_addr, operator_addr)
   → distribute_internal runs
   → reaches operator's turn in the loop
   → deposit_coins(@malicious, commission_coins)
   → can_receive_direct_coin_transfers(@malicious) == false
   → assert! fires → EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS
   → entire tx reverts, staker receives nothing

5. staker calls: switch_operator(staker_signer, operator_addr, new_operator, ...)
   → internally calls distribute_internal(staker_addr, operator_addr, ...)
   → same abort → staker cannot switch operators

// Result: staker's stake is permanently frozen until operator cooperates.

    /// Set whether `account` can receive direct transfers of coins that they have not explicitly registered to receive.
    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }
