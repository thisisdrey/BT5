### Title
Quarantine-directory naming heuristic bypasses repository-ownership check in `ObjectDirectoryPath`, allowing storage-path escape - (File: internal/git/localrepo/paths.go)

### Summary
`Repo.ObjectDirectoryPath()` accepts a client-supplied `GitObjectDirectory` field on the `Repository` message and resolves it to an absolute path used for filesystem operations. The function trusts a purely syntactic signal — whether the path's basename is literally `quarantine` (or its parent is `quarantine` and the basename matches a `tmp_objdir` prefix) — to skip the check that verifies the directory actually belongs to the target repository's own quarantine. This is analogous to H-4: instead of relying on a protocol-enforced/trusted attribute, the code relies on a self-declared property of attacker-controlled input to bypass the real ownership/ownership-boundary validation.

### Finding Description
`ObjectDirectoryPath` first ensures the resolved path stays within the storage root: [1](#0-0) 

It then computes `isTransactionQuarantineDir` purely from the last path component name(s) of the client-supplied `objectDirectoryPath`: [2](#0-1) 

If that naming heuristic matches, the function completely skips the second, meaningful check — the one that verifies the quarantine directory is actually prefixed by `expectedQuarantinePrefix := filepath.Join(tempDir, storage.QuarantineDirectoryPrefix(repo))`, i.e. that the quarantine directory genuinely belongs to *this* repository and was created by *this* transaction: [3](#0-2) 

Because `GitObjectDirectory` is a field on the `Repository` protobuf message supplied directly in the RPC request (as exercised by `GetObjectDirectorySizeRequest`), any caller with normal Gitaly RPC access can set this field to an arbitrary storage-relative path whose final path segment happens to be named `quarantine` (or `<quarantine>/tmp_objdir-*`). Because the first check only bounds the path to the *storage root* — not the *repository* — and the second, repository-ownership-specific check is skipped whenever the naming heuristic is satisfied, an attacker can point `ObjectDirectoryPath()` at any directory elsewhere in the same storage, as long as it ends in a `quarantine`-named path component that exists on disk: [4](#0-3) 

The test suite only exercises legitimate quarantine directories and rejects obviously escaping paths (e.g., `"../bazqux.git"`), but never a path crafted to look like a quarantine directory while pointing at another repository or unrelated directory within the same storage: [5](#0-4) 

This mirrors the Cooler bug class exactly: a "trust" decision (here, "is this really a quarantine directory belonging to me?") is derived from a property that the untrusted caller fully controls (the literal string "quarantine" appearing as the final path component), rather than from a value enforced by the trusted subsystem (the transaction manager's own quarantine prefix, `storage.QuarantineDirectoryPrefix(repo)`).

### Impact Explanation
`ObjectDirectoryPath()` is consumed by `GetObjectDirectorySize`, which walks the resolved directory and reports its total size back to the caller: [6](#0-5) 

An attacker who controls the `GitObjectDirectory` field of a `GetObjectDirectorySizeRequest` can therefore make Gitaly walk and report the size of an arbitrary directory within the same storage (e.g., another repository's data), as long as they can arrange for the final path component to be named `quarantine` (or a matching `tmp_objdir-*` name under a `quarantine` parent) and for that directory to exist. This is a cross-repository storage-boundary bypass and information-disclosure primitive within the storage-path resolution layer, not merely a quarantine-directory issue restricted to the intended use case.

### Likelihood Explanation
Exploitation requires only a crafted RPC field (`GitObjectDirectory`) on a request that is otherwise unprivileged relative to normal Gitaly RPC access (the same access level used by Rails' access-check callback loop that legitimately sets this field). No additional entitlement beyond standard Gitaly authentication is required, and the bypass condition (naming the final path segment `quarantine`) is trivial for a caller to satisfy since it is a pure string match, not a cryptographic or transaction-scoped secret.

### Recommendation
Do not use path-naming conventions (`basename == "quarantine"`) as a substitute for verifying repository ownership of the quarantine directory. Always validate the resolved directory against `storage.QuarantineDirectoryPrefix(repo)` (or the actual transaction-recorded quarantine path) regardless of what the path's basename looks like, and only skip that verification when the quarantine directory is obtained from an internal, non-attacker-controlled source (e.g. directly from the transaction object) rather than from the client-supplied `GitObjectDirectory`/`GitAlternateObjectDirectories` fields.

### Proof of Concept
1. Client calls `GetObjectDirectorySize` with a `Repository` whose `git_object_directory` is set to a storage-relative path such as `../other-repo.git/quarantine` (or any storage-relative path ending in a component literally named `quarantine`, provided such a directory exists within the storage, e.g. created by an unrelated concurrent transaction).
2. In `ObjectDirectoryPath`, `storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))` succeeds because the resulting path is still within the storage root (just not within the target repository).
3. `baseDir == "quarantine"` sets `isTransactionQuarantineDir = true`, entirely skipping the check that would normally verify the directory is prefixed by `expectedQuarantinePrefix` derived from `storage.QuarantineDirectoryPrefix(repo)` for the *target* repository.
4. `fullPath` is returned and `dirSizeInBytes` walks and sums the size of the unrelated directory, disclosing its size to the caller instead of returning an `InvalidArgument`/`NotFound` error scoped to the target repository.

// ObjectDirectoryPath returns the full path of the object directory. The errors returned are gRPC
// errors with relevant error codes and should be passed back to gRPC without further decoration.
func (repo *Repo) ObjectDirectoryPath(ctx context.Context) (string, error) {
	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", err
	}

	objectDirectoryPath := repo.GetGitObjectDirectory()
	if objectDirectoryPath == "" {
		return "", structerr.NewInvalidArgument("object directory path is not set")
	}

	baseDir := filepath.Base(relativeObjectDirectoryPath)
	isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

	// Transactions quarantine a repository by pointing the object directory to a 'quarantine' named
	// directory in the transaction's temporary directory. If the base directory is `quarantine`,
	// Git push may apply an additional layer of quarantine such as `/quarantine/tmp_objdir-incoming-Gbc29N`
	// so we don't assert the `/quarantine` being the last element of the path. We thus also check for
	// whether the parent directory is in `quarantine` and whether the base directory has the expected
	// `tmp_objdir` suffix.
	if !isTransactionQuarantineDir {
		// We need to check whether the relative object directory as given by the repository is
		// a valid path. This may either be a path in the Git repository itself, where it may either
		// point to the main object directory storage or to an object quarantine directory as
		// created by git-receive-pack(1). Alternatively, if that is not the case, then it may be a
		// manual object quarantine directory located in the storage's temporary directory. These
		// have a repository-specific prefix which we must check in order to determine whether the
		// quarantine directory does in fact belong to the repo at hand.

			if !strings.HasPrefix(absoluteObjectDirectoryPath, expectedQuarantinePrefix) {

func (s *server) GetObjectDirectorySize(ctx context.Context, in *gitalypb.GetObjectDirectorySizeRequest) (*gitalypb.GetObjectDirectorySizeResponse, error) {
	repository := in.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}
	repo := s.localRepoFactory.Build(repository)

	path, err := repo.ObjectDirectoryPath(ctx)
	if err != nil {
		return nil, err
	}
	// path is the objects directory path, not repo's path
	sizeInBytes, err := dirSizeInBytes(path, snapshot.NewDefaultFilter(ctx))
	if err != nil {
		return nil, fmt.Errorf("calculating directory size: %w", err)
	}

	return &gitalypb.GetObjectDirectorySizeResponse{Size: sizeInBytes / 1024}, nil
}
