### Title
Vote-worker `buffer_packet_batch` never checks `PacketMeta::discard()`, letting sigverify-failed packets in a mixed batch reach `vote_storage.insert_packet` unverified - (File: core/src/banking_stage/vote_packet_receiver.rs)

### Summary
`SigVerifyWorkerPool::run_transaction_task` runs `ed25519_verify_serial` on a whole `PacketBatch` and marks failing packets `discard = true`, but forwards the *entire* batch to the banking-stage channel as long as `num_valid_packets > 0` for that batch [1](#0-0) . `VotePacketReceiver::buffer_packet_batch`, which consumes that channel for the TPU-vote path, iterates every packet in the batch and sanitizes/inserts it without ever checking `packet.meta().discard()` [2](#0-1) . As a result, a packet that failed ed25519 verification but was coalesced into the same `PacketBatch` as a validly-signed packet is sanitized and passed straight to `vote_storage.insert_packet`.

### Finding Description
The TPU-vote ingress pipeline is: `fetch_stage` streamer receives raw UDP packets and batches/coalesces them into a `PacketBatch` [3](#0-2) , which is handed to `SigVerifyWorkerPool` on the `tpu_vote_receiver` channel [4](#0-3) . There, `run_transaction_task` runs signature verification per-packet with `ed25519_verify_serial`, which marks failing packets `discard = true` in place, but the discard-marking is per-packet while the forward-or-drop decision is per-*batch*:

```
let num_valid_packets = sigverify::count_valid_packets(std::iter::once(&batch));
...
if num_valid_packets == 0 {
    return true;
}
let banking_packet_batch = BankingPacketBatch::new(batch);
...
state.banking_stage_sender.send(banking_packet_batch.clone())
``` [5](#0-4) 

So a batch is dropped only if *every* packet in it fails verification; if even one packet is valid, the whole batch — including the discarded/invalid packets — is sent downstream to the vote worker's `tpu_vote_receiver` (mapped in `BankingStage::spawn_vote_worker` to `VotePacketReceiver`) [6](#0-5) .

`VotePacketReceiver::buffer_packet_batch` then iterates `packet_batch.iter()` and, for each packet, only checks `packet.data(..)` is present, attempts `SanitizedTransactionView::try_new_sanitized`, applies `should_filter_packet` (an account-key filter unrelated to signatures), and calls `vote_storage.insert_packet` — with no check of `packet.meta().discard()` anywhere in this function [7](#0-6) . This is in contrast to other consumers of post-sigverify batches, such as the sigverify benchmark test harness, which explicitly filters `!packet.meta().discard()` before counting/using packets [8](#0-7) , confirming that downstream consumers are expected to respect the discard flag rather than have it enforced automatically by the channel/iterator.

Once inside `vote_storage.insert_packet` → `insert_vote`, the only checks performed are: (a) the referenced vote-account pubkey has nonzero stake, and (b) the `authorized_voter_pubkey` embedded in the transaction matches the epoch's cached authorized voter for that vote account [9](#0-8) . Neither of these checks re-verifies the ed25519 signature; they only inspect pubkey fields carried in the (attacker-controlled) transaction bytes. Consequently, a forged vote packet with an invalid signature — but referencing a legitimately staked vote account/authorized voter — is inserted into `vote_storage` as if it had passed sigverify, because the discard marker set by `ed25519_verify_serial` is silently dropped on the floor by `buffer_packet_batch`.

### Impact Explanation
This is a signature-verification bypass on the TPU-vote path: an unstaked, unprivileged attacker can get a transaction with an invalid signature accepted into `VoteStorage` and subsequently consumed by the vote worker / banking stage, matching the "packet reaches banking without passing sigverify" bounty category. It undermines the core invariant that every transaction reaching banking has a verified signature, potentially allowing insertion of vote-storage entries that were never actually signed by the claimed authorized voter (though the fake vote must reference an already-staked, already-authorized-voter pubkey to survive the `insert_vote` stake/authority checks, limiting it to spoofing content on top of a legitimate voter's identity, e.g., wrong vote slots/hashes cannot be attributed but the record itself is inserted without signature proof).

### Likelihood Explanation
The attacker only needs to be an unstaked remote client sending UDP/QUIC packets to the leader's TPU-vote port: no keys, stake, or gossip/peer control required. The precondition is that the forged (invalid-signature) packet lands in the same `PacketBatch` as at least one validly-signed packet, which the fetch-stage streamer's coalescing (`streamer::receiver` with a coalesce window) makes achievable by a burst of packets sent within the coalescing window [3](#0-2) . This is deterministic and repeatable given control over packet timing from the attacker's own connection.

### Recommendation
In `VotePacketReceiver::buffer_packet_batch`, skip any packet whose `meta().discard()` is `true` before attempting to sanitize/insert it (mirroring the pattern already used in `core/benches/sigverify_stage.rs`), so batches partially rejected by `ed25519_verify_serial` do not leak invalid packets into `VoteStorage`. Additionally, consider making `run_transaction_task` filter/split packets by discard status before sending to the banking-stage channel, rather than relying on downstream consumers to remember to check the flag.

### Proof of Concept
```rust
// core/src/banking_stage/vote_packet_receiver.rs (tests module)
#[test]
fn test_discarded_packet_in_batch_is_not_inserted() {
    let keypair = ValidatorVoteKeypairs::new_rand();
    let genesis_config =
        genesis_utils::create_genesis_config_with_vote_accounts(100, &[&keypair], vec![200])
            .genesis_config;
    let (bank, _bank_forks) = Bank::new_with_bank_forks_for_tests(&genesis_config);
    let mut vote_storage = VoteStorage::new(&bank);

    // valid, correctly-signed vote packet
    let mut good_packet = packet_from_slots(vec![(1, 1)], &keypair, None);

    // forged packet: tamper with signature bytes after construction so
    // it fails ed25519 verification but still sanitizes successfully.
    let mut bad_packet = packet_from_slots(vec![(2, 1)], &keypair, None);
    corrupt_signature(&mut bad_packet); // flips bytes in the sig region

    // simulate sigverify: mark bad_packet discarded, leave good_packet valid
    bad_packet.meta_mut().set_discard(true);

    let (sender, receiver) = bounded(1024);
    sender
        .send(Arc::new(PacketBatch::from(vec![good_packet, bad_packet])))
        .unwrap();

    let mut receiver = VotePacketReceiver::new(receiver, Arc::new(HashSet::new()));
    let mut banking_stage_stats = BankingStageStats::new();
    let mut slot_metrics_tracker = LeaderSlotMetricsTracker::default();

    receiver
        .receive_and_buffer_packets(
            &mut vote_storage,
            &mut banking_stage_stats,
            &mut slot_metrics_tracker,
            VoteSource::Tpu,
        )
        .unwrap();

    // Only the valid, sigverified vote for slot 1 should be present.
    // Currently FAILS: the forged packet for slot 2 is also inserted
    // because buffer_packet_batch never checks meta().discard().
    assert_eq!(
        vote_storage.get_latest_vote_slot(keypair.vote_keypair.pubkey()),
        Some(1)
    );
}
```
Expected (post-fix) behavior: the discarded packet is skipped in `buffer_packet_batch`, so `vote_storage` reflects only the slot-1 vote from the correctly signed packet; currently, absent the fix, the forged slot-2 vote overwrites/coexists based on `insert_vote`'s slot-comparison logic, demonstrating the bypass.

    fn buffer_packet_batch(
        &self,
        packet_batch: &BankingPacketBatch,
        sanitize_config: &SanitizeConfig,
        vote_storage: &mut VoteStorage,
        vote_source: VoteSource,
        slot_metrics_tracker: &mut LeaderSlotMetricsTracker,
        stats: &mut ReceiveAndBufferStats,
    ) {
        stats.num_packets_received += packet_batch.len();

        for packet in packet_batch.iter() {
            let Some(packet_data) = packet.data(..) else {
                continue;
            };

            match SanitizedTransactionView::try_new_sanitized(
                packet_bytes(packet, packet_data),
                sanitize_config,
            ) {
                Ok(packet) => {
                    if self.should_filter_packet(&packet) {
                        stats.packet_stats.filtered_account_key_count += 1;
                        continue;
                    }

                    stats.num_buffered_packets += 1;
                    let vote_insertion_metrics = vote_storage.insert_packet(vote_source, packet);
                    slot_metrics_tracker.accumulate_vote_insertion_metrics(&vote_insertion_metrics);
                    stats.dropped_packets_count += vote_insertion_metrics.total_dropped_packets();
                }
                Err(err) => {
                    stats.errors += 1;
                    match err {
                        TransactionViewError::AddressLookupMismatch => {}
                        TransactionViewError::ParseError | TransactionViewError::SanitizeError => {
                            stats.packet_stats.failed_sanitization_count += 1
                        }
                    }
                }
            }
        }
    }
