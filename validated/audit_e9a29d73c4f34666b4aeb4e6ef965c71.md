The boundary check is correct: when `self.data.len() < 128`, the short branch prints the full `self.data` (no slicing), and when `self.data.len() >= 128` (including exactly 128), the else branch does `&self.data[..128]`, which is always in-bounds since `len >= 128`. There is no off-by-one gap between the two branches — the condition is `<` for the safe (non-slicing) path and the slicing path only executes when length is `>= 128`, so a buffer of exactly 128 bytes takes the else branch with a fully valid slice.
