### Title
Operator-Controlled Beneficiary Permanently Freezes Staker's Unlocked APT in `staking_contract::distribute_internal` — (`aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

`staking_contract::distribute_internal` iterates over all distribution-pool shareholders inside a `while` loop and calls `aptos_account::deposit_coins` for each one. If the operator has set their beneficiary to an address that rejects direct coin transfers, `deposit_coins` aborts, reverting the entire distribution. Because `switch_operator` unconditionally calls `distribute_internal` before reassigning the operator, the staker is also unable to escape by switching operators. The staker's inactive (unlocked) APT is permanently frozen inside the staking contract with no recovery path.

---

### Finding Description

**Step 1 – `deposit_coins` guard**

`aptos_account::deposit_coins` contains a guard that fires whenever the destination address is not yet registered for the coin type:

```move
if (!coin::is_account_registered<CoinType>(to)) {
    assert!(
        can_receive_direct_coin_transfers(to),
        error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
    );
    coin::register<CoinType>(&create_signer(to));
};
``` [1](#0-0) 

`can_receive_direct_coin_transfers` returns `false` when the account has explicitly called `set_allow_direct_coin_transfers(false)`:

```move
public fun can_receive_direct_coin_transfers(account: address): bool acquires DirectTransferConfig {
    !exists<DirectTransferConfig>(account)
        || borrow_global<DirectTransferConfig>(account).allow_arbitrary_coin_transfers
}
``` [2](#0-1) 

**Step 2 – Loop in `distribute_internal`**

`distribute_internal` loops over every shareholder in the distribution pool and calls `deposit_coins` for each, including the operator's commission which is redirected to `beneficiary_for_operator(operator)`:

```move
while (distribution_pool.shareholders_count() > 0) {
    let recipients = distribution_pool.shareholders();
    let recipient = recipients[0];
    ...
    if (recipient == operator) {
        recipient = beneficiary_for_operator(operator);
    };
    aptos_account::deposit_coins(
        recipient, coin::extract(&mut coins, amount_to_distribute)
    );
``` [3](#0-2) 

If `deposit_coins` aborts for any recipient, the entire transaction reverts. The coins are returned to the `coins` variable (Move's ownership model), but the distribution state is also reverted — so the next call to `distribute` will attempt the same failing deposit again, forever.

**Step 3 – Operator sets a blocking beneficiary (unprivileged)**

Any operator can call `set_beneficiary_for_operator` to redirect their commission to an arbitrary address:

```move
public entry fun set_beneficiary_for_operator(
    operator: &signer, new_beneficiary: address
) acquires BeneficiaryForOperator {
``` [4](#0-3) 

No validation is performed on `new_beneficiary`. The operator can point it to an address that has `allow_arbitrary_coin_transfers = false` and no legacy `CoinStore<AptosCoin>` registration.

**Step 4 – `switch_operator` is also blocked**

The staker's only escape route — switching to a new operator — unconditionally calls `distribute_internal` first:

```move
let (_, staking_contract) = staking_contracts.remove(&old_operator);
// Force distribution of any already inactive stake.
distribute_internal(
    staker_address,
    old_operator,
    &mut staking_contract,
);
``` [5](#0-4) 

Because `distribute_internal` aborts, `switch_operator` also aborts. The staker cannot reassign the operator, cannot distribute, and has no other path to recover their inactive stake from the staking contract's `owner_cap`-controlled pool.

**Same pattern in `vesting::distribute`**

`vesting::distribute` has the identical loop-over-shareholders pattern, calling `aptos_account::deposit_coins` for each beneficiary:

```move
shareholders.for_each_ref(|shareholder| {
    ...
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);
});
``` [6](#0-5) 

Here the trigger requires the vesting admin to set a blocking beneficiary, making it a privileged path; the staking contract path is fully unprivileged.

---

### Impact Explanation

The staker's inactive (unlocked) APT held inside the staking contract's stake pool is permanently inaccessible. The staker cannot call `distribute`, cannot call `switch_operator`, and has no direct access to the pool's `owner_cap`. This constitutes permanent freezing of staking balances, which is within the Aptos bounty scope.

---

### Likelihood Explanation

The operator is a semi-trusted party chosen by the staker, but the operator has an economic incentive to grief: they can freeze the staker's funds while suffering no loss themselves (their own commission is also frozen, but they may have already extracted it via `request_commission` before setting the blocking beneficiary). The attack requires two cheap transactions (`set_allow_direct_coin_transfers(false)` + `set_beneficiary_for_operator`) and is irreversible from the staker's side.

---

### Recommendation

1. **In `distribute_internal`**: Replace `aptos_account::deposit_coins` with a try-catch pattern (or a skip-on-failure approach) so that a single failing recipient does not abort the entire distribution. Alternatively, use `coin::deposit` directly after ensuring registration, bypassing the `can_receive_direct_coin_transfers` gate for protocol-level distributions.

2. **In `switch_operator`**: Do not call `distribute_internal` unconditionally before the operator switch. Either make distribution optional or handle its failure gracefully so the staker can always escape a malicious operator.

3. **Validate `new_beneficiary`** in `set_beneficiary_for_operator` to ensure the address can receive APT (i.e., is registered or has direct transfers enabled) before accepting the change.

---

### Proof of Concept

```
// Step 1: Attacker (operator) creates a blocking beneficiary address
// Account BLOCK_ADDR calls:
aptos_account::set_allow_direct_coin_transfers(block_signer, false);
// BLOCK_ADDR never calls coin::register<AptosCoin>(), so is_account_registered = false

// Step 2: Operator sets their beneficiary to BLOCK_ADDR
staking_contract::set_beneficiary_for_operator(operator_signer, BLOCK_ADDR);

// Step 3: Staker unlocks stake and waits for lockup to expire
// Stake moves to inactive in the pool

// Step 4: Anyone calls distribute — permanently fails
staking_contract::distribute(staker_addr, operator_addr);
// → distribute_internal → deposit_coins(BLOCK_ADDR, commission)
// → can_receive_direct_coin_transfers(BLOCK_ADDR) == false → ABORT

// Step 5: Staker tries to escape via switch_operator — also permanently fails
staking_contract::switch_operator(staker_signer, operator_addr, new_operator_addr, 5);
// → distribute_internal called first → same abort
// Staker's inactive APT is permanently frozen with no recovery path
```

    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
