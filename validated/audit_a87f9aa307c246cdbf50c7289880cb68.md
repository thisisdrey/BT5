### Title
Oracle price-update sandwiching via `Pool.swap` mints unbacked synthetics - (File: contracts/Pool.sol)

### Summary
`Pool.swap` exchanges one synthetic asset for another purely at the `MasterOracle` spot quote, with no `amountOutMin` slippage parameter, no per-block delay, and no staleness bound on how "fresh" the quoted price must be. When `swapFee == 0` for a pair (the default in `FeeProviderStorageV1`, and explicitly exercised in `test/Pool.test.ts:1067`), an unprivileged attacker can atomically bracket a permissionless pull-oracle update (Pyth `updatePriceFeeds` / RedStone `updatePrice`) with two opposite swaps, profiting the price delta in freshly minted synthetic tokens — value that is backed by no debt position.

### Finding Description
`swap` burns `syntheticTokenIn_` and mints `syntheticTokenOut_` at `quoteSwapOut`, which resolves to `masterOracle().quote(tokenIn, tokenOut, amountIn)` minus the fee (contracts/Pool.sol:642-668, 508-524).

The deployed oracle configuration uses pull oracles whose updates are permissionless: anyone can call `pyth.updatePriceFeeds(...)` or the RedStone `updatePrice(...)`, and `Operator.execute` exists precisely to bundle `updatePrice` with a protocol action in one transaction (test/E2E.mainnet.test.ts:1051-1077, test/E2E.hemi.pullOracle.test.ts:129-159).

Attack path, fully unprivileged, executable inside a single `Operator.execute(calls)` bundle or an attacker contract:

1. `swap(msUSD → msETH, X)` at the stale price `P_old`.
2. `pullOracle.updatePrice(...)` / `pyth.updatePriceFeeds(...)` raising the ETH price to `P_new`.
3. `swap(msETH → msUSD)` converting all received msETH back at `P_new`, ending with `X * P_new/P_old` msUSD.

No modifier stops this: `swap` only checks `whenNotShutdown`, `nonReentrant`, `isSwapActive`, and token existence. There is no `amountOutMin_` argument (unlike `SmartFarmingManager` flows which do take slippage params), and no restriction on swapping twice in one block. Since the minted output is new supply not covered by any borrower's debt, each round-trip dilutes the synthetic asset's backing.

### Impact Explanation
Direct extraction of protocol value: the profit is paid in newly minted synthetic tokens redeemable against the same collateral pool as honest debt-backed supply, causing protocol insolvency/depeg proportional to `|P_new - P_old| / P_old * amount`. With volatile-asset synth pairs (e.g., msUSD/msETH) and flash-borrowed or self-minted `amountIn_`, the delta can be harvested on every material oracle update on any chain where the pair has `swapFee == 0`.

### Likelihood Explanation
Requires (a) `isSwapActive` on the pool, (b) a swap pair with zero (or sub-delta) fee — the default when no per-pair fee is set, and (c) a price update large enough to exceed gas/fees. Oracle updates are public mempool targets and can also be triggered by the attacker directly with fresh signed data, so no privileged observation is needed. Profitability depends on deployment fee configuration, so the practical severity is medium.

### Recommendation
Add an `amountOutMin_` parameter to `Pool.swap`/`IPool.swap` and revert if `quoteSwapOut` returns less; alternatively enforce a minimum swap fee floor per pair so round-trip sandwiching is never profitable, or record `block.number` of last oracle-relative state and disallow two swaps by the same account within the same block.

### Proof of Concept
```solidity
// Foundry fork test (mainnet), Pool.swap path
// 1. Attacker holds msUSD (minted via own deposit + debtToken.issue).
uint256 amt = 1_000_000e18;
uint256 priceOld = masterOracle.getPriceInUsd(address(msETH));

// 2. Same-tx bundle via Operator.execute or an attacker contract:
//    a) swap msUSD -> msETH at P_old
(uint256 out,) = pool.swap(msUSD, msETH, amt);
//    b) permissionless price update to P_new > P_old
pyth.updatePriceFeeds{value: fee}(freshUpdateData); // pushes ETH price up
//    c) swap msETH -> msUSD at P_new
(uint256 back,) = pool.swap(msETH, msUSD, out);

// 3. With swapFee == 0: back ≈ amt * P_new / P_old > amt
assertGt(back, amt); // attacker profit is unbacked msUSD supply
```
