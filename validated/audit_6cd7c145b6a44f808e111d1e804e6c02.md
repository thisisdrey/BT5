### Title
Per-key stream throttle counter resets on connection re-establishment, allowing unstaked churn to evade `MAX_UNSTAKED_TPS` - ([File: streamer/src/nonblocking/swqos.rs], [File: streamer/src/nonblocking/stream_throttle.rs], [File: streamer/src/nonblocking/quic.rs])

### Summary
`SwQos::try_add_connection` keys each unstaked connection's `ConnectionStreamCounter` to its `ConnectionTable` entry, which is created fresh (`stream_count = 0`) whenever a peer's table entry is fully removed and re-added. Because table entries are removed both on ordinary disconnect (`remove_connection`) and on `prune_oldest`/`prune_unstaked_connection_table` eviction, an unstaked attacker who closes/reopens (or gets pruned and reconnects) faster than `STREAM_THROTTLING_INTERVAL_MS` (100ms) obtains a fresh `MAX_UNSTAKED_TPS`-sized burst budget on every churn cycle instead of one 100ms-bounded budget.

### Finding Description
`throttle_stream` in [1](#0-0)  only throttles a peer once its `ConnectionStreamCounter.stream_count` (reset every `STREAM_THROTTLING_INTERVAL` via `reset_throttling_params_if_needed`, [2](#0-1) ) reaches `max_streams_per_throttling_interval`, which for unstaked peers is `max_unstaked_load_in_throttling_window = MAX_UNSTAKED_TPS * STREAM_THROTTLING_INTERVAL_MS / 1000` (20 streams/100ms by default) [3](#0-2) .

This counter is attached to a `ConnectionTable` entry keyed by `ConnectionTableKey` (IP or pubkey). It is only reused across multiple simultaneous connections from the same key while at least one entry for that key remains in the table (`connection_entry.first().map(...).unwrap_or_else(stream_counter_factory)` in `try_add_connection`) [4](#0-3) . Once all connections for a key are removed — via `remove_connection` (called when the QUIC connection closes) [5](#0-4)  or via `prune_oldest`/`prune_unstaked_connection_table` evicting the entry outright [6](#0-5) , [7](#0-6)  — the entry is deleted from the `IndexMap`. Any subsequent connection from that key creates a brand-new `ConnectionEntry` with a brand-new `ConnectionStreamCounter::new()` (`stream_count = 0`) via `cache_new_connection` [8](#0-7) .

Exploit flow: an unstaked attacker opens a QUIC connection, immediately sends up to `max_unstaked_load_in_throttling_window` uni-streams (bounded per-connection by `QUIC_MAX_UNSTAKED_CONCURRENT_STREAMS` via `compute_max_allowed_uni_streams_with_rtt`, [9](#0-8) ), then closes the connection before the 100ms throttle window elapses and reconnects (same or new source port/IP). Each reconnect resets `stream_count` to 0, so the attacker can repeatedly harvest a fresh burst quota at a rate limited only by QUIC handshake cost, not by `MAX_UNSTAKED_TPS`. `prune_unstaked_connection_table`'s 90%-capacity eviction (triggered once `total_size >= max_unstaked_connections`) has the same effect on any peer whose entry gets evicted and who reconnects — it also clears the shared counter for that key.

The check that fails to catch this is the assumption in `stream_throttle.rs` that a `ConnectionStreamCounter` persists for the "life" of a peer's rate-limiting window; in reality its lifetime is tied to `ConnectionTable` entry lifetime, which the attacker (or ordinary churn/pruning) controls.

### Impact Explanation
This is a QoS-evasion issue: it allows unstaked/unprivileged traffic to exceed the intended aggregate unstaked ingress rate (`MAX_UNSTAKED_TPS`, nominally reserving `EXPECTED_UNSTAKED_STREAMS_RATIO` of `max_streams_per_ms` for unstaked clients) by repeatedly resetting the per-connection throttle counter through connection churn. This increases sigverify/banking-stage ingress load from unstaked sources beyond the designed cap, matching the "QoS evasion" bounty category. It does not cause a panic, deadlock, or unbounded memory growth on its own, since `max_unstaked_connections` still bounds the concurrent connection count.

### Likelihood Explanation
Fully unprivileged and remotely reproducible: the attacker only needs the ability to open/close QUIC connections to the TPU port faster than 100ms per cycle, which is well within normal client capability (handshake round-trips are typically single-digit to low double-digit milliseconds on a local/regional network). No staked keys, gossip participation, or validator control are required. Repeatability is high since the reset happens on every full connection-table-entry removal, which occurs both organically (peer disconnect) and via pruning.

### Recommendation
Decouple the per-peer stream-rate accounting from `ConnectionTable` entry lifetime. Track throttling state (e.g., in an IP/pubkey-keyed side-table with its own TTL, or an EMA-style global unstaked load counter analogous to `StakedStreamLoadEMA`) that persists across reconnects for at least one full `STREAM_THROTTLING_INTERVAL`, and rate-limit based on wall-clock time since last stream from that identity rather than resetting on new-connection creation.

    // Actual: observed_tps significantly exceeds 200 because each churn cycle grants
    // a fresh 20-stream burst faster than the 100ms window that MAX_UNSTAKED_TPS assumes.

                self.stream_count.store(0, Ordering::Relaxed);

pub(crate) async fn throttle_stream(
    stats: &StreamerStats,
    peer_type: ConnectionPeerType,
    remote_addr: std::net::SocketAddr,
    stream_counter: &Arc<ConnectionStreamCounter>,
    max_streams_per_throttling_interval: u64,
) {
    let throttle_interval_start = stream_counter.reset_throttling_params_if_needed();
    let streams_read_in_throttle_interval = stream_counter.stream_count.load(Ordering::Relaxed);
    if streams_read_in_throttle_interval >= max_streams_per_throttling_interval {
        // The peer is sending faster than we're willing to read. Sleep for what's
        // left of this read interval so the peer backs off.
        let throttle_duration =
            STREAM_THROTTLING_INTERVAL.saturating_sub(throttle_interval_start.elapsed());

        if !throttle_duration.is_zero() {
            debug!(
                "Throttling stream from {remote_addr:?}, peer type: {peer_type:?}, \
                 max_streams_per_interval: {max_streams_per_throttling_interval}, \
                 read_interval_streams: {streams_read_in_throttle_interval} throttle_duration: \
                 {throttle_duration:?}"
            );
            stats.throttled_streams.fetch_add(1, Ordering::Relaxed);
            match peer_type {
                ConnectionPeerType::Unstaked => {
                    stats
                        .throttled_unstaked_streams
                        .fetch_add(1, Ordering::Relaxed);
                }
                ConnectionPeerType::Staked(_) => {
                    stats
                        .throttled_staked_streams
                        .fetch_add(1, Ordering::Relaxed);
                }
            }
            sleep(throttle_duration).await;
        }
    }

    pub(crate) fn prune_oldest(&mut self, max_size: usize) -> usize {
        let mut num_pruned = 0;
        let key = |(_, connections): &(_, &Vec<_>)| {
            connections.iter().map(ConnectionEntry::last_update).min()
        };
        while self.total_size.saturating_sub(num_pruned) > max_size {
            match self.table.values().enumerate().min_by_key(key) {
                None => break,
                Some((index, connections)) => {
                    num_pruned += connections.len();
                    self.table.swap_remove_index(index);
                }
            }
        }
        self.total_size = self.total_size.saturating_sub(num_pruned);
        num_pruned
    }

    pub(crate) fn remove_connection(
        &mut self,
        key: ConnectionTableKey,
        port: u16,
        stable_id: usize,
    ) -> usize {
        if let Entry::Occupied(mut e) = self.table.entry(key) {
            let e_ref = e.get_mut();
            let old_size = e_ref.len();

            e_ref.retain(|connection_entry| {
                // Retain the connection entry if the port is different, or if the connection's
                // stable_id doesn't match the provided stable_id.
                // (Some unit tests do not fill in a valid connection in the table. To support that,
                // if the connection is none, the stable_id check is ignored. i.e. if the port matches,
                // the connection gets removed)
                connection_entry.port != port
                    || connection_entry
                        .connection
                        .as_ref()
                        .and_then(|connection| (connection.stable_id() != stable_id).then_some(0))
                        .is_some()
            });
            let new_size = e_ref.len();
            if e_ref.is_empty() {
                e.swap_remove_entry();
            }
            let connections_removed = old_size.saturating_sub(new_size);
            self.total_size = self.total_size.saturating_sub(connections_removed);
            connections_removed
        } else {
            0
        }
    }

fn compute_max_allowed_uni_streams_with_rtt(
    rtt_millis: u32,
    peer_type: ConnectionPeerType,
    total_stake: u64,
) -> u32 {
    let streams = match peer_type {
        ConnectionPeerType::Staked(peer_stake) => {
            // No checked math for f64 type. So let's explicitly check for 0 here
            if total_stake == 0 || peer_stake > total_stake {
                warn!(
                    "Invalid stake values: peer_stake: {peer_stake:?}, total_stake: \
                     {total_stake:?}"
                );

                QUIC_MIN_STAKED_CONCURRENT_STREAMS
            } else {
                let delta = (QUIC_TOTAL_STAKED_CONCURRENT_STREAMS
                    - QUIC_MIN_STAKED_CONCURRENT_STREAMS) as f64;

                (((peer_stake as f64 / total_stake as f64) * delta) as u32
                    + QUIC_MIN_STAKED_CONCURRENT_STREAMS)
                    .clamp(
                        QUIC_MIN_STAKED_CONCURRENT_STREAMS,
                        QUIC_MAX_STAKED_CONCURRENT_STREAMS,
                    )
            }
        }
        ConnectionPeerType::Unstaked => QUIC_MAX_UNSTAKED_CONCURRENT_STREAMS,
    };
    // scale amount of streams based on RTT if RTT is larger than REFERENCE_RTT_MS
    // multiply first then divide to avoid rounding errors.
    (streams.saturating_mul(rtt_millis.clamp(REFERENCE_RTT_MS, MAX_RTT_MS))) / REFERENCE_RTT_MS
}
