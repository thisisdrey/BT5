## Analysis of the premise

The exploit requires two versioned nonces, A and B, to "share a prefix" (i.e., share the same `word_pos`, the first 31 of the 32 nonce bytes used as the `BitMap256` key) while having **different** internal `ExpirableNonce.deadline` values — A's short/expired, B's long/still-valid.

Tracing the exact byte layout of a `V1` nonce as produced by `VersionedNonce::from`:

`MAGIC_PREFIX(4) || VERSION(1) || SALT(4) || DEADLINE(8) || RANDOM(15)` = 32 bytes total. [4](#0-3) [5](#0-4) 

`BitMap256::get_bit`/`set_bit`/`cleanup_by_prefix` split the 32-byte nonce as `[word_pos @ .., bit_pos]`, i.e. `word_pos = bytes[0..31]` and `bit_pos = bytes[31]` (the single trailing byte): [6](#0-5) 

Given the layout above, `word_pos` (bytes 0..31) fully contains the magic prefix, version, salt, **the entire 8-byte deadline**, and the first 14 of the 15 random bytes. Only the last random byte (byte 31) is the `bit_pos`. Consequently, **any two nonces that share the same `word_pos` (and therefore the same storage entry removed by `cleanup_by_prefix`) must have byte-identical `deadline` fields**, since the deadline occupies fixed byte positions inside `word_pos`. `verify_intent_nonce` and `is_nonce_cleanable` both read this same `deadline` field for expiry checks: [7](#0-6) [8](#0-7)

    fn verify_intent_nonce(&self, nonce: Nonce, intent_deadline: Timestamp) -> Result<()> {
        let Some(nonce) = VersionedNonce::maybe_from(nonce) else {
            return Ok(());
        };

        match nonce {
            VersionedNonce::V1(SaltedNonce {
                salt,
                nonce: ExpirableNonce { deadline, .. },
            }) => {
                if !self.state.is_valid_salt(salt) {
                    return Err(DefuseError::InvalidSalt);
                }

                if intent_deadline > deadline {
                    return Err(DefuseError::DeadlineGreaterThanNonce);
                }

                if deadline < Timestamp::now() {
                    return Err(DefuseError::NonceExpired);
                }
            }
        }

        Ok(())
    }
