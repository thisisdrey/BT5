### Title
Missing post-unpause grace period allows instant liquidation of positions that went unhealthy while the protocol was paused/shutdown - (File: contracts/Pool.sol)

### Summary
`Pool.liquidate()` is gated only by `whenNotShutdown`, while user remediation paths are gated more strictly: `DepositToken.deposit()` reverts when `Pool.paused()`, and `DebtToken.repay()`/`repayAll()` plus `DepositToken.withdraw()` all revert on `everythingStopped()`. There is no grace-period mechanism after `unpause()`/`open()`, so a liquidator can atomically (or in the same block as) `open()`/`unpause()` call `liquidate()` on any position whose collateral fell in value or whose accrued interest pushed it below the collateralization floor during the halt — the borrower never had a chance to add collateral or repay.

### Finding Description
The pause model in `Pauseable` (`contracts/utils/Pauseable.sol`) has two levels:
- `pause()` sets `_paused` (deposit-suspension level)
- `shutdown()` sets `_everythingStopped` (suspends issue, repay, deposit, withdraw, liquidate, swap)
- `unpause()`/`open()` clear the flags instantly, with no timestamp recorded and no cooldown

Per `docs/emergency-flags.md`:
- `Pool.liquidate()` — disabled only if `everythingStopped()`
- `DebtToken.repay()`/`repayAll()` — disabled if `everythingStopped()`
- `DepositToken.deposit()` — disabled if `paused()` **or** `everythingStopped()`
- `DepositToken.withdraw()` — disabled if `everythingStopped()`

`Pool.liquidate()` at `contracts/Pool.sol:537-596` carries only `whenNotShutdown` (line 545), and it checks `debtPositionOf(account_)` freshness with no notion of "recently unpaused":

```solidity
function liquidate(...) external override whenNotShutdown nonReentrant ...
    ...
    (bool _isHealthy, , , , ) = debtPositionOf(account_);
    if (_isHealthy) revert PositionIsHealthy();
```

Two concrete harm paths:

1. **Pause-only path (stronger — no unpause needed):** While `Pool.paused()`, `DepositToken.deposit()` reverts (`Manageable.whenNotPaused` → `pool.paused()`), but `Pool.liquidate()` still executes (confirmed by test `Pool.test.ts:353-365` "should not revert if paused"). During a pause a borrower's only defense is repaying the full debt in synth — they cannot add collateral — while liquidators keep full ability to seize.

2. **Shutdown path:** During `everythingStopped()`, repay, deposit, withdraw and liquidate are all blocked. Interest keeps accruing conceptually via `debtIndex` (`DebtToken.accrueInterest()` is called inside `liquidate`), and external collateral prices move. The moment the governor calls `open()`, a liquidator can call `liquidate()` in the same block — even front-running the `open()` transaction ordering is unnecessary since any MEV bot can back-run it — seizing collateral plus the liquidator incentive and protocol fee before the borrower can react.

The invariant broken is a liveness/fairness bound on liquidation: borrowers are denied remediation during the halt but are exposed to liquidation immediately upon resumption.

### Impact Explanation
High. Borrowers whose positions became unhealthy during a pause/shutdown lose collateral deterministically — seized at oracle price plus `liquidatorIncentive` and `protocolFee` (`quoteLiquidateOut`, `Pool.sol:451-472`) — with zero opportunity to cure, because the remediation functions were disabled by the same flag that now enables liquidation. This is a direct loss of user funds enforceable by any unprivileged liquidator in the first post-`open()`/`unpause()` block.

### Likelihood Explanation
Low-to-medium. It requires a governor-initiated pause/shutdown that is long enough for collateral prices to move or interest to accrue past the liquidation threshold. Pause/shutdown is an emergency power, but the code provides no mitigation once it is exercised, and liquidations during a *pause* require no unpause race at all — `deposit()` is blocked while `liquidate()` is live.

### Recommendation
Record an `unpausedAt`/`openedAt` timestamp in `unpause()`/`open()` and add a `LIQUIDATION_GRACE_PERIOD` in `Pool.liquidate()` (e.g., `if (block.timestamp < openedAt + GRACE) revert LiquidationGracePeriod()`), giving borrowers a window to `repay()`/`deposit()` after the halt. Additionally, consider blocking `liquidate()` while `paused()` so that a deposit-blocking pause cannot be combined with active liquidations.

### Proof of Concept
Hardhat sketch (pattern follows `test/Pool.test.ts:353-377`):

```ts
// setup: alice deposits MET collateral, issues msETH; liquidator holds msETH
// 1. Governor halts protocol
await pool.shutdown();            // everythingStopped = true

// 2. While shutdown: alice's repay/deposit/withdraw all revert
await expect(msEthDebtToken.repay(alice.address, 1)).revertedWithCustomError(pool, 'IsShutdown');
await expect(msdMET.deposit(parseEther('1'))).revertedWithCustomError(pool, 'IsShutdown');

// 3. Collateral price drops during the halt
await masterOracle.updatePrice(met.address, toUSD('0.5'));
expect((await pool.debtPositionOf(alice.address))._isHealthy).false;

// 4. Governor re-opens; liquidator liquidates in the same block — no grace period exists
await pool.open();
await pool.connect(liquidator)
  .liquidate(msEth.address, alice.address, amountToRepay, msdMET.address); // succeeds

// alice never had a window to repay or add collateral between open() and liquidate()
```

        ISyntheticToken syntheticToken_,
        address account_,
        uint256 amountToRepay_,
        IDepositToken depositToken_
    )
        external
        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticToken_)
        onlyIfDepositTokenExists(depositToken_)
        returns (uint256 _totalSeized, uint256 _toLiquidator, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (amountToRepay_ == 0) revert AmountIsZero();
        if (_msgSender == account_) revert CanNotLiquidateOwnPosition();

        IDebtToken _debtToken = debtTokenOf[syntheticToken_];
        _debtToken.accrueInterest();

        (bool _isHealthy, , , , ) = debtPositionOf(account_);

        if (_isHealthy) {
            revert PositionIsHealthy();
        }

        uint256 _debtTokenBalance = _debtToken.balanceOf(account_);

        if (amountToRepay_.wadDiv(_debtTokenBalance) > maxLiquidable) {
            revert AmountGreaterThanMaxLiquidable();
        }

        if (debtFloorInUsd > 0) {
            uint256 _newDebtInUsd = masterOracle().quoteTokenToUsd(
                address(syntheticToken_),
                _debtTokenBalance - amountToRepay_
            );
            if (_newDebtInUsd > 0 && _newDebtInUsd < debtFloorInUsd) {
                revert RemainingDebtIsLowerThanTheFloor();
            }
        }

        (_totalSeized, _toLiquidator, _fee) = quoteLiquidateOut(syntheticToken_, amountToRepay_, depositToken_);

        if (_totalSeized > depositToken_.balanceOf(account_)) {
            revert AmountIsTooHigh();
        }

        syntheticToken_.burn(_msgSender, amountToRepay_);
        _debtToken.burn(account_, amountToRepay_);
        depositToken_.seize(account_, _msgSender, _toLiquidator);

        if (_fee > 0) {
            depositToken_.seize(account_, _poolRegistry.feeCollector(), _fee);
        }

        emit PositionLiquidated(_msgSender, account_, syntheticToken_, amountToRepay_, _totalSeized, _fee);
    }

    function open() external virtual whenShutdown onlyGovernor {
        _everythingStopped = false;
        emit Open(_msgSender());
    }

    /**
     * @dev Suspend deposit feature, if contract is not paused.
     */
    function pause() external virtual whenNotPaused onlyGovernor {
        _paused = true;
        emit Paused(_msgSender());
    }

    /**
     * @dev Suspend all features (issue, repay, deposit, withdraw, liquidate and swap), if not already shutdown.
     */
    function shutdown() external virtual whenNotShutdown canShutdown {
        _everythingStopped = true;
        _paused = true;
        emit Shutdown(_msgSender());
    }

    /**
     * @dev Unpause contract operations, allow only if contract is paused and not shutdown.
     */
    function unpause() external virtual whenPaused whenNotShutdown onlyGovernor {
        _paused = false;
        emit Unpaused(_msgSender());
    }
