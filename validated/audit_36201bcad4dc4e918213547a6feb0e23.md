### Title
Compromised CA can mint backdated certificates that evade fingerprint blocklisting because no issuance-chain proof is required for "old" validity windows - (File: `cert/ca_pool.go`)

### Summary
The reported bug allowed users to withdraw funds against an "old" `blockRid` that predated a `massExitBlock`, because the bridge trusted any block whose timestamp was old enough without requiring a hash-chain proof tying that block to the legitimately-issued chain history — it only checked the timestamp, not the provenance of who actually produced/approved it after compromise. Nebula's CA trust model has the same structural gap: certificate trust is decided purely by timestamp bounds (`NotBefore`/`NotAfter`) checked against the issuing CA's own bounds, plus a blocklist keyed on the *exact* certificate fingerprint — there is no mechanism that ties a new certificate's claimed "age" to a proof of legitimate issuance history.

### Finding Description
`CAPool.verify()` in `cert/ca_pool.go` decides trust for a certificate using only:
1. An exact-fingerprint blocklist check (`IsBlocklisted`), and
2. Time-window containment checks in `checkCAConstraints` (`notBefore`/`notAfter` must fall inside the signer's own validity window). [1](#0-0) [2](#0-1) 

Because `AddCA`/`VerifyCertificate` never checks that a certificate was actually issued at (or near) the wall-clock time it claims — only that its `NotBefore`/`NotAfter` fall inside the *signer's* window — a party in possession of a still-trusted CA's signing key (the nebula analog of a "compromised validator set") can mint a brand-new certificate with an arbitrary backdated `NotBefore`, as long as it is within the CA's own lifetime. Blocklisting only stops *specific, already-known* fingerprints (`BlocklistFingerprint`/`IsBlocklisted`); a freshly forged certificate has a new signature and therefore a new fingerprint (`Fingerprint()` hashes the whole cert including the signature), so it trivially bypasses the blocklist that operators would use during an incident response ("mass exit") to shut out a compromised signer's future output. [3](#0-2) [4](#0-3) 

There is no equivalent of a "hash chain proof" (e.g., a certificate-transparency-style log, issuance sequence number, or monotonic counter) that would let a verifier distinguish a certificate legitimately issued before compromise from a certificate forged after compromise but *claiming* to be old. The only backstop is removing the CA entirely from the trust pool on reload (`loadCAPoolFromConfig` / `PKI.reloadCAPool`), which is an all-or-nothing operator action, not a per-certificate integrity guarantee. [5](#0-4) [6](#0-5) 

### Impact Explanation
If a CA's signing key is compromised (the direct nebula analog of "malicious validators"), the operator's typical incident response is to blocklist known-bad fingerprints via `pki.blocklist`. This finding shows that response is incomplete: the compromised key can still be used to sign fresh, previously-unseen host certificates with backdated validity windows that pass `CAPool.verify()` cleanly (correct signature, in-window timestamps, not on the blocklist), and such a certificate will be accepted by `certVerifier()` during a handshake, letting the attacker stand up a fully trusted, authenticated tunnel into the mesh. [7](#0-6) 

### Likelihood Explanation
This requires possession of a trusted CA's private key (a strong precondition, matching the original report's "compromised validators" assumption). Given that precondition, exploitation is trivial and deterministic — signing a new certificate with any timestamp inside the CA's own window is a normal, supported operation of the CA tooling; no protocol-level obstacle exists.

### Recommendation
Do not rely solely on timestamp containment and a static fingerprint blocklist to gate trust during a CA compromise response. Introduce an issuance-chain / transparency mechanism (e.g., a monotonically increasing issuance counter or a signed log the CA must append to) so that verifiers can require proof that a certificate was actually issued before a declared compromise point, rather than trusting a self-declared `NotBefore` value. At minimum, when a CA is suspected compromised, treat *all* certificates signed by that CA fingerprint as blocklisted (a CA-level blocklist keyed on issuer fingerprint) rather than only specific leaf-certificate fingerprints, so newly forged-but-backdated certificates from the same signer are also rejected.

### Proof of Concept
1. Obtain the private key of a currently trusted CA in the pool (compromise scenario, mirrors "malicious validators").
2. Sign a new host certificate `evil` with `NotBefore` set to a date before the compromise was discovered (still within the CA's own `NotBefore`/`NotAfter` bounds) and a network claim inside the CA's permitted ranges.
3. Add the `evil` certificate's fingerprint is *not* on the operator's `pki.blocklist` (it's brand-new, never seen before).
4. Present `evil` during a handshake; `HandshakeManager.certVerifier()` → `CAPool.VerifyCertificate()` → `verify()` passes all checks (signature valid, in-window, not blocklisted), and a trusted tunnel is established despite the CA compromise having been "handled" via blocklisting known-bad fingerprints.

// VerifyCertificate verifies the certificate is valid and is signed by a trusted CA in the pool.
// If the certificate is valid then the returned CachedCertificate can be used in subsequent verification attempts
// to increase performance.
func (ncp *CAPool) VerifyCertificate(now time.Time, c Certificate) (*CachedCertificate, error) {
	if c == nil {
		return nil, fmt.Errorf("no certificate")
	}
	fp, err := c.Fingerprint()
	if err != nil {
		return nil, fmt.Errorf("could not calculate fingerprint to verify: %w", err)
	}

	signer, err := ncp.verify(c, now, fp, "")
	if err != nil {
		return nil, err
	}

	// Pre nebula v1.10.3 could generate signatures in either high or low s form and validation
	// of signatures allowed for either. Nebula v1.10.3 and beyond clamps signature generation to low-s form
	// but validation still allows for either. Since a change in the signature bytes affects the fingerprint, we
	// need to test both forms until such a time comes that we enforce low-s form on signature validation.
	fp2, err := CalculateAlternateFingerprint(c)
	if err != nil {
		return nil, fmt.Errorf("could not calculate alternate fingerprint to verify: %w", err)
	}
	if fp2 != "" && ncp.IsBlocklisted(fp2) {
		return nil, ErrBlockListed
	}

	cc := CachedCertificate{
		Certificate:       c,
		InvertedGroups:    make(map[string]struct{}),
		Fingerprint:       fp,
		fingerprint2:      fp2,
		signerFingerprint: signer.Fingerprint,
	}

	for _, g := range c.Groups() {
		cc.InvertedGroups[g] = struct{}{}
	}

	return &cc, nil
}

func (ncp *CAPool) verify(c Certificate, now time.Time, certFp string, signerFp string) (*CachedCertificate, error) {
	if ncp.IsBlocklisted(certFp) {
		return nil, ErrBlockListed
	}

	signer, err := ncp.GetCAForCert(c)
	if err != nil {
		return nil, err
	}

	if signer.Certificate.Curve() != c.Curve() {
		return nil, ErrCurveMismatch
	}

	if signer.Certificate.Expired(now) {
		return nil, ErrRootExpired
	}

	if c.Expired(now) {
		return nil, ErrExpired
	}

	// If we are checking a cached certificate then we can bail early here
	// Either the root is no longer trusted or everything is fine
	if len(signerFp) > 0 {
		if signerFp != signer.Fingerprint {
			return nil, ErrFingerprintMismatch
		}
		return signer, nil
	}
	if !c.CheckSignature(signer.Certificate.PublicKey()) {
		return nil, ErrSignatureMismatch
	}

	err = CheckCAConstraints(signer.Certificate, c)
	if err != nil {
		return nil, err
	}

	return signer, nil
}

func loadCAPoolFromConfig(l *slog.Logger, c *config.C) (*cert.CAPool, error) {
	caPathOrPEM := c.GetString("pki.ca", "")
	if caPathOrPEM == "" {
		return nil, errors.New("no pki.ca path or PEM data provided")
	}

	var caReader io.ReadCloser
	var err error

	if strings.Contains(caPathOrPEM, "-----BEGIN") {
		caReader = io.NopCloser(strings.NewReader(caPathOrPEM))
	} else {
		caReader, err = os.Open(caPathOrPEM)
		if err != nil {
			return nil, fmt.Errorf("unable to read pki.ca file %s: %s", caPathOrPEM, err)
		}
	}
	defer caReader.Close()

	caPool, err := cert.NewCAPoolFromPEMReader(caReader)
	if errors.Is(err, cert.ErrExpired) {
		var expired int
		for _, crt := range caPool.CAs {
			if crt.Certificate.Expired(time.Now()) {
				expired++
				l.Warn("expired certificate present in CA pool", "cert", crt)
			}
		}

		if expired >= len(caPool.CAs) {
			return nil, errors.New("no valid CA certificates present")
		}

	} else if err != nil {
		return nil, fmt.Errorf("error while adding CA certificate to CA trust store: %s", err)
	}

	bl := c.GetStringSlice("pki.blocklist", []string{})
	if len(bl) > 0 {
		for _, fp := range bl {
			caPool.BlocklistFingerprint(fp)
		}

		l.Info("Blocklisted certificates", "fingerprintCount", len(bl))
	}

	return caPool, nil
}
