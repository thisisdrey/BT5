### Title
Arbitrary file write via unsanitized tar extraction in `untar` (CreateRepositoryFromSnapshot) - ([File: internal/gitaly/service/repository/create_repository_from_snapshot.go])

### Summary
`(*server).untar` streams an HTTP response body directly into a raw `tar -C <path> -xvf -` shell-out with no path or symlink validation, unlike the hardened `extractTarToDirectory` used by `replicate.go`. Any tar entry with `../` traversal or an absolute/symlink path in the served archive is extracted by the system `tar` binary using its own (non-Gitaly) path handling, allowing writes outside the newly created repository directory.

### Finding Description
`CreateRepositoryFromSnapshot` calls `repoutil.Create(...)` with a callback that resolves the target repo path and invokes `s.untar(ctx, path, in)` [1](#0-0) . Inside `untar`, the response body of an HTTP GET to `in.GetHttpUrl()` (optionally resolved via `in.GetResolvedAddress()`, with `in.GetHttpAuth()` sent as the `Authorization` header) is piped as stdin directly into `command.New(ctx, s.logger, []string{"tar", "-C", path, "-xvf", "-"}, command.WithStdin(rsp.Body))` [2](#0-1) . There is no parsing of the tar stream by Gitaly itself to reject path traversal (`../../..`), absolute paths, or symlink/hardlink entries that point outside `path` — the shell-out simply hands the entire trust decision to the system `tar` binary, which by default (GNU tar) will follow relative `../` sequences and write symlink targets wherever instructed, potentially outside `-C path`. This is in stark contrast to `extractTarToDirectory` in `replicate.go`, which explicitly cleans the target directory and checks `strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator))` for every entry type (regular file, symlink, hardlink) before writing [3](#0-2) . The code itself acknowledges this gap: `// NOTE: The received archive is trusted *a lot*. Before pointing this RPC at endpoints not under our control, it should undergo a lot of hardening.` [4](#0-3) . Since `HttpUrl`, `ResolvedAddress`, and `HttpAuth` are all attacker-controllable RPC fields, an attacker who can trigger this RPC and control (or redirect, via SSRF) the HTTP endpoint returning the tar stream fully controls the tar content and thus the extraction targets.

### Impact Explanation
If reached with an attacker-controlled `HttpUrl`, this allows arbitrary file write outside the repository storage root (e.g., planting a symlink or traversal entry to overwrite `/etc/cron.d/*`, another repository's custom hooks, or Gitaly/host configuration files), which can lead to remote code execution or storage-root escape — matching GitLab's "arbitrary file write leading to RCE" bounty impact class.

### Likelihood Explanation
Exploitability strictly depends on whether an unprivileged actor can actually cause Gitaly to fetch from a URL they control. In the normal GitLab product flow, `CreateRepositoryFromSnapshot` is invoked internally by GitLab Rails/Workhorse with a URL generated and signed by GitLab (e.g., project import/export snapshot endpoints), not a raw user-supplied URL — this repo's Gitaly component alone does not enforce that constraint, and the question's own preconditions require "SSRF or a permissive GitLab-side snapshot endpoint" to reach it, which is a caller-side (Rails) trust boundary, not a bug purely within Gitaly. Given the codebase's explicit NOTE acknowledging the RPC is only safe when the endpoint is trusted/controlled by GitLab, the vulnerable code path is real and unguarded, but the attacker capability to supply an arbitrary/attacker-controlled `HttpUrl` is not established as reachable by an "unprivileged attacker" from within the Gitaly RPC surface itself — it depends on an unverified assumption about a permissive or SSRF-vulnerable Rails-side endpoint outside this repository's scope.

### Recommendation
Replace the raw `tar -C path -xvf -` shell-out in `untar` with a hardened extraction routine equivalent to `extractTarToDirectory` (path containment checks, symlink/hardlink target validation, absolute-path rejection) applied to the HTTP response stream before/instead of invoking the system `tar` binary; alternatively, restrict `CreateRepositoryFromSnapshot` to only accept URLs pre-validated/signed by trusted internal callers.

func TestUntar_PathTraversalEscapesRepoDir(t *testing.T) {
    // Build a malicious tar with an entry "../../../../tmp/evil-escape-marker"
    var buf bytes.Buffer
    tw := tar.NewWriter(&buf)
    content := []byte("pwned")
    require.NoError(t, tw.WriteHeader(&tar.Header{
        Name: "../../../../tmp/evil-escape-marker",
        Mode: 0o644,
        Size: int64(len(content)),
    }))
    _, err := tw.Write(content)
    require.NoError(t, err)
    require.NoError(t, tw.Close())

    srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        w.Write(buf.Bytes())
    }))
    defer srv.Close()

    repoPath := testhelper.TempDir(t) // simulated new repo dir
    req := &gitalypb.CreateRepositoryFromSnapshotRequest{HttpUrl: srv.URL}

    err = server.untar(ctx, repoPath, req)
    require.NoError(t, err)

    // Assert the file escaped to /tmp/evil-escape-marker instead of staying under repoPath.
    _, statErr := os.Stat("/tmp/evil-escape-marker")
    require.NoError(t, statErr, "expected path traversal to escape repository directory")
}

func (s *server) untar(ctx context.Context, path string, in *gitalypb.CreateRepositoryFromSnapshotRequest) error {
	req, err := http.NewRequestWithContext(ctx, "GET", in.GetHttpUrl(), nil)
	if err != nil {
		return structerr.NewInvalidArgument("Bad HTTP URL: %w", err)
	}

	client := httpClient
	if resolvedAddress := in.GetResolvedAddress(); resolvedAddress != "" {
		client, err = newResolvedHTTPClient(in.GetHttpUrl(), resolvedAddress)
		if err != nil {
			return structerr.NewInvalidArgument("creating resolved HTTP client: %w", err)
		}
	}

	if in.GetHttpAuth() != "" {
		req.Header.Set("Authorization", in.GetHttpAuth())
	}

	rsp, err := client.Do(req)
	if err != nil {
		return structerr.NewInternal("HTTP request failed: %w", err)
	}
	defer rsp.Body.Close()

	if rsp.StatusCode < http.StatusOK || rsp.StatusCode >= http.StatusMultipleChoices {
		return structerr.NewInternal("HTTP server: %s", rsp.Status)
	}

	cmd, err := command.New(ctx, s.logger, []string{"tar", "-C", path, "-xvf", "-"}, command.WithStdin(rsp.Body))
	if err != nil {
		return err
	}

	return cmd.Wait()

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}

			// Remove existing file/symlink if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for symlink %s: %w", targetPath, err)
			}

			if err := os.Symlink(header.Linkname, targetPath); err != nil {
				return fmt.Errorf("creating symlink %s -> %s: %w", targetPath, header.Linkname, err)
			}

		case tar.TypeLink:
			linkTarget := filepath.Join(targetDir, header.Linkname)

			if !strings.HasPrefix(linkTarget, targetDir+string(os.PathSeparator)) &&
				linkTarget != targetDir {
				return fmt.Errorf("invalid hard link target: %s", header.Linkname)
			}

			// Remove existing file if it exists
			if err := os.Remove(targetPath); err != nil && !os.IsNotExist(err) {
				return fmt.Errorf("removing existing file for hard link %s: %w", targetPath, err)
			}

			if err := os.Link(linkTarget, targetPath); err != nil {
				return fmt.Errorf("creating hard link %s -> %s: %w", targetPath, linkTarget, err)
			}

		default:
			// Skip unsupported file types (devices, FIFOs, etc.)
			s.logger.WithField("file", header.Name).WithField("type", header.Typeflag).
				WarnContext(ctx, "skipping unsupported file type in tar archive")
		}

		if header.Typeflag == tar.TypeReg || header.Typeflag == tar.TypeDir {
			if err := os.Chmod(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("setting permissions for %s: %w", targetPath, err)
			}
		}
	}

	return nil
}
