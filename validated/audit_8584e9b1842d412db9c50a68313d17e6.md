### Title
StackerDB sync's `connect_try_finish` accepts `StackerDBHandshakeAccept` replies without verifying the responder's public-key hash matches the expected replica's `NeighborAddress` - ([File: stackslib/src/net/stackerdb/sync.rs])

### Summary
`StackerDBSync::connect_try_finish` treats a peer as a legitimate, connected StackerDB replica as soon as it receives a `StackerDBHandshakeAccept` with a matching `rc_consensus_hash` and a matching smart-contract ID, but it never checks that the responder's actual public key hashes to the `public_key_hash` recorded in the `NeighborAddress` (`naddr`) that was dialed. The general neighbor-walk protocol enforces exactly this equality via `check_handshake_pubkey_hash` before trusting a handshake response, but the StackerDB-sync connect path has no equivalent check.

### Finding Description
`StackerDBSync::connect_begin` populates `self.replicas` from `find_qualified_replicas` (peers known via `PeerDB`) and from `StackerDBConfig::hint_replicas`, both represented as `NeighborAddress { addrbytes, port, public_key_hash }`, then calls `self.comms.neighbor_session_begin(network, &naddr)` to connect and send a `Handshake`: [1](#0-0) 

Later, `connect_try_finish` iterates the collected replies keyed by `naddr` and, on receiving a `StackerDBHandshakeAccept`, only checks that:
1. `db_data.rc_consensus_hash` equals the local chain view's `rc_consensus_hash`, and
2. the announced `smart_contracts` list contains `self.smart_contract_id`,

before inserting `naddr` into `self.connected_replicas`: [2](#0-1) 

No step verifies that the actual `node_public_key` in the `HandshakeAcceptData`/`StackerDBHandshakeData` hashes to `naddr.public_key_hash`. Contrast this with the general neighbor-walk protocol, which explicitly performs this equality check before accepting a handshake response from a "neighbor of a neighbor" or a pingback target: [3](#0-2) 
and calls it in the pingback-finish path: [4](#0-3) 

The connection-establishment helper `neighbor_session_begin_only` (used by `neighbor_session_begin`) does call `network.can_register_peer_with_pubkey(&nk, true, neighbor_pubkh)`, but this only governs *whether an event slot may be (re)used for that address/pubkey pair* to avoid duplicate registrations — it is checked before the handshake round-trip completes, and it does not re-validate the pubkey against the peer's actual signed handshake response once it arrives: [5](#0-4) 

`ConversationP2P::validate_handshake` (used generically for any inbound `Handshake`) only checks that, for outbound connections where a public key is *already* known, the self-reported address matches; it does not tie the newly-presented public key back to any externally-expected `public_key_hash` for the destination the StackerDB sync machine dialed: [6](#0-5) 

As a result, the equality "responder's actual pubkey hash == the pubkey hash promised by the `NeighborAddress` that was targeted" — enforced for general peer discovery — is not enforced for StackerDB replica session establishment. Because `hint_replicas` addresses/pubkey-hashes are themselves attacker-influenced contract data (see `StackerDBConfig::eval_hint_replicas`, which imposes only IP-format/port-range sanity checks, not any binding to an actual reachable key holder): [7](#0-6) 
a network-position attacker who can respond on a targeted `(addr, port)` (e.g., by IP/route hijack, or by simply being the address named in a maliciously-crafted StackerDB contract that a victim node is later told to sync with) is treated as a fully "connected" and pinned StackerDB replica without ever proving possession of the specific private key the local peer expected for that neighbor address.

### Impact Explanation
Once accepted as a "connected replica," the attacker's address is inserted into `connected_replicas`/`replicas` and its connection is pinned (kept alive, preferentially reused) by the sync state machine. It will be queried for chunk inventories/chunks and used to drive `StackerDBSyncResult`s that are then merged into the sync process. Actual chunk writes are still gated by per-slot signer verification (`validate_received_chunk`/`try_replace_chunk`), so the attacker cannot directly forge signed chunk contents. However, this identity-verification gap lets an attacker occupy a "trusted" StackerDB replica slot under a spoofed/false identity, steering the node's StackerDB inventory/sync traffic toward an attacker-controlled endpoint, and lets that endpoint serve stale/omitted/false-negative inventories, wasting sync cycles and connections and denying legitimate replication (bounded DoS on the StackerDB replication subsystem), consistent with the "High: steering a node off the tip via false inventory" category referenced in scope.

### Likelihood Explanation
This requires only the ability to answer (or intercept) connections on the address the StackerDB sync machine is currently trying to reach — via published `hint_replicas` in a StackerDB control contract (attacker-controlled, permissionless deploy), or via network-level address spoofing/hijack for peer-DB-discovered replicas. No node secret, signer key, or privileged role is required to *pass* this specific check; only network reachability and knowledge of the target `rc_consensus_hash` and configured `smart_contract_id`, both of which are public.

### Recommendation
In `StackerDBSync::connect_try_finish`, after receiving a `StackerDBHandshakeAccept`/`HandshakeAcceptData`, verify that `Hash160::from_node_public_key_buffer(&data.handshake.node_public_key) == naddr.public_key_hash` (mirroring `NeighborWalk::check_handshake_pubkey_hash`) before inserting the peer into `connected_replicas`. Reject and drop the connection (treat like a NACK/protocol violation) on mismatch.

### Proof of Concept
1. Deploy (or otherwise cause a node to load) a StackerDB-controlling contract whose `hint-replicas` list names an attacker-controlled `(addr, port)` with an arbitrary `public-key-hash` value B, for a `smart_contract_id` the victim node also replicates.
2. Run a listener at `(addr, port)` that performs the Stacks p2p handshake using an arbitrary keypair A (any key, not matching B), and reply to the incoming `Handshake` with a `StackerDBHandshakeAccept` whose `rc_consensus_hash` matches the victim's current view and whose `smart_contracts` list includes the target contract ID.
3. Observe that `StackerDBSync::connect_try_finish` accepts this peer into `connected_replicas` (per the logic at `stackslib/src/net/stackerdb/sync.rs:804-880`) despite the responding key A never matching the promised hash B in `naddr.public_key_hash`, whereas an equivalent scenario driven through the general neighbor-walk `pingback_handshakes_try_finish`/`neighbor_handshakes_try_finish` paths would be rejected by `check_handshake_pubkey_hash`.

    pub fn connect_try_finish(&mut self, network: &mut PeerNetwork) -> Result<bool, net_error> {
        for (naddr, message) in self.comms.collect_replies(network).into_iter() {
            let data = match message.payload {
                StacksMessageType::StackerDBHandshakeAccept(_, db_data) => {
                    if network.get_chain_view().rc_consensus_hash != db_data.rc_consensus_hash {
                        // stale or inconsistent view. Do not proceed
                        debug!(
                            "{:?}: {}: remote peer {:?} has stale view ({} != {})",
                            network.get_local_peer(),
                            &self.smart_contract_id,
                            &naddr,
                            &network.get_chain_view().rc_consensus_hash,
                            &db_data.rc_consensus_hash
                        );
                        // don't unpin, since it's usually transient
                        self.connected_replicas.remove(&naddr);
                        continue;
                    }
                    db_data
                }
                StacksMessageType::Nack(data) => {
                    debug!(
                        "{:?}: {}: remote peer {:?} NACK'ed our StackerDBHandshake with code {}",
                        &network.get_local_peer(),
                        &self.smart_contract_id,
                        &naddr,
                        data.error_code
                    );
                    if data.error_code == NackErrorCodes::StaleView
                        || data.error_code == NackErrorCodes::FutureView
                    {
                        self.connected_replicas.remove(&naddr);
                        self.stale_neighbors.insert(naddr);
                    } else {
                        self.unpin_connected_replica(network, &naddr);
                    }
                    continue;
                }
                x => {
                    info!(
                        "{:?}: {}: Received unexpected message {:?}",
                        &network.get_local_peer(),
                        &self.smart_contract_id,
                        &x
                    );
                    continue;
                }
            };

            if data
                .smart_contracts
                .iter()
                .find(|db_id| *db_id == &self.smart_contract_id)
                .is_none()
            {
                debug!(
                    "{:?}: {}: remote peer does not replicate",
                    network.get_local_peer(),
                    &self.smart_contract_id
                );

                // disconnect
                self.unpin_connected_replica(network, &naddr);
                continue;
            }

            debug!(

                network.get_local_peer(),
                &self.smart_contract_id,
                &naddr,
                &data
            );

            // this neighbor is good
            self.connected_replicas.insert(naddr);

            );

        }

        true
    }

    fn neighbor_session_begin_only<NK: ToNeighborKey>(
        &mut self,
        network: &mut PeerNetwork,
        neighbor_addr: &NK,
        neighbor_pubkh: &Hash160,
    ) -> Result<Option<ReplyHandleP2P>, net_error> {
        let nk = neighbor_addr.to_neighbor_key(network);
        match network.can_register_peer_with_pubkey(&nk, true, neighbor_pubkh) {
            Ok(_) => self.neighbor_connect_and_handshake(network, &nk),
            Err(net_error::AlreadyConnected(event_id, handshake_nk)) => {
                // already connected, but on a possibly-different address.
                // If the already-connected handle is inbound,
                // then try to connect to this address anyway in
                // order to maximize our outbound connections we have.
                if let Some(convo) = network.get_p2p_convo(event_id) {
                    if !convo.is_outbound() {
                        test_debug!("{:?}: Already connected to {:?} on inbound event {} (address {:?}). Try to establish outbound connection to {:?} {:?}.",
                               network.get_local_peer(), &nk, &event_id, &handshake_nk, neighbor_pubkh, &nk);

                        self.remove_connecting(network, &nk);
                        return self.neighbor_handshake(network, &nk).map(Some);
                    }
                    test_debug!(
                        "{:?}: Already connected to {:?} on event {} (address: {:?})",
                        network.get_local_peer(),
                        &nk,
                        &event_id,
                        &handshake_nk
                    );
                    self.remove_connecting(network, &handshake_nk);
                    let handle = self.neighbor_handshake(network, &handshake_nk)?;
                    return Ok(Some(handle));
                }

                // should never be reachable
                error!(
                    "AlreadyConnected error on event {} has no conversation",
                    event_id
                );
                return Err(net_error::PeerNotConnected(format!(
                    "Already connected to {nk} as {handshake_nk} on event {event_id}",
                )));
            }
            Err(e) => {
                test_debug!(
                    "{:?}: Failed to check connection to {:?}: {:?}. No handshake sent.",
                    network.get_local_peer(),
                    &nk,
                    &e
                );
                return Err(e);
            }
        }
    }

    fn validate_handshake(
        &mut self,
        local_peer: &LocalPeer,
        chain_view: &BurnchainView,
        message: &mut StacksMessage,
    ) -> Result<(), net_error> {
        let handshake_data = match message.payload {
            StacksMessageType::Handshake(ref mut data) => data.clone(),
            _ => panic!("Message is not a handshake"),
        };

        match self.connection.get_public_key() {
            None => {
                // if we don't yet have a public key for this node, verify the message.
                // if it's improperly signed, it's probably a poorly-timed re-key request (but either way the message should be rejected)
                message
                    .verify_secp256k1(&handshake_data.node_public_key)
                    .map_err(|_e| {
                        debug!(
                            "{:?}: invalid handshake: not signed with given public key",
                            &self
                        );
                        net_error::InvalidMessage
                    })?;
            }
            Some(_) => {
                // for outbound connections, the self-reported address must match socket address if we already have a public key.
                // (not the case for inbound connections, since the peer socket address we see may
                // not be the same as the address the remote peer thinks it has).
                // The only exception to this is if the remote peer does not yet know its own
                // public IP address, in which case, its handshake addrbytes will be the
                // any-network bind address (0.0.0.0 or ::)
                if self.stats.outbound
                    && (!handshake_data.addrbytes.is_anynet()
                        && (self.peer_addrbytes != handshake_data.addrbytes
                            || self.peer_port != handshake_data.port))
                {
                    // wrong peer address
                    debug!(
                        "{:?}: invalid handshake -- wrong addr/port ({:?}:{:?})",
                        &self, &handshake_data.addrbytes, handshake_data.port
                    );
                    return Err(net_error::InvalidHandshake);
                }
            }
        };

    /// Evaluate contract-given hint-replicas
    fn eval_hint_replicas(
        contract_id: &QualifiedContractIdentifier,
        hint_replicas_list: Vec<ClarityValue>,
    ) -> Result<Vec<NeighborAddress>, NetError> {
        let mut hint_replicas = vec![];
        for hint_replica_value in hint_replicas_list.into_iter() {
            let hint_replica_data = hint_replica_value.expect_tuple()?;

            let addr_byte_list = hint_replica_data
                .get("addr")
                .expect("FATAL: missing 'addr'")
                .clone()
                .expect_list()?;
            let port = hint_replica_data
                .get("port")
                .expect("FATAL: missing 'port'")
                .clone()
                .expect_u128()?;
            let pubkey_hash_bytes = hint_replica_data
                .get("public-key-hash")
                .expect("FATAL: missing 'public-key-hash")
                .clone()
                .expect_buff_padded(20, 0)?;

            let mut addr_bytes = vec![];
            for byte_val in addr_byte_list.into_iter() {
                let byte = byte_val.expect_u128()?;
                if byte > (u8::MAX as u128) {
                    let reason = format!(
                        "Contract {} stipulates an addr byte above u8::MAX",
                        contract_id
                    );
                    warn!("{}", &reason);
                    return Err(NetError::InvalidStackerDBContract(
                        contract_id.clone(),
                        reason,
                    ));
                }
                addr_bytes.push(byte as u8);
            }
            if addr_bytes.len() != 16 {
                let reason = format!(
                    "Contract {} did not stipulate a full 16-octet IP address",
                    contract_id
                );
                warn!("{}", &reason);
                return Err(NetError::InvalidStackerDBContract(
                    contract_id.clone(),
                    reason,
                ));
            }

            if port < 1024 || port > u128::from(u16::MAX - 1) {
                let reason = format!(
                    "Contract {} stipulates a port lower than 1024 or above u16::MAX - 1",
                    contract_id
                );
                warn!("{}", &reason);
                return Err(NetError::InvalidStackerDBContract(
                    contract_id.clone(),
                    reason,
                ));
            }
            // NOTE: port is now known to be in range [1024, 65535]

            let pubkey_hash_slice: &[u8; 20] = pubkey_hash_bytes
                .get(0..20)
                .and_then(|bytes| bytes.try_into().ok())
                .ok_or_else(|| {
                    let reason = format!("{contract_id} stipulates pubkey hash bytes length < 20");
                    warn!("{reason}");
                    NetError::InvalidStackerDBContract(contract_id.clone(), reason)
                })?;

            let peer_addr = PeerAddress::from_slice(&addr_bytes).expect("FATAL: not 16 bytes");
            if peer_addr.is_in_private_range() {
                debug!(
                    "Ignoring private IP address '{}' in hint-replicas",
                    &peer_addr.to_socketaddr(port as u16)
                );
                continue;
            }

            let naddr = NeighborAddress {
                addrbytes: peer_addr,
                port: port as u16,
                public_key_hash: Hash160(*pubkey_hash_slice),
            };
            hint_replicas.push(naddr);
        }
        Ok(hint_replicas)
