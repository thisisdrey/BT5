### Title
No exploitable vulnerability - roaming trust is intentionally decoupled from firewall policy

### Summary
`handleHostRoaming` is called strictly after `ConnectionState.Decrypt` succeeds (an AEAD-authenticated operation using the session key established via the certificate-authenticated Noise handshake), not after the firewall check. This is documented intended behavior, not a scoping gap, because roaming trust is defined by "who could produce a validly-decryptable packet," while the firewall governs whether the decapsulated tunnel traffic may reach the TUN device — two orthogonal trust boundaries.

### Finding Description
In `outside.go`, `readOutsidePackets` decrypts the packet at [1](#0-0)  before calling `f.handleHostRoaming(hostinfo, via)` at [2](#0-1) , and only afterward dispatches to `handleOutsideMessagePacket`, which applies firewall policy. `handleHostRoaming` itself gates the address update on the lighthouse remote allow-list and a roam-suppression window, but does not (and, by design, should not) depend on downstream firewall verdicts [3](#0-2) .

The premise that an attacker can trigger this "without keys" by merely spoofing the UDP source address of an "in-flight packet" requires that packet to already be an AEAD-authenticated ciphertext produced by the legitimate remote peer's session key (`hostinfo.ConnectionState.dKey`), since `Decrypt` will fail and return early otherwise [1](#0-0) . An attacker without the session key (established only through a certificate-authenticated Noise handshake) cannot forge such a packet. The only way to "spoof the source address of an in-flight packet" is to be positioned on-path to intercept a genuine ciphertext and re-emit it with a different source IP/port — a capability that already lets an on-path attacker do everything a roam would allow (i.e., receive/observe traffic at that vantage point), and is exactly the scenario the roaming feature is designed to tolerate, since decrypt success is nebula's chosen authenticity proof for "this is the real peer, possibly on a new address."

Whether the payload is later dropped by the firewall is irrelevant to this trust decision: the firewall protects the tun/application layer (which IP:port flows are allowed to pass), not the UDP transport-layer address book. There is no invariant in the codebase or documented design stating that roaming should also require a firewall "Allow" — the comment "`// Roam before we respond`" at [4](#0-3)  confirms this is an intentional ordering choice.

### Impact Explanation
None. No authentication bypass, no forgery, and no state poisoning by an unprivileged attacker occurs: an attacker without the session key cannot produce a packet that survives `Decrypt`, and an attacker who can capture/replay a genuine ciphertext with a spoofed source is already an on-path attacker whose capabilities exceed what this "poisoning" would add.

### Likelihood Explanation
Not applicable — the described precondition (possessing a decryptable-but-firewall-dropped packet from the real peer to relay with a spoofed source) is not achievable by an unprivileged remote attacker per the stated threat model (no keys, no host access, no on-path/MITM assumed).

### Recommendation
No change required. If desired for defense-in-depth, roaming could optionally be gated on the firewall verdict as well, but this is a design/policy choice, not a security fix for an exploitable bug.

### Proof of Concept
Not applicable — no PoC can be constructed by an unprivileged attacker without possession of the peer's session key, which the audit rules exclude (no leaked keys, no compromised peer).

func (f *Interface) handleHostRoaming(hostinfo *HostInfo, via ViaSender) {
	curRemote := hostinfo.GetRemote()
	if !via.IsRelayed && curRemote != via.UdpAddr {
		if !f.lightHouse.GetRemoteAllowList().AllowAll(hostinfo.vpnAddrs, via.UdpAddr.Addr()) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("lighthouse.remote_allow_list denied roaming", "newAddr", via.UdpAddr)
			}
			return
		}

		if !hostinfo.lastRoam.IsZero() && via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < RoamingSuppressSeconds*time.Second {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("Suppressing roam back to previous remote",
					"suppressSeconds", RoamingSuppressSeconds,
					"udpAddr", curRemote,
					"newAddr", via.UdpAddr,
				)
			}
			return
		}

		hostinfo.logger(f.l).Info("Host roamed to new udp ip/port.",
			"udpAddr", curRemote,
			"newAddr", via.UdpAddr,
		)
		hostinfo.lastRoam = time.Now()
		hostinfo.lastRoamRemote = curRemote
		hostinfo.SetRemote(via.UdpAddr)
	}

}
