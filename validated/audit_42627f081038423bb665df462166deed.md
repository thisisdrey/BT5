### Title
Permanent DoS of `vesting::distribute()` via a single shareholder's blocked beneficiary address — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`vesting::distribute()` iterates over every shareholder in a `for_each_ref` closure and calls `aptos_account::deposit_coins(recipient_address, share_of_coins)` for each one without any error isolation. If any single recipient causes `deposit_coins` to abort, the entire transaction reverts and the function becomes permanently un-callable, freezing all shareholders' vested APT inside the contract forever.

---

### Finding Description

`vesting::distribute()` withdraws all unlocked stake from the underlying staking pool and then distributes it to every shareholder in a single atomic loop: [1](#0-0) 

```move
shareholders.for_each_ref(|shareholder| {
    let shareholder = *shareholder;
    let shares = pool_u64::shares(grant_pool, shareholder);
    let amount = pool_u64::shares_to_amount_with_total_coins(...);
    let share_of_coins = coin::extract(&mut coins, amount);
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);
});
```

`aptos_account::deposit_coins` aborts under two reachable conditions:

1. **Recipient account exists but is not registered for `AptosCoin` AND `allow_arbitrary_coin_transfers = false`** — the `assert!(can_receive_direct_coin_transfers(to), ...)` fires.
2. **Recipient's `CoinStore<AptosCoin>` is frozen** — `coin::deposit` aborts. [2](#0-1) 

Condition 1 is reachable without any privileged action: any account can call `set_allow_direct_coin_transfers(self, false)` on itself. If a shareholder (or their admin-assigned beneficiary) has not yet registered for `AptosCoin` and has set this flag to `false`, every future call to `distribute()` will abort at that shareholder's iteration.

Because Move's abort semantics roll back all state changes atomically, the coins are returned to the stake pool on each failed call — but the same abort fires on every subsequent attempt. The vesting contract is permanently wedged.

The same structural flaw exists in `staking_contract::distribute_internal()`, which iterates over its distribution pool recipients in a `while` loop and calls `aptos_account::deposit_coins` for each one without error isolation: [3](#0-2) 

---

### Impact Explanation

- **All shareholders permanently lose access to their vested APT.** Every call to `distribute()` reverts; the coins remain locked in the stake pool indefinitely.
- **`terminate_vesting_contract` is also blocked**, because it calls `distribute()` first before setting the contract state to terminated. [4](#0-3) 

- **`admin_withdraw` is unreachable**, because it requires the contract to be in `VESTING_POOL_TERMINATED` state, which can never be set.
- This constitutes **permanent freezing of user-controlled on-chain APT assets**, which is within the allowed impact scope.

---

### Likelihood Explanation

- Any shareholder whose account has not registered for `AptosCoin` can call `set_allow_direct_coin_transfers(self, false)` (an unprivileged, permissionless transaction) to trigger the DoS.
- Resource accounts used as shareholder addresses are a realistic scenario where APT may not be pre-registered.
- The admin can also inadvertently set a beneficiary to a problematic address via `set_beneficiary()`.
- Once triggered, the condition is permanent and self-reinforcing — there is no recovery path. [5](#0-4) 

---

### Recommendation

Replace the atomic `for_each_ref` loop with a pattern that isolates per-recipient failures:

1. **Skip-and-accumulate**: If `deposit_coins` would abort for a recipient, skip that recipient and accumulate their share in a separate "failed distributions" map that can be retried individually.
2. **Pre-validate recipients**: Before entering the distribution loop, check `can_receive_direct_coin_transfers` and frozen status for each recipient; abort early with a clear error rather than mid-loop.
3. **Per-recipient withdrawal**: Allow each shareholder to pull their own share individually (pull-over-push pattern), eliminating the shared-loop failure mode entirely.

The same fix should be applied to `staking_contract::distribute_internal()`.

---

### Proof of Concept

```
1. Admin creates a vesting contract with shareholders [Alice, Bob].
2. Bob calls set_allow_direct_coin_transfers(bob_account, false)
   and has not registered for AptosCoin.
3. After the lockup expires, anyone calls distribute(contract_address).
4. The loop reaches Bob's iteration:
     aptos_account::deposit_coins(bob_address, bob_share)
     → can_receive_direct_coin_transfers(bob_address) == false
     → abort(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
5. The entire transaction reverts. Alice receives nothing.
6. Every subsequent call to distribute() produces the same abort.
7. terminate_vesting_contract() also aborts (calls distribute() internally).
8. Alice's vested APT is permanently frozen in the stake pool.
``` [6](#0-5) [7](#0-6)

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

        emit(
            Terminate {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
            },
        );
    }
