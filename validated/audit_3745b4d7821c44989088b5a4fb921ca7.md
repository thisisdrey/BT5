Based on the code review: `Interface.rejectOutside` (inside.go:105) is invoked only after `f.firewall.Drop(*fwPacket, true, hostinfo, f.pki.GetCAPool(), localCache)` returns a non-nil `dropReason` in `handleOutsideMessagePacket` (outside.go:502-514). The `firewall.Drop` function applies the exact same rule pipeline — CA/cert checks, `f.routableNetworks.Contains(fp.LocalAddr)`, conntrack lookup, and `table.match(...)` — regardless of whether `fp.LocalAddr`/`fp.RemoteAddr` correspond to an overlay peer or to a configured unsafe_route destination.

The `NetworkTypeUnsafe` branch in `Firewall.Drop` explicitly falls through with "nothing special" treatment, meaning unsafe-route remote addresses receive identical rule evaluation as VPN addresses.
<cite repo="Kohvert/nebula--005" path="firewall.go" start="439="446" />

This is confirmed by the existing test `TestFirewall_Drop_EnforceIPMatch/allow_inbound_unsafe_route`, which shows a packet destined to an unsafe route (`LocalAddr = 192.168.0.3` in an `unsafeNetworks` prefix) is bounced with `ErrNoMatchingRule` when no rule permits it, and is only allowed after a matching firewall rule targeting that local CIDR is explicitly added — i.e., the same `table.match` firewall rule enforcement applies to unsafe-route traffic as to overlay traffic. [1](#0-0) 

Only when `Drop` returns a non-nil error does the code call `f.rejectOutside`, which itself performs no route-specific logic — it simply builds and sends a reject packet. [2](#0-1) [3](#0-2) 

No divergence in rule evaluation between unsafe_route-destined traffic and overlay-local traffic exists in this path, so the stated invariant (identical firewall evaluation) holds and there is no exploitable firewall bypass here.

func (f *Interface) rejectOutside(packet []byte, ci *ConnectionState, hostinfo *HostInfo, nb, out []byte, q int) {
	if !f.firewall.InboundSendReject {
		return
	}

	out = iputil.CreateRejectPacket(packet, out)
	if len(out) == 0 {
		return
	}

	if len(out) > iputil.MaxRejectPacketSize {
		if f.l.Enabled(context.Background(), slog.LevelInfo) {
			f.l.Info("rejectOutside: packet too big, not sending",
				"packet", packet,
				"outPacket", out,
			)
		}
		return
	}

	f.sendNoMetrics(header.Message, 0, ci, hostinfo, netip.AddrPort{}, out, nb, packet, q)
}
