### Title
Unauthenticated `/shutdown` HTTP endpoint allows single-message DoS of the signer event pipeline - (File: libsigner/src/events.rs)

### Summary
The `SignerEventReceiver::next_event` handler in `libsigner/src/events.rs` matches on the URL `/shutdown` and unconditionally stores `true` into `stop_signal` with no authentication, source-IP check, or secret verification. Any remote party able to reach the signer's bound event-listener port can terminate the entire event-receiving main loop with a single unauthenticated HTTP POST.

### Finding Description
The broken equality is: "a request whose URL happens to be `/shutdown`" is treated as equivalent to "a request from an authorized shutdown initiator." In `next_event`, the dispatch logic is: [1](#0-0) 

This branch is reached identically to the legitimate `SignerStopSignaler::send` path, which itself just opens a plain `TcpStream` and issues `POST /shutdown` with no credentials: [2](#0-1) 

There is no secret, token, HMAC, or peer-address allow-list check anywhere in `next_event` before the `/shutdown` branch is taken — the only gating in the function is on HTTP method and URL string, e.g. the `/status` and other routes get the same unauthenticated treatment: [3](#0-2) 

Once `stop_signal` is set, `is_stopped()` becomes true: [4](#0-3) 

and the next call to `next_event` returns `Err(EventError::Terminated)` immediately (checked at the very top of the function body), causing `main_loop` to exit and cease processing all further signer events (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`).

The socket is bound via `SignerEventReceiver::bind`, which calls `HttpServer::http(listener)` on whatever `SocketAddr` is configured for the signer's event endpoint: [5](#0-4) 

The intended model is that only the local co-located `stacks-node` posts events to this endpoint, but the code contains no mechanism (bind to loopback only, shared secret, mTLS, allow-list) enforcing that assumption — it is purely a deployment/firewall convention. If the configured `endpoint` is reachable from the network (e.g., bound to `0.0.0.0` or a routable interface, which is a valid and common operator configuration since `bind` accepts any `SocketAddr`), any remote unprivileged party can hit it.

### Impact Explanation
A single unauthenticated `POST /shutdown` terminates the signer's event receiver main loop, which is the sole channel through which the signer process learns about StackerDB chunks, burn blocks, new blocks, and block-validation responses. This is a Critical-severity, single-message, unauthenticated DoS of the signer's entire event pipeline, effectively blinding the signer node until it is manually restarted. It is trivially repeatable — the attacker can re-send the same request after every restart. This matches the specified Critical category: "remote crash/unauthenticated DoS from few messages."

### Likelihood Explanation
Preconditions: the attacker only needs network reachability to the signer's configured event-listener port; no secret, peer key, or StackerDB slot ownership is required. Attacker cost is a single raw TCP connection issuing a well-formed HTTP POST — no cryptographic work, no privileged role. Whether this is exploitable in a given deployment depends on whether the operator has bound/exposed the endpoint beyond loopback/local network, which is a configuration choice rather than something enforced by the code; the code itself provides no protection regardless of exposure.

### Recommendation
Add authentication to the `/shutdown` route (and ideally to all mutating routes) in `next_event`, such as requiring a shared secret/bearer token configured out-of-band between the co-located node and signer, or restrict `bind` to loopback-only by default with an explicit opt-in warning for non-loopback binding. At minimum, verify the request originates from an allow-listed local address before honoring `/shutdown`.

### Proof of Concept

```rust
// libsigner/src/tests/shutdown_dos.rs (conceptual)
#[test]
fn unauthenticated_shutdown_terminates_receiver() {
    let mut receiver: SignerEventReceiver<StacksBlockEvent> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Attacker: plain socket, no auth, no prior handshake
    let mut stream = TcpStream::connect(bound).unwrap();
    let body = "attacker shutdown";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        bound, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Server processes the request
    let _ = receiver.next_event(); // returns Err(EventError::Terminated)

    assert!(receiver.is_stopped()); // stop_signal now true from unauthenticated request
}
```
