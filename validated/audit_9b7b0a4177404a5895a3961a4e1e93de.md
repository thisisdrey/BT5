### Title
Permissionless `initialize` lets anyone front-run deployment and seize governorship plus oracle control - ([File: contracts/PoolRegistry.sol](contracts/PoolRegistry.sol))

### Summary
`PoolRegistry.initialize` (and the same pattern in `Pool`, `DebtToken`, `DepositToken`, `SyntheticToken`, `Treasury`, `FeeProvider`, `RewardsDistributor`, `SmartFarmingManager`, `AMO`) is an external function gated only by OZ's `initializer` modifier, with no caller restriction. Whoever calls it first becomes `governor` via `__Governable_init()` and sets `masterOracle` and `feeCollector`. If the proxy is deployed and initialized in separate transactions (the deployment flow described in the analogous RocketPool report), an attacker monitoring the mempool can front-run the legitimate `initialize` call and take full ownership of the registry. All subsequent privileged setters (`updateMasterOracle`, `registerPool`, `updateSwapper`, `updateOperator`, `addGuardian`, `pause`/`shutdown`) are gated solely by `onlyGovernor`, which the attacker now satisfies.

### Finding Description
- `PoolRegistry.initialize(masterOracle_, feeCollector_)` is `external initializer` with no `onlyGovernor`/guardian check: [PoolRegistry.sol:83-93](contracts/PoolRegistry.sol#L83-L93).
- Inside it, `__Pauseable_init()` → `__Governable_init()` sets `governor = _msgSender()`, i.e., the caller: [Governable.sol:49-53](contracts/access/Governable.sol#L49-L53).
- `masterOracle` is attacker-controlled input; `feeCollector` likewise.
- Every config setter is `onlyGovernor`: `updateMasterOracle` (L196), `registerPool` (L137), `updateSwapper` (L218), `updateNativeTokenGateway` (L207), `addGuardian` (L159), plus `pause`/`shutdown`/`open` in `Pauseable` (L97-L122).
- Same uninitialized-window pattern exists in `SyntheticToken.initialize` (sets `_poolRegistry`, [SyntheticToken.sol:129-146](contracts/SyntheticToken.sol#L129-L146)) and `AMO.initialize` ([AMO.sol:57-61](contracts/AMO.sol#L57-L61)). An attacker-supplied `_poolRegistry` that returns `true` from `isPoolRegistered(attacker)` would defeat `onlyIfCanMint`/`onlyIfCanSeize`, allowing unlimited minting.

### Impact Explanation
An attacker who wins the initialization race obtains `governor` on the core registry and points `masterOracle` at a malicious oracle. With arbitrary prices, they can borrow against worthless collateral, swap synths at manipulated rates, and liquidate honest positions — direct theft of user funds and protocol insolvency. They can also `registerPool` for a malicious pool, replace `swapper`/`operator`, add themselves as guardian, and `shutdown()` the system for permanent freezing of funds. For token contracts, hijacking `_poolRegistry` grants unbounded mint/seize power.

### Likelihood Explanation
Requires a deployment window where the proxy exists uninitialized — exactly the multi-transaction bootstrap scenario in the reference report. It is fully capturable by an unprivileged EOA front-running the deployer's `initialize` transaction in the public mempool; no privileged role is needed. Once the legitimate initializer lands first, the window closes (`initializer` is one-shot), so on already-initialized deployments this is not exploitable — likelihood is confined to each contract's deployment/bootstrap phase (including future pool/synthetic deployments, which are frequent).

### Recommendation
Atomically initialize in the proxy constructor (`ERC1967Proxy(logic, initData)`), or restrict `initialize` to a known deployer/guardian address (e.g., `require(msg.sender == DEPLOYER)`) until initialization completes — mirroring RocketPool's fix of gating bootstrap writes to a trusted account.

### Proof of Concept
```solidity
// SPDX-License-Identifier: MIT
pragma solidity 0.8.24;

import "forge-std/Test.sol";
import {PoolRegistry} from "contracts/PoolRegistry.sol";
import {ERC1967Proxy} from "contracts/dependencies/openzeppelin/proxy/ERC1967/ERC1967Proxy.sol";

contract InitFrontRunTest is Test {
    function test_anyoneCanInitializeAndBecomeGovernor() public {
        PoolRegistry impl = new PoolRegistry();

        // Deploy proxy WITHOUT initialization calldata (separate-tx bootstrap)
        ERC1967Proxy proxy = new ERC1967Proxy(address(impl), "");
        PoolRegistry registry = PoolRegistry(address(proxy));

        // Attacker front-runs deployer's initialize() in the mempool
        address attacker = makeAddr("attacker");
        address maliciousOracle = makeAddr("maliciousOracle");
        vm.prank(attacker);
        registry.initialize(IMasterOracle(maliciousOracle), attacker);

        // Attacker is now governor and controls the oracle
        assertEq(registry.governor(), attacker);
        assertEq(address(registry.masterOracle()), maliciousOracle);

        // Legitimate deployer's initialize now reverts (already initialized)
        vm.expectRevert("Initializable: contract is already initialized");
        registry.initialize(IMasterOracle(makeAddr("realOracle")), makeAddr("realFeeCollector"));

        // Attacker exercises governor privileges: register fake pool, shutdown
        vm.prank(attacker);
        registry.registerPool(makeAddr("fakePool"));
        assertTrue(registry.isPoolRegistered(makeAddr("fakePool")));

        vm.prank(attacker);
        registry.shutdown();
        assertTrue(registry.everythingStopped());
    }
}
```
