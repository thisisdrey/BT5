This confirms the mechanism is sound. The gas_weight distribution (`distribute_gas` in `runtime/runtime/src/receipt_manager.rs:654-696`) allocates only the *creating call's own leftover unused gas* — gas that was already reserved from the creating transaction's prepaid gas and would otherwise simply be refunded to the signer. It does not create or reserve gas twice. [1](#0-0) [2](#0-1) 

The `promise_yield_resume` (and `promise_yield_resume_with_yield_id`) path only charges `yield_resume_base`/`yield_resume_byte` fees against the *resuming* transaction's own prepaid gas, and simply submits data via `submit_promise_resume_data`, producing a `PromiseResume` data receipt with zero associated gas cost (`ParameterCost::ZERO` for `PromiseResume` in `receipt_required_cost`). [3](#0-2) [4](#0-3) 

It does not attach any additional gas to the already-created `FunctionCall` action inside the `PromiseYield` receipt. That action's `gas` field was fixed once, at `promise_yield_create` time — first via `prepay_gas(Gas::from_gas(gas))` for the static portion, and then via `distribute_gas` at the end of the creating call for the weighted portion, using only that call's own unused gas budget. [5](#0-4) 

When the `PromiseResume` receipt is later processed, the runtime looks up the stored `PromiseYield` action receipt (with its gas field already fixed) and executes it normally — the resuming receipt/transaction's own gas budget is entirely separate and pays only for its own `yield_resume_base/byte` fees and receipt-creation overhead, not for the callback's execution. [6](#0-5) 

There is no code path where gas_weight-derived gas is reserved a second time from the resuming receipt. The invariant (sum of gas burnt + refunded across both receipts equals sum of prepaid gas from both transactions) holds because: (1) the create-side transaction pays for and reserves the callback's full gas (fixed + weight-distributed portion of its own leftover budget) at creation time, refunding any truly unused remainder to the creating signer; (2) the resume-side transaction pays only for its own distinct, separately-metered `yield_resume_base/byte` costs and receipt overhead. A large `gas_weight` value simply changes how the *creating* call's own leftover gas is distributed between refund-to-signer and the callback's budget (per the same floor-division logic tested in `function_call_weight_basic_cases_test`), it does not summon gas from the resuming receipt. [7](#0-6)

    /// Distribute the provided `gas` between receipts managed by this `ReceiptManager` according
    /// to their assigned weights.
    ///
    /// Returns the amount of gas distributed (either `0` or `unused_gas`.)
    pub(super) fn distribute_gas(&mut self, unused_gas: Gas) -> Result<Gas, RuntimeError> {
        let ReceiptManager {
            action_receipts,
            data_receipts: _,
            gas_weights,
            promise_yield_receipt_index: _,
        } = self;
        let gas_weight_sum: u128 = gas_weights.iter().map(|(_, gv)| u128::from(gv.0)).sum();
        if gas_weight_sum == 0 || unused_gas == Gas::ZERO {
            return Ok(Gas::ZERO);
        }
        let mut distributed = 0u64;
        let mut gas_weight_iterator = gas_weights.iter().peekable();
        loop {
            let Some((index, weight)) = gas_weight_iterator.next() else { break };
            let FunctionCallActionIndex { receipt_index, action_index } = *index;
            let Some(Action::FunctionCall(action)) = action_receipts
                .get_mut(receipt_index)
                .and_then(|receipt| receipt.actions.get_mut(action_index))
            else {
                panic!(
                    "Invalid function call index (promise_index={receipt_index}, action_index={action_index})",
                );
            };
            let to_assign =
                (u128::from(unused_gas.as_gas()) * weight.0 as u128 / gas_weight_sum) as u64;
            action.gas =
                action.gas.checked_add(Gas::from_gas(to_assign)).ok_or(IntegerOverflowError)?;
            distributed = distributed
                .checked_add(to_assign)
                .unwrap_or_else(|| panic!("gas computation overflowed"));
            if gas_weight_iterator.peek().is_none() {
                let remainder = unused_gas.as_gas().wrapping_sub(distributed);
                distributed = distributed
                    .checked_add(remainder)
                    .unwrap_or_else(|| panic!("gas computation overflowed"));
                action.gas =
                    action.gas.checked_add(Gas::from_gas(remainder)).ok_or(IntegerOverflowError)?;
            }
        }
        assert_eq!(unused_gas.as_gas(), distributed);
        Ok(Gas::from_gas(distributed))
    }
