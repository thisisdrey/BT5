### Title
Missing per-transaction voter authorization allows any authenticated Gitaly node to stop or vote on another node's reference transaction - (File: internal/praefect/service/transaction/server.go)

### Summary
The external report describes a missing ownership check in `TransferAgentGateway.cancelRequest`: the function verifies the caller is *a* shareholder, but never checks the caller is *the* shareholder who owns the specific request being cancelled. The same class of bug — a request-scoped operation authenticated only at the "is this caller a legitimate participant of the system" level, but not at the "is this caller a legitimate participant of *this specific request*" level — appears in Gitaly's Praefect reference-transaction coordination path.

### Finding Description
`Server.StopTransaction` and `Server.VoteTransaction` in [1](#0-0)  take a client-supplied `TransactionId` and forward it straight to `Manager.StopTransaction` / `Manager.VoteTransaction` in [2](#0-1) . Neither the RPC handler nor the manager verifies that the calling node (`in.GetNode()`) is one of the `Voter`s that were registered for that specific `transactionID` via `RegisterTransaction` [3](#0-2) . Transaction IDs are simply a monotonically increasing counter (`atomic.AddUint64(&mgr.idSequence, 1)`) with no per-transaction secret, so any caller that can reach the `RefTransaction` gRPC service and knows (or guesses/enumerates) a `transactionID` can call `StopTransaction` for a transaction it was never registered to vote on, exactly as the shareholder in the report could cancel a transaction request belonging to another account.

`transaction.stop()` unconditionally transitions the transaction to the stopped state and unblocks/aborts every voter's `VoteTransaction` call waiting on quorum for that ID, and `Manager.CancelTransactionNodeVoter` similarly lets a caller cancel any node's vote by name for a given transaction ID [4](#0-3) . The check that exists in the report ("is the caller *a* shareholder") maps to Gitaly's check that the caller is *an* authenticated Gitaly node speaking to Praefect's internal gRPC service; the missing check ("is the caller *the* shareholder for *this* request") maps to the missing verification that the caller is *a registered voter for this specific transaction ID*.

### Impact Explanation
If reachable, this allows a rogue or compromised node/process holding a valid connection to the `RefTransaction` service to gracefully stop in-flight reference transactions belonging to unrelated repositories/other nodes by transaction ID, causing those in-flight pushes/writes to abort (`ErrTransactionStopped`/`VoteTransactionResponse_STOP`) — a targeted denial-of-service against arbitrary concurrent write operations across the Gitaly Cluster, directly analogous to the "cancel any transaction request" DoS in the report.

### Likelihood Explanation
This is only actionable by an entity that can already establish a gRPC connection to Praefect's `RefTransaction` service — in the intended deployment this is restricted to Gitaly nodes participating in the cluster, authenticated via the internal token/backchannel mechanism (I was unable to fully confirm within available context whether `RefTransaction` is exposed on the same listener/interceptor chain as client-facing RPCs or is isolated to node-to-node traffic only, since `internal/praefect/server.go` registration and its auth-interceptor wiring were not fully inspected). Transaction IDs are sequential and thus trivially enumerable/guessable once any single transaction ID is observed (e.g., from logs, metrics, or a legitimately owned transaction), which increases likelihood for any party with node-level connectivity, even without the ability to observe the target transaction ID directly. This is not a fully unprivileged, ordinary-Git-user-triggered path like a crafted push or fetch; it requires a node-level connection to Praefect's internal service.

### Recommendation
- Bind each `transactionID` to the set of `Voter` node identities established at `RegisterTransaction` time, and require `StopTransaction`, `VoteTransaction`, and `CancelTransactionNodeVoter` to verify that the calling/requesting node is a member of that voter set before acting on the transaction, mirroring `TransactionalModule`'s (missing) per-account ownership check.
- Consider issuing a per-transaction, unguessable token (rather than a sequential integer) at registration time, requiring it be presented alongside `transactionID` on subsequent calls, closing the enumeration vector even if per-node checks are bypassed by a compromised node.
- Document and test the authorization invariant explicitly: "a node may only vote/stop/cancel transactions it was registered as a voter for" — with unit tests exercising both positive (registered voter succeeds) and negative (non-participant node rejected) cases for `StopTransaction`, `VoteTransaction`, and `CancelTransactionNodeVoter`.

### Proof of Concept
1. Node A calls `RegisterTransaction` (internally, via a push through the reference-transaction hook) creating `transactionID = N` with voters `{primary, secondary-1}`.
2. Node B (not a voter for `N`), or any process able to invoke Praefect's `RefTransaction.StopTransaction` RPC, calls:
   ```
   StopTransaction(&gitalypb.StopTransactionRequest{TransactionId: N})
   ```
3. `Server.StopTransaction` [5](#0-4)  forwards directly to `Manager.StopTransaction(ctx, N)` with no check that Node B is a voter of transaction `N`.
4. `transaction.stop()` is invoked, causing every legitimate voter of `N` (e.g., `secondary-1` still waiting in `VoteTransaction`) to receive `VoteTransactionResponse_STOP`/`ErrTransactionStopped`, aborting the in-flight write for a repository/transaction Node B has no relation to.
5. Repeating this for sequentially enumerated `transactionID`s lets Node B stop an arbitrary stream of concurrent transactions cluster-wide.

func (s *Server) VoteTransaction(ctx context.Context, in *gitalypb.VoteTransactionRequest) (*gitalypb.VoteTransactionResponse, error) {
	vote, err := voting.VoteFromHash(in.GetReferenceUpdatesHash())
	if err != nil {
		return nil, structerr.NewInvalidArgument("invalid reference update hash: %w", err)
	}
	if err := s.txMgr.VoteTransaction(ctx, in.GetTransactionId(), in.GetRepository().GetStorageName(),
		in.GetRepository().GetRelativePath(), in.GetNode(), in.GetPhase(), vote); err != nil {
		switch {
		case errors.Is(err, transactions.ErrNotFound):
			return nil, structerr.NewNotFound("%w", err)
		case errors.Is(err, transactions.ErrTransactionCanceled):
			return nil, structerr.NewCanceled("%w", err)
		case errors.Is(err, transactions.ErrTransactionStopped):
			return &gitalypb.VoteTransactionResponse{
				State: gitalypb.VoteTransactionResponse_STOP,
			}, nil
		case errors.Is(err, transactions.ErrTransactionFailed):
			return &gitalypb.VoteTransactionResponse{
				State: gitalypb.VoteTransactionResponse_ABORT,
			}, nil
		default:
			return nil, structerr.NewInternal("%w", err)
		}
	}

	return &gitalypb.VoteTransactionResponse{
		State: gitalypb.VoteTransactionResponse_COMMIT,
	}, nil
}

// StopTransaction is called by a client who wants to gracefully stop a
// transaction. All voters waiting for quorum will be stopped and new votes

// the same transaction.
func (s *Server) StopTransaction(ctx context.Context, in *gitalypb.StopTransactionRequest) (*gitalypb.StopTransactionResponse, error) {

		switch {
		case errors.Is(err, transactions.ErrNotFound):
			return nil, structerr.NewNotFound("%w", err)
		case errors.Is(err, transactions.ErrTransactionCanceled):
			return nil, structerr.NewCanceled("%w", err)
		case errors.Is(err, transactions.ErrTransactionStopped):
			return &gitalypb.StopTransactionResponse{}, nil
		default:
			return nil, structerr.NewInternal("%w", err)
		}
	}

	return &gitalypb.StopTransactionResponse{}, nil

func (mgr *Manager) RegisterTransaction(ctx context.Context, voters []Voter, threshold uint) (Transaction, CancelFunc, error) {
	mgr.lock.Lock()
	defer mgr.lock.Unlock()

	transactionID := atomic.AddUint64(&mgr.idSequence, 1)

	transaction, err := newTransaction(transactionID, voters, threshold)
	if err != nil {
		return nil, nil, err
	}

	if _, ok := mgr.transactions[transactionID]; ok {
		return nil, nil, errors.New("transaction exists already")
	}
	mgr.transactions[transactionID] = transaction

	mgr.logger.WithFields(log.Fields{
		"transaction.id":     transactionID,
		"transaction.voters": voters,
	}).DebugContext(ctx, "RegisterTransaction")

	mgr.counterMetric.WithLabelValues("registered").Add(float64(len(voters)))

	return transaction, func() error {
		return mgr.cancelTransaction(ctx, transaction)
	}, nil
}

func (mgr *Manager) VoteTransaction(ctx context.Context, transactionID uint64, storageName, repoRelativePath, node string, phase gitalypb.VoteTransactionRequest_Phase, vote voting.Vote) error {
	start := time.Now()
	defer func() {
		delay := time.Since(start)
		mgr.delayMetric.WithLabelValues("vote").Observe(delay.Seconds())
	}()

	logger := mgr.logger.WithFields(log.Fields{
		"transaction.id":    transactionID,
		"transaction.voter": node,
		"transaction.hash":  vote.String(),
		"transaction.phase": phase,
	})

	mgr.counterMetric.WithLabelValues("started").Inc()
	logger.DebugContext(ctx, "VoteTransaction")

	if err := mgr.voteTransaction(ctx, transactionID, storageName, repoRelativePath, node, phase, vote); err != nil {
		var counterLabel string

		if errors.Is(err, ErrTransactionStopped) {
			counterLabel = "stopped"
			// Stopped transactions indicate a graceful
			// termination, so we should not log an error here.
		} else if errors.Is(err, ErrTransactionFailed) {
			counterLabel = "failed"
			logger.WithError(err).ErrorContext(ctx, "VoteTransaction: did not reach quorum")
		} else if errors.Is(err, ErrTransactionCanceled) {
			counterLabel = "canceled"
			logger.WithError(err).ErrorContext(ctx, "VoteTransaction: transaction was canceled")
		} else {
			counterLabel = "invalid"
			logger.WithError(err).ErrorContext(ctx, "VoteTransaction: failure")
		}

		mgr.counterMetric.WithLabelValues(counterLabel).Inc()

		return err
	}

	logger.InfoContext(ctx, "VoteTransaction: transaction committed")
	mgr.counterMetric.WithLabelValues("committed").Inc()

	return nil
}

// StopTransaction will gracefully stop a transaction.
func (mgr *Manager) StopTransaction(ctx context.Context, transactionID uint64) error {
	mgr.lock.Lock()
	transaction, ok := mgr.transactions[transactionID]
	if ok {
		// Release while holding mgr.lock so a concurrent voteTransaction
		// can't acquire a fresh repo lock between this release and stop.
		mgr.releaseRepoLock(transactionID)
	}
	mgr.lock.Unlock()

	if !ok {
		return fmt.Errorf("%w: %d", ErrNotFound, transactionID)
	}
	if err := transaction.stop(); err != nil {
		return err
	}

	mgr.logger.WithFields(log.Fields{
		"transaction.id": transactionID,
	}).DebugContext(ctx, "VoteTransaction: transaction stopped")
	mgr.counterMetric.WithLabelValues("stopped").Inc()

	return nil
}

// CancelTransactionNodeVoter cancels the voter associated with the specified transaction
// and node. Voters are canceled when the node RPC fails and its votes can no longer count
// towards quorum.
func (mgr *Manager) CancelTransactionNodeVoter(transactionID uint64, node string) error {
	mgr.lock.Lock()
	transaction, ok := mgr.transactions[transactionID]
	mgr.lock.Unlock()

	if !ok {
		return fmt.Errorf("%w: %d", ErrNotFound, transactionID)
	}

	if err := transaction.cancelNodeVoter(node); err != nil {
		return fmt.Errorf("canceling transaction node voter: %w", err)
	}

	return nil
}
