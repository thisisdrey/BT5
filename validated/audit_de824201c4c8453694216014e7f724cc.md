### Title
Uninitialized `accountIndexOf` rewards accounts their full token balance when a reward token is registered with index `INITIAL_INDEX` - (File: contracts/RewardsDistributor.sol)

### Summary
Analogous to the uninitialized-buffer read in the kernel report, `RewardsDistributor._calculateTokenDelta` reads `accountIndexOf[token_][account_]`, which is `0` for accounts that never had a rewards checkpoint. The fallback that substitutes `INITIAL_INDEX` only triggers when `_tokenIndex > INITIAL_INDEX`. When a token is newly registered, `tokenStates[token_].index == INITIAL_INDEX` exactly, so the fallback is skipped and the delta index is computed as `INITIAL_INDEX - 0 = 1e18`, crediting the account `balanceOf(account)` reward tokens with zero elapsed accrual time. [1](#0-0) 

### Finding Description
- `_updateTokenSpeed` registers a new reward token with `TokenState({index: INITIAL_INDEX, timestamp: now})`. [2](#0-1) 
- `updateBeforeMintOrBurn` / `updateBeforeTransfer` skip updating when `tokenStates[token_].index == 0`, so accounts holding the DepositToken/DebtToken before registration never get `accountIndexOf` initialized. [3](#0-2) 
- `claimRewards` then calls `_updateTokensAccruedOf` for any token with `index > 0`, and `_calculateTokenDelta` computes `_deltaIndex = _tokenIndex - _accountIndex` and `_tokensDelta = balanceOf.wadMul(_deltaIndex)`. With `_accountIndex = 0` and `_tokenIndex = 1e18`, `_tokensDelta = balanceOf(account)`. [4](#0-3) 
- `_transferRewardIfEnoughTokens` pays out `tokensAccruedOf[account]` as long as the distributor holds enough rewardToken. [5](#0-4) 

### Impact Explanation
Direct theft of reward tokens: any holder of a deposit/debt token whose balance predates reward registration can claim `balanceOf` worth of `rewardToken` instantly, up to the distributor's full balance. Multiple pre-existing holders each claim their full balance, draining the distributor and stealing yield owed to legitimate accrual.

### Likelihood Explanation
Requires the governor to register an already-distributed DepositToken/DebtToken as a reward token (normal operation when adding new incentive programs), and the distributor to hold rewardToken. The attacker is unprivileged: they only need to hold (or flash-acquire) the token before `updateTokenSpeed`, then call `claimRewards(accounts, [token])` — a public, non-guarded function. `accountIndexOf` is only set when index updates run, which the `index == 0` guard prevents pre-registration.

### Recommendation
Change the fallback in `_calculateTokenDelta` to apply whenever `_accountIndex == 0` (i.e., `_accountIndex = _tokenIndex > INITIAL_INDEX ? INITIAL_INDEX : _tokenIndex`, or simply `_accountIndex = _tokenIndex` when uninitialized), so an uninitialized account index is treated as fully synced rather than `0`.

### Proof of Concept
```solidity
// Fork test: pool with DepositToken (dToken) already held by users.
// 1. attacker holds 1000 dToken before rewards configured
//    (accountIndexOf[dToken][attacker] == 0, tokenStates[dToken].index == 0)
// 2. governor calls distributor.updateTokenSpeed(dToken, 1e18)
//    -> tokenStates[dToken] = {index: 1e18, timestamp: now}
// 3. attacker calls distributor.claimRewards(attacker)
//    -> index > 0, so _updateTokenIndex + _updateTokensAccruedOf run
//    -> _tokenIndex = 1e18, _accountIndex = 0, fallback skipped (1e18 !> 1e18)
//    -> _tokensDelta = 1000e18 * wadMul(1e18) = 1000e18
//    -> tokensAccruedOf[attacker] = 1000e18 rewardToken claimed
assertEq(rewardToken.balanceOf(attacker), 1000e18);
```

    function _calculateTokenDelta(
        TokenState memory _tokenState,
        IERC20 token_,
        address account_
    ) private view returns (uint256 _tokenIndex, uint256 _tokensDelta) {
        _tokenIndex = _tokenState.index;
        uint256 _accountIndex = accountIndexOf[token_][account_];

        if (_accountIndex == 0 && _tokenIndex > INITIAL_INDEX) {
            _accountIndex = INITIAL_INDEX;
        }

        uint256 _deltaIndex = _tokenIndex - _accountIndex;
        _tokensDelta = token_.balanceOf(account_).wadMul(_deltaIndex);
    }
