### Title
Unauthenticated remote `POST /shutdown` permanently terminates the signer's event-receiver thread - ([File: libsigner/src/events.rs])

### Summary
The signer's HTTP event-receiver endpoint accepts a `POST /shutdown` request from any TCP peer with no signature, secret, or origin check, immediately setting `stop_signal` to `true` and returning `EventError::Terminated`. This kills the dedicated event-receiver thread, permanently cutting the node→signer event channel until the signer process is manually restarted.

### Finding Description
`SignerEventReceiver::bind` opens a plain `tiny_http::HttpServer` with no authentication layer [1](#0-0) . In `next_event`, the request URL is dispatched purely by string match with no signature or origin verification anywhere in the branch chain [2](#0-1) . For `/shutdown`, the handler unconditionally does `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` [3](#0-2) . This is the exact same primitive used internally by `SignerStopSignaler::send`, which crafts a raw `POST /shutdown` HTTP request over a `TcpStream` to itself for graceful shutdown [4](#0-3) ; nothing distinguishes a legitimate local shutdown signal from an arbitrary remote one, because the listener has no auth check at all. Any other unmatched POST path falls through to `ack_dispatcher`, which merely responds `200 OK` with no state change [5](#0-4) [6](#0-5)  — that fallback is benign (by design, "return OK so other side doesn't keep sending this") and causes no forged/stored state, so it is not itself a vulnerability. The `/shutdown` path, however, causes a real state transition: once `stop_signal` is `true`, the next call to `next_event` sees `event_receiver.is_stopped()` true and returns `Err(EventError::Terminated)` [7](#0-6) , which propagates out of the event-receiver's main loop and terminates that thread, per the `RunningSigner`/`Signer::spawn` wiring where the event receiver runs in its own dedicated thread that is expected to exit only on an intentional stop signal [8](#0-7) .

### Impact Explanation
A single unauthenticated `POST /shutdown` from any remote party that can reach the signer's bound event-receiver TCP address permanently stops that signer instance's event-receiver thread, severing the node→signer channel that delivers `stackerdb_chunks`, `proposal_response`, `new_burn_block`, and `new_block` events. The signer becomes unable to receive new block proposals or StackerDB chunk events until an operator manually restarts the process. This is a Critical unauthenticated DoS achievable with a single crafted message and no privileged role, secret, or signature.

### Likelihood Explanation
The only precondition is TCP reachability to the signer's bound event-receiver address, which is explicitly given as satisfied in this scope (the endpoint has no auth gate by design — it is intended to only be reached by the local node, but the code enforces this via no mechanism other than network topology). Given reachability, the attack is a single well-formed HTTP POST with no cryptographic material required, trivially repeatable, and 100% reliable (unconditional `store(true)`).

### Recommendation
Add an authentication/authorization check on the event-receiver HTTP endpoint (e.g., a shared secret header, mTLS, or restricting `/shutdown` handling to loopback-only connections) before honoring `/shutdown`, or at minimum require that `SignerStopSignaler`-originated shutdown requests be distinguished from arbitrary remote requests (e.g., via a token embedded in the shutdown POST body/header that is checked against a value only known to the local process).

### Proof of Concept
```rust
// libsigner/src/tests/events_shutdown_poc.rs (conceptual)
use std::net::TcpStream;
use std::io::Write;

#[test]
fn unauthenticated_remote_shutdown() {
    // Assume SignerEventReceiver bound at 127.0.0.1:30000 in a test harness
    // spawned exactly as libsigner::runloop::Signer::spawn does.
    let mut stream = TcpStream::connect("127.0.0.1:30000").unwrap();
    let body = "attacker";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: 127.0.0.1:30000\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Assertion: the event_join thread handle for the receiver completes
    // (i.e. `main_loop` returned) even though no legitimate SignerStopSignaler::send()
    // was ever called by this test -- proving an unauthenticated remote peer
    // terminated the event receiver thread.
    // e.g. running_signer.event_join.join().is_ok() returns promptly instead of hanging,
    // and subsequent legitimate node POSTs to /stackerdb_chunks or /new_block
    // no longer receive any response because the HttpServer's recv loop has exited.
}
```
