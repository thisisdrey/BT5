### No vulnerability found for this question.

The premise doesn't match the actual code. `ObjectDirectories` explicitly appends a trailing path separator to `storageRoot` before it's used as `storagePrefix` for the `strings.HasPrefix` boundary check: [1](#0-0) . That prefix (with the trailing separator, e.g. `/storage/root/`) is what's compared against candidate alternate paths in `altObjectDirs`, so a sibling path like `/storage/root-evil/...` or `/storage/rootXYZ` does **not** match the prefix `/storage/root/` and is correctly rejected as `alternateOutsideStorageError`: [2](#0-1) . This exact byte-prefix-without-separator scenario is already covered by an existing unit test, `TestObjectDirsOutsideStorage`, which asserts both relative and absolute alternates pointing to a storage-sibling directory are rejected: [3](#0-2) .

Separately, the check only bounds alternates to the *storage root*, not to the individual repository directory — but that is intentional design (object pools/forks share objects across repos within the same storage via alternates), not an unchecked boundary bug. Additionally, the `info/alternates` file itself is not attacker-controlled content from a push: it is written server-side by Gitaly's quarantine mechanism (`quarantine.Apply`), which sets it to the quarantine/object directory relative paths computed by Gitaly, not arbitrary attacker-supplied content [4](#0-3) . No reachable path was found by which an unprivileged attacker's push or import content directly writes an arbitrary line into `objects/info/alternates` that would then bypass the storage-root boundary check.

	repoPath := filepath.Join(storageRoot, "repo")

// Apply applies the quarantine on the repository. This is done by setting the quarantineDirectory
// as the repository's object directory, and configuring the repository's object directory as an alternate.
func Apply(repoPath string, repo *gitalypb.Repository, quarantineDir string) (*gitalypb.Repository, error) {
	relativePath, err := filepath.Rel(repoPath, quarantineDir)
	if err != nil {
		return nil, fmt.Errorf("creating quarantine: %w", err)
	}

	// All paths are relative to the repository root.
	objectDir := repo.GetGitObjectDirectory()
	if objectDir == "" {
		// Set the default object directory as an alternate if the repository didn't
		// have the object directory overwritten yet.
		objectDir = "objects"
	}

	alternateObjectDirs := make([]string, 0, len(repo.GetGitAlternateObjectDirectories())+1)
	alternateObjectDirs = append(alternateObjectDirs, objectDir)
	alternateObjectDirs = append(alternateObjectDirs, repo.GetGitAlternateObjectDirectories()...)

	quarantinedRepo := proto.Clone(repo).(*gitalypb.Repository)
	quarantinedRepo.GitObjectDirectory = relativePath
	quarantinedRepo.GitAlternateObjectDirectories = alternateObjectDirs

	return quarantinedRepo, nil
}
