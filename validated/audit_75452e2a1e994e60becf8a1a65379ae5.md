### Title
Protocol fee bypass on Nep245/Imt TokenDiff swaps by splitting into unit-sized (|delta|=1) intents - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::execute_intent` computes and collects the protocol fee independently for each `TokenDiff` intent, using only that intent's own `delta` magnitude. Because `TokenDiff::token_fee` returns `Pips::ZERO` for `Nep245`/`Imt` token IDs whenever `amount <= 1`, a signer can split one N-unit swap on such a token into N separate unit-delta (`delta = ±1`) `TokenDiff` intents (either as multiple intents inside one signed `DefuseIntents` payload, or as multiple signed payloads in the same `execute_intents` batch) and pay zero fee in total, instead of `protocol_fee.fee_ceil(N)`.

### Finding Description
The broken binding:
`fee_owed_single = TokenDiff::token_fee(token_id, N, protocol_fee).fee_ceil(N)` for a single `TokenDiff` with `delta = -N` on a `Nep245`/`Imt` `TokenId`
should equal
`fee_owed_split = Σ_{i=1}^{N} TokenDiff::token_fee(token_id, 1, protocol_fee).fee_ceil(1)` for N intents each with `delta = -1` on the same `TokenId`, since both represent the exact same net economic transfer for the signer.

Code path: [1](#0-0)  shows the fee is computed per `(token_id, delta)` pair inside a single `TokenDiff.diff` map, with `amount = delta.unsigned_abs()` taken from that intent alone. `Self::token_fee` explicitly zeroes the fee for `Nep245`/`Imt` when `amount <= 1`: [2](#0-1) .

Balance netting across the whole batch is handled separately by `TransferMatcher`/`Deltas`, which only checks that deposits and withdrawals across all intents net to zero per token — it does not recompute or aggregate fees: [3](#0-2) . `DefuseIntents::execute_intent` simply loops over each sub-intent and executes it independently: [4](#0-3) , and `Engine::execute_signed_intent` verifies the payload/signature/nonce once per signed payload before dispatching to that intent list: [5](#0-4) .

Attacker's payload: a single NEP-413 signed `DefusePayload<DefuseIntents>` whose `intents` vector contains N `TokenDiff` intents, each `diff = {Nep245TokenId: -1}` (or split across N separately signed payloads in one `execute_intents` call), matched by a counterparty (which can be the attacker's own second account) providing the corresponding `+1` deltas. Each iteration computes `token_fee(token_id, 1, fee) == Pips::ZERO`, so `fees_collected` stays empty for every intent, while a single `TokenDiff` with `delta = -N` on the same token would have collected `protocol_fee.fee_ceil(N) > 0`.

No existing guard prevents this: signature/nonce checks operate at the payload level and are unrelated to fee accounting; `TransferMatcher::finalize` only enforces balance conservation, not fee equivalence across differently-partitioned intents.

### Impact Explanation
The `fee_collector` receives strictly less fee revenue than it is owed for economically identical trades, matching the "protocol fees bypassed" Critical category. Any signer trading a `Nep245` (or `Imt`) token can reduce their fee on an N-unit trade to zero by chunking it into N unit-delta intents (self-matched with a second account they control, or matched with a willing counterparty), repeatable for every trade and every batch, with no upper bound on volume other than transaction size/gas for packing N sub-intents.

### Likelihood Explanation
The attacker needs no special privileges — only a `Nep245`/`Imt` balance in the Verifier (which they can create using their own deployed MT contract with attacker-chosen low-precision/decimals so that "amount" units correspond to large economic value, making N small and the attack cheap) and a second account (also attacker-controlled) to match the opposite side of the intra-batch netting. Cost scales with N sub-intents packed into one or a few signed payloads within one `execute_intents` call; for attacker-chosen tokens with coarse unit granularity, N can be small, making the bypass cheap and fully repeatable.

### Recommendation
Compute the fee basis on the net aggregate delta per `(signer_id, token_id)` across the whole batch (or at minimum across all `TokenDiff` intents signed together) rather than per individual `TokenDiff` intent, before applying the `Nep245`/`Imt` `amount <= 1` no-fee exception, so that partitioning a swap into unit-sized diffs cannot change the total fee owed.

### Proof of Concept
Add a `cargo test` in `contracts/defuse/core/src/intents/token_diff.rs` (unit-level, using `Engine`/`Deltas`/a mock `State`) or in `tests/src/tests/defuse/intents/token_diff.rs` (sandbox level) that:
1. Sets `protocol_fee = Pips::ONE_PERCENT` (or any nonzero fee) and a `Nep245TokenId` with a balance of `N` (e.g., `N = 10`) for `user1`, and a matching `+N` counterparty position for `user2`.
2. Case A: `user1` signs one `TokenDiff{ diff: {token_id: -N, other_token: +M} }`, `user2` signs the closing `TokenDiff`; execute via `execute_intents`; assert `fees_collected`/`fee_collector` balance on `token_id` equals `protocol_fee.fee_ceil(N) > 0`.
3. Case B: `user1` signs N `TokenDiff` intents (packed in one `DefuseIntents` payload or N separate signed payloads) each `{ diff: {token_id: -1, other_token: +m_i} }` summing to the same net `-N`/`+M`, matched by `user2`'s corresponding intents; execute via the same `execute_intents` call.
4. Assert `fee_collector`'s `token_id` balance after Case B is `0`, while after Case A it is `protocol_fee.fee_ceil(N)`, proving the two economically equivalent trades yield different (bypassable) fee collection.

        self.0.entry_or_default(token_id).deposit(owner_id, amount)
    }

    #[inline]
    pub fn withdraw(&mut self, owner_id: AccountId, token_id: TokenId, amount: u128) -> bool {
        self.0.entry_or_default(token_id).withdraw(owner_id, amount)
    }

    #[inline]
    pub fn add_delta(&mut self, owner_id: AccountId, token_id: TokenId, delta: i128) -> bool {
        self.0.entry_or_default(token_id).add_delta(owner_id, delta)
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }
