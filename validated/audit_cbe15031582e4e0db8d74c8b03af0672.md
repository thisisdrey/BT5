The CVE describes a Linux kernel ksmbd (in-kernel SMB server) flaw where an unvalidated Owner/Group SID inside a parent directory's `smb_ntsd` security descriptor is trusted during ACL inheritance. The closest constructs in this Go repository are the Windows SID/ACL wrappers such as `syscall.SID`, `StringToSid`, `LookupSID` in [1](#0-0) , and the `internal/syscall/windows` SID helpers (`GetSidIdentifierAuthority`, `GetSidSubAuthority`, `IsValidSid`) in [2](#0-1) , plus the `SECURITY_DESCRIPTOR`/ACL types in [3](#0-2) .

None of these constitute an SMB server or any code path that parses an untrusted, attacker-supplied NT security descriptor received over a network protocol and propagates it into newly created file ACLs. These are thin wrappers around Windows `advapi32`/`ntdll` APIs used by the local process to manage its own file security attributes (e.g., in `os/user` and test helpers), not a parser for externally-supplied binary security-descriptor blobs from an unauthenticated peer. There is no "parent directory's untrusted SID gets inherited without validation" pattern reachable by an unauthenticated/unprivileged network attacker anywhere in this codebase, so the bug class does not have a matching, provable analog here.

// StringToSid converts a string-format security identifier
// sid into a valid, functional sid.
func StringToSid(s string) (*SID, error) {
	var sid *SID
	p, e := UTF16PtrFromString(s)
	if e != nil {
		return nil, e
	}
	e = ConvertStringSidToSid(p, &sid)
	if e != nil {
		return nil, e
	}
	defer LocalFree((Handle)(unsafe.Pointer(sid)))
	return sid.Copy()
}

// instrumentation can't see that the pointer returned by the syscall is pointing
// into the sid's memory, which is normally allocated on the Go heap. Therefore,
// the checkptr instrumentation would incorrectly flag the pointer dereference
// as pointing to an invalid allocation.
// Also, use runtime.KeepAlive to ensure that the sid is not garbage collected
// before the GetSid* functions return, as the Go GC is not aware that the
// pointers returned by the syscall are pointing into the sid's memory.

//go:nocheckptr
func GetSidIdentifierAuthority(sid *syscall.SID) SID_IDENTIFIER_AUTHORITY {
