### Title
Signer event-receiver HTTP server accepts unauthenticated stackerdb_chunks/proposal_response/burn_block/block events - (File: libsigner/src/events.rs)

### Summary
The `SignerEventReceiver::next_event` handler in `libsigner/src/events.rs` dispatches any POST to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` straight into `process_event`, and from there into the signer's runloop as a trusted `SignerEvent`, with no authentication check of any kind on the HTTP request.

### Finding Description
`next_event` reads the raw HTTP request from the listener socket and dispatches purely on the URL path and verb, with no check of a shared secret, token, TLS client cert, or source-address allow-list: [1](#0-0) 

The lower-level HTTP decoder `decode_http_request` in `libsigner/src/http.rs` likewise only parses verb/path/headers — it has no concept of authenticating the caller: [2](#0-1) 

`process_event` deserializes the body directly into a `StackerDBChunksEvent`/`BlockValidateResponse`/`BurnBlockEvent`/`StacksBlockEvent` and converts it into a `SignerEvent<T>` that is forwarded to the signer's decision runloop as if it had come from the local, trusted Stacks node: [3](#0-2) 

I confirmed via `grep_search` that there is no `Authorization`, `auth_token`, `shared_secret`, or `X-Auth`-style check anywhere in `libsigner/`. The design assumption appears to be that the signer's event-receiver port is only reachable by the paired Stacks node (e.g., bound to loopback or a private network segment), but nothing in this code enforces that assumption — it is purely a deployment/firewall convention, not an authentication mechanism in the protocol itself. Any host that can reach the bound TCP port can POST arbitrary, attacker-chosen `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` payloads and have them treated as authentic node-sourced events.

This is a structurally identical bug class to CVE-2018-14643 (smart_proxy_dynflow): a component meant to receive privileged, trusted instructions over HTTP performs no authentication of the caller, "failing open" for any party who can reach the socket.

### Impact Explanation
If the event-receiver's bind address is reachable by anything other than the exact paired node (e.g., misconfiguration, container/bridge networking, or any network path to the port), an attacker can inject forged `SignerMessages`/`MinerMessages`/`BlockValidateResponse`/burn-block events directly into the signer's decision loop, i.e., an unauthenticated write into signer runloop state that downstream signer logic treats as coming from the trusted local node. This matches the "Critical: unauthenticated/unauthorized write to state" bucket in scope, though the severity is capped by the fact that this depends on the event receiver being reachable beyond the intended loopback/private link, which is a deployment concern this code does nothing to enforce or verify.

### Likelihood Explanation
No source verification exists in the code, so exploitability is entirely dependent on network reachability of the event-receiver port. Where the port is exposed beyond the local Stacks node pairing (any misconfigured deployment, containerized setup with shared network namespace exposure, or a compromised host on the same segment), the attack requires only a single crafted HTTP POST with no credentials.

### Recommendation
Add an explicit authentication mechanism to the signer event-receiver HTTP path (e.g., a per-deployment shared secret/HMAC header verified in `next_event`/`process_event`, or mutual TLS), rather than relying solely on network topology/firewalling to keep the endpoint private. Reject any `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block` POST that fails this check before it reaches `process_event`.

### Proof of Concept
1. Start a signer with `SignerEventReceiver::bind` on a reachable address (per `libsigner/src/tests/mod.rs` test harness pattern, e.g. `127.0.0.1:31000`, or any misconfigured non-loopback bind).
2. From a remote/unauthenticated peer with network access to that port, send:
```
POST /stackerdb_chunks HTTP/1.1
Host: <addr>
Content-Length: <n>
Content-Type: application/json

<attacker-crafted StackerDBChunksEvent JSON>
```
3. `next_event` (`libsigner/src/events.rs:437-438`) routes this straight to `process_event::<T, StackerDBChunksEvent>`, which deserializes and forwards it as a `SignerEvent` into the signer runloop — with no verification that the request originated from the paired Stacks node.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

/// Decode the HTTP request payload into its headers and body.
/// Returns (verb, path, table of headers, body_offset) on success
pub fn decode_http_request(payload: &[u8]) -> Result<SignerHttpRequest, EventError> {
    // realistically, there won't be more than 32 headers
    let mut headers_buf = [httparse::EMPTY_HEADER; MAX_HTTP_HEADERS];
    let mut req = httparse::Request::new(&mut headers_buf);
    let (verb, path, headers, body_offset) =
        if let Ok(httparse::Status::Complete(body_offset)) = req.parse(payload) {
            // version must be valid
            match req
                .version
                .ok_or(EventError::MalformedRequest("No HTTP version".to_string()))?
            {
                0 => {}
                1 => {}
                _ => {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP version".to_string(),
                    ));
                }
            };

            let verb = req
                .method
                .ok_or(EventError::MalformedRequest("No HTTP method".to_string()))?
                .to_string();
            let path = req
                .path
                .ok_or(EventError::MalformedRequest("No HTTP path".to_string()))?
                .to_string();

            let mut headers: HashMap<String, String> = HashMap::new();
            for i in 0..req.headers.len() {
                let value = String::from_utf8(req.headers[i].value.to_vec()).map_err(|_e| {
                    EventError::MalformedRequest("Invalid HTTP header value: not utf-8".to_string())
                })?;
                if !value.is_ascii() {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is not ASCII-US".to_string(),
                    ));
                }
                if value.len() > MAX_HTTP_HEADER_LEN {
                    return Err(EventError::MalformedRequest(
                        "Invalid HTTP request: header value is too big".to_string(),
                    ));
                }

                let key = req.headers[i].name.to_string().to_lowercase();
                if headers.get(&key).is_some() {
                    return Err(EventError::MalformedRequest(format!(
                        "Invalid HTTP request: duplicate header \"{key}\""
                    )));
                }
                headers.insert(key, value);
            }
            (verb, path, headers, body_offset)
        } else {
            return Err(EventError::Deserialize(
                "Failed to decode HTTP headers".to_string(),
            ));
        };

    Ok(SignerHttpRequest::new(verb, path, headers, body_offset))
}
