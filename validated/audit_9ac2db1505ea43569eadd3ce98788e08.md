### Title
Unauthenticated remote termination of signer's event receiver via `POST /shutdown` - ([File: libsigner/src/events.rs])

### Summary
The `SignerEventReceiver::next_event` handler treats any HTTP `POST /shutdown` request as a legitimate stop command, with no verification that the sender is the signer's own `SignerStopSignaler` handle. Any TCP client able to reach the bound event-receiver port can trigger this branch and terminate the signer's `main_loop`.

### Finding Description
`SignerStopSignaler::send` normally signals shutdown by connecting to its own bound address and sending a raw `POST /shutdown HTTP/1.1` request [1](#0-0) . The receiving side, `SignerEventReceiver::next_event`, dispatches purely on `request.url()`: if the URL is `/shutdown`, it unconditionally sets `stop_signal` to `true` and returns `EventError::Terminated`, with no check of origin, secret, or any credential [2](#0-1) . `EventReceiver::main_loop` treats `EventError::Terminated` as a clean exit signal and breaks out of the loop [3](#0-2) . This breaks the intended equality "party who can trigger termination == holder of the `SignerStopSignaler` handle": the endpoint itself carries no authentication and treats `url == "/shutdown"` as sufficient proof of authority regardless of the TCP peer's identity.

The event receiver is bound via `Signer::spawn(bind_addr)` [4](#0-3) , and the configured address for stacks-signer's event endpoint is operator-controlled (commonly bound to a specific interface/port per node config); whether that interface is localhost-only or externally reachable is a deployment decision, but the code itself does not enforce any binding restriction, source-IP allowlist, or secret/token check at this endpoint.

### Impact Explanation
Any party who can open a TCP connection to the signer's event-receiver port can send a single crafted HTTP POST to `/shutdown` and stop the signer's event-processing thread, which causes `main_loop` to exit and the runloop's `event_recv` channel to disconnect, effectively halting that signer's participation in block signing until manually restarted. This is a low-cost, repeatable, single-message unauthenticated DoS against the signer process, matching the "Critical - remote crash/unauthenticated DoS from few messages" category, scoped strictly to the signer's own event loop (not the node's P2P/RPC surface, no consensus/state impact).

### Likelihood Explanation
Precondition is solely network reachability to the signer's bound event-receiver port; no key, secret, StackerDB slot ownership, or peer relationship is required — the check is purely `request.url() == "/shutdown"` with no authentication of the caller [2](#0-1) . Attacker cost is one raw TCP write of a fixed HTTP request; it is fully repeatable against any signer whose event port is reachable by the attacker.

### Recommendation
Do not use a network-reachable HTTP endpoint as the sole shutdown mechanism. Options: (1) bind the event receiver strictly to loopback and additionally require a per-process shared secret/token in the `/shutdown` request that `SignerStopSignaler` includes and `next_event` verifies before honoring it; (2) replace the `/shutdown` HTTP hack with an in-process signal (e.g., a self-pipe, condvar, or a local Unix domain socket) rather than an externally reachable TCP listener; (3) at minimum, reject `/shutdown` requests whose source address does not match `127.0.0.1`/the loopback interface.

### Proof of Concept
```rust
// libsigner/src/events.rs (test scaffold)
use std::net::TcpStream;
use std::io::Write;
use std::thread;
use std::time::Duration;

#[test]
fn unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<SomeSignerMessageType> = SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    let handle = thread::spawn(move || receiver.main_loop());

    // Attacker: no credentials, just a raw socket
    let mut stream = TcpStream::connect(addr).unwrap();
    stream
        .write_all(b"POST /shutdown HTTP/1.1\r\nHost: x\r\nContent-Length: 0\r\n\r\n")
        .unwrap();

    // main_loop should exit promptly with no auth check
    handle.join().unwrap();
}
```
Assertion: `handle.join()` returns without hanging, proving `next_event` matched `/shutdown` at [2](#0-1)  and set `stop_signal`, causing `main_loop` to break at [3](#0-2) , from an attacker connection with zero credentials.
