### Title
Unstaked QUIC stream throttle caps TPS per-connection, not cluster-wide, allowing aggregate ingress far above intended budget via many concurrent unstaked connections - (File: streamer/src/nonblocking/stream_throttle.rs)

### Summary
`ConnectionStreamCounter` and `throttle_stream` enforce `MAX_UNSTAKED_TPS` (200) as a per-connection budget, not a global/aggregate cap for all unstaked traffic. Since an attacker can maintain up to `max_unstaked_connections` (default 2000) concurrent unstaked QUIC connections, each independently allowed ~20 streams per 100ms interval, aggregate unstaked ingress scales linearly with connection count rather than being bounded at the intended cluster-wide share.

### Finding Description
`StakedStreamLoadEMA::new` computes `max_unstaked_load_in_throttling_window = MAX_UNSTAKED_TPS * STREAM_THROTTLING_INTERVAL_MS / 1000` [1](#0-0) , a fixed value (20 streams/100ms with defaults) independent of how many unstaked connections exist. `available_load_capacity_in_throttling_duration` returns this same fixed value for every `ConnectionPeerType::Unstaked` connection [2](#0-1) . This value is consumed in `SwQos::on_new_stream` -> `throttle_stream`, which checks/limits only the *per-connection* `ConnectionStreamCounter.stream_count` against this budget, using a per-connection `last_throttling_instant` [3](#0-2) , [4](#0-3) . There is no shared/global token bucket aggregating stream consumption across all unstaked connections.

The comment "Max TPS allowed for unstaked connection" [5](#0-4)  confirms this is a per-connection limit, while `EXPECTED_UNSTAKED_STREAMS_RATIO` (0.20) is only used to shrink the *staked* budget (`max_staked_load_in_ms = max_streams_per_ms - 20%`), not to cap unstaked traffic in aggregate [6](#0-5) .

The only limits on the number of concurrent unstaked connections are `max_connections_per_unstaked_peer` (default 8 per IP, `DEFAULT_MAX_QUIC_CONNECTIONS_PER_UNSTAKED_PEER`) [7](#0-6)  and `max_unstaked_connections` (default 2000, node-wide, with pruning down to 90% once at capacity) [8](#0-7) . The `overall_connection_rate_limiter` and per-IP `ConnectionRateLimiter` only throttle the *rate of establishing new connections* [9](#0-8) , [10](#0-9) ; once connections are established they can be held open indefinitely and each stream continuously up to its independent per-connection budget, so connection churn/reconnection is not even required — a stable pool of ~2000 unstaked connections (reachable using ~250 distinct source IPs at the default 8-per-IP cap) suffices.

With defaults, aggregate unstaked capacity becomes `max_unstaked_connections * MAX_UNSTAKED_TPS` = 2000 * 200 = 400,000 streams/sec, versus the global `max_streams_per_ms` budget of 500 (500,000/sec, `DEFAULT_MAX_STREAMS_PER_MS`) [11](#0-10) . This lets unstaked traffic consume nearly the entire global stream budget instead of the intended ~20% share, starving legitimate staked/forwarded traffic — a QoS evasion.

### Impact Explanation
This is a QoS evasion: unstaked (unpaying, low-priority) traffic is architecturally supposed to receive a small (~20%) fraction of total QUIC stream ingress capacity relative to staked traffic, but because the per-connection budget is not divided across the pool of concurrently permitted unstaked connections, an attacker who maintains many parallel unstaked connections can drive aggregate unstaked ingress up to the full global `max_streams_per_ms` ceiling, displacing legitimate staked/forwarded transaction traffic and increasing load on sigverify/banking stages disproportionately relative to the intended allocation.

### Likelihood Explanation
Feasible for an unprivileged attacker with access to a moderate number of distinct source IPs (~250 at default settings, since `max_connections_per_unstaked_peer` = 8) to reach `max_unstaked_connections` = 2000 concurrent unstaked connections. No staked identity, gossip participation, or privileged access is required — only standard QUIC/TPU connections to the public TPU port. The connection-establishment rate limiters (`ConnectionRateLimiter`, `overall_connection_rate_limiter`) only slow the ramp-up of new connections, not sustained per-connection streaming once connections are open, so the attack is fully repeatable and sustainable over time without needing precise timing at `STREAM_THROTTLING_INTERVAL` boundaries (the boundary-race framing in the question is unnecessary; continuous per-connection streaming at the allowed cap achieves the same aggregate effect).

### Recommendation
Introduce a global (or per-source-IP-aggregated) token bucket/counter for unstaked stream admission shared across all unstaked connections in `StakedStreamLoadEMA`/`throttle_stream`, so the aggregate unstaked ingress rate is capped at the intended cluster-wide `MAX_UNSTAKED_TPS`-derived budget regardless of the number of concurrent unstaked connections, rather than granting each connection an independent fixed allowance.

### Proof of Concept
Integration test plan (extending `streamer/src/nonblocking/quic.rs` test harness, e.g. near `test_throttling_check_no_packet_drop`):
1. Spin up `setup_quic_server` with `SwQosConfig { max_unstaked_connections: N, max_connections_per_unstaked_peer: M, .. }` for some N (e.g. 100) and low `M`.
2. Open N distinct unstaked QUIC client connections (using distinct client endpoints to simulate distinct sources, up to N/M grouping constraint).
3. From each connection concurrently, call `open_uni` + write in a loop for the duration of several `STREAM_THROTTLING_INTERVAL` windows (e.g. 1 second), attempting to sustain the max allowed per-connection rate (~20 streams/100ms).
4. Measure `stats.total_new_streams` accepted per second across all connections combined.
5. Assert that the aggregate accepted streams/sec is bounded near `MAX_UNSTAKED_TPS` (200) scaled by some fixed cluster-wide factor — current code will show aggregate throughput ≈ N * 200 (violating the expectation), demonstrating the per-connection (not aggregate) enforcement. [12](#0-11)

        &self,
        peer_type: ConnectionPeerType,
        total_stake: u64,
    ) -> u64 {
        match peer_type {
            ConnectionPeerType::Unstaked => self.max_unstaked_load_in_throttling_window,
            ConnectionPeerType::Staked(stake) => {
                if self.staked_throttling_enabled.load(Ordering::Relaxed) {
                    // 1 is added to `max_unstaked_load_in_throttling_window` to guarantee that staked
                    // clients get at least 1 more number of streams than unstaked connections.
                    self.max_staked_load_in_throttling_window
                        .saturating_mul(stake)
                        .checked_div(total_stake)
                        .unwrap_or(self.max_unstaked_load_in_throttling_window + 1)
                        .max(self.max_unstaked_load_in_throttling_window + 1)
                } else {
                    self.max_staked_load_in_throttling_window
                }
            }
        }

pub struct ConnectionStreamCounter {
    pub(crate) stream_count: AtomicU64,
    last_throttling_instant: RwLock<tokio::time::Instant>,
}

impl OpaqueStreamerCounter for ConnectionStreamCounter {}

impl ConnectionStreamCounter {
    pub fn new() -> Self {
        Self {
            stream_count: AtomicU64::default(),
            last_throttling_instant: RwLock::new(tokio::time::Instant::now()),
        }
    }

    /// Reset the counter and last throttling instant and
    /// return last_throttling_instant regardless it is reset or not.
    pub(crate) fn reset_throttling_params_if_needed(&self) -> tokio::time::Instant {
        let last_throttling_instant = *self.last_throttling_instant.read().unwrap();
        if tokio::time::Instant::now().duration_since(last_throttling_instant)
            > STREAM_THROTTLING_INTERVAL
        {
            let mut last_throttling_instant = self.last_throttling_instant.write().unwrap();
            // Recheck as some other thread might have done throttling since this thread tried to acquire the write lock.
            if tokio::time::Instant::now().duration_since(*last_throttling_instant)
                > STREAM_THROTTLING_INTERVAL
            {
                *last_throttling_instant = tokio::time::Instant::now();
                self.stream_count.store(0, Ordering::Relaxed);
            }
            *last_throttling_instant
        } else {
            last_throttling_instant
        }
    }
}

pub(crate) async fn throttle_stream(
    stats: &StreamerStats,
    peer_type: ConnectionPeerType,
    remote_addr: std::net::SocketAddr,
    stream_counter: &Arc<ConnectionStreamCounter>,
    max_streams_per_throttling_interval: u64,
) {
    let throttle_interval_start = stream_counter.reset_throttling_params_if_needed();
    let streams_read_in_throttle_interval = stream_counter.stream_count.load(Ordering::Relaxed);
    if streams_read_in_throttle_interval >= max_streams_per_throttling_interval {
        // The peer is sending faster than we're willing to read. Sleep for what's
        // left of this read interval so the peer backs off.
        let throttle_duration =
            STREAM_THROTTLING_INTERVAL.saturating_sub(throttle_interval_start.elapsed());

        if !throttle_duration.is_zero() {
            debug!(
                "Throttling stream from {remote_addr:?}, peer type: {peer_type:?}, \
                 max_streams_per_interval: {max_streams_per_throttling_interval}, \
                 read_interval_streams: {streams_read_in_throttle_interval} throttle_duration: \
                 {throttle_duration:?}"
            );
            stats.throttled_streams.fetch_add(1, Ordering::Relaxed);
            match peer_type {
                ConnectionPeerType::Unstaked => {
                    stats
                        .throttled_unstaked_streams
                        .fetch_add(1, Ordering::Relaxed);
                }
                ConnectionPeerType::Staked(_) => {
                    stats
                        .throttled_staked_streams
                        .fetch_add(1, Ordering::Relaxed);
                }
            }
            sleep(throttle_duration).await;
        }
    }
}

use {
    solana_net_utils::token_bucket::{KeyedRateLimiter, TokenBucket},
    std::net::IpAddr,
};

/// Limits the rate of connections per IP address.
pub struct ConnectionRateLimiter {
    limiter: KeyedRateLimiter<IpAddr>,
}

/// The threshold of the size of the connection rate limiter map. When
/// the map size is above this, we will trigger a cleanup of older
/// entries used by past requests.
const CONNECTION_RATE_LIMITER_CLEANUP_SIZE_THRESHOLD: usize = 100_000;

impl ConnectionRateLimiter {
    /// Create a new rate limiter per IpAddr. The rate is specified as the count per minute to allow for
    /// less frequent connections. Higher limit also allows higher bursts.
    /// num_shards controls how many shards are used in the underlying dashmap,
    /// should be set >= number of contending threads.
    pub fn new(limit_per_minute: u64, max_burst: u64, num_shards: usize) -> Self {
        Self {
            limiter: KeyedRateLimiter::new(
                CONNECTION_RATE_LIMITER_CLEANUP_SIZE_THRESHOLD,
                TokenBucket::new(limit_per_minute, max_burst, limit_per_minute as f64 / 60.0),
                num_shards,
            ),
        }
    }

    /// Check if the connection from the said `ip` is allowed.
    /// Here we assume that only IPs with actual confirmed connections are stored in it,
    /// since we should only modify server state once source IP is verified
    pub fn is_allowed(&self, ip: &IpAddr) -> bool {
        // Check if we have records in the rate limiter for the given IP address
        match self.limiter.current_tokens(ip) {
            Some(r) => r > 0, // we have a record, and rate is not exceeded
            None => true,     // if we have not seen IP, allow connection request
        }
    }

    pub fn register_connection(&self, ip: &IpAddr) -> bool {
        if self.limiter.consume_tokens(*ip, 1).is_ok() {
            debug!("Request from IP {ip:?} allowed");
            true // Request allowed
        } else {
            debug!("Request from IP {ip:?} blocked");
            false // Request blocked
        }
    }
