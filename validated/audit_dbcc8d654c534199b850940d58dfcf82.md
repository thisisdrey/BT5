### Title
Out-of-bounds slice read in reftable block parser due to unvalidated length fields - ([File: internal/git/reftable/reftable.go])

### Summary
`internal/git/reftable/reftable.go` parses the Git "reftable" ref-storage format directly out of an in-memory byte slice using length and count fields taken from the file itself, without validating that the resulting slice bounds stay inside the buffer. This is the same bug class as CVE-2017-13010: a length-prefixed field is trusted to compute an offset/length pair that is then used to slice/compare a buffer, without confirming the slice stays within the allocated buffer, resulting in an out-of-bounds read.

### Finding Description
`extractBlockLen` reads a 3-byte length straight out of the block header with no bound check against `len(src)`: [1](#0-0) 

`parseRefBlock` then uses that attacker/file-controlled length (`currentBS`) to locate the restart-count trailer and compute `RestartStart` using unsigned arithmetic that can underflow if `currentBS` is small or `RestartCount` is large: [2](#0-1) 

`getRefsFromBlock` walks the block using `getVarInt` to decode `prefixLength`, `suffixLength`, hash sizes, and symref sizes, then directly slices `src` with these values: [3](#0-2) 

None of `src[idx:idx+suffixLength]`, `src[idx:idx+uint(hashSize)]`, or `src[idx:idx+size]` are checked against `len(src)` (or even against `b.RestartStart`/`b.FullBlockSize` other than as a loop-continuation condition evaluated *before* the current record is fully parsed). A single record whose length field is inflated can push `idx+length` past the end of the underlying byte slice returned by `io.ReadAll(t.src)` in `GetReferences`: [4](#0-3) 

In Go this manifests as a slice-bounds-out-of-range runtime panic rather than a silent heap over-read (Go's runtime enforces slice bounds), but the root cause — trusting an on-disk length field to index a buffer without validating it against the buffer's actual size — is the direct analog of `l_strnstart()`'s missing length check in the tcpdump report.

### Impact Explanation
A malformed `.ref` table file reaching this parser causes an unrecovered panic in the RPC-handling goroutine, crashing the goroutine (and, depending on gRPC panic-recovery configuration, potentially the whole Gitaly process) that is processing a reference-listing operation. `Table.GetReferences`/`ParseTable`/`parseRefBlock` are invoked from `internal/gitaly/storage/storagemgr/partition/reftable.go`'s `stageTables()` during transaction commit (executed for every push against a repository that uses the reftable backend) and from `internal/gitaly/service/repository/replicate.go`. This gives a DoS of the RPC handler processing pushes or ref replication against reftable-backend repositories.

### Likelihood Explanation
Reachability requires the repository to use the reftable ref-storage backend (not the default `files` backend) and requires a `.ref` table file with a corrupted/oversized block-length or varint field to be present in the repository directory that `ParseTable`/`GetReferences` reads. This can occur via: (1) reftable files brought in during repository import/fork from an external, non-Gitaly-managed source that places crafted files under `reftable/`, or (2) replication of an already-corrupted table from another storage node. `parseHeader`/`parseFooter` validate the header/footer magic, version, and checksum, but there is no equivalent validation of individual block bodies before `getRefsFromBlock` walks them, so a corrupted body downstream of a valid header/footer/checksum is not rejected.

### Recommendation
Add explicit bounds checks in `extractBlockLen`, `parseRefBlock`, `getVarInt`, and `getRefsFromBlock` before every slice operation, verifying that computed offsets (`blockStart+4`, `idx+suffixLength`, `idx+hashSize`, `idx+size`, and `blockStart+currentBS-2`) do not exceed `len(src)` and that `currentBS`/`RestartCount` cannot cause `RestartStart` to underflow. Reject the table with an error instead of panicking when a computed length would run past the buffer.

### Proof of Concept
Conceptual (a background Devin session with filesystem/test access would be needed to fully confirm the panic at runtime):
1. Create a reftable-backend repository and take a valid `.ref` file produced by `ParseTable`.
2. Patch the block-length byte(s) read by `extractBlockLen` (offset `blockStart+headerOffset+1..+4`) to a value that makes `currentBS` small enough that `RestartStart` computation underflows, or patch a varint length byte inside a ref record (consumed by `getVarInt`/`getRefsFromBlock`) to an oversized value.
3. Call `reftable.ParseTable(path)` followed by `Table.GetReferences()` (as done by `stageTables` in `internal/gitaly/storage/storagemgr/partition/reftable.go` during a push, or by `internal/gitaly/service/repository/replicate.go`).
4. Observe a `runtime error: slice bounds out of range` panic originating from `getRefsFromBlock`/`parseRefBlock`, matching the existing test harness pattern in `internal/git/reftable/reftable_test.go` (`patchHeader`/`patchTable` helpers used for other corruption tests around lines 283-365) but targeting the block body instead of the header/footer.

// getRefsFromBlock provides the ref udpates from a reference block.
func (t *Table) getRefsFromBlock(src []byte, b *block) ([]git.Reference, error) {
	var references []git.Reference

	prefix := ""

	// Skip the block_type and block_len
	idx := b.BlockStart + 4

	for idx < b.RestartStart {
		var prefixLength, suffixLength, updateIndexDelta uint
		var err error

		idx, prefixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting prefix length: %w", err)
		}

		idx, suffixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting suffix length: %w", err)
		}

		extra := (suffixLength & 0x7)
		suffixLength >>= 3

		refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])
		idx = idx + suffixLength

		idx, updateIndexDelta, err = t.getVarInt(src, idx, b.FullBlockSize)
		if err != nil {
			return nil, fmt.Errorf("getting update index delta: %w", err)
		}
		// we don't use this for now
		_ = updateIndexDelta

		reference := git.Reference{
			Name: git.ReferenceName(refname),
		}

		switch extra {
		case 0:
			// Deletion, no value
			reference.Target = t.shaFormat().ZeroOID.String()
		case 1:
			// Regular reference
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)
		case 2:
			// Peeled Tag
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)

			// For now we don't need the peeledOID, but we still need
			// to skip the index.
			// peeledOID := ObjectID(bytesToHex(t.src[idx : idx+uint(hashSize)]))
			idx += uint(hashSize)
		case 3:
			// Symref
			var size uint
			idx, size, err = t.getVarInt(src, idx, b.FullBlockSize)
			if err != nil {
				return nil, fmt.Errorf("getting symref size: %w", err)
			}

			reference.Target = git.ReferenceName(src[idx : idx+size]).String()
			reference.IsSymbolic = true
			idx = idx + size
		}

		prefix = refname

		references = append(references, reference)
	}

	return references, nil
}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}

// GetReferences returns all references from the table.
func (t *Table) GetReferences() ([]git.Reference, error) {
	headerOffset := uint(t.footer.Version.HeaderSize())
	offset := uint(0)
	var allRefs []git.Reference

	if _, err := t.src.Seek(0, io.SeekStart); err != nil {
		return nil, fmt.Errorf("seek start: %w", err)
	}

	src, err := io.ReadAll(t.src)
	if err != nil {
		return nil, fmt.Errorf("read all: %w", err)
	}

	for offset < t.footerOffset {
		blockStart, blockEnd := t.getBlockRange(offset, t.blockSize)
		if blockStart == 0 && blockEnd == 0 {
			break
		}

		// If we run out of ref blocks, we can stop the iteration.
		if src[blockStart+headerOffset] != 'r' {
			return allRefs, nil
		}

		references, err := t.parseRefBlock(src, headerOffset, blockStart, blockEnd)
		if err != nil {
			return nil, fmt.Errorf("parsing block: %w", err)
		}

		if len(references) == 0 {
			break
		}

		allRefs = append(allRefs, references...)

		offset = blockEnd
	}

	return allRefs, nil
}
