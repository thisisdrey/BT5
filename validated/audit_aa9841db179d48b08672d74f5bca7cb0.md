### Title
Interest continues to accrue on `Paused` banks via the permissionless `lending_pool_accrue_bank_interest` instruction while `repay` is blocked - ([File: programs/marginfi/src/instructions/marginfi_group/accrue_bank_interest.rs])

### Summary
When a group admin sets a bank's `operational_state` to `Paused`, all user-facing operations (deposit, borrow, withdraw, repay, liquidate) are blocked via `validate_bank_state`. However, the permissionless `LendingPoolAccrueBankInterest` instruction does not check the bank's `operational_state` at all — it only checks the group-level `is_protocol_paused()` flag. Any unprivileged user can therefore keep calling this instruction to accrue interest on a `Paused` bank's liabilities, growing borrower debt while those same borrowers are prevented from repaying, reproducing the TRST-M-8 bug class described in the referenced report.

### Finding Description
`lending_account_repay` explicitly blocks repayment on a `Paused` bank: [1](#0-0) 

`validate_bank_state` confirms that `FailsInPausedState` (used by repay) and `FailsIfPausedOrReduceState` (used by deposit/borrow) both reject the `Paused` state: [2](#0-1) 

The stand-alone, permissionless interest-accrual instruction, by contrast, has no such check — it only validates that the group is not globally/protocol-paused, and does not inspect `bank.config.operational_state` at all: [3](#0-2) 

Because `Bank::accrue_interest` itself has no operational-state guard — it only checks whether `total_assets`/`total_liabilities` are zero and unconditionally recomputes `asset_share_value`/`liability_share_value` based on elapsed time — any unprivileged caller invoking `lending_pool_accrue_bank_interest` on a bank that is `Paused` (but not `KilledByBankruptcy`, and while the protocol/group itself is not globally paused) will keep growing `liability_share_value` for existing borrowers: [4](#0-3) 

This documentation confirms the intended behavior of `Paused` is that "all operations are halted," with no carve-out mentioned for interest continuing to accrue: [5](#0-4) 

### Impact Explanation
A borrower whose bank has been set to `Paused` by the admin cannot repay their debt (`BankPaused` error), but any unprivileged third party can still permissionlessly call `lending_pool_accrue_bank_interest` on that same bank, causing the borrower's `liability_share_value` (and thus their outstanding debt) to keep growing. This can push previously healthy positions toward unhealthiness/liquidation or toward insolvency/bad debt for the group, purely as a side effect of an admin pause the borrower has no way to react to (since repay is blocked). This matches the accepted medium-severity finding from the analogous report: interest is not paused in lockstep with repay being paused.

### Likelihood Explanation
The `lending_pool_accrue_bank_interest` instruction is permissionless and requires no special role — any account can call it for any bank at any time (as long as the group is not globally/protocol-paused). Admins pausing individual banks (e.g. for maintenance, migration, or a security incident short of a full protocol pause) is an anticipated and documented lifecycle state, not a rare edge case, making this reachable in normal operational scenarios.

### Recommendation
Add an operational-state check to `LendingPoolAccrueBankInterest` (or to `Bank::accrue_interest` itself) so that interest accrual is halted whenever the bank is in `Paused` state (and/or gate it the same way as `FailsInPausedState`/`FailsIfPausedOrReduceState` are used elsewhere), ensuring debt cannot grow on a bank whose borrowers are simultaneously prevented from repaying.

### Proof of Concept
1. Group admin calls `LendingPoolConfigureBank` to set a bank's `operational_state` to `Paused`.
2. Borrower with an outstanding liability on that bank attempts `LendingAccountRepay` → fails with `MarginfiError::BankPaused` (per `validate_bank_state` in `repay.rs`).
3. Any unprivileged account calls `LendingPoolAccrueBankInterest` on the same bank → succeeds because the instruction only checks `!group.load()?.is_protocol_paused()`, not `bank.config.operational_state`.
4. `Bank::accrue_interest` runs normally, increasing `liability_share_value` based on elapsed time, growing the borrower's debt with no way for them to repay it until the admin unpauses the bank.

pub fn validate_bank_state(bank: &Bank, kind: InstructionKind) -> MarginfiResult {
    if bank.config.operational_state == BankOperationalState::KilledByBankruptcy {
        return err!(MarginfiError::BankKilledByBankruptcy);
    }
    // Bank exists but has not completed one-time setup (e.g. JupLend seed deposit). Block every
    // operation until init runs.
    if bank.config.operational_state == BankOperationalState::Uninitialized {
        return err!(MarginfiError::BankUninitialized);
    }

    match kind {
        InstructionKind::FailsInReduceState if bank.config.operational_state.is_reduce_only() => {
            return err!(MarginfiError::BankReduceOnly);
        }

        InstructionKind::FailsInPausedState
            if bank.config.operational_state == BankOperationalState::Paused =>
        {
            return err!(MarginfiError::BankPaused);
        }

        InstructionKind::FailsIfPausedOrReduceState
            if matches!(
                bank.config.operational_state,
                BankOperationalState::Paused
                    | BankOperationalState::ReduceOnly
                    | BankOperationalState::ReduceOnlyWithBorrowingPower
            ) =>
        {
            return match bank.config.operational_state {
                BankOperationalState::Paused => {
                    err!(MarginfiError::BankPaused)
                }
                state if state.is_reduce_only() => {
                    err!(MarginfiError::BankReduceOnly)
                }
                _ => unreachable!(),
            };
        }
        _ => {}
    }

pub fn lending_pool_accrue_bank_interest(
    ctx: Context<LendingPoolAccrueBankInterest>,
) -> MarginfiResult {
    let clock = Clock::get()?;
    let mut bank = ctx.accounts.bank.load_mut()?;
    let group = &ctx.accounts.group.load()?;

    bank.accrue_interest(
        clock.unix_timestamp,
        group,
        #[cfg(not(feature = "client"))]
        ctx.accounts.bank.key(),
    )?;

    // TODO see if we can recycle some things like the InterestRateCalc from accrue to save some CU
    bank.update_bank_cache(group)?;

    Ok(())
}

#[derive(Accounts)]
pub struct LendingPoolAccrueBankInterest<'info> {

        has_one = group @ MarginfiError::InvalidGroup
