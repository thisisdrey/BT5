## Missing authentication on the signer's `SignerEventReceiver` HTTP endpoints, allowing unauthenticated remote shutdown/DoS — (File: `libsigner/src/events.rs`)

### Summary
The stacks-signer's inbound HTTP event server (`SignerEventReceiver`, in `libsigner/src/events.rs`) accepts and processes `POST` requests on `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, and `/shutdown` with no authentication check whatsoever, unlike every comparable privileged endpoint in `stackslib`.

### Finding Description
`SignerEventReceiver::next_event()` binds a `tiny_http` server and dispatches based solely on URL path, with zero checks on headers, tokens, or peer identity: [1](#0-0) 

Notably, the `/shutdown` branch immediately flips the receiver's stop flag for any caller: [2](#0-1) 

This is a direct architectural analog to the reported "EmbeddedServer ... missing authentication for the component API Endpoint" bug class: an HTTP server exposing privileged actions with no auth gate. By contrast, every comparable privileged RPC handler in `stackslib/src/net/api/*` (e.g. `blockreplay.rs`, `blocksimulate.rs`, `postblock_proposal.rs`, `postblock_v3.rs`, `fastcallreadonly.rs`, `txsimulate.rs`) explicitly requires an `authorization` header matching a configured password before processing: [3](#0-2) [4](#0-3) 

The `SignerEventReceiver` has no equivalent guard. The `auth_token` field that does exist in the signer's config is only consumed for outbound requests the signer makes *to* the Stacks node (client credential), not to protect this inbound listener: [5](#0-4) 

The `Signer::spawn` path shows the receiver is bound directly to `bind_addr` from config with no additional access control layered on top: [6](#0-5) 

### Impact Explanation
Any remote, unprivileged party who can reach the signer's listening endpoint (which operators are told to run "locally," but is a plain TCP/HTTP listener with no authentication enforced in code) can send a single unauthenticated `POST /shutdown` and permanently terminate the event receiver's main loop: [7](#0-6) 

Once stopped, the signer stops receiving burn-block events, block proposals/validation responses, and stacker DB chunk pushes from the node — a remote, unauthenticated denial-of-service achievable with a single crafted HTTP request, matching the "Critical - remote crash/unauthenticated DoS from few messages" impact tier. The `stacks-signer` codebase itself documents the risk of exposing this listener without additional protection, which confirms no protection exists at the code layer: [8](#0-7) 

### Likelihood Explanation
This requires only network reachability to the signer's configured `endpoint` (bind address/port) — no credentials, no valid signature, and no privileged role. Given signer endpoints must be reachable by the paired Stacks node (frequently across a local network, VPN, or in operator configurations that are not strictly loopback-bound), the likelihood of exposure is directly proportional to how the operator's network topology restricts access — the application layer provides no defense-in-depth of its own.

### Recommendation
Add an authentication check (e.g., a shared secret/token compared to a configured value, mirroring the `auth_header != password` pattern used across `stackslib/src/net/api/*` handlers) to `SignerEventReceiver::next_event()` before dispatching to any of `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, and especially `/shutdown`. At minimum, the `/shutdown` action should require proof of authorization since it is a state-changing/DoS-capable action reachable by any TCP peer.

### Proof of Concept
Given a running signer bound to `bind_addr` (e.g. `127.0.0.1:30000`, or any reachable address per operator config), an attacker with network access simply sends:
```
POST /shutdown HTTP/1.1
Host: <signer-endpoint>
Connection: close

```
This is enough to trip `event_receiver.stop_signal.store(true, Ordering::SeqCst)` and return `EventError::Terminated`, terminating the receiver's `main_loop()` with no credentials required — matching the test harness pattern already present in the repo for issuing raw requests to this listener: [9](#0-8)

    fn main_loop(&mut self) {
        loop {
            if self.is_stopped() {
                info!("Event receiver stopped");
                break;
            }
            let next_event = match self.next_event() {
                Ok(event) => event,
                Err(EventError::UnrecognizedEvent(..)) => {
                    // got an event that we don't care about (not a problem)
                    continue;
                }
                Err(EventError::Terminated) => {
                    // we're done
                    info!("Caught termination signal");
                    break;
                }
                Err(e) => {
                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };
            if !self.forward_event(next_event) {
                info!("Failed to forward event");
                break;
            }
        }
        info!("Event receiver main loop exit");
    }

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    pub fn spawn(&mut self, bind_addr: SocketAddr) -> Result<RunningSigner<EV, R, T>, EventError> {
        let mut event_receiver = self
            .event_receiver
            .take()
            .ok_or(EventError::AlreadyRunning)?;
        let result_sender = self
            .result_sender
            .take()
            .ok_or(EventError::AlreadyRunning)?;
        let mut signer_loop = self.signer_loop.take().ok_or(EventError::AlreadyRunning)?;

        let (event_send, event_recv) = channel();
        event_receiver.add_consumer(event_send);

        let bind_port = bind_addr.port();
        event_receiver.bind(bind_addr)?;
        let stop_signaler = event_receiver.get_stop_signaler()?;
        let mut ret_stop_signaler = event_receiver.get_stop_signaler()?;

        // start a thread for the event receiver
        let event_thread = thread::Builder::new()
            .name(format!("event_receiver:{bind_port}"))
            .stack_size(THREAD_STACK_SIZE)
            .spawn(move || event_receiver.main_loop())

                error!("EventReceiver failed to start: {:?}", &e);
