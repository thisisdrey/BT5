### Title
Unauthenticated `/shutdown` POST terminates the signer's event-receiver loop - (File: `libsigner/src/events.rs`)

### Finding Description
`SignerEventReceiver::next_event` in `libsigner/src/events.rs` dispatches on `request.url()` after only checking that the HTTP method is `POST`. For the `/shutdown` path it immediately executes `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)` with no signature, secret, or origin check of any kind: [1](#0-0) 

This is the same atomic flag exposed by `SignerStopSignaler::send`, which is the mechanism the local stacks-node process is *intended* to use to gracefully stop the signer's event thread by connecting to the signer's bound event-receiver socket and POSTing to `/shutdown`: [2](#0-1) 

Any TCP client that can reach the signer's event-receiver listening address (bound via `bind_addr`/`config.endpoint` in `stacks-signer/src/lib.rs`) can open a raw socket and send `POST /shutdown HTTP/1.1 ...` to trigger `stop_signal.store(true, SeqCst)`. Once set, `next_event` immediately returns `EventError::Terminated` on any subsequent call (checked via `is_stopped()` at the top of `next_event`), and `EventReceiver::main_loop` treats `EventError::Terminated` as a clean exit and breaks out of the loop, permanently ending event delivery to the signer runloop: [3](#0-2) [4](#0-3) 

No comparison of a shared secret, no TLS client cert, no source-IP allowlist, and no correlation with the node's RPC/auth token gates this branch — the only "authentication" is reaching the TCP port and speaking basic HTTP. This is also acknowledged in the codebase itself: `stacks-signer/src/lib.rs::SpawnedSigner::new` emits a runtime warning that exposing this endpoint to anything other than a trusted local node is a security risk, but the code contains no enforcement of that expectation: [5](#0-4) 

### Impact Explanation
Any party capable of opening a TCP connection to the signer's event-receiver port can permanently halt the signer's event processing with a single well-formed HTTP POST, no signature or shared secret required. This terminates delivery of `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, and `StacksBlockEvent` notifications to the signer runloop, effectively disabling that signer's ability to observe and participate in block signing until the operator restarts the signer process. This is a repeatable, single-message, unauthenticated DoS against a signer node.

### Likelihood Explanation
The only precondition is TCP reachability to the signer's configured event-receiver `endpoint`. In typical deployments this endpoint is meant to be bound to a loopback/private address reachable only by the local, co-located stacks-node — a network-level mitigation, not a check enforced by the code. If the endpoint is reachable (e.g., misconfigured to bind on a non-loopback interface, or reachable through internal network segments not fully isolated from untrusted parties), exploitation cost is a single crafted HTTP request with no cryptographic material needed.

### Recommendation
Add authentication to the `/shutdown` (and ideally all) event-receiver endpoints — e.g., require a shared secret/token configured between the node and its co-located signer and verified before honoring `/shutdown`, or restrict `bind()` to enforce loopback-only binding and reject connections not originating from localhost.

### Proof of Concept

```rust
// libsigner/src/tests/mod.rs style test
#[test]
fn test_unauthenticated_shutdown() {
    let ev = SignerEventReceiver::<SignerMessage>::new(false);
    let (res_send, _res_recv) = channel();
    let mut signer = Signer::new(SimpleRunLoop::new(5), ev, res_send);
    let endpoint: SocketAddr = "127.0.0.1:32000".parse().unwrap();
    let running_signer = signer.spawn(endpoint).unwrap();

    // "foreign" attacker client - no secret, no auth, just raw TCP
    let mut sock = TcpStream::connect(endpoint).unwrap();
    let body = "attacker shutdown";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {endpoint}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    sock.write_all(req.as_bytes()).unwrap();

    // event loop terminates immediately with no further events processed
    let accepted_events = running_signer.stop().unwrap();
    // main_loop already exited on EventError::Terminated before receiving any real events
}
```
