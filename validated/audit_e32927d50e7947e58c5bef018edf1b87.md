### Title
Missing zero-address validation on `new_authority` in account migration allows permanent lock of funds - (File: `programs/marginfi/src/instructions/marginfi_account/transfer_account.rs`)

### Summary
`transfer_to_new_account` / `transfer_to_new_account_pda` let the current authority of a `MarginfiAccount` migrate all positions to a brand-new account under an arbitrary `new_authority` pubkey, but the program never validates that `new_authority` is non-zero/non-default before disabling the old account and finalizing the migration. This mirrors the reported bug class (constructor accepting an unvalidated critical address parameter, rendering the contract/account permanently unusable).

### Finding Description
`TransferToNewAccount`/`TransferToNewAccountPda` accept `new_authority` as a completely unchecked account: [1](#0-0) 

The handler uses this value directly to set the authority of the freshly created account and then immediately disables the old account (`ACCOUNT_DISABLED`) and marks it migrated, with no way to reverse the operation: [2](#0-1) 

The same unchecked pattern exists in the PDA variant, where the PDA itself is derived from `new_authority.key()`: [3](#0-2) [4](#0-3) 

Neither instruction handler nor the `Accounts` struct constraints reject `new_authority == Pubkey::default()`. If the zero pubkey (or any pubkey with no corresponding private key) is passed, all positions (deposits, borrows, collateral) are irreversibly moved to an account that no one can ever sign for — nobody can withdraw, repay, or otherwise interact with the new account's balances, and the old account is already disabled and cannot be un-migrated (`AccountAlreadyMigrated` check blocks retrying).

Notably, the off-chain CLI tooling is aware of this exact risk and defends against it client-side: [5](#0-4) 

but this check exists only in `p0-cli`, not in the on-chain program, so any other caller (SDK, direct RPC/transaction construction, or a malicious front-end) bypasses it entirely. The Anchor account docs even flag this as a known unchecked field ("WARN: New authority is completely unchecked"), confirming the gap is unintentional/unmitigated at the protocol level.

### Impact Explanation
This is a genuine permanent lock/freeze of user funds: once migrated, the old account is disabled and the new account's authority (the zero pubkey or an unrecoverable pubkey) can never sign a transaction to operate on it. All collateral/borrow positions transferred to the new account become permanently inaccessible — a direct, protocol-level "permanent lock/freeze" of user funds, which is one of the explicitly accepted impact categories. This is reachable entirely by an unprivileged account authority acting on their own margin account (no validator/admin/privileged access required), matching the accepted class of analog (margin-account/core-accounting path).

### Likelihood Explanation
Likelihood is best characterized as a foot-gun / integration risk: it requires the calling client (SDK, custom integration, or user error) to supply a bad `new_authority` (zero or otherwise unrecoverable pubkey) without the client-side guard that exists in `p0-cli`. Since third-party integrators, bots, or direct RPC callers do not necessarily reuse `p0-cli`'s guard, and the on-chain program performs no defense-in-depth check, this is realistically triggerable by a mistake in any external caller/integration, or could be used adversarially in a social-engineering/phishing flow that gets a victim to sign a transfer instruction with an attacker-controlled unchecked or garbage new_authority.

### Recommendation
Add an explicit on-chain check in `transfer_to_new_account` and `transfer_to_new_account_pda` that rejects `new_authority == Pubkey::default()` (and optionally any account that is not a `Signer` or otherwise verifiably controllable), mirroring the client-side check already present in `p0-cli::marginfi_account_transfer`:
```rust
check!(
    ctx.accounts.new_authority.key() != Pubkey::default(),
    MarginfiError::InvalidAuthority // or similar
);
```
This should be placed before `finalize_migrated_old_account` is called, ensuring the old account is never irreversibly disabled in favor of an unusable new authority.

### Proof of Concept
1. Create a `MarginfiAccount` and deposit/borrow to establish non-trivial positions.
2. Call `transfer_to_new_account` (or `transfer_to_new_account_pda`) directly via a raw transaction (bypassing `p0-cli`), passing `new_authority = Pubkey::default()` (or any pubkey with no known private key) and a fresh `new_marginfi_account` keypair/PDA.
3. Observe the transaction succeeds: `old_account.migrated_to` is set, `old_account` is flagged `ACCOUNT_DISABLED`, and `new_account.authority == Pubkey::default()`.
4. Attempt to sign any subsequent instruction (deposit/withdraw/borrow/repay/close) on `new_account` — impossible since no private key exists for `Pubkey::default()`. Attempt to migrate back — blocked by `AccountAlreadyMigrated` on the old account. Funds are permanently locked.

fn finalize_migrated_old_account(
    old_account: &mut MarginfiAccount,
    new_account_key: Pubkey,
    current_timestamp: u64,
) {
    old_account.migrated_to = new_account_key;
    old_account.last_update = current_timestamp;
    old_account.lending_account = LendingAccount::zeroed();
    old_account.set_flag(ACCOUNT_DISABLED, true);
    old_account.sync_indexer_flags();
}

pub fn transfer_to_new_account(ctx: Context<TransferToNewAccount>) -> MarginfiResult {
    // Validate the global fee wallet and claim a nominal fee
    let group = ctx.accounts.group.load()?;
    check_eq!(
        ctx.accounts.global_fee_wallet.key(),
        group.fee_state_cache.global_fee_wallet,
        MarginfiError::InvalidFeeAta
    );
    anchor_lang::system_program::transfer(ctx.accounts.transfer_fee(), ACCOUNT_TRANSFER_FEE)?;

    let mut old_account = ctx.accounts.old_marginfi_account.load_mut()?;

    check!(
        !old_account.get_flag(ACCOUNT_IN_FLASHLOAN),
        MarginfiError::AccountInFlashloan
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_RECEIVERSHIP),
        MarginfiError::ForbiddenIx
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_ORDER_EXECUTION),
        MarginfiError::ForbiddenIx
    );

    check!(
        old_account.active_orders == 0,
        MarginfiError::IllegalAction,
        "Close all active orders before transfer"
    );

    // Prevent multiple migrations from the same account
    check_eq!(
        old_account.migrated_to,
        Pubkey::default(),
        MarginfiError::AccountAlreadyMigrated
    );

    let mut new_account = ctx.accounts.new_marginfi_account.load_init()?;
    let current_timestamp = Clock::get()?.unix_timestamp as u64;
    initialize_migrated_account(
        &mut new_account,
        &old_account,
        ctx.accounts.new_authority.key(),
        current_timestamp,
        ctx.accounts.old_marginfi_account.key(),
    );

    finalize_migrated_old_account(
        &mut old_account,
        ctx.accounts.new_marginfi_account.key(),
        current_timestamp,
    );

    emit!(MarginfiAccountTransferToNewAccount {
        header: AccountEventHeader {
            signer: Some(ctx.accounts.authority.key()),
            marginfi_account: ctx.accounts.new_marginfi_account.key(),
            marginfi_account_authority: ctx.accounts.new_authority.key(),
            marginfi_group: ctx.accounts.group.key(),
        },
        old_account: ctx.accounts.old_marginfi_account.key(),
        old_account_authority: ctx.accounts.authority.key(),
        new_account_authority: ctx.accounts.new_authority.key(),
    });

    Ok(())
}

pub fn transfer_to_new_account_pda(
    ctx: Context<TransferToNewAccountPda>,
    account_index: u16,
    third_party_id: Option<u16>,
) -> MarginfiResult {
    // Validate the global fee wallet and claim a nominal fee
    let group = ctx.accounts.group.load()?;
    check_eq!(
        ctx.accounts.global_fee_wallet.key(),
        group.fee_state_cache.global_fee_wallet,
        MarginfiError::InvalidFeeAta
    );
    anchor_lang::system_program::transfer(ctx.accounts.transfer_fee(), ACCOUNT_TRANSFER_FEE)?;

    let mut old_account = ctx.accounts.old_marginfi_account.load_mut()?;

    check!(
        !old_account.get_flag(ACCOUNT_IN_FLASHLOAN),
        MarginfiError::AccountInFlashloan
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_RECEIVERSHIP),
        MarginfiError::ForbiddenIx
    );

    check!(
        !old_account.get_flag(ACCOUNT_IN_ORDER_EXECUTION),
        MarginfiError::ForbiddenIx
    );

    check!(
        old_account.active_orders == 0,
        MarginfiError::IllegalAction,
        "Close all active orders before transfer"
    );

    // Prevent multiple migrations from the same account
    check_eq!(
        old_account.migrated_to,
        Pubkey::default(),
        MarginfiError::AccountAlreadyMigrated
    );

    // Validate third-party id restriction if provided
    if let Some(id) = third_party_id {
        if !is_allowed_cpi_for_third_party_id(&ctx.accounts.instructions_sysvar, id)? {
            return err!(MarginfiError::Unauthorized);
        }
    }

    let mut new_account = ctx.accounts.new_marginfi_account.load_init()?;
    let current_timestamp = Clock::get()?.unix_timestamp as u64;
    initialize_migrated_account(
        &mut new_account,
        &old_account,
        ctx.accounts.new_authority.key(),
        current_timestamp,
        ctx.accounts.old_marginfi_account.key(),
    );
    new_account.account_index = account_index;
    new_account.third_party_index = third_party_id.unwrap_or(0);
    new_account.bump = ctx.bumps.new_marginfi_account;

    finalize_migrated_old_account(
        &mut old_account,
        ctx.accounts.new_marginfi_account.key(),
        current_timestamp,
    );

    emit!(MarginfiAccountTransferToNewAccount {
        header: AccountEventHeader {
            signer: Some(ctx.accounts.authority.key()),
            marginfi_account: ctx.accounts.new_marginfi_account.key(),
            marginfi_account_authority: ctx.accounts.new_authority.key(),
            marginfi_group: ctx.accounts.group.key(),
        },
        old_account: ctx.accounts.old_marginfi_account.key(),
        old_account_authority: ctx.accounts.authority.key(),
        new_account_authority: ctx.accounts.new_authority.key(),
    });

    Ok(())
}
