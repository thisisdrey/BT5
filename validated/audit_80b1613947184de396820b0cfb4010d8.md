Based on my research, I found a directly analogous pattern already recognized and fixed multiple times in this codebase — but one precompile was missed.

### Title
System precompile (`0x900`) is missing the `PrecompileDelegateDenied` guard applied to every other caller-sensitive precompile - (File: `substrate/frame/revive/src/precompiles/builtin/system.rs`)

### Summary
The repository has repeatedly patched the exact bug class described in the Kakarot report: a precompile deriving caller identity from `env.caller()`, which during a `delegatecall` resolves to the *original* external caller rather than the immediate calling contract, letting an untrusted intermediary contract impersonate a trusted caller when invoking the precompile. This was fixed for the assets ERC20 precompile [1](#0-0) , and then generalized across the asset-conversion, XCM, and vesting precompiles via `PrecompileDelegateDenied` [2](#0-1) , with explicit guards in each: XCM [3](#0-2) , vesting [4](#0-3) , and the builtin Storage precompile enforcing the opposite (delegatecall-only) invariant [5](#0-4) . The System builtin precompile at fixed address `0x900`, however, has no such guard anywhere in its `call` implementation [6](#0-5) .

### Finding Description
`Stack::caller()` in `pallet-revive`'s execution engine explicitly returns the *original delegating caller* (`DelegateInfo.caller`) when the current top frame is a delegate-call frame, rather than the identity of the contract that issued the delegatecall [7](#0-6) . This is precisely the "code address vs execution address" confusion described in the Kakarot report.

The System precompile's `ISystemCalls::callerIsOrigin`, `callerIsRoot`, and `ownCodeHash` handlers all consume `env.caller()` (directly or via `caller_is_origin`/`caller_is_root`) to answer identity questions [8](#0-7) , and `ISystemCalls::terminate` performs a state-changing, fund-moving self-destruct via `env.terminate_caller(&h160)` guarded only by an `is_read_only` check — with no `is_delegate_call` check at all [9](#0-8) . Every sibling precompile in the codebase that touches caller-derived state or performs mutation (assets, asset-conversion, XCM, vesting) was hardened specifically because "Delegatecall to precompiles allows a malicious contract to execute precompile logic in a misleading caller context... There is no legitimate use case for delegatecalling into these precompiles" [10](#0-9) . System is the one caller-identity-consuming precompile left without this defense-in-depth guard at the precompile-call boundary.

### Impact Explanation
Any contract that a user or a DEX-style contract trusts to make bounded external calls (the same "DEX supporting callbacks" scenario from the original report) can be tricked into delegatecalling to `0x900`. Downstream logic gating privileged behavior on `callerIsOrigin()`, `callerIsRoot()`, or `ownCodeHash()` would observe the *original caller's* identity/code hash instead of the true immediate caller, enabling origin-escalation-style authorization bypass consistent with the "unauthorized execution or origin escalation" impact category. If `terminate`'s self-destruct/fund-transfer path is not independently protected against delegate-call framing further up the stack, it also matches "permanent user-fund lock" / unauthorized fund movement.

### Likelihood Explanation
Exploitability requires only an unprivileged contract deployer crafting a delegatecall to the fixed precompile address `0x900` — no privileged actor, relayer, or governance action needed, matching the "public entry-point, unprivileged attacker" bar. However, I could not fully rule out that `terminate_caller`'s implementation in `exec.rs` (not directly located within tool-call budget) independently re-checks `frame.delegate` before executing — a similarly-named guard string ("illegal to call this pre-compile via delegate call") appears in `substrate/frame/revive/src/tests/sol/terminate.rs`, which may indicate the termination path already has protection at a different layer. This uncertainty should be resolved before treating the `terminate` sub-case as conclusively exploitable; the `callerIsOrigin`/`callerIsRoot`/`ownCodeHash` identity-leak sub-case has no such caveat and is directly confirmed by the code shown above.

### Recommendation
Add the same `PrecompileDelegateDenied`/`is_delegate_call()` guard used by the assets, asset-conversion, XCM, and vesting precompiles to the top of `System::call` in `substrate/frame/revive/src/precompiles/builtin/system.rs`, rejecting any delegate-call invocation of the System precompile exactly as done in `polkadot/xcm/pallet-xcm/precompiles/src/lib.rs` lines 78–81, and add a `delegatecall_is_rejected` regression test mirroring the existing ones in the assets/asset-conversion/XCM/vesting precompile test suites.

### Proof of Concept
1. Deploy a `Caller`-style intermediary contract (as used in `polkadot/xcm/pallet-xcm/precompiles/src/tests.rs` lines 757-819) that exposes a `delegateCall(address callee, bytes data, uint64 gas)` function.
2. From this contract, delegatecall to `0x0000...0900` (System precompile) invoking `callerIsRoot()` or `ownCodeHash()`.
3. Because `Stack::caller()` resolves to the *original* external caller under delegate-call framing [11](#0-10) , the intermediary contract obtains root/identity attestations belonging to the original caller rather than itself, which any consuming contract that trusts System's precompile output for authorization would incorrectly honor — the same "impersonate the DEX" pattern from the Kakarot finding.

	fn call(
		_address: &[u8; 20],
		input: &Self::Interface,
		env: &mut impl Ext<T = Self::T>,
	) -> Result<Vec<u8>, Error> {
		use ISystem::ISystemCalls;
		match input {
			ISystemCalls::terminate(_) if env.is_read_only() => {
				Err(crate::Error::<T>::StateChangeDenied.into())
			},
			ISystemCalls::hashBlake256(ISystem::hashBlake256Call { input }) => {
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::HashBlake256(input.len() as u32))?;
				let output = sp_io::hashing::blake2_256(input.as_bytes_ref());
				Ok(output.abi_encode())
			},
			ISystemCalls::hashBlake128(ISystem::hashBlake128Call { input }) => {
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::HashBlake128(input.len() as u32))?;
				let output = sp_io::hashing::blake2_128(input.as_bytes_ref());
				Ok(output.abi_encode())
			},
			ISystemCalls::toAccountId(ISystem::toAccountIdCall { input }) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::ToAccountId)?;
				let account_id = env.to_account_id(&H160::from_slice(input.as_slice()));
				Ok(account_id.encode().abi_encode())
			},
			ISystemCalls::callerIsOrigin(ISystem::callerIsOriginCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::CallerIsOrigin)?;
				let is_origin = env.caller_is_origin(true);
				Ok(is_origin.abi_encode())
			},
			ISystemCalls::callerIsRoot(ISystem::callerIsRootCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::CallerIsRoot)?;
				let is_root = env.caller_is_root(true);
				Ok(is_root.abi_encode())
			},
			ISystemCalls::ownCodeHash(ISystem::ownCodeHashCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::OwnCodeHash)?;
				let caller = env.caller();
				let addr = T::AddressMapper::to_address(caller.account_id()?);
				let output = env.code_hash(&addr.into()).0.abi_encode();
				Ok(output)
			},
			ISystemCalls::minimumBalance(ISystem::minimumBalanceCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::MinimumBalance)?;
				let minimum_balance = env.minimum_balance();
				Ok(minimum_balance.to_big_endian().abi_encode())
			},
			ISystemCalls::weightLeft(ISystem::weightLeftCall {}) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::WeightLeft)?;
				let ref_time = env.frame_meter().weight_left().unwrap_or_default().ref_time();
				let proof_size = env.frame_meter().weight_left().unwrap_or_default().proof_size();
				let res = (ref_time, proof_size);
				Ok(res.abi_encode())
			},
			ISystemCalls::terminate(ISystem::terminateCall { beneficiary }) => {
				// no need to adjust gas because this always deletes code
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::Terminate { code_removed: true })?;
				let h160 = H160::from_slice(beneficiary.as_slice());
				env.terminate_caller(&h160).map_err(Error::try_to_revert::<T>)?;
				Ok(Vec::new())
			},
			ISystemCalls::sr25519Verify(ISystem::sr25519VerifyCall {
				signature,
				message,
				publicKey,
			}) => {
				env.frame_meter_mut()
					.charge_weight_token(RuntimeCosts::Sr25519Verify(message.len() as _))?;
				let ok = env.sr25519_verify(signature, message, publicKey);
				Ok(ok.abi_encode())
			},
			ISystemCalls::ecdsaToEthAddress(ISystem::ecdsaToEthAddressCall { publicKey }) => {
				env.frame_meter_mut().charge_weight_token(RuntimeCosts::EcdsaToEthAddress)?;
				let address =
					env.ecdsa_to_eth_address(publicKey).map_err(Error::try_to_revert::<T>)?;
				Ok(address.abi_encode())
			},
		}
	}

	fn caller(&self) -> Origin<T> {
		if let Some(Ok(mock_caller)) = self
			.exec_config

			.and_then(|mock_handler| mock_handler.mock_caller(self.frames.len()))

			return mock_caller;
		}

		if let Some(DelegateInfo { caller, .. }) = &self.top_frame().delegate {
			caller.clone()
		} else {
			self.frames()
				.nth(1)
				.map(|f| Origin::from_account_id(f.account_id.clone()))
				.unwrap_or(self.origin.clone())
		}
	}
