### Title
Unbounded remote-controlled packfile size in `FetchRemote` allows disk exhaustion of a storage shard - ([File: internal/gitaly/service/repository/fetch_remote.go])

### Summary
`fetchRemoteAtomic` invokes `git-fetch(1)` with `--dry-run --porcelain` against a caller-supplied remote URL, writing all received objects into a per-request quarantine directory before any reference update, hook, or size check runs. Because neither Gitaly nor the invoked `git-fetch(1)` command enforces any cap on the amount of data received, a malicious/controlled remote can stream an arbitrarily large packfile that fills the underlying storage shard.

### Finding Description
In `fetchRemoteAtomic` (`internal/gitaly/service/repository/fetch_remote.go:95-104`), a quarantine directory is created via `quarantine.New` and `quarantineRepo.FetchRemote(ctx, "inmemory", opts)` is executed with `DryRun: true`. `opts.CommandOptions` only carries refspec/URL/auth configuration built in `buildCommandOpts` (lines 260-304); there is no `pack.window`, transfer size cap, `git -c core.bigFileThreshold`, or streaming byte-limit passed to the `git-fetch` invocation. `quarantine.Migrate` (`internal/git/quarantine/quarantine.go:97-113`) only runs after the fetch has fully completed and reference updates are queued — meaning the entire packfile must already be resident on disk in `<storage>/+gitaly/tmp/quarantine-*` before any subsequent step (hook execution, `refUpdater.Commit()`, migration) occurs. `req.GetRemoteParams().GetUrl()` is attacker-influenced input (e.g., a pull-mirror URL or project import source under attacker control), so the attacker's server fully controls the response size and content of the fetch. No `storage.ValidateRelativePath`-style or quota check inspects the size of data being received during transfer; the only size accounting in the codebase (`internal/gitaly/service/repository/size.go`'s `dirSizeInBytes`, used by `GetObjectDirectorySize`) is a post-hoc read-only reporting RPC, not an enforcement mechanism invoked during fetch.

### Impact Explanation
This matches GitLab's "denial of service of an RPC handler" bounty class scoped to resource exhaustion. Because quarantine directories live on the same storage shard as all other repositories, filling the shard's disk via one attacker-controlled fetch/mirror/import can starve write operations (git objects, packs, WAL/transaction state) for every other repository hosted on that shard, not just the attacker's own repository — this breaks the expected isolation between tenants sharing storage.

### Likelihood Explanation
The attacker only needs the ability to point a `FetchRemote`-driven feature (pull mirroring or repository import by URL) at a server they control and have that server serve an oversized packfile in response to the git fetch negotiation — no privileged Gitaly/Praefect access, secrets, or GitLab Rails bug are required. This is straightforward and fully repeatable (can be re-triggered on every mirror update interval or on repeated import attempts), and can be resource-cheap for the attacker (e.g. a stream of duplicate/compressible blob data) while being disk-cheap-to-generate but expensive to store.

### Recommendation
Enforce a maximum transfer/object size during `git-fetch(1)` invocations driven by `FetchRemote` — e.g., pass Git's built-in `--depth`/pack byte-count safeguards are insufficient; instead, wrap the fetch subprocess's stdout/stderr or the quarantine directory writes with an active disk-quota/byte-counter that aborts the `git-fetch` process once a configurable ceiling (aligned with GitLab's `repository_size_limit`) is exceeded, and/or periodically check available free space on the storage shard during the fetch and cancel the context if a low-disk threshold is crossed.

func buildCommandOpts(ctx context.Context, opts *localrepo.FetchOpts, req *gitalypb.FetchRemoteRequest) error {
	remoteURL := req.GetRemoteParams().GetUrl()
	var config []gitcmd.ConfigPair

	for _, refspec := range getRefspecs(req.GetRemoteParams().GetMirrorRefmaps()) {
		config = append(config, gitcmd.ConfigPair{
			Key: "remote.inmemory.fetch", Value: refspec,
		})
	}

	if resolvedAddress := req.GetRemoteParams().GetResolvedAddress(); resolvedAddress != "" {
		modifiedURL, resolveConfig, err := gitcmd.GetURLAndResolveConfig(remoteURL, resolvedAddress)
		if err != nil {
			return fmt.Errorf("couldn't get curloptResolve config: %w", err)
		}

		remoteURL = modifiedURL
		config = append(config, resolveConfig...)
	}

	config = append(config, gitcmd.ConfigPair{Key: "remote.inmemory.url", Value: remoteURL})

	if featureflag.FetchRemoteProactiveAuth.IsEnabled(ctx) {
		if u, err := url.Parse(remoteURL); err == nil && u.User != nil {
			password, _ := u.User.Password()
			if u.User.Username() != "" && password != "" {
				config = append(config, gitcmd.ConfigPair{
					Key:   "http.proactiveAuth",
					Value: "basic",
				})
			}
		}
	}

	if authHeader := req.GetRemoteParams().GetHttpAuthorizationHeader(); authHeader != "" {
		config = append(config, gitcmd.ConfigPair{
			Key:   fmt.Sprintf("http.%s.extraHeader", req.GetRemoteParams().GetUrl()),
			Value: "Authorization: " + authHeader,
		})
	}

	opts.CommandOptions = append(opts.CommandOptions, gitcmd.WithConfigEnv(config...))

	return nil
}

// Migrate migrates all objects part of the quarantine directory into the repository and thus makes
// them generally available. This implementation follows the git.git's `tmp_objdir_migrate()`.
func (d *Dir) Migrate(ctx context.Context) error {
	repoPath, err := d.locator.GetRepoPath(ctx, d.repo, storage.WithRepositoryVerificationSkipped())
	if err != nil {
		return fmt.Errorf("migrating quarantine: %w", err)
	}

	objectDir := d.repo.GetGitObjectDirectory()
	if objectDir == "" {
		// Migrate the objects to the default object directory if the repository
		// didn't have an object directory explicitly configured.
		objectDir = "objects"
	}

	return migrate(ctx, d.dir.Path(), filepath.Join(repoPath, objectDir))
}

func (s *server) GetObjectDirectorySize(ctx context.Context, in *gitalypb.GetObjectDirectorySizeRequest) (*gitalypb.GetObjectDirectorySizeResponse, error) {
	repository := in.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}
	repo := s.localRepoFactory.Build(repository)

	path, err := repo.ObjectDirectoryPath(ctx)
	if err != nil {
		return nil, err
	}
	// path is the objects directory path, not repo's path
	sizeInBytes, err := dirSizeInBytes(path, snapshot.NewDefaultFilter(ctx))
	if err != nil {
		return nil, fmt.Errorf("calculating directory size: %w", err)
	}

	return &gitalypb.GetObjectDirectorySizeResponse{Size: sizeInBytes / 1024}, nil
}
