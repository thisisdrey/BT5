### Title
Committee-gated `UnfreezeBalanceV2` feature check missing in TVM native-contract path allows bypass via smart contract - (File: `actuator/src/main/java/org/tron/core/vm/nativecontract/UnfreezeBalanceV2Processor.java`)

### Summary
The transaction-based `UnfreezeBalanceV2Actuator` and the TVM-callable `UnfreezeBalanceV2Processor` duplicate almost identical validation logic for unstaking (TRON Power v2) balances, but the two copies have diverged: the actuator enforces a committee-controlled feature gate that the processor omits entirely.

### Finding Description
`UnfreezeBalanceV2Actuator.validate()` explicitly requires the `supportUnfreezeDelay` dynamic property (a feature flag that must be "opened by the committee") before any `UnfreezeBalanceV2Contract` transaction is accepted: [1](#0-0) 

`UnfreezeBalanceV2Processor.validate()`, which is the code path invoked when a smart contract triggers the native "unfreezeBalanceV2" TVM operation, replicates the same address/account/resource/unfreeze-amount checks but never checks `dynamicStore.supportUnfreezeDelay()`: [2](#0-1) 

Because these two validators are copy-pasted rather than sharing one implementation (the exact "avoid duplicate code" bug class from the report), the feature-flag check present in one was not carried over to the other. Grepping the TVM operation dispatch code (`Program.java`, `OperationActions.java`, `PrecompiledContracts.java`) that invokes `UnfreezeBalanceV2Processor` shows no independent `supportUnfreezeDelay` gate at the opcode-dispatch layer either, meaning nothing else protects this path.

### Impact Explanation
`supportUnfreezeDelay` is the governance switch that determines whether the "Stake 2.0" unfreeze-with-delay mechanism is active on the network. When it is disabled, ordinary users cannot submit `UnfreezeBalanceV2Contract` transactions at all. However, a smart contract can call the native `unfreezeBalanceV2` operation directly, which reaches `UnfreezeBalanceV2Processor.validate()`/`execute()` without ever checking whether the committee has enabled the feature. This lets a contract caller unstake TRON Power v2 balances and immediately reclaim TRX/resources (bypassing the delay-based accounting the actuator enforces) before the committee has officially rolled out the mechanism. This is an authorization/governance-gate bypass of a committee-controlled feature — a concrete unauthorized account/resource operation reachable purely from a contract call.

### Likelihood Explanation
Reachable by any account that deploys or calls a smart contract exercising the `unfreezeBalanceV2` native operation — no special privilege, validator status, or node compromise is required. The bug is a simple omitted check that is easy to trigger deterministically.

### Recommendation
Extract the `supportUnfreezeDelay()` gate (and any other checks required to remain consistent) into a single shared validation routine used by both `UnfreezeBalanceV2Actuator` and `UnfreezeBalanceV2Processor`, eliminating the duplicated/divergent copies, and add the missing check to `UnfreezeBalanceV2Processor.validate()`.

### Proof of Concept
1. On a network/testnet where `supportUnfreezeDelay` is not yet enabled (committee has not opened the proposal), attempt to submit an `UnfreezeBalanceV2Contract` transaction directly — it is rejected with "Not support UnfreezeV2 transaction, need to be opened by the committee" per `UnfreezeBalanceV2Actuator.validate()` line 107-110.
2. Deploy a smart contract that invokes the native `unfreezeBalanceV2` TVM operation (reachable via `OperationActions`/`Program.java`) targeting the caller's own previously-frozen V2 balance.
3. Because `UnfreezeBalanceV2Processor.validate()` never checks `supportUnfreezeDelay()`, the call succeeds and `execute()` proceeds to unfreeze the balance, demonstrating the gate bypass documented above. [3](#0-2)

  public void validate(UnfreezeBalanceV2Param param, Repository repo)
      throws ContractValidateException {
    if (repo == null) {
      throw new ContractValidateException(STORE_NOT_EXIST);
    }

    byte[] ownerAddress = param.getOwnerAddress();
    DynamicPropertiesStore dynamicStore = repo.getDynamicPropertiesStore();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }
    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    if (accountCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ACCOUNT_EXCEPTION_STR + readableOwnerAddress + "] does not exist");
    }
    long now = dynamicStore.getLatestBlockHeaderTimestamp();
    int unfreezingCount = accountCapsule.getUnfreezingV2Count(now);
    if (UnfreezeBalanceV2Actuator.getUNFREEZE_MAX_TIMES() <= unfreezingCount) {
      throw new ContractValidateException("Invalid unfreeze operation, unfreezing times is over limit");
    }
    switch (param.getResourceType()) {
      case BANDWIDTH:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.BANDWIDTH)) {
          throw new ContractValidateException("no frozenBalance(BANDWIDTH)");
        }
        break;
      case ENERGY:
        // validate frozen balance
        if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.ENERGY)) {
          throw new ContractValidateException("no frozenBalance(ENERGY)");
        }
        break;
      case TRON_POWER:
        if (dynamicStore.supportAllowNewResourceModel()) {
          if (!this.checkExistFrozenBalance(accountCapsule, Common.ResourceCode.TRON_POWER)) {
            throw new ContractValidateException("no frozenBalance(TRON_POWER)");
          }
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException("Unknown ResourceCode, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    if (!checkUnfreezeBalance(accountCapsule, param.getUnfreezeBalance(), param.getResourceType())) {
      throw new ContractValidateException(
          "Invalid unfreeze_balance, [" + param.getUnfreezeBalance() + "] is invalid");
    }

    if (accountCapsule.hasInvalidDelegatedV2()) {
      MUtil.checkCPUTimeForInvalidDelegatedV2Balance();
    }
  }

  public long execute(UnfreezeBalanceV2Param param, Repository repo) {
    byte[] ownerAddress = param.getOwnerAddress();
    long unfreezeBalance = param.getUnfreezeBalance();
    VoteRewardUtil.withdrawReward(ownerAddress, repo);

    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    long now = repo.getDynamicPropertiesStore().getLatestBlockHeaderTimestamp();

    long unfreezeExpireBalance = this.unfreezeExpire(accountCapsule, now);

    if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    long expireTime = this.calcUnfreezeExpireTime(now, repo);
    accountCapsule.addUnfrozenV2List(param.getResourceType(), unfreezeBalance, expireTime);

    this.updateTotalResourceWeight(accountCapsule, param.getResourceType(), unfreezeBalance, repo);
    this.updateVote(accountCapsule, param.getResourceType(), ownerAddress, repo);

    if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()
        && !accountCapsule.oldTronPowerIsInvalid()) {
      accountCapsule.invalidateOldTronPower();
    }

    repo.updateAccount(accountCapsule.createDbKey(), accountCapsule);
    return unfreezeExpireBalance;
  }
