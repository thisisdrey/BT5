## Finding [1](#0-0) 

### Title
Directory-name-based quarantine check allows cross-repository object directory access bypass - (File: internal/git/localrepo/paths.go)

### Summary
`Repo.ObjectDirectoryPath` decides whether a client-supplied `GitObjectDirectory` is a legitimate transaction quarantine directory purely by inspecting the **basename** of the resolved relative path (`baseDir == "quarantine"` or `tmp_objdir-*` under a `quarantine` parent). If that broad, name-based condition matches, the function skips the narrower, repository-specific ownership check that would otherwise require the path to be prefixed by `filepath.Join(tempDir, storage.QuarantineDirectoryPrefix(repo))`. This mirrors the Aragon `_auth` bug pattern: a broad/self-referential condition (matching by name only) is OR'd together with — and effectively bypasses — the narrow, resource-specific authorization check (matching by the repo's own SHA1-derived prefix).

### Finding Description
`ObjectDirectoryPath` first validates that `GitObjectDirectory` resolves inside the storage root via `storage.ValidateRelativePath(storagePath, ...)`. Then it computes:

```go
parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
baseDir := filepath.Base(relativeObjectDirectoryPath)
isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

if !isTransactionQuarantineDir {
    if _, origError := storage.ValidateRelativePath(repoPath, objectDirectoryPath); origError != nil {
        ...
        expectedQuarantinePrefix := filepath.Join(tempDir, storage.QuarantineDirectoryPrefix(repo))
        if !strings.HasPrefix(absoluteObjectDirectoryPath, expectedQuarantinePrefix) {
            return "", structerr.NewInvalidArgument("not a valid relative path: %w", origError)
        }
    }
}
``` [2](#0-1) 

The intended, narrow check is that a transaction quarantine directory must live under `TempDir(storage)` and be prefixed with `QuarantineDirectoryPrefix(repo)` — a SHA1 hash of the *specific* repository's relative path, guaranteeing the quarantine dir "belongs to the repo at hand" [3](#0-2) . However, `isTransactionQuarantineDir` is computed purely from the final path component's name, with no verification that the directory actually resides in this repository's temp/quarantine hierarchy. Any path within the storage whose last segment is literally `quarantine` (or `tmp_objdir*` under a `quarantine` parent) short-circuits and skips the ownership check entirely — this is the "broad self-scope bypasses narrow where-scope" defect.

`GitObjectDirectory` is a plain field on the `Repository` protobuf message [4](#0-3)  that any RPC client can set. The transaction middleware explicitly treats a populated `GitObjectDirectory`/`GitAlternateObjectDirectories` as a signal that the request is an "access check" loop-back from Rails and lets accessor RPCs through without re-validating the directory's true ownership: [5](#0-4) . Mutators are rejected in this path, but accessor RPCs (e.g. `GetObjectDirectorySize`, `FindCommits`, etc., which call `ObjectDirectoryPath`/consult object directories) are not.

### Impact Explanation
An attacker who can influence the `GitObjectDirectory` field of an accessor RPC (as GitLab Rails does during pre-receive access checks, and as any gRPC client technically can since it's an ordinary request field) can point it at any sibling path within the same storage whose basename is `quarantine` — for example another repository's own transaction-state `quarantine` directory, or an attacker-created directory under a path they control that simply ends in `/quarantine`. Because the ownership/prefix check tying the quarantine dir to the *calling* repository is skipped entirely, Gitaly will read objects (or otherwise trust the directory) as if it were this repository's own quarantine, resulting in cross-repository object directory access within the same storage. This is a concrete instance of the "cross-repository object access" class flagged as in-scope.

### Likelihood Explanation
Exploitation requires reachability of `ObjectDirectoryPath` with an attacker/GitLab-controlled `GitObjectDirectory` value and a same-storage directory literally named `quarantine` to exist (e.g., another repository's live transaction quarantine directory, or `tx-tmp/quarantine`-style paths seen in the codebase's own test fixtures) [6](#0-5) . This is plausible in normal operation since every concurrent push creates such directories, but successful exploitation additionally requires timing/knowledge of another repository's transient quarantine path, which somewhat lowers likelihood despite the check itself being trivially bypassable by name alone.

### Recommendation
Do not classify a directory as a "transaction quarantine directory" based on its basename alone. Always additionally verify that the resolved absolute path is contained within this repository's own temporary directory and matches `storage.QuarantineDirectoryPrefix(repo)`, mirroring the check already present in the `else` branch, regardless of whether the basename happens to be `quarantine`/`tmp_objdir*`. In other words, eliminate the `isTransactionQuarantineDir` early-exit and always perform the prefix-based ownership check.

### Proof of Concept
1. Repository A has `RelativePath = "repo-a"`; its quarantine prefix is `QuarantineDirectoryPrefix(repoA)` = `sha1("repo-a")`-derived string, e.g. `quarantine-aaaa-`.
2. During a concurrent push to Repository B (`RelativePath = "repo-b"`), Gitaly creates a legitimate transaction quarantine directory such as `STORAGE/+gitaly/tmp/quarantine-bbbb-XXXX/quarantine`.
3. A caller issues an accessor RPC (e.g. `GetObjectDirectorySize`) for Repository A, but sets:
   ```
   Repository{
     StorageName:   "storage",
     RelativePath:  "repo-a",
     GitObjectDirectory: "../../+gitaly/tmp/quarantine-bbbb-XXXX/quarantine",
   }
   ```
4. In `ObjectDirectoryPath`, `storage.ValidateRelativePath(storagePath, ...)` succeeds (path stays inside storage root). `baseDir` resolves to `"quarantine"`, so `isTransactionQuarantineDir` is `true`, and the block enforcing `expectedQuarantinePrefix` tied to `repo-a`'s own hash is skipped entirely.
5. `ObjectDirectoryPath` returns Repository B's live quarantine directory as if it belonged to Repository A, and the RPC operates on/reveals objects from Repository B's in-flight push — a cross-repository object directory access that bypasses the intended repo-ownership check, analogous to the Aragon `_auth` bug where a broad match short-circuited the narrow, resource-specific authorization.

// ObjectDirectoryPath returns the full path of the object directory. The errors returned are gRPC
// errors with relevant error codes and should be passed back to gRPC without further decoration.
func (repo *Repo) ObjectDirectoryPath(ctx context.Context) (string, error) {
	repoPath, err := repo.Path(ctx)
	if err != nil {
		return "", err
	}

	objectDirectoryPath := repo.GetGitObjectDirectory()
	if objectDirectoryPath == "" {
		return "", structerr.NewInvalidArgument("object directory path is not set")
	}

	storagePath, err := repo.locator.GetStorageByName(ctx, repo.GetStorageName())
	if err != nil {
		return "", fmt.Errorf("get storage by name: %w", err)
	}

	// Ensure the path points somewhere in the storage.
	relativeObjectDirectoryPath, err := storage.ValidateRelativePath(storagePath, filepath.Join(repoPath, objectDirectoryPath))
	if err != nil {
		return "", structerr.NewInvalidArgument("validate relative path: %w", err)
	}

	parentDir := filepath.Base(filepath.Dir(relativeObjectDirectoryPath))
	baseDir := filepath.Base(relativeObjectDirectoryPath)
	isTransactionQuarantineDir := (baseDir == "quarantine") || ((parentDir == "quarantine") && strings.HasPrefix(baseDir, "tmp_objdir"))

	// Transactions quarantine a repository by pointing the object directory to a 'quarantine' named
	// directory in the transaction's temporary directory. If the base directory is `quarantine`,
	// Git push may apply an additional layer of quarantine such as `/quarantine/tmp_objdir-incoming-Gbc29N`
	// so we don't assert the `/quarantine` being the last element of the path. We thus also check for
	// whether the parent directory is in `quarantine` and whether the base directory has the expected
	// `tmp_objdir` suffix.
	if !isTransactionQuarantineDir {
		// We need to check whether the relative object directory as given by the repository is
		// a valid path. This may either be a path in the Git repository itself, where it may either
		// point to the main object directory storage or to an object quarantine directory as
		// created by git-receive-pack(1). Alternatively, if that is not the case, then it may be a
		// manual object quarantine directory located in the storage's temporary directory. These
		// have a repository-specific prefix which we must check in order to determine whether the
		// quarantine directory does in fact belong to the repo at hand.
		if _, origError := storage.ValidateRelativePath(repoPath, objectDirectoryPath); origError != nil {
			tempDir, err := repo.locator.TempDir(repo.GetStorageName())
			if err != nil {
				return "", structerr.NewInvalidArgument("getting storage's temporary directory: %w", err)
			}

			expectedQuarantinePrefix := filepath.Join(tempDir, storage.QuarantineDirectoryPrefix(repo))
			absoluteObjectDirectoryPath := filepath.Join(repoPath, objectDirectoryPath)

			// The relative path is outside of the repository
			if !strings.HasPrefix(absoluteObjectDirectoryPath, expectedQuarantinePrefix) {
				return "", structerr.NewInvalidArgument("not a valid relative path: %w", origError)
			}
		}
	}

	fullPath := filepath.Join(repoPath, objectDirectoryPath)
	if _, err := os.Stat(fullPath); os.IsNotExist(err) {
		return "", structerr.NewNotFound("object directory does not exist: %q", fullPath)
	}

	return fullPath, nil
}
```

// QuarantineDirectoryPrefix returns a prefix for use in the temporary directory. The prefix is
// based on the relative repository path and will stay stable for any given repository. This allows
// us to verify that a given quarantine object directory indeed belongs to the repository at hand.
// Ideally, this function would directly be located in the quarantine module, but this is not
// possible due to cyclic dependencies.
func QuarantineDirectoryPrefix(repo Repository) string {
	hash := [20]byte{}
	if repo != nil {
		hash = sha1.Sum([]byte(repo.GetRelativePath()))
	}
	return fmt.Sprintf("quarantine-%x-", hash[:8])
}
