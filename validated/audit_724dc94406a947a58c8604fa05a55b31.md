### Title
Overpaid NEP-145 `storage_deposit` refund is permanently lost, not credited back to the user - (File: `contracts/defuse/src/contract/tokens/nep141/withdraw.rs`, `contracts/defuse/src/contract/tokens/nep171/withdraw.rs`, `contracts/defuse/src/contract/tokens/nep245/withdraw.rs`, `contracts/defuse/src/contract/intents/state.rs`)

### Summary
When a user attaches a `storage_deposit` amount to `ft_withdraw`/`nft_withdraw`/`mt_withdraw`, or submits a standalone `StorageDeposit` intent, the full amount is debited from the user's internal wNEAR ledger balance, unwrapped to native NEAR, and attached to an external `storage_deposit()` call on the target token contract. Any excess over the actual NEP-145 storage cost is refunded by that external contract to the caller — which is the Defuse contract itself, not the user. The Defuse contract never captures or re-credits this refund to the user's ledger, so the overpaid amount is permanently lost to the user.

### Finding Description
The withdraw-with-storage-deposit flow is implemented identically for FT, NFT and MT withdrawals, and for the standalone `StorageDeposit` intent:

1. The user's internal wNEAR balance is debited by the full `storage_deposit` amount via `self.withdraw(...)`. [1](#0-0) 

2. That amount is unwrapped from wNEAR to native NEAR (`near_withdraw`) and then attached in full as `attached_deposit` to an external `storage_deposit()` call on the target `token` contract: [2](#0-1) 

3. Per NEP-145 semantics, any `storage_deposit` amount in excess of the actual required storage cost is refunded by the target contract back to its `predecessor_account_id()` — which is the Defuse contract's own account, since Defuse is the direct caller of that cross-contract call. No promise result of the `storage_deposit()` call is ever inspected or forwarded; the subsequent resolver callbacks only look at the result of the final `ft_transfer`/`nft_transfer`/`mt_transfer`, never at the `storage_deposit` refund: [3](#0-2) 

4. The identical pattern (debit full amount, unwrap, attach in full, never recapture excess) is repeated in `internal_nft_withdraw`/`do_nft_withdraw`: [4](#0-3) 

and in `internal_mt_withdraw`/`do_mt_withdraw`: [5](#0-4) 

and in the standalone `StorageDeposit` intent handler: [6](#0-5) 

This breaks the conservation binding described in the analog rules — "value debited versus value delivered plus refunded" — exactly as in the H-3 report, where residual value returned by an external call was not forwarded back to the entity that originally paid for it, and instead accumulates unaccounted-for in the calling contract.

### Impact Explanation
Any amount attached as `storage_deposit` beyond the exact minimum storage cost required by the target token contract is silently and permanently absorbed into the Defuse contract's own NEAR account balance. It is never credited back to the paying user's internal ledger (`token_balances`), and there is no code path anywhere in `ft_resolve_withdraw`, `nft_resolve_withdraw`, `mt_resolve_withdraw`, `do_storage_deposit`, or the corresponding intent handlers that recaptures or refunds this excess. This is a permanent loss of user funds with no recovery mechanism, matching the "funds permanently frozen" / value-debited-vs-delivered-plus-refunded criterion.

### Likelihood Explanation
Any unprivileged user can trigger this on every withdrawal that specifies a `storage_deposit` (a normal, documented usage pattern intended to cover the receiver's storage registration on the destination token contract). Because the exact minimum storage cost of an arbitrary target NEP-141/171/245 contract is not knowable with certainty by the caller in advance (storage costs can vary between token contracts, and callers are naturally incentivized to overpay slightly to guarantee success), any non-exact estimate — even by 1 yoctoNEAR — results in loss of the difference. This makes the issue highly likely to occur in normal operation, not just as a crafted edge case.

### Recommendation
Capture the return/refund behavior of the `storage_deposit()` cross-contract call (e.g., by comparing the account's native NEAR balance before and after, or by having `do_ft_withdraw`/`do_nft_withdraw`/`do_mt_withdraw`/`do_storage_deposit` chain a callback that measures unused deposit) and credit any excess back to the owner's internal wNEAR balance, mirroring how `ft_resolve_withdraw` already refunds unused token transfer amounts back to the sender.

### Proof of Concept
1. User has an internal wNEAR balance of at least `X + storage_cost` for some target `token` contract whose actual NEP-145 minimum storage balance is `storage_cost`.
2. User signs and submits `FtWithdraw { token, receiver_id, amount, storage_deposit: Some(NearToken::from_near(X + storage_cost)), .. }` (analogous for `NftWithdraw`/`MtWithdraw`, or a standalone `StorageDeposit` intent).
3. `internal_ft_withdraw` debits `X + storage_cost` from the user's wNEAR ledger balance, unwraps it to native NEAR, and calls `token.storage_deposit()` with `attached_deposit = X + storage_cost`.
4. The target token contract (standard NEP-145 implementation) consumes only `storage_cost` and refunds `X` back to `env::predecessor_account_id()`, i.e., the Defuse contract's own account.
5. `ft_resolve_withdraw` only inspects the result of the subsequent `ft_transfer`, never the `storage_deposit` refund; no code credits `X` back to the user.
6. Result: the user's ledger balance was reduced by `X + storage_cost`, but only `storage_cost` was consumed usefully — `X` accrues to the Defuse contract's own NEAR balance with no path back to the user.

#[near]
impl FungibleTokenWithdrawResolver for Contract {
    #[private]
    fn ft_resolve_withdraw(
        &mut self,
        token: AccountId,
        sender_id: AccountId,
        amount: U128,
        is_call: bool,
    ) -> U128 {
        let used = if is_call {
            // `ft_transfer_call` returns successfully transferred amount
            match promise_result_checked_json::<U128>(0) {
                Ok(Ok(used)) => used.0.min(amount.0),
                Ok(Err(_deserialize_err)) => 0,
                // do not refund on failed `ft_transfer_call` due to
                // NEP-141 vulnerability: `ft_resolve_transfer` fails to
                // read result of `ft_on_transfer` due to insufficient gas
                Err(_) => amount.0,
            }
        } else {
            // `ft_transfer` returns empty result on success
            if promise_result_checked_void(0).is_ok() {
                amount.0
            } else {
                0
            }
        };

        let refund = amount.0.saturating_sub(used);
        if refund > 0 {
            self.deposit(
                sender_id,
                [(Nep141TokenId::new(token).into(), refund)],
                Some(REFUND_MEMO),
            )
            .unwrap_or_else(|err| err.panic());
        }

        U128(used)
    }
}

    pub(crate) fn internal_nft_withdraw(

        owner_id: AccountId,
        withdraw: NftWithdraw,
        force: bool,
    ) -> Result<PromiseOrValue<bool>> {
        self.withdraw(
            &owner_id,

                Nep171TokenId::new(withdraw.token.clone(), withdraw.token_id.clone()).into(),
                1,
            ))
            .chain(withdraw.storage_deposit.map(|amount| {
                (
                    Nep141TokenId::new(self.wnear_id().into_owned()).into(),
                    amount.as_yoctonear(),
                )
            })),
            Some("withdraw"),
            force,
        )?;

        let is_call = withdraw.is_call();
        Ok(if let Some(storage_deposit) = withdraw.storage_deposit {
            ext_wnear::ext(self.wnear_id.clone())
                .with_attached_deposit(NearToken::from_yoctonear(1))
                .with_static_gas(NEAR_WITHDRAW_GAS)
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .near_withdraw(U128(storage_deposit.as_yoctonear()))
                .then(
                    // schedule storage_deposit() only after near_withdraw() returns
                    Self::ext(env::current_account_id())
                        .with_static_gas(
                            Self::DO_NFT_WITHDRAW_GAS
                                .checked_add(withdraw.min_gas())
                                .ok_or(DefuseError::GasOverflow)
                                .unwrap_or_else(|err| err.panic()),
                        )
                        .do_nft_withdraw(withdraw.clone()),
                )
        } else {
            Self::do_nft_withdraw(withdraw.clone())
        }
        .then(
            Self::ext(env::current_account_id())
                .with_static_gas(Self::NFT_RESOLVE_WITHDRAW_GAS)
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .nft_resolve_withdraw(withdraw.token, owner_id, withdraw.token_id, is_call),
        )
        .into())
    }

    #[private]
    pub fn do_nft_withdraw(withdraw: NftWithdraw) -> Promise {
        let min_gas = withdraw.min_gas();

                .with_static_gas(STORAGE_DEPOSIT_GAS)
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .storage_deposit(Some(withdraw.receiver_id.clone()), None)
        } else {
            Promise::new(withdraw.token)
        };

        let p = ext_nft_core::ext_on(p)
            .with_attached_deposit(NearToken::from_yoctonear(1))
            .with_static_gas(min_gas)
            // distribute remaining gas here
            .with_unused_gas_weight(1);
        if let Some(msg) = withdraw.msg {
            p.nft_transfer_call(
                withdraw.receiver_id,
                withdraw.token_id,
                None,
                withdraw.memo,
                msg,
            )
        } else {
            p.nft_transfer(withdraw.receiver_id, withdraw.token_id, None, withdraw.memo)
        }
    }

impl Contract {
    pub(crate) fn internal_mt_withdraw(
        &mut self,
        owner_id: AccountId,
        withdraw: MtWithdraw,
        force: bool,
    ) -> Result<PromiseOrValue<Vec<U128>>> {
        if withdraw.token_ids.len() != withdraw.amounts.len() || withdraw.token_ids.is_empty() {
            return Err(DefuseError::InvalidIntent);
        }

        self.withdraw(
            &owner_id,
            withdraw
                .token_ids
                .iter()
                .cloned()
                .map(|token_id| Nep245TokenId::new(withdraw.token.clone(), token_id))
                .map(Into::into)
                .zip(withdraw.amounts.iter().copied())
                .chain(withdraw.storage_deposit.map(|amount| {
                    (
                        Nep141TokenId::new(self.wnear_id().into_owned()).into(),
                        amount.as_yoctonear(),
                    )
                })),
            Some("withdraw"),
            force,
        )?;

        let is_call = withdraw.msg.is_some();
        Ok(if let Some(storage_deposit) = withdraw.storage_deposit {
            ext_wnear::ext(self.wnear_id.clone())
                .with_attached_deposit(NearToken::from_yoctonear(1))
                .with_static_gas(NEAR_WITHDRAW_GAS)
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .near_withdraw(U128(storage_deposit.as_yoctonear()))
                .then(
                    // schedule storage_deposit() only after near_withdraw() returns
                    Self::ext(env::current_account_id())
                        .with_static_gas(
                            Self::DO_MT_WITHDRAW_GAS
                                .checked_add(withdraw.min_gas())
                                .ok_or(DefuseError::GasOverflow)
                                .unwrap_or_else(|err| err.panic()),
                        )
                        .do_mt_withdraw(withdraw.clone()),
                )
        } else {
            Self::do_mt_withdraw(withdraw.clone())
        }
        .then(
            Self::ext(env::current_account_id())
                .with_static_gas(Self::mt_resolve_withdraw_gas(withdraw.token_ids.len()))
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .mt_resolve_withdraw(
                    withdraw.token,
                    owner_id,
                    withdraw.token_ids,
                    withdraw.amounts.into_iter().map(U128).collect(),
                    is_call,
                ),
        )
        .into())
    }

    #[must_use]
    fn mt_resolve_withdraw_gas(token_count: usize) -> Gas {
        // Values chosen to be similar to `MT_RESOLVE_TRANSFER_*` values
        const MT_RESOLVE_WITHDRAW_PER_TOKEN_GAS: Gas = Gas::from_tgas(2);
        const MT_RESOLVE_WITHDRAW_BASE_GAS: Gas = Gas::from_tgas(8);

        let token_count: u64 = token_count.try_into().unwrap();

        MT_RESOLVE_WITHDRAW_BASE_GAS
            .checked_add(
                MT_RESOLVE_WITHDRAW_PER_TOKEN_GAS
                    .checked_mul(token_count)
                    .ok_or(DefuseError::GasOverflow)
                    .unwrap_or_else(|err| err.panic()),
            )
            .ok_or(DefuseError::GasOverflow)
            .unwrap_or_else(|err| err.panic())
    }
}

    #[private]
    pub fn do_mt_withdraw(withdraw: MtWithdraw) -> Promise {
        let min_gas = withdraw.min_gas();
        let p = if let Some(storage_deposit) = withdraw.storage_deposit {
            require!(
                promise_result_checked_void(0).is_ok(),
                "near_withdraw failed",
            );

            ext_storage_management::ext(withdraw.token)
                .with_attached_deposit(storage_deposit)
                .with_static_gas(STORAGE_DEPOSIT_GAS)
                // do not distribute remaining gas here
                .with_unused_gas_weight(0)
                .storage_deposit(Some(withdraw.receiver_id.clone()), None)
        } else {
            Promise::new(withdraw.token)
        };

        let p = ext_mt_core::ext_on(p)
            .with_attached_deposit(NearToken::from_yoctonear(1))
            .with_static_gas(min_gas)
            // distribute remaining gas here
            .with_unused_gas_weight(1);
        let amounts: Vec<U128> = withdraw.amounts.into_iter().map(U128).collect();
        if let Some(msg) = withdraw.msg {
            p.mt_batch_transfer_call(
                withdraw.receiver_id,
                withdraw.token_ids,
                amounts,
                None,
                withdraw.memo,
                msg,
            )
        } else {
            p.mt_batch_transfer(
                withdraw.receiver_id,
                withdraw.token_ids,
                amounts,
                None,
                withdraw.memo,
            )
        }
    }
}
