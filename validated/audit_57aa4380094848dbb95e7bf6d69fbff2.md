## Title
Guard Representative (Genesis Witness) reward `allowance` can never be withdrawn, permanently locking TRX — ([File: actuator/src/main/java/org/tron/core/actuator/WithdrawBalanceActuator.java])

## Summary
Guard Representatives (the witnesses configured in `genesis.block.witnesses`) continuously accrue block rewards, transaction-fee rewards and vote/brokerage rewards into their account's `allowance` field, exactly like any other Super Representative. However, both exit points that convert `allowance` into spendable `balance` — `WithdrawBalanceActuator` and the TVM native `WithdrawRewardProcessor` — unconditionally reject any address that matches a genesis witness. There is no other actuator, TVM opcode, or admin/emergency function anywhere in the codebase that lets this accumulated allowance be converted into a usable balance, so the funds accrue indefinitely and are permanently unspendable — mirroring the NukeFund pattern where value flows into a "fund" that can only be released by one specific, gated action.

## Finding Description
Genesis witnesses are seeded at chain start with large vote counts, guaranteeing they remain in the active Super Representative set and keep producing blocks and receiving rewards forever [1](#0-0) . Every time such a witness produces a block, `Manager.payReward()` credits its `allowance` via `MortgageService.payBlockReward()`/`payTransactionFeeReward()`, and standby-witness rewards are credited through `IncentiveManager.reward()` [2](#0-1) [3](#0-2) [4](#0-3) . Vote-based rewards likewise flow into `allowance` via `MortgageService.withdrawReward()` / `VoteRewardUtil.withdrawReward()` [5](#0-4) .

The only two code paths that turn `allowance` into spendable `balance` both explicitly forbid genesis witnesses:
- `WithdrawBalanceActuator.validate()` throws when the owner address matches any `genesisBlock.getWitnesses()` entry [6](#0-5) .
- `WithdrawRewardProcessor.validate()` (invoked by the `withdrawreward()` TVM opcode via `Program.withdrawReward()`) performs the identical check [7](#0-6) [8](#0-7) .

A unit test explicitly documents that this call fails for guard representatives with `"is a guard representative and is not allowed to withdraw Balance"` [9](#0-8) .

No other path exists to move this value out: `UnfreezeBalanceV2Actuator` and other flows only call `mortgageService.withdrawReward(ownerAddress)`, which merely migrates pending vote reward into the `allowance` field — it does not check `isGP`, but it also does not convert `allowance` into `balance`; only the two blocked entry points above do that final conversion. There is no admin/committee/emergency function anywhere in the actuator or TVM native-contract set that can release a specific account's `allowance` to `balance`.

## Impact Explanation
Any TRX credited as `allowance` to a genesis witness address is permanently non-spendable: it can never be moved into the account's `balance`, and thus can never be transferred, staked, or otherwise used. Because genesis witnesses are guaranteed active SRs by their initial vote weight, this reward stream is continuous and grows without bound — a de-facto permanent freezing of protocol-issued funds, which is worsened over time and not recoverable by the account owner or by any privileged operator function present in the code.

## Likelihood Explanation
This requires no attacker action or special privilege: it triggers automatically as part of ordinary consensus operation. Any genesis witness that continues (or is made to continue, e.g. via normal voting by any TRX holder) to be an active SR earns block/standby/transaction-fee rewards every cycle, and the lock is deterministic — not probabilistic or dependent on adversarial input — it happens on every reward payment to that address.

## Recommendation
Either (a) remove the guard-representative restriction from `WithdrawBalanceActuator.validate()` and `WithdrawRewardProcessor.validate()` so genesis witnesses can withdraw like any other SR, or (b) if the restriction is intentional (e.g., these funds should be burned or redirected), explicitly route their reward accrual away from `allowance` (e.g., burn it or redirect to a treasury/proposal-controlled account) instead of silently accumulating an unspendable balance in the account's `allowance` field.

## Proof of Concept
1. At genesis, configure a witness in `genesis.block.witnesses` (as done in `config.conf`) with high `voteCount`, guaranteeing it is elected into the active SR set every cycle.
2. Let the network run: `Manager.payReward()` and `IncentiveManager.reward()` will repeatedly increase this witness's `AccountCapsule.allowance` for every block it produces and every standby-reward cycle.
3. Attempt to withdraw via a `WithdrawBalanceContract` transaction (e.g. through `WithdrawBalanceServlet`/`WalletClient.withdrawBalance()`) — `WithdrawBalanceActuator.validate()` rejects it with `"is a guard representative and is not allowed to withdraw Balance"`, matching the assertion in `WithdrawBalanceActuatorTest.isGR()` [10](#0-9) .
4. Attempt the equivalent via the TVM `withdrawreward()` opcode from a contract deployed at (or triggered by) that address — `WithdrawRewardProcessor.validate()` rejects it identically [11](#0-10) .
5. No other actuator, opcode, or RPC/HTTP endpoint exists to convert this `allowance` to spendable `balance` for this address — the funds remain locked indefinitely while continuing to grow every reward cycle.

  private void payReward(BlockCapsule block) {
    WitnessCapsule witnessCapsule =
        chainBaseManager.getWitnessStore().getUnchecked(block.getInstance().getBlockHeader()
            .getRawData().getWitnessAddress().toByteArray());
    if (getDynamicPropertiesStore().allowChangeDelegation()) {
      mortgageService.payBlockReward(witnessCapsule.getAddress().toByteArray(),
          getDynamicPropertiesStore().getWitnessPayPerBlock());
      mortgageService.payStandbyWitness();

      if (chainBaseManager.getDynamicPropertiesStore().supportTransactionFeePool()) {
        long transactionFeeReward = floorDiv(
            chainBaseManager.getDynamicPropertiesStore().getTransactionFeePool(),
                Constant.TRANSACTION_FEE_POOL_PERIOD,
            chainBaseManager.getDynamicPropertiesStore().disableJavaLangMath());
        mortgageService.payTransactionFeeReward(witnessCapsule.getAddress().toByteArray(),
            transactionFeeReward);
        chainBaseManager.getDynamicPropertiesStore().saveTransactionFeePool(
            chainBaseManager.getDynamicPropertiesStore().getTransactionFeePool()
                - transactionFeeReward);
      }
    } else {
      byte[] witness = block.getWitnessAddress().toByteArray();
      AccountCapsule account = getAccountStore().get(witness);
      account.setAllowance(account.getAllowance()
          + chainBaseManager.getDynamicPropertiesStore().getWitnessPayPerBlock());

      if (chainBaseManager.getDynamicPropertiesStore().supportTransactionFeePool()) {
        long transactionFeeReward = floorDiv(
            chainBaseManager.getDynamicPropertiesStore().getTransactionFeePool(),
                Constant.TRANSACTION_FEE_POOL_PERIOD,
            chainBaseManager.getDynamicPropertiesStore().disableJavaLangMath());
        account.setAllowance(account.getAllowance() + transactionFeeReward);
        chainBaseManager.getDynamicPropertiesStore().saveTransactionFeePool(
            chainBaseManager.getDynamicPropertiesStore().getTransactionFeePool()
                - transactionFeeReward);
      }

      getAccountStore().put(account.createDbKey(), account);
    }
  }

    long brokerageAmount = (long) (brokerageRate * value);

  public void withdrawReward(byte[] address) {
    if (!dynamicPropertiesStore.allowChangeDelegation()) {
      return;
    }
    AccountCapsule accountCapsule = accountStore.get(address);
    long beginCycle = delegationStore.getBeginCycle(address);
    long endCycle = delegationStore.getEndCycle(address);
    long currentCycle = dynamicPropertiesStore.getCurrentCycleNumber();
    long reward = 0;
    if (beginCycle > currentCycle || accountCapsule == null) {
      return;
    }
    if (beginCycle == currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        return;
      }
    }
    //withdraw the latest cycle reward
    if (beginCycle + 1 == endCycle && beginCycle < currentCycle) {
      AccountCapsule account = delegationStore.getAccountVote(beginCycle, address);
      if (account != null) {
        reward = computeReward(beginCycle, endCycle, account);
        adjustAllowance(address, reward);
        reward = 0;
        logger.info("Latest cycle reward {}, {}.", beginCycle, account.getVotesList());
      }
      beginCycle += 1;
    }
    //
    endCycle = currentCycle;
    if (CollectionUtils.isEmpty(accountCapsule.getVotesList())) {
      delegationStore.setBeginCycle(address, endCycle + 1);
      return;
    }
    if (beginCycle < endCycle) {
      reward += computeReward(beginCycle, endCycle, accountCapsule);
      adjustAllowance(address, reward);
    }
    delegationStore.setBeginCycle(address, endCycle);
    delegationStore.setEndCycle(address, endCycle + 1);
    delegationStore.setAccountVote(endCycle, address, accountCapsule);
    logger.info("Adjust {} allowance {}, now currentCycle {}, beginCycle {}, endCycle {}, "
            + "account vote {}.", Hex.toHexString(address), reward, currentCycle,
        beginCycle, endCycle, accountCapsule.getVotesList());
  }

  public void reward(List<ByteString> witnesses) {
    if (consensusDelegate.allowChangeDelegation()) {
      return;
    }
    if (witnesses.size() > WITNESS_STANDBY_LENGTH) {
      witnesses = witnesses.subList(0, WITNESS_STANDBY_LENGTH);
    }
    long voteSum = 0;
    for (ByteString witness : witnesses) {
      voteSum += consensusDelegate.getWitness(witness.toByteArray()).getVoteCount();
    }
    if (voteSum <= 0) {
      return;
    }
    long totalPay = consensusDelegate.getWitnessStandbyAllowance();
    for (ByteString witness : witnesses) {
      byte[] address = witness.toByteArray();
      long pay = (long) (consensusDelegate.getWitness(address).getVoteCount() * ((double) totalPay
          / voteSum));
      AccountCapsule accountCapsule = consensusDelegate.getAccount(address);
      accountCapsule.setAllowance(accountCapsule.getAllowance() + pay);
      consensusDelegate.saveAccount(accountCapsule);
    }
  }

  public long withdrawReward() {
    Repository repository = getContractState().newRepositoryChild();
    byte[] owner = getContextAddress();

    increaseNonce();
    InternalTransaction internalTx = addInternalTx(null, owner, owner, 0, null,
        "withdrawReward", nonce, null);

    WithdrawRewardParam param = new WithdrawRewardParam();
    param.setOwnerAddress(owner);
    param.setNowInMs(getTimestamp().longValue() * 1000);
    try {
      WithdrawRewardProcessor processor = new WithdrawRewardProcessor();
      processor.validate(param, repository);
      long allowance = processor.execute(param, repository);
      repository.commit();
      if (internalTx != null) {
        internalTx.setValue(allowance);
      }
      return allowance;
    } catch (ContractValidateException e) {
      logger.warn("TVM WithdrawReward: validate failure. Reason: {}", e.getMessage());
    } catch (ContractExeException e) {
      logger.warn("TVM WithdrawReward: execute failure. Reason: {}", e.getMessage());
    }
    if (internalTx != null) {
      internalTx.reject();
    }
    return 0;
  }
