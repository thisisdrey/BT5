The report's bug class ("no verification that the caller has the accredited authority it claims") maps onto `SignerEventReceiver` in `libsigner/src/events.rs`. This is the HTTP server the signer binds to receive events pushed by the Stacks node (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`). ### Title
Unauthenticated event injection into signer event receiver - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event` accepts and processes any POST to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` without validating an auth token/password, even though the documented deployment model relies on `auth_token`/`auth_password` matching between the node and signer to establish trust.

### Finding Description
The signer binds an HTTP listener via `EventReceiver::bind` and processes incoming requests in `next_event` [5](#0-4) . It routes by URL to `process_event::<T, StackerDBChunksEvent>`, `process_event::<T, BlockValidateResponse>`, or `process_event::<T, BurnBlockEvent>` and immediately trusts and forwards whatever it decoded [6](#0-5) . There is no check comparing an `Authorization` header (or any credential) against the `auth_password` configured for the signer. The mismatch is between "authenticated sender (the node, holding `auth_token`)" and "any TCP peer that can reach the bind address" — the equality the report's bug class targets (verified caller vs. arbitrary caller) is never enforced in this transport code.

### Impact Explanation
Any remote host that can reach the signer's bind address (per the sample config, `0.0.0.0:30000`, i.e., all interfaces) can POST a forged `StackerDBChunksEvent`, `BlockValidateResponse`, or `BurnBlockEvent` and have it forwarded into the signer's runloop as if it came from the trusted node [7](#0-6) . This is an unauthenticated write into the signer's internal event stream — the signer has no way at the transport layer to distinguish genuine node-originated data from attacker-forged data.

### Likelihood Explanation
Exploitability depends entirely on network exposure of the signer's event-receiver bind address. If it is bound to a non-loopback interface (as the documented sample config does), the endpoint is reachable by any unauthenticated remote party, requiring no credentials, keys, or privileged role — matching the "remote, unprivileged" requirement.

### Recommendation
Enforce the documented `auth_password`/`auth_token` check inside `SignerEventReceiver::next_event` (or `process_event`) by validating an `Authorization` header against the configured secret before decoding/forwarding any event, rejecting unauthenticated requests with 401/403.

### Proof of Concept
1. Start a signer configured with `auth_password = "secret"` per `docs/signing.md`, bound to a reachable interface.
2. From a separate unauthenticated host, POST a crafted JSON body to `http://<signer-host>:<port>/stackerdb_chunks` (or `/proposal_response`, `/new_burn_block`) with no `Authorization` header, matching the shape expected by `StackerDBChunksEvent`/`BlockValidateResponse`/`BurnBlockEvent`.
3. Observe that `next_event` decodes it via `process_event` and `forward_event` pushes it into the signer's runloop channel exactly as if the trusted node had sent it [7](#0-6) , with no rejection based on missing/incorrect credentials.

**Caveat:** I could not verify within the available iterations whether `stacks-signer` wraps `SignerEventReceiver` with an additional authentication layer outside `libsigner` (e.g., a reverse proxy or middleware performing the header check before requests reach `next_event`). The code inspected in `libsigner/src/events.rs` — the in-scope transport file — itself contains no such check.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(

                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
