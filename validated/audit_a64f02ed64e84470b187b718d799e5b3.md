### Title
Conntrack fast-path in `Firewall.Drop()` skips certificate expiration checks, allowing traffic from expired peer certificates until the connection manager's polling interval catches up - (File: firewall.go)

### Summary
`Firewall.Drop()` uses a conntrack fast-path (`inConns()`) that permits any packet matching an existing 5-tuple entry without re-validating whether the peer's certificate is still valid (not expired/not blocklisted). This mirrors the C4 finding's root cause: a security-relevant validation (`funding_tick()`'s funding-rate check) relies on a value (`get_synthetic_price()`) that is not verified fresh at the time of validation, allowing stale data to pass gate checks that should require up-to-date state.

### Finding Description
In `Firewall.Drop()`, once the CA/cert/rule check has been performed once for a flow and a `conn` entry is cached, subsequent packets on the same 5-tuple bypass the certificate/rule check entirely as long as `c.rulesVersion == f.rulesVersion`: [1](#0-0) 

The only revalidation path (`inConns` → re-`match()`) triggers when `f.rulesVersion` changes, not when the peer's certificate expires: [2](#0-1) 

Certificate expiration is instead checked out-of-band, on a periodic timer, by `connectionManager.isInvalidCertificate()`, which calls `caPool.VerifyCachedCertificate(now, remoteCert)` and only tears down the tunnel if `disconnectInvalid` is configured true: [3](#0-2) 

If `disconnectInvalid` is false (the default posture the code supports — "keep tunnels from now-invalid certs open"), or simply during the window between periodic checks, packets continue to be admitted by the firewall's conntrack fast-path using a certificate that is provably expired, because `Drop()`'s fast path never calls `caPool.VerifyCachedCertificate`/`Expired()` at all — it only performs the CA/group/name match, and only on the *slow* path when a new conntrack entry is created: [4](#0-3) 

This is directly analogous to the report: `funding_tick()`'s validation logic (`funding.validate_funding_rate()`) trusted a price value fetched via `get_synthetic_price()` without checking whether that price was still "fresh," letting stale data pass a check meant to gate state changes. Here, the firewall's "is this flow still authorized" check is effectively cached/stale — the enforcement decision made once at flow-open time is trusted indefinitely (until a rules-version bump or a periodic out-of-band poll), even though the authorization input (peer certificate validity) can change (expire) underneath it.

### Impact Explanation
An expired (or blocklisted, if blocklisting happens between the initial connection and later packets) peer certificate does not immediately cut off traffic. As long as the connection manager has not yet run to disconnect the tunnel — or is configured not to disconnect on invalid certs — the firewall keeps permitting all packets matching the existing conntrack entry, regardless of certificate state. This is a state-poisoning/authorization-bypass condition: traffic continues to flow under a security boundary (nebula relies on certs for group/identity-based firewall rules) that should have been closed.

### Likelihood Explanation
This is reachable by any already-connected peer whose certificate later expires or is blocklisted — no CA-signed certificate forgery is required, only the natural passage of time relative to a legitimately-issued (but now-expired) certificate, or an operator blocklisting action that should immediately cut off a peer. Because `disconnectInvalid` can legitimately be configured `false`, and even when `true` the check is periodic rather than per-packet, there is a guaranteed window (and potentially unlimited window if `disconnectInvalid=false`) during which stale authorization state is trusted.

### Recommendation
When a certificate has expired (or gets blocklisted), the firewall conntrack fast path should stop trusting the cached decision, similar to how a `rulesVersion` bump forces `inConns()` to fall through to a full `table.match()` re-check. Concretely: track a per-hostinfo "certificate validity generation" (or simply consult `caPool.VerifyCachedCertificate` on the periodic path and immediately invalidate/purge the corresponding conntrack entries when a cert is found expired/blocklisted), rather than relying solely on `connectionManager`'s independent timer to tear down the whole tunnel. At minimum, `Drop()`'s fast path should not admit packets once `isInvalidCertificate`-equivalent state is known false, regardless of `disconnectInvalid` configuration for firewall-level authorization decisions (tunnel teardown and packet admission are separate concerns and currently only the former is checked, tying admission's freshness entirely to teardown's schedule/config).

### Proof of Concept
1. Establish a tunnel between host A and host B with a certificate for B that has a near-term `NotAfter`.
2. A and B exchange traffic that matches a firewall rule; a `conn` entry is cached in `f.Conntrack.Conns` for the flow's `firewall.Packet` tuple, as done at the end of `Drop()`: `f.addConn(fp, incoming)` [5](#0-4) .
3. Let B's certificate pass its `NotAfter` time. Do not change firewall rules (`f.rulesVersion` unchanged).
4. Continue sending packets on the same flow tuple. `Drop()` calls `f.inConns(fp, h, caPool, localCache)`, which finds the existing entry, sees `c.rulesVersion == f.rulesVersion`, and returns `true` immediately without ever calling `caPool.VerifyCertificate`/`VerifyCachedCertificate` or checking `Expired()` [6](#0-5) , [7](#0-6) .
5. Traffic continues to flow through the firewall using the now-expired certificate's authorization until `connectionManager`'s periodic `isInvalidCertificate` check runs and (only if `disconnectInvalid` is true) tears down the tunnel [8](#0-7) , confirmed by the existing test demonstrating the timing window: [9](#0-8) .

// Drop returns an error if the packet should be dropped, explaining why. It
// returns nil if the packet should not be dropped.
func (f *Firewall) Drop(fp firewall.Packet, incoming bool, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) error {
	// Make sure remote address matches nebula certificate, and determine how to treat it
	if h.networks == nil {
		// Simple case: Certificate has one address and no unsafe networks
		if h.vpnAddrs[0] != fp.RemoteAddr {
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrInvalidRemoteIP
		}
	} else {
		nwType, ok := h.networks.Lookup(fp.RemoteAddr)
		if !ok {
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrInvalidRemoteIP
		}
		switch nwType {
		case NetworkTypeVPN:
			break // nothing special
		case NetworkTypeVPNPeer:
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrPeerRejected // reject for now, one day this may have different FW rules
		case NetworkTypeUnsafe:
			break // nothing special, one day this may have different FW rules
		default:
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrUnknownNetworkType //should never happen
		}
	}

	// Make sure we are supposed to be handling this local ip address
	if !f.routableNetworks.Contains(fp.LocalAddr) {
		f.metrics(incoming).droppedLocalAddr.Inc(1)
		return ErrInvalidLocalIP
	}

	// Check if we spoke to this tuple, if we did then allow this packet
	if f.inConns(fp, h, caPool, localCache) {
		return nil
	}

	table := f.OutRules
	if incoming {
		table = f.InRules
	}

	// We now know which firewall table to check against
	if !table.match(fp, incoming, h.ConnectionState.peerCert, caPool) {
		f.metrics(incoming).droppedNoRule.Inc(1)
		return ErrNoMatchingRule
	}

	// We always want to conntrack since it is a faster operation
	f.addConn(fp, incoming)

	return nil
}

func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}

	if c.rulesVersion != f.rulesVersion {
		// This conntrack entry was for an older rule set, validate
		// it still passes with the current rule set
		table := f.OutRules
		if c.incoming {
			table = f.InRules
		}

		// We now know which firewall table to check against
		if !table.match(fp, c.incoming, h.ConnectionState.peerCert, caPool) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				h.logger(f.l).Debug("dropping old conntrack entry, does not match new ruleset",
					"fwPacket", fp,
					"incoming", c.incoming,
					"rulesVersion", f.rulesVersion,
					"oldRulesVersion", c.rulesVersion,
				)
			}
			delete(conntrack.Conns, fp)
			conntrack.Unlock()
			return false
		}

		if f.l.Enabled(context.Background(), slog.LevelDebug) {
			h.logger(f.l).Debug("keeping old conntrack entry, does match new ruleset",
				"fwPacket", fp,
				"incoming", c.incoming,
				"rulesVersion", f.rulesVersion,
				"oldRulesVersion", c.rulesVersion,
			)
		}

		c.rulesVersion = f.rulesVersion
	}

	switch fp.Protocol {
	case firewall.ProtoTCP:
		c.Expires = time.Now().Add(f.TCPTimeout)
	case firewall.ProtoUDP:
		c.Expires = time.Now().Add(f.UDPTimeout)
	default:
		c.Expires = time.Now().Add(f.DefaultTimeout)
	}

	conntrack.Unlock()

	if localCache != nil {
		localCache[fp] = struct{}{}
	}

	return true
}

// isInvalidCertificate decides if we should destroy a tunnel.
// returns true if pki.disconnect_invalid is true and the certificate is no longer valid.
// Blocklisted certificates will skip the pki.disconnect_invalid check and return true.
func (cm *connectionManager) isInvalidCertificate(now time.Time, hostinfo *HostInfo) bool {
	remoteCert := hostinfo.GetCert()
	if remoteCert == nil {
		return false //don't tear down tunnels for handshakes in progress
	}

	caPool := cm.intf.pki.GetCAPool()
	err := caPool.VerifyCachedCertificate(now, remoteCert)
	if err == nil {
		return false //cert is still valid! yay!
	} else if err == cert.ErrBlockListed { //avoiding errors.Is for speed
		// Block listed certificates should always be disconnected
		hostinfo.logger(cm.l).Info("Remote certificate is blocked, tearing down the tunnel",
			"error", err,
			"fingerprint", remoteCert.Fingerprint,
		)
		return true
	} else if cm.intf.disconnectInvalid.Load() {
		hostinfo.logger(cm.l).Info("Remote certificate is no longer valid, tearing down the tunnel",
			"error", err,
			"fingerprint", remoteCert.Fingerprint,
		)
		return true
	} else {
		//if we reach here, the cert is no longer valid, but we're configured to keep tunnels from now-invalid certs open
		return false
	}
}
