Based on my research, `encoding/gob` is the closest Go analog to Hessian's interface deserialization, but it does not share the vulnerable primitive.

Key findings:
- `gob.Decoder.decodeInterface` (src/encoding/gob/decode.go:684-733) requires the concrete type name to already exist in `nameToConcreteType`, a table populated only by explicit, developer-controlled calls to `gob.Register`/`gob.RegisterName` [1](#0-0) . This is a whitelist model, not a Hessian-style blacklist — an attacker cannot supply an arbitrary class name and get gadget-chain execution; the name must match a pre-registered Go type, and the decoded value must additionally satisfy `typ.AssignableTo(ityp)` against the receiving interface [2](#0-1) .
- Even for registered types, gob decoding never invokes arbitrary methods as a side effect of deserialization except explicitly-implemented `GobDecoder`/`BinaryUnmarshaler`/`TextUnmarshaler` interfaces, and only for the type the developer chose to register [3](#0-2) [4](#0-3) . There's no reflection-based "any JDK class with a matching gadget" surface like Hessian's blacklist bypass.
- Go's own documentation explicitly states that `encoding/gob` is not hardened against adversarial input and is declared **out of scope** of the Go security policy: "This package is not designed to be hardened against adversarial inputs, and is outside the scope of https://go.dev/security/policy" [5](#0-4) . This mirrors the review policy's exclusion of already-acknowledged, non-actionable design tradeoffs.

Given gob's registration-based whitelist design, the lack of an arbitrary-type/gadget-chain execution primitive, and Go's explicit statement that this package sits outside its security policy, there is no valid analog to the SOFA Hessian blacklist-bypass RCE in this codebase.

// decodeGobDecoder decodes something implementing the GobDecoder interface.
// The data is encoded as a byte slice.
func (dec *Decoder) decodeGobDecoder(ut *userTypeInfo, state *decoderState, value reflect.Value) {
	// Read the bytes for the value.
	n, ok := state.getLength()
	if !ok {
		errorf("GobDecoder: length too large for buffer")
	}
	b := state.b.Bytes()
	if len(b) < n {
		errorf("GobDecoder: invalid data length %d: exceeds input size %d", n, len(b))
	}
	b = b[:n]
	state.b.Drop(n)
	var err error
	// We know it's one of these.
	switch ut.externalDec {
	case xGob:
		gobDecoder, _ := reflect.TypeAssert[GobDecoder](value)
		err = gobDecoder.GobDecode(b)
	case xBinary:
		binaryUnmarshaler, _ := reflect.TypeAssert[encoding.BinaryUnmarshaler](value)
		err = binaryUnmarshaler.UnmarshalBinary(b)
	case xText:
		textUnmarshaler, _ := reflect.TypeAssert[encoding.TextUnmarshaler](value)
		err = textUnmarshaler.UnmarshalText(b)
	}
	if err != nil {
		error_(err)
	}
}
