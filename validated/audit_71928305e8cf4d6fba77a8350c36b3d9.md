### Title
Unauthenticated HTTP event injection into `SignerEventReceiver::next_event()` allows forged `SignerEvent::NewBlock`/`NewBurnBlock`/`StatusCheck` delivery to the signer runloop - (File: `libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event()` dispatches purely on HTTP method and URL path (`/new_block`, `/new_burn_block`, `/stackerdb_chunks`, `/proposal_response`, `/status`, `/shutdown`) with no shared-secret, HMAC, or peer-identity check, then blindly JSON-deserializes the body and forwards the resulting `SignerEvent<T>` to the signer runloop. Any TCP client that can reach the signer's listening endpoint can post a crafted body and have it accepted as if it came from the locally-run `stacks-node`'s event dispatcher.

### Finding Description
The claimed equality — "`SignerEvent::NewBlock` delivered to `run_one_pass()` == an event produced by this node's own block-processing pipeline" — is broken. In `next_event()` [1](#0-0) , the only gates are:
1. `request.url() == "/status"` → immediately returns `SignerEvent::StatusCheck` and responds `"OK"`, no auth check at all.
2. `request.method() != &HttpMethod::Post` → rejects non-POST, but this is a method check, not an authentication check.
3. URL string match routes `/new_block` to `process_event::<T, StacksBlockEvent>(request)`.

`process_event` [2](#0-1)  reads the raw body, ACKs the request, and does `serde_json::from_slice::<StacksBlockEvent>(body)` followed by `TryInto<SignerEvent<T>>`. There is no shared secret header, no source-IP allowlist, no signature over the body, and no correlation to any locally observed chainstate. `StacksBlockEvent` itself only requires `index_block_hash`, optional `signer_signature_hash`, `consensus_hash`, `block_hash`, `block_height`, and a `transactions` array (which can be empty) — all attacker-controlled and independently verifiable-free [3](#0-2) . The resulting `SignerEvent::NewBlock` is forwarded unconditionally via `forward_event` → `Sender::send` into the signer runloop [4](#0-3) .

The "shared secret" (`auth_password`/`auth_token`) documented in the signer/node config only secures the *signer → node* RPC direction (block-proposal validation endpoint); it is never checked on the *node → signer* event-POST direction implemented by `SignerEventReceiver` [5](#0-4) . The signer's own reference config binds this receiver to `0.0.0.0:30000` [6](#0-5) , i.e. remotely reachable by design, not merely loopback.

### Impact Explanation
An unprivileged remote TCP client that can reach the signer's bound event port can:
- Inject forged `SignerEvent::NewBlock` events with attacker-chosen `block_id`, `consensus_hash`, `signer_sighash`, `block_height`, and `transactions`, causing the signer runloop to believe a Stacks block was locally processed when it was not.
- Inject `SignerEvent::NewBurnBlock` and `SignerEvent::StatusCheck` similarly, with no verification.
- Repeat this indefinitely (each POST is independently accepted).

This is an unauthenticated write into the signer's local processing pipeline that drives state transitions (tenure/chainstate tracking used by signing decisions), matching the "Critical — unauthenticated/unauthorized write to state" category, since it can desynchronize the signer's local view of chain state from what any node actually validated.

### Likelihood Explanation
- No privileged role, secret, or key is required — only network reachability to the bound `endpoint` (default reference config: `0.0.0.0:30000`).
- Attacker cost is a single crafted HTTP POST; fully repeatable and scriptable.
- Preconditions: the signer's event endpoint must be reachable from the attacker (non-loopback bind, or attacker on the same host/LAN); this matches the documented default sample configuration, not a hardened deployment choice enforced by the code itself.

### Recommendation
Add an authentication gate to `SignerEventReceiver::next_event()`/`process_event()` (e.g., require and verify a shared secret/HMAC header, reusing the existing `auth_password`/`auth_token` mechanism but applied in the node→signer direction), and/or bind the event listener to loopback only by default with an explicit opt-in warning for exposing it beyond localhost.

### Proof of Concept
```rust
// libsigner: net-level test simulating an unauthenticated attacker
use std::net::TcpStream;
use std::io::Write;

#[test]
fn test_unauthenticated_new_block_injection() {
    let mut receiver = SignerEventReceiver::<SomeTMessage>::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();
    let (tx, rx) = std::sync::mpsc::channel();
    receiver.add_consumer(tx);
    std::thread::spawn(move || receiver.main_loop());

    let body = r#"{"index_block_hash":"0x00..00","consensus_hash":"0x00..00",
                    "block_hash":"0x00..00","block_height":0,"transactions":[]}"#;
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = format!(
        "POST /new_block HTTP/1.1\r\nHost: {addr}\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let ev = rx.recv().unwrap();
    // Assertion: attacker-supplied event accepted with no auth failure
    assert!(matches!(ev, SignerEvent::NewBlock { block_height: 0, .. }));
}
```
This demonstrates that a raw, unauthenticated `TcpStream` POST to `/new_block` is accepted and forwarded to the runloop, confirming the missing authentication gate in `next_event`/`process_event`.

```rust
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
```

```rust
    fn forward_event(&mut self, ev: SignerEvent<T>) -> bool {
        if self.out_channels.is_empty() {
            // nothing to do
            error!("No channels connected to event receiver");
            false
        } else if self.out_channels.len() == 1 {
            // avoid a clone
            if let Err(e) = self.out_channels[0].send(ev) {
                error!("Failed to send to signer runloop: {:?}", &e);
                return false;
            }
            true
        } else {
            for (i, out_channel) in self.out_channels.iter().enumerate() {
                if let Err(e) = out_channel.send(ev.clone()) {
                    error!("Failed to send to signer runloop #{}: {:?}", i, &e);
                    return false;
                }
            }
            true
        }
    }
```

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```
