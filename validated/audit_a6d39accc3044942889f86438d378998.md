### Title
Unauthenticated remote HTTP `POST /shutdown` triggers DoS of signer event receiver - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` matches the URL `/shutdown` and unconditionally sets `stop_signal` to `true`, terminating the signer's event-receiving HTTP server, with no check that the request actually came from the local `SignerStopSignaler` or the node itself. Any TCP client that can reach the bound event-receiver port can send a bare `POST /shutdown` and permanently stop the signer's event stream.

### Finding Description
The intended invariant is that the event-receiver's stop flag is only ever set by the signer's own `SignerStopSignaler::send()` (a local, same-process call that connects back to `self.local_addr`) [1](#0-0) . However, `next_event()` implements the stop condition purely as a URL match on the inbound HTTP request, with no secret, no signature, no source-IP restriction, and no distinction between "this came from our own loopback signaler" and "this came from an arbitrary remote peer": [2](#0-1) 

This is reached via `HttpServer::recv()` inside `with_server`, which accepts any TCP connection to the bound socket [3](#0-2) . The bind address (`bind_addr`) is caller/config-supplied via `Signer::spawn` and `EventReceiver::bind`, and is not restricted to loopback by this code [4](#0-3) [5](#0-4) . Once the flag is set, `main_loop` treats `EventError::Terminated` as a clean, deliberate exit and breaks out of the loop entirely, ending event processing for the signer [6](#0-5) .

The broken equality: the code treats "any TCP client that reaches `/shutdown`" as equivalent to "the trusted local stop signaler," when in fact no authentication ties the two together.

### Impact Explanation
A single unauthenticated POST permanently halts the signer's `SignerEventReceiver` main loop, cutting the signer off from all StackerDB chunk events, burn-block events, and block-validation responses forwarded by the node. This prevents the signer from participating in block signing (no more `SignerMessages`, `NewBurnBlock`, `BlockValidationResponse` events reach `run_one_pass`), which is a Critical unauthenticated DoS achievable with one message, matching the stated Critical severity bucket ("remote crash/unauthenticated DoS from few messages").

### Likelihood Explanation
The only precondition is TCP reachability to the signer's configured event-receiver bind address/port. Since this endpoint must be reachable by the stacks-node's event dispatcher (often configured as `0.0.0.0:<port>` or an externally-routable address in multi-host deployments), an unprivileged remote attacker with no secret, no key, and no privileged role can trivially reach it. The attack requires a single crafted HTTP request and is fully repeatable against any signer instance whose event port is exposed.

### Recommendation
Do not gate shutdown solely on URL path. Require an authenticated/local-only shutdown mechanism, e.g.: restrict the `/shutdown` handler to requests originating from `127.0.0.1`/the loopback interface (checking the peer address from `HttpRequest`), or require a locally-generated shared secret/token known only to `SignerStopSignaler` and compared via constant-time comparison before setting `stop_signal`. Alternatively, replace the HTTP-based stop signal with an in-process channel/condvar so the shutdown path never traverses the network socket at all.

### Proof of Concept
```rust
// libsigner/src/events.rs (test module) or a new integration test
#[test]
fn unauthenticated_remote_shutdown() {
    use std::net::{TcpStream, SocketAddr};
    use std::io::Write;
    use std::thread;
    use std::time::Duration;

    let mut event_receiver: SignerEventReceiver<SomeSignerMessageType> =
        SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap(); // use an ephemeral port in a real test
    let bound = event_receiver.bind(addr).unwrap();

    // Simulate a remote, unprivileged attacker (no secret, no signature)
    let attacker = thread::spawn(move || {
        let mut stream = TcpStream::connect(bound).unwrap();
        let req = "POST /shutdown HTTP/1.1\r\nHost: x\r\nContent-Length: 0\r\n\r\n";
        stream.write_all(req.as_bytes()).unwrap();
    });

    // next_event() processes the attacker's request and sets the stop flag
    let result = event_receiver.next_event();
    attacker.join().unwrap();

    assert!(event_receiver.is_stopped());
    assert!(matches!(result, Err(EventError::Terminated)));
}
```
This confirms that `event_receiver.stop_signal` is set to `true` and `EventError::Terminated` is returned purely from an unauthenticated remote POST, with no verification tying the request to the legitimate `SignerStopSignaler`.
