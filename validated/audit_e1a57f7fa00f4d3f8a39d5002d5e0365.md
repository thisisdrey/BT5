Based on my research into this repository (which is a mirror of the actual Go standard library and toolchain source, not the Java `Alpine` library referenced in the advisory), I did not find a reachable, unpatched analog to the `Alpine` URL access filter bypass (CVE-2022-23553).

The closest candidate code paths are:

1. **`html/template/url.go` `isSafeURL`/`urlFilter`** — an allowlist-based URL scheme filter (matches the CVE's "whitelist filter" pattern most closely), but it correctly cuts at the first `:` and does an exact `EqualFold` match against `http`/`https`/`mailto`; no bypass via case, whitespace, or embedded slash is evident. [1](#0-0) 

2. **`cmd/go/internal/vcs/vcs.go` `checkGOINSECURE`/`checkGOVCS`** — these gate module/VCS fetches over insecure schemes. Go's own issue tracker shows these were hardened against exactly this bug class (insecure-redirect bypass) in issues #29591, #61877, and #78805, with regression tests still present and passing. [2](#0-1) [3](#0-2) 

3. **`net/http/client.go` `shouldCopyHeaderOnRedirect`/`isDomainOrSubdomain`** — sensitive-header retention across redirects is scoped by domain/subdomain match, is documented as intentionally permissive by design (not a filter-bypass bug), and is covered by extensive tests including issue #70530 (repeated-redirect stripping) and IDN homograph cases. [4](#0-3) [5](#0-4) 

None of these exhibit an unpatched, exploitable filter-bypass matching the CWE-863 (incorrect authorization) primitive from the reference advisory — they are either allowlist-correct, already fixed with regression tests tied to tracked Go issues, or intentionally permissive documented behavior rather than a defect.

```go
// isSafeURL is true if s is a relative URL or if URL has a protocol in
// (http, https, mailto).
func isSafeURL(s string) bool {
	if protocol, _, ok := strings.Cut(s, ":"); ok && !strings.Contains(protocol, "/") {
		if !strings.EqualFold(protocol, "http") && !strings.EqualFold(protocol, "https") && !strings.EqualFold(protocol, "mailto") {
			return false
		}
	}
	return true
}
```

```go
// isDomainOrSubdomain reports whether sub is a subdomain (or exact
// match) of the parent domain.
//
// Both domains must already be in canonical form.
func isDomainOrSubdomain(sub, parent string) bool {
	if sub == parent {
		return true
	}
	// If sub contains a :, it's probably an IPv6 address (and is definitely not a hostname).
	// Don't check the suffix in this case, to avoid matching the contents of a IPv6 zone.
	// For example, "::1%.www.example.com" is not a subdomain of "www.example.com".
	if strings.ContainsAny(sub, ":%") {
		return false
	}
	// If sub is "foo.example.com" and parent is "example.com",
	// that means sub must end in "."+parent.
	// Do it without allocating.
	if !strings.HasSuffix(sub, parent) {
		return false
	}
	return sub[len(sub)-len(parent)-1] == '.'
}
```
