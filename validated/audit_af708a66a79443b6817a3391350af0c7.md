### Title
Zero minimum lock time for `FreezeBalanceV2Contract` (`TRON_POWER`) allows flash-freeze voting to game SR elections - ([File: actuator/src/main/java/org/tron/core/actuator/FreezeBalanceV2Actuator.java])

### Summary
The legacy `FreezeBalanceContract` (v1) enforces a mandatory minimum lock duration (`minFrozenTime`, typically 3 days) before a freeze can be unwound, via `frozenDuration >= minFrozenTime && frozenDuration <= maxFrozenTime` in `FreezeBalanceActuator.validate()`. [1](#0-0)  In contrast, `FreezeBalanceV2Actuator.validate()` performs no equivalent duration check at all — it only validates balance bounds and resource type, and immediately grants `TRON_POWER`/resource weight on `execute()`. [2](#0-1)  This mirrors the reported bug class: an operation whose "commitment" (freeze) is essentially free/instant compared to the benefit it grants (voting power), letting an actor time the action at the last possible moment before a decision point.

### Finding Description
`FreezeBalanceV2Actuator.execute()` immediately credits `TRON_POWER` weight on freeze with no minimum holding period: [3](#0-2) 

`VoteWitnessActuator.validate()` computes the caster's voting power directly from `accountCapsule.getAllTronPower()` (which includes the just-frozen `FrozenV2` TRON_POWER balance) with no lock-time check either: [4](#0-3) 

Unfreezing via `UnfreezeBalanceV2Actuator`/`UnfreezeBalanceV2Processor` only delays the return of principal by `unfreezeDelayDays` (via `calcUnfreezeExpireTime`), it does not require the balance to have been frozen for any minimum time before initiating unfreeze: [5](#0-4) [6](#0-5) 

Compare this to the FreezeBalanceV1 flow which enforces `minFrozenTime` before the freeze is even valid: [1](#0-0) 

Net effect: an account can broadcast `FreezeBalanceV2Contract(TRON_POWER)` in one block, immediately broadcast `VoteWitnessContract` in the same or next block using that freshly-frozen power, and then broadcast `UnfreezeBalanceV2Contract` to start reclaiming the principal (subject only to `unfreezeDelayDays` for withdrawal, not for the vote itself). The voting right was already exercised with essentially zero holding-period cost.

### Impact Explanation
This allows short-term/flash freezing of TRX purely to sway an SR (Super Representative) election or a maintenance-cycle vote snapshot at the last moment, without the multi-day skin-in-the-game that the legacy freeze mechanism intentionally required. Since SR elections determine block production and reward distribution rights across the entire chain, this directly affects consensus fairness/governance integrity — a core network security property — analogous to the report's "renew right before default" abuse of a too-short minimum duration.

### Likelihood Explanation
Any unprivileged account holding sufficient TRX can perform this sequence purely through ordinary signed transactions (`FreezeBalanceV2Contract` → `VoteWitnessContract` → `UnfreezeBalanceV2Contract`), with no special privileges required, making likelihood high given the low cost (a few blocks of illiquidity plus `unfreezeDelayDays` for actual withdrawal). The main mitigating factor is that principal itself is still locked for `unfreezeDelayDays` before it's usable elsewhere, so this is a governance-influence exploit rather than a fund-theft exploit; note I could not fully verify from the code how/when TRON_POWER vote weight is subtracted or re-validated at the actual SR vote-counting/maintenance cycle (i.e., whether votes cast are re-checked against tron power at counting time vs. at cast time), which affects the exact window of abuse.

### Recommendation
Introduce a minimum freeze duration (or minimum "vote eligibility age") for `FreezeBalanceV2Contract`/`TRON_POWER`, analogous to `minFrozenTime` in v1's `FreezeBalanceActuator.validate()`, or require that TRON_POWER used for `VoteWitnessContract` has been held for at least one full maintenance cycle before being counted.

### Proof of Concept
1. Broadcast `FreezeBalanceV2Contract` with `resource = TRON_POWER` — validated only by `FreezeBalanceV2Actuator.validate()` at lines 131-164 (no duration check), executed immediately (`FreezeBalanceV2Actuator.execute()` lines 73-77) granting `TRON_POWER`.
2. Immediately broadcast `VoteWitnessContract` — `VoteWitnessActuator.validate()` (lines 129-143) accepts votes up to `accountCapsule.getAllTronPower()`, which already reflects the freeze from step 1.
3. Broadcast `UnfreezeBalanceV2Contract` to begin reclaiming the frozen TRX — `UnfreezeBalanceV2Processor.execute()`/`calcUnfreezeExpireTime()` only imposes `unfreezeDelayDays` before final withdrawal, not before initiating unfreeze, so the voting benefit was already obtained with no meaningful lock-in.

  @Override
  public boolean validate() throws ContractValidateException {
    if (this.any == null) {
      throw new ContractValidateException(ActuatorConstant.CONTRACT_NOT_EXIST);
    }
    if (chainBaseManager == null) {
      throw new ContractValidateException(ActuatorConstant.STORE_NOT_EXIST);
    }
    AccountStore accountStore = chainBaseManager.getAccountStore();
    DynamicPropertiesStore dynamicStore = chainBaseManager.getDynamicPropertiesStore();
    if (!any.is(FreezeBalanceV2Contract.class)) {
      throw new ContractValidateException(
          "contract type error,expected type [FreezeBalanceV2Contract],real type[" + any
              .getClass() + "]");
    }

    if (!dynamicStore.supportUnfreezeDelay()) {
      throw new ContractValidateException("Not support FreezeV2 transaction,"
          + " need to be opened by the committee");
    }

    final FreezeBalanceV2Contract freezeBalanceV2Contract;
    try {
      freezeBalanceV2Contract = this.any.unpack(FreezeBalanceV2Contract.class);
    } catch (InvalidProtocolBufferException e) {
      logger.debug(e.getMessage(), e);
      throw new ContractValidateException(e.getMessage());
    }
    byte[] ownerAddress = freezeBalanceV2Contract.getOwnerAddress().toByteArray();
    if (!DecodeUtil.addressValid(ownerAddress)) {
      throw new ContractValidateException("Invalid address");
    }

    AccountCapsule accountCapsule = accountStore.get(ownerAddress);
    if (accountCapsule == null) {
      String readableOwnerAddress = StringUtil.createReadableString(ownerAddress);
      throw new ContractValidateException(
          ActuatorConstant.ACCOUNT_EXCEPTION_STR + readableOwnerAddress + NOT_EXIST_STR);
    }

    long frozenBalance = freezeBalanceV2Contract.getFrozenBalance();
    if (frozenBalance <= 0) {
      throw new ContractValidateException("frozenBalance must be positive");
    }
    if (frozenBalance < TRX_PRECISION) {
      throw new ContractValidateException("frozenBalance must be greater than or equal to 1 TRX");
    }

    if (frozenBalance > accountCapsule.getBalance()) {
      throw new ContractValidateException("frozenBalance must be less than or equal to accountBalance");
    }

    switch (freezeBalanceV2Contract.getResource()) {
      case BANDWIDTH:
      case ENERGY:
        break;
      case TRON_POWER:
        if (!dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "ResourceCode error, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
        break;
      default:
        if (dynamicStore.supportAllowNewResourceModel()) {
          throw new ContractValidateException(
              "ResourceCode error, valid ResourceCode[BANDWIDTH、ENERGY、TRON_POWER]");
        } else {
          throw new ContractValidateException(
              "ResourceCode error, valid ResourceCode[BANDWIDTH、ENERGY]");
        }
    }

    return true;
  }

  public long execute(UnfreezeBalanceV2Param param, Repository repo) {
    byte[] ownerAddress = param.getOwnerAddress();
    long unfreezeBalance = param.getUnfreezeBalance();
    VoteRewardUtil.withdrawReward(ownerAddress, repo);

    AccountCapsule accountCapsule = repo.getAccount(ownerAddress);
    long now = repo.getDynamicPropertiesStore().getLatestBlockHeaderTimestamp();

    long unfreezeExpireBalance = this.unfreezeExpire(accountCapsule, now);

    if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()
        && accountCapsule.oldTronPowerIsNotInitialized()) {
      accountCapsule.initializeOldTronPower();
    }

    long expireTime = this.calcUnfreezeExpireTime(now, repo);
    accountCapsule.addUnfrozenV2List(param.getResourceType(), unfreezeBalance, expireTime);

    this.updateTotalResourceWeight(accountCapsule, param.getResourceType(), unfreezeBalance, repo);
    this.updateVote(accountCapsule, param.getResourceType(), ownerAddress, repo);

    if (repo.getDynamicPropertiesStore().supportAllowNewResourceModel()
        && !accountCapsule.oldTronPowerIsInvalid()) {
      accountCapsule.invalidateOldTronPower();
    }

    repo.updateAccount(accountCapsule.createDbKey(), accountCapsule);
    return unfreezeExpireBalance;
  }

    long unfreezeDelayDays = repo.getDynamicPropertiesStore().getUnfreezeDelayDays();

    return now + unfreezeDelayDays * FROZEN_PERIOD;
  }
