**Reasoning:**

The described attack path is not reachable under the "unprivileged attacker" threat model, and even under relaxed assumptions the check ordering in `Firewall.Drop` prevents the described bypass.

1. `handleOutsideMessagePacket` only runs after `hostinfo.ConnectionState.Decrypt` succeeds [1](#0-0) , meaning the attacker must already possess a valid, established, authenticated tunnel (`hostinfo`) with a peer whose identity was verified via CA-signed certificate during the handshake. An attacker with "no CA-signed certificate" as stipulated cannot produce ciphertext that decrypts successfully, so they can never reach `newPacket`/`Drop` at all.

2. Even granting an authenticated peer (which is already outside the "unprivileged" threat model), `Firewall.Drop` validates `fp.RemoteAddr` against the certificate-bound `h.vpnAddrs[0]` (or the certificate's authorized networks via `h.networks.Lookup`) *before* `inConns` is ever consulted: [2](#0-1) . This means the inner IP header's "RemoteAddr" field cannot be forged to an arbitrary/colliding value — it must equal the address(es) actually certified to that specific `HostInfo`. Since the `firewall.Packet` conntrack key includes `RemoteAddr`, a collision with an existing `Conntrack.Conns` entry for a *different* peer's tuple would require the attacker's own cert to authorize that RemoteAddr, which is precisely what CA-signed certificate issuance prevents.

3. `inConns` itself performs no additional authentication beyond the map lookup [3](#0-2) , but it is only reachable after the `RemoteAddr` gate above, so it cannot be used to bypass identity binding — it only accelerates matching for tuples already scoped to the calling peer's authorized address space.

Because the exploit requires either (a) decrypting/forging AEAD ciphertext without valid keys, or (b) having a CA-signed certificate that authorizes an address matching another connection's tuple — both of which are excluded by the stated attacker constraints — this does not constitute a genuine firewall bypass reachable by an unprivileged attacker.

```go
func (f *Firewall) Drop(fp firewall.Packet, incoming bool, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) error {
	// Make sure remote address matches nebula certificate, and determine how to treat it
	if h.networks == nil {
		// Simple case: Certificate has one address and no unsafe networks
		if h.vpnAddrs[0] != fp.RemoteAddr {
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrInvalidRemoteIP
		}
	} else {
		nwType, ok := h.networks.Lookup(fp.RemoteAddr)
		if !ok {
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrInvalidRemoteIP
		}
		switch nwType {
		case NetworkTypeVPN:
			break // nothing special
		case NetworkTypeVPNPeer:
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrPeerRejected // reject for now, one day this may have different FW rules
		case NetworkTypeUnsafe:
			break // nothing special, one day this may have different FW rules
		default:
			f.metrics(incoming).droppedRemoteAddr.Inc(1)
			return ErrUnknownNetworkType //should never happen
		}
	}

	// Make sure we are supposed to be handling this local ip address
	if !f.routableNetworks.Contains(fp.LocalAddr) {
		f.metrics(incoming).droppedLocalAddr.Inc(1)
		return ErrInvalidLocalIP
	}
```

```go
func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}
```
