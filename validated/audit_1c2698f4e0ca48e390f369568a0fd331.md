### Title
Vesting Distribution Permanently Blocked by Shareholder Disabling Direct Coin Transfers — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`vesting::distribute()` iterates over every shareholder and calls `aptos_account::deposit_coins()` for each one inside a single atomic transaction. `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS` when the recipient account exists, has not registered a `CoinStore<AptosCoin>`, and has explicitly set `allow_arbitrary_coin_transfers = false`. A single shareholder who performs these two unprivileged on-chain actions can cause every subsequent call to `distribute()` — and therefore `terminate_vesting_contract()` — to abort, permanently blocking all other shareholders from receiving their vested APT and blocking the admin from terminating the contract.

---

### Finding Description

**Root cause — `aptos_account::deposit_coins`** [1](#0-0) 

```move
public fun deposit_coins<CoinType>(to: address, coins: Coin<CoinType>)
    acquires DirectTransferConfig {
    if (!account::exists_at(to)) { create_account(to); };
    if (!coin::is_account_registered<CoinType>(to)) {
        assert!(
            can_receive_direct_coin_transfers(to),
            error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
        );
        coin::register<CoinType>(&create_signer(to));
    };
    coin::deposit<CoinType>(to, coins)
}
```

The abort fires when **all three** conditions hold simultaneously:
1. The recipient account already exists on-chain.
2. The recipient has **not** registered a `CoinStore<AptosCoin>` (possible in the post-FA-migration world where `register_apt` only creates a primary fungible store, not a legacy coin store).
3. The recipient has called `set_allow_direct_coin_transfers(account, false)`, setting `allow_arbitrary_coin_transfers = false`. [2](#0-1) 

Both steps are unprivileged entry functions callable by any account holder.

**Propagation — `vesting::distribute()`** [3](#0-2) 

```move
public entry fun distribute(contract_address: address) acquires VestingContract {
    ...
    shareholders.for_each_ref(|shareholder| {
        ...
        let recipient_address = get_beneficiary(vesting_contract, shareholder);
        aptos_account::deposit_coins(recipient_address, share_of_coins);  // ← aborts here
    });
    ...
}
```

There is no per-recipient error handling. One failing `deposit_coins` call aborts the entire transaction, leaving all extracted coins in a dropped `Coin<AptosCoin>` value that Move's linear type system destroys — but because the abort rolls back the entire transaction, no coins are actually lost; however the distribution is completely blocked.

**Cascade — `terminate_vesting_contract()` is also blocked** [4](#0-3) 

```move
public entry fun terminate_vesting_contract(admin: &signer, contract_address: address)
    acquires VestingContract {
    assert_active_vesting_contract(contract_address);
    distribute(contract_address);   // ← always called first; aborts if any shareholder blocks it
    ...
}
```

The admin cannot terminate the contract while `distribute()` is broken.

**Same pattern in `staking_contract::distribute_internal()`** [5](#0-4) 

`distribute_internal` is called from `unlock_stake`, `switch_operator`, and `request_commission`. If the operator sets a malicious beneficiary address (one that has disabled direct coin transfers and has no `CoinStore<AptosCoin>`), every call to those three entry points aborts, locking the staker's funds and preventing operator switching.

---

### Impact Explanation

| Affected function | Who is blocked | Fixable without attacker? |
|---|---|---|
| `vesting::distribute()` | All shareholders in the contract | Admin can call `set_beneficiary` for the attacker's slot |
| `vesting::terminate_vesting_contract()` | Admin | Only after fixing the beneficiary |
| `staking_contract::unlock_stake()` | Staker | Only if operator changes beneficiary |
| `staking_contract::switch_operator()` | Staker | Only if operator changes beneficiary |

For the vesting case the admin has a recovery path (`set_beneficiary`). For the staking case the staker has **no unilateral recovery path** — they cannot unlock stake or switch operators without the operator's cooperation, effectively freezing staking balances.

---

### Likelihood Explanation

- Both `set_allow_direct_coin_transfers(account, false)` and simply never calling `coin::register<AptosCoin>` are unprivileged, zero-cost on-chain actions.
- In the post-FA-migration environment, new accounts created via `aptos_account::create_account` receive a primary fungible store for APT but **not** a legacy `CoinStore<AptosCoin>`, making the precondition naturally satisfied for many modern accounts.
- A shareholder or a malicious operator beneficiary can set this up before or after joining the contract.

---

### Recommendation

Replace the hard-abort `deposit_coins` call inside distribution loops with a pattern that skips or queues failed recipients rather than aborting the entire transaction. Concretely:

1. **Vesting**: Before iterating, verify each `recipient_address` can receive coins; skip and accumulate unclaimed amounts for later manual withdrawal, or use `primary_fungible_store::deposit` (FA path) which does not check `allow_arbitrary_coin_transfers`.
2. **Staking contract**: Apply the same guard in `distribute_internal` before calling `aptos_account::deposit_coins`.
3. Alternatively, mandate that all shareholder/beneficiary addresses are registered for `AptosCoin` at contract-creation time and enforce this invariant when beneficiaries are updated.

---

### Proof of Concept

```
// Attacker is shareholder S in vesting contract at address C.

// Step 1 (unprivileged): ensure S has an account but no CoinStore<AptosCoin>
// (naturally true for accounts created post-FA migration)

// Step 2 (unprivileged): disable direct coin transfers
aptos_account::set_allow_direct_coin_transfers(&S_signer, false);

// Step 3: any caller tries to distribute
vesting::distribute(C);
// → iterates shareholders, reaches S
// → aptos_account::deposit_coins(S, share_of_coins)
// → coin::is_account_registered<AptosCoin>(S) == false
// → can_receive_direct_coin_transfers(S) == false
// → ABORT: EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS
// All other shareholders receive nothing; transaction rolls back.

// Step 4: admin tries to terminate
vesting::terminate_vesting_contract(&admin_signer, C);
// → calls distribute(C) → same abort → termination impossible.
```

    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);

        emit(
            Terminate {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
            },
        );
    }
