### Title
Recipient-Controlled Abort in `deposit_coins` Blocks Entire Vesting/Staking Distribution — (`aptos-move/framework/aptos-framework/sources/vesting.move`, `staking_contract.move`)

---

### Summary

`vesting::distribute()` and `staking_contract::distribute_internal()` iterate over all recipients and call `aptos_account::deposit_coins<AptosCoin>()` for each one inside a single atomic transaction. `deposit_coins` will **abort** if the recipient account exists, has no `CoinStore<AptosCoin>`, and has set `allow_arbitrary_coin_transfers = false`. Because Move transactions are all-or-nothing, a single blocking recipient causes the entire distribution to revert, preventing every other shareholder or staker from receiving their funds until an admin or operator intervenes.

This is the direct Aptos analog of the Solidity `transfer()` vs `call()` class: a push-payment loop where any one recipient can grief the whole batch.

---

### Finding Description

**Root cause — `aptos_account::deposit_coins` can abort on a valid recipient:** [1](#0-0) 

```move
public fun deposit_coins<CoinType>(to: address, coins: Coin<CoinType>) acquires DirectTransferConfig {
    if (!account::exists_at(to)) { create_account(to); };
    if (!coin::is_account_registered<CoinType>(to)) {
        assert!(
            can_receive_direct_coin_transfers(to),
            error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
        );
        coin::register<CoinType>(&create_signer(to));
    };
    coin::deposit<CoinType>(to, coins)
}
```

`aptos_account::create_account` only creates the APT **fungible-asset** primary store (via `register_apt` → `ensure_primary_fungible_store_exists`); it does **not** create a `CoinStore<AptosCoin>`. So an account created this way has `coin::is_account_registered<AptosCoin>() == false`. If that account then calls `set_allow_direct_coin_transfers(account, false)`, `can_receive_direct_coin_transfers` returns `false` and `deposit_coins` aborts. [2](#0-1) 

**Affected site 1 — `vesting::distribute()` iterates all shareholders atomically:** [3](#0-2) 

```move
shareholders.for_each_ref(|shareholder| {
    let shareholder = *shareholder;
    ...
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);  // ← can abort
});
```

If any `recipient_address` satisfies the blocking condition, the entire `distribute()` call aborts. All other shareholders' coins are rolled back into the stake pool; no one receives anything.

**Affected site 2 — `staking_contract::distribute_internal()` iterates all distribution-pool shareholders:** [4](#0-3) 

```move
while (distribution_pool.shareholders_count() > 0) {
    ...
    if (recipient == operator) { recipient = beneficiary_for_operator(operator); };
    aptos_account::deposit_coins(recipient, coin::extract(&mut coins, amount_to_distribute));
    // ↑ aborts if beneficiary has disabled direct transfers
};
if (coin::value(&coins) > 0) {
    aptos_account::deposit_coins(staker, coins);  // ← also can abort
```

`distribute_internal` is called from `distribute`, `request_commission`, `switch_operator`, and `update_commission`. If it always aborts, the staker cannot switch operators, request commission, or update commission rates — they are locked into the current staking arrangement.

---

### Impact Explanation

**Vesting contract:** A single shareholder (or the admin who sets beneficiaries) can point their beneficiary at an address that has disabled direct coin transfers. Every subsequent call to `distribute()` or `distribute_many()` aborts. All other shareholders are blocked from receiving vested APT until the admin calls `set_beneficiary` to override the problematic entry. During the blocking window, vesting balances are effectively frozen.

**Staking contract:** The operator can set their beneficiary (`set_beneficiary_for_operator`) to a blocking address. Every call to `distribute_internal` then aborts, which cascades to `request_commission`, `switch_operator`, and `update_commission`. The staker loses the ability to manage their staking contract until the operator voluntarily fixes their beneficiary.

---

### Likelihood Explanation

- Any shareholder in a vesting contract, or any operator in a staking contract, can trigger this with two unprivileged transactions: (1) create an account without registering for APT coin, (2) call `set_allow_direct_coin_transfers(false)`.
- The `distribute` entry point is callable by anyone (`public entry fun distribute`), so the DoS is easy to confirm but not easy to trigger accidentally — it requires deliberate setup.
- The admin/operator can remediate, but remediation requires them to notice the problem and act; during that window all other participants are harmed.

---

### Recommendation

Replace the push-payment loop with a pull-payment pattern or skip-and-accumulate pattern:

1. **Skip-and-accumulate**: If `deposit_coins` would abort for a recipient, skip that recipient and record their unclaimed balance in a separate map. Provide a separate `claim(recipient)` entry function.
2. **Use `coin::force_deposit`** (which bypasses the `DirectTransferConfig` check) for framework-internal distributions where the recipient's opt-out preference should not block other parties.
3. At minimum, wrap each `deposit_coins` call in a conditional that checks `can_receive_direct_coin_transfers` before attempting the deposit, and accumulates unclaimed amounts rather than aborting.

---

### Proof of Concept

```
// Step 1: attacker creates a blocking address
aptos_account::create_account(@blocker);           // FA store only, no CoinStore<APT>
set_allow_direct_coin_transfers(@blocker, false);  // disable direct transfers

// Step 2: attacker is a shareholder in a vesting contract;
//         admin (or attacker if they control admin) sets their beneficiary
vesting::set_beneficiary(admin, contract_addr, @attacker_shareholder, @blocker);

// Step 3: anyone calls distribute — it aborts for ALL shareholders
vesting::distribute(contract_addr);
// → abort: EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS
// All shareholders receive nothing; coins remain locked in stake pool.
```

The same pattern applies to `staking_contract::distribute` by setting the operator's beneficiary to `@blocker` via `set_beneficiary_for_operator`. [5](#0-4) [6](#0-5) [1](#0-0)

    /// Distribute any withdrawable stake from the stake pool.
    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
