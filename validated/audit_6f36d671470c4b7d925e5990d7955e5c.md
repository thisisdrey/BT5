### Title
Signer event-receiver HTTP endpoint accepts unauthenticated event POSTs, allowing unprivileged injection of forged signer/node events - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event()` in `libsigner/src/events.rs` is the HTTP endpoint the stacks-signer binds to receive event-observer pushes from its paired node (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`). Nowhere in this handler is any credential (the `auth_token`/`auth_password` documented in `docs/signing.md`) checked before the request body is parsed and dispatched as a trusted `SignerEvent`. This mirrors the `Red-DiscordBot` CWE-863 pattern: a permission/authorization gate that is assumed to be enforced by the framework but is not actually checked at the enforcement point, letting an unauthorized caller reach privileged functionality.

### Finding Description
`docs/signing.md` states that the signer's `auth_password` and the node's `[connection_options] auth_token` "must match" and are used to secure the event-observer channel between the node and the signer: [1](#0-0) 

However, in `libsigner/src/events.rs`, the actual HTTP request handler that receives these events performs no authentication check at all. It only dispatches based on `request.url()` and `request.method()`: [2](#0-1) 

Compare this to the node-side RPC handlers that *do* correctly gate privileged endpoints with an `authorization` header check before processing the body, e.g. `RPCBlockProposalRequestHandler::try_parse_request` and `RPCFastCallReadOnlyRequestHandler::try_parse_request`: [3](#0-2) [4](#0-3) 

The signer's `bind()` simply stands up an `HttpServer` with no auth middleware, and `SignerStopSignaler::send()` even demonstrates that any TCP client can POST to this listener (it does so itself, unauthenticated, to trigger shutdown): [5](#0-4) 

Grepping the signer transport code confirms no `Authorization`/`auth_token` check exists anywhere in `libsigner`, while the equivalent check exists (and is enforced) only on unrelated node-side HTTP RPC endpoints (`postblock_proposal.rs`, `fastcallreadonly.rs`, `config/mod.rs`). The intended "authenticated request" equality (caller presents correct `auth_token` == what the receiver expects) is never evaluated on the signer's event-receiver side — the check is missing entirely rather than merely misapplied, but the effect is the same class of bug as the advisory: an authorization gate that is expected/documented to protect a sensitive operation fails open because the check site does not exist on the enforcement path.

Once through this "gate" (which doesn't exist), the body is deserialized directly into `StackerDBChunksEvent`, `BlockValidateResponse`, `BurnBlockEvent`, or `StacksBlockEvent` and forwarded as a trusted `SignerEvent` to the signer's runloop: [6](#0-5) 

For `BurnBlockEvent` and `StacksBlockEvent` in particular, there is no cryptographic signature carried in the JSON payload that is verified before the event is trusted — unlike `StackerDBChunksEvent`, which at least carries a per-chunk signature (`chunk.recover_pk()`), these events are accepted purely because they arrived on the right URL path: [7](#0-6) 

### Impact Explanation
Any unprivileged network client that can reach the signer's bound event-receiver port can inject forged `BurnBlockEvent`/`StacksBlockEvent`/`BlockValidateResponse` messages into the signer's runloop as if they came from the trusted node, or replay/forge `StackerDBChunksEvent` payloads. This lets an attacker feed the signer non-canonical burn-chain/tip state or fabricated validation responses without needing the node's secret `auth_token`, directly violating the "authenticated vs. stored/served" equality the advisory's bug class targets. Depending on how the (out-of-scope) signer decision logic consumes these events, this can steer the signer off the true chain tip or falsify block-validation results it acts on — matching the "High: steering a node off the tip via false inventory" impact bucket.

### Likelihood Explanation
High. This requires only network reachability to the signer's bound HTTP port and knowledge of the fixed URL paths (`/stackerdb_chunks`, `/new_burn_block`, `/new_block`, `/proposal_response`), which are public in the source code. No key material, node secret, or admin role is required — exactly the "unprivileged remote" condition emphasized in the rules.

### Recommendation
Add an authentication check (validating the `auth_token`/`auth_password` documented in `docs/signing.md`, e.g. via an `Authorization` header) inside `SignerEventReceiver::next_event()` in `libsigner/src/events.rs` before dispatching any `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, or `/new_block` request, mirroring the pattern already used in `stackslib/src/net/api/postblock_proposal.rs` and `fastcallreadonly.rs`. Reject requests with a missing or incorrect token with an HTTP 401 prior to reading/deserializing the body.

### Proof of Concept
1. Start a stacks-signer bound to `endpoint` (e.g. `127.0.0.1:30000`) with any `auth_password` configured, per `sample/conf/testnet-signer.toml`.
2. From an unauthenticated peer with network access to that port, send:
```
POST /new_burn_block HTTP/1.1
Host: 127.0.0.1:30000
Content-Type: application/json
Content-Length: <n>

{ <forged BurnBlockEvent JSON> }
```
   (no `Authorization` header, no valid `auth_token`).
3. Observe `SignerEventReceiver::next_event()` accepts, deserializes, and forwards the forged event to the signer's runloop exactly as it would for a genuine event from the paired node — confirmed by the code path at `libsigner/src/events.rs:413-458` and `519-542`, which contain no credential check.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

impl<T: SignerEventTrait> TryFrom<StackerDBChunksEvent> for SignerEvent<T> {
    type Error = EventError;

    fn try_from(event: StackerDBChunksEvent) -> Result<Self, Self::Error> {
        let received_time = SystemTime::now();
        let signer_event = if event.contract_id.name.as_str() == MINERS_NAME
            && event.contract_id.is_boot()
        {
            let mut messages = vec![];
            for chunk in event.modified_slots {
                match T::consensus_deserialize(&mut chunk.data.as_slice()) {
                    Ok(msg) => messages.push(msg),
                    Err(e) => {
                        debug!(
                            "Signer failed to deserialize miner chunk";
                            "slot_id" => chunk.slot_id,
                            "slot_version" => chunk.slot_version,
                            "data_len" => chunk.data.len(),
                            "error" => %e,
                        );
                    }
                }
            }
            SignerEvent::MinerMessages(messages)
        } else if event.contract_id.name.starts_with(SIGNERS_NAME) && event.contract_id.is_boot() {
            let Some((signer_set, message_id)) =
                get_signers_db_signer_set_message_id(event.contract_id.name.as_str())
            else {
                return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
            };
            // signer-XXX-YYY boot contract
            //
            // NOTE: the payload-type check below uses v0 `SignerMessageTypePrefix` semantics
            // (the mapping in `signer_message_payload_matches_lane` is fixed to v0). Future
            // signer-message versions must extend that mapping, or their chunks will not be
            // recognized here regardless of which `T` is in scope.
            let messages: Vec<_> = event
                .modified_slots
                .iter()
                .filter_map(|chunk| {
                    // Accept only payloads whose type is valid for this contract's message id.
                    let &type_byte = chunk.data.first()?;
                    let payload_kind = SignerMessageTypePrefix::from_u8(type_byte)?;
                    if !signer_message_payload_matches_lane(payload_kind, message_id) {
                        warn!(
                            "Skipping signer chunk with unexpected payload type for contract";
                            "contract" => %event.contract_id,
                            "lane_message_id" => message_id,
                            "payload_type_prefix" => type_byte,
                        );
                        return None;
                    }
                    let Ok(pk) = chunk.recover_pk() else {
                        warn!(
                            "Skipping signer chunk: signature recovery failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    let Ok(message) = read_next::<T, _>(&mut &chunk.data[..]) else {
                        warn!(
                            "Skipping signer chunk: payload deserialization failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    Some((chunk.slot_id, pk, message))
                })
                .collect();
            SignerEvent::SignerMessages {
                signer_set,
                messages,
                received_time,
            }
        } else {
            return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
        };
        Ok(signer_event)
    }
}
