This repository is the Go standard library/toolchain source (`Loderfordw/go--015`), not a web application like reNgine, so there is no unauthenticated HTTP-facing request handler that builds a shell command from user input analogous to reNgine's `nmap_cmd` parameter. The `exec.Command` call sites found are either developer/build-tooling internals with trusted or locally-configured inputs (e.g., `buildCommand` for the user-configured `GOAUTH` command in [1](#0-0) , VCS command execution using a fixed argument template in [2](#0-1) , and the cgo compiler wrapper in [3](#0-2) ), or are test/browser-opening utilities not reachable from unauthenticated network input ( [4](#0-3) ). Crucially, all of these use `os/exec.Command`, which per the package's own documentation "does not invoke the system shell and does not expand any glob patterns or handle other expansions, pipelines, or redirections typically done by shells" [5](#0-4) , unlike the reNgine Python code which likely built a shell string for `nmap`. None of these entry points match the required primitive: an unauthenticated HTTP request reaching a shell-interpreted command sink.

```go
func run(stdin []byte, argv []string) (stdout, stderr []byte, ok bool) {
	if i := slices.Index(argv, "-xc"); i >= 0 && argv[len(argv)-1] == "-" {
		// Some compilers have trouble with standard input.
		// Others have trouble with -xc.
		// Avoid both problems by writing a file with a .c extension.
		f, err := os.CreateTemp("", "cgo-gcc-input-")
		if err != nil {
			fatalf("%s", err)
		}
		name := f.Name()
		f.Close()
		if err := os.WriteFile(name+".c", stdin, 0666); err != nil {
			os.Remove(name)
			fatalf("%s", err)
		}
		defer os.Remove(name)
		defer os.Remove(name + ".c")

		// Build new argument list without -xc and trailing -.
		new := append(argv[:i:i], argv[i+1:len(argv)-1]...)

		// Since we are going to write the file to a temporary directory,
		// we will need to add -I . explicitly to the command line:
		// any #include "foo" before would have looked in the current
		// directory as the directory "holding" standard input, but now
		// the temporary directory holds the input.
		// We've also run into compilers that reject "-I." but allow "-I", ".",
		// so be sure to use two arguments.
		// This matters mainly for people invoking cgo -godefs by hand.
		new = append(new, "-I", ".")

		// Finish argument list with path to C file.
		new = append(new, name+".c")

		argv = new
		stdin = nil
	}

	p := exec.Command(argv[0], argv[1:]...)
```
