Unauthenticated remote shutdown / event forgery via `SignerEventReceiver::next_event` URL dispatch - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` binds a plain `tiny_http` HTTP server and dispatches solely on `request.url()` string equality, with no check of the sender's identity, secret, or source. Any TCP client that can reach the bound port can POST `/shutdown` to kill the signer's event receiver, or POST a forged JSON body to `/new_block` or `/new_burn_block` to inject an event into the signer runloop as if it came from the trusted local node dispatcher.

### Finding Description
`bind()` opens an unauthenticated `HttpServer::http(listener)` [1](#0-0) . `next_event()` then reads one request and dispatches purely by matching `request.url()` against fixed strings (`/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/shutdown`, `/new_block`), with no signature, token, or peer-identity check anywhere in the path [2](#0-1) . A POST to `/shutdown` unconditionally sets `stop_signal` and returns `EventError::Terminated`, which `main_loop` treats as normal termination [3](#0-2) [4](#0-3) . A POST to `/new_block` is deserialized via `process_event::<T, StacksBlockEvent>`, which only performs `serde_json::from_slice` on the body with no origin verification, then converts directly into `SignerEvent::NewBlock` and is forwarded to the runloop [5](#0-4) [6](#0-5) . The legitimate stop path (`SignerStopSignaler::send`) itself works by connecting a plain `TcpStream` and sending the same unauthenticated `POST /shutdown` request [7](#0-6) , confirming there is no secret or credential distinguishing a legitimate caller from an arbitrary one — the mechanism is "whoever can open a TCP connection to this port and issue this exact HTTP request can control the receiver."

### Impact Explanation
An attacker who can reach the bound event-receiver TCP port can: (1) send `POST /shutdown` to terminate the event-receiver thread, which is treated as a clean stop, effectively performing an unauthenticated remote DoS against the signer's ability to receive future node events; (2) send `POST /new_block` or `POST /new_burn_block` with an attacker-crafted JSON body to inject a `SignerEvent::NewBlock`/`NewBurnBlock` into the signer's runloop, whose fields (`block_height`, `transactions` via `deserialize_raw_tx_hex`, `consensus_hash`, etc.) are taken verbatim from the JSON with no validation against actual chain state. This breaks the trust invariant that events forwarded to the signer runloop originate from the node's local, trusted event dispatcher. This matches the Critical category ("remote crash/unauthenticated DoS from few messages" and "unauthenticated/unauthorized write to state") since a single crafted HTTP request achieves it.

### Likelihood Explanation
The only precondition is TCP reachability to the configured bind address/port of the signer's event receiver — no secret, peer identity, or privileged role is required, matching the "unprivileged remote attacker" threat model. Whether this is remotely exploitable in practice depends on the deployed bind address (e.g., loopback-only vs. a publicly/externally reachable interface) and network firewalling around the signer's event port, which is an operational/deployment configuration outside of what `libsigner/src/events.rs` enforces in code — the code itself provides zero defense-in-depth regardless of bind address. Each malicious request is cheap, requires no state, and is fully repeatable (repeat `/shutdown` POSTs indefinitely, or repeat forged `/new_block` POSTs).

### Recommendation
Add authentication to the signer's event-receiver HTTP endpoint: require a shared secret/bearer token (checked via constant-time comparison) on every request, or bind exclusively to loopback and require the dispatcher and event receiver to run on the same host, or introduce mutual TLS/HMAC-signed request bodies so `next_event` can verify the sender is the configured node dispatcher before acting on `/shutdown`, `/new_block`, or `/new_burn_block`.

### Proof of Concept
```rust
// In libsigner/src/tests/mod.rs or a new test module
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use libsigner::events::{SignerEventReceiver, EventReceiver};
use libsigner::EventError;

#[test]
fn unauthenticated_remote_shutdown() {
    let mut receiver: SignerEventReceiver<SomeMessageType> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Attacker: not the node dispatcher, just a raw TCP client
    let mut attacker = TcpStream::connect(bound).unwrap();
    let body = "attack";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        bound, body.len(), body
    );
    attacker.write_all(req.as_bytes()).unwrap();

    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());
}
```
This demonstrates that an arbitrary TCP client (not the configured node dispatcher) can terminate the event receiver with a single unauthenticated request, matching the `EventError::Terminated` path at [3](#0-2) . A parallel PoC posting a crafted JSON body to `/new_block` and asserting `forward_event` receives an attacker-controlled `SignerEvent::NewBlock` demonstrates the forgery path via `process_event::<T, StacksBlockEvent>` at [8](#0-7) .

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```
