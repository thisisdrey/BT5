**Reasoning basis:** `TokenDiff::supply_delta` (contracts/defuse/core/src/intents/token_diff.rs, lines 169-183) is only invoked by `closure_delta`, `closure_deltas`, and `closure_many`, which are pure helper functions for computing arbitrage "closures" — they are not called anywhere in `TokenDiff::execute_intent`, the code path that actually mutates Verifier balances. [1](#0-0) 

The real fund-moving logic in `execute_intent` applies `delta` directly via `engine.state.internal_apply_deltas` and computes the fee independently using `Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount)`, which calls `Pips::fee_ceil` — an unsigned `checked_mul_div_ceil` on `amount: u128` (always non-negative), not the signed `i128::checked_mul_div_ceil` used inside `supply_delta`. [2](#0-1) [3](#0-2) 

Grepping the repo confirms `supply_delta`/`closure_delta`/`closure_deltas` are referenced only within this file and its own test module (`tests/src/tests/defuse/intents/token_diff.rs`), with no call site in the engine's balance-settlement or fee-collection path. Therefore, even if the signed `checked_mul_div_ceil` behaves asymmetrically for negative numerators (rounding toward positive infinity, i.e., less aggressive magnitude reduction for negative deltas), this cannot be exploited to under-debit a signer's actual Verifier balance, since the balance-affecting fee computation never passes through `supply_delta`. The claimed binding break has no reachable path to fund movement, so the required Critical impact ("value leaving the Verifier that the signer never authorised") is not demonstrated.

    fn execute_intent<S, I>(
        self,
        signer_id: &AccountIdRef,
        engine: &mut Engine<S, I>,
        intent_hash: [u8; 32],
    ) -> Result<()>
    where
        S: State,
        I: Inspector,
    {
        if self.diff.is_empty() {
            return Err(DefuseError::InvalidIntent);
        }

        let protocol_fee = engine.state.fee();
        let mut fees_collected: Amounts = Amounts::default();

        for (token_id, delta) in &self.diff {
            if *delta == 0 {
                return Err(DefuseError::InvalidIntent);
            }

            // add delta to signer's account
            engine
                .state
                .internal_apply_deltas(signer_id, [(token_id.clone(), *delta)])?;

            // take fees only from negative deltas (i.e. token_in)
            if *delta < 0 {
                let amount = delta.unsigned_abs();
                let fee = Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount);

                // collect fee
                fees_collected
                    .add(token_id.clone(), fee)
                    .ok_or(DefuseError::BalanceOverflow)?;
            }
        }
