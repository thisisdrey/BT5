### Title
Stale per-routine conntrack cache bypasses firewall rule re-validation - (File: `firewall.go`, `firewall/cache.go`)

### Summary
The reported LoopFi bug is a class of "state omission in a value used for a critical decision": `totalAssets()` excludes unclaimed rewards, so downstream share/asset math is computed against stale data. The reachable analog in this codebase is `Firewall.inConns` combined with the per-routine `ConntrackCache` (`firewall/cache.go`): a local, unsynchronized cache short-circuits the firewall's authoritative re-validation logic (which checks `rulesVersion` and `Expires` against the shared `Conntrack` table), allowing packets to be admitted purely because a flow was seen recently in the local cache — without re-checking whether the firewall rules changed or the conntrack entry actually expired in the meantime.

### Finding Description
`Firewall.inConns` is the authoritative conntrack lookup used by `Firewall.Drop` to decide whether a packet belonging to an existing "connection" is allowed through without a full rule match: [1](#0-0) 

Critically, before even taking the `conntrack` lock, it consults a per-goroutine local cache and returns `true` immediately if the flow key is present, with **no re-validation of rule version or freshness**: [2](#0-1) 

The authoritative path, by contrast, explicitly re-validates against the *current* `f.rulesVersion` and drops/deletes the entry if the ruleset changed and no longer matches: [3](#0-2) 

The local cache (`firewall.ConntrackCache`) is populated any time `inConns` succeeds and is only cleared wholesale on a timer tick (`conntrackCacheTimeout`, default 1s when `routines > 1`), not immediately when firewall rules are reloaded: [4](#0-3) [5](#0-4) 

So a flow that was legitimately allowed under an old ruleset gets memoized in the local cache and continues to be treated as "allowed" for up to `conntrackCacheTimeout` (or indefinitely if the routine's cache tick never advances), even after `reloadFirewall` bumps `f.rulesVersion` to something that would otherwise cause `inConns` to invalidate and drop it (`c.rulesVersion != f.rulesVersion` branch). This is exactly analogous to `totalAssets()` omitting `earned()` rewards: a "cheap" derived/cached value is used in place of the authoritative, up-to-date state, producing an incorrect (here, security-relevant) decision.

### Impact Explanation
This allows temporary firewall-rule bypass: traffic that should be rejected under a newly-applied (tightened) ruleset is instead passed through for the duration the stale local cache entry persists, because the local cache decision (`return true`) is never subjected to the `rulesVersion`/expiry re-check that the authoritative `conntrack.Conns` path performs. This is a remote-state (firewall enforcement) integrity issue reachable purely by an already-connected peer sending packets that match a previously-allowed flow tuple — no valid CA-signed certificate re-verification is bypassed, but the firewall's security-group enforcement (which is meant to react to config/rule changes immediately) is undermined for the cache window.

### Likelihood Explanation
The condition requires `routines > 1` (multi-queue mode) or an explicitly configured `firewall.conntrack.routine_cache_timeout`, which is a supported and documented (if "EXPERIMENTAL") configuration. Any operator running multi-routine mode and tightening firewall rules while a flow is active is affected without any attacker action; an attacker on an already-established tunnel simply needs to keep a flow "warm" across a rule reload to benefit, which is a normal, easily-achievable network pattern. Likelihood is moderate: it depends on a rule reload happening concurrently with an active flow and multi-routine mode being enabled.

### Recommendation
Either (a) invalidate/clear the local `ConntrackCache` immediately when `f.rulesVersion` changes (e.g., signal the ticker or maintain a rules-version stamp per cache entry checked on every `Get()`/lookup), or (b) store enough information in the local cache entry (e.g., the `rulesVersion` at insertion time) so `inConns` can detect staleness on the fast path and fall through to the authoritative re-validation instead of unconditionally returning `true`.

### Proof of Concept
1. Run nebula with `routines > 1` (or explicit `firewall.conntrack.routine_cache_timeout` > 0) so `ctCache := firewall.NewConntrackCacheTicker(...)` is active per `listenIn`/`listenOut` routine.
2. Establish a flow `A` that is allowed by the current firewall ruleset; `inConns` populates both the shared `conntrack.Conns` map and the routine-local `ConntrackCache`.
3. Reload the firewall configuration with a stricter ruleset that no longer permits flow `A` (`f.rulesVersion` increments via `reloadFirewall`).
4. Continue sending packets for flow `A` within the local cache's tick window (default up to 1s, or longer/indefinitely depending on config/tick cadence): `inConns` hits the local cache check at [2](#0-1)  and returns `true` without ever reaching the `rulesVersion` comparison at [6](#0-5) , so the packet is passed even though the authoritative table would have dropped it (as demonstrated by the ruleset-swap behavior in `TestFirewall_DropConntrackReload`, which only exercises the non-cached path): [7](#0-6)

func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}

// Get checks if the cache ticker has moved to the next version before returning
// the map. If it has moved, we reset the map.
func (c *ConntrackCacheTicker) Get() ConntrackCache {
	if c == nil {
		return nil
	}
	if tick := c.cacheTick.Load(); tick != c.cacheV {
		c.cacheV = tick
		if ll := len(c.cache); ll > 0 {
			if c.l.Enabled(context.Background(), slog.LevelDebug) {
				c.l.Debug("resetting conntrack cache", "len", ll)
			}
			c.cache = make(ConntrackCache, ll)
		}
	}

	return c.cache
}

func TestFirewall_DropConntrackReload(t *testing.T) {
	ob := &bytes.Buffer{}
	l := test.NewLoggerWithOutput(ob)
	myVpnNetworksTable := new(bart.Lite)
	myVpnNetworksTable.Insert(netip.MustParsePrefix("1.1.1.1/8"))

	p := firewall.Packet{
		LocalAddr:  netip.MustParseAddr("1.2.3.4"),
		RemoteAddr: netip.MustParseAddr("1.2.3.4"),
		LocalPort:  10,
		RemotePort: 90,
		Protocol:   firewall.ProtoUDP,
		Fragment:   false,
	}
	network := netip.MustParsePrefix("1.2.3.4/24")

	c := cert.CachedCertificate{
		Certificate: &dummyCert{
			name:     "host1",
			networks: []netip.Prefix{network},
			groups:   []string{"default-group"},
			issuer:   "signer-shasum",
		},
		InvertedGroups: map[string]struct{}{"default-group": {}},
	}
	h := HostInfo{
		ConnectionState: &ConnectionState{
			peerCert: &c,
		},
		vpnAddrs: []netip.Addr{network.Addr()},
	}
	h.buildNetworks(myVpnNetworksTable, c.Certificate)

	fw := NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 0, 0, []string{"any"}, "", "", "", "", ""))
	cp := cert.NewCAPool()

	// Drop outbound
	assert.Equal(t, fw.Drop(p, false, &h, cp, nil), ErrNoMatchingRule)
	// Allow inbound
	resetConntrack(fw)
	require.NoError(t, fw.Drop(p, true, &h, cp, nil))
	// Allow outbound because conntrack
	require.NoError(t, fw.Drop(p, false, &h, cp, nil))

	oldFw := fw
	fw = NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 10, 10, []string{"any"}, "", "", "", "", ""))
	fw.Conntrack = oldFw.Conntrack
	fw.rulesVersion = oldFw.rulesVersion + 1

	// Allow outbound because conntrack and new rules allow port 10
	require.NoError(t, fw.Drop(p, false, &h, cp, nil))

	oldFw = fw
	fw = NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 11, 11, []string{"any"}, "", "", "", "", ""))
	fw.Conntrack = oldFw.Conntrack
	fw.rulesVersion = oldFw.rulesVersion + 1

	// Drop outbound because conntrack doesn't match new ruleset
	assert.Equal(t, fw.Drop(p, false, &h, cp, nil), ErrNoMatchingRule)
