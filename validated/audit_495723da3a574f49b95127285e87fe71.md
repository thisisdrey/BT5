### Title
Vault share price optimistically counts uncollected accrued interest as backing, letting early redeemers extract real cash owed to remaining depositors - (File: `mainnet/contracts/vault/v0-vault-usdc.clar` and equivalent `v0-vault-*.clar` vaults)

### Summary
Every Zest vault (`v0-vault-usdc.clar`, `v0-vault-sbtc.clar`, `v0-vault-ststx.clar`, `v0-vault-ststxbtc.clar`, `v0-vault-stx.clar`, `v0-vault-usdh.clar`) prices `zft` shares using `total-assets()`/`total-assets-preview()`, which add not-yet-collected accrued interest (`debt - borrowed`) on top of the real underlying balance (`assets`). `redeem` pays out real underlying tokens using this inflated price while only guarding against reverting if the real `assets`/liquidity is insufficient — it never forces collection of the debt that the price optimistically assumes exists, exactly mirroring the M-02 `_doSherX` pattern of computing payout from an optimistic "all debt is paid" view.

### Finding Description
`total-assets` and its preview variant treat accrued-but-uncollected borrower interest as vault backing: [1](#0-0) 

`interest` here is `total-debt - total-borrowed`, i.e. interest that has accrued in the virtual `index`/`principal-scaled` accounting but has **not** actually been repaid into the vault's real underlying balance. Real underlying only increases via `system-repay`, which moves `interest-paid` into the real `assets` var: [2](#0-1) 

Both `convert-to-shares-preview` and `convert-to-assets-preview` (used by `deposit` and `redeem`) divide by/multiply by this inflated `total-assets-preview`: [3](#0-2) 

`redeem` is a public, unprivileged entry point that computes the payout `inkind` from this inflated price and transfers real underlying, only reverting if the real cash (`current-assets`, `available-assets`) happens to be insufficient — there is no step analogous to `LibPool.payOffDebtAll` that force-collects the outstanding interest before it is priced into a withdrawal: [4](#0-3) 

Because the "interest" component of `total-assets` is purely a projection of `index`/`principal-scaled` and is never verified to be actually collectible from borrowers at redemption time, any depositor who redeems while real cash is still available extracts real underlying priced as if that interest had already been repaid. If a borrower's debt later turns out to be uncollectible, the loss is only recognized when `socialize-debt` is explicitly called, which writes down `lindex` and the real `assets` var for whoever is still holding shares at that moment: [5](#0-4) 

This is the same root cause as `_doSherX`/`calcUnderlying`: a payout is computed from a value that optimistically assumes outstanding debt will be paid, without confirming or forcing that collection before real funds leave the pool.

### Impact Explanation
Depositors who redeem before a bad debt is recognized/socialized get paid out of the real underlying pool at a price that includes interest never actually collected. This is a direct transfer of real value from later/remaining depositors (who bear the full write-down via `socialize-debt` against a now-smaller supply) to earlier redeemers, and can also leave remaining depositors unable to withdraw their fair share of real assets (temporary freezing of funds) once the cash pool is drained faster than the true backing supports. This lands in the in-scope "temporary freezing of funds" / theft-of-unclaimed-yield category, since the interest being distributed was never actually earned/collected before being paid out.

### Likelihood Explanation
This triggers under normal operating conditions whenever any borrower's accrued interest sits uncollected while other users redeem (a routine, permissionless state — no DAO action or oracle manipulation is required), which is likely at any point where utilization/interest is not immediately repaid before a redeem transaction lands. The severity scales with the amount of uncollectible/at-risk debt outstanding at redemption time.

### Recommendation
Before pricing a `redeem` (or `deposit`) using `total-assets`/`total-assets-preview`, either (a) exclude uncollected accrued interest from the share-price numerator and only recognize it once actually repaid via `system-repay`, or (b) force collection/haircut of at-risk interest (similar to Sherlock's `payOffDebtAll`) so the price used for payout never exceeds what is verifiably backed by real, collectible underlying.

### Proof of Concept
1. Vault has `assets = 100`, one borrower has `principal-scaled` corresponding to `total-borrowed = 100`; time passes and `index` accrues so `total-debt = 110` (10 accrued interest, uncollected).
2. `total-assets()` returns `100 + (110 - 100) = 110`; `total-supply` corresponds to shares minted for the original 100 deposited. Share price is now `110/100` per unit supply, i.e., inflated by the uncollected interest.
3. A depositor calls `redeem`, computing `inkind = convert-to-assets-preview(shares)` using the inflated `total-assets-preview` [6](#0-5) , and receives real underlying out of the `assets = 100` pool at the inflated rate, as long as `current-assets`/`available-assets` checks pass [7](#0-6) .
4. The borrower later defaults; `socialize-debt` is called and writes down `assets`/`lindex` for the now-smaller remaining `total-supply` [8](#0-7) , meaning remaining depositors absorb the full loss while the earlier redeemer already extracted value based on interest that was never collected.

(define-private (total-debt)
  (calc-cumulative-debt (var-get principal-scaled) (var-get index)))

(define-private (debt-preview)
  (calc-cumulative-debt (var-get principal-scaled) (next-index)))

(define-private (total-assets)
  (let ((current-assets (var-get assets))
        (debt (total-debt))
        (borrowed (var-get total-borrowed))
        (interest (if (> debt borrowed) (- debt borrowed) u0)))
    (+ current-assets interest)))

(define-public (system-repay (amount uint))
  (let (
        (states (var-get pause-states))
        (u (try! (accrue)))
        (scaled-principal (var-get principal-scaled))
        (idx (var-get index))
        (debt (total-debt))
        (total-borrowed-amount (var-get total-borrowed))
        (capped-amount (if (> amount debt) debt amount))
        (principal-reduction (calc-principal-ratio-reduction capped-amount scaled-principal debt))
        (capped-reduction (if (> principal-reduction scaled-principal) scaled-principal principal-reduction))
        (updated-scaled-principal (- scaled-principal capped-reduction))
        (principal-repaid (mul-div-down capped-amount total-borrowed-amount debt))
        (interest-paid (- capped-amount principal-repaid))
        (total-borrowed-new (if (> total-borrowed-amount principal-repaid) (- total-borrowed-amount principal-repaid) u0)))

    (try! (check-caller-auth))
    (asserts! (not (get repay states)) ERR-PAUSED)
    (asserts! (> amount u0) ERR-AMOUNT-ZERO)

    (try! (receive-underlying capped-amount tx-sender))
    (var-set principal-scaled updated-scaled-principal)
    (var-set total-borrowed total-borrowed-new)
    (var-set assets (+ (var-get assets) interest-paid))

(define-public (socialize-debt (scaled-amount uint))
  (let ((scaled-principal (var-get principal-scaled))
        (borrowed (var-get total-borrowed))
        (idx (var-get index))
        (current-assets (var-get assets))
        (current-lindex (var-get lindex))
        (old-total-assets (total-assets))
        (debt-reduction (mul-div-down scaled-amount idx INDEX-PRECISION))
        (principal-reduction (if (> scaled-principal u0)
                                (mul-div-down scaled-amount borrowed scaled-principal)
                                u0))
        ;; Write down lindex proportionally to loss in total-assets
        (new-lindex (if (and (> old-total-assets u0) (> old-total-assets debt-reduction))
                       (mul-div-down current-lindex (- old-total-assets debt-reduction) old-total-assets)
                       u0)))

    (try! (check-caller-auth))
    (asserts! (> scaled-amount u0) ERR-AMOUNT-ZERO)

    (var-set lindex new-lindex)
    (var-set principal-scaled (if (> scaled-principal scaled-amount) (- scaled-principal scaled-amount) u0))
    (var-set total-borrowed (if (> borrowed principal-reduction) (- borrowed principal-reduction) u0))
    (var-set assets (if (> current-assets principal-reduction) (- current-assets principal-reduction) u0))
