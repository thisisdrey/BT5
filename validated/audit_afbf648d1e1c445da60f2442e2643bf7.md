### No vulnerability found for this question.

**Rationale:** `ExtractHooks` at [1](#0-0)  shells out to the system `tar` binary with `-C tmpDir.Path() --strip-components N custom_hooks`, restricting extraction to entries whose name matches the `custom_hooks` member. Path-traversal protection for entries like `custom_hooks/../../../etc/cron.d/x` is enforced by GNU tar's own default extraction hardening (rejecting/neutralizing `..` path components and not following pre-existing symlinks for subsequent writes), not by custom Gitaly logic — this is a property of the external `tar` dependency's default behavior rather than a Gitaly-introduced flaw, and per the rules a dependency's own built-in default protections are out of scope unless Gitaly disables or bypasses them (it does not: no `-P`/`--absolute-names` or unsafe flags are passed, as seen in the fixed `cmdArgs` at [2](#0-1) ).

Additionally, extraction always lands in a fresh per-call temp directory obtained via `tempdir.NewWithoutContext` [3](#0-2) , which is removed via `defer os.RemoveAll(tmpDir.Path())` regardless of outcome, and only the resulting `custom_hooks` subdirectory is atomically renamed into the repository at [4](#0-3) . There is no evidence in this file of a Gitaly-side check being bypassable to write outside `tmpDir.Path()`; the only symlink-aware, manually-validated extraction path in this codebase is the separate Go-native `extractTarToDirectory` used for snapshots at [5](#0-4) , which is unrelated to `SetCustomHooks`/`RestoreCustomHooks`. No test or code path in `custom_hooks_test.go` demonstrates an actual escape, and constructing one would require a defect in the external `tar` binary itself, which is excluded by the audit rules.

// extractTarToDirectory extracts a tar archive to the specified directory using Go's tar package
func (s *server) extractTarToDirectory(ctx context.Context, reader io.Reader, targetDir string) error {
	targetDir = filepath.Clean(targetDir)
	tarReader := tar.NewReader(reader)

	for {
		select {
		case <-ctx.Done():
			return ctx.Err()
		default:
		}

		header, err := tarReader.Next()
		if err == io.EOF {
			break // End of archive
		}
		if err != nil {
			return fmt.Errorf("reading tar header: %w", err)
		}

		targetPath := filepath.Join(targetDir, header.Name)

		if !strings.HasPrefix(targetPath, targetDir+string(os.PathSeparator)) &&
			targetPath != targetDir {
			return fmt.Errorf("invalid file path in tar: %s", header.Name)
		}

		switch header.Typeflag {
		case tar.TypeDir:
			if err := os.MkdirAll(targetPath, os.FileMode(header.Mode)); err != nil {
				return fmt.Errorf("creating directory %s: %w", targetPath, err)
			}

		case tar.TypeReg:
			if err := s.extractFile(ctx, tarReader, targetPath, header); err != nil {
				return fmt.Errorf("extracting file %s: %w", targetPath, err)
			}

		case tar.TypeSymlink:
			if filepath.IsAbs(header.Linkname) {
				return fmt.Errorf("absolute symlink not allowed: %s -> %s", header.Name, header.Linkname)
			}

			// Resolve the relative symlink target from the symlink's parent directory
			// and verify it stays within the extraction boundary, consistent with the
			// hard link validation below.
			resolvedTarget := filepath.Join(filepath.Dir(targetPath), header.Linkname)
			if !strings.HasPrefix(resolvedTarget, targetDir+string(os.PathSeparator)) &&
				resolvedTarget != targetDir {
				return fmt.Errorf("symlink target escapes extraction directory: %s -> %s", header.Name, header.Linkname)
			}
