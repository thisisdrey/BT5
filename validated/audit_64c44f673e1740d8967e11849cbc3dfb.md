### Title
Firewall conntrack entries store an absolute expiration time set at creation, so reducing `firewall.conntrack.*_timeout` does not shorten already-established sessions - ([File: firewall.go])

### Summary
The Nebula firewall's connection tracking (conntrack) table stores an absolute expiration timestamp (`conn.Expires`) computed once, at the moment a connection is created or last refreshed, using whatever timeout value (`TCPTimeout`/`UDPTimeout`/`DefaultTimeout`) was active at that instant. This mirrors the reported `StakedlvlUSD` cooldown bug class: an absolute "end time" is persisted instead of a relative "start time" plus the currently configured duration. When an operator reduces the conntrack timeout at runtime (e.g. via SIGHUP config reload, to react to an incident and force faster teardown of sessions), pre-existing idle conntrack entries keep their old, longer `Expires` value and are not re-evaluated against the new, shorter timeout until that stale absolute time is reached.

### Finding Description
`Firewall.addConn` and `Firewall.inConns` set the absolute expiry as `time.Now().Add(timeout)` using the timeout in effect at that moment: [1](#0-0) [2](#0-1) 

When the firewall config is reloaded (`Interface.reloadFirewall`), a brand-new `Firewall` object is built with the new timeout values from config, but the existing `Conntrack` table (containing entries with `Expires` computed under the old timeout) is deliberately carried over to the new firewall instance so that active sessions aren't dropped on reload: [3](#0-2) 

The eviction logic in `Firewall.evict` only compares the stored absolute `Expires` against `time.Now()`; it never recomputes the remaining lifetime using the *current* `f.TCPTimeout`/`f.UDPTimeout`/`f.DefaultTimeout`: [4](#0-3) 

The `rulesVersion` re-validation path in `inConns` only re-checks whether a packet still matches the new *rule set* (allow/deny), and only refreshes `Expires` when new traffic actually arrives on that flow — it does not retroactively shrink the expiry of idle flows to the new timeout: [5](#0-4) 

As a result, any conntrack entry created before a timeout reduction retains its original, longer absolute expiration and will not be evicted early, exactly analogous to the reported issue where a stored absolute cooldown end time is not adjusted when the duration parameter is reduced.

### Impact Explanation
This is a firewall enforcement bypass: an operator who reduces `firewall.conntrack.tcp_timeout`, `udp_timeout`, or `default_timeout` at runtime — for example during an incident response to force faster expiration of open flows (analogous to emergency zeroing of `cooldownDuration` in the report) — will find that already-established, currently idle connections continue to be treated as valid/allowed by the firewall for the full duration of their original (longer) timeout. This defeats the security intent of shortening the timeout and allows already-permitted flows (potentially to/from a host whose certificate or rule eligibility has since been revoked/tightened) to persist longer than the administrator intends.

### Likelihood Explanation
This does not require a malicious peer or lighthouse; it is triggered purely by normal, legitimate operator action (a config reload lowering conntrack timeouts) combined with the existence of any established conntrack entry — a state reachable in any deployment doing runtime tuning or incident response. No attacker collusion is required for the state to be reachable, though the security consequence (extended validity of an existing flow) benefits whichever remote party owns that flow.

### Recommendation
Store the time the entry was created/last renewed (a relative reference point) rather than only an absolute `Expires` computed from the timeout in effect at that moment, and recompute the effective expiry against the *current* `f.TCPTimeout`/`UDPTimeout`/`DefaultTimeout` whenever `evict` or `inConns` handles a conntrack entry whose `rulesVersion` differs from the current firewall's `rulesVersion` (i.e., a config/firewall reload has occurred). This ensures a reduced timeout takes effect immediately for existing sessions rather than only for newly created ones.

### Proof of Concept
1. Start Nebula with `firewall.conntrack.default_timeout: 10m`.
2. Establish a flow that gets added to conntrack via `Firewall.addConn`/`inConns`; its `conn.Expires` is set to `time.Now()+10m`.
3. Trigger a SIGHUP/config reload lowering `firewall.conntrack.default_timeout` to `10s`, matching `Interface.reloadFirewall` → `NewFirewallFromConfig`, which builds a new `Firewall` with `DefaultTimeout = 10s` but reuses the old `Conntrack` table via `fw.Conntrack = conntrack`.
4. Observe that the existing flow's `conn.Expires` is untouched by the reload; `Firewall.evict` keeps re-adding it to the timer wheel with `newT = t.Expires.Sub(time.Now())`, which still reflects the old 10-minute timeout, not the newly configured 10-second one — the connection remains tracked/allowed for up to the original 10 minutes despite the operator's intent to shorten it to 10 seconds. This is directly analogous to `firewall_test.go`'s `TestFirewall_DropConntrackReload`, which demonstrates conntrack entries surviving rule reloads by design but does not test/handle the timeout-shrinking case: [6](#0-5)

func (f *Firewall) inConns(fp firewall.Packet, h *HostInfo, caPool *cert.CAPool, localCache firewall.ConntrackCache) bool {
	if localCache != nil {
		if _, ok := localCache[fp]; ok {
			return true
		}
	}
	conntrack := f.Conntrack
	conntrack.Lock()

	// Purge every time we test
	ep, has := conntrack.TimerWheel.Purge()
	if has {
		f.evict(ep)
	}

	c, ok := conntrack.Conns[fp]

	if !ok {
		conntrack.Unlock()
		return false
	}

	if c.rulesVersion != f.rulesVersion {
		// This conntrack entry was for an older rule set, validate
		// it still passes with the current rule set
		table := f.OutRules
		if c.incoming {
			table = f.InRules
		}

		// We now know which firewall table to check against
		if !table.match(fp, c.incoming, h.ConnectionState.peerCert, caPool) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				h.logger(f.l).Debug("dropping old conntrack entry, does not match new ruleset",
					"fwPacket", fp,
					"incoming", c.incoming,
					"rulesVersion", f.rulesVersion,
					"oldRulesVersion", c.rulesVersion,
				)
			}
			delete(conntrack.Conns, fp)
			conntrack.Unlock()
			return false
		}

		if f.l.Enabled(context.Background(), slog.LevelDebug) {
			h.logger(f.l).Debug("keeping old conntrack entry, does match new ruleset",
				"fwPacket", fp,
				"incoming", c.incoming,
				"rulesVersion", f.rulesVersion,
				"oldRulesVersion", c.rulesVersion,
			)
		}

		c.rulesVersion = f.rulesVersion
	}

	switch fp.Protocol {
	case firewall.ProtoTCP:
		c.Expires = time.Now().Add(f.TCPTimeout)
	case firewall.ProtoUDP:
		c.Expires = time.Now().Add(f.UDPTimeout)
	default:
		c.Expires = time.Now().Add(f.DefaultTimeout)
	}

	conntrack.Unlock()

	if localCache != nil {
		localCache[fp] = struct{}{}
	}

	return true
}

func (f *Firewall) addConn(fp firewall.Packet, incoming bool) {
	var timeout time.Duration
	c := &conn{}

	switch fp.Protocol {
	case firewall.ProtoTCP:
		timeout = f.TCPTimeout
	case firewall.ProtoUDP:
		timeout = f.UDPTimeout
	default:
		timeout = f.DefaultTimeout
	}

	conntrack := f.Conntrack
	conntrack.Lock()
	if _, ok := conntrack.Conns[fp]; !ok {
		conntrack.TimerWheel.Advance(time.Now())
		conntrack.TimerWheel.Add(fp, timeout)
	}

	// Record which rulesVersion allowed this connection, so we can retest after
	// firewall reload
	c.incoming = incoming
	c.rulesVersion = f.rulesVersion
	c.Expires = time.Now().Add(timeout)
	conntrack.Conns[fp] = c
	conntrack.Unlock()
}

// Evict checks if a conntrack entry has expired, if so it is removed, if not it is re-added to the wheel
// Caller must own the connMutex lock!
func (f *Firewall) evict(p firewall.Packet) {
	// Are we still tracking this conn?
	conntrack := f.Conntrack
	t, ok := conntrack.Conns[p]
	if !ok {
		return
	}

	newT := t.Expires.Sub(time.Now())

	// Timeout is in the future, re-add the timer
	if newT > 0 {
		conntrack.TimerWheel.Advance(time.Now())
		conntrack.TimerWheel.Add(p, newT)
		return
	}

	// This conn is done
	delete(conntrack.Conns, p)
}

func TestFirewall_DropConntrackReload(t *testing.T) {
	ob := &bytes.Buffer{}
	l := test.NewLoggerWithOutput(ob)
	myVpnNetworksTable := new(bart.Lite)
	myVpnNetworksTable.Insert(netip.MustParsePrefix("1.1.1.1/8"))

	p := firewall.Packet{
		LocalAddr:  netip.MustParseAddr("1.2.3.4"),
		RemoteAddr: netip.MustParseAddr("1.2.3.4"),
		LocalPort:  10,
		RemotePort: 90,
		Protocol:   firewall.ProtoUDP,
		Fragment:   false,
	}
	network := netip.MustParsePrefix("1.2.3.4/24")

	c := cert.CachedCertificate{
		Certificate: &dummyCert{
			name:     "host1",
			networks: []netip.Prefix{network},
			groups:   []string{"default-group"},
			issuer:   "signer-shasum",
		},
		InvertedGroups: map[string]struct{}{"default-group": {}},
	}
	h := HostInfo{
		ConnectionState: &ConnectionState{
			peerCert: &c,
		},
		vpnAddrs: []netip.Addr{network.Addr()},
	}
	h.buildNetworks(myVpnNetworksTable, c.Certificate)

	fw := NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 0, 0, []string{"any"}, "", "", "", "", ""))
	cp := cert.NewCAPool()

	// Drop outbound
	assert.Equal(t, fw.Drop(p, false, &h, cp, nil), ErrNoMatchingRule)
	// Allow inbound
	resetConntrack(fw)
	require.NoError(t, fw.Drop(p, true, &h, cp, nil))
	// Allow outbound because conntrack
	require.NoError(t, fw.Drop(p, false, &h, cp, nil))

	oldFw := fw
	fw = NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 10, 10, []string{"any"}, "", "", "", "", ""))
	fw.Conntrack = oldFw.Conntrack
	fw.rulesVersion = oldFw.rulesVersion + 1

	// Allow outbound because conntrack and new rules allow port 10
	require.NoError(t, fw.Drop(p, false, &h, cp, nil))

	oldFw = fw
	fw = NewFirewall(l, time.Second, time.Minute, time.Hour, c.Certificate)
	require.NoError(t, fw.AddRule(true, firewall.ProtoAny, 11, 11, []string{"any"}, "", "", "", "", ""))
	fw.Conntrack = oldFw.Conntrack
	fw.rulesVersion = oldFw.rulesVersion + 1

	// Drop outbound because conntrack doesn't match new ruleset
	assert.Equal(t, fw.Drop(p, false, &h, cp, nil), ErrNoMatchingRule)
}
