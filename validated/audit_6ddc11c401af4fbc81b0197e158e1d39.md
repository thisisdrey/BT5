## Finding

### Title
Unauthenticated `/v2/neighbors` endpoint discloses private/internal peer IP addresses regardless of the node operator's `private_neighbors` configuration - (File: stackslib/src/net/api/getneighbors.rs)

### Summary
Analogous to the Doorkeeper CVE-2020-10187 pattern (an unauthenticated listing endpoint that serializes model attributes the operator did not intend to expose), the Stacks `/v2/neighbors` RPC handler serializes bootstrap, sample, inbound, and outbound peer records without applying the same private-address filter that its sibling endpoint enforces, silently defeating the node operator's `private_neighbors=false` configuration.

### Finding Description
`RPCNeighborsInfo::from_p2p` in [1](#0-0)  builds the bootstrap, sample, inbound, and outbound peer lists straight from `PeerDB` and live connection state and returns them via `RPCNeighbor::from_neighbor_key_and_pubkh`, with no filtering on `addrbytes.is_in_private_range()` or `is_anynet()`. The handler `try_handle_request` then serializes this data directly to an unauthenticated HTTP response (`security: []` per the OpenAPI spec) at [2](#0-1) .

Contrast this with the StackerDB replicas listing handler, which explicitly filters out `anynet` and (when `!allow_private`) private-range addresses before returning the neighbor address list: [3](#0-2) 

The node's own private-address policy is expressed via `network.get_connection_opts().private_neighbors`, and is enforced consistently elsewhere in the codebase — e.g. in the neighbor-walk logic that filters sensible neighbors before crawling [4](#0-3) , in `can_register_peer` when accepting inbound connections [5](#0-4) , and in the peer-to-peer `GetNeighbors` handler which chooses between exposing public-only or mixed public/private neighbor sets [6](#0-5) . The RPC `/v2/neighbors` handler is the outlier: it never checks `private_neighbors` at all, so an operator who has configured their node to hide internal/private-range peers from public probing will nonetheless leak those peers' IP addresses, ports, and public-key hashes to any unauthenticated remote caller.

This is the equivalent equality break to the Doorkeeper bug class: "what the operator's configuration says should be exposed" vs. "what the serialization layer actually exposes" — the RPC layer fails to apply the same authorization/filtering gate that a sibling, functionally-identical endpoint applies correctly.

### Impact Explanation
An unauthenticated remote caller can enumerate a node's currently-connected and known bootstrap/sample peers, including those in private IP ranges, by issuing a single `GET /v2/neighbors`. This discloses internal network topology (e.g., peers running on private/internal subnets that the operator explicitly intended to keep hidden via `private_neighbors=false`), which can be used to fingerprint infrastructure or target internal-only nodes that were never meant to be publicly reachable/known.

### Likelihood Explanation
High likelihood of triggering: the endpoint requires no authentication (`security: []`), no special request body, and simply returns whatever is currently in the `PeerDB`/live connection tables. Any node that has private-range peers (e.g., inbound connections from a LAN, or a `private_neighbors=false` configuration meant to suppress this) will leak them on every call.

### Recommendation
Apply the same `private_neighbors`/`is_anynet()` filtering used in `liststackerdbreplicas.rs` and `neighbors/walk.rs::filter_sensible_neighbors` to the `bootstrap`, `sample`, `inbound`, and `outbound` lists constructed in `RPCNeighborsInfo::from_p2p`, so unauthenticated callers only see addresses the operator has configured to be publicly disclosed.

### Proof of Concept
1. Configure a stacks-node with `private_neighbors = false` and connect it to at least one peer whose bound address is in a private IP range (e.g., `10.x.x.x` or `192.168.x.x`), or allow an inbound connection from such an address.
2. As an unauthenticated remote client, issue `GET /v2/neighbors` against the node's RPC port.
3. Observe that the response's `inbound`/`outbound`/`sample`/`bootstrap` arrays include the private-range peer's `ip`, `port`, and `public_key_hash`, even though `private_neighbors=false` should have suppressed it — as confirmed by comparing against `GET /v2/stackerdb/{principal}/{contract_name}/replicas`, which correctly omits such entries per [7](#0-6) .

impl RPCNeighborsInfo {
    /// Load neighbor address information from the peer network
    pub fn from_p2p(network: &PeerNetwork) -> Result<RPCNeighborsInfo, NetError> {
        let network_epoch = network.get_current_epoch().network_epoch;
        let network_id = network.get_local_peer().network_id;
        let max_neighbor_age = network.get_connection_opts().max_neighbor_age;
        let burnchain_view = network.get_chain_view();
        let peerdb_conn = network.peerdb_conn();

        let bootstrap_nodes =
            PeerDB::get_bootstrap_peers(peerdb_conn, network_id).map_err(NetError::DBError)?;
        let bootstrap = bootstrap_nodes
            .into_iter()
            .map(|n| {
                let stackerdb_contract_ids =
                    PeerDB::static_get_peer_stacker_dbs(peerdb_conn, &n).unwrap_or_default();
                RPCNeighbor::from_neighbor_key_and_pubkh(
                    n.addr.clone(),
                    Hash160::from_node_public_key(&n.public_key),
                    true,
                    stackerdb_contract_ids,
                    None,
                )
            })
            .collect();

        let neighbor_sample = PeerDB::get_fresh_random_neighbors(
            peerdb_conn,
            network_id,
            network_epoch,
            network.peer_version,
            get_epoch_time_secs().saturating_sub(max_neighbor_age),
            MAX_NEIGHBORS_DATA_LEN,
            burnchain_view.burn_block_height,
            false,
            true,
        )
        .map_err(NetError::DBError)?;

        let sample: Vec<RPCNeighbor> = neighbor_sample
            .into_iter()
            .map(|n| {
                let stackerdb_contract_ids =
                    PeerDB::static_get_peer_stacker_dbs(peerdb_conn, &n).unwrap_or_default();
                RPCNeighbor::from_neighbor_key_and_pubkh(
                    n.addr.clone(),
                    Hash160::from_node_public_key(&n.public_key),
                    true,
                    stackerdb_contract_ids,
                    None,
                )
            })
            .collect();

        let mut inbound = vec![];
        let mut outbound = vec![];
        for event_id in network.iter_peer_event_ids() {
            let convo = if let Some(convo) = network.get_p2p_convo(*event_id) {
                convo
            } else {
                continue;
            };

            let nk = convo.to_neighbor_key();
            let naddr = convo.to_neighbor_address();
            if convo.is_outbound() {
                outbound.push(RPCNeighbor::from_neighbor_key_and_pubkh(
                    nk,
                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            } else {
                inbound.push(RPCNeighbor::from_neighbor_key_and_pubkh(
                    nk,
                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            }
        }

        Ok(RPCNeighborsInfo {
            bootstrap,
            sample,
            inbound,
            outbound,
        })
    }
