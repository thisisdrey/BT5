### Title
Unauthenticated `/shutdown` POST allows any TCP-reachable party to halt the signer's event receiver - (File: libsigner/src/events.rs)

### Summary
The `/shutdown` branch of `SignerEventReceiver::next_event` sets `stop_signal` to `true` and returns `EventError::Terminated` without checking any signature, secret, or peer address. Since `main_loop` exits on `EventError::Terminated`, a single unauthenticated POST to `/shutdown` from any party who can open a TCP connection to the signer's event-receiver bind address permanently stops the signer from receiving further node events.

### Finding Description
The claimed authentication equality — "the sender of a POST to `/shutdown` == an authorized local operator process" — does not hold in code. In `next_event`, requests are dispatched purely on URL path and HTTP method: [1](#0-0) 

```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
```

There is no check of a shared secret, HMAC/signature, source IP allow-list, or any credential tied to the request — any `POST /shutdown` (even with an arbitrary/empty body, as seen in the legitimate self-signal implementation) flips the shared `AtomicBool` in `stop_signal`, which is read by `is_stopped()`: [2](#0-1) 

`main_loop` treats `EventError::Terminated` as an unconditional exit condition: [3](#0-2) 

Once `main_loop` exits, the receiver thread (spawned in `Signer::spawn`) ends, and the signer's `out_channels` no longer receive burn-block, block-proposal, `stackerdb_chunks`, or `new_block` events, so the signer's `run_one_pass` runloop starves of node input, effectively stopping the signer's participation. This matches exactly how the legitimate `SignerStopSignaler::send()` shuts the receiver down: it just opens a `TcpStream` and sends a raw `POST /shutdown` request, with no credential in the payload: [4](#0-3) 

None of the other branches' guards (JSON body validation via `process_event`, `/status` handling) apply to `/shutdown`; it is checked before any auth-equivalent mechanism and there is none for this whole HTTP server (`tiny_http`-based `HttpServer`), so the endpoint is reachable by anyone who can complete a TCP connection to the bound port.

### Impact Explanation
Any unprivileged remote party that can reach the signer's event-receiver TCP port (the address the stacks-node is configured to POST events to) can send one `POST /shutdown` request and permanently stop that signer's event-receiving thread, halting its ability to process burn blocks, block proposals, and StackerDB chunk events — i.e., unauthenticated DoS from a single message, matching the "Critical" impact category. This is repeatable against every signer instance whose event-receiver endpoint is reachable, and disabling a threshold of signers can affect block-signing liveness for the network.

### Likelihood Explanation
The attacker only needs network reachability to the event-receiver's bound socket and no key, secret, peer role, or StackerDB slot. The cost is a single raw HTTP POST with no crafted payload requirements (any body is accepted since the handler doesn't parse it). Repeated attempts are always the same trivial operation, so the exploit is fully reliable whenever the port is exposed beyond a strictly localhost-only binding.

### Recommendation
Require an authentication mechanism for `/shutdown` (and other admin-plane calls) — e.g., verify a pre-shared secret/HMAC token known only to the node/operator, restrict to loopback/allow-listed source addresses at the listener level, or require the request to originate from the same process via a Unix domain socket instead of a plain TCP listener reachable from the network.

### Proof of Concept
```rust
// libsigner/src/tests.rs (illustrative)
use std::io::Write;
use std::net::TcpStream;
use std::thread;

#[test]
fn unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<StacksBlockEvent> = SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    let handle = thread::spawn(move || {
        receiver.main_loop();
        receiver // return receiver after loop exits to check is_stopped()
    });

    // Attacker thread: no secret, no signature, just a raw POST to /shutdown
    let body = "irrelevant";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {addr}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(),
        body
    );
    let mut stream = TcpStream::connect(addr).unwrap();
    stream.write_all(req.as_bytes()).unwrap();

    let receiver = handle.join().unwrap();
    assert!(receiver.is_stopped()); // main_loop exited from unauthenticated POST
}
```
