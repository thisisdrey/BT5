### Title
Unbounded body read in `process_event` causes unauthenticated memory-exhaustion DoS on signer event port - (File: `libsigner/src/events.rs`)

### Summary
`process_event::<T, E>`, reached from `next_event()` for the `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` routes, reads the entire HTTP request body into a `String` via `request.as_reader().read_to_string(&mut body)` with no size cap before any JSON parsing occurs. Unlike `libsigner/src/http.rs`'s `decode_http_body`, which enforces a `MAX_MESSAGE_LEN`-style bound, this path has no equivalent check, so an attacker who can reach the signer's event listener port can force it to allocate memory proportional to an attacker-declared `Content-Length`.

### Finding Description
The vulnerable code is:
```rust
// libsigner/src/events.rs:519-537
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where ...
{
    let mut body = String::new();
    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        ...
    }
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())...
```
`tiny_http`'s `Request::as_reader()` yields a reader bounded by the declared `Content-Length`, and `read_to_string` will attempt to read and buffer the full declared length into `body` before any length validation, JSON parsing, or authentication occurs. There is no `MAX_MESSAGE_LEN`/`MAX_PAYLOAD_LEN`-style comparison anywhere in this function or in `next_event()`'s dispatch (`libsigner/src/events.rs:413-459`) before this read. This is in contrast to the pattern used elsewhere in the same crate — `libsigner/src/http.rs`'s `decode_http_body`, and the equivalent `stackslib/src/net/httpcore.rs`/`stackslib/src/net/server.rs` paths — which do enforce `MAX_MESSAGE_LEN` caps prior to buffering.

The attacker's exact message: an HTTP POST to `/stackerdb_chunks` (or any of the other routes dispatched through `process_event`) with a very large declared `Content-Length` and a body that is slow-fed or genuinely large. `read_to_string` will grow `body`'s buffer to match, causing large/unbounded allocation and potentially long-blocking I/O in the receiver's single-threaded `main_loop`, before any validation such as JSON schema checks, StackerDB chunk signature recovery (`chunk.recover_pk()`), or contract-name checks in the `TryFrom<StackerDBChunksEvent>` impl (lines 544-625) ever run.

### Impact Explanation
A single crafted POST can force the signer's event-receiver thread to allocate memory sized to the attacker's chosen `Content-Length`, with no upper bound. Repeated requests can exhaust the signer process's memory or otherwise degrade/crash it, denying the signer's ability to process real stacker/miner events — a legitimate Critical, single-message, unauthenticated DoS on the signer process, matching the reachable routes through `next_event()`.

### Likelihood Explanation
No signature, secret, or authentication is required to reach this code: any TCP client that can connect to the signer's event listener port and issue an HTTP POST to one of the dispatched paths triggers `process_event`. The only precondition is network reachability to the bound event port (which is exactly the precondition given in the question) — no privileged role, no valid StackerDB slot ownership, and no config secret are needed. The attack is trivially repeatable per connection.

### Recommendation
Enforce a maximum request-body size (mirroring `MAX_MESSAGE_LEN`/`MAX_PAYLOAD_LEN` used in `libsigner/src/http.rs` and `stackslib/src/net/httpcore.rs`) in `process_event` before reading the body — e.g., check the `Content-Length` header against the cap and reject/close the connection if it exceeds it, and/or use a bounded reader (`Read::take(MAX_LEN)`) instead of unbounded `read_to_string`.

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

impl<T: SignerEventTrait> TryFrom<StackerDBChunksEvent> for SignerEvent<T> {
    type Error = EventError;

    fn try_from(event: StackerDBChunksEvent) -> Result<Self, Self::Error> {
        let received_time = SystemTime::now();
        let signer_event = if event.contract_id.name.as_str() == MINERS_NAME
            && event.contract_id.is_boot()
        {
            let mut messages = vec![];
            for chunk in event.modified_slots {
                match T::consensus_deserialize(&mut chunk.data.as_slice()) {
                    Ok(msg) => messages.push(msg),
                    Err(e) => {
                        debug!(
                            "Signer failed to deserialize miner chunk";
                            "slot_id" => chunk.slot_id,
                            "slot_version" => chunk.slot_version,
                            "data_len" => chunk.data.len(),
                            "error" => %e,
                        );
                    }
                }
            }
            SignerEvent::MinerMessages(messages)
        } else if event.contract_id.name.starts_with(SIGNERS_NAME) && event.contract_id.is_boot() {
            let Some((signer_set, message_id)) =
                get_signers_db_signer_set_message_id(event.contract_id.name.as_str())
            else {
                return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
            };
            // signer-XXX-YYY boot contract
            //
            // NOTE: the payload-type check below uses v0 `SignerMessageTypePrefix` semantics
            // (the mapping in `signer_message_payload_matches_lane` is fixed to v0). Future
            // signer-message versions must extend that mapping, or their chunks will not be
            // recognized here regardless of which `T` is in scope.
            let messages: Vec<_> = event
                .modified_slots
                .iter()
                .filter_map(|chunk| {
                    // Accept only payloads whose type is valid for this contract's message id.
                    let &type_byte = chunk.data.first()?;
                    let payload_kind = SignerMessageTypePrefix::from_u8(type_byte)?;
                    if !signer_message_payload_matches_lane(payload_kind, message_id) {
                        warn!(
                            "Skipping signer chunk with unexpected payload type for contract";
                            "contract" => %event.contract_id,
                            "lane_message_id" => message_id,
                            "payload_type_prefix" => type_byte,
                        );
                        return None;
                    }
                    let Ok(pk) = chunk.recover_pk() else {
                        warn!(
                            "Skipping signer chunk: signature recovery failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    let Ok(message) = read_next::<T, _>(&mut &chunk.data[..]) else {
                        warn!(
                            "Skipping signer chunk: payload deserialization failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    Some((chunk.slot_id, pk, message))
                })
                .collect();
            SignerEvent::SignerMessages {
                signer_set,
                messages,
                received_time,
            }
        } else {
            return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
        };
        Ok(signer_event)
    }
}
