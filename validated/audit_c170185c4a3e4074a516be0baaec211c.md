### Title
Low-stake identities keyed by pubkey (not IP) in the unstaked connection table let a single IP amplify its per-peer connection quota via identity partitioning - (File: streamer/src/nonblocking/swqos.rs)

### Summary
`SwQos::build_connection_context` always sets `remote_pubkey: Some(pubkey)` for any connection whose certificate pubkey has a nonzero stake entry, even when `stake_ratio < min_stake_ratio` causes it to be reclassified as `ConnectionPeerType::Unstaked`. When `cache_new_connection` inserts this connection into `unstaked_connection_table`, it builds the table key via `ConnectionTableKey::new(remote_addr.ip(), conn_context.remote_pubkey)`, which resolves to `ConnectionTableKey::Pubkey(pubkey)` instead of `ConnectionTableKey::IP(ip)` whenever a pubkey is present. This means the per-peer unstaked cap (`max_connections_per_unstaked_peer`) is enforced per distinct low-stake pubkey rather than per source IP for this class of connections.

### Finding Description
The relevant logic lives in `build_connection_context` in [1](#0-0) , which computes `stake_ratio = stake / total_stake` and reclassifies the peer as `ConnectionPeerType::Unstaked` when `stake_ratio < min_stake_ratio`, but unconditionally keeps `remote_pubkey: Some(pubkey)` in the resulting `SwQosConnectionContext`.

That context is then passed into `cache_new_connection`, which computes the connection-table key as: [2](#0-1) 

using `ConnectionTableKey::new(remote_addr.ip(), conn_context.remote_pubkey)`: [3](#0-2) 

Since `conn_context.remote_pubkey` is `Some(pubkey)` for these downgraded-to-unstaked connections, the key resolves to `ConnectionTableKey::Pubkey(pubkey)`, not `ConnectionTableKey::IP(ip)`. Only connections with no known stake entry at all (`get_connection_stake` returns `None`, i.e., `remote_pubkey: None` in the `map_or` fallback branch) get keyed by IP: [4](#0-3) 

The per-peer cap check in `ConnectionTable::try_add_connection` operates on the entry for whichever key was chosen: [5](#0-4) 

An attacker holding `N` distinct pubkeys, each with a stake delegation whose `stake_ratio` is nonzero but below `min_stake_ratio` (this ratio is `1 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS)`, i.e., an extremely small fraction of total network stake — trivially achievable with minimal delegated lamports on a large-stake network), can open connections from a single source IP address. Because each such connection is keyed by its own pubkey rather than by the shared IP key, the attacker can accumulate up to `N * max_connections_per_unstaked_peer` connections from one IP into the same `unstaked_connection_table`, whereas a genuinely anonymous unstaked client (no matching stake entry, keyed by IP) is capped at exactly `max_connections_per_unstaked_peer` from that IP. This breaks the intended per-source invariant that the per-peer unstaked cap is meant to bound a single network-observable entity, since identity partitioning (creating many distinct minimally staked pubkeys) is unprivileged and multiplies the attacker's slice of the shared unstaked connection/stream budget at the expense of other unstaked peers, and disproportionately consumes the shared `max_unstaked_connections` global ceiling and stream/EMA throttling capacity that the unstaked pool provides.

Neither `prune_unstaked_connection_table` (LRU-based, `prune_oldest`, unaware of identity) nor the overall/per-IP QUIC handshake rate limiters in `streamer/src/nonblocking/quic.rs` (`rate_limiter`, `overall_connection_rate_limiter`) mitigate this, since those limiters bound handshake attempt rate, not sustained per-peer connection-table occupancy, and pruning is oldest-first regardless of key type.

### Impact Explanation
This is a QoS-evasion / fairness-invariant violation in the unstaked connection admission path: a single source IP, by partitioning into many trivially-staked identities, can occupy a multiple of the intended per-peer unstaked connection quota, degrading service for other unstaked clients sharing the same bounded `unstaked_connection_table` and consuming a disproportionate share of stream throughput budget governed by `StakedStreamLoadEMA`. It does not cause unbounded memory growth (bounded by `max_unstaked_connections` + pruning) or a panic/deadlock, but it is a genuine "QoS evasion" per the bounty categories, since the per-IP unstaked cap is bypassable via unprivileged identity partitioning.

### Likelihood Explanation
Preconditions are low-cost and fully unprivileged: the attacker only needs to control multiple keypairs each with a nonzero stake delegation below `min_stake_ratio` (a tiny fraction of total stake — permissionless staking, not requiring validator/leader/gossip control), and open QUIC connections from one IP presenting each pubkey's self-signed certificate (`get_remote_pubkey`/`get_pubkey_from_tls_certificate`, [6](#0-5) ). This is repeatable and does not require any leaked keys, mocked paths, or validator-side cooperation.

### Recommendation
When a connection is reclassified from `Staked` to `Unstaked` due to `stake_ratio < min_stake_ratio`, do not propagate `remote_pubkey: Some(pubkey)` into the `SwQosConnectionContext` used for unstaked-table keying — clear it (set `remote_pubkey: None`) so `ConnectionTableKey::new` falls back to `ConnectionTableKey::IP(ip)`, ensuring the unstaked per-peer cap is uniformly enforced per source IP regardless of how many low-stake identities an attacker controls.

### Proof of Concept
```rust
// streamer/src/nonblocking/swqos.rs (test module)
#[tokio::test]
async fn test_low_stake_ratio_peers_keyed_by_pubkey_not_ip() {
    use std::collections::HashMap;

    let cancel = CancellationToken::new();
    let stats = Arc::new(StreamerStats::default());

    // total_stake huge; each attacker identity has stake just under
    // min_stake_ratio * total_stake so stake_ratio < min_stake_ratio.
    let total_stake: u64 = 1_000_000_000_000;
    let low_stake: u64 = 1; // ratio ~ 1e-12, well below min_stake_ratio

    let mut stakes = HashMap::new();
    let num_identities = 5;
    let keypairs: Vec<_> = (0..num_identities).map(|_| Keypair::new()).collect();
    for kp in &keypairs {
        stakes.insert(kp.pubkey(), low_stake);
    }
    // pad total stake with one big staker so total_stake is as intended
    let big_staker = Keypair::new();
    stakes.insert(big_staker.pubkey(), total_stake - (low_stake * num_identities as u64));

    let staked_nodes = Arc::new(RwLock::new(StakedNodes::new(Arc::new(stakes), HashMap::new())));

    let config = SwQosConfig {
        max_connections_per_unstaked_peer: 2,
        max_unstaked_connections: 1000, // large enough to not be the limiting factor
        ..SwQosConfig::default_for_tests()
    };
    let qos = SwQos::new(config, stats.clone(), staked_nodes, cancel.clone());

    // Simulate `num_identities` distinct low-stake pubkeys, all connecting
    // from the SAME source IP, each opening up to max_connections_per_unstaked_peer
    // connections via build_connection_context + try_add_connection.
    let mut total_admitted = 0;
    for kp in &keypairs {
        for _ in 0..2 {
            let (server_connection, ..) =
                create_connection_with_keypairs_from_fixed_ip(&big_staker, kp).await;
            let mut ctx = qos.build_connection_context(&server_connection);
            assert!(matches!(ctx.peer_type(), ConnectionPeerType::Unstaked));
            // BUG: remote_pubkey is Some(kp.pubkey()), not None.
            assert_eq!(ctx.remote_pubkey(), Some(kp.pubkey()));

            let client_tracker = ClientConnectionTracker { stats: stats.clone() };
            if qos.try_add_connection(client_tracker, &server_connection, &mut ctx).await.is_some() {
                total_admitted += 1;
            }
        }
    }

    // Expected (if per-IP invariant held): total_admitted <= max_connections_per_unstaked_peer (2)
    // Actual (bug): total_admitted == num_identities * max_connections_per_unstaked_peer (10)
    assert!(
        total_admitted > config_max_connections_per_unstaked_peer(&qos),
        "single IP exceeded intended per-peer unstaked cap via pubkey-keyed partitioning: {total_admitted}"
    );
}
```
Note: `create_connection_with_keypairs_from_fixed_ip` is a test helper (not shown in the indexed snippets) that would need to bind all client endpoints to the same source IP/loopback address while varying the client keypair/cert — this mirrors existing helpers like `create_connection_with_keypairs` already used in `simple_qos.rs` tests. The key assertion is that `conn_context.remote_pubkey()` is `Some(pubkey)` (not `None`) for stake-ratio-downgraded peers, which is what causes `ConnectionTableKey::new` to key by `Pubkey` instead of `IP`, and that repeating this with multiple distinct low-stake keypairs from one IP admits more than `max_connections_per_unstaked_peer` total connections into `unstaked_connection_table`.

impl QosController<SwQosConnectionContext> for SwQos {
    fn build_connection_context(&self, connection: &Connection) -> SwQosConnectionContext {
        let remote_address = connection.remote_address();
        get_connection_stake(connection, &self.staked_nodes).map_or(
            SwQosConnectionContext {
                peer_type: ConnectionPeerType::Unstaked,
                total_stake: 0,
                remote_pubkey: None,
                in_staked_table: false,
                remote_address,
                stream_counter: None,
                last_update: Arc::new(AtomicU64::new(timing::timestamp())),
            },
            |(pubkey, stake, total_stake)| {
                // The heuristic is that the stake should be large enough to have 1 stream pass through within one throttle
                // interval during which we allow max (MAX_STREAMS_PER_MS * STREAM_THROTTLING_INTERVAL_MS) streams.

                let peer_type = {
                    let max_streams_per_ms = self.staked_stream_load_ema.max_streams_per_ms();
                    let min_stake_ratio =
                        1_f64 / (max_streams_per_ms * STREAM_THROTTLING_INTERVAL_MS) as f64;
                    let stake_ratio = stake as f64 / total_stake as f64;
                    if stake_ratio < min_stake_ratio {
                        // If it is a staked connection with ultra low stake ratio, treat it as unstaked.
                        ConnectionPeerType::Unstaked
                    } else {
                        ConnectionPeerType::Staked(stake)
                    }
                };

                SwQosConnectionContext {
                    peer_type,
                    total_stake,
                    remote_pubkey: Some(pubkey),
                    in_staked_table: false,
                    remote_address,
                    last_update: Arc::new(AtomicU64::new(timing::timestamp())),
                    stream_counter: None,
                }
            },
        )

pub fn get_pubkey_from_tls_certificate(
    der_cert: &rustls::pki_types::CertificateDer,
) -> Option<Pubkey> {
    let (_, cert) = X509Certificate::from_der(der_cert.as_ref()).ok()?;
    match cert.public_key().parsed().ok()? {
        PublicKey::Unknown(key) => Pubkey::try_from(key).ok(),
        _ => None,
    }
}

/// Recover the peer's Solana pubkey from a `quinn::Connection`. Accepts
/// only a self-signed cert chain of length 1 (matches the cert shape
/// produced by [`new_dummy_x509_certificate`]).
///
/// Single source of truth for anything doing QUIC and using
/// Solana validator identities for auth.
pub fn get_remote_pubkey(connection: &quinn::Connection) -> Option<Pubkey> {
    connection
        .peer_identity()?
        .downcast::<Vec<rustls::pki_types::CertificateDer>>()
        .ok()
        .filter(|certs| certs.len() == 1)?
        .first()
        .and_then(get_pubkey_from_tls_certificate)
}
