### Title
Wrong Gas Constant in `bls12381_pk_subgroub_check` Enables Validator CPU Exhaustion via Undercharged Subgroup Check — (`aptos-move/framework/natives/src/cryptography/bls12381.rs`)

### Summary
`bls12381_pk_subgroub_check` charges `BLS12381_PER_PUBKEY_DESERIALIZE` for a subgroup membership check that costs ~3.4× more CPU time than deserialization. Any unprivileged caller of `verify_normal_signature_internal` with a valid-but-non-subgroup public key triggers this path and receives ~2.2× more validator CPU work than the gas paid for.

### Finding Description
In `bls12381_pk_subgroub_check`, the gas charge is:

```rust
context.charge(BLS12381_PER_PUBKEY_DESERIALIZE * NumArgs::one())?;
``` [1](#0-0) 

The correct constant is `BLS12381_PER_PUBKEY_SUBGROUP_CHECK`. The code's own comment on line 166 acknowledges the subgroup check takes "around 39 microseconds on Apple M1," while deserialization is calibrated at ~12 microseconds — exactly the ratio reflected in the gas schedule:

- `bls12381_per_pubkey_deserialize` = **4,006,840** internal gas
- `bls12381_per_pubkey_subgroup_check` = **13,601,200** internal gas [2](#0-1) 

`native_bls12381_verify_normal_signature` always sets `check_pk_subgroup = true` and delegates to `bls12381_verify_signature_helper`, which calls `bls12381_pk_subgroub_check` when the PK deserializes successfully: [3](#0-2) [4](#0-3) 

For a valid-but-non-subgroup PK (a point on the BLS12-381 G2 curve but outside the prime-order subgroup — constructible using the curve's cofactor), the full call charges:

| Step | Gas charged | Actual CPU |
|---|---|---|
| Base | 5,510 | negligible |
| PK deserialize | 4,006,840 | ~12 µs |
| Subgroup check (wrong constant) | 4,006,840 | ~39 µs |
| **Total** | **8,019,190** | **~51 µs** |

Correct total should be **17,613,550** internal gas. The attacker pays for ~24 µs of work and receives ~51 µs — a **2.2× overall undercharge**, with the subgroup check itself undercharged by **3.4×**.

The same bug exists in `native_bls12381_validate_pubkey`, which also calls `bls12381_pk_subgroub_check`: [5](#0-4) 

### Impact Explanation
An unprivileged attacker submits a stream of transactions calling `verify_normal_signature_internal` (exposed as `verify_normal_signature_internal` in `aptos_std::bls12381`) with a crafted valid-but-non-subgroup PK. Each transaction forces validators to execute a ~39 µs subgroup check while collecting gas calibrated for a ~12 µs deserialization. At scale, this allows the attacker to consume ~3.4× more validator CPU per gas unit on the subgroup-check path than the gas model intends, constituting a material validator slowdown reachable from an unprivileged transaction entrypoint.

### Likelihood Explanation
Constructing a BLS12-381 G2 point outside the prime-order subgroup is straightforward (multiply any curve point by the cofactor). The native function is publicly callable from any Move module. No privileged access, governance power, or validator control is required.

### Recommendation
Change line 167 in `bls12381_pk_subgroub_check` from:
```rust
context.charge(BLS12381_PER_PUBKEY_DESERIALIZE * NumArgs::one())?;
```
to:
```rust
context.charge(BLS12381_PER_PUBKEY_SUBGROUP_CHECK * NumArgs::one())?;
```

The analogous `bls12381_sig_subgroub_check` function correctly uses `BLS12381_PER_SIG_SUBGROUP_CHECK` and should be used as the reference pattern. [6](#0-5) 

### Proof of Concept
1. Compute a BLS12-381 G2 point `P` not in the prime-order subgroup: take any generator `G` and multiply by the cofactor `h` to get a torsion point, then use `G + h*G` — this is on the curve but not in the subgroup.
2. Serialize `P` as a 96-byte compressed G2 point (it will pass `bls12381::PublicKey::try_from` since it is a valid curve point).
3. Submit a transaction calling `aptos_std::bls12381::verify_normal_signature` with this PK, any 96-byte signature bytes, and any message.
4. Observe: the transaction charges `BLS12381_BASE + 2 * BLS12381_PER_PUBKEY_DESERIALIZE` (8,019,190 internal gas) but the validator executes a full ~39 µs subgroup check. The correct charge would be `BLS12381_BASE + BLS12381_PER_PUBKEY_DESERIALIZE + BLS12381_PER_PUBKEY_SUBGROUP_CHECK` (17,613,550 internal gas).
5. Repeat at high frequency to exhaust validator CPU at 2.2× the intended gas-to-CPU ratio.

fn native_bls12381_validate_pubkey(
    context: &mut SafeNativeContext,
    ty_args: &[Type],
    mut arguments: VecDeque<Value>,
) -> SafeNativeResult<SmallVec<[Value; 1]>> {
    debug_assert!(ty_args.is_empty());
    debug_assert!(arguments.len() == 1);

    context.charge(BLS12381_BASE)?;

    let pk_bytes = safely_pop_arg!(arguments, Vec<u8>);

    let pk = match bls12381_deserialize_pk(pk_bytes, context)? {
        Some(key) => key,
        None => return Ok(smallvec![Value::bool(false)]),
    };

    let valid = bls12381_pk_subgroub_check(&pk, context)?;

    Ok(smallvec![Value::bool(valid)])
}
