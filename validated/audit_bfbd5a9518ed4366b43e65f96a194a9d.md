The external report describes a TON FunC-specific bug (`contracts/walletV4_plugin.fc`) where manual cell-based storage writing/parsing in `set_data()`/`recv_external()` drops fields, causing misaligned reads in get-methods. This file and this storage model do not exist anywhere in this repository — `contracts/walletV4_plugin.fc` has no matches, and the actual contracts (`contracts/wallet/**`, `contracts/defuse/**`, `contracts/global-deployer/src/**`, `contracts/outlayer/app/src/**`, `contracts/treasury-logger/src/**`) are NEAR/Rust contracts using Borsh derive-based serialization rather than manual bit/cell packing.

In this codebase, storage structs like `State<PubKey>` [1](#0-0)  and `ContractStorage` [2](#0-1)  use `#[derive(BorshSerialize, BorshDeserialize)]`, which serializes and deserializes all struct fields automatically and symmetrically — there is no manual bit-offset writing/parsing logic that could selectively omit a flag or conditional field the way FunC's raw `store_uint`/`begin_cell`/`set_data` calls can. Versioned migrations are handled explicitly through typed `From` conversions [3](#0-2) , not through hand-rolled offset math, so the specific bug class (storage writer omitting fields present in the reader's expected layout) has no reachable analog here.

No custody-binding equality (authorisation, replay, conservation, settlement, identity, or fee) is broken by this bug class in the in-scope Rust/NEAR contracts.

impl BorshDeserializeAs<ContractStorage> for MaybeVersionedContractStorage {
    fn deserialize_as<R>(reader: &mut R) -> io::Result<ContractStorage>
    where
        R: io::Read,
    {
        // There will always be 4 bytes for u32:
        // * either `VERSIONED_MAGIC_PREFIX`,
        // * or u32 for `Contract.accounts.keys.len`
        let mut buf = [0u8; size_of::<u32>()];
        reader.read_exact(&mut buf)?;
        let prefix = u32::deserialize_reader(&mut buf.as_slice())?;

        if prefix == Self::VERSIONED_MAGIC_PREFIX {
            VersionedContractStorage::deserialize_reader(reader)
        } else {
            // legacy state
            ContractStorageV0::deserialize_reader(
                // prepend already consumed part of the reader
                &mut buf.chain(reader),
            )
            .map(Into::into)
        }
        .map(Into::into)
    }
