### Title
`LinkRepositoryToObjectPool` links a repository to an arbitrary object pool without verifying pool ownership - ([File: internal/gitaly/service/objectpool/link.go])

### Summary
The bug class in the external report is a missing ownership/authorization binding: `MarginTradingHook#updateOrder` checks that the order exists and that the caller has *a* position, but never checks that the caller's position is the one that actually owns the order being mutated. The Gitaly analog is `LinkRepositoryToObjectPool`, which checks that the pool repository and the target repository are each individually *valid* repositories, but never checks that the target repository is actually authorized to use (e.g. was forked from, or otherwise associated with) that specific pool before wiring it in as an alternate object source.

### Finding Description
`LinkRepositoryToObjectPool` validates the target repository and resolves the pool via `poolForRequest`/`objectpool.FromProto`, which only checks that the pool path is a well-formed, existing pool repository — not that it belongs to (or was created for) the caller's repository: [1](#0-0) 

`poolForRequest` / `objectpool.FromProto` verify the pool is *a* valid pool repository, with no binding to the specific requesting repository: [2](#0-1) [3](#0-2) 

`objectpool.Link` then unconditionally writes the pool's object path into the target repository's `objects/info/alternates` file, which makes every object in the pool readable through the linked repository via Git's alternates mechanism: [4](#0-3) 

This mirrors the reported pattern exactly: an entity identifier supplied in the request (`_orderId` / `ObjectPool.Repository`) is validated for existence/well-formedness, but the code never checks that the caller-supplied "owner" identifier (`initPosId` / the calling repository) actually corresponds to that entity before performing a state-mutating action on it.

### Impact Explanation
If any caller able to invoke `LinkRepositoryToObjectPool` (whether an internal Rails/Praefect caller or any actor able to reach this RPC with a crafted `ObjectPool.Repository` field) can specify a pool repository that does not actually belong to their target repository's fork network, they can link an arbitrary repository (as long as it satisfies `storage.IsPoolRepository`) to their own repository's alternates. Because Git alternates grant transparent read access to all objects in the pool, this allows disclosure of objects (blobs, commits, trees) from a pool the caller does not otherwise have access to — a cross-repository object access / information disclosure, the same "any resource can be modified/associated by any caller" class as the original finding.

### Likelihood Explanation
Exploitability depends on whether an authorization layer above Gitaly (Rails internal API / Praefect) additionally restricts which pool a given repository may be linked to. Within Gitaly's own service code there is no such check — `poolForRequest` only validates pool well-formedness, not ownership — so the guarantee that "you can only link your own fork's pool" rests entirely outside this component. Any caller that can reach this internal RPC directly (e.g., a compromised or buggy internal client, or a future caller that forwards user-influenced fields) bypasses the intended fork-relationship invariant with no Gitaly-side check, exactly as `updateOrder` relied on an absent invariant check.

### Recommendation
Add an explicit ownership/association check in `LinkRepositoryToObjectPool` (and any other pool-mutating RPC such as `FetchIntoObjectPool`) analogous to the recommended fix in the report: verify that the target repository's recorded/expected object pool (e.g. via its already-configured alternates, or a stored pool-repository association) matches the `ObjectPool.Repository` supplied in the request before calling `pool.Link`, rather than only validating that the pool is *some* valid pool repository.

### Proof of Concept
1. Create repository `A` with no existing pool link.
2. Create an unrelated `ObjectPool` `P` (a valid pool repository not derived from `A`).
3. Call `LinkRepositoryToObjectPool{Repository: A, ObjectPool: {Repository: P}}`.
4. `poolForRequest` succeeds because `P` is a structurally valid pool repository (`FromProto` in [3](#0-2) ), with no check that `P` is `A`'s intended pool.
5. `objectpool.Link` writes `P`'s object directory into `A`'s `objects/info/alternates` ( [5](#0-4) ), granting anyone with access to `A` transparent read access to all objects contained in `P`.

func (s *server) LinkRepositoryToObjectPool(ctx context.Context, req *gitalypb.LinkRepositoryToObjectPoolRequest) (*gitalypb.LinkRepositoryToObjectPoolResponse, error) {
	repository := req.GetRepository()
	if err := s.locator.ValidateRepository(ctx, repository); err != nil {
		return nil, structerr.NewInvalidArgument("%w", err)
	}

	pool, err := s.poolForRequest(ctx, req)
	if err != nil {
		return nil, err
	}

	repo := s.localRepoFactory.Build(repository)

	if err := pool.Link(ctx, repo); err != nil {
		return nil, structerr.NewInternal("%w", err)
	}

	return &gitalypb.LinkRepositoryToObjectPoolResponse{}, nil

func (s *server) poolForRequest(ctx context.Context, req PoolRequest) (*objectpool.ObjectPool, error) {
	pool, err := objectpool.FromProto(ctx, s.logger, s.locator, s.gitCmdFactory, s.catfileCache, s.txManager, s.housekeepingManager, req.GetObjectPool())
	if err != nil {
		if errors.Is(err, objectpool.ErrInvalidPoolDir) {
			return nil, errInvalidPoolDir
		}

		if errors.Is(err, objectpool.ErrInvalidPoolRepository) {
			return nil, structerr.NewFailedPrecondition("%w", err)
		}

		return nil, structerr.NewInternal("%w", err)
	}

	return pool, nil

// FromProto returns an object pool object from its Protobuf representation. This function verifies
// that the object pool exists and is a valid pool repository.
func FromProto(
	ctx context.Context,
	logger log.Logger,
	locator storage.Locator,
	gitCmdFactory gitcmd.CommandFactory,
	catfileCache catfile.Cache,
	txManager transaction.Manager,
	housekeepingManager housekeepingmgr.Manager,
	proto *gitalypb.ObjectPool,
) (*ObjectPool, error) {
	poolPath, err := locator.GetRepoPath(ctx, proto.GetRepository(), storage.WithRepositoryVerificationSkipped())
	if err != nil {
		return nil, err
	}

	if !storage.IsPoolRepository(proto.GetRepository()) {
		// When creating repositories in the ObjectPool service we will first create the
		// repository in a temporary directory. So we need to check whether the path we see
		// here is in such a temporary directory and let it pass.
		tempDir, err := locator.TempDir(proto.GetRepository().GetStorageName())
		if err != nil {
			return nil, fmt.Errorf("getting temporary storage directory: %w", err)
		}

		if !strings.HasPrefix(poolPath, tempDir) {
			return nil, ErrInvalidPoolDir
		}
	}

	pool := &ObjectPool{
		Repo:                localrepo.New(logger, locator, gitCmdFactory, catfileCache, proto.GetRepository()),
		logger:              logger,
		locator:             locator,
		gitCmdFactory:       gitCmdFactory,
		txManager:           txManager,
		housekeepingManager: housekeepingManager,
	}

	if !pool.IsValid(ctx) {
		return nil, ErrInvalidPoolRepository
	}

	return pool, nil
}

// Link calls the non-receiver method version of Link with the parameters
// injected from the object pool.
func (o *ObjectPool) Link(ctx context.Context, repo *localrepo.Repo) error {
	return Link(ctx, o.Repo, repo, o.txManager)
}

// Link will link the given repository to the object pool. This is done by writing the object pool's
// path relative to the repository into the repository's "alternates" file. This does not trigger
// deduplication, which is the responsibility of the caller.
func Link(ctx context.Context, pool, repo *localrepo.Repo, txManager transaction.Manager) (returnedErr error) {
	altPath, err := repo.InfoAlternatesPath(ctx)
	if err != nil {
		return err
	}

	expectedRelPath, err := getRelativeObjectPath(ctx, pool, repo)
	if err != nil {
		return err
	}

	linked, err := linkedToRepository(ctx, pool, repo)
	if err != nil {
		return err
	}

	if linked {
		// When the repository is already linked to the repository, cast a vote to ensure the
		// repository is consistent with the other replicas.
		if err := transaction.VoteOnContext(ctx, txManager, voting.VoteFromData([]byte("repository linked")), voting.Synchronized); err != nil {
			return fmt.Errorf("vote on linked repository: %w", err)
		}

		return nil
	}

	alternatesWriter, err := safe.NewLockingFileWriter(altPath)
	if err != nil {
		return fmt.Errorf("creating alternates writer: %w", err)
	}
	defer func() {
		if err := alternatesWriter.Close(); err != nil && returnedErr == nil {
			returnedErr = fmt.Errorf("closing alternates writer: %w", err)
		}
	}()

	if _, err := io.WriteString(alternatesWriter, expectedRelPath); err != nil {
		return fmt.Errorf("writing alternates: %w", err)
	}
