### Title
ECDSA signature malleability bypasses multi-sig weight threshold in `ValidateMultiSign` TVM precompile - (File: `actuator/src/main/java/org/tron/core/vm/PrecompiledContracts.java`)

### Summary
The `ValidateMultiSign` precompiled contract (invoked via the TVM `validatemultisign(address,uint256,bytes32,bytes[])` builtin) deduplicates signatures by comparing the *raw signature bytes* concatenated with the recovered address, instead of deduplicating by the recovered address alone. Because signature recovery in this codebase only consumes the first 65 bytes of a signature blob (`r[0:32] | s[32:64] | v[64]`) and silently ignores any trailing bytes, an attacker can take one valid signature and resubmit it multiple times with different trailing padding. Each "different" padded copy recovers to the same signer address but fails the byte-exact duplicate check, so its weight is counted again — allowing a single signer's weight to be counted multiple times toward the permission threshold.

### Finding Description
`PrecompiledContracts.recoverAddrBySign` only requires `sign.length >= 65` and parses via `Rsv.fromSignature`, which reads exactly bytes `[0,32)`, `[32,64)`, and byte `64`, ignoring anything beyond index 64: [1](#0-0) [2](#0-1) 

In `ValidateMultiSign.execute`, each raw signature entry pulled from the caller-controlled ABI-encoded `bytes[]` array is recovered to an address, then merged with that address to form a dedup key that is checked against `executedSignList`: [3](#0-2) 

The `continue` (skip-weight) branch only fires when **both** the recovered address and the exact merged byte sequence (`addr + sign`) already exist in `executedSignList`. If an attacker supplies the same valid 65-byte signature twice, but appends arbitrary extra trailing bytes to the second copy (e.g. `sig2 = sig1 + garbage`), then:
- `recoverAddrBySign(sig2, hash)` still recovers the same address, because `Rsv.fromSignature` only reads bytes 0–64.
- `ByteArray.matrixContains(executedSignList, recoveredAddr)` is `true` (address seen before).
- `ByteArray.matrixContains(executedSignList, sign)` is `false` (the padded merged bytes differ from the first entry), so the `continue` is **not** taken.
- Execution falls through to `totalWeight += weight`, double-counting the same signer's weight.

This is the exact malleability pattern described in the report: the code marks "the signature itself as used rather than the signed message or a derived identity/nonce," and a resubmitted, syntactically-different-but-semantically-equivalent signature bypasses the reuse guard.

### Impact Explanation
An attacker controlling a smart contract that calls `validatemultisign` (e.g. to authorize a privileged operation gated by an on-chain `Permission` with a multi-signer threshold) can satisfy the threshold using fewer distinct authorized signers than required — down to a single colluding/compromised key — by padding one real signature into N distinct byte blobs that all recover to the same address. This is an unauthorized-account-operation / permission-threshold-bypass vulnerability (funds-custody or governance contracts relying on `ValidateMultiSign` for authorization can be drained or misused with insufficient real signer approval), directly reachable from an ordinary contract call with no special privileges. This qualifies as High severity per the validation rules (concrete unauthorized account operation / theft-adjacent bypass of signature-based authorization).

### Likelihood Explanation
Trivially reachable: any account can deploy a contract that calls the `ValidateMultiSign` precompile with a crafted `bytes[]` signatures argument (padding one signer's real signature with arbitrary trailing bytes). No special permissions, no race conditions, and no dependency on validator/witness behavior are required — this is a pure calldata-crafting attack against a public precompiled contract.

### Recommendation
Deduplicate strictly by recovered address (not by the raw/padded signature bytes): once `recoveredAddr` has been counted, skip any further signature that recovers to the same address regardless of its raw byte encoding. Additionally, enforce that signature blobs passed to `recoverAddrBySign`/`Rsv.fromSignature` are exactly 65 bytes (reject `sign.length != 65`) so that no ignored trailing bytes can be used to create distinct-looking but semantically identical signatures.

### Proof of Concept
1. Signer key `K` (address `A`) is one of the keys in a `Permission` with `threshold = 2`, `weight(A) = 1`, and no other signer available/compromised.
2. Attacker computes `sig1 = K.sign(hash)` (65 bytes: `r|s|v`).
3. Attacker constructs `sig2 = sig1 || 0x00` (66 bytes) — still recovers to `A` via `Rsv.fromSignature`/`recoverAddrBySign` because only the first 65 bytes are read.
4. Attacker calls `validatemultisign(address, permissionId, hash, [sig1, sig2])`.
5. In `ValidateMultiSign.execute`:
   - Iteration 1 (`sig1`): `recoveredAddr = A`, not in `executedSignList` → `totalWeight = 1`, add `(A+sig1)`, `A` to list.
   - Iteration 2 (`sig2`): `recoveredAddr = A` → `A` is in `executedSignList` (true), but merged `(A+sig2) != (A+sig1)` (false) → the `continue` is skipped → `totalWeight += 1` → `totalWeight = 2`.
6. `totalWeight (2) >= threshold (2)` → precompile returns success (`dataOne()`), even though only a single real signer authorized the action. [4](#0-3)

  private static byte[] recoverAddrBySign(byte[] sign, byte[] hash) {
    byte[] out = null;
    if (ArrayUtils.isEmpty(sign) || sign.length < 65) {
      return new byte[0];
    }
    try {
      Rsv rsv = Rsv.fromSignature(sign);
      SignatureInterface signature = SignUtils.fromComponents(rsv.getR(), rsv.getS(), rsv.getV(),
          CommonParameter.getInstance().isECKeyCryptoEngine());
      if (signature.validateComponents()) {
        out = SignUtils.signatureToAddress(hash, signature,
            CommonParameter.getInstance().isECKeyCryptoEngine());
      }
    } catch (Throwable any) {
      logger.info("ECRecover error", any.getMessage());
    }
    return out;
  }

  public static class ValidateMultiSign extends PrecompiledContract {

    private static final int ENGERYPERSIGN = 1500;
    private static final int MAX_SIZE = 5;
    private static final int ABI_HEADER_WORDS = 5;
    private static final int ABI_ITEM_WORDS = 5;


    @Override
    public long getEnergyForData(byte[] data) {
      long cnt = (data.length / WORD_SIZE - 5) / 5;
      // one sign 1500, half of ecrecover
      return cnt * ENGERYPERSIGN;
    }

    @Override
    public Pair<Boolean, byte[]> execute(byte[] rawData) {
      if (VMConfig.allowTvmOsaka()
          && !isValidAbiEncoding(rawData, ABI_HEADER_WORDS, ABI_ITEM_WORDS)) {
        return Pair.of(false, EMPTY_BYTE_ARRAY);
      }
      DataWord[] words = DataWord.parseArray(rawData);
      byte[] address = words[0].toTronAddress();
      int permissionId = words[1].intValueSafe();
      byte[] data = words[2].getData();

      byte[] combine = ByteUtil.merge(address, ByteArray.fromInt(permissionId), data);
      byte[] hash = Sha256Hash.hash(CommonParameter
          .getInstance().isECKeyCryptoEngine(), combine);

      if (VMConfig.allowTvmSelfdestructRestriction()) {
        int sigArraySize = words[words[3].intValueSafe() / WORD_SIZE].intValueSafe();
        if (sigArraySize > MAX_SIZE) {
          return Pair.of(true, DATA_FALSE);
        }
      }
      byte[][] signatures = VMConfig.allowTvmSelfdestructRestriction() ?
          extractSigArray(words, words[3].intValueSafe() / WORD_SIZE, rawData) :
          extractBytesArray(words, words[3].intValueSafe() / WORD_SIZE, rawData);

      if (signatures.length == 0 || signatures.length > MAX_SIZE) {
        return Pair.of(true, DATA_FALSE);
      }

      AccountCapsule account = this.getDeposit().getAccount(address);
      if (account != null) {
        try {
          Permission permission = account.getPermissionById(permissionId);
          if (permission != null) {
            //calculate weight
            long totalWeight = 0L;
            List<byte[]> executedSignList = new ArrayList<>();
            for (byte[] sign : signatures) {
              byte[] recoveredAddr = recoverAddrBySign(sign, hash);

              sign = merge(recoveredAddr, sign);
              if (ByteArray.matrixContains(executedSignList, recoveredAddr)) {
                if (ByteArray.matrixContains(executedSignList, sign)) {
                  continue;
                }
                MUtil.checkCPUTime();
              }
              long weight = TransactionCapsule.getWeight(permission, recoveredAddr);
              if (weight == 0) {
                //incorrect sign
                return Pair.of(true, DATA_FALSE);
              }
              totalWeight += weight;
              executedSignList.add(sign);
              executedSignList.add(recoveredAddr);
            }

            if (totalWeight >= permission.getThreshold()) {
              return Pair.of(true, dataOne());
            }
          }
        } catch (Throwable t) {
          if (t instanceof OutOfTimeException) {
            throw t;
          }
          logger.info("ValidateMultiSign error:{}", t.getMessage());
        }
      }
      return Pair.of(true, DATA_FALSE);
    }
  }
