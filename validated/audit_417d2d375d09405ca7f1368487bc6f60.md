### Title
Atomic Multi-Recipient APT Distribution in `vesting::distribute` and `staking_contract::distribute_internal` Allows Single Recipient to Permanently Block All Other Shareholders' Funds — (`aptos-move/framework/aptos-framework/sources/vesting.move`, `aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

`vesting::distribute` and `staking_contract::distribute_internal` iterate over all recipients in a single atomic transaction and call `aptos_account::deposit_coins` for each one. If any single recipient's deposit aborts — because the recipient account exists but has not registered for `AptosCoin` and has called `set_allow_direct_coin_transfers(false)` — the entire transaction reverts. All other shareholders' or stakers' APT remains locked in the contract with no permissionless recovery path.

---

### Finding Description

`vesting::distribute` withdraws all unlocked stake from the underlying pool and then loops over every shareholder, depositing each share atomically:

```move
// vesting.move lines 730-740
let grant_pool = &vesting_contract.grant_pool;
let shareholders = &grant_pool.shareholders();
shareholders.for_each_ref(|shareholder| {
    let shareholder = *shareholder;
    let shares = pool_u64::shares(grant_pool, shareholder);
    let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
    let share_of_coins = coin::extract(&mut coins, amount);
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);  // <-- can abort
});
``` [1](#0-0) 

`aptos_account::deposit_coins<AptosCoin>` contains the following guard:

```move
// aptos_account.move lines 123-127

    assert!(

        error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)

`can_receive_direct_coin_transfers` returns `false` when the account has explicitly called `set_allow_direct_coin_transfers(false)`:

```move
// aptos_account.move lines 226-231
public fun can_receive_direct_coin_transfers(account: address): bool acquires DirectTransferConfig {
    !exists<DirectTransferConfig>(account)
        || borrow_global<DirectTransferConfig>(account).allow_arbitrary_coin_transfers
}
``` [3](#0-2) 

`set_allow_direct_coin_transfers` is a public entry function callable by any account owner with no restrictions: [4](#0-3) 

The same structural issue exists in `staking_contract::distribute_internal`, which loops over all distribution-pool shareholders (operator beneficiary + staker) and calls `aptos_account::deposit_coins` for each:

```move
// staking_contract.move lines 888-911
while (distribution_pool.shareholders_count() > 0) {
    ...
    if (recipient == operator) {
        recipient = beneficiary_for_operator(operator);
    };
    aptos_account::deposit_coins(
        recipient, coin::extract(&mut coins, amount_to_distribute)
    );
};
``` [5](#0-4) 

An operator can call `set_beneficiary_for_operator` to point their commission to any address. If that address has not registered for `AptosCoin` and has `allow_arbitrary_coin_transfers = false`, the deposit aborts, blocking the staker's withdrawal as well.

---

### Impact Explanation

- **`vesting::distribute`**: A single shareholder whose account exists, has not registered for `AptosCoin`, and has called `set_allow_direct_coin_transfers(false)` causes every call to `distribute(contract_address)` to revert. All other shareholders' vested APT — already withdrawn from the stake pool into the local `coins` variable — cannot be delivered. Move's linear type system returns the coins to the pool on abort, but the distribution loop cannot make forward progress. All shareholders' APT is permanently frozen until the admin calls `update_beneficiary` to reroute the blocking shareholder's share.

- **`staking_contract::distribute_internal`**: An operator who sets their beneficiary to a blocking address prevents the staker from ever withdrawing their unlocked stake. The `distribute` entry function is callable by anyone, but every call reverts. [6](#0-5) [7](#0-6) 

---

### Likelihood Explanation

The trigger requires an account that (a) exists on-chain, (b) has not registered for `AptosCoin` via the standard `aptos_account::create_account` path (which auto-registers APT), and (c) has explicitly called `set_allow_direct_coin_transfers(false)`. Accounts created through the lower-level `account::create_account` without calling `register_apt` satisfy condition (b). Condition (c) is a single unprivileged transaction. For the staking-contract path, the operator controls their own beneficiary address and can deliberately construct this state. Likelihood is **low-medium** for vesting (requires a shareholder to be in this state) and **medium** for staking contracts (operator can deliberately engineer it to grief the staker).

---

### Recommendation

1. **Parametrize distribution**: Allow `distribute` to accept a specific shareholder/recipient address and deliver only that recipient's share in a single call, keeping separate per-recipient accounting of delivered amounts. This mirrors the fix applied in the referenced Clober PR 359.

2. **Graceful skip with escrow**: If `deposit_coins` would abort for a recipient, extract that recipient's share into a per-address claimable escrow mapping rather than aborting the entire loop.

3. **Pre-validate recipients**: Before the distribution loop, verify that every recipient can receive `AptosCoin` (registered and not frozen). If any cannot, revert early with a clear error rather than after partial extraction.

---

### Proof of Concept

**Vesting path:**

1. Attacker (shareholder `A`) creates an account via `account::create_account(@A)` — this does **not** call `register_apt`, so `coin::is_account_registered<AptosCoin>(@A)` returns `false`.
2. `A` calls `aptos_account::set_allow_direct_coin_transfers(false)`.
3. Admin creates a vesting contract with shareholders `[A, B, C]`.
4. After the lockup expires, anyone calls `vesting::distribute(contract_address)`.
5. The loop reaches shareholder `A`; `deposit_coins(@A, ...)` hits the `assert!(can_receive_direct_coin_transfers(@A), ...)` guard and aborts.
6. The entire transaction reverts. Shareholders `B` and `C` receive nothing.
7. Every subsequent call to `distribute` reverts identically. `B` and `C`'s APT is locked until the admin calls `update_beneficiary(admin, contract_address, @A, some_valid_address)`. [8](#0-7) [9](#0-8) 

**Staking-contract path:**

1. Operator calls `staking_contract::set_beneficiary_for_operator(operator, @blocking_addr)` where `@blocking_addr` satisfies the same conditions above.
2. Staker calls `staking_contract::distribute(staker_address, operator_address)`.
3. `distribute_internal` reaches the operator's commission payout, calls `deposit_coins(@blocking_addr, commission)`, and aborts.
4. The staker's withdrawn stake is never delivered; the transaction reverts on every attempt. [10](#0-9)

    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun set_allow_direct_coin_transfers(
        account: &signer, allow: bool
    ) acquires DirectTransferConfig {
        let addr = signer::address_of(account);
        if (exists<DirectTransferConfig>(addr)) {
            let direct_transfer_config = borrow_global_mut<DirectTransferConfig>(addr);
            // Short-circuit to avoid emitting an event if direct transfer config is not changing.
            if (direct_transfer_config.allow_arbitrary_coin_transfers == allow) { return };

            direct_transfer_config.allow_arbitrary_coin_transfers = allow;

            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
        } else {
            let direct_transfer_config = DirectTransferConfig {
                allow_arbitrary_coin_transfers: allow,
                update_coin_transfer_events: new_event_handle<
                    DirectCoinTransferConfigUpdatedEvent>(account)
            };
            emit(
                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

```text
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
