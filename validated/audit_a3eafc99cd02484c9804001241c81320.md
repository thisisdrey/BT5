### Title
Unauthenticated remote dispatch of `/new_burn_block`, `/new_block`, `/proposal_response`, `/stackerdb_chunks` events into the signer runloop - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` dispatches purely on `request.url()` and `request.method()`, with no check of the client's source IP or any shared secret/token, before converting the POST body into a `SignerEvent` and forwarding it to the signer's decision runloop. Any TCP client that can reach the bound listener address and knows the well-known paths can inject arbitrary `NewBurnBlock`, `NewBlock`, or `BlockValidationResponse` events with attacker-chosen fields.

### Finding Description
The claimed equality is: every `SignerEvent` forwarded to the signer runloop must equal an event that was actually emitted by the locally-configured, trusted stacks-node event dispatcher. Tracing `next_event()` in `libsigner/src/events.rs` (lines 413-459), after `http_server.recv()` returns a `Request`, the only checks performed are on `request.url()` (string equality against `/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/shutdown`, `/new_block`) and `request.method()` (must be POST). There is no inspection of `request.remote_addr()`, no comparison against a configured peer/source allowlist, and no shared-secret/bearer-token header requirement anywhere in this function or in `process_event` (lines 519-542). `process_event` simply reads the body, JSON-deserializes it into the target type `E` (e.g. `BurnBlockEvent`, `StacksBlockEvent`, `BlockValidateResponse`), and converts it via `TryFrom` into a `SignerEvent`, which is then handed back to `main_loop` (lines 284-312) and forwarded verbatim to the runloop channel via `forward_event`. None of the `TryFrom` impls (lines 637-649, 708-720, 627-635) perform any signature check, freshness check, or cross-validation against known chain state — they copy attacker-supplied JSON fields (`burn_block_height`, `consensus_hash`, `burn_block_hash`, `index_block_hash`, `block_height`, `transactions`, etc.) directly into the `SignerEvent`. Consequently, the equality "forwarded event == node-originated event" is not enforced by any guard in this code path; it depends entirely on network-layer isolation (firewalling the bound socket) that is outside this file's control.

### Impact Explanation
An attacker who can reach the signer's HTTP event-listener TCP port can inject fabricated `SignerEvent::NewBurnBlock` (fake burn height/consensus hash/parent hash), `SignerEvent::NewBlock` (fake block id, consensus hash, height, and transaction list), or `SignerEvent::BlockValidationResponse` records directly into the signer's runloop input channel, indistinguishable from genuine node-emitted events. This is a repeatable, single-message unauthenticated write into the signer's decision-input stream (Critical: unauthenticated/unauthorized write to state feeding consensus-adjacent decisions), bounded strictly to the transport/injection primitive as scoped — the downstream decision logic that consumes these events is explicitly out of scope for this finding.

### Likelihood Explanation
The only precondition is TCP reachability to the address:port the operator bound the signer's event server to (`SignerEventReceiver::bind`, line 404, binds via `tiny_http::Server::http(listener)` with no built-in restriction to loopback). No secret, credential, peer identity, or privileged role is required by this code — cost to the attacker is a single crafted HTTP POST. Whether the listener is remotely reachable depends on operator configuration (bind address), but the code itself imposes zero authentication regardless of bind address, so any party capable of reaching the socket (including from within a shared LAN, container network, or misconfigured public bind) can exploit it every time.

### Recommendation
Add an authentication gate in `next_event()`/`process_event` before dispatching on URL: require a shared-secret header/token configured between the stacks-node event-dispatcher and the signer (verified via constant-time comparison) and/or restrict `bind()` to loopback plus an explicit allowlist of remote addresses, rejecting requests from unauthorized `request.remote_addr()` values before any body is read or deserialized.

```rust
use std::net::TcpStream;
use std::io::{Write, Read};

#[test]
fn unauthenticated_remote_can_inject_new_burn_block() {
    let mut receiver: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    let handle = std::thread::spawn(move || receiver.next_event().unwrap());

    // Simulate an unrelated remote peer, not the configured node.
    let body = serde_json::json!({
        "burn_block_hash": "0x1111111111111111111111111111111111111111111111111111111111111111",
        "burn_block_height": 999999,
        "consensus_hash": "0x2222222222222222222222222222222222222222",
        "parent_burn_block_hash": "0x3333333333333333333333333333333333333333333333333333333333333333"
    }).to_string();

    let mut stream = TcpStream::connect(addr).unwrap();
    let req = format!(
        "POST /new_burn_block HTTP/1.1\r\nHost: {addr}\r\nContent-Length: {}\r\nContent-Type: application/json\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let event = handle.join().unwrap();
    match event {
        SignerEvent::NewBurnBlock { burn_height, .. } => assert_eq!(burn_height, 999999),
        _ => panic!("expected NewBurnBlock"),
    }
}
```

```rust
    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
```

```rust
fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}
```
