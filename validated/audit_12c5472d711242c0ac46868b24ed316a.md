### Title
Push-Payment via `aptos_account::deposit_coins` Can Be Blocked by Recipient Opt-Out, Permanently Freezing Vesting and Staking Distributions — (`File: aptos-move/framework/aptos-framework/sources/vesting.move`, `aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

`vesting::distribute()` and `staking_contract::distribute_internal()` use a push-payment loop that calls `aptos_account::deposit_coins()` for every recipient. `deposit_coins` aborts with `EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS` if the recipient has not yet registered a legacy `CoinStore<AptosCoin>` **and** has called `set_allow_direct_coin_transfers(false)`. Because the abort reverts the entire transaction, a single shareholder or beneficiary who opts out can permanently block all distributions for every other participant in the contract.

---

### Finding Description

`aptos_account::deposit_coins<CoinType>` contains the following guard:

```move
if (!coin::is_account_registered<CoinType>(to)) {
    assert!(
        can_receive_direct_coin_transfers(to),
        error::permission_denied(EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS)
    );
    coin::register<CoinType>(&create_signer(to));
};
``` [1](#0-0) 

`can_receive_direct_coin_transfers` returns `false` when the account has explicitly stored a `DirectTransferConfig` with `allow_arbitrary_coin_transfers = false`:

```move
public fun can_receive_direct_coin_transfers(account: address): bool acquires DirectTransferConfig {
    !exists<DirectTransferConfig>(account)
        || borrow_global<DirectTransferConfig>(account).allow_arbitrary_coin_transfers
}
``` [2](#0-1) 

Any account can set this flag with an unprivileged transaction:

```move
public entry fun set_allow_direct_coin_transfers(account: &signer, allow: bool) acquires DirectTransferConfig { ... }
``` [3](#0-2) 

**In `vesting::distribute()`**, the function iterates over all shareholders and calls `aptos_account::deposit_coins` for each:

```move
shareholders.for_each_ref(|shareholder| {
    let shareholder = *shareholder;
    let shares = pool_u64::shares(grant_pool, shareholder);
    let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
    let share_of_coins = coin::extract(&mut coins, amount);
    let recipient_address = get_beneficiary(vesting_contract, shareholder);
    aptos_account::deposit_coins(recipient_address, share_of_coins);
});
``` [4](#0-3) 

If any one `recipient_address` has not registered a legacy `CoinStore<AptosCoin>` and has opted out, the `assert!` inside `deposit_coins` aborts the entire transaction. Because Move's execution model reverts all state changes on abort, the coins return to the stake pool and no shareholder receives anything.

The same pattern exists in `staking_contract::distribute_internal()`:

```move
aptos_account::deposit_coins(
    recipient, coin::extract(&mut coins, amount_to_distribute)
);
``` [5](#0-4) 

and for the dust remainder sent to the staker:

```move
if (coin::value(&coins) > 0) {
    aptos_account::deposit_coins(staker, coins);
``` [6](#0-5) 

**Account creation via `aptos_account::create_account` only creates the primary fungible store** (via `register_apt` → `ensure_primary_fungible_store_exists`), not the legacy `CoinStore<AptosCoin>`. Therefore `coin::is_account_registered<AptosCoin>` returns `false` for such accounts, making the opt-out check reachable. [7](#0-6) 

Critically, `create_vesting_contract` validates `withdrawal_address` with `assert_account_is_registered_for_apt` but imposes **no such requirement on shareholders**: [8](#0-7) 

---

### Impact Explanation

- **Vesting**: A single shareholder (or a beneficiary set by the admin) who opts out of direct coin transfers permanently blocks `vesting::distribute()` for every other shareholder. All accumulated staking rewards and vested APT grants are frozen in the stake pool until the blocking address is resolved. The admin can call `set_beneficiary` to redirect that shareholder's funds, but this requires admin availability and is not guaranteed.
- **Staking contract**: If the staker or the operator's beneficiary opts out, `staking_contract::distribute()` (callable by anyone) permanently aborts, freezing all pending commission and withdrawal distributions.
- Both `distribute_many` (vesting) and the implicit calls to `distribute_internal` inside `request_commission`, `unlock_stake`, and `update_commission_percentage` are equally affected.

This constitutes permanent freezing of user-controlled APT staking balances and vesting balances, matching the allowed impact gate.

---

### Likelihood Explanation

- The trigger is a single unprivileged transaction (`set_allow_direct_coin_transfers(false)`) by any shareholder or beneficiary.
- Shareholders are added by the admin and may be third parties with no incentive to cooperate. A malicious or compromised shareholder can execute this at any time after contract creation.
- The `distribute` entry function is public and callable by anyone, so the abort is observable and repeatable.
- No existing guard in `vesting::distribute()` or `staking_contract::distribute_internal()` checks recipient opt-out status before attempting the push payment.

---

### Recommendation

Replace the push-payment loop with a pull-payment pattern, or add a per-recipient try/catch (not available in Move) — instead, use one of:

1. **Skip opted-out recipients and accumulate their share for later pull-withdrawal**: Track unclaimed balances in a `SimpleMap<address, u64>` and expose a `claim()` entry function.
2. **Pre-validate all recipients** at distribution time and revert early with a clear error identifying the blocking address, so the admin can act (e.g., call `set_beneficiary`) before funds are withdrawn from the stake pool.
3. **Use `primary_fungible_store::deposit` instead of `deposit_coins`** for APT distributions, since the fungible-asset path does not check `can_receive_direct_coin_transfers` and always succeeds for APT (APT's primary fungible store is created unconditionally).

Option 3 is the most direct fix: `aptos_account::deposit_fungible_assets` does not perform the opt-out check and is safe for APT: [9](#0-8) 

---

### Proof of Concept

```
1. Admin creates a vesting contract with shareholders [Alice, Bob].
   - Neither Alice nor Bob has a legacy CoinStore<AptosCoin>.

2. Bob calls:
     aptos_account::set_allow_direct_coin_transfers(bob_signer, false)
   This stores DirectTransferConfig { allow_arbitrary_coin_transfers: false } under Bob's address.

3. Time passes; stake pool earns rewards; vest() is called.

4. Anyone calls vesting::distribute(contract_address).
   - withdraw_stake() succeeds; coins are extracted from the stake pool.
   - Loop reaches Bob: deposit_coins(bob_address, bob_share) →
       coin::is_account_registered<AptosCoin>(bob) == false
       can_receive_direct_coin_transfers(bob) == false
       → ABORT: EACCOUNT_DOES_NOT_ACCEPT_DIRECT_COIN_TRANSFERS
   - Entire transaction reverts; Alice receives nothing; coins return to stake pool.

5. distribute() will abort on every future call as long as Bob's opt-out is active.
   Alice's vested APT is permanently inaccessible without admin intervention.
```

Affected entry points:
- `vesting::distribute` / `vesting::distribute_many` — [10](#0-9) 
- `staking_contract::distribute` / `distribute_internal` — [11](#0-10)

        account: &signer, allow: bool

                DirectCoinTransferConfigUpdated {
                    account: addr,
                    new_allow_direct_transfers: allow
                }
            );
            move_to(account, direct_transfer_config);
        };
    }

    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    /// Distribute all unlocked (inactive) funds according to distribution shares.
    fun distribute_internal(
        staker: address,
        operator: address,
        staking_contract: &mut StakingContract,
    ) acquires BeneficiaryForOperator {
        let pool_address = staking_contract.pool_address;
        // Create the Staker resource if it doesn't exist to backfill the Staker resource for each pool.
        if (!exists<Staker>(pool_address)) {
            let pool_signer =
                &account::create_signer_with_capability(&staking_contract.signer_cap);
            move_to(pool_signer, Staker { staker });
        };
        let (_, inactive, _, pending_inactive) = stake::get_stake(pool_address);
        let total_potential_withdrawable = inactive + pending_inactive;
        let coins =
            stake::withdraw_with_cap(
                &staking_contract.owner_cap, total_potential_withdrawable
            );
        let distribution_amount = coin::value(&coins);
        if (distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        let distribution_pool = &mut staking_contract.distribution_pool;
        update_distribution_pool(
            distribution_pool,
            distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        // Buy all recipients out of the distribution pool.
        while (distribution_pool.shareholders_count() > 0) {
            let recipients = distribution_pool.shareholders();
            let recipient = recipients[0];
            let current_shares = distribution_pool.shares(recipient);
            let amount_to_distribute =
                distribution_pool.redeem_shares(recipient, current_shares);
            // If the recipient is the operator, send the commission to the beneficiary instead.
            if (recipient == operator) {
                recipient = beneficiary_for_operator(operator);
            };
            aptos_account::deposit_coins(
                recipient, coin::extract(&mut coins, amount_to_distribute)
            );

            emit(
                Distribute {
                    operator,
                    pool_address,
                    recipient,
                    amount: amount_to_distribute
                }
            );
        };

        // In case there's any dust left, send them all to the staker.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(staker, coins);
            distribution_pool.update_total_coins(0);
        } else {
            coin::destroy_zero(coins);
        }
    }
