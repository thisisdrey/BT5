### Title
Stale `PromiseYieldReceipt` survives `remove_account()`, letting a deleted account's parked callback (e.g. `DeleteAccount{beneficiary}`) drain any account later re-created under the same name - (`core/store/src/utils/mod.rs`, `runtime/runtime/src/lib.rs`)

### Summary
`remove_account()` only deletes `Account`, `ContractCode`, `AccessKey`/`GasKeyNonce`, and `ContractData` trie entries for the deleted account, but never removes `PromiseYieldReceipt`, `PromiseYieldStatus`, or the `YieldIdToDataId`/`DataIdToYieldId` mappings keyed by that account, nor the already-enqueued `PromiseYieldTimeout` entry. If an account self-deletes while it still has a pending `yield_create` whose parked callback contains a `DeleteAccountAction{beneficiary: attacker}`, that callback and its timeout survive the deletion. When the timeout later fires, `resolve_promise_yield_timeouts` finds the orphaned receipt still present and delivers a timeout `PromiseResume`, causing the stale `DeleteAccountAction` to execute against whatever account now occupies that name, sending its balance to the attacker-chosen beneficiary.

### Finding Description
`resolve_promise_yield_timeouts` (`runtime/runtime/src/lib.rs:3009-3105`) walks the `PromiseYieldTimeout` queue purely by `(account_id, data_id)` and block height; at line 3051 it checks only `state_update.contains_key(&promise_yield_key)` (`TrieKey::PromiseYieldReceipt{receiver_id, data_id}`) to decide whether to synthesize a `PromiseResume{data:None}` for that account. It has no notion of "this account was deleted and recreated" - it only cares whether the receipt key still exists in the trie.

`remove_account()` (`core/store/src/utils/mod.rs:504-575`) removes:
- `TrieKey::Account`
- `TrieKey::ContractCode`
- `TrieKey::AccessKey` / `TrieKey::GasKeyNonce` entries
- `TrieKey::ContractData` entries

It does **not** remove `TrieKey::PromiseYieldReceipt`, `TrieKey::PromiseYieldStatus`, `TrieKey::YieldIdToDataId`, or `TrieKey::DataIdToYieldId`, even though these are all account-keyed columns listed in `COLUMNS_WITH_ACCOUNT_ID_IN_KEY` (`core/primitives/src/trie_key.rs:87-102`). The `PromiseYieldTimeout` queue entry (global, index-keyed, `core/primitives/src/receipt.rs:1082-1091`) is also untouched by deletion, since it isn't account-keyed at all.

The permission check that might have stopped this, `check_actor_permissions` (`runtime/runtime/src/actions.rs:739-785`), only requires `actor_id == account_id` for `Action::DeleteAccount`. Since NEAR account identity is purely name-based (no persistent unique ID beyond the `AccountId` string), a *new* account created under the same name automatically satisfies `actor_id == account_id` for a stale receipt whose `predecessor_id` and `receiver_id` were both set to that same account name at yield-creation time (`runtime/runtime/src/function_call.rs:187-194`, PromiseYield receipts are confined to a single account). Thus this check offers no protection against name reuse.

Exploit flow:
1. Attacker's account `A` runs a contract that calls `promise_yield_create` and constructs the yielded callback's actions to include `DeleteAccountAction{beneficiary_id: attacker_beneficiary}`, targeting `A` itself. This is stored via `set_promise_yield_receipt` keyed `(A, data_id)`, and a timeout is queued via `enqueue_promise_yield_timeout` (`runtime/runtime/src/function_call.rs:160-169`).
2. Attacker submits a normal transaction from `A` with `Action::DeleteAccount{beneficiary_id: attacker}` deleting `A`. `remove_account` clears account/keys/code/data but leaves the `PromiseYieldReceipt`, `PromiseYieldTimeout` queue entry, and (if present) yield-id mappings behind.
3. Account name `A` is now free. Anyone can `CreateAccount` under name `A` again and fund it (deposit/transfer NEAR).
4. When `apply_state.block_height` reaches the original `expires_at`, `resolve_promise_yield_timeouts` finds `contains_key(PromiseYieldReceipt{A, data_id})` true, synthesizes `PromiseResume{A, data:None}` (lines 3051-3097).
5. `process_receipt`'s `PromiseResume` branch (`runtime/runtime/src/lib.rs:1500-1562`) checks `get_promise_yield_status` (also never cleaned up, but was never set to `ResumeInitiated` in this scenario, so it does not block), finds the stale receipt via `get_promise_yield_receipt`, and executes it via `apply_action_receipt` against whatever account now lives at name `A`.
6. `action_delete_account` (`runtime/runtime/src/actions.rs:314-390`) refunds the *current* account's balance to the beneficiary fixed by the original attacker, then deletes the new account.

### Impact Explanation
Direct theft of funds: any account that reuses a name previously used by a "parked, then deleted" yield-holding account is automatically drained to an attacker-controlled beneficiary once the original timeout height passes, with zero further action required from the attacker. This is a straightforward instance of the NEAR bounty "theft of funds" category, achievable entirely by an unprivileged account owner using ordinary transactions (`yield_create` via contract call, `DeleteAccount`, and later—by anyone—`CreateAccount` + funding).

### Likelihood Explanation
Preconditions are cheap and fully within attacker control: deploy a small contract, call it to create the yield with a `DeleteAccount` callback, then send a `DeleteAccount` transaction for the same account, and wait `yield_timeout_length_in_blocks` blocks. No special privileges, races with validators, or network-layer access are needed. The main practical constraint is getting a victim (or the attacker's own future use) to reuse the exact deleted account name before the timeout height, which is entirely plausible for well-known/short/desirable account names or for account-naming schemes that recycle subaccount names. The bug is deterministic and repeatable for any account/data_id pair.

### Recommendation
In `remove_account()` (`core/store/src/utils/mod.rs`), also enumerate and remove any `PromiseYieldReceipt`, `PromiseYieldStatus`, `YieldIdToDataId`, and `DataIdToYieldId` entries for the account being deleted (mirroring the access-key/contract-data cleanup already done), and/or invalidate any outstanding `PromiseYieldTimeout` queue entries referencing the deleted account so a later timeout cannot resurrect a stale receipt against a differently-owned account of the same name. Alternatively, `resolve_promise_yield_timeouts`/the `PromiseResume` handler should verify that the account at `receiver_id` is "the same" account that created the yield (e.g., by binding the yield to some account-generation-independent nonce) before executing the stale callback.

pub struct RemoveAccountResult {
    pub gas_key_nonce_count: usize,
    pub gas_key_nonce_total_key_bytes: usize, // used to calculate compute cost
}

/// Removes account, code and all access keys and gas keys associated to it.
pub fn remove_account(
    state_update: &mut TrieUpdate,
    account_id: &AccountId,
) -> Result<RemoveAccountResult, StorageError> {
    state_update.remove(TrieKey::Account { account_id: account_id.clone() });
    state_update.remove(TrieKey::ContractCode { account_id: account_id.clone() });

    let mut gas_key_nonce_count: usize = 0;
    let mut gas_key_nonce_total_key_bytes: usize = 0;

    // Removing access keys and gas key nonces
    let lock = state_update.trie().lock_for_iter();
    let mut keys_to_remove: Vec<TrieKey> = Vec::new();
    for raw_key in state_update
        .locked_iter(&trie_key_parsers::get_raw_prefix_for_access_keys(account_id), &lock)?
    {
        let raw_key = raw_key?;
        let key_handle = trie_key_parsers::parse_key_handle_from_access_key_key(
            &raw_key, account_id,
        )
        .map_err(|_e| {
            StorageError::StorageInconsistentState(
                "Can't parse key handle from raw key for AccessKey".to_string(),
            )
        })?;
        let nonce_index =
            trie_key_parsers::parse_nonce_index_from_gas_key_key(&raw_key, account_id, &key_handle)
                .map_err(|_e| {
                    StorageError::StorageInconsistentState(
                        "Can't parse nonce index from raw key for AccessKey".to_string(),
                    )
                })?;
        if let Some(index) = nonce_index {
            gas_key_nonce_count += 1;
            gas_key_nonce_total_key_bytes += raw_key.len();
            keys_to_remove.push(TrieKey::gas_key_nonce(
                account_id.clone(),
                key_handle.clone(),
                index,
            ));
        } else {
            keys_to_remove.push(TrieKey::access_key(account_id.clone(), key_handle.clone()));
        }
    }
    drop(lock);

    for trie_key in keys_to_remove {
        state_update.remove(trie_key);
    }

    // Removing contract data
    let lock = state_update.trie().lock_for_iter();
    let data_keys = state_update
        .locked_iter(&trie_key_parsers::get_raw_prefix_for_contract_data(account_id, &[]), &lock)?
        .map(|raw_key| {
            trie_key_parsers::parse_data_key_from_contract_data_key(&raw_key?, account_id)
                .map_err(|_e| {
                    StorageError::StorageInconsistentState(
                        "Can't parse data key from raw key for ContractData".to_string(),
                    )
                })
                .map(Vec::from)
        })
        .collect::<Result<Vec<_>, _>>()?;
    drop(lock);

    for key in data_keys {
        state_update.remove(TrieKey::ContractData { account_id: account_id.clone(), key });
    }
    Ok(RemoveAccountResult { gas_key_nonce_count, gas_key_nonce_total_key_bytes })
}

pub(crate) fn action_delete_account(
    state_update: &mut TrieUpdate,
    account: &mut Option<Account>,
    actor_id: &mut AccountId,
    receipt: &Receipt,
    result: &mut ActionResult,
    account_id: &AccountId,
    delete_account: &DeleteAccountAction,
    config: &RuntimeConfig,
    current_protocol_version: ProtocolVersion,
) -> Result<(), StorageError> {
    let account_ref = account.as_ref().unwrap();
    let account_storage_usage = if ProtocolFeature::FixDeleteAccountGlobalContractStorageUsage
        .enabled(current_protocol_version)
    {
        let contract_storage = get_contract_storage_usage(state_update, account_id, account_ref)?;
        account_ref.storage_usage().saturating_sub(contract_storage)
    } else {
        // Legacy behavior: only subtracts local contract code, misses the
        // global contract identifier overhead.
        let account_storage_usage = account_ref.storage_usage();
        let code_len = get_code_len_or_default(
            state_update,
            account_id.clone(),
            account_ref.local_contract_hash().unwrap_or_default(),
        )?;
        debug_assert!(
            code_len == 0 || account_storage_usage > code_len,
            "account storage usage should be larger than code size. storage usage: {}, code size: {}",
            account_storage_usage,
            code_len
        );
        account_storage_usage.saturating_sub(code_len)
    };
    if account_storage_usage > Account::MAX_ACCOUNT_DELETION_STORAGE_USAGE {
        result.result =
            Err(ActionErrorKind::DeleteAccountWithLargeState { account_id: account_id.clone() }
                .into());
        return Ok(());
    }
    let gas_key_balance_to_burn = compute_gas_key_balance_sum(state_update, account_id)?;
    if gas_key_balance_to_burn > GasKeyInfo::MAX_BALANCE_TO_BURN {
        result.result = Err(ActionErrorKind::GasKeyBalanceTooHigh {
            account_id: account_id.clone(),
            public_key: None,
            balance: gas_key_balance_to_burn,
        }
        .into());
        return Ok(());
    }
    // We use current amount as a pay out to beneficiary.
    let account_balance = account_ref.amount();
    if account_balance > Balance::ZERO {
        result
            .new_receipts
            .push(Receipt::new_balance_refund(&delete_account.beneficiary_id, account_balance));
    }
    let remove_result = remove_account(state_update, account_id)?;
    result.tokens_burnt =
        result.tokens_burnt.checked_add(gas_key_balance_to_burn).ok_or_else(|| {
            StorageError::StorageInconsistentState("tokens_burnt overflow".to_string())
        })?;
    if remove_result.gas_key_nonce_count > 0 {
        let compute = storage_removes_compute(
            &config.wasm_config.ext_costs,
            remove_result.gas_key_nonce_count,
            remove_result.gas_key_nonce_total_key_bytes,
            AccessKey::NONCE_VALUE_LEN * remove_result.gas_key_nonce_count,
        );
        result.compute_usage = safe_add_compute(result.compute_usage, compute).map_err(|_| {
            StorageError::StorageInconsistentState("compute_usage overflow".to_string())
        })?;
    }
    *actor_id = receipt.predecessor_id().clone();
    *account = None;
    Ok(())
}

pub(crate) fn check_actor_permissions(
    action: &Action,
    account: &Option<Account>,
    actor_id: &AccountId,
    account_id: &AccountId,
) -> Result<(), ActionError> {
    match action {
        Action::DeployContract(_)
        | Action::Stake(_)
        | Action::AddKey(_)
        | Action::DeleteKey(_)
        | Action::DeployGlobalContract(_)
        | Action::UseGlobalContract(_)
        | Action::WithdrawFromGasKey(_) => {
            if actor_id != account_id {
                return Err(ActionErrorKind::ActorNoPermission {
                    account_id: account_id.clone(),
                    actor_id: actor_id.clone(),
                }
                .into());
            }
        }
        Action::DeleteAccount(_) => {
            if actor_id != account_id {
                return Err(ActionErrorKind::ActorNoPermission {
                    account_id: account_id.clone(),
                    actor_id: actor_id.clone(),
                }
                .into());
            }
            let account = account.as_ref().unwrap();
            if !account.locked().is_zero() {
                return Err(ActionErrorKind::DeleteAccountStaking {
                    account_id: account_id.clone(),
                }
                .into());
            }
        }
        Action::CreateAccount(_)
        | Action::FunctionCall(_)
        | Action::Transfer(_)
        | Action::TransferToGasKey(_) => (),
        Action::Delegate(_) | Action::DelegateV2(_) => (),
        Action::DeterministicStateInit(_) => (),
    };
    Ok(())
}
