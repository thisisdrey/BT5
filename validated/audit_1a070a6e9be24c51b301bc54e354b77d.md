### Title
Unconfirmed one-step "remote address" ownership transfer allows off-path hijack of an established tunnel via `handleHostRoaming` - (File: outside.go)

### Summary
`readOutsidePackets` in `outside.go` calls `f.handleHostRoaming(hostinfo, via)` immediately after a data packet decrypts successfully, and `handleHostRoaming` unconditionally reassigns the tunnel's trusted `remote` UDP address (`hostinfo.SetRemote(via.UdpAddr)`) to whatever source address the packet arrived from, with no second confirmation step verifying that the new address is actually held by the legitimate peer. This mirrors the reported `Ownable.sol` flaw: a security-critical binding (there, contract ownership; here, the address Nebula trusts to reach a peer) is transferred in a single unconfirmed step, so a wrong/adversarial value silently becomes authoritative.

### Finding Description
`readOutsidePackets` decrypts the AEAD payload with `hostinfo.ConnectionState.Decrypt` and, on success, immediately calls: [1](#0-0) 

`handleHostRoaming` then performs the "roam": [2](#0-1) 

The AEAD construction used by `Decrypt` authenticates the encrypted payload and the fixed Nebula header bytes (`packet[:header.Len]`), but not the outer UDP/IP source address (`via.UdpAddr`) the packet physically arrived from: [3](#0-2) 

Because the source IP:port is not part of the authenticated data, and `handleHostRoaming` swaps `hostinfo`'s trusted remote to `via.UdpAddr` as soon as any packet with a fresh, unseen counter decrypts and authenticates correctly — with only a rate/roam-suppression check and the `remote_allow_list`, but no round-trip challenge confirming the new address is actually reachable/controlled by the real peer — a single valid-looking packet from an unconfirmed source address is enough to become the new "owner" of that tunnel's destination. This is the same defect class as the reported bug: a trust-critical value (owner / trusted remote) is updated in one step from an unverified party instead of requiring a two-step accept/confirm handshake.

### Impact Explanation
If an attacker positioned to observe network traffic between two Nebula peers (or otherwise able to win a race against the legitimate packet, e.g. on a shared/broadcast segment, a compromised intermediate router, or via UDP source-spoofing combined with timing) replays or forges a UDP packet using the intercepted ciphertext but a different (attacker-controlled) source address before the genuine packet arrives, the responder will reassign the tunnel's `remote` to the attacker's address. All subsequent traffic that Nebula sends to that peer (via `HostInfo.GetRemote`) will be redirected to the attacker's IP:port, enabling traffic interception, black-holing, or redirection of an already-established, trusted tunnel — a remote state-poisoning impact.

### Likelihood Explanation
Exploitation requires the attacker to have captured/observed at least one valid, not-yet-consumed authenticated packet from the legitimate sender (e.g. via on-path position or race condition) and resend it with a spoofed source before the original arrives; the replay window (`ConnectionState.window`) would reject a true duplicate of an already-processed counter, so this is a timing/race-dependent, on-path-adjacent attack rather than a trivial fully remote one. It does not require the attacker to hold a CA-signed certificate or complete a handshake, matching the "no controlled credentials" reachability constraint, but likelihood is moderate rather than high due to the race/positioning requirement.

### Recommendation
Do not trust a new source address for an established tunnel based on a single decrypted packet. Require a two-step confirmation before roaming: upon observing a new source address, send a challenge (e.g., a `Test`/keepalive) to that new address and only promote it to `hostinfo.remote` after receiving a valid authenticated response from it, mirroring the "propose then accept" pattern recommended for ownership transfer. At minimum, rate-limit and log roams more aggressively and consider binding roam acceptance to additional out-of-band verification (e.g., requiring the new address to also be validated against `lighthouse`-reported/`static_host_map` data) rather than accepting the packet's source address outright.

### Proof of Concept
1. Establish a Nebula tunnel between hosts A and B.
2. Position an attacker M on a network segment able to observe UDP packets sent from A to B (or otherwise capture one live encrypted packet from A).
3. M captures a genuine encrypted data/control packet from A→B and immediately re-sends the identical byte stream to B, but from M's own UDP source address, racing to arrive before A's original packet (or before A's next packet, if the specific counter hasn't been consumed yet).
4. B's `readOutsidePackets` decrypts the packet successfully (AEAD validates because the ciphertext/header are unmodified) and calls `handleHostRoaming`, which calls `hostinfo.SetRemote(via.UdpAddr)` with M's address as `via.UdpAddr` — see [4](#0-3) .
5. B now sends all further traffic destined for A to M's address instead of A's, without any confirmation round-trip having occurred with M.

func (f *Interface) handleHostRoaming(hostinfo *HostInfo, via ViaSender) {
	curRemote := hostinfo.GetRemote()
	if !via.IsRelayed && curRemote != via.UdpAddr {
		if !f.lightHouse.GetRemoteAllowList().AllowAll(hostinfo.vpnAddrs, via.UdpAddr.Addr()) {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("lighthouse.remote_allow_list denied roaming", "newAddr", via.UdpAddr)
			}
			return
		}

		if !hostinfo.lastRoam.IsZero() && via.UdpAddr == hostinfo.lastRoamRemote && time.Since(hostinfo.lastRoam) < RoamingSuppressSeconds*time.Second {
			if f.l.Enabled(context.Background(), slog.LevelDebug) {
				hostinfo.logger(f.l).Debug("Suppressing roam back to previous remote",
					"suppressSeconds", RoamingSuppressSeconds,
					"udpAddr", curRemote,
					"newAddr", via.UdpAddr,
				)
			}
			return
		}

		hostinfo.logger(f.l).Info("Host roamed to new udp ip/port.",
			"udpAddr", curRemote,
			"newAddr", via.UdpAddr,
		)
		hostinfo.lastRoam = time.Now()
		hostinfo.lastRoamRemote = curRemote
		hostinfo.SetRemote(via.UdpAddr)
	}

}

func (cs *ConnectionState) Decrypt(l *slog.Logger, messageCounter uint64, out []byte, packet []byte, nb []byte) ([]byte, error) {
	var err error
	cs.decryptLock.Lock()
	result := cs.window.Check(l, messageCounter)
	cs.decryptLock.Unlock()
	if !result {
		return nil, ErrAlreadySeen
	}

	out, err = cs.dKey.DecryptDanger(out, packet[:header.Len], packet[header.Len:], messageCounter, nb)
	if err != nil {
		return nil, err
	}

	cs.decryptLock.Lock()
	result = cs.window.Update(l, messageCounter)
	cs.decryptLock.Unlock()
	if !result {
		return nil, ErrAlreadySeen
	}
	return out, nil
}
