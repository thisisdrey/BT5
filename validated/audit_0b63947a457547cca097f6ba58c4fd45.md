Audit Report

## Title
Era reward marked as claimed before pot-transfer settlement succeeds, permanently losing staker payouts when the reward pot lacks balance - (File: substrate/frame/staking-async/src/pallet/impls.rs)

## Summary
In `pallet-staking-async`'s non-minting (`DisableMinting = true`) reward path, `do_payout_stakers_by_page` calls `Eras::<T>::set_rewards_as_claimed(era, &stash, page)` before any transfer of the owed reward is attempted, and the subsequent transfer (`make_payout_from_provider`) can silently fail without reverting the claimed flag. Combined with `EraRewardManager::drain`/`cleanup_era`, which forcibly withdraws an era pot's remaining balance irrespective of whether all payees for that era have claimed, a staker's page can be marked "claimed" while the actual `Currency::transfer` from the era pot never lands, permanently losing the reward with no retry path.

## Finding Description
`do_payout_stakers_by_page` sets the claim flag immediately after the `AlreadyClaimed` check and before computing/executing any transfer: [1](#0-0) 

The actual value transfer only happens later, via `payout_from_provider` → `make_payout_from_provider`, which performs `T::Currency::transfer` from the era's `staker_rewards_pot` to the payout account: [2](#0-1) 

On transfer failure, `make_payout_from_provider` only logs an error and returns `None` — the caller `payout_from_provider` simply skips emitting the `Rewarded` event and does not propagate any error back to the dispatchable, nor does anything unset the claimed flag set earlier: [3](#0-2) 

Meanwhile, `EraRewardManager::drain` (invoked via `cleanup_era`) unconditionally withdraws an era pot's entire remaining balance to `UnclaimedRewardHandler` with no check for outstanding unclaimed pages for that era: [4](#0-3) 

Because `payout_stakers` accepts any era within `era >= current_era.saturating_sub(history_depth)`, and pot draining is decoupled from per-page claim completion, a late claimant's page can be marked claimed via line 386 and then fail the transfer at line ~592-599 in `make_payout_from_provider` if the pot was already drained (or is short due to `Preservation::Expendable` semantics), while the dispatchable still returns `Ok` and the flag is never reverted. Re-invoking `payout_stakers` for the same era/page will hit the `AlreadyClaimed` check at line 381-384 and be permanently rejected.

## Impact Explanation
This is a real value-conservation/settlement violation: staking reward payouts do not settle exactly once to the rightful beneficiary and amount, because "claimed" bookkeeping advances independent of whether funds were actually delivered. A staker's reward for an era/page can be permanently and silently destroyed with no error surfaced to the caller and no recovery path, since the extrinsic returns `Ok` and any retry is rejected by `Error::AlreadyClaimed`. This matches the required pivot: "payout state must only advance after ... settlement succeed[s] atomically," which is violated here.

## Likelihood Explanation
No privileged action or malicious actor is required — this is triggered by ordinary sequencing of two independently-scheduled, unprivileged/automatic mechanisms: (a) any user calling the public `payout_stakers` extrinsic for a page within the valid `HistoryDepth` window, and (b) automatic era-pot draining (`cleanup_era`) that runs once an era passes out of the retained window. If cleanup can run before every payee of an era has claimed all pages (which is plausible for slow/inactive nominators, or is exacerbated by `Preservation::Expendable` transfers exhausting a shared pot across many claimants of the same era), the described fund loss occurs.

## Recommendation
Reorder `do_payout_stakers_by_page` so that `set_rewards_as_claimed` is only persisted after the transfer(s) for that page have been attempted and confirmed successful (or track per-page transfer failures explicitly and expose a retryable path). Additionally, `EraRewardManager::drain`/`cleanup_era` should not reclaim an era pot's balance while unclaimed pages remain for that era — e.g., track an outstanding/unclaimed-page counter per era and gate `drain` on it reaching zero, or extend the era's retained window until all pages are claimed.

## Proof of Concept
1. Configure a staking-async runtime with `DisableMinting = true` so era pots are used instead of minting.
2. Let an era complete; `snapshot_era_rewards` funds the era's `StakerRewards` pot.
3. Advance eras until the era in question reaches the edge of `HistoryDepth`, triggering `EraRewardManager::cleanup_era`/`drain` for that era while at least one validator/nominator page has not yet called `payout_stakers`.
4. `drain` withdraws the era pot's full remaining balance to `UnclaimedRewardHandler`.
5. The remaining staker calls `payout_stakers` for their era/page. `do_payout_stakers_by_page` executes `Eras::<T>::set_rewards_as_claimed(era, &stash, page)` (impls.rs:386), then `make_payout_from_provider` attempts `T::Currency::transfer` from the now-empty pot, which fails, logs an error, and returns `None` (impls.rs:592-616) — the extrinsic still returns `Ok`.
6. Re-invoking `payout_stakers` for the same era/page returns `Error::AlreadyClaimed` (impls.rs:381-384), confirming the reward is permanently unrecoverable.

	/// Payout stakers from an era reward pot (transfer-based, no minting).
	fn payout_from_provider(
		era: EraIndex,
		stash: &T::AccountId,
		validator_payout: BalanceOf<T>,
		exposure: &crate::PagedExposure<T::AccountId, BalanceOf<T>>,
		overview_own: BalanceOf<T>,
		total_nominator_payout: BalanceOf<T>,
	) -> u32 {
		let mut nominator_payout_count: u32 = 0;

		if let Some((amount, dest)) = Self::make_payout_from_provider(era, stash, validator_payout)
		{
			Self::deposit_event(Event::<T>::Rewarded { stash: stash.clone(), dest, amount });
		}

		let total_nominator_stake = exposure.total().saturating_sub(overview_own);
		for nominator in exposure.others().iter() {
			let nominator_exposure_part =
				Perbill::from_rational(nominator.value, total_nominator_stake);
			let nominator_reward: BalanceOf<T> =
				nominator_exposure_part.mul_floor(total_nominator_payout);

			if let Some((amount, dest)) =
				Self::make_payout_from_provider(era, &nominator.who, nominator_reward)
			{
				nominator_payout_count.saturating_inc();
				Self::deposit_event(Event::<T>::Rewarded {
					stash: nominator.who.clone(),
					dest,
					amount,
				});
			}
		}

		nominator_payout_count
	}

	/// Make a payment to a staker from an era reward pot (transfer, not mint).
	fn make_payout_from_provider(
		era: EraIndex,
		stash: &T::AccountId,
		amount: BalanceOf<T>,
	) -> Option<(BalanceOf<T>, RewardDestination<T::AccountId>)> {
		if amount.is_zero() {
			return None;
		}

		let dest = match Self::payee(Stash(stash.clone())) {
			Some(d) => d,
			None => {
				Self::deposit_event(Event::<T>::Unexpected(UnexpectedKind::MissingPayee {
					era,
					stash: stash.clone(),
				}));
				return None;
			},
		};

		let payout_account = Self::payout_account_for_dest(stash, &dest)?;

		let staker_rewards_pot =
			T::RewardPots::pot_account(RewardPot::Era(era, RewardKind::StakerRewards));
		if let Err(e) = T::Currency::transfer(
			&staker_rewards_pot,
			&payout_account,
			amount,
			Preservation::Expendable,
		) {
			log!(
				error,
				"Failed to transfer reward from pot for era {:?}, stash {:?}: {:?}",
				era,
				stash,
				e
			);
			return None;
		}

	pub(crate) fn drain(era: EraIndex, kind: RewardKind) {
		let pot_account = T::RewardPots::pot_account(RewardPot::Era(era, kind));

		// Skip if pot was never created (legacy mode doesn't create pots).
		if frame_system::Pallet::<T>::providers(&pot_account) == 0 {
			return;
		}

		let remaining = T::Currency::balance(&pot_account);

		if remaining.is_zero() {
			return;
		}

		match T::Currency::withdraw(
			&pot_account,
			remaining,
			Precision::BestEffort,
			Preservation::Expendable,
			Fortitude::Force,
		) {
			Ok(credit) => {
				T::UnclaimedRewardHandler::on_unbalanced(credit);
				log!(
					debug,
					"Drained {:?} unclaimed rewards from era {:?} {:?} pot",
					remaining,
					era,
					kind
				);
			},
			Err(e) => {
				defensive!("Failed to withdraw unclaimed rewards from era pot");
				log!(
					error,
					"Era {:?} {:?}: unclaimed reward withdrawal failed: {:?}",
					era,
					kind,
					e
				);
			},
		}
	}

	/// Whether the slot backing this era's staker reward pot exists.
