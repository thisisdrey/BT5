Audit Report

## Title
Halting `OutboundQueue` does not stop already-enqueued messages from being committed and dispatched - (File: `bridges/snowbridge/pallets/outbound-queue/src/lib.rs`)

## Summary
`snowbridge-pallet-outbound-queue`'s halt check is enforced only at the `deliver()` intake function via `ensure!(!Self::operating_mode().is_halted(), SendError::Halted)`, while the actual settlement function `do_process_message` — invoked by `pallet-message-queue`'s `ProcessMessage::process_message` on every block — contains no halted check at all. [1](#0-0) [2](#0-1)  This allows a message enqueued before a halt to still be committed into the header digest and made available for relay to Ethereum after governance activates `Halted`.

## Finding Description
`set_operating_mode(Halted)` is a root-only call intended to stop all pallet operations, and the only enforcement of this mode is the `ensure!` guard inside `deliver()` for non-governance channels. [3](#0-2)  Once a message is accepted into `T::MessageQueue` (decoupled `pallet-message-queue`), its own `on_initialize`/`on_idle` hooks call `ProcessMessage::process_message`, which forwards unconditionally to `Pallet::do_process_message` with no re-check of `OperatingMode`. [4](#0-3)  `do_process_message` assigns a nonce, ABI-encodes the message, and appends it to `Messages`/`MessageLeaves` with no halted guard anywhere in the function body. [2](#0-1)  At block finalization, `commit()` unconditionally builds the merkle root from `MessageLeaves` and inserts it into the header digest via `deposit_log`, again without any halted check. [5](#0-4)  The existing test `submit_upgrade_message_success_when_queue_halted` only demonstrates that new low-priority `deliver()` calls are rejected while halted; it does not exercise or protect messages already sitting in the queue at halt time. [6](#0-5) 

## Impact Explanation
This matches the "public underpriced work that degrades block production or stalls bridge processing" and "message queues... must only advance after decode, dispatch, execution, and settlement succeed atomically" pivots. A message accepted before a halt (e.g., containing a malformed or exploit-crafted `Command` discovered only after enqueue) will still be committed into the merkle root deposited in the parachain header digest and made available to relayers — the exact state that `Halted` was meant to freeze — undermining the incident-response purpose of the halt mechanism.

## Likelihood Explanation
No privileged capability is needed beyond a normal permitted `deliver()` call (e.g., via a sibling parachain's XCM send through `EthereumBlobExporter::deliver`) performed while the pallet is still `Normal`. Settlement of that already-enqueued message then proceeds automatically via `pallet-message-queue`'s routine block servicing, independent of any subsequent `set_operating_mode(Halted)` call — this requires no relayer or validator compromise, only normal message-queue block processing.

## Recommendation
Add an explicit halted check inside `do_process_message` (and/or guard `commit()`), returning `ProcessMessageError::Yield` when `OperatingMode::<T>::get().is_halted()` for non-governance channels, so that already-queued messages remain intact in `pallet-message-queue` and are only drained/committed once governance resumes normal operating mode.

## Proof of Concept
1. A sibling parachain calls `EthereumBlobExporter::deliver`, which invokes `OutboundQueue::validate` + `OutboundQueue::deliver`, successfully enqueuing a message while `OperatingMode` is `Normal`. [1](#0-0) 
2. Governance calls `set_operating_mode(Halted)`. [3](#0-2) 
3. On the next block, `pallet-message-queue`'s hooks still invoke `ProcessMessage::process_message` → `do_process_message`, which has no halted check and appends the message to `Messages`/`MessageLeaves`. [2](#0-1) 
4. `on_finalize` calls `commit()`, which inserts the merkle root (including the message enqueued before the halt) into the header digest, exactly as if the pallet were never halted. [5](#0-4)

```rust
		pub(crate) fn commit() {
			let count = MessageLeaves::<T>::decode_len().unwrap_or_default() as u64;
			if count == 0 {
				return;
			}

			// Create merkle root of messages
			let root = merkle_root::<<T as Config>::Hashing, _>(MessageLeaves::<T>::stream_iter());

			let digest_item: DigestItem = SnowbridgeDigestItem::Snowbridge(root).into();

			// Insert merkle root into the header digest
			<frame_system::Pallet<T>>::deposit_log(digest_item);

			Self::deposit_event(Event::MessagesCommitted { root, count });
		}
```

```rust
		/// Process a message delivered by the MessageQueue pallet
		pub(crate) fn do_process_message(
			_: ProcessMessageOriginOf<T>,
			mut message: &[u8],
		) -> Result<bool, ProcessMessageError> {
			use ProcessMessageError::*;

			// Yield if the maximum number of messages has been processed this block.
			// This ensures that the weight of `on_finalize` has a known maximum bound.
			ensure!(
				MessageLeaves::<T>::decode_len().unwrap_or(0) <
					T::MaxMessagesPerBlock::get() as usize,
				Yield
			);

			// Decode bytes into versioned message
			let versioned_queued_message: VersionedQueuedMessage =
				VersionedQueuedMessage::decode(&mut message).map_err(|_| Corrupt)?;

			// Convert versioned message into latest supported message version
			let queued_message: QueuedMessage =
				versioned_queued_message.try_into().map_err(|_| Unsupported)?;

			// Obtain next nonce
			let nonce = <Nonce<T>>::try_mutate(
				queued_message.channel_id,
				|nonce| -> Result<u64, ProcessMessageError> {
					*nonce = nonce.checked_add(1).ok_or(Unsupported)?;
					Ok(*nonce)
				},
			)?;

			let pricing_params = T::PricingParameters::get();
			let command = queued_message.command.index();
			let params = queued_message.command.abi_encode();
			let max_dispatch_gas =
				T::GasMeter::maximum_dispatch_gas_used_at_most(&queued_message.command);
			let reward = pricing_params.rewards.remote;

			// Construct the final committed message
			let message = CommittedMessage {
				channel_id: queued_message.channel_id,
				nonce,
				command,
				params,
				max_dispatch_gas,
				max_fee_per_gas: pricing_params
					.fee_per_gas
					.try_into()
					.defensive_unwrap_or(u128::MAX),
				reward: reward.try_into().defensive_unwrap_or(u128::MAX),
				id: queued_message.id,
			};

			// ABI-encode and hash the prepared message
			let message_abi_encoded = ethabi::encode(&[message.clone().into()]);
			let message_abi_encoded_hash = <T as Config>::Hashing::hash(&message_abi_encoded);

			Messages::<T>::append(Box::new(message));
			MessageLeaves::<T>::append(message_abi_encoded_hash);

			Self::deposit_event(Event::MessageAccepted { id: queued_message.id, nonce });

			Ok(true)
		}
```

```rust
impl<T: Config> ProcessMessage for Pallet<T> {
	type Origin = AggregateMessageOrigin;
	fn process_message(
		message: &[u8],
		origin: Self::Origin,
		meter: &mut WeightMeter,
		_: &mut [u8; 32],
	) -> Result<bool, ProcessMessageError> {
		let weight = T::WeightInfo::do_process_message();
		if meter.try_consume(weight).is_err() {
			return Err(ProcessMessageError::Overweight(weight));
		}
		Self::do_process_message(origin, message)
	}
```
