`TrieRecorder::record_key_removal` (`core/store/src/trie/trie_recording.rs:140-146`) adds a flat 2000-byte charge to `upper_bound_size`, but this is **additional to**, not **instead of**, the actual node bytes recorded for the removal. Every trie node actually read/rewritten during a delete (path-to-leaf nodes plus any sibling read during branch→extension squashing) goes through `TrieRecorder::record`/`record_with` (`trie_recording.rs:109-131`), which increments **both** `size` (the true recorded byte total, line 129) and `upper_bound_size` (line 128) by the same amount, atomically, for every unique node. Only *after* that does `record_key_removal` add its extra flat 2000 bytes on top of `upper_bound_size` alone.

Because of this construction, `upper_bound_size` is algebraically guaranteed to be `>= size` at all times: it equals `size` plus non-negative extra terms (`removal_counter * 2000` and `code_len_counter`). `recorded_storage_size()` (`trie_recording.rs:199-201`) returns exactly `size`, and the true serialized `PartialStorage` byte length equals the sum of the deduplicated node byte lengths recorded (`recorded_storage`, `trie_recording.rs:165-176`), i.e. exactly `size`. So `recorded_storage_size_upper_bound() >= recorded_storage_size()` holds unconditionally by construction, regardless of trie shape.

The proposed attack (deep/wide branch via colliding-prefix keys, then one deletion) doesn't change this: `squash_node`/`extend_child` (`core/store/src/trie/ops/squash.rs:29-106`, `:110-175`) only touch the path from root to the deleted leaf plus, at most, a single sibling node per squashed branch level via `ensure_updated` (`core/store/src/trie/ops/insert_delete.rs:381`, `trie_storage_update.rs:92-103`) — not the full width of a branch. Every one of those touched nodes is fully recorded through `record`/`record_with`, so its real byte size is already included in `upper_bound_size` before the flat 2000-byte margin is even added.     /// Allows to avoid re-serializing the node when it has already been recorded.
    pub fn record_with(&self, hash: &CryptoHash, get_serialized_node: impl FnOnce() -> Arc<[u8]>) {
        let mut size_from_first_insert: Option<usize> = None;
        self.recorded
            .entry(*hash)
            .or_insert_with(|| {
                let serialized = get_serialized_node();
                size_from_first_insert = Some(serialized.len());
                serialized.into()
            })
            .increment();

        // Only do size accounting if this is the first time we see this value.
        if let Some(size) = size_from_first_insert {
            self.upper_bound_size.fetch_add(size, Ordering::Release).checked_add(size).unwrap();
            self.size.fetch_add(size, Ordering::Release);
        }
    }
