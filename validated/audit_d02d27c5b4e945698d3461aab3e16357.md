### Title
Unauthenticated peer-supplied `data_url` drives outbound HTTP connections without private-range/host filtering (SSRF-style) - ([File: stackslib/src/net/chat.rs])

### Summary
An analog of the Moodle blind-SSRF class (CVE-2019-6970) exists in the Stacks P2P layer: a remote, unauthenticated `Handshake` sender fully controls the `data_url` field that the receiving node later resolves and connects to over HTTP for RPC/StackerDB/tenure-download purposes, with no validation that the resolved address is non-private/non-loopback/non-metadata-service before the node's own HTTP client dials it.

### Finding Description
`HandshakeData::data_url` is attacker-controlled: any peer initiating a `Handshake` sets `handshake_data.data_url`, which is copied verbatim into the conversation state via `update_from_handshake_data` [1](#0-0) . This happens for both inbound and outbound conversations, and — critically — inbound handshakes are only gated by `disable_inbound_handshakes`/signature checks, not by any restriction on the advertised `data_url` [2](#0-1) .

The URL is later resolved to a concrete `SocketAddr` (`data_ip`) via `try_decode_data_url_ipaddr`/DNS resolution [3](#0-2) . The only validation applied is `UrlString::parse_to_block_url`, which enforces scheme (`http`/`https`) and rejects userinfo/query/fragment — it does **not** reject private, loopback, link-local, or cloud-metadata addresses (e.g. `127.0.0.1`, `10.x.x.x`, `169.254.169.254`) [4](#0-3) . The companion `has_routable_host()` check only excludes `0.0.0.0`/`::` [5](#0-4) .

Once `data_ip`/`data_url` are set on the conversation, `NeighborRPC::send_request` (used by StackerDB sync, tenure/mempool/RPC state machines) unconditionally dials `data_addr` via `http.connect_http`, with **no** `is_in_private_range()` check on this path [6](#0-5) . This contrasts with the mempool-sync code path, which explicitly guards the analogous case: `if !network.get_connection_opts().private_neighbors && PeerAddress::from_socketaddr(addr).is_in_private_range() { ... skip ... }` [7](#0-6) . The presence of this guard in one code path and its absence in `neighbors/rpc.rs::send_request` demonstrates the intended invariant (outbound connections must not target private/internal addresses by default) is broken for the generic neighbor-RPC send path that backs StackerDB sync and Nakamoto tenure downloading.

This breaks the equality "peer-advertised network destination == destination the node is willing/expected to dial." A malicious but otherwise unprivileged remote peer can advertise a `data_url` pointing at an internal service (e.g., a management/database port bound to `127.0.0.1` or an RFC1918 address reachable from the node's host/container network) and get the honest Stacks node to make outbound HTTP requests to it. The node's timing and connect/response behavior can reveal internal-network topology or trigger side effects on internal services — the "blind" SSRF pattern from the reported Moodle advisory.

### Impact Explanation
This matches the "High" impact tier defined in scope: it lets a remote unprivileged actor steer a node's outbound network calls off its intended target (peer's actual RPC endpoint) toward attacker-chosen internal destinations, which can be used to probe or interact with internal-only services (port-scanning primitive, or triggering unauthenticated internal HTTP endpoints) — reachable without needing the node's key or an admin role.

### Likelihood Explanation
Likelihood is High: any peer that can complete a P2P handshake (no special privilege required beyond opening a TCP connection to the node's P2P port, which nodes accept from the public internet by design) controls the `data_url` field entirely, and the resolution/dial path (`neighbors/rpc.rs::send_request`) is on the hot path used for StackerDB sync and Nakamoto tenure downloads, so it will be exercised routinely, not just under contrived conditions.

### Recommendation
Add the same private/loopback/link-local filtering used in `net/mempool/mod.rs` (`PeerAddress::is_in_private_range()`, gated by `connection_opts.private_neighbors`) directly inside `NeighborRPC::send_request` (and any other call site that dials `convo.data_url`/`data_ip`) before invoking `http.connect_http`, so the check is centralized and cannot be bypassed by any consumer of `NeighborComms`.

### Proof of Concept
1. Stand up a malicious peer that completes a valid P2P handshake with a target Stacks node, setting `HandshakeData.data_url = "http://127.0.0.1:PORT/..."` (or an internal RFC1918 address reachable from the node's host) — this is accepted and stored via `update_from_handshake_data` (`stackslib/src/net/chat.rs:1131-1147`).
2. Trigger a code path that uses `NeighborRPC::send_request` against this peer's `NeighborAddress` — e.g., cause StackerDB sync or Nakamoto tenure download to select this peer as a data source.
3. Observe (via response-timing / connect success-vs-fail differences, i.e. "blind" SSRF) that the target node makes an outbound HTTP connection to the attacker-chosen internal address instead of failing closed, since `send_request` performs no `is_in_private_range()` check (`stackslib/src/net/neighbors/rpc.rs:195-241`), unlike the equivalent mempool-sync path (`stackslib/src/net/mempool/mod.rs:485-498`).

    pub fn parse_to_block_url(&self) -> Result<url::Url, codec_error> {
        // even though this code uses from_utf8_unchecked() internally, we've already verified that
        // the bytes in this string are all ASCII.
        let url = url::Url::parse(&self.to_string())
            .map_err(|e| codec_error::DeserializeError(format!("Invalid URL: {:?}", &e)))?;

        if url.scheme() != "http" && url.scheme() != "https" {
            return Err(codec_error::DeserializeError(format!(
                "Invalid URL: invalid scheme '{}'",
                url.scheme()
            )));
        }

        if !url.username().is_empty() || url.password().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: must not contain a username/password".to_string(),
            ));
        }

        if url.host_str().is_none() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: no host string".to_string(),
            ));
        }

        if url.query().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: query strings not supported for block URLs".to_string(),
            ));
        }

        if url.fragment().is_some() {
            return Err(codec_error::DeserializeError(
                "Invalid URL: fragments are not supported for block URLs".to_string(),
            ));
        }

        Ok(url)
    }

    pub fn has_routable_host(&self) -> bool {
        let url = match url::Url::parse(&self.to_string()) {
            Ok(x) => x,
            Err(_) => {
                // should be unreachable
                return false;
            }
        };
        match url.host_str() {
            Some(host_str) => {
                if host_str == "0.0.0.0" || host_str == "[::]" || host_str == "::" {
                    return false;
                } else {
                    return true;
                }
            }
            None => {
                return false;
            }
        }
    }

    pub fn send_request(
        &mut self,
        network: &mut PeerNetwork,
        naddr: NeighborAddress,
        request: StacksHttpRequest,
    ) -> Result<(), NetError> {
        let nk = naddr.to_neighbor_key(network);
        let convo = network
            .get_neighbor_convo(&nk)
            .ok_or(NetError::PeerNotConnected(format!(
                "No authenticated conversation open to {nk} -- cannot perform HTTP request",
            )))?;
        let data_url = convo.data_url.clone();
        let data_addr = if let Some(ip) = convo.data_ip {
            ip
        } else if convo.waiting_for_dns() {
            debug!(
                "{}: have not resolved {} data URL {} yet: waiting for DNS",
                network.get_local_peer(),
                &convo,
                &data_url
            );
            return Err(NetError::WaitingForDNS);
        } else {
            debug!(
                "{}: have not resolved {} data URL {} yet, and not waiting for DNS",
                network.get_local_peer(),
                &convo,
                &data_url
            );
            return Err(NetError::PeerNotConnected(format!(
                "Have not resolved {nk} data URL {data_url} yet, and not waiting for DNS",
            )));
        };

        let event_id =
            PeerNetwork::with_network_state(network, |ref mut network, ref mut network_state| {
                PeerNetwork::with_http(network, |ref mut network, ref mut http| {
                    match http.connect_http(network_state, network, data_url, data_addr, None) {
                        Ok(event_id) => Ok(event_id),
                        Err(NetError::AlreadyConnected(event_id, _)) => Ok(event_id),
                        Err(e) => {
                            return Err(e);
                        }
                    }
                })
            })?;
