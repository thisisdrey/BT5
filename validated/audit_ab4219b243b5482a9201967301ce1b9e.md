### Title
Unauthenticated remote DoS via `/shutdown` HTTP request permanently halts signer event pipeline - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` matches the request URL `/shutdown` and unconditionally sets `event_receiver.stop_signal` to `true` and returns `Err(EventError::Terminated)`, with no authentication, secret, or peer-identity check of any kind. Since `stop_signal` is a shared `AtomicBool` checked on every future call to `next_event`, and `EventReceiver::main_loop` breaks out of its loop on `Err(EventError::Terminated)`, any remote TCP client that can reach the event-receiver's bound port can permanently kill all future event delivery (`stackerdb_chunks`, `proposal_response`, `new_burn_block`, `new_block`) with a single crafted HTTP POST.

### Finding Description
The intended equality is "authenticated shutdown authority == the party allowed to POST /shutdown," implemented via `SignerStopSignaler`, which is only supposed to be invoked internally (e.g., on `Drop` of the receiver) by connecting to `self.local_addr` and sending the literal shutdown request as a same-process signal mechanism. However, the actual code path in `next_event` at [1](#0-0)  treats any client's `/shutdown` POST identically to the internal stop signaler's request — there is no shared secret, HMAC, token, or `localhost`-only binding check distinguishing an internal signal from an external attacker's request. The `SignerStopSignaler::send` implementation itself simply opens a `TcpStream` and writes the literal HTTP request bytes [2](#0-1) , which is exactly reproducible by any external TCP client since the event receiver's port is bound via `HttpServer::http(listener)` at [3](#0-2)  with no IP-based or auth-based access restriction visible in the `bind` implementation. Once `stop_signal` is set to `true`, every subsequent call to `next_event` immediately short-circuits at the `is_stopped()` check [4](#0-3)  and returns `Err(EventError::Terminated)`, and `main_loop` (in the `EventReceiver` trait's driving loop) breaks out on that specific error, permanently halting the signer runloop's receipt of `stackerdb_chunks`, `proposal_response`, `new_burn_block`, and `new_block` events.

### Impact Explanation
A single unauthenticated HTTP POST to `/shutdown` permanently disables the signer's event pipeline, preventing it from receiving StackerDB chunk updates, block proposal validation responses, and new burn/Stacks block notifications going forward — effectively taking the signer offline from the node's event-dispatch perspective without crashing the process. This matches the "Critical — remote crash/unauthenticated DoS from few messages" category: it is a single-message, unauthenticated, repeatable (for any newly started or restarted receiver) denial of service on a core signer capability.

### Likelihood Explanation
No preconditions are required beyond TCP reachability to the bound event-receiver port, which the signer must expose to receive events from the node in the first place; no secret, peer credential, or admin role is needed. The attack cost is a single raw HTTP request, trivially reproducible from any TCP client.

### Recommendation
Restrict `/shutdown` handling to only trusted/local callers — e.g., bind the event receiver to `127.0.0.1` only, or require a per-process shared secret/token in the shutdown request that is generated at `bind()` time and known only to `SignerStopSignaler`, validating it before acting on the stop signal.

### Proof of Concept
```rust
// In libsigner/src/events.rs test module or an integration test:
#[test]
fn unauthenticated_shutdown_dos() {
    let mut receiver = SignerEventReceiver::new(/* mainnet */ false);
    let bind_addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let addr = receiver.bind(bind_addr).unwrap();

    // Attacker: raw TCP connection, no secret, no SignerStopSignaler used
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
        addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());
    // All subsequent next_event calls will also return Err(EventError::Terminated),
    // permanently halting event delivery, without ever calling get_stop_signaler/SignerStopSignaler::send.
}
```
