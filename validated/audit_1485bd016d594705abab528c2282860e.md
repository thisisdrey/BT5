## Title
`pallet-whitelist` deferred-dispatch relay lets any unprivileged signed account choose the moment a Root-privileged call is executed - ([File: substrate/frame/whitelist/src/lib.rs])

### Summary
`pallet-whitelist`'s `dispatch_whitelisted_call` / `dispatch_whitelisted_call_with_preimage` extrinsics implement a "deferred dispatch" flow: if `T::DispatchWhitelistedOrigin` submits a call before it is whitelisted, the call is not rejected but recorded in `DeferredDispatch` with an expiry, and *any signed account* is then permitted to trigger its execution (as `Root`) once `T::WhitelistOrigin` whitelists the hash [1](#0-0) . This mirrors the report's core defect class: an entity other than the one authorized to decide *when* a privileged/queued action executes can trigger it unilaterally, at a time of its own choosing.

### Finding Description
`dispatch_whitelisted_call` checks the caller against `DispatchWhitelistedOrigin`; if that fails, it falls back to `ensure_signed_deferred_dispatch`, which only requires: a signed origin, an existing (non‑expired) `DeferredDispatch` entry, and that the hash is currently whitelisted [2](#0-1) . Once these hold, `clean_and_dispatch` unconditionally dispatches the decoded call with `frame_system::Origin::<T>::Root` [3](#0-2) , and the relaying signed account pays no fee (`Pays::No`) [4](#0-3) .

The corrupted invariant: the *timing* of Root-level dispatch — which should remain controlled by `DispatchWhitelistedOrigin` (the only entity that decided to submit/queue the call) — is instead handed to an arbitrary unprivileged signed account as soon as `WhitelistOrigin` whitelists the hash. There is no requirement that the relaying account be the same as, or authorized by, `DispatchWhitelistedOrigin`, and no additional delay/authorization step analogous to "only admin can execute." This is exactly the missing-access-control pattern from the report: `Timelock.executeTransaction` allowed *anybody* to trigger a queued, privileged operation once its time condition was met, instead of restricting the trigger to the entity that authorized the action, letting an attacker pick the advantageous block/state at which to force execution.

### Impact Explanation
Any deferred call dispatched via this relay path runs with **Root origin** — the most privileged origin in the runtime, capable of `set_code`, forced balance/asset operations, or any other root-gated logic bundled into the whitelisted preimage. An unprivileged actor decides exactly which block (within the expiry window) the call executes in, giving them the ability to time execution to align with other on-chain state they control or observe (e.g., pending balances, oracle prices, other pending extrinsics in the same block), for advantage — the same "Eve" scenario from the report, generalized to a Root-privileged action instead of a Timelock transaction. This falls under "unauthorized execution or origin escalation" and "runtime bugs that compromise intended behavior" in the impact gate, since a signed, unprivileged account effectively decides the execution moment of a Root call meant to be governed by the whitelisting/dispatch authorities.

### Likelihood Explanation
Requires no privileged actor, governance abuse, leaked keys, or malicious infrastructure — only: (1) `DispatchWhitelistedOrigin` submits a call that is not yet whitelisted (a normal, documented use of the deferred-dispatch feature, per `prdoc/pr_11336.prdoc`), and (2) any ordinary signed account monitoring `WhitelistedCall`/`DeferredDispatch` storage or the `CallWhitelisted` event calls `dispatch_whitelisted_call`/`_with_preimage` themselves. This is entirely achievable by an unprivileged watcher and is exactly the usage pattern the pallet's own tests exercise (e.g. `test_deferred_dispatch_with_signed_origin`, `relay_cannot_be_replayed`) [5](#0-4) , confirming the path is reachable in normal operation, not a corner case.

### Recommendation
- Short term: restrict who may consume a `DeferredDispatch` entry to the same account/origin family that created it (e.g., record the originating `DispatchWhitelistedOrigin` identity or require a second `DispatchWhitelistedOrigin`-gated confirmation step to actually trigger execution), removing the "any signed origin" trigger, mirroring the report's "only allow the admin to call executeTransaction."
- Long term: if permissionless relaying is intentionally desired for UX/gas reasons, bind the deferred entry to a fixed execution block (rather than an open window up to expiry) so no party — privileged or not — can choose the exact block of Root execution, and require the relay to also be non-front-runnable (e.g., via `eta`-style exact-block execution rather than "any time before expiry").

### Proof of Concept
1. `DispatchWhitelistedOrigin` (e.g. via `dispatch_whitelisted_call_with_preimage`) submits `call` (unwhitelisted). This stores `DeferredDispatch::<T>::insert(call_hash, now + Expiration)` and returns `Ok` without executing anything [6](#0-5) .
2. `WhitelistOrigin` later whitelists `call_hash` via `whitelist_call`.
3. Any signed account `Eve` observes the `CallWhitelisted` event / storage and, at the block of her choosing (before expiry), calls `dispatch_whitelisted_call_with_preimage(RuntimeOrigin::signed(Eve), call)`.
4. `ensure_signed_deferred_dispatch` passes (deferred entry exists, not expired, whitelisted) [2](#0-1) ; `clean_and_dispatch` executes `call` with `Root` origin at the exact block Eve chose, for free (`Pays::No`) [3](#0-2) ; test `test_deferred_dispatch_with_signed_origin` demonstrates this exact flow succeeding for `RuntimeOrigin::signed(4)` [5](#0-4) .

	fn ensure_signed_deferred_dispatch(
		origin: T::RuntimeOrigin,
		call_hash: T::Hash,
	) -> Result<T::AccountId, DispatchError> {
		let who = ensure_signed(origin)?;

		let expire_at =
			DeferredDispatch::<T>::get(call_hash).ok_or(Error::<T>::DeferredDispatchNotFound)?;

		ensure!(
			T::BlockNumberProvider::current_block_number() < expire_at,
			Error::<T>::DeferredDispatchExpired
		);

		ensure!(WhitelistedCall::<T>::contains_key(call_hash), Error::<T>::CallIsNotWhitelisted);

		Ok(who)
	}

	/// Clean whitelisting/preimage and dispatch call.
	///
	/// Returns the inner call's actual weight.
	fn clean_and_dispatch(call_hash: T::Hash, call: <T as Config>::RuntimeCall) -> Option<Weight> {
		WhitelistedCall::<T>::remove(call_hash);
		T::Preimages::unrequest(&call_hash);
		DeferredDispatch::<T>::remove(call_hash);

		let result = call.dispatch(frame_system::Origin::<T>::Root.into());

		let call_actual_weight = match result {
			Ok(call_post_info) => call_post_info.actual_weight,
			Err(call_err) => call_err.post_info.actual_weight,
		};
		Self::deposit_event(Event::<T>::WhitelistedCallDispatched { call_hash, result });

		call_actual_weight
	}

#[test]
fn test_deferred_dispatch_with_signed_origin() {
	new_test_ext().execute_with(|| {
		// This is a call that both signed origin and root can call, provided all requirements are
		// met.
		let balance_call = RuntimeCall::Balances(pallet_balances::Call::force_transfer {
			source: 1,
			dest: 2,
			value: 100,
		});

		// Fund source account balance
		assert_ok!(Balances::force_set_balance(RuntimeOrigin::root(), 1, 1000));

		let balance_call_hash = <Test as frame_system::Config>::Hashing::hash_of(&balance_call);
		let balance_call_len = balance_call.encoded_size() as u32;
		let balance_encoded_call = balance_call.encode();
		let balance_call_weight = balance_call.get_dispatch_info().call_weight;

		// Initial caller should be root or assigned Origin
		assert_noop!(
			Whitelist::dispatch_whitelisted_call(
				RuntimeOrigin::signed(1),
				balance_call_hash,
				balance_call_len,
				balance_call_weight,
			),
			crate::Error::<Test>::DeferredDispatchNotFound
		);

		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::root(),
			balance_call_hash,
			balance_call_len,
			balance_call_weight,
		));

		assert!(events().iter().any(|event| {
			match event {
				Event::<Test>::DispatchDeferred { call_hash: hash } => hash == &balance_call_hash,
				_ => false,
			}
		}));

		assert_ok!(Whitelist::whitelist_call(RuntimeOrigin::root(), balance_call_hash));

		assert_ok!(Preimage::note(balance_encoded_call.into()));

		assert!(Preimage::is_requested(&balance_call_hash));

		// Subsequent call to the same hash can be from any signed origin before the dispatch expiry
		assert_ok!(Whitelist::dispatch_whitelisted_call(
			RuntimeOrigin::signed(4),
			balance_call_hash,
			balance_call_len,
			balance_call_weight,
		));

		let post_dispatch_events = events();

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(event, Event::<Test>::CallWhitelisted { call_hash: hash } if hash == &balance_call_hash)
		}));

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::WhitelistedCallDispatched { call_hash: hash, result: Ok(_) }
				if hash == &balance_call_hash
			)
		}));

		assert!(post_dispatch_events.iter().any(|event| {
			matches!(
				event,
				Event::<Test>::DeferredDispatchExecuted { call_hash: hash, who: 4 }
				if hash == &balance_call_hash
			)
		}));

		assert!(!Preimage::is_requested(&balance_call_hash));
	});
}
