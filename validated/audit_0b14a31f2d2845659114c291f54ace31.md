The reported CVE-2026-72066 concerns a Linux kernel sysfs interface (`states_show()` in `cpu/hotplug.c`) writing CPU hotplug state names into a `PAGE_SIZE` buffer via unbounded `sprintf()`. This is a kernel-internal sysfs read path exposed to local users with filesystem access to `/sys/devices/system/cpu/hotplug/states` — it has no meaningful analog in the Go toolchain/runtime source tree, which does not implement sysfs or any kernel-level hotplug state reporting.

I searched the Go repository for comparable patterns — buffer-bounded string/state formatting reachable by an unauthenticated/unprivileged attacker through an HTTP entry point, TLS certificate handling, module checksum/fetch, or archive extraction — and found none that match the actual root cause (unbounded `sprintf` into a fixed-size buffer driven by an attacker-controlled/expandable list of names):

- `internal/cpu` (`src/internal/cpu/cpu.go`, `cpu_x86.go`) exposes CPU feature detection and a `GODEBUG`-driven `processOptions()` parser, but this only processes the local `GODEBUG` environment variable set by the process owner, not attacker-supplied network input, and does not write into a fixed-size buffer at all. [1](#0-0) 
- `internal/godebug` and `runtime.parsegodebug` similarly parse the `GODEBUG` env var into individual settings using slicing, not `sprintf`-style fixed-buffer writes, and are not attacker-reachable over any untrusted channel. [2](#0-1) 
- `cmd/link/internal/loader/symbolbuilder.go`'s `AddStringAt`/`AddCStringAt` explicitly bounds-check writes and `panic` on overflow rather than silently overrunning a buffer, which is the opposite failure mode of the reported kernel bug. [3](#0-2) 

None of these constitute a Go entry point reachable by an unauthenticated/unprivileged attacker (HTTP request, TLS handshake, module fetch, or untrusted source consumption) with a genuine "write past a fixed buffer" root cause matching the kernel report. No further plan is warranted since no valid vulnerability was identified.

func (sb *SymbolBuilder) AddStringAt(off int64, str string) int64 {
	strLen := int64(len(str))
	if off+strLen > int64(len(sb.data)) {
		panic("attempt to write past end of buffer")
	}
	copy(sb.data[off:off+strLen], str)
	return off + strLen
}

func (sb *SymbolBuilder) AddCStringAt(off int64, str string) int64 {
	strLen := int64(len(str))
	if off+strLen+1 > int64(len(sb.data)) {
		panic("attempt to write past end of buffer")
	}
	copy(sb.data[off:off+strLen], str)
	sb.data[off+strLen] = 0
	return off + strLen + 1
}
