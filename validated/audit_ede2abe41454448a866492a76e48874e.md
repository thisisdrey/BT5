### Title
Reftable block parser panics on out-of-bounds slice access when parsing malformed/crafted reftable data - ([File: internal/git/reftable/reftable.go])

### Summary
`Table.getRefsFromBlock`, `Table.parseRefBlock`, and `Table.getVarInt` in [1](#0-0)  parse the binary contents of `.ref` reftable files without validating that decoded length fields (`prefixLength`, `suffixLength`, hash sizes, restart counts) stay within the bounds of the block/slice being read. Multiple slice expressions such as `src[idx:idx+suffixLength]`, `src[idx:idx+uint(hashSize)]`, and `src[blockStart+currentBS-2:]` will panic with an out-of-range index if the underlying `.ref` file is malformed, mirroring the underflow-panic bug class described in the source report where an unchecked cell layout led to a parser panic on malformed input.

### Finding Description
The reftable block-record parser trusts length values decoded straight out of the file via `getVarInt` (`internal/git/reftable/reftable.go:204-219`) and then immediately slices the in-memory buffer with them: [2](#0-1) 

`suffixLength` and `prefixLength` are attacker/data-controlled 61+-bit varints with no upper bound check against `b.RestartStart`/`len(src)` before being used to slice `src` and `prefix`, so a crafted length larger than the remaining buffer causes a Go runtime slice-bounds-out-of-range panic rather than a handled error. The same unchecked pattern repeats for the hash-sized reference/peeled-tag/symref cases (lines 268, 274, 290) and in `parseRefBlock`'s restart-count read: [3](#0-2) 

`currentBS` comes directly from `extractBlockLen` (`internal/git/reftable/reftable.go:198-201`), which itself just interprets 3 raw bytes with no correlation check against the actual block/file size, so `blockStart+currentBS-2` can also panic via unsigned-integer underflow-turned-huge-offset if `currentBS` is smaller than 2.

This directly parallels the reported bug class: a structured payload is accepted from a boundary without the parser validating remaining length/format before performing type-punned reads, and the mismatch surfaces as a hard panic instead of a graceful validation error.

### Impact Explanation
`Table.GetReferences` (and thus this parser) is exercised by the storage-partition reftable code path (`internal/gitaly/storage/storagemgr/partition/reftable.go`) and by test helpers that assert on-disk reftable content, and is Gitaly's own implementation of the reftable ref-storage format used by the "reftable" reference backend. A crafted or corrupted `.ref` table file — e.g. arising from disk corruption, a WAL/log replication issue, or any code path where a reftable file's bytes are not fully attacker-excluded before being handed to this parser — triggers an unrecovered Go panic in the parsing goroutine. Since Gitaly serves this backend inside its RPC-handling processes, this is a denial-of-service class defect: a single malformed reftable can crash or abort a request-serving goroutine instead of returning a clean error, which matches the "DoS of a handler" acceptance criterion. I was not able to fully confirm, within the available context, an existing production RPC path where the *exact bytes* of a `.ref` file are influenced end-to-end by an unprivileged remote caller (as opposed to being generated exclusively by Gitaly's own reftable-writing code); this is the main remaining uncertainty.

### Likelihood Explanation
Likelihood depends on whether reftable files can end up malformed in production. Since Gitaly currently only writes reftables via its own trusted code and Git's own reftable writer, reaching this parser with a genuinely malformed file requires either an on-disk corruption scenario, a partially-written/interrupted WAL entry, or a future/alternate ingestion path (e.g., replication, import, or backup restoration) that writes untrusted table bytes before they're parsed. Given the parser has no defensive bounds checks at all around length-derived slicing, any such path is high-likelihood to panic rather than fail gracefully.

### Recommendation
- Add explicit bounds validation in `getVarInt`, `getRefsFromBlock`, and `parseRefBlock` before every slice operation derived from decoded lengths (`prefixLength`, `suffixLength`, hash sizes, `currentBS`, `RestartCount`), returning a descriptive parse error instead of allowing a panic.
- Validate `currentBS >= 2` (and other minimum-size invariants) before computing `blockStart+currentBS-2` to avoid unsigned underflow.
- Add fuzz/unit tests feeding truncated and out-of-range reftable block records to `Table.GetReferences` to ensure errors are returned instead of panics, consistent with the long-term recommendation in the source report to test malformed-data scenarios.

### Proof of Concept
Construct a minimal reftable file with a valid header/footer but a ref block whose first record encodes (via `getVarInt`) a `suffixLength` value larger than the remaining bytes in the block (e.g., set the length byte to a value like `0xF8` without continuation bytes, or a continued varint yielding a value exceeding `b.RestartStart - idx`). Calling `reftable.ParseTable(path)` followed by `table.GetReferences()` on this file causes `src[idx:idx+suffixLength]` in `getRefsFromBlock` (`internal/git/reftable/reftable.go:247`) to panic with `runtime error: slice bounds out of range` instead of returning an error. // getVarInt parses a variable int and increases the index.
func (t *Table) getVarInt(src []byte, start uint, blockEnd uint) (uint, uint, error) {
	var val uint

	val = uint(src[start]) & 0x7f

	for (uint(src[start]) & 0x80) > 0 {
		start++
		if start > blockEnd {
			return 0, 0, fmt.Errorf("exceeded block length")
		}

		val = ((val + 1) << 7) | (uint(src[start]) & 0x7f)
	}

	return start + 1, val, nil
}

// getRefsFromBlock provides the ref udpates from a reference block.
func (t *Table) getRefsFromBlock(src []byte, b *block) ([]git.Reference, error) {
	var references []git.Reference

	prefix := ""

	// Skip the block_type and block_len
	idx := b.BlockStart + 4

	for idx < b.RestartStart {
		var prefixLength, suffixLength, updateIndexDelta uint
		var err error

		idx, prefixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting prefix length: %w", err)
		}

		idx, suffixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting suffix length: %w", err)
		}

		extra := (suffixLength & 0x7)
		suffixLength >>= 3

		refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])
		idx = idx + suffixLength

		idx, updateIndexDelta, err = t.getVarInt(src, idx, b.FullBlockSize)
		if err != nil {
			return nil, fmt.Errorf("getting update index delta: %w", err)
		}
		// we don't use this for now
		_ = updateIndexDelta

		reference := git.Reference{
			Name: git.ReferenceName(refname),
		}

		switch extra {
		case 0:
			// Deletion, no value
			reference.Target = t.shaFormat().ZeroOID.String()
		case 1:
			// Regular reference
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)
		case 2:
			// Peeled Tag
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)

			// For now we don't need the peeledOID, but we still need
			// to skip the index.
			// peeledOID := ObjectID(bytesToHex(t.src[idx : idx+uint(hashSize)]))
			idx += uint(hashSize)
		case 3:
			// Symref
			var size uint
			idx, size, err = t.getVarInt(src, idx, b.FullBlockSize)
			if err != nil {
				return nil, fmt.Errorf("getting symref size: %w", err)
			}

			reference.Target = git.ReferenceName(src[idx : idx+size]).String()
			reference.IsSymbolic = true
			idx = idx + size
		}

		prefix = refname

		references = append(references, reference)
	}

	return references, nil
}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}
