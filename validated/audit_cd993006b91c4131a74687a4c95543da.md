`noiseutil/chachapoly.go` (containing `NewCipherStateChaChaPoly`, `EncryptDanger`, `DecryptDanger`) has no `//go:build` constraints at all — it is compiled identically regardless of the `boringcrypto` build tag [1](#0-0) . The only files in `noiseutil` that are build-tag gated for boringcrypto are `boring.go` and `notboring.go`, and both only affect `CipherAESGCM` (the AES-GCM path via `NewGCMTLS`/`aeadCipher`), never ChaCha20-Poly1305 [2](#0-1) [3](#0-2) . The dispatcher `NewCipherState` routes to `NewCipherStateAESGCM` or `NewCipherStateChaChaPoly` based on cipher name, but the ChaChaPoly branch is the single unconditional implementation in both build modes [4](#0-3) .

Since there is no boringcrypto-specific code path for ChaChaPoly, there is no possibility of divergent acceptance behavior at a rekey/nonce boundary between the two build tags — both builds execute the exact same `NewCipherStateChaChaPoly`, `EncryptDanger`, and `DecryptDanger` functions. The premise of the question (that boringcrypto vs stdlib builds handle ChaChaPoly key rotation differently) does not hold in this codebase.

// CipherStateChaChaPoly is the data-plane wrapper for the ChaCha20-Poly1305 AEAD cipher.
// ChaCha20-Poly1305 uses little-endian nonce encoding per the Noise spec.
type CipherStateChaChaPoly struct {
	c cipher.AEAD
}

// NewCipherStateChaChaPoly extracts the underlying AEAD from the post-handshake noise.CipherState.
// The caller is responsible for ensuring the noise cipher is actually ChaCha20-Poly1305.
func NewCipherStateChaChaPoly(s *noise.CipherState) *CipherStateChaChaPoly {
	return &CipherStateChaChaPoly{c: s.Cipher().(cipher.AEAD)}
}

// NewCipherState wraps the post-handshake noise.CipherState in the per-cipher type that matches cipherFunc.
// cipherFunc must be the same cipher used to build the noise CipherSuite that produced s.
func NewCipherState(s *noise.CipherState, cipherFunc noise.CipherFunc) CipherState {
	switch cipherFunc.CipherName() {
	case CipherAESGCM.CipherName():
		return NewCipherStateAESGCM(s)
	case noise.CipherChaChaPoly.CipherName():
		return NewCipherStateChaChaPoly(s)
	default:
		panic(fmt.Sprintf("noiseutil: unsupported cipher %q", cipherFunc.CipherName()))
	}
