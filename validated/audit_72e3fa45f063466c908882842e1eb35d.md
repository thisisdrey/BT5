### Title
Unbounded reference-name path depth inflates conflict-tree clone/walk cost on every transaction - ([File: internal/gitaly/storage/storagemgr/partition/conflict/refdb/tree.go])

### Summary
`git.ValidateReference` never bounds the number of `/`-separated path components (or overall length) of a reference name [1](#0-0) . That name is used as the key to walk and mutate a per-repository conflict-detection tree (`refdb.node`) whose depth equals the number of path components in the reference [2](#0-1) . Every new transaction calls `History.Begin()`, which deep-clones the *entire* current tree via `node.clone()` before applying its own updates [3](#0-2) [4](#0-3) . This mirrors the reported bug class: a user-controlled key (here, a reference name) determines the depth/size of a tree structure that must be walked on every verification, letting an ordinary user drive up the resource cost paid by unrelated, subsequent operations.

### Finding Description
- `ValidateReference` checks character-level rules (no HEAD, must start with `refs/`, no `..`, no `@{`, forbidden characters, `.lock` suffix, leading dot, trailing slash/dot) but performs **no check on the number of path components or total length** [1](#0-0) .
- Reference names reach the conflict tree via `Transaction.ApplyUpdates` → `node.applyUpdates` → `node.applyUpdate`, which walks/creates one tree node per `/`-delimited path segment of the reference name [5](#0-4) [2](#0-1) .
- `History.Begin()` is invoked once per new transaction and performs `h.root.clone()`, a full recursive copy of the entire node tree (not just the path touched by that transaction) [6](#0-5) [4](#0-3) .
- Because the same in-memory `History.root` is shared and cloned for every concurrently-started transaction against the same repository partition until `Evict()` removes obsolete LSNs [7](#0-6) , a single malicious reference with an artificially large number of path segments (e.g. `refs/heads/a/a/a/.../a` repeated thousands of times, up to the gRPC message-size limit) inflates the tree that *every other concurrent transaction* on that repository must clone and walk — not just the transaction that created the reference.
- This is the same bug pattern as the external report: an attacker-chosen key (there: account/storage-slot hash bits; here: reference-name path segments) determines the depth of a tree that a verification routine (there: `walkTree`; here: `node.clone`/`applyUpdate`) must traverse, inflating per-operation cost without violating any hard limit.

### Impact Explanation
This does not break correctness or provide any data/access escape — it purely increases CPU/allocation cost of `History.Begin()` and `applyUpdate()`/`evict()` for every transaction on the affected repository/partition for as long as the malicious reference (or its history entry) remains un-evicted. Since Gitaly's transaction manager serializes reference verification through this shared, mutable in-memory structure, an attacker who can push/create references (an ordinary write RPC such as `UpdateReferences`/branch creation) can degrade throughput for concurrent legitimate transactions on the same repository, analogous to the reported "increased gas cost of verification" — a resource-cost amplification rather than a hard DoS, since Git enforces its own overall reference-name length ceiling and clones remain proportional to (bounded) tree size.

### Likelihood Explanation
Reachable directly from an ordinary user's write path (any RPC that stages `git.ReferenceUpdates`, e.g. branch/tag creation via `UserCreateBranch`, `UpdateReferences`, hooks-driven reference transactions) with no special privileges required — only the ability to push/create a reference with a deeply-nested name, which is not currently rejected by `ValidateReference`. The magnitude of the effect depends on how many extra path segments can be crammed into a single reference name before gRPC message-size or Git's own internal limits are hit, which was not independently verified in this pass.

### Recommendation
Add an explicit bound in `git.ValidateReference` (or at the RPC layer before staging `ReferenceUpdates`) on the number of `/`-separated components and/or total byte length of a reference name, consistent with practical Git usage, to prevent the conflict-tree depth (and therefore `clone()`/`applyUpdate()`/`evict()` cost) from being inflated by adversarial input. Additionally, consider avoiding full-tree `clone()` in `History.Begin()` in favor of a copy-on-write/path-copying scheme so that transaction cost scales with the paths actually touched rather than the size of the entire historical tree.

### Proof of Concept
Conceptual (not executed against a live instance):
1. An authenticated ordinary user issues `UpdateReferences` (or an equivalent branch-creation RPC) with a reference name such as `refs/heads/` followed by thousands of single-character segments joined by `/` (e.g., `a/a/a/.../a`), staying under the gRPC message-size limit and passing `ValidateReference` since no depth/length check exists [1](#0-0) .
2. This reference is applied to `History.root` via `node.applyUpdate`, creating one node per path segment [2](#0-1) .
3. Every subsequent transaction started against the same repository partition calls `History.Begin()`, which performs `h.root.clone()`, recursively duplicating the now-inflated tree [6](#0-5) [4](#0-3) , incurring cost proportional to the number of nodes the attacker introduced, until the LSN that created the reference is evicted.

func ValidateReference(name string) error {
	if name == "HEAD" {
		return fmt.Errorf("HEAD reference not allowed")
	}

	// TODO: this can eventually be converted to use `strings.CutPrefix()`.
	if !strings.HasPrefix(name, "refs/") {
		return fmt.Errorf("reference is not fully qualified")
	}
	name = name[len("refs/"):]

	if len(name) == 0 {
		return fmt.Errorf("refs/ is not a valid reference")
	}

	if strings.HasSuffix(name, "/") {
		return fmt.Errorf("reference must not end with slash")
	}

	if strings.HasSuffix(name, ".") {
		return fmt.Errorf("reference must not end with dot")
	}

	if strings.Contains(name, "@{") {
		return fmt.Errorf("reference must not contain @{")
	}

	if strings.Contains(name, "..") {
		return fmt.Errorf("reference must not contain double dots")
	}

	for _, c := range name {
		switch c {
		case ' ', '\t', '\n':
			return fmt.Errorf("reference must not contain space characters")
		case ':', '?', '[', '\\', '^', '~', '*', '\177':
			return fmt.Errorf("reference must not contain special characters")
		}

		// Note that we treat some of the characters below 32 specially in the switch above so
		// that we can report back more precise error messages.
		if c < 32 {
			return fmt.Errorf("reference must not contain control characters")
		}
	}

	// We need to check the components individually as components aren't allowed to have some specific constructs.
	for {
		component, tail, _ := strings.Cut(name, "/")

		if component == "" {
			if tail != "" {
				return fmt.Errorf("empty component is not allowed")
			}

			// Otherwise, if both component and tail are empty, we have fully verified the complete
			// reference and can thus return successfully.
			return nil
		}

		if strings.HasPrefix(component, ".") {
			return fmt.Errorf("component must not start with dot")
		}

		if strings.HasSuffix(component, ".lock") {
			return fmt.Errorf("component must not end with .lock")
		}

		name = tail
	}

// clone returns a deep copy of the node.
func (n *node) clone() *node {
	children := make(children, len(n.children))
	for key, child := range n.children {
		children[key] = child.clone()
	}

	return &node{
		target:          n.target,
		childReferences: n.childReferences,
		children:        children,
	}
}

func (n *node) applyUpdate(zeroOID git.ObjectID, ref git.ReferenceName, update git.ReferenceUpdate) error {
	var (
		refPrefix   string
		refBase     = ref.String()
		parentNodes []*node
		node        = n
	)

	// Walk down the tree until we find the node of the reference.
	for {
		prefix, suffix, foundSeparator := strings.Cut(refBase, "/")
		if !foundSeparator {
			// If there was no separator, then it means the current node
			// is the parent node of the reference that is modified.
			//
			// Get the target node of the reference write.
			targetNode := node.children[refBase]
			if targetNode == nil {
				// The target node didn't exist yet so create it.
				targetNode = newNode()
				node.children[refBase] = targetNode
			}

			parentNodes = append(parentNodes, node)
			node = targetNode
			break
		}

		// Since there was a separator, we still need to walk down the tree
		// to find parent node.
		child := node.children[prefix]
		if child == nil {
			// Child node didn't exist. Create it so we can walk it further down.
			child = newNode()
			node.children[prefix] = child
		}

		currentRef := filepath.Join(refPrefix, prefix)
		if child.isReference(zeroOID) {
			// We can only create a reference if none of its parents already exist.
			// Doing so would lead to a directory-file conflict with loose references.
			//
			// reftable format would support storing both `refs/heads/main` and
			// `refs/heads/main/child` but prevents this for consistency with the files
			// backend.
			return NewParentReferenceExistsError(git.ReferenceName(currentRef), ref)
		}

		parentNodes = append(parentNodes, node)
		node = child
		refPrefix = currentRef
		refBase = suffix

	}

// History tracks the last LSN that modified each reference. The nodes are cleaned up when Evict()
// is called to drop changes related to a certain LSN. The transaction manager evicts LSNs when it
// no longer needs to keep them around to conflict check. This occurs when there are no writes reading
// snapshots at or below a given LSN.
//
// The LSN that last wrote to a reference is tracked in two maps. referenceByLSN is used by Evict()
// to determine which references were last updated by the LSN that is being evicted. lsnByReference
// is reverse index and keeps track of the last LSN that updated a given reference. This is used
// to keep referenceByLSN up to date when applying updates by removing the updated references from the
// map of the LSN that previously updated it.
type History struct {
	zeroOID         git.ObjectID
	root            *node
	referencesByLSN map[storage.LSN]map[git.ReferenceName]struct{}
	lsnByReference  map[git.ReferenceName]storage.LSN
}

// NewHistory returns a new History.
func NewHistory(zeroOID git.ObjectID) *History {
	return &History{
		zeroOID:         zeroOID,
		root:            newNode(),
		referencesByLSN: map[storage.LSN]map[git.ReferenceName]struct{}{},
		lsnByReference:  map[git.ReferenceName]storage.LSN{},
	}
}

// Begin begins a new transaction for applying changes to the History.
// The changes are persisted once Commit() is called. If the changes
// should not be persisted, the transaction can be discarded.
func (h *History) Begin() *Transaction {
	return &Transaction{
		history:            h,
		root:               h.root.clone(),
		modifiedReferences: map[git.ReferenceName]struct{}{},
	}
}

// Evict drops all changes related to the given LSN.
func (h *History) Evict(lsn storage.LSN) {
	refs := h.referencesByLSN[lsn]
	// We're dropping the LSN and the associated reference
	// updates, so drop them from the indexes as well.
	delete(h.referencesByLSN, lsn)
	for ref := range refs {
		delete(h.lsnByReference, ref)
	}

	h.root.evict(h.zeroOID, refs)
}
