Tracing the exact mechanics disproves the premised equality:

- `cur_reward_cycle` (returned by `reward_cycle()`) only advances via `next_reward_cycle()`, which is called **exclusively** inside `getnakamotoinv_try_finish()` on the `StacksMessageType::NakamotoInv` branch — i.e., only after a genuine, truthful `NakamotoInv` reply is merged via `merge_tenure_inv()`. [1](#0-0) 

- On a `Nack` with `NoSuchBurnchainBlock`, `next_reward_cycle()` is **not** called and `cur_reward_cycle` does not move; the peer stays `online` and its cursor remains pinned at the cycle it refused to answer. [2](#0-1) 

- `getnakamotoinv_begin()`'s "fully sync'ed" early return only fires when `self.reward_cycle() > max_reward_cycle`, which by construction can only happen *after* the peer has already truthfully answered for reward cycle `max_reward_cycle` (since `merge_tenure_inv` stores data for `self.reward_cycle()` *before* it is incremented past `max_reward_cycle`). [3](#0-2) [4](#0-3) 

- Conversely, if the peer NACKs the live cycle itself (`cur_reward_cycle == max_reward_cycle`), `reward_cycle() > max_reward_cycle` is false, so `getnakamotoinv_begin()` returns `true` and the node keeps re-requesting that exact cycle on every subsequent tick (bounded only by in-flight checks), never silently skipping it.

        &mut self,
        network: &mut PeerNetwork,
        reply: StacksMessage,
    ) -> Result<bool, NetError> {
        match reply.payload {
            StacksMessageType::NakamotoInv(inv_data) => {
                debug!(
                    "{:?}: got NakamotoInv from {:?}: {:?}",
                    network.get_local_peer(),
                    &self.neighbor_address,
                    &inv_data
                );

                let ret = self.merge_tenure_inv(inv_data.tenures, self.reward_cycle());
                self.next_reward_cycle();
                return Ok(ret);
            }
            StacksMessageType::Nack(nack_data) => {
                info!("{:?}: remote peer NACKed our GetNakamotoInv", network.get_local_peer();
                      "remote_peer" => %self.neighbor_address,
                      "error_code" => nack_data.error_code);

                if nack_data.error_code != NackErrorCodes::NoSuchBurnchainBlock {
                    // any other error besides this one is a problem
                    self.set_online(false);
                }
                return Ok(false);
            }
