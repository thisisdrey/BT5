## Title
Unauthenticated `/shutdown` HTTP endpoint permanently kills the signer's event receiver - ([File: libsigner/src/events.rs])

## Summary
The `SignerEventReceiver::next_event` handler in `libsigner/src/events.rs` matches any incoming HTTP request to `/shutdown` and immediately sets the `stop_signal` atomic bool and returns `Err(EventError::Terminated)`, with no check of the caller's identity, source, or any shared secret. Any TCP client that can reach the signer's event-receiver bind address can send this raw HTTP POST and permanently stop the signer's event loop.

## Finding Description
The claimed equality/fault is real: the code only checks `request.url() == "/shutdown"` and `request.method() == Post`; it does not verify the sender is the local `SignerStopSignaler` (which is only reachable via the loopback-style `TcpStream::connect(self.local_addr)` call in `SignerStopSignaler::send`, `libsigner/src/events.rs:376-396`). The handler itself:
```
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
}
``` [1](#0-0) 
This is reached unconditionally for any request whose URL is `/shutdown`, and `main_loop` treats `Err(EventError::Terminated)` as a clean exit, breaking the loop for good: [2](#0-1) 
Once `stop_signal` is `true`, `is_stopped()` returns `true` forever (no reset path exists), so all subsequent `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block` events from the legitimate node are dropped.

Whether this is remotely reachable by an unprivileged attacker depends entirely on operator configuration of the `endpoint` value bound in `SignerEventReceiver::bind` (called from `stacks-signer/src/lib.rs:138`, using `config.endpoint`). The codebase does not itself provide any network-layer restriction (no auth token, no allow-list, no TLS/mTLS) on this listener — it's purely an HTTP server that accepts any TCP connection reaching the bound address. The code explicitly warns operators about this at startup: [3](#0-2) 
This warning acknowledges the risk but is not an enforced control — if an operator binds this endpoint to a non-loopback address (a documented, non-default but supported configuration, e.g., for a "local or subnet network"), any remote party on that subnet/network with mere TCP connectivity can send this shutdown request. No signature, secret, or peer identity is checked anywhere in `next_event`.

## Impact Explanation
A single crafted `POST /shutdown` HTTP request permanently disables the signer's event receiver thread, causing it to stop processing StackerDB chunks, burn-block events, and block-validation responses indefinitely (until process restart). This matches the "Critical - remote crash/unauthenticated DoS from few messages" category, since one message from an unauthenticated party halts a security-critical component of signer operation.

## Likelihood Explanation
The precondition is that the signer's event-receiver bind address is reachable by the attacker's network position — this is explicitly a supported (if discouraged) configuration per the in-code warning about "communicating with an external node." Where the bind address is loopback-only (the documented recommended default), this is not remotely exploitable by an unprivileged network attacker per the threat model (no local access). Where it is bound more broadly, the attack requires no credentials, no valid peer key, and is trivially repeatable at zero cost — a single raw TCP write.

## Recommendation
Add authentication/authorization to the `/shutdown` (and ideally all) endpoints in `SignerEventReceiver::next_event` — e.g., require a shared secret/token known only to the local node and signer, verify the request originates from `127.0.0.1`/the configured node peer, or remove the HTTP-triggered shutdown mechanism entirely in favor of a purely in-process/local-socket signal (e.g., a Unix domain socket only accessible locally, or the existing `Arc<AtomicBool>` triggered directly rather than via network round-trip).

        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)

                Err(EventError::Terminated)
