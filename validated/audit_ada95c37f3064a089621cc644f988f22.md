### Title
`TokenDiff::token_fee` waives fees per-intent for `TokenId::Imt` amounts ≤ 1, letting a signer split a large `imt` transfer into unit-sized `TokenDiff` intents inside one `execute_intents` call to collect zero aggregate protocol fee - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::execute_intent` computes and collects the protocol fee independently for every single `TokenDiff` intent, using `TokenDiff::token_fee`, which explicitly returns `Pips::ZERO` for `TokenIdType::Imt` (and `Nep171`/`Nep245`) whenever the intent's own `|delta| <= 1`. Because `DefuseIntents::execute_intent` and `Engine::execute_signed_intents` iterate and fee every intent independently with no accounting of the aggregate volume moved by the signer across the whole call, an attacker can replace one `TokenDiff{imt:-1000,...}` (which would owe `fee_ceil(1000, protocol_fee)`) with 1000 `TokenDiff{imt:-1,...}` intents, each paying `0`, while moving the identical aggregate `imt` volume in one atomic `execute_intents` transaction.

### Finding Description
The claimed broken binding: `total_fee_owed(aggregate_imt_volume_in_one_call) == sum(per_intent_fee_collected)`. Tracing the code:

- `TokenDiff::execute_intent` computes, per intent, `let fee = Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount);` and adds it to a local `fees_collected` that is credited to the fee collector at the end of *that single intent's* execution [1](#0-0) .
- `TokenDiff::token_fee` returns `Pips::ZERO` for `TokenIdType::Imt` (grouped with `Nep171`/`Nep245`) whenever `amount <= 1`, and only applies the nonzero `fee` when `amount > 1` [2](#0-1) .
- `DefuseIntents::execute_intent` simply loops `for intent in self.intents { intent.execute_intent(...)? }`, with no cross-intent aggregation of deltas per token/signer before fee calculation [3](#0-2) .
- `Engine::execute_signed_intents` iterates over the `Vec<MultiPayload>` and calls `execute_signed_intent` for each, which in turn calls `intents.execute_intent(...)` for the single signer's `DefuseIntents` — again with no aggregate fee tracking across intents or across payloads in the same call [4](#0-3) .
- The only cross-cutting invariant enforced is a **balance** invariant, not a fee invariant: `Deltas::finalize` / `TransferMatcher::finalize` require that, summed over the *entire* `execute_signed_intents` call (potentially many `MultiPayload`s), every token's deltas net to zero, otherwise `InvariantViolated::UnmatchedDeltas` is returned [5](#0-4) . This invariant checks only that debits equal credits per token across the whole transaction; it does not check or correct for fees, so it does not prevent fee-splitting.

Exploit flow: the attacker (as taker) signs one `MultiPayload` whose `DefuseIntents.message.intents` is `Vec<TokenDiff>` of length N, each `TokenDiff{diff:{imt:-1, other_token:+k}}`, matched (within the same `execute_intents` call, i.e. same NEAR transaction) against one or more counterparty `MultiPayload`s (e.g., a market maker or a colluding second account) that supply the offsetting `+imt`/`-other_token` legs so the global per-token invariant nets to zero. Each of the N `TokenDiff` intents independently evaluates `token_fee(imt, amount=1, fee)` → `Pips::ZERO`, so `fees_collected` for every intent is `0`, and the fee collector receives nothing, whereas a single `TokenDiff{imt:-1000,...}` moving the same aggregate volume would have paid `fee_ceil(1000, protocol_fee)` (nonzero for any `protocol_fee > 0`). No existing guard (`MultiPayload::verify`, nonce checks, `Lock`, `TransferMatcher::finalize`) checks or aggregates fees across intents/payloads — they only validate signatures, nonces, and net-zero token balances.

### Impact Explanation
This is a systematic protocol fee bypass: the fee collector's balance under-accrues by exactly the fee that would be owed on the aggregate `imt` (and, by the same logic, `Nep171`/`Nep245`) volume moved by a signer, while the full economic value of the trade still transfers between the counterparties inside one atomic transaction. This matches the explicitly listed Critical impact category "protocol fees bypassed or over-collected." It is repeatable by any unprivileged account pair for any `Imt`/`Nep245` token and any volume, limited only by how many `TokenDiff` intents can be packed into one transaction under the NEAR gas limit.

### Likelihood Explanation
- Requires only unprivileged capabilities already granted to any caller: constructing and signing a `MultiPayload`, and finding/being a counterparty willing to trade (which can be the attacker's own second account, i.e. wash trading, for a pure fee-avoidance benefit with no real counterparty risk).
- No special role, relayer key, or DAO permission needed.
- Practical N is bounded by NEAR's per-transaction gas limit (attached gas budget) but is a feasibility parameter, not a blocker of the underlying design flaw — the same bypass is exploitable across multiple transactions/execute_intents calls too, and it is reachable within one call for realistic N.
- Any protocol fee (`Pips > 0`) configured on `Imt`/`Nep245` diffs is bypassable this way, so likelihood is high wherever such fees are non-zero.

### Recommendation
Aggregate deltas per `(signer_id, token_id)` across all `TokenDiff` intents within a `DefuseIntents` message (and, if feasible, across the whole `execute_signed_intents` call) before applying the `amount <= 1` fee-waiver threshold in `TokenDiff::token_fee`, so the fee is computed on the true aggregate volume rather than per-intent. Alternatively, remove/rework the `amount <= 1` waiver for divisible/fungible-like `Imt`/`Nep245` tokens, restricting the zero-fee exemption strictly to intrinsically atomic NFT transfers (`Nep171`, or true single-unit `Nep245`/`Imt` tokens that cannot represent fungible volume).

### Proof of Concept
`near-workspaces`/unit test plan:
1. Set up a `Defuse` contract with `protocol_fee = Pips::ONE_PERCENT` (or any nonzero fee) and a fee collector account.
2. Register an `ImtTokenId` and mint/credit `1000` units to account `A`, and `1000` units of a second token to account `B`.
3. Build one signed `MultiPayload` for `A` containing `DefuseIntents.message.intents = vec![TokenDiff{diff:{imt:-1, token2:+1}}; 1000]`.
4. Build a matching signed `MultiPayload` for `B` containing the offsetting `TokenDiff{diff:{imt:+1, token2:-1}}; 1000]` (or a single aggregated counter-offer) so per-token deltas net to zero.
5. Call `execute_intents(vec![A_payload, B_payload])` in one call; assert success (no `InvariantViolated`).
6. Assert `fee_collector` balance for `imt` == `0` after the call.
7. As comparison, execute a single `TokenDiff{diff:{imt:-1000, token2:+1000}}` for `A` matched against a single offsetting `TokenDiff` for `B` in another test, and assert `fee_collector` balance for `imt` == `fee_ceil(1000, protocol_fee) > 0`.
8. Assert the two fee totals differ (`0 != fee_ceil(1000, protocol_fee)`) despite identical aggregate `imt` volume moved, confirming the binding `total_fee_owed == sum(per-intent fees collected)` is broken.

    pub fn execute_signed_intents(
        mut self,
        signed: impl IntoIterator<Item = MultiPayload>,
    ) -> Result<Transfers> {
        for signed in signed {
            self.execute_signed_intent(signed)?;
        }
        self.finalize()
    }

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
