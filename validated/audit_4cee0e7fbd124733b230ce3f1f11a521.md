CreateRepositoryFromSnapshot is a documented "trusted a lot" endpoint that extracts an attacker-influenced tar archive directly on top of a freshly-initialized bare repository, and the sibling `extractSnapshot`/`extractTarToDirectory` path used by `ReplicateRepository` does the same from a remote Gitaly's `GetSnapshot` stream. If the reference backend is reftables, an extracted archive can plant a crafted `reftable/tables.list` and `.ref` file directly into the repository, which will later be parsed by `reftable.Table.GetReferences()` / `parseRefBlock()` / `getRefsFromBlock()` in `internal/git/reftable/reftable.go`.

### Title
Out-of-bounds slice access when parsing crafted reftable blocks - (File: internal/git/reftable/reftable.go)

### Summary
`Table.getRefsFromBlock`, `parseRefBlock`, `extractBlockLen`, and `getVarInt` in `internal/git/reftable/reftable.go` compute byte offsets from length/size fields taken directly from the table file content and slice the in-memory buffer using those offsets without validating them against the buffer's actual length, mirroring the `LibBytes.sol#keccak` bug of using `offset`/`length` without checking `offset + length <= data.length`.

### Finding Description
`GetReferences()` reads the whole reftable file into `src` and, for each block, calls `parseRefBlock` and `getRefsFromBlock`: [1](#0-0) 
`extractBlockLen` slices `src[blockStart+1 : blockStart+4]` and `parseRefBlock` computes `RestartStart` and reads a restart count from `src[blockStart+currentBS-2:]`, all derived from attacker-controlled `currentBS`/`RestartCount` values with no bounds check against `len(src)`: [2](#0-1) [3](#0-2) 
Inside `getRefsFromBlock`, `prefixLength`/`suffixLength`/hash sizes/symref sizes are read via `getVarInt` and used to slice `src[idx:idx+suffixLength]`, `src[idx:idx+hashSize]`, and `src[idx:idx+size]` without verifying `idx+length <= len(src)` (or even `<= b.RestartStart`/`b.FullBlockSize`): [4](#0-3) 
Because Go performs runtime bounds checking on slices, an out-of-range index here does not leak memory (unlike the Solidity `keccak256` case) but instead triggers a `panic: runtime error: slice bounds out of range`, crashing the goroutine/process handling the request.

### Impact Explanation
An attacker able to influence the contents of a repository's `reftable/` directory before it is read — e.g., via `CreateRepositoryFromSnapshot`'s tar extraction (explicitly marked "trusted a lot... should undergo a lot of hardening") at `internal/gitaly/service/repository/create_repository_from_snapshot.go:123-149`, or via `ReplicateRepository`'s `extractSnapshot`/`extractTarToDirectory` at `internal/gitaly/service/repository/replicate.go:264-406` — can plant a malformed `.ref` table file. Any subsequent call to `ParseTable`/`GetReferences` (used for reference reads, `RepositoryInfo`, WAL `stageTables` resequencing, etc.) will read attacker-crafted offsets and can panic, causing a denial of service of the Gitaly RPC handler (and, depending on recovery middleware, potentially the whole process/goroutine group).

### Likelihood Explanation
Moderate to high in a reftable-backend deployment: `CreateRepositoryFromSnapshot` is explicitly documented as trusting the incoming archive without hardening, and no code path validates the extracted reftable byte layout before repositories parse it. `ParseTable` does check header/footer magic and a checksum, but the per-block bounds derived from `currentBS`, `RestartCount`, `prefixLength`/`suffixLength`/`size` inside `getRefsFromBlock` are unchecked against `len(src)`.

### Recommendation
Add explicit bounds validation before every slice operation in `internal/git/reftable/reftable.go` that derives offsets/lengths from file content:
- In `extractBlockLen`, verify `blockStart+4 <= len(src)`.
- In `parseRefBlock`, verify `blockStart+currentBS <= len(src)` and `RestartStart` stays within `[0, blockStart+currentBS)`.
- In `getRefsFromBlock`, after each `getVarInt` call, verify `idx+suffixLength`, `idx+hashSize`, and `idx+size` do not exceed `len(src)` (and ideally `b.RestartStart`/`b.FullBlockSize`) before slicing, returning a parse error instead of panicking.

### Proof of Concept
1. Enable the reftable reference backend.
2. Craft a repository archive whose `reftable/<name>.ref` file has a valid header/footer/CRC32 (so `ParseTable` succeeds) but contains a ref block with an inflated `suffixLength`, `RestartCount`, or symref `size` field that, when added to `idx`, exceeds the actual file length.
3. Submit this archive via `CreateRepositoryFromSnapshot` (or as the source of `ReplicateRepository`).
4. Any operation that calls `Table.GetReferences()` on this table (e.g. `RepositoryInfo`, ref listing, WAL table resequencing) triggers `src[idx:idx+suffixLength]` (or similar) out of range and panics, crashing the handling goroutine/request.

Note: I was unable to fully verify runtime panic-recovery behavior (whether Gitaly's gRPC interceptors gracefully recover such panics into an error response versus crashing the process) within available context; this would need to be confirmed to fully assess whether impact is limited to the failing RPC or affects overall server availability.

func (t *Table) getVarInt(src []byte, start uint, blockEnd uint) (uint, uint, error) {
	var val uint

	val = uint(src[start]) & 0x7f

	for (uint(src[start]) & 0x80) > 0 {
		start++
		if start > blockEnd {
			return 0, 0, fmt.Errorf("exceeded block length")
		}

		val = ((val + 1) << 7) | (uint(src[start]) & 0x7f)
	}

	return start + 1, val, nil
}

// getRefsFromBlock provides the ref udpates from a reference block.
func (t *Table) getRefsFromBlock(src []byte, b *block) ([]git.Reference, error) {
	var references []git.Reference

	prefix := ""

	// Skip the block_type and block_len
	idx := b.BlockStart + 4

	for idx < b.RestartStart {
		var prefixLength, suffixLength, updateIndexDelta uint
		var err error

		idx, prefixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting prefix length: %w", err)
		}

		idx, suffixLength, err = t.getVarInt(src, idx, b.RestartStart)
		if err != nil {
			return nil, fmt.Errorf("getting suffix length: %w", err)
		}

		extra := (suffixLength & 0x7)
		suffixLength >>= 3

		refname := prefix[:prefixLength] + string(src[idx:idx+suffixLength])
		idx = idx + suffixLength

		idx, updateIndexDelta, err = t.getVarInt(src, idx, b.FullBlockSize)
		if err != nil {
			return nil, fmt.Errorf("getting update index delta: %w", err)
		}
		// we don't use this for now
		_ = updateIndexDelta

		reference := git.Reference{
			Name: git.ReferenceName(refname),
		}

		switch extra {
		case 0:
			// Deletion, no value
			reference.Target = t.shaFormat().ZeroOID.String()
		case 1:
			// Regular reference
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)
		case 2:
			// Peeled Tag
			hashSize := t.shaFormat().Hash().Size()
			reference.Target = git.ObjectID(hex.EncodeToString(src[idx : idx+uint(hashSize)])).String()

			idx += uint(hashSize)

			// For now we don't need the peeledOID, but we still need
			// to skip the index.
			// peeledOID := ObjectID(bytesToHex(t.src[idx : idx+uint(hashSize)]))
			idx += uint(hashSize)
		case 3:
			// Symref
			var size uint
			idx, size, err = t.getVarInt(src, idx, b.FullBlockSize)
			if err != nil {
				return nil, fmt.Errorf("getting symref size: %w", err)
			}

			reference.Target = git.ReferenceName(src[idx : idx+size]).String()
			reference.IsSymbolic = true
			idx = idx + size
		}

		prefix = refname

		references = append(references, reference)
	}

// parseRefBlock parses a block and if it is a ref block, provides
// all the reference updates.
func (t *Table) parseRefBlock(src []byte, headerOffset, blockStart, blockEnd uint) ([]git.Reference, error) {
	currentBS := t.extractBlockLen(src, blockStart+headerOffset)

	fullBlockSize := t.blockSize
	if fullBlockSize == 0 {
		fullBlockSize = currentBS
	} else if currentBS < fullBlockSize && currentBS < (blockEnd-blockStart) && src[blockStart+currentBS] != 0 {
		fullBlockSize = currentBS
	}

	b := &block{
		BlockStart:    blockStart + headerOffset,
		FullBlockSize: fullBlockSize,
	}

	if err := binary.Read(bytes.NewBuffer(src[blockStart+currentBS-2:]), binary.BigEndian, &b.RestartCount); err != nil {
		return nil, fmt.Errorf("reading restart count: %w", err)
	}

	b.RestartStart = blockStart + currentBS - 2 - 3*uint(b.RestartCount)

	return t.getRefsFromBlock(src, b)
}
