### Title
Unprivileged Caller Can Permanently Freeze Victim's Fungible Asset Store via `migrate_coin_store_to_fungible_store` - (`aptos-move/framework/aptos-framework/sources/coin.move`)

### Summary

`migrate_coin_store_to_fungible_store<CoinType>` is a `public entry fun` that accepts an arbitrary `vector<address>` with **no victim signer requirement**. When a victim holds a frozen `CoinStore` (frozen=true) alongside a pre-existing unfrozen primary FA store, any unprivileged caller can invoke this function on the victim's address, causing `set_frozen_flag_internal` to freeze the victim's FA store — without holding the `TransferRef` that normally gates freeze authority.

### Finding Description

`migrate_coin_store_to_fungible_store` is declared as:

```move
public entry fun migrate_coin_store_to_fungible_store<CoinType>(
    accounts: vector<address>
) acquires CoinStore, CoinConversionMap, CoinInfo {
    accounts.for_each(|account| {
        maybe_convert_to_fungible_store<CoinType>(account);
    });
}
``` [1](#0-0) 

No signer of the victim is required — any account can pass any `address` in the vector.

Inside `maybe_convert_to_fungible_store`, the `CoinStore` is destructured and its `frozen` flag is extracted:

```move
let CoinStore<CoinType> { coin, frozen, deposit_events, withdraw_events } =
    move_from<CoinStore<CoinType>>(account);
``` [2](#0-1) 

Then `ensure_primary_store_exists` is called (creating or fetching the existing FA store), and the frozen flag is propagated:

```move
if (frozen != fungible_asset::is_frozen(store)) {
    fungible_asset::set_frozen_flag_internal(store, frozen);
}
``` [3](#0-2) 

The code comment at lines 707–711 explicitly acknowledges this behavior:

> "if the account owns a frozen CoinStore and an unfrozen primary fungible store, this function would convert and deposit the rest coin into the primary store and **freeze it**" [4](#0-3) 

`set_frozen_flag_internal` in `fungible_asset.move` bypasses the `TransferRef`-gated `set_frozen_flag` path — it directly mutates the `FungibleStore.frozen` field without any capability check: [5](#0-4) 

### Impact Explanation

The victim's primary FA store — which was **unfrozen and fully accessible** before the attack — is now frozen by an unprivileged third party. The victim's FA balance becomes unspendable. Only the `TransferRef` holder (the coin issuer) can unfreeze it; the victim has no self-remedy. This constitutes unauthorized permanent freezing of user-controlled fungible assets by an unprivileged caller.

### Likelihood Explanation

The entry point is a `public entry fun` callable by any account on mainnet. The precondition (frozen `CoinStore` + pre-existing unfrozen FA store) is realistic: a coin issuer may freeze a user's `CoinStore` while the user independently holds FA balance in their primary store (e.g., received via FA transfer). An attacker monitoring on-chain state can identify such accounts and trigger the migration at will.

### Recommendation

Add an authorization check in `migrate_coin_store_to_fungible_store` so that the frozen-flag propagation path either:
- Requires the victim's own signer (like `migrate_to_fungible_store` does), or
- Skips the `set_frozen_flag_internal` call when the FA store already exists and is in a different frozen state (i.e., do not override an existing FA store's frozen state during third-party migration), or
- Only allows the freeze propagation when called by the `TransferRef` holder or the account itself.

### Proof of Concept

1. Coin issuer deploys `MyCoin` and creates a paired FA metadata.
2. Victim receives `MyCoin` into their `CoinStore`; coin issuer freezes victim's `CoinStore` (`frozen=true`).
3. Victim independently receives paired FA tokens into their primary FA store (unfrozen).
4. Attacker (any third party) calls `migrate_coin_store_to_fungible_store<MyCoin>(vector[victim_address])`.
5. `maybe_convert_to_fungible_store` reads `frozen=true`, calls `set_frozen_flag_internal(victim_fa_store, true)`.
6. Assert: `fungible_asset::is_frozen(victim_fa_store) == true` — victim's FA balance is now permanently unspendable by the victim.
