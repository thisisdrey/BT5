### Title
`go build`/`go list` VCS-stamping runs `git status`/`git log` in an untrusted repo, executing attacker-controlled `core.fsmonitor` command - ([File: src/cmd/go/internal/vcs/vcs.go])

### Summary
When `-buildvcs=auto` (the default) is active, `cmd/go` locates the enclosing Git repository via `vcs.FromDir` and calls `gitStatus`, which shells out to `git status --porcelain` and `git -c log.showsignature=false log -1 ...` in that repository's working directory via `Cmd.run1`/`runOutputVerboseOnly`. Because these invocations use the ordinary system `git` binary with the repository's own local `.git/config` honored (no `GIT_CONFIG_NOSYSTEM`, no `-c core.fsmonitor=`, no `--no-optional-locks`), a repository whose `.git/config` sets `core.fsmonitor` to an attacker-chosen command will have that command executed by `git status` the moment a victim runs `go build`, `go install`, or `go list` inside it.

### Finding Description
Attacker input: a malicious Go module/repository containing a `.git/config` with `[core] fsmonitor = <malicious command>`.
Entry point: victim runs `go build`/`go install`/`go list` inside a checkout of this repository.
Path: `load.setBuildInfo` (`src/cmd/go/internal/load/pkg.go:2506+`) calls `vcs.FromDir(base.Cwd(), "")` to detect the repo, then invokes `vcsCmd.Status(vcsCmd, repoDir)`, which for git is `gitStatus` (`src/cmd/go/internal/vcs/vcs.go:230-257`). `gitStatus` calls `vcsGit.runOutputVerboseOnly(rootDir, "status --porcelain")`, which lands in `Cmd.run1` (`src/cmd/go/internal/vcs/vcs.go:409-448`).
Failed check: `run1` constructs `exec.Command(v.Cmd, args...)` with `cmd.Dir = dir` and no config sandboxing whatsoever — there is no equivalent to the `runGitAuth` defense in `gitauth.go` (which explicitly guards against "config-injection attacks," see `src/cmd/go/internal/auth/gitauth.go:40-44`) applied here.
Sink: the real `git` binary executes `git status --porcelain` in the repo directory; git's own config-processing honors `core.fsmonitor` in that repo's `.git/config` and executes it as a subprocess with the victim's full environment (including any provider credentials/environment the `go` process has).

### Impact Explanation
Arbitrary command execution in the victim's environment merely by running a normal `go build`/`go list` inside a downloaded/cloned malicious repository — this is the same class of impact as the reported Hermes Agent CVE (RCE via `core.fsmonitor` triggered by an innocuous `git status`), but here the trigger is Go's own automatic VCS-stamping feature, which runs by default (`buildvcs=auto`) without any explicit user action beyond building the code. This would be a PUBLIC/URGENT-track concern for the Go security team.

### Likelihood Explanation
Victim workflow: cloning a third-party repository (e.g., via `git clone` outside of module-proxy flow, or `go get`/`GOPATH` checkouts) and then running any `go build`, `go install`, or `go list` inside its directory — an extremely common developer action requiring no special privileges from the attacker beyond publishing a booby-trapped repo.

### Recommendation
Isolate the VCS-status subprocess from repository-controlled config that can trigger side effects: run git status/log with `GIT_CONFIG_NOSYSTEM=1`, explicit `-c core.fsmonitor=`, `-c core.hooksPath=/dev/null`, and `--no-optional-locks`, or otherwise sandbox the invoked `git` calls used purely for status/stamping so that they cannot execute repository-supplied config commands.

func gitStatus(vcsGit *Cmd, rootDir string) (Status, error) {
	out, err := vcsGit.runOutputVerboseOnly(rootDir, "status --porcelain")
	if err != nil {
		return Status{}, err
	}
	uncommitted := len(out) > 0

	// "git status" works for empty repositories, but "git log" does not.
	// Assume there are no commits in the repo when "git log" fails with
	// uncommitted files and skip tagging revision / committime.
	var rev string
	var commitTime time.Time
	out, err = vcsGit.runOutputVerboseOnly(rootDir, "-c log.showsignature=false log -1 --format=%H:%ct")
	if err != nil && !uncommitted {
		return Status{}, err
	} else if err == nil {
		rev, commitTime, err = parseRevTime(out)
		if err != nil {
			return Status{}, err
		}
	}

	return Status{
		Revision:    rev,
		CommitTime:  commitTime,
		Uncommitted: uncommitted,
	}, nil
}

func (v *Cmd) run1(dir string, cmdline string, keyval []string, verbose bool) ([]byte, error) {
	m := make(map[string]string)
	for i := 0; i < len(keyval); i += 2 {
		m[keyval[i]] = keyval[i+1]
	}
	args := strings.Fields(cmdline)
	for i, arg := range args {
		args[i] = expand(m, arg)
	}

	_, err := pathcache.LookPath(v.Cmd)
	if err != nil {
		fmt.Fprintf(os.Stderr,
			"go: missing %s command. See https://go.dev/s/gogetcmd\n",
			v.Name)
		return nil, err
	}

	cmd := exec.Command(v.Cmd, args...)
	cmd.Dir = dir
	if v.Env != nil {
		cmd.Env = append(cmd.Environ(), v.Env...)
	}
	if cfg.BuildX {
		fmt.Fprintf(os.Stderr, "cd %s\n", dir)
		fmt.Fprintf(os.Stderr, "%s %s\n", v.Cmd, strings.Join(args, " "))
	}
	out, err := cmd.Output()
	if err != nil {
		if verbose || cfg.BuildV {
			fmt.Fprintf(os.Stderr, "# cd %s; %s %s\n", dir, v.Cmd, strings.Join(args, " "))
			if ee, ok := err.(*exec.ExitError); ok && len(ee.Stderr) > 0 {
				os.Stderr.Write(ee.Stderr)
			} else {
				fmt.Fprintln(os.Stderr, err.Error())
			}
		}
	}
	return out, err
}
