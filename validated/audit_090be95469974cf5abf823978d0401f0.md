### Title
Unbounded Shareholder Iteration in `distribute` Permanently Freezes Vested APT — (`aptos-move/framework/aptos-framework/sources/vesting.move`)

---

### Summary

`vesting.move`'s `distribute` entry function iterates over every shareholder in the `grant_pool` with no upper bound on the shareholder count. A vesting contract created with a sufficiently large shareholder list will cause every subsequent `distribute` call to exceed the transaction gas limit and revert, permanently locking all vested and reward APT inside the contract.

---

### Finding Description

`distribute` is a `public entry fun` callable by anyone:

```move
public entry fun distribute(contract_address: address) acquires VestingContract {
    ...
    let grant_pool = &vesting_contract.grant_pool;
    let shareholders = &grant_pool.shareholders();
    shareholders.for_each_ref(|shareholder| {          // ← unbounded loop
        let shareholder = *shareholder;
        let shares = pool_u64::shares(grant_pool, shareholder);
        let amount = pool_u64::shares_to_amount_with_total_coins(...);
        let share_of_coins = coin::extract(&mut coins, amount);
        let recipient_address = get_beneficiary(vesting_contract, shareholder);
        aptos_account::deposit_coins(recipient_address, share_of_coins);
    });
    ...
}
``` [1](#0-0) 

The `grant_pool` is a `pool_u64::Pool` populated at contract creation time from a caller-supplied `vector<address>` of shareholders. There is no `MAXIMUM_SHAREHOLDERS` constant or any other enforced upper bound on the shareholder count in `vesting.move`. [2](#0-1) 

Each loop iteration performs multiple arithmetic operations (`shares`, `shares_to_amount_with_total_coins`, `extract`, `get_beneficiary`, `deposit_coins`), each of which consumes gas. Once the shareholder list is large enough that the cumulative gas exceeds `txn.max_execution_gas` (currently 20,000,000,000 internal gas units), every `distribute` call reverts unconditionally. [3](#0-2) 

**Contrast with `staking_contract.move`:** that module explicitly caps its distribution pool at `MAXIMUM_PENDING_DISTRIBUTIONS = 20`, acknowledging the same risk. [4](#0-3) 

`vesting.move` has no equivalent guard.

---

### Impact Explanation

Once `distribute` is permanently gas-blocked:

- All vested APT and staking rewards accumulated in the contract are frozen inside the resource account.
- `terminate_vesting_contract` calls `distribute` internally before terminating, so it also reverts, preventing admin recovery.
- `admin_withdraw` only works after termination, which is now also blocked.
- Shareholders permanently lose access to their vested APT — a direct, permanent freeze of user-controlled on-chain assets. [5](#0-4) 

---

### Likelihood Explanation

**Medium.** The admin must create a vesting contract with a large shareholder list. This is a legitimate use case (e.g., an organization vesting tokens to hundreds of employees). No malicious intent is required; the admin may simply not be aware of the gas ceiling. The threshold number of shareholders that triggers the failure depends on the gas schedule but is finite and reachable in practice. Once the contract is deployed with too many shareholders, the freeze is permanent and irreversible.

---

### Recommendation

1. **Short term:** Enforce a `MAX_SHAREHOLDERS` constant (analogous to `MAXIMUM_PENDING_DISTRIBUTIONS = 20` in `staking_contract.move`) and assert it in `create_vesting_contract`.
2. **Long term:** Replace the all-at-once loop with a paginated or pull-based distribution model where each shareholder claims their own share individually, eliminating the O(n) gas cost from a single transaction.

---

### Proof of Concept

1. Admin calls `create_vesting_contract` with `N` shareholders (e.g., N = 500) and a valid grant.
2. Stake pool earns rewards; `vest` is called to unlock coins.
3. Anyone calls `distribute(contract_address)`.
4. The VM executes `shareholders.for_each_ref(...)` over all 500 entries, each performing `shares`, `shares_to_amount_with_total_coins`, `coin::extract`, `get_beneficiary`, and `aptos_account::deposit_coins`.
5. Cumulative gas exceeds `max_execution_gas`; the transaction aborts with `EXECUTION_LIMIT_REACHED`.
6. All subsequent `distribute` calls revert identically. Vested APT is permanently frozen. [6](#0-5) [7](#0-6)

    public entry fun distribute(contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        let coins = withdraw_stake(vesting_contract, contract_address);
        let total_distribution_amount = coin::value(&coins);
        if (total_distribution_amount == 0) {
            coin::destroy_zero(coins);
            return
        };

        // Distribute coins to all shareholders in the vesting contract.
        let grant_pool = &vesting_contract.grant_pool;
        let shareholders = &grant_pool.shareholders();
        shareholders.for_each_ref(|shareholder| {
            let shareholder = *shareholder;
            let shares = pool_u64::shares(grant_pool, shareholder);
            let amount = pool_u64::shares_to_amount_with_total_coins(grant_pool, shares, total_distribution_amount);
            let share_of_coins = coin::extract(&mut coins, amount);
            let recipient_address = get_beneficiary(vesting_contract, shareholder);
            aptos_account::deposit_coins(recipient_address, share_of_coins);
        });

        // Send any remaining "dust" (leftover due to rounding error) to the withdrawal address.
        if (coin::value(&coins) > 0) {
            aptos_account::deposit_coins(vesting_contract.withdrawal_address, coins);
        } else {
            coin::destroy_zero(coins);
        };

        emit(
            Distribute {
                admin: vesting_contract.admin,
                vesting_contract_address: contract_address,
                amount: total_distribution_amount,
            },
        );
    }

    public entry fun terminate_vesting_contract(admin: &signer, contract_address: address) acquires VestingContract {
        assert_active_vesting_contract(contract_address);

        // Distribute all withdrawable coins, which should have been from previous rewards withdrawal or vest.
        distribute(contract_address);

        let vesting_contract = borrow_global_mut<VestingContract>(contract_address);
        verify_admin(admin, vesting_contract);
        let (active_stake, _, pending_active_stake, _) = stake::get_stake(vesting_contract.staking.pool_address);
        assert!(pending_active_stake == 0, error::invalid_state(EPENDING_STAKE_FOUND));

        // Unlock all remaining active stake.
        vesting_contract.state = VESTING_POOL_TERMINATED;
        vesting_contract.remaining_grant = 0;
        unlock_stake(vesting_contract, active_stake);
