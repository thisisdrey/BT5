### Title
Unauthenticated `/shutdown` POST permanently halts signer event ingestion (Critical DoS) - (`libsigner/src/events.rs`)

### Summary
`SignerEventReceiver::next_event()`'s `/shutdown` branch sets `stop_signal` to `true` and returns `Err(EventError::Terminated)` for *any* POST to `/shutdown` on the signer's bound HTTP listener, with no check that the caller is the signer's own local `SignerStopSignaler`. Any remote party able to reach the listener socket can send the exact same bytes `SignerStopSignaler::send()` constructs and permanently stop the signer's event loop.

### Finding Description
The intended equality is "the party that stops the event receiver == the signer's own local stop-signaler thread," enforced only by `SignerStopSignaler::send()` constructing a specific `POST /shutdown` request [1](#0-0) . However, the server side does not verify origin, a secret, or any credential — it treats `/shutdown` as a public, unauthenticated command:

```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
}
``` [2](#0-1) 

This is reached unconditionally for any POST with `url() == "/shutdown"` inside `next_event()`, which only gates on HTTP method, not source address, secret header, or token [3](#0-2) . Once `stop_signal` is `true`, `is_stopped()` returns `true` permanently (there is no reset path) [4](#0-3) , and `main_loop()` observes `Err(EventError::Terminated)` and breaks out of its loop for good [5](#0-4) . This ends all further processing of `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` events forwarded from the node — i.e., the signer stops observing block proposals, burn blocks, and StackerDB messages entirely.

### Impact Explanation
A single unauthenticated HTTP POST from any party able to reach the signer's event-listener socket permanently disables that signer's event ingestion pipeline, since `stop_signal` never resets and `main_loop()` exits for good [6](#0-5) . This is a Critical unauthenticated remote DoS against a single signer instance from one crafted message, matching the stated Critical criteria ("remote crash/unauthenticated DoS from few messages"). It does not compromise consensus data integrity or forge state, but it does silence a signer's participation entirely until the process/thread is manually restarted.

### Likelihood Explanation
The only precondition is network reachability to the signer's bound event-listener endpoint (the same socket that the associated stacks-node's event dispatcher posts events to). This endpoint's address is operator-configured (`endpoint` in signer config) and, in deployments where the signer and node are not co-located behind a loopback-only binding, is reachable across the network. No secret, signature, or session token guards this endpoint. Attacker cost is a single raw TCP connection and one crafted HTTP request; the effect (once triggered) is a single-shot, permanent DoS per signer instance — no repetition/rate needed after the first successful send, and repeated sends are harmless once already stopped.

### Recommendation
Remove the network-triggerable `/shutdown` HTTP path entirely, or gate it behind an unguessable per-instance secret/token established out-of-band (e.g., a value only known to the local `SignerStopSignaler`, transmitted via a header checked against a value stored in the receiver, not derivable from the wire format), and additionally restrict acceptance to loopback-originated connections (verify `request.remote_addr()` is loopback) before honoring `/shutdown`. Prefer an in-process/local IPC (e.g., a Unix socket, or a local channel) instead of an HTTP endpoint reachable over the same socket used for node event delivery.

### Proof of Concept
```rust
// libsigner/src/events.rs (test module)
use std::net::{TcpStream, SocketAddr};
use std::io::Write;
use std::thread;

#[test]
fn unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<SomeSignerEventTraitImpl> =
        SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Attacker: independent connection, no stop-signaler ever obtained.
    let mut stream = TcpStream::connect(bound).unwrap();
    let body = "attacker forged shutdown";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\nContent-Type: text/plain\r\n\r\n{}",
        bound, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // The receiver services the request and terminates.
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());

    // Subsequent calls are permanently terminated, with no legitimate
    // get_stop_signaler() ever having been called.
    let result2 = receiver.next_event();
    assert!(matches!(result2, Err(EventError::Terminated)));
}
```
This reproduces the exact assertion path: server-side handling at `libsigner/src/events.rs:443-445` unconditionally sets `stop_signal` and returns `Terminated` for the forged POST, verified via `is_stopped()` and a follow-up `next_event()` call.
