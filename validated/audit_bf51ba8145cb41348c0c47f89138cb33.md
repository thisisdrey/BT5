### Title
Unauthenticated `/wallet/getnodeinfo` HTTP/gRPC endpoint discloses internal peer, machine, and configuration information - (File: `framework/src/main/java/org/tron/core/services/http/GetNodeInfoServlet.java`)

### Summary
The `getnodeinfo` API, reachable via HTTP (`/wallet/getnodeinfo`, `/walletsolidity/getnodeinfo`) and gRPC without any authentication or authorization check, returns a detailed `NodeInfo` payload containing peer IP addresses/ports, node IDs, connection/sync internals, JVM/OS/machine statistics, and node configuration (backup member counts/priority, DB version, participation-rate thresholds, etc.). Any anonymous client on the network can enumerate this information for every reachable full/solidity node, analogous to the OpenAFS CVE-2016-9772 issue where fileserver/RPC responses leaked internal directory and partition information to unauthenticated callers.

### Finding Description
`GetNodeInfoServlet.doGet` calls `NodeInfoService.getNodeInfo()` directly and serializes the entire result with no visibility filtering or authentication, unlike other sensitive endpoints that at least support address-based or visibility-based checks: [1](#0-0) 

`NodeInfoService.setConnectInfo` populates the response with each connected peer's real IP address (`channel.getInetAddress()`), listening port, node ID, disconnect reasons, and sync-queue internals: [2](#0-1) 

`setConfigNodeInfo` and `setMachineInfo` additionally expose backup-cluster membership/priority, DB version, participation thresholds, and OS/JVM/CPU/memory statistics: [3](#0-2) [4](#0-3) 

The endpoint is registered on the FullNode HTTP service and Solidity HTTP service without a specific auth filter, only subject to the generic `disabledApi` opt-out list, which is empty by default: [5](#0-4) [6](#0-5) 

`isDisabled` in `HttpApiAccessFilter` only blocks endpoints explicitly named in `node.disabledApi`, which ships empty, so `getnodeinfo` is reachable by default to anyone who can send an HTTP request to the node's port: [7](#0-6) 

### Impact Explanation
An anonymous remote attacker can call `/wallet/getnodeinfo` on any full node to harvest the real IP addresses and node IDs of that node's peers, its backup/HA topology (member count and priority), DB engine version, and machine fingerprinting data (OS, JVM version, CPU/memory). This directly parallels the CVE's "sensitive directory information disclosure" class: unauthenticated reconnaissance of node/network topology and internal state that should not be exposed to arbitrary API clients, and can be used to target specific peers for further network-level attacks (e.g., targeted DoS, deanonymization of SR/witness infrastructure, or backup-cluster takeover attempts).

### Likelihood Explanation
High likelihood: the endpoint requires no authentication, no special transaction, and no rate-limit bypass — a single anonymous HTTP GET/POST is sufficient, and `disabledApi` is empty by default in shipped configs.

### Recommendation
Restrict `getnodeinfo` to trusted/internal callers by default (e.g., require it to be explicitly enabled, bind it to a loopback/admin-only listener, or gate it behind an authentication filter), and strip peer IP/node-ID and backup-cluster fields from the public-facing response, keeping only non-sensitive aggregate counters for general clients.

### Proof of Concept
1. Start a default-configured full node (`config.conf` ships with `disabledApi = []`).
2. From any machine with network access to the node's HTTP port, send: `curl http://<node-ip>:8090/wallet/getnodeinfo`.
3. Observe the JSON response includes `peerInfoList[].host`, `peerInfoList[].nodeId`, `configNodeInfo.backupMemberSize`, `configNodeInfo.backupPriority`, `configNodeInfo.dbVersion`, and `machineInfo` OS/JVM details — all disclosed without any credential or signed transaction.

  private void setConnectInfo(NodeInfo nodeInfo) {
    int activeCnt = PeerManager.getActivePeersCount().get();
    int passiveCnt = PeerManager.getPassivePeersCount().get();
    nodeInfo.setCurrentConnectCount(activeCnt + passiveCnt);
    nodeInfo.setActiveConnectCount(activeCnt);
    nodeInfo.setPassiveConnectCount(passiveCnt);
    List<PeerInfo> peerInfoList = new ArrayList<>();
    for (PeerConnection peerConnection : PeerManager.getPeers()) {
      Channel channel = peerConnection.getChannel();
      NodeStatistics nodeStatistics = peerConnection.getNodeStatistics();
      P2pService P2pService = TronNetService.getP2pService();
      P2pConfig p2pConfig = TronNetService.getP2pConfig();
      PeerInfo peerInfo = new PeerInfo();
      peerInfo.setHeadBlockWeBothHave(peerConnection.getBlockBothHave().getString());
      peerInfo.setActive(peerConnection.getChannel().isActive());
      peerInfo.setAvgLatency(peerConnection.getChannel().getAvgLatency());
      peerInfo.setBlockInPorcSize(peerConnection.getSyncBlockInProcess().size());
      peerInfo.setConnectTime(channel.getStartTime());
      peerInfo.setDisconnectTimes(nodeStatistics.getDisconnectTimes());
      //peerInfo.setHeadBlockTimeWeBothHave(peerConnection.getHeadBlockTimeWeBothHave());
      peerInfo.setHost(channel.getInetAddress().toString());
      peerInfo.setLastBlockUpdateTime(peerConnection.getBlockBothHaveUpdateTime());
      peerInfo.setLastSyncBlock(peerConnection.getLastSyncBlockId() == null ? ""
          : peerConnection.getLastSyncBlockId().getString());
      ReasonCode reasonCode = nodeStatistics.getLocalDisconnectReason();
      peerInfo.setLocalDisconnectReason(reasonCode == null ? "" : reasonCode.toString());
      reasonCode = nodeStatistics.getRemoteDisconnectReason();
      peerInfo.setRemoteDisconnectReason(reasonCode == null ? "" : reasonCode.toString());
      peerInfo.setNeedSyncFromPeer(peerConnection.isNeedSyncFromPeer());
      peerInfo.setNeedSyncFromUs(peerConnection.isNeedSyncFromUs());
      int tableNodesSize = P2pService.getTableNodes().size();
      peerInfo.setNodeCount(tableNodesSize);

  private boolean isDisabled(String endpoint) {
    boolean disabled = false;

    try {
      endpoint = URI.create(endpoint).normalize().toString();
      List<String> disabledApiList = CommonParameter.getInstance().getDisabledApiList();
      if (!disabledApiList.isEmpty()) {
        disabled = disabledApiList.contains(endpoint.split("/")[2].toLowerCase(Locale.ROOT));
      }
    } catch (Exception e) {
      logger.warn("check isDisabled except, endpoint={}, {}", endpoint, e.getMessage());
    }

    return disabled;
  }
