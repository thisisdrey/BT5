### Title
Unauthenticated `POST /shutdown` permanently halts the signer's event receiver - (File: libsigner/src/events.rs)

### Summary
The signer's HTTP event-listener socket accepts an unauthenticated `POST /shutdown` request and immediately sets `stop_signal` to `true`, terminating the event receiver's main loop. Any remote TCP client that can reach this socket (which is configured to receive node event-observer callbacks) can send this single crafted HTTP request to permanently disable the signer until manually restarted.

### Finding Description
In `libsigner/src/events.rs`, `SignerEventReceiver::next_event` (lines 413-459) dispatches incoming HTTP requests by URL with no authentication layer at all: `/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/shutdown`, `/new_block` are all handled identically regardless of the request's origin. For `/shutdown` specifically (lines 443-445):
```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
```
There is no signature check, no shared secret comparison, no loopback/source-address restriction — the only "protection" intended is that the legitimate stop path is `SignerStopSignaler::send` (lines 376-396), which is invoked by the local signer process itself and connects to `self.local_addr` (the same bound socket) to send the very same unauthenticated `POST /shutdown` request. Any remote party capable of opening a TCP connection to the bound event-receiver address can send byte-for-byte the same request and achieve the identical effect, breaking the intended equality that only the local signer process (not a remote peer) can request this receiver's own shutdown.

Once `stop_signal` is set, `is_stopped()` (line 462-464) returns `true` forever (it is never reset), so `next_event` on the next call at line 416-418 returns `EventError::Terminated`, and `EventReceiver::main_loop` (lines 284-312) exits its loop on `Err(EventError::Terminated)` (line 296-300), ending the entire signer event-receiving thread permanently until the process is restarted.

### Impact Explanation
A single unauthenticated HTTP POST from any remote party who can reach the signer's event-listener port (the same port the stacks-node event dispatcher posts StackerDB chunks, burn blocks, and block-validation responses to) permanently stops the signer from receiving any further events — no more `stackerdb_chunks`, `proposal_response`, `new_burn_block`, or `new_block` events are processed. This is a Critical, single-message unauthenticated remote DoS against a signer, which can prevent the signer from participating in block signing until an operator notices and restarts it, undermining Stacks consensus liveness for that signer.

### Likelihood Explanation
The event-receiver listens on a configured local socket address that is typically bound so the co-located stacks-node's event dispatcher can reach it; if that bind address/port is reachable from outside the local host (e.g., bound to a non-loopback interface, common in containerized/distributed deployments), any remote attacker with network reachability and zero credentials can trivially send the crafted HTTP request. No signature, secret, peer identity, or StackerDB slot ownership is required — this is the lowest possible attacker cost matching the "unprivileged remote attacker" threat model.

### Recommendation
Require authentication for state-changing endpoints on the event receiver, at minimum:
- Restrict `bind()` / require configuration to only bind to loopback (`127.0.0.1`) so only the local co-located node can reach it, and/or
- Add a shared-secret/token check (e.g., a header or bearer token known only to the local node and signer) validated before honoring `/shutdown` (and ideally all POST endpoints), rejecting requests that don't present it.

fn test_unauthenticated_shutdown() {
    let mut receiver: SignerEventReceiver<v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Simulate a remote unprivileged attacker (no signature, no secret) sending shutdown
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = "POST /shutdown HTTP/1.1\r\nHost: x\r\nConnection: close\r\nContent-Length: 0\r\n\r\n";
    stream.write_all(req.as_bytes()).unwrap();

    // The bare `next_event` call processes the request and sets stop_signal
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped());

    // Any subsequent call immediately terminates without processing real events
    let result2 = receiver.next_event();
    assert!(matches!(result2, Err(EventError::Terminated)));
}

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(

                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
