### Title
Unauthenticated remote DoS via `/shutdown` HTTP POST to `SignerEventReceiver` - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event()` treats any HTTP POST to the `/shutdown` path as authorization to permanently halt the signer's event-processing loop, with no authentication, secret, or peer-address check. Any TCP client that can reach the signer's event-receiver bind address can send a single crafted POST and permanently stop the signer from processing further events.

### Finding Description
In `next_event()`, the dispatch logic matches on `request.url()` for various node-originated event paths (`/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`) but also includes `/shutdown`: [1](#0-0) 
which unconditionally does `event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated)`. This is the exact same mechanism the legitimate `SignerStopSignaler::send()` uses to shut down the receiver by connecting to `self.local_addr` and issuing a raw `POST /shutdown` request: [2](#0-1) 
There is no shared secret, HMAC, bearer token, or source-IP/localhost check gating this branch — the handler only checks `request.url() == "/shutdown"` and the HTTP method, both attacker-controlled and trivially satisfiable. Once `stop_signal` is set, `is_stopped()` returns true forever (it's a monotonically-set `AtomicBool` with no reset path), so `main_loop()` breaks out of its loop for good: [3](#0-2) 
The `bind_addr` used to start listening is caller-supplied (typically the signer's configured `endpoint`), and the receiver thread accepts connections from any client that can reach that socket: [4](#0-3) 
The broken equality is exactly as stated: the code implicitly assumes "the sender of `/shutdown` == the local stacks-node process," but nothing in the code enforces that assumption. Any remote TCP client satisfies `remote_sender == local_node` from the code's perspective, because no check for that equality exists at all.

### Impact Explanation
A single unauthenticated POST to `/shutdown` permanently disables the signer's HTTP event ingestion, which is the channel through which the local stacks-node delivers StackerDB chunks, burn-block events, block-validation responses, and new-block events to the signer. Once terminated, the signer stops receiving and forwarding these events, effectively taking the signer out of the signing loop until manually restarted — a Critical, repeatable, one-shot unauthenticated remote DoS, matching the "Critical - remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
No preconditions beyond TCP reachability to the signer's configured event-receiver bind address are required — no secret, no valid peer identity, no StackerDB slot ownership. The attack is a single raw HTTP POST, deliverable with a plain `TcpStream`, and is fully repeatable/instant (no rate limiting or volume needed). The only variable is deployment-specific: whether the operator's configured bind address is reachable from the attacker's network position (e.g., bound to a non-loopback interface), which is a normal operational configuration, not a privileged assumption.

### Recommendation
Remove or gate the `/shutdown` HTTP path entirely. If a remote-triggerable shutdown mechanism is required, protect it with a shared secret/HMAC check or bind the shutdown-signaling socket to loopback only and verify the peer's `SocketAddr` in `next_event()` before honoring `/shutdown`. Alternatively, replace this HTTP-based self-connect trick with an in-process signal (e.g., waking a poll via a pipe/eventfd or an internal channel) rather than exposing it on the same externally-reachable socket that receives node events.

### Proof of Concept
```rust
use std::io::Write;
use std::net::{TcpStream, SocketAddr};
use libsigner::events::{SignerEventReceiver, EventReceiver};
use libsigner::v0::messages::SignerMessage;

#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut receiver: SignerEventReceiver<SignerMessage> = SignerEventReceiver::new(false);
    let addr: SocketAddr = "127.0.0.1:0".parse().unwrap();
    let bound = receiver.bind(addr).unwrap();

    // Attacker: any TCP client, no auth token, no secret
    let mut stream = TcpStream::connect(bound).unwrap();
    let body = "attacker payload";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {bound}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // Receiver processes the malicious POST and terminates permanently
    let result = receiver.next_event();
    assert!(matches!(result, Err(libsigner::EventError::Terminated)));

    // Confirm it stays terminated forever (DoS persists)
    assert!(receiver.is_stopped());
}
```
