### Title
`Pool.paused` blocks collateral deposits while `Pool.liquidate` remains executable — users can be force-liquidated during pause with no ability to add margin - (File: contracts/Pool.sol, contracts/DepositToken.sol, contracts/utils/Pauseable.sol)

### Summary
Metronome's `Pauseable` implements two distinct flags: `paused` (blocks deposits only) and `everythingStopped` (blocks `issue`, `repay`, `repayAll`, `liquidate`, `swap`). The governor's `pause()` sets only `_paused`. `DepositToken.deposit()` reverts while `pool.paused()`, but `Pool.liquidate()` is gated solely by `whenNotShutdown` semantics — it is explicitly functional while paused (test: "should not revert if paused" in `test/Pool.test.ts:353`). This is a strict superset of the Hubble M-11 scenario: not only can a liquidator front-run a user's re-collateralization at unpause, the position can be liquidated *while the contract is still paused* and the user has no path to add collateral.

### Finding Description
- `Pauseable.pause()` sets `_paused = true`; `unpause()` clears it [1](#0-0) 
- `DepositToken.deposit()` is disabled when `PoolRegistry.paused() || Pool.paused()` — confirmed by `docs/emergency-flags.md:79-81` and the revert test `test/DepositToken.test.ts:371-381` [2](#0-1) 
- `Pool.liquidate()` is disabled only by `everythingStopped` — confirmed by `docs/emergency-flags.md:63-65` and the test showing liquidation succeeds after `pool.pause()` and only reverts with `IsShutdown` after `pool.shutdown()` [3](#0-2) 
- There is no grace period, delay, or liquidation-after-unpause cooldown anywhere in `Pauseable`/`Pool`.

Attack scenario: governor pauses the pool (routine emergency operation, not malicious); collateral price drops making user A's position unhealthy; user A cannot deposit to restore health; any liquidator calls `Pool.liquidate(debtToken, userA, amountToRepay, depositToken)` during the pause itself and seizes collateral plus the liquidator incentive. If the liquidator somehow misses it, the unpause front-run variant from the original report also applies.

### Impact Explanation
Users lose collateral (deposit seized + liquidation incentive) through no fault of their own while their only collateral-adding entry point is disabled. Partial mitigation exists: `DebtToken.repay`/`repayAll` and `Pool.swap` remain live during `paused`, so a user holding or able to buy the synth can deleverage — but users who sold their minted synth into external markets, or whose only defense is depositing more collateral, have no recourse.

### Likelihood Explanation
Requires a routine (non-malicious) governor pause plus a price move that renders a position unhealthy during the pause window — historically judged medium for this bug class on Sherlock. Execution needs only an unprivileged liquidator EOA calling the public `liquidate`.

### Recommendation
Either gate `liquidate` behind the same pause that blocks `deposit`, or implement a grace period after `unpause()` (e.g., store `unpausedAt` and reject `liquidate` until `block.timestamp > unpausedAt + GRACE_PERIOD`) so users can deposit or repay before liquidation resumes.

### Proof of Concept
Reproducible in the existing Hardhat suite (`test/Pool.test.ts`, "when the position is unhealthy" block):

```ts
// setup: alice has unhealthy position after masterOracle.updatePrice(met, toUSD('0.95'))
await pool.pause();                                            // governor action
await expect(
  msdMET.connect(alice).deposit(amount, alice.address)          // user tries to add margin
).revertedWithCustomError(msdMET, 'IsPaused');
await pool.connect(liquidator)                                  // unprivileged liquidator
  .liquidate(msEth.address, alice.address, amountToRepay, msdMET.address); // succeeds, seizes collateral
```

Note: full certainty on the modifier set of `liquidate`/`repay` in `Pool.sol`/`DebtToken.sol` is inferred from `docs/emergency-flags.md` and the pause/shutdown tests rather than read line-by-line (grep output was truncated in this session), but the test assertions directly confirm the reachable behavior described above.

```text
    function pause() external virtual whenNotPaused onlyGovernor {
        _paused = true;
        emit Paused(_msgSender());
    }

    /**
     * @dev Suspend all features (issue, repay, deposit, withdraw, liquidate and swap), if not already shutdown.
     */
    function shutdown() external virtual whenNotShutdown canShutdown {
        _everythingStopped = true;
        _paused = true;
        emit Shutdown(_msgSender());
    }

    /**
     * @dev Unpause contract operations, allow only if contract is paused and not shutdown.
     */
    function unpause() external virtual whenPaused whenNotShutdown onlyGovernor {
        _paused = false;
        emit Unpaused(_msgSender());
    }
```
