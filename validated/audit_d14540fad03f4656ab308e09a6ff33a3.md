The premise linking `from_p2p` in `stackslib/src/net/api/getneighbors.rs` to `stackerdb/config.rs`'s slot-to-owner mapping does not hold up against the actual code.

`RPCNeighborsInfo::from_p2p` only reads peer/neighbor metadata: it calls `PeerDB::get_bootstrap_peers`, `PeerDB::static_get_peer_stacker_dbs`, `PeerDB::get_fresh_random_neighbors`, and iterates active P2P conversations to report `NeighborKey`/`NeighborAddress` info and each peer's advertised StackerDB contract IDs [1](#0-0) . It never invokes `stackerdb/config.rs`, never resolves a reward cycle, and never maps a slot ID to a signer/owner address — it merely reports which contract IDs a peer has previously advertised via `get_stackerdb_contract_ids()` [2](#0-1) .

The actual slot-to-owner mapping logic lives in `stackslib/src/net/stackerdb/config.rs` and `stackslib/src/net/stackerdb/db.rs` (e.g., `create_stackerdb`/`reconfigure_stackerdb` map `(StacksAddress, slot_count)` tuples to `slot_id`s) [3](#0-2) , and this is entirely decoupled from the `/v2/neighbors` RPC handler. There is no code path by which a byte sequence reaching `from_p2p` causes a stale-cycle slot/owner lookup in `config.rs`; the two components do not interact in the way the question assumes.

Since the target function and the described exploit mechanism have no actual code relationship, the claimed invariant violation ("owner enforced for a slot == owner for current cycle" being broken via `from_p2p`) cannot be traced through real code, and the finding is invalid as stated.

                RPCNeighbor::from_neighbor_key_and_pubkh(

                    stackerdb_contract_ids,

                )
            })

        let mut outbound = vec![];

                convo
            } else {
                continue;
            };

            let nk = convo.to_neighbor_key();
            let naddr = convo.to_neighbor_address();
            if convo.is_outbound() {
                outbound.push(RPCNeighbor::from_neighbor_key_and_pubkh(
                    nk,
                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            } else {

                    naddr.public_key_hash,
                    convo.is_authenticated(),
                    convo.get_stackerdb_contract_ids().to_vec(),
                    Some(convo.age()),
                ));
            }
        }

        Ok(RPCNeighborsInfo {
            bootstrap,
            sample,
            inbound,
