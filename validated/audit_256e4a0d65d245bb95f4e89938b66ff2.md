### Title
Unhandled `SortBy` enum value crashes `FindLocalBranches` RPC handler via `panic("never reached")` - (File: internal/gitaly/service/ref/find_local_branches.go)

### Summary
`FindLocalBranchesRequest` accepts a `SortBy` enum field that is fully attacker-controlled by any client issuing the RPC. The handler passes this field into `parseSortKey`, which only handles three known enum values and calls `panic("never reached")` for anything else, mirroring the external report's pattern of an incompletely-implemented code path that panics when it processes an unexpected/uncovered input value.

### Finding Description
`FindLocalBranches` calls `s.findLocalBranches(in, stream)`, which computes `opts.sortBy = parseSortKey(in.GetSortBy())` and also directly interpolates `parseSortKey(in.GetSortBy())` into a `--sort=` git flag. [1](#0-0) 

`parseSortKey` only recognizes `FindLocalBranchesRequest_NAME`, `_UPDATED_ASC`, and `_UPDATED_DESC`; any other value falls through to `panic("never reached")`: [2](#0-1) 

Because `SortBy` is a proto3 enum, the wire format allows any `int32` value to be sent for this field — proto3 enums are "open" and do not reject unrecognized values at deserialization time. There is no validation of `in.GetSortBy()` anywhere in `FindLocalBranches` before it reaches `parseSortKey`. [3](#0-2) 

This is analogous to the external report's root cause: an unhandled/uncovered branch in event- or field-processing code that panics instead of returning a graceful error, reachable directly from attacker-supplied input (there, an event type; here, an RPC enum field).

### Impact Explanation
Gitaly registers a gRPC panic-recovery interceptor (`panichandler.UnaryPanicHandler` / `StreamPanicHandler`) at the server level, which recovers from panics inside RPC handlers and converts them to a `codes.Internal` gRPC error rather than crashing the whole `gitaly` process. [4](#0-3) 

Because `FindLocalBranches` is a streaming RPC, the panic is caught by `StreamPanicHandler`, so the practical impact is limited to failing that single RPC call (denial of service of the handler for that call) rather than crashing the entire Gitaly server or corrupting state. This is a narrower impact than the original oracle bug (which froze all attestation processing), but it still matches the "DoS of a handler" category from the validation criteria.

### Likelihood Explanation
Likelihood is high: any ordinary, unprivileged gRPC client that can call `FindLocalBranches` can set `sort_by` to any out-of-range enum integer (e.g., `99`) in the request, deterministically triggering the panic on every such call. No special permissions, race conditions, or unusual state are required.

### Recommendation
Replace the `panic("never reached")` fallback in `parseSortKey` with a graceful error path, e.g. return an error (or a `structerr.NewInvalidArgument` at the call site) for unrecognized `SortBy` values, and have `FindLocalBranches`/`findLocalBranches` propagate that as an `InvalidArgument` gRPC error instead of relying on the panic-recovery interceptor to mask the crash.

### Proof of Concept
1. As any client with access to the RefService, construct a `FindLocalBranchesRequest` with a valid `Repository` and set `sort_by` to an integer not defined by the `FindLocalBranchesRequest_SortBy` enum (e.g., `3`), which proto3 permits on the wire.
2. Send the RPC to Gitaly.
3. Server-side, `findLocalBranches` calls `parseSortKey(in.GetSortBy())` at [5](#0-4) , which falls through the switch and executes `panic("never reached")` at [6](#0-5) .
4. The panic is caught by the gRPC stream panic interceptor and returned as an `Internal` error, failing that call every time it is sent with such an out-of-range value.

func (s *server) FindLocalBranches(in *gitalypb.FindLocalBranchesRequest, stream gitalypb.RefService_FindLocalBranchesServer) error {
	if err := s.locator.ValidateRepository(stream.Context(), in.GetRepository()); err != nil {
		return structerr.NewInvalidArgument("%w", err)
	}

	for _, pattern := range in.GetExcludePatterns() {
		p := string(pattern)
		if p == "" {
			return structerr.NewInvalidArgument("empty exclude pattern")
		}
		if strings.ContainsRune(p, 0) {
			return structerr.NewInvalidArgument("exclude pattern contains null byte: %q", p)
		}
		if !strings.HasPrefix(p, "refs/heads/") {
			return structerr.NewInvalidArgument("exclude pattern must start with %q: %q", "refs/heads/", p)
		}
	}

	if err := s.findLocalBranches(in, stream); err != nil {
		return err
	}

	return nil
}

func parseSortKey(sortKey gitalypb.FindLocalBranchesRequest_SortBy) string {
	switch sortKey {
	case gitalypb.FindLocalBranchesRequest_NAME:
		return "refname"
	case gitalypb.FindLocalBranchesRequest_UPDATED_ASC:
		return "committerdate"
	case gitalypb.FindLocalBranchesRequest_UPDATED_DESC:
		return "-committerdate"
	}

	panic("never reached") // famous last words
}
