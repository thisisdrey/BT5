### Title
Unauthenticated remote DoS via unauthenticated `/shutdown` POST to `SignerEventReceiver` — ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` honors a bare `POST /shutdown` HTTP request by setting `stop_signal` to `true` and returning `EventError::Terminated`, which causes `main_loop` to exit. There is no authentication, shared secret, or source-address check applied before this control path is taken, so any TCP client that can reach the bound `endpoint` address can terminate the signer's event pipeline with a single request.

### Finding Description
In `next_event`, the branch dispatch is purely based on `request.url()` string equality with no prior identity/authorization check: [1](#0-0) 

Specifically, `if request.url() == "/shutdown" { event_receiver.stop_signal.store(true, Ordering::SeqCst); Err(EventError::Terminated) }` fires for any incoming request matching that URL, regardless of sender. This mirrors exactly how the legitimate `SignerStopSignaler::send` triggers shutdown — by opening a plain `TcpStream` to `local_addr` and issuing a raw `POST /shutdown` HTTP request with no credential: [2](#0-1) 

Because this is the exact same code path the legitimate in-process stop signaler uses, and it requires no secret or signature, an external attacker who can open a TCP connection to the bound `endpoint` and speak minimal HTTP can replicate it. `main_loop` treats `EventError::Terminated` as a clean exit signal and breaks out of its loop: [3](#0-2) 

No other guard (no header check, no token, no allow-listed peer) exists in this file to gate the `/shutdown` branch differently from `/status`, `/stackerdb_chunks`, etc.

### Impact Explanation
Any party able to reach the signer's bound event-receiver TCP endpoint can permanently stop the signer's `main_loop`, halting all downstream event forwarding (block proposals, burn blocks, StackerDB chunk events) to the signer's runloop with a single crafted HTTP POST. This is a full, repeatable denial-of-service against the signer's event ingestion pipeline, matching the "Critical - remote crash/unauthenticated DoS from few messages" category, since exactly one message is required and it is trivially repeatable against any newly restarted receiver.

### Likelihood Explanation
The `endpoint` address that `SignerEventReceiver::bind` listens on is a signer-configurable value (`endpoint`/`event_recv` style config keys in `stacks-signer/src/config.rs`); whether it is exposed beyond localhost depends on operator configuration, but nothing in `libsigner/src/events.rs` enforces a loopback-only binding or authenticates callers. Any operator who binds this to a non-loopback interface (common in containerized/multi-host signer deployments) is remotely exploitable by an unprivileged attacker with zero preconditions beyond network reachability — no key, no StackerDB slot, no signer role required.

### Recommendation
Require authentication for the `/shutdown` (and ideally all) event-receiver endpoints — e.g., a shared secret/token configured out-of-band and checked via a header, or restrict acceptance to loopback/allow-listed source IPs at bind time, rather than trusting any TCP peer that can form a valid HTTP request.

### Proof of Concept
```rust
// libsigner/src/events.rs (test module)
#[test]
fn test_unauthenticated_shutdown() {
    let mut receiver: SignerEventReceiver<StacksTransaction> = SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Attacker: raw TCP connection, no credentials
    let mut stream = TcpStream::connect(addr).unwrap();
    let req = "POST /shutdown HTTP/1.1\r\nHost: x\r\nContent-Length: 0\r\nConnection: close\r\n\r\n";
    stream.write_all(req.as_bytes()).unwrap();

    let err = receiver.next_event().unwrap_err();
    assert!(matches!(err, EventError::Terminated));
    assert!(receiver.is_stopped());
}
```
This reproduces the exact path: `TcpServer::recv` → `request.url() == "/shutdown"` → `stop_signal.store(true, ...)` → `Err(EventError::Terminated)`, with no credential presented.

                    continue;
                }

                    // we're done
                    info!("Caught termination signal");
                    break;

                    warn!("Failed to receive next event: {:?}", &e);
                    continue;
                }
            };

                break;
            }
