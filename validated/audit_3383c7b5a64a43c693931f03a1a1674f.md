### Title
Protocol fee bypass on `Nep245`/`Imt` tokens via unit-splitting of `TokenDiff` intents - (File: `contracts/defuse/core/src/intents/token_diff.rs`)

### Summary
`TokenDiff::token_fee` waives the protocol fee entirely (`Pips::ZERO`) whenever the *per-intent* declared amount on a `Nep245`/`Imt` (or `Nep171`) token delta is `<= 1`, regardless of how many such intents are batched together in one `execute_intents` call. Since fee is computed per intent on that intent's own delta rather than on the netted notional volume across the batch, two colluding signers can decompose an arbitrarily large `Nep245`/`Imt` swap into many `|delta| == 1` legs and pay zero fee on volume that would otherwise be fee‑bearing.

### Finding Description
The broken binding is: `fees_credited_to_fee_collector == fee_owed_on_total_notional_traded`. For a single `TokenDiff` intent trading amount `A` of a `Nep245`/`Imt` token, fee owed is `protocol_fee.fee_ceil(A)` when `A > 1` [1](#0-0) . But fee is computed inside `TokenDiff::execute_intent` strictly per-intent, using only that single intent's own `delta` magnitude: [2](#0-1) 

`Engine::execute_signed_intents` simply loops over each signed payload and calls `execute_signed_intent` → `intents.execute_intent`, with no aggregation of per-signer/per-token amounts across intents before fee is charged — only balance conservation is checked later via `TransferMatcher::finalize` [3](#0-2) [4](#0-3) .

Because `token_fee` returns `Pips::ZERO` whenever the declared amount for a `Nep245`/`Imt` (or `Nep171`) delta is `<= 1` [1](#0-0) , an attacker controlling two signer keys (A and B) that want to swap `N` units of `Nep245` token `X` for `N` units of `Nep245` token `Y` can, instead of submitting one `TokenDiff` per side with `delta = -N` (which would incur `fee.fee_ceil(N) > 0` on each negative side), submit `N` separate signed `TokenDiff` intents per side, each with `delta = -1`/`+1`. Every individual intent computes `token_fee(token_id, 1, fee) == Pips::ZERO`, so `fees_collected` is `0` in every intent. All `2N` intents are bundled into one `execute_intents`/`MultiPayload` call; `TransferMatcher` still nets the deltas to zero across the whole batch, so the conservation invariant holds and the call succeeds, but the fee collector receives nothing despite `N` units of true notional volume being exchanged on each side.

None of the existing guards prevent this: `MultiPayload::verify`, nonce/salt checks, and `TransferMatcher::finalize` only validate signatures, replay and balance conservation — they never re-derive or validate the fee that should have been charged against the aggregate volume moved by a signer within the batch.

### Impact Explanation
This directly falls under "protocol fees bypassed" (Critical). The fee collector (`fee_collector()`) is under-credited relative to the true notional volume traded by colluding accounts; the protocol permanently loses fee revenue it is entitled to on `Nep245`/`Imt` swaps that could otherwise have been executed as fewer, larger-amount `TokenDiff` intents. This is repeatable indefinitely, for any pair of colluding signer keys, on any `Nep245`/`Imt` token pair, and scales linearly with the number of unit-legs the attacker is willing to sign and submit in a batch.

### Likelihood Explanation
Preconditions are minimal and fully within an unprivileged attacker's control: two self-controlled accounts holding balances of `Nep245`/`Imt` tokens inside the Verifier, the ability to sign `N` cheap `TokenDiff` intents (no special role, relayer key, or DAO permission needed), and a single `execute_intents`/`MultiPayload` call containing all `2N` intents. The only cost is the linear growth in payload size/gas for larger `N`, which is a resource cost, not a blocking control (and gas/resource limits are explicitly out of scope per the rules, but do bound how large `N` can practically be in one transaction).

### Recommendation
Compute and charge fee based on the netted absolute volume a signer moves on a given token across the whole intent batch (or at minimum disallow the `amount <= 1` fee exemption from being trivially reset per intent by netting all `TokenDiff` deltas from the same signer/token before applying `token_fee`), rather than per individual `TokenDiff` intent's own delta.

### Proof of Concept
`cargo test` plan (near-workspaces sandbox, extending `tests/src/tests/defuse/intents/token_diff.rs`):
1. Set `fee = Pips::ONE_PERCENT` (or any nonzero fee) via `Env::builder().fee(fee)`.
2. Create two users A and B; deposit `N = 1000` units each of two distinct `Nep245` tokens `X` and `Y` to A and B respectively.
3. Baseline: sign and execute ONE `TokenDiff` per user: A `{X: -1000, Y: +1000}`, B `{Y: -1000, X: +1000}`; execute via `execute_intents`; record `fee_collector` balance delta for `X` and `Y` — assert it equals `2 * fee.fee_ceil(1000)`.
4. Attack: reset balances; instead sign `1000` `TokenDiff` intents for A (`{X: -1, Y: +1}` each) and `1000` for B (`{Y: -1, X: +1}` each), batch all `2000` signed payloads into one `execute_intents` call.
5. Assert the call succeeds (conservation invariant holds, `TransferMatcher::finalize` returns `Ok`).
6. Assert `fee_collector` balance delta for `X` and `Y` is `0`, contradicting the baseline non-zero fee owed for the same notional volume — i.e. `fees_credited (0) != fee_owed (2 * fee.fee_ceil(1000))`.

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
}
