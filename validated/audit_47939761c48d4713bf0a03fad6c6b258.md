Confirmed: no authentication mechanism exists for the signer's event-listener HTTP endpoints, including `/shutdown`.

### Title
Unauthenticated `/shutdown` POST allows any TCP peer to permanently terminate the signer's event receiver - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` treats any HTTP POST to `/shutdown` as a valid termination signal, with no verification that the sender is the local Stacks node. Any remote party with TCP access to the signer's bound event-listener port can send a forged `POST /shutdown` and permanently kill the signer's event-processing loop.

### Finding Description
In `next_event`, the branch handling `/shutdown` unconditionally sets the stop flag and returns `Terminated` for any POST to that URL, without checking source, headers, or any secret/token: [1](#0-0) 
This mirrors exactly how the legitimate stop signaler triggers shutdown — by connecting to the bound address and issuing a plain, unauthenticated `POST /shutdown`: [2](#0-1) 
There is no authentication layer (no bearer token, shared secret, or peer-address check) anywhere in the event listener's request-handling path — `/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block`, and `/shutdown` are all dispatched purely based on URL and HTTP method: [3](#0-2) 
Once `Terminated` is returned, `EventReceiver::main_loop` breaks out of its loop entirely and does not resume: [4](#0-3) 
The attacker's exact message is a raw TCP payload of `POST /shutdown HTTP/1.1\r\nHost: <addr>\r\nContent-Length: <n>\r\n\r\n<any body>` sent directly to the signer's bound event port — no valid signature, secret, or node identity is required, and the body content is irrelevant since the branch is chosen purely by URL match before any body is read.

### Impact Explanation
A single forged POST permanently stops the signer's event-receiver thread, meaning the signer stops observing `StackerDBChunksEvent`, `BlockValidateResponse`, `NewBurnBlock`, and `NewBlock` events pushed by the node. This deafens the signer to block proposals and StackerDB messages, degrading its ability to participate in signing (silently, since the process itself does not necessarily crash but effectively becomes non-functional until externally restarted). This is a remote, unauthenticated DoS achievable with a single crafted message, matching the "Critical - remote crash/unauthenticated DoS from few messages" category.

### Likelihood Explanation
The only precondition is raw TCP reachability to the signer's bound event-listener address/port — the same reachability the node itself uses to deliver events. The attacker needs no credentials, no valid peer/slot key, and no privileged role; the attack is a single crafted HTTP request repeatable at will and trivially scriptable.

### Recommendation
Authenticate the `/shutdown` endpoint (and ideally all node→signer event endpoints): require a shared secret/token known only to the node and signer (e.g., an `Authorization` header checked against a configured value), and/or restrict `HttpServer::http` binding to loopback/local-only interfaces when not otherwise firewalled, and additionally validate the source socket address of incoming connections against an expected node address where feasible.

```rust
// libsigner/src/events.rs (test module) or a standalone integration test
use std::io::Write;
use std::net::TcpStream;
use std::sync::atomic::Ordering;

#[test]
fn test_unauthenticated_shutdown_terminates_receiver() {
    let mut receiver: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Attacker (no credentials) opens a raw TCP connection and forges /shutdown
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker-controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        addr, body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // next_event should return Terminated purely from URL match, no auth check
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped()); // stop_signal flipped by an unauthenticated party
}
```

```rust
                Ok(event) => event,

                }

                    // we're done
                    info!("Caught termination signal");

                    continue;
                }
            };

                break;
            }
```

```rust
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)

                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)

                process_event::<T, StacksBlockEvent>(request)

                let url = request.url().to_string();

                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
```
