### Title
Unauthenticated event injection into signer via `SignerEventReceiver` HTTP listener - (File: libsigner/src/events.rs)

### Summary
The `SignerEventReceiver::next_event()` handler, which is the HTTP listener the `stacks-signer` binds to receive event-observer callbacks from a trusted node, accepts and processes POST requests to `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` with no authentication check whatsoever. Any TCP client that can reach the signer's bound port can POST arbitrary JSON bodies to these endpoints and have them deserialized and forwarded straight into the signer's runloop as if they came from the paired Stacks node.

### Finding Description
`SignerEventReceiver::next_event` dispatches purely on HTTP method and URL path, with no check of any shared secret, token, or peer identity: [1](#0-0) 

The node-side configuration documents an `auth_token`/`auth_password` pairing meant to protect this channel (`[connection_options] auth_token` on the node must match `auth_password` in the signer config), but that value is never checked anywhere in `SignerEventReceiver`'s request-handling path — it is enforced (if at all) only by the node when it originates the callback, not by the signer when it receives one: [2](#0-1) 

Once a request is accepted, `process_event` reads the body, JSON-deserializes it into the expected event type, and converts it into a `SignerEvent` that is unconditionally forwarded to the signer's business logic: [3](#0-2) 

For `/stackerdb_chunks` specifically, the conversion in `TryFrom<StackerDBChunksEvent> for SignerEvent<T>` does perform per-chunk signature checks (`chunk.recover_pk()`), so forged StackerDB chunk *contents* cannot be attributed to an arbitrary signer key. However, `/proposal_response` (`BlockValidateResponse`) and `/new_burn_block` (`BurnBlockEvent`) carry no such per-message authentication at the transport layer at all — the receiver has no way to distinguish a real node callback from an attacker-crafted POST: [4](#0-3) 

This breaks the intended equality "message accepted only if it originated from the paired, authenticated node" — the endpoint fails open for any reachable client.

### Impact Explanation
An attacker who can reach the signer's bound HTTP port (`endpoint` in the signer config, e.g. `0.0.0.0:30000` per the sample docs) can inject forged `BlockValidateResponse` and `NewBurnBlock` events into the signer's decision loop without needing the node's `auth_token`, the node's private key, or any signer's private key. This is an unauthenticated write into signer-internal state that drives block-signing decisions, matching the "unauthenticated/unauthorized write to state" and "auth bypass" impact classes for this scan.

### Likelihood Explanation
Likelihood is high if the signer's event endpoint is reachable from an untrusted network (bound to `0.0.0.0` per sample config, and the documentation explicitly warns operators about exposing it to "external" networks without additional security). No cryptographic material is needed — just network reachability and a well-formed HTTP POST with a valid JSON body for one of the four handled URLs.

### Recommendation
Have `SignerEventReceiver` validate an authentication token/header (matching the node's configured `auth_token`) on every incoming request before dispatching to `process_event`, rejecting unauthenticated requests with 401/403 rather than processing them. This should apply uniformly to all four dispatched endpoints, not just `/stackerdb_chunks` (which happens to get incidental protection from per-chunk signer-key verification).

### Proof of Concept
1. Start a `stacks-signer` instance bound to a reachable address (per sample config `endpoint = "0.0.0.0:30000"`).
2. From an unauthenticated remote host, craft a `BurnBlockEvent` or `BlockValidateResponse` JSON payload and POST it to `http://<signer-ip>:30000/new_burn_block` or `/proposal_response` with `Content-Type: application/json`, without any `auth_token`/`auth_password` header — mirroring the test harness's own unauthenticated POST pattern used in `test_simple_signer`: [5](#0-4) 
3. Observe that `next_event()` accepts the request, deserializes it, and forwards it as a `SignerEvent` to the signer runloop exactly as it would for a legitimate node-originated callback, since no token check exists in `libsigner/src/events.rs`.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?

fn process_event<T, E>(mut request: HttpRequest) -> Result<SignerEvent<T>, EventError>
where
    T: SignerEventTrait,
    E: serde::de::DeserializeOwned + TryInto<SignerEvent<T>, Error = EventError>,
{
    let mut body = String::new();

    if let Err(e) = request.as_reader().read_to_string(&mut body) {
        error!("Failed to read body: {:?}", &e);
        ack_dispatcher(request);
        return Err(EventError::MalformedRequest(format!(
            "Failed to read body: {:?}",
            e
        )));
    }
    // Regardless of whether we successfully deserialize, we should ack the dispatcher so they don't keep resending it
    ack_dispatcher(request);
    let json_event: E = serde_json::from_slice(body.as_bytes())
        .map_err(|e| EventError::Deserialize(format!("Could not decode body to JSON: {:?}", e)))?;

    let signer_event: SignerEvent<T> = json_event.try_into()?;

    Ok(signer_event)
}

impl<T: SignerEventTrait> TryFrom<StackerDBChunksEvent> for SignerEvent<T> {
    type Error = EventError;

    fn try_from(event: StackerDBChunksEvent) -> Result<Self, Self::Error> {
        let received_time = SystemTime::now();
        let signer_event = if event.contract_id.name.as_str() == MINERS_NAME
            && event.contract_id.is_boot()
        {
            let mut messages = vec![];
            for chunk in event.modified_slots {
                match T::consensus_deserialize(&mut chunk.data.as_slice()) {
                    Ok(msg) => messages.push(msg),
                    Err(e) => {
                        debug!(
                            "Signer failed to deserialize miner chunk";
                            "slot_id" => chunk.slot_id,
                            "slot_version" => chunk.slot_version,
                            "data_len" => chunk.data.len(),
                            "error" => %e,
                        );
                    }
                }
            }
            SignerEvent::MinerMessages(messages)
        } else if event.contract_id.name.starts_with(SIGNERS_NAME) && event.contract_id.is_boot() {
            let Some((signer_set, message_id)) =
                get_signers_db_signer_set_message_id(event.contract_id.name.as_str())
            else {
                return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
            };
            // signer-XXX-YYY boot contract
            //
            // NOTE: the payload-type check below uses v0 `SignerMessageTypePrefix` semantics
            // (the mapping in `signer_message_payload_matches_lane` is fixed to v0). Future
            // signer-message versions must extend that mapping, or their chunks will not be
            // recognized here regardless of which `T` is in scope.
            let messages: Vec<_> = event
                .modified_slots
                .iter()
                .filter_map(|chunk| {
                    // Accept only payloads whose type is valid for this contract's message id.
                    let &type_byte = chunk.data.first()?;
                    let payload_kind = SignerMessageTypePrefix::from_u8(type_byte)?;
                    if !signer_message_payload_matches_lane(payload_kind, message_id) {
                        warn!(
                            "Skipping signer chunk with unexpected payload type for contract";
                            "contract" => %event.contract_id,
                            "lane_message_id" => message_id,
                            "payload_type_prefix" => type_byte,
                        );
                        return None;
                    }
                    let Ok(pk) = chunk.recover_pk() else {
                        warn!(
                            "Skipping signer chunk: signature recovery failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    let Ok(message) = read_next::<T, _>(&mut &chunk.data[..]) else {
                        warn!(
                            "Skipping signer chunk: payload deserialization failed";
                            "contract" => %event.contract_id,
                            "slot_id" => chunk.slot_id,
                        );
                        return None;
                    };
                    Some((chunk.slot_id, pk, message))
                })
                .collect();
            SignerEvent::SignerMessages {
                signer_set,
                messages,
                received_time,
            }
        } else {
            return Err(EventError::UnrecognizedStackerDBContract(event.contract_id));
        };
        Ok(signer_event)
    }
}
