### Title
Unbounded FetchBundleRequest.Data stream allows temp-directory disk exhaustion - (File: internal/gitaly/service/repository/fetch_bundle.go)

### Summary
`FetchBundle` streams `FetchBundleRequest.Data` chunks directly into `createTempBundle`, which copies them via `io.Copy` into a file under the storage's temp directory with no size cap, timeout, or quota check. An attacker with write access to any repository on a shared storage can send an unbounded/slow byte stream to fill the temp directory, degrading or denying service to co-located repositories on the same storage backend.

### Finding Description
`FetchBundle` in [1](#0-0)  validates only the repository via `s.locator.ValidateRepository` and then feeds a `streamio.Reader` wrapping the client's chunked `Data` field straight into `repo.FetchBundle`, which calls `createTempBundle` at [2](#0-1) . `createTempBundle` performs `io.Copy(file, reader)` with no byte limit, no context deadline enforcement tied to volume, and no pre-check of available space on the storage backing `tempdir.New`. Since gRPC streaming has no aggregate message-size cap (only per-chunk limits), an attacker can keep sending `Data` chunks indefinitely, and the server will keep appending them to the temp file until the underlying filesystem is full.

### Impact Explanation
This matches GitLab's DoS impact class: exhausting the temp directory on a shared Gitaly storage can starve disk space for every other repository hosted on that storage shard, causing write/fetch failures for unrelated projects and tenants, not just the attacker's own repository. The impact is bounded by attacker's ability to keep the stream open and by available disk quota on the storage, but no in-code limit exists to cap the damage.

### Likelihood Explanation
Preconditions are minimal: any unprivileged user with push/write access to a single repository (owned, forked, or imported) can invoke `FetchBundle` against it, since the RPC only validates that the target repository exists and is writable — no additional authorization or payload constraints apply. The attack is trivially repeatable and requires no special timing, race conditions, or configuration flaws.

### Recommendation
Enforce a maximum bundle size (e.g., via a `io.LimitReader` or explicit byte counter during the `io.Copy` in `createTempBundle`), reject/abort streams once a configurable ceiling is exceeded, and consider a per-RPC idle/overall deadline to bound slow-write style attacks. Optionally check available free space on the storage's temp filesystem before/while copying.

func (s *server) FetchBundle(stream gitalypb.RepositoryService_FetchBundleServer) error {
	ctx := stream.Context()

	firstRequest, err := stream.Recv()
	if err != nil {
		return structerr.NewInternal("first request: %w", err)
	}

	if err := s.locator.ValidateRepository(ctx, firstRequest.GetRepository()); err != nil {
		return structerr.NewInvalidArgument("%w", err)
	}

	firstRead := true
	reader := streamio.NewReader(func() ([]byte, error) {
		if firstRead {
			firstRead = false
			return firstRequest.GetData(), nil
		}

		request, err := stream.Recv()
		return request.GetData(), err
	})

	repo := s.localRepoFactory.Build(firstRequest.GetRepository())

	// Verify that the repository actually exists.
	if _, err := repo.Path(ctx); err != nil {
		return err
	}

	opts := &localrepo.FetchBundleOpts{
		UpdateHead: firstRequest.GetUpdateHead(),
	}

	if err := repo.FetchBundle(ctx, s.txManager, reader, opts); err != nil {
		return structerr.NewInternal("%w", err)
	}

	return stream.SendAndClose(&gitalypb.FetchBundleResponse{})

func (repo *Repo) createTempBundle(ctx context.Context, reader io.Reader) (bundlPath string, cleanup func(), returnErr error) {
	tmpDir, cleanup, err := tempdir.New(ctx, repo.GetStorageName(), repo.logger, repo.locator)
	if err != nil {
		return "", nil, fmt.Errorf("create temp bundle: %w", err)
	}

	bundlePath := filepath.Join(tmpDir.Path(), "repo.bundle")

	file, err := os.Create(bundlePath)
	if err != nil {
		cleanup() // Clean up if we fail after creating the temp directory
		return "", nil, fmt.Errorf("create temp bundle: %w", err)
	}
	defer func() {
		if err := file.Close(); err != nil && returnErr == nil {
			returnErr = fmt.Errorf("create temp bundle: %w", err)
		}
	}()

	if _, err = io.Copy(file, reader); err != nil {
		cleanup() // Clean up if we fail after creating the temp directory
		return "", nil, fmt.Errorf("create temp bundle: %w", err)
	}

	return bundlePath, cleanup, nil
}
