### Title
Unauthenticated `/shutdown` HTTP endpoint permanently kills the signer's event receiver - ([File: libsigner/src/events.rs])

### Summary
The `SignerEventReceiver::next_event` handler treats any HTTP POST to `/shutdown` as authoritative and immediately sets `stop_signal` to `true`, unconditionally returning `EventError::Terminated`. There is no authentication, secret, or peer-address check tying this to the legitimate `SignerStopSignaler`, so any TCP client that can reach the signer's event-receiver bind address can permanently halt the receiver's `main_loop`.

### Finding Description
`SignerEventReceiver::next_event` dispatches based solely on the request URL and HTTP method: [1](#0-0) 
when `request.url() == "/shutdown"`, it stores `true` into `event_receiver.stop_signal` and returns `Err(EventError::Terminated)`, with no validation of a token, header, or the sender's identity/address. Legitimate operator-triggered shutdown is implemented in `SignerStopSignaler::send`, which itself just opens a plain `TcpStream` and sends a hardcoded `POST /shutdown` request with no secret embedded in it: [2](#0-1) 
Because the receiving side does not verify that the caller is the process itself, the exact same bytes can be sent by any other TCP client. `EventReceiver::main_loop` treats `EventError::Terminated` as an intentional, graceful stop and `break`s out permanently: [3](#0-2) 
Once `main_loop` exits, the event-receiver thread is gone; the `signer_runloop` thread that depends on receiving forwarded events over the channel (`stacks-signer/src/runloop.rs`, `libsigner/src/runloop.rs::main_loop`) will simply time out repeatedly and never receive new StackerDB, proposal, or burn-block events again, silently starving the signer of node input.

### Impact Explanation
A single crafted HTTP POST permanently disables the signer's ability to receive `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, and `/new_block` events pushed by the node, since the listening HTTP server thread has exited. This is a remote, unauthenticated, single-message DoS against the signer process (not the node itself), matching the "Critical - remote crash/unauthenticated DoS from few messages" category. The signer's own code acknowledges the general risk of exposing this endpoint externally: `stacks-signer/src/lib.rs` explicitly warns operators about exposing the endpoint to non-local networks, but this warning does not amount to an enforced control, and no header/secret check exists in code. [4](#0-3) 

### Likelihood Explanation
The attacker only needs TCP reachability to the signer's configured event-receiver bind address/port and needs to send one crafted HTTP POST — no signature, no StackerDB slot ownership, no secret, and no privileged role. This is exactly the unprivileged remote scenario in scope. Whether the endpoint is reachable from the public internet depends on the operator's network/firewall configuration for the signer's `endpoint`, but the code itself provides no authentication regardless of exposure.

### Recommendation
Require the shutdown request to be authenticated, e.g., bind the shutdown control channel to a local-only Unix socket / loopback-only listener separate from the node-facing HTTP endpoint, or require a shared secret/token (compared in constant time) between `SignerStopSignaler::send` and `SignerEventReceiver::next_event`'s `/shutdown` handler before setting `stop_signal`.

### Proof of Concept
```rust
// libsigner/src/tests/mod.rs (new test)
#[test]
fn test_unauthenticated_shutdown_dos() {
    let mut ev = SignerEventReceiver::<SignerMessage>::new(false);
    let endpoint: SocketAddr = "127.0.0.1:32000".parse().unwrap();
    ev.bind(endpoint).unwrap();

    // Attacker: unrelated TcpStream, no SignerStopSignaler involved.
    let mut sock = TcpStream::connect(endpoint).unwrap();
    let body = "attacker payload";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {endpoint}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    sock.write_all(req.as_bytes()).unwrap();

    // Verify the receiver is now permanently stopped without any legitimate stop signaler call.
    let result = ev.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(ev.is_stopped());
}
```
