### Title
Fee bypass on Nep245/Imt token diffs via unit-size intent splitting - ([File: contracts/defuse/core/src/intents/token_diff.rs])

### Summary
`TokenDiff::token_fee` charges `Pips::ZERO` whenever a `Nep245`/`Imt` token delta has `|amount| <= 1`, and this check is applied per-`TokenDiff` intent rather than per aggregate trade. An attacker can split what would normally be a single `-N` delta on an `Nep245` token into `N` separate `TokenDiff` intents each with `delta == -1`, causing `fee_ceil` to evaluate to `0` on every leg instead of the fee owed on `N`.

### Finding Description
The broken binding: `sum_{i=1}^{N} Pips::fee_ceil(protocol_fee, |delta_i|)` (with each `|delta_i| = 1`) should equal `Pips::fee_ceil(protocol_fee, N)` (the fee on the economically equivalent single `-N` delta), but it evaluates to `0 != fee_ceil(protocol_fee, N)` for any `protocol_fee > 0` and `N` large enough that `fee_ceil(protocol_fee, N) > 0`.

Root cause is in `TokenDiff::execute_intent` and `TokenDiff::token_fee`: [1](#0-0) [2](#0-1) 

Each `TokenDiff` intent is processed independently by `Engine::execute_signed_intent` → `DefuseIntents::execute_intent` → `Intent::execute_intent` → `TokenDiff::execute_intent`, and each call computes fee only from its own `diff` map, with no cross-intent accumulation of the fee base: [3](#0-2) [4](#0-3) 

The signer's overall balance change and the batch-level netting via `TransferMatcher` are computed on the total per-token deltas across the whole batch, agnostic of how many intents/legs contributed to it: [5](#0-4) 

So an attacker (as the "token_in" side of a trade) can sign a `MultiPayload` whose `DefuseIntents::intents` contains `N` `TokenDiff` intents, each with `diff = {mt_token_id: -1, other_token_id: +k}` (or equivalently split across `N` distinct signed payloads, all valid under the normal `nonce`/`verify` checks, which do not restrict this pattern), instead of one `TokenDiff` with `diff = {mt_token_id: -N, other_token_id: +N*k}`. `fee_ceil` returns `0` per leg via `Pips::fee_ceil` since `TokenDiff::token_fee` short-circuits to `Pips::ZERO` for `TokenIdType::Nep245`/`Imt` at `amount <= 1`: [6](#0-5) 

None of the existing guards (`verify`, `has_public_key`, `verify_intent_nonce`, nonce commit, `TransferMatcher::finalize` invariant check, `assert_one_yocto`) address this, because they only validate signature/nonce authenticity and that the aggregate deltas net to zero across the batch — they do not enforce that the fee base matches the aggregate traded amount per counterparty leg.

### Impact Explanation
`fee_collector`'s balance ends up short by `Pips::fee_ceil(protocol_fee, N)` compared to the correctly-computed fee for an `N`-unit `Nep245`/`Imt` trade, for every batch structured this way. This directly falls into the "protocol fees bypassed" Critical category defined by the rules — repeatable by any unprivileged signer, across any `Nep245`/`Imt` token they hold balance in, and across any number of batches; the magnitude scales with `N` and `protocol_fee`.

### Likelihood Explanation
Preconditions are minimal and fully within an unprivileged actor's control: the attacker only needs to hold `N` units of a registered `Nep245`/`Imt` token in their own Verifier balance, and the ability to sign a `MultiPayload` with `N` distinct `TokenDiff` intents (or `N` separate signed payloads) instead of one. There is no capital cost beyond ordinary gas for extra intents/signature verifications, and the pattern is trivially repeatable on every trade involving such tokens, at the direct expense of `fee_collector`.

### Recommendation
Compute/enforce the fee base on the aggregate per-token, per-signer (or per-batch) negative delta rather than per-individual-intent delta — e.g., accumulate all negative deltas per `token_id` across the whole `DefuseIntents`/batch before applying `TokenDiff::token_fee`'s `amount <= 1` exemption, so that splitting a trade into unit-size legs cannot change the total fee charged.

### Proof of Concept
Add a `cargo test` in `contracts/defuse/core/src/intents/token_diff.rs`'s test module (or in `tests/src/tests/defuse/intents/token_diff.rs` using a sandbox `Env`) that:
1. Sets `protocol_fee = Pips::ONE_PERCENT` (or similar non-zero fee).
2. Executes one `TokenDiff` intent with `diff = {nep245_token_id: -N, other_token_id: +X}` and asserts `fees_collected.amount_for(&nep245_token_id) == protocol_fee.fee_ceil(N)` (non-zero for `N` large enough).
3. Resets state, then executes `N` separate `TokenDiff` intents each with `diff = {nep245_token_id: -1, other_token_id: +X/N}` for the same signer/token, and asserts the total `fees_collected` accumulated across all `N` intents equals `0`.
4. Assert the two totals differ (`fee_ceil(protocol_fee, N) != 0`), demonstrating the binding `sum(fee_ceil(1)) != fee_ceil(N)` is violated and `fee_collector`'s `internal_add_balance` under-credits in the split path.

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
}
