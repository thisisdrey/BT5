### Title
Protocol fee bypass on Nep245/Imt token transfers via unit-delta splitting - (File: contracts/defuse/core/src/intents/token_diff.rs)

### Summary
`TokenDiff::token_fee` charges `Pips::ZERO` on any Nep245 or Imt `TokenId` whenever the per-intent `amount` (the `unsigned_abs()` of that single `TokenDiff`'s delta) is `<= 1`. Because fee is computed independently for each `TokenDiff` entry rather than on the aggregate delta a signer moves for a given token across a batch, any unprivileged signer can split one intended `delta = -N` transfer into `N` separate `TokenDiff` intents each with `delta = -1` (all inside the same signed `DefuseIntents` message or across multiple signed payloads in one `execute_intents` call) and collect `0` fee total instead of `Pips::fee_ceil(protocol_fee, N)`.

### Finding Description
The broken binding is:
`sum(fee collected across the batch for token T) == Pips::fee_ceil(protocol_fee, total |negative delta on T|)`

Tracing the code: `DefuseIntents::execute_intent` iterates every `TokenDiff` in `self.intents` and calls `TokenDiff::execute_intent` for each one independently [1](#0-0) . Inside `TokenDiff::execute_intent`, for each negative `delta` in that single intent's `diff` map, the fee is computed as `Self::token_fee(token_id, amount, protocol_fee).fee_ceil(amount)` where `amount = delta.unsigned_abs()` for that one intent only [2](#0-1) . `token_fee` explicitly returns `Pips::ZERO` for `Nep245`/`Imt` token types whenever `amount <= 1` [3](#0-2) .

There is no aggregation step anywhere in the engine that sums a signer's per-token deltas across multiple `TokenDiff` intents (within the same `DefuseIntents` message, or across multiple signed `MultiPayload`s in one `execute_signed_intents` call) before computing the fee. `Engine::execute_signed_intents` simply loops over each signed payload and calls `execute_signed_intent`, which in turn dispatches to `DefuseIntents::execute_intent` [4](#0-3) . The only cross-intent aggregation that exists is `TransferMatcher`, which reconciles net deposits/withdrawals per token to satisfy the zero-sum solvency invariant via `finalize()` [5](#0-4)  — this checks balance conservation, not fee correctness, so it does not prevent or detect the fee bypass.

Exploit: An attacker who wants to move (or swap) 100 units of a Nep245/Imt `TokenId` signs a single `DefuseIntents` payload containing 100 `TokenDiff` intents, each with `diff = {token_id: -1}`, paired with a matching counterparty (or their own compensating `+1` legs elsewhere in the same batch) so the batch's `TransferMatcher::finalize` still nets to zero for solvency. Each of the 100 calls to `TokenDiff::execute_intent` computes `amount = 1`, hits the `amount > 1` false branch in `token_fee`, and returns `Pips::ZERO`, so `fees_collected` stays empty for all 100 legs — versus a single `TokenDiff` with `delta = -100` which computes `token_fee(..., 100, protocol_fee) = protocol_fee` and collects `Pips::fee_ceil(protocol_fee, 100) > 0`.

No existing guard (`MultiPayload::verify`, nonce checks, `TransferMatcher::finalize`) inspects the aggregate amount per token across the intents in a batch/message, so nothing prevents this divergence.

### Impact Explanation
The fee_collector (`ContractStateV0.fees` / `engine.state.fee_collector()`) receives zero fee on a Nep245/Imt transfer of any size greater than 1 unit, as long as the signer structures it as unit-delta legs, instead of the intended `Pips::fee_ceil(protocol_fee, amount)`. This is a direct, repeatable protocol-fee bypass usable by any unprivileged signer on every Nep245/Imt-denominated swap or transfer they originate, at no additional cost beyond constructing a larger intents list (gas cost only). It matches the Critical category "protocol fees bypassed or over-collected" from the rules, since real economic value (the fee that would otherwise be credited to `fee_collector`) never leaves the signer's side.

### Likelihood Explanation
Preconditions are minimal: the signer only needs to hold the Nep245/Imt balance they intend to move and construct/sign one `DefuseIntents` payload with N single-unit `TokenDiff` legs (or coordinate matching legs from a counterparty for a swap) instead of one large-delta `TokenDiff`. No role, relayer key, or DAO privilege is required — this is fully reachable via `execute_intents` by any account holder. It is repeatable across every batch, every account, and every Nep245/Imt `TokenId`, scaling linearly with the number of unit legs used.

### Recommendation
Compute the Nep245/Imt fee exemption based on the *aggregate* magnitude of a signer's net delta per `TokenId` across the whole intents batch (or disallow multiple `TokenDiff` intents from the same signer touching the same `TokenId` within one execution), rather than per individual `TokenDiff` struct's per-line delta. Alternatively, only exempt from fees deltas of `|delta| <= 1` when this represents the *entire* transfer for that token by that signer in the batch (i.e., track cumulative negative deltas per `(signer_id, token_id)` before evaluating `token_fee`).

    fn execute_signed_intent(&mut self, signed: MultiPayload) -> Result<()> {
        // verify signed payload and get public key
        let public_key = signed.verify().ok_or(DefuseError::InvalidSignature)?;

        // calculate intent hash
        let hash = signed.hash();

        // extract NEP-413 payload
        let DefusePayload::<DefuseIntents> {
            signer_id,
            verifying_contract,
            deadline,
            nonce,
            message: intents,
        } = signed.extract_defuse_payload()?;

        // check recipient
        if verifying_contract != *self.state.verifying_contract() {
            return Err(DefuseError::WrongVerifyingContract);
        }

        self.inspector.on_deadline(deadline);

        // make sure message is still valid
        if deadline < Timestamp::now() {
            return Err(DefuseError::DeadlineExpired);
        }

        // make sure the account has this public key
        if !self.state.has_public_key(&signer_id, &public_key) {
            return Err(DefuseError::PublicKeyNotExist(signer_id, public_key));
        }

        // commit nonce
        self.verify_intent_nonce(nonce, deadline)?;
        self.state.commit_nonce(signer_id.clone(), nonce)?;

        intents.execute_intent(&signer_id, self, hash)?;
        self.inspector.on_intent_executed(&signer_id, hash, nonce);

        Ok(())
    }

    // Finalizes all transfers, or returns unmatched deltas.
    // If unmatched deltas overflow, then Err(None) is returned.
    pub fn finalize(self) -> Result<Transfers, InvariantViolated> {
        let mut transfers = Transfers::default();
        let mut deltas = TokenDeltas::default();
        for (token_id, transfer_matcher) in self.0 {
            if let Err(unmatched) = transfer_matcher.finalize_into(&token_id, &mut transfers)
                && (unmatched == 0 || deltas.apply_delta(token_id, unmatched).is_none())
            {
                return Err(InvariantViolated::Overflow);
            }
        }
        if !deltas.is_empty() {
            return Err(InvariantViolated::UnmatchedDeltas {
                unmatched_deltas: deltas,
            });
        }
        Ok(transfers)
    }
