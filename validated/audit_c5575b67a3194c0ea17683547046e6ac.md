### Title
Old Operator's Pending Commission Shares Charged Commission by New Operator After `switch_operator` — (`aptos-move/framework/aptos-framework/sources/staking_contract.move`)

---

### Summary

After `switch_operator` records `old_operator`'s earned commission into the `distribution_pool`, subsequent calls to `distribute` pass `operator = new_operator` into `update_distribution_pool`. Because `update_distribution_pool` exempts only the current `operator` argument from commission charges, `old_operator`'s shares are treated as a non-exempt shareholder and a portion of the rewards that accumulate on those shares is transferred to `new_operator`.

---

### Finding Description

**Step 1 — `switch_operator` records old commission**

`switch_operator` calls `request_commission_internal(old_operator, ...)`, which calls `add_distribution(old_operator, staking_contract, old_operator, commission_amount)`.

Inside `add_distribution`, `update_distribution_pool` is called with `operator = old_operator`, then `distribution_pool.buy_in(old_operator, commission_amount)` adds `old_operator` as a shareholder: [1](#0-0) 

The contract is then re-keyed under `new_operator` with `new_commission_percentage`: [2](#0-1) 

**Step 2 — `distribute` is called after lockup expires**

`distribute(staker, new_operator)` fetches the contract under `new_operator` and calls `distribute_internal(staker, new_operator, staking_contract)`: [3](#0-2) 

Inside `distribute_internal`, `update_distribution_pool` is called with `operator = new_operator`: [4](#0-3) 

**Step 3 — `old_operator` is not exempt**

Inside `update_distribution_pool`, the exemption check is `shareholder != operator`, where `operator` is now `new_operator`. `old_operator` is a shareholder and `old_operator != new_operator`, so the condition is `true`: [5](#0-4) 

The rewards that accumulated on `old_operator`'s pending commission during the lockup period are computed as `unpaid_commission = (current_worth - previous_worth) * new_commission_percentage / 100`, and the corresponding shares are transferred from `old_operator` to `new_operator`.

---

### Impact Explanation

`old_operator`'s earned commission is already in the `distribution_pool` as shares. When the pending_inactive stake earns rewards during the lockup period, those rewards grow the pool's total value. On the next `distribute` call, `update_distribution_pool` charges `new_commission_percentage` on that growth against `old_operator`'s shares, transferring APT from `old_operator` to `new_operator`. This is a direct, on-chain theft of APT staking balance from `old_operator`.

The staker controls `new_commission_percentage` (0–100). Setting it to 100% causes `new_operator` to capture **all** rewards that accumulate on `old_operator`'s pending commission during the lockup period.

---

### Likelihood Explanation

The entrypoint is `switch_operator`, callable by any staker with an existing staking contract — no privileged access required. The staker and `new_operator` can collude. The lockup period on mainnet is typically months, so meaningful rewards accumulate on the pending commission. The trigger (`distribute`) is a public entry function callable by anyone.

---

### Recommendation

In `distribute_internal`, before calling `update_distribution_pool`, iterate over the distribution pool's shareholders and identify any address that is not the current `operator` but was a previous operator (i.e., has shares but is not the staker). The cleanest fix is to pass the **recipient's own address** as the exempt operator when that recipient is a former operator — or, more robustly, track a set of "commission recipients" in the pool who are always exempt from further commission charges. A simpler mitigation: in `update_distribution_pool`, exempt **all** shareholders whose shares were added as commission (i.e., added via `add_distribution` with `recipient == operator at that time`) by storing a flag or by exempting any shareholder that is not the staker address.

---

### Proof of Concept

```move
#[test(aptos_framework = @0x1, staker = @0x123, operator_a = @0x234, operator_b = @0x345)]
public entry fun test_commission_on_commission_theft(
    aptos_framework: &signer,
    staker: &signer,
    operator_a: &signer,
    operator_b: &signer,
) acquires Store, BeneficiaryForOperator {
    // 1. Setup: create staking contract with operator_a at 10% commission
    setup(aptos_framework, staker, operator_a, INITIAL_BALANCE);
    let staker_addr = signer::address_of(staker);
    let op_a = signer::address_of(operator_a);
    let op_b = signer::address_of(operator_b);
    create_staking_contract(staker, op_a, op_a, INITIAL_BALANCE / 2, 10, b"");

    // 2. Accumulate rewards (simulate epoch)
    let pool_addr = stake_pool_address(staker_addr, op_a);
    stake::end_epoch(); // rewards accumulate

    // 3. switch_operator to operator_b with 50% commission
    //    This internally calls request_commission_internal(op_a, ...) and records
    //    op_a's commission in distribution_pool, then re-keys contract under op_b
    switch_operator(staker, op_a, op_b, 50);

    // 4. More rewards accumulate on the pending_inactive (op_a's commission)
    stake::end_epoch();

    // 5. Record op_a's expected payout before distribute
    let op_a_balance_before = coin::balance<AptosCoin>(op_a);

    // 6. distribute() — passes operator=op_b into update_distribution_pool,
    //    which charges op_a's shares at 50% commission rate
    distribute(staker_addr, op_b);

    let op_a_balance_after = coin::balance<AptosCoin>(op_a);
    let op_b_balance_after = coin::balance<AptosCoin>(op_b);

    // op_a should have received full commission_amount + rewards on it
    // but instead received less due to op_b's commission being charged on op_a's shares
    // Assert: op_b received more than 0 (stole from op_a's commission rewards)
    assert!(op_b_balance_after > 0, 0); // op_b stole from op_a
    // Assert: op_a received less than their full entitlement
    // (exact amounts depend on reward rate and timing)
}
```

```text
    fun add_distribution(
        operator: address,
        staking_contract: &mut StakingContract,
        recipient: address,
        coins_amount: u64,
    ) {
        let distribution_pool = &mut staking_contract.distribution_pool;
        let (_, _, _, total_distribution_amount) =
            stake::get_stake(staking_contract.pool_address);
        update_distribution_pool(
            distribution_pool,
            total_distribution_amount,
            operator,
            staking_contract.commission_percentage
        );

        distribution_pool.buy_in(recipient, coins_amount);
        let pool_address = staking_contract.pool_address;
        emit(AddDistribution { operator, pool_address, amount: coins_amount });
    }
```
