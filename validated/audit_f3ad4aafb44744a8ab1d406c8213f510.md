### Title
Unauthenticated `/shutdown` HTTP request terminates the signer's event-processing thread - ([File: libsigner/src/events.rs])

### Summary
`SignerEventReceiver::next_event` matches the literal URL `/shutdown` on any POST request and unconditionally sets `stop_signal` and returns `EventError::Terminated`, with no verification of origin, authentication token, or shared secret. Any remote party who can reach the signer's bound event-receiver port (which the sample config documents as bindable to `0.0.0.0`) can send a single crafted HTTP request to permanently halt the signer's event stream.

### Finding Description
The broken equality is: the code treats "a message with URL `/shutdown`" as equivalent to "a message from the node/an authorized stop-signaler," when in fact `next_event` performs zero authentication of the request's origin before executing the irreversible stop action [3](#0-2) . The internal `SignerStopSignaler::send` mechanism constructs exactly this kind of raw HTTP `POST /shutdown` request and fires it at `self.local_addr` with no credential attached [4](#0-3) , confirming that this is the sole "authorization" mechanism intended — reachability of the TCP endpoint itself. Since `bind` simply opens an `HttpServer` on the configured `SocketAddr` with no ACL [5](#0-4) , and the `endpoint` config is explicitly documented/sample-configured as `0.0.0.0:30000` [1](#0-0) , any remote TCP peer reaching that port can request `/shutdown` directly. The event-receiver thread's `main_loop` (driven by repeated `next_event` calls) will subsequently observe `is_stopped() == true` or the `Terminated` error and exit [6](#0-5) , and per `RunningSigner::join`/`spawn` wiring the event thread's termination halts the signer's ability to receive further block proposals, StackerDB chunks, or burn-block events from the node [7](#0-6) . No `auth_password`/`auth_token` shared secret used elsewhere for node RPC is checked here at all [8](#0-7) .

### Impact Explanation
A remote attacker who can reach the signer's event port sends one `POST /shutdown` request and permanently stops the event-receiver thread, cutting the signer off from the node's block proposal, burn-block, and StackerDB chunk events. This is a single-message, unauthenticated, remote DoS against a component whose availability is required for the signer's participation in block signing — matching the "Critical: remote crash/unauthenticated DoS from few messages" category. It is trivially repeatable against every reachable signer instance.

### Likelihood Explanation
The only precondition is TCP reachability to the configured `endpoint` port; the documented/sample configuration binds it to `0.0.0.0`, i.e., all interfaces, not `127.0.0.1` [1](#0-0) . No signer key, node RPC secret, StackerDB slot, or any privileged role is needed — a bare TCP connection and a static HTTP request suffice, and the code itself warns operators about exactly this exposure risk without providing an in-code mitigation [2](#0-1) .

### Recommendation
Require the `/shutdown` (and ideally all POST) endpoints to validate a shared secret/token (e.g., reuse or introduce an `auth_password`-style header check) before acting, and/or restrict the stop-signal path to loopback-only by construction (e.g., have `SignerStopSignaler` use a dedicated local-only control channel such as a Unix domain socket or an in-process channel rather than a network-reachable HTTP endpoint), so remote unauthenticated peers cannot trigger termination.

### Proof of Concept
Rust test in `libsigner::events` (or `libsigner/src/tests/http.rs`):
1. Construct `SignerEventReceiver::<T>::new(false)` and call `bind("127.0.0.1:0".parse().unwrap())` (or an externally-reachable address) to get the actual bound port.
2. Spawn `next_event()` in a loop on a background thread.
3. From a separate `TcpStream` (simulating a "stranger" with no relation to the signer's `stop_signal`/`SignerStopSignaler`), connect to the bound address and write the raw bytes:
   `"POST /shutdown HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\nContent-Length: 0\r\n\r\n"`.
4. Assert that `event_receiver.is_stopped() == true` shortly after, and that the background `next_event` loop returns `Err(EventError::Terminated)` at `libsigner/src/events.rs:443-445`, without the stranger ever presenting any signer-derived credential.
