### Title
Unauthenticated `/shutdown` HTTP request permanently halts `SignerEventReceiver::main_loop` - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` handles any POST to `/shutdown` by unconditionally setting `stop_signal` to `true` and returning `EventError::Terminated`, with no check that the request came from the node itself (i.e., from `SignerStopSignaler::send`). Any TCP client that can reach the signer's bound event-receiver socket can send a bare `POST /shutdown` request and permanently stop the signer's event-processing loop.

### Finding Description
The intended invariant is "shutdown is authorized == request originated from `SignerStopSignaler::send`", since that is the only sanctioned caller [1](#0-0) . However, in `next_event`, the `/shutdown` branch performs no authentication, origin check, secret comparison, or any verification at all before acting:

```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
}
``` [2](#0-1) 

This is reached from the generic request-dispatch inside `next_event`, which only checks that the HTTP method is `POST` before routing based on `request.url()` [3](#0-2) . Once `stop_signal` is set to `true`, `EventReceiver::main_loop` observes `is_stopped()` returning `true` on its next iteration, or immediately receives `EventError::Terminated` and breaks out of the loop:

```rust
Err(EventError::Terminated) => {
    // we're done
    info!("Caught termination signal");
    break;
}
``` [4](#0-3) 

The `stop_signal` `AtomicBool` has no reset path — once set, `is_stopped()` permanently returns `true` [5](#0-4) , so `main_loop` will never process another event again without restarting the whole signer process. The attacker's exact payload is simply:
```
POST /shutdown HTTP/1.1\r\nHost: <addr>\r\nConnection: close\r\nContent-Length: 0\r\n\r\n
```
No body validation, secret, or signature is required — the branch is reached purely from URL string equality and HTTP method equality.

### Impact Explanation
Any single unauthenticated message causes the signer's `SignerEventReceiver` thread to exit `main_loop` and stop consuming StackerDB chunk events, block-validation responses, burn-block events, and new-block events from the node. This is a message-drop-permanently denial of service against the signer's own event pipeline: the signer will stop receiving `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/new_block` notifications from its co-located node until restarted, which can prevent the signer from participating in block signing. This matches the "Critical - remote crash/unauthenticated DoS from few messages" category, since a single crafted POST from an unprivileged remote party permanently disables the signer's event stream.

### Likelihood Explanation
The only precondition is that the attacker can open a TCP connection to the address:port on which the signer's `SignerEventReceiver` HTTP server is bound (the `event_server`/endpoint address configured for the signer to receive node event-observer callbacks) and send a well-formed but trivial HTTP POST — no secret, no signature, no peer/slot ownership, and no privileged role is required. This is a single-message, deterministic, always-reproducible attack; there is no rate limit or retry logic protecting the `/shutdown` path.

### Recommendation
Add an authentication/authorization check before honoring `/shutdown`: e.g., only accept the shutdown request if it originates from a loopback/local connection (bind the listener to localhost only) and/or require a shared secret or token generated at `bind()` time that only `SignerStopSignaler` knows and includes in its request, verifying it inside `next_event` before setting `stop_signal`.

        SignerEventReceiver::new(false);

    let (tx, _rx) = channel();

        receiver.main_loop();
    });

    // Attacker: plain TCP connection, no secret, no SignerStopSignaler involved.

    stream.write_all(req.as_bytes()).unwrap();

    // main_loop should exit purely from this unauthenticated request.
    handle.join().unwrap();
    // Assert: main_loop returned (i.e., it exited), proving the event
    // receiver thread was permanently halted without SignerStopSignaler::send
    // ever being called.
}

                }
            };

            if request.url() == "/status" {

                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }

            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
