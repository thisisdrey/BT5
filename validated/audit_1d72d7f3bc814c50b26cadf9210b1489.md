**Analysis:** `POA_TOKEN_FT_DEPOSIT_GAS` is not an entrypoint or ownership-transfer mechanism — it is a static `Gas` constant used to bound the gas allocated to a cross-contract `ft_deposit` call. [1](#0-0) 

The only function that consumes this constant is `ft_deposit`, which is gated by `#[access_control_any(roles(Role::DAO, Role::TokenDepositer))]`, meaning only accounts holding the `DAO` or `TokenDepositer` role can invoke it at all. [2](#0-1) 

There is no "propose owner / accept owner" two-step transfer function, no pending-owner state, and no path in this file where an attacker-controlled `owner_id` argument affects who holds administrative privileges — `owner_id` in `ft_deposit` is merely the recipient of the deposited FT balance, not a contract admin. Ownership/role management for this contract is handled entirely by the `near_plugins::AccessControllable` framework (super-admin/admin/grantee model set up in `new`), which is not touched or bypassed anywhere in this file. [3](#0-2) 

Since the premise of the question (an ownership/admin-transfer entrypoint reachable by a non-owner) does not exist in this file, and the only guarded function using the named constant is properly access-controlled, the claimed invariant break does not apply.

    #[pause]
    #[access_control_any(roles(Role::DAO, Role::TokenDepositer))]
    #[payable]
    fn ft_deposit(
        &mut self,
        token: String,
        owner_id: AccountId,
        amount: U128,
        msg: Option<String>,
        memo: Option<String>,
    ) -> Promise {
        require!(
            env::attached_deposit() >= self.bridge_token_storage_deposit_required,
            "not enough deposit attached for token storage_deposit"
        );
        require!(self.tokens.contains(&token), "token does not exist");

        let token_id = Self::token_id(token);

        if let Some(msg) = msg {
            require!(
                env::prepaid_gas().saturating_sub(env::used_gas())
                    > POA_TOKEN_FT_DEPOSIT_GAS.saturating_add(POA_TOKEN_FT_TRANSFER_CALL_MIN_GAS),
                "insufficient gas"
            );
            ext_poa_fungible_token::ext(token_id.clone())
                .with_attached_deposit(env::attached_deposit())
                .with_static_gas(POA_TOKEN_FT_DEPOSIT_GAS)
                .ft_deposit(env::current_account_id(), amount, None)
                .then(
                    ext_ft_core::ext(token_id)
                        .with_attached_deposit(NearToken::from_yoctonear(1))
                        .ft_transfer_call(owner_id, amount, memo, msg),
                )
        } else {
            ext_poa_fungible_token::ext(token_id)
                .with_attached_deposit(env::attached_deposit())
                .with_static_gas(POA_TOKEN_FT_DEPOSIT_GAS)
                .ft_deposit(owner_id, amount, memo)
        }
    }
