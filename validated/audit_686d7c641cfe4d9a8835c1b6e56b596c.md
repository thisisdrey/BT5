This report describes a JavaScript-specific vulnerability class — **prototype pollution** via `lodash.merge`/`defaultsDeep`, where an attacker-supplied `{constructor: {prototype: {...}}}` payload walks up to `Object.prototype` and mutates a property shared by *every* object in the runtime. That primitive fundamentally depends on JavaScript's dynamic prototype-chain object model.

Go has no equivalent runtime object model: struct field access is resolved by fixed, compile-time-determined offsets (not dynamic string-keyed property lookup with an inheritable global prototype), and there is no shared "object prototype" that untrusted data can walk up to and poison.

I looked at the closest analogous Go constructs — the merge/decode paths in `encoding/json`:

- `encoding/json`'s `Unmarshal` documents that "later values will replace or be merged into prior values, depending on the field type (in particular maps and structs will have values merged, while other types have values replaced)" [1](#0-0) , and the object-decoding path `(*decodeState).object` only ever writes into fields resolved via `cachedTypeFields(t)` for structs or explicit map keys for maps [2](#0-1) .
- The newer `encoding/json/v2` package implements RFC 7396-style merge semantics for map/struct unmarshaling [3](#0-2) , again bounded strictly to the destination Go type's declared fields/keys, with duplicate names either merged per key or rejected via `newDuplicateNameError` [4](#0-3) .

None of these paths allow an attacker-controlled key (e.g., a `"constructor"` or `"__proto__"`-like string) to escape the target value's own field/key namespace and mutate a globally shared type or other unrelated objects — there is no mechanism in Go's type system for a decoded key to reach a "prototype" shared across all values of a type, unlike JS's `Object.prototype`. Reflection-based field writes (`reflect.Value.Field`, `reflect.Value.SetMapIndex`) operate on a specific value's memory and offsets [5](#0-4) , never on a shared class-level prototype object.

Because the underlying primitive (a shared, walkable, attacker-poisonable global prototype object) doesn't exist in Go, there is no faithful analog of this CVE in this repository, and stretching `encoding/json` merge semantics into a "prototype pollution" claim would not be a real, reproducible vulnerability — it's a difference in language object models, not a missing check that was later patched.

### No vulnerability found for this question.

// Field returns the i'th field of the struct v.
// It panics if v's Kind is not [Struct] or i is out of range.
func (v Value) Field(i int) Value {
	if v.kind() != Struct {
		panic(&ValueError{"reflect.Value.Field", v.kind()})
	}
	tt := (*structType)(unsafe.Pointer(v.typ()))
	if uint(i) >= uint(len(tt.Fields)) {
		panic("reflect: Field index out of range")
	}
	field := &tt.Fields[i]
	typ := field.Typ

	// Inherit permission bits from v, but clear flagEmbedRO.
	fl := v.flag&(flagStickyRO|flagIndir|flagAddr) | flag(typ.Kind())
	// Using an unexported field forces flagRO.
	if !field.Name.IsExported() {
		if field.Embedded() {
			fl |= flagEmbedRO
		} else {
			fl |= flagStickyRO
		}
	}
	if fl&flagIndir == 0 && typ.Size() == 0 {
		// Special case for picking a field out of a direct struct.
		// A direct struct must have a pointer field and possibly a
		// bunch of zero-sized fields. We must return the zero-sized
		// fields indirectly, as only ptr-shaped things can be direct.
		// See issue 74935.
		// We use &zeroVal[0] instead of v.ptr as it doesn't matter and
		// we can avoid pinning a possibly now-unused object.
		// Don't use nil, see issue 77779.
		return Value{typ, unsafe.Pointer(&zeroVal[0]), fl | flagIndir}
	}

	// Either flagIndir is set and v.ptr points at struct,
	// or flagIndir is not set and v.ptr is the actual struct data.
	// In the former case, we want v.ptr + offset.
	// In the latter case, we must have field.offset = 0,
	// so v.ptr + field.offset is still the correct address.
	ptr := add(v.ptr, field.Offset, "same as non-reflect &v.field")
	return Value{typ, ptr, fl}
