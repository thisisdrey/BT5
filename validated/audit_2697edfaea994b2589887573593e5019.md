### Title
Unliquidatable bad debt keeps accruing interest and mints unbacked synthetic tokens to the fee collector - (File: contracts/DebtToken.sol)

### Summary
Metronome's `Pool.liquidate` only clears debt when a liquidator repays synthetic tokens in exchange for seized collateral, and it reverts entirely when the collateral to seize exceeds the account's remaining deposit balance (`AmountIsTooHigh`). Once a position's collateral value falls below the debt amount, no liquidator can profitably repay it, so the debt becomes bad debt. However, `DebtToken.accrueInterest()` computes interest on the full `totalSupply_` — which includes the bad-debt principal — and mints that interest as brand-new synthetic tokens to `pool.feeCollector()`. This reproduces the JPEG'd bug class: interest generated by unbacked debt is minted as real, circulating synths.

### Finding Description [1](#0-0) 

`Pool.liquidate` requires:
1. The position to be unhealthy (`PositionIsHealthy` revert otherwise).
2. `amountToRepay_` capped at `maxLiquidable` (default 50% of debt balance).
3. `quoteLiquidateOut` computes `_totalSeized = repaidUsd * (1 + liquidatorIncentive)` converted to collateral units, and the call reverts with `AmountIsTooHigh` when `_totalSeized > depositToken_.balanceOf(account_)`.

When collateral price crashes such that collateralUSD < debtUSD, any repayment sized to seize within the account's balance still pays the liquidator collateral worth less than the synths burned, so rational liquidators do not act. Worse, for a deeply underwater account, even a small `amountToRepay_` can produce `_totalSeized > balanceOf(account_)`, making liquidation revert outright — the residual bad debt cannot be cleared by anyone.

Meanwhile in `DebtToken`: [2](#0-1) [3](#0-2) 

`_calculateInterestAccrual` computes `_interestAmountAccrued = rate * totalSupply_`, where `totalSupply_` is the aggregate principal of all debtors including permanently-insolvent ones. `accrueInterest()` then mints the full accrued amount (plus any `pendingInterestFee`) to `feeCollector`. If minting fails (e.g. synth inactive), the amount is parked in `pendingInterestFee` and is later mintable by *anyone* via the permissionless `collectPendingInterestFee()` (DebtToken.sol#L220-L226). There is no bad-debt accounting anywhere — no `badDebtPortion`, no haircut, no insolvency tracking.

### Impact Explanation
Protocol insolvency / unbacked synthetic supply. Interest on debt that can never be repaid is minted as spendable synthetic tokens to the fee collector (or extracted via `collectPendingInterestFee`). Each accrued token is a claim on collateral that does not exist, diluting the backing of every other synth holder. Because accrual compounds (`debtIndex` grows, `totalSupply_` grows), the unbacked fraction grows exponentially the longer bad debt persists. This directly degrades the synthetic asset's solvency invariant: total synth supply is no longer covered by system collateral.

### Likelihood Explanation
Requires only an ordinary market crash in a listed collateral — no privileged actor, no oracle manipulation, no governance action. Any EOA creates the initial position (`DepositToken.deposit` + `DebtToken.issue`); the crash (or a same-transaction price move where the oracle permits it) renders it underwater; liquidation reverts or is economically irrational; `accrueInterest` is invoked on every `issue`, `repay`, `repayAll`, `liquidate`, `mint`, and `flashIssue`, so unbacked minting is continuous. Deeply-underwater positions revert liquidations via `AmountIsTooHigh`, guaranteeing permanent bad debt rather than a one-time loss.

### Recommendation
- Track bad debt explicitly (e.g. `badDebtAmount` per debt token) with a public function allowing anyone to flag positions where `collateralInUsd < debtInUsd`, optionally rewarding the flagger with a portion of seized collateral.
- In `accrueInterest`, mint only interest attributable to solvent debt: `collectible = interestAccrued * (totalSupply_ - badDebtAmount) / totalSupply_`, and exclude bad-debt principal from the index growth.
- Add a bad-debt socialization/write-off path (e.g. seize all remaining collateral for partial repayment without the `maxLiquidable`/`AmountIsTooHigh` constraint) so hopeless positions can be fully cleared rather than compounding forever.

### Proof of Concept
Hardhat fork (mainnet/Base pool, following existing `test/E2E.mainnet.test.ts` setup):

```ts
// 1. alice deposits USDC collateral and issues msUSD up to her limit
await msdUSDC.deposit(parseUnits('400', 6), alice.address);
const { _issuableInUsd } = await pool.debtPositionOf(alice.address);
await msUSDDebt.issue(_issuableInUsd, alice.address);

// 2. Collateral price crashes (mock oracle price move, as tests do with
//    `newMetPrice` / masterOracle mock): collateral USD now << debt USD.
await masterOracleMock.setPrice(usdc.address, crashedPrice);

// 3. Position is unhealthy; liquidation is impossible for a liquidator:
//    - full repay: `_totalSeized > depositToken.balanceOf(alice)` -> AmountIsTooHigh
//    - any profitable repay size also reverts or is economically irrational
await expect(
  pool.connect(bob).liquidate(msUSD.address, alice.address, repayAmt, msdUSDC.address)
).revertedWithCustomError(pool, 'AmountIsTooHigh');

// 4. Bad debt still accrues. Advance time and accrue:
const feeCollector = await pool.feeCollector();
const before = await msUSD.balanceOf(feeCollector);
await time.increase(time.duration.years(1));
await msUSDDebt.accrueInterest(); // public, anyone can call
const after = await msUSD.balanceOf(feeCollector);

// Interest minted on unbacked debt:
expect(after.sub(before)).to.be.gt(0);
// Every further accrual compounds: principalOf(alice) grows via debtIndex,
// totalSupply_ grows, and the unbacked minted interest grows with it.
```

Note: I verified `accrueInterest` and the liquidation revert path directly in `contracts/DebtToken.sol` and `contracts/Pool.sol`. `quoteLiquidateOut`'s exact seize formula (`liquidatorIncentive`, `protocolLiquidationFee` split in `FeeProvider`/`DepositToken.seize`) was not fully re-read within the iteration budget, but the `AmountIsTooHigh` guard at `Pool.sol:583` and the unconditional full-supply interest mint at `DebtToken.sol:169-178` are sufficient to establish the analog.

        ISyntheticToken syntheticToken_,
        address account_,
        uint256 amountToRepay_,
        IDepositToken depositToken_

        override
        whenNotShutdown
        nonReentrant
        onlyIfSyntheticTokenExists(syntheticToken_)
        onlyIfDepositTokenExists(depositToken_)
        returns (uint256 _totalSeized, uint256 _toLiquidator, uint256 _fee)
    {
        address _msgSender = _msgSender();

        if (amountToRepay_ == 0) revert AmountIsZero();
        if (_msgSender == account_) revert CanNotLiquidateOwnPosition();

        IDebtToken _debtToken = debtTokenOf[syntheticToken_];
        _debtToken.accrueInterest();

        (bool _isHealthy, , , , ) = debtPositionOf(account_);

        if (_isHealthy) {
            revert PositionIsHealthy();
        }

        uint256 _debtTokenBalance = _debtToken.balanceOf(account_);

        if (amountToRepay_.wadDiv(_debtTokenBalance) > maxLiquidable) {
            revert AmountGreaterThanMaxLiquidable();
        }

        if (debtFloorInUsd > 0) {
            uint256 _newDebtInUsd = masterOracle().quoteTokenToUsd(
                address(syntheticToken_),
                _debtTokenBalance - amountToRepay_
            );
            if (_newDebtInUsd > 0 && _newDebtInUsd < debtFloorInUsd) {
                revert RemainingDebtIsLowerThanTheFloor();
            }
        }

        (_totalSeized, _toLiquidator, _fee) = quoteLiquidateOut(syntheticToken_, amountToRepay_, depositToken_);

    function accrueInterest() public override {
        (
            uint256 _interestAmountAccrued,
            uint256 _debtIndex,
            uint256 _lastTimestampAccrued
        ) = _calculateInterestAccrual();

        if (block.timestamp == _lastTimestampAccrued) {
            return;
        }

        lastTimestampAccrued = block.timestamp;

        if (_interestAmountAccrued > 0) {
            totalSupply_ += _interestAmountAccrued;
            debtIndex = _debtIndex;

            // Note: Address states where minting will fail (e.g. the token is inactive, it reached max supply, etc)
            try syntheticToken.mint(pool.feeCollector(), _interestAmountAccrued + pendingInterestFee) {
                pendingInterestFee = 0;
            } catch {
                pendingInterestFee += _interestAmountAccrued;
            }
        }
    }

    function _calculateInterestAccrual()
        private
        view
        returns (uint256 _interestAmountAccrued, uint256 _debtIndex, uint256 _lastTimestampAccrued)
    {
        _lastTimestampAccrued = lastTimestampAccrued;
        _debtIndex = debtIndex;

        if (block.timestamp > _lastTimestampAccrued) {
            uint256 _interestRateToAccrue = interestRatePerSecond() * (block.timestamp - _lastTimestampAccrued);
            if (_interestRateToAccrue > 0) {
                _interestAmountAccrued = _interestRateToAccrue.wadMul(totalSupply_);
                _debtIndex += _interestRateToAccrue.wadMul(_debtIndex);
            }
        }
    }
