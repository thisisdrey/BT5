### Title
Attacker-Controlled `CertVersion` Field Lets an Unauthenticated Peer Select an Arbitrary Certificate-Parsing Codec During Handshake - (File: `handshake/machine.go`)

### Summary
During the nebula noise handshake, the peer sends a `CertVersion` field inside the unauthenticated handshake payload. This value is used verbatim, before any certificate/CA verification, to select which certificate-decoding implementation (`unmarshalCertificateV1` protobuf codec, or `unmarshalCertificateV2` ASN.1 codec) is used to parse the attached certificate bytes. This is the same bug class as the Scroll `commitBatch` finding: an attacker-controlled version selector routes data through a decoder that was not designed to handle it, decoupling the wire-format library used from the actual encoding of the payload.

### Finding Description
The wire-level handshake payload carries a `CertVersion` field that is fully attacker controlled and parsed before authentication: [1](#0-0) 

That field flows unmodified into `cert.Recombine`, which switches decoding strategy purely on the caller-declared version, not on any property of the actual bytes: [2](#0-1) 

The call site, `Machine.validateCert`, passes the untrusted `payload.CertVersion` straight into `Recombine` prior to any signature or CA-pool verification: [3](#0-2) 

`Version1`/`VersionPre1` route to the protobuf-based `unmarshalCertificateV1`: [4](#0-3) 

`Version2` routes to the ASN.1/cryptobyte-based `unmarshalCertificateV2`: [5](#0-4) 

Exactly as in the Scroll analog — where `_version` picks `BatchHeaderV0Codec` vs `BatchHeaderV1Codec` independent of the batch's real version — here `CertVersion` picks the protobuf vs ASN.1 certificate codec independent of how the certificate bytes were actually produced. The value is taken from an unauthenticated, pre-verification part of the handshake, so any peer that can send a handshake packet controls it (`processPayload`/`ProcessPacket` path), not merely an already-authorized party.

### Impact Explanation
This is a decoder-confusion condition reachable pre-authentication (before CA pool verification, curve check, or public key comparison run). At minimum it lets an unauthenticated remote peer force nebula's cert-parsing logic down an arbitrary path unrelated to the true encoding of the bytes it supplies, which is the exact "arbitrary library selection" class described in the report. Both concrete decoders (`unmarshalCertificateV1`, `unmarshalCertificateV2`) do bounds/format validation and ultimately require a valid CA-chained signature to be accepted by `m.verifier`, so a full authentication bypass was not established; the confirmed impact is limited to protocol/implementation-hygiene weakening of the version binding used before trust decisions, consistent with the "low risk, to be resolved" framing of the original report.

### Likelihood Explanation
Likelihood is comparable to the original: any peer initiating or responding to a handshake controls this field unconditionally (no signature or authorization gate exists at this point in the protocol), so the “arbitrary version” condition is trivially reachable by any remote party attempting a handshake, unauthenticated.

### Recommendation
Do not let the peer's declared `CertVersion` alone select the certificate codec used to interpret untrusted bytes. Cross-check that the codec selected for `payload.CertVersion` is consistent with expectations (e.g., only accept versions the local `CertState`/verifier explicitly supports, and independently confirm the decoded certificate's self-reported `Version()` matches `payload.CertVersion` before trusting any downstream branching decisions in `validateCert`).

### Proof of Concept
Not applicable — no working exploit chain to a concrete authentication bypass, decryption/forgery/replay, firewall bypass, state poisoning, or crash was identified; the finding is a structural analog of the reported bug class rather than a demonstrated compromise.

```go
func Recombine(v Version, rawCertBytes, publicKey []byte, curve Curve) (Certificate, error) {
	if publicKey == nil {
		return nil, ErrNoPeerStaticKey
	}

	if rawCertBytes == nil {
		return nil, ErrNoPayload
	}

	var c Certificate
	var err error

	switch v {
	// Implementations must ensure the result is a valid cert!
	case VersionPre1, Version1:
		c, err = unmarshalCertificateV1(rawCertBytes, publicKey)
	case Version2:
		c, err = unmarshalCertificateV2(rawCertBytes, publicKey, curve)
	default:
		return nil, ErrUnknownVersion
	}
```

```go
func (m *Machine) validateCert(payload Payload) error {
	cred := m.getCred(m.myVersion)
	if cred == nil {
		m.failed = true
		return fmt.Errorf("%w: %v", ErrNoCredential, m.myVersion)
	}
	rc, err := cert.Recombine(
		cert.Version(payload.CertVersion),
		payload.Cert,
		m.hs.PeerStatic(),
		cred.Cert.Curve(),
	)
	if err != nil {
		m.failed = true
		return fmt.Errorf("recombine cert: %w", err)
	}
```

```go
func unmarshalCertificateV2(b []byte, publicKey []byte, curve Curve) (*certificateV2, error) {
	l := len(b)
	if l == 0 || l > MaxCertificateSize {
		return nil, ErrBadFormat
	}

	input := cryptobyte.String(b)
	// Open the envelope
	if !input.ReadASN1(&input, asn1.SEQUENCE) || input.Empty() {
		return nil, ErrBadFormat
	}

	// Grab the cert details, we need to preserve the tag and length
	var rawDetails cryptobyte.String
	if !input.ReadASN1Element(&rawDetails, TagCertDetails) || rawDetails.Empty() {
		return nil, ErrBadFormat
	}

	//Maybe grab the curve
	var rawCurve byte
	if !readOptionalASN1Byte(&input, &rawCurve, TagCertCurve, byte(curve)) {
		return nil, ErrBadFormat
	}
```
