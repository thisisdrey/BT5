### Title
`go env -w` writes the persistent Go environment config file (which can contain GOPROXY credentials) with world-readable permissions - ([File: src/cmd/go/internal/envcmd/env.go])

### Summary
`go env -w` persists Go environment variables (including `GOPROXY`, which the `go` command explicitly supports embedding HTTP Basic Auth credentials into via URL userinfo, e.g. `GOPROXY=https://user:pass@proxy.example.com`) to a config file using `os.WriteFile(file, data, 0666)`. Because the mode is `0666` (before umask) rather than an owner-only mode like `0600`, on a system with a default umask (e.g. `022`), the resulting file is created world-readable (`0644`), letting any other local user read module-proxy credentials the same way the AWS CLI advisory describes for its credential/config files.

### Finding Description
An unprivileged local user runs `go env -w GOPROXY=https://user:pass@proxy.example.com` (a normal, documented workflow for configuring a private module proxy) or any other `go env -w KEY=VALUE`. This calls `updateEnvFile` in `src/cmd/go/internal/envcmd/env.go`, which resolves the config path via `cfg.EnvFile()` and writes the merged key/value lines with: [1](#0-0) 
`os.WriteFile(file, data, 0666)` — and if the directory doesn't exist, it creates it with `os.MkdirAll(..., 0777)` and retries with the same `0666` mode. `os.WriteFile` ultimately calls `OpenFile(name, O_WRONLY|O_CREATE|O_TRUNC, perm)`: [2](#0-1) 
On Unix, the requested permission bits are passed straight through to the `open(2)` syscall in `openFileNolog`, subject only to the process umask: [3](#0-2) 
No `checkEnvWrite` validation or later code tightens this mode (e.g., via `Chmod(0600)`); the value is stored and later re-serialized unencrypted as plaintext `KEY=VALUE` lines in this same file. With a default umask of `022`, the file ends up `0644` — readable by any local user on the host, exposing embedded proxy credentials.

### Impact Explanation
Concrete impact: local information disclosure of secrets (module-proxy Basic Auth credentials stored in `GOPROXY`) to any other unprivileged local user on a multi-user host — the same primitive as the reported AWS CLI advisory (CWE-732, world-readable credential/config file instead of owner-only 0600). This would fall under Go's PUBLIC track as a low/medium-severity local-disclosure hardening issue, not remote code execution or an authentication bypass.

### Likelihood Explanation
The victim workflow is entirely ordinary and requires no attacker control of the host: a developer configures a private Go module proxy with embedded credentials via `go env -w GOPROXY=...`, which is a documented and common way to authenticate against private proxies. The attacker only needs local, unprivileged access to the same machine (e.g., a shared build server or CI host) — no host/environment compromise or privileged access is presumed as the initial condition, matching the advisory's threat model.

### Recommendation
Change the file mode used in `updateEnvFile` (and the corresponding `os.MkdirAll` call) from `0666`/`0777` to `0600`/`0700` so the go env config file is created owner-only, consistent with how other credential-bearing files (e.g., `.netrc`) are expected to be protected.

### Proof of Concept
```go
package envcmd_test

import (
	"os"
	"path/filepath"
	"runtime"
	"testing"
)

// Simulates updateEnvFile's write call in
// src/cmd/go/internal/envcmd/env.go and shows the resulting file mode
// is group/world readable under a default umask, unlike 0600.
func TestEnvFileWorldReadable(t *testing.T) {
	if runtime.GOOS == "windows" {
		t.Skip("POSIX permission bits only")
	}
	dir := t.TempDir()
	file := filepath.Join(dir, "env")

	// mirrors: os.WriteFile(file, data, 0666) in updateEnvFile
	if err := os.WriteFile(file, []byte("GOPROXY=https://user:pass@proxy.example.com\n"), 0666); err != nil {
		t.Fatal(err)
	}

	fi, err := os.Stat(file)
	if err != nil {
		t.Fatal(err)
	}
	mode := fi.Mode().Perm()
	if mode&0044 != 0 {
		t.Fatalf("go env config file is group/world readable: mode=%v; credentials in GOPROXY are exposed to other local users", mode)
	}
}
```
Expected assertion failure under a default umask (022): the file mode is `0644`, i.e. `mode&0044 != 0`, demonstrating the config file (which may contain `GOPROXY` credentials) is readable by other local users — the same class of issue as GHSA-wfp6-f47h-hxc3. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3)

func WriteFile(name string, data []byte, perm FileMode) error {
	f, err := OpenFile(name, O_WRONLY|O_CREATE|O_TRUNC, perm)
	if err != nil {
		return err
	}
	_, err = f.Write(data)
	if err1 := f.Close(); err1 != nil && err == nil {
		err = err1
	}
	return err

func openFileNolog(name string, flag int, perm FileMode) (*File, error) {
	setSticky := false
	if !supportsCreateWithStickyBit && flag&O_CREATE != 0 && perm&ModeSticky != 0 {
		if _, err := Stat(name); IsNotExist(err) {
			setSticky = true
		}
	}

	var (
		r int
		s poll.SysFile
		e error
	)
	// We have to check EINTR here, per issues 11180 and 39237.
	ignoringEINTR(func() error {
		r, s, e = open(name, flag|syscall.O_CLOEXEC, syscallMode(perm))

	})
