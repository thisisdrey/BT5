Based on my research, this Go standard-library repository has no component analogous to the reported issue. The Python `redshift-connector` vulnerability involves a database client blindly `eval()`-ing/interpreting untrusted data sent back by a (potentially rogue) server, leading to RCE. The closest conceptual analog in this repo would be `encoding/gob`, which similarly decodes structured data from a remote peer and can even invoke arbitrary `GobDecoder`/`UnmarshalBinary`/`UnmarshalText` methods based on wire-supplied type information [1](#0-0) . However, the package's own documentation explicitly states it is not designed to be hardened against adversarial input and is outside the scope of the Go security policy, with the caveat that it should be used carefully with untrusted sources [2](#0-1) [3](#0-2) . This is a documented, accepted design tradeoff rather than an unpatched vulnerability, so it fails the "already-fixed/known-and-accepted" exclusion in the rules.

Additionally, `database/sql` itself does not parse wire-protocol data from servers directly — that responsibility is delegated entirely to third-party `driver.Rows` implementations [4](#0-3) , and `Scan`/`ConvertAssign` only perform type conversions on values already produced by the driver [5](#0-4) , so there is no equivalent "driver eval()-ing server response" primitive to match against.

No concrete, reproducible, in-scope Go analog to the reported eval()-injection RCE was found in this repository.

// decodeGobDecoder decodes something implementing the GobDecoder interface.
// The data is encoded as a byte slice.
func (dec *Decoder) decodeGobDecoder(ut *userTypeInfo, state *decoderState, value reflect.Value) {
	// Read the bytes for the value.
	n, ok := state.getLength()
	if !ok {
		errorf("GobDecoder: length too large for buffer")
	}
	b := state.b.Bytes()
	if len(b) < n {
		errorf("GobDecoder: invalid data length %d: exceeds input size %d", n, len(b))
	}
	b = b[:n]
	state.b.Drop(n)
	var err error
	// We know it's one of these.
	switch ut.externalDec {
	case xGob:
		gobDecoder, _ := reflect.TypeAssert[GobDecoder](value)
		err = gobDecoder.GobDecode(b)
	case xBinary:
		binaryUnmarshaler, _ := reflect.TypeAssert[encoding.BinaryUnmarshaler](value)
		err = binaryUnmarshaler.UnmarshalBinary(b)
	case xText:
		textUnmarshaler, _ := reflect.TypeAssert[encoding.TextUnmarshaler](value)
		err = textUnmarshaler.UnmarshalText(b)
	}
	if err != nil {
		error_(err)
	}
}
