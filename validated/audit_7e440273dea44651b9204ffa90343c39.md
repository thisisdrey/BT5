### Title
Unauthenticated `/shutdown` endpoint allows any peer able to reach the signer's event-receiver port to terminate the signer's event loop - (File: libsigner/src/events.rs)

### Summary
`SignerEventReceiver::next_event` dispatches solely on the raw HTTP request URL, with no authentication, shared secret, or source-address check. Any POST to `/shutdown` sets `stop_signal` to `true` and returns `EventError::Terminated`, which causes `EventReceiver::main_loop` to break and stop processing further signer events.

### Finding Description
In `next_event` [1](#0-0) , the request is dispatched purely by string-matching `request.url()` against fixed paths (`/status`, `/stackerdb_chunks`, `/proposal_response`, `/new_burn_block`, `/shutdown`, `/new_block`), with no verification of who sent the request. The `/shutdown` branch immediately does:

```rust
} else if request.url() == "/shutdown" {
    event_receiver.stop_signal.store(true, Ordering::SeqCst);
    Err(EventError::Terminated)
``` [2](#0-1) 

This is the same mechanism the legitimate `SignerStopSignaler::send` uses internally to notify itself across threads — it opens a `TcpStream` to its own `local_addr` and POSTs `/shutdown` with an arbitrary body [3](#0-2) . Nothing distinguishes this legitimate internal call from a request forged by any other TCP client that can reach the bound address: there is no shared secret, token, or `SocketAddr`/peer-identity check performed in the dispatch path before the `stop_signal` store executes.

Once `Err(EventError::Terminated)` propagates up, `EventReceiver::main_loop` matches on it and breaks the loop [4](#0-3) , permanently halting the signer's event-processing thread until an operator restarts the process.

### Impact Explanation
Any actor capable of opening a TCP connection to the signer's event-receiver bind address can send a single `POST /shutdown` (any body, even empty, since the body isn't read/parsed in this branch) and immediately and permanently stop the signer's `main_loop`. This is a repeatable, single-message, unauthenticated denial-of-service against a signer node's event pipeline — matching the "Critical - remote crash/unauthenticated DoS from few messages" category, since it stops the signer from receiving/proposing/validating StackerDB chunks, burn blocks, or new blocks going forward.

### Likelihood Explanation
The only precondition is TCP reachability to the event-receiver's bound socket. The prompt itself notes this is "typically loopback-bound but reachable from any process/peer that can route to it" — I was not able to fully confirm, within available tool budget, whether the production deployment configuration always restricts this bind address to loopback-only or whether it can be configured to bind on a non-loopback interface (this is configured in `stacks-signer/src/config.rs`, which I located but did not have iterations left to fully inspect). If the endpoint is reachable only via `127.0.0.1`, this reduces exploitability to local processes only (out of scope per the "unprivileged remote" threat model, which excludes local/physical access). If it can be bound to a non-loopback address (e.g., for containerized/remote node-signer topologies), the attack is trivially exploitable by any remote party with network access to that address, at negligible cost (one raw HTTP POST, no auth, no computation).

### Recommendation
Add authentication to the `/shutdown` (and ideally all) event-receiver endpoints — e.g., a shared secret token compared in constant time, or restrict the listener to bind strictly to loopback and additionally verify the peer socket address on each accepted connection matches the expected caller. Alternatively, replace the self-directed HTTP `/shutdown` POST mechanism with an in-process signal (e.g., closing the listening socket or using a `mio`/condvar-based interrupt) so that no network-reachable endpoint can trigger the stop.

use std::io::Write;
use std::net::TcpStream;
use std::sync::atomic::Ordering;

#[test]
fn test_unauthenticated_shutdown_via_raw_tcp() {
    let mut receiver: SignerEventReceiver<crate::v0::messages::SignerMessage> =
        SignerEventReceiver::new(false);
    let addr = receiver.bind("127.0.0.1:0".parse().unwrap()).unwrap();

    // Simulate an attacker (not the paired node) opening a raw TCP connection
    // and POSTing /shutdown with an arbitrary body.
    let mut stream = TcpStream::connect(addr).unwrap();
    let body = "attacker-controlled";
    let req = format!(
        "POST /shutdown HTTP/1.1\r\nHost: {addr}\r\nConnection: close\r\nContent-Length: {}\r\n\r\n{}",
        body.len(), body
    );
    stream.write_all(req.as_bytes()).unwrap();

    // next_event() observes the forged /shutdown POST with no auth check
    let result = receiver.next_event();
    assert!(matches!(result, Err(EventError::Terminated)));
    assert!(receiver.is_stopped()); // stop_signal now true, main_loop will exit
}
```
This test demonstrates that a bare, unauthenticated raw TCP client (standing in for any unprivileged attacker who can reach the port) can flip `stop_signal` to `true` and force `EventError::Terminated`, exactly as the internal `SignerStopSignaler` does, confirming no authentication gates this endpoint at `libsigner/src/events.rs:443-445`.

    fn next_event(&mut self) -> Result<SignerEvent<T>, EventError> {
        self.with_server(|event_receiver, http_server, _is_mainnet| {
            // were we asked to terminate?
            if event_receiver.is_stopped() {
                return Err(EventError::Terminated);
            }
            debug!("Request handling");
            let request = http_server.recv()?;
            debug!("Got request"; "method" => %request.method(), "path" => request.url());

            if request.url() == "/status" {
                request
                .respond(HttpResponse::from_string("OK"))
                .expect("response failed");
                return Ok(SignerEvent::StatusCheck);
            }

            if request.method() != &HttpMethod::Post {
                return Err(EventError::MalformedRequest(format!(
                    "Unrecognized method '{}'",
                    request.method(),
                )));
            }
            debug!("Processing {} event", request.url());
            if request.url() == "/stackerdb_chunks" {
                process_event::<T, StackerDBChunksEvent>(request)
            } else if request.url() == "/proposal_response" {
                process_event::<T, BlockValidateResponse>(request)
            } else if request.url() == "/new_burn_block" {
                process_event::<T, BurnBlockEvent>(request)
            } else if request.url() == "/shutdown" {
                event_receiver.stop_signal.store(true, Ordering::SeqCst);
                Err(EventError::Terminated)
            } else if request.url() == "/new_block" {
                process_event::<T, StacksBlockEvent>(request)
            } else {
                let url = request.url().to_string();
                debug!(
                    "[{:?}] next_event got request with unexpected url {}, return OK so other side doesn't keep sending this",
                    event_receiver.local_addr,
                    url
                );
                ack_dispatcher(request);
                Err(EventError::UnrecognizedEvent(url))
            }
        })?
    }
